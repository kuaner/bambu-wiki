## 导轨系统

轨道是 3D 打印机中影响使用寿命和精度的最重要因素。A2L 采用了全金属的运动导轨，在 X 轴使用了高质量的直线导轨，在 Y 轴使用了双轴心导轨和全金属导轮，这套导轨系统保证了用户不需要频繁调整 A2L 的运动组件，但需要定期的润滑和清洁，以减少磨损和异音，保证打印机的精度和寿命，并能有效防止导轨生锈。

## 所需工具

- 无尘布
- 酒精
- 镊子
- 润滑油和润滑脂（请勿混淆）

## XY 轴

### 维护频率

X 轴建议每一个月维护一次；Y 轴在首次开箱装机后和每打印 200 小时需要维护一次（打印机会有相应的HMS提醒）。

### 润滑 X 轴导轨

关闭打印机电源后，在无尘布上喷涂适量的酒精。

![jiujing.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/jiujing.jpg)

将工具头移动到最右侧。

![zuiyouce.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/zuiyouce.jpg)  
使用带酒精的无尘布擦拭 X 轴 2-3 次。

![cashi2.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/cashi2.jpg)  
将工具头移动到最左侧。

![zuizuoce.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/zuizuoce.jpg)  
重复擦拭工作。

![cashi1.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/cashi1.jpg)  
取出工具盒中的润滑油。

> 请勿使用润滑脂

![runhuayou.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/runhuayou.jpg)

在 X 轴线规上下表面涂抹润滑油。

|  |  |
| --- | --- |
| tuyou1.jpg | tuyou2.jpg |
| tuyou3.jpg | tuyou4.jpg |

使用无尘布擦拭多余的润滑油。

![cashi3.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/cashi3.jpg)

来回推拉工具头，确保润滑油遍布 X 轴线轨。

![xtuila.webp](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/xtuila.webp)

### 润滑 Y 轴导轨

在新的无尘布上喷涂适量的酒精。

![jiujing.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/jiujing.jpg)  
向上推动 X 轴，抬高工具头高度。

![taigao.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/taigao.jpg)  
将热床推向最前方，取下 Y 轴盖板。

![gaiban.png](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/gaiban.png)  
使用无尘布擦拭 Y 轴钢棒，清理旧润滑油或其他杂质。

|  |  |
| --- | --- |
| cashiy1.jpg | cashiy2.jpg |

再将热床移动到后侧，擦拭前段 Y 轴钢棒。

|  |  |
| --- | --- |
| cashiy3.jpg | cashiy4.jpg |

在 Y 轴钢棒上涂抹新的润滑油。

|  |  |
| --- | --- |
| tuyouy1.jpg | tuyouy2.jpg |
| tuyouy3.jpg | tuyouy4.jpg |

涂抹后来回拉动热床，确保润滑油遍布 Y 轴钢棒。

![tuilay.webp](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/tuilay.webp)

清理多余的润滑油，再将 Y 轴盖板盖回。

![qingliy.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/qingliy.jpg)

## Z轴 丝杆

### 维护频率

Z 轴建议每三个月维护一次。

### 润滑 Z 轴丝杆

将工具头推到最顶端，并在新的无尘布上喷涂适量的酒精。

![jiujing.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/jiujing.jpg)

擦拭丝杆表面，清理明显的异物。

|  |  |
| --- | --- |
| qingliz1.jpg | qingliz2.jpg |

擦拭同时向下推动 Z 轴，清除旧润滑脂以及其他杂质。

![qingliz3.webp](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/qingliz3.webp)  
![qingliz4.webp](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/qingliz4.webp)

再用同样方式擦拭丝杆顶部。

|  |  |
| --- | --- |
| qingliz5.jpg | qingliz6.jpg |

从工具盒中取出新的润滑脂。

![runhuazhi.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/runhuazhi.jpg)

将新的润滑脂点涂到丝杆上，再进行后续校准工作，确保润滑脂均匀分布在丝杆上。

![tumo1.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/tumo1.jpg)

## 校准

开机后在屏幕上点击“设置-维护-校准”，选择“振动补偿”并开始，此时 XYZ 轴将会开始运动。

![jiaozhun.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/jiaozhun.jpg)
