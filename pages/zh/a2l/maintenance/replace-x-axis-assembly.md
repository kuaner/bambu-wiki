## X 轴组件

![faz058.png](https://public-cdn.bblmw.com/wiki/new/a2l/danpintu/faz058.png)

## 何时使用本指南？

- X 轴导轨移动卡顿
- 拓竹售后技术支持建议更换

## 所需的工具和材料

X 轴组件

- H2.0 内六角螺丝刀
- 镊子（可选）

### **安全警告**

> **重要提醒！**
>
> **在进行任何维护工作之前，务必关闭打印机的电源**，包括对打印机的电子元件和工具头电线进行维护。在打印机通电时进行此类操作可能会导致短路，从而损坏电子设备和造成安全隐患。
>
> 在维护或故障排除过程中，您可能需要拆卸热端等部件，从而暴露电线和电子元件。如果它们在打印机仍处于通电状态时相互接触或与其他金属、电子元件接触，就可能发生短路。**这将损坏打印机的电子元件和造成其他问题。**
>
> 因此，**在进行任何维护前，务必关闭打印机并断开电源**，以防止短路或损坏打印机的电子原件，从而确保维护工作安全有效地进行。如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.com/zh/my/support/tickets?from=5)，我们将及时回复并提供帮助。

## **拆卸步骤**

### 1. 移除 X 轴同步带

参照教程移除 X 轴同步带：[更换 X 轴皮带](https://wiki.bambulab.com/zh/a2l/maintenance/replace-x-belt)

### 2. 移除工具头线缆（底座端）

使用 H2.0 内六角螺丝刀拆下图示两颗螺丝，拔出线缆。  
![xdjh006.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh006.jpg)![xdjh007.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh007.jpg)

### 3. 移除 X 轴

使用 H2.0 内六角螺丝刀先拧出橙色标记4颗螺丝。  
![xpd016.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd016.jpg)  
当拆除到两侧的各最后一颗螺丝时请用手托住X轴，以免X轴突然掉落损坏。使用 H2.0 内六角螺丝刀拧出剩余两颗蓝色标记螺丝，取下X轴。  
![xpd015.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd015.jpg)

### 4. 移除 X 电机盒

参照以下教程移除 X 电机盒：[更换 X 电机盒](https://wiki.bambulab.com/zh/a2l/maintenance/replace-x-axis-motor-cover)

### 5. 移除工具头

1. 移除前盖、热端硅胶套、热端；
2. 使用 H2.0 内六角螺丝刀拧出图示7颗螺丝，将挤出机向前拉出一段距离，翻转热端加热组件掀起，漏出后方四颗螺丝。

![xpd021.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd021.jpg)![xpd020.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd020.webp)

3. 使用 H2.0 内六角螺丝刀拧出图示四颗螺丝，取下整个工具头。

![xpd019.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd019.jpg)![xpd021.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd021.webp)

### 6. 移除 X 电机座

使用 H1.5 内六角螺丝刀拧下三颗螺丝，取下转接板，断开霍尔连接线。  
![x0115.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/x0115.jpg)

使用 H2.0 内六角螺丝刀拧下三颗螺丝，取下 X 电机座。  
![xpd022.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd022.jpg)

### 7. 移除配重块、霍尔连接线

使用 H2.0 内六角螺丝刀拧出图示两颗螺丝，取下配重块。  
![x011.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/x011.jpg)

将霍尔连接线从 X 轴型材内抽出。  
![x012.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/x012.jpg)

## **安装步骤**

### 1. 安装配重块、霍尔连接线

将配重块安装到新的 X 轴轨道组件上，使用 H2.0 内六角螺丝刀锁入两颗螺丝。  
![x010.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/x010.webp)![x011.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/x011.jpg)

将霍尔连接线重新穿入 X 轴型材内。  
![x0112.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/x0112.webp)![x0113.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/x0113.webp)

### 2. 安装 X 电机座

将电机座装回 X 轴，使用 H2.0 内六角螺丝刀锁入三颗螺丝。  
![xpd022.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd022.jpg)  
插回霍尔连接线，使用 H1.5 内六角螺丝刀锁入三颗螺丝。  
![x0114.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/x0114.webp)![x0115.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/x0115.jpg)

### 3. 安装工具头

将工具头安装到导轨滑块上，使用 H2.0 内六角螺丝刀锁入图示四颗螺丝。  
![xpd019.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd019.jpg)

将挤出机组件、热端加热组件装回原位，使用 H2.0 内六角螺丝刀依次锁入图示7颗螺丝。  
![xpd021.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd021.jpg)

### 4. 安装 X 电机盒

参照以下教程安装 X 电机盒：[更换 X 电机盒](https://wiki.bambulab.com/zh/a2l/maintenance/replace-x-axis-motor-cover)

### 5. 安装 X 轴

将 X 轴装回龙门架，并用手固定住，使用 H2.0 内六角螺丝刀先左右各锁入一颗螺丝固定 X 轴。  
![xpd015.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd015.jpg)  
使用 H2.0 内六角螺丝刀锁入剩余四颗螺丝。  
![xpd016.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd016.jpg)

### 6. 移除工具头线缆（底座端）

将线缆插头的凸起部分对准后盖的缺口插入，使用 H2.0 内六角螺丝刀锁入两颗螺丝。  
![xdjh007.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh007.jpg)![xdjh006.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh006.jpg)

### 7. 安装 X 轴同步带

参照教程装回X轴同步带：[更换 X 轴皮带](https://wiki.bambulab.com/zh/a2l/maintenance/replace-x-belt)
