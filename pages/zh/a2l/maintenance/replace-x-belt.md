## X 同步带

![fab013.png](https://public-cdn.bblmw.com/wiki/new/a2l/danpintu/fab013.png)

## 何时使用本指南？

- X 同步带磨损或断裂
- 拓竹售后技术支持建议更换

## 所需的工具和材料

X 同步带

- H2.0 内六角螺丝刀
- 镊子（可选）

> 更换 X 电机预计耗时 30 分钟

### **安全警告**

> **重要提醒！**
>
> **在进行任何维护工作之前，务必关闭打印机的电源**，包括对打印机的电子元件和工具头电线进行维护。在打印机通电时进行此类操作可能会导致短路，从而损坏电子设备和造成安全隐患。
>
> 在维护或故障排除过程中，您可能需要拆卸热端等部件，从而暴露电线和电子元件。如果它们在打印机仍处于通电状态时相互接触或与其他金属、电子元件接触，就可能发生短路。**这将损坏打印机的电子元件和造成其他问题。**
>
> 因此，**在进行任何维护前，务必关闭打印机并断开电源**，以防止短路或损坏打印机的电子元件，从而确保维护工作安全有效地进行。如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.com/zh/my/support/tickets?from=5)，我们将及时回复并提供帮助。

## **拆卸步骤**

### 1. 移除 X 电机盒前盖

从X 电机盒前盖右侧凹槽处将前盖揭开，然后再解锁左侧接合位置，取下X电机盒前盖。  
![xdjh001.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh001.webp)

### 2. 移除摄像头组件

使用螺丝刀按下摄像头卡扣，取下摄像头组件、断开摄像头连接线。  
![xdjh002.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh002.webp)

### 3. 移除工具头线缆

使用 H2.0 六角螺丝刀拆下两颗螺丝，取下线缆压片。  
![gjtxl003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl003.jpg)  
参照图示拔出工具头线固定扣，按下插头上方卡扣，拔除工具头线缆。  
![gjtxl001.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl001.webp)![gjtxl002.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl002.webp)

### 4. 移除 X 电机盒

使用 H2.0 内六角螺丝刀拆下 4 颗螺丝，然后向前取下 X 电机盒。  
![xdjh005.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh005.jpg)![gjtxl007.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl007.webp)

### 5. 移除吐料组件

参照图示取下吐料组件盖板  
![tlzj001.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj001.webp)

轻轻拉出吐料组件插头，按住插头解锁卡扣断开插头。  
![tlzj002.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj002.webp)

使用 H2.0 内六角螺丝刀拆下一颗螺丝，将线缆向上拨动后，向后移出吐料组件。  
![tlzj003.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj003.webp)![tlzj004.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj004.webp)

### 6. 移除端盖

使用 H2.0 内六角螺丝刀拆下端盖固定螺丝，取下端盖。  
![dg001.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/dg001.jpg)![dg002.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/dg002.webp)

> 拆除端盖和 X 电机盒后，X 轴导轨两侧将失去限位保护。请注意固定工具头，防止其从导轨滑出而导致滑块滚珠丢失。

![x001.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/wiki-test/x001.jpg)

### 7. 移除 X 同步带压块

使用 H2.0 内六角螺丝刀拧下 X 同步带张紧螺丝，取下张紧螺丝及垫片。  
![xdj011.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xdj011.jpg)![xpd002.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd002.webp)

使用 H2.0 内六角螺丝刀拆下左右同步带压块螺丝，并取下同步带压块。  
![xpd001.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd001.jpg)![xpd003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd003.jpg)

### 8. 移除 X 同步带

按图示方法顶出右侧同步带压块中的白色塑料件，将同步带从压块中取出。  
![xpd005.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd005.jpg)![xpd004.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd004.webp)

拉住左侧皮带压块部分，将 X 同步带完全抽出。  
![xpd007.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd007.webp)

## **安装步骤**

### 1. 安装 X 同步带

将新同步带**齿面朝上**穿入 X 轴型材内。当同步带送达 X 电机位置时，可使用镊子等工具将同步带绕过电机同步轮。  
![xpd006.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd006.jpg)![xpd008.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd008.webp)

### 2. 安装皮带压块

将塑料压块对齐同步带齿，只漏出**半个同步带齿**，并装入右同步带压块中。  
![xpd011.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd011.webp)![xpd012.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd012.jpg)

> 正确安装状态下，从压块外侧只能看到半个同步带齿。同步带露出过多或完全不可见均为错误安装，将导致额外的打印误差及同步带张紧力异常。

先安装左侧压块，使用 H2.0 内六角螺丝刀锁入两颗螺丝固定，然后同样方法安装右侧压块。  
![xpd003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd003.jpg)![xpd001.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd001.jpg)

装回 X 同步带张紧螺丝和垫片，但先不要锁紧。左右移动工具头数次以释放同步带张力后，再使用 H2.0 内六角螺丝刀锁紧张紧螺丝。  
![xdj011.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xdj011.jpg)

> 安装过程中请确认同步带在 X 轴型材内无扭转，确保同步带平行安装。

### 3. 安装端盖

参照图示装回端盖，使用 H2.0 内六角螺丝刀锁紧端盖固定螺丝。  
![xpd009.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd009.webp)![dg003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/dg003.jpg)

> 请确保端盖内线缆走线与下图一致。如线缆未正确放入型材缺口内，端盖将无法安装到位。

![xpd010.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd010.jpg)

### 4. 安装吐料组件

将吐料组件从后方推入固定槽内，使用 H2.0 内六角螺丝刀锁入一颗螺丝固定。  
![tlzj005.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj005.webp)![tlzj006.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj006.jpg)

连接吐料组件插头，整理线缆。  
![tlzj007.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj007.webp)

参照图示装回吐料组件盖板。  
![tlzj008.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj008.webp)

### 5. 安装 X 电机盒

按图示装回 X 电机盒，注意避让线缆，并使用 H2.0 内六角螺丝刀锁紧 4 颗螺丝。  
![gjtxl010.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl010.webp)![xdjh005.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh005.jpg)

### 6. 安装工具头线缆

按图示将工具头线缆插入中继板，并固定线缆卡扣。  
![gjtxl014.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl014.jpg)![gjtxl013.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl013.webp)

装入金属压片，使用 H2.0 内六角螺丝刀锁入两颗螺丝，固定线缆。  
![gjtxl003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl003.jpg)

### 7. 安装摄像头组件

连接摄像头组件插头，并将摄像头组件推入固定位置。  
![xdjh004.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh004.webp)

### 8. 安装 X 电机盒前盖

整理线缆后，将 X 电机盒前盖装回原位。

![xdjh003.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh003.webp)
