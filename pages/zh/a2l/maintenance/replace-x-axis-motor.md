## X 电机

![fam028.png](https://public-cdn.bblmw.com/wiki/new/a2l/danpintu/fam028.png)

## 何时使用本指南？

- X 电机转动异常
- 拓竹售后技术支持后建议更换

## 所需的工具和材料

X 电机

- H2.0 内六角螺丝刀
- H1.5 内六角螺丝刀
- 镊子（可选）

> 更换 X 电机预计耗时30分钟

### **安全警告**

> **重要提醒！**
>
> **在进行任何维护工作之前，务必关闭打印机的电源**，包括对打印机的电子元件和工具头电线进行维护。在打印机通电时进行此类操作可能会导致短路，从而损坏电子设备和造成安全隐患。
>
> 在维护或故障排除过程中，您可能需要拆卸热端等部件，从而暴露电线和电子元件。如果它们在打印机仍处于通电状态时相互接触或与其他金属、电子元件接触，就可能发生短路。**这将损坏打印机的电子元件和造成其他问题。**
>
> 因此，**在进行任何维护前，务必关闭打印机并断开电源**，以防止短路或损坏打印机的电子原件，从而确保维护工作安全有效地进行。如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.com/zh/my/support/tickets?from=5)，我们将及时回复并提供帮助。

## **拆卸步骤**

### 1. 移除 X 电机盒

请先参照以下教程拆卸 X 电机盒：[更换 X 电机盒](https://wiki.bambulab.com/zh/a2l/maintenance/replace-x-axis-motor-cover)

### 2. 移除右侧皮带压块

拧松 X 轴皮带张紧螺丝  
![xdj011.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xdj011.jpg)

使用 H2.0 内六角螺丝刀拧下图示两颗螺丝，取下右侧皮带压块。  
![xdjh009.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh009.jpg)

### 3. 移除 X 电机

拔出 X 电机插头，使用 H2.0 内六角螺丝刀拆下图示四颗螺丝，取下 X 电机。  
![xdjh008.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh008.jpg)![xdj010.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdj010.jpg)![gjtxl011.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl011.webp)

## **安装步骤**

### 1. 安装 X 电机

调整 X 皮带位置，将电机同步轮穿过皮带，使用 H2.0 内六角螺丝刀锁入四颗螺丝。  
![gjtxl012.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl012.webp)![xdj010.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdj010.jpg)!

> 安装时请确保电机出线位置朝向左侧。

### 2. 安装右侧皮带压块

将右侧压块装回工具头，使用 H2.0 内六角螺丝刀锁入两颗螺丝。  
![xdjh009.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh009.jpg)

> 锁紧皮带压块螺丝时，请用手按紧压块，并同步拧紧两颗压块螺丝，避免安装时只有一侧螺丝孔受力导致损坏。

左右移动几次工具头，释放皮带张力，然后重新锁紧 X 轴皮带张紧螺丝。  
![xdj011.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xdj011.jpg)

### 3. 安装 X 电机盒

参照下方教程装回 X 电机盒：[更换 X 电机盒](https://wiki.bambulab.com/zh/a2l/maintenance/replace-x-axis-motor-cover)
