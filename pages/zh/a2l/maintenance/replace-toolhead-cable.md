## 工具头线缆

![cab054.png](https://public-cdn.bblmw.com/wiki/new/a2l/danpintu/cab054.png)  
工具头线缆组件包含两根连接线（工具头端、底座端）和转接板，请根据需要选择更换。

## 何时使用本指南？

- 工具头线缆外观破损
- TH 板通信异常
- 拓竹售后技术支持建议更换

## 所需的工具和材料

X 电机盒

- H2.0 内六角螺丝刀
- H1.5 内六角螺丝刀
- 镊子

### **安全警告**

> **重要提醒！**
>
> **在进行任何维护工作之前，务必关闭打印机的电源**，包括对打印机的电子元件和工具头电线进行维护。在打印机通电时进行此类操作可能会导致短路，从而损坏电子设备和造成安全隐患。
>
> 在维护或故障排除过程中，您可能需要拆卸热端等部件，从而暴露电线和电子元件。如果它们在打印机仍处于通电状态时相互接触或与其他金属、电子元件接触，就可能发生短路。**这将损坏打印机的电子元件和造成其他问题。**
>
> 因此，**在进行任何维护前，务必关闭打印机并断开电源**，以防止短路或损坏打印机的电子元件，从而确保维护工作安全有效地进行。如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.com/zh/my/support/tickets?from=5)，我们将及时回复并提供帮助。

## **拆除工具头线缆（工具头端）**

工具头线缆组件共包含三部分，请根据需要选择对应的更换步骤。

### 1. 移除 X 电机盒前盖

从X电机盒前盖右侧凹槽处将前盖揭开。然后解锁左侧的接合位置，取下 X 电机盒前盖。  
![xdjh001.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh001.webp)

### 2. 断开电机盒端连接

使用 H2.0 内六角螺丝刀拆下固定线缆压片的两颗螺丝，并取下压片。  
![gjtxl003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl003.jpg)

参照图示，拔出工具头线缆固定扣，按下插头上方的解锁卡扣后，拔出工具头线缆。  
![gjtxl001.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl001.webp)![gjtxl002.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl002.webp)

### 3. 移除工具头线缆（工具头端）

使用 H1.5 内六角螺丝刀，拆下固定工具头端线缆的四颗螺丝。向上拔出工具头线缆。  
![gjtxl016.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-th-board/gjtxl016.jpg)![gjtxl004.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl004.webp)

> 如需更换转接板，请继续执行“移除转接板”步骤；否则可跳过该部分。

## **移除转接板**

### 1. 移除摄像头组件

使用螺丝刀按下摄像头卡扣，取下摄像头组件，并断开摄像头连接线。

![xdjh002.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh002.webp)

### 2. 移除 X 电机盒

使用 H2.0 内六角螺丝刀拆下图示中的四颗螺丝，然后向前取下 X 电机盒。  
![xdjh005.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh005.jpg)![gjtxl007.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl007.webp)

### 3. 移除 X 电机盒后盖

使用 H2.0 内六角螺丝刀拆下图示两颗螺丝，拔出线缆。

![xdjh006.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh006.jpg)![xdjh007.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh007.jpg)  
向后拉出 X 电机盒后盖。  
![gjtxl008.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl008.webp)

### 4. 移除转接板

拔除 X 电机插头。使用 H1.5 内六角螺丝刀拆下固定转接板的三颗螺丝。  
![xdjh008.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh008.jpg)![zjb002.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/zjb002.jpg)

拔除摄像头线排线和霍尔排线插头。  
![zjb001.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/zjb001.webp)

> 此处插头出厂时涂有防松胶，建议先清理插头周围的胶水后再拔出。重新安装时无需重新涂胶。

## **安装转接板**

> 若此前未移除转接板，可跳过此步骤。

### 1. 安装转接板

连接摄像头排线和霍尔排线，将转接板装回原位，并使用 H1.5 内六角螺丝刀锁紧三颗螺丝。随后插入 X 电机线。  
![zjb003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/zjb003.jpg)![zjb002.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/zjb002.jpg)![xdjh008.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh008.jpg)

### 2. 安装 X 电机盒后盖

参照图示安装 X 电机盒后盖。  
![gjtxl009.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl009.webp)

将线缆插头的**凸起部分向上**对准后盖的缺口插入，使用 H2.0 内六角螺丝刀锁入两颗螺丝。  
![zjb004.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/zjb004.jpg)![xdjh006.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh006.jpg)

### 3. 安装 X 电机盒

参照图示装回 X 电机盒，注意避让线缆。使用 H2.0 内六角螺丝刀锁入 4 颗螺丝。  
![gjtxl010.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl010.webp)![xdjh005.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh005.jpg)

### 4. 安装摄像头组件

连接摄像头插头，将摄像头组件推入固定位置。

![xdjh004.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh004.webp)

## **安装工具头线缆（工具头端）**

### 1. 安装工具头线缆（工具头端）

按图示将工具头线缆插入转接板，并固定线缆卡扣。  
![gjtxl014.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl014.jpg)![gjtxl013.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl013.webp)

装入金属压片，使用 H2.0 内六角螺丝刀锁入两颗螺丝，固定线缆。  
![gjtxl003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/gjtxl003.jpg)

将工具头线缆凸起的一侧对准插槽缺口插入到位，再使用 H1.5 内六角扳手锁紧四颗螺丝完成固定。  
![gjtxl001.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/wiki-test/gjtxl001.jpg)![gjtxl016.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-th-board/gjtxl016.jpg)

> 安装前请确认线缆走向正确，避免线缆扭转。

### 2. 安装 X 电机盒前盖

整理线缆，装回 X 电机盒前盖。

![xdjh003.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-motor-cover/xdjh003.webp)

> 如需继续更换工具头线缆（底座端），请执行以下步骤

## **移除工具头线缆（底座端）**

### 1. 移除龙门架

参照以下教程拆卸出底座部分：[更换龙门架](https://wiki.bambulab.com/zh/a2l/maintenance/replace-printer-frame)

### 2. 移除前底盖

将底座翻转放置，使屏幕悬空置于桌面边缘。  
![dz001.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz001.jpg)

> 屏幕较为脆弱，翻转底座时请勿直接将屏幕接触桌面。

使用 H2.0 内六角螺丝刀拆下图示 12 颗螺丝，其中蓝色标记螺丝与其他位置不同，请注意区分。  
![dz002.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz002.jpg)

取下Y轴张紧器盖板和前底盖。  
![dz003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz003.jpg)

![dz004.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz004.webp)

### 3. 移除工具头线缆（底座端）

使用 H1.5 内六角螺丝刀拆下图示中的两颗螺丝，拔出工具头线缆。  
![dz005.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz005.jpg)![dz006.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz006.jpg)

使用 H1.5 内六角螺丝刀拧下图示两颗螺丝，将线缆卡扣向外推出。  
![dz010.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz010.jpg)![dz008.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz008.webp)

取出工具头线缆（底座端）。  
![dz011.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz011.webp)

## **安装工具头线缆（底座端）**

### 1. 安装工具头线缆（底座端）

将工具头线缆（底座端）穿入底座内部。  
![dz012.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz012.webp)

将插头有凸起一面向上插入主板，并使用 H1.5 内六角螺丝刀锁紧两颗螺丝。  
![dz007.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz007.jpg)![dz005.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz005.jpg)

使用 H1.5 内六角螺丝刀锁入两颗螺丝固定线缆卡扣。

![dz010.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz010.jpg)

### 2. 安装前底盖

参照图示装回前底盖，按压到位，装回Y轴张紧器盖板。  
![gjtxl014.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/gjtxl014.webp)![gjtxl015.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/gjtxl015.jpg)

使用 H2.0 内六角螺丝刀锁入图示 12 颗螺丝，其中蓝色标记螺丝与其他位置不同，请注意区分。  
![dz002.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-bottom-cover/dz002.jpg)

### 3. 安装龙门架

参照以下教程装回底座：[更换龙门架](https://wiki.bambulab.com/zh/a2l/maintenance/replace-printer-frame)
