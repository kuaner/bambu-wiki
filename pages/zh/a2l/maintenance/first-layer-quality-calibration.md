## 概述

首层打印质量会直接影响模型附着、成型稳定性以及后续层的打印效果。本指南将帮助您快速判断首层是否偏高或偏低，并通过基础校准与检查步骤恢复正常打印。

## 合格首层标准

理想的首层应具备以下特征：

- 线与线之间贴合良好，无明显缝隙；
- 表面整体平整，无多余的褶皱、堆料或起皮；
- 首层能够稳定附着在打印板表面，不易被喷嘴拖动。

在实际打印过程中，受打印板表面附着力差异或耗材粘嘴导致的挤出波动影响，首层出现少量轻微瑕疵属于正常现象，通常不会影响最终打印结果。例如，若首层仅约 10% 的区域存在轻微线宽波动或细小褶皱，而其余大部分区域均打印平整，通常不会对打印成功率和成品质量造成明显影响。只要整体附着力正常，且不影响后续层的稳定成型，即可视为可接受的首层状态。

## 如何打印高质量首层

> **注意：**由于 A2L 为开放式打印机，对环境温度变化较为敏感，**建议不要在空调直吹或温度波动较大的环境中进行首层打印。**环境温度变化可能导致热床发生轻微形变，进而影响首层成型质量并产生表面瑕疵。在进行任何打印作业时，应避免在上述环境条件下操作。

### 校准与调平

无论遇到哪种首层打印质量问题，我们都建议您在“**设置 > 维护 > 校准 > 打印校准”**中运行一次**自动热床调平。**若机器经过**搬运、长时间存放或者拆装更换热床**后，也必须重新运行调平。

![](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/first-layer-quality-calibration/014.png)

此外，建议在每次打印前，在发送任务窗口中将**“自动热床调平”** 设为 **“打开”**。

![](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/first-layer-quality-calibration/002.png)

如果从打印机屏幕端发起打印，也可在：**高级设置 > 自动热床调平**中开启该功能。

| --- | --- |
|  |  |

> **注意：**打印前的调平数据和校准调平数据（包括自动热床调平及 80℃ 热床调平）均会保存在打印机内。打印时，系统将自动综合应用这两组调平数据。

### 清洗打印板

打印板表面的油污、灰尘或残留材料都会影响首层附着。建议使用**洗洁精**或**专用清洁剂**彻底清洁打印板。详情参考：[Bambu Lab 纹理 PEI 打印板质量与预期不符](../../general/textured-PEI-plate-not-working-as-expected.md)。

### 常见首层问题及解决方法

严重的首层问题通常分为两类：**首层偏低**和**首层偏高**；您可根据实际现象对照下文进行排查。

#### **首层偏低**

**现象特征：**

- 首层表面出现明显褶皱、起皮或堆料；
- 严重时材料无法顺利挤出，甚至在喷嘴尖端堆积，喷嘴刮擦打印板或已打印区域；

**可能带来的问题：**

- 喷嘴持续刮擦热床，可能损坏喷嘴和打印板；
- 模型与热床粘连过强，导致打印件难以取下，甚至撕裂模型；
- 挤出不畅，可能引发喷嘴尖端堆料或“堵头”。

> 注：对于 I3 结构机型，只要不出现明显刮板、挤出不畅或严重褶皱，首层轻微偏低通常是可接受的。与完全理想化的首层相比，轻微偏低有助于提高首层附着力，减少因打印板表面状态波动，或支撑在打印过程中整体脱离热床而导致裹头的风险。

![](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/first-layer-quality-calibration/020.png)

**解决方案：**

1. **检查喷嘴的安装是否正确**

按照正确的方式扣紧喷嘴锁扣，确保无松动。

![nozzle-installation.png](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/first-layer-quality-calibration/nozzle-installation.png)

2. **进行首层质量校准**

- 进入 **校准 > 首层质量校准**；若首层偏低，可将校准值**向正方向微调**，例如调整至 **+0.010 mm**；

> 注意：打印过程中无法实时调整距离。

![first-layer-calibration.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/first-layer-quality-calibration/first-layer-calibration.jpg)

- 调整后重新打印测试模型，观察首层是否恢复正常。

3. **锁紧陶瓷底座前后螺丝**

首先拧下陶瓷底座的 3 颗固定螺丝，然后适度拧紧加热组件背面的 4 颗螺丝，再重新安装陶瓷底座。

#### 首层偏高

**现象特征：**

- 首层线条未被充分压实，线条之间较为稀疏，存在明显缝隙；
- 模型与打印板粘附不牢，取下打印件时，首层可能线条分离。

|  |  |
| --- | --- |
|  |  |

**可能带来的问题：**

- 首层附着不足，打印过程中模型可能移位、翘起甚至倒塌；
- 严重时可能引发“炒面”或“裹头”，最终导致打印失败。

**解决方案**：

1. **检查擦嘴组件状态**

- 检查擦嘴钢片或软硅胶刷是否清洁到位；
- 确认钢片是否存在弯曲变形，若钢片中间下凹，可能导致喷嘴擦拭不充分，从而影响测量与首层状态。

![](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/first-layer-quality-calibration/001.png)

2. **检查喷嘴是否漏料**

- 若喷嘴存在漏料，可能会在调平时影响实际高度判断，进而造成首层偏高。需要在调平之前将喷嘴清洁干净。

3. **进行首层质量校准**

- 进入 **校准 > 首层质量校准，**若首层偏高，可将校准值**向负方向微调**，例如调整至 **-0.010 mm**；
- 调整后重新打印测试模型，确认线条是否已贴合、压实。

![](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/first-layer-quality-calibration/011.png)

> 注意：
>
> - 由于打印板存在批次和工艺差异，每台打印机对首层的要求略有不同。因此，机器在出厂前会对打印机及其配套打印板进行首层质量校准，部分机器会写入对应的 Z 偏移量。
> - 首层质量也会受到打印板批次的影响。即使是同一台打印机，更换不同的纹理板后（甚至第三方打印板），可能也需要微调 Z 偏移量，才能获得理想首层。

## 首层异常处理步骤

如果您遇到明显的首层质量异常，**建议按以下顺序进行处理**，可避免重复拆装部件，并快速定位问题原因。

1. 清洁打印板；
2. 运行**自动热床调平**和 **80℃ 热床调平**；
3. 打印首层测试模型，判断问题属于“偏高”还是“偏低”；
4. 根据对应问题检查喷嘴、擦嘴组件或加热组件状态；
5. 进入**首层质量校准**进行小幅微调；
6. 重新打印测试模型，确认问题是否解决。

## 热床保温

A2L 可在自动热床调平前将热床维持在目标温度。这一额外的等待时间由模型的摆放位置决定，最长可达 500 秒。这一准备过程有助于打印机打出稳定一致的首层。

> **了解更多：**  
> A2L 打印机屏幕上的“热床保温”功能，指的是通常所说的“*热浸（heat soaking）*”过程，即让热床达到目标温度后，在校准开始前保持数分钟。这样可确保热床处于热稳定状态，因为加热会引起微小的尺寸变化——这些变化肉眼不可见，但在高精度调平校准时能被检测到。因此，当使用整块 A2L 打印板时，建议进行热浸，以帮助在整个打印表面上实现一致的首层。

**仅当以下两个条件同时满足时，打印机才会执行此过程：**  
✅ 打印设置中已启用热床保温。  
✅ 打印开始时未禁用自动热床调平。

![](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/first-layer-quality-calibration/009.png)

![requirements_wiki_a2l.jpg](https://wiki.bambulab.com/a2l/manual/heatbed-insulation/requirements_wiki_a2l.jpg)

保温结束后，打印机会执行自动热床调平，随后开始打印。

- 这是 A2L 屏幕上提示热床保温功能已激活的通知。此阶段只需等待打印开始，无需任何用户操作。  
  ![heat-bed-option-on-screen-wiki-a2l.png](https://wiki.bambulab.com/a2l/manual/heatbed-insulation/heat-bed-option-on-screen-wiki-a2l.png)

A2L 热浸策略【？】的所有细节如下表所示：

| 检查以下三个条件 | | | |
| --- | --- | --- | --- |
| ✅ 打印区域大于 **260 × 260 mm**  ✅ 模型高度仅为 **一个打印层【？】**  ✅ 切片软件中热床温度设置为 **55°C** | | | |
| 条件结果 | 热床保温 | 实际打印温度 | 流程 |
| ✅ **三个条件全部满足** | 自动强制执行 | **65°C**  系统忽略切片软件的 55°C 设置 | 1. 将热床温度从 **55°C 强制提升至 65°C**  2. 在保温和打印期间将热床维持在 **65°C**  3. 在保温期间完成其他打印前准备工作  4. 准备工作完成后，再额外等待 **500 秒**  5. 将喷嘴加热至 **140°C**  6. 执行 **8 × 8 点热床调平**  7. 在热床 **65°C** 状态下开始打印 |
| ❌ **一个或多个条件未满足** | ✅ 已启用 | 保留切片软件的温度设置 | 1. 根据模型面积和覆盖的调平点计算等待时间  2. 对热床保温，最长 **500 秒**  3. 执行自动热床调平  4. 以切片软件配置的热床温度开始打印。 |
| ❌ **一个或多个条件未满足** | ❌ 已禁用 | 保留切片软件的温度设置 | 1. 跳过热床保温等待时间  2. 立即开始热床调平  3. 以切片软件配置的热床温度开始打印 |

  

### 摆放位置如何控制保温时间

| 切片软件中的摆放位置 | 保温时间 | 后续处理 |
| --- | --- | --- |
| 所有内容均处于内侧白色框内 | 无额外保温时间 | 热床达到目标温度后即开始调平 |
| 任何打印项接触或超出内框，但仍处于外框内 | 2 至 4 分钟 | 在分配的保温时间结束后开始调平 |
| 任何打印项超出外框 | 4 至 5 分钟 | 在分配的保温时间结束后开始调平 |

> **注意：** 打印项超出内框越远，保温时间可能越长。总保温时间不会超过五分钟。

![a2l_time_soak_wiki_a2l.jpg](https://wiki.bambulab.com/a2l/manual/heatbed-insulation/a2l_time_soak_wiki_a2l.jpg)

当 Bambu Studio 检测到模型超出内框时，右下角会出现警告。

### 模型之外的其他项也计入判断

模型本身可能处于内框内，而另一个打印项接触或穿过了内框。此时热床保温仍会启动。

以下项目会计入判断：

- 多色模型的**擦料塔**
- 为延时摄影录制生成的**擦料塔**
- 支撑
- Brim
- 裙边（skirt）

在下图的情况下，Brim 超出了内侧方框，从而导致保温时间更长。

![brim_exceeding_area.png](https://wiki.bambulab.com/a2l/manual/heatbed-insulation/brim_exceeding_area.png)

如果将模型放置在热床中央，准备时间会更短，因为热床保温功能不会被激活。

![brim_case_wiki_a2l.jpg](https://wiki.bambulab.com/a2l/manual/heatbed-insulation/brim_case_wiki_a2l.jpg)

### 常见问题

| 问题 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 模型明明处于内框内，保温却仍然启动 | 擦料塔、支撑、Brim 或裙边穿过了内框 | 在最终预览中检查每一个打印项 |
| 打印机使用了四到五分钟的保温区间 | 某个打印项穿过了外框 | 对照外框检查模型和所有生成的打印项 |
| 保温未启动 | 所有内容都处于内框内、热床保温已关闭，或自动调平已被禁用 | 检查摆放位置以及两项打印启动设置 |
| 未出现越线弹窗提示 | 此前可能已选择了不再显示该弹窗的选项 | 借助白色方框和最终预览来检查摆放位置 |

> **如何在 Bambu Studio 中启用和禁用热床保温警告。**
>
> - 点击顶部栏中的 **小箭头**（1），选择 **偏好设置（Preferences）**（2），然后选择 **3D** 菜单（3）。在这里即可找到用于启用或禁用 **显示热浸区域（Show Heat-Soak Area）** 的选项（4）。
