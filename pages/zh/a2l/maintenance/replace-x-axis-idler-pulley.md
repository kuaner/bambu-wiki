## X 轴惰轮组件

X 轴惰轮是安装在 A2L 打印机 X 轴一端的滑轮。主要用于支撑和引导 X 同步带。

![a1_x-axis-idler-pulley.png](https://wiki.bambulab.com/a2l/maintenance/replace-x-axis-idler-pulley/a1_x-axis-idler-pulley.png)

## 何时更换

- X 轴惰轮损坏

## 所需工具和材料

- X 同步带
- H2.0 内六角螺丝刀
- 镊子
- 胶带（如美纹胶）

## **安全提示**

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除 X 轴惰轮组件

### 1. 移除吐料组件

参照图示取下吐料组件盖板  
![tlzj001.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj001.webp)

轻轻拉出吐料组件插头，按住插头解锁卡扣断开插头。  
![tlzj002.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj002.webp)

使用 H2.0 内六角螺丝刀拆下一颗螺丝，将线缆向上拨动后，向后移出吐料组件。  
![tlzj003.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj003.webp)![tlzj004.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj004.webp)

### 2. 移除端盖

使用 H2.0 内六角螺丝刀拆下端盖固定螺丝，取下端盖。  
![dg001.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/dg001.jpg)![dg002.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/dg002.webp)

> 拆除端盖后，X 轴导轨左侧将失去限位保护，建议**用胶带固定工具头**（如美纹胶），防止其从导轨滑出，导致滑块滚珠丢失。  
> ![x001.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/wiki-test/x001.jpg)

### 3. 移除 X 同步带压块

使用 H2.0 内六角螺丝刀拧下 X 同步带张紧螺丝，取下张紧螺丝及垫片。  
![xdj011.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xdj011.jpg)![xpd002.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd002.webp)

使用 H2.0 内六角螺丝刀拆下两颗左侧同步带压块螺丝，并取出同步带压块。  
![xpd001.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd001.jpg)

### 4. 移除 X 轴

使用 H2.0 内六角螺丝刀先拧出橙色标记的 4 颗螺丝。  
![xpd016.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd016.jpg)

当拆除到两侧的各最后一颗螺丝时，请用手托住 X 轴，以免 X 轴突然掉落损坏；然后使用 H2.0 内六角螺丝刀拧出剩余两颗蓝色标记螺丝，取下 X 轴。  
![xpd015.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd015.jpg)

将 X 轴组件平行放置在热床上，便于后续拆装 X 轴惰轮组件。  
![x002.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/pingmu/x002.jpg)

### 5. 移除 X 轴惰轮

使用 H2.0 内六角螺丝刀拧松图示一颗螺丝，取下 X 轴惰轮组件。  
![x003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/pingmu/x003.jpg)

> 注意：惰轮两侧各有一个垫片，拆卸时请注意。  
> ![x001.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/pingmu/x001.jpg)

## 安装 X 轴惰轮组件

### 1. 安装 X 轴惰轮

先放入一颗垫片，穿入惰轮固定螺丝，再放入惰轮。将螺丝向后拉出约 8mm，使用镊子将另一颗垫片送入对应位置，然后使用 H2.0 内六角螺丝刀锁紧螺丝。  
![x004.webp](https://public-cdn.bblmw.com/wiki/new/a2l/pingmu/x004.webp)

### 2. 安装 X 轴

将 X 轴装回龙门架，并用手固定住，使用 H2.0 内六角螺丝刀先左右各锁入一颗螺丝固定 X 轴。  
![xpd015.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd015.jpg)

使用 H2.0 内六角螺丝刀锁入剩余四颗螺丝。  
![xpd016.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-x-axis-assembly/xpd016.jpg)

### 3. 安装 X 同步带压块

使用 H2.0 内六角螺丝刀锁入两颗螺丝，固定左侧压块。  
![xpd003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd003.jpg)

装回 X 同步带张紧螺丝和垫片，但先不要锁紧。左右移动工具头数次以释放同步带张力后，再使用 H2.0 内六角螺丝刀锁紧张紧螺丝。  
![xdj011.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xdj011.jpg)

> 安装过程中请确认同步带在 X 轴型材内无扭转，确保同步带平行安装。

### 4. 安装端盖

参照图示装回端盖，使用 H2.0 内六角螺丝刀锁紧端盖固定螺丝。  
![xpd009.webp](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd009.webp)![dg003.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/dg003.jpg)

> 请确保端盖内线缆走线与下图一致。如线缆未正确放入型材缺口内，端盖将无法安装到位。  
> ![xpd010.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/replace-mainboard/xpd010.jpg)

### 5. 安装吐料组件

将吐料组件从后方推入固定槽内，使用 H2.0 内六角螺丝刀锁入一颗螺丝固定。  
![tlzj005.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj005.webp)![tlzj006.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj006.jpg)

连接吐料组件插头，整理线缆。  
![tlzj007.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj007.webp)

参照图示装回吐料组件盖板。  
![tlzj008.webp](https://public-cdn.bblmw.com/wiki/new/a2l/sanliao/tlzj008.webp)

## 操作后的校准步骤

建议您在更换完 X 轴惰轮后清洗打印板并进行一次全面校准，以确保打印机顺畅运行。
