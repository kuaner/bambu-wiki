## 概述

针对 A2L 机型，Bambu Studio 设置了两种擦料塔冲刷模式：**标准模式**和**快速模式**。用户可以根据实际需求，在**节省耗材**与**加快打印速度**之间自由权衡，以满足不同场景下的打印需求。

## 模式介绍与对比

在**项目耗材列表**右侧，可以对 A2L 的**冲刷模式**进行选择。

![](https://wiki.bambulab.com/a2l/manual/purge-mode/003.png)

### **标准模式**

- **冲刷量：**在标准模式下，冲刷量严格按用户在切片中设定的材料清理量执行；

![](https://wiki.bambulab.com/a2l/manual/purge-mode/002.png)

- **冲刷温度：**与推荐喷嘴温度中的最高温度保持一致，因此每次冲刷时需要对喷嘴进行额外升温。

![](https://wiki.bambulab.com/a2l/manual/purge-mode/004.png)

### **快速模式**

- **打印时间：**相比标准模式，快速模式可节省**约 15%** 的打印时间；

|  |  |
| --- | --- |
| 标准模式 | 快速模式 |

- **冲刷量：**按用户在切片中设定的材料清理量的 **1.2 倍**执行；

![](https://wiki.bambulab.com/a2l/manual/purge-mode/011.png)

- **冲刷温度：**和打印温度保持一致，每次换料冲刷省去了升温——降温的时间，所以多色打印的时间会降低；

![](https://wiki.bambulab.com/a2l/manual/purge-mode/013.png)

以下为标准模式和快速模式的对比；需注意的是，**若自行设置了冲刷系数，系统将以设定的冲刷倍率执行**，并覆盖默认的 1（标准模式）或 1.2（快速模式）冲刷系数。

|  | 标准模式 | 快速模式 |
| --- | --- | --- |
| **冲刷量** | 材料清理量的 1 倍 | 材料清理量的 1.2 倍 |
| **冲刷温度** | 与最高推荐喷嘴温度一致（需额外升温） | 与打印温度一致 |
| **多色打印时间** | 整体较慢 | 整体较快（约省 15%） |
| **耗材消耗** | 相对较少 | 相对较多 |

#### 选择建议

- **标准模式**：多色打印冲刷时间更长，但相对更省料；追求耗材节约或对打印质量要求较高时，推荐此模式；
- **快速模式**：多色打印冲刷速度更快，但耗材消耗相对较多；追求打印效率、可接受少量额外耗材时，推荐此模式。
