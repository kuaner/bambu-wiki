本页面将介绍 A2L 打印机的主要部件，帮助您初步了解该设备的结构与组成。

## A2L 运动系统

A2L 采用笛卡尔坐标运动系统，运动系统包括 X 轴、Y 轴和 Z 轴，最大打印体积为 330\*320\*325 mm。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/034.png)

### X 轴

X 轴运动系统由一根高精度线轨和一根横梁组成。工具头固定在线轨滑块上，滑块可在水平线轨上自由滑动。通过控制滑块的左右运动，工具头可在 X 轴上精准移动。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/004.webp)

### Y 轴

Y 轴运动系统由一根高精度水平导轨和一个打印平台组成。打印平台固定在导轨滑块上，滑块可在水平导轨上自由滑动。通过控制滑块的前后运动，打印平台可在 Y 轴上精准移动。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/005.webp)

### Z 轴

Z 轴运动系统由双光轴 - 直线轴承导向组件、双丝杆螺母、步进电机和同步带驱动组件组成，用于控制工具头相对于打印平台的垂直位置。双丝杆通过同步带与步进电机串联，可实现两根丝杆的同步运动。此外，同步带配备有快速张紧器，并结合张紧力检测算法，确保同步带在最佳张力范围内运动，从而保证工具头在 Z 轴方向上的精准且稳定的移动。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/006.webp)

通过同时控制 X 轴、Y 轴和 Z 轴的运动，A2L 可实现工具头在三个方向上的精准移动。通常情况下，这些运动由电机和相应的驱动电路控制，机器控制器读取打印文件并发送指令来控制工具头的运动路径和速度。

## 皮带张紧器

A2L 的 X、Y 和 Z 皮带均配有可调节的皮带张紧器：

- X 皮带张紧螺丝位于工具头背面

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/035.png)

- Y 皮带张紧螺丝位于 Y 滑车盖下方

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/011.png)

- Z 皮带张紧螺丝位于右侧 Z 轴立柱旁

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/022.png)

当打印件出现失圆、丢步等问题，或校准过程中系统提示“共振频率偏低”时，通常意味着皮带张力不足。此时，请参考 [A2L 皮带张紧](https://wiki.bambulab.com/zh/a2l/maintenance/belt-tension)进行维护，以确保打印精度。

## 工具头

工具头是 3D 打印机中最核心的执行部件之一，负责将耗材加热熔融、精确挤出，并在打印平面上完成逐层沉积成型。以下介绍工具头的主要组成部分及其功能。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/003.jpg)

### 五通组件

A2L 的 PTFE 管需连接至工具头上的五通组件。五通组件用于汇集并固定四根料管，使工具头能够同时接入四种耗材，从而支持多色打印。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/001.jpg)

五通组件底座包含一块进料霍尔板，该霍尔板集成以下 5 个传感器：

|  |  |
| --- | --- |
|  |  |

1. **缠料检测/缓冲器：**检测送料过程中是否出现缠料、阻力异常等情况，具体请参考：[缠料检测介绍](https://wiki.bambulab.com/zh/a2l/manual/air-printing-and-filament-tangle-detection)；同时该模块兼具缓冲功能，可实现打印机直连 AMS，无需额外加装独立缓冲器；
2. **刀切模组在位霍尔检测：**检测刀切模组是否正确滑入，避免模组未装好时发起刀切/画笔作业；
3. **切刀检测霍尔：**检测工具头切刀是否正常工作，切断耗材后刀柄是否正常归位；
4. **进料霍尔：**判断耗材是否进入挤出机，辅助识别进料异常；
5. **挤出机温度传感器：**实时监测挤出机温度，预警高温导致的耗材软化与堵头风险；

五通组件底部嵌有磁铁和弹簧，可与缠料检测传感器配合检测进料阻力。当进料阻力过大时，五通组件会向下移动，使磁铁接近霍尔传感器，并触发缠料报警。同时在配合 AMS 使用时，可以作为缓冲器调节进料速度。

|  |  |
| --- | --- |
|  |  |

### 挤出机组件

挤出电机负责将耗材从线轴中拉出并送入热端，加热熔化后通过喷嘴挤出，生成打印模型。挤出电机需要精确控制通过热端挤出的线材长度，是 3D 打印机核心部件之一。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/032.png)

挤出机齿轮和挤出电机是挤出机的重要组成部分。

- **挤出机齿轮组件：**A2L 采用硬化钢挤出机齿轮，由主动轮和从动轮组成，在挤出电机驱动下对耗材进行精确推送。

|  |  |
| --- | --- |
|  |  |

- **挤出电机：**挤出电机安装在挤出机背面，用于驱动挤出机，完成耗材的挤出。与 A1 系列打印机不同，A2L 采用了拓竹自研的高精度永磁同步伺服电机，可通过监测运行过程中的阻力变化，实现缠料检测，进一步保障打印过程的顺畅与可靠。

| --- | --- |
| A1 | A2L |

### 热端组件

热端组件是工具头模块的核心部件，主要由热端加热组件、热端和热端硅胶套组成，支持最高加热温度为 300℃。热端组件将耗材加热到指定温度，熔化后的耗材以薄层的形式沉积来生成模型。

#### 热端

热端集成了喷嘴、热阻断器和散热片，通过快拆锁扣固定在加热组件上方。热端分为热端部分和冷端部分：

- **热端（橙色部分）：**耗材在此处熔融后通过喷嘴以薄层的形式沉积，从而生成模型。
- **冷端（蓝色部分）：**包含散热片和热阻断器。保持热端上部低温，防止热量向上传导（热爬现象），减少堵塞风险。

![a2l_cold_end_hot_end.jpg](https://wiki.bambulab.com/a2l/manual/a2l-intro/a2l_cold_end_hot_end.jpg)

#### 热端加热组件

热端加热组件包含热端加热器、NTC 测温传感器、陶瓷底座和快拆锁扣，用于实现精准加热和温度监测，支持最高加热温度为 300℃。

其中热端加热器和 NTC 测温传感器固定在加热底座上，无需拔插细小端子或使用螺丝刀；快拆锁扣用于固定热端，确保热传导和耗材融化。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/015.png)

#### 硅胶套

硅胶套包覆喷嘴，起到保温作用，减少热量流失，维持稳定温度，同时防止耗材在喷嘴表面积聚。如果缺少热端硅胶套，热端则会被部件冷却风扇过度冷却，导致温度波动，影响打印稳定性。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/016.png)

### 热端风扇

A2L 工具头的左侧配备了一个热端散热风扇，风扇吹出的冷空气通过风道导向热端散热片附近，以保持热端温度的稳定，防止过热，从而提高打印质量并减少堵塞问题。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/002.jpg)

### 部件冷却风扇

快速打印需要对打印部件进行良好的冷却，A2L 配备了一个定制的 5015 离心风扇，带有相对的两个出风风道，使冷却空气精准的吹到喷嘴附近，保证打印部件的快速冷却。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/017.png)

### 切刀

切刀刀柄安装在挤出组件上，用于固定切刀和切料检测磁铁。切料时，按下刀柄即可带动切刀切断耗材；切断完成后，刀柄会自动回弹复位。

刀柄上集成了一枚磁铁，在其对应位置的工具头内部设有配套的霍尔传感器。打印机可通过该霍尔传感器检测刀柄位置，从而判断切刀的动作状态。

### 刀切模组

除以上工具头的主要组成部分之外，A2L 还支持安装刀切或画笔模组进行 2D 任务，其安装步骤和 H2 系列相同，具体请参考：[A2L 刀切/画笔使用教程](https://wiki.bambulab.com/zh/a2l/manual/cutting-module-user-guide)。A2L 的工具头内包含一块刀切模组转接板，用于连接刀切模组，以确保 2D 模组可正常工作。

## 吐料组件

吐料组件用于高效回收喷嘴排出的废料，负责运送并确保废料得到妥善处理，从而保证打印过程的连贯与顺畅。吐料组件在多个环节中发挥关键作用，包括：

- 打印机的准备、暂停与恢复
- 耗材进料与退料
- 多色打印时的耗材更换及冲刷

A2L 吐料组件内置霍尔传感器，可实现裹头检测。当热端因模型脱落等原因出现裹头时，工具头会自动移动到吐料组件位置，传感器即可捕捉并触发相应的处理流程。详情请参考：[A2L 裹头检测功能](https://wiki.bambulab.com/zh/a2l/manual/nozzle-clumping-detection)。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/021.png)

## 擦嘴组件

擦嘴组件在每次打印任务启动前会自动对喷嘴进行清洁，无需人工介入。清洁流程分为粗擦与精擦：

- **粗擦（蓝色）**：利用热床上预装的热床擦嘴胶条，去除喷嘴内部残留的废料。
- **精擦（橙色）**：喷嘴在热床的不锈钢擦嘴片指定位置向下轻刮 1–2 mm，确保喷嘴端面光洁。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/007.png)

## 热床组件

热床的主要功能是加热打印表面，以帮助打印层更好地附着在打印板上。如果不对打印表面进行加热，沉积在热床上的首层很可能无法稳定附着在热床表面，导致后续的打印过程中打印件翘曲甚至掉落。A2L 打印机在使用过程中，根据所使用的耗材类型来控制热床的加热温度，最高可达 80°C。

同时，热床也是打印机的 Y 轴运动部件。Y 轴电机通过同步带与热床相连，驱动热床沿 Y 轴运动，实现 Y 方向的打印成形。X 轴的运动由 X 轴电机通过同步带驱动工具头完成，两者协同工作，使得打印机喷嘴能在热床表面实现 XY 方向的运动。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/008.png)

## 打印板

A2L 标配了一张纹理 PEI 打印板（开箱包装内），由 PEI 材料喷涂在不锈钢板上而成，能够给打印件的底部带来特殊的纹理质感。该打印板可用于打印 PLA/PETG/TPU 等各类耗材，且无需使用任何粘合剂。

建议定期清洁打印板以保持最佳粘附力，同时尽量避免用手指直接触碰打印板表面，以防皮肤油脂附着到打印板表面，影响打印板对耗材的粘附力。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/023.png)

此外，A2L 还可安装刀切垫板，配合刀切模组或画笔模组完成 2D 任务。刀切垫板由刀切保护钢板和刀切粘板组成，在开始刀切作业前，需要先将待加工材料贴附在粘板表面，以便在加工过程中对材料进行固定。

## 屏幕

A2L 配备了一块 3.5 英寸、分辨率为 240 × 320 的触控屏幕，并搭载更流畅的用户界面，带来顺畅的操作体验。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/026.png)

## **摄像头**

A2L 配备了一枚最高支持 1080P 的低帧率摄像头。该摄像头安装在 X 电机盒内，可用于查看打印机工作画面、录制打印视频，并生成延时摄影录像。安装时需确保摄像头正确安装，使摄像头视野正确朝向打印机腔体，以避免对打印区域或喷嘴的检测出现问题。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/a2l-intro/027.png)
