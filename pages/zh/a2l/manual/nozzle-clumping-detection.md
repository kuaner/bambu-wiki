## 什么是裹头检测？

“裹头”通常指打印过程中，因耗材未能牢固粘附在打印板或其他原因，导致喷嘴被溢出的耗材包裹，从而引发打印失败甚至损坏挤出机的现象。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/nozzle-warp-detection/018.png)

鉴于裹头可能对设备造成损害，Bambu A2L 打印机配备了裹头检测功能。当打印机检测到喷嘴被耗材包裹时，会自动暂停打印并发出提醒，以尽量避免因持续打印而扩大损伤。

请注意，喷嘴裹头检测并非绝对可靠的故障检测方案。其主要作用是辅助识别潜在问题，但不能保证完全解决问题。实际使用中，可能因具体情况或故障类型而出现检测偏差。建议您通过 Bambu Handy 或 Bambu Studio 设备页面的监控画面检查打印状态，并在每次打印前[清洗打印板](../../filament-acc/acc/pei-plate-clean-guide.md)。**绝大多数裹头问题都是由打印模型底部未能正常附着在打印板上引起的。**因此，确保耗材与打印板之间具有良好的附着力至关重要。

## 检测原理

裹头检测依靠吐料组件处的传感器实现。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/nozzle-warp-detection/017.png)

检测时，工具头会运动至吐料组件处并进行试探。

- 若喷嘴未被包裹，则过程中仅接触空气，传感器未检测到裹头，喷嘴可顺利通过；

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/nozzle-warp-detection/005.webp)

- 若喷嘴已被耗材包裹形成料团，则运动时料团会触碰裹头检测弹片，导致传感器检测到裹头。

|  |  |
| --- | --- |
|  |  |

> **注意：** 裹头检测仅在打印过程中的特定检测窗口内生效，窗口外手动拨动弹片不触发报错属于正常现象，并不代表传感器故障。

## 功能开启

进入“**设置** > **打印选项”**，即可开启**裹头检测**功能。该功能默认设置为“自动”。

|  |  |
| --- | --- |
|  |  |

- **自动**：**根据当前使用的耗材类型自动判断是否执行裹头检测**。对于 PLA Aero 等特殊耗材，系统会为避免因漏料导致误报或影响打印质量，而自动关闭该功能；
- **开启**：打印所有耗材时均执行裹头检测；
- **关闭**：打印所有耗材时均不执行裹头检测。

## 触发检测的场景

开启裹头检测后，将在以下三种情况下触发检测：

### **常规检测**

**每次工具头移动到吐料组件位置时**（比如执行吐料、换色或打印暂停回到吐料组件，并经过检测弹片时），都会执行一次裹头检测。

### **定层检测**

系统会在打印至**第 2 层**和**第 3 层**时强制执行检测。  
此外，在打印高度 **10 mm 以内**，系统会按固定的层数间隔自动执行定层检测。超过 10 mm 后，将不再执行定层检测，但不影响其他检测方式的正常执行。

### **质量检测**

系统会根据不同耗材类型，按累计耗材消耗量执行质量检测；当累计检测达到设定次数后，将不再继续执行质量检测。

例如：

- **PLA**：每消耗 **6 g** 进行一次检测，共检测 **3 次**；
- **PETG**：每消耗 **4 g** 进行一次检测，共检测 **3 次**。

以 PLA 为例，当累计消耗达到 **6 g** 时，系统会自动执行第一次质量检测；此后每再消耗 **6 g**，将执行下一次检测。若累计 **3 次**检测结果均正常，后续则不再触发质量检测。此时系统认为打印约 **18 g** 耗材后，后续发生裹头的概率较低，但不影响其他检测方式的正常执行。

> **注意：所有检测均在当前层第一个对象的外墙打印完成后进行。**这是因为检测过程中，喷嘴空驶可能产生瑕疵；将检测安排在外墙完成后，可将这类瑕疵尽量位于模型内部，从而减少对模型外观的影响。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/nozzle-warp-detection/020.png)

## 检测到裹头后的处理

一旦检测到裹头，打印机将自动暂停打印并弹出提醒。由于该检测并非绝对准确，用户需自行判断是真实发生裹头，还是因霍尔传感器异常或检测弹片被意外触碰所导致。请根据实际进行处理。

1. **确实发生裹头：**请参考 [A2L 喷嘴冷拔维护指南](../maintenance/nozzle-cold-pull-maintenance.md) 进行清理；
2. **霍尔传感器异常：**请参考[霍尔开关故障排查指南](../troubleshooting/hmscode/0300_1A00_0002_0003.md)进行处理；
3. **弹片被意外触碰：**检查弹片位置是否有异物导致弹片歪斜；如有，请清理异物。

|  |  |
| --- | --- |
| 弹片正常状态 | 异物拉扯导致弹片向左偏移 |

## 注意事项

1. 如果您在**特殊模式**里选择了**旋转花瓶**选项，裹头检测将不会生效；
2. 如果您在**特殊模式**里选择了**逐件打印**，打印机会自动分析切片模型。只有在执行裹头检测不会导致工具头于已打印模型发生碰撞时，系统才会按上述策略进行检测。这是因为裹头检测需要工具头在当前高度沿 X 轴移动至检测位置。若当前打印件左侧存在已打印完成的模型（如下图），为避免发生碰撞，系统将跳过此次检测。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/nozzle-warp-detection/004.png)
