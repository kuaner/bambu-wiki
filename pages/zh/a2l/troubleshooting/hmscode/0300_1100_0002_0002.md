## 故障描述

发起打印的准备阶段中，设备会自动高频振动来检测 XY 轴的共振频率，从而判断 XY 轴皮带是否偏松。

## 故障排查

从后方将盖板取下后，露出前方 Y 同步带张紧位置；

![zhangjin4.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/belt-tension/zhangjin4.jpg)

使用 H2.0 内六角扳手将 2 颗张紧螺丝松开一圈（请勿完全松开）。

![ybelt.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/belt-tension/ybelt.jpg)

在新的无尘布上喷涂适量的酒精。

![jiujing.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/jiujing.jpg)

向上推动 X 轴，抬高工具头高度。

![taigao.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/taigao.jpg)

使用无尘布擦拭 Y 轴钢棒，清理旧润滑油或其他杂质。

|  |  |
| --- | --- |
| cashiy1.jpg | cashiy2.jpg |

再将热床移动到后侧，擦拭前段 Y 轴钢棒。

|  |  |
| --- | --- |
| cashiy3.jpg | cashiy4.jpg |

在 Y 轴钢棒上涂抹新的润滑油。

|  |  |
| --- | --- |
| tuyouy1.jpg | tuyouy2.jpg |
| tuyouy3.jpg | tuyouy4.jpg |

涂抹后来回拉动热床，确保润滑油遍布 Y 轴钢棒。

![tuilay.webp](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/tuilay.webp)

清理多余的润滑油。

![qingliy.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/qingliy.jpg)

之后再重新拧紧张紧螺丝，并安装盖板。

![zhangjin7.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/belt-tension/zhangjin7.jpg)

## 校准

在屏幕上点击“设置-维护-校准”，选中振动补偿，完成一次校准流程。若反复涨紧后依然报错，可能需要更换新的 Y 轴皮带，可参考[该Wiki](../../maintenance/replace-y-belt.md)。

![zhangjin12.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/belt-tension/zhangjin12.jpg)
