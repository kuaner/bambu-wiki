## 故障描述

当 AMS lite 退料结束后，里程轮检测到耗材已被拉出工具头，但挤出机霍尔开关仍检测到有料，此时打印机会判断耗材断在挤出机中。

进料霍尔开关由磁铁和进料霍尔板组成。耗材插入后会触碰磁铁靠近霍尔板。退料后，磁铁会自动弹回。打印机根据检测到的霍尔值判断耗材是否在挤出机内部。

|  |  |
| --- | --- |
|  |  |

**可能的原因：**

- 进料霍尔处存在断料，导致进料霍尔始终保持开启状态；
- 进料霍尔磁铁的扭簧卡住，无法顺利回弹，导致即使没有断料，磁铁依然靠近霍尔元件，从而误判为有断料。

## 故障排除

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

1. 拧下五通底座的固定螺丝，小心取出五通底座；

> 请小心操作，避免损坏黑色 FPC 排线！

|  |  |
| --- | --- |
|  |  |

2. 拧松霍尔板的两颗固定螺丝后，翻开霍尔板；

|  |  |
| --- | --- |
|  |  |

3. 将一截耗材插入进料霍尔组件，观察检测磁铁是否能够正常回弹。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_2000_0002_0004/001.webp)

- 若磁铁无法回弹，请检查进料组件内部是否有断料，如有断料，需及时清理；
- 若清理后依旧异常，请参考[进料霍尔板更换指南](../../maintenance/replace-filament-sensor-unit.md) 更换进料霍尔板。
