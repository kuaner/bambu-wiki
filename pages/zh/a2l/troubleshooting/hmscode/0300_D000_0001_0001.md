## 故障描述

该故障表示打印机在工作过程中，检测到刀切模组未安装到工具头模组上，或未正确安装到位。

**可能的原因：**

刀切模组未完全卡入工具头模组安装位，安装时未推至底部，导致未被正确识别。

## 故障排除

### 步骤 1. 重新安装刀切模组

- 重新安装刀切模组，确保安装的时候卡到底，并连接线缆。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/0300_d000_0001_0001/001.webp)

- 向下按压，锁紧快拆锁扣，并连接线缆。

|  |  |
| --- | --- |
|  |  |

- 若仍出现该报错，请参考下一步。

### 步骤 2. 更换进料霍尔板

仍报错的原因可能为工具头内用于刀切模组识别的霍尔传感器（#2）异常，请参考[进料霍尔板更换指南](../../maintenance/replace-filament-sensor-unit.md) 更换进料霍尔板。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/0300_d000_0001_0001/002.png)

若更换进料霍尔板后问题仍未解决，请提交工单并上传设备日志。
