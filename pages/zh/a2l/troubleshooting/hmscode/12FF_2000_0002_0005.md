## 故障描述

检测到耗材用尽后，挤出机会继续挤出一段耗材，将齿轮内残留的耗材完全推送至热端。在此过程中若仍检测到有料，且冲刷至最大长度后依然检测到耗材，可能存在以下原因：耗材已通过霍尔传感器但未被齿轮咬合；或挤出霍尔传感器信号波动。

## 故障排除

***用户可视情调整各排故措施的顺序。***

### 步骤 1. 检查进料霍尔板

1. 拧下五通底座的固定螺丝，小心取出五通底座；

> 请小心操作，避免损坏黑色 FPC 排线！

|  |  |
| --- | --- |
|  |  |

2. 拧松霍尔板的两颗固定螺丝后，翻开霍尔板；

|  |  |
| --- | --- |
|  |  |

3. 将一截耗材插入进料霍尔组件，观察检测磁铁是否能够正常回弹。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/12ff_2000_0002_0005-/001.webp)

- 若磁铁无法回弹，请检查进料组件内部是否有断料，如有断料，需及时清理；

4. 若清理后依旧异常，请参考[进料霍尔板更换指南](https://wiki.bambulab.com/zh/a2l/maintenance/replace-filament-sensor-unit)更换进料霍尔板。

### 步骤 2. 检查五通组件

请参考：[A2L 五通组件拆解与清理](https://wiki.bambulab.com/zh/a2l/troubleshooting/filament-hub-clear) 检查五通组件内是否有断料，如果有，请清理后重试。

### 步骤 3. 检查工具头挤出机是否卡住

请参考：[A2L 堵塞排查](https://wiki.bambulab.com/zh/a2l/troubleshooting/clogging)，检查挤出机内是否存在卡料。
