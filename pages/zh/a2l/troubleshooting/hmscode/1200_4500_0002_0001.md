## 故障描述

在使用 AMS 打印过程中，当打印机执行退料或换料操作时，会通过切刀完成耗材的切割。在切割过程中，工具头将缓慢移动至切刀顶杆位置，挤压切割杆并驱动切刀完成对耗材的切割。待耗材被切断后，刀柄会自动复位。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0001/001.png)

刀柄内部嵌有磁铁，而在进料霍尔组件的对应位置安装有霍尔传感器。打印机通过该霍尔传感器实时感应刀柄的位置，以判断切刀是否成功回弹。如果检测到的霍尔值没有在正常范围，系统将自动在屏幕上弹出该提示信息。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0001/005.png)

## 故障排除

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

1. 使用 H2.0 内六角扳手拆除五通组件底座顶部的 2 颗螺丝，垂直向上轻轻拔出五通组件和底座；

> 注意：
>
> - 进料霍尔板底座处有阻尼脂，可能较粘手，请小心操作；
> - 请勿损坏黑色 FPC 排线。

|  |  |
| --- | --- |
|  |  |

2. 重新插拔进料霍尔板端的排线；

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0001/004.png)

3. 参考[更换 TH 板](../../maintenance/replace-th-board.md)，重新连接 TH 板端的排线（#5），拆装时请检查翻盖式锁扣是否可正常开合。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0001/006.png)

4. 如果进行以上尝试后仍报错，则可能霍尔传感器出现故障。请参考[进料霍尔板更换指南](../../maintenance/replace-filament-sensor-unit.md)更换进料霍尔板。
