## 故障描述

打印机连接 AMS 打印时，打印过程中发现耗材无法正常挤出（俗称"空打"），系统会自动切断并回收耗材到 AMS，然后暂停打印任务并显示错误提示。

> 注意：A1 打印机报此码时，指进料挤出失败与打印过程中空打；A2L 打印机报此码时，只指进料的时候挤出失败。

**可能的原因包括：**

- 喷嘴堵头
- 耗材在挤出机内变形卡住
- 挤出机齿轮上存在大量料屑
- 耗材太细或耗材受潮，导致与挤出机齿轮打滑

> **注意：**排除故障后，点击“继续打印”，打印件上可能会出现缺层等问题
>
> - 如果您能接受轻微瑕疵 → 可以继续打印
> - 如果要求完美打印效果 → 建议取消并重新开始打印

## 故障排除

### 工具、设备及材料

- H2.0 内六角扳手
- H1.5 内六角扳手
- 游标卡尺
- 斜口剪钳/剪刀
- 尖嘴钳

### 排故措施

#### 步骤一：耗材质量排查

将发生问题的 AMS 槽位中的耗材抽出；

- 若耗材前端存在磨损、变形，请切断该部分耗材；

|  |  |
| --- | --- |
|  |  |

- 使用游标卡尺测量多点线材直径，正常的线材料直径为 1.75mm +/- 0.03mm。若线材直径太小，可更换耗材后重新尝试打印；

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_2000_0002_0006/004.png)

- 若耗材受潮严重，可更换耗材或耗材烘干后，重新进行打印；

将耗材插入 AMS 后，点击继续打印，若耗材依旧无法挤出，请参考步骤二。

#### 步骤二：热端堵塞排查

- 手动按压切刀杆，切断耗材;

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_2000_0002_0006/002.png)

- 小心拆下热端，并在热端温度较高时，用尖嘴钳夹住热端入口耗材，拔出残料；

> 注意高温烫伤，可佩戴手套操作！

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_2000_0002_0006/006.png)

- 重新安装热端后，尝试继续打印；若依旧失败，可参考 [A2L 喷嘴堵塞清理](https://wiki.bambulab.com/zh/a2l/maintenance/cold-pull-maintenance-hotend)进行热端堵塞排查。
- 热端清理干净后，请安装热端，重新进行挤出测试。若测试失败，请参考步骤三。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_2000_0002_0006/001.png)

#### 步骤三：挤出机堵塞排查

请参考 [A2L 挤出机堵塞清理](https://wiki.bambulab.com/zh/a2l/maintenance/extruder-cleaning-guide)进行排查。

#### 步骤四：检查入料口里程轮

- 将耗材插入 AMS lite 的四个插槽中，手动推拉耗材，观察经常报错的槽位是否拉动阻力明显大于其它槽，以及里程轮转动是否顺畅。

|  |  |
| --- | --- |
| 转动顺畅 | 转动异常 |

如果仅有一个槽提示挤出失败，且对应槽位里程轮未存在阻力，则说明里程轮存在故障，请参考[更换 AMS lite 入料口组件](../../../ams/maintenance/ams-lite-filament-funnel.md) 更换新的入料口组件。
