## 故障描述

AMS 在送料至挤出机或从挤出机退料时，如果耗材丝卡住或整个送料路径的阻力太大，可能会导致上下料器的电机过载。

## 故障排查

### 步骤 1. 检查料盘是否缠料

- 请检查料盘上的耗材是否缠料；

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_1000_0002_0002/002.png)

- 如果缠料，且不想直接剪断缠料处，可参考下方视频进行操作：

[

](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_1000_0002_0002/1200-1000-0002-0002-pixpin_2026-05-12_12-11-41.mp4)

### 步骤 2. 检查料管

检查出现问题的槽位连接的 PTFE 管是否过长或过度弯曲。

1、2 号槽料管的标准长度为 580mm；3、4 号槽料管的标准长度为 700mm。打印机和 AMS lite 的最佳摆放位置如下图。如果打印机和 AMS lite 相距较远，PTFE 管将被拉弯，导致进料阻力变大。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_1000_0002_0002/001.png)

### 步骤 3. 检查是否有断料

- 请参考 [A2L 堵塞排查](../clogging.md)，检查是否有来自其他槽的耗材或者断料堵塞在工具头内部，清理干净后重试一次。
- 请参考 [A2L 五通组件拆解与清理](../filament-hub-clear.md)，检查五通内部是否有断料，如果有，请进行清理。

### 步骤 4. 检查进料霍尔板

手动将一段耗材插入工具头（插入时请确保其他料管中无耗材），并观察屏幕中耗材页面的挤出机图标是否亮小绿点；取出耗材，小绿点是否消失。

|  |  |
| --- | --- |
|  |  |

- 如果正常，则表示进料霍尔板工作正常。
- 如果不正常，则为进料霍尔板故障，请参考：[进料霍尔板更换指南](../../maintenance/replace-filament-sensor-unit.md) 更换进料霍尔板。

如果您无法通过上述操作步骤解决，请创建工单。
