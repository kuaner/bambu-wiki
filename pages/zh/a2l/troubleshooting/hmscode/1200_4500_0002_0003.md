## 故障现象

当打印机使用 AMS 打印过程中退料或换料时，切刀用于在拉回之前切割耗材。切割时，工具头会移动到打印机的右边，让右侧的杠杆块压住切刀柄，从而推动刀片切割挤出机中的耗材。耗材被切断后，刀柄会自动弹回。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0003/001.png)

刀柄内部有磁铁，挤出机相应位置有霍尔传感器。打印机通过霍尔传感器感应切刀位置，判断是否成功回弹。**当检测到刀柄几秒内没有弹回原位时，屏幕会弹出提示。当屏幕显示切刀卡住时，首先检查刀柄是否真的卡在工具头内。**

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0003/003.png)

切刀卡住时，刀柄会卡在工具头内，不会弹回，如下图所示：

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0003/011.png)

## 情况一：刀柄卡在工具头内

### 步骤 1. 检查耗材

如果刀柄卡住一段时间后可自行弹回，则与打印的耗材有关。在打印 **Support** 或 **Silk** 耗材时，偶尔会出现此现象，此时可点击 **“重试”。**

- 若提示不再出现，可继续打印；
- 若多次点击“重试”仍无法恢复，可能是进料霍尔板异常。请参考以下指南更换霍尔板：[进料霍尔板更换指南](https://wiki.bambulab.com/zh/a2l/maintenance/replace-filament-sensor-unit)。

### 步骤 2. 热端堵塞排查

热端堵塞时，挤出机与热端之间的耗材压力过大，可能导致切刀卡住，无法回弹。请参考以下指南进行热端堵塞排查：[A2L 堵塞排查](https://wiki.bambulab.com/zh/a2l/troubleshooting/clogging)；

- 如果热端堵塞，请参考：[A2L 喷嘴堵塞清理](https://wiki.bambulab.com/zh/a2l/maintenance/cold-pull-maintenance-hotend) 进行清理；
- 如果热端未堵塞，请参考步骤 3。

### 步骤 3. 检查无耗材时切刀状态

将挤出机内耗材退出，再手动按压刀柄，确认在**无耗材状态**下切刀是否仍会卡住。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0003/009.png)

- 如果仍卡住，请参考下一步。

### 步骤 4. 检查切刀弹簧安装

检查切刀弹簧一侧是否正确插入小孔，且位置到位。请参考：[更换切刀刀柄](https://wiki.bambulab.com/zh/a2l/maintenance/replace-filament-cutter-lever) 进行检查调整。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0003/010.png)

## 情况二：刀柄位置正常

### 步骤 1. 清理霍尔传感器

1. 使用 H2.0 内六角扳手拆除五通组件底座顶部的 2 颗螺丝；

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0003/006.png)

垂直向上轻轻拔出五通组件和底座；

> 注意：
>
> - 进料霍尔板底座处有阻尼脂，可能较粘手，请小心操作；
> - 请勿损坏黑色 FPC 排线。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0003/005.png)

2. 使用 H1.5 内六角扳手，拆下霍尔板上的 2 颗螺丝；

|  |  |
| --- | --- |
|  |  |

3. 使用吹风机或者气吹，清理内部磁铁。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0003/002.png)

4. 完成后将霍尔板、五通底座以及固定螺丝重新装回设备，开机确认报错是否消失。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0003/004.png)

### 步骤 2. 检查并插拔霍尔传感器

1. 请参考：[更换 TH 板](https://wiki.bambulab.com/zh/a2l/maintenance/replace-th-board)，重新连接霍尔传感器（#5），拆装时请检查翻盖式锁扣是否可正常开合。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_4500_0002_0003/012.png)

2. 开机确认报错是否消失；若故障仍存在，请联系客户支持团队。
