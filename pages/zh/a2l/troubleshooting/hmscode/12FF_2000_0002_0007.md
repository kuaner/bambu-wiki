## 故障描述

在发起进料、退料或启动打印任务时，如果打印机检测到工具头内有耗材，则会运行“检查耗材位置”步骤。此步骤目的是确认工具头内的耗材来自 AMS 的哪个槽或者来自料盘支架。如果多根耗材堵塞在五通内，或耗材过细打滑，都可能引发报错。

## 故障排查

### 步骤 1. 耗材质量排查

- 按压切刀，切断耗材；

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/12ff_2000_0002_0007/004.png)

- 按压从动轮支架，将发生问题的耗材从 AMS lite 槽位中抽出；

|  |  |
| --- | --- |
|  |  |

- 拔出耗材丝后，检查材料是否有磨损的迹象，若耗材前端存在磨损、变形，请切断该部分耗材，然后再将耗材插入 AMS 中。

|  |  |
| --- | --- |
|  |  |

### 步骤 2. 确认耗材位置

- 在点击“重试”按钮之前，请确认工具头内没有耗材，可根据屏幕“耗材”页面的挤出机图标判断，显示绿点则说明有耗材在工具头内部，并确认所有槽的耗材都在五通外。

|  |  |
| --- | --- |
|  |  |

- 如果仍报错，请提交工单联系客户支持团队。
