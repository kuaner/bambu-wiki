## 故障描述

发起打印或校准工作时，设备首先需要回中 XYZ 轴。X 轴回中过程中工具头将移动到最左侧，当工具头移动出现异常时，可能导致 X 轴归零异常。

- 打印机左右方向存在障碍物；
- X 轴导轨上存在杂物；
- X 轴皮带偏松；
- X 轴电机故障；
- X 轴导轨阻力异常。

## 故障排除

### 打印机周围存在障碍

检查打印机周围是否存在障碍物，可左右拉动工具头观察阻碍情况。

### X 轴导轨上存在杂物

检查导轨上是否有耗材碎屑粘附，可使用酒精湿巾擦拭，或根据 [该Wiki](../../maintenance/lubricate-x-y-z-axis.md) 重新清洁润滑导轨。

![cashi2.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/cashi2.jpg)

### X 轴皮带偏松

可参考 [该Wiki](../../maintenance/belt-tension.md) 重新张紧一次 X 轴皮带，若故障依旧则排查下一步。

### X 轴电机故障或导轨阻力异常

关机状态下左右拉动工具头，或开机后通过屏幕控制 X 轴左右运动。

![xtuila.webp](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/lubricate-x-y-z-axis/xtuila.webp)

若移动顺滑，则需要更换新的 X 轴皮带，可参考 [该Wiki](../../maintenance/replace-x-belt.md)；

若移动出现卡顿，则拧松 X 轴张紧螺丝。

![zhangjin1.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/maintenance/belt-tension/zhangjin1.jpg)  
再拧下右侧皮带压块，并将压块放在 X 轴电机盖上。

![beltblock2.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/0300_2000_0001_0001/beltblock2.jpg)  
![xbeltblock.jpg](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/0300_2000_0001_0001/xbeltblock.jpg)

左右来回推动工具头，若移动顺畅则为 X 轴电机故障，需更换新的 X 轴电机；若移动依然受阻，则为 X 轴导轨异常，可参考 [该Wiki](../../maintenance/lubricate-x-y-z-axis.md) 清洁维护 X 轴导轨，若阻力没有改善，则需要更换新的 X 轴导轨。

![move1.webp](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/0300_2000_0001_0001/move1.webp)
