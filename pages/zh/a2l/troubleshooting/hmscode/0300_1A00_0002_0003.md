## 故障描述

A2L 打印机在吐料组件处配备了裹头检测传感器，用于在打印过程中实时检测裹头现象，及时发出警报并暂停打印，以避免耗材浪费和设备损坏。在执行裹头检测前，系统会对裹头检测传感器进行自检。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/0300_1a00_0002_0003/03001a0000020003-image-4.png)

若检测到传感器未正常工作（如断路、短路或处于异常触发状态），设备将触发报错并暂停打印。若需临时忽略该报错继续打印，您可点击屏幕“设置 > 打印选项”，暂时关闭裹头检测功能。裹头检测功能的具体细节可参考：[A2L 裹头检测介绍](https://wiki.bambulab.com/zh/a2l/manual/nozzle-clumping-detection)

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/0300_1a00_0002_0003/03001a0000020003-image.png)

> **注意：** 裹头检测仅在打印过程中的特定检测窗口内生效，**窗口外手动拨动弹片不触发报错属于正常现象**，并不代表传感器故障。

### 故障原因

裹头监测传感器异常的可能原因：

- 传感器弹片被异物缠绕，导致误触
- 接线端子接触异常
- 传感器连接线破损，内部金属线与设备金属部件接触
- 裹头检测传感器损坏

## 故障排除

### 步骤一：检查弹片周围是否有异物

1. 检查裹头检测弹片周围是否有耗材、碎屑等异物，需确保弹片区域干净整洁，无外部干扰；
2. 如发现异物，请清理后重启打印。

|  |  |
| --- | --- |
| 弹片正常状态 | 异物拉扯导致弹片向左偏移 |

### 步骤二：检查弹片归位是否正常

用手向左轻拨传感器弹片，观察弹片能否自动归位。若无法自动归位，则说明弹片故障，请联系客户支持团队。

![03001a0000020003-pixpin_2026-04-29_18-48-36.webp](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/0300_1a00_0002_0003/03001a0000020003-pixpin_2026-04-29_18-48-36.webp)

### 步骤三：重新拔插传感器的线缆

重新拔插吐料组件端和转接板端的线缆接头。

|  |  |
| --- | --- |
|  |  |

### 步骤四：检查传感器线缆是否破皮

若连接线表面破皮，请联系客户支持团队。
