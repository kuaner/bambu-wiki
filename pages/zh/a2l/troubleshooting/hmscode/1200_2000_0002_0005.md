## 故障描述

在使用 AMS lite 打印的换色过程中，打印机检测到耗材可能用完，并尝试自动排空挤出机内的剩余尾料，但在排料达到最大长度限制后，传感器仍检测到挤出机内有耗材，导致报错。

**可能的原因：**

- AMS lite 上下料霍尔传感器故障，实际有料但检测出无料；
- 工具头霍尔传感器故障，当 AMS lite 耗材和挤出机内耗材均已用尽后，若挤出机仍检测到有料，则会误触发冲刷流程；
- 五通内有断料残留，无法冲出；或耗材本身存在质量问题，导致卡在挤出机内。

## 故障排除

***用户可视情调整各排故措施的顺序。***

### 步骤 1. 检查 AMS lite 上下料霍尔

观察 AMS lite 上该槽位耗材是否真的用完，以及屏幕是否显示该槽位无料；如果误检查出无料，则会在换料过程中误进入冲刷流程。

|  |  |
| --- | --- |
|  |  |

- 如果一致且正确，则 AMS 上下料组件正常；
- 如果不一致，则可能是 AMS 上下料组件霍尔异常，请重新插拔对应上下料组件的线缆；

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/12ff_2000_0002_0005/001.png)

如果重试后依旧报错，则为上下料组件故障，请参考：[AMS lite 上下料组件拆装指引](../../../ams/maintenance/ams-lite-feeder.md) 更换上下料组件。

### 步骤 2. 检查工具头进料霍尔

此时请手动将一段耗材插入工具头（插入时请确保其他料管中无耗材），并观察屏幕中耗材页面的挤出机图标是否亮小绿点；取出耗材，小绿点是否消失。

|  |  |
| --- | --- |
|  |  |

- 如果正常，则表示进料霍尔板工作正常。
- 如果不正常，则为进料霍尔板故障，请参考：[进料霍尔板更换指南](../../maintenance/replace-filament-sensor-unit.md) 更换进料霍尔板。

### 步骤 3. 检查耗材是否卡在挤出机内

请参考：[A2L 堵塞排查](../clogging.md)，检查挤出机内是否存在卡料。
