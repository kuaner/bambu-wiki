## 故障现象

AMS lite 的每个槽都有一个上下料组件。上下料组件中的齿轮挤压料线，并在有刷电机的驱动下把耗材送入或者拉出工具头。如下图所示：

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_1200_0001_0001/001.png)

当耗材过细或者齿轮损坏时，齿轮与料线的间距变大，引发齿轮打滑，最终导致进退料失败。

## 故障排除

本文针对实时视频异常的常见情形提供故障隔离定位及排故措施。常见异常情形如：

- 料线头部区域较细
- 料线规格不标准，直径较细
- 上下料器齿轮损坏

### 工具、设备及材料

- H1.5 /H2.0 内六角扳手
- 游标卡尺

### 排故措施

#### 步骤 1. 耗材质量排查

> 如果是送料过程中报错挤出失败，请手动按压工具头切刀切断耗材。若是打印过程中报挤出失败，请直接跳到步骤 2。

- 按压切刀，切断耗材；

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_1200_0001_0001/006.png)

- 按压从动轮支架，将发生问题的耗材从 AMS lite 槽位中抽出；

|  |  |
| --- | --- |
|  |  |

- 拔出耗材丝后，检查材料是否有磨损的迹象，若耗材前端存在磨损、变形，请切断该部分耗材；

|  |  |
| --- | --- |
|  |  |

- 使用游标卡尺测量多点耗材直径，正常的耗材直径为 1.75mm +/- 0.03mm。若耗材直径太小，可更换耗材后重新尝试打印；

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_1200_0001_0001/003.png)

- 将耗材插入 AMS lite 后，点击继续打印；若耗材依旧无法挤出，请参考步骤 2。

#### **步骤 2. 检查上下料器齿轮是否损坏**

目视检查上下料组件齿轮，检查其是否有严重磨损、齿轮偏移等缺陷；也可参考 [AMS lite 上下料组件拆装指引](../../../ams/maintenance/ams-lite-feeder.md)进行拆解检查。

![](https://public-cdn.bblmw.com/wiki/new/a2l/troubleshooting/hmscode/1200_1200_0001_0001/004.png)

- 若齿轮损坏，更换上下料组件。
