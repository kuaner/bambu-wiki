## 抽屉把手与可调万向轮

组件包含抽屉把手和可调万向轮，两个组件的更换相互独立，请根据需要选择。

|  |  |
| --- | --- |
|  |  |
| 抽屉把手 | 可调万向轮 |

## 何时更换

1. 抽屉把手丢失。
2. 可调万向轮转动卡涩、脚轮破损、无法调高度等。

## 所需工具和材料

- H3.0 内六角扳手
- 十字螺丝刀

## 安全提示

> 在开始更换前，请务必提前清空所有抽屉并将上方的打印机等重物安全搬离，防止重心前移导致倾倒损坏；由于该柜体包含金属材质，拆装时**请务必全程佩戴防护手套**，谨防钣金剪裁边缘、冲压折角及螺丝孔位可能残留的锋利毛刺割伤皮肤；拆卸抽屉滑轨时请参照教程准确寻找释放卡扣，切勿暴力硬拉，推拉抽屉及分离轨道时请时刻留意手指位置，以免夹伤；同时请规范使用工具，妥善收纳拆下的各类五金件，确保整个操作过程安全高效。

## 更换抽屉把手

### 步骤 1.移除抽屉把手

打开需要更换把手的抽屉。

> 三个抽屉更换把手的方法一致，本步骤以上层抽屉为例，展示拆装过程。

![drawer_handle_and_adjustable_caster_wheel_kit_replacement_guide-c8741.mp4_20261119_195610.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-drawer-handle-and-adjustable-caster-wheel/zh/________________-drawer_handle_and_adjustable_caster_wheel_kit_replacement_guide-c8741.mp4_20261119_195610.webp)

使用十字螺丝刀移除一颗螺丝，取下抽屉把手。

![drawer_handle_and_adjustable_caster_wheel_kit_replacement_guide-________-drawer_bottom_panel_replacement_guide-image-2.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-drawer-handle-and-adjustable-caster-wheel/zh/________________-drawer_handle_and_adjustable_caster_wheel_kit_replacement_guide-________-drawer_bottom_panel_replacement_guide-image-2.png)

### 步骤 2.安装抽屉把手

从抽屉前板后面放入 1 颗螺丝 L，对齐螺丝旋紧「21」抽屉把手。

使用十字螺丝刀锁紧螺丝固定。

## 更换可调万向轮

### 步骤 1.移除可调万向轮

将工作站倒置，漏出底部可调万向轮。

> **注意：** 倒置柜体前，请先清理操作台面，确保在干净、平整、无异物及硬物的平面上操作，以免划伤柜体表面或操作台面。

![drawer_handle_and_adjustable_caster_wheel_kit_replacement_guide-image-1.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-drawer-handle-and-adjustable-caster-wheel/zh/________________-drawer_handle_and_adjustable_caster_wheel_kit_replacement_guide-image-1.png)

选择需要更换的可调万向轮，使用 H3.0 内六角螺丝刀移除对应的 4 颗螺丝，取下可调万向轮。

|  |  |
| --- | --- |
| ________________-drawer_handle_and_adjustable_caster_wheel_kit_replacement_guide-image-2.png | ________________-drawer_handle_and_adjustable_caster_wheel_kit_replacement_guide-c8761.mp4_20261119_102840.webp |

### 步骤 2.安装可调万向轮

装回新的可调万向轮，使用 H3.0 内六角扳手锁入四颗螺丝。

|  |  |
| --- | --- |
| ________________-drawer_handle_and_adjustable_caster_wheel_kit_replacement_guide-c8761.mp4_20261119_111207.webp | ________________-drawer_handle_and_adjustable_caster_wheel_kit_replacement_guide-image-3.png |

所有万向轮安装完毕后，将工作站移至最终使用位置进行固定。

逆时针旋转可调万向轮红色旋转件，使支撑调节块触地，直至可调万向轮完全离地。

逐一调节各支撑调节块，直至从顶部按压拓竹工作站时不晃动。

**注意**：可调万向轮离地高度建议不超过 7mm。
