## 大抽屉

工作站下层抽屉为大抽屉，本组件包含大抽屉除抽屉底板外的其他组件。

![_________-large_drawer_replacement_guide-image-8.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-large-drawer/zh/_________-large_drawer_replacement_guide-image-8.png)

## 何时更换

1. 抽屉侧板、抽屉前板或抽屉背板损坏。
2. 抽屉安装螺丝孔滑牙、破损。

## 所需工具和材料

- H3.0 内六角扳手
- 十字螺丝刀

## 安全提示

> 在开始更换前，请务必提前清空所有抽屉并将上方的打印机等重物安全搬离，防止重心前移导致倾倒损坏；由于该柜体包含金属材质，拆装时**请务必全程佩戴防护手套**，谨防钣金剪裁边缘、冲压折角及螺丝孔位可能残留的锋利毛刺割伤皮肤；拆卸抽屉滑轨时请参照教程准确寻找释放卡扣，切勿暴力硬拉，推拉抽屉及分离轨道时请时刻留意手指位置，以免夹伤；同时请规范使用工具，妥善收纳拆下的各类五金件，确保整个操作过程安全高效。

## 移除大抽屉

### 步骤 1.移除大抽屉

拉出下层抽屉到极限位置，将左侧拨片向上抬起解锁限位，同时将外侧导轨向后推过限位位置。

![_________-large_drawer_replacement_guide-c8746.mp4_20261118_151439.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-large-drawer/zh/_________-large_drawer_replacement_guide-c8746.mp4_20261118_151439.webp)

向下按压右侧导轨拨片解锁右侧导轨限位，同时将外侧导轨向后推过限位位置，然后将抽屉完全抽出。

![_________-large_drawer_replacement_guide-c8752.mp4_20261118_154547.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-large-drawer/zh/_________-large_drawer_replacement_guide-c8752.mp4_20261118_154547.webp)

### 步骤 2.拆解大抽屉

> 大抽屉组件已经包含除底板外的完整大抽屉物料，大多数情况下此时您可以选择直接跳转到安装步骤组装全新的大抽屉组件，如想要继续更换旧抽屉的部分组件，可参照后续步骤完全拆解大抽屉。

使用十字螺丝刀移除一颗螺丝，取下抽屉把手。

![_________-large_drawer_replacement_guide-________-drawer_bottom_panel_replacement_guide-image-2.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-large-drawer/zh/_________-large_drawer_replacement_guide-________-drawer_bottom_panel_replacement_guide-image-2.png)

使用十字螺丝刀移除图示两颗螺丝。

![_________-large_drawer_replacement_guide-image.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-large-drawer/zh/_________-large_drawer_replacement_guide-image.png)

## 安装大抽屉

### 步骤 1.组装大抽屉

取出新的抽屉前板，使用十字螺丝刀锁入图示四颗螺丝。

![_________-large_drawer_replacement_guide-image-10.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-large-drawer/zh/_________-large_drawer_replacement_guide-image-10.png)

安装左右抽屉侧板。

|  |  |
| --- | --- |
| _________-large_drawer_replacement_guide-image-11.png | _________-large_drawer_replacement_guide-image-12.png |

将偏心轮箭头向下装入安装孔。

|  |  |
| --- | --- |
| _________-large_drawer_replacement_guide-image-13.png | _________-large_drawer_replacement_guide-image-14.png |

用十字螺丝刀将四颗偏心轮顺时针拧紧约 180°，使偏心轮的箭头朝上。

|  |  |
| --- | --- |
| _________-large_drawer_replacement_guide-image-15.png | _________-large_drawer_replacement_guide-image-16.png |

|  |  |

### 步骤 2.安装大抽屉

对齐两侧导轨缺口，将抽屉推入到底，然后拉出到最外侧验证抽屉限位是否已经生效。
