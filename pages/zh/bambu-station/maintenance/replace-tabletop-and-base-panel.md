## 木质面板组件

木质面板组件包含**桌面**和**底板**两部分，请根据需要选择更换。

|  |  |
| --- | --- |
|  |  |
| 桌面 | 底板 |

## 何时更换

1. 桌面、底板损坏。
2. 底板固定螺丝滑牙。

## 所需工具和材料

- H3.0 内六角扳手
- 十字螺丝刀

## 安全提示

> 在开始更换前，请务必提前清空所有抽屉并将上方的打印机等重物安全搬离，防止重心前移导致倾倒损坏；由于该柜体包含金属材质，拆装时**请务必全程佩戴防护手套**，谨防钣金剪裁边缘、冲压折角及螺丝孔位可能残留的锋利毛刺割伤皮肤；拆卸抽屉滑轨时请参照教程准确寻找释放卡扣，切勿暴力硬拉，推拉抽屉及分离轨道时请时刻留意手指位置，以免夹伤；同时请规范使用工具，妥善收纳拆下的各类五金件，确保整个操作过程安全高效。

## 移除木质面板

### 步骤 1.移除抽屉

拉出上层抽屉到极限位置，此时可以观察到抽屉左侧导轨处有一个塑料拨片，将拨片向上抬起解锁限位，同时将外侧导轨向后推过限位位置。

![__________-wood_panel_assembly_replacement_guide-c8743.mp4_20261118_150703.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-tabletop-and-base-panel/zh/__________-wood_panel_assembly_replacement_guide-c8743.mp4_20261118_150703.webp)

向下按压右侧导轨拨片解锁右侧导轨限位，同时将外侧导轨向后推过限位位置，然后将抽屉完全抽出。

![__________-wood_panel_assembly_replacement_guide-__________.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-tabletop-and-base-panel/zh/__________-wood_panel_assembly_replacement_guide-__________.webp)

中层抽屉和上层抽屉完全一致，同样方法解锁中层的小抽屉左右导轨限位，移除中层抽屉。

向下按压右侧导轨拨片解锁右侧导轨限位，同时将外侧导轨向后推过限位位置，然后将抽屉完全抽出。

![__________-wood_panel_assembly_replacement_guide-c8752.mp4_20261118_154547.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-tabletop-and-base-panel/zh/__________-wood_panel_assembly_replacement_guide-c8752.mp4_20261118_154547.webp)

> **注意：** 导轨边缘较锋利。移除抽屉后，请先将所有导轨推回柜体内，再用胶带固定好导轨前部，避免翻转柜体时导轨滑出，造成划伤或碰伤。

### 步骤 5.移除脚轮

将工作站倒置，漏出底部脚轮。

> **注意：** 倒置柜体前，请先清理操作台面，确保在干净、平整、无异物及硬物的平面上操作，以免划伤柜体表面或操作台面。

使用 H3.0 内六角螺丝刀从每个脚轮处移除 4 颗螺丝，重复操作移除 4 个脚轮。

## 安装木质面板

### 步骤 1.安装底板

在木质面板两侧各插入两个木榫。

|  |  |
| --- | --- |
| __________-wood_panel_assembly_replacement_guide-image-16.png | __________-wood_panel_assembly_replacement_guide-c8773.mp4_20261119_105712.webp |

将左框架「5」对齐木榫推入，然后使用 H3.0 内六角扳手锁入两颗螺丝固定。

> 底板上有一颗箭头，箭头指示位置为工作站前方，左侧安装的左框架组件上有「5」数字标记，右侧右框架组件有「3」数字标记，请注意区分。

|  |  |
| --- | --- |
| __________-wood_panel_assembly_replacement_guide-c8769.mp4_20261119_105838.webp | __________-wood_panel_assembly_replacement_guide-image-17.png |

将右框架「3」对齐木榫推入，然后使用 H3.0 内六角扳手锁入两颗螺丝固定。

|  |  |
| --- | --- |
| __________-wood_panel_assembly_replacement_guide-c8768.mp4_20261119_110024.webp | __________-wood_panel_assembly_replacement_guide-image-18.png |

装回顶部支撑条[4]，从工作站左右侧各锁入一颗螺丝固定。

### 步骤 2.安装脚轮

将工作站翻转底部朝上，依次装回 4 个脚轮，每个脚轮使用 H3.0 内六角扳手锁入 4 颗螺丝固定。

| --- | --- |

### 步骤 3.安装背板

装回背板，对齐四周螺丝孔。

![__________-wood_panel_assembly_replacement_guide-c8760.mp4_20261119_112304.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-tabletop-and-base-panel/zh/__________-wood_panel_assembly_replacement_guide-c8760.mp4_20261119_112304.webp)

使用 H3.0 内六角螺丝刀锁入图示四颗红色标记螺丝，使用十字螺丝刀锁入两颗蓝色标记螺丝。

![__________-wood_panel_assembly_replacement_guide-image-22.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-tabletop-and-base-panel/zh/__________-wood_panel_assembly_replacement_guide-image-22.png)

### 步骤 4.安装桌面

将桌面朝下放置，保持箭头位置向前。

![__________-wood_panel_assembly_replacement_guide-image-23.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-tabletop-and-base-panel/zh/__________-wood_panel_assembly_replacement_guide-image-23.png)

将工作站转动到底板箭头朝前位置，然后放置在桌面上。

|  |  |
| --- | --- |
| __________-wood_panel_assembly_replacement_guide-image-24.png | __________-wood_panel_assembly_replacement_guide-image-25.png |

使用 H3.0 内六角扳手从左右两侧锁入 4 颗螺丝，可先锁入几圈定位，不锁紧。

|  |  |
| --- | --- |
| __________-wood_panel_assembly_replacement_guide-image-26.png | __________-wood_panel_assembly_replacement_guide-image-27.png |

继续使用 H3.0 内六角螺丝刀锁紧图示 2 颗螺丝，同时重新锁紧上一步的四颗螺丝，完成桌面安装。

> 锁入桌面螺丝时，建议先不锁紧，待 6 颗螺丝均对齐位置后再锁紧螺丝，以免个别螺丝安装困难。

![__________-wood_panel_assembly_replacement_guide-image-28.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-tabletop-and-base-panel/zh/__________-wood_panel_assembly_replacement_guide-image-28.png)

### 步骤 5.安装侧板

将工作站转正放置，装回右侧板，使用十字螺丝刀锁入 6 颗螺丝。

![__________-wood_panel_assembly_replacement_guide-image-29.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-tabletop-and-base-panel/zh/__________-wood_panel_assembly_replacement_guide-image-29.png)

装回左侧板，使用十字螺丝刀锁入 6 颗螺丝。

![__________-wood_panel_assembly_replacement_guide-image-30.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-tabletop-and-base-panel/zh/__________-wood_panel_assembly_replacement_guide-image-30.png)

### 步骤 6.安装抽屉

撕除导轨上的胶带，拉出滑轨。

![__________-wood_panel_assembly_replacement_guide-___________-image-75.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/maintenance/replace-tabletop-and-base-panel/zh/__________-wood_panel_assembly_replacement_guide-___________-image-75.png)

对齐两侧导轨缺口，将抽屉推入到底，然后拉出到最外侧验证抽屉限位是否已经生效，依次将三个抽屉装回。
