本文为您介绍如何安装 P3C 拓竹工作站废料滑梯模型。安装后，打印过程中产生的废料可通过滑梯落入收纳盒，便于集中清理。

![01.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/01.png)

## 所需材料与工具

- 废料滑梯模型（[点击下载.3mf](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/purge-chute-guide_for_bambu-station.3mf)）
- H2.0 内六角扳手

## 安全提示

拆装过程中需要移动打印机。操作前，请先关闭打印机电源并断开电源连接，以避免因电路短路导致设备损坏或安全隐患。

![02.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/02.png)

## 安装步骤

### 步骤 1. 打印模型

下载并打印 P3C 拓竹工作站废料滑梯模型。

**下载链接**：[拓竹工作站废料滑梯模型.3mf](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/purge-chute-guide_for_bambu-station.3mf)

**推荐耗材**：PLA 具有较好的刚性与尺寸精度，适合打印此模型。也可以使用 PETG 打印，以获得更好的耐用性。

![03.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/03.png)

1. 废料滑梯通道 1
2. 废料滑梯通道 2
3. 废料收纳盒
4. 圆形垫片

### 步骤 2. 调整打印机位置

在打印机背面，向前移动打印机，为工作站桌面后侧边缘预留约 2 厘米距离。

> **注意：** 距离不宜过大或过小，以确保后续部件可以正确安装，并保证打印机稳定放置。

![04.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/04.png)

### 步骤 3. 安装废料滑梯通道 1

在打印机背面，使用 H2.0 内六角扳手移除机身废料滑梯下方的 1 颗螺丝。

> **注意：** 螺丝细小，拆装时请小心操作，避免遗失。

![05.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/05.png)

将圆形垫片的窄侧朝内、宽侧朝外，对准螺丝孔位。然后使用 H2.0 内六角扳手拧入螺丝。

![06.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/06.webp)

将通道 1 两侧的叶片对齐机身废料滑梯的两侧，将孔位对齐圆形垫片，向下滑动，将通道 1 卡入圆形垫片以固定。

|  |  |
| --- | --- |
| 07.png | 08.webp |

### 步骤 4. 安装废料滑梯通道 2

将废料滑梯通道 2 的凹槽卡入工作站桌面边缘，向左推动至与通道 1 对齐。

![09.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/09.webp)

### 步骤 5. 放置收纳盒

拉出工作站上层抽屉，将废料收纳盒后侧限位槽卡入抽屉后侧边框，向下按压固定，然后推动至最右侧。放置完毕后，推入抽屉。

|  |  |
| --- | --- |
| 10.png | 11.png |

![13.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/12.webp)

**注意**：请确保收纳盒后侧限位槽卡至抽屉边缘，如下图所示。

![13.png](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/13.png)

### 步骤 6. 完成安装

废料滑梯安装完成后，打印过程产生的废料会通过通道落入抽屉内的废料收纳盒。

|  |  |
| --- | --- |
| 14.jpg | 15.png |

清理废料时，只需拉出抽屉并取出废料收纳盒清理。

![16.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/16.webp)

> **注意事项**
>
> - 使用过程中，请勿大幅移动打印机相对于工作站的位置，以免废料滑梯掉落或错位。
> - 如果废料滑梯发生错位，请按照本文安装步骤重新安装。
> - 请勿大幅移动废料收纳盒在抽屉中的位置，以免废料掉落到收纳盒外。

## 拆卸步骤

### 步骤 1. 移除废料收纳盒

拉出工作站上层抽屉，取出废料收纳盒。

![17.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/17.webp)

### 步骤 2. 移除废料滑梯通道 2

向右推出废料滑梯通道 2 ，然后取下。

![18.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/18.webp)

### 步骤 3. 移除废料滑梯通道 1

向上推出废料滑梯通道 1 并取下。

![19.webp](https://public-cdn.bblmw.com/wiki/new/bambu-station/manual/p3c-purge-chute-guide/zh/19.webp)
