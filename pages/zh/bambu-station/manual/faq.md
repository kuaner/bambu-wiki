## 产品信息相关

### 1. 工作站可以给其他打印机使用吗？

拓竹工作站仅适配 P 系列和 X 系列拓竹 3D 打印机。

- H 系列不适用拓竹工作站，请选购拓竹工作站 L。
- A 系列暂不适配拓竹工作站和拓竹工作站 L。配合这两款工作站打印时，产生的晃动会影响打印质量。请关注官方消息，了解后续适配情况。

> 使用前请确认打印机符合桌面尺寸和承重要求，未列入适配范围的机型不建议使用。

### 2. 拓竹工作站的尺寸、重量是多少？

|  |  |
| --- | --- |
| 外形尺寸 | 422×477×571 mm |
| 包装尺寸 | 605×585×300 mm |
| 净重 | 18.7 kg |
| 包装重量 | 22 kg |

### 3. 工作站的承重是多少？每一层分别可以承重多少？

各区域建议承重如下：

| 区域 | 最大承重 |
| --- | --- |
| 顶部 | ≤ 45 kg |
| 单个抽屉 | ≤ 15 kg |

为确保使用安全，请勿超过建议承重范围，并避免将重物集中放置在局部区域。

### 4. 拓竹工作站包装箱内包含哪些内容物？

包装内包含工作站的全部配件，以及安装所需的螺丝和工具。详细包装清单及安装指南请参考[工作站开箱指南](../../h3c/manual/bambu-station-installation-guide.md)。

### 5. 拓竹工作站侧板的作用是什么？

侧板为带挂孔板面（类似洞洞板），可挂在侧板孔位上放置常用工具和配件，也可自行加装收纳盒、挂钩等，把零散物品固定在柜体侧面，方便取用、减少桌面占用。

### 6. 拓竹工作站的上抽屉和中抽屉有什么区别？

上、中抽屉均为小抽屉，区别在背板高度：上抽屉背板较矮，对应最上层安装位置，便于废料滑梯将废料排入抽屉；中抽屉背板较高，装于中间滑轨。

请前往 [MakerWorld](https://makerworld.com.cn) 或 Bambu Handy，在 Bambu Lab 官方账号内搜索「拓竹工作站废料滑梯」，打印适配的模型并安装使用，详细的安装方法请前往“[拓竹工作站废料滑梯模型安装指南](p3c-purge-chute-guide.md)”。

### 8. 工作站的主要材质是什么？

工作站主要材质为刨花板、中密度板、Q195 钢。

## 使用与维护相关

### 工作站是整机发货，还是需要自行组装？

工作站为散件发货，收到后需要自行组装。

单人组装预计耗时约 **60–90 分钟**。包装内已包含完整的螺丝配件、专用工具和图文安装说明书。您可以按照说明书步骤完成组装，也可以参考官方安装视频进行操作。详情请参考：拓竹工作站开箱安装指南。

### 拓竹工作站与普通家用柜子有什么区别？

拓竹工作站面向 3D 打印使用场景设计，空间布局更适合打印设备和相关配件的收纳与使用，例如可放置耗材及常用工具。

相比普通家用柜子，拓竹工作站支持更灵活的收纳拓展，例如自定义侧板收纳方案等，可为用户提供更匹配打印场景的专属工作站。

### 洞洞板无法顺利卡入配件怎么办？

如果配件不容易卡入洞洞板，建议检查配件的设计尺寸。

在 3D 打印相关配件时，不建议按 5 mm 厚度进行设计。建议预留一定装配间隙，将卡接位置厚度设计为约 4.8 mm，这样更容易安装到洞洞板上。
