## Bambu Handy 是什么？

Bambu Handy 是一款专为拓竹 3D 打印机设计的一体化移动应用程序。它可用于远程监控和管理拓竹 3D 打印机，也支持快速打印此前打印过的项目，以及在打印过程中调整打印任务。

![what_is_bambu_handy.png](https://wiki.bambulab.com/software/bambu-handy/cn-homepage/what_is_bambu_handy.png)

## 下载和安装

Bambu Handy 可以通过拓竹官方网站下载，也可在各大应用市场搜索下载。

Bambu Handy 官方下载地址：[**https://bambulab.cn/zh-cn/download/app**](https://bambulab.cn/zh-cn/download/app)

## 首次使用

首次打开 Bambu Handy 时，请阅读并同意隐私政策。选择**同意**后，应用会请求开启通知权限。建议开启通知权限，以便及时接收打印状态等重要信息。完成后，应用将自动进入主界面。

|  |  |
| --- | --- |
|  |  |

### 登录/注册

进入主界面后，点击底部导航栏右侧的 1 **我的**按钮，进入「我的」页面。然后点击屏幕上方的 2 **登录/注册**，完成账号注册或登录。

Bambu Handy 支持使用手机号或第三方账号登录。

|  |  |
| --- | --- |
|  |  |

### 添加打印机

登录账号后，点击底部导航栏的 1 **设备**按钮，然后点击 2 **绑定打印机**以添加打印机。

![how_to_bind.png](https://wiki.bambulab.com/software/bambu-handy/cn-homepage/how_to_bind-p1-portrait.png)

绑定打印机共有三种方式：

1 扫描二维码

2 通过 PIN 码绑定

3 配对附近设备

![bind_options.png](https://wiki.bambulab.com/software/bambu-handy/cn-homepage/bind_options-portrait.png)

#### 1 扫描二维码

在打印机屏幕上找到用于绑定的二维码，然后使用 Bambu Handy 扫描。

|  |  |
| --- | --- |
|  |  |

阅读并勾选同意用户条款和隐私政策后，点击「**确定绑定**」，即可绑定打印机。

> **注意**：如果扫码失败，可在扫码页面缩放二维码，或者清洁摄像头镜头。

#### 2 通过 PIN 码绑定

点击「**通过 PIN 码绑定**」，随后输入打印机屏幕上显示的 6 位 PIN 码（由字母和数字组成的验证码）。

|  |  |
| --- | --- |
|  |  |

> 在打印机屏幕上点击「**账号**」或「**登录**」，即可获取二维码或绑定用的 PIN 码。

| H2/P2/X 系列 | P1 系列 | A 系列 |
| --- | --- | --- |
| screen_operation.png | region.png | a1-series-pincode-3.png |

回到打印机屏幕点击「**绑定**」或「**允许**」，完成连接。（以 A 系列举例）

![bind-on-a1.png](https://wiki.bambulab.com/bambu-studio/manual/pin-code/bind-on-a1.png)

#### 3 配对附近设备

点击「**配对附近设备**」，应用会自动搜索并列出附近可绑定的打印机。请确保手机与打印机处于同一局域网内，否则无法搜索到设备。

已连接的打印机会显示在「**我的打印机**」中，未绑定的打印机则显示在「**未绑定设备**」中。在「**未绑定设备**」中选择要绑定的打印机，然后点击「**确定绑定**」。

|  |  |  |
| --- | --- | --- |
|  |  |  |

部分手机系统可能会请求「附近设备」权限。点击「**允许**」后，Bambu Handy 才能搜索打印机。

打印机需连接网络才能使用 Bambu Handy 绑定账号：

- X 系列、H2 系列和 A1 系列以及 P2S 可直接在打印机界面连接网络；
- P1 系列需先通过蓝牙连接打印机，再连接网络，详情可参考 [**P1 系列打印机网络故障问题排查指南**](../../p1/troubleshooting/printer-binding-issue.md)；
- 当打印机与手机在同一局域网内时，Bambu Handy 应用会自动显示搜索到的设备。

> **注意**：Bambu Handy 目前不支持打印机局域网模式，必须使用互联网才可连接到打印机。局域网仅用于打印机发现，数据传输需通过互联网实现。更多关于局域网模式的信息请访问[如何在打印机上使用局域网模式](../../knowledge-sharing/enable-lan-mode.md)。

#### 如何从模型页面开始打印

1. 选中心仪的模型后，点击右下角的**准备打印**。
2. 选择打印配置。
3. 确认打印机、打印板、耗材等信息无误后，点击最下方**开始打印**。
4. 开始切片，并自动进入设备页面。

## 进阶功能

该部分主要介绍 Bambu Handy 的两项进阶功能。

### 打印零件/跳过零件

在以下两种情况下，您可以选择要打印的特定零件：

1. **通过 Bambu Studio 发送的打印任务：** 当打印任务从 Bambu Studio 发送到打印机后，可在设备界面选择需要打印的零件。
2. **通过打印历史或 MakerWorld 发起的打印任务：** 当从打印历史或直接从 MakerWorld 开始打印时，可使用零件跳过功能，在包含多个零件的盘中选择特定零件。

**何时使用零件跳过功能**：打印包含多个模型的打印板时，可以使用“跳过零件”功能跳过指定模型。该功能适用于某些意外情况，例如，打印任务中的某个模型因脱落、倒塌等原因打印失败后，如果继续打印，可能会产生「炒面」（喷嘴继续挤出耗材，但模型已脱落，导致耗材缠绕）。跳过该模型就可以保留其他完好的打印件继续打印，减少耗材和时间的浪费。

零件跳过页面会显示打印板俯视图和本盘零件列表，您可以逐个勾选，也可以使用「全选」，确认后点击「跳过」。

但需要注意，在打印过程中一旦跳过某个零件，该操作将无法撤销；如需打印被跳过的零件，必须重新开始打印。

更多信息请参考[**零件跳过**](../../general/skipping-objects.md)。
