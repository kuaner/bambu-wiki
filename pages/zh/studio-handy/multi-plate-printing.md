## 介绍

本页介绍如何在 Bambu Studio 中进行多盘打印。

## 何时使用

适用于模型文件体积较大，单盘无法容纳的情况。

## 适用型号

X 系列、P 系列、H 系列（A1 系列暂不支持）

## 操作步骤

### 添加新盘

- 在打印板上选好模型后，点击工具栏中的第二个按键**添加新盘**，即可添加第二盘。一次可添加多盘，最多可添加36盘。

|  |  |
| --- | --- |
|  |  |

- 可在新盘中添加想要的模型。本篇以4盘为例。

![选择模型-4盘.png](https://wiki.bambulab.com/studio-print-all/%E9%80%89%E6%8B%A9%E6%A8%A1%E5%9E%8B-4%E7%9B%98.png)

### 切片所有盘

- 选择完模型后，点击右上方切片单盘左侧的**箭头**，选择**切片所有盘**。

![切片所有盘-四.png](https://wiki.bambulab.com/studio-print-all/%E5%88%87%E7%89%87%E6%89%80%E6%9C%89%E7%9B%98-%E5%9B%9B.png)

- 点击所选的**切片所有盘**，开始切片。

![切片所有盘-四盘.png](https://wiki.bambulab.com/studio-print-all/%E5%88%87%E7%89%87%E6%89%80%E6%9C%89%E7%9B%98-%E5%9B%9B%E7%9B%98.png)

### 打印所有盘

- 切片完成后，光标会自动落在 **All Plates Stats** 上。点击右上方打印单盘左侧的**箭头**，选择**打印所有盘**。

![打印所有盘-蓝色.png](https://wiki.bambulab.com/studio-print-all/%E6%89%93%E5%8D%B0%E6%89%80%E6%9C%89%E7%9B%98-%E8%93%9D%E8%89%B2.png)

- 点击所选的**打印所有盘**，即可开始打印。

![打印所有盘-确认.png](https://wiki.bambulab.com/studio-print-all/%E6%89%93%E5%8D%B0%E6%89%80%E6%9C%89%E7%9B%98-%E7%A1%AE%E8%AE%A4.png)

### 打印第二盘

- 第一盘打印完成后，点击打印机屏幕的**关闭**。

![关闭.jpg](https://wiki.bambulab.com/studio-print-all/%E5%85%B3%E9%97%AD.jpg)

- 待打印件冷却后，将其从打印板上取下，并清理干净打印板，放回热床。
- 屏幕会自动回到文件夹页面，点击新添加的多盘打印文件，可翻页选择接下来想要打印的模型。

![第二盘-2.png](https://wiki.bambulab.com/studio-print-all/%E7%AC%AC%E4%BA%8C%E7%9B%98-2.png)  
![翻页-1.jpg](https://wiki.bambulab.com/studio-print-all/%E7%BF%BB%E9%A1%B5-1.jpg)

- 选好模型后，点击右下角的**打印**，即可开始打印。

![右下角打印.jpg](https://wiki.bambulab.com/studio-print-all/%E5%8F%B3%E4%B8%8B%E8%A7%92%E6%89%93%E5%8D%B0.jpg)

## 所有盘的打印顺序

在进行多盘打印时，通常情况下，**第一个打印的模型是最后添加的模型**。因此，打印顺序应基于盘片的添加顺序，即先添加的盘片应后打印。这种顺序有助于确保模型的正确组装和拼接。

![动画_打印所有盘.gif](https://wiki.bambulab.com/studio-print-all/%E5%8A%A8%E7%94%BB_%E6%89%93%E5%8D%B0%E6%89%80%E6%9C%89%E7%9B%98.gif)
