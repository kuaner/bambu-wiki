## 目的

本文指导如何在湿态下使用 PETG HF 耗材并设置合适的参数。

## **基本规律：耗材越干，打印质量越高**

**每种耗材都会或多或少地从空气中吸收水分而受潮**，在打印时，这些水汽在温度很高的喷嘴中受热后会迅速汽化，从而使耗材熔体膨胀、流动更快并产生气孔，进而使打印件出现拉丝、漏料、孔洞、表面粗糙、强度低等问题，且耗材受潮越严重（环境湿度越高、暴露时间越长），这些问题往往更严重。因此，**强烈建议在打印模型前，尤其是那些对外观要求很高的模型，如果无法确认耗材足够干燥，就需要先把耗材烘干，且在使用过程中，对耗材进行密封、干燥保护。若发现耗材已经受潮，推荐使用 Generic PETG HF 打印参数。**

## **使用 Generic PETG HF 参数时，干湿态耗材的打印对比**

**在不需要对 Generic PETG HF 进行烘烤的情况下，也能打印好此材料。**

|  |  |
| --- | --- |
| Generic PETG HF 参数线材干态的小船与测试件 | Generic PETG HF 参数线材湿态的小船与测试件 |

注：为了打印潮湿状态下的 PETG HF，Generic PETG HF 设置的打印温度为 220℃，体积速度为 16mm³/s，整体速度低于 Bambu PETG HF 的打印参数。在此温度下进行打印，不建议调高打印速度，避免造成堵头、挤出故障等问题。材料烘干后，更推荐使用默认的 Bambu PETG HF 打印参数，速度更快，性能更强更加稳定。

## 注意事项

- **打印前先把耗材烘干：**PETG HF 在使用前需要干燥（在鼓风干燥箱中以 65°C 的温度干燥 8 小时）以避免水汽使得挤出线条中存在气泡、孔洞。
- **使用干燥盒：**使用过程中需要用干燥剂保护，防止吸湿。
- **若耗材已经受潮且没有保护条件：**建议降低打印温度与速度，推荐使用 Generic PETG HF 打印参数（此参数是针对于耗材已受潮而专门进行的优化，打印质量随着耗材的潮湿程度而发生变化，若发现打印质量还是比较差，建议继续降低打印速度）。

## 将准备使用的耗材按照正确的操作、温度、时长等进行烘干

如果您购买的是无盘耗材，请将耗材安装在料盘上再进行烘干。安装方法可参考此 Wiki：[如何把无盘耗材装到可重复使用料盘上 |Bambu Lab Wiki](../../general/swaping-new-filament-with-bambu-reusable-spool.md)

![20250414-202919.jpg](https://wiki.bambulab.com/filament-acc/filament/petg-hf-unfinished-drying/20250414-202919.jpg)

使用 X1、X1C 干燥耗材时，需要用耗材包装纸盒或自行打印的 PC 盒来盖住料盘，且全程都要盖紧上盖和关紧前门，以使料盘所处空间的温度达到较高值；另外，烘烤过程需给料盘翻面，使耗材整体都能烤干。具体操作请参见：[耗材烘干操作指南](dry-filament.md)

**准备打印前，将耗材放入 AMS 或密封盒中，并放入干燥剂进行保护。**

## **使用 Bambu PETG HF 参数干湿态打印对比**

**使用 Bambu PETG HF 参数打印时，请务必烘干耗材。**

|  |  |
| --- | --- |
| Bambu PETG HF 参数线材干态的小船与测试件 | Bambu PETG HF 参数线材湿态的小船与测试件 |
| Bambu PETG HF 参数湿态线材有拉丝漏料风险 | Bambu PETG HF 参数湿态线材有拉丝表面气孔风险 |

材料潮湿后，若未烘干线材使用 Bambu PETG HF 打印参数，则会出现明显的拉丝漏料情况，严重时可能出现大量气孔，影响模型质量。
