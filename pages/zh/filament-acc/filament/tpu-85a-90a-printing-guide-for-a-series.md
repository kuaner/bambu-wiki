## TPU 90A

TPU 90A 是热塑性聚氨酯（ TPU ）材料中的邵氏硬度为 90A 的产品。

- 硬度：TPU 的硬度通常以邵氏硬度 A（Shore A）来表示。90A 表示这种材料的硬度等级
- 弹性与柔韧性：能够在较大的范围内拉伸和弯曲而不破裂，恢复性强。这种特性使得 TPU 90A 在需要弹性和柔韧性的应用中表现出色。
- 耐磨性：TPU 材料具有良好的耐磨性，能够在长时间的使用过程中保持稳定的性能。

在应用方面， TPU 90A 可以用于制造鞋底、运动器材部件等需要弹性和耐磨性能的产品，也可以用于制造手机保护壳、智能手表表带等电子产品配件。总的来说，TPU 90A 是一种性能优异、应用广泛的热塑性聚氨酯材料。不同硬度等级使得它们能够满足不同应用场景的需求。

## 打印前准备

### 耗材防潮

TPU 材料具有较强的吸湿性，在自然环境中容易吸收水分，受潮后会导致打印质量下降（如气泡、拉丝、层间粘结不良等）。

日常存放时，建议将 TPU 耗材放置在环境湿度低于 20% RH 的环境中。**推荐将耗材放在密封收纳盒内，并在收纳盒中放置足量的硅胶干燥剂，以延长耗材的可用寿命。**

![收纳箱.jpeg](https://wiki.bambulab.com/filament-acc/filament/tpu-85a-90a-printing-guide/%E6%94%B6%E7%BA%B3%E7%AE%B1.jpeg)

### 耗材烘干

TPU 材料具有较强的吸湿性，在自然环境中容易吸收水分。若含有水分的 TPU 直接用于 3D 打印，打印过程中水分受热会迅速汽化，从而在打印制品中形成气泡、空洞等缺陷严重影响打印质量，甚至可能导致打印失败。

因此使用 TPU 打印前必需对 TPU 耗材进行烘干，使用完后正确密封存储。

耗材烘干的方式有以下两种：

**1. 使用 AMS 2 Pro \ AMS HT 烘干**

**2. 使用封箱式打印机的热床烘干**

由于 A1/A1mini 是开放式打印机，无法通过热床烘干耗材。如果您有封箱的 X 系列、P 系列和 H2 系列打印机，可以使用这些打印机的热床来进行烘干。

> 💡 具体的烘干流程请参考 [耗材烘干操作指南 | Bambu Lab Wiki](dry-filament.md)。

![](https://wiki.bambulab.com/filament-acc/filament-dry-prepare/image-9.png)

### 热端

强烈推荐选用全新热端，或使用只打印过 TPU 的热端。

| 耗材种类 | 0.2mm 热端 | 0.4mm 热端 | 0.6mm 热端 | 0.8mm 热端 |
| --- | --- | --- | --- | --- |
| TPU 90A | 不适用 | 推荐 | 推荐 | 推荐 |

> **⚠️ 务必注意，切勿使用曾打印过纤维增强耗材（如碳纤增强、玻纤增强耗材）的热端来打印 TPU。**

若不是全新热端，请检查热端状态（是否有残料，若有请升温后用 PLA / PETG 耗材冲刷 2 - 3 次，不可使用纤维增强耗材进行冲刷）。

**冲刷操作步骤（以 PLA Matte 为例）：**

1. 为操作方便，首先将工具头上的 PTFE 管与工具头断连。
2. 推荐将热端温度升至 250 ℃，取一截 PLA Matte 耗材插入工具头。
3. 点击操作界面 “向下挤出” 按键，观察耗材是否连续均匀挤出。（此步骤需重复 3 - 5 次）

![冲刷.gif](https://wiki.bambulab.com/filament-acc/filament/tpu-85a-90a-printing-guide/a-series/%E5%86%B2%E5%88%B7.gif)

> **注意：** 如果想进一步清理热端，达到更加良好的打印效果，推荐冷拔，请参考此 wiki：[A1 系列打印机热端堵塞清理](https://wiki.bambulab.com/zh/a1-mini/troubleshooting/nozzle-clog#h-2-%E4%BD%BF%E7%94%A8%E9%80%9A%E9%92%88%E7%96%8F%E9%80%9A%E5%B9%B6%E5%86%B7%E6%8B%94)。

### 打印板

| 耗材种类 | 低温打印板 | 工程材料打印板 | 光面PEI打印板/高温打印板 | 低温增稳打印板 | 是否涂胶 |
| --- | --- | --- | --- | --- | --- |
| TPU 90A | 推荐 | 推荐 | 推荐 | 不适用 | 是（除纹理板） |

- 纹理 PEI 打印板涂胶后可能会出现过粘的现象，因此**不推荐使用纹理板打印时涂胶**。
- 其余打印板均需涂胶，以防止出现模型首层质量差，不粘松脱，甚至导致打印失败的情况。
- 🚫 **不可使用低温增稳打印板打印 TPU**，使用低温增稳打印板打印 TPU 可能出现粘接过牢现象。

### 挤出机

打印前，参考教程 [A1 系列挤出机清理](../../a1-mini/troubleshooting/extruder-clog.md) 检查并保养挤出机（如有异物，如料渣，请拆卸后擦拭，清洁），若进料齿轮有磨损需要更换（否则可能会出现耗材打滑的情况）。

## 操作步骤

### 装载方法

#### 1. **使用 AMS HT 进料**

在**打印** TPU 耗材时，AMS HT 可以作为装载耗材的密封容器，但是**无法使用 AMS HT 的送料功能**。

因此，我们需要将 TPU 耗材通过 **TPU 出料口**送出耗材，**而不是默认的出料口**。

![进料口.png](https://wiki.bambulab.com/filament-acc/tpu/%E8%BF%9B%E6%96%99%E5%8F%A3.png)

**使用 AMS HT 装载耗材的步骤如下：**

- **步骤 1**：

先裁剪 50mm 长的 PTFE 管，并将 PTFE 管微微弯折，使其保持弯曲，便于后续进料。然后打开 AMS HT 尾部的硅胶塞，将 PTFE 管凸起一侧朝上，将 PTFE 管插入硅胶塞的小孔，确保插入 AMS HT 的长度为 5mm。

|  |  |
| --- | --- |
| 50mm 长的 PTFE 管 | 插入 AMS HT |

- **步骤 2**：

确认耗材的方向，将耗材放入 AMS HT 中，从下至上穿过铁氟龙管。

|  |  |
| --- | --- |
| 确认耗材的方向 | 将耗材从下至上穿过铁氟龙管 |

- **步骤 3**：

扣紧 AMS HT 上盖，即安装完成。

|  |  |
| --- | --- |
| TPU 出料口 | 耗材进料方向 |

#### 2. **使用料桶进料**

料桶为进料提供了一个阻力较小、密封性强的空间。

4L 料桶可以保证料盘转动流畅的最大宽度上限约为 67.5 mm，5.8L 料桶可以保证料盘流畅转动的最大宽度上限约为 108.5 mm。

由于 TPU 烘干后耗材受热膨胀可能会导致料盘涨大变形，从烘干前 65.4 mm 的料盘外沿宽度涨大到约 69.4 mm，因此，我们强烈推荐使用 5.8L 料桶装载 TPU 进行进料打印，保证进料通畅。

### 进料步骤

本例将为您展示**使用料桶**进料的步骤。

**进料前提示：**

1. 进料前请确保耗材充分干燥。
2. 使用料桶进料请从侧面开口。

**进料前准备：**

1. 摘除连接在工具头端的其中一根铁氟龙管，并确保挤出机无其他耗材。
2. 将料架放置于打印机侧边，保证出料口位置高于挤出机进料口。

|  |  |
| --- | --- |
| 断开_ptfe_管.jpg | 耗材插入五通.jpg |

**进料步骤：**

1. 推荐将热端升温至 250 ℃。
2. 从料桶中扯出耗材，直接插入到挤出机进料口中。
3. 低频点击 “向下箭头” 进料，直到耗材连续顺畅挤出。

![升温点进料.gif](https://wiki.bambulab.com/filament-acc/filament/tpu-85a-90a-printing-guide/a-series/%E5%8D%87%E6%B8%A9%E7%82%B9%E8%BF%9B%E6%96%99.gif)

**注意事项：**

- 从工具头进料过程中，若是发现进料有明显阻力，请检查料桶内耗材转动是否流畅。
- 当挤出机齿轮已经咬合住 TPU 耗材之后，慢慢点击挤出按钮，确保耗材从热端顺利挤出，避免进料失败。

### 退料步骤

A1 系列机型都需要升温后进行手动退料，不支持用切刀自动退料。

**步骤 1.** 将热端温度升至 250℃。

**步骤 2.** 缓慢点击挤出机 “向上箭头” ，跟随齿轮回转将耗材轻轻拉出工具头。

![退料.gif](https://wiki.bambulab.com/filament-acc/filament/tpu-85a-90a-printing-guide/a-series/%E9%80%80%E6%96%99.gif)

### 参数设定

除了预设参数外，具体参数设定应当随模型的特点进行调整。

1. TPU 90A 推荐打印温度为 225 ℃，热床温度为 30 - 35 ℃。
2. 打印时请保留默认的体积速度上限，不建议加快打印速度。
3. 打印 TPU 90A 时关闭动态流量校准。

|  |  |  |
| --- | --- | --- |
| 动态流量校准-屏幕.png | 动态流量校准-handy.jpg | 动态流量校准-studio.png |

4. 不建议打印细高模型，TPU材质较软，模型打印一定高度时容易晃动导致打印失败。

## 常见打印问题

**TPU 材料容易出现下列问题：**

1. 缺料（堵头、进料阻力、耗材打滑）
2. 卡挤出（耗材弯曲卡柱挤出齿轮，需拆开挤出机后扯出卡住耗材）
3. 拉丝漏料（使用大口径热端，微调回抽，进一步烘干耗材，模型后处理）

详细问题解决方法，请参考此 wiki：[常见打印质量问题和解决办法](../../knowledge-sharing/common-print-quality-problem.md)。
