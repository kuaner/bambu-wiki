## 局部拉丝或漏料

**拉丝**是指打印过程中，喷嘴在空驶移动时，熔融耗材从喷嘴口意外渗出并拉出细丝，在模型表面或不同部件之间留下蛛网状的细丝。

**漏料**则是指喷嘴在不应出料时仍持续渗出熔体，导致模型局部堆积多余材料、粘嘴或表面瑕疵。

两者通常成因相近，多由喷嘴出料过量、耗材受潮或回抽设置不当等因素引起。

## 常见原因与改善方法

拉丝或漏料主要由以下原因引起，可对照排查并处理。

### 1. 耗材受潮

打印时水分受热汽化，导致熔体破裂、异常流动。

**解决方法：**

1. 打印前先烘干耗材。请参考：[耗材烘干操作指南](../dry-filament.md)。
2. 将耗材存放在含有效干燥剂的密封容器中存储与使用。

![](https://wiki.bambulab.com/filament-acc/filament/pla-pure/3.3dry_the_filament_zh.png)

  

### 2. 空驶距离长且回抽不足

模型存在较长空驶距离、且回抽长度偏小时，熔体会在空驶过程中流出喷嘴。

**解决方法：**

- 打印多个模型时，减小模型间距。
- 适当增加回抽长度或回抽速度。

> ℹ️ **提示**：回抽长度设置过大容易引起堵头，一般建议不超过 `2 mm`。

### 3. 模型结构特殊或摆盘方式不当

当单个模型存在较多不连续结构，或单盘打印多个模型且摆放间距过大时，打印过程中会出现较多、较长的空驶。熔体在空驶时向下滴落，从而造成漏料、粘嘴等缺陷。

**解决方法：**

- 减小模型间的摆放距离。
- 开启「**避免跨越外墙**」，以降低拉丝概率。

![avoid_crossing_wall.png](https://wiki.bambulab.com/knowledge-sharing/print-quality/stringing-oozing/avoid_crossing_wall.png)

  

### 4. 喷嘴温度过高

喷嘴温度过高会使熔体粘度过小，导致出料异常。

**解决方法：** 适当调低喷嘴温度。

### 5. 低密度耗材未调整参数

低密度耗材（如 PLA Aero）内部存在较多孔洞和气体（含水），且打印过程中还会产生气体，这会使耗材熔体产生较大膨胀、异常流动。若未相应调低打印温度或流量比例，便容易出现拉丝、漏料。

**解决方法：**

1. 打印前先烘干耗材。请参考：[**耗材烘干操作指南**](../dry-filament.md)。
2. 适当调低打印温度。
3. 切片时将流量比例调至 `0.5 ~ 0.7` 之间。

### 6. 喷嘴口径过大

喷嘴口径过大会使流出的熔体偏多。常见情况与处理方法如下：

- **配置与喷嘴不匹配**：切片时选错喷嘴配置，或打印时误用了大口径喷嘴。打印前请确保所选配置与实际喷嘴规格一致。

|  |  |
| --- | --- |
|  |  |

- **喷嘴磨损**：喷嘴长期使用、磨损明显。请更换新喷嘴。
