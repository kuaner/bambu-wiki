## 何时使用

更换耗材的操作不当时，耗材会缠绕或卡在可重复使用的料盘中，此时需要本故障排除指南。

## 视频指南

操作前，请您卸下耗材，手动将其从 AMS/外部线轴支架中取出，然后按照视频中的操作步骤释放卡住的耗材。

## 操作指南

以 AMS lite 上耗材缠料举例，所有官方耗材解开缠料的操作一致。

### 外部缠料：

步骤一：找到打结位置并压住两端

![步骤一.png](https://wiki.bambulab.com/filament-acc/tangled-stuck/%E6%AD%A5%E9%AA%A4%E4%B8%80.png)

步骤二：取下料盘并抽出结点

![抽出打结耗材.webp](https://wiki.bambulab.com/filament-acc/tangled-stuck/%E6%8A%BD%E5%87%BA%E6%89%93%E7%BB%93%E8%80%97%E6%9D%90.webp)

步骤三：将结点解开并重新绕线

![解开.webp](https://wiki.bambulab.com/filament-acc/tangled-stuck/%E8%A7%A3%E5%BC%80.webp)

步骤四：将耗材放入设备恢复打印,或将料头插入侧方孔洞保存。

### 内部缠料：

步骤一：定位卡料点

|  |  |
| --- | --- |
| 发现卡料点 | 将卡料点一面朝上放置 |

步骤二：旋开料盘，排除卡料点

|  |  |
| --- | --- |
| 逆时针旋开料盘 | 将卡在侧面的线小心抽出 |

> **注意：此步骤需要小心操作，尽量保证料盘宽片在下放置，以免线材散开后无法装回！**

步骤三：重新安装料盘

|  |  |
| --- | --- |
| 确保侧面无卡线后，将上侧料盘扣回 | 旋紧料盘 |

步骤四：收回线材

|  |  |
| --- | --- |
| 拉扯线材几圈，排除是否存在其他缠线点 | 确认无缠绕点后，将线材绕回盘上 |

将耗材放入设备恢复打印,或将料头插入侧方孔洞保存。
