## 打印板

打印板是 FDM 3D 打印机的核心配件之一，通过磁吸的方式固定在打印机的**热床**上，作为**模型的承载平台**。在打印过程中，耗材被逐层挤出并堆叠成型。打印板为挤出的耗材提供**稳定的附着表面**，确保模型不发生位移或翘边。此外，打印板的**可弯曲设计**，使得模型打印完成后，只需轻轻弯折打印板，即可快捷、方便地取下模型。

![build_plates.png](https://wiki.bambulab.com/filament-acc/home/build_plates.png)

- **打印板尺寸**：由于不同机型的热床尺寸各异，需要搭配不同尺寸的打印板。各机型对应的打印板尺寸如下：

| 面积规格 | 适配机型 |
| --- | --- |
| **350×320 mm** | H2D / H2S |
| **330×320 mm** | H2C / A2L |
| **256×256 mm** | X2D / P2S / P1 系列 / X1 系列 / A1 |
| **180×180 mm** | A1 mini |

- **打印板类型**：拓竹提供多种类型的打印板，它们在制作工艺和性能上各有不同，可满足多样化的打印需求。此外，不同打印板适配及推荐的耗材类型也有所差异。目前，拓竹打印板主要包括以下几种类型：

  - 纹理 PEI 打印板
  - 光面 PEI 打印板
  - 纹理 + 光面 PEI 打印板
  - 工程材料打印板
  - 增稳低温打印板
- **打印板清洁**：在使用过程中，**打印板需要定期清洁**，以保持最佳的附着力。详细的清洁方法请参阅：[纹理 PEI 板清理指南](pei-plate-clean-guide.md)。

> **⚠️ 重要提醒：**
>
> 1. **256×256 mm 的纹理 PEI 打印板、光面 PEI 打印板、增稳低温打印板** 分为一代与二代，其中一代适配 A1 和 X1/P1 系列打印机，二代适配 P2S/X2D 打印机。两者主要区别在于二维码标识更新，**一代打印板不支持第二代机型（P2S 及后续机型）的打印板识别功能**。
> 2. **P2S/X2D** 打印机可正常使用一代打印板，但无法识别其类型。如设备提示无法识别打印板类型，可在屏幕手动选择"已解决"或关闭打印板检测功能。
> 3. **X1** 系列打印机可正常使用二代打印板，但无法识别其类型。如设备提示无法识别打印板类型，可在屏幕手动选择"已解决"或关闭打印板检测功能。
> 4. **A1 和 P1** 系列打印机可正常使用二代打印板。
