## 取下模型

> **⚠️ 注意：** 打印结束后，**请等待热床和模型完全冷却到室温**，再将模型从打印板上轻轻取下，以免手部烫伤或造成模型变形、损伤或打印板损伤。

|  |  |
| --- | --- |
|  |  |

对于底面较大的模型，可能会与打印板粘结过牢，可尝试以下方法来移除：

- 从**多个角度弯折打印板**，使模型与之分离。
- 借助**铲刀**等工具，将模型底面各边角轻轻铲开，直到模型能取下。
- 用**清水浸泡**模型与打印板的粘结面，待胶溶解后再轻轻拆下。
- 参考下方移除 TPU 模型的方法。

 TPU 耗材模型移除方法 
一般而言，TPU 对打印板的粘结力较强，部分底面较大的模型较难拆下。这时，请勿使用蛮力，以免损伤模型或打印板，而是应该将模型的一个边角拉起一道缝隙后，往其中喷洒酒精，然后便可逐渐用力把模型和打印板分离。

如果打印前在打印板上涂了液体胶或固体胶，模型底部通常会**残留胶膜**。建议取下模型后用**清水冲洗**底部并擦干，以免胶膜粘到手上。

## 清洁打印板

使用过的打印板通常残留有打印材料、胶膜、手部油脂等，长时间放置还会覆盖灰尘。**定期清洁打印板**，可保证下次使用时调平正常、模型底部粘结牢固，从而降低打印失败的风险。**清洁步骤**如下：

1. 用**铲刀**等工具去除打印板表面的固体残留物。
2. 用**清水**加**洗涤剂**清除表面的胶膜、油脂、灰尘等。
3. 用**洁净的纸巾**或抹布擦干水分。
4. 将打印板**晾干**，或放到热床上烘干。
5. 清洁完毕后，**避免**用手指接触打印板表面，建议从侧面手持打印板。

另外，对于部分特殊的打印板，更推荐用酒精和洁净的纸巾或抹布来清洁。

## 给模型进行外观处理

### 1. 拆除支撑

打印带有支撑结构的模型时，应在打印结束后**尽早拆除支撑**，以免其受潮变软后变得难以拆除。

- 建议在打印结束 **2 小时**内拆除支撑，尤其是对于易吸水的 PA-CF、PAHT-CF、PA6-CF 等 PA 类耗材而言。
- 若支撑结构确实已因放置太久而变得难拆，请把整个模型烘干、放置冷却后再及时拆除。

不同支撑类型的拆除方式略有不同：

- **专用支撑耗材**：正确使用时，支撑结构更易拆下，且模型被支撑处的表面外观更好。
- **水溶性支撑**：若不便用钳子、镊子等工具拆除，可先用水将支撑泡至变软或溶解，再冲走或拆除。注意：大部分模型内部有很多孔洞，长时间泡水时内部可能会进水。

### 2. 去除拉丝

对于绝大部分耗材，如果打印前将其**正确烘干**，且打印全程使用**干燥剂、密封盒**保护，以防止其在打印过程中再次受潮，即可避免或减轻拉丝问题。（对于 TPU 耗材，拉丝不能完全避免，尤其是在打印跳跃较多的模型时）。

去除模型上的拉丝，可采用以下方法：

- 用热风枪或电吹风机的热风吹拂模型。
- 用打火机的火焰对准拉丝部位迅速烫烧。

⚠️ **注意**： 上述方法均需**小心操作，注意安全**，同时避免模型损伤。

### 3. 修补、打磨、抛光

针对不同的表面瑕疵，可采用相应的处理方式：

- **缺料、孔洞等缺陷**：取适量对应耗材放入容器，用加热器熔化后，用工具蘸取并粘到缺陷区，最后抹平、打磨。
- **悬垂区域、支撑面不平整等瑕疵**：使用砂纸、打磨机等打磨、修复。
- **表面粗糙、光泽度低、层纹明显等问题**：可以先打磨模型，再用适当的溶剂抛光；或选用合适的清漆、光油为表面附上一层涂层。

> **⚠️ 注意：** 本行业常用的溶剂有丙酮、二氯甲烷、甲苯等，它们均有一定毒性且易燃，使用前请务必查阅使用说明，并注意操作安全。

## 给模型退火

一般而言，退火可消除部分热应力、提高结晶材料的结晶度、改善结晶形态，从而提升部分模型的强度、耐热性、耐水性等性能。

需要注意的是，退火效果受多种因素影响：

- 取决于材料种类（不同品牌的同种材料也可能存在差异）。
- 与退火温度、时长有关。
- 与模型本身的尺寸、结构、填充密度、填充走线方式、角度等参数有关。
- 部分模型在退火后可能发生变形、翘曲。

为减轻变形、翘曲并保证较好的退火效果，**建议采用阶梯式升温退火**：先在相对低温下退火一段时间，再在中间温度下退火一段时间，最后在相对高温下退火。

> **⚠️ 注意：** 退火与耗材干燥都需使用温度均匀、容积较大的烤箱（如鼓风型烤箱），且模型不能过于靠近发热区。请勿使用微波炉或厨房烤箱，以免损坏耗材、料盘或模型。

## 粘结模型

有些打印件需要将多个零件粘成一个整体。请根据耗材类型和强度要求选择合适的粘结方式。

- **常规耗材（如 PLA、PETG），若对粘结点强度要求不高**：可使用常见的“502”胶水。但该胶水耐寒性、耐久性较差，在寒冷环境或长期使用后会产生裂纹、失去粘结强度。也可选用对应耗材的专用胶水，如 PLA 专用胶水、PC 专用胶水等。
- **若对粘结点强度要求较高**：对于大多数耗材，可尝试 AB 胶、TPU 型补鞋胶等。但它们的适用材料和环境有限，使用前需查阅说明书。
- **表面粗糙、不适配常规胶水的耗材（如 PAHT-CF、PET-CF、PA6-CF）**：可使用热熔枪和热熔胶粘结，以获得很高的粘结强度。市面常见的热熔胶材质为 EVA，具有粘结强度高、耐寒、耐振动、耐撞击等优点。

 热熔胶的粘结方法
1. 在一个待粘结面上涂满热熔胶。  
2. 用火焰或加热器加热该面上的胶，使其充分熔化（⚠️ **请注意操作安全，防止烫伤或打印件变形**）。  
3. 贴上另一个待粘结面，按紧并保持，直到热熔胶冷却，两个零件即牢固粘在一起。
