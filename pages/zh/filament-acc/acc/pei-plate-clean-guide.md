## 清洗原因

打印板在使用过程中，其表面可能会积累空气中的灰尘，或因取模操作而沾上手指的汗渍、油脂。这些不易察觉的附着物均可能降低打印板粘结性能，进而影响打印质量。及时清洗打印板即可使其恢复正常状态。

本指南以金色PEI纹理板为例进行说明，其他类型的面板也同样需要定期清洗维护。

## 清洁建议

> **重要提醒！**
>
> - **请勿使用酮类（如丙酮）有机溶剂进行清洗**，以免损坏打印板涂层。
> - 请确保**所用洗涤剂不含油类或保湿剂**，这些成分可能会残留在打印板上，影响附着力。
> - **建议使用洗洁精来清洁打印板**

- 由于打印板表面具有纹理，使用酒精可能只会将油分散在表面而无法完全去除。因此，**建议使用洗洁精来清洁纹理板**。洗洁精作为脱脂剂，使用海绵或刷子清洗板可以确保洗洁精深入纹理表面，从而有效清洁并提高附着力。

## 所需工具和材料

- 洗洁精
- 海绵
- 纸巾

## 清洁步骤

### 1. 用温水润湿纹理 PEI 板

![](https://wiki.bambulab.com/filament-acc/pei-plate-clean-guide/01-%E6%B0%B4%E6%B6%A6%E6%B9%BFpei%E6%9D%BF.png)

### 2. 将洗洁精均匀涂抹在纹理板上，并用海绵擦洗纹理板

用普通海绵擦洗纹理板，使洗洁精产生泡沫，能有效去除纹理 PEI 板上的任何残留模型和油脂。

![](https://wiki.bambulab.com/filament-acc/pei-plate-clean-guide/02-%E6%B8%85%E6%B4%81%E5%89%82%E6%B8%85%E6%B4%81pei%E6%9D%BF.png)

建议您使用百洁布或者塑料刷，它可以更好地进入纹理的凹槽并清除所有杂质。

|  |  |
| --- | --- |
|  |  |

### 3. 用清水冲洗掉洗洁精，并用纸巾擦干纹理板

![](https://wiki.bambulab.com/filament-acc/pei-plate-clean-guide/03-%E6%93%A6%E5%B9%B2pei%E6%9D%BF.png)

> **注意**：
>
> - 将洗洁精涂抹在纹理 PEI 板上后，**务必使用海绵或刷子进行擦洗**，以彻底清除任何残留的模型和油脂。
> - **避免用手指接触打印板表面，建议从侧面手持打印板**。
> - 使用细砂纸或钢丝绒打磨打印板表面可使其焕然一新，并增强附着力。请确保在打磨后彻底清洁表面，以去除任何磨屑。

## 判断依据

通过打印板上水流的状态，我们可以判断打印板的干净程度。

- 清洁前，打印板上的水流成股流下，无法形成水膜，此时打印板粘附性较差。  
  ![](https://wiki.bambulab.com/filament-acc/pei-plate-clean-guide/纹理_pei_打印板清洁前.gif)
- 清洁后，打印板上的水流形成薄薄的水膜，此时打印板粘附性良好。  
  ![](https://wiki.bambulab.com/filament-acc/pei-plate-clean-guide/纹理_pei_打印板清洁后.gif)

## 清洗板后解决粘附问题的其他解决方案

### 稍微提高热床温度

耗材和打印板之间的粘附性受热床温度的显著影响；热床温度越高，粘合力越强。如果粘附性不够，可稍微提高热床温度来增强粘合力。

> **注意**：对于 PLA 和 PETG 耗材，过高的温度可能会导致堵塞和[象脚](../../software/bambu-studio/parameter/elephant-foot.md)问题。

### 添加 brim 和支撑结构

打印件与打印板之间的附着力大致与它们的接触面积成正比。在打印小物体时，添加 brim 可以增强打印件与打印板之间的压力，防止翘曲或脱落。对于细长物品，在高速打印时更容易出现喷嘴刮擦现象。因此，建议在打印此类物品时添加适当的支撑，以优化力的分布，并最大限度地降低翘曲或脱落的风险。

### 检查热床温度和使用的耗材

大多数耗材类型在 Bambu Studio 中都带有默认预设。如果自定义配置文件，建议仔细检查热床的温度设置，有时可能需要根据使用的耗材类型及其属性调整热床温度。

### 调整 Bambu Studio 中的首层设置

可通过调整首层切片设置来增强粘合力。Bambu Studio 中的切片配置已预先设置了测试中表现最佳的参数。不过，如果出现问题，我们建议您可以尝试用 0.5 毫米的线宽和 0.25 毫米的层高开始打印，以获得更好的效果。
