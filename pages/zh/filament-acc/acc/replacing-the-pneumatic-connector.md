## 何时需要更换？

当您遇到以下的情况时候，可以通过更换气动接头来解决问题：

- PTFE 管无法被固定，比如 PTFE 管无法被固定在挤出机上；
- 耗材无法通过气动接头，比如耗材无法通过缓冲器（如下图所示的位置，一般可能是由于气动接头内部损坏所导致）；

![](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/00-%E6%96%99%E7%BA%BF%E5%8D%A1%E5%9C%A8%E7%BC%93%E5%86%B2%E5%99%A8%E7%9A%84%E7%A4%BA%E6%84%8F.png)

- 气动接头损坏

> **在打印机和 AMS 上所有的气动接头都是相同规格**。

## 更换 AMS 集线器的气动接头

### 1. 从打印机上拆下 AMS 集线器

参照下方的视频，从打印机上拆下 AMS 集线器，断开它与各 AMS 的连接线和料管。

### 2. 拆解 AMS 集线器

用 H1.5内六角扳手拧下3颗螺丝，然后取出选通板组件。

|  |  |
| --- | --- |
|  |  |

取下右侧处的料管接头，移除4颗螺丝，然后打开盖子，根据损坏情况，进行配件的更换。

|  |  |
| --- | --- |
|  |  |

（非必须步骤）若上图右侧处的料管接头处的气动接头损坏，请继续移除4颗螺丝，并更换气动接头。

|  |  |
| --- | --- |
|  |  |

注意：若集线器的磁铁在拆装过程中掉落，您可以借助内六角扳手并参考下面的图片进行安装。

![](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/ams_hub_%E7%A3%81%E9%93%81.jpg)

### 3. 组装 AMS 集线器

（非必须步骤）把新的气动接头放入料管接头组件，然后合上两个组件，并锁紧4颗螺丝。

|  |  |
| --- | --- |
|  |  |

集线器中的气动接头安装完成后，重新装上料管接头，合上盖子，锁好4颗螺丝，在右侧装上料管理接头组件。

|  |  |
| --- | --- |
|  |  |

将选通器板组件装入外壳中，确认弹簧有安装到位，再接入右侧料管。

|  |  |
| --- | --- |
|  |  |

### 4. 把 AMS 集线器安装到打印机上

参照上方步骤1.中的视频后半部分，把 AMS 集线器安装到打印机上，并连接它与各 AMS 的连接线和料管。

更多安装注意事项请参考下面的Wiki：[连接 AMS Hub 和多台 AMS](../../x1/manual/Connect-AMS-Hub-and-multi-AMS.md)

## 更换 AMS 五通的气动接头

在五通中一共有五个气动接头，其中四个分别连接四个上下料器，另外一个气动接头通过 PTFE 管连接缓冲器。

![](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/20-%E4%BA%94%E9%80%9A%E6%B0%94%E5%8A%A8%E6%8E%A5%E5%A4%B4%E7%A4%BA%E6%84%8F.png)

如果遇到其中的某一个气动接头损坏，无法固定 PTFE 管，可以参考以下方法将五通拆开，来更换新的气动接头。

### 1. 拆下五通组件

请参考 [更换AMS五通组件](../../x1/maintenance/replace-filament-hub.md) 将五通组件从 AMS 上拆下和分离电机。

### 2. 移除五通按键

解锁五通组件的4个扣爪，移除五通按键。

|  |  |
| --- | --- |
|  |  |

### 3. 移除五通主动轮

用 H1.5内六角扳手移除4颗螺丝，取下保护盖和主动轮。

|  |  |
| --- | --- |
|  |  |

### 4. 分离五通上下壳

用 H1.5内六角扳手移除6颗螺丝，将五通上下壳分离。（**注：拆开时请小心，防止气动接头松出**。）

|  |  |
| --- | --- |
|  |  |

### 5. 更换对应的气动接头

如果下图所示的某个气动接头损坏，则将对应的气动接头取下，然后更换新的气动接头。

![](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/24-%E6%9B%B4%E6%8D%A2%E6%B0%94%E5%8A%A8%E6%8E%A5%E5%A4%B4.png)

### 6. 组合五通上下壳

五通上下壳可以通过6个扣爪完成初步固定，然后锁入6颗螺丝进行固定。

|  |  |
| --- | --- |
|  |  |

### 7. 安装五通主动轮

安装五通主动轮和保护盖，锁入4颗螺丝进行固定。

|  |  |
| --- | --- |
|  |  |

### 8. 安装五通按键

将五通按键扣装到单气动接着的位置，按压按键，确认动作顺畅。

|  |  |
| --- | --- |
|  |  |

### 9. 安装五通组件

请参考 [更换 AMS 五通组件](../../x1/maintenance/replace-filament-hub.md) 将电机安装到五通组件上，然后将 AMS 组装好。

### 2. 取出 AMS HT 中框

首先需要拆下料槽的**从动支撑轴**和**主动支撑轴**，取出轴承套时，小心两端的轴承，避免丢失。

|  |  |
| --- | --- |
|  |  |

移除底部两颗螺丝（BT3\*8）。

![3.底壳螺丝.jpg =800x](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/3.%E5%BA%95%E5%A3%B3%E8%9E%BA%E4%B8%9D.jpg)

移除螺丝后缓慢向上拉动中框组件。

|  |  |
| --- | --- |
|  |  |

打开缝隙后向上提起中框组件，**注意有电缆连接，请勿暴力操作**。

|  |  |
| --- | --- |
|  |  |

### 3. 取下上下料组件

按压气动接头黑色垫圈，同时拔出料管。

![disconnect_ht_ptfe_tube.jpg](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/disconnect_ht_ptfe_tube.jpg)

按压底座解锁，拔出上下料组件线缆与上下料电机线缆。

![feeder_and_motor_cables.png](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/feeder_and_motor_cables.png)

移除上下料器 4 颗固定螺丝（黑色）。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/42%E4%B8%8A%E4%B8%8B%E6%96%99%E7%BB%84%E4%BB%B64%E9%A2%97%E8%9E%BA%E4%B8%9D.jpg)

按住耗材释放按钮即可将上下料组件推出。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/3.%E6%8E%A8%E5%87%BA%E7%94%B5%E6%9C%BA.jpg)

### 4. 更换气动接头

首先，移除下图标记的一颗螺丝，然后将这块小电路板移开。

![feeder_silver_screws_i.jpg](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/feeder_silver_screws_i.jpg)

> 💡 电路板下方有磁铁和弹簧，操作时请注意不要遗失。  
> ![note_magnet_and_spring.jpg](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/note_magnet_and_spring.jpg)

移除下图标记的6颗螺丝。

![feeder_silver_screws_i.jpg](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/feeder_silver_screws_ii.jpg)

小心分离上下料组件的上下壳。

![feeder_upper_and_lower_shells.webp](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/feeder_upper_and_lower_shells.webp)

取出气动接头，并放入新的气动接头，再装回上下料组件的上下壳。

![ams_ht_feeder_pneumatic_connector_green.jpg](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/ams_ht_feeder_pneumatic_connector_green.jpg)

拧入下图标记的6颗螺丝。

![feeder_silver_screws_i.jpg](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/feeder_silver_screws_ii.jpg)

放回小电路板，拧入下图标记的一颗螺丝。

![feeder_silver_screws_i.jpg](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/feeder_silver_screws_i.jpg)

### 5. 安装上下料组件

将上下料组件装回中框组件，并拧入4颗黑色固定螺丝。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/42%E4%B8%8A%E4%B8%8B%E6%96%99%E7%BB%84%E4%BB%B64%E9%A2%97%E8%9E%BA%E4%B8%9D.jpg)

将料管插入气动接头。

![insert_ptfe_tube.jpg](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/insert_ptfe_tube.jpg)

插入上下料组件线缆与上下料电机线缆。

![feeder_and_motor_cables.png](https://wiki.bambulab.com/filament-acc/acc/replacing-the-pneumatic-connector/feeder_and_motor_cables.png)

### 6. 安装中框组件

用手指勾住凸出的线缆，将中框组件安装至下盖组件内。

|  |  |
| --- | --- |
|  |  |

需要确保中框组件完全压入下壳组件且前后没有翘起的情况，安装底部两颗固定螺丝（BT3\*8）。

|  |  |
| --- | --- |
|  |  |

### 7. 安装主动支撑轴和从动支撑轴

主动支撑轴压入 AMS HT 前端槽内，直到听到“咔嗒”声，注意主动支撑轴黑色齿轮一端需要和中框组件内的黄色齿轮一端对齐。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/2%E5%AE%89%E8%A3%85%E4%B8%BB%E5%8A%A8%E8%BD%B4.jpg)

将从动支撑轴压入中框组件内，直到听到“咔嗒”声。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/%E4%BB%8E%E5%8A%A8%E8%BD%B4%E3%80%81.jpg)

> 注意：安装完成后可以手动转动**主动支撑轴和从动支撑轴**，需要确保旋转顺滑。
