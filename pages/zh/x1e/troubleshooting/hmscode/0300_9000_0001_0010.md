## 故障描述

腔温加热控制板与 MC 之间通信存在异常时，将出现该报错信息。

### 可能的原因

- 线缆脱落或损坏
- 加热控制板故障

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 故障排查

### 检查连接线

#### 加热模块控制板和 AMS 接口板连接线

参考[X1E 加热模块拆装指引](../../../x1/maintenance/x1e-heater-unit.md)拆卸背板以及风道。

|  |  |
| --- | --- |
|  |  |

检查加热模块控制板的 3 号插头是否脱落或受损，若外观正常则重新安装一次。

![](https://wiki.bambulab.com/x1e/printer-cables/%E5%8A%A0%E7%83%AD%E6%A8%A1%E5%9D%97%E6%8E%A5%E5%A4%B4%E5%AE%9A%E4%B9%89.jpg)

检查 AMS 接口板上 1 号插头是否脱落或受损，若外观正常则重新安装一次。

![pixpin_2026-07-02_14-55-55.jpg](https://wiki.bambulab.com/x1e/hmscode/0300_9000_0001_0010/pixpin_2026-07-02_14-55-55.jpg)

再从走线孔中检查该线缆是否被压破或压断。

![](https://wiki.bambulab.com/x1e/printer-cables/%E7%90%86%E7%BA%BF%E6%A7%BD.jpg)

完成后可开机检查报错是否消失，若报错依旧则进行下一步。

#### AMS 接口板和 MC 板连接线

检查 AMS 接口板上 2 号插头是否脱落或受损，若外观正常则重新安装一次。

![pixpin_2026-07-02_14-55-55.jpg](https://wiki.bambulab.com/x1e/hmscode/0300_9000_0001_0010/pixpin_2026-07-02_14-55-55.jpg)

检查 MC 板上该插头是否脱落或受损，若外观正常则重新安装一次。

![](https://wiki.bambulab.com/x1e/printer-cables/amscom.jpg)

完成后再次开机检查报错是否消失，若报错依旧，可更换线材包、腔温加热模块控制板、 MC 板。（按故障可能性排序）
