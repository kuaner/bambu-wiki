## 打印错层

打印错层是指在 3D 打印过程中，打印机在某一层或多层的打印时发生了位置偏差或高度错误，导致打印的模型出现层与层之间错位的现象。这种问题可能导致模型的结构不完整、表面不平整或其他质量问题。

![](https://wiki.bambulab.com/knowledge-sharing/printing-issues/layer_shifts.jpg)

## 潜在原因和解决方案

### 1. 外力干涉

不同的外力干扰可能导致打印错层。例如，在换料时，打印机可能会与废料滑梯中堆积的耗材发生干涉；工具头的拖链断裂会影响运动（X1、P1、P2 和 H2 系列）；如果料管或线缆未妥善放置，可能导致工具头移动受阻（A 系列）。

- **解决方案：** 建议**检查 XY 轴前后移动时是否会受到异物的干扰**。如果条件允许，可以通过[查看录像](../x1/troubleshooting/enable-the-video-recording-function.md)的方式进行排查，以便更清楚地观察到任何可能影响运动的障碍物。这样可以帮助您及时发现并解决问题，确保打印过程顺畅。

### 2. 喷嘴与模型剐蹭

如果您使用的是黏性较高的耗材（如 PETG Basic），可能会因耗材粘嘴而导致喷嘴与模型发生碰撞。为降低因粘嘴引起的模型错层风险，建议参考 [耗材烘干操作指南](../filament-acc/filament/dry-filament.md) 干燥耗材或开启[擦拭塔](../software/bambu-studio/parameter/prime-tower.md)。

同时，**选择合适的热床温度**也很重要。如果模型在打印过程中出现翘边，喷嘴很可能会撞到翘起的部分，导致丢步或模型位置移动。通常情况下，使用 Bambu Textured PEI Plate 并根据对应耗材选择合适的温度，可以有效避免翘边。如果需要打印工程材料（如 PAHT-CF 等），建议使用 Bambu Smooth PEI Plate，并在打印板上均匀涂抹胶水，以降低翘边导致模型错层的风险。

### 3. 打印速度太快

当打印速度设置过快且碳杆阻力偏大时，模型可能出现错层。例如：在正常模式下开始打印，然后中途切换到 **狂暴模式**，由于移动速度骤增，容易引发错层。

**解决方案：** 启用 **丢步恢复** 功能

- X、H2、A 系列：可在打印机屏幕中开启。操作界面示例如下：

|  |  |  |
| --- | --- | --- |
| X1 系列： 控制 → 打印选项 → 勾选 **丢步自动恢复** | A 系列： 设置 → 打印选项 → 勾选 **丢步自动恢复** | H2 系列、P2S 及 X2D： 设置 → 打印选项 → 勾选 **丢步自动恢复** |

- P1 系列：可在 **Bambu Studio** 中开启。操作界面示例如下：

![P1 系列丢步恢复界面](https://wiki.bambulab.com/knowledge-sharing/layer-shifts/p1-丢步.png)

启用后，当电机检测到位置偏移（丢步）时，X、Y、Z 轴会自动重新定位，并从偏移前继续执行未完成的 G-code，确保打印质量。

同时，对于 X1/P1 系列打印机，可通过 [清洁碳杆](../general/carbon-rods-clearance.md) 的方式降低打印错层的风险。
