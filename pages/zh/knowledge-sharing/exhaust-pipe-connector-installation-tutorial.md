# 何时需要用到

当机器本身的过滤器不满足您的使用需求时，可以通过我们提供的排气管接口连接您自己的过滤器或者将废气排放到室外。

注：本指南以X1E为例。该排气管接口适用于X1E，X1C和P1S。

# 所需工具

1. PETG、PC等耐高温耗材
2. 2颗M3\*14\**5 半牙圆柱头螺丝*
3. *扎带或者喉箍*
4. *H2 六角扳手*

# 如何使用

## 步骤 1 下载模型

首先点击[这里下载](https://wiki.bambulab.com/knowledge-sharing/exhaust-pipe-connector-installation-tutorial/01-holder-tube.stp)或进入[X1E/ X1C/ P1S 排气管接口 来自 Bambu Lab Support - MakerWorld](https://makerworld.com.cn/zh/models/565743)打印模型。

由于X1E具备腔温加热功能，开启情况下过滤器排出气体温度约为60°C，我们推荐使用PETG、PC等耐高温材料，不推荐使用PLA等低温材料。

**注：不推荐外部抽风！**

## 步骤 2 准备半牙螺丝和扎带

要在X1E上使用此排气管接口，您需要准备2颗M3\*14\*5半牙圆柱头螺丝（Partially Treaded），一根长度合适的扎带或者喉箍。
