2. 相框内卡扣以及相框支架的连接处可能会有悬垂物，请务必剪去，以免影响后续安装。

> **注意**：请确保不要将整个卡扣剪掉，影响后续灯板安装。

## 组装相框

1. 确保螺母带凹槽一面朝上，将打印工具嵌入螺母凹槽中，按压稳固。

|  |  |
| --- | --- |
|  |  |

2. 将支撑架对准相框背部孔位插入，将打印工具和螺母从相框正面插入，并顺时针旋转，固定螺母。

|  |  |
| --- | --- |
|  |  |

3. 螺母固定后，将打印工具拔出。

![拔出.jpg](https://wiki.bambulab.com/knowledge-sharing/lithophane-led-backlight-board-kit/%E6%8B%94%E5%87%BA.jpg)

> **注意**：其余尺寸的相框组装方式同理。

## 连接 LED 灯板

将 LED 灯板翻至背面，按顺序整齐摆放，确保 PH2.0 接口处凸起的一面朝上，然后连接灯板，可参考下图。  
![连接灯板.jpg](https://wiki.bambulab.com/knowledge-sharing/lithophane-led-backlight-board-kit/3.jpg)

**注意**：

1. Make My Lithophane 支持生成三种尺寸的相框，分别由 2、3 和 4 块灯板拼接而成。每块灯板有两个并联的电源插口，可作为电流入口或出口。请确保所有灯板连接起来，并将其中一块灯板与 USB 电源线连接。请参考下图中的推荐连接方式，方框处为电源插口：

|  |  |
| --- | --- |
|  |  |
|  |  |

2. PH2.0 电源连接线两端无区别，可以任意连接至任意接口。

![连接线两端.jpg](https://wiki.bambulab.com/knowledge-sharing/lithophane-led-backlight-board-kit/%E8%BF%9E%E6%8E%A5%E7%BA%BF%E4%B8%A4%E7%AB%AF.jpg)

3. 此步骤先不要将 LED 灯板连接电源。

## 连接电源线

1. 根据打印的浮雕方向（竖向或横向），将 USB 电源线从相框后面的预留孔位穿入相框。

![插入电源线.jpg](https://wiki.bambulab.com/knowledge-sharing/lithophane-led-backlight-board-kit/%E6%8F%92%E5%85%A5%E7%94%B5%E6%BA%90%E7%BA%BF.jpg)

2. 将 USB 电源线连接至 LED 灯板。

> **注意**：相框有两个电源孔位，可根据浮雕方向选择适当孔位插入 USB 电源线。

![接入电源.jpg](https://wiki.bambulab.com/knowledge-sharing/lithophane-led-backlight-board-kit/%E6%8E%A5%E5%85%A5%E7%94%B5%E6%BA%90.jpg)

## 固定 LED 灯板

1. 调整 LED 灯板底部连接线的位置，确保平整无凸起。
2. 将 LED 灯板按照连接顺序卡入相框内部边缘的卡扣下，平铺在相框内。

![相框卡扣.png](https://wiki.bambulab.com/knowledge-sharing/lithophane-led-backlight-board-kit/%E7%9B%B8%E6%A1%86%E5%8D%A1%E6%89%A3.png)

3. 拆下打印的插销支撑，将插销插入灯板间的圆孔进行固定。

|  |  |
| --- | --- |
|  |  |

> **注意**：
>
> 1. 插销数量取决于灯板数量，四块灯板需要六个插销，打印文件中均已包含。
> 2. 如灯板无法平铺，请检查相框内的打印支撑是否清理干净，或连接线是否放置整齐。

## 安装浮雕

轻轻掰开相框的插入口，将打印的浮雕嵌入相框。

|  |  |
| --- | --- |
|  |  |

## 接通电源

连接电源，轻触开关即可点亮浮雕。长按开关可调节亮度。
