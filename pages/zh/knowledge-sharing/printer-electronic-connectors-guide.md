## 何时使用

根据使用场景、功能的不同，打印机内存在多种不同类型的电子连接器，其拆装方式也因此存在差异。在您更换备件、维护设备时，可以根据该指南了解到某一类型连接器的拆装方式。

## 注意事项：

本指南旨在帮助理解不同类型连接器的基本操作要点。由于打印机的连接器数量较多，本指南**无法覆盖所有插头的拆装方式**。实际操作时请以实物结构为准，如遇到外观不一致、结构不明或无法确认拔插方向的情况，请停止操作并联系售后支持。

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 拆卸插头时请尽可能**捏住线缆顶部的胶壳插头**，避免拉扯线缆过度，导致线缆与胶壳脱落。

## 直拔式（摩擦保持）：

这类连接器依靠连接器插壳上的锁舌，或本身摩擦力固定。您可以观察插头的外观，若形状单一，那么通常小幅左右摆动向外拉出即可。

|  |  |

**拆除方式：** 缓慢晃动拔出。  
**安装方式：** 对齐后直接插入。

## 按压卡扣式（需解锁）：

这类连接器顶部带有按压式卡扣，当插头插入母座后，卡扣会与板端座的锁止结构啮合，形成明确的“卡住”限位。这类插头从外观上能够看到明显的按压结构，拆卸时需要按压/解锁卡扣后才能拔出。

### PHD 2.0mm 带锁扣连接器

**介绍：** 主要出现在 MC 板或 AP 板上各模块与主板连接。

|  |  |
| --- | --- |
|  |  |

**拆除方式：** 按压顶部的卡扣后，**小幅左右摆动拔出** 。  
**安装方式：** 对齐后直接插入，卡扣自动扣合 。

![webp_(5).webp](https://wiki.bambulab.com/knowledge-sharing/printer-electronic-connectors-guide/webp_(5).webp)

## 特殊连接器：

为了满足特定工作需求，打印机上还有部分较为特殊的连接器，这类连接器可能存在特殊的解锁方式或不常见的拆装方式，您可以参考下面表格学习这类插头的拆装方法。

### 带自锁 插簧端子

**介绍：** 主要出现在 AC 板上。

|  |  |
| --- | --- |
|  |  |

**拆除方式：** 推开绝缘胶套后，使用螺丝刀**压住锁止铁片**后（上图标记），**小幅左右摆动拔出** 。  
**安装方式：** 对齐后直接插入，卡扣自动扣合。

![webp_(7).webp](https://wiki.bambulab.com/knowledge-sharing/printer-electronic-connectors-guide/webp_(7).webp)

### 无自锁 插簧端子

**介绍：** 主要出现在 A1 打印机的 AC 板处使用。

|  |  |
| --- | --- |
|  |  |

**拆除方式：** 推开绝缘胶套后，使用螺丝刀缓慢撬出。  
**安装方式：** 对齐后直接插入。

![acboard.webp](https://wiki.bambulab.com/knowledge-sharing/printer-electronic-connectors-guide/acboard.webp)

**拆除方式：** 翘起顶部黑色压块后，小心拉出排线。  
**安装方式：** 将排线慢慢推入插座后，合上黑色压块。
