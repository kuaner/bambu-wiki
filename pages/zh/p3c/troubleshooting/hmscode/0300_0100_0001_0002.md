## 故障描述

热床温度控制系统由加热器和温度传感器为主，若加热器故障，或温度传感器出现故障，都会导致温控系统出现异常。

## 可能的原因：

- 加热器故障
- 温度传感器故障

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手
- H2.0 六角扳手

### 排故措施

#### 步骤1. 重新加热

通过屏幕控制热床加热到 40℃。

![001.png](https://public-cdn.bblmw.com/wiki/new/p3c/troubleshooting/hmscode/0300_0100_0001_0002/zh/001.png)

用手贴合热床，感受热床温度是否上升，若热床温度正常上升，但屏幕上热床实际温度仍为室温，则说明温度传感器存在异常，请进行步骤 2。

若热床表面温度不变，则说明加热器存在异常，请进行步骤 3。

#### 步骤2. 检查温度传感器

关机状态下参考WIKI：[废料滑梯更换指南](../../maintenance/replace-purge-chute.md)，移除背板及滑梯。

![002.png](https://public-cdn.bblmw.com/wiki/new/p3c/troubleshooting/hmscode/0300_0100_0001_0002/zh/002.png)

露出 MC 板后，重新连接热床信号线连接器。

|  |  |
| --- | --- |
| 003.png | 004.png |

完成后重启设备，再次通过屏幕加热，观察热床温度示数是否上升。若故障依旧，请联系客户支持团队。

#### 步骤3. 检查加热器

关机状态下参考WIKI：[废料滑梯更换指南](../../maintenance/replace-purge-chute.md)，移除背板及滑梯。

![005.png](https://public-cdn.bblmw.com/wiki/new/p3c/troubleshooting/hmscode/0300_0100_0001_0002/zh/005.png)

将热床线缆插簧的硅胶保护套向后推出，露出插簧，使用内六角扳手轻顶插簧上的卡扣，并向外拔出。两根线缆的拆装方式相同。

|  |  |
| --- | --- |
| 006.png | 007.webp |

重新安装后装回胶套，重启设备，通过屏幕控制热床加热。若热床依然无法加热，请联系客户支持团队。
