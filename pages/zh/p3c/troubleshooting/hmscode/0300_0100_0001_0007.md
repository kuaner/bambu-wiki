## 故障描述

当 MC 板无法获取热床温度传感器数值时，热床温度会显示为 0℃，并提示该错误信息。

## 可能的原因

- 热床信号线接触不良
- 温度传感器故障

## 故障排查

### **安全提示**

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，**请关闭打印机电源并断开电源连接**，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 工具、设备及材料

- H2.0 六角扳手
- H1.5 六角扳手
- 镊子

### 排故措施

#### 步骤 1. 热床信号线接触不良

首先关机状态下参考WIKI：[背板更换指南](../../maintenance/replace-back-panel.md) ，完成 6-pin 接口板/缓冲器和背板的移除。

![001.png](https://public-cdn.bblmw.com/wiki/new/p3c/troubleshooting/hmscode/0300_0100_0001_0007/zh/001.png)

使用 H2.0 内六角扳手，移除滑梯的 1 颗螺丝，取下滑梯。

|  |  |
| --- | --- |
| 002.png | 003.png |

按压插头上的防松卡扣，取下连接器，重新连接热床信号线。

|  |  |
| --- | --- |
| 004.png | 005.png |

完成后开机观察屏幕上，热床是否显示室温。

![006.png](https://public-cdn.bblmw.com/wiki/new/p3c/troubleshooting/hmscode/0300_0100_0001_0007/zh/006.png)

若屏幕上热床温度依然显示为 0℃，则需要[更换新的热床](../../maintenance/replace-heatbed-assembly.md)。
