## 温馨提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 关机与准备

- 屏幕进入耗材页，点击②退料→③全选→④退料，退出所有耗材。

|  |  |
| --- | --- |
| 001.png | 002.png |

- 收回并取出所有耗材，并移除干燥剂。

|  |  |
| --- | --- |
| 003.png | 004.png |

- 放回热床底部的泡棉。

![005.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/005.png)

- 使用屏幕控制热床下降至底部，压紧泡棉。

| --- | --- |

![008.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/008.png)

## AMS 3P 拆卸及装箱

### 取下打印头

- 从扣手位取下 AMS 左右侧板。

|  |  |
| --- | --- |
| 011.png | 012.png |

- 轻拉取下 5 个打印头。

![013.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/013.png)

### 移除 AMS 3P

- 使用 H1.5 内六角扳手，拧下 4 颗 AMS 3P 安装螺丝。

![014.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/014.png)

- 抬起 AMS 3P 右后侧，拔出打印头控制板线缆。

![015.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/015.png)

- 将 AMS 3P 从打印机顶部取下。

![016.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/016.png)

### 装箱 AMS 3P

- 打开 AMS 上盖，装回每个槽位的泡棉后合上上盖。

![017.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/017.png)

- 用胶带固定左右框架。

|  |  |
| --- | --- |
| 018.png | 019.png |

- 装回左右侧板。

|  |  |
| --- | --- |
| 020.png | 021.png |

- 用胶带固定上盖和侧板后，表面盖回保护膜。

![022.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/022.png)

- 将 AMS 3P 向后轻轻放倒。

![023.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/023.png)

- 用贴纸固定背板内侧的线缆。

![024.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/024.png)

- 将打印头装回固定包装，回正 AMS 3P。

|  |  |
| --- | --- |
| 025.png | 026.png |

- 将 AMS 放入保护袋内，轻抬左右两侧装回底部泡棉。

|  |  |
| --- | --- |
| 027.png | 028.png |

- 调整打印头包装盒位置，卡入泡棉槽位。

![029.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/029.png)

- 提起 AMS 3P 保护袋，放回包装箱，再放入顶部泡棉。

![030.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/030.png)

- 将快速入门指南、干燥剂放回包装箱。

![031.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/031.png)

## P3C 拆卸及装箱

### 移除屏幕

- 按压屏幕转轴底部的解锁位，左推屏幕后向外轻拉。

|  |  |
| --- | --- |
| 032.png | 033.png |

- 按住排线两侧端子取下屏幕。

![034.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/034.png)

- 用胶布固定排线。

![035.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/035.png)

### 固定闪切挂架

1. 将红色固定件前半部分卡入 3、5 号槽，插入螺丝。

![036.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/036.png)

2. 将红色固定件后半部分放回，用 H2.0 扳手拧紧 2 颗螺丝。

|  |  |
| --- | --- |
| 037.png | 038.png |

### 固定热床

- 将固定件放回原位。

![039.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/039.png)

- 对齐孔位后，用 H2.0 内六角扳手拧回 6 颗螺丝。

![040.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/040.png)

### 固定工具头

- 用胶带固定空气滤芯盖和 LED 灯。

![041.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/041.png)

- 将扎带穿过后侧框架。

![042.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/042.png)

- 将泡棉放回工具头后方，拉动工具头压紧泡棉。

|  |  |
| --- | --- |
| 043.png | 044.png |

- 用扎带固定光杆及工具头。

|  |  |
| --- | --- |
| 045.png | 046.png |

- 放回拖链上的泡棉。

![047.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/047.png)

### 装箱 P3C

- 前门套上保护袋。

![048.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/048.png)

- 将工具盒及所有配件放回顶部纸卡。

![049.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/049.png)

- 将纸卡放回机顶并用胶带固定。

![050.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/050.png)

- 将防潮袋套回打印机。

![051.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/051.png)

- 抓住防潮袋顶部两角，将打印机放回包装箱。

![052.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/052.png)

- 放回顶部泡棉。

![053.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/053.png)

- 用胶带封住包装箱。

![054.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/packing-p3c-ams-combo/zh/054.png)
