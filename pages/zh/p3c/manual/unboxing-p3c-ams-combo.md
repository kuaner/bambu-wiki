> 建议保留所有包装材料和螺丝。如需运输打印机，原包装可以最大程度避免运输损坏。  
> 如果您购买了拓竹工作站，请参考[拓竹工作站安装指南](bambu-station-installation-guide.md)，组装工作站后收纳打印机。

## 推荐预留空间

打印机组装完成后的尺寸为 413 × 538 × 935 mm，使用时建议至少预留 513 × 960 × 1212 mm 的空间。请按此高度将打印机放置在便于操作的稳定平面上。

![001.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/001.png)

## 温馨提示

**1.** 挂架上的每个泊位底部安装有黑色的堵嘴硅胶，用于防止热端漏料造成打印瑕疵。打印头安装到位后，喷嘴应抵住泊位底部的堵嘴硅胶，请勿拆除堵嘴硅胶。

![002.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/002.png)

**2.** 请注意检查打印头安装状态，确保热端和泊位磁铁完全到位。

|  |  |
| --- | --- |
| 003.png | 004.webp |

**3. 开机初始化异响：**由于开箱时热床处于最底部，在开机初始化阶段，热床向下移动并触底时会产生异响。

此为正常现象，请放心使用。该初始化动作采用较小的电机电流，触底堵转属于正常运行机制，不会损伤电机或机械结构。

解决办法

推荐
**方案一：升级固件**

开箱后将固件升级至 01.01.00.00 及以上版本。新固件已优化触底声音。

**方案二：锁紧 Z 轴张紧器滑块螺丝**

升级固件后如果仍然介意此声音，可以按以下步骤处理：

1. 在屏幕上上下升降热床 3 次。
2. 从侧面轻轻放倒打印机。
3. 用工具盒中附赠的 1 颗 Z 轴张紧器滑块螺丝锁紧底部。

![005.webp](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/005.webp)

锁紧该螺丝后，Z 同步带的张力不再自动补偿。建议每 2 个月检查一次同步带张紧情况。如果打印时出现首层异常或 Z 方向纹路，请执行一次 Z 同步带张紧。详细步骤请参见 [同步带张紧](../maintenance/belt_tension.md)。

## P3C 开箱及安装

### 移除包装

- 打开包装箱，仔细阅读快速入门指南，了解详细操作步骤。

![008.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/008.png)

- 移除顶部泡棉。

![009.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/009.png)

- 抓住防潮袋顶部两角提出打印机，并将打印机放在地面或较低的平面上。

|  |  |
| --- | --- |
| 010.png | 011.png |

- 撕开并移除防潮袋。

|  |  |
| --- | --- |
| 012.png | 013.png |

- 揭下侧窗上的保护膜和胶带，取下顶部纸卡。

|  |  |
| --- | --- |
| 014.png | 015.png |

> 顶部纸卡内嵌配件，请小心拿取。

- 打开纸卡，取出内嵌的工具盒及所有配件。

|  |  |
| --- | --- |
| 016.png | 017.png |

> 如需查阅详细的包装清单，请参阅 [P3C 包装清单](acc-in-the-box.md)。

- 打开前门，移除保护袋。

![018.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/018.png)

### 解锁工具头

- 移除拖链上的泡棉。

![019.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/019.png)

- 剪断并移除光杆及工具头上的所有扎带。

![020.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/020.png)

> 注意不要剪到皮带或线缆。

- 向前门方向拉动工具头，移除其后方的泡棉，然后将工具头推回机箱后侧。

|  |  |
| --- | --- |
| 021.png | 022.png |

- 确保拖链和工具头顶部的挡块无交叉。

|  |  |
| --- | --- |
| 023.png | 024.png |

- 移除空气滤芯盖和 LED 灯上的胶带。

> 撕胶带时请用另一只手按压空气滤芯盖和 LED 灯，避免部件脱落。

|  |  |
| --- | --- |
| 025.png | 026.png |

### 解锁热床

- 使用工具盒里的 H2.0 内六角扳手拧下 6 颗红色标记的螺丝。

|  |  |
| --- | --- |
| 027.png | 028.png |

> - 完成首次校准后，才能移除热床底部泡棉。
> - 工具盒内附赠一块磁铁，请将磁铁吸附在扳手长端附近，以防止操作过程中螺丝掉落。

- 取出 2 个热床固定件。

![029.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/029.png)

### 解锁闪切挂架

- 打开玻璃前门，用 H2.0 扳手移除 2 颗螺丝，取出 2 个红色固定件。

![030.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/030.png)

- 移除螺丝时一手扶住后方，拧松螺丝后取下红色固定件的前后两部分。

|  |  |
| --- | --- |
| 031.png | 032.png |

### 安装屏幕

- 移除打印机上的排线固定胶布。

![033.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/033.png)

- 向上转动屏幕后方的转轴。

![034.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/034.png)

- 双手操作，将排线插入屏幕后方的连接口。

![035.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/035.png)

> 请勿大力拉拽排线，以免造成损坏。
>
> 请按图示双手插入排线，使其左右两侧受力均匀，也更便于插入到位。

- 先将排线收回打印机槽内，再对准孔位插入屏幕。向右推动屏幕转轴直至听到“咔哒”声。

## AMS 3P 开箱及安装

安装 AMS 3P 前，请先完成打印机开箱与安装，并准备好 P3C 包装箱内的工具盒及剩余配件。

> 安装 AMS 3P 前务必确保打印机未通电。

### 移除 AMS 3P 包装

- 打开包装箱，取出快速入门指南和配件后，移除顶部泡棉。

|  |  |
| --- | --- |
| 038.png | 039.png |

> 部分 AMS 包装内不含 AMS 3P 安装螺丝，请从 P3C 包装内的工具盒中取用。

​

- 取出 AMS 3P ，移除保护袋。

![040.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/040.png)

- 轻抬两侧，移除底部泡棉。

![041.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/041.png)

- 将 AMS 轻轻向后放倒。

![042.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/042.png)

> 请暂时不要移除 AMS 上盖处的固定胶带，以免上盖意外掉落导致损坏。

- 移除固定打印头的包装。

- 将 AMS 3P 回正，移除顶部和左右两侧的保护膜。

| --- | --- |

### 固定 AMS 3P

- 选择以下任意方式将 AMS 上的线缆插入打印机顶部。

| 方法一 | 方法二 |
| --- | --- |
| - 将 AMS 3P 轻放在打印机顶部，确保 AMS 背板略微超出打印机背板 20 mm，为后续安装步骤留出操作空间。 Image - 手伸入 AMS 右框架，将打印头控制板线缆插入接口。 Image - 略微抬起 AMS 3P 前移，插入打印机顶部对应孔位。 Image | - 对准 AMS 3P 底部定位柱和打印机顶部孔位，将 AMS 3P 轻放在打印机顶部。 Image - 抬起 AMS 右后侧，将打印头控制板线缆插入接口。 Image - 放下 AMS 右后侧。 Image |
| 注意检查线缆位置，避免挤压损坏。 |  |

- 将磁铁吸附于 H1.5 内六角扳手长端附近，固定 4 颗 AMS 3P 安装螺丝。

### 安装打印头

- 找到打印头上的橙色定位框和泊位磁铁。

![068.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/068.png)

- 略微倾斜打印头，将定位框对准闪切挂架上的橙色泊位挂钩后吸附安装。

> 打印头安装到位后，喷嘴应抵住泊位底部的堵嘴硅胶，请勿拉拽堵嘴硅胶。

![069.webp](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/069.webp)

- 依次安装 5 个打印头，确保打印头安装牢固无偏斜，且各料管间无交叉缠绕。

![070.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/070.png)

> 开机后，打印机将自动检测打印头安装状态。如收到安装错误提示，请根据屏幕指引将打印头调整到正确泊位。

> 如需移动或更换打印头，请参考[打印头组件更换指南](../../h3c/maintenance/replace-printtool.md)。

- 将 AMS 左右侧板底部卡入框架，再利用磁吸固定。

|  |  |
| --- | --- |
| 071.png | 072.png |

### 放置干燥剂

- 打开 AMS 上盖后放手，左右撑杆会自动撑住上盖。

![073.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/073.png)

- 移除干燥剂外包装后放至左右撑杆旁的槽位。

|  |  |
| --- | --- |
| 074.png | 075.png |

- 再次将上盖完全打开，然后轻轻合上上盖。

![076.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/076.png)

> 请小心操作，以免夹伤。

### 连接 AMS 3P 与 P3C

从 P3C 包装内取出 6-pin 连接线，将其插入 AMS 背部和打印机背板上的任一 6-pin 接口。

## 开机与校准

- 确保电源插座旁标签所示的电压与当地电压标准一致。

![079.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/079.png)

- 插入打印机电源线并开机。

![080.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/080.png)

- 根据屏幕指引进行首次校准。

![081.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/081.png)

- 完成校准后，取出热床底部的泡棉。

![083.png](https://public-cdn.bblmw.com/wiki/new/p3c/manual/unboxing-p3c-ams-combo/zh/083.png)

一切准备就绪，现在即可开启您的创作之旅。请参见 [P3C 首次打印](first-print.md)，完成您的首次打印。
