## 01.01.00.00（20261124）

### 新功能

1. 新增支持选配烘干模块。
2. 新增支持 1 号打印头外接最多 4 台 AMS、AMS 2 Pro 或 AMS HT 自动供料系统。用户可连接上述设备进行打印，并执行进料、退料和烘干等操作。
3. 新增自动续料组的手动编辑与维护功能，支持同一耗材大类（如 PLA）下不同颜色、不同子类的耗材之间的自动续料（如 PLA Basic 续接 PLA Matte）。

4. 屏幕 UI 状态栏新增时间显示功能。
5. 新增支持拓竹空气净化器 E1 。
6. 新增耗材进退料指引。

|  |  |
| --- | --- |
| 003.png | 004.png |

7. 新增空打检测开关。
8. 新增热床保温开关。
9. 新增画笔类型识别和笔盖在位检测功能。
10. 新增对冷烫金和压痕工艺的支持。
11. 针对部分常见异常，新增屏幕端故障排查引导页面 MiniWiki，帮助用户快速排除故障。

|  |  |
| --- | --- |

12. 新增对高流量碳化钨喷嘴的支持。

### 功能优化

1. 优化手动进料体验。
2. 全面升级 UI 设计。

|  |  |
| --- | --- |
| 007.png | 008.png |

3. 提升普通拍照模式下刀切和画笔的加工位置精度。
4. 将 AMS 的最长烘干时长从 24 小时延长至 72 小时。
5. 优化录像开关逻辑，使其不再受 U 盘识别状态影响。
6. 优化冷拔流程体验。
7. 优化休眠模式体验。
8. 优化断料续打体验，支持从 Bambu Handy 选择其他槽位兼容的同类型耗材进行续打。

![009.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/manual/firmware-release-history/zh/009.jpg)

9. 优化开门检测的默认行为：检测到舱门开启时自动暂停打印，以确保打印安全。如需更改，可前往“设置 > 打印选项”进行调整。
10. 优化部分耗材打印前的风险提示信息。

### 问题修复

1. 修复打印过程中拔出 U 盘时，模型表面质量偶尔变差的问题。
2. 修复部分场景下打印头使用后未放回闪切挂架的问题。
3. 修复部分场景下画笔回中时可能撞飞笔盖的问题。
4. 修复 TPU 75A 耗材余量检测误差。

### 已知问题

1. 使用出厂版本完成某个或多个热端的退料流程，或者手动使用切刀切料拉出耗材退料后，直接升级至当前版本并使用该热端进料，会误报“耗材挤出失败”，根据弹窗提示点击重试并手动持续向前轻推耗材，完成进料后，此问题不会再出现。
