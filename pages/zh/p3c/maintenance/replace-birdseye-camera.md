## 俯视摄像头

拓竹P3C 用户可选配 800 万像素高清俯视摄像头。支持两种模式：3D 打印监控模式下分辨率为 1632 × 1224（30fps），确保画面流畅；2D 俯拍创作模式下分辨率可达 3264 × 2448（10fps），满足高精度拍摄需求。

![001.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-birdseye-camera/zh/001.jpg)

## 何时更换

1. 俯视摄像头画面异常；
2. 俯视摄像头通信故障。

## 所需工具和材料

- H2.0 内六角扳手
- 俯视摄像头

## 安全提示

> 安全提示
>
> - 在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> ![002.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-birdseye-camera/zh/002.png)
>
> - 拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次损伤。
> - 拆除部件前，请妥善保管拆除的固定螺丝，以免丢失。
> - 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 加装俯视摄像头

### 步骤 1. 移除 AMS 3P 舱体

> 注意：在移除或安装 AMS 舱体前，请先执行退料操作，并取出舱内的所有料盘。若未退料，残留的耗材可能在
>
> 安装时被夹断或卡住，导致后续进退料困难；同时，料盘的自重也会增加操作难度。
>
> |  |  |
> | --- | --- |
> | 003.png | 004.png |

请参考 [AMS 3P 舱体拆除与安装指南](../../ams3p/maintenance/replace-chamber.md)，对AMS 舱体进行移除。

### 步骤 2. 移除 AMS 左侧板与维修盖板

用手抓住左/右侧板扣手位，向外侧用力使其与 AMS 分离，取下左侧板；

|  |  |
| --- | --- |
| 005.jpg | 006.png |

使用 H2.0 内六角扳手移除图示 4 颗螺丝。用手轻轻向外提拉维修盖板通风孔边缘，翘起维修盖板一端，随后缓慢将整块维修盖板取下；

|  |  |
| --- | --- |
| 007.png | 008.png |

### 步骤 3. 连接线缆

使用内六角扳手或尖嘴钳将图示中的上盖泡棉移除。

|  |  |
| --- | --- |
| 009.jpg | 010.jpg |

使用 H2.0 内六角扳手移除 AP 板 USB-C 接头压块螺丝移除压块，按压线缆接头解锁卡扣后移除 AP 板图示左下方的两处线缆接头；

|  |  |
| --- | --- |
| 011.jpg | 012.jpg |

将打印机左侧顶部的遮盖撬起，取下遮盖露出穿线孔；

|  |  |
| --- | --- |
| 013.jpg | 014.jpg |

将线缆 “L型” 一端连接到摄像头，注意线缆与摄像头卡扣位于同一方向；

|  |  |
| --- | --- |
| 015.jpg | 016.png |

从左料管支架旁图示位置将相机和线缆放入到 AMS 内，使线缆另一端穿过穿线孔到达 AP 板一侧；

|  |  |
| --- | --- |
| 017.jpg | 018.jpg |

将 USB-C 线缆接头连接到 AP 板，随后往 AMS 内回收线缆长度余量并将线缆固定到左侧上盖组件的理线扣中。

|  |  |
| --- | --- |
| 019.jpg | 020.jpg |

将左下方 2 处线缆接头连接到 AP 板对应接口，随后从包装内取出泡棉撕下背胶贴纸；用手轻轻向外侧扩张线扣，然后将泡棉塞入到上盖组件线扣中；

|  |  |
| --- | --- |
| 021.jpg | 022.jpg |

### 步骤 4. 安装俯视摄像头

将摄像头线缆埋入主料管支架左侧的限位结构中，随后将相机的卡抓对准卡扣装入;

|  |  |
| --- | --- |
| 023.jpg | 024.jpg |

按图示操作将相机向后推，直到听见卡扣发出咔哒声表示安装到位；

|  |  |
| --- | --- |
| 025.webp | 026.png |

### 步骤 5. 整理线缆

从包装内取出线扣，撕下背胶贴纸，将线扣张贴到主料管支架左侧后方；

|  |  |
| --- | --- |
| 027.jpg | 028.jpg |

用手按压住带背胶的线扣（避免塞入线缆时线扣脱落），随后将线缆依次埋入图示 3 处线扣中；

|  |  |
| --- | --- |
| 029.jpg | 030.jpg |

最后整理余量线缆，放置在 AMS 后方靠近背板一侧。

![031.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-birdseye-camera/zh/031.jpg)

### 步骤 6. 安装维修盖板与左侧板

将维修盖板装回原位，使用 H2.0 内六角扳手锁入 4 颗螺丝固定；随后再将 AMS 左侧板装回。

|  |  |
| --- | --- |
| 032.png | 033.jpg |

### 步骤 7. 安装 AMS 3P 舱体

请参考 [AMS 3P 舱体拆除与安装指南](../../ams3p/maintenance/replace-chamber.md)，对AMS 舱体进行移除。

## 移除俯视摄像头

> **拆装提示：**
>
> 移除步骤中，需对 AMS 3P 舱体、左侧板与维修盖板进行拆装，拆装步骤与上述加装内容中的步骤相同；下文不再赘述。

### 步骤 1. 断开线缆

使用 H2.0 内六角扳手移除 USB-C 线缆压块固定螺丝，移除压块后先断开 AP 板左下方线缆接头，再断开俯视摄像头USB-C 线缆，随后从穿线孔中将摄像头线缆抽出到 AMS 侧。

|  |  |
| --- | --- |
| 034.jpg | 035.jpg |

### 步骤 2. 移除俯视摄像头

将摄像头向前推解锁卡扣，随后将摄像头线缆从线扣中松出，移除俯视摄像头。

|  |  |
| --- | --- |
| 036.jpg | 037.jpg |

### 步骤 3. 重新安装 AP 板线缆

将线缆重新连接到 AP 板，然后装回 USB 线缆压线块，并使用 H2.0 内六角扳手锁入 1 颗螺丝固定。

![038.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-birdseye-camera/zh/038.jpg)

## 功能验证

接通电源并用 Bambu Studio 绑定打印机，在设备状态页点击圆圈处切换至俯视视角；若画面正常显示，即代表安装成功。

![039.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-birdseye-camera/zh/039.png)
