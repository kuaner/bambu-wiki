## 喷嘴偏移校准传感器

简述：喷嘴偏移校准传感器安装在热床的后方，可以对不同打印头的位置进行校准，保证良好的打印质量。

![001.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-nozzle-offset-calibration-sensor/zh/001.png)

## 何时更换

- 喷嘴的定位出现偏移，导致打印时模型出现错位、层移，并且通过喷嘴偏移校准也无法恢复。
- 结构件损坏，导致校准失败；
- 经 Bambu Lab 官方技术支持确认需更换喷嘴偏移校准传感器。

## 所需工具和材料

- H2.0 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除喷嘴偏移校准传感器

### 步骤 1. 移除螺丝

使用 H2.0 内六角扳手，移除喷嘴偏移校准传感器 2 颗螺丝。

![002.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-nozzle-offset-calibration-sensor/zh/002.png)

### 步骤 2. 移除喷嘴偏移校准传感器

小幅度提起喷嘴偏移校准传感器，露出连接器位置；按压接线端子断开线缆，移除喷嘴偏移校准传感器。

|  |  |
| --- | --- |
| 003.png | 004.png |

## 安装喷嘴偏移校准传感器

### 步骤 1. 安装喷嘴偏移校准传感器

保持连接器卡扣朝上，连接线缆，随后将喷嘴偏移校准传感器放置在支架上。

|  |  |
| --- | --- |
| 005.png | 006.png |

### 步骤 2. 安装螺丝

使用 H2.0 内六角扳手，锁入喷嘴偏移校准传感器 2 颗螺丝固定。

![007.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-nozzle-offset-calibration-sensor/zh/007.png)

---

## 移除擦嘴钢片

使用 H2.0 内六角扳手，移除擦嘴钢片的 1 颗螺丝，随后取下擦嘴钢片。

|  |  |
| --- | --- |
| 008.png | 009.jpg |

## 安装擦嘴钢片

将擦嘴钢片安装到喷嘴偏移校准器右侧，然后锁入 1 颗螺丝固定。

|  |  |
| --- | --- |
| 010.jpg | 011.png |

## 功能验证

启动打印机，放置打印板，执行一次喷嘴偏移校准操作，校准结果通过即可。
