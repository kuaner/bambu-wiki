## USB-C 线

简述：USB-C 数据线是用于连接打印机 AP 板和 TH 板，对工具头进行控制及数据交互的连接线。

![001.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-usb-c-cable/zh/001.png)

## 拖链

简述：拖链是连接在工具头和打印机上盖后侧，用于保护 USB - C 线的链式结构装置。

![002.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-usb-c-cable/zh/002.png)

## 何时更换

- USB-C 数据线损坏；
- 拖链损坏；
- 经过 Bambu Lab 官方技术支持确认需要更换。

## 所需工具和材料

- H1.5 内六角扳手
- H2.0 内六角扳手
- USB-C 线
- 拖链

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除 USB-C 线

### 步骤 1. 移除背板

您可以参考WIKI[P3C 背板更换指南](replace-back-panel.md)，完成 6-pin 接口板/缓冲器和背板的移除。

![003.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-usb-c-cable/zh/003.png)

### 步骤 2. 移除拖链

> \*\*说明：\*\*本步骤仅适用于移除拖链的主体部分，不含固定底座，写在第 2 步主要是为了对应单独更换拖链的需求。如果目标不是更换拖链，而是更换 USB-C 线，可在最后再操作。
>
> 调整工具头处的拖链位置，使拖链与 X 轴方向接近垂直，然后如图所示，向右用力推倒拖链支架使拖链支架与固定底座分离。
>
> |  |  |
> | --- | --- |
> | 004.png | 005.png |

> 将 USB-C 线缆从链接支架上松出。
>
> |  |  |
> | --- | --- |
> | 006.jpg | 007.jpg |

> 从打印机背面找到拖链与上盖组件的连接位置，将 USB-C 线上的磁环从槽位里拉出来；
>
> |  |  |
> | --- | --- |
> | 008.png | 009.png |

> 然后用内六角扳手或撬棍在拖链的末端撬起，解除拖链的锁定后，松出拖链。
>
> |  |  |
> | --- | --- |
> | 010.png | 011.jpg |

> 沿着拖链的缺口，将线从拖链上松出，移除拖链。
>
> ![012.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-usb-c-cable/zh/012.png)

### 步骤 3. 移除维修盖板

使用 H2.0 内六角扳手，移除维修盖板 4 颗螺丝，取下维修盖板。

|  |  |
| --- | --- |
| 013.png | 014.png |

### 步骤 4. 移除 TH 板

请您参考Wiki：[P3C TH 板更换指南](replace-th-board.md)，完成 TH 板的移除。

![015.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-usb-c-cable/zh/015.png)

### 步骤 5. 移除 USB-C 线

使用 H1.5 内六角扳手移除拖链支架固定底座 3 颗螺丝，松出拖链支架底座。

|  |  |
| --- | --- |
| 016.png | 017.png |

使用 H2.0 内六角扳手移除 AP 板侧 USB-C 线缆固定块螺丝，取下固定块，随后断开 USB-C 线的插头，从打印机背面将 USB-C 线的插头抽出。

|  |  |
| --- | --- |
| 018.png | 019.png |

将 USB-C 线上的磁环从槽位里拉出来，然后用内六角扳手或撬棍在拖链的末端撬起，解除拖链的锁定，松出拖链。

|  |  |
| --- | --- |
| 020.png | 021.png |

调整磁环的角度，使磁环退回到打印机腔内，可将 USB-C 线与拖链组件完全从打印机上移除。随后沿着拖链的缺口，将线从拖链上松出，移除拖链。

|  |  |
| --- | --- |
| 022.png | 023.png |

## 安装 USB-C 线

### 步骤 1. 安装 USB-C 线

将连接 AP 板一端的 USB-C 插头穿过打印机上盖组件的预留孔，并通过左后立柱穿到 AP 板的区域。

|  |  |
| --- | --- |
| 024.png | 025.png |

将 USB-C 线缆接头插入连接器座，并依次锁附固定片和 1 颗固定螺丝（USB-C 接头带有凸起部分的一侧朝上，当该凸起部位与固定片槽位完全卡入嵌合时，即表示接头已插入到位），再将其余线缆插回插座；

|  |  |
| --- | --- |
| 026.png | 027.png |

### 步骤 2. 安装维修盖板

安装维修盖板，并使用 H2.0 内六角扳手锁入维修盖板 4 颗螺丝固定。

|  |  |
| --- | --- |
| 028.png | 029.png |

### 步骤 3. 安装拖链

将 USB-C 线卡进拖链的末端，然后将拖链末端安装到打印机上，确保图示 3 处卡扣固定到位。

|  |  |
| --- | --- |
| 030.png | 031.png |

> - **如果您只是更换拖链，且参考了拆除内容的步骤 2 来移除了拖链，请参考如下操作将拖链安装好：**
>
> 将线材支架的缺口对准线缆后用力压向线缆，使线缆进到支架内，将线缆整理入支架折向的位置和第 1 节拖链。
>
> |  |  |
> | --- | --- |
> | 032.png | 033.png |

> 调整拖链的位置，向支架底座按压，使支架与底座扣合；整理线缆将线缆卡入拖链。
>
> |  |  |
> | --- | --- |
> | 034.png | 035.png |

> - **如果您是更换了 USB-C 线或拆除了拖链底座，请参考以下的步骤继续：**
>
> **重要提示：**
>
> USB 线缆与拖链底座具有特定的安装方向与定位要求。安装时，**务必将线缆上的白色标记（如左图箭头所示）对齐至拖链底座的卡口边缘（如右图箭头所示）**，具体对齐位置见下图：
>
> |  |  |
> | --- | --- |
> | 036.png | 037.png |

> 将 USB 线沿着拖链支架的缺口和底座的线槽，装进拖链。最后将拖链支架安装到工具头上，锁入 3 颗螺丝固定。
>
> |  |  |
> | --- | --- |
> | 038.png | 039.png |

### 步骤 4. 安装TH板

请您参考Wiki：[P3C TH 板更换指南](replace-th-board.md)，完成 TH 板及工具头后盖的安装。

![040.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-usb-c-cable/zh/040.png)

### 步骤 5. 安装背板

您可以参考WIKI：[P3C 背板更换指南](replace-back-panel.md)，完成 6-pin 接口板/缓冲器和背板的安装。

![041.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-usb-c-cable/zh/041.png)

## 功能验证

连接电源并打开打印机，发起打印任务系统无报错。
