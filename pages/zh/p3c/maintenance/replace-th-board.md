## TH 板

简述：安装在工具头背部的小型集成电路板，主要负责控制工具头上各个电机的运转、监测工具的状态并协调热端温度与挤出动作的同步。

| 3 | 挤出电机 | / | / |

## 何时更换

1. 电路板上的元器件、连接器或连接排线出现明显的损坏，并影响使用；
2. 经过交换检查或工具的测量，确认是相关配件的故障；
3. 经 Bambu Lab 技术支持确认，需更换 TH 板的故障。

## 所需工具和材料

- H2.0 内六角扳手
- H1.5 内六角扳手
- TH 板

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 拆装提示

> 本指南是在已拆除 AMS 3P 的情况下进行的，您可以参考WiKi：[AMS 3P 拆装指南](replace-ams3p.md) 对 AMS 进行移除。

## 移除 TH 板

### 步骤 1. 移除工具头后盖

使用 H1.5 内六角扳手移除工具头后盖 2 颗螺丝，再向后抠开后盖。（若后盖拆卸困难，可参考右图示，将内六角扳手或撬棍插入拖链缝隙，轻轻撬动使后盖上边缘的卡扣脱开，再将后盖整体取下。）

|  |  |
| --- | --- |
| 003.png | 004.png |

### 步骤 2. 移除 TH 板

先打开 TH 板上 1、2 号 FPC 排线压盖，随后再断开 3、4 号线缆；

|  |  |
| --- | --- |
| 005.png | 006.png |

使用 H1.5 内六角扳手移除 TH 板 4 颗固定螺丝，松开 TH 板后断开 USB-C 连接器，再抽出 1、2 号 FPC 排线，移除 TH 板。

|  |  |
| --- | --- |
| 007.png | 008.png |

## 安装 TH 板

### 步骤 1. 安装 TH 板

先连接 3 号 FPC 排线并压紧盖子，然后连接 1、2 号 FPC 排线并压紧盖子，最后再连接 4 号接头和 USB-C 连接器；

|  |  |
| --- | --- |
| 009.png | 010.png |

将 TH 板安装到工具头上，参照图示调整线缆余量，确保线缆不干涉后盖安装；随后用 H1.5 内六角扳手锁紧 4 颗螺丝固定。

|  |  |
| --- | --- |
| 011.png | 012.png |

### 步骤 2. 安装工具头后盖

对齐螺丝柱和螺丝孔，将后盖安装到工具头背部，按压后盖，将后盖安装到位。随后使用 H1.5 内六角扳手锁入工具头后盖 2 颗螺丝固定。

|  |  |
| --- | --- |
| 013.png | 014.png |

## 功能验证

连接电源，启动打印机，执行一次加载打印头的操作，能正常完成即可。
