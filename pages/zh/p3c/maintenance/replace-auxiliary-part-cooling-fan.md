## 辅助部件冷却风扇

简述：属于选配的配件，它安装在腔室的左侧，为高速打印提供了更好的冷却条件。

![001.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan/zh/001.jpg)

## 何时更换

- 塑料风道物理损坏
- 风扇电机损坏或异响
- 风扇转速异常经 Bambulab 技术支持确认需更换的

## 所需工具和材料

- H2.0 内六角扳手
- 辅助部件冷却风扇

## 安全提示

> 下降热床后，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 加装辅助部件冷却风扇

### 步骤 1. 下降热床

启动打印机，在屏幕上点击下降热床的图标，将热床下降到底部；

|  |  |
| --- | --- |
| 002.png | 003.png |

### 步骤 2. 移除背板

您可以参考 [P3C 背板更换指南](replace-back-panel.md)，完成 6-pin 接口板/缓冲器和背板的移除。

![004.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan/zh/004.png)

### 步骤 3. 安装辅助部件冷却风扇

放置辅助部件冷却风扇到腔内，将线缆穿过左内衬与侧板之间的预留孔隙到打印机背面，拉出一定长度的线缆避免重新掉回腔内；

|  |  |
| --- | --- |
| 005.png | 006.png |

将辅助部件冷却风扇对齐侧板上的螺丝立柱，使用 H2.0 内六角扳手按序预锁入 4 颗螺丝，最后再将 4 颗螺丝同时拧紧；

![007.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan/zh/007.png)

将线缆埋入后自适应风道上的理线扣，并插入图示转接板接口中。

|  |  |
| --- | --- |
| 008.png | 009.png |

### 步骤 4. 安装背板

您可以参考 [P3C 背板更换指南](replace-back-panel.md)，完成 6-pin 接口板/缓冲器和背板的安装。

![010.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan/zh/010.png)

## 移除辅助部件冷却风扇

### 步骤 1. 下降热床

启动打印机，在屏幕上点击下降热床的图标，将热床下降到底部；

![011.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan/zh/011.png)

### 步骤 2. 移除背板

您可以参考 [P3C 背板更换指南](replace-back-panel.md)，完成 6-pin 接口板/缓冲器和背板的移除。

![012.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan/zh/012.png)

### 步骤 3. 移除辅助部件冷却风扇

断开转接板上辅助部件冷却风扇线缆，并从理线扣中移除线缆；

|  |  |
| --- | --- |
| 013.png | 014.png |

使用 H2.0 内六角扳手移除辅助部件冷却风扇的 4 颗螺丝，取下风扇；并将线缆向腔内回收。

|  |  |
| --- | --- |
| 015.png | 016.png |

## 功能验证

连接电源线并开启电源，在屏幕上点击辅助部件冷却风扇图标，开启辅助部件冷却风扇。如果辅助部件冷却风扇按预期工作无报错提示，那么更换完成。
