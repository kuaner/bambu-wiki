## XY 轴皮带

简述：安装在 P3C 打印机上的开口同步皮带，一共有两条，它们将 X/Y 电机和工具头连接起来并驱动工具头在 X/Y 方向的移动。

## 何时更换

- XY 轴皮带使用磨损，影响打印质量
- XY 轴皮带断裂

## 所需工具和材料

- H2.0 内六角扳手
- 瞬干胶（如 502胶水）
- XY 轴皮带

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 拆装提示

> 本指南是在已移除 AMS 3P 的情况下进行的，操作前请先参考Wiki：[AMS 3P 拆装指南](replace-ams3p.md)，完成对 AMS 的移除。

## 更换 XY 轴皮带

### 步骤 1. 松出皮带固定支架

用 H2.0 内六角扳手按图中螺丝标识的顺序，移除 3 颗螺丝，将 XY 皮带固定支架松出。（另一侧同样的操作）

|  |  |
| --- | --- |
| 001.jpg | 002.jpg |

### 步骤 2. 松出皮带

用力按箭头方向推动皮带，可将皮带压紧块松出。

|  |  |
| --- | --- |
| 003.jpg | 004.jpg |

移除压紧块，将皮带从固定支架中松出。同样的操作，将另一侧对应位置的皮带也从固定支架中松出。

|  |  |
| --- | --- |
| 005.jpg | 006.jpg |

> 温馨提示：如果压紧块安装比较牢固，可使用 H1.5 内六角扳手将皮带压紧块撬出。
>
> ![007.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-xy-belt/zh/007.jpg)

### 步骤 3. 粘接新皮带

在旧皮带的齿面涂布少量瞬干胶，控制涂布面在 2~3 个齿范围内。

![008.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-xy-belt/zh/008.jpg)

将新皮带的背面贴到涂布瞬干胶的位置，保持约 5 秒钟，然后尝试拉扯两条皮带，确认皮带能受住正常的拉扯不分开。（注：如果断开了，请重新点上瞬干胶，延长连接保持的时间。）

![009.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-xy-belt/zh/009.png)

### 步骤 4. 穿引皮带

从旧皮带的另一侧拉皮带，将新皮带牵引过去，覆盖旧皮带，直到能看到两条皮带的连接点出现。

|  |  |
| --- | --- |
| 010.jpg | 011.jpg |

用手在连接位置将两条皮带前后掰开，移除旧皮带，新皮带将旧皮带完全替换掉。

|  |  |
| --- | --- |
| 012.jpg | 013.jpg |

如果需要更换另一条旧皮带，可以重复第 2 步~第 4 步的操作。

### 步骤 5. 固定皮带

将新皮带穿过皮带固定支架，自末端装上皮带压紧块。

|  |  |
| --- | --- |
| 014.jpg | 015.jpg |

将皮带拉紧，使压紧块固定。同样的操作将皮带另一端也固定到支架上。

|  |  |
| --- | --- |
| 016.jpg | 017.jpg |

### 步骤 6. 安装皮带固定支架

将皮带固定支架安装到工具头两侧，按序号依次锁紧两侧的螺丝。

|  |  |
| --- | --- |
| 018.jpg | 019.jpg |

### 步骤 7. 张紧皮带

拧松左右两个 XY 张紧器螺丝，让张紧器自然张紧，前后移动工具头2~3次，然后重新锁紧张紧器螺丝。

![020.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-xy-belt/zh/020.jpg)

## 功能验证

连接电源并打开打印机，执行一次“校准—打印校准—振动补偿校准”能正常通过即可。

![021.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-xy-belt/zh/021.png)
