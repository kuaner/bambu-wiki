## 左侧板

简述：面对打印机玻璃前门，安装在打印机左侧的塑料面板，用于封闭打印机。

![001.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/001.png)

## 右侧板

简述：面对打印机玻璃前门，安装在打印机右侧的塑料面板，用于封闭打印机。

![002.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/002.png)

## 何时更换

侧板凹陷或损坏时更换。

## 所需工具和材料

- 左/右侧板
- H1.5 内六角扳手
- H2.0 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 拆装提示

> 本指南是在已移除 AMS 的情况下操作的，请参考WIKI: [AMS 3P（舱体和支架一体） 拆装指南](replace-ams3p.md) 完成将 AMS 从打印机上移除和安装的操作。

## 移除左侧板

> 1. 左侧板固定螺丝共计 27 颗（不含辅助部件冷却风扇）；
> 2. 由于螺丝数量与种类较多，建议提前在 MakerWorld 打印螺丝收纳盒，用于区分螺丝的类型与安装位置。

### 步骤 1. 移除前面盖螺丝

移除前面盖顶部与左侧板共锁的 1 颗螺丝。

|  |  |
| --- | --- |
| 003.png | 004.png |

### 步骤 2. 移除玻璃前门

保持玻璃前门处于关闭状态，使用 H2.0 内六角扳手移除固定前门的 4 颗螺丝，取下玻璃前门。

![005.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/005.png)

### 步骤 3. 移除左辅助部件冷却风扇

> 说明：左侧辅助部件冷却风扇为选配套装，若您的机器未加配辅助部件冷却风扇，可直接跳过此步。

您可以参考 WIKI：[P3C 左辅助部件冷却风扇更换指南](replace-auxiliary-part-cooling-fan.md)，完成辅助部件冷却风扇的移除。  
![remove-aux-part-cooling-fan.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/remove-aux-part-cooling-fan.png)

### 步骤 4. 移除左侧板螺丝

使用H2.0 内六角扳手移除左侧板靠前门处的 3 颗螺丝；

![006.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/006.png)

找到左侧板顶部泡棉有十字划痕处，使用H2.0 内六角扳手移除下面 2 颗螺丝；

![007.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/007.png)

使用H2.0 内六角扳手移除侧板内侧图示位置的 3 颗螺丝；

![008.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/008.png)

使用H2.0 内六角扳手移除前立柱的 3 颗螺丝；

![009.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/009.png)

使用H2.0 内六角扳手移除打印机背面料盘底座的 2 颗螺丝，取下料盘底座，随后再移除左侧板背部图示 4 颗；

|  |  |
| --- | --- |
| 010.png | 011.png |

按图示操作将机器缓慢侧放（**机器较重，请小心侧放**），并使用H2.0 内六角扳手移除打印机底部的 5 颗螺丝；

|  |  |
| --- | --- |
| 012.png | 013.png |

### 步骤 5. 移除左侧板

> 侧板除了螺丝外，还依靠一些卡扣辅助定位和固定，在拆除侧板时需要注意用力的位置和方向，避免损坏卡扣。

将机器扶正立起，从图示侧板前面位置用力，将侧板从打印机上分离少许。随后使用撬棒或扳手从已分离的侧板上部撬，使上部的卡扣完全从打印机上分离开；

|  |  |
| --- | --- |
| 014.png | 015.png |

最后斜向上取下左侧板。

|  |  |
| --- | --- |
| 016.png | 017.png |

## 安装左侧板

### 步骤 1. 安装左侧板

将左侧板下方的 5 个螺丝立柱对准打印机安装槽扣入，随后推入左侧板；

|  |  |
| --- | --- |
| 018.png | 019.png |

随后按压侧板上部，当听到卡扣发出咔哒声时代表卡扣安装到位，确保侧板与打印机框架完全贴合。

|  |  |
| --- | --- |
| 020.png | 021.png |

### 步骤 2. 安装左侧板螺丝

使用H2.0 内六角扳手，锁入左侧板顶部的 2 颗固定螺丝；

![022.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/022.png)

使用H2.0 内六角扳手，依次锁入左侧板内侧的 3 颗螺丝和前立柱的 3 颗螺丝；

|  |  |
| --- | --- |
| 023.png | 024.png |

使用H2.0 内六角扳手，锁入侧板前面 3 颗螺丝；

![025.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/025.png)

使用H2.0 内六角扳手，锁入侧板后面（机器背面）的 4 颗螺丝；随后安装料盘底座，锁入支架的 2 颗固定螺丝。

|  |  |
| --- | --- |
| 026.png | 027.png |

### 步骤 3. 固定左辅助部件冷却风扇

> 说明：左侧辅助部件冷却风扇为选配套装，若您的机器未加配辅助部件冷却风扇，可直接跳过此步。

您可以参考 WIKI：[P3C 左辅助部件冷却风扇更换指南](replace-auxiliary-part-cooling-fan.md)，完成辅助部件冷却风扇的安装。  
![remove-aux-part-cooling-fan.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/remove-aux-part-cooling-fan.png)

### 步骤 4. 安装玻璃前门

装回玻璃前门，使用 H2.0 内六角扳手锁入固定前门的 4 颗螺丝。

![028.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-side-panel-left/zh/028.png)

### 步骤 5. 锁入前面盖螺丝

使用H2.0 内六角扳手，锁入前面盖顶部与侧板共锁的 1 颗螺丝。

|  |  |
| --- | --- |
| 029.png | 030.png |
