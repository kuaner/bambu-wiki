### 惰轮组件

简述：皮带路径上的从动轮，是保障传动平稳、维持皮带张力的核心传动部件。本指南所述惰轮组件，是指 XY 同步皮带路径上使用的 10 个较容易更换的惰轮：

1. 安装在打印机后立柱两侧的惰轮组件，共 4 个；

![001.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-idler-pulley/zh/001.jpg)

- 安装在打印机前立柱两侧的惰轮组件，共 2 个；

|  |  |
| --- | --- |
| 002.jpg | 003.jpg |

- 安装在左侧 Y 滑车上的惰轮组件，共 4 个（ 靠上的 2 个适用本指南，靠下的 2 个只能在将 X 轴组件拆下后再处理。 ）

|  |  |
| --- | --- |
| 004.jpg | 005.jpg |

## 何时更换

- 惰轮异响
- 惰轮脏污或变形，且不可恢复。

## 所需工具和材料

- H2.0 内六角扳手
- 惰轮组件

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## **螺丝滑牙风险提示：**

> 由于后惰轮组件的螺丝锁附方向与 XY 皮带走向一致，拆装时若皮带处于张紧状态，皮带拉力会增加螺纹间的正压力，极易导致螺丝滑牙。**请务必先将 XY 皮带从工具头上松开，确认 XY 皮带完全处于松弛状态后，方可进行后惰轮组件的拆装作业。**  
> 具体的操作如下：用 H2.0 内六角扳手按图中螺丝标识的顺序，移除 3 颗螺丝，将 XY 皮带固定支架松出。
>
> ![006.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-idler-pulley/zh/006.jpg)

## 移除惰轮组件（后）

### 步骤 1. 移除皮带固定支架

用 H2.0 内六角扳手按图中螺丝标识的顺序，移除 3 颗螺丝，将 XY 皮带固定支架松出。使 XY 皮带处于放松状态。

|  |  |
| --- | --- |
| 007.jpg | 008.jpg |

### 步骤 2. 移除惰轮组件（后）

用 H2.0 内六角扳手，移除 2 颗螺丝；轻拉对应位置的同步皮带，可将整个惰轮组件扯出；两侧惰轮操作方式一致。

|  |  |
| --- | --- |
| 009.jpg | 010.jpg |

## 安装惰轮组件（后）

### 步骤 1. 安装惰轮组件（后）

将惰轮轴穿过惰轮，随后将惰轮轴安装到惰轮支架上；

|  |  |
| --- | --- |
| 011.jpg | 012.jpg |

将惰轮组件安装到打印机上，并使用 H2.0 内六角扳手锁入 2 颗螺丝固定；两侧惰轮操作方式一致。

|  |  |
| --- | --- |
| 013.jpg | 014.jpg |

### 步骤 2. 安装皮带固定支架

将 XY 皮带固定支架安装到工具头上，用手压着固定支架，先锁中间位置的 1 颗螺丝，然后再锁上下 2 颗螺丝。

|  |  |

## 移除惰轮组件（前）

## 拆装提示：

> 1. 位于前方的 2 个惰轮组件，被闪切挂架遮挡，如果需要更换，请参考 WIKI ：[闪切挂架更换指南](replace-swaptek-rack.md)，需先对闪切挂架进行移除，惰轮安装完成后，再进行闪切挂架的安装；
> 2. 请根据要更换的惰轮位置，移除同侧的 XY 皮带固定支架；如更换左侧惰轮则移除左侧皮带固定支架。

### 步骤 1. 移除皮带固定支架

用 H2.0 内六角扳手按图中螺丝标识的顺序，移除 3 颗螺丝，将 XY 皮带固定支架松出。使 XY 皮带处于放松状态。

## 安装惰轮组件（Y 滑车）

### 步骤 1. 安装惰轮组件（Y 滑车）

将惰轮放置到 Y 滑车上，注意 XY 同步皮带是被惰轮压在后面的，放入惰轮螺丝轴，用手微调惰轮的位置，使惰轮螺丝轴能完全通过惰轮并进入下面的螺纹孔，锁紧螺丝轴。

将 XY 皮带固定支架安装到工具头上，用手压着固定支架，先锁中间位置的 1 颗螺丝，然后再锁上下 2 颗螺丝。

## 功能验证

拧松左右两个 XY 张紧器螺丝，让张紧器自然张紧，前后移动工具头 2~3 次，然后重新锁紧张紧器螺丝；

![039.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-idler-pulley/zh/039.jpg)

通电开机，在屏幕上点击：设置-维护-校准，选中振动补偿，完成一次校准流程。

![040.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-idler-pulley/zh/040.png)
