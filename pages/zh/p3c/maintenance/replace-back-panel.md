## 背板

简述：安装在打印机背面的金属板，起到封闭作用。

![001.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-back-panel/zh/001.png)

## 何时更换

运输损坏导致背板明显变形

## 所需工具和材料

- H2.0 内六角扳手
- 背板

## 安全提示

> 重要提醒！
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> ![002.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-back-panel/zh/002.png)  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除背板

### 步骤 1. 移除 6-pin 接口板或缓冲器

使用 H2.0 内六角扳手，移除接口板或外接缓冲器 2 颗螺丝；

|  |  |
| --- | --- |
| 003.png | 004.png |

露出连接器，按压插头卡扣进行解锁，断开插头连接，移除 6-pin 接口板/缓冲器。

|  |  |
| --- | --- |
| 005.png | 006.png |

### 步骤 2. 移除外挂料盘底座

使用 H2.0 内六角扳手，移除外挂料盘底座所有螺丝，取下料盘底座。

![007.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-back-panel/zh/007.png)

### 步骤 3. 移除背板

用 H2.0 内六角扳手移除机牙螺丝 6 颗（两侧蓝色圈）与自攻螺丝 13 颗（绿色圈）。

|  |  |
| --- | --- |
| 008.png | 009.png |

松开背板后，将背板向上提起，移除背板。

|  |  |
| --- | --- |
| 010.png | 011.png |

## 安装背板

### 步骤 1. 安装背板

将背板下方左右两侧卡扣对准打印机底部的安装槽安装到位；

|  |  |
| --- | --- |
| 012.png | 013.png |

使用 H2.0 内六角扳手，按下图编号的顺序先锁入 7 颗螺丝，其中 1、3 为机牙螺丝，其余为自攻螺丝；

|  |  |
| --- | --- |
| 014.png | 015.png |

使用 H2.0 内六角扳手，锁入背板其余全部螺丝。（蓝色圈锁机牙螺丝，绿色圈锁自攻螺丝）

![016.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-back-panel/zh/016.png)

### 步骤 2. 安装外挂料盘底座

使用 H2.0 内六角扳手，锁入外挂料盘底座螺丝。

![017.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-back-panel/zh/017.png)

### 步骤 3. 安装 6-pin 接口板或缓冲器

将线缆接头插回接口板或缓冲器接口，随后将接口板或缓冲器下方的卡扣斜向下插回背板卡槽安装到位。

|  |  |
| --- | --- |
| 018.png | 019.png |

使用 H2.0 内六角扳手锁入接口板或缓冲器 2 颗固定螺丝。（安装缓冲器后请确认将料管和线缆连接到位）

|  |  |
| --- | --- |
| 020.png | 021.png |

## 功能验证

1. 背板螺丝全数锁入，无错用、无漏锁；
2. 背板四周没有异常翘起；
3. 连接 AMS 3P 并启动打印机，确认 AMS 3P 供电响应正常。
