## AMS 烘干组件

简述：AMS 3P 的烘干组件安装在 AMS 舱体下方，由加热单元、涡轮风扇、风门切换系统和 NTC 温度传感器组成。

![001.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-optional-filament-dryer/zh/001.png)

## 首次安装提示

\*\*重要提醒：\*\*烘干模块为选配套件，不搭配烘干模块使用时，AMS舱体底部的进气孔由贴纸覆盖以保证密闭性；\*\*首次安装烘干模块前，必须完整撕下附着在AMS舱体进气孔上的贴纸，否则烘干模块可能过热导致损坏！\*\*由于工艺设计变更，贴纸存在 2 个版本。

**版本一：**

使用 H2.0 内六角扳手拆下左图示的 2 颗螺丝，捏住螺丝孔处多出的贴纸边角，缓慢揭起并整片撕下，完整露出右图示三处区域的进气孔。

**版本二：**

贴纸较于版本一无两侧多出贴纸，揭起贴纸一角后即可整片撕下，完整露出右图示三处区域的进气孔。

## 何时更换

烘干组件工作异常经 Bambulab 技术支持确认需要更换的。

## 所需工具和材料

- H2.0 内六角扳手
- AMS 烘干组件

## 安全提示

> - 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
> - 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
> - 更换烘干组件之前请先断开烘干组件电源适配器插头与 6-pin 线缆插头（需按压接头解锁卡扣后拔出）：

## 拆装提示

> 为便于拆装，请参考 [AMS 舱体拆装指南](replace-chamber.md)，对AMS舱体进行移除。

## 安装 AMS 烘干组件

### 步骤 1. 安装 AMS 烘干组件

从 AMS 装饰盖内侧向外顶，将穿线孔遮丑盖移除；

|  |  |
| --- | --- |
| 008.png | 009.png |

首次安装时，请将电源适配器线缆与 6-pin 线缆穿过 AMS 电路板装饰后盖上的预留孔。（若后续只是更换 AMS 烘干组件，不更换线缆，可忽略此步）

![010.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-optional-filament-dryer/zh/010.png)

将电源适配器接头与 6-pin 线接头插入烘干组件插座中。

|  |  |
| --- | --- |
| 011.png | 012.png |

将烘干组件安装到位；

\*\*重要提醒：\*\*请将烘干组件对齐中框上的螺丝孔位水平安装，注意检查烘干组件与 AMS 中框是否贴合到位！

|  |  |
| --- | --- |
| 013.webp | 014.png |

使用 H2.0 内六角扳手依次锁入烘干组件 1-5 号颗螺丝固定，随后将线缆卡入理线扣并锁入 6 号螺丝固定线缆。

|  |  |
| --- | --- |
| 015.png | 016.png |

### 步骤 2. 安装 AMS 舱体

您可以参考 [AMS 3P 舱体拆装指南](replace-chamber.md)，安装 AMS 舱体。

### 步骤 3. 安装 AMS 耗材烘干仓盖

将仓盖后方对准图示 AMS 舱体磁吸位置，待磁铁吸附后放置仓盖；

|  |  |
| --- | --- |
| 017.png | 018.webp |

确认仓盖两侧已卡入 RFID 线圈的凹槽中，整体贴合到位无缝隙或异常翘起。

![019.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-optional-filament-dryer/zh/019.png)

## 移除 AMS 烘干组件

### 步骤 1. 取下 AMS 舱体

您可以参考 [AMS 3P 舱体拆装指南](replace-chamber.md)，取下 AMS 舱体，并将舱体倒放在桌面上。

> 注意：在移除或安装 AMS 舱体前，请先执行退料操作，并取出舱内的所有料盘。若未退料，残留的耗材可能在安装时被夹断或卡住，导致后续进退料困难；同时，料盘的自重也会增加操作难度。
>
> |  |  |
> | --- | --- |
> | 020.png | 021.png |

### 步骤 2. 移除 AMS 烘干组件

使用 H2.0 内六角扳手移除烘干组件的 5 颗螺丝，和理线扣的 1 颗螺丝，松出 AMS 烘干组件。

![022.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-optional-filament-dryer/zh/022.png)

断开烘干组件电源适配器接头、6-pin 线缆接头，移除烘干组件。断开 6-pin 线时需按压接头解锁卡扣后再向外拔出。

|  |  |
| --- | --- |
| 023.png | 024.png |

## 功能验证

开启打印机电源，通过屏幕菜单启动 AMS 烘干程序，烘干组件工作运行正常，无错误提示。
