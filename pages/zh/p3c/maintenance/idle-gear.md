## 介绍

XY 轴的传动总共包含 12 个惰轮，而惰轮内的轴承可能因为润滑不足，导致工具头移动过程中出现异响，本文将介绍如何进行维护。

## 所需工具

- H2.0 内六角扳手
- 清洁湿巾
- 润滑油
- [针头打印件](https://makerworld.com.cn/zh/models/1730129-xiao-shui-run-hua-you-di-cheng-ben-zhen-tou?from=search#profileId-1906070)

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 维护步骤

首先降低热床到合适位置并上升挂架高度，以便于后续操作。

![001.jpg](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/idle-gear/zh/001.jpg)

### X 轴组件

先检查惰轮表面是否有脏污，若存在脏污，可使用清洁湿巾仔细擦除。

![002.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/idle-gear/zh/002.png)

再向惰轮上挤入适量润滑油。

![003.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/idle-gear/zh/003.png)

下侧和右侧惰轮也是相同的操作。

|  |  |
| --- | --- |
| 004.png | 005.png |

### 打印机前侧

打印机前侧总共 2 个惰轮，确保表面没有污渍后，可在惰轮上挤入适量润滑油。

|  |  |
| --- | --- |
| 006.png | 007.png |

### 打印机后侧

拧松惰轮支架的固定螺丝，取出惰轮。

|  |  |
| --- | --- |
| 008.png | 009.png |

检查惰轮表面是否存在脏污，并使用清洁湿巾擦拭。

![010.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/idle-gear/zh/010.png)

在轴承上挤入适量润滑油后，装回设备。

![011.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/idle-gear/zh/011.png)

可从打印机仓内观察张紧位置的两个惰轮是否需要擦拭清洁。

|  |  |
| --- | --- |
| 012.png | 013.png |

若需润滑，请先 [P3C 背板更换指南](replace-back-panel.md)，再向张紧器惰轮上侧挤入适量润滑油。

|  |  |
| --- | --- |
| 014.png | 015.png |

完成以上工作后，推拉工具头左右滑动，更有利于润滑油进入轴承中。

![016.webp](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/idle-gear/zh/016.webp)
