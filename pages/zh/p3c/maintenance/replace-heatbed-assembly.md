## 热床组件

简述：打印机的热床是安装在打印机腔体内，能沿 Z 方向上下运动并能根据用户的设定温度进行加热的平台。设置合适的热床温度能有效提升模型与打印板的粘接力，防止模型翘边。

![001.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-heatbed-assembly/zh/001.png)

## 何时更换

- 热床不升温， 且已排查过，确认热床故障；
- 影响功能的物理损坏或明显的形变；
- 经过 Bambu Lab 官方确认需要更换热床。

## 所需工具和材料

- H2.0 内六角扳手
- 热床

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除热床组件

### 步骤 1. 移除背板与废料滑梯

您可以参考WIKI：[废料滑梯更换指南](replace-purge-chute.md)，移除背板及滑梯。

![002.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-heatbed-assembly/zh/002.png)

### 步骤 2. 断开线缆

将热床线缆插簧的硅胶保护套向后推出露出插簧，使用内六角扳手轻顶插簧上的卡扣并向外拔出。两根线缆拆装方式相同。

|  |  |
| --- | --- |
| 003.png | 004.webp |

在 MC 板上找到 15 号端口，按压线缆端子解锁卡扣，拔出热床-MC 信号线缆；

|  |  |
| --- | --- |
| 005.png | 006.png |

使用 H2.0 内六角扳手移除立柱上的热床地线螺丝，松出地线；随后再移除立柱上线夹螺丝，将热床线缆与线夹分离；

|  |  |
| --- | --- |
| 007.png | 008.png |

### 步骤 3. 移除热床

热床与 3 个滑块共有 6 颗螺丝固定，先使用 H2.0 内六角扳手移除 1 、2 号的 2 颗螺丝，然后再揭开热床左右两侧的硅胶条，移除 3-6 号共 4 颗螺丝；

|  |  |
| --- | --- |
| 009.png | 010.png |

向上提起热床线缆使其与 Z 滑块理线扣分离，并将线缆往打印机腔室方向回收，倾斜热床，从打印机前门位置将热床取出。

|  |  |
| --- | --- |
| 011.png | 012.png |

## 安装热床组件

### 步骤 1. 安装热床

将热床线缆穿过内衬中间空隙，倾斜热床放入腔内；

|  |  |
| --- | --- |
| 013.png | 014.png |

将热床放置在 Z 滑块上，确认后方定位柱位于两个螺丝孔中间，随后使用 H2.0 内六角扳手预锁 1、2 号螺丝；

|  |  |
| --- | --- |
| 015.png | 016.png |

确认左右两侧滑块定位柱位于两个螺丝孔中间，随后使用 H2.0 内六角扳手预锁入 3-6 号螺丝；

|  |  |
| --- | --- |
| 017.png | 018.png |

然后将 3 个滑块上固定热床的 6 颗螺丝都进行拧紧，并用力下压盖好两侧硅胶条；

|  |  |
| --- | --- |
| 019.png | 020.png |

## 拆装提示

> 若热床两侧硅胶条按压复位困难，您可以使用斜口钳或剪刀将硅胶条背面的卡扣剪掉，再放置到热床两侧安装槽位上：  
> ![heatbed-jian.jpg](https://wiki.bambulab.com/p3c/manual/heatbed-jian.jpg)

### 步骤 2. 连接线缆

将热床线缆依次卡入Z滑块理线扣、后立柱理线扣中；热床地线弯折后一并卡入理线扣；

|  |  |
| --- | --- |
| 021.png | 022.png |

使用 H2.0 内六角扳手锁入 2 颗螺丝，分别固定理线扣和接地线（一颗固定理线扣，一颗固定地线）。

|  |  |
| --- | --- |
| 023.png | 024.png |

将热床-MC 板信号线接头插入 MC 板 15 号接口，随后将热床供电线插簧插入 AC 板；

|  |  |
| --- | --- |
| 025.png | 026.png |

### 步骤 3. 安装废料滑梯与背板

您可以参考WIKI：[废料滑梯更换指南](replace-purge-chute.md)，安装废料滑梯和背板。

![027.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-heatbed-assembly/zh/027.png)

## 功能验证

连接电源线并启动打印机，设置热床温度为 50 ℃，确认热床温度能升高到目标值。
