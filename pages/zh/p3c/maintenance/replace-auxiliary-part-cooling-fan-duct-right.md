## 右辅助部件冷却风扇风道

简述：安装于打印机腔内右侧，在冷却模式下，可提供更强的风冷支持，优化冷却条件并提升成型稳定性。右辅助部件冷却风扇风道单品中不包含辅助部件冷却风扇。

![001.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan-duct-right/zh/001.png)

## 何时更换

- 风道外观或结构损坏；
- 涉及风道拆装的特定维护场景（例如：更换辅助部件冷却风扇等）。

## 所需工具和材料

- H2.0 内六角扳手
- 右辅助部件冷却风扇风道

## 拆装提示

> 右辅助部件冷却风扇风道下方与底座通过卡扣固定。为便于拆卸风道，请在操作前通过屏幕控制热床移动至顶部，为风道的移除预留充足的操作空间。

![002.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan-duct-right/zh/002.png)

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除右辅助部件冷却风扇风道

### 步骤 1. 移除背板

您可以参考WIKI：[P3C 背板更换指南](replace-back-panel.md) ，完成 6-pin 接口板/缓冲器和背板的移除。

![003.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan-duct-right/zh/003.png)

### 步骤 2. 断开线缆连接

按压 MC 板 8 号线缆接头锁扣进行解锁，断开右辅助部件冷却风扇的线缆接头。

![004.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan-duct-right/zh/004.png)

### 步骤 3. 移除右辅助部件冷却风扇风道

使用 H2.0 内六角扳手移除图示右辅助部件冷却风扇风道 4 颗螺丝；

![005.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan-duct-right/zh/005.png)

使用 H1.5 内六角扳手移除风道与打印机金属框架连接的 2 颗螺丝；

![006.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan-duct-right/zh/006.png)

按图示操作，沿左侧水平方向对风道上下两端同时施力并扳动，使其与底座卡扣脱开，随后将风道取出。

稍微抬起辅助部件冷却风扇，然后依次顺着缺口方向用力将四角固定软钉拔出，使软钉与风扇分离；

稍微撑开理线支架，将线缆连接器从支架中取下；

将线缆从风道理线卡扣中取出，随后移除辅助部件冷却风扇。

## 安装右辅助部件冷却风扇风道

### 步骤 1. 安装辅助部件冷却风扇

稍微向上提起软钉，对准风扇四角的缺口方向将其卡入，将风扇装回风道；

|  |  |
| --- | --- |
| 016.png | 017.png |

请从包装盒内的三条线缆中，找到带有黑色端子的目标线缆（其余两条线缆属多机型共用，可忽略），将其白色一端与风扇线缆端子对齐插入连接；

|  |  |
| --- | --- |
| 018.png | 019.png |

随后向下按压连接器使其卡入支架，并将线缆理顺嵌入理线卡扣中。

|  |  |
| --- | --- |
| 020.png | 021.png |

### 步骤 2. 安装右辅助部件冷却风扇风道

将线缆穿过内衬与侧板间的小孔；

![022.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan-duct-right/zh/022.png)

将风道向打印机背部方向推到底，再向右侧板方向推入并安装到位，确保风道与内衬完全贴合。

|  |  |
| --- | --- |
| 023.png | 024.png |

使用 H2.0 内六角扳手锁入图示右辅助部件冷却风扇风道 4 颗螺丝；

![025.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan-duct-right/zh/025.png)

使用 H1.5 内六角扳手移除风道与打印机金属框架连接的 2 颗螺丝；

![026.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan-duct-right/zh/026.png)

### 步骤 3. 连接线缆

将辅助部件冷却风扇的线缆接头插入 MC 板 8 号接口。

![027.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan-duct-right/zh/027.png)

### 步骤 4. 安装背板

您可以参考WIKI：[P3C 背板更换指南](replace-back-panel.md) ，完成 6-pin 接口板/缓冲器和背板的安装。

## 功能验证

启动打印机，开启辅助部件冷却风扇，确认能正常启动和控制输出。

1. 启动打印机并进入空调系统界面；
2. 在冷却模式下，点击辅助部件冷却风扇标签（左/右）并开启风扇；
3. 确认风扇能全开到 100% 并能根据设置输出比例变更风速。

![028.png](https://public-cdn.bblmw.com/wiki/new/p3c/maintenance/replace-auxiliary-part-cooling-fan-duct-right/zh/028.png)
