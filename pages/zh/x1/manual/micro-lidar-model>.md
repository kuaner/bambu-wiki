# 2. 激光雷达版本变更说明

当前我们出厂的机器共配有两种不同型号的激光雷达，其主要区别为使用了不同波长的激光器（详见下图）。配置不同版本的激光器只是我们生产计划的变更，**双红外光激光器和单红光激光器在功能上没有任何区别，随机发货，请放心使用**。

# 3. 如何区分激光雷达版本

**请注意，激光雷达的版本和工具头硬件电路板(以下简称TH板)是配套使用的，即不同的激光器版本对应着不同的TH板。如果您需要更换激光器或者TH板，则必须使用相配套的版本，否则会造成激光雷达和TH上电子元器件的烧毁。**

**所以，如果您需要更换激光雷达或者TH板，请提供以下材料并联系售后技术支持确认激光器和配套的TH板的版本。**

## 方法1：

通过[提交工单](../../create-support-ticket.md)上传打印机日志，我们的技术支持人员会通过日志中的相关信息来帮助您判断版本。

## 方法2：

打开工具头前盖，将激光雷达的SN二维码照片和扫描二维码得到的SN信息上传到工单中，如下图所示：

![](https://wiki.bambulab.com/x1/manual/micro-lidar-version/lidar_sn.png)

提供图示激光雷达的SN二维码照片及扫描二维码得到的SN信息

## 方法3：

打开工具头后盖，将TH板的SN二维码照片和扫描二维码得到的SN信息上传到工单中，如下图所示：（二维码具体位置可能不同于下图）

![](https://wiki.bambulab.com/x1/manual/micro-lidar-version/th_sn.png)

提供图示TH板的SN二维码照片和扫描二维码得到的SN信息

## 方法4：

打开工具头后盖，观察垂直激光器的尾部，如果尾部带有一块小的PCB板，则这款激光器是单红光激光器，如果尾部不带有小的PCB板，则为双红外光激光器。

![](https://wiki.bambulab.com/x1/manual/micro-lidar-version/pcb_cn.png)

## 方法5：

从视频录像中来观察激光发出来的颜色，来判断激光器的版本。需要注意的是，双红外光激光器的波长位于红外线波段，肉眼不可见，只能通过摄像头录像来观察颜色。另外，有一部分摄像头具有IR cut 功能，可能会导致看不清红外光。请放心，如果激光雷达出现任何错误（比如激光不亮），HMS会通知故障问题，如果没有报错，则意味着你可以放心使用，你的激光雷达是正常运行的。但总的来说，这种方法用于判断激光器的版本不一定准确。

|  |  |
| --- | --- |
| 竖直激光器发出的蓝光 | 水平激光器发出的红外光（肉眼不可见） |

需要说明的是，机箱相机位于左侧，对于双红外激光器而言，右侧过来的水平红外激光可以被摄像头捕捉到，但后侧竖直红外光会被构建板镜面反射，因而大部分光是无法被机箱相机所捕获，所以通过监控相机录像一般只能看到水平激光器发出来的光，而无法看到竖直激光器发出光，如下图所示：

![](https://wiki.bambulab.com/x1/manual/micro-lidar-version/red-rr.png)

和单红光激光器相比，我们只能通过机箱相机观测到双红外激光器发出的水平红外光，竖直的红外光会被反射而无法被相机捕获

但如果将手机摄像头靠近激光雷达，并利用45度斜角，有机会用摄像头捕捉到后侧竖直激光器发出来的光，如下图所示：

![](https://wiki.bambulab.com/x1/manual/micro-lidar-version/rr-rr.jpg)

## 总结

**综上，我们比较推荐您同时提供方法1和方法2描述的材料，确保判断准确。再次声明，无论您收到的是哪种版本，其功能不受影响，您可以放心使用，祝您打印愉快。**

# 激光雷达和TH板版本的判断逻辑

在购买X1C/X1的TH板或激光雷达之前，请务必确保先确定其版本，以免购买错误版本导致报错不兼容。

**根据上述方法2和方法3，您可以分别获取激光雷达和TH板的序列号（SN）**。在此步骤中，您可以根据以下列表中的编码逻辑来确定您的激光雷达和TH板所属的版本：

|  |  |
| --- | --- |
| 激光雷达SN二维码照片 | TH板的SN二维码照片；二维码具体位置可能不同于该图 |

|  |  |  |
| --- | --- | --- |
|  | 单红光版本激光雷达 | 双红光版本激光雷达 |
| 激光雷达的SN | 00ExxA | 00ExxB |
| TH板的SN | 003xxA  003xxB | 003xxC  003xxD  003xxY |
| x 代表任意数字  Y 代表任意D以后的字母，比如E。 | | |

## 序列号(SN)的编码逻辑说明:

如果激光雷达的序列号以00ExxA开头，这意味着激光雷达是单红光版本，TH板也应使用序列号003xxA或003xxB开头的单红光版本。

如果激光雷达的序列号以00ExxB开头，这意味着激光雷达是双红光版本，TH板也应使用序列号003xxC、003xxD或003xxY开头的双红光版本。

## 案例1:

激光雷达 SN: 00E00A270400471

TH板 SN: 00301B2B2904166

激光雷达的SN是以00ExxA开始的，所以这是一个单红光版本的激光雷达。

TH板的SN是以003xxB开始的，所以这是一块单红光相匹配的TH板，这也与上述判断相符。

## 案例2:

激光雷达 SN: 00E00B321201095

TH板 SN: 00301C313004727

激光雷达的SN是以00ExxB开始的，所以这是一个双红光版本的激光雷达。

TH板的SN是以003xxC开始的，所以这是一块双红光相匹配的TH板，这也与上述判断相符。

## 案例3：

激光雷达SN: 00E09B341300483

TH板SN: 00301D331803375

激光雷达的SN是以00ExxB开始的，所以这是一个双红光版本的激光雷达。

TH板的SN是以003xxD开始的，所以这是一块双红光相匹配的TH板，这也与上述判断相符。
