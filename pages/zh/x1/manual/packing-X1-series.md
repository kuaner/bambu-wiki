X1和P1具有相同的尺寸和类似的结构，因此本文以X1系列打印机为例，描述如何装箱 X1/P1combo。

温馨提示：建议使用原包装打包产品,具有更好的保护性。

## 视频教程

## 步骤 1：调整热床

安装热床保护泡沫，通过屏幕控制，将热床下降到最底部。

|  |  |
| --- | --- |
|  |  |
|  |  |

## 步骤 2: 拆卸线轴支架

关闭打印机并卸下线轴支架。

|  |  |
| --- | --- |
|  |  |
|  |  |

## 步骤 3：拆卸 AMS 等配件

从打印机上移除PTFE管、4针/6针总线电缆和AMS缓冲器以及AMS。

|  |  |
| --- | --- |
| image1.webp |  |
|  |  |

## 步骤 4：打包线缆

从缓冲器上拆下4针和6针总线电缆，然后将缓冲器重新安装到打印机上。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 步骤 5：拆卸屏幕

卸下屏幕，并将其与线缆和线轴支架一起放入配件盒中。

|  |  |  |
| --- | --- | --- |
|  |  |  |
|  |  |  |

## 步骤 6：固定热床

将工具头包裹起来并移动到右上角，用3颗螺丝将热床固定住。

|  |  |  |  |
| --- | --- | --- | --- |
|  |  |  |  |

## 步骤 7：固定 AMS

安装AMS固定支架并锁定AMS。

|  |  |  |  |
| --- | --- | --- | --- |
|  |  |  |  |

## 步骤 8：安放备件

将配件盒和备用打印板放入打印机中，并安装泡沫和胶带。

|  |  |  |
| --- | --- | --- |
|  |  |  |
|  |  |  |

## 步骤 9：打包

将打印机打包至纸箱中

|  |  |  |  |
| --- | --- | --- | --- |
|  |  |  |  |

请将线轴放入包装中。它们是盒子保护的一部分。
