#### 方案 2：购买了 X1C Combo 套装

如果您购买的是 X1C AMS 2 Pro Combo 套装，该套装已包含 X1C 打印机、AMS 2 Pro 单元和所需配件（不含 6-pin 线，因为电源适配器已实现相同功能）。无需额外购买配件。

#### 方案 3：分别购买 X1C 和 AMS 2 Pro

如果您分别购买了 X1C 和 AMS 2 Pro，包装中仅包含 6-pin 线，您需要额外购买以下配件：

- 4-pin 线

- 电源适配器

- PTFE 接头

## 操作步骤

### 步骤 1：更新固件

X1C 的耗材烘干功能需通过固件升级来启用 AMS 2 Pro 的烘干控制。未更新固件时烘干功能将无法使用。更新固件方法请参考 [X1 固件更新指南](X1-firmware-update-support-ams2pro-ams-ht.md)。

### 步骤 2：确认安装与供电

确保 AMS 2 Pro 已正确连接至 X1C 打印机。安装方法可参考 [安装指南](installing-ams-2-pro-to-x1c.md)。

> 注意：X1C 无法直接为 AMS 2 Pro 的烘干功能供电，每个 AMS 2 Pro 单元都需要额外的外接电源适配器。连接后，“烘干与湿度”页面上的电源图标会变为绿色。

|  |  |
| --- | --- |
|  |  |

### 步骤 3：放置耗材

将耗材放入 AMS 2 Pro 的槽位，并关闭 AMS 2 Pro 顶盖以确保密封性，这是保证烘干效果的关键。

![](https://wiki.bambulab.com/x1/manual/x1c-with-ams-2-pro/filament-spools-in-ams.png)

> **注意**：烘干时不要点击进料。如已进料，系统会提示退料。退料方法：选择对应槽位并点击 **退料**，即可将耗材退回到卷盘。

|  |  |
| --- | --- |
|  |  |

### 步骤 4：进入烘干与湿度页面

在 X1C 触摸屏进入 **耗材** 菜单，点击 **AMS 湿度图标** 进入 **烘干与湿度** 页面。

|  |  |
| --- | --- |
|  |  |

或点击右下角 **设置** → **AMS 烘干** 进入页面。

![](https://wiki.bambulab.com/screen-operation/20250513-180056.jpg)

### 步骤 5：选择槽位并开始烘干

在“烘干与湿度”页面选择要烘干的耗材槽位。AMS 2 Pro 有 4 个槽位，可选择一个或多个。

- 使用带 RFID 的 Bambu Lab 耗材时，AMS 2 Pro 会自动根据耗材类型设置最佳烘干温度和时间。
- 对于非 Bambu 耗材或手动模式，可自定义温度（最高 65°C）和时长。

设置完成后点击 **开始** 按钮启动烘干。

![55度2.jpg](https://wiki.bambulab.com/h2/manual/screen-operation/drying.png)

AMS 2 Pro 会加热至设定温度并转动耗材卷以均匀烘干，同时利用主动排风口排出湿气。请确保底部和后部的通风口未被遮挡。

![vent_holes_in_ams_2_pro.png](https://wiki.bambulab.com/ams-2-pro/manual/using-ams-2-pro-for-drying/vent_holes_in_ams_2_pro.png)

### 步骤 6：监控烘干进度

“烘干与湿度”页面会显示实时温度与湿度数据。如果连接了多个 AMS，可通过左上角的图标切换。

|  |  |

### 步骤 7：完成烘干

当烘干时间结束后，AMS 2 Pro 会自动停止加热。请等待耗材冷却后再取出，以免变软。如果准备打印，选择对应槽位并点击 **进料** 来使用干燥后的耗材。

## 常见问题排查

- **烘干功能无法启用**：需确保 X1/P1 系列固件已更新至支持 AMS 2 Pro 烘干功能的版本。
- **提示电力不足**：X1/P1 系列无法直接为 AMS 2 Pro 提供烘干所需功率，必须使用官方电源适配器。第三方电源可能导致烘干功能无法正常工作，且造成的硬件损坏不在保修范围内。
- **耗材已进料导致无法烘干**：需先退料后再进行烘干。
- **干燥后其他耗材变形**：烘干高温耗材时需要将低温耗材取出，如烘干 ABS 时，AMS 中不能放置 PLA 耗材。
- **烘干效果不理想**：请确认耗材类型和设定参数。对于高温耗材，建议使用 [AMS HT](https://detail.tmall.com/item.htm?abbucket=11&id=902091701417&pisk=gCPqjXYQqsC2dmx5GuhwYQNz1ehxsfSCg5isSP4ilmmcBtFZQyZlkNUif5la2uDgGjab4EFzYCOfDtUM_fGGAM1COrQx6fjIQCvTRn3iSVfsomAoMV6Nuw3FOrUxXE-GR8fB7XcxwOvijlcoEq3msV0inalo52cMiAA0r0m-SfcimAYoZV3wmdvDna5oWViMoxA0rb0K7ncislclzVnoofcgjzbrWjoojDOr8xblMis0jBkr3D4m4Bz8aqXEY6nks7VooxPUu0z7P7uq3DDgKzC0iuagGSHR3KcTPJraIkjWhm2E8ukQ3MR4Yo3g7VqV9eougPPrH8tDn2lq0vV0qeQQ8A2zajNcXpU7zmDEN86RcAG40JnKnTI8bzobjSkk0gi_dzNmUkjWalHaISGuigfF4ettrPd06--MQx0-zD_Pz0uLrRh6Oe8yBdHYe4oCkZp9Bx0-zD_PzdptHb3rAZQA.&rn=745e1f2b710e094283c61e04ce917197&spm=a1z10.3-b-s.w4011-25177047232.23.31033c0eAiYPMx&skuId=5927102527211)，因为 AMS 2 Pro 最高仅支持 65°C。您也可以使用打印平台（热床）进行烘干，具体方法请参考 [耗材烘干操作指南](../../filament-acc/filament/dry-filament.md)
