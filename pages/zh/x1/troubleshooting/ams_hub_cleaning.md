## 问题现象

1. 打印丝断在AMS集线器了；

2. AMS集线器内部清洁维护。

## 操作步骤

### **情形一：断料在料管处**

这种情形，往往只需要拔掉料管即可将打印丝抽出，可以参考更换AMS集线器料管的相关视频移除对应的料管。

|  |  |
| --- | --- |
|  |  |

### 情形二：断料在AMS集线器内部

这种情况需要将拆解AMS集线器，也可以同步清洁AMS集线器，具体操作步骤如下：

#### 1. 从打印机上拆下AMS集线器

参照情形一的视频，从打印机上拆下AMS集线器，断开它与各AMS的连接线和料管。

#### 2. 拆解&清洁AMS集线器

用H1.5内六角扳手拧下3颗螺丝，然后取出选通板组件。

|  |  |
| --- | --- |
|  |  |

按压料管接头，松脱料管，如果有断的打印丝，也可以同步取出。

|  |  |
| --- | --- |
|  |  |

取下右侧处的料管接头，移除4颗螺丝，然后打开盖子，根据内部脏污的情况，进行清理。

|  |  |
| --- | --- |
|  |  |

#### 3. 组装AMS集线器

清洁干净后，重新装上料管接头，合上盖子，锁好4颗螺丝，在右侧装上料管理接头组件。

|  |  |
| --- | --- |
|  |  |

将选通器板组件装入外壳中，确认弹簧有安装到位，再接入右侧料管。

|  |  |
| --- | --- |
|  |  |

#### 4. 将AMS集线器安装到打印机

请参考情形一的视频内容，将AMS集线安装到打印机，也可参考以下连接完成安装。

- [连接AMS Hub和多台AMS](../manual/Connect-AMS-Hub-and-multi-AMS.md)
