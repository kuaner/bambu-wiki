## 报错原理

腔温加热器长时间处于满功率工作，设备检测该过程并报错提示。

## 可能的原因:

1. 机器没关门并且环境温度低，导致腔温偏低，无法达到目标温度。
2. 腔温传感器坏了,误认为腔温未达到目标温度。
3. 加热模块控制板坏了，加热器一直处于加热状态。
4. MC 控制板坏了，加热器一直处于加热状态。

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 排查流程

### 腔温传感器示数异常

空闲状态下，热床、喷嘴、腔温的温度示数通常不会有很大差异。如果腔温示数单方面存在异常，则需要排查腔温传感器。

设备的腔温传感器位于按键板上，而按键板连接在 AP 板的 4 号插座。先断电重新安装一次 4 号线缆插头，再开机观察腔温示数是否与室温相当。

![](https://wiki.bambulab.com/x1/maintenance/replace-ap-board/connectors_on_the_ap_board.jpg)

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| **序号** | **连接对象** | **序号** | **连接对象** | **序号** | **连接对象** |
| 1 | 机箱摄像头 | 4 | 按键板 | 7 | USB-C |
| 2 | 机箱LED | 5 | MC 板 (电源) |  |  |
| 3 | WIFI 天线 | 6 | MC 板(通信) |  |  |

如果腔温示数依然异常，则需要更换新的按键板，请参考[更换按键板](../../maintenance/replace-button-board.md)

### 腔温传感器示数正常

腔温传感器示数正常的情况下，该报错的故障原因就和控制板有关。我们建议优先更换新的加热模块控制板，若如果依旧则需要更换新的MC板。  
拆装工作请参考：[X1E 加热模块拆装指引](../../maintenance/x1e-heater-unit.md)、[更换 MC 板](../../maintenance/replace-mc-board.md)。
