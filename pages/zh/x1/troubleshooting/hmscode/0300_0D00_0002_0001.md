## 这是什么

由于热床归位是通过“感应喷嘴接触热床的力”来实现的，所以要使归位足够精确，有一个必要的前提条件：喷嘴尖端干净，底板表面坚硬。如果出现此错误消息，则表示不满足检测到的前提条件，这可能是由以下原因引起的：

底板表面有凸起；

喷嘴头不干净，喷嘴上粘有残留的耗材

软件错误，检测算法不够准确...

## 故障排除指南

### 第 1 步: 检查打印板表面或者热床软磁贴表面是否有鼓包

从前面打光，眼睛紧贴热床表面观察是否有鼓包：

正面打光，眼睛紧贴平台表面，观察平台表面是否有凸起：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-how-to-observe-the-bulge-on-the-build-plate.png)

|  |  |
| --- | --- |
|  |  |

最好的办法是换一块新的打印板贴膜，但如果急用的话，用刀片在凸起的表面切几刀，使其平整：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-make-kerf-on-the-bulge-surface.png)

### 第 2 步: 清洁喷嘴

清洁喷嘴（正常情况下，打印机会在开始打印时自动清洁喷头，但仍有可能喷头不够干净）：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-clean-the-nozzle-tip.png)

### 第3步：确保两颗热端固定螺丝已拧紧

![](https://wiki.bambulab.com/p1/maintenance/hotend-assembly/2_screws.jpg)

### 第 4 步: 完成上述步骤后，再次点击“home”键。

完成以上步骤后，再次点击“home”键，观察这个错误是否会自动消失。

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-%E5%B1%8F%E5%B9%95%E4%B8%8A%E7%82%B9home.png)

如果仍然显示此错误，请联系客户支持团队。
