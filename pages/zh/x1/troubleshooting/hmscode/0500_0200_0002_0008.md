# 故障现象

当设备无法通过网络访问时间同步服务，设备将无法刷新二维码或屏幕显示“时间同步失败”的错误。该现象通常是由网络条件不佳所致。

# 故障排除

以下故障排除流程和步骤旨在隔离问题的根本原因，并引导您逐步解决问题。

## 工具、设备及材料

- Windows电脑
- 路由器，适用于X1系列打印机（除X1E）

## 排故措施

***用户可视情调整各排故措施的顺序。***

- **切换手机热点或路由器，然后重启打印机**

  1. 连接手机2.4G热点；  
     ![personalhotspot](https://wiki.bambulab.com/x1/troubleshooting/hmscode/ap-assets/personalhotspot.png)  
     ![connect2.4g](https://wiki.bambulab.com/x1/troubleshooting/hmscode/ap-assets/connect2.4g.png)
  2. 或更换路由器；
  3. 断电重启打印机。
- **NTP服务连接测试**

  1. 点击Windows电脑左下角“开始”图标，并搜索“CMD”，按Enter键进入；
  2. 执行命令"w32tm /stripchart /computer:***NTP服务域名*** /dataonly /samples:5"，可选域名如下：

  | NTP服务域名 |
  | --- |
  | [pool.ntp.org](http://pool.ntp.org) |
  | [0.pool.ntp.org](http://0.pool.ntp.org) |
  | [1.pool.ntp.org](http://1.pool.ntp.org) |
  | [2.pool.ntp.org](http://2.pool.ntp.org) |
  | [3.pool.ntp.org](http://3.pool.ntp.org) |

  3. 如果出现时间同步延迟数值，代表连接成功，否则您将在CMD中看到错误提示。
- **更改DNS**

  1. 针对X1E，请参考[X1E网络连接指南](../../manual/x1e-network-connection-guide.md)；
  2. 针对X1、X1C，请准备一个路由器，并将路由器DNS服务修改成下表；
  3. 连接打印机与路由器。

  | 地区 | NTP服务 | 主DNS | 次DNS |
  | --- | --- | --- | --- |
  | 国际 | Google | 8.8.8.8 | 8.8.4.4 |
  | 国际 | Control D | 76.76.2.0 | 76.76.10.0 |
  | 国际 | Quad9 | 9.9.9.9 | 149.112.112.112 |
  | 国际 | OpenDNS Home | 208.67.222.222 | 208.67.220.220 |
  | 国际 | Cloudflare | 1.1.1.1 | 1.0.0.1 |
  | 国际 | AdGuard DNS | 94.140.14.14 | 94.140.15.15 |
  | 国际 | CleanBrowsing | 185.228.168.9 | 185.228.169.9 |
  | 中国大陆 | 114 | 114.114.114.114 | 114.114.114.115 |
  | 中国大陆 | Ali DNS | 223.5.5.5 | 223.5.5.6 |
