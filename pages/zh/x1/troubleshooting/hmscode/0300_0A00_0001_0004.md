## 这是什么

### X/P系列打印机

在进行施加于热床上的力测试之前，打印机会通过上下振动温床来测试每个力传感器的敏感度。

如果有任何物体接触到热床，打印机将会获得错误的敏感度参数，导致后续程序无法正常工作。

以下是打印机认为可能导致外部干扰的原因：

1. 打印板未正确放置。
2. 打印机放置在不稳定的平台上，例如软垫或晃动的桌子。
3. 工作台上有异物卡住了Z轴电机或Z轴同步带轮。
4. 当热床靠近腔室底部时，Z轴滑块被底部的异物卡住。
5. Z轴滑块上有异物，或者Z线性轴承凸起
6. 热床受到废料滑梯的干涉，或者打印板受到打印机内衬的干涉。
7. 热床线缆过紧，干扰了热床的运动。
8. 安装 AMS-HUB 时使用了错误规格的螺丝。
9. Z 轴滑块装配公差异常。
10. 压力传感器或其信号链路异常，导致处理器接受不到压力传感器的数据。

请注意，以上仅列举了一些可能的原因，实际情况可能还存在其他因素导致该错误。  
![](https://wiki.bambulab.com/x1/maintenance/heatbed-force-sensor/sensor_positions.jpg)

### A1 打印机

在对Y轴进行共振频率补偿之前，打印机通过振动热床来测试热床加速度传感器的灵敏度。如果有任何东西触及热床或者传感器本身受到来自热床以外的力，打印机将得到错误的灵敏度参数，导致后续程序无法正常工作。

可能的原因:

1. 热床在振动过程中被卡住或与外界发生摩擦，例如热床底壳与Y轴保护上盖发生摩擦，或者与底座塑料壳发生摩擦；

2. 打印机放置在不稳定的平台上(如软垫、晃动的桌子)；

3. 传感器信号线的屏蔽线已发生损毁导致严重的外界信号干扰；

4. 热床加速度传感器的信号线脱落，导致振动过程中信号线不不断拉扯传感器导致错误的信号传入；

5. 传感器信号线接头松动或者故障；

## X/P系列打印机故障排除指南

### 第 1 步：确保打印板正确放置

详情请参考：[HMS\_0300-0D00-0001-0003: 打印板可能未放好。](0300_0D00_0001_0003.md)

### 第 2 步：确保打印机放置在稳定的平台上（如刚性桌子、地板），确保环境没有高频振动（比如有人在附近敲钉子），并检查打印机底座是否有异物

稍微抬起打印机前端，检查是否有任何东西会粘住Z轴同步带。 注意橡胶脚垫是贴在打印机底部的，如果用力推打印机，脚垫可能会被推开卡在Z轴同步带上（红框处和它对应的台面）：

同时检查是否有东西粘住Z电机和同步带轮（如下图红框处）：

### **第 3 步：清洁打印机箱底部，确保打印机底部没有异物。**

清洁打印机底部。如果加热床向下移动并与底部的异物碰撞，归位过程可能会中断：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-hotbed-touched-hotbed-bottom-surface.png)

图示异物会影响打印机的行程造成报错

### 第 4 步：清洁Z轴滑块表面，确保Z轴滑块表面没有异物。

请检查Z轴滑块的表面是否有任何异物，特别是位于内衬后面的滑块。

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-check-z-axis-slider-top-surface-1.jpg)

除了检查滑块表面的异物外，在这一步，您还需要检查滑块上的Z轴轴承套是否凸起。

如果您发现轴承套有凸起现象，请参考下方的操作视频对轴承套进行复位。需要注意的是，在按照视频进行操作之前，请先拆下工具头的热端组件([点击此处查看拆解热端组件的指南](../../maintenance/replace-hotend.md))，然后再执行视频中的操作。

如果在这个过程中，你遇到任何困难，请联系售后寻求帮助。

这个操作的目的是使用固定块将凸起的轴承按压回原位：

<https://public-cdn.bblmw.com/wiki/X1/fix_bearing_up.mp4>

轴承凸起通常是由于线性光轴底部的三个孔中存在异物，例如废料，导致轴承受到挤压而凸出。如果这些孔中有任何异物，请确保彻底清理干净，否则故障可能会再次发生。

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-clean-the-chamber-botton-holes.png)

### 第 5 步：检查热床是否受到废料滑梯的干涉或者打印板是否离打印机内衬太近

检查热床与废料滑梯之间是否有明显的干涉。

| --- | --- |
|  |  |

如果您发现废料滑梯存在干扰，请点击查看此wiki页面，获取解决方案：[Z轴回中失败—组件干涉](../homing-z-axis-failed_part-unit-interference.md)

同时，请检查打印板的后缘，确保其与打印机内衬之间保持足够的距离。

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-hotbed-touched-inner-liner.png)

### **第 6 步：检查**热床线缆被拉紧，从而干涉热床的运动

慢慢抬升热床，直到它几乎接近喷嘴，然后从腔室朝内部观察，检查Z轴丝杠旁边的热床电缆是否被过紧。如果电缆的形状与下图最左边的情况相似，则可能被过紧：

请您将手指伸入缝隙中，将线缆从电壳内部拉出，如下图所示。请注意：线缆边缘可能会有些锋利，请小心操作或戴上手套：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-how_to_loose_the_hotbed_cable.png)

如果热床线缆被拉紧，请点击此wiki页面，获取解决方案：[Z轴回中失败错误—热床线缆被拉紧](../homing-Z-axis-failed_cable-tensioned.md)

### 第 7 步：检查打印机背面的AMS hub或缓冲器

如果你安装了AMS HUB或缓冲器，如果螺丝拧得太紧，也可能在床靠近喷嘴时卡住z轴，所以试着松开这两个螺丝1~2圈：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-loose_ams_buffer_screws.png)

### 第 8 步：重新调整Z轴滑块

钢棒可能在暴力运输下移动，所以需要重新调整z轴滑块，见下图：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-z-stuck-diagnosis-2.png)

#### 8.3 松开两个螺丝，然后重新拧紧

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-z-stuck-diagnosis-3.png)

#### 8.4 松开两个螺丝，然后重新拧紧

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-z-stuck-diagnosis-4.png)

#### 8.5 松开这两个螺丝，然后重新拧紧它们

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-z-stuck-diagnosis-5.png)

### 第 9 步：完成上述步骤后，再次点击“home”键。

完成以上步骤后，再次点击“home”键，观察XYZ的归位过程，检查喷嘴是否能正常接触到热床表面。 如果归位成功，那么这个错误会自动消失。

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-%E5%B1%8F%E5%B9%95%E4%B8%8A%E7%82%B9home.png)

如果仍然显示此错误，请联系客户支持团队。

## A1 打印机故障排查指南

1. 请确保热床在振动过程中未被异物卡住或者发生摩擦；
2. 确保打印机放置在一个稳定的表面，不会有异常的晃动；
3. 取下打印板，并移除螺丝孔的硅胶保护盖，暴露出螺丝孔并卸下螺丝。

|  |  |
| --- | --- |
|  |  |

4. 翻转热床，暴露出热床底部结构即可看到热床加速度传感器，检查传感器是否有明显松动或者损坏。

|  |  |
| --- | --- |
|  |  |

5. 若传感器没有松动，很有可能已损坏，请参考这篇wiki更换传感器：[A1 热床拆装指引 | Bambu Lab Wiki](../../../a1/maintenance/heatbed.md)
