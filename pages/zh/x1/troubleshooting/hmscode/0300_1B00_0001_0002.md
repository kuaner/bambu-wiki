# 故障现象

A1打印机使用加速度传感器探测热床沿Y方向上运动。传感器的信号线用胶水固定于热床底部支架。当传感器信号线从热床底部支架脱落时，信号线随热床运动会干扰加速度传感器，触发告警。

# 故障排除

## A1 打印机

1.取下打印板，并移除螺丝孔的硅胶保护盖，暴露出螺丝孔并卸下螺丝；

|  |  |
| --- | --- |
|  |  |

2.翻转热床面，暴露出热床底部结构即可看到热床加速度传感器。检查传感器信号线是否固定于热床底部支架。

|  |  |
| --- | --- |
|  |  |

3.若信号线脱落，请使用胶水固定，待胶水凝固后使用。

# 错误信息

HMS\_0300-1B00-0001-0002: 热床加速度传感器检测到外部干扰，可能传感器信号线未固定。
