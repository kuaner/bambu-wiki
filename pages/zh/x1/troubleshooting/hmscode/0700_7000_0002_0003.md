# 故障现象

喷嘴处耗材挤出异常，可能挤出机和喷嘴发生堵塞。

|  |  |
| --- | --- |
|  |  |

若可以从工具头上方观察到料线，但是喷嘴处挤出异常，可能的故障原因有如下：

- 挤出机堵塞
- 喷嘴堵塞
