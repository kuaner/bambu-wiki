## 故障描述

使用 AMS 时，缓冲器（或 AMS 集线器）会连接在 AMS 和打印机之间。

它由一个滑块、一个弹簧和一个霍尔传感器组成。当 AMS 将耗材推入工具头挤出机时，由于耗材的压力，滑块将向前移动。然后，入口处第一个霍尔传感器检测耗材是否进入缓冲器，第二个滑块上方的霍尔传感器可以检测载滑块的位移和位置，并将该信号反馈回 AMS 和打印机。如果缓冲信号丢失，AMS 将无法顺利送入耗材。

## 故障排除

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。  
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

### 步骤 1：检查连接

检查线缆是否和 AMS 、缓冲器接触良好，用手是否很容易就拔出来，正常状态需要按下卡扣才能拔出。

|  |  |

建议使用二代 AMS 配套线缆，区别如下:

![](https://wiki.bambulab.com//h2/troubleshooting/hmscode/0700_4000_0002_0001/image-8.png)

### 步骤 2：检查线缆

请检查 pin 线缆的引脚是否张开（如下图 4-pin 所示），如果张开则需要更换新的线缆。

![](https://wiki.bambulab.com//h2/troubleshooting/hmscode/0700_4000_0002_0001/image.png)

若正常，则重新连接 6-pin 和4-pin 线缆。

![](https://wiki.bambulab.com/x1/manual/pack-x1cc/remove-6pin2.png)

### 步骤 3：检查 AMS 内部连接

如果问题仍然存在，请参考以下步骤检查 AMS 信号连接线是否松动：

打开AMS上盖，按压AMS 五通组件上的按钮（解锁快速接头），然后从AMS背面拉出PTFE管。

|  |  |
| --- | --- |
|  |  |

移除固定AMS主框架上2颗螺丝。

![](https://wiki.bambulab.com/x1/maintenance/replace-first-stage-feeder/611px-remove_2_screw.png)

向上翻转中间框架组件，断开bambu总线电缆和电源电缆，移除AMS主框架组件。

|  |  |
| --- | --- |
|  |  |

检查标记插头是否松动，重新安装后复原 AMS，并开机观察报错是否消失。  
![image3.png](https://wiki.bambulab.com/x1/troubleshooting/hmscode/0700_4000_0002_0003/image3.png)

如果故障依旧，请将设备的日志文件上传给我们技术团队。
