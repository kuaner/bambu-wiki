## 这是什么

### X/P 系列打印机

在测试施加在热床上的力之前，打印机会测量每个压力传感器的灵敏度，测量后，打印机会检查灵敏度是否正常，如果不正常，则会出现此错误消息。

以下是可能导致压力传感器灵敏度低的可能原因：

1.连接热床和热床框架的螺丝拧得太紧；

2.热床与热床架之间有东西卡住；

3.压力传感器与应力臂分离；

### A1 打印机

在对Y轴进行共振频率补偿之前,打印机会测量热床加速度传感器的灵敏度，测量后，打印机会检查灵敏度是否正常,如果不正常，则会出现此错误消息。

可能的原因:

1. 热床加速度传感器本身受到损坏而失效；

2.传感器已从热床支架上脱落或者出现松动；

3.热床本身被异物卡住而无法移动或移动量很小；

4.传感器信号线的屏蔽线已发生损毁导致严重的外界信号干扰。

## 开始操作前的安全警告和机器状态

确认热床已经冷却**，电源插头的地线是否真正接地。**

## 故障排除指南

### X/P系列打印机

#### 第1步

检查加热床预紧螺钉和螺母，是否拧得过紧。通常，螺钉在螺母中的深度如下图中间所示：

![](https://wiki.bambulab.com/x1/manual/bed-leveling/screw_tension.jpg)

### 第2步

检查Z轴滑块附近热床与热床框之间的缝隙，看里面有没有东西卡住：

### 第3步

在第1步和第2步之后，重试“回零”功能，看看在完成回零后这个错误信息是否会消失。

如果不消失，则压力传感器可能与应变片分离。那么需要更换压力传感器，请参考[更换热床力传感器](https://wiki.bambulab.com/x1/maintenance/replace-the-heatbed-force-sensor)

### A1 打印机

1. 先断电并拔掉电源线；

2. 先检查热床导轨是否有异物导致热床被卡住无法正常移动；

3. 如果热床未被卡住，取下打印板，并移除螺丝孔的硅胶保护盖,暴露出螺丝孔并卸下螺丝；

|  |  |
| --- | --- |
|  |  |

4. 翻转整个热床，暴露出热床底部结构即可看到热床加速度传感器。

![](https://wiki.bambulab.com/a1/maintenance/heatbed/remove_the_heatbed.jpg)

5. 先检查加速度传感器是否有松动。如果有，先重新连接传感器并将其固定住；

![](https://wiki.bambulab.com/a1/maintenance/heatbed/clear_glue.jpg)

6. 如果没有松动，则很有可能是传感器故障了，请参考这篇wiki更换新的传感器：[A1 热床拆装指引 | Bambu Lab Wiki](../../../a1/maintenance/heatbed.md)
