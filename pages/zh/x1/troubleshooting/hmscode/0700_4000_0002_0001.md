## 这是什么

HMS\_0700\_4000\_0002\_0001：料线缓冲信号丢失，电缆或信号传感器可能出现故障。  
使用 AMS 时，缓冲器（或 AMS 集线器）连接在 AMS 和打印机之间。

它有一个滑块、一个弹簧和一个霍尔传感器。当 AMS 将长丝推入工具头挤出机时，由于长丝的压力，滑块将向前移动。然后，霍尔传感器可以检测载滑块的位移和位置，并将该信号反馈回 AMS 和打印机。如果缓冲信号丢失，AMS 将无法顺利送入料线。

![](https://wiki.bambulab.com/x1/manual/intro-ams/filament-buffer.png)
![](https://wiki.bambulab.com/x1/manual/intro-ams/ams-connection.jpg)

## 操作指南

### 检查并重新连接 6 针电缆

通常这是6P 电缆问题，请检查6P 电缆的引脚是否打开：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/0700_4000_0002_0001/6pin-openv1-cn.png)

并尝试重新连接 6 针电缆：

![](https://wiki.bambulab.com/x1/manual/connect-ams/step-4-connect-to-first-port-on-ams.png)
![](https://wiki.bambulab.com/x1/manual/connect-ams/step-4-connect-to-leftside-of-filament-buffer.png)

### 检查 AMS 内部连接

如果问题仍然存在，请检查 AMS 内部的总线（BUS）电缆是否松动：

![](https://wiki.bambulab.com/ams_buffer_signal_lost/bus_inside_ams.png)

建议重新插入总线电缆并尝试再次加载料线，看看是否可以恢复，以便我们可以将故障缩小到总线电缆。

### 测量电压和电阻

1.如果您有万用表，请将料线卸载回 AMS，并检查 AMS 缓冲器的滑块是否在左侧，如下所示：

![](https://wiki.bambulab.com/ams_buffer_signal_lost/buffer.png)

然后**测量 6 针电缆（**从 AMS 上拔下）引脚之间的电压。

![](https://wiki.bambulab.com/ams_buffer_signal_lost/ams_buffer.drawio.svg)
![](https://wiki.bambulab.com/ams_buffer_signal_lost/%E6%B5%8B%E7%BC%93%E5%86%B2%E5%8C%BA%E7%94%B5%E5%8E%8B.png)

正常电压应如下。**确保缓冲滑块回到左侧，否则电压值会有所不同。**

|  |  |
| --- | --- |
| **pin-pin** | **Voltage** |
| GND-Buffe\_A | 0.5~1.0V |
| GND-Buffe\_B | 2.8~2.3V |

**两个电压之和为3.0~3.3V（可以滑动滑块，测量不同位置电压，相加在这个范围内）。**

2.如果上一步中测量的电压在正常范围内，则问题可能出在 AMS 侧。请测量 6 针电缆（插入  AMS）的电阻。

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/0700_4000_0002_0001/ams.png)

正常电阻值如下：

|  |  |
| --- | --- |
| **pin-pin** | **Resistance** |
| GND-Buffe\_A | 4~6 KΩ |
| GND-Buffe\_B | 4~6 KΩ |

如果测得的电阻值异常，请拆卸 AMS 并测量 AMS 主板上缓冲器 A 和 B 对 GND 的电阻。**正常范围为4~6KΩ。**如果电阻值异常，则 AMS 主板有故障。

![](https://wiki.bambulab.com/ams_buffer_signal_lost/测量主板电阻.png)

然后检查 AMS 主板上的缓冲区 A 和缓冲区 B 与 6 针电缆（插入 AMS）上相应引脚的连通性。**如果连通性异常，则 AMS 电源板有问题，需要更换。**

![](https://wiki.bambulab.com/ams_buffer_signal_lost/ams电源板和6pin线连通性.png)

请按照上述步骤进行测试，记录测试结果，并联系客户支持团队以获得进一步的帮助。

### 检查 AMS 缓冲器内部磁铁是否装反

若在拆装 AMS 缓冲器时**错误**地把这（如下左图）四颗螺丝拆下来，以致（如下右图）内部的**磁铁**掉落。请注意，磁铁安装时的**南北极方向**需要按照如下右图的方向进行安装。

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/s_n3.png)

下图中标记为红色的一面表示北极（N），请根据该标记安装磁铁。

![](https://wiki.bambulab.com/ams/filament-buffer-connection-board/北极.jpg)
