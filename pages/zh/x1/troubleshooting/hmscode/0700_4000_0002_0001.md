## 这是什么

HMS\_0700\_4000\_0002\_0001：料线缓冲信号丢失，电缆或信号传感器可能出现故障。  
使用 AMS 时，缓冲器（或 AMS 集线器）连接在 AMS 和打印机之间。

它有一个滑块、一个弹簧和一个霍尔传感器。当 AMS 将长丝推入工具头挤出机时，由于长丝的压力，滑块将向前移动。然后，霍尔传感器可以检测载滑块的位移和位置，并将该信号反馈回 AMS 和打印机。如果缓冲信号丢失，AMS 将无法顺利送入料线。

![](https://wiki.bambulab.com/x1/manual/intro-ams/ams-connection.jpg)

## 操作指南

### 检查并重新连接 6 针电缆

通常这是6P 电缆问题，请检查6P 电缆的引脚是否打开：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/0700_4000_0002_0001/6pin-openv1-cn.png)

并尝试重新连接 6 针电缆：

![](https://wiki.bambulab.com/x1/manual/connect-ams/step-4-connect-to-first-port-on-ams.png)

![](https://wiki.bambulab.com/x1/manual/connect-ams/step-4-connect-to-leftside-of-filament-buffer.png)

### 测量电压和电阻

1. 如果您有万用表，请将耗材卸载回 AMS，并检查缓冲器的滑块是否位于最左侧，如下所示：

![](https://wiki.bambulab.com/ams_buffer_signal_lost/buffer.png)

然后测量 6 针电缆（从 AMS 上拔下）引脚之间的电压。

|  |  |
| --- | --- |
|  |  |

正常电压应如下。**确保缓冲滑块回到左侧，否则电压值会有所不同。**

|  |  |
| --- | --- |
| pin-pin | 电压 |
| GND-Buffe\_A | 0.5~1.0V |
| GND-Buffe\_B | 2.8~2.3V |

**两个电压之和为3.0~3.3V（可以滑动滑块，测量不同位置电压，相加在这个范围内）。**

2. 如果测量的电压在正常范围内，则问题可能出在 AMS，请根据机型选择测量方法。

- AMS
- AMS 2 Pro
- AMS HT
