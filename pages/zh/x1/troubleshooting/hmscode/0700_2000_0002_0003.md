## 故障描述

AMS 的每个耗材插槽都有两个传感器来检测耗材的位置，一个传感器在上下料组件，另一个在五通组件的电路板上，如下图所示：

|  |  |
| --- | --- |
|  |  |
| 上下料组件的传感器 | 五通组件的传感器 |

一些较脆的耗材可能会在 AMS 内部断裂，这通常会导致五通组件的传感器处于“开启”状态，上下料组件传感器处于“关闭”状态，AMS 会弹出报错消息“......料线可能断裂在 AMS 中“，同时，该料槽的指示灯也会变红。

## 所需工具和材料

- H2.0 内六角扳手（用于 AMS 的排查步骤）
- 一小段耗材（长度大于 250 mm）

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 排查步骤

### AMS

请参考下方视频清理 AMS 内部断裂的耗材：

如果耗材在五通组件内部断裂，则需要拆卸、检查和清洁五通组件，请参考这篇 wiki 指南：[拆解和清洁AMS五通组件](../clean-the-filaments-hub.md)。

### AMS 2 Pro

#### 步骤 1. 拆卸料管

首先取出 AMS 2 Pro 内放置的耗材，然后在五通组件处，用一只手指按住气动接头黑色垫圈，另一只手拔出料管。

![hands_removing_tubes.png](https://wiki.bambulab.com/ams-2-pro/maintenance/broken-material/hands_removing_tubes.png)

#### 步骤 2. 清理料管内部

另取一段耗材，将其从 AMS 2 Pro 入料口插入，并从料管另一端穿出，将内部断裂的耗材顶出料管。操作时请保持动作轻柔，避免耗材在内部再次断裂。

|  |  |
| --- | --- |
|  |  |

#### 步骤 3. 安装料管

清理完成后，将料管插回原来的插槽。

![removing_the_tubes.png](https://wiki.bambulab.com/ams-2-pro/maintenance/broken-material/removing_the_tubes.png)

如果耗材在五通组件内部断裂，则需要拆卸、检查和清洁五通组件，请参考这篇 wiki 指南：[拆解和清洁 AMS 2 Pro 五通组件](../../../ams-2-pro/troubleshooting/clean-the-filaments-hub.md)。
