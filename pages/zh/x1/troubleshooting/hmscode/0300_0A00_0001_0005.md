## 这是什么

### X/P系列打印机

当热床静止且未施加力时，压力传感器的电压信号应该为0V。如果电压不为0，则表示压力传感器检测到异常持续外力。在测试中，我们遇到了以下可能的故障原因：

1. 工作台上有异物卡住Z轴电机或Z轴同步带轮。

2. Z轴滑块上有异物，或者Z线性轴承凸起。当热床向上移动时，这些异物会卡在Z轴滑块和Z轴固定块之间，导致喷嘴无法接触热床。

3. 当热床靠近腔室底部时，Z轴滑块被底部的异物卡住。

4. 热床受到废料滑梯的干涉。

5. 热床线缆被拉扯，干扰了热床的运动。

6. 安装AMS-HUB时使用了错误规格的螺丝。

7. Z轴滑块装配公差异常。

8. 压力传感器异常，导致机器无法检测到喷嘴与热床的接触，直到Z轴电机检测到高负载并停止。

9. 打印机放置在不稳定的平台上，例如软垫或晃动的桌子。

请注意，以上仅列举了一些可能的原因，实际情况可能还有其他因素导致该错误。

### A1 打印机

当热床不动时，热床加速度传感器的电压信号应为0V。如果电压不为0，则说明有问题。可能的原因:

1. 热床加速度传感器本身被异物顶住;

2. 传感器电极短路

## X/P系列打印机故障排除指南

### 第 1 步：**清洁**Z轴滑块表面\*\*，确保**Z轴滑块表面**没有异物。\*\*

请检查Z轴滑块的表面是否有任何异物，特别是位于内衬后面的滑块。

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-check-z-axis-slider-top-surface-1.jpg)

除了检查滑块表面的异物外，在这一步，您还需要检查滑块上的Z轴轴承套是否凸起。

如果您发现轴承套有凸起现象，请参考下方的操作视频对轴承套进行复位。需要注意的是，在按照视频进行操作之前，请先拆下工具头的热端组件([点击此处查看拆解热端组件的指南](../../maintenance/replace-hotend.md))，然后再执行视频中的操作。

如果在这个过程中，你遇到任何困难，请联系售后寻求帮助。

这个操作的目的是使用固定块将凸起的轴承按压回原位：

<https://public-cdn.bblmw.com/wiki/X1/fix_bearing_up.mp4>

轴承凸起通常是由于线性光轴底部的三个孔中存在异物，例如废料，导致轴承受到挤压而凸出。如果这些孔中有任何异物，请确保彻底清理干净，否则故障可能会再次发生。

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-clean-the-chamber-botton-holes.png)

### 第 2 步 ：检查热床是否受到废料滑梯的干涉或者打印板是否离打印机内衬太近

检查热床与废料滑梯之间是否有明显地干涉。

|  |  |
| --- | --- |
|  |  |

如果您发现废料滑梯存在干扰，请点击查看此wiki页面，获取解决方案：[Z轴回中失败—组件干涉](../homing-z-axis-failed_part-unit-interference.md)

同时，请检查打印板的后缘，确保其与打印机内衬之间保持足够的距离。

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-hotbed-touched-inner-liner.png)

### 第 4 步： 检查打印机底座是否有异物

稍微抬起打印机前端，检查是否有任何东西会粘住Z轴同步带。 注意橡胶脚垫是贴在打印机底部的，如果用力推打印机，脚垫可能会被推开卡在Z轴同步带上（红框处和它对应的台面）：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-check-bottom-near-timing-belt-wheel.jpg)

### **第 5 步：检查Z电机和同步带轮是否有异物粘住**

稍微抬起打印机后部，检查是否有东西粘住Z电机和同步带轮（如下图红框处）：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-check-bottom-rear-timing-belt-wheel.jpg)

### **第6 步：检查**热床线缆被拉紧，从而干涉热床的运动

慢慢抬升热床，直到它几乎接近喷嘴，然后从腔室朝内部观察，检查Z轴丝杠旁边的热床电缆是否被过紧。如果电缆的形状与下图最左边的情况相似，则可能被过紧：

请您将手指伸入缝隙中，将线缆从电壳内部拉出，如下图所示。请注意：线缆边缘可能会有些锋利，请小心操作或戴上手套：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-how_to_loose_the_hotbed_cable.png)

如果热床线缆被拉紧，请点击此wiki页面，获取解决方案：[Z轴回中失败错误—热床线缆被拉紧](../homing-Z-axis-failed_cable-tensioned.md)

### 第 7 步：检查打印机背面的AMS hub或缓冲器

如果你安装了AMS HUB或缓冲器，如果螺丝拧得太紧，也可能在床靠近喷嘴时卡住z轴，所以试着松开这两个螺丝1~2圈：

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-loose_ams_buffer_screws.png)

### 第 8 步: 检查打印机底部平台。

在打印机底部放置松软的垫子、或者打印机放置的平台不牢固都有可能导致热床压力传感器的测量值异常。您可尝试移除软垫或将打印机放置于平坦的牢固平台上（如地面）进行测试。

### 第 9 步: 完成上述步骤后，再次点击“home”键。

完成以上步骤后，再次点击“home”键，观察XYZ的归位过程，检查喷嘴是否能正常接触到热床表面。 如果归位成功，那么这个错误会自动消失。

![](https://wiki.bambulab.com/x1/troubleshooting/hmscode/mc-assets/500px-%E5%B1%8F%E5%B9%95%E4%B8%8A%E7%82%B9home.png)

如果仍然显示此错误，请联系客户支持团队。

## A1 打印机故障排查指南

1. 请确保热床在移动过程中未被异物卡住或者发生摩擦；

2. 取下打印板，并移除螺丝孔的硅胶保护盖,暴露出螺丝孔并卸下螺丝；

|  |  |
| --- | --- |
|  |  |

3. 翻转热床面，暴露出热床底部结构即可看到热床加速度传感器，检查传感器是否有被异物顶住，如果有请将其清理。

![](https://wiki.bambulab.com/a1/maintenance/heatbed/remove_the_heatbed.jpg)

![](https://wiki.bambulab.com/a1/maintenance/heatbed/buckle.jpg)

4. 若没有异物干扰，很有可能传感器已损坏，需要更换热床压力传感器，具体更换步骤请参考wiki：[A1 热床拆装指引 | Bambu Lab Wiki](../../../a1/maintenance/heatbed.md)
