## 这是什么

可能发生炒面缺陷  
当启用炒面检测功能时（只能与机箱摄像头配合使用），智能分析系统会实时分析视频流，并在检测到炒面故障风险时通知用户。出现此条报告意味着AI认为可能存在炒面故障，但严重程度不足以暂停打印。您可能想亲自检查打印质量，因为AI可能会出现错误。

**注意**：强烈建议在炒面检测开启时不要关闭机箱的灯。此功能需要良好的光照条件才能工作。

## 故障排除指南

### 步骤一：检查打印质量并决定是否停止打印。

|  |  |
| --- | --- |
|  |  |
| 检测到真正的炒面故障，用户可以停止打印或清理炒面  如果一盘中只有部分物件炒面、可尝试[零件跳过](../../../general/skipping-objects.md)功能。 | 由填充图案引起的错误警报，用户可以忽略它 |

### 步骤二：如您需要零件跳过

如果一盘中只有部分物件炒面，可尝试“零件跳过”功能。使用时推荐您先清理盘中炒面的物件再继续打印，避免炒面物件影响其他物品。

您可从以下入口进入零件跳过功能。如有需要，可查看[**零件跳过Wiki**](../../../general/skipping-objects.md)

|  |  |
| --- | --- |
| **APP零件跳过入口** | **X1C机型可选择用屏幕启用该功能** |
|  |  |
