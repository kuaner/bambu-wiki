#### 故障现象

如果您的打印机有以下问题，可能与USB线连接有关。

1. 工具头失控，加热热端失败，对移动命令无响应，风扇和LED灯打开失败。
2. 不执行打印项目。
3. Z轴回中失败。
4. 激光雷达关联报错。

#### 造成原因

1. USB-C线缆移动导致老化。
2. 接触不良。

#### 解决方案

1. 检查USB-C线缆每一端的连接情况，如果是接触不良则重新连接。
2. 上传日志文件并与客服团队联系。
3. 更换USB-C线缆。

### 如何检查USB-C连接

#### 检查核心PCB上的USB端口

1. 打开线缆盖

![](https://wiki.bambulab.com/x1/troubleshooting/usbc-cable-connection-issue/432px-cover2.png)

2. 检查USB线的连接，如果发现连接线松动，尝试重新连接。

![](https://wiki.bambulab.com/x1/troubleshooting/usbc-cable-connection-issue/400px-connect1.png)

#### 工具头处的USB端口

1.移除工具头背部盖板上的四颗螺丝。

|  |  |
| --- | --- |
|  |  |

2. 打开工具头后盖

![](https://wiki.bambulab.com/x1/troubleshooting/usbc-cable-connection-issue/415px-back_cover3.png)

3. 检查USB线缆连接，如发现USB线缆松动，请重新连接USB线缆。

![](https://wiki.bambulab.com/x1/troubleshooting/usbc-cable-connection-issue/con2.png)
