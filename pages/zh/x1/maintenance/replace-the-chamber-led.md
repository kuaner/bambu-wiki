## 什么是机箱 LED 灯条

机箱 LED 灯条是安装在机箱左侧横梁上，用于给机箱补光的 LED 灯条，我们提供的是带连接线的 LED 灯条。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-chamber-led/led_bar.jpg)

## 何时更换

- LED 灯烧坏
- LED 灯电缆损坏、短路

## 所需的工具和材料

- 新的机箱 LED 灯
- H2.0 内六角扳手
- 镊子
- 电吹风
- 硅胶胶水

![](https://wiki.bambulab.com/x1/maintenance/replace-the-chamber-led/silicone_glue.jpg)

## 开始操作前的安全警告和机器状态

在开始本指南中的过程之前，请确保机器已关闭

## 拆卸指南

### 步骤 1 - 关闭电源

关闭打印机电源，拔下电源线，并取下顶部玻璃盖板。

### 步骤 2 - 打开 AP 主板盖

揭开位于机器左上方的 AP 主板盖，如下图所示。

|  |  |
| --- | --- |
|  |  |

### 步骤 3 - 断开连接线

用电吹风适当加热连接器上的硅胶，减轻粘接力，然后断开 LED 灯和按键板连接。

|  |  |
| --- | --- |
|  |  |

### 步骤 4 - 松脱摄像头

推动摄像头，将摄像头从横梁上松脱出来，以方便 LED 灯条的拆除和安装。

|  |  |
| --- | --- |
|  |  |

### 步骤 5 - 移除 LED 灯条

先确认 LED 末端有没有加固黑胶，如有，需手动清理。然后按图中箭头方向推动 LED 灯条，将 LED 灯条松脱出来，然后断开其上的电缆连接，先将灯条移除，保留电缆在原位。

|  |  |
| --- | --- |
|  |  |

### 步骤 6 - 松开 AP 主板

用 H2.0 内六角扳手拧下 5 颗螺丝，将 AP 主板从横梁上松脱出来。

|  |  |
| --- | --- |
|  |  |

### 步骤 7 - 释放 LED 电缆

将旧的 LED 电缆从夹缝中释放出来，因为可能卡得比较紧，可能需要稍稍用力扯出。

|  |  |
| --- | --- |
|  |  |

## 安装指南

### 步骤 1 - 穿新 LED 电缆

将新旧电缆的连接器用胶带连接起来，注意前端位置要贴紧，尽可能拧细些，然后用旧电缆将新 LED 的电缆引导过穿线孔。注意穿线时，不要用力过猛和过快，避免损伤新的电缆，另外，电线应从侧面板和光杆（皮带）之间穿过。然后去除胶带和旧电缆。

|  |  |
| --- | --- |
|  |  |

### 步骤 2 -安装 LED 灯条

对齐 LED 灯座底下的扣爪和横梁上的安装孔，然后按箭头方向推动 LED 灯条将其安装到位。然后将 LED 电缆尽可能塞进夹缝中，但不可损坏电缆，也可以用胶布贴紧在左侧板上。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 3 - 安装摄像头

将摄像头放置到下图所示位置上，对齐安装孔，然后按箭头方向推动摄像头，将其安装到位，同时将电缆压入线槽内。

|  |  |
| --- | --- |
|  |  |

### 步骤 4 - 安装 AP 主板

根据限位槽将 AP 主板装回原位，注意 LED 灯电缆要从 FPC 排线下方穿出，锁入5颗螺丝进行固定 AP 主板和 USB 线扣。检查各连接器，确认连接状态正常。

|  |  |
| --- | --- |
|  |  |

### 步骤 5 - 连接电缆

将按键板电缆和 LED 电缆连接到对应的连接器上，建议点上硅胶胶水对连接器进行加固。

|  |  |
| --- | --- |
|  |  |

### 步骤 6 - 合上 AP 主板盖

将 AP 保护盖压回原位，最后盖上玻璃顶盖。

![](https://wiki.bambulab.com/x1/maintenance/replace-ap-board/350px-cover3.png)

## 如何验证完成/成功

连接电源线并打开电源。

1. 在如下所示主页面中，点击灯光图标，确认能正常控制机箱 LED 灯的开启和关闭。

![照明.png](https://wiki.bambulab.com/%E7%85%A7%E6%98%8E.png)

2. 如下所示运行设备自检操作，如果没有出现错误，则更换成功。

![selftest.png](https://wiki.bambulab.com/screen-operation/selftest.png)

否则，请检查所有连接，然后重试。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助

### 其他

在不能确认是电缆损伤还是LED灯本身烧坏的情况下，请将电缆和 LED 灯一起进行更换。如果能明确只是 LED 灯本身烧坏，可选择只更换 LED 灯体部分。
