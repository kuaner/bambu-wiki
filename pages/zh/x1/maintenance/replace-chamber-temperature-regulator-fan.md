## 什么是机箱控温风扇

顾名思义，打印机机箱控温风扇是调节机箱内部温度的风扇。风扇的开启和关闭，以及风扇的转速均由传器器检测到的机箱温度决定。

![](https://wiki.bambulab.com/x1/maintenance/replace-chamber-temp-fan/396px-the_chamber_temperature_regulator_fan_(1).png)

## 何时更换

如果显示屏上弹出关于打印机机箱控温风扇的警告，并且检查确认了连接线和运行环境（如风扇积尘等）一切正常，则极大可能需要更换控温风扇。

## 所需的工具和材料

- 一个新的机箱控温风扇
- H1.5 和 H2.0 内六角扳手
- 镊子

## 开始操作前的安全警告和机器状态

> 在开始操作前，**请确认机器已关闭**。如有连接 AMS，则需要先将 PTFE 管和供料缓冲器移除。

## 操作指南

### 拆除后盖

1. 如图所示，取下后盖上的 10 颗螺丝和 4 颗螺丝。

> **注意：该过程涉及到很多螺丝，请将它们区分开并放在不同区域，以免弄混。**

|  |  |
| --- | --- |
|  |  |

2. 取下进料管接口。

![取下进料管接口.png](https://wiki.bambulab.com/x1/maintenance/replace-chamber-temp-fan/%E5%8F%96%E4%B8%8B%E8%BF%9B%E6%96%99%E7%AE%A1%E6%8E%A5%E5%8F%A3.png)

3. 先将后盖从左侧（面向后盖）皮带张紧口的位置松开，再松开右侧（面向后盖）皮带张紧口的位置，以免卡住。

|  |  |
| --- | --- |
|  |  |

### 移除废料滑梯

拧下 2 颗螺丝（新版本机器为 3 颗螺丝），并拆下废料滑梯。

|  |  |
| --- | --- |
|  |  |

### 拆除风扇

1. 将风扇连接线从 MC 板上的连接器上断开，并从连接线从各卡扣中松脱出来。

|  |  |  |
| --- | --- | --- |
|  |  |  |

2. 移除固定风扇的 4 颗螺丝，并用镊子夹住螺丝，防止掉落。

|  |  |
| --- | --- |
|  |  |

3. 移除机箱控温风扇。

![移除风扇.png](https://wiki.bambulab.com/x1/maintenance/replace-chamber-temp-fan/%E7%A7%BB%E9%99%A4%E9%A3%8E%E6%89%87.png)

### 安装新风扇

1. 将新的风扇线缆从卡扣中取出。

![将新的风扇的连接线从卡扣中取出.png](https://wiki.bambulab.com/x1/maintenance/replace-chamber-temp-fan/%E5%B0%86%E6%96%B0%E7%9A%84%E9%A3%8E%E6%89%87%E7%9A%84%E8%BF%9E%E6%8E%A5%E7%BA%BF%E4%BB%8E%E5%8D%A1%E6%89%A3%E4%B8%AD%E5%8F%96%E5%87%BA.png)

2. 将风扇安装到相应位置，并使用 4 颗螺丝将风扇固定，借助镊子将螺丝先放到螺丝孔上并保持夹住，防止螺丝跌落。

|  |  |
| --- | --- |
|  |  |

3. 将风扇电缆穿过框架和 MC 板上的卡扣，然后将连接线连接到 MC 板对应的接口上。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 安装废料滑梯

将废料滑梯装回原位，安装时注意滑槽两侧突出的止扣，锁紧 2 颗（新版本机器为 3 颗）螺丝。

|  |  |
| --- | --- |
|  |  |

### 安装后盖

1. 先将后盖穿过 PTFE 管支架和装好右侧的皮带张紧口位置，再卡住左侧皮带张紧口。

|  |  |
| --- | --- |
|  |  |

2. 用螺丝将后盖重新固定。注意使用的不同类型的螺丝 (如下图所示的 10 颗螺丝和 4 颗螺丝)。

|  |  |
| --- | --- |
|  |  |

## 如何验证完成/成功

连接电源线并打开电源。如下所示运行设备自检操作，如果没有出现错误，则更换成功。

![](https://wiki.bambulab.com/x1/maintenance/replace-chamber-temp-fan/350px-self_test.png)

否则，请检查所有连接，然后重试。如果问题仍然存在，请联系Bambu Lab服务团队寻求进一步帮助。
