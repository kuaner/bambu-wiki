## 什么是 WIFI 天线

WIFI 天线是用于增强无线网络信号电子配件，X 系列打印机的 WIFI 天线安装在前面盖内侧并连接至 AP 主板。

![](https://wiki.bambulab.com/x1/maintenance/replace-wifi-antenna/x_wifi_antenna.jpg)

## 何时更换

1. WIFI 天线线缆或连接器损坏。

2. WIFI 信号不稳定或较弱，且 Bambu Lab 服务团队通过日志分析确认是 WIFI 天线的问题。

## 所需的工具和材料

- 新的 WIFI 天线
- 电吹风机
- 镊子（平头）
- 硅胶

![](https://wiki.bambulab.com/x1/maintenance/replace-the-chamber-led/silicone_glue.jpg)

仅供参考

## 开始操作前的安全警告和机器状态

在开始本指南中的过程之前，请确保机器已关闭

## 操作指南

### 步骤 1 - 打开 AP 主板盖

关闭打印机电源，拔出电源线，取下顶部玻璃盖板，揭开位于机器左上方的 AP 主板盖，如下图所示。

|  |  |
| --- | --- |
|  |  |

### 步骤 2 - 断开电缆连接

使用吹风机加热软化固定连接器的硅胶，先断开按钮板电缆的连接，用镊子去除固定 WIFI 电缆的一些硅胶，然后用镊子断开 WIFI 天线连接。

|  |  |
| --- | --- |
|  |  |

### 步骤 3 - 松出电缆

依次将按键板电缆和 WIFI 天线电缆从卡扣中松出，注意卡扣的开口方向。

|  |  |
| --- | --- |
|  |  |

### 步骤 4 - 移除 WIFI 天线

去除固定天线电缆的胶布，用镊子将由双面胶固定的 WIFI 天线电路板揭起，取下 WIFI 天线。

|  |  |
| --- | --- |
|  |  |

### 步骤 5 - 安装 WIFI 天线

准备好替换的 WIFI 天线，去除保护贴纸，将天线电路板如下图所示贴到打印机前面盖内侧。

|  |  |
| --- | --- |
|  |  |

### 步骤 6 - 固定天线电缆

将电缆连接器穿过前横梁上的过线孔，用胶布将电线进行固定。

|  |  |
| --- | --- |
|  |  |

### 步骤 7 - 理线

将天线电缆和按键板电缆依次安装到前面盖的卡扣上。

|  |  |
| --- | --- |
|  |  |

### 步骤 8 - 连接电缆

对齐 WIFI 天线的连接口，将天线连接到 AP 主板上，然后再连接按键板电缆。建议涂布硅胶胶水加固连接。

|  |  |
| --- | --- |
|  |  |

特别提醒：连接天线时，请务必对齐后再按压接好，避免连接器损坏。

![](https://wiki.bambulab.com/x1/maintenance/replace-wifi-antenna/connector.jpg)

### 步骤 9 - 合上 AP 主板盖

将 AP 护盖压回原位，最后盖上玻璃顶盖。

![](https://wiki.bambulab.com/x1/maintenance/replace-ap-board/350px-cover3.png)

## 如何验证完成/成功

连接电源线并打开电源，通过 APP 连接打印机，确认打印机能正常检测到 WIFI 信号并能完成连接即可。否则，请检查所有连接，然后重试。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
