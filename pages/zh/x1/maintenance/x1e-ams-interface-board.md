# AMS 接口板

## 什么是 AMS 接口板

AMS 接口板是安装在打印机后框架上的一块电路板，它为 AMS 提供 24V 的直流电源，并处理 AMS 和打印机之间的通信连接。对于 X1E 来说，这块接口板同时搭载了网线接口，可用于连接以太网。

![](https://wiki.bambulab.com/x1/maintenance/x1e/power-supply/interface_board.jpg)

## 何时更换

AMS 接口板的电源输出不正常，AMS 出现电源或通信故障的，有很大可能需要更换 AMS 接口板。当以太网出现故障时，可能也需要更换该接口板。

![](https://wiki.bambulab.com/接地.jpg)

## 所需的工具和材料

- 一块新的 AMS 接口板
- H2.0 内六角扳手.

# 安全提示

> ***重要提醒 ！***
>
> *在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。*
>
> *在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。*

# 操作步骤 - 拆卸

## 步骤 1 - 断开电源线

关闭电源，从电源插座上拔下电源线。

## 步骤 2 - 断开 PTFE 管

按下快速接头，断开 PTFE 管。拔下 4pin 连接电缆，断开 AMS 与打印机的连接。

## 步骤 3 - 移除 AMS 供料缓冲器

拆下固定供料缓冲器的 2 颗螺丝 F，移除供料缓冲器。

然后参照图 1-4-3 所示，向左用力，将后面板从左侧张紧器处松出，取下后面板。

# 操作步骤 - 组装

## 步骤 1 - 安装网线及 AMS 接口板

如图 2-1-1 所示，根据以上接口的说明，依次连接 3 个连接器；

如图 2-1-2 所示，安装网线及 AMS 接口板，锁入 2 颗螺丝 D 和 1 颗螺丝 E。

|  |  |
| --- | --- |
| 2-1-1 | 2-1-2 |

## 步骤 2 - 安装后面板

如图 2-2-1 中所示，先将料管支架穿过后面板，将右侧张紧器处的位置安装到位，可以使用扳手按压边缘，将其安装好；

如图 2-2-2 中所示，向左用力拉着后面板，将左侧张紧器处的位置安装到位，可以使用扳手按压边缘，辅助安装；

如图 2-2-3 所示，锁入 9 颗螺丝 A，4 颗螺丝 B 和 1 颗螺丝 C，将后面板固定。

|  |  |  |
| --- | --- | --- |
| 2-2-1 | 2-2-2 | 2-2-3 |

## 步骤 3 - 安装 AMS 供料缓冲器

安装 AMS 供料缓冲器，并锁入固定供料缓冲器的 2 颗螺丝 F。

![](https://wiki.bambulab.com/x1/maintenance/x1e/ams-interface-board/x1e-buffer-screw.jpg)

## 步骤 4 - 连接 PTFE 管并连接 AMS

只需将带连接器的 PTFE 管推向机器后部的 PTFE 管，即可快速连接 PTFE 管，连接 4pin 总线电缆。

| --- | --- |
|  |  |

> ***注意：4pin 电缆的方向不要插错，如果插错方向有可能导致打印机和AMS的主板烧毁。***

# 功能确认

连接电源线并启动电源。在显示屏上，按下屏幕上的 AMS 标签，如下所示，屏幕将显示AMS控制面板。按下“上料”按钮开始上料，如果该过程没有任何错误地完成，AMS 接口板更换完成并成功。

否则，请检查所有连接，然后重试。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
