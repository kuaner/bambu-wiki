# 加热模块的拆解与安装

为给打印机腔室提供更高和更稳定的腔温，我们在X1E打印机增设了加热模块及配套的其他部件

# 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

# 拆解指引

## 步骤1：移除滤芯

移除玻璃上盖，通过拉Z轴皮带的方式，将热床下降到底部，露出整个滤芯盖，如图1-1-1所示，然后揭开并取下滤芯盖；

如图1-1-2所示，两只手分别拉着滤芯的带子，取下滤芯。

# 组装指引

## 步骤1：安装加热模块

如图2-1-1所示，两根凸柱对齐安装槽，将加热模块放置到位；

如图2-1-2所示，将拆下来的螺丝H和螺丝安装回原位，用手压住螺丝或用尖嘴钳夹住螺母，然后锁螺丝；

如图2-1-3所示,，将回热模块的所有连接线都穿过右后立柱与内衬的通孔

如图2-1-4所示，侧放打印机，从底座下方锁入2颗螺丝F固定加热模块。

# 功能确认

1. 连接AMS，接上打印机电源，启动打印机，确认打印机和AMS能正常启动 ;

2. 在显示屏上操作，点击腔温风扇图标，然后开启控温风扇，确认风扇能正常开启和关闭；

![](https://wiki.bambulab.com/x1/maintenance/x1e/power-supply/chamber_f.jpg)

3. 在显示屏上操作，占击腔温图标，设置高于当前的温度，确认电源冷却风扇和加热器风扇能开始工作。

![](https://wiki.bambulab.com/x1/maintenance/x1e/power-supply/chamber_t.jpg)

如测试失败，请再次检查所有连接并重试。如果仍然不行，请联系 Bambu Lab 服务团队。
