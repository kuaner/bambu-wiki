## 什么是 XY 张紧器惰轮

XY 张紧器惰轮是安装在 XY 皮带张紧器上的惰轮，左右（XY）各一个，每个包含有两个垫圈和一个惰轮。

![](https://wiki.bambulab.com/p1/maintenance/xy-idler-pulley/idler_pulley_2.jpg)

## 何时更换

- 惰轮异响，打油未能解决
- 惰轮轴承损坏

> 注：两个位置的惰轮，更换方法基本一致。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-idler-pulley/2_idlers.jpg)

## 所需工具和材料

1. H2.0 内六角扳手
2. 新的惰轮组件

## 开始操作前的安全警告和机器状态

关闭电源，移除电源线，如果装有 AMS 缓冲区和料盘支架，也需要先拆除。

## 操作指南

### 步骤 1 - 移除后盖螺丝

> 注意：这个过程涉及到很多螺丝，请将它们区分开来，并把它们放在不同的区域，以免弄混。

如图所示，取下后盖上的 10 颗螺丝和 4 颗螺丝。这是两种类型的螺丝，所以要把它们分开。

|  |  |
| --- | --- |
|  |  |

### 步骤 2 - 拆下后盖

拆下后盖，先将后盖从左侧（面向后盖）皮带张紧口的位置松开，再松开右侧（面向后盖）皮带张紧口的位置，以免卡住。

|  |  |
| --- | --- |
|  |  |

### 步骤3 - 移除张紧轮螺丝

用 H2.0 内六角扳手拧下两颗锁定张紧器的螺丝，同时也移除两个金属支架。

|  |  |
| --- | --- |
|  |  |

### 步骤 4 - 移除张紧弹簧和固定支架

拧下 2 颗螺丝，移除张紧弹簧和固定支架。

|  |  |
| --- | --- |
|  |  |

### 步骤 5 - 松出张紧器

用内六角扳手推动张紧器，将张紧器松脱出来。

|  |  |
| --- | --- |
|  |  |

### 步骤 6 - 移除惰轮

用内六角扳手从下往上将惰轮转轴推出，然后移除转轴和惰轮。

|  |  |
| --- | --- |
|  |  |

### 步骤 7 - 贴附垫圈

准备好新的惰轮组件，将两个垫圈分别贴装到惰轮两端，你可能需要用手帮助固定。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-idler-pulley/attach_washers.jpg)

### 步骤 8 - 安装惰轮

将惰轮安装到惰轮支架上，可以暂时用内六角扳手穿起来，以保证惰轮和两个垫圈均在位置上，然后从上往下压入转轴，将转轴完全压入即可。

|  |  |
| --- | --- |
|  |  |

### 步骤 9 - 安装张紧器

将张紧器组件滑入到位，拧入 2 颗螺丝（带支架），螺丝不要拧紧，保持松动的状态即可。

|  |  |
| --- | --- |
|  |  |

### 步骤 10 - 安装张紧弹簧和固定支架

安装张紧弹簧和固定支架，锁入 2 颗螺丝进行固定。

|  |  |
| --- | --- |
|  |  |

### 步骤 11 - 安装打印机后盖

安装后盖时，应首先穿过 PTFE 管支架和装好右侧的皮带张紧口位置。

|  |  |
| --- | --- |
|  |  |

### 步骤 12 - 锁后盖螺丝

将后盖重新固定。注意使用的不同类型的螺丝(如下图所示的 10 颗螺丝和 4 颗螺丝)。

|  |  |
| --- | --- |
|  |  |

### 步骤 13 - 张紧同步皮带

更换好惰轮后，需要重新张紧 XY 皮带：拧松另外一个张紧器的 2 颗固定螺丝，握住工具头两端的滑车，前后移动工具头数次，最后将滑车紧靠后部，再拧紧 2 个张紧器上的 4 颗螺丝。更详细的操作请参考 [张紧同步带 | Bambu Lab Wiki](belt-tension.md) 进行了解。

|  |  |
| --- | --- |
|  |  |

## 如何验证完成/成功

- 连接电源，启动打印机
- 如下图所示，运行设备自检流程，如果没有报错，更换同步带完成。

![selftest.png](https://wiki.bambulab.com/screen-operation/selftest.png)

如果报错了，请排查组装是否有问题，重新张紧皮带后，再次运行设备自检。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步的帮助。
