## 什么是左侧面板

面向打印机前门，左手边的侧盖就是左侧面板，其中 X1C 用的是面板是金属材质的，X1 用的是塑料材质的。另外，因作业性改善，金属材质的右侧面板的固定螺丝位置有减少。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/left_panel_cn.jpg)

## 何时更换

左侧面板上出现不能接受的变形或损伤。

## 所需的工具和材料

- 左侧面板
- H2.0 内六角扳手

## 开始操作前的安全警告和机器状态

在开始操作前，请确认机器已关闭。如有连接 AMS，则需要先将 PTFE 管和供料缓冲器移除。

如果您的打印机侧板使用老版本的安装方式，请查看**操作指南（旧版）。**

## 操作指南（新版）

> **注意: 锁底座的 2 颗螺丝与其他位置的螺丝不一样。**

### 步骤 1 - 拆除前门

移除玻璃上盖，并参考 [更换玻璃前门](replace-the-front-door.md) 步骤 1 ~步骤 3 的操作内容，将前门拆除，如下图所示。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/remove_the_front_door.jpg)

### 步骤 2 - 拆卸辅助部件冷却风扇

用 H2.0 内六角扳手拧下固定风扇的 3 颗螺丝，然后将风扇从侧盖分离。

|  |  |
| --- | --- |
|  |  |

### 步骤 3 - 拆左前立柱螺丝

移除左前立柱处的 4 颗螺丝。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/front_4.jpg)

### 步骤 4 - 拆背面螺丝

移除左侧面板后方的 4 颗螺丝。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/rear_4_new.jpg)

### 步骤 5 - 移除上横梁处的螺丝

揭开 AP 主板盖，找到位于上横梁中间位置的螺丝，用 H2.0 内六角扳手进行移除。

|  |  |
| --- | --- |
|  |  |

### 步骤 6 - 移除底部螺丝，取下左侧面板

侧放打印机，使右侧面板朝上，移除底部的 2 颗螺丝，然后取下左侧面板。注意因为侧风扇处于松脱状态，侧放过程中注意轻放。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/bottom_2_new.jpg)

### 步骤 7 - 安装左侧面板，锁底部螺丝

将左侧面板安装到打印机上，确认安装到位，锁入 2 颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 8 - 锁上横梁螺丝

锁上横梁中间位置处的螺丝 1 颗，合上 AP 主板盖。

|  |  |
| --- | --- |
|  |  |

### 步骤 9 - 锁左前立柱螺丝

锁左前立柱处的 4 颗螺丝。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/front_4.jpg)

### 步骤 10 - 锁背面螺丝

在打印机背面，锁 4 颗螺丝。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/rear_4_new.jpg)

### 步骤 11 - 安装辅助部件冷却风扇

安装辅助部件冷却风扇，锁 3 颗螺丝。

![](https://wiki.bambulab.com/x1/maintenance/replace-aux-fan/3_screws.jpg)

> **注意**：如果在拆卸时损坏了风扇与侧板间的粘合剂，可使用耐温的双面胶进行涂抹。

### 步骤 12 - 安装玻璃前门

请参考 [更换玻璃前门](replace-the-front-door.md) 步骤 4 ~步骤 6 的操作内容，安装好玻璃前门，盖好玻璃上盖。

## 操作指南（旧版）

### 步骤 1 - 拆除前门

请参考 [更换玻璃前门](replace-the-front-door.md) 步骤 1 ~步骤 3 的操作内容，将前门拆除，如下图所示。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/remove_the_front_door.jpg)

### 步骤 2 - 拆除 AP 主板

请参考 [更换AP主板](replace-ap-board.md) 步骤 1 ~步骤 5 的操作内容，将 AP 主板松出，如下图所示。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/unlock_the_ap_board.jpg)

### 步骤 3 - 拆辅助部件冷却风扇（X1C 适用）

请参考 [更换辅助部件冷却风扇](replace-aux-part-cooling-fan.md) 步骤 1 ~步骤 4 的操作内容，移除辅助部件冷却风扇。

### 步骤 4 - 移除 AP 主板保护盖

移除在打印机后背上的 1 颗螺丝，将 AP 主板保护盖移除。

|  |  |
| --- | --- |
|  |  |

### 步骤 5 - 移除左侧面板

旧版本的左侧金属面板共有 16 颗螺丝固定，其中在后面的 4 颗螺丝跟其他 12 颗不一样。参考下面图片找到对应位置上的螺丝并逐个移除，然后移除左侧面板。

> 注：X1可参考本版本进行处理，只是因材质不同，螺丝会有差异。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/rear_4.jpg)

移除左侧面板后方的 4 颗螺丝

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/bottom_2.jpg)

移除底部的 2 颗螺丝

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/middle_4.jpg)

移除上横梁的 3 颗螺丝（有 EVA 垫盖住）和中横梁的 1 颗螺丝

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/rear_2.jpg)

移除左后立柱处的 2 颗螺丝

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/front_4.jpg)

移除左前立柱处的 4 颗螺丝

### 步骤 6 - 安装左侧面板

将左侧面板安装到打印机上，确认安装到位。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/install_the_left_panel.jpg)

### 步骤 7 - 锁左侧面板螺丝

根据实际的版本锁附全部螺丝，螺丝锁附顺序可参考下面的图片，注意后面4颗跟另外位置的螺丝有区别，不要上错。

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/middle_4.jpg)

先锁附上横梁的3颗螺丝和中横梁的 1 颗螺丝

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/front_4.jpg)

再锁左前立柱处的 4 颗螺丝

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/rear_2.jpg)

然后锁左后立柱处的 2 颗螺丝

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/rear_4.jpg)

再锁左侧面板后方的 4 颗螺丝

![](https://wiki.bambulab.com/x1/maintenance/replace-left-panel/bottom_2.jpg)

最后锁底部的 2 颗螺丝

### 步骤 8 - 安装辅助部件冷却风扇（X1C 适用）

请参考 [更换辅助部件冷却风扇](replace-aux-part-cooling-fan.md)步骤 5 ~步骤 8 的操作内容，安装辅助部件冷却风扇。

### 步骤 9 - 安装 AP 主板

请参考 [更换AP主板](replace-ap-board.md) 步骤 9 ~步骤 11 的操作内容，安装 AP 主板和连接线。

### 步骤 10 - 安装 AP 主板盖

先安装下图所示的缺口位置，然后将整个 AP 主板盖安装到位，再在打印机后背锁入 1 颗螺丝进行固定。

|  |  |  |
| --- | --- | --- |
| 先将此处安装到位 | 再将两端安装好 | 锁螺丝固定 |

### 步骤 11 - 安装玻璃前门

请参考 [更换玻璃前门](replace-the-front-door.md) 步骤 4 ~步骤 6 的操作内容，安装好玻璃前门。

## 如何验证完成/成功

1. 目视检查外观，确认左侧面板安装到位；

2.连接电源线并打开电源。如下所示运行设备自检操作，没有出现错误提示，确认 AP 主板的安装正常；

![](https://wiki.bambulab.com/x1/maintenance/replace-chamber-temp-fan/350px-self_test.png)

3. 点击辅助部件冷却风扇按钮，确认该风扇能正常启动。

![](https://wiki.bambulab.com/x1/maintenance/replace-aux-fan/turn_on_the_aux_fan.png)

否则，请检查所有连接，然后重试。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
