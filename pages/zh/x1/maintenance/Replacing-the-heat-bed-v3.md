## 什么是热床 (V3版)

X1 系列打印机的热床是安装在打印机腔体内，能沿 Z 方向上下运动并能根据用户的设定温度进行加热的平台。设置合适的热床温度能有效提升模型与构建板的粘接力和防止模型翘边。为了优化热床的组装和可靠性，我们对热床的结构进行了变更 。

![](https://wiki.bambulab.com/x1/maintenance/replace-heat-bed-v3/heat_bed_v3.jpg)

## V2 版本热床和 V3 版本热床的区别

![](https://wiki.bambulab.com/x1/maintenance/replace-the-heat-bed/heatbed.png)

[更换热床（V2） | Bambu Lab Wiki](Replacing-the-heat-bed.md)

目前市面上的 X1 系列机型配置了 V2 和 V3 两种版本的热床，而且未来X1系列打印机的热床将全部切换至V3版本。

相比 V2 版本，V3 版本的热床更容易更换，版本的变更只是我们生产计划的改变，这两个版本的热床在功能上没有区别。

此外，需要注意的是，不同版本的热床需要配套相应版本的 AC 板。  
左边的 AC 板是用于 V2 热床，右边的 AC 板是用于 V3 热床

![v2、v3_版本对比.jpg](https://wiki.bambulab.com/v2%E3%80%81v3_%E7%89%88%E6%9C%AC%E5%AF%B9%E6%AF%94.jpg)

如果你的整机是配置了V2热床，但你想升级到V3热床，那么你需要将整机的AC板也相应的升级到V3热床相适配的AC板

[更换AC电源板 (用于V2热床)| Bambu Lab Wiki](replace-ac-board.md)

[更换AC电源板 （用于V3热床）| Bambu Lab Wiki](../../p1/maintenance/ac-board.md)

## 何时更换

1. 热床不升温， 且已排查过，确认热床故障；

2. 影响功能的物理损坏或明显的形变；

3. 其他售后人员的确认，需要更换热床的情形。

## 所需的工具和材料

- 新的热床
- H1.5/H2.0 内六角扳手
- 镊子
- 一些必要的胶布和胶水

![](https://wiki.bambulab.com/x1/maintenance/replace-the-chamber-led/silicone_glue.jpg)

硅胶胶水，仅供参考

## 开始操作前的安全警告和机器状态

确认打印材料和AMS配件已移除，在进行拆装作业时，请确保打印机没有连接电源。

## 操作指南

> 操作步骤以 X1 为例，P1S 拆装步骤几乎一致。

### 步骤 1 - 调整热床位置

在开机状态下，通过显示屏幕控制热床运动，将热床置于约全程 ⅔ 的高度。然后关闭打印机，断开电源线，移除玻璃上盖。也可以在关机状态下，侧放打印机，然后拉动 Z 轴皮带，将热床上升至约全程 ⅔ 的高度。

![](https://wiki.bambulab.com/x1/maintenance/replace-heat-bed-v3/raise_up_the_heat_bed.jpg)

### 步骤 2 - 拆除后面板螺丝

注意：这个过程涉及到很多螺丝，请将它们区分开来，并把它们放在不同的区域，以免弄混。

如图所示，移除后面板上的 10 颗螺丝和 4 颗螺丝。这是两种不同类型的螺丝，要把它们分开，避免混淆。

![](https://wiki.bambulab.com/x1/maintenance/replace-heat-bed-v3/rear_panel_screws.jpg)

### 步骤 3 - 拆除后面板

拆除后面板时，需先将后面板从右侧（面向后盖）皮带张紧口的位置松开，再松开左侧（面向后盖）皮带张紧口的位置，以免卡住。

|  |  |
| --- | --- |
|  |  |

### 步骤 4 - 移除废料滑梯

如下图所示，用 H2.0 内六角扳手拆除 1 颗银色螺丝，用 H1.5 内六角扳手拆除两颗黑色螺丝，取下废料滑梯。

|  |  |
| --- | --- |
|  |  |

### 步骤 5 -移除护线盖

用 H2.0 内六角扳手移除 2 颗螺丝，取下走线槽；用 H1.5 内六角扳手移除 6 颗螺丝，取下护线盖。

|  |  |
| --- | --- |
|  |  |

### 步骤 6 - 移除右侧面板

根据下图所示位置，移除固定右侧面板的 11 颗螺丝，并依次移除，然后取下右侧面板。

> 注意：螺丝有两种，要进行区分，不可混用。

|  |  |
| --- | --- |
|  |  |

### 步骤 7 **- 松**热床地线，松出电缆

正放打印机，用 H2.0 内六角扳手拧下地线锁定螺丝，松开地线。将热床电缆从线扣和过线孔中松出。

|  |  |
| --- | --- |
|  |  |

### 步骤 8 **-** 断开热床电源线

松开蓝色保护胶套，用镊子解除热床电源线锁扣，拔出两根电源线。

|  |  |
| --- | --- |
|  |  |

### 步骤 9 **-** 断开热床信号线

建议先去除部份涂布在接口处的硅胶（用镊子或电吹风加热，不要用热风枪），然后再断开热床信号线的连接。

|  |  |
| --- | --- |
|  |  |

### 步骤 10 **-** 移除扎网

撕开扎网两端的胶布，将扎网沿电缆方向松出并移除。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed/remove_the_net.jpg)

### 步骤 11 **-** 移除走线压片

用 H1.5 内六角扳手拧下 2 颗螺丝，移除走线压片。

![](https://wiki.bambulab.com/x1/maintenance/replace-heat-bed-v3/plate_screws.jpg)

### 步骤 12 **- 移除热床**

用 H2.0 内六角扳手，移除 6 颗固定热床的螺丝。然后侧放热床，往热床方向抽回所有的电缆，移除热床。

> 部分螺丝上有黑色贴纸，可放心戳破。

|  |  |
| --- | --- |
|  |  |

### 步骤 13 **-** 安装热床

将热床安装到滑块上，将热床尽量靠前门方向放置，锁入 6 颗螺丝进行固定。

|  |  |
| --- | --- |
|  |  |

### 步骤 14 **-** 穿热床线，安装走线压片

将热床电缆穿过后滑块过线孔，将电缆整理好压入后滑块线槽，然后装上走线压片，锁入 2 颗螺丝固定。可以将打印机侧放，方便安装。

![](https://wiki.bambulab.com/x1/maintenance/replace-heat-bed-v3/plate_screws.jpg)

### 步骤 15 **-** 安装扎网

将扎网安装到电缆上，两端用胶带固定。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed/remove_the_net.jpg)

### 步骤 16 **- 锁地线**

穿地线，按下图所示布置好地线，然后锁入 1 颗地线固定螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 17 **-** 接电源线

确认电源线插头的状态正常，然后将两个插头连接到 AC 板接口上，将蓝色的胶套装回原位，并将线理好。

|  |  |
| --- | --- |
|  |  |

### 步骤 18 **-** 连接热床信号线

将热床信号线连接到 MC 板对应接口上，连接 MC-AC 连接线，在连接器处点上硅胶进行加固。

|  |  |
| --- | --- |
|  |  |

### 步骤 19 - 安装右侧面板

安装右侧面板，根据下图所示螺丝位置，依次锁入固定右侧面板的 11 颗螺丝。

> 注意：螺丝有两种，要进行区分，不可混用。

|  |  |
| --- | --- |
|  |  |

### 步骤 20 - 安装护线盖

安装好护线盖，锁入 6 颗固定螺丝； 安装走线槽，锁入 2 颗螺丝固定。

|  |  |
| --- | --- |
|  |  |

### 步骤 21 - 安装废料滑梯

安装废料滑梯，注意滑梯两侧需要安装到位，右侧确认没有压到电缆，在滑梯方锁入 2 颗黑色螺丝，在左侧锁入 1 颗银色螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 22 - 安装后面板

安装后面板时，应首先穿过 PTFE 管支架和装好右侧的皮带张紧口位置。

|  |  |
| --- | --- |
|  |  |

### 步骤 23 -锁紧螺丝

用螺丝将后盖重新固定。注意使用的不同类型的螺丝(如下图所示的 10 颗螺丝和 4 颗螺丝)。

![](https://wiki.bambulab.com/x1/maintenance/replace-heat-bed-v3/rear_panel_screws.jpg)

## 如何验证完成/成功

连接电源线并打开电源。

确保腔室和热床上没有任何打印物品或挤出材料。然后进入 LCD 屏幕上的设置菜单，选择校准选项卡，然后按“开始校准”

![calibration.png](https://wiki.bambulab.com/screen-operation/calibration.png)

如果一切正常，并且在校准过程中没有出现错误或警告，则更换成功。否则，请检查连接并重试。如果问题仍然存在，请联系服务团队寻求进一步帮助。
