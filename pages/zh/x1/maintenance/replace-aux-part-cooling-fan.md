## 什么是辅助部件冷却风扇

辅助部件冷却风扇是一个强大的 12W 冷却风扇，安装在腔室的左侧，为高速打印提供了更好的冷却条件。目前存在两种版本的风扇。

|  |  |
| --- | --- |
| 旧版风扇 | 新版风扇 |

> *说明：如果是 X1 (非 X1Carbon) 产品加装辅助部件冷却风扇后，须在切片时将机型选择为 X1 Carbon，才能正常启动风扇。*

## 何时更换/安装

叶片损坏或风扇电机故障；

X1 升级冷却性能，加装辅助零件冷却风扇。

## 所需的工具和材料

- 辅助部件冷却风扇
- H2.0 内六角扳手
- 镊子

## 开始操作前的安全警告和机器状态

在开始操作前，请确认机器已关闭。如有连接 AMS，则需要先将 PTFE 管和供料缓冲器移除。

## 操作指南

### 步骤1 - (拆卸) 拆除螺丝

注意：这个过程涉及到很多螺丝，请将它们区分开来，并把它们放在不同的区域，以免弄混。

如图所示，取下后盖上的 10 颗螺丝和 4 颗螺丝。这是两种类型的螺丝，所以要把它们分开。

|  |  |
| --- | --- |
|  |  |

### 步骤2 - 拆除后盖

拆下后盖，先将后盖从左侧（面向后盖）皮带张紧口的位置松开，再松开右侧（面向后盖）皮带张紧口的位置，以免卡住。

|  |  |
| --- | --- |
|  |  |

### 步骤3 - 断开辅助部件冷却风扇电缆

找到MC板上辅助风扇的连接器，然后断开电缆连接。

|  |  |
| --- | --- |
|  |  |

### 步骤4 - 拆卸辅助部件冷却风扇（旧版)

将电缆拉向风扇方向，然后用力将风扇从左侧面板上分离开来。

|  |  |
| --- | --- |
|  |  |

### 步骤4 - 拆卸辅助部件冷却风扇（新版)

将风扇电缆沿风扇方向拉出，用 H2.0 内六角扳手拧下固定风扇的 3 颗螺丝，然后将风扇从侧盖分离，取下风扇。

|  |  |
| --- | --- |
|  |  |

### 步骤5 - 粘贴风扇（旧版）

按照[重新装配辅助部件冷却风扇](../troubleshooting/reattach-auxiliary-part-cooling-fan.md)的指引重新粘贴好辅助部件冷却扇。

### 步骤5 - 安装风扇（新版）

将风扇电缆穿过内衬，撕掉风扇上的双面胶保护纸，根据螺柱位将风扇安装到位，然后锁入 3 颗螺丝固定。

|  |  |
| --- | --- |
|  |  |

### 步骤6 - 连接风扇电缆

将风扇电缆穿过侧面板和内搁板之间的间隙，然后将电缆连接到 MC 板上的连接器。

|  |  |
| --- | --- |
|  |  |

### 步骤7 - 安装后盖

安装后盖时，应首先穿过 PTFE 管支架和装好右侧的皮带张紧口位置。

|  |  |
| --- | --- |
|  |  |

### 步骤8 - 锁紧螺丝

用螺丝将后盖重新固定。注意使用的不同类型的螺丝(如下图所示的 10 颗螺丝和 4 颗螺丝)。

|  |  |
| --- | --- |
|  |  |

## 如何验证完成/成功

连接电源线并开启电源，在屏幕上点击辅助部件冷却风扇图标，开户辅助冷却风扇 。

![](https://wiki.bambulab.com/辅助部件冷却风扇.png)

如果辅助部件冷却风扇按预期工作，那么更换完成。否则，请返回检查步骤和连接后重试。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
