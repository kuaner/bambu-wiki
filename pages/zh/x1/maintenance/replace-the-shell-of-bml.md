## 什么是激光雷达外壳

拓竹激光雷达外壳由三个部分组成，一个顶盖、一个底盖和一个摄像头保护镜片。

![](https://wiki.bambulab.com/x1/maintenance/cover-of-the-micro-lidar/the_shell_of_bml.png)

## 何时更换

当盖子出现裂缝或保护镜片因撞击而破裂时，建议更换激光雷达外壳。

## 需要的工具和材料

- 薄金属片/薄刀片
- 内六角扳手

## 开始操作前的安全警告和机器状态

为安全起见，请确保在拆装前关闭电源。

## 操作指南

### \*\*第 1 步 -\*\*下降热床

打开打印机电源，在显示屏的移动菜单中点击下降热床标签，将热床降低到接近机器底部。完成后，关闭打印机电源并取下顶部玻璃盖板。

|  |  |
| --- | --- |
|  |  |

### **步骤 2 -** 打开前盖组件

打开前盖组件，然后将其悬挂在碳杆上，避免影响操作。

![](https://wiki.bambulab.com/x1/maintenance/cover-of-the-micro-lidar/remove.png)

### **第 3 步 - 移除激光雷达的上盖**

使用准备好的金属片或薄刀片撬开激光雷达上盖，然后将上盖从激光雷达上取下。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 - 移除激光雷达下盖**

如下图所示将内六角扳手插入激光雷达下盖和主体间隙中，通过内六角扳手轻微向下用力，撬开激光雷达下盖并将其取下。

|  |  |
| --- | --- |
|  |  |

### **第 5 步 - 准备新的外壳**

准备好一个新的激光雷达外壳，并将上盖与下盖分开。

|  |  |
| --- | --- |
|  |  |

### **第 6 步 - 安装下盖**

如下图所示，根据激光雷达摄像头的外壳位置，先预安装激光雷达下盖。

![](https://wiki.bambulab.com/x1/maintenance/cover-of-the-micro-lidar/install_cover_1.png)

### **第 7 步 - 检查电缆，装好下盖**

从工具头的后侧，检查确认电缆全部没有超出边缘，以防止在安装下盖时造成任何电缆损伤。确认完成后，将下盖向上推，安装到位。

|  |  |
| --- | --- |
|  |  |

### **第 8 步 - 安装上盖**

将激光雷达上盖插入下图所示间隙中，确认上盖与下盖对齐后，将上盖按压安装到位。

|  |  |
| --- | --- |
|  |  |

### **步骤 9 - 合上工具头**前壳组件

更换过程现已完成。合上工具头前壳组件。

## 如何验证完成/成功

目视检查顶盖和底盖之间是否存在间隙或错位。
