## 什么是前玻璃门

安装在打印机前面的玻璃材质的门。

## 何时更换

前门有开裂或损坏时。

## 所需的工具和材料

- 前玻璃门
- H2.0 内六角扳手

## 开始操作前的安全警告和机器状态

玻璃易碎，移除和安装时注意持稳，防止跌落。如果玻璃有损坏的地方，要防止伤手。取出玻璃门时请检查一下轴承坑内是否有异物，防止更换后碎玻璃卡在轴承坑内，导致回零时把轴承顶出。

> **注意：X1、P1 系列新机的前玻璃门都粘上了双面胶，在拆卸时需要用风筒或铲刀将前玻璃门翘起，请务必小心操作。**

## 操作指南

### 步骤1 - 拆除前门螺丝

用H2.0内六角扳手移除固定前门的4颗螺丝，上下各2颗，注意要用手扶住前玻璃门，防止跌落。

|  |  |
| --- | --- |
|  |  |

### 步骤2 - 拆除前玻璃门硅胶垫

用手取下4个前门硅胶垫，上下各2个。注意要用手扶住前玻璃门，防止跌落。

|  |  |
| --- | --- |
|  |  |

### 步骤3 - 移除前玻璃门

一只手把着前玻璃门提手，另一只手扶着前玻璃门，将它取下。

#### 如果您的玻璃是用强力双面胶固定的：

- 请使用塑料撬棒或柔性铲刀，小心地将玻璃与安装支架分离。
- 对于粘性较强的胶带，可先用吹风机低温加热粘贴区域，使胶层软化后再尝试拆除。
- 当玻璃开始松动时，请立即扶稳，以防突然脱落或破裂。

> ⚠️ 操作过程中请始终双手托住玻璃。如果您是独自作业，可将打印机平放或侧放。

![](https://wiki.bambulab.com/x1/maintenance/replace-front-door/remove_the_front_door.jpg)

### 步骤4 - 安装前玻璃门

将玻璃前门上的4个螺丝孔，对齐开合器上的螺丝位安装好，用手扶稳。

|  |  |
| --- | --- |
|  |  |

### 步骤5 - 安装硅胶垫

依次装入4个硅胶垫， 保持用手扶稳玻璃门。

|  |  |
| --- | --- |
|  |  |

### 步骤6 - 锁前玻璃门螺丝

依次锁入4颗前玻璃门螺丝。

|  |  |
| --- | --- |
|  |  |

### 如何验证完成/成功

目视检查外观，确认螺丝无浮起；手动开合玻璃门，动作顺畅，闭合位置正常即可。
