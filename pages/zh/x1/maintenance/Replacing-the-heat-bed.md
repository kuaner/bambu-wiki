## 什么是热床（V2版本）

X1 系列打印机的热床是安装在打印机腔体内，能沿 Z 方向上下运动并能根据用户的设定温度进行加热的平台。设置合适的热床温度能有效提升模型与构建板的粘接力和防止模型翘边。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-heat-bed/heat_bed.jpg)

## V2 版本热床和 V3 版本热床的区别

![](https://wiki.bambulab.com/x1/maintenance/replace-the-heat-bed/heatbed.png)

[更换热床(V3版) | Bambu Lab Wiki](Replacing-the-heat-bed-v3.md)

目前市面上的 X1 系列机型配置了 V2 和 V3 两种版本的热床，而且未来 X1 系列打印机的热床将全部切换至 V3 版本。

相比 V2 版本，V3 版本的热床更容易更换，版本的变更只是我们生产计划的改变，这两个版本的热床在功能上没有区别。

此外，需要注意的是，不同版本的热床需要配套相应版本的 AC 板。  
左边的 AC 板是用于 V2 热床，右边的 AC 板是用于 V3 热床

![v2、v3_版本对比.jpg](https://wiki.bambulab.com/v2%E3%80%81v3_%E7%89%88%E6%9C%AC%E5%AF%B9%E6%AF%94.jpg)

如果你的整机是配置了 V2 热床，但你想升级到 V3 热床，那么你需要将整机的 AC 板也相应的升级到 V3 热床相适配的AC板

[更换AC电源板 (用于V2热床)| Bambu Lab Wiki](replace-ac-board.md)

[更换AC电源板 （用于V3热床）| Bambu Lab Wiki](../../p1/maintenance/ac-board.md)

此外，假如你选择 V3 热床加 AC 板的组合来替换原来 V2 的热床，但由于绕线方式的差异，你还是需要根据更换 V2 热床的操作指导进行更换。

## 何时更换

1. 热床不升温， 且已排查过，确认连接器状态正常；

2. 影响功能的物理损坏或明显的形变；

3. 经过售后人员的确认，需要更换热床。

## 所需的工具和材料

- 新的热床
- H1.5/H2.0 内六角扳手
- 镊子
- Z 轴滑块固定螺丝 3 颗(如果开箱后有保留的话)
- 一些必要的胶布和胶水

![](https://wiki.bambulab.com/x1/maintenance/replace-the-chamber-led/silicone_glue.jpg)

硅胶胶水，仅供参考

## 开始操作前的安全警告和机器状态

在进行拆装作业时，请确保打印机没有连接电源。

## 操作指南

### 步骤 1 - 调整热床位置

在打印机开启的情况下，通过显示屏幕控制热床运动，将热床置于约中间高度的位置。然后关闭打印机，断开电源线，移除玻璃上盖。

![](https://wiki.bambulab.com/x1/maintenance/heatbed-force-sensor/space.jpg)

### 步骤 2 - 拆除后盖螺丝

注意：这个过程涉及到很多螺丝，请将它们区分开来，并把它们放在不同的区域，以免弄混。

如图所示，取下后盖上的 10 颗螺丝和 4 颗螺丝。这是两种类型的螺丝，所以要把它们分开。

|  |  |
| --- | --- |
|  |  |

### 步骤 3 - 拆除后盖

拆下后盖，先将后盖从左侧（面向后盖）皮带张紧口的位置松开，再松开右侧（面向后盖）皮带张紧口的位置，以免卡住。

|  |  |
| --- | --- |
|  |  |

### 步骤 4 - 移除废料滑梯

拧下固定螺丝，拆下废料滑梯。请注意，有一些打印机使用 2 颗螺丝固定废料滑梯，而有些打印机使用了 3 颗螺丝固定废料滑梯，具体使用了几颗螺丝，请检查您的打印机。

用镊子解锁滑梯底下的卡扣， 将热床线和卡扣从滑梯底下移除。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 5 -移除保护盖

用 H1.5 内六角扳手拆下 6 颗螺丝，移除将电源板保护盖。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-heat-bed/remove_6_screws.jpg)

### 步骤 6 - 移除电源线插头

断开热床电源线连接，用镊子分别按压插头的两个 PIN，将插头移除。

|  |  |
| --- | --- |
|  |  |

### 步骤 7 - 断开热床通信线

用电吹风加热通信线上的白色硅胶，使硅胶软化， 然后用镊子剔除部分硅胶后，断开通信线连接。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-heat-bed/disconnect_the_control_cable.jpg)

### 步骤 8 - 移除右侧盖

根据下图所示位置，找到固定右侧盖的 12+4（后）颗螺丝，并依次移除，然后取下右侧盖。

|  |  |
| --- | --- |
|  |  |

更细节的移除右侧盖操作，请参考页面[更换右侧面板](replace-right-panel.md)

### 步骤 9 - 移除地线

移除 1 颗螺丝，松开热床地线，然后将地线拉出。

|  |  |
| --- | --- |
|  |  |

### 步骤 10 - 去除胶带和扎网

将缠绕热床线的胶布去除，取下扎网。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-heat-bed/remove_the_tapes.jpg)

### 步骤 11 - 解锁热床

移除固定热床的 6 颗螺丝，小心地将热床翻转过来，露出底下的电缆。

> 部分螺丝上有黑色贴纸，可放心戳破。

|  |  |
| --- | --- |
|  |  |

### 步骤 12 - 回退热床电缆 ，移除旧热床

两边同时操作，用手将线往热床方向推，另一边同时用手拉，将所有的电线回退到热床一端，最后将热床整个取下。

|  |  |
| --- | --- |
|  |  |

### 步骤 13 - 穿新热床线

将新热床斜放在机箱内，将其上的电缆依次穿过过线孔（从侧面穿出，依次为通信线、地线、电源线），缓慢拉动电缆，将电缆都拉过后，将热床放置到滑块上，再次确认热床底下的电缆已全部拉紧。

|  |  |
| --- | --- |
|  |  |

### 步骤 14 - 将热床并下降到底部

稍微倾斜打印机 ，拉Z轴皮带，将热床完全下降到底部，用螺丝将 3 个滑块固定。

|  |  |
| --- | --- |
|  |  |

### 步骤 15 - 锁热床

依次锁入 6 颗热床固定螺丝，不要直接拧紧。待确认热床放置没有问题后，将热床向前门方向靠，然后再锁紧6颗螺丝。

![](https://wiki.bambulab.com/x1/troubleshooting/homing-z-failed-2/heatbed_reset.jpg)

### 步骤 16 - 移除 3 颗滑块固定螺丝

热床固定好后，将固定滑块的 3 颗螺丝移除。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-heat-bed/remove_the_prefix_screws_0.jpg)

### 步骤 17 - 理线

理好热床线，穿回扎网，用胶带将扎网两端进行固定。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-heat-bed/remove_the_tapes.jpg)

### 步骤 18 - 安装地线

将地线穿过过线孔，连接到前门右立柱相应位置，锁入1颗螺丝将电源地线和热床地线一起锁紧。

|  |  |
| --- | --- |
|  |  |

### 步骤 19 - 安装电源线

安装电源线插头，然后将电源线连接到 AC 板的连接器上。

|  |  |
| --- | --- |
|  |  |

### 步骤 20 - 连接热床通信线

将热床通信线连接到 MC 板对应的连接器上，确认插到位，建议补上硅胶进行加固。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-heat-bed/disconnect_the_control_cable.jpg)

### 步骤 21 - 安装电源板保护盖

安装电源板保护盖，锁入 6 颗螺丝固定。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-heat-bed/install_the_power_board_cover.jpg)

### 步骤 22 - 安装废料滑梯

安装废料滑梯，注意两边的卡扣，锁紧 2 颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 23 - 安装线扣

安装热床线缆束线扣，然后将束线扣安装到滑梯底下的安装孔上。

|  |  |
| --- | --- |
|  |  |

### 步骤 24 - 安装右侧盖

装上右侧盖，根据下图所示位置，找到固定侧盖的 4+12 个螺丝位，并锁入螺丝固定。

|  |  |
| --- | --- |
|  |  |

更细节的安装右侧盖的操作，请参考页面[更换右侧面板](replace-right-panel.md)

### 步骤 25 - 安装后盖

安装后盖时，应首先穿过 PTFE 管支架和装好右侧的皮带张紧口位置。

|  |  |
| --- | --- |
|  |  |

### 步骤 26 - 锁紧螺丝

用螺丝将后盖重新固定。注意使用的不同类型的螺丝(如下图所示的10颗螺丝和4颗螺丝)。

## 如何验证完成/成功

连接电源线并打开电源。

确保腔室和热床上没有任何打印物品或挤出材料。然后进入 LCD 屏幕上的设置菜单，选择校准选项卡，然后按“开始校准”

![calibration.png](https://wiki.bambulab.com/screen-operation/calibration.png)

如果一切正常，并且在校准过程中没有出现错误或警告，则更换成功。否则，请检查连接并重试。如果问题仍然存在，请联系服务团队寻求进一步帮助。
