## 什么是AMS入料口组件

 AMS入料口组件主要由带漏斗状进料口的结构件和上下料电路板件构成。

![](https://wiki.bambulab.com/x1/maintenance/replace-feed-funnel-assay/funnel_assy.jpg)

## 何时更换

漏斗状进料口严重磨损，已经对上下料造成了影响，或经售后人员确认为上下料器电路板件故障。

![](https://wiki.bambulab.com/x1/maintenance/replace-feed-funnel-assay/worn_funnel_assy.jpg)

## 所需工具和材料

1. 新的AMS入料口组件

2. H2.0/H1.5 内六角扳手

3. 镊子

4. 钳子

## 开始操作前的安全警告和机器状态

关闭打印机电源并断开AMS 与打印机的连接。

## 操作指南

### **第 1 步 - 从AMS上拆下上下料器**

请参考 [更换AMS上下料组件](replace-first-stage-feeder.md)  的步骤1~7的内容将需要处理的AMS上下料组件拆下并移除料管。

![](https://wiki.bambulab.com/x1/maintenance/replace-feed-funnel-assay/the_first_stage_feeder.jpg)

### **第 2 步 -** 移除螺丝

用H1.5内六角扳手移除4颗螺丝。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 - 分离底座和上盖**

将上盖从底座上分离开来，移除弹簧，断开上下料电路板的电缆连接。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 - 将转轴敲击出来**

利用内六角扳手和钳子，将料嘴转轴敲击出来，注意转轴出来的地方要留有避让位置。

|  |  |
| --- | --- |
|  |  |

### **第 5 步 - 移除转轴，取下**AMS入料口组件

用镊子移除转轴，然后取下AMS入料口组件 。

|  |  |
| --- | --- |
|  |  |

### **第 6 步 - 安装**AMS入料口组件**，压入转轴**

安装AMS入料口组件，压入料嘴转轴，可以用钳子将转轴敲到位。

|  |  |
| --- | --- |
|  |  |

### **第 7 步 - 装弹簧，连接电缆**

将弹簧安装到AMS入料口组件上，并接上电缆。

|  |  |
| --- | --- |
|  |  |

### **第 8 步 - 组合上盖和底座**

调整好齿轮组件的位置，将上盖和底座接合起来，在接合的过程中，用镊子调整弹簧位置并将另一端安装到底座凸柱上。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/ams/maintenance/20250307-092455.webp)

### **第 9 步 - 检查齿轮组位置**

接合到位后，检查齿轮组的位置，如果位置不对，请调整齿轮位置后重新安装。

|  |  |
| --- | --- |
|  |  |

### **第 10 步 - 锁附螺丝**

依次锁入4颗螺丝固定，锁到位即可，不可大力拧紧，防止滑牙。

|  |  |
| --- | --- |
|  |  |

### **第 11 步 - 安装上下料组件到AMS**

请参考 [更换AMS上下料组件](replace-first-stage-feeder.md)  的步骤8~14的内容将料管接好，将上下料器安装到AMS上，并组装好AMS。

## 如何验证完成/成功

将 AMS 连接到打印机并打开电源。将材料装载到您更换了料嘴的料槽上，单击屏幕上的“进料”开始加载打印丝。

![](https://wiki.bambulab.com/x1/maintenance/replace-first-stage-feeder/494px-load1.png)

这里以料槽1为例

进料完成后，再单击“退料”开始退打印丝。

![](https://wiki.bambulab.com/x1/maintenance/replace-first-stage-feeder/557px-unload_filament.png)

重复以上操作3次，如果所有功能OK，则更换完成并成功。

否则，请检查电缆和料管的连接后重试，如果没有发现异常但仍存在故障，请联系服务团队寻求解决方案。
