# 前面盖

X系列打印机的前面盖是安装在打印机正面上方，并印刷有打印机型号（X1 或 X1C）的银灰色盖子。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-front-cover/x1_front_cover.jpg)

## 何时更换

一般情况下都是因为物流运输导致了前面盖损坏才会进行更换。

## 所需工具和材料

- 新的前面盖
- H2.0 内六角扳手
- 平头镊子

# 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

# 移除旧的前面盖

## **第 1 步 -**关闭电源

关闭打印机电源，打开前玻璃门，取下玻璃盖板。

## **第 2 步 - 移除高清屏幕**

|  |  |
| --- | --- |
| 将屏幕向上倾斜并按压图示位置以松开卡扣，再向右推动整个组件将高清屏幕解锁。 | 按下 FPC 连接器的两侧以解锁连接器，移除高清屏幕。 |

## **第 3 步 - 回退屏幕FPC**

|  |  |
| --- | --- |
| 松出约束屏幕FPC的透明固定胶带 | 将屏幕FPC 从方孔中往回抽出。 |

## **第 4 步 - 松电缆**

将按键板连接电缆从卡扣中松脱出来。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-button-board/buckles.jpg)

## **第 5 步 - 松右侧盖边角（右前上角）**

如下图所示，移除3颗固定右侧盖的螺丝，使右侧盖右上角可以松动，以方便拆前面盖。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-button-board/corner_screws.jpg)

## **第 6 步 - 移除前面盖固定螺丝**

|  |  |
| --- | --- |
| 移除固定前面盖的2颗细牙螺丝（正面）。 | 移除1颗粗牙螺丝（背面）。 |

## **第 7 步 - 移除WIFI天线**

|  |  |
| --- | --- |
| 用平头镊子将WIFI天线从前面盖上撬起。 | 将WIFI天线从前面盖上分离。 |

## **第 8 步 - 移除前面盖**

|  |  |
| --- | --- |
| 将前面盖两边向上推出少许，解除卡扣的锁定。 | 先将前面盖右侧位置松出，再将整个前面盖从横梁上移除。 |

# 安装新的前面盖

## **第1 步 - 安装前面盖**

|  |  |
| --- | --- |
| 如下图，按步骤提示，先安装前面盖左侧，然后再将前面盖右侧安装到位。 | 然后左右两边同时向下按压前面盖，将其安装到位。 |

## **第2 步 - 锁前面盖螺丝**

|  |  |
| --- | --- |
| 在前面盖正面锁入2颗细牙螺丝。 | 在前面盖背面锁入1颗粗牙螺丝。 |

## **第3 步 - 固定右侧盖**

锁入移除的3颗固定右侧盖右上角的螺丝。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-button-board/corner_screws.jpg)

## **第4 步 - 整理电缆**

将按键板连接电缆整理到线扣上。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-button-board/buckles.jpg)

## **第5 步 - 贴附WIFI天线**

如下图所示，紧贴边缘将WIFI天线粘接到前面盖上。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-front-cover/attach_wifi.jpg)

## **第 6 步 - 穿屏幕FPC**

|  |  |
| --- | --- |
| 将屏幕连接FPC按下图的朝向，穿过方孔。 | 理好排线、电缆，贴上透明固定胶带。 |

## **第 7 步 - 安装高清屏幕**

将屏幕FPC 连接到高清屏幕上的连接器，将多余的 FPC 排线退回打印机，将高清屏幕安装到打印机的 4 个插槽中，然后轻轻向左推，直到听到卡扣到位的声音乐，完成安装，盖上玻璃盖板。

# 功能确认

开机状态下，检查显示功能和按键功能。

1. 启动打印机，确认打印机屏幕能正常显示且触摸屏功能正常；

![](https://wiki.bambulab.com/x1/maintenance/replace-high-resolution-screen/615px-screen.png)

2. 按下睡眠按键确认能将显示屏熄屏，再次按下睡眼按键，显示屏能恢复显示，并且按键感正常。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-button-board/sleep_button.jpg)

否则，请检查连接并重试。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。

# 设备校准

更换前面盖不需要进行设备校准。
