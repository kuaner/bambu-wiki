## X1C/P1 打印机线材包（ 4 合一）

适用于 X1C 和 P1 系列打印机的 4 根内部连接线材包。

1. MC 板到 AC 控制板连接线 1 根；   
2. 热床电源线 1 根；   
3. MC 板到 AMS 接口板连接线 1 根；   
4. MC 板的电源线 1 根。

(从左往右)

![](https://wiki.bambulab.com/x1/maintenance/4-in-1/4_in_1.jpg)

## 何时更换

- 两端的插头有物料损坏，影响安装；
- 连接线有明显的损伤或断路；
- 拓竹服务团队通过日志文件确认的连接线有异常。

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 拆装金属背板、废料滑梯、护线盖

### **第 1 步 - 拆装金属背板**

参考 [金属后面板](replace-rear-panel.md) 的相关内容，移除（或安装）金属后面板。

### 步骤2 - 拆装废料滑梯

|  |  |
| --- | --- |
| 如下图所示，用 H2.0 内六角扳手拆除 1 颗银色螺丝 | 用 H1.5 内六角扳手拆除2颗黑色螺丝，取下废料滑梯 |

|  |  |
| --- | --- |
| 安装废料滑梯，注意滑梯两侧需要安装到位，右侧确认没有压到电缆 | 在滑梯上方锁入 2 颗黑色螺丝；在左侧锁入 1 颗银色螺丝 |

### 步骤 3 - 拆装护线盖

|  |  |
| --- | --- |
| 用 H2.0 内六角扳手移除 2 颗螺丝，取下走线槽 | 用 H1.5 内六角扳手移除 6 颗螺丝，取下护线盖 |

|  |  |
| --- | --- |
| 安装好护线盖，锁入 6 颗固定螺丝 | 安装走线槽，锁入 2 颗螺丝固定 |

## 更换 AMS 接口板连接线

连接主控板和 AMS 接口板的黑色线缆

![](https://wiki.bambulab.com/x1/maintenance/4-in-1/ams_cable.jpg)

将连接线从 AMS 接口板上断开，然后再将连接线从主控板上断开，即可移除 AMS 接口板连接线。

注意插头卡扣的方向，将连接线接到主控板和 AMS 接口板对应的连接器上即可。

![](https://wiki.bambulab.com/x1/maintenance/4-in-1/connectors_for_ams_interface_cable.jpg)

## 更换 MC-AC 连接线

连接 AC 控制板和主控制板的灰色线缆。

|  |  |
| --- | --- |
|  |  |

用镊子去除主控板上连接器处的部分白胶，依次断开连接线与主控板和 AC 控制板的连接，然后撕开黑色固定胶布，取下旧的 MC-AC 连接线。

|  |  |
| --- | --- |
|  |  |

按下图所示穿好新的 MC-AC 连接线，并连接到对应接口上，使用原来的黑色胶带固定线线并给主控板处的连接器涂上白色硅胶进行加固。

## 更换 MC 板电源线

从电源模块到主控板的连接电缆，主要作用是给主板供电。

| --- | --- |
|  |  |

## 更换热床电源线

从 AC 控制板连接到热床，并为热床供电的黑色线缆。

![](https://wiki.bambulab.com/x1/maintenance/4-in-1/heatbed_power_cable.jpg)

参考 [热床信号线（新版）](Replacing-the-heat-bed-cable-v3.md) 的相关内容，将热床从 3 个滑块上取下，底面朝上放置在打印机底座上。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/upside_down_the_heat_bed.jpg)

用 H1.5 内六角扳手，移除 2PCS 螺丝，取下端子盖，然后用十字螺丝刀移除 2 颗螺丝，取下旧的热床电源线。

|  |  |
| --- | --- |
|  |  |

将新的热床电源线连接到热床端子处，并用螺丝锁紧，然后盖上端子盖，锁入两颗螺丝固定。

|  |  |
| --- | --- |
|  |  |

然后参考 [热床信号线（新版）](Replacing-the-heat-bed-cable-v3.md) 的相关内容，将热床安装好，并整理后连接线。

![](https://wiki.bambulab.com/x1/maintenance/4-in-1/heat_bed_installed.jpg)

## 功能确认

1. 将 AMS 与打印连接，启动打印机，给 AMS 供电，AMS 上下料处的指示灯亮起，供电正常，说明主控板电源线和 AMS 接口板连接线连接正常；

2. 在显示屏上设置热床温度，热温能正常升温加热，说明 MC-AC 连接线以及热床电源线连接正常。

否则，请再次检查所有连接并重试。如果仍然不行，请联系 Bambu Lab 服务团队寻求进一步帮助。

## 设备校准

更换热床电源线需要重新执行设备校准，校准操作如下：

确保腔室和热床上没有任何打印物品或挤出材料。然后进入 LCD 屏幕上的设置菜单，选择校准选项卡，然后按“开始校准”。

![](https://wiki.bambulab.com/x1/manual/calibration.png)

如果一切正常，并且在校准过程中没有出现错误或警告，则更换成功。否则，请检查连接并重试。如果问题仍然存在，请联系服务团队寻求进一步帮助。
