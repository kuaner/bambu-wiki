## 什么是 MC 板冷却风扇

MC (机器控制器)板冷却风扇是安装在 MC 板上，用于给 MC 板芯片散热的风扇。

![](https://wiki.bambulab.com/x1/maintenance/replace-mc-board-fan/392px-mc_board_fan.png)

## 何时更换

1. 屏幕上出现相关风扇的警告，如“电机驱动器过热，它的散热器可能松动，或者它的冷却风扇可能损坏”，并且检查确认连接线状态正常，这时很有可能需要更换 MC 板冷却风扇。

2.  MC 板冷却风扇异响。

## 所需的工具和材料

- 一个新的 MC 板冷却风扇
- H1.5 和 H2.0 内六角扳手
- 镊子

## 开始操作前的安全警告和机器状态

在开始操作前，请确认机器已关闭。如有连接 AMS，则需要先将 PTFE 管和供料缓冲器移除。

## 操作指南

### 步骤1 - 拆除螺丝

注意：这个过程涉及到很多螺丝，请将它们区分开来，并把它们放在不同的区域，以免弄混。

如图所示，取下后盖上的 10 颗螺丝和 4 颗螺丝。这是两种类型的螺丝，所以要把它们分开。

### 步骤 2 - 拆除后盖

拆下后盖，先将后盖从左侧（面向后盖）皮带张紧口的位置松开，再松开右侧（面向后盖）皮带张紧口的位置，以免卡住。

|  |  |
| --- | --- |
|  |  |

### 步骤 3 - 移除废料滑梯

拧下固定螺丝，并拆下废料滑梯。**请注意，有一些打印机使用2颗螺丝固定废料滑梯，而有些打印机使用了3颗螺丝固定废料滑梯，具体使用了几颗螺丝，请检查您的打印机。**

注意：早期的版本，滑梯底下有用卡扣固定的热床线缆，取下滑梯时不要用力过猛。

### 步骤 4 - 断开电机电缆

找到位于机器背面右侧的 MC 板，并将 MC 板底部的 2 根电机连接线断开(注意:左边的是 Z 轴电机的电缆)。

### 步骤 5 - 拆下散热器

松开固定散热器的 2 颗螺丝，然后取下散热器。

|  |  |
| --- | --- |
|  |  |

### 步骤 6 - 移除 MC 板风扇

将 MC 板冷却风扇连接线从 MC 板上断开，并向外拉出风扇。风扇是用 AB 胶固定的，因此可能需要稍微用力才能将风扇拉出。如果拆除风扇比较困难，可以尝试用电吹风吹热 AB 胶后，再尝试拆除风扇。

|  |  |
| --- | --- |
|  |  |

### 步骤 7 - 贴附双面胶

准备好新的 MC 板冷却风扇，将旧风扇上的双面胶移到新风扇对应的面上贴附好。

![](https://wiki.bambulab.com/x1/maintenance/replace-mc-board-fan/427px-fan_adhesive.png)

### 步骤 8 -安装风扇

背胶朝向打印机内衬，将风扇装入指定的安装槽内，风扇的标签应朝向 MC 板（即散热片的方向）。

如下图所示，沿 MC 板整理风扇电缆，然后将其连接到 MC 板的接口上。

### 步骤 10 -安装散热器

将散热器放回 MC 板上，并用 2 个螺钉固定。

### 步骤 11 -连接电机电缆

将 2 根电机电缆重新连接到 MC 板上，注意左边的连接器是用于 Z 轴电机电缆的连接器。

将废料滑梯装回原位，安装时注意滑槽两侧突出的止扣，锁紧 2 颗螺丝。

用螺丝将后盖重新固定。注意使用的不同类型的螺丝(如下图所示的 10 颗螺丝和 4 颗螺丝)。

## 如何验证完成/成功

连接电源线并打开电源。如下所示运行设备自检操作，如果没有出现错误，则更换成功。

![selftest.png](https://wiki.bambulab.com/screen-operation/selftest.png)

否则，请检查所有连接，然后重试。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
