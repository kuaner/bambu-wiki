## 擦嘴组件

热端擦嘴组件是一种安装在废料滑梯边缘的带弹性的工具，用于在打印前清理打印机喷嘴溢出的废料。它由IPP弹性结构、聚四氟乙烯管以及锁紧螺钉组成。

## 何时更换

当擦嘴组件变形或破裂时，更换喷嘴擦拭组件。

## 所需工具和材料

- 新的擦嘴组件
- H2.0 内六角扳手

## 开始运行前的安全警告和机器状态

关闭打印机电源。

## 操作指南

### **第 1 步 - 取下顶部玻璃盖板**

关闭打印机电源并取下顶部玻璃盖板，将工具头移出废料滑梯，以便更好拆装擦嘴组件。

![](https://wiki.bambulab.com/x1/maintenance/replace-nozzle-wiper/373px-excess_chute.png)

### **第 2 步 - 拆下旧的**擦嘴组件

移除 1 颗螺丝并取下擦嘴组件。

![](https://wiki.bambulab.com/x1/maintenance/replace-nozzle-wiper/391px-wiper_screw.png)

### **第 3 步 - 安装新的**擦嘴组件

将新的擦嘴组件安装到位。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 - 固定**擦嘴组件

锁入 1 颗螺丝固定擦嘴组件，然后放回玻璃盖板。

![](https://wiki.bambulab.com/x1/maintenance/replace-nozzle-wiper/391px-wiper_screw_(1).png)

## 如何验证完成/成功

手动检查打印头擦拭器和螺丝是否正确固定。
