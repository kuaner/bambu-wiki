## 什么是AMS下盖组件

AMS下盖组件是指已安装所有密封件的AMS底壳。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-ams-bottom-cover-unit/ams_bottom_cover_unit.jpg)

> *注意：由于不同物料批次的生产工艺差异，导致产品在结构上有细微区别，该区别对产品功能不产生任何影响。*
>
> ![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-top-lid-bottom-cover/%E5%AF%B9%E6%AF%94-.png)

## 何时更换

1. 底壳开裂；
2. 运输导致的损坏，用户要求更换底壳。

## 所需工具和材料

- 新的AMS底壳
- H2.0 内六角扳手

## 开始操作前的安全警告和机器状态

在开始操作之前，请确认AMS已经从打印上断开连接。

## 操作指南

### 步骤 1 - 拆除PTFE管

打开AMS上盖，按压AMS 五通组件上的按钮（解锁快速接头），然后从AMS背面拉出PTFE管。

|  |  |
| --- | --- |
|  |  |

### 步骤2 - 松开AMS主框架

如下图所示，移除固定AMS主框架上2颗螺丝，然后向上转动翻起主框架。您可能需要按压五通组件上的按钮来将主框架后部完全翻转起来，但注意不要将主框架组件完全取出，因为仍然有电缆连接在上面。

|  |  |
| --- | --- |
|  |  |

### 步骤3 - 移除AMS主框架组件

将Bambu总线电缆和电源电缆从AMS电源板上断开，现在，您可以取出AMS主框架组件了。

![](https://wiki.bambulab.com/x1/maintenance/replace-ams-power-board/377px-2_cables_ams_power_board.png)

### 步骤4 - 移除AMS电源板

移除固定AMS电源板的4个螺丝，然后取下电源板。

|  |  |
| --- | --- |
|  |  |

### 步骤5 - 移除AMS上盖

从AMS底部移除4颗螺丝，左右各2颗，然后移除AMS上盖。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-ams-bottom-cover-unit/remove_4_screws.jpg)

![](https://wiki.bambulab.com/x1/maintenance/replace-the-ams-bottom-cover-unit/remove_the_upper_cover.jpg)

### 步骤6 - 安装AMS上盖到新底壳

准备一个新的AMS底壳，将已穿上转轴的上盖安装到底壳上，锁入4颗螺丝进行固定。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/x1/maintenance/replace-the-ams-bottom-cover-unit/remove_4_screws.jpg)

### 步骤7 - 安装AMS电源板

安装AMS电源板，用4颗螺丝将其固定在AMS外壳的内侧，如下所示。

|  |  |
| --- | --- |
|  |  |

### 步骤8 -安装AMS主框架组件

将AMS主框架组件装入AMS外壳，并将Bambu总线电缆和电源电缆连接到AMS电源板。

|  |  |
| --- | --- |
|  |  |

### 步骤9 - 固定AMS主框架组件

如下图所示，将AMS主框架安装到位，用2颗螺丝固定AMS主框架组件。

![](https://wiki.bambulab.com/x1/maintenance/replace-ams-power-board/524px-remove_2_screw.png)

### 步骤10 - 连接PTFE管

检查确认PTFE管硅胶支架与五通组件的料孔对齐，并从AMS后部推入PTFE管。装完后，拉动PTFE管，确认PTFE管已固定。

|  |  |
| --- | --- |
|  |  |

## 如何验证完成/成功

连接电源线，将AMS连接到打印机，打开电源，通过机器显示屏的操作，开始使用AMS上料，如果能完成上料动作并且整个上料过程没有出现错误提示，则更换成功。

![](https://wiki.bambulab.com/x1/maintenance/replace-ams-power-board/494px-load1.png)

否则，请检查所有连接，然后重试。如果问题仍然存在，请联系Bambu Lab服务团队寻求进一步帮助。
