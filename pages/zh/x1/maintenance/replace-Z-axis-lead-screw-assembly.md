## Z 轴丝杆套件

适用于 X/P 系列打印机的 Z 轴丝杆套件包含丝杆、丝杆螺母、法兰轴承（丝杆顶部）、法兰轴承（丝杆底部）以及螺丝等。  
![20250110-142728.jpg](https://wiki.bambulab.com/x1/maintenance/replace-z-axis-screw-assembly/20250110-142728.jpg)

X/P 打印机上共有三个丝杆，靠近前门立柱的两个丝杆拆装方式相同，本指南以左侧丝杆拆装为例。

靠近打印机背部的丝杆由于被内衬挡住，需要将内衬螺丝松开后再进行拆装。

顶部/底部法兰轴承内径不同，顶部法兰轴承内径比底部法兰轴承内径更大（下图左为顶部法兰轴承F688Z，右为底部法兰轴承F625Z）：

![顶部底部法兰轴承.jpg](https://wiki.bambulab.com/x1/maintenance/replace-z-axis-screw-assembly/%E9%A1%B6%E9%83%A8%E5%BA%95%E9%83%A8%E6%B3%95%E5%85%B0%E8%BD%B4%E6%89%BF.jpg)

## 适用打印机型号

X1C/P1P/P1S/X1E

## 何时更换

1. 丝杆变形
2. 丝杆螺母磨损
3. 法兰轴承损坏

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 所需工具和材料

- Z 轴丝杆套件（如需更换，请[提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)联系售后团队）
- H2.0 内六角扳手
- BT3-28-15 螺丝 - 用于固定热床 \* 3

## 移除前门立柱两侧 Z 轴丝杆

本指南以 P1P 为例，演示更换前门立柱左侧的丝杆，右侧的丝杆可参考相同的方法进行更换。

### 步骤 1：移除丝杆螺母固定螺丝

使用 H2.0 内六角扳手移除四颗丝杆螺母固定螺丝；

![丝杆螺母固定螺丝.jpg](https://wiki.bambulab.com/x1/maintenance/replace-z-axis-screw-assembly/%E4%B8%9D%E6%9D%86%E8%9E%BA%E6%AF%8D%E5%9B%BA%E5%AE%9A%E8%9E%BA%E4%B8%9D.jpg)

### 步骤 2：移除底部法兰轴承固定螺丝

使用 H2.0 内六角扳手移除两颗法兰轴承固定螺丝；

![法兰轴承固定螺丝.jpg](https://wiki.bambulab.com/x1/maintenance/replace-z-axis-screw-assembly/%E6%B3%95%E5%85%B0%E8%BD%B4%E6%89%BF%E5%9B%BA%E5%AE%9A%E8%9E%BA%E4%B8%9D.jpg)

### 步骤 3：移除 Z 轴同步轮/Z 皮带

将打印机侧放，使用 H2.0 内六角扳手拧松一颗 Z 轴张紧器固定螺丝，并将扭簧释放，然后将 Z 轴皮带从同步轮上取出。

![](https://wiki.bambulab.com/p1/maintenance/z-belt/remove_the_cover.jpg)

使用 H2.0 内六角扳手移除两颗同步轮固定螺丝，然后使用铲刀铲除同步轮与丝杆间的 AB 胶；

> 注意：使用铲刀铲除 AB 胶时请小心，避免划伤。

|  |  |
| --- | --- |
|  |  |

然后将热床移动至底部（打印机倒置后），再拿住 Z 轴同步轮，向上提起并移除 Z 轴同步轮。

### 步骤 4：移除 Z 轴丝杆/法兰轴承

使用 H2.0 内六角扳手顶住丝杆底部，然后用力将丝杆敲出。

![移除丝杆.jpg](https://wiki.bambulab.com/x1/maintenance/replace-z-axis-screw-assembly/%E7%A7%BB%E9%99%A4%E4%B8%9D%E6%9D%86.jpg)

然后将顶部的法兰轴承和硅胶套从丝杆上取下，如果底部的法兰轴承留在打印机底座上，用内六角扳手敲出即可；如果和丝杆一起取出，则将法兰轴承从丝杆上拆下。

> 注：如果法兰轴承损坏，可以使用套件中附带的法兰轴承。

## 安装前门立柱两侧 Z 轴丝杆

### 步骤 1：安装法兰轴承

将打印机底部的法兰轴承安装至对应的孔位，然后使用 H2.0 内六角扳手拧紧两颗固定螺丝；

![安装法兰轴承.jpg](https://wiki.bambulab.com/x1/maintenance/replace-z-axis-screw-assembly/%E5%AE%89%E8%A3%85%E6%B3%95%E5%85%B0%E8%BD%B4%E6%89%BF.jpg)

### 步骤 2：安装丝杆和同步轮

先将丝杆螺母安装进丝杆中，然后将塑料垫圈安装至丝杆底部，然后先将丝杆插入 Z 轴滑块，再将丝杆插入法兰轴承中。

|  |  |
| --- | --- |
| 安装丝杆螺母和垫圈.jpg | 安装丝杆.jpg |

> 建议用手扶着丝杆，避免掉落；

然后将 Z 轴同步轮上的平面对准丝杆的平面，将同步轮插入丝杆中，再使用 H2.0 内六角扳手拧紧两颗固定螺丝；

|  |  |
| --- | --- |
| 丝杆和同步轮平面.jpg) |  |

### 步骤 3：固定热床

将打印机正放，先检查打印机底部是否存在异物，然后将热床降低至打印机底部（打印机翻转后热床将自动降低至底部），使用 H2.0 内六角拧紧三颗固定螺丝（BT3x28x15）。

![](https://wiki.bambulab.com/p1/maintenance/z-motor/lower_the_head_bed_and_lock_the_sliders.jpg)

> 可以使用开箱时固定热床的螺丝。如丢失，则可以使用相同规格的螺丝（BT3x28x15，螺纹长度 15mm）。

### 步骤 4：拧紧丝杆螺母固定螺丝

使用 H2.0 内六角扳手拧紧四颗固定螺丝。

|  |  |
| --- | --- |
| 丝杆螺母螺丝孔位.jpg | 丝杆螺母固定螺丝.jpg |

> 如果丝杆螺母的螺丝孔位没有完全对准 Z 轴滑块上的孔位，请检查步骤 3 中热床固定螺丝是否完全拧到位，以及热床底部是否存在异物。如果已经拧紧，可以尝试手动转动底部同步轮来将螺丝孔位对齐。

### 步骤 5：安装 Z 轴皮带

将打印机侧放，将 Z 轴皮带重新绕回 Z 轴同步轮以及 Z 轴电机，然后将扭簧重新扣回；

![](https://wiki.bambulab.com/p1/maintenance/z-motor/right_side_down.jpg)

然后使用 H2.0 内六角扳手移除三颗热床固定螺丝，将热床解锁后手动往复拉动 Z 轴皮带几次，然后使用 H2.0 内六角扳手拧紧 Z 张紧器螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 6：安装顶部法兰轴承和硅胶塞

将法兰轴承压入丝杆顶部，然后将硅胶套装入。

## 移除打印机背部丝杆

本指南以 P1P 为例，演示更换打印机背部的丝杆。

### 步骤1：移除打印机背板

您可以根据机型，来参考对应的 Wiki 移除打印机背板：

- P1P [更换P1P金属后面板 | Bambu Lab Wiki](../../p1/maintenance/rear-panel.md)
- P1S [更换P1系列金属背板 | Bambu Lab Wiki](../../p1/maintenance/p1s-rear-panel.md)
- X1C [更换X1系列金属后面板 | Bambu Lab Wiki](replace-rear-panel.md)
- X1E [X1E 封闭机箱拆装指引 | Bambu Lab Wiki](x1e-enclosure.md)

### 步骤 2：移除丝杆螺母固定螺丝和法兰轴承固定螺丝

使用 H2.0 内六角扳手移除四颗丝杆螺母固定螺丝；使用 H2.0 内六角扳手移除两颗法兰轴承固定螺丝；

|  |  |
| --- | --- |
| 丝杆螺母固定螺丝.jpg | 法兰轴承固定螺丝.jpg |

### 步骤 3：移除 Z 轴同步轮

将打印机倒置，使用 H2.0 内六角扳手移除两颗同步轮固定螺丝，然后使用铲刀铲除同步轮与丝杆间的 AB 胶；

|  |  |
| --- | --- |
|  |  |

> 使用铲刀铲除 AB 胶时请小心，避免划伤。

然后将热床移动至底部（打印机倒置后），再拿住 Z 轴同步轮，向上提起并移除 Z 轴同步轮。

### 步骤 4：解锁内衬

使用 H2.0 内六角扳手移除三颗内衬固定螺丝，然后将电机线缆从线扣中取出，将内衬往外推，露出顶部的法兰轴承；

|  |  |  |
| --- | --- | --- |
| 内衬上部固定螺丝.jpg | 电机线.jpg | 推开内衬.jpg |

> 请将热床降低至打印机底部，再往外推内衬。

### 步骤 5：移除丝杆/法兰轴承

将打印机侧放，然后使用 H2.0 内六角扳手顶住丝杆底部，然后用力将丝杆敲出。

![移除丝杆.jpg](https://wiki.bambulab.com/x1/maintenance/replace-z-axis-screw-assembly/%E7%A7%BB%E9%99%A4%E4%B8%9D%E6%9D%86.jpg)

然后将顶部的法兰轴承和硅胶套从丝杆上取下，如果底部的法兰轴承留在打印机底座上，用内六角扳手敲出即可；如果和丝杆一起取出，则将法兰轴承从丝杆上拆下。

> 注：如果法兰轴承损坏，可以使用套件中附带的法兰轴承。

## 安装打印机背部丝杆

### 步骤 1：安装底部法兰轴承

将打印机底部的法兰轴承安装至对应的孔位，然后使用 H2.0 内六角扳手拧紧两颗固定螺丝；

![安装法兰轴承.jpg](https://wiki.bambulab.com/x1/maintenance/replace-z-axis-screw-assembly/%E5%AE%89%E8%A3%85%E6%B3%95%E5%85%B0%E8%BD%B4%E6%89%BF.jpg)

### 步骤 2：安装丝杆和同步轮

将塑料垫圈安装至丝杆底部，然后先将丝杆插入 Z 轴滑块，再将丝杆插入法兰轴承中。

|  |  |
| --- | --- |
| 安装丝杆螺母和垫圈.jpg | 安装丝杆.jpg |

> 建议用手扶着丝杆，避免掉落；

然后将 Z 轴同步轮上的平面对准丝杆的平面，将同步轮插入丝杆中，再使用 H2.0 内六角扳手拧紧两颗固定螺丝；

|  |  |
| --- | --- |
| 丝杆和同步轮平面.jpg) |  |

### 步骤 3：安装顶部法兰轴承和内衬

将顶部的法兰轴承从上往下压入，然后将硅胶塞装入；

然后将内衬扣回原位，使用 H2.0 内六角扳手拧紧三颗固定螺丝，并将电机线扣入线扣中。

|  |  |
| --- | --- |
| 内衬上部固定螺丝.jpg | 电机线.jpg |

### 步骤 4：固定热床

将打印机正放，先检查打印机底部是否存在异物，然后将热床降低至打印机底部（打印机翻转后热床将自动降低至底部），使用 H2.0 内六角拧紧三颗固定螺丝。

![](https://wiki.bambulab.com/p1/maintenance/z-motor/lower_the_head_bed_and_lock_the_sliders.jpg)

> 螺丝可以使用开箱时固定热床的螺丝，如开箱时固定热床的螺丝丢失，如有该规格的螺丝可使用，或通过 Bambu Lab 官方商城购买该规格的螺丝。

### 步骤 5：拧紧丝杆螺母固定螺丝

使用 H2.0 内六角扳手拧紧四颗热床螺母固定螺丝。

|  |  |
| --- | --- |
| 丝杆螺母螺丝孔位.jpg | 丝杆螺母固定螺丝.jpg |

### 步骤 6：安装 Z 轴皮带

将打印机继续侧放，将 Z 轴皮带重新绕回 Z 轴同步轮以及 Z 轴电机，然后将扭簧重新扣回；

![](https://wiki.bambulab.com/p1/maintenance/z-motor/right_side_down.jpg)

### 步骤 7：安装丝杆硅胶套

将硅胶套放置在丝杆上。通过打印机屏幕控制热床上下运动。丝杆转动的同时压入硅胶套，使其贴合丝杆。

## 功能确认

连接电源并启动打印机，点击回中，确认打印机是否可以正常回中。

如果无法正常回中/或热床不平，则请按照操作步骤排查组装是否有问题，排除后，再次运行设备自检。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步的帮助。
