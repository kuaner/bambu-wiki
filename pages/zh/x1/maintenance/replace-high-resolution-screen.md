## 什么是高清屏幕

X1 系列打印机使用的高清屏幕是 5 英寸的、分辨率为 1280\*720 的触摸屏，可用于控制打印机。

![](https://wiki.bambulab.com/x1/maintenance/replace-high-resolution-screen/427px-high_resolution_screen.png)

## 何时更换

如果连接高清屏幕的 FPC 检查正常，但 LCD 屏幕一直黑屏、闪烁或有其他显示故障时，很可能需要更换高清屏幕。

## 所需工具和材料

新的高清屏幕

## 开始运行前的安全警告和机器状态

进行任何拆卸或组装工作时，请关闭打印机电源。

## 操作指南

### **第 1 步 -** 解锁屏幕

关闭打印机电源。将屏幕向上倾斜并按压图示位置以松开卡扣，再向右推动以解锁高清屏幕。

|  |  |
| --- | --- |
|  |  |

### **第 2 步 - 断开 FPC**

按下 FPC 连接器的两侧以解锁连接器，移除高清屏幕。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 -** 连接 FPC

拉出 FPC 少许，按下 FPC 连接器的两侧，将 FPC 连接器接入到高清屏幕背面的连接器。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 - 安装高分辨率屏幕**

将多余的 FPC 排线退回打印机，将高清屏幕安装到打印机的 4 个插槽中，然后轻轻向左推，直到听到卡扣到位的声音，完成安装。

|  |  |
| --- | --- |
|  |  |

## 如何验证完成/成功

开启打印机电源。如果液晶屏亮起且显示无异常，触摸屏功能响应正常，则更换完成。

![](https://wiki.bambulab.com/x1/maintenance/replace-high-resolution-screen/615px-screen.png)

否则，请再次检查连接线后重试。如果仍然不行，请联系 Bambu Lab 服务团队寻求进一步帮助。
