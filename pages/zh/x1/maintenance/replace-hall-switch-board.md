## 什么是霍尔开关板组件

霍尔开关板组件是安装在挤出机上，主要由霍尔开关板、挤出机入料口和固定座组装而成的组件。它除了是挤出机的供料入口，还同时具备检测料线和切刀状态的功能。

![](https://wiki.bambulab.com/x1/maintenance/replace-extru-sw-assembly/x-extru-sw.jpg)

## 何时更换

- 连接电缆损坏；
- 误报退料异常；
- 误报切刀卡住，经拓竹服务团队确认是霍尔检查开关的问题。

## 所需工具和材料

新的霍尔开关板组件

H1.5 内六角扳手

## 螺丝清单

|  |  |  |  |
| --- | --- | --- | --- |
|  | 型号 | 位置 | 规格 |
| 螺丝A | BT2\*05 | 霍尔开关组件底座 |  |
| 螺丝B | MG2.5\*13 | 切刀刀柄 |  |

## 开始运行前的安全警告和机器状态

移除打印材料，在进行拆卸和组装工作时需关闭打印机电源。

## 操作指南

### **步骤 1 -** 打开前盖组件

关闭打印机电源，打开工具头前盖组件。

![](https://wiki.bambulab.com/x1/maintenance/replace-extru-sw-assembly/open_the_front_housing_2.jpg)

### **第 2 步 - 移除料管，松切刀柄**

按压料管支架，移除料管，用 H1.5 内六角扳手拧松切刀柄螺丝（螺丝 B），使刀柄下垂。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 - 断开电缆连接**

断开热端加热器、热端风扇和 NTC 电阻连接线，露出霍尔开关板连接线接口。用电吹风加热硅胶，然后断开连接线。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 - 移除霍尔开关板组件**

用 H1.5 内六角扳手移除 2 颗螺丝(螺丝 A)，将内六角扳手伸入气动接口将组件撬松，然后取下霍尔开关板组件。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/x1/maintenance/replace-extru-sw-assembly/remove_the_assembly.jpg)

### **第 5 步 - 安装霍尔开关板组件**

按压霍尔开关板组件上的气动接头，将开关板组件安装到位，然后锁入 2 颗螺丝(螺丝 A)进行固定。

|  |  |
| --- | --- |
|  |  |

### **第 6 步 - 连接电缆**

连接霍尔开关板电缆，建议对这个连接器使用硅胶进行加固。然后依次连接热端 NTC 电缆、热端风扇和热端加热器。

|  |  |
| --- | --- |
|  |  |

### **第 7 步 - 锁切刀刀柄，安装前盖**

将料管接入气动接头，然后用手扶起切片刀柄，将切刀滑入刀槽内，拧紧切刀柄螺丝(螺丝 B)，然后盖上前盖。

|  |  |
| --- | --- |
|  |  |

## 如何验证完成/成功

打开打印机电源，手动上料(或通过 AMS 加载耗材)，然后操作一次退料操作，能正常完成说明更换完成。

否则，请再次检查所有连接并重试。如果仍然不行，请联系 Bambu Lab 服务团队寻求进一步帮助。
