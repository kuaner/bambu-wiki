## 什么是保险丝

保险丝是一种安装在电路中、用于保证电路安全运行的电子元器件。不同设备的峰值功率不同，因此保险丝规格有所差异。

| 机型 | 规格 |
| --- | --- |
| X1C | 250V 6A |
| P1P/P1S | 250V 6A |
| X1E | 250V 10A |
| A1 | 250V 6A |
| H2 | 250V 10A |
| P2S | 250V 6A、12.5A |

**目前我们使用的保险丝外观主要有两种：**

- 玻璃壳保险丝（左图）：壳体透明，可以直观看到熔丝状态，便于判断是否熔断。通常适用于可视性要求高的场合。
- 陶瓷壳保险丝（右图）：壳体为白色陶瓷，不易看到内部熔丝，但其具有更高的耐压性和抗爆性能，在承载较大电流或更高风险的电路中更为常见和可靠。

|  |  |
| --- | --- |

目前我们主要采用白色陶瓷壳保险丝，但是部分机型使用的是玻璃壳保险丝。

## 何时更换

- 接通电源线后，若打开电源开关时电源指示灯不亮，很可能是保险丝已熔断所致。

![](https://wiki.bambulab.com//x1/maintenance/replace-fuse/390px-power_on_failed.png)

- 在通电状态下，如果电源指示灯突然熄灭，也可能是保险丝损坏引起的。

**此外，也可通过观察保险丝本身判断是否需要更换：**

- 若为**透明保险丝**，可直接通过**目视检查**判断是否熔断。若金属丝明显断裂、烧黑或有熔化痕迹，则说明保险丝已熔断，应及时更换。
- 若为**白色保险丝**，由于外壳不透明，无法直接观察熔丝状态，可借助**万用表**进行检测。将万用表拨至蜂鸣档（或电阻档），表笔分别接触保险丝两端的金属帽：若有蜂鸣声或电阻值接近 0Ω，表示保险丝正常；若无蜂鸣声、显示“OL”（开路）或电阻值很大，则说明保险丝已熔断，需要更换。

## 需要的工具和材料

- 新保险丝
- H1.5 内六角扳手或镊子

## 开始操作前的安全警告和机器状态

注意用电安全。更换保险丝时，请关闭电源开关并拔下电源线。

## 操作指南

### 步骤 1 - 断开电源线

从电源插座上拔下电源线。

![](https://wiki.bambulab.com/x1/maintenance/replace-fuse/377px-disconnect_the_power.png)

### 步骤 2 - 拔出保险丝座

使用工具( H1.5 内六角扳手或镊子)拔出保险丝及其支架。

|  |  |
| --- | --- |

### 步骤 3 - 拆除保险丝

从支架上拆下保险丝。

|  |  |
| --- | --- |

### 步骤 4 - 安装保险丝

将新保险丝安装到保险丝支架上。

![](https://wiki.bambulab.com/x1/maintenance/replace-fuse/371px-install_fuse_to_holder.png)

### 步骤 5 - 安装保险丝支架

将装有保险丝的支架安装到电源插座上。

|  |  |
| --- | --- |

## 如何验证完成/成功

连接电源线并打开电源。如果开关灯亮起，则保险丝更换完成并成功。

![](https://wiki.bambulab.com/x1/maintenance/replace-fuse/395px-power_on.png)

否则，当您打开电源开关但开关灯不亮，或者开关灯亮起后再次熄灭，请联系 Bambu Lab 服务团队寻求进一步帮助。
