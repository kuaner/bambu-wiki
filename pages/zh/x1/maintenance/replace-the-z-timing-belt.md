## 什么是 Z 轴同步皮带

Z 轴同步皮带是安装在打印机底部、节线长为 1142mm 的闭口皮带。它连接 Z 轴电机和 Z 轴丝杆，带动热床完成在 Z 方向的移动。

![](https://wiki.bambulab.com/x1/maintenance/replace-z-belt/z_belt.jpg)

## 何时更换

- 同步皮带断裂
- 同步皮带老化或磨损，并已影响功能

## 所需工具和材料

1. H1.5 和 H2.0 内六角扳手
2. 新的 Z 轴同步皮带

## 开始操作前的安全警告和机器状态

1. 关闭电源，移除电源线;

2. 需要先移除玻璃上盖和 LCD 显示屏。

## 操作指南

### 步骤 **1 - 清洁打印机底座**

清理打印机底座上的异物，特别是光杆处的残留物。

|  |  |
| --- | --- |
|  |  |

### 步骤 2 **- 将热床下降到底部**

皮带还能使用的情况：

在显示屏上操作，将热床下降到底部，用 3 颗螺丝将 3 个滑块进行锁定，就像当初开箱时，固定热床那样。然后关闭打印机，断开电源连接。

|  |  |
| --- | --- |
|  |  |

皮带不能使用的情况：

关闭打印机电源，断开电源连接，拧下 6 颗热床螺丝，从 Z 轴滑块上取下热床，然后倾斜打印机，用手转动大波轮，将热床 Z 轴滑块下降到底部，再用螺丝将滑块进行锁定。

### 步骤 3 **- 移除玻璃上盖，侧放打印机**

移除玻璃上盖，侧放打印机。

|  |  |
| --- | --- |
|  |  |

### 步骤 4 - 移除螺丝

释放弹簧，用 H2.0 内六角扳手移除黑色的螺丝，用 H1.5 内六角扳手移除 4 颗银色螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 5 - 移除张紧轮盖子和扭簧

取下张紧轮盖子，移除 Z 轴张紧弹簧。

![](https://wiki.bambulab.com/x1/maintenance/replace-z-belt/remove_spring.jpg)

### 步骤 6 - 移除 Z 轴张紧轮组件

移除 Z 轴张紧轮组件，注意组件里有一个螺母，不要弄丢了。

|  |  |
| --- | --- |
|  |  |

### 步骤 7 - 移除旧皮带

现在可以轻松地将旧皮带取下了。

![](https://wiki.bambulab.com/x1/maintenance/replace-z-belt/remove_the_belt.jpg)

### 步骤 8 - 安装新的 Z 轴皮带

将新的 Z 轴皮带安装到打印机底座上，如下图所示布置皮带，注意皮带齿面朝内。

![](https://wiki.bambulab.com/x1/maintenance/replace-z-belt/install_new_belt.jpg)

### 步骤 9 - 安装 Z 轴张紧轮组件

先确认前面提到的螺母有在组件上，将张紧轮组件安装到相应位置，注意根据卡扣位完成安装。

|  |  |
| --- | --- |
|  |  |

### 步骤 10 - 安装扭簧和张紧轮盖子

将扭簧安装到相应的立柱上，注意扭簧的长边在左边，然后放上张紧轮盖子，如下图所示。

|  |  |
| --- | --- |
|  |  |

### 步骤 11 - 锁螺丝，卡弹簧

用 H1.5 内六角扳手锁入 3 颗银色螺丝固定张紧轮盖子，用 H2.0 内六角扳手拧入黑色螺丝，但不要拧紧。然后将弹簧的长臂卡到位，如下图所示。

|  |  |
| --- | --- |
|  |  |

### 步骤 12 **-** 解除 Z 滑块锁定

正放打印机，然后移除锁定 Z 轴滑块的 3 颗螺丝。

![](https://wiki.bambulab.com/x1/maintenance/replace-z-motor/unlock_the_sliders.jpg)

### 步骤 13 - 张紧皮带，拧紧螺丝

重新侧放打印机，来回移动 Z 轴皮带，确认动作顺畅，然后锁紧黑色螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 14 - 将打印机正放，盖上玻璃上盖

将打印机翻转回来，正向放置，盖上玻璃上盖。

## 如何验证完成/成功

- 连接电源，启动打印机
- 如下图所示，运行设备自检流程，如果没有报错，更换同步带完成。

![](https://wiki.bambulab.com/x1/maintenance/replace-th-board-assembly/self_test.png)

如果有异常了，请排查组装是否有问题，特别是皮带的安装方向和 LCD 显示屏的连接，排除后，再次运行设备自检。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步的帮助。
