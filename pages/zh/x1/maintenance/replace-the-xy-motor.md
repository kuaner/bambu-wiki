## 什么是 XY 电机

XY 电机是安装在打印机背部，用于驱动工具头完成 XY 方向移动的步进电机。左右各一个，为了方便区分，根据位置分别称为 A 电机、B 电机。

|  |  |
| --- | --- |
|  |  |

## 何时更换

- 电机烧坏
- 售后人员通过日志分析，确认是 XY 电机故障。

## 所需工具和材料

1. H1.5 内六角扳手
2. H2.0 内六角螺丝刀(拆电机需要有较长的内六角螺丝刀)
3. 镊子
4. 新的 XY 电机

## 开始操作前的安全警告和机器状态

关闭电源，移除电源线，如果装有 AMS 缓冲器和料盘支架，也需要先拆除。

## 操作指南

### 步骤 1 - 松出 XY 皮带张紧器

根据实际损坏的电机，参考 [更换 XY 张紧器隋轮 | Bambu Lab Wiki](replaec-the-idler-pulley.md) 步骤 1~5 的内容，松出对应位置的 XY 张紧器。

|  |  |
| --- | --- |
| 松张紧轮A | 松张紧轮B |

### 步骤 2 - 移除 A 电机

A 电机和 B 电机的拆装有诸多不同之处，我们分别进行说明。

#### 步骤 2 - 1  移除 A 电机电缆

断开电机 A 连接，并移除其上的柱形磁环，将电机电缆从线扣和胶带中松脱出来。

|  |  |
| --- | --- |
|  |  |

#### 步骤 2 - 2 移除 A 电机固定螺丝

A 电机由 4 颗螺丝固定，两颗明显可见，两颗需要用较长的内六角螺丝刀从上往下穿到螺丝位置，移除4颗螺丝。

> **注意：固定电机的螺丝比较紧，需要小心处理，防止螺帽损坏。**

|  |  |
| --- | --- |
|  |  |

#### 步骤 2 - 3 移除 A 电机

将同步皮带从电机主动轮上移除，取下 A 电机。

|  |  |
| --- | --- |
|  |  |

### 步骤 3 - 安装 A 电机

#### 步骤 3 - 1 安装 A 电机

将 A 电机线穿过穿线孔，用手托住电机，将同步皮带装到主动轮上。

|  |  |
| --- | --- |
|  |  |

#### 步骤 3 - 2 锁 A 电机螺丝

锁入固定电机的 4 颗螺丝，后面的两颗螺丝需要在上横梁的位置将螺丝放置到内六角螺丝刀上，再通过螺丝刀将螺丝送到位。

|  |  |
| --- | --- |
|  |  |

#### 步骤 3 - 3 连接 A 电机电缆

如下图所示整理好电机电缆，安装上柱形磁环，然后连接到 MC 板 A 电机的接口上。

|  |  |
| --- | --- |
|  |  |

### 步骤 4 - 移除 B 电机

B 电机的拆装较 A 电机复杂些，需要多拆除一些部件，如废料滑梯、AP 主板盖、内衬组件等。

#### 步骤 4 - 1 移除废料滑梯

用 H1.5 内六角扳手拧下 2 颗螺丝，并拆下废料滑梯。

|  |  |
| --- | --- |
|  |  |

> 注意：我们后来的机器，在滑梯左侧有追加 1 颗螺丝，可以用 H2.0 扳手拧下。

![](https://wiki.bambulab.com/p1/maintenance/excess-chute/new_screw.png)

#### 步骤 4 - 2 移除 AP 主板盖

用 H1.5 内六角扳手移除 1 颗螺丝，揭开 AP 主板盖并将其移除。

|  |  |
| --- | --- |
|  |  |

#### 步骤 4 - 3 移除散热器并断开电缆连接

1. 用 H1.5 内六角扳手移除固定散热器的 2 颗螺丝，取下散热器；

![](https://wiki.bambulab.com/散热器螺丝.png)
> 散热器底部涂有导热硅脂，拆卸时可能会产生轻微粘附，需要适当用力将散热器拔出。

2. 断开 B 电机连接线和 AMS 接口板电缆；

![](https://wiki.bambulab.com/散热器.jpg)

3. 移除电机电缆上的柱形磁环，再将电缆从线扣中松出。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-xy-motor/b_motor_cables_2.jpg)

#### 步骤 4 - 4 降低热床

倾斜打印机，通过 Z 轴皮带下降热床，在不影响拆装内衬螺丝的前提下，尽可能下降到最低。

|  |  |
| --- | --- |
| 下降热床 | 不要遮挡此螺丝 |

#### 步骤 4 - 5 松开电源插口

用镊子撬松电源插口，将电源插口松出。

|  |  |
| --- | --- |
|  |  |

#### 步骤 4 -6 松开内衬

用 H2.0 内六角螺丝刀，移除 9 颗固定内衬的螺丝，从内衬上的过线孔将 B 电机电缆抽出，然后将内衬与后横梁分离，腾出 B 电机拆装的空间。

|  |  |  |
| --- | --- | --- |
|  |  |  |

#### 步骤 4 - 7 移除电机固定螺丝

B 电机同样由 4 颗螺丝固定，两颗明显可见，两颗需要用较长的内六角螺丝刀从上往下穿到螺丝位置，移除 4 颗螺丝。

> **注意：固定电机的螺丝比较紧，需要小心处理，防止螺帽损坏。**

|  |  |
| --- | --- |
|  |  |

#### 步骤 4 - 8 移除 B 电机

将同步皮带从电机主动轮上移除，移除 B 电机。

|  |  |
| --- | --- |
|  |  |

### 步骤 5 - 安装 B 电机

#### 步骤 5 -1 安装 B 电机

将 B 电机安装到位，并将同步皮带安装到电机主动轮上。

|  |  |
| --- | --- |
|  |  |

#### 步骤 5 -2 锁 B 电机螺丝

锁入固定电机的 4 颗螺丝，后面的螺丝有 1 颗需要在上横梁的位置将螺丝放置到内六角螺丝刀上，再通过螺丝刀将螺丝送到位，另一颗螺丝需要直接将螺丝放到螺丝孔上，再用螺丝刀拧紧。

|  |  |
| --- | --- |
|  |  |

#### 步骤 5 - 3 装回散热器

在散热器底部补涂适量导热硅脂，然后将散热器装回原位，锁入固定散热器的 2 颗螺丝。  
您可参考选用以下导热硅脂：

![](https://wiki.bambulab.com/x1/maintenance/replace-the-chamber-led/silicone_glue.jpg)

#### 步骤 5 - 4 连接电缆

穿电机排线，安装好柱形磁环，并将电机线连接到 MC 板 B 电机的连接口上，连接 AMS 接口板，整理好电缆。

|  |  |  |
| --- | --- | --- |
|  |  |  |

#### 步骤 5 - 5 安装内衬

将内衬贴合后横梁，锁入 9 颗螺丝固定。

|  |  |
| --- | --- |
|  |  |

#### 步骤 5 - 6 安装电源插口

将电源插口装回原位。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-xy-motor/install_the_power_socket2.jpg)

#### 步骤 5 - 7 安装 AP 主板盖

如下图所示，将箭头所示的位置对齐，安装好 AP 主板盖，然后在打印机背面锁入1颗螺丝固定 AP 主板盖。

|  |  |
| --- | --- |
|  |  |

#### 步骤 5 - 8 安装废料滑梯

将废料滑梯装回原位，安装时注意滑槽两侧突出的卡扣，锁紧 2 颗螺丝。

|  |  |
| --- | --- |
|  |  |

> 注意：如果在拆时发现侧面有固定螺丝，可以拧回去。

![](https://wiki.bambulab.com/p1/maintenance/excess-chute/new_screw.png)

### 步骤 6 - 安装张紧器，装好打印机

参考 [更换XY张紧器隋轮 | Bambu Lab Wiki](replaec-the-idler-pulley.md) 步骤 9~13 的内容，安装好张紧器，组装好打印机，并完成 XY 同步皮带的张紧。

## 如何验证完成/成功

- 连接电源，启动打印机
- 如下图所示，运行设备自检流程，如果没有报错，更换电机完成。

![](https://wiki.bambulab.com/x1/maintenance/replace-th-board-assembly/self_test.png)

如果报错了，请排查组装是否有问题，并重新张紧皮带后，再次运行设备自检。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步的帮助。
