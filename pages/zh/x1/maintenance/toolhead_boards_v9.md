## 什么是工具头电路板（新版）

新版的 X1 系列的工具头的电路板包括安装在工具头上的挤出主板、接口板及其连接软排线，可根据实际损坏的部件进行更换。

如果您发现您的工具头电路板与本篇不同，可能是因为您使用的是[旧版工具头电路板](replace-the-th-board-assembly.md)。新旧版工具头差异请见[文末介绍](#different)，当旧版工具头电路板故障时，您可以使用新版本替换其使用。

![toolheadcn.png](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/toolheadcn.png)

## 何时更换

- 连接器或组件损坏
- 通过打印机日志分析发现了问题

## 所需工具与材料

1. H1.5  内六角扳手
2. Bambu Lab 工具头相关板件
3. 硅胶

## 开始操作前的安全警告和机器状态

> 在进行任何维护工作之前请关闭打印机电源。

## 操作指南

注意： 对于使用硅胶加固的连接器，在从接头拔出连接件之前，请使用电吹风加热接头处的硅胶，或使用镊子去除一部分，以防止损坏连接器。并建议在重新连接后，追加硅胶进行加固。

### 操作指南与安装技巧：

如果您觉得在工具头上安装 FPC 或是小螺丝时很困难，可以尝试以下方法：先把挤出主板、FPC 排线、挤出接口板放在平整的桌面上：

1. 将挤出主板和挤出接口板如下图所示方向放置

2. 确保带状 FPC 排线朝向正确，您可以通过线缆上文字的方向来判断是否摆放与下图一致：

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/%E6%93%8D%E4%BD%9C%E6%8C%87%E5%8D%97_1.png)

请您注意 FPC 线上的文字，安装时请参考如图所示的阅读方向，其应该是沿着红色箭头指向接口板方向。

3. 连接 FPC 线缆时请保持挤出主板和挤出接口板平放在桌面上，确保不要过度拧紧螺丝并确保金属屏蔽片将连接器固定在原位，如下图所示：

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/%E6%93%8D%E4%BD%9C%E6%8C%87%E5%8D%97_2.png)

4. 安装完成后，以上述方向拿住电路板

5. 然后将 FPC 排线从右到左滑入工具头的顶部位置：

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/%E6%93%8D%E4%BD%9C%E6%8C%87%E5%8D%97_3.jpeg)

6. 完成这些步骤后，您可以继续执行本 wiki 中“操作指南-第 8 步”之后的步骤。

### **第 1 步 - 移除工具头前盖**

揭开工具头前盖，断开连接电缆，取下前盖。

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/disconnect_the_front_housing.jpg)

### **第 2 步 - 松切刀刀柄**

用 H1.5 内内六角扳手拧松切刀刀柄螺丝，使切刀刀柄自然下垂，按压接头，然后断开挤出机 PTFE 管。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 - 移除工具头外壳**

用 H1.5 内内六角扳手移除固定工具头外壳的 8 颗螺丝，取下工具头后盖和中框。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 - 断开 USB 连接**

从挤出主板上断开 USB 线的连接，然后将 USB 线连同支架一起，从工具头上移除。

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/disconnect_the_usb_cable.jpg)

### **第 5 步 - 移除 FPC 排线**

用 H1.5 内内六角扳手拧下 FPC 排线两端的固定螺丝，移除固定支架，断开排线连接，取下 FPC 排线。

注意：这里使用的 4 颗螺丝，尺寸较小，避免大力拧螺丝，防止螺丝断裂，且不能与另外的螺丝混用。

|  |  |
| --- | --- |
|  |  |

### **第 6 步 - 移除接口板**

断开接口板上的 4 条连接电缆，用 H1.5 内内六角扳手移除 2 颗螺丝，取下接口板。

|  |  |
| --- | --- |
|  |  |

请注意：热敏电阻插头上有一个锁扣装置（不同于风扇和加热器插头），这个插头需要按下锁扣装置来解开，而不是拉扯线缆来拔出 PCB 接头。

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/%E7%AC%AC%E5%85%AD%E6%AD%A5_3.png)

### **第 7 步 - 移除挤出主板**

断开挤出主板正面上的 3 条连接电缆，用 H1.5 内内六角扳手移除 3 颗螺丝，然后向左翻转挤出主板，断开两根激光电缆，取下挤出主板。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### **第 8 步 - 安装挤出主板**

将挤出主板安装到工具头上，锁入 3 颗螺丝进行固定。然后连接相机软排线，装上固定支架并锁入 2 颗螺丝进行固定。

|  |  |
| --- | --- |
|  |  |

### **第 9 步 - 连接电缆（挤出主板）**

将 5 条电缆分别连接到挤出主板上，注意区分接口方向，建议在原先有打胶的接口点上硅胶进行加固。将 3 条激光雷达的连接电缆如图所示整理好，避免损伤和影响外壳安装。

|  |  |
| --- | --- |
|  |  |

### **第 10 步 - 安装接口板**

将接口板安装到工具头上，拧入 2 颗螺丝进行固定。然后连接霍尔开头板（挤出机）电缆，建议点上硅胶进行加固，再连接 3 条热端电缆。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### **第 11 步 - 安装 FPC 排线**

将 FPC 排线的“公端”连接到小板上（挤出接口板）。

将“母端”连接到大板上（挤出主板）。

我们强烈建议您在安装前仔细检查连接排线的接口，因为这些接口必须要公母配对才能正确安装。

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/%E7%AC%AC%E5%8D%81%E4%B8%80%E6%AD%A5_1.png)

如果您觉得辨别端口的公母有些困难，也可以通过观察 FPC 排线上的文字方向来确定安装方向。

在 FPC 排线上有一行文字，其阅读方向应该是沿着下图箭头方向并指向小板（挤出接口板）的。

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/%E7%AC%AC%E5%8D%81%E4%B8%80%E6%AD%A5_2.png)

确认连接排线的方向后，安装到工具头上方的线槽。然后分别连接到接口板和挤出主板的连接器上，并用压线支架和螺丝进行加固。

注意：这里使用的 4 颗螺丝，尺寸较小，避免大力拧螺丝，防止螺丝断裂，且不能与另外的螺丝混用。

|  |  |
| --- | --- |
|  |  |

### **第 12 步 - 连接 USB 电缆**

将 USB 电缆连接到挤出主板上，将 USB 线压入线材底座后，将线材支架扣装到位。

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/connect_usb_cable.jpg)

### **第 13 步 - 验证 TH 板的安装正确性（尤其是 FPC 排线的连接）**

在安装工具头外壳之前，可以进行以下两个测试来检查 TH 板组件是否正确安装：

1. 使用一截耗材来判断挤出机[霍尔传感器](../../p1/maintenance/extruder-filament-sensor.md)能否正常检测到耗材丝。例如当有耗材从挤出机上端插入时，屏幕上的霍尔标识会亮起绿色，而拔出耗材又会熄灭。

|  |  |
| --- | --- |
|  |  |

2. 将热端温度设置到 60 ℃。当温度超过 50 ℃时，热端风扇将会自动开启。

如果在安装 TH 板之后，打印机无法通过上述这两个测试，那么很可能是连接两个板块的 FPC 排线没有正确安装，请尝试将其重新安装（参考操作指南与安装技巧）。

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/%E7%AC%AC%E5%8D%81%E4%B8%89%E6%AD%A5_3.png)

### **第 14 步 - 安装工具头外壳**

安装工具头中框和后盖，并在两侧分别锁入4颗螺丝进行固定。

|  |  |
| --- | --- |
|  |  |

### **第 15 步 - 安装切刀刀柄**

用手抬起切刀刀柄，将切刀沿刀槽滑入挤出机内，锁紧固定螺丝，然后接上 PTFE 管。

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/install_the_lever.jpg)

### **第 16 步 - 安装工具头前盖**

如下图所示连接前盖电缆，合上前盖。

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/disconnect_the_front_housing.jpg)

## 如何验证更换完成/成功

### 根据电路板灯语判断

**正常状态：TH 板指示灯常亮红灯**

在拧回所有螺丝前，可先预装或不装盖子（小心用电安全，断电操作），再通电检查该电路板灯语是否正常，灯语正常，再拧回螺丝，这样可以避免返工。

<https://public-cdn.bblmw.com/wiki/video/X1-TH.mp4>

### 连接电源线并打开电源，发起设备自检，检查是否有报错。

- 打开打印机电源
- 如下图运行设备自检操作，如果没有出现错误，则更换成功。

![selftest.png](https://wiki.bambulab.com/screen-operation/selftest.png)

如果您遇到任何问题，请先回溯您的步骤并检查所有连接以重试。 如果问题仍然存在，请联系服务团队寻求进一步帮助。

## 新旧版本差异

新旧版本工具头电路板的主要不同点。如下图所示，V8 是旧版，V9 是新版。

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/v8.jpg)

![](https://wiki.bambulab.com/x1/maintenance/th-boards-v9/v9.jpg)

差异 1：将电缆和地线合并为一根软排线；

差异 2：连接线两端的加固方式从硅胶固定变更为压片补强；

差异 3：接口板上的 NTC 连接器方向变更；

差异 4：挤出主板到工具头前盖的连接器方向变更。
