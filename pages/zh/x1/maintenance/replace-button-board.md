## 什么是按键板

按键板是安装在 X1 打印机右上角，包括紧急停止和睡眠（熄屏）两个的按键的电路板，板件上也有用于测量打印机腔温的传感器。**如果打印机报告打印腔温度异常，请检查带状电缆是否已牢固连接到按钮板。**

![](https://wiki.bambulab.com/x1/maintenance/replace-the-button-board/button_board.jpg)

## 何时更换

1. 按键功能失效；

2. 腔温异常(**这种情况，应该先检查按键板连接电缆两端的连接是否没有接好**)。

## 所需工具和材料

- 新的按键板
- H2.0 内六角扳手

## 开始运行前的安全警告和机器状态

请按照指导步骤进行更换，在进行拆卸和组装作业时需关闭打印机电源。

## 操作指南

### 第 1 步 - 关闭电源

关闭打印机电源，打开前玻璃门，取下玻璃盖板。

### **第 2 步 - 移除高清屏幕**

将屏幕向上倾斜并按压图示位置以松开卡扣，再向右推动以解锁高清屏幕，按下 FPC 连接器的两侧以解锁连接器，移除高清屏幕。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 - 回抽屏幕 FPC**

取下透明固定胶带，将屏幕 FPC 从方孔中往回抽出。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 - 松电缆**

将按键板连接电缆从卡扣中松脱出来。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-button-board/buckles.jpg)

### **第 5 步 - 松右侧盖边角**

用 H2.0 内六角扳手拧下固定在右侧面板上的 3 颗螺丝，这样就可以松开右侧面板的右上角，方便拆卸前盖。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-button-board/corner_screws.jpg)

### **第 6 步 - 移除前面盖固定螺丝**

使用 H2.0 内六角扳手移除固定前面盖的 2 颗细牙螺丝和 1 颗粗牙螺丝。

|  |  |
| --- | --- |
|  |  |

### **第 7 步 - 移除前面盖**

**注意：WiFi 天线位于前盖上，因此松开前盖时请注意不要用力过猛**

将前面盖两边向上推出少许，解除卡扣的锁定，然后先将前面盖右侧位置松出，再将整个前面盖从横梁上移除。

|  |  |
| --- | --- |
|  |  |

### **第 8 步 - 移除按键板**

> **如果您正在排除箱体温度传感器读数错误**的问题，请首先断开并重新连接连接器，确保它们牢固地安装在电路板上。接下来，重新连接显示屏并启动机器。在此过程中，请小心操作显示屏，以免造成任何损坏。如果箱体温度读数正常，请断开显示屏并继续执行步骤 10 重新组装机器。如果问题仍然未解决，请继续执行以下步骤更换电路板。

断开按键板电缆和门开关检测电缆，用 H2.0 内六角扳手拧下 1 颗螺丝，取下按键板。

|  |  |
| --- | --- |
|  |  |

### **第 9 步 - 安装按键板**

将按键板安装到横梁上，锁入 1 颗螺丝固定，连接 AP 板连接电缆和开门检测开关电缆。

|  |  |
| --- | --- |
|  |  |

### **第 10 步 - 安装前面盖**

先安装左侧位置，然后再将右侧安装好，左右两边同时向下按压前面盖，将其安装到位。

|  |  |
| --- | --- |
|  |  |

### **第 11 步 - 锁前面盖螺丝**

锁入 3 颗螺丝固定前面盖，前面的 2 颗是细牙螺丝，背后 1 颗是粗牙螺丝。

|  |  |
| --- | --- |
|  |  |

### **第 12 步 - 固定右侧盖边角**

锁入 3 颗固定右侧盖右上角的螺丝。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-button-board/corner_screws.jpg)

### **第 13 步 - 整理电缆**

将按键板连接电缆整理到线扣上，并确保没有突出的电线。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-button-board/buckles.jpg)

### **第 14 步 - 穿屏幕 FPC**

将连接 FPC 折叠起来，穿过指定的方孔，理好排线、电缆，贴上透明固定胶带。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### **第 15 步 - 安装高清屏幕**

将屏幕 FPC 连接到高清屏幕上的连接器，将多余的 FPC 排线退回打印机，将高清屏幕安装到打印机的 4 个插槽中，然后轻轻向左推，直到听到卡扣到位的声音乐，完成安装，盖上玻璃盖板。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 如何验证完成/成功

打开打印机电源。待显示屏显示稳定后，按下睡眠按键，确认显示屏能正常熄屏，再次按下睡眼按键，显示屏能恢复显示，说明按键板更换成功。

![](https://wiki.bambulab.com/x1/maintenance/replace-the-button-board/sleep_button.jpg)

![home.png](https://wiki.bambulab.com/screen-operation/home.png)

否则，请检查连接并重试。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
