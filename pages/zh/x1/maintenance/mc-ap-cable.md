## MC-AP 连接线

连接X系列打印机主控板和AP主板的2根黑色连接线，实现主控板到AP主板的数据交互，并为AP主板提供电源。

![](https://wiki.bambulab.com/x1/maintenance/mc_ap/mc-ap_cable.jpg)

## 何时更换

- 两端的插头有物料损坏，影响安装；
- 连接线有明显的损伤或断路；
- 拓竹服务团队通过日志文件确认的连接线有异常。

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 移除旧的MC-AP连接线

### **第1步 -  移除金属背板**

参考 [金属后面板](replace-rear-panel.md) 的相关内容，移除金属后面板。

![](https://wiki.bambulab.com/x1/maintenance/mc_ap/rear_panel_removed.jpg)

### **第 2 步 - 移除拖链盖**

|  |  |
| --- | --- |
| 用H1.5内六角扳手，移除位于打印背面PTFE支架下方的1颗螺丝C | 完全揭开拖链盖，然后将拖链盖从XY框架上移除 |

### **第 3 步 - 断开MC-AP线缆连接**

|  |  |
| --- | --- |
| 按压插头卡扣，将MC-AP的连接线从AP主板上的两个连接器断开，并从线扣中移除。 | 按压插头卡扣，将AMS接口板连接线断开，然后再将MC-AP连接线从MC板上的两个连接器中断开连接。 |

### **第 4 步 - 移除MC-AP连接线**

|  |  |
| --- | --- |
| 将MC--AP连接线依次从线槽中释放出来 | 然后如图所示，分别将两端插头拉出，取下线缆。 |

## 安装新的MC-AP连接线

### **第1步 - 穿线**

如下图所示，将MC-AP连接线的两端穿过对应的过线孔。

|  |  |
| --- | --- |
|  |  |

然后将线依次整理入线槽内。

|  |  |
| --- | --- |
|  |  |

### **第 2 步 -** 连接电缆

|  |  |
| --- | --- |
| 如下图所示，在将线材连接前，请确认好卡扣的方向。 | 如图所示，主控板侧需要连接3根据电缆，连接器位置如图所示。 |

|  |  |
| --- | --- |
| 按图示卡扣方向将MC-AP连接线连接到MC板上，然后接上AMS接口板电缆。 | 将AP主板侧的连接线从USB线下方穿过，连接到AP主板的连接器上，并将电缆整理入线扣中。 |

### **第 3 步 - 安装拖链盖**

|  |  |
| --- | --- |
| 将拖链盖的螺丝孔与后横梁上的通孔对齐，安装较短那部分的盖子 | 轻微用力按压长端盖子边缘，将盖子顶端装入横梁 |

|  |  |
| --- | --- |
| 对齐缺口位置将长的一端盖子安装到位。 | 在打印机后侧靠上方的螺丝孔处锁入1颗螺丝。 |

### **第4步 -  安装金属背板**

参考 [金属后面板](replace-rear-panel.md) 的相关内容，安装好金属后面板。

## 功能确认

连接打印机电源，开启打印机，确认显示屏能正常启动。

![](https://wiki.bambulab.com/x1/maintenance/replace-high-resolution-screen/615px-screen.png)

否则，请再次检查所有连接并重试。如果仍然不行，请联系 Bambu Lab 服务团队寻求进一步帮助。
