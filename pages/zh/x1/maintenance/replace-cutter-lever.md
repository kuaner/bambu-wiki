## 切刀刀柄

切刀刀柄是安装切刀并推动切刀进行切料的把手。

![](https://wiki.bambulab.com/x1/maintenance/replace-filament-cutter-lever/filament_cutter_lever.jpg)

### 何时更换

切刀刀柄有物理损坏，且影响使用。

### 所需工具和材料

- 切刀刀柄
- H1.5 内六角扳手
- 镊子

螺丝清单：

|  |  |  |  |
| --- | --- | --- | --- |
|  | 型号 | 位置 |  |
| 螺丝A | MG2.5\*13 | 切刀刀柄 |  |

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除旧切刀刀柄

### **步骤 1 -** 打开[前壳组件](replace-front-housing-assembly.md)

**关闭打印机电源**，打开工具头前壳组件。

![](https://wiki.bambulab.com/x1/maintenance/replace-extru-sw-assembly/open_the_front_housing_2.jpg)

### **第 2 步 - 移除卡簧**

|  |  |
| --- | --- |
| 按照图示，使用镊子的柄部按压卡簧，使其松开。 | 取下卡簧（×1）和垫圈（×1）。 |

### **第 3 步 - 移除切刀刀柄**

|  |  |
| --- | --- |
| 用H1.5内六角扳手拧松切刀杆固定螺丝A，直到螺丝完全从挤出机上松出。 | 移除切刀刀柄。 |

## 安装新切刀刀柄

### **第 1 步 - 安装切刀刀柄**

|  |  |  |
| --- | --- | --- |
| 将弹簧一侧插入孔中。 | 如图所示确认转轴弹簧的位置，将切刀刀柄安装到转轴上，切刀刀柄需要向后推到底。 | 用手扶起切刀刀柄，将切刀滑入刀槽内，拧紧切刀刀柄螺丝(螺丝A)。 |

> 拧入螺丝后，缓慢松开切刀刀柄，否则可能会导致中框损坏。

### **第 2 步 - 安装卡簧**

|  |  |
| --- | --- |
| 确认转轴上已留有足够安装垫圈和卡簧的位置。 | 装上垫圈（×1），然后用镊子压入卡簧（×1）。 |

### **第 3 步 - 安装**[前壳组件](replace-front-housing-assembly.md)

合上工具头前壳组件。

![](https://wiki.bambulab.com/x1/maintenance/replace-extru-sw-assembly/close_the_housing.jpg)

## 功能确认

在合上工具头前壳组件前， 可以手动确认切刀动作，动作顺畅即可。

## 设备校准

更换切刀刀柄不需要进行额外的校准操作。
