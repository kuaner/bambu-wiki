## 什么是前盖组件？

前盖组件是一个装有磁铁（小磁铁2mmx2mm，大磁铁4mmx2mm）、包含了部件冷却风扇和系统 LED 灯的工具头前盖。  
![](https://wiki.bambulab.com/x1/maintenance/replace-front-housing-assembly/416px-front_housing_assembly.png)

## 何时更换

- 碰撞后损坏
- 部件冷却风扇故障
- 系统 LED 故障

## 所需工具和材料

新的工具头前盖组件

## 开始运行前的安全警告和机器状态

在进行拆卸和组装工作时需关闭打印机电源。

## 操作指南

### **步骤 1 -** 打开前盖组件

关闭打印机电源并将前盖组件与工具头分开。

![](https://wiki.bambulab.com/x1/maintenance/replace-front-housing-assembly/377px-remove_the_front_housing_assembly.png)

### **第 2 步 - 断开电缆**

断开工具头 LED 电缆与连接器的连接，然后从卡扣上取下电缆。

![](https://wiki.bambulab.com/x1/maintenance/replace-front-housing-assembly/337px-remove_cable2.png)

### **第 3 步 -** 连接电缆

准备新的前盖组件并将工具头LED电缆连接到工具头前盖组件的连接器上。

|  |  |
| --- | --- |
|  |  |

> 前盖风扇螺丝BT2\*6  
> ![350px-connect_led_cable.png](https://wiki.bambulab.com/x1e/1-1-0-4/350px-connect_led_cable.png)

### **第 4 步 - 关闭**前盖**组件**

将工具头 LED 电缆别入卡扣中，然后合上工具头前盖组件。

## 如何验证完成/成功

打开打印机电源。如果在启动打印机过程中工具头 LED 亮起，并且您在屏幕上点击**控制 > 风扇 > 部件冷却风扇**时，能够打开风扇，则说明更换成功。

![](https://wiki.bambulab.com/x1/maintenance/replace-front-housing-assembly/305px-led_on.png)

![screenshot-20250522-211219.png](https://wiki.bambulab.com/x1/maintenance/replace-front-housing-assembly/screenshot-20250522-211219.png)

![fan--cn.png](https://wiki.bambulab.com/x1/maintenance/replace-front-housing-assembly/fan--cn.png)

否则，请再次检查所有连接并重试。
