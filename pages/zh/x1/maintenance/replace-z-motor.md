## 什么是 Z 轴电机

Z 轴电机是一个通过 Z 轴同步皮带驱动热床在 Z 轴方向的运动的步进电机，它会带有电机电缆和主动轮。

![](https://wiki.bambulab.com/x1/maintenance/replace-z-motor/z_motor.jpg)

## 何时更换

- Z 轴电机烧坏，不能动作
- 售后人员通过日志分析，确认是 Z 轴电机故障。

## 所需工具和材料

1. 新的 Z 轴步进电机
2. H2.0 内六角扳手

## 开始操作前的安全警告和机器状态

1. 关闭电源，移除电源线;

2.需要清理机器底座上的异物，以保证热床能平整地下降到底部；

3. 需要先移除玻璃上盖和 LCD 显示屏。

## 操作指南

### 步骤 **1 - 清洁打印机底座**

清理打印机底座上的异物，特别是光杆处的残留物，移除打印机玻璃上盖。

|  |  |
| --- | --- |
|  |  |

### 步骤 2 **- 将热床下降到底部**

电机还能使用的情况：

在显示屏上操作，将热床下降到底部，用 3 颗螺丝将 3 个滑块进行锁定，就像当初开箱时，固定热床那样。然后关闭打印机，断开电源连接。

|  |  |
| --- | --- |
|  |  |

电机完全不能使用的情况：

关闭打印机电源，断开电源连接，倾斜打印机，手动移动 Z 轴皮带，将热床下降到底部，再用 3 颗螺丝将 3 个滑块进行锁定。

![](https://wiki.bambulab.com/x1/maintenance/replace-z-motor/move_the_belt.jpg)

### 步骤 3 - 拆除后盖螺丝

> 注意：这个过程涉及到很多螺丝，请将它们区分开来，并把它们放在不同的区域，以免弄混。

如图所示，取下后盖上的 10 颗螺丝和 4 颗螺丝。这是两种类型的螺丝，所以要把它们分开。

|  |  |
| --- | --- |
|  |  |

### 步骤 4 - 拆除后盖

拆下后盖，先将后盖从左侧（面向后盖）皮带张紧口的位置松开，再松开右侧（面向后盖）皮带张紧口的位置，以免卡住。

|  |  |
| --- | --- |
|  |  |

### 步骤 5 - 断开电机电缆

找到位于机器背面右侧的 MC 板，并将 MC 板底部的 Z 轴电机连接线断开，取下上面的柱形磁环。

|  |  |
| --- | --- |
|  |  |

### 步骤 6 - 移除电源线磁环

将方形磁环的锁扣位转出来，解除锁定，然后将方形磁环取下。

|  |  |
| --- | --- |
|  |  |

### 步骤 7 - 松出电机电缆

将电机电缆从卡扣和走线孔中退出。

|  |  |
| --- | --- |
|  |  |

### 步骤 8 **- 移除 LCD 显示屏**

将屏幕向上倾斜并按压图示位置以松开卡扣，再向右推动以解锁高清屏幕。

|  |  |
| --- | --- |
|  |  |

按下 FPC 连接器的两侧以解锁连接器，移除高清屏幕

|  |  |
| --- | --- |
|  |  |

### 步骤 9 **- 倒置打印机**

倒置打印机，使打印机底面朝上。

![](https://wiki.bambulab.com/x1/maintenance/replace-z-belt/bottom_side_up.jpg)

### 步骤 10- 释放张紧弹簧和张紧轮

释放弹簧，用 H2.0 内六角扳手拧松黑色的螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 11 - 移除Z轴电机

移除 4 颗螺丝，这 4 颗螺丝锁定力矩较大，建议使用可靠的工具进行移除，否则容易滑牙。拆到最后一颗螺丝时，请用手接住电机，防止掉落。

|  |  |
| --- | --- |
|  |  |

### 步骤 12 - 安装 Z 轴电机

将新的 Z 轴电机安装到位，可根据步骤 11 中电机电缆的朝向确定安装方向，用对角线锁螺丝的方式将 4 颗螺丝拧紧。

|  |  |
| --- | --- |
|  |  |

### 步骤 13 - 卡弹簧，锁张紧轮

将弹簧的长臂卡到位，将张紧轮螺丝锁到位

![](https://wiki.bambulab.com/x1/maintenance/replace-z-motor/release_the_spring.jpg)

### 步骤 14 - 移除滑块固定螺丝，动作检查

将打印机翻转回来，正向放置，移除 3 个滑块上的锁定螺丝。然后倾斜打印机，来回移动 Z 轴皮带，确认热床能上下移动。

|  |  |
| --- | --- |
|  |  |

### 步骤 15 **- 安装 LCD 显示屏**

拉出 FPC 少许，按下 FPC 连接器的两侧，将 FPC 连接器接入到高清屏幕背面的连接器。

|  |  |
| --- | --- |
|  |  |

将多余的 FPC 排线退回打印机，将高清屏幕安装到打印机的 4 个插槽中，然后轻轻向左推，直到听到卡扣到位的声音乐，完成安装。

|  |  |
| --- | --- |
|  |  |

### 步骤 16 - 穿电机电缆

将电机电缆穿过底座的两个穿线孔和两个卡扣位，并扣到侧边上的线扣上，如同拆除前那样。

|  |  |
| --- | --- |
|  |  |

### 步骤 17 - 安装柱形磁环，连接电机电缆

将柱形磁环安装到电机电缆上，并将电缆接到 MC 板的连接器上，确认安装到位。

|  |  |
| --- | --- |
|  |  |

### 步骤 18 - 安装方形磁环

安装方形磁环，理好线缆。

|  |  |
| --- | --- |
|  |  |

### 步骤 19 -安装后盖

安装后盖时，应首先穿过 PTFE 管支架和装好右侧的皮带张紧口位置。

|  |  |
| --- | --- |
|  |  |

### 步骤 20 -锁紧后盖螺丝

用螺丝将后盖重新固定。注意使用的不同类型的螺丝(如下图所示的 10 颗螺丝和 4 颗螺丝)， 盖上玻璃上盖。

|  |  |
| --- | --- |
|  |  |

## 如何验证完成/成功

- 连接电源，启动打印机
- 如下图所示，运行设备自检流程，如果没有报错，说明 Z 轴电机更换成功。

![](https://wiki.bambulab.com/x1/maintenance/replace-th-board-assembly/self_test.png)

如果有异常了，请按照操作步骤排查组装是否有问题，排除后，再次运行设备自检。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步的帮助。
