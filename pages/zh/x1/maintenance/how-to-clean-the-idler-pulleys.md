惰轮是 3D 打印机运动系统中的关键组件，对维持皮带张力和实现平稳的机械运动起着至关重要的作用。整台机器共有 12 个惰轮。随着使用时间的增加，灰尘、耗材碎屑或导轨上的润滑剂残留可能会在惰轮处积聚，导致运动阻力增加、噪音异常，甚至出现诸如莫尔纹等打印问题。

下面是惰轮的外观示意图：  
![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/dirty-pulleys.jpg)  
本篇 Wiki 将为您详细讲解如何高效清洁惰轮。但在此之前，我们先来了解一下惰轮在打印机中的具体位置。

## **清洁惰轮所需工具**

开始清洁前，请准备以下工具，其中一些可能已包含在您的 3D 打印工具包中，部分工具则可能需额外购买：

- **WD-40 喷雾剂**：虽然常被用作润滑剂，但 WD-40 对去除惰轮等金属表面上的污垢、碎屑和旧润滑脂也非常有效。我们将用它去除顽固污渍而不腐蚀金属表面。如无，可在网上购买。
- **棉签**：作为主要清洁工具，在棉签上蘸取少量 WD-40 擦拭惰轮表面。
- **H2.0 内六角扳手**：用于拆卸结构件以便更方便地接触惰轮。
- **无纺布**：用于清除多余污垢。

### **可选工具**

- **吹风机**: 用于清洁前后吹掉惰轮周围的灰尘与细小颗粒。
- **手套**: 防止润滑剂、金属边缘或油污弄脏手，同时避免指纹污染机器内部。
- **手电筒或头灯:** 便于查看打印机内部结构。
- **备用螺丝**: 拆卸时小螺丝容易丢失，备用螺丝可防止意外情况。

> 注意：12 个惰轮中，前 10 个可直接清洁，后部 2 个需拆机处理（一般不建议清洁，除非明显有污垢）。

## 开始操作前的安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 清洁步骤

### 清洁 Y 轴前部惰轮

打印机靠近门框两侧 Y 轴处各有一个惰轮，请按以下步骤清洁：

#### 步骤 1：打开前门

找到靠近摄像头位置的惰轮。

#### 步骤 2：将 WD-40 喷洒在棉签上

![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/spraying-wd-40d.png)

注意避免喷洒到热床或其他打印部件上。如无 WD-40，可用酒精或异丙醇代替。

#### 步骤 3：轻柔擦拭惰轮边缘

![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/cleaning_idler_pulley.jpg)

一边擦拭，一边缓慢来回移动皮带以清除污垢。

#### 步骤 4：清洁对侧惰轮

使用相同方法清洁右侧惰轮。

### 清洁 X 轴横梁边的惰轮

共有 4 个惰轮，左右两侧各 2 个。

#### 步骤 1：移动打印头至一侧

手动滑动打印头至一侧，便于查看和清洁对侧惰轮。

#### 步骤 2：用棉签蘸 WD-40 轻柔清洁惰轮

![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/cleaning_middle_idler_pulleys.jpg)  
注意避免 WD-40 滴入打印头、横梁或其他部件。可来回移动工具头辅助清洁。

![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/moving-print-head.gif)  
移动工具头时注意勿用力过猛，避免对 X 轴导轨施加较大压力。

另一侧两个惰轮也按相同步骤清洁。如有多余污垢，可用干布擦拭。

### 清洁打印机后部惰轮

打印机后部每侧有两个惰轮，用于 CoreXY 皮带引导与张紧。如果看不太清操作时可能需要手电筒等辅助照明。

#### 步骤 1：将打印头移动至前方中间位置

为清理后部留出空间，请移动工具头至前方并移除打印机上盖。

#### 步骤 2：用棉签蘸 WD-40 清洁惰轮

![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/back_pulleys.jpg)

参考前面步骤中强调的注意事项。您在清洁时可用手来回轻推皮带，以彻底清洁惰轮，注意不要拉扯过度以免影响张力。

### 清洁背部两个惰轮（需拆机）

![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/idler_pulleys_at_the_rear_back.png)

T这两个惰轮位于打印机背部深处，需拆卸以下部件后才能接触：

- 打印机背板
- 张紧弹簧与支架
- 张紧轮组件

以下是详细拆解步骤：

#### **步骤 1：移除背板**

用 H 2.0 内六角扳手卸下所有背板螺丝。P1 与 X1 系列适用。  
如图所示，分为 4 颗相同的粗牙螺丝（左图）和 10 颗相同的细牙螺丝（右图），拆下后需分类保存，避免混淆。

![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/rear_back_of_a_3d_printer.png)

拆下后盖时先将后盖向左后（面向后盖）从左侧皮带张紧口的位置松脱，再向右（面向后盖）松开右侧皮带张紧口的位置，以免卡住。

|  |  |
| --- | --- |
|  |  |

> 清理前，用吹风机吹净机内灰尘。如为了方便操作翻转了机器，请提前将热床调至最低点并锁紧，防止之后机器翻转时移动。如果必要也可卸下顶部屏幕，防止机器侧放时挤压损坏。

#### 步骤 2：卸下张紧弹簧与支架

首先用 H 2.0 内六角扳手拧下如图所示两颗螺丝。

![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/removing-the-screws.png)

然后移除张紧弹簧和支架。

![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/inserting-the-cover.jpg)

#### 步骤 3：松开张紧组件

用 H 2.0 内六角扳手拧下2颗螺丝，取下2片金属片，然后将张紧轮组件松脱出来。

|  |  |  |
| --- | --- | --- |
|  |  |  |

#### 步骤 4：清洁惰轮

使用 WD-40 棉签清洁惰轮表面。

![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/cleaning_idler_pulley_using_swab.png)

操作示意如下：

![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/cleaning_idler_pulleys3.gif)

#### 步骤 5：完成清洁并复位

清洁后，确认惰轮转动顺畅无卡顿，重新安回张紧轮组件：  
![](https://wiki.bambulab.com/x1/maintenance/clean-idler-pulleys/aligning_the_belt.png)

将张紧轮组件滑入到位，拧入2颗螺丝（带支架），螺丝不要拧紧，保持较松的状态即可。

|  |  |
| --- | --- |
|  |  |

安装张紧弹簧和支架，锁入2颗螺丝进行固定。如下图所示，确保弹簧和支架被螺丝固定在正确的位置。

|  |  |
| --- | --- |
|  |  |

操作完成后，可对另一侧的惰轮也进行同样的操作。

#### 步骤6：安装打印机后盖

完成两边的惰轮清洁后，接下来安装后盖。应首先穿过PTFE管进料处和扣好右侧的皮带张紧口位置，再扣好对准左侧。

|  |  |
| --- | --- |
|  |  |

然后将后盖重新固定。注意使用的不同类型的螺丝(如下图所示的10颗螺丝和4颗螺丝)。

|  |  |
| --- | --- |
|  |  |

#### 步骤7：张紧皮带

因为清洁操作中可能皮带的松紧产生了影响，可能需要重新对皮带进行张紧。拧松另一个张紧轮组件上的两颗螺丝，握住工具头两端的滑车，前后移动工具头数次，最后将滑车紧靠后部，然后拧紧2个张紧轮组件上的4颗螺丝。具体操体可参考 [皮带张紧](belt-tension.md)中的视频。

|  |  |
| --- | --- |
|  |  |

现在我们已经成功完成了惰轮的清洁，虽然操作是以X1系列打印机为例，但此操作对P1系列打印机依然适用。
