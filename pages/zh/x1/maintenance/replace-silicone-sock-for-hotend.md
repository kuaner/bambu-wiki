## 什么是热端硅胶套

热端硅胶套是一个黑色硅胶套，套在喷嘴的表面，用于保证喷嘴温度的稳定。

![xp硅胶套.jpg](https://wiki.bambulab.com/x1/maintenance/replacing-the-silicone-sock-for-hotend/xp%E7%A1%85%E8%83%B6%E5%A5%97.jpg)

## 何时更换

- 硅胶套开裂时
- 硅胶套松动的
- 硅胶套损坏的

## 所需工具和材料

新的硅胶套

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 操作指南

### **步骤 1 - 打开前壳组件**

关闭打印机电源，打开前壳组件，并将其挂在碳杆上。

|  |  |
| --- | --- |
|  |  |

### **第 2 步 - 取下硅胶套**

将工具头向前移动到方便操作的位置，然后用力向下拉，取下硅胶套。

（必要时需要对喷嘴进行清洁）

|  |  |
| --- | --- |
|  |  |

### **第 3 步 - 安装硅胶套**

准备一个新的硅胶套，确保硅胶套的槽口位于正确的方向。将硅胶套向上推至喷嘴顶端，确认安装到位。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 - 合上前壳组件**

合上前壳组件。

![](https://wiki.bambulab.com/x1/maintenance/replace-silicone-sock-for-hotend/346px-close.png)

## 如何验证完成/成功

目视检查硅胶套是否有跷起，触摸硅胶套是否有松动。
