## 什么是 XY 同步皮带

X1 系列 3D 打印上使用的 XY 同步皮带是节线长为 1442mm，宽 6mm 的开口皮带，一共有两条。 它们将 XY 电机和工具头连接起来并驱动工具头在 XY 方向的移动。

![](https://wiki.bambulab.com/x1/maintenance/replace-xy-belt/belt.jpg)

**有两种方法可以实现更换 XY 皮带：**

**方法一**：将原有皮带保留在打印机上，然后将新皮带与旧皮带首尾粘接，通过牵引的方式完成皮带更换。该方法更换皮带相对简单，更适用于 XY 皮带磨损等场景。详细的方法您可继续参阅本 Wiki。

**方法二**：将原有皮带从打印机上取下，再将新皮带依次穿入打印机。该方法更换皮带相对困难，花费时间较长，更适用于 XY 皮带断裂等场景。详细方法您可继续参阅该 Wiki：[XY 同步皮带 | Bambu Lab Wiki](../../p1/maintenance/xy-timing-belt.md)

## 何时更换

- 同步皮带断裂
- 同步皮带老化或磨损，并已影响功能

## 所需工具和材料

1. H1.5 内六角扳手
2. 新的 XY 同步皮带
3. 瞬干胶
4. 平头镊子或一字螺丝刀

## 开始操作前的安全警告和机器状态

关闭电源，移除电源线，如果装有 AMS 缓冲区和料盘支架，也需要先拆除。

## 注意事项

需要更换同步皮带时，如下几点需要特别注意：

1. 更换同步皮带前，不要将旧的皮带拉出，它可用作引线方便安装新的同步皮带；
2. 新旧皮带朝向要一致；
3. 更换同步皮带前，应通过旧皮带了解整条皮带的路径；
4. 使用旧皮带进行引导穿新的同步皮带时，穿的时候不要过快，有明显阻力时，应停下来，确认没异常后再继续；
5. 新旧皮带的粘接处要足够牢固，避免在穿皮带时断开。

特别说明：本指引更偏向为大家提供一个比正常操作简便一些的方案，通过利用旧的皮带进行牵引，可以在不拆除侧面板的情况下完成皮带的更换，请先完整查阅后判断是否按这个指引操作。

## 拆卸指南

### 步骤 1 - 降低热床

开启打印机，在屏幕上操作，将热床下降到底部。完成后，关闭打印机，取下玻璃上盖。

![](https://wiki.bambulab.com/x1/maintenance/replace-xy-belt/space.jpg)

### 步骤 2 - 移除工具头后盖

用 H1.5 内六角扳手拧下4颗螺丝，移除工具头后盖。

![](https://wiki.bambulab.com/x1/maintenance/replace-micro-lidar/1020px-lidar_ds4.png)

### 步骤 3 - 移除后盖螺丝

注意：这个过程涉及到很多螺丝，请将它们区分开来，并把它们放在不同的区域，以免弄混。

如图所示，取下后盖上的 10 颗螺丝和 4 颗螺丝。这是两种类型的螺丝，所以要把它们分开。

| --- | --- |
|  |  |

### 步骤 4 - 拆下后盖

拆下后盖，先将后盖从左侧（面向后盖）皮带张紧口的位置松开，再松开右侧（面向后盖）皮带张紧口的位置，以免卡住。

|  |  |
| --- | --- |
|  |  |

### 步骤 5 - 移除张紧弹簧和支架

拧下 2 颗螺丝，移除张紧弹簧和支架。

|  |  |
| --- | --- |
|  |  |

### 步骤 6 - 松开张紧轮

拧下 2 颗螺丝，取下 2 片金属支架，然后将张紧轮组件松脱出来。

|  |  |
| --- | --- |
|  |  |

### 步骤 7 - 粘接新旧同步皮带

将旧皮带的断裂面（或剪断面）修剪齐整，再将新旧同步带用速干胶粘接起来。注意粘接时，要确认皮带的朝向一致，且要确认粘接是牢固的。对于大部分因同步带断裂而需要更换同步带的例子，你可能需要将新皮带的两端分别跟断裂的同步带粘接起来。而对于因老化而需要更换同步带的情况，一般只需要在接近工具头的位置剪断旧皮带，再粘接新皮带的一端即可。

|  |  |
| --- | --- |
|  |  |

### 步骤 8 - 穿同步皮带

在旧同步带的引导下，将新同步带穿过惰轮和电机。但操作要放慢些和小心点，可以用一边推送，另一边拉的方式穿同步带。还可以用圆柱类的工具如固体胶，来方便你绕过电机齿轮。

|  |  |
| --- | --- |
|  |  |

### 步骤 9 - 移除工具头处的旧同步皮带

穿完同步带后，先将旧的同步带从工具头上移除掉。拧下 1 颗螺丝，用平头镊子或一字螺丝刀将同步带固定块撬出，可以用剪刀将旧的同步带剪断，移除旧的同步带。按照同样的方法移除工具头另一端的旧同步带。

| --- | --- |
|  |  |

## 安装指南

### 步骤 1 - 粘接固定块

如下图所示，用瞬干胶将固定块粘接到同步带端点。

![](https://wiki.bambulab.com/x1/maintenance/replace-xy-belt/attach_the_stopper.jpg)

### 步骤 2 - 安装新同步带到工具头

弯曲同步带，将其沿侧面固定槽向上推到位。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 3 - 固定同步带

用内六角扳手将同步带固定块完全压入安装到位，拧入 1 颗螺丝固定，注意螺丝刚好拧到螺帽与结构件接触即可，不可太过用边拧紧，防止变形。根据步骤 1 到 2 的方法，完成新同步带在工具头另一端的安装。

![](https://wiki.bambulab.com/x1/maintenance/replace-xy-belt/install_the_belt_3.jpg)

### 步骤 4 - 安装张紧轮

将张紧轮组件滑入到位，拧入 2 颗螺丝（带支架），螺丝不要拧紧，保持较松的状态即可。

|  |  |

### 步骤 5 - 安装张紧弹簧和支架

安装张紧弹簧和支架，锁入 2 颗螺丝进行固定。

### 步骤 6 - 安装打印机后盖

安装后盖时，应首先穿过 PTFE 管支架和装好右侧的皮带张紧口位置。

### 步骤 7 - 锁后盖螺丝

将后盖重新固定。注意使用的不同类型的螺丝(如下图所示的 10 颗螺丝和 4 颗螺丝)。

|  |  |
| --- | --- |

### 步骤 8 - 张紧同步带

拧松另一个张紧轮组件上的两颗螺丝，握住工具头两端的滑车，前后移动工具头数次，最后将滑车紧靠后部，然后拧紧 2 个张紧轮上的4颗螺丝。具体操体可参考 [张紧同步带 | Bambu Lab Wiki](belt-tension.md)。

### 步骤 9 - 安装工具头后盖

重新安装工具头的后盖并用 4 颗螺丝（每侧 2 颗）将其固定。完成后，将顶部玻璃盖放回机器上。

## 校准

更换碳棒后，需要重新张紧皮带。

1. 关闭打印机。
2. 松开皮带张紧器的四颗螺钉（但不要卸下）。轻轻前后移动工具头几次，然后将其移至打印机的后端。
3. 再次拧紧四颗螺钉。皮带张紧器中的弹簧系统会自动将皮带调整到正确的张力。**注意：** 只需像拧其他螺钉一样适度拧紧，请勿过度拧紧皮带张紧螺钉。过度拧紧可能导致损坏，且不会提升效果。

## 如何验证完成/成功

- 连接电源，启动打印机。
- 如下图所示，运行设备自检流程，如果没有报错，更换同步带完成。

![](https://wiki.bambulab.com/x1/maintenance/replace-th-board-assembly/self_test.png)

如果报错了，请排查组装是否有问题，重新张紧皮带后，再次运行设备自检。如果问题仍然存在，请联系Bambu Lab服务团队寻求进一步的帮助。
