## 故障描述

当设备检查到某一工具既不在工具头上，也不在挂架上时，设备将判定该工具脱落，并提示该报错信息。  
**可能的原因：**

- 工具脱落；
- 工具在挂架上未放置到位。

## 故障排除

### 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 步骤 1. 检查报错的工具是否掉落

检查报错的工具是否真的掉落；如果掉落，将其按顺序放回对应的挂架泊位即可。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/print-preprint-printtool-drop-detected/zh/02_03008032_h3c-01.png)

### 步骤 2. 检测工具是否正确放置

工具放置到位时，泊位灯应亮起，根据不同工作情况会有不同颜色，常亮、呼吸、闪烁等模式。具体请参考：  
**当机器为空闲状态时**，打印头指示灯的灯语如下：

|  | **挂架/工具头上打印头** |
| --- | --- |
| **白色常亮** | 常温 |
| **橙色常亮** | 高温 |
| **橙色呼吸** | 加热 |
| **红色闪烁** | 异常 |
| **熄灭** | 脱落 |

**当机器处于打印任务中时**，打印头指示灯的灯语如下：

|  | **挂架/工具头上打印头** |
| --- | --- |
| **白色常亮** | 常温/高温 |
| **橙色呼吸** | 加热 |
| **红色闪烁** | 异常 |
| **熄灭** | 脱落 |

- 如果指示灯处于熄灭状态，则说明没有放置到位，请将打印头收回到打印机腔体内，先对齐橙色安装导向槽，然后顺着磁铁吸附到位，放置到挂架上。
