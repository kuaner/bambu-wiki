## 故障现象

发起打印时，实况摄像头会识别打印板上的标签，从而确定是否放置了打印板，以及放置的打印板类型。当打印板放歪、未放置，标签或摄像头被遮挡时，识别过程将受到影响，设备将提示该报错信息。

## 可能的原因

- 打印板放歪
- 打印板未放置
- 标签或摄像头被遮挡

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 排查步骤

### 步骤一：检查打印板

1. 检查打印板是否放歪。

|  |  |
| --- | --- |
| 图 | 图 |

2. 打印板和热床的限位块需紧密贴合。若歪斜，请重新放置。

|  |  |
| --- | --- |
| 图 | 图 |

3. 检查打印板是否是 H3C 专用的打印板。若不是，请使用 H3C 专用打印板重试。

> 注意：H2C 打印板**不适配**H3C 打印机，若在 H3C 上使用 H2C 打印板，其最前沿与闪切挂架的间距仅约 2mm。受尺寸链公差及摆放偏差影响，存在打印头与打印板发生碰撞、蹭板的风险。因此，不建议在 H3C 中使用 H2C 的打印板。

了解更多打印板的信息，请阅读[**拓竹打印板介绍**](../../filament-acc/acc/plates.md)。

### 步骤二：检查遮挡

检查打印板上的标签是否有脏污或遮挡。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/build-plate-not-detected/zh/12_05004095_h3c-05.png)

检查实况摄像头是否被遮挡。

> 若需要安装摄像头隐私盖，请确保打印板放置正确后，忽略该报错。

![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/build-plate-not-detected/zh/12_05004095_h3c-06.png)
