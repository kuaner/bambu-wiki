## 指示灯

在日常使用 AMS 3H 时，可通过指示灯的颜色和闪烁方式判断设备是否正常工作。

![20261030c-001.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/ams-led-status/zh/20261030c-001.jpg)

## 指示灯状态解析

| 序号 | LED 灯 | AMS 3H 状态 |
| --- | --- | --- |
| **错误状态（红灯）** |  |  |
| 1 | 所有槽位红灯双闪。 | AMS 与打印机之间通信异常。 |
| 2 | 个别槽位红灯双闪 | 对应槽位进退料异常，或该槽耗材已用尽。 |
| 3 | 烘干仓内槽位（6、8）红灯同频呼吸。 | 烘干异常。 |
| 4 | 所有槽位红灯常亮。 | 开机校准失败。 |
| 正常状态（白灯、橙灯） |  |  |
| 1 | 所有白灯先逐渐点亮，随后转为常亮 | 设备处于开机后的初始化阶段。若 10 分钟内没有插入耗材，指示灯会全部熄灭。 |
| 2 | 所有已插入耗材的槽位白灯常亮；未插入耗材的槽位保持熄灭。 | 设备处于空闲状态。 |
| 3 | 正在进料或打印的槽位白灯呈呼吸效果；其余已插入耗材的槽位白灯常亮；未插入耗材的槽位保持熄灭。 | 设备正在执行进退料，或处于打印过程中。 |
| 4 | 烘干仓内槽位（6、8）橙灯同频呼吸。 | 正常烘干中。 |
