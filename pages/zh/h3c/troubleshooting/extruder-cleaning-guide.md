## 何时使用

1. 长时间使用设备打印后，需要清理挤出轮；
2. 耗材在挤出机中磨损，产生了较多碎屑。

## 所需工具和材料

- 毛刷
- 剪钳

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 清理工作

在屏幕上放置当前使用的打印头。

![sc2.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/extruder-cleaning-guide/zh/sc2.jpg)

取下 AMS 的磁吸侧板。

|  |  |
| --- | --- |
| 002.png | 003.png |

观察从动轮和挤出轮上是否有残留的耗材碎屑，清理干净。

![004.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/extruder-cleaning-guide/zh/004.png)

清理完成后检查打印头上残留的耗材是否被磨损。

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/extruder-cleaning-guide/zh/005.png)

若存在磨损，请先按压上方切刀。

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/extruder-cleaning-guide/zh/006.png)

切断耗材后，切刀刀片会卡住，再按住下方调回切刀。

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/extruder-cleaning-guide/zh/007.png)

再使用剪钳从底部剪断这段耗材，并拉出上半部分。

|  |  |
| --- | --- |
| 008.gif | 009.png |

完成该步骤后， 从 AMS 处回收耗材，重新插入并进料。

![010.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/extruder-cleaning-guide/zh/010.png)

若某一耗材经常出现磨损，建议尝试使用其他耗材；若不同耗材使用时都出现磨损，请进行[喷嘴冷拔](../maintenance/nozzle-cold-pull-maintenance.md)，并检查料管是否存在过度弯折。
