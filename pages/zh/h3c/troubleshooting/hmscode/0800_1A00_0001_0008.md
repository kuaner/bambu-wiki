## 故障现象

锁紧电机和变距电机必须经过机械行程标定后才可使用。在发起动作时，当检测到未进行过机械行程标定，打印机则会弹出该错误提示。

## 可能的原因

- 更换了新的 TH 板
- 更换了新的变距电机/组件、锁紧电机/组件

## 排查步骤

### 下载标定 G-code 并导入 U 盘。

获取附件：[th-motor-calibration.gcode](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_1a00_0001_0008/th-motor-calibration.gcode)

### 取下工具

拆卸 AMS 的左右磁吸侧板。

|  |  |
| --- | --- |
| 001.png | 002.png |

扶住工具顶部，在屏幕上点击“工具箱->打印头&挂架维护->解锁工具”。

![003.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_1a00_0001_0008/zh/003.jpg)

小心取下工具。

![004.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_1a00_0001_0008/zh/004.webp)

放置在挂架上。

![005.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_1a00_0001_0008/zh/005.webp)

<details>

<summary><b>若解锁后依然无法取下工具，可参考本步骤操作。</b></summary>

1. 参考[工具头外壳拆装指南](../../maintenance/replace-toolhead-front-cover.md)取下工具头左侧前盖。
2. 使用套筒工具，顺时针转动锁紧电机轴，解锁工具。

|  |  |
| --- | --- |
| 006.png | 007.webp |

3. 小心取下工具，并放置在挂架上。

![008.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_1a00_0001_0008/zh/008.webp)

### 执行 G-code

在屏幕上选择“文件”，点击导入的 G-code，发起打印。

![009.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_1a00_0001_0008/zh/009.png)

屏幕提示打印完成，代表标定完成。
