## 故障描述

取用工具过程中，在工具头上锁动作执行完成后，正常情况下需要满足：工具头的工具识别传感器能够检测到工具，且能够识别到有效的工具序号。如果以上条件都不满足，就会触发取用失败并上报该hms。

**可能的原因：**

1. 取用过程中发生碰撞丢步但没有检测出来。
2. 上锁组件失效导致没有成功上锁。

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手

***用户可视情调整各排故措施的顺序。***

#### 步骤 1. 重试，观察取用过程中是否有碰撞

- 取下 AMS 磁吸侧板，点击重试；

|  |  |
| --- | --- |
| 001.png | 002.png |

- 观察机器在取用工具，工具头进入泊位路径上有没有明显的干涉、丢步，或明显的撞击声音；

  - 如果有，请参考 [1A00\_0100\_0001\_005C](1A00_0100_0001_005C.md)进行丢步故障的排查。
  - 如果没有，可跳过此步骤。

#### 步骤 2. 检查上锁弹片是否断裂

检查工具头的两个上锁弹片是否完整；

![003.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_0100_0001_0059/zh/003.png)

- 若弹片断裂缺失，请联系售后团队更换。
- 若弹片正常，跳过此步骤。

#### 步骤 3. 重新进行泊位标定

- 结束当前打印任务，将工具放回泊位。

![004.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_0100_0001_0059/zh/004.png)

- 进入**设备校准**页面，重新执行一次**挂架泊位标定**。

|  |  |
| --- | --- |
| 005.png | 006.png |

若完成上述操作后故障仍未解决，请联系客户支持团队。
