## 故障描述

放置工具时，在工具头解锁并退出挂架泊位后，如果检测到被放置的工具从挂架泊位上掉落，机器会报错暂停，需要用户干预恢复。

**可能的原因：**

1. 热端锥面、工具头上的工具定位槽锥面上有打印耗材残留，融化后把工具与定位槽粘住导致放置失败；
2. 泊位磁铁上吸附金属异物；
3. 料管变形、歪斜、交叉；
4. 挂架、泊位相对机身 XY 框架发生偏移，如果拆装过挂架、泊位组件，泊位坐标可能发生变化；长途运输搬运、碰撞也可能导致泊位坐标发生变化，需要重新进行泊位标定。

## 故障排除

#### 步骤 1. 装回脱落的工具

拆掉磁吸侧板。

|  |  |
| --- | --- |
| 001.png | 002.png |

将脱落的工具放回挂架后，点击重试。

![003.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_0100_0001_0058/zh/003.webp)

如果出现以下情况，请**先停止打印**后，按照后续步骤排查：

1. 打印头在工具头上，无法取下放回挂架；
2. 某个打印头\刀切头\画笔头多次出现该报错，必须手动放回挂架。

#### 步骤 2. 检测工具头、热端锥面是否有耗材残留

进入“工具箱-打印头/挂架维护”，点击“解锁工具”（注意打印任务、取用工具、放置工具、进退料中无法使用“解锁工具”，需要停止后才能使用）。

![004.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_0100_0001_0058/zh/004.png)

扶住打印头，缓慢取下。

注：若无法取下，可能是耗材冷却后黏住了打印头，请设置热端加热到 250℃，并佩戴隔热手套进行后续操作。

![005.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_0100_0001_0058/zh/005.webp)

检查报错的热端锥面、以及工具头的工具定位槽锥面是否有耗材残留，有的话需参考[工具头定位槽粘料清理指南](../guide-for-cleaning-the-tool-holder.md) 清理干净。

|  |  |
| --- | --- |
| 006.png | 007.png |

若没有耗材残留，请检查步骤二。

#### 步骤 3. 检查工具和泊位上的磁铁

检查并清理掉工具、泊位磁铁上吸附的异物，然后重试。没有的话，跳过此步骤。

![008.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_0100_0001_0058/zh/008.png)

#### 步骤 4. 检查料管

在工具放回泊位的状态下，如果料管有明显扭曲、歪斜、交叉，需要重新安装或更换新的料管，可参考[料管更换指南](../../maintenance/replace-ptfe-tube.md)。

如果料管整洁没有问题，可跳过此步骤。

![009.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_0100_0001_0058/zh/009.png)

#### 步骤 5. 重新进行挂架对位校准

设备空闲状态下，进入设备校准页面，进行挂架对位校准。

![010.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_0100_0001_0058/zh/010.png)

#### 步骤 6. 磁铁脱落

工具上有传感器检测磁场变化，若挂架上的圆形磁铁脱落，那么工具装上挂架后依然会报错脱落。

![011.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_0100_0001_0058/zh/011.png)

若磁铁脱落则需要[更换泊位组件](../../maintenance/replace-dock-assembly.md)。
