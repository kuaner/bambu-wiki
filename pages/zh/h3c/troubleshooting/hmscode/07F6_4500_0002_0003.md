## 故障现象

当打印机在退料或换料时，切刀用于在拉回耗材之前切割耗材。切割时，工具头会移动到切料位置，切刀顶杆会自动弹出，顶杆压下工具头刀柄进而带动装在打印头上的刀片完成切割。切料是否到位由工具头刀柄内的磁铁与工具头上的霍尔传感器配合检测，磁铁靠近霍尔传感器时即判定切料成功。**当检测到刀柄在设定的时间范围内没有弹回原位时，打印机会弹出该提示。**

|  |  |
| --- | --- |
| 001.jpg | 002.png |

左图： 切刀刀柄的磁铁；右图：工具头上的切料霍尔传感器

故障发生时会出现以下现象：

- 切料后工具头被移开，刀柄没有自动弹回；
- 打印过程或切料前，刀柄在起始位置，但刀柄磁铁对应的霍尔传感器异常，导致打印机依然报错刀柄未松开。

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 排查步骤

#### 若刀柄已松开

若确认刀柄已松开但仍提示报错，请先点击“重试”或“继续”，观察设备是否恢复正常。

若重试后仍异常，需检查切刀刀柄上的磁铁是否正常安装，步骤如下：

1. 请参考下方 wiki 移除工具头右侧盖：

[**工具头外壳更换**](../../maintenance/replace-toolhead-front-cover.md)

![003.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/07f6_4500_0002_0003/zh/003.png)

2. 松出刀柄的一颗固定螺丝。

![004.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/07f6_4500_0002_0003/zh/004.png)

3. 检查刀柄上的磁铁是否正确安装。

![005.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/07f6_4500_0002_0003/zh/005.jpg)

4. 参考 Wiki [**更换 H3C 挤出接口板**](../../maintenance/replace-extruder-connection-board.md) 检查切刀霍尔排线是否松动，若松动请重新连接排线。

![006.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/07f6_4500_0002_0003/zh/006.jpg)

#### 若刀柄未松开

若刀柄未松开，请按以下步骤排查：

1.**观察耗材状态**

从挤出轮观察窗检查耗材是否送入，并检查耗材头是否变形。

|  |  |
| --- | --- |
| 007.png | 008.png |

**若观察到耗材头变形，请进行以下检查：**

- 放置当前使用的打印头；

![009.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/07f6_4500_0002_0003/zh/009.png)

- 用手抓住 AMS 左/右侧板扣手位，向外侧用力，将左/右侧板从 AMS 支架上分离并取下。

![010.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/07f6_4500_0002_0003/zh/010.jpg)

- 取下打印头，使用剪钳剪断变形的耗材，然后装回重试。

注意：请勿触碰热端，小心烫伤。

|  |  |
| --- | --- |
| 011.png | 012.png |

2.**检查热端是否堵塞或裹头**

请参考这篇 wiki：[**H3C 堵塞排查指南**](../clogging.md) {target="\_blank"} 的步骤3，检查热端是否堵塞。

若堵塞，请参考这篇 wiki：[**H3C 热端堵塞清理指南**](../unclogging.md) 清理热端后重试。

![013.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/07f6_4500_0002_0003/zh/013.png)

3. 检查切刀刀柄周围是否有残料，清除残料后再重试。

具体步骤可参考这篇 wiki：[**工具头切料组件更换指南**](../../maintenance/replace-cutter-push-arm-assembly.md)。

![014.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/07f6_4500_0002_0003/zh/014.png)

4. 若以上步骤都无法解决问题，则可能是刀柄内部的回弹结构故障，导致无法正常复位，需要更换切料组件，具体步骤可参考这篇 wiki：[**工具头切料组件更换指南**](../../maintenance/replace-cutter-push-arm-assembly.md)。

![015.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/07f6_4500_0002_0003/zh/015.jpg)
