## 故障描述

重启后的第一次锁紧/解锁动作，锁紧电机会进行行程标定动作，检查整个运动路径是否顺畅。该过程电机会进行连续两次的运动，当两次运动结果相差过大时，设备将会提示该报错信息。

## 可能的原因：

- 电机转子/齿条/弹片被异物卡住
- 电机固定到工具头的螺丝松动，导致电机空转
- 齿条润滑失效

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手
- H2.0 六角扳手
- 工具头电机解锁套筒

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 排故措施

***用户可视情调整各排故措施的顺序。***

#### 步骤1. 检查运动结构是否卡住

成功抓取后工具前端的斜面会被牢牢按压在工具头定位槽上。

|  |  |
| --- | --- |
| 001.png | 002.png |

如发现未抓取到位，可拆下磁吸侧板。

|  |  |
| --- | --- |
| 003.png | 004.png |

尝试取下工具。

若无法取下，可一手扶住工具，另一只手点击屏幕设置->工具箱->打印头&挂架维护->解锁工具。

![005.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0006/zh/005.jpg)

解锁工具后，检查工具上是否存在异常，如耗材脱出、切刀卡住等。

|  |  |
| --- | --- |
| 006.png | 007.jpg |

若耗材脱出，则按压切刀上方，切断该截耗材后取出即可。

![008.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0006/zh/008.png)

若切刀卡主，需从 AMS 处抽回耗材，并按压切刀下方；

![009.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0006/zh/009.png)

没有异常则将工具放回挂架，点击屏幕重新取用此工具，若报错依旧请进行后续检查。

![010.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0006/zh/010.png)

#### 步骤2. 检查电机固定螺丝是否松动

参考[工具头外壳拆装指南](../../maintenance/replace-toolhead-front-cover.md)取下工具头左侧前盖。

取下工具头前盖后，从工具头侧方观察锁紧电机、齿条上是否有异物。

![011.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0006/zh/011.png)

排除异物后，取出工具盒中的套筒，装在 H2.0 内六角扳手上转动电机轴。

![012.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0006/zh/012.png)

将齿条移动到最右侧位置。

![013.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0006/zh/013.webp)

再使用螺丝刀检查锁紧电机的固定螺丝是否紧固，若螺丝固定牢靠，装回左侧前盖后重新取用。

![014.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0006/zh/014.png)

若依旧报错，请联系客户支持团队。
