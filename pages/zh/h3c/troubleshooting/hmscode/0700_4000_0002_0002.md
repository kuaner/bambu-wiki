## 故障描述

在使用 AMS 时，缓冲器安装于 AMS 与打印机之间。

缓冲器由**滑块、弹簧和两个霍尔传感器**组成：

- 当 AMS 将耗材推入挤出机时，耗材的压力会推动滑块前移；
- 入口处的第一个霍尔传感器用于检测耗材是否进入缓冲器；
- 第二个霍尔传感器位于滑块上方，用于检测滑块位置并将信号反馈给 AMS 与打印机；
- 一旦缓冲信号丢失，AMS 将无法顺利输送耗材。

## 故障排除

#### 步骤 1. 重新连接缓冲器连接线

1. 关闭打印机电源。

![002.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_4000_0002_0002/zh/002.jpg)

2. 移除缓冲器的两颗螺丝，取下缓冲器。

|  |  |
| --- | --- |
| 003.png | 004.png |

3. 断开并重新连接缓冲器连接线，确保插紧到位。

|  |  |
| --- | --- |
| 005.png | 006.png |

4. 安装缓冲器，锁紧两颗螺丝进行固定。

|  |  |
| --- | --- |
| 007.png | 008.png |

5. 重新开机，观察该错误提示是否消失。若仍弹出，请继续下一步。

![009.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_4000_0002_0002/zh/009.jpg)

#### 步骤 2. 检查缓冲器弹簧

检查缓冲器弹簧是否出现扭曲，如果扭曲，请使用镊子矫正弹簧。

![010.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_4000_0002_0002/zh/010.png)

#### 步骤 3. 检查 6-pin 线缆版本

版本 1 的 6-pin 线缆（图左）安装在 AMS 2 Pro 或 AMS HT 上可能导致该报错，请使用版本 2 线缆（图右）。

![011.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_4000_0002_0002/zh/011.jpg)

#### 步骤 4. 检查并重新连接 6-pin 线缆

检查 6-pin 线缆针脚是否开口。

若方形口明显变形，则需要更换新的线缆。若线缆无明显异常，请断开线缆并重新连接后重试。

![012.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_4000_0002_0002/zh/012.jpg)

#### 步骤 5. 检查 AMS 内部线缆

若问题仍未解决，请检查 AMS 内部信号线是否松动。

1. 从 AMS 背面按下 PTFE 料管释放按钮，拉出料管；

![013.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_4000_0002_0002/zh/013.png)

2. 从下盖内侧捏住卡扣，同时从背面扶住释放按钮，避免弹簧弹出丢失；

|  |  |
| --- | --- |
| 014.png | 015.png |

3. 拆下中间 2 个料槽的从动支撑套筒组件；

![016.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_4000_0002_0002/zh/016.png)

4. 拆下 2 颗螺丝 A (BT3x8)；

![017.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_4000_0002_0002/zh/017.png)

5. 将主框架后部完全提起来，竖立放置在 AMS 下盖上。抬起时，建议先抬主框架前部分，再往前推，为框架后部分腾出空间。竖放 AMS 主框架时需避开风门的电子部件，以防压坏。

|  |  |
| --- | --- |
| 018.png | 019.png |

6. 检查信号线是否牢固插入。如未插紧，请重新插好；然后断开信号线和电源线，抬出中框；

|  |  |
| --- | --- |
| 020.png | 021.png |

7. 再次确认信号连接线是否插紧。

![022.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_4000_0002_0002/zh/022.png)

#### 步骤 6. 测量电压和电阻（可选）

若您有万用表，可参考本章节进一步检查信号线状态。

若无万用表，请联系我们的客户服务团队并提供打印机日志。具体步骤请参考这篇 Wiki 教程：[如何创建工单及上传日志](../../../x1/troubleshooting/how-to-upload-log.md)。

1. 将耗材卸载回 AMS，缓冲器滑块应处于左侧；
2. 测量 6-Pin 电缆（从 AMS 拔下）的电压：

|  |  |
| --- | --- |
| 023.png | 024.png |

**正常电压范围如下（两者相加应为 3.0～3.3V）：**

| pin-pin | 电压 |
| --- | --- |
| GND - Buffer\_A | 0.5 ~ 1.0 V |
| GND - Buffer\_B | 2.3 ~ 2.8 V |

*提示：可以滑动缓冲滑块，在不同位置测量电压，其和应始终在 3.0～3.3 V 范围内。*

3. 如果电阻异常，请拆卸 AMS 并在主板上直接测量。正常范围为 4～6 kΩ，否则 AMS 主板可能损坏。

**正常电阻范围如下**

| pin-pin | 电阻 |
| --- | --- |
| GND - Buffer\_A | 4 ~ 6 kΩ |
| GND - Buffer\_B | 4 ~ 6 kΩ |
