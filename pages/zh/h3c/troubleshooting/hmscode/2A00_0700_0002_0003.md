## 故障描述

设备开机时，首先会将选料杆回零，从而确定选料杆的起始位置。如果回零成功，则进入空档位状态，此时不会选择任何槽位。当设备长时间未完成回零时，将提示该报错信息。

## 可能的原因：

1. 选料电机卡住不能正常转动，不能带动选料杆移动。
2. 选料杆运动阻力过大、被异物卡住，不能移动到回零磁铁位置。

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手
- H2.0 六角扳手

### 排故措施

#### 检查选料杆移动状态

重启设备后，透过透明外壳观察选料杆移动。若选料杆无法移动，请跳转**步骤二**。若选料杆能够移动，则继续本步骤。

![001.gif](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0003/zh/001.gif)

退出所有耗材，并将料头固定在料盘上。

![002.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0003/zh/002.png)

拔出所有料嘴。

![003.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0003/zh/003.png)

使用 H2.0 六角扳手拧下保护盖的 4 颗固定螺丝。

![004.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0003/zh/004.png)

向上拆下进料机构保护盖子。

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0003/zh/005.png)

重新开机，观察选料杆左右移动是否受到阻碍，并排查移动路径上的异物。若外观均正常，可参考 [AMS 3H 维护指南](../../maintenance/ams_3h.md)进行维护。

![006.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0003/zh/006.webp)

#### **检查选料电机线缆**

从AMS 3H中拿出所有料盘。

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0003/zh/007.png)

拆下AMS 3H侧面的两个磁吸盖板。

|  |  |
| --- | --- |
| 008.png | 009.png |

使用H2.0六角扳手拧下四颗固定螺丝。

|  |  |
| --- | --- |
| 010.png | 011.png |

双手将整个AMS 3H从打印机上抬起，然后反转放到桌面上。

![012.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0003/zh/012.png)

使用 H1.5 螺丝刀拆下 AMS 3H 主板的保护壳。

![013.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0003/zh/013.png)

重新拔插“6 号”选料电机的插头，注意需按压顶部防松卡扣才能取下。

![014.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0003/zh/014.png)

完成后复原设备，通电开机，观察选料杆是否能够运动。若依然无法运动，则需要[更换新的选料电机](../../../ams3/maintenance/replace-feed-selector-motor.md)。
