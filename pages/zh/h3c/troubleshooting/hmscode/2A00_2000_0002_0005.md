## 故障描述

当 AMS 上该槽位的耗材用尽后，设备会将剩余的旧料全部冲刷完。若冲刷过程中打印头上霍尔传感器长时间检测到有耗材，则会判定冲刷存在异常。

## 可能的原因：

- 热端堵塞。
- 耗材卡在打印头内部或断裂。
- 打印头耗材传感器异常。
- AMS 耗材传感器异常

## 故障排除

### 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 排故措施

**步骤1. 检查耗材是否用尽**

观察 AMS 上该槽位的料盘中是否还有耗材。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0005/zh/001.png)

- 若耗材已经用尽，请进行后续排查。
- 若耗材断裂，可重新插入耗材恢复打印，或更换其他耗材使用。
- 若耗材未用尽，则为 AMS 耗材传感器故障导致的异常现象。

请参考AMS 3H 维护[AMS 3H 定期维护指南](../../maintenance/ams_3h.md)清理入料口组件。

装回后开机并插入耗材。

![002.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0005/zh/002.png)

若屏幕上无法显示该槽位存在耗材，则需要更换新的 AMS 入料口组件[AMS 3H 入料口组件更换指南](../../../ams3/maintenance/replace-filament-inlet-assembly.md)。

**步骤2. 检查热端是否堵塞**

若耗材卡在料管中，可能是进料阻力过大或热端堵塞导致的故障。

拆卸左右两侧的 AMS 磁吸侧板。

![003.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0005/zh/003.png)

从挂架上取下打印头，按住打印头刀柄切断耗材；

注：此时热端温度较高，小心烫伤。

|  |  |
| --- | --- |
| 004.png | 005.png |

按压黑色压块，取下料管。

|  |  |
| --- | --- |
| 006.png | 007.png |

抽出料管中的耗材，若阻力适当，则可能是热端堵塞导致报错。 参考热端堵塞清理[拓竹H3C 热端堵塞清理指南](../unclogging.md)处理，确保耗材能够从热端挤出。

![008.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0005/zh/008.webp)

若较难抽出料管中的耗材，请检查料管是否弯折或耗材是否变形，减轻阻力后抽出旧料，重新插入新耗材。

**步骤3. 检查打印头进料霍尔**

若料管中已经没有耗材，但仍反复提示该报错信息，则可能是打印头耗材传感器工作异常。

![009.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0005/zh/009.png)

请参考"霍尔排查指引"[拓竹H3C 打印头进料霍尔排查指南](../filament-sensor-test.md)，检查传感器是否能正确检测耗材状态。

- 若传感器存在故障，则需要更换打印头基座[打印头组件更换指南](../../maintenance/replace-printtool.md)。
- 若传感器工作正常，则联系客户支持团队。
