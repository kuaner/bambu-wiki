## 故障描述

放置工具时，工具头运动过程中发生丢步，机器自动进行回中、重试后，仍然检测到丢步，已无法继续进行放置动作，此情况下会报该hms。

**可能的原因：**

1. 此工具、以及相邻工具在挂架泊位上没有放置到位，歪斜，导致工具头进入泊位途中发生干涉。
2. 泊位磁铁有异物吸附。
3. 工具头外挂件未安装到位、变形损坏。
4. 异常泊位相邻热端的切刀卡住，没有复位弹出。
5. 泊位坐标偏移。

## 故障排除

***用户可视情调整各排故措施的顺序。***

#### 步骤 1. 检查相邻工具

确保该工具以及相邻工具均放置到位。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_0100_0001_005c/zh/001.png)

#### 步骤 2. 检查磁铁是否有异物

检查并清理泊位磁铁上是否存在异物。

|  |  |
| --- | --- |
| 002.png | 003.png |

#### 步骤 3. 检查工具头外观件

检测工具头前盖是否安装到位，若存在缝隙请参考[工具头外壳 (前盖/后盖) 更换指南](../../maintenance/replace-toolhead-front-cover.md)重新安装。若存在破损变形请联系客户支持团队。

|  |  |

|  |  |

#### 步骤 4. 检查相邻泊位热端切刀

泊位上的切刀需要处于正常回弹状态，如果相邻的热端切刀卡住，可能会导致干涉造成丢步，请手动将其复位后重试。

|  |  |
| --- | --- |
| 006.jpg | 007.jpg |

#### 步骤 5. 对位校准

设备空闲状态下，进入设备校准页面，进行对位校准。

|  |  |
| --- | --- |
| 008.png | 009.png |

若对位校准失败，请联系客户支持团队为您提供帮助。
