## 故障现象

挂架回中过程中，系统会测量挂架上下限位之间的距离，如果测量得到的距离和限位之间的设计距离差别过大，挂架会重试回中，如果重试多次后的测量距离仍无法满足要求，打印机则会弹出该错误提示。

## 可能的原因

- 打印板放歪
- 挂架运行路径上有异物阻挡

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 排查步骤

### 步骤一：检查打印板

1. 检查打印板是否放歪，打印板放置不当，会导致挂架下移时撞击打印板，阻碍运动。若歪斜，请重新放置。

|  |  |
| --- | --- |
| 001.png | 002.png |

2. 检查打印板和热床的限位块是否紧密贴合。若歪斜，请重新放置。

|  |  |
| --- | --- |
| 003.png | 004.png |

3. 检查打印板是否是拓竹H3C 专用的打印板。若不是，请使用拓竹H3C 专用打印板重试。

注意：H2C 打印板**不适配**拓竹H3C 打印机，若在拓竹H3C 上使用 H2C 打印板，其最前沿与闪切挂架的间距仅约 2mm。受尺寸链公差及摆放偏差影响，存在打印头与打印板发生碰撞、蹭板的风险。因此，不建议在拓竹H3C 中使用 H2C 的打印板。

了解更多打印板的信息，请阅读[拓竹打印板介绍](../../../filament-acc/acc/plates.md)

### 步骤二：检查挂架上是否存在异物

拆卸左右两侧的 AMS 磁吸侧板。

|  |  |
| --- | --- |
| 005.png | 006.png |

观察挂架运动路径上是否有异物，常见异物有：

- 倒塌/移位的擦抖塔
- 热端上的料管或连接线
- 没放好掉下来的热端
- 小打印件

若有异物，请将其妥善清理，然后点击屏幕重试挂架回中，如果挂架回中后没有报错，则问题解决。

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_e400_0001_0061/zh/007.png)

若重试仍报错，请关闭打印机电源，用手上下推拉挂架，若感受到较大的阻力，可能是异物仍未清除，请检查并清除异物。

![008.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_e400_0001_0061/zh/008.webp)

点击回中，若报错消失，则故障解决；若故障依旧，请联系客户支持团队。
