## 故障描述

> **由于系统针对 TPU 打印设置了特定的堵头检测阈值，因此本故障排查仅用于“使用外挂料盘打印 TPU 耗材”的场景。材料不匹配可能导致误报**。

当挤出电机检测到挤出阻力异常时，打印机会处于暂停状态，需要排查故障后继续打印。

## 可能的原因：

- 耗材卡在工具头内。
- 切片文件中的材料设置与实际使用的耗材不一致。例如，在切片文件中选择 TPU 材料，而实际使用的并非 TPU。
- 热端堵头。

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 排故措施

#### 步骤一：检查耗材是否从打印头中滑出

通过打印头的观察窗，检查内部耗材是否有滑出风险。

|  |  |
| --- | --- |
| 001.png | 002.png |

若耗材存在滑出，请拆卸左右两侧的磁吸侧板。

|  |  |
| --- | --- |
| 003.png | 004.png |

通过屏幕点击“打印头/挂架维护”。

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0002/zh/005.png)

点击左下角的解锁工具。

![006.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0002/zh/006.jpg)

取下打印头。

![007.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0002/zh/007.webp)

放回挂架。

![008.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0002/zh/008.webp)

回收 TPU 耗材。

![009.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0002/zh/009.png)

根据 《步骤三》，疏通一次热端后再使用 TPU。

#### 步骤二：确保实际使用耗材与切片耗材均为 TPU

1. 若切片中耗材与实际耗材不匹配，请重新切片以匹配当前耗材，或更换耗材以匹配切片；

![010.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0002/zh/010.png)

2. 若耗材类型匹配，可额外增加 5-10℃ 后重新尝试挤出；如果仍然无法挤出耗材，请参考步骤 2。

#### 步骤三：热端堵塞清理

1. 在屏幕上点击“退料”，退出当前 TPU 耗材。

![011.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0002/zh/011.png)

2. 参考[喷嘴堵塞清理](../unclogging.md)使用 PLA 耗材进行程序自动冷拔清理。完成清理后，尝试重新挤出。

- 若恢复正常成功挤出，则问题已解决；
- 若仍然无法挤出，可能热端已经磨损或损坏，则需[更换热端](../../maintenance/replace-hotend.md)。
