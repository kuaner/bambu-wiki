## 故障现象

AMS 3H 开机后，会首先进行自检与回零。正常情况下，可透过中间的透明盖观察到内部橘色选料杆左右移动，校准初始位置。若在此回零过程中，观察到选料杆在原地振动，伴随“哒哒哒”的异常响声，9个料嘴的高度无法回到同一水平高度，且红色指示灯亮起，系统会检测到选料杆的行程误差过大，打印机则会弹出该错误提示。此时难以插入耗材，插入耗材后也不会进行预上料。

## 可能的原因

- 选料杆被异物卡住，导致行程异常。
- 回零阻力过大，导致行程异常。
- 齿轮组件故障，导致行程异常。

## 排查步骤

### 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

1. 重启打印机，或者断开并重连 AMS 3H 后部的 6-Pin 线，重新触发 AMS 3H 的回零动作。

|  |  |
| --- | --- |
| 001.jpg | 002.png |

2. 使用手电筒贴紧 AMS 3H 进料组件透明外壳的左侧部分，向内部照射灯光。

![003.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0001/zh/003.png)

3. 仔细观察内部是否有异物。若有，请参考[更换 AMS 进料组件上盖](../../../ams3/maintenance/replace-auto-filament-loader-cover.md)，取下透明盖后，清理异物。

|  |  |
| --- | --- |
| 004.png | 005.png |

4. 如果齿轮发生跳齿，发出哒哒哒异响，则说明挤出齿轮组件故障。请参考这篇 wiki 教程更换：[**AMS 3H 挤出齿轮组件更换指南**](../../../ams3/maintenance/replace-feeder-gear-set.md)

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0001/zh/006.png)

5. 在打印机屏幕上，退出全部耗材，手动拉出耗材。然后，断开并重连 AMS 3H 后部的 6-Pin 线，重启 AMS 3H。如果回零正常，则说明回零阻力过大，需要更换选料杆与选料齿轮组件，具体教程请参考这一篇 wiki：[**AMS 3H 自动进料组件更换指南**](../../../ams3/maintenance/replace-auto-filament-loader.md)。
