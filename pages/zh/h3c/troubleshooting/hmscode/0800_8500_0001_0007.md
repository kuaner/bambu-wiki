## 故障描述

变距电机驱动摆臂左右运动，从而调节从动轮齿轮和挤出齿轮间距。当摇臂超过限制时间仍未到达目标位置，则会提示该报错信息。

## 可能的原因：

- 热端未被弹片抓取到位
- 电机/凸轮/摆臂被异物卡住
- 凸轮润滑失效

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手
- H2.0 六角扳手
- 工具头电机解锁套筒

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 排故措施

***用户可视情调整各排故措施的顺序。***

#### 步骤1. 检查热端是否抓取到位

成功抓取后，打印头前端的斜面会被牢牢按压在工具头定位槽上。

|  |  |
| --- | --- |
| 001.png | 002.png |

如发现未抓取到位，可拆下磁吸侧板。

|  |  |
| --- | --- |
| 003.png | 004.png |

尝试取下工具。

若无法取下，可一手扶住工具，另一只手点击屏幕设置->工具箱->打印头&挂架维护->解锁工具。

![005.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8500_0001_0007/zh/005.jpg)

解锁工具后，检查工具上是否存在异常。

![006.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8500_0001_0007/zh/006.jpg)

若耗材脱出，可从 AMS 处回收，或按压切刀杆，裁断这截耗材。

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8500_0001_0007/zh/007.png)

没有异常则将工具放回挂架，点击屏幕重新拾取此工具，若报错依旧请进行后续检查。

#### 步骤2. 检查运动结构是否卡住

参考[工具头外壳拆装指南](../../maintenance/replace-toolhead-front-cover.md)取下工具头左侧前盖，观察从动轮组件上是否有异物。

![008.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8500_0001_0007/zh/008.png)

如果没有异物，可参考《[定期维护指南](../../maintenance/periodic-maintenance.md)》润滑从动轮组件。

完成后参考[工具头外壳拆装指南](../../maintenance/replace-toolhead-front-cover.md)

装回前盖。

#### 步骤3. 检查电机凸轮是否松动

若使用套筒转动电机轴时，凸轮不会跟着旋转，则需要[更换新的变距电机](../../maintenance/replace-2012-flexfeed-motor.md)。
