## 故障描述

当打印任务涉及多个喷嘴时，为确保各喷嘴间的相对定位准确，需执行喷嘴偏移校准。发起打印时若未勾选"喷嘴偏移校准"，则会沿用上次校准的数值。

当手动执行校准时，若各喷嘴间的检测数据差异过大，设备在多次重试后仍无法满足要求，屏幕将显示该报错信息。

##**可能的原因**

- 喷嘴尖端或工具头定位槽存在耗材残留
- 打印板上方或下方存在打印件残留
- 喷嘴偏移校准传感器未固定牢固

## 所需要工具

- 镊子
- H2.0 六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 排故措施

### 步骤1. 检查打印头和热床

1. 检查热端喷嘴或热床上是否粘有耗材，并及时清理干净。

|  |  |
| --- | --- |
| 001.png | 002.png |

2. 检查每个喷嘴的锥面和工具头定位槽上是否存在耗材残留。若有耗材残留，请清理后重新执行喷嘴偏移校准。

|  |  |
| --- | --- |
| 003.png | 004.png |

### 步骤2. 检查喷嘴偏移校准传感器

检查热床后侧的喷嘴偏移校准传感器上是否粘有耗材，若有耗材残留，请清理后重新执行喷嘴偏移校准。

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2700_0001_0002/zh/005.png)

若没有耗材残留，请拧下固定螺丝。

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2700_0001_0002/zh/006.png)

重新安装一次传感器接头，再固定回热床。

> 该插头需按压防松卡扣后才能取下。

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2700_0001_0002/zh/007.png)

完成上述检查后，重新开启喷嘴偏移校准，若故障依旧，请联系客户支持团队。

![008.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2700_0001_0002/zh/008.png)
