## 故障描述

在取用工具过程中，工具头移动到对应泊位上锁动作完成后，若此时工具头的工具识别传感器无法检测到工具，但能读取到工具序号，则会上报该 hms。

## 可能的原因

1. 打印头（画笔、刀切）在挂架泊位上放歪了，导致对位校准时获取的数据有了微小偏差，因此取用失败；
2. 工具头进入泊位过程中，工具头与泊位或工具发生了干涉，导致工具头丢步，与要取用的工具之间出现明显间隙，工具识别传感器无法检测到工具；
3. 打印头（画笔、刀切）上的在位磁铁脱落；
4. 工具头上的工具识别传感器损坏、排线连接松动、排线损坏。

## 故障排除

### 步骤 1. 确保工具在挂架泊位上安装正确

检查问题工具是否在泊位上是否安装歪斜。重新摆放工具，确保紧贴在挂架泊位上，之后进行步骤2的校准。

### 步骤 2. 重新运行挂架对位校准

前往“设置 > 设备校准”中进行挂架对位校准。

|  |  |
| --- | --- |
|  |  |

若重新校准后依旧存在问题，请进行步骤3。

### 步骤 3. 检查热端上的在位检测磁铁

检查磁铁是否在位：

![magnet.png](https://wiki.bambulab.com/h3c/hmscode/1a00_0100_0001_0051/magnet.png)

- 如果磁铁脱落，联系售后团队；
- 若磁铁正常，请继续排查。

### 步骤 4. 尝试取用其他工具

#### 情况 1：取用成功

请先检查报错工具是否正确放置在泊位上（没有放歪、翘起）；

![rack.png](https://wiki.bambulab.com/h3c/hmscode/1a00_0100_0001_0051/rack.png)

- 如果放置不当，请重新放置后尝试；
- 如果放置正确，请参考步骤 5。

#### 情况 2：取用失败，且故障相同

请重启机器，并尝试重新插拔排线；

![001.png](https://wiki.bambulab.com/h3c/hmscode/1a00_0100_0001_0051/001.png)

- 若故障消失，则为排线松动；
- 若故障依旧，请联系售后团队并上传日志以获得帮助。

### 步骤 5. 再次进行挂架对位校准

停止取放刀流程、打印任务后，确保工具头上没有打印头（画笔或刀切），然后前往“设置 > 设备校准”中进行挂架对位校准；

|  |  |
| --- | --- |
|  |  |

> 如果放置遇到问题，请到“设置 > 工具箱 > 打印头 & 挂架维护”点击“解锁工具”，将解锁后的打印头挂到挂架上，然后重试。
>
> ![re-calibration.png](https://wiki.bambulab.com/h3c/hmscode/1a00_0100_0001_0051/re-calibration.png)
