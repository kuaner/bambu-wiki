## 故障描述

锁紧电机的霍尔传感器信号异常，锁紧电机可能存在故障。

## 可能的原因：

- 锁紧电机接线不良
- 锁紧电机的霍尔传感器故障

## 故障排除

### 所需工具

- H2.0 内六角扳手
- H1.5 内六角扳手

### 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 故障排除

拆卸左右两侧的 AMS 磁吸侧板。

|  |  |
| --- | --- |
| 001.png | 002.png |

拧下工具头前盖的 4 个固定螺丝。

|  |  |
| --- | --- |
| 003.png | 004.png |

从侧面水平取下前盖。

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0004/zh/005.png)

拧下顶盖的 4 个固定螺丝。

|  |  |
| --- | --- |
| 006.png | 007.png |

从侧面缝隙中撬开顶盖。

![008.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0004/zh/008.webp)

完成以上工作后，通电开机，远距离观察 绿色标记的 2 个指示灯是否常亮。

![009.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0004/zh/009.png)

若指示灯 1 不亮，请尝试重新连接 a 处线缆。

若指示灯 2 不亮，请尝试重新连接 b 处线缆。

若指示灯 1、2 常亮，但报错依旧，则可能是电机出现故障，需[更换新的电机](../../maintenance/replace-2012-toollock-motor.md)。

若报错消失，则参考[工具头外壳拆装指南](../../maintenance/replace-toolhead-front-cover.md)装回工具头外壳，可正常使用。
