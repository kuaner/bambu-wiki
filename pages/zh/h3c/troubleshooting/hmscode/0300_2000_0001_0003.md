## 故障描述

X 轴回零测得的行程大于允许上限，故报此 hms。

## 可能的原因：

- X 轴同步带过松。

## 故障排除

### 工具、设备及材料

- H2.0 六角扳手

### 步骤一：张紧皮带

- 用 H2.0 内六角扳手拧松 XY 张紧螺丝一圈（**请勿完全松开**）。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2000_0001_0003/zh/001.png)

- 取下 AMS 的磁吸侧板。

![002.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2000_0001_0003/zh/002.png)

- 用手移动工具头来回画圆运动 3 次，最后将工具头推向废料滑梯处；

|  |  |
| --- | --- |
| 003.webp | 004.png |

- 重新拧紧张紧螺丝，请勿过度拧紧导致螺丝滑丝。

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2000_0001_0003/zh/005.png)

### 步骤 2. 执行振动补偿

在屏幕上点击“校准 > 打印校准”，进行“振动补偿”。

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2000_0001_0003/zh/006.png)

## 等效代码

如下HMS代码均代表同一类型的故障。

| HMS代码 | 故障描述 |
| --- | --- |
| 0300-2000-0001-0003 | X轴回零异常，可能是同步带松了。 |
