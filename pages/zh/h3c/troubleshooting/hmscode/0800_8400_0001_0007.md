## 故障描述

锁紧电机驱动锁紧插销水平移动，从而实现锁紧或解锁工具。当锁紧插销超过限制时间仍未到达目标位置，设备将会提示该报错信息。

## 可能的原因：

- 电机转子/锁紧插销/弹片被异物卡住
- 电机固定到工具头的螺丝松动，导致电机空转
- 工具未被弹片抓取到位
- 工具顶部被外物卡住，或打印头被融化的耗材黏在工具头上
- 锁紧插销润滑失效

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手
- H2.0 六角扳手
- 工具头电机解锁套筒

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 取用失败排故措施

#### 步骤1. 检查工具是否抓取到位

成功抓取后，工具前端的斜面会被牢牢按压在工具头定位槽上。

|  |  |
| --- | --- |
| 001.png | 002.png |

如发现未抓取到位，可尝试取下工具。若无法取下，可一手扶住工具，另一只手点击屏幕设置->工具箱->打印头&挂架维护->解锁工具。

![003.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0007/zh/003.jpg)

解锁工具后，检查工具上是否存在异常，如打印头耗材脱出、左侧相邻打印头的切刀卡住等。

|  |  |
| --- | --- |
| 004.jpg | 005.png |

若耗材脱出，可从 AMS 处回收，或按压切刀杆，裁断这截耗材。

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0007/zh/006.png)

没有异常则将工具放回挂架，点击屏幕重新取用此工具，若报错依旧请进行后续检查。

#### 步骤2. 检查运动结构是否卡住

参考[工具头外壳拆装指南](../../maintenance/replace-toolhead-front-cover.md)取下工具头左侧前盖。

取下工具头前盖后，从工具头侧方观察锁紧电机、锁紧插销上是否有异物。

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0007/zh/007.png)

排除异物后，取出工具盒中的套筒，装在 H2.0 内六角扳手上转动电机轴。

![008.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0007/zh/008.png)

观察齿轮，锁紧插销是否能顺畅工作，如有卡涩，请参考[定期维护指南](../../maintenance/periodic-maintenance.md)润滑锁紧组件。

![009.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0007/zh/009.webp)

再使用螺丝刀检查锁紧电机的固定螺丝是否紧固，若螺丝固定牢靠，装回左侧前盖后重新取用。

![010.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0007/zh/010.png)

## 卸载失败排故措施

### 步骤1. 检查热端是否卡住

若解锁打印头时无法取下打印头，请检查是否被融化的耗材黏在工具头上。

![011.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0007/zh/011.png)

如有，在屏幕上加热热端后取下耗材，重复解锁操作取下热端；

![012.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0800_8400_0001_0007/zh/012.png)

若没有融化的耗材，请检查并清理工具、工具头、挂架上的异物。若故障依旧请联系客户支持团队。
