## 故障现象

打印过程中，设备会实时监测耗材挤出情况，但挤出低于预期时，设备会判定耗材挤出异常（空打）并暂停打印。

## 可能的原因

- 料盘内耗材缠绕打结，导致无法上料，挤出轮空转
- 耗材快用尽时，其末端从料盘的固定胶布脱落
- 耗材直径不标准、不均匀
- 打印头进料挤出轮处耗材磨损或打滑，导致挤出轮咬合耗材失败，无法正常挤出耗材
- 喷嘴堵塞导致耗材无法正常挤出
- 里程轮故障或卡住

## 所需工具和材料

- H1.5 内六角扳手
- 镊子

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 排查步骤

### 检查料盘是否缠料

取出提示槽位的料盘，检查耗材是否缠绕。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0007/zh/001.png)

若发现缠料，请按以下步骤重试：

1. 请按住打结位置，固定打结部分后取出料盘。

![002.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0007/zh/002.jpg)

卡住打结的耗材，同时从料盘中绕出，再解开缠绕。

![003.gif](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0007/zh/003.gif)

完成后将料盘放回 AMS，恢复打印。

![004.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0007/zh/004.jpg)

当打印头回到吐料组件开始挤出时，需手动向内轻推耗材，直到感受到耗材被自动向内拉扯。

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0007/zh/005.png)

### AMS 转轴受损

若料盘转动不顺畅，检查料盘是否变形，或 AMS 转轴是否受损。

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0007/zh/006.png)

### **检查耗材是否磨损或打滑**

拆下磁吸侧板。

|  |  |
| --- | --- |
| 007.png | 008.png |

在屏幕上点击放置打印头，然后取下打印头，检查耗材前端是否出现磨损。

|  |  |
| --- | --- |
| 009.png | 010.png |

若存在磨损：

1. 请参考这篇 wiki 指南：[挤出轮清理指南](../extruder-cleaning-guide.md)清理挤出轮。
2. 再将耗材的磨损段平齐地剪断；

![011.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0007/zh/011.webp)

3. 抽回料盘中的耗材，重新插入并恢复打印。若该耗材反复出现磨损，建议更换其他耗材重试。

### 检查耗材直径

使用游标卡尺测量耗材直径，确保其在1.75±0.03mm范围内。

若耗材直径不符合标准，请换一盘耗材重试。

![012.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0007/zh/012.jpg)

### **检查热端是否堵塞**

若进料挤出轮清理后故障依旧，则可能是热端发生堵塞。 请参考[热端堵塞清理指南](../unclogging.md)疏通热端，完成后可恢复打印。

### 检查里程轮

若耗材能够从热端中顺畅挤出，则可能是里程轮故障或卡住。

请放置打印头，然后使用螺丝刀或镊子尝试拨动从动轮。

![013.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_0900_0002_0007/zh/013.png)

- 若从动轮转动卡顿，请参考这篇 wiki：[更换工具头外壳](../../maintenance/replace-toolhead-front-cover.md)拆卸工具头前盖后清理异物。
- 若从动轮转动顺畅，则里程轮可能故障，请联系我们的客户支持团队并上传打印机日志。
