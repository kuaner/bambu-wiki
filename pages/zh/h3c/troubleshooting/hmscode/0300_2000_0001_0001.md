## 故障描述

当X轴的移动行程小于设定值，或 X 轴回零运动失败时，设备将认为工具头被卡住或 X 轴移动阻力过大。

## 可能的原因：

- 工具头被卡住；
- X 轴阻力过大。

## 故障排除

### 步骤1. 外观检查

关机断电，从设备前侧观察工具头状态，如打印后未取模或工具头两侧存在异物，均会导致该报错。

|  |  |
| --- | --- |
| 001.png | 002.png |

### 步骤2. 手动推拉

手动推拉工具头左右移动，若移动阻力较大，请则沿着同步带检查是否存在异物阻碍，并及时清理；若不存在异物请进行下一步。

![003.gif](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2000_0001_0001/zh/003.gif)

### 步骤3. X 轴维护

请参考 [XYZ 轴维护](../../maintenance/lubricate-x-y-z-axis.md)清理并润滑 X 轴，完成后再次发起任务，若依然无法完成回零，请联系客户支持团队。
