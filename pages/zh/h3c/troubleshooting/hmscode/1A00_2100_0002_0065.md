## 故障描述

挂架对位校准的过程中，如果工具头移动出现丢步，设备将会提示该错误信息。

## 可能的原因：

- 回零异常
- 工具头盖子没有安装到位，导致标定检查时候，盖子碰撞其他打印头，导致工具头发生丢步
- 打印头切刀杆卡住没有回弹，导致标定检查的时候，切刀杆碰撞隔壁打印头，导致工具头发生丢步
- 耗材位置错误，导致工具头碰撞，发生丢步。
- 挤出齿轮和从动轮间距过小，耗材无法卡入，导致工具头碰撞，发生丢步。

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 故障排除

### 工具、设备及材料

- 剪钳

### 排故措施

### 检查回零区域

拆卸左右两侧的 AMS 磁吸侧板。

|  |  |
| --- | --- |
| 001.png | 002.png |

关机后将工具头推向最后侧。

![003.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_2100_0002_0065/zh/003.png)

观察左右 Y 滑块与后侧极限位置的间距是否相同，或同时贴合。

|  |  |
| --- | --- |
| 004.png | 005.png |

若一侧已经触碰到极限位置，而另一侧还有间隙，请重新[张紧 XY 轴皮带](../../maintenance/belt_tension.md)。

若张紧后该现象依旧，则需要[更换新的皮带](../../maintenance/replace-xy-belt.md)。

### 检查工具头

观察工具头前盖是否安装到位。 如果存在如图的间隙，请参考[工具头前盖安装教程](../../maintenance/replace-toolhead-front-cover.md)重新安装扣合。

|  |  |
| --- | --- |
| 006.jpg | 007.jpg |

### 检查打印头切刀杆

取下左侧相邻打印头，观察切刀杆是否卡住。

若出现图二无法回弹的情况，则会影响其右侧相邻打印头的取放过程，需按压切刀杆下方，确保回弹。

|  |  |
| --- | --- |
| 008.jpg | 009.jpg |

若无法按回，请检查切刀刀片和切刀杆是否被异物阻塞。

### 检查打印头内耗材

若打印头中的耗材脱出，也会影响挂架校准以及打印头的取用，请从 AMS 处回收该段耗材后重试。

![010.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_2100_0002_0065/zh/010.jpg)

或按压切刀杆裁断这截耗材。

![011.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_2100_0002_0065/zh/011.png)

### 检查轮系间距

取用打印头时，从动轮将被收起，此时从动轮和挤出轮之间的间距最大。当从动轮和挤出轮之间的间距过小/异常时，从动轮会和耗材相互撞击，并产生丢步，触发报错。

可点击“工具箱-打印头/挂架维护-解锁工具”，观察从动轮和挤出轮的间距是否开到最大。

![012.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_2100_0002_0065/zh/012.png)

若从动轮能够正常移动，请联系客户支持团队并提供校准过程中工具头移动的视频。 若从动轮无法移动，则可能需要[更换变距电机](../../maintenance/replace-2012-flexfeed-motor.md)或者[从动轮组件](../../maintenance/replace-idler-assembly.md)。
