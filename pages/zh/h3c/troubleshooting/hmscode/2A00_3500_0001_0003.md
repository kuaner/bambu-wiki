## 故障现象

AMS 3H 内共有两个温湿度传感器，分别检测烘干区和非烘干区。当主板检测到非烘干区域的温湿度传感器离线，则会提示该错误信息。与此同时，屏幕上的温湿度值可能长时间不变化、显示为 0，或显示其他异常数值。

## 可能的原因

- 温湿度传感器板的插头接触不良
- 温湿度传感器排线在 AMS 3H 主板侧的插头接触不良
- 温湿度传感器故障

## 所需工具和材料

- H1.5 内六角扳手
- H2.0 内六角扳手

## 排查步骤

### 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 1. 退出所有耗材

在打印机屏幕上，点击退出所有耗材。然后，将耗材全部收回到料盘中，将所有耗材从 AMS 中取出。

| 001.png | 002.png |

### 2. 断开电源

关闭打印机并断开 AMS 的电源线。

|  |  |
| --- | --- |
| 003.jpg | 004.jpg |

### 3. 取下 AMS

用手抓住左/右侧板扣手位，向外侧用力，可将左/右侧板从 AMS 支架上分离，取下左/右侧板。

![005.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_3500_0001_0003/zh/005.jpg)

拧松 AMS 的 4 颗固定螺丝。

|  |  |
| --- | --- |
| 006.png | 007.png |

抱住 AMS 前后侧，取下 AMS，并将其反转至底面朝上，放置在桌面上。

![008.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_3500_0001_0003/zh/008.png)

### 4. 重新连接线缆插头

1. 用 H1.5 内六角扳手移除下图所示 8 颗螺丝，拆开两个装饰盖。

|  |  |
| --- | --- |
| 009.png | 010.png |

2. 断开下图所示 2 处位置的线缆接头，然后重新连接，确保连接到位。

![011.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_3500_0001_0003/zh/011.png)

### 5. 开机重试

1. 用 H1.5 内六角扳手安装下图所示 8 颗螺丝，安装两个装饰盖。

|  |  |
| --- | --- |
| 012.png | 013.png |

2. 将 AMS 装回打印机上；

![014.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_3500_0001_0003/zh/014.png)

装回4颗固定螺丝。

|  |  |
| --- | --- |
| 015.png | 016.png |

3. 连接电源，开机重试，从屏幕上观察故障报错是否消失。
4. 如果拔插两个插头后故障依旧，则说明温湿度传感器故障，需要更换，具体步骤请参考这篇 Wiki：[温湿度传感器更换指南](../../../ams3/maintenance/replace-temperature-humidity-sensor.md)。
