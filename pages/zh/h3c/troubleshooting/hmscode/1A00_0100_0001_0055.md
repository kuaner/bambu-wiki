## 故障描述

如果工具基座背后的泊入检测传感器（塑料外壳内）无法检测到挂架泊位上的泊入检测磁铁，则说明此工具不在挂架泊位上，设备将会提示该报错信息。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/1a00_0100_0001_0055/zh/001.png)

**可能的原因：**

工具从挂架泊位上掉落，或者工具在挂架泊位上未放置正确，工具和泊位没有紧密贴合。

## 故障排除

### 步骤 1. 打开 AMS 磁吸侧板

打开靠近报错泊位一侧的 AMS 磁吸侧板。

|  |  |
| --- | --- |
| 002.png | 003.png |

### 步骤 2. 检查挂架和热端

将报错的工具放回对应的挂架泊位，先对齐橙色安装导向槽，然后顺着磁铁吸附到位，放置到挂架上。

|  |  |
| --- | --- |
| 004.jpg | 005.jpg |

确认放置到位后点击重试；如果仍报错，请联系售后团队。
