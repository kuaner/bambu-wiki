## 故障描述

打印机在一定时间内无法获取到实况相机的图像，导致实况相机相关的 AI 检测功能暂时失效，故报此 hms。

## 故障排除

### 步骤一：在软件播放 liveview

在 Bambu Handy / Bambu Studio 上播放 liveview；如果可以正常观看 liveview，则可能是软件链路存在问题，请尝试重启打印机；

|  |  |
| --- | --- |
| 001.png | 002.png |

- 如果重启后报错依旧，请参考步骤二。

### 步骤二：检查实况摄像头连接

- 关闭打印机，使用 H2.0 内六角扳手移除维修盖板 4 颗螺丝，取下维修盖板。

|  |  |
| --- | --- |
| 003.png | 004.png |

- 检查**⑨号实况摄像头排线**的连接情况；如果异常，请重新插入；

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0c00_0100_0002_0008/zh/005.png)

- 开启打印机，如果仍报错，请参考 wiki：[实况摄像头更换指南](../../maintenance/replace-liveview-camera.md)，更换实况摄像头；

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0c00_0100_0002_0008/zh/006.png)

- 如果按照上述步骤处理后问题仍旧无法解决，建议联系我们的客户服务团队。
