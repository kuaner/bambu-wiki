## 故障描述

打印过程中若检测到需要使用 AMS 3H 进料或者退料，但 AMS 3H 离线时，设备将提示该报错信息。

## 可能的原因：

1. 6-pin 线松动、接触不良
2. 线束故障
3. 6-pin 接口板故障

## 故障排除

### 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 一、AMS 3H 指示灯红灯双闪

指示灯红灯双闪代表 AMS 3H 通讯存在异常，但供电正常。

1. 若设备连接了多台 AMS，请拔掉其他 AMS，仅保留 AMS 3H。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_5000_0002_0001/zh/001.png)

2. 观察屏幕是否能够识别 AMS 3H。如果能恢复，再次逐一接入其他 AMS，确认某一 AMS 接入后导致故障。

|  |  |
| --- | --- |
| 002.png | 003.png |

3. 如果仅连接了 AMS 3H 时仍然红灯双闪，则尝试使用缓冲器/接口板的另一个接口。

|  |  |
| --- | --- |
| 004.png | 005.png |

若切换其他接口后通讯恢复正常，则可能是缓冲器/接口板出现故障，可选择[更换新的缓冲器/接口板](../../maintenance/replace-filament-buffer.md)；若设备故障依旧，请联系客户支持团队。

### 二、AMS 3H 指示灯不亮灯

1. 重新拔插 AMS 3H 和打印机之间的连接线缆，观察耗材页面是否识别到 AMS 3H。

|  |  |
| --- | --- |
| 006.png | 007.png |

2. 如果未识别，交换线缆在AMS和打印机上连接的接口，以排除单一接口故障。

|  |  |
| --- | --- |
| 008.png | 009.png |

3. 如果仍未识别，建议更换新的 6-pin 线缆，或联系客户支持团队。
