## 故障描述

AMS 进料过程中，打印头的耗材传感器会检测耗材是否成功插入。若在一定时间内打印头的耗材传感器始终未检测到耗材，则判定耗材送出失败并上报该 HMS。

## 可能的原因：

- 耗材端部不平/弯曲/膨大，卡在料管入口或打印头进料口。
- 料线缠绕或下垂卡住，送料电机拉不动。
- 料盘尺寸超出 AMS 规格、料盘变形或使用了纸板料盘，转动不顺畅。
- AMS 送料电机异常（堵转、打滑）。
- 选料杆运动异常（选槽超时/不到位）。
- AMS 到打印头之间的 PTFE 料管脱落、堵塞或过度弯曲。
- 打印头进料口有卡点/堵塞，或耗材传感器异常，无法检测到已送达的耗材。

## 故障排除

### 工具、设备及材料

- 耗材剪钳（剪平耗材端部）

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 排故措施

#### **步骤1. 检查打印头耗材传感器**

若观察到耗材被送入了打印头，但仍然报错。请参考[**打印头进料霍尔传感器排查指南**](../filament-sensor-test.md)检查打印头进料霍尔传感器是否故障。

若耗材并未送达打印头，请进行下一步排查。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0002/zh/001.png)

#### **步骤1. 检查料盘规格**

检查料盘宽度是否在 50~68mm 之间、直径是否在 197~202mm 之间。

|  |  |
| --- | --- |
| 002.jpg | 003.jpg |

前后推动料盘旋转，检查料盘转动是否顺畅。

![004.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0002/zh/004.webp)

若料盘变形或过大，则会导致料盘转动卡顿，请更换其他料盘正常的耗材。

若料盘正常但转动受阻，可能是转轴安装不当或故障，可向外取出转轴，重新安装一次或更换新转轴。

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0002/zh/005.png)

#### **步骤2. 检查料线是否缠绕**

取出提示槽位的料盘，检查耗材是否缠绕。

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0002/zh/006.png)

若发现缠料，请按以下步骤重试，其他方法可参考[拓竹H3C 耗材缠料处理方法](../tangle-stuck-filament.md)。

请按住打结位置，固定打结部分后取出料盘。

![007.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0002/zh/007.jpg)

卡住打结的耗材，同时从料盘中绕出，再解开缠绕。

![008.gif](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0002/zh/008.gif)

完成后将料盘放回 AMS，恢复打印。

![009.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0002/zh/009.jpg)

#### **步骤3. 检查耗材**

检查耗材头部是否平整。若头部因储存而变形弯折，请剪断前面一截耗材，然后重试进料。

![010.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0002/zh/010.png)

若耗材头部外观正常，可使用卡尺测量或与其他耗材对比粗细，耗材过粗或过细也会影响进料。

![011.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0002/zh/011.jpg)

#### **步骤4. 检查料管**

检查 AMS 与打印头之间的料管是否脱落、堵塞或过度弯曲。

|  |  |
| --- | --- |
| 012.png | 013.png |

- 如果料管脱落需重新插紧；
- 如果发现料管中存在断料，可参考[断料清理指南](../clear-filament-jam.md)进行疏通
- 如果料管过度弯曲，或存在折痕，请重新理顺料管以减小阻力，或更换新的料管。

#### **步骤5. 检查 AMS 送料电机与选料杆**

若以上情况均正常但仍报错，可能是 AMS 送料电机堵转/打滑或选料杆运动不到位。

可参考[拆装指南](../../maintenance/ams_3h.md)拆开清理，并重新补充润滑脂。
