## 故障描述

设备开机时，首先会将选料杆回零，从而确定选料杆的起始位置。如果回零成功，则进入空档位状态，此时不会选择任何槽位。

若传感器掉线，则无法正常完成回零，设备将提示该报错信息。

## 可能的原因：

- 霍尔板插头脱落或者接触不良。
- 霍尔板连接到AMS 3H主板的插头脱落或者接触不良。

## 故障排除

### 工具、设备及材料

- H2.0 六角扳手
- H1.5 六角扳手

### 排故措施

#### **排查传感器插头是否接触不良**

退出所有耗材，并将料头固定在料盘上。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0006/zh/001.png)

拔出所有料嘴。

![002.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0006/zh/002.png)

使用 H2.0 六角扳手拧下保护盖的 4 颗固定螺丝。

![003.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0006/zh/003.png)

向上拆下进料机构保护盖子。

![004.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0006/zh/004.png)

按住插头上方的防松卡扣，拔出后重新连接该线缆。

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0006/zh/005.png)

开机，观察报错是否消失。

- 如果故障没有消失，则需要继续排查主板上的插头是否接触不良。

#### **排查主板的插头是否接触不良**

从AMS 3H中拿出所有料盘。

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0006/zh/006.png)

拆下AMS 3H侧面的两个磁吸盖板。

|  |  |
| --- | --- |
| 007.png | 008.png |

使用H2.0六角扳手拧下四颗固定螺丝。

|  |  |
| --- | --- |
| 009.png | 010.png |

双手将整个AMS 3H从打印机上抬起，然后反转放到桌面上。

![011.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0006/zh/011.png)

使用 H1.5 螺丝刀拆下 AMS 3H 主板的保护壳。

![012.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0006/zh/012.png)

重新拔插“12号”霍尔板的插头，注意需按压顶部防松卡扣才能取下。

![013.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0006/zh/013.png)

通电开机，观察故障是否消失，若故障依旧，请联系客户支持团队。
