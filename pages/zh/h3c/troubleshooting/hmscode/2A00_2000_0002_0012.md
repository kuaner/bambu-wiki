## 故障现象

\*\*功能：\*\*在进料过程中，AMS 3H 的送料电机负责将耗材送往打印机。若送料电机运作时间超时，即耗材输送时间已超过系统设定的阈值，耗材无法正常送至打印头，则会触发该错误提示。

\*\*现象：\*\*耗材无法送至打印头，屏幕上打印头位置显示耗材为虚线，同时 AMS 3H 对应的槽位显示红色灯语，打印机屏幕弹出该报错提示。

## 可能的原因

- 耗材没有插入到位。耗材插入的长度过短，导致送料选择器无法咬住耗材，将耗材送往打印头。
- 耗材出现磨损。若耗材上有磨损的凹坑，导致送料选择器的送料电机无法驱动耗材前进。
- 送料选择器的选料位置出现偏差，导致无法选中正确的槽位。
- 送料选择器齿轮故障，导致送料电机无法驱动耗材前进。

## 所需工具和材料

- H1.5 内六角扳手
- H2.0 内六角扳手
- 手电筒或闪光灯

## 排查步骤

### 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 1. 手动输送耗材

打开 AMS 上盖，手动将对应槽位的耗材插入料嘴，并送出一段距离后重试。

重试后若依旧报错，请继续下一步。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0012/zh/001.png)

### 2. 检查耗材外观状态

从 AMS 中取出耗材，检查耗材外观是否出现磨损；

若耗材上出现弧形磨损缺口，请裁断这截异常耗材，重新尝试进料。

![002.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0012/zh/002.png)

重试后若依旧报错，请继续下一步。

### 3. 检查料盘摆放位置

- 检查料盘是否正确摆放：手动转动料盘，检查料盘是否可以流畅转动，如果转动阻力大，则需要重新摆放好料盘。

![003.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0012/zh/003.webp)

- 若料盘转动依旧受阻，可能是转轴安装不当或故障，可取出转轴，重新安装一次或更换新的转轴。

|  |  |
| --- | --- |
| 004.png | 005.png |

- 重试后若依旧报错，请继续下一步。

### 4. 检查 AMS 3H 选料杆

1. 使用手电筒/闪光灯在送料选择器选料杆刻度位置（位于数字 7 与 9 之间）打灯，如下图所示；

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0012/zh/006.png)

2. 在屏幕上重试进料，**同时**，从前侧观察 进料槽位所对应的刻度 是否移动到固定刻度线处。正常情况下，各刻度与固定刻度线误差小于 1 mm。

**图注**：

① 各槽位对应的**刻度**及序号

② 黑块的右边缘为**固定刻度线**

③\*\*“空”**字代表初始**空档位刻度\*\*

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0012/zh/007.png)

例如下图所示，3 号槽位刻度移动到固定刻度线。

![008.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0012/zh/008.webp)

3. 若误差较大（大于 1mm），请借助手电筒打灯，观察透明盖内部送料杆结构上是否存在异物。

内部结构示意图如下，若观察到以上两个部分存在明显异物，请参考[更换 AMS 进料组件上盖](../../../ams3/maintenance/replace-auto-filament-loader-cover.md)，清理异物。

|  |  |
| --- | --- |
| 009.png | 010.png |

若没有异物，请断开并重新连接 AMS 背部的 6-pin 线，重启 AMS 后重试，观察屏幕上是否仍有该错误提示弹出。

![011.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0012/zh/011.png)

若重启后仍弹出报错，则需要更换选料杆。具体教程请参考这一篇 wiki：[**AMS 3H 自动进料组件更换指南**](../../../ams3/maintenance/replace-auto-filament-loader.md)

![012.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_2000_0002_0012/zh/012.png)

### 5. 更换送料电机

如果以上排查都无法解决问题，则可能是送料电机故障，需要更换。具体步骤请参考这篇 Wiki 教程：[**送料电机更换指南**](../../../ams3/maintenance/replace-feed-selector-motor.md)。
