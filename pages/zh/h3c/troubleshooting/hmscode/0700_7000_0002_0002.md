## 故障描述

AMS 进料过程中，打印头的进料霍尔传感器会检测耗材是否成功插入。若在一定时间内打印头的进料霍尔始终未检测到耗材，则判定耗材送往挤出机失败并提示该报错信息。

## 可能的原因：

- 耗材端部不平/弯曲/膨大，卡在 AMS 中或料管中，无法顺利送入打印头。
- 耗材端部磨损/过细，插入后未被识别。
- 打印头进料霍尔故障。

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 故障排除

### 工具、设备及材料

- 耗材剪钳（用于剪平耗材端部）

### 排故措施

#### 步骤 1. 检查耗材是否缠绕

取出提示槽位的料盘，检查耗材是否缠绕。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_7000_0002_0002/zh/001.png)

若耗材未缠绕，请进行后续步骤。

若发现缠料，请按以下步骤重试：

1. 拆下磁吸侧板。

|  |  |
| --- | --- |
| 002.png | 003.png |

2. 取消本次打印任务，在屏幕上放置当前使用的打印头。

![004.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_7000_0002_0002/zh/004.png)

3. 从挂架上取下打印头，按住打印头刀柄切断耗材。

注：此时热端温度较高，小心烫伤。

|  |  |
| --- | --- |
| 005.png | 006.png |

若切刀刀片被卡住，需按压下方，调整切刀后再放回挂架。

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_7000_0002_0002/zh/007.png)

4. 抽回耗材, 理顺打结的缠料；

![008.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_7000_0002_0002/zh/008.webp)

#### 步骤 2. 检查料盘转动是否顺畅

小幅度转动料盘，感受料盘转动阻力。

![009.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_7000_0002_0002/zh/009.webp)

若阻力较大，请检查转轴是否受损，或料盘放置是否歪斜。如存在转轴受损，可临时对调安装其他槽位的转轴使用。

![010.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_7000_0002_0002/zh/010.png)

#### 步骤 3. 检查耗材是否能够送入打印头

1. 若耗材成功进入打印头，可能是进料霍尔异常（无法检测到已插入的耗材），可参考[霍尔排查指南](../filament-sensor-test.md)进行故障确认。

![011.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_7000_0002_0002/zh/011.png)

2. 若耗材无法送入打印头，卡在 AMS 中或料管中。

检查耗材所处位置，若卡在料管中，请检查料管是否弯折过度，可适当理顺料管，减轻阻力。

![012.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0700_7000_0002_0002/zh/012.png)

若无法送出 AMS，请取出该槽位耗材，检查耗材端部是否平整、有无弯曲、膨大、磨损或过细。

- 若端部弯曲、膨大或不平，用剪钳将耗材端部剪平，再重新插入槽位重试。
- 若端部磨损、过细或变形，剪掉该段后再重新插入。

完成以上检查后若依然无法送出，则可能是 AMS 内街垒较多耗材碎屑，可进行 [AMS 维护工作](../../maintenance/ams_3h.md)。
