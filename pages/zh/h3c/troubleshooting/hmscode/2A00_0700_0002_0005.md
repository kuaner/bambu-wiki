## 故障描述

设备开机时，首先会将选料杆回零，从而确定选料杆的起始位置。如果回零成功，则进入空档位状态，此时不会选择任何槽位。当回零过程中传感器未被触发，将提示该报错信息。

## 可能的原因：

1. 回零磁铁脱落，其中一颗、或者两颗都脱落。

## 故障排除

### 工具、设备及材料

- 无

### 排故措施

#### 排查磁铁是否脱落

可直接通过 1、3槽位之间的外壳观察选料杆上的磁铁是否丢失。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0005/zh/001.png)

若磁铁丢失，则需要更换新的选料杆组件。

若磁铁完好，请参考后续步骤检查传感器工作状态。

#### **排查传感器插头是否接触不良**

退出所有耗材，并将料头固定在料盘上。

![002.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0005/zh/002.png)

拔出所有料嘴。

![003.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0005/zh/003.png)

使用 H2.0 六角扳手拧下保护盖的 4 颗固定螺丝。

![004.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0005/zh/004.png)

向上拆下进料机构保护盖子。

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0005/zh/005.png)

按住插头上方的防松卡扣，拔出后重新连接该线缆。

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0005/zh/006.png)

开机，观察报错是否消失。

- 如果故障没有消失，则需要继续排查主板上的插头是否接触不良。

#### **排查主板的插头是否接触不良**

从AMS 3H中拿出所有料盘。

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0005/zh/007.png)

拆下AMS 3H侧面的两个磁吸盖板。

|  |  |
| --- | --- |
| 008.png | 009.png |

使用H2.0六角扳手拧下四颗固定螺丝。

|  |  |
| --- | --- |
| 010.png | 011.png |

双手将整个AMS 3H从打印机上抬起，然后反转放到桌面上。

![012.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0005/zh/012.png)

使用 H1.5 螺丝刀拆下 AMS 3H 主板的保护壳。

![013.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0005/zh/013.png)

重新拔插“12号”霍尔板的插头，注意需按压顶部防松卡扣才能取下。

![014.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0700_0002_0005/zh/014.png)

通电开机，观察故障是否消失，若故障依旧，请联系客户支持团队。
