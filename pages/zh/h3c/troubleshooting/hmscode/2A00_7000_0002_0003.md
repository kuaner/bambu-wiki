## 故障现象

AMS 将耗材送入打印头并尝试从喷嘴挤出后，会通过从动轮组件上的**里程轮**检测实际挤出量是否达标。若挤出量不足或里程轮未检测到耗材运动，打印机则会弹出该错误提示。

## 可能的原因

- 喷嘴堵塞
- 耗材偏细，无法咬合
- 料盘内的耗材发生缠绕
- 料盘卡住了
- 耗材头变形，卡在料管内或打印头内
- AMS 送料异常
- 喷嘴温度偏低，耗材未充分熔融
- 打印头进料传感器异常
- 主动轮组件被异物卡住（概率较小）

## 所需工具和材料

- 剪钳/剪刀
- 游标卡尺
- 镊子

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 排查步骤

### \*\*1.\*\*检查耗材是否缠绕

检查 AMS 上的耗材是否发生缠绕。

![001.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/001.jpg)

**若发现缠料，请按以下步骤重试：**

> 其他方法可参考[拓竹H3C 耗材缠料的处理办法](../tangle-stuck-filament.md)

请按住打结位置，固定打结部分后取出料盘。

![002.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/002.jpg)

卡住打结的耗材，同时从料盘中绕出，再解开缠绕。

![003.gif](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/003.gif)

完成后将料盘放回 AMS，恢复打印。

![004.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/004.jpg)

### 2. 检查料盘转动是否顺畅

前后转动料盘，检查料盘转动是否顺畅。

![005.webp](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/005.webp)

**若料盘转动不顺畅，检查料盘是否变形，或 AMS 转轴是否受损。**

- 若料盘变形或过大，则会导致料盘转动卡顿，需更换符合 AMS 规格的料盘。
- 若料盘正常但转动受阻，可能是转轴安装不当或出现故障，可向外取出转轴，重新安装一次或更换新转轴重试。

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/006.png)

### **3.观察耗材状态**

从挤出轮观察窗检查耗材是否送入，并检查耗材头是否变形。

|  |  |
| --- | --- |
| 007.png | 008.png |

**若耗材未送入或观察到耗材头变形，请进行以下检查：**

1. 取消本次打印后，放置当前使用的打印头；

![009.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/009.png)

2. 用手抓住 AMS 左/右侧板扣手位，向外侧用力，将左/右侧板从 AMS 支架上分离并取下。

![010.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/010.jpg)

3. 取下打印头，检查打印头上残留的耗材是否变形、膨胀。

注意：请勿触碰热端，小心烫伤。

![011.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/011.png)

4. 若变形，请使用剪钳剪断变形的耗材，重新进料。

![012.gif](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/012.gif)

### 4. 检查耗材质量

使用游标卡尺测量耗材线径，确保其在 1.75±0.03mm 范围内（实际公差以包装盒标注为准，不同耗材会有细微差异）。

此外，检查耗材表面、截面是否有杂质，确保其干净整洁。

![013.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/013.jpg)

### **5. 检查热端温度**

请确认报错时或重试打印时，热端温度是否符合耗材的预设温度。

若将热端温度设置得远低于耗材正常打印温度，会导致耗材无法正常挤出。例如，将 PLA Basic 设为 60℃，而非常规的 220℃。

- 如果热端温度不正常，请设置正确的耗材温度，然后恢复打印；
- 如果热端温度正常，请继续下一步的排查。

![014.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_7000_0002_0003/zh/014.png)

### **6.热端堵塞疏通**

请参考[喷嘴堵塞清理指南](../unclogging.md)处理，确保耗材挤出顺畅。
