## 故障描述

每个腔温加热出风口处都有温度传感器，当温度传感器出现损坏时，加热片就无法准确控制温度，设备将提示该报错信息。

## 可能的原因：

- 温度传感器插头接触不良
- 温度传感器损坏

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手
- H2.0 六角扳手

### 后侧温度传感器故障

#### 步骤1. 拆卸背板

关机后参考[背板更换指南](../../maintenance/replace-back-panel.md)，拆卸背板，露出后自适应风道切换组件。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_9100_0001_0007/zh/001.png)

#### 步骤3. 检查线缆连接

检查转接板上所标记的两根线缆插头是否脱落或倾斜，若插头倾斜可轻轻按压，确保连接牢固。

> 该类插头需按压顶部防松卡扣，才能拔下。

![002.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_9100_0001_0007/zh/002.png)

同样 MC 板上对应的线缆也需要检查外观，若插头倾斜可轻轻按压，确保连接牢固。

|  |  |
| --- | --- |
| 003.png | 004.png |

#### 步骤4. 测试功能

开机后在屏幕上切换“腔温保持模式”，观察报错是否消失。若报错消失，则装回背板以及其他部件；若报错依旧，则参考[后自适应风道组件及后腔温组件更换指南](../../maintenance/replace-adaptive-airflow-assembly-back.md)，更换腔温组件。

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_9100_0001_0007/zh/005.png)

### 右侧温度传感器故障

#### 步骤1. 拆卸背板

关机后参考[背板更换指南](../../maintenance/replace-back-panel.md)和[右侧板更换指南](../../maintenance/replace-side-panel-right.md)，拆卸背板和侧板。

#### 步骤2. 检查线缆连接

检查右侧温度传感器接头以及转接板接头是否脱落或倾斜，若插头倾斜可轻轻按压装回，确保连接牢固。

> 该类插头需按压顶部防松卡扣，才能拆下。

|  |  |
| --- | --- |
| 006.png | 007.png |

同样 MC 板处的 8/9 号线缆也需要检查是否脱落或倾斜，若插头倾斜可轻轻按压装回，确保连接牢固。

|  |  |
| --- | --- |
| 008.png | 009.png |

#### 步骤4. 测试功能

完成上述检查后开机，并设置腔温加热一段时间。若腔温加热过程中屏幕上依旧出现该报错，则需要更换[右自适应风道组件](../../maintenance/replace-adaptive-airflow-assembly-right.md)。

![010.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_9100_0001_0007/zh/010.png)
