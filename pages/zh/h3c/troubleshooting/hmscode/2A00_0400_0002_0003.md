## 故障描述

送料选择器通过电机带动选料杆左右移动到特定的位置，从而选择指定的槽位进料。如果电机通电后未检测到电流，则会提示该错误信息。

## 可能的原因：

- 电机的插头接触不良。
- 主板的插头接触不良。
- 电机故障。

## 故障排除

### 工具、设备及材料

- H2.0 六角扳手
- H1.5 六角扳手

### 排故措施

退出所有耗材，并将料头固定在料盘上。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0400_0002_0003/zh/001.png)

从AMS 3H中拿出所有料盘

![002.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0400_0002_0003/zh/002.png)

拆下AMS 3H侧面的两个磁吸盖板

|  |  |
| --- | --- |
| 003.png | 004.png |

使用H2.0六角扳手拧下四颗固定螺丝。

|  |  |
| --- | --- |
| 005.png | 006.png |

双手将整个AMS 3H从打印机上抬起，然后反转放到桌面上。

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0400_0002_0003/zh/007.png)

使用 H1.5 螺丝刀拆下 AMS 3H 主板的保护壳

![008.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0400_0002_0003/zh/008.png)

重新拔插“4号”选料电机的插头，注意需按压顶部防松卡扣才能取下。

![009.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0400_0002_0003/zh/009.png)

再重新安装电机尾部的插头。

![010.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/2a00_0400_0002_0003/zh/010.png)

通电开机，观察故障是否消失。

- 如果拔插两个插头后故障依旧，则说明电机故障，请联系客户支持团队。
