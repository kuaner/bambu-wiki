## 故障描述

俯视摄像头初始时，机器检测出图格式和配置文件无法匹配，则报此 hms。

## 可能的原因：

- 俯视摄像头连接异常

## 故障排除

### 工具、设备及材料

- 十字螺丝刀、一字螺丝刀

### 步骤 1. 重启机器

请重启机器，如果仍报错，请参考下一步。

### 步骤 2. 检查摄像头处线缆

- 移除 AMS 左侧磁吸侧板；

![left-panel.jpeg](https://wiki.bambulab.com/h3c/hmscode/0500_0100_0002_000e/left-panel.jpeg)

- 检查摄像头端线缆是否连接到位；如有松动，请重新拔插。

![camera.png](https://wiki.bambulab.com/h3c/hmscode/0500_0100_0002_000e/camera.png)

检查报错是否消失，如果未消失，请参考下一步。

### 步骤 3. 检查 AP 板端线缆

- 关机，然后参考 WIKI: [视窗更换指南](../../maintenance/replace-side-glass-left.md) ，将打印机左侧视窗移除。

![ap1.jpeg](https://wiki.bambulab.com/h3c/hmscode/0500_0100_0002_000e/ap1.jpeg)

- 视机器版本而定，若此处有泡棉，请将其推下移除。

![clip.png](https://wiki.bambulab.com/h3c/hmscode/0500_0100_0002_000e/clip.png)

- 用 H1.5 内六角扳手移除 2 颗螺丝，并取下导光板。注意需将导光板向上提，离开卡扣位置后再取下。  
  ![light.jpeg](https://wiki.bambulab.com/h3c/hmscode/0500_0100_0002_000e/light.jpeg)
- 用 H1.5 内六角扳手移除 1 颗螺丝，取下 USB 线材卡。  
  ![ap-screw.jpeg](https://wiki.bambulab.com/h3c/hmscode/0500_0100_0002_000e/ap-screw.jpeg)
- 检查线缆插头是否连接到位，可拔下检查插头朝向是否正确，**有凸起的一侧朝外**，然后重新插入。

|  |  |
| --- | --- |
|  |  |

- 重新安装好后重启机器，查看报错是否消失；如果未消失，请联系客户服务。
