## 故障描述

热床调平旨在使热端与热床的距离在热床各处保持一致，以提升首层打印质量。当某点的检测值偏差过大时，设备将弹出该报错提示。

## 可能的原因

- 热端粘有耗材
- 打印板表面有残留耗材
- 打印板与热床之间有异物
- 热床过于倾斜或热床固定发生松动
- 工具头在 XY 方向上运动丢步

## 故障排除

### 1. 检查并清理热端上残留耗材

若热端上有耗材残留，使用镊子清理干净，小心高温烫伤。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2d00_0001_0006/zh/001.png)

### 2. 检查并清理残留耗材

打印板上或打印板下方存在耗材碎屑，也会影响本次调平，请及时清理干净。

|  |  |
| --- | --- |
| 002.png | 003.png |
| 004.png |

### 3. 检查热床锁紧情况

热床与 3 个滑块共有 6 颗螺丝固定，先检查并拧紧位置 1 处的 2 颗螺丝，然后揭开位置 2 和位置 3 处的硅胶条，再拧紧两处共 4 颗螺丝。

![005.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2d00_0001_0006/zh/005.jpg)

### 4. 检查工具头XY方向运动丢步

再次开启“热床调平”，观察准备过程中热端是否偏离吐料组件中心，以及擦嘴组件。

|  |  |
| --- | --- |
| 006.png | 007.png |

再观察工具头是否移动到热床外进行调平，正常情况下将切换至下一行。

![008.gif](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/hmscode/0300_2d00_0001_0006/zh/008.gif)

若存在以下情况，请检查 XY 方向上是否有异物阻碍工具头运动，检查 X 轴两边滑块的前后端面上是否有碎屑。

|  |  |
| --- | --- |
| 009.png | 010.png |

若 XY 轴上并不存在异物，请录制设备回中以及调平视频，上传至客户服务团队获得帮助。
