## 介绍

日常使用过程中耗材可能会粘黏在工具定位槽上，导致取放工具时出现异常。当观察到工具定位槽上有明显的耗材残留时，可参考本文进行清洁。

## 所需工具

- H2.0 内六角扳手
- 隔热手套
- 镊子
- 纸巾
- 刮刀

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 操作步骤

取下左右两侧磁吸侧板。

|  |  |
| --- | --- |
| 图 | 图 |

观察挂架上某个或多个热端斜面上是否存在耗材碎屑。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/guide-for-cleaning-the-tool-holder/zh/01_h3c___________-03.png)

选择存在碎屑的热端加热。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/guide-for-cleaning-the-tool-holder/zh/01_h3c___________-04.png)

从挂架上取下该打印头，斜向上按压在工具头上，当黄色指示灯亮起时，热端散热风扇才会工作。  
注意佩戴隔热手套操作。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/guide-for-cleaning-the-tool-holder/zh/01_h3c___________-05.png)

等待 3-4 分钟后，将打印头放回挂架，再使用镊子夹住纸巾擦拭耗材残留。

|  |  |
| --- | --- |
| 图 | 图 |

清理完定位槽后，再从挂架上取下打印头，擦拭热端锥面。

|  |  |
| --- | --- |
| 图 | 图 |

若定位槽上的耗材难以擦除，可拆卸定位槽进行清理。  
拧下工具头左侧前盖的 2 个固定螺丝。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/guide-for-cleaning-the-tool-holder/zh/01_h3c___________-10.png)

从侧面水平移动，取下左侧前盖。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/guide-for-cleaning-the-tool-holder/zh/01_h3c___________-11.png)

再拧松工具定位槽的固定螺丝，取下定位槽。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/guide-for-cleaning-the-tool-holder/zh/01_h3c___________-12.png)

首先检查裹头传感器上是否存在耗材碎屑，可使用 H1.5 六角扳手或其他工具清理。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/guide-for-cleaning-the-tool-holder/zh/01_h3c___________-13.gif)

请勿用力撬动碎屑，若内部弹簧受损，可能会影响裹头传感器工作。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/guide-for-cleaning-the-tool-holder/zh/01_h3c___________-14.png)

再使用刮刀刮除耗材碎屑。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/troubleshooting/guide-for-cleaning-the-tool-holder/zh/01_h3c___________-15.webp)
