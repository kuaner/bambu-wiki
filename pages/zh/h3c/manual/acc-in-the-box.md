## 包装清单

**配件的种类、数量可能会随时发生变化，请您以实际收到的为准。**

| H3C 包装箱 | AMS 3H 包装箱 |
| --- | --- |
| H3C 打印机  打印板（已预装在热床上） | AMS 3H  料管接头（已预装在料管架组件上） |
| **顶部纸卡内**     - 屏幕 - 打印机电源线 - FEP 料管 - 6-pin 连接线 - 烘干模块电源线 - 工具盒 | **顶部**     - 干燥剂×2 - AMS 3H 安装螺丝\* |
| **工具盒**     - 通针 - 擦嘴块 - 刮刀刀片 - 内六角扳手 H1.5 - 内六角扳手 H2.0 - 磁铁 - 堵嘴硅胶 - 润滑油 - 润滑脂 - 工具头润滑脂 - 工具头电机解锁套筒 - 料盘支架接头 - 螺丝（用于刮刀） - AMS 3H 安装螺丝\* | **AMS 舱内**     - 干燥剂×2 |
| **\* AMS 3H 安装螺丝的存放位置因包装版本而异，请在 AMS 3H 包装顶部或 H3C 包装内的工具盒中取用。** | |
| 快速入门指南  保修条款  免责声明和安全指引 | 快速入门指南  保修条款  免责声明和安全指引 |

## 配件介绍

| 实物照片 | 名称 | 描述 |
| --- | --- | --- |
| Image | 纹理 PEI 打印板 | 预装在热床上，承载模型；两面均可使用。 |
| Image | 屏幕 | 5 英寸 854\*480 全彩触控屏幕。 |
| Image | 通针 | 用于疏通热端堵塞。 |
| Image | 擦嘴块 | 位于吐料组件上，在开始打印任务前清洁喷嘴。 |
| Image | 堵嘴硅胶 | 位于泊位底部、喷嘴下方，堵住非工作状态的喷嘴，防止漏料。 |
| Image | 刮刀刀片& 螺丝（用于刮刀） | 用于制作刮刀，可在打印机内置模型中找到刮刀模型，打印后进行组装。 |
| Image | 内六角扳手（H1.5 和 H2.0）& 磁铁 | 内六角扳手（H1.5 和 H2.0）：拆装工具。 磁铁：将磁铁吸附在 H1.5/H2.0 内六角扳手长端附近，以防止操作过程中螺丝掉落。 |
| Image | 工具头电机解锁套筒 | 一端插入内六角扳手，另一端扭转工具头上的电机轴，手动解锁工具头上的电机。仅在维修打印机时需要用到，详细操作方法请参见[从动轮组件更换指南](../maintenance/replace-idler-assembly.md)。 |
| Image | 料盘支架接头 & 螺丝 | 打印料盘支架内置模型后进行组装。 |
| Image Image | 润滑油 | 用于润滑光杆、惰轮。 |
| Image Image | 润滑脂 | 用于润滑丝杆和挤出轮组件。 |
| Image Image | 工具头润滑脂 | 用于润滑工具头上的变距凸轮和锁紧插梢。 |
| Image | 打印机电源线 | 为打印机供电。 |
| Image | 烘干模块电源线 | 为 AMS 烘干模块供电。 |
| Image | 6-pin 连接线 | 连接 AMS 3H 与打印机。 |
| Image | FEP 料管\*3 | 传导运输耗材，用于连接料管架组件和打印头。 |
| Image | AMS 3H 安装螺丝 | 安装固定 AMS 3H。 |
| Image | 干燥剂 | 保持 AMS 3H 内部空气干燥。 |
