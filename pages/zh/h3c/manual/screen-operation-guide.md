## 介绍

本指南旨在介绍拓竹H3C 打印机屏幕按键及功能。

## 主页

主页左侧为屏幕菜单栏，包括主页、耗材、控制、设置和助手；右侧为账号、文件、耗材和工具，点击图标可快速跳转至对应的控制界面。

![001.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/001.png)

点击“文件”，可显示项目。其中，项目包括机内存储、历史记录和外部存储；

- **机内存储**：缓存在打印机本地的模型文件；
- **历史记录**：显示打印机缓存空间内的模型列表；
- **外部存储**：缓存在打印机上 U 盘内的模型文件；

## 控制

![005.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/005.png)

### 空调系统

可根据耗材的不同选择合适的空调系统。

- **冷却模式**：适合打印 PLA/TPU 等耐热性较低的耗材；腔体降温时，系统会自动切换至冷却模式。

![006.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/006.png)

- **腔温保持模式**：适合打印 ABS/ASA/PC/PA 等具备高耐热性的耗材。腔体加热时，系统会自动切换至腔温保持模式。

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/007.png)

- **腔体散热风扇**：位于 AMS 背板，该风扇的核心功能是提升系统散热效率，可进一步加强上部腔体的散热能力。

![008.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/008.png)

- **部件冷却风扇**：位于工具头上，用于确保在打印过程中充分冷却打印层，有助于在挤出时快速冷却耗材，使每一层都能在下一层沉积之前凝固并保持原始形状。

![009.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/009.png)

- **左/右部件辅助冷却风扇**：位于机箱内两侧，能为高速打印提供更好的冷却条件。

|  |  |
| --- | --- |
| 010.png | 011.png |

- **外排风扇**：位于打印机背板；打印 PLA 等低温耗材时，可实现打印气体外排，并联动自适应空气循环系统强化散热；打印高温耗材时，通过在屏幕开启“打印结束时净化空气”功能，可在打印完成后自动排出机箱残留气体。

![012.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/012.png)

- **右侧加热风扇：** 腔温保持模式下，右侧辅助冷却风扇自动变为右侧加热风扇，风扇气流与腔温加热器协同加热腔体，同时热气流经滤芯过滤，进一步提升机箱内部空气质量。

![013.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/013.png)

- **净化器**：连接净化器后，右上角会出现“净化器”按钮，点击后可选择净化器强度，并查看滤芯信息、转速等。

![014.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/014.png)

- **腔温**：根据打印耗材的不同，可设置合适的腔温。低腔温适合打印 PLA、PETG 等耗材；高腔温适合打印 ABS 等易翘曲耗材。

![015.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/015.png)

### 运动

![016.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/016.png)

- **工具头**：点击 1 格或 10 格的移动按钮，控制工具头在 X 轴和 Y 轴上移动。
- **热床**：点击 1 格或 10 格的移动按钮，升降热床。
- **挂架**：点击“上升”、“回中”或“下降”，可控制挂架的高度状态。

### 照明

点击此按钮可控制机箱内部 LED 补光灯。

### 校准

校准包括打印校准、运动精度校准、挂架对位校准、平面加工偏移校准和平面加工调节（平面工艺校准），以及首层质量校准。

![042.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/042.png)

**打印校准**

![043.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/043.png)

- **电机降噪**：减少打印过程中电机产生的噪音，特别是在进行长时间或高速打印时。通过优化电机的运行算法和控制策略，不仅能降低噪音，还能提升打印表面的光滑度，从而改善最终打印效果。
- **振动补偿**：在打印中实时监测并检测到任何震动时，可自动调整工具头位置，以确保打印的精确度。尤其在打印复杂或细致模型时，通过此校准能够有效防止因震动引起的误差，确保每层都准确无误地完成。
- **自动热床调平**：通过智能算法调整喷嘴与打印板之间的距离，确保每个角落的间隙一致，能够有效避免因热床不平整导致的打印缺陷，从而提高打印精度。
- **喷嘴偏移校准**：如果两个喷嘴的定位出现偏移，则可能导致打印过程中模型出现错位或层移现象。在打印过程中发现切换喷嘴后模型出现明显的层移时，建议进行一次喷嘴偏移校准。此过程利用工具头内的涡流传感器和热床后面的喷嘴偏移校准传感器，确保喷嘴位置的准确性，以提高打印质量和精确度。通过有效的校准，可以减少打印错误，确保每个层次的完美对齐。

**运动精度校准**

专为对打印质量有高要求的用户设计，旨在解决 3D 打印过程中的绝对定位问题，从而提高打印精度，尤其是大尺寸打印的精度。通过这一过程，可以显著抑制运动迟滞和运动畸变，确保打印结果更加精准。

![044.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/044.png)

**挂架对位校准**

当挂架运动异常进而影响打印过程时，可进行挂架对位校准。系统将通过在预设坐标附近搜索磁铁记录其精确三维坐标，并在初步标定与取放测试后进行二次标定对比：差值在阈值内则判定标定可靠，超出阈值则识别出人工放置不正导致的异常并判定为不可靠。

![045.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/045.png)

**平面加工偏移校准**

当多刀具的实际位置与理论位置存在偏差时，用于校准各刀具之间的偏置。

![046.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/046.png)

**平面加工调平**

用于提高切割均匀性，避免出现局部切不穿或局部线条过深的情况。

> 注意：安装画笔头时，只可进行平面加工偏移校准；如需进行平面加工调节，请**安装刀切头**。

![047.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/047.png)

**首层质量校准**

支持微调首层打印时喷嘴与热床间的距离，从而提升首层附着力与表面平整度，有效解决首层偏高或偏低导致的打印质量问题。

> 注意：该功能是为了满足用户不同场景差异化的调参需求，一般情况无需用到，建议按需使用。

![048.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/048.png)

### 工具箱

![049.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/049.png)

- **腔体烘干**：可将需要烘干的耗材放置在热床上，用简易罩盖覆盖，并设置对应的温度，对耗材进行烘干处理。

![050.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/050.png)

- **XYZ 轴清洁**：光杆的定期清洁可防止碎屑积累，确保设备正常运作并延长使用寿命。屏幕左侧进度条长度会随光杆的清洁程度减少；如果进度条变为红色，则需进行清洁，具体教程可通过右侧二维码获取。

![051.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/051.png)

- **丝杆润滑**：丝杆需要定期润滑，以确保热床上下移动运行平稳。

![052.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/052.png)

- **打印头 & 挂架维护**：打印头与挂架在长期使用过程中，容易积累灰尘，这些灰尘会影响挂架对打印头的锁紧效果。通过对打印头与挂架进行润滑保养，可以减少部件磨损概率，延长使用寿命。

![053.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/053.png)

- **喷嘴冷拔维护**：当挤出电机在常规打印流量下频繁出现过载报错，则表示喷嘴阻力过大，急需清理；同时，由于 TPU 对喷嘴阻力极为敏感，若此前喷嘴打印过其他耗材，建议在打印 TPU 前对喷嘴进行冷拔清理，以保证打印顺畅。

![054.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/054.png)

- **更换净化器滤芯**：可选择所使用的滤芯种类，并根据进度条提示进行滤芯更换，保持净化器的性能稳定。

### 更多设置

|  |  |  |
| --- | --- | --- |
| 057.png | 058.png | 059.png |

1. **打印选项**

- **炒面检测**：在打印过程中检测炒面问题，并选择暂停打印的灵敏度；暂停打印的灵敏度分为高（发现小问题立即暂停）、中（出现一定程度问题时暂停）和低（仅在明显异常时暂停），以适应不同的打印质量需求。
- **堆料检测**：在打印过程中检测废料槽堆积问题，并选择暂停打印的灵敏度；暂停打印的灵敏度分为高（发现小问题立即暂停）、中（出现一定程度问题时暂停）和低（仅在明显异常时暂停），以适应不同的打印质量需求。
- **裹头检测**：在打印过程中检测裹头问题，并选择暂停打印的灵敏度；暂停打印的灵敏度分为高（发现小问题立即暂停）、中（出现一定程度问题时暂停）和低（仅在明显异常时暂停），以适应不同的打印质量需求。
- **异物检测**：发起打印任务后，实况摄像头会检查打印平台是否存在异物；若检测到异物，则无法开启打印。

|  |  |
| --- | --- |
| 060.png | 061.png |

- **类型检测**：若实际使用的打印板与切片文件中的打印板不匹配，则及时停止打印，避免打印失败。
- **偏移检测**：若打印板的标记未处于预定义范围内，打印机将自动停止打印，以避免打印板未放置或放置不当导致的打印异常。
- **空打检测**：若检测到喷嘴堵塞、耗材缠料或磨损导致的空打现象，打印机将自动停止打印。

![062.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/062.png)

- **丢步自动恢复**：当电机检测到位置偏移（丢步）时，X、Y 和 Z 轴会重新定位，并回到偏移前的位置继续执行未完成的 G-code，以保证打印质量。
- **开门检测**：开启后，打印机将检测前玻璃门是否打开，可选择在门打开时触发通知或暂停打印。
- **缓存远程打印文件到外部存储中**：通过云端发起的打印，打印文件将缓存到外部存储中。

![063.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/063.png)

- **运动精度增强**：专为对打印质量有高要求的用户设计，旨在解决 3D 打印过程中的绝对定位问题，从而提高打印精度，尤其是大尺寸打印的精度。通过这一过程，可以显著抑制运动迟滞和运动畸变，确保打印结果更加精准。
- **打印结束时净化空气**：安装外排风扇后，打开该按钮，支持结束打印后自动开始净化腔内气体，通过外排风扇排出机箱残留气体。
- **外接净化器自动模式参数设置**：可按耗材类型自定义自动模式下的净化强度和延时关闭的时长。
- **打印状态快照**：打印任务完成后，打印机会自动拍摄打印件照片并上传至云端，该照片将同步显示在 Bambu Handy 的打印完成弹窗中。

![064.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/064.png)

2. **AMS 选项**

- **AMS 自动续料**：当 AMS 中放入多卷同品牌、同类型、同颜色\*的耗材，且分别位于打印头/热端类型一致的槽位下方时，系统会自动形成续料关系，一卷用完可无缝切换至下一卷，保障长时间打印不中断。该功能不限于 AMS，只要满足续料关系生效条件，外挂耗材也可以实现自动续料。

![065.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/065.png)

3. **录像**：可选择开启实况摄像头或俯视摄像头。

![066.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/066.png)

4. **声音**：如果开启声音选项，打印机在开机、打印开始和打印结束时都会发出提示音。
5. **状态指示灯**：用于提示打印机健康状态和打印任务状态。

![067.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/067.png)

7. **低功率模式**：在打印机供电功率受限的情况下，可通过延长热床升温时间，降低最大功率。

![069.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/screen-operation-guide/zh/069.png)

11. **仅局域网**：开启仅局域网模式后，打印机只能在本地网络内进行连接和访问，不能通过互联网远程访问或控制。如果多个设备通过同一局域网连接，可进行视频直播或数据共享。
