## 概述

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 关机与准备

- 屏幕进入耗材页，点击②退料→③全选→④退料，退出所有耗材。

|  |  |
| --- | --- |
| 001.png | 002.png |

- 转动料盘收回所有耗材。

![003.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/003.png)

- 放回热床底部的泡棉。

![004.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/004.png)

- 使用屏幕控制热床下降至底部，压紧泡棉。

|  |  |
| --- | --- |
| 005.png | 006.png |

> 注意：热床接近底部时，请每次降低 1mm ，防止热床冲撞打印机底部。

- 关闭电源，拔下打印机电源线。

![007.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/007.png)

- 拔下 AMS 烘干模块电源线。

![008.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/008.png)

## AMS 3H 拆卸及装箱

### 断开 AMS 3H 与 H3C

- 移除 6-pin 连接线。

|  |  |
| --- | --- |
| 009.png | 010.png |

### 固定 AMS 舱体内部

- 将泡棉放回所有槽位，用胶带固定烘干仓盖。

![011.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/011.png)

- 再次将上盖完全打开，然后轻轻合上上盖。

![012.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/012.png)

> 请小心操作，以免夹伤。

### 取下打印头

- 从扣手位取下 AMS 左右侧板。

|  |  |
| --- | --- |
| 013.png | 014.png |

- 轻拉取下 9 个打印头。

![015.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/015.png)

### 移除 AMS 3H

- 使用 H1.5 内六角扳手，拧下 4 颗 AMS 3H 安装螺丝。

![016.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/016.png)

- 抬起 AMS 3H 右后侧，按压解锁位拔出腔体散热风扇线缆和打印头控制板线缆。

![017.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/017.png)

- 将 AMS 3H 从打印机顶部取下。

![018.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/018.png)

### 装箱 AMS 3H

- 用胶带固定左右框架。

|  |  |
| --- | --- |
| 019.png | 020.png |

- 装回左右侧板。

|  |  |
| --- | --- |
| 021.png | 022.png |

- 用胶带固定上盖和侧板。

|  |  |
| --- | --- |
| 023.png | 024.png |

- 将 AMS 3H 向后轻轻放倒。

![025.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/025.png)

- 用贴纸固定线缆背板内侧的两根线缆。

![026.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/026.png)

- 将打印头装回纸卡。

|  |  |
| --- | --- |
| 027.png | 028.png |

- 将纸卡和泡棉放回 AMS 内部，注意泡棉方向。

![029.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/029.png)

- 将 AMS 3H 放回包装箱，放入顶部包装材料。

![030.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/030.png)

- 将快速入门指南、干燥剂和 AMS 3H 安装螺丝放回包装箱。

## H3C 拆卸及装箱

### 移除屏幕

- 按压屏幕转轴底部的解锁位，左推屏幕后向外轻拉。

|  |  |
| --- | --- |
| 033.png | 034.png |

- 按住排线两侧端子取下屏幕。

![035.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/035.png)

- 用胶布固定排线。

![036.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/036.png)

### 固定闪切挂架

1. 将红色固定件前半部分卡入 3、5 号槽，插入螺丝。

![037.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/037.png)

2. 将红色固定件后半部分放回，用 H2.0 扳手拧紧 2 颗螺丝。

![038.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/038.png)

### 固定热床

- 将固定件放回原位。

![039.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/039.png)

- 对齐孔位后，用 H2.0 内六角扳手拧回 4 颗螺丝。

![040.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/040.png)

- 用胶带固定空气滤芯盖。

![041.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/041.png)

### 固定工具头

- 将泡棉放回工具头后方，拉动工具头压紧泡棉。

|  |  |
| --- | --- |
| 042.png | 043.png |

- 将扎带穿过后侧框架，固定光杆及工具头。

|  |  |
| --- | --- |
| 044.png | 045.png |

- 用扎带固定拖链，放回拖链上的泡棉。

![046.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/046.png)

### 装箱 H3C

- 将机箱内的纸卡支撑放回原位。

![047.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/047.png)

- 前门套上保护袋后用胶带固定。

|  |  |
| --- | --- |
| 048.png | 049.png |

- 将所有配件放回纸卡，再将纸卡放回机顶并用胶带固定。

|  |  |
| --- | --- |
| 050.png | 051.png |

- 两人合力抬起打印机，放回纸箱底座。

![052.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/052.png)

- 将防潮袋套回打印机。

![053.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/packing-h3c-ams-combo/zh/053.png)

- 放回机身顶部及四周的纸卡、泡棉和气垫。

|  |  |
| --- | --- |
| 054.png | 055.png |

- 将外箱从上向下套回，并装回底部 4 个卡扣。

|  |  |
| --- | --- |
| 056.png | 057.png |
