本文为您介绍如何安装 拓竹H3C 拓竹工作站 L 废料滑梯模型。安装后，打印过程中产生的废料可通过滑梯落入收纳盒，便于集中清理。

![](https://wiki.bambulab.com/h3c/manual/bambu-station-l-purge-chute/purge-chute-overview.png)

> **说明**：本教程中的模型仅适用于安装两层抽屉的拓竹工作站 L（封箱版与开放版均适配），如下图所示；不适用于加装为三层抽屉的拓竹工作站 L。

|  |  |
| --- | --- |
|  |  |

## 所需材料与工具

- 废料滑梯模型（[点击下载.3mf](https://wiki.bambulab.com/h3c/manual/bambu-station-l-purge-chute/purge_chute_guide_for_bambu_station_l.3mf)）
- H2.0 内六角扳手

## 安全提示

> 拆装过程中需要移动打印机。操作前，**请先关闭打印机电源并断开电源连接**，以避免线缆拉扯导致的设备损坏或安全风险。  
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-purge-chute/zh/01__________2012_toollock_motor_replacement_guide_01457bbe50.jpg)

## 安装步骤

### 步骤 1. 打印模型

下载并打印 拓竹H3C 拓竹工作站 L 废料滑梯模型。

**下载链接**：[拓竹工作站 L 废料滑梯模型.3mf](https://wiki.bambulab.com/h3c/manual/bambu-station-l-purge-chute/purge_chute_guide_for_bambu_station_l.3mf)

**推荐耗材**：PLA 具有较好的刚性与尺寸精度，适合打印此模型。也可以使用 PETG 打印，以获得更好的耐用性。

![](https://wiki.bambulab.com/h3c/manual/bambu-station-l-purge-chute/printed-parts.png)

| 序号 | 名称 | 数量 |
| --- | --- | --- |
| 1 | 废料滑梯通道 1 | 1 |
| 2 | 废料滑梯通道 2 | 1 |
| 3 | 废料收纳盒 | 1 |
| 4 | 圆形垫片 | 2 |

### 步骤 2. 调整打印机位置

在打印机背面，将打印机稍微向前移动，使工作站桌面后侧的长条凸起边缘露出。

> ℹ️ **注意**：移动距离不宜过大或过小。仅需露出下图所示的凸起边缘，以确保后续部件可以正确安装，并保证打印机稳定放置。

|  |  |
| --- | --- |
|  |  |

### 步骤 3. 安装废料滑梯通道 1

在打印机背面，使用 H2.0 内六角扳手移除机身废料滑梯处的上下两颗螺丝。

> ℹ️ **注意**：螺丝细小，拆装时请小心操作，避免遗失。

![](https://wiki.bambulab.com/h3c/manual/bambu-station-l-purge-chute/remove-chute-screws.png)

将圆形垫片的窄侧朝内、宽侧朝外，对准螺丝孔位。然后使用 H2.0 内六角扳手重新拧入两颗螺丝。

|  |  |
| --- | --- |
|  |  |

将通道 1 两侧的叶片对齐机身废料滑梯的两侧，同时将通道 1 上下两个孔位对齐圆形垫片。然后向下滑动，将通道 1 卡入圆形垫片以固定。

|  |  |
| --- | --- |
|  |  |
| 对齐叶片 | 对齐孔位 |

![](https://wiki.bambulab.com/h3c/manual/bambu-station-l-purge-chute/seat-channel-1.webp)

### 步骤 4. 安装废料滑梯通道 2

将废料滑梯通道 2 的凹槽卡入工作站柜体边缘，向左推动，使其移动到通道 1 下方并与通道 1 对齐。

|  |  |
| --- | --- |
|  |  |
| 凹槽对齐卡入柜体边缘 | 向左推动 |

![](https://wiki.bambulab.com/h3c/manual/bambu-station-l-purge-chute/place-channel-2.webp)

### 步骤 5. 放置收纳盒

拉出工作站上层抽屉，将废料收纳盒后侧限位槽卡入抽屉后侧边框，向下按压固定，然后推动至最右侧。

|  |  |
| --- | --- |
|  |  |
| 废料收纳盒后侧限位槽 | 放置收纳盒 |

ℹ️ 注意：请确保收纳盒后侧限位槽卡至抽屉边缘，如右图所示。

|  |  |
| --- | --- |
|  |  |

确保收纳盒放置于抽屉最右后侧后，推入抽屉。

![](https://wiki.bambulab.com/h3c/manual/bambu-station-l-purge-chute/close-drawer.webp)

### 步骤 6. 完成安装

废料滑梯安装完成后，打印过程产生的废料会通过通道落入抽屉内的废料收纳盒。

|  |  |
| --- | --- |
|  |  |

清理废料时，只需拉出抽屉并取出废料收纳盒清理。

![](https://wiki.bambulab.com/h3c/manual/bambu-station-l-purge-chute/remove-purge-bin.webp)

> ℹ️ **注意事项**
>
> - 使用过程中，请勿大幅移动打印机相对于工作站的位置，以免废料滑梯掉落或错位。
> - 如果废料滑梯发生错位，请按照本文安装步骤重新安装。
> - 请勿大幅移动废料收纳盒在抽屉中的位置，以免废料掉落到收纳盒外。

## 拆卸步骤

### 步骤 1. 移除废料收纳盒

拉出工作站上层抽屉，取出废料收纳盒。

![](https://wiki.bambulab.com/h3c/manual/bambu-station-l-purge-chute/remove-purge-bin.webp)

### 步骤 2. 移除废料滑梯通道 2

将废料滑梯通道 2 向右推出并取下。

![](https://wiki.bambulab.com/h3c/manual/bambu-station-l-purge-chute/remove-channel-2.png)

### 步骤 3. 移除废料滑梯通道 1

将废料滑梯通道 1 向上推出并取下。
