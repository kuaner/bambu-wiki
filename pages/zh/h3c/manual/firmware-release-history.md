## 版本 01.01.03.00

**新功能：**

1. 1 号打印头新增支持外接最多 4 台 AMS、AMS 2 Pro 或 AMS HT 自动供料系统。用户可通过上述设备进行打印，并执行进料、退料和烘干等操作。
2. 新增自动续料组的手动编辑与维护功能，支持同一耗材大类（如 PLA）下不同颜色、不同子类的耗材之间的自动续料（如 PLA Basic 续接 PLA Matte）

|  |  |

3. 屏幕 UI 状态栏新增时间显示功能
4. 新增对拓竹空气净化器 E1 的支持
5. 新增耗材进退料指引

|  |  |
| --- | --- |
| 003.png | 004.png |

6. 新增空打检测开关
7. 新增画笔类型识别和笔盖在位检测功能
8. 新增高精度拍照模式，提升刀切和画笔加工的定位精度
9. 新增对冷烫金和压痕工艺的支持
10. AMS 3H 新增对官方 TPU 75A 耗材 RFID 信息的读取支持
11. 针对部分常见异常，新增屏幕端故障排查引导页面 MiniWiki，帮助用户快速排除故障

**功能优化：**

1. 全面升级 UI 设计

|  |  |
| --- | --- |
| 007.png | 008.png |

2. 提升普通拍照模式下刀切和画笔的加工位置精度
3. 优化耗材进退料体验
4. 将 AMS 的最长烘干时长从 24 小时延长至 72 小时
5. 优化录像开关逻辑，使其不再受 U 盘识别状态影响
6. 优化冷拔流程体验
7. 优化休眠模式体验
8. 优化断料续打体验，支持从handy选择其他槽位兼容的同类型耗材进行续打

![009.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/manual/firmware-release-history/zh/009.jpg)

9. 优化开门检测的默认行为：检测到舱门开启时自动暂停打印，以确保打印安全。如需更改，可前往“设置 > 打印选项”进行调整。
10. 优化部分耗材打印前的风险提示信息

**问题修复：**

1. 修复打印过程中拔出 U 盘时，模型表面质量偶尔变差的问题
2. 修复部分场景下打印头使用后未放回闪切挂架的问题
3. 修复部分场景下画笔回中时可能撞飞笔盖的问题
4. 修复 TPU 75A 耗材余量检测误差
