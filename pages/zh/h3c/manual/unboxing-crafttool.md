## 重要提醒

- 刀头十分锋利，进行安装、更换或切换时，请小心操作，避免划伤。
- 拆除 AMS 舱体、拔插线缆前，请先关闭打印机电源。
- 妥善保管拆下的螺丝与堵嘴硅胶，避免遗失。

## 安装刀切头/画笔头

### 提前打印取刀器

进行平面加工头安装前，请前往 [MakerWorld](https://makerworld.cn/) 或 Bambu Handy，在 Bambu Lab 官方账号内搜索“取刀器”并打印。取刀器用于夹持刀头，辅助更安全地安装与拆卸，避免手指直接接触刀刃。

![012.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/012.png)

### 放置刀切垫板

在屏幕上降低热床高度。

取下打印板。

对准刀切垫板两角与热床限位块，将刀切垫板放置在热床上，在使用时撕除所需面的保护膜。

> 提示：请勿丢弃保护膜，使用粘板后请贴回保护膜，放置粘附杂物，保持粘板的粘性。

> 建议优先更换两侧打印头。

### 移除 AMS 舱体

取出 AMS 内全部耗材，关闭 AMS 舱门。

![028.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/028.png)

关闭打印机电源。

![029.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/029.png)

拔下 AMS 舱体后端 6-pin 连接线与电源线。

|  |  |
| --- | --- |
| 030.png | 031.png |

取下左右磁吸侧板。

|  |  |
| --- | --- |
| 032.png | 033.png |

使用 H2.0 内六角扳手，逆时针拧松并取出 AMS 舱体两侧螺丝（两侧各 2 颗），妥善保管螺丝。

|  |  |
| --- | --- |
| 034.png | 035.png |

托住 AMS 舱体前后两端，将其轻轻抬出，妥善放置在一旁。

![036.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/036.gif)

### 决定安装数量

若需安装多个平面加工头，请按使用数量移除相应打印头，并在对应位置安装刀切头或画笔头。安装完成后可长期保留，无需频繁拆装。

刀座与笔座已预装在平面加工头基座上。下图左侧为刀座，右侧为笔座；请根据加工需求安装刀切头或画笔头。

### 移除打印头

为便于操作，建议优先更换两侧打印头。以下操作以最右侧打印头为例，其余位置操作相同。

![039.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/039.png)

按压 6-pin 线卡扣，从打印头控制板下方拔出该线。

![040.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/040.gif)

将 6-pin 线从料管支架滑块中解锁。

![041.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/041.gif)

将 6-pin 线向屏幕方向抽出，使插头穿过料管架组件。

|  |  |
| --- | --- |
| 042.gif | 043.gif |

向屏幕方向推动料管支架滑块直至露出气动接头，向前推动滑块的同时向后按压气动接头黑色外圈，从控制板下方拔出 FEP 料管。

![044.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/044.gif)

将打印头向上提起，从挂架上移除。

|  |  |
| --- | --- |
| 045.png | 046.png |

取下挂架泊位上的堵嘴硅胶。

> 提示：后续若需装回打印头，须将堵嘴硅胶装回原位，请妥善保管。若遗失，可使用随附的替换堵嘴硅胶。

|  |  |
| --- | --- |
| 047.png | 048.png |

### 连接平面加工头基座

向屏幕方向推动料管支架滑块直至露出气动接头，将平面加工头基座的 FEP 料管插入气动接头，确认插入到位。

![049.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/049.gif)

将 6-pin 线插头向后穿过料管架组件。

![050.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/050.gif)

先将线缆橙色实心标记处卡入料管支架滑块最后端卡扣，然后再将线缆卡入其他卡扣中。

![051.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/051.gif)

插入打印头控制板下方 6-pin 接口，确认插入到位。

![052.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/052.png)

将 6-pin 线缆都卡入卡扣中

![053.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/053.png)

### 安装刀切头

下面操作以精细尖刀为例，压痕刀和冷烫金刀也可使用相同方法安装。

> 注意：
>
> 安装前请确认刀座已在平面加工头基座上拧紧。初次使用前也请检查，以免加工过程中刀座脱落。
>
> 请小心操作，以免受伤。

![054.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/054.png)

移除刀头上的保护套。

![055.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/055.gif)

使用取刀器夹住刀头，将刀头插入刀座。

> 提示：请提前打印取刀器。前往 [MakerWorld](https://makerworld.cn/) 或 Bambu Handy，在 Bambu Lab 官方账号内搜索“取刀器”并打印。

![056.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/056.gif)

确认挂架泊位无堵嘴硅胶，将基座上橙色部分对准橙色泊位挂钩，将刀切头吸附安装到挂架上。

![057.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/057.gif)

### 安装画笔头

> 注意：安装前请确认笔座已在平面加工头基座上拧紧。初次使用前也请检查，以免加工过程中笔座脱落。

拔下笔盖。

> 不使用画笔时请及时盖回笔盖，防止笔尖变干。

|  |  |
| --- | --- |
| 058.png | 059.png |

将画笔插入笔座。

![060.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/060.gif)

确认挂架泊位堵嘴硅胶已取下，将基座倾斜挂入橙色泊位挂钩，完成磁吸安装。

![061.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/061.gif)

### 安装 AMS 舱体

完成刀切头或画笔头安装后，将 AMS 舱体轻轻放置于支架上，确保与支架完全贴合。

> 放置 AMS 舱体时请小心轻放，避免磕碰。

![062.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/062.gif)

使用 H2.0 内六角扳手，将 AMS 舱体两侧各 2 颗螺丝顺时针完全拧紧。

|  |  |
| --- | --- |
| 063.png | 064.png |

装回左右侧板视窗。

|  |  |
| --- | --- |
| 065.png | 066.png |

在 AMS 舱体后端插入 6-pin 连接线与电源线。

![067.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/067.png)

打开打印机电源。

![068.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/068.png)

## 切换刀座与笔座

更换刀座和笔座，可快速切换刀切与绘画功能。下面以刀切功能切换为画笔功能为示例。

> 注意：操作前请关闭打印机电源。

### 取下刀切头

取下磁吸侧板视窗，从侧面轻拉刀切头线缆，将刀切头从挂架上取下。

![069.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/069.png)

### 取下刀头与刀座

建议优先使用方法一；若刀头不易夹取，请改用方法二，小心取下刀头。

#### 🟢 方法一：标准取下（推荐）

1. 使用取刀器夹住刀头并取下。  
     
   ![Image](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/070.gif)
2. 给刀头套上保护套（如有），妥善存放。  
     
   ![Image](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/071.gif)
3. 逆时针旋转取下刀座。  
     
   ![Image](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/072.gif)

---

#### 🟡 方法二：备选取下（刀头不易夹取时使用）

1. 逆时针旋转取下刀座。  
     
   ![Image](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/073.gif)
   > **注意**：刀头仍在刀座上，请小心操作，防止受伤。
2. 按压刀座上方推杆推出刀头，并用取刀器取下刀头。  
     
   ![Image](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/074.png)
3. 给刀头套上保护套（如有），妥善存放。  
     
   ![Image](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/075.gif)

![076.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/076.gif)

拔开笔盖。

> 注意：不使用画笔时请及时盖回笔盖，防止笔尖变干。

|  |  |
| --- | --- |
| 077.png | 078.png |

将画笔插入笔座。

![079.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/079.gif)

确认挂架泊位堵嘴硅胶已取下，将基座倾斜挂入橙色泊位挂钩，完成磁吸安装。

![080.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/080.gif)

装回侧板视窗。

![081.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/unboxing-crafttool/zh/081.png)
