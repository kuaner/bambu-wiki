## 介绍

压痕刀和冷烫金刀外观相似，**主要区别在于刀头处的痕迹**：压痕刀有一道圆环形凹槽，冷烫金刀有两道圆环形凹槽。

![20261030-001.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-001.jpg)

- **压痕刀：**不切断材料，只在表面压出折痕，方便后续折叠或立体造型。

![20261030-002.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-002.png)

- **冷烫金刀：**配合适配冷压的烫金纸使用，将金属箔转移到指定区域，用于制作装饰线条等烫金效果，无需高温烫印。

![20261030-003.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-003.png)

> 注：基础刀切加工、其他工具介绍、校准介绍等其他信息请参考：[拓竹H3C 刀切加工介绍](crafting-guide.md)。

## 箔纸转印工艺

以下将介绍箔纸转印工艺的具体步骤。

### 加工前准备

- 冷烫金刀
- 卡纸、烫金纸
- 胶带
- 刀切垫板
- 俯视摄像头（可选）

> 注：烫金纸需自行购买，使用效果可能因烫金纸规格和品质而异，恕不保证自购烫金纸的使用效果。

### 安装刀切头和刀切垫板

请参考[平面加工头开箱指南](unboxing-crafttool.md)安装。

### 安装俯视摄像头（选做）

请参考：[俯视摄像头更换指南](../maintenance/replace-birdseye-camera.md)安装俯视摄像头。

> 注意：未选配俯视摄像头时，无法在 Bambu Suite 中直接拍照对位，但可用 Bambu Handy 拍照完成对位。如需体验更顺畅的平面加工流程，建议选购俯视摄像头。

### 加工准备

- 在打印机屏幕上设置正确的加工头信息，并取用该打印头；

|  |  |
| --- | --- |
| 20261030-004.png | 20261030-005.png |
| 20261030-006.png | 20261030-007.png |

- 在 Suite 添加需要加工的图案；

![20261030-008.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-008.png)

- 在“**工艺类型**”中选择“**箔纸转印**”;

![20261030-009.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-009.png)

- 在右下角点击“准备制作”；

![20261030-010.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-010.png)

- 在刀切垫板上粘贴一张白色卡纸作为底纸，并用滚筒工具使其完全贴合；

![20261030-011.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-011.png)

- 使用胶带将烫金纸粘贴在底纸上；

> **注意：尽量将烫金纸铺平后再粘贴**，避免中间部分出现褶皱，影响加工效果。

|  |  |
| --- | --- |
| 20261030-012.png | 20261030-013.png |

- 安装刀切垫板。

![20261030-014.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-014.png)

- 在 Bambu Suite 右侧“**材料组**”中选择使用的材料。

![20261030-015.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-015.png)

### 拍照对位

#### 俯视摄像头自动拍照

点击“拍照”，俯视摄像头将自动拍照。

> 注：可选择打开“精细轮廓提取”，大多数情况下，使用精细轮廓都会得到更准确的材料轮廓边界，但轮廓提取过程将更加耗时，具体请参考：[精细轮廓提取](../../h2/software/bambu-suite/manual/take-photos-and-troubleshooting.md)。

|  |  |
| --- | --- |
| 20261030-016.png | 20261030-017.jpeg |

#### Bambu Handy 手动拍照

- 点击“拍照”按钮，打印机检测到未安装俯视摄像头后，将提示打开 Bambu Handy 进行手动拍照；

|  |  |
| --- | --- |
| 20261030-018.png | 20261030-019.png |

- 打开 Bambu Handy，点击“拍照”，然后参考指示进行垫板拍照；

|  |  |  |
| --- | --- | --- |
| 20261030-020.png | 20261030-021.jpg | 20261030-022.jpg |

- 拍照完成后，在 Bambu Suite 中再次点击“拍照”图标，即可获取加工背景图，可在背景上调整图案至所需位置。

![20261030-023.jpeg](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-023.jpeg)

### 开启加工

- 确认无误后点击“制作”发送任务，并检查是否符合任务要求；

![20261030-024.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-024.png)

- 检查垫板和材料是否正确，并检查工具“冷烫金刀”是否选择正确。确认完毕后，点击“发送”，打印机将开始加工。

![20261030-025.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-025.png)

### 完成加工

- 制作完成后，取下刀切垫板；

![20261030-026.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-026.png)

- 小心撕下烫金纸，检查加工效果；

|  |  |
| --- | --- |
| 20261030-027.png | 20261030-028.png |

- 重新贴上刀切垫板的离型膜。

> 注：正式粘贴前建议先试贴，并用粘性较弱的一面粘贴，以便后续取下离型膜。

![20261030-029.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-029.png)

> 如果加工效果不佳，可参考 wiki：[拓竹H3C 平面加工质量排查](crafttool-quality.md)进行排查。

## 基础压痕工艺

以下将介绍基础压痕工艺的具体步骤。

### 加工前准备

- 压痕刀、精细尖刀
- 卡纸
- 刀切垫板
- 俯视摄像头（可选）

### 安装刀切头和刀切垫板

请参考[平面加工头开箱指南](unboxing-crafttool.md)安装压痕刀、精细尖刀和刀切垫板。

> 注意：基础压痕的默认顺序为**先压痕再刀切**。如果只有一个槽位可用刀切头，可以**先安装压痕刀**，后续发起任务时，在“发送到打印机”步骤中选择**“手动替换”**（可参考下文“开启加工”部分），机器会在特定时间暂停任务，提醒用户安装精细尖刀。

### 安装俯视摄像头（选做）

请参考：[俯视摄像头更换指南](../maintenance/replace-birdseye-camera.md)安装俯视摄像头。

> 注意：未选配俯视摄像头时，无法在 Bambu Suite 中直接拍照对位，但可用 Bambu Handy 拍照完成对位。如需体验更顺畅的平面加工流程，建议选购俯视摄像头。

### 加工准备

- 在打印机屏幕上设置正确的加工头信息，并取用该打印头；

- 导入需要刀切的图案，在“**工艺类型**”中选择“**基础刀切**”；

|  |  |
| --- | --- |
| 20261030-034.png | 20261030-035.png |

- 再绘制或选择需要压痕的形状，在“**工艺类型**”中选择“**基础压痕**”；

|  |  |
| --- | --- |
| 20261030-036.png | 20261030-037.png |

- 点击右下角“准备制作”；

![20261030-038.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-038.png)

- 把需要加工的材料粘附在刀切垫板上，并用滚筒工具使其完全贴合，然后安装刀切垫板；

|  |  |
| --- | --- |
| 20261030-039.png | 20261030-040.png |

- 在 Bambu Suite 右侧“**材料组**”中选择使用的材料。

![20261030-041.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-041.png)

### 拍照对位

#### 俯视摄像头自动拍照

点击“拍照”，俯视摄像头将自动拍照，可将图案移动至需要加工的位置。

> 注：可选择打开“精细轮廓提取”，大多数情况下，使用精细轮廓都会得到更准确的材料轮廓边界，但轮廓提取过程将更加耗时，具体请参考：[精细轮廓提取](../../h2/software/bambu-suite/manual/take-photos-and-troubleshooting.md)。

#### Bambu Handy 手动拍照

- 点击“拍照”按钮；打印机检测到未安装俯视摄像头后，将提示打开 Bambu Handy 进行手动拍照；

|  |  |
| --- | --- |

- 打开 Bambu Handy，点击“拍照”，参考指示进行垫板拍照；

|  |  |  |
| --- | --- | --- |
| 20261030-046.png | 20261030-047.jpg | 20261030-048.jpg |

- 拍照完成后，在 Bambu Suite 中再次点击“拍照”图标，即可获取加工背景图，可在背景上调整图案至所需位置。

![20261030-049.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-049.png)

### 开启加工

- 确认无误后点击“制作”发送任务，并检查是否符合任务要求；

![20261030-050.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-050.png)

- 检查垫板和材料是否正确，并检查工具“压痕刀”是否选择正确；如果只有一个槽位可用刀切头，可选择**“手动替换”**，机器会在特定时间暂停任务，提醒用户进行换刀。选择完成后，点击“**发送**”；

![20261030-051.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-051.png)

- 打印机将开始执行压痕加工；

![20261030-052.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-052.png)

- 压痕结束后，待打印机提示，手动从挂架上取下打印头，并小心取下压痕刀，安装精细尖刀；

|  |  |
| --- | --- |
| 20261030-053.png | 20261030-054.png |

- 在屏幕点击“**已更换，继续**”，打印机将进行刀切加工。

![20261030-055.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-055.png)

### 完成加工

- 加工完成后，小心取下刀切垫板；

![20261030-056.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-056.png)

- 小心揭下材料；

|  |  |
| --- | --- |
| 20261030-057.png | 20261030-058.png |

- 根据压痕折叠纸盒，并粘上胶水；

|  |  |
| --- | --- |
| 20261030-059.png | 20261030-060.png |

- 完成纸盒制作。

![20261030-061.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/deboss-and-foil-transfer-tip/zh/20261030-061.png)

> 如果加工效果不佳，可参考 wiki：[拓竹H3C 平面加工质量排查](crafttool-quality.md)进行排查。
