## 概览

根据该机型的特性与实际使用场景，我们整理了一系列适配的 3D 打印配件模型，帮助提升设备安全性，并优化日常使用体验。本文将介绍部分新模型的安装方法。

## 3D 打印相关配件

| 模型图片 | 名称 | 简介 |
| --- | --- | --- |
| Image | 润滑刷 | 连接到随附的润滑油管口，方便为光杆涂抹润滑油。 |
| Image | 闪切挂架维护挡块 | 进行维护保养时，将挂架固定在高位，方便更清晰地观察机箱内部。 |
| Image | 外挂料盘支架 | 打印后，需在其上安装料盘支架接头，组装完成后，滑入机箱背板预留的料盘支架底座，承载外挂料盘进行打印。详细方法请参见[外挂进料指南](print-with-external-spool.md)。 |
| Image | 刮刀 | 从打印板上取下模型，或从刀切垫板上移除材料。 |
| Image Image | 外挂料盘 | 可组合成外挂料盘，安装耗材后使用。 |

## 安装指南

> 以下章节仅收录需要单独说明安装步骤的配件；其余配件请参考 MakerWorld 模型页说明或相关 Wiki 章节。

### 安装闪切挂架维护挡块

1. 抬升闪切挂架到顶。

![013.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/internal-print-files/zh/013.png)

2. 将挡块对准孔位插入任意槽，即可固定闪切挂架。

> 建议一次性安装 2-3 个挡块，以确保挂架稳固不坠落，并增加打印机的维护空间。

![014.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/internal-print-files/zh/014.png)

### 组装外挂料盘支架

1. 组装料盘支架；

> 组装方向可根据需使用的打印头位置进行调整。

![015.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/internal-print-files/zh/015.png)

2. 从配件盒里取出料盘支架接头和螺丝，将螺丝放进接头中；

![016.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/internal-print-files/zh/016.png)

3. 将接头安装到料盘支架上，使用 H2.0 内六角扳手拧紧螺丝；

|  |  |
| --- | --- |
| 017.png | 018.png |

4. 安装料管；

![019.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/internal-print-files/zh/019.png)

5. 将料盘支架滑入打印机背部的料盘支架底座；

![020.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/internal-print-files/zh/020.png)

### 组装刮刀

1. 将工具盒中附赠的刀片卡入刀柄上的凸起位置。

![021.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/internal-print-files/zh/021.png)

> 注意：如果刀片无法卡入，说明方向错误，请翻转刀片调整方向。请确保刀片安装方向正确，避免使用中脱落导致受伤。

2. 对齐刀片、刀柄和抵手块上的螺丝孔位，使用 H2.0 内六角扳手拧紧 2 颗螺丝。

|  |  |
| --- | --- |
| 022.png | 023.png |

> 注意：刀片锋利，装配时请小心操作，防止划伤。请将刮刀放置在儿童无法触及的地方

### 组装外挂料盘

1. 找到料盘和耗材卷上的定位块，对齐安装。

|  |  |
| --- | --- |
| 024.png | 025.png |

2. 安装另外半边料盘，旋转料盘锁紧。

![026.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/internal-print-files/zh/026.png)

3. 将固定片插入料盘内圈槽位。
