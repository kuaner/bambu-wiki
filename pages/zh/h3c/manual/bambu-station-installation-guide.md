## 安装框架（开放版）

### 步骤 1：准备工作

在干净、平整、无异物和硬物的平面上进行组装。

![023.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/023.png)

请佩戴手套进行组装，避免脏污和意外剐蹭受伤。

![024.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/024.png)

### 步骤 2：安装立柱

将桌面朝下，放置在平面上。

![025.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/025.png)

确认立柱编号与桌面插槽编号一致。

![026.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/026.png)

沿约 45° 方向将立柱插入桌面插槽，推至孔位对齐。

![027.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/027.gif)

在立柱下方拧紧 2 颗 1 号螺丝。

![028.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/028.png)

用相同方法，安装其余 3 根立柱。检查各立柱下方螺丝均已拧紧。

![029.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/029.png)

### 步骤 3：安装底座

取出底座，对准底座四角塑胶件与立柱插槽。

![030.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/030.png)

轮流下压底座四角，将塑胶件竖直下压至半插入（勿完全压入），保持立柱垂直。

![031.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/031.gif)

对齐立柱定位楔与底座定位槽。

![032.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/032.png)

继续轮流下压四角，直至定位楔完全卡入槽内。

> 注意：安装时请保持立柱垂直。

![033.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/033.gif)

在底座下方立柱中锁入 2 颗 1 号螺丝。

![034.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/034.png)

在其他 3 个立柱中各锁入 2 颗 1 号螺丝。检查 8 颗螺丝均已锁入。

![035.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/035.png)

### 步骤 4：安装可调万向轮

将可调万向轮对准底座一角。

|  |  |
| --- | --- |
| 036.png | 037.png |

在单个万向轮中锁紧 4 颗 2 号螺丝。

|  |  |
| --- | --- |
| 038.png | 039.png |

按相同方法安装其余 3 个可调万向轮。确认 4 个万向轮均已安装到位。

![040.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/040.png)

### 步骤 5：固定桌面

翻转框架，使可调万向轮着地。

![041.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/041.png)

在桌面四角分别锁紧 3 颗 3 号螺丝，共 12 颗螺丝。

|  |  |
| --- | --- |
| 042.png | 043.png |

### 步骤 6：安装抽屉

有产品名称的一面为前端，凹面为后端。后续操作均面向前端。右侧安装 R 滑轨，左侧安装 L 滑轨。

> 提示：内外滑轨上都有标记 R 或 L。

|  |  |
| --- | --- |
| 044.png | 045.png |

完全拉开抽屉滑轨。

> 滑轨含润滑油，请佩戴手套操作。

![046.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/046.gif)

推动滑轨卡扣，拆下内滑轨。

![047.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/047.gif)

面向抽屉前端，将有 **R** 标记的右内滑轨放在抽屉右侧，标记端朝向抽屉前端。

|  |  |
| --- | --- |
| 048.png | 049.png |

将右内滑轨向后插入抽屉右后端插槽。

|  |  |
| --- | --- |
| 050.png | 051.png |

完全插入后端槽位后，抬起右内滑轨前端，插入抽屉右前端插槽。

![052.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/052.gif)

将有 **L** 标记的左内滑轨放在抽屉左侧，标记端朝向抽屉前端。

将左内滑轨向后插入抽屉左后端插槽。

|  |  |
| --- | --- |
| 053.png | 054.png |

完全插入后端槽位后，抬起左内滑轨前端，插入抽屉左前端插槽。

![055.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/055.gif)

在另一个抽屉上重复上述操作，安装左右内滑轨。

![056.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/056.png)

将 R 外滑轨后端插入右后立柱槽位，下压前端卡入前立柱槽位。

|  |  |
| --- | --- |
| 057.gif | 058.gif |

用相同方法，在右下立柱槽位安装另一根 R 外滑轨。

|  |  |
| --- | --- |
| 059.png | 060.gif |

在左立柱相同高度的槽位安装两根 L 外滑轨，方法与右侧相同。

![061.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/061.png)

拉出立柱上的滑轨。

![062.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/062.gif)

同时将抽屉左右两侧内滑轨对准立柱上的外滑轨，向后推进抽屉。

|  |  |
| --- | --- |
| 063.png | 064.gif |

用相同方法安装另一个抽屉。

![065.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/065.png)

## 固定工作站

如您购买了选配件或购买版本为封箱版，请先根据以下内容完成抽屉前板、侧板或背板的安装。全部部件安装完毕后，将工作站移至最终使用位置进行固定。

逆时针旋转万向轮上的红色旋转件，使支撑调节块触地、万向轮完全离地。逐一调节各支撑调节块，直至按压桌面时整体无晃动。

> 提示：调节后万向轮与地面间隙建议不超过 7 mm。

|  |  |
| --- | --- |
| 066.png | 067.png |

如您购买了选购配件或购买版本为封箱版，可先不进行最终固定，继续查看后续抽屉前板、侧板和背板安装内容，全部部件安装完毕后再固定工作站。

## 安装抽屉前板

两块前板高度不同：较矮者为上抽屉前板，较高者为下抽屉前板。

> 提示：抽屉前板背后有字母标记区分，上抽屉前板为 A，下抽屉前板为 B。

![068.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/068.png)

拉开下抽屉，对齐两侧边缘，将前板扣入下抽屉前端。

![069.gif](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/069.gif)

左右微调前板，直至螺丝孔完全露出。

|  |  |
| --- | --- |
| 070.png | 071.png |

在孔位中锁紧 4 颗螺丝。封箱版请使用 4 号螺丝；开放版选购配件所需螺丝随配件包装提供。

![072.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/072.png)

用相同方法，将上抽屉前板扣入上抽屉，然后锁紧 4 颗螺丝。

![073.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/073.png)

## 安装工作站侧板

将侧板完全放入右侧框架。

|  |  |
| --- | --- |
| 074.png | 075.png |

在四角各拧紧 1 颗螺丝（共 4 颗）。封箱版请使用 5 号螺丝；开放版选购配件所需螺丝随配件包装提供。

![076.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/076.png)

按相同方法在工作站左边安装侧板。

## 安装工作站背板

将背板放入工作站后端，确保背板底部贴合框架，两侧孔位对齐。

|  |  |
| --- | --- |
| 077.png | 078.png |

在左右两侧孔位中共锁紧 4 颗螺丝。封箱版请使用 6 号螺丝；开放版选购配件所需螺丝随配件包装提供。

|  |  |
| --- | --- |
| 079.png | 080.png |

完成安装。

![081.png](https://public-cdn.bblmw.com/wiki/new/h3c/manual/bambu-station-installation-guide/zh/081.png)

完成所有配件安装后，将工作站移至最终使用位置并固定，具体操作请参考“[固定工作站](#fix-station)”。
