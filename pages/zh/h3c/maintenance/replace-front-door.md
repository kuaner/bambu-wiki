## 玻璃前门

玻璃前门是安装在打印机正面的玻璃材质配件，便于观察打印机作业并起防护作用。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-front-door/zh/112__________front_door_replacement_guide_e240e15011.jpg)

## 何时更换

玻璃前门有开裂或损坏时更换。

## 工具和材料

- H2.0 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除玻璃前门

### 第 1 步 移除前门螺丝

合上玻璃前门，用 H2.0 内六角扳手分别移除位于前门左上角和左下角的 2 颗螺丝。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 2 步 移除玻璃前门

一只手握住前门把手，将前门与打印机轻微分离开，另一只手扶住玻璃前门的左边，移除玻璃前门。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-front-door/zh/70____________front_door_mounting_kit_replacement_guide_80b1eca3e4.jpg)

## 安装玻璃前门

### 第1 步 安装玻璃前门

将玻璃前门对齐上下合页上的螺丝柱，确认安装到位。

|  |  |
| --- | --- |
| 图 | 图 |

### 第2 步 锁前门螺丝

用手扶着前门，确保前门不会掉落。然后分别锁入位于前门左上角的螺丝，各 2 颗。

|  |  |
| --- | --- |
| 图 | 图 |

## 功能验证

开合玻璃前门2~3 次，确认开合顺畅无干涉。
