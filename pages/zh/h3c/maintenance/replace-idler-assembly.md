## 从动轮组件

![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-assembly/zh/41___________idler_assembly_replacement_guide_618d47be60.jpg)

## 何时更换

- 连接排线损坏
- 从动轮磨损
- 其他物理结构损坏

## 工具和材料

- H1.5 内六角扳手
- H2.0 内六角扳手
- 专用套筒

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-assembly/zh/01__________2012_toollock_motor_replacement_guide_01457bbe50.jpg)

> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 拆装提示

> 从动轮组件在拆除和安装时，有特定的位置要求，请使用专用套筒进行调整。  
> 拆除时：逆时针旋转到底，使从动轮位于1.75 mm 线径适应位置。
>
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-assembly/zh/41___________idler_assembly_replacement_guide_55ee7f9a3b.jpg)

> 1.75 mm 线径适应位置
>
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-assembly/zh/41___________idler_assembly_replacement_guide_89b7854355.jpg)

> 2.85 mm 线径适应位置
>
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-assembly/zh/41___________idler_assembly_replacement_guide_5edf4813ca.jpg)

> 完全解锁位置
>
> 安装时：调整凸轮“尖端”朝向，使其大约指向左下位置的电机固定螺丝。  
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-assembly/zh/41___________idler_assembly_replacement_guide_1ec90e058a.jpg)

## 移除从动轮组件

### 第 1 步 移除工具头前盖和顶盖

请参考 WIKI：[工具头外壳更换指南](replace-toolhead-front-cover.md)， 移除工具头前盖和顶盖。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-assembly/zh/23__________2521_extruder_servo_motor_replacement_guide_3857e0ee6a.jpg)

### 第 2 步 松开连接线缆

将涡流线圈的插头从挤出接口板上断开，并将线缆从卡扣上松出，使涡流线圈的线缆完全与从动轮组件分离。

|  |  |
| --- | --- |
| 图 | 图 |

用镊子或扳手打开从动轮组件排线连接器的盖子，解除排线的锁定状态。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-assembly/zh/41___________idler_assembly_replacement_guide_fb4c4d045d.jpg)

### 第 3 步 调整变距凸轮位置

在 H2.0 内六角扳手上装上专用套筒，顺时针拧动变矩凸轮，使其处于咬紧状态（即 1.75 线径状态）。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 4 步 移除从动轮组件

用 H1.5 内六角扳手，移除 3 颗螺丝，然后取下从动轮组件。（ 排线连接器盖子在第 2 步时已打开 ）  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-assembly/zh/41___________idler_assembly_replacement_guide_b805b65a3b.jpg)

## 安装从动轮组件

### 第 1 步 调整凸轮位置，检查轴承

安装从动轮组件前，请先确认变距凸轮已处于图示的位置状态。若凸轮方向与图示不符，将导致从动轮组件无法完全装入到位。（如果拆下从动轮组件后，没有再次拧动过，可跳过这一步）；  
**检查从动轮组件的轴承：变距凸轮轴或从动轮组件两个位置须且只须有一个轴承，多了要移除，少了要增加。**

|  |  |
| --- | --- |
| 图 | 图 |

### 第 2 步 安装从动轮组件

将从动轮组件安装到工具头上，倾斜着对齐凸轮，然后再摆正。

|  |  |
| --- | --- |
| 图 | 图 |

锁入 3 颗螺丝固定从动轮组件，然后连接排线，并合上盖子。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-assembly/zh/41___________idler_assembly_replacement_guide_b805b65a3b.jpg)

### 第 3 步 连接线缆

将涡流线圈的插头重新连接到挤出接口板上，并将线缆（缠绕有保护胶布的位置）整理进从动轮的卡扣中。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 4 步 安装工具头前盖和顶盖

请参考 WIKI：[工具头外壳更换指南](replace-toolhead-front-cover.md)， 安装工具头顶盖和前盖。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-assembly/zh/40__________2012_flexfeed_motor_replacement_guide_5494848a85.jpg)

### 第 5 步 运行标定 （仅更换时用）

> 注意：如果不是更换需要重新标定的配件，请不要运行 Gcode, 可能会导致损坏或出现不可预知的错误。

更换该组件后需要进行标定，请参考 WIKI ：[锁紧和变距电机未进行过机械行程标定，请在标定后再执行其他操作](../troubleshooting/hmscode/0800_1A00_0001_0008.md) 完成标定操作。

## 功能验证

1. 如果是更换配件，设置好打印机后，标定通过即可。
2. 如果是拆装过配件，执行一次更换工具，操作完成即可。
