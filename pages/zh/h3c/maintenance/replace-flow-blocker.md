## 堵嘴组件

堵嘴组件位于泊位底部，包含堵嘴硅胶及堵嘴支架。用于堵住喷嘴，以防其内部的熔融耗材滴落。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-flow-blocker/zh/63__________flow_blocker_replacement_guide_b03be82f5d.jpg)

## 何时更换

- 硅胶破损，影响使用，需要更换堵硅胶；
- 堵嘴支架损坏，需要更换支架。

## 工具和材料

- H1.5 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除堵嘴组件

### 第 1 步 移除打印头

用手握住打印头组件的上部，斜向上提起，卸载对应位置的打印头组件。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-flow-blocker/zh/04_____________filament_cutter_assembly_replacement_guide_ed45d93eb1.jpg)

### 第 2 步 移除堵嘴硅胶 （堵嘴硅胶损坏时适用）

直接用手扯下破损的堵嘴硅胶即可。（补移除后的图）

|  |  |

### 第 3 步 移除堵嘴支架 （堵嘴支架损坏时适用）

用 H1.5 内六角扳手，移除 2 颗螺丝，取下堵嘴组件 。

| --- | --- |
| 图 | 图 |

## 安装堵嘴组件

### 第 1 步 安装堵嘴硅胶到支架 （只更换堵嘴硅胶时适用）

对齐堵嘴硅胶上的引脚和支架的安装孔，放置堵嘴硅胶并下压，使引脚多向下延伸。

|  |  |
| --- | --- |
| 图 | 图 |

用手逐个拉扯硅胶引脚将引脚安装到位。

|  |
| --- |
| 图 |

### 第 2 步 安装堵嘴支架（组件）到挂架上 （更换支架时适用）

将新的堵嘴硅胶安装到支架上，然后再将支架安装到挂架上，锁入 2 颗螺丝固定。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 放置打印头

将打印头收回到打印机腔体内，先对齐橙色安装导向槽，然后顺着磁铁吸附到位，放置到挂架上。

|  |  |
| --- | --- |
| 图 | 图 |

## 功能验证

不影响打印头放置即可。
