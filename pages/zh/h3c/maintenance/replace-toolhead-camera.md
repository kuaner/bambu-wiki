## 工具头摄像头

工具头摄像头安装在工具头的左侧，可用于运动精度校准、高精度喷嘴偏移校准等功能。  
![452.jpeg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-camera/452.jpeg)

## 何时更换

- 工具头摄像头连接排线损坏
- 结构件损坏，影响固定
- 排线连接正常，但提示工具头摄像头关联报错

## 工具和材料

- H1.5 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-camera/zh/01__________2012_toollock_motor_replacement_guide_01457bbe50.jpg)

> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除工具头摄像头

### 第 1 步 松部件冷却风扇

请参考 WIKI ：[更换部件冷却风扇](replace-part-cooling-fan.md)，移除工具头后盖，移除固定部件冷却风扇的 3 颗螺丝，将部件冷却风扇从工具头上松出。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-camera/zh/43____________toolhead_camera_replacement_guide_40c4c639e0.jpg)

### 第 2 步 移除工具头摄像头

用手从工具头后侧凸出的位置向上掰，掰开工具头相机上盖并移除。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-camera/zh/43____________toolhead_camera_replacement_guide_847bb78851.jpg)

揭开连接器盖子将排线松出，用 H1.5 内六角扳手移除 2 颗螺丝，将工具头摄像头从工具头上移除，连接排线从过线孔上退出。

## 安装工具头摄像头

### 第 1 步 安装工具头摄像头

将工具头摄像头排线穿过过线孔，对应安装孔，将工具头摄像头（底座）预装到工具头上。

|  |  |
| --- | --- |
| 图 | 图 |

锁入 2 颗螺丝固定工具头摄像头，将排线连接到 TH 板上，合上盖子。

|  |  |
| --- | --- |
| 图 | 图 |

装回工具头摄像头上盖，上下按压，确保扣合到位。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 2 步 安装部件冷却风扇

请参考 WIKI ：[更换部件冷却风扇](replace-part-cooling-fan.md)，将部件冷却风扇装回原位，装好工具头后盖。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-camera/zh/43____________toolhead_camera_replacement_guide_322e1339fe.jpg)

## 功能验证

连接电源，启动打印机，没有工具头摄像头关联的报错信息即可。
