## XY 轴皮带张紧器

XY 张紧器安装在打印机背部，包含惰轮及其塑料底座、张紧弹簧，通过改变弹簧的压缩量实现 XY 皮带的张紧。  
![img_f86daf044686.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-belt-tensioner/zh/img_f86daf044686.jpg)

## 何时更换

张紧器惰轮异响，润滑后未能改善。

## 工具和材料

- H2.0 内六角扳手
- H1.5 内六角扳手

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> ![img_01457bbe50f0.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-belt-tensioner/zh/img_01457bbe50f0.jpg)

> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 拆装提示

> 1. 如果操作空间不足，可提前移除 AMS 3H，请参考 WIKI： [AMS 3H 拆除与安装指南](replace-ams3.md)，将 AMS 3H 从打印机上移除。
> 2. 左右两侧的XY轴皮带张紧器 在拆装操作上基本一致，只是位置有差异，本指南以左侧的XY轴皮带张紧器为例进行编写， 如果实际要更换的是右侧的 XY轴皮带张紧器，则请注意进行对位调整。

## 移除 XY 轴皮带张紧器

### 第 1 步 移除背板

请参考 WIKI：[背板更换指南](replace-back-panel.md)，断开电源线并将背板移除。

### 第 2 步 松出皮带

用 H2.0 内六角扳手按图中螺丝标识的顺序，移除 3 颗螺丝，将左侧 XY 皮带固定支架松出。

|  |  |
| --- | --- |
| img_8a033665262a.jpg | img_1f79bad44c7c.jpg |

用 H1.5 内六角扳手将皮带末端的两个压紧块均撬出，移除固定支架，从 X 电机一侧拉松出靠上方的皮带（左侧是拉扯出上方的皮带，右侧是拉扯下方的皮带），将皮带从 Y 滑车上移除。

|  |  |
| --- | --- |
| img_2314ee5ec558.jpg | img_d3071053ecb9.jpg |

### 第 3 步 移除惰轮组件

用 H2.0 内六角扳手，移除 2 颗螺丝；轻拉对应位置的同步皮带，可将整个惰轮组件扯出。

|  |  |
| --- | --- |
| img_9940424c849f.jpg | img_14980a260f4a.jpg |

### 第 4 步 移除张紧器

用 H2.0 内六角扳手移除 4 颗螺丝，移除黑色张紧器压片和银色弹簧压片。

|  |  |
| --- | --- |
| img_6ad1446f1b50.jpg | img_46069aaee323.jpg |

松出张紧器，取下张紧弹射，然后继续将皮带向后拉出，移除 XY 张紧器。

|  |  |
| --- | --- |
| img_a1cb727362e8.jpg | img_3f178e4ea46b.jpg |

## 安装 XY 轴皮带张紧器

### 第 1 步 安装张紧器

如图所示，将皮带穿过张紧器上的惰轮，然后穿过电机并伸到打印机腔内。

|  |  |
| --- | --- |
| img_a7e7e849a7e4.jpg | img_5e23bc7d8da5.jpg |

将张紧弹簧安装到张紧器上，并装入张紧器槽中，弹簧先进槽。

|  |  |
| --- | --- |
| img_675c155a5247.jpg | img_17793fb51b72.jpg |

安装张紧器压片，左侧张紧器的压片，缺口朝上进行安装，锁入 2 颗张紧器螺丝（细牙螺丝），不要锁紧；安装弹簧压片，方形定位缺口朝上，锁入 2 颗螺丝（粗牙）固定。

> 注意：另一侧的电机，压片的位置是刚好相反的。

|  |  |
| --- | --- |
| img_b95c848ff766.jpg | img_0cad8e366bc9.jpg |

用扳手推动张紧器压缩张紧弹簧，然后锁紧两颗张紧螺丝，使张紧器处于较极限的压缩状态。（这个操作是为了后面更容易安装 XY 皮带固定支架）

|  |  |
| --- | --- |
| img_6e875abd928d.jpg | img_6428326479b0.jpg |

### 第 2 步 安装惰轮组件

将皮带穿过惰轮安装区，并将拉扯到打印机背面的皮带全部拉回腔窒内，安装惰轮组件，锁入 2 颗螺丝固定。

|  |  |
| --- | --- |
| img_7be205bd08c0.jpg | img_5361965c2467.jpg |

### 第 3 步 安装皮带

将皮带直接穿过 Y 轴上的通孔，经前立柱惰轮后转向回来。

|  |  |
| --- | --- |
| img_be3f6acb2843.jpg | img_bbda532a9f40.jpg |

将皮带再次穿到 Y 滑车上，但需要折向工具头位置。 为了避免皮带两次直接穿过 Y 滑车，这里可以用另一根皮带先穿过 Y 滑车进行遮挡，并作为引导皮带辅助穿过。

|  |  |
| --- | --- |
| img_8a4f1a6ae36b.jpg | img_9fc205bbbfa6.jpg |

然后可以将皮带穿到固定支架上，并用压块压紧，压反向拉皮带可以使压块更好地压紧皮带。

|  |  |
| --- | --- |
| img_b37975677dc8.jpg | img_81527551f7a0.jpg |

将 XY 皮带固定支架安装到工具头上，用手压着固定支架，先锁中间位置的 1 颗螺丝，然后再锁上下 2 颗螺丝。

|  |  |
| --- | --- |
| img_fdeec0f0fd9f.jpg | img_0ab80a41add1.jpg |

### 第 4 步 张紧皮带

拧松**左右两个** XY 张紧器的螺丝，让张紧器自然张紧，前后移除工具头 2~ 3 次，然后重新锁紧张紧器螺丝，完成张紧 XY 皮带的操作。  
![img_39a23b3cc486.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-belt-tensioner/zh/img_39a23b3cc486.jpg)

### 第 5 步 安装背板 （检验后安装）

请参考 WIKI：[背板更换指南](replace-back-panel.md)，将背板及其他配件安装好。  
![img_2980526540f2.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-belt-tensioner/zh/img_2980526540f2.jpg)

## 功能验证

启动打印机，执行一次打印机校准，能正常完成即可。
