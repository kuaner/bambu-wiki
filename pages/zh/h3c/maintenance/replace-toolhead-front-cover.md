## 工具头外壳

工具头外壳由 4 个具体的部件构成，并设置了成了两个 SKU，其中工具头前盖包含了左前盖和右前盖，安装在工具头前面。工具头后盖包含了工具头顶盖和工具头后盖，分别安装在工具头的顶部和背面。

| --- | --- |
| 图 | 图 |

## 何时更换

- 工具头外壳出现运输损坏
- 工具头外壳在拆装过程中出现结构损伤

## 工具和材料

- H1.5 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除工具头外壳

### 第 1 步 移除工具头左前盖

用 H1.5 内六角扳手移除 2 颗螺丝。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-front-cover/zh/11_h3c_____screws_kit_for_h3c_79d20845a1.png)

轻微用力，将左前盖沿左侧扳松，然后取下左前盖。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-front-cover/zh/39___________tool_holder_replacement_guide_c128be8603.jpg)

### 第 2 步 移除工具头右前盖

用 H1.5 内六角扳手移除 2 颗螺丝。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-front-cover/zh/42_____________cutter_push_arm_assembly_replacement_guide_d821f1c5a5.jpg)

上下两端均轻微用力，向右侧推松右前盖，然后取下右前盖。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-front-cover/zh/42_____________cutter_push_arm_assembly_replacement_guide_3d55c7e69d.jpg)

### 第 3 步 移除工具头顶盖

用 H1.5 内六角扳手移除项部的 2 颗螺丝和打印头安装槽的 2 颗螺丝。

|  |  |
| --- | --- |
| 图 | 图 |

向上抠开上盖，并从拖链支架中较细的位置松出上盖。  
由于上盖四周皆有卡扣，建议先撬开一侧并晃动松开其他卡扣，再旋转避开拖链取出。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 4 步 移除工具头后盖

用 H1.5 内六角扳手移除背部的 2 颗螺丝。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-front-cover/zh/62__________________toolhead_front_cover_replacement_guide_9039d7cf85.jpg)

向后抠开并移除工具头后盖。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-front-cover/zh/62__________________toolhead_front_cover_replacement_guide_c742b57a7d.jpg)

## 安装工具头外壳

### 第 1 步 安装工具头后盖

对齐螺丝柱和螺丝孔，将后盖安装到工具头背部，按压后盖，将后盖安装到位。

|  |  |
| --- | --- |
| 图 | 图 |

锁入 2 颗螺丝固定。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-front-cover/zh/62__________________toolhead_front_cover_replacement_guide_9039d7cf85.jpg)

### 第 2 步 安装工具头顶盖

将顶盖缺口对着拖链支架较细小的位置进行安装，对齐位置后，向下按压顶盖，使顶盖扣合到位。

|  |  |
| --- | --- |
| 图 | 图 |

在顶部和打印头安装槽处各锁入 2 颗螺丝固定。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 安装工具头右前盖

根据右前盖的安装槽将右前盖安装到工具头右前侧，按压靠近 X 轴的位置确保安装到位。安装时可以先对齐框出来的特征位置，再往左整体推入对齐，确保无间隙。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-front-cover/zh/62__________________toolhead_front_cover_replacement_guide_2f7cbcc27b.jpg)

锁入 2 颗螺丝进行固定。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-front-cover/zh/42_____________cutter_push_arm_assembly_replacement_guide_d821f1c5a5.jpg)

### 第 4 步 安装工具头左前盖

将右前盖的孤形缺口对着 X 轴靠上一光轴进行安装，按压左前盖确保安装到位。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-front-cover/zh/39___________tool_holder_replacement_guide_385ec0253b.jpg)

锁入 2 颗螺丝进行固定。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toolhead-front-cover/zh/11_h3c_____screws_kit_for_h3c_79d20845a1.png)

## 功能验证

检查外壳间的间隙，确认无明显的浮起或错位即可。
