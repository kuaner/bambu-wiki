## 打印头切料组件

打印头切料组件由切料刀柄和切料刀片构成，配合工具头切料组件使用可完成自动切断耗材的操作。  
![img_45b2398f8ffb.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-filament-cutter-assembly/zh/img_45b2398f8ffb.jpg)

## 何时更换

1. 退料时耗材切割不完全，经检查是切料刀片磨损；
2. 切料刀柄出现结构损坏。

## 工具和材料

- H1.5 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除打印头切料组件

### 第 1 步 取出打印头组件

用手抓住左/右侧板扣手位，向外侧用力，可将左/右侧板从 AMS 支架上分离，取下左/右侧板。  
![img_e11bdfa442e6.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-filament-cutter-assembly/zh/img_e11bdfa442e6.jpg)

用手握住打印头组件的上部，斜向上提起，卸载打印头组件，并从 AMS 支架侧面伸出。  
![img_ed45d93eb1c7.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-filament-cutter-assembly/zh/img_ed45d93eb1c7.jpg)

### 第 2 步 移除切料组件

用 H1.5 内六角扳手移除 1 颗螺丝，注意移除螺丝时，保持轻按切料组件的状态，避免小配件弹出丢失。

|  |  |
| --- | --- |
| img_ace3cba6b0a5.jpg | img_d6d7af705359.jpg |

移除螺丝后，依次取出切料刀柄（上面有个小型扭簧，不要丢失）和切料刀片。

|  |  |
| --- | --- |
| img_056ceb434786.jpg | img_4a5ea888ad4d.jpg |

## 安装打印头切料组件

### 第 1 步 安装切料组件

将切料刀片安装到滑动槽内

|  |  |
| --- | --- |
| img_07ebda178ef0.jpg | img_48e185ed4102.jpg |

将扭簧安装到切料刀柄上，然后切料刀柄的卡口卡到切料刀片上。

|  |  |
| --- | --- |
| img_e07320712ea9.jpg | img_09c5555b54ad.jpg |

将切料刀柄压向打印头基座，对齐螺丝孔，用手将螺丝安装到螺丝孔上，确认螺丝穿过切料刀柄，然后再用扳手拧紧螺丝。

|  |  |
| --- | --- |
| img_2c624402d69e.jpg | img_88b92341eef6.jpg |

### 第 2 步 安装打印头组件

将打印头收回到打印机腔体内，先对齐橙色安装导向槽，然后顺着磁铁吸附到位，放置到挂架上。

|  |  |
| --- | --- |
| img_d2c06f628f88.jpg | img_2bc8c76d6194.jpg |

对齐左/右框架下方的安装槽，将左/右侧板贴向 AMS 支架，按压左/右侧板确认无浮起。  
![img_f822c69a32b3.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-filament-cutter-assembly/zh/img_f822c69a32b3.jpg)

手动测试，确认切料动作顺畅。
