## AMS 3H

AMS 3H 是独立包装的商品，由于在日常的产品维护或维修中，存在需要将 AMS 3H 从打印机顶部移除的场景，所以准备了这篇指引，旨在说明具体的操作步骤和注意事项。

## 何时使用

维护内容需要将 AMS 3H 从打印机顶部移除的场景。

## 工具和材料

- H1.5 内六角扳手

## 安全提示

> 重要提醒 ！  
> 在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。  
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ams3/zh/02_tpu___________ceramic_bypass_feed_replacement_guide_79620aa4b6.jpg)

> 拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次损伤。  
> 拆除部件前，请妥善保管拆除的固定螺丝，以免丢失。

## 拆除 AMS 3H

> 1. 注意：在移除 AMS 3H 前，请先执行退料操作，并取出舱内的所有料盘，料盘的自重会增加操作难度和损坏风险。

### 第 1 步 移除左右磁吸侧板

> 左/右侧板使用同样的磁吸方式进行固定，拆装方法一致。

用手抓住左/右侧板扣手位，向外侧用力，可将左/右侧板从 AMS 支架上分离，取下左/右侧板。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ams3/zh/04_____________filament_cutter_assembly_replacement_guide_e11bdfa442.jpg)

### 第 2 步 拆卸机身固定螺丝

使用 H1.5 内六角扳手依次拧下固定 AMS 3H 与打印机顶部的 4 颗固定螺丝，并妥善保管好螺丝。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 卸下打印头

手持打印头组件并轻轻向上提，使其脱离磁性吸附及橙色挂钩的位置，依次将闪切挂架泊位组件上的 9 个打印头组件卸下。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ams3/zh/04_____________filament_cutter_assembly_replacement_guide_ed45d93eb1.jpg)

### 第 4 步 分离 AMS 与打印机

将 AMS 3H 整体微幅抬起并向后平移约 20 mm，使其脱离定位孔对接状态。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ams3/zh/26_ams_3h__________c807d089b5.png)

将手伸入 AMS 右侧框架内，小心拔下连接在打印机顶部接口上的**打印头控制板线缆**与**腔体散热风扇线缆。**  
（注意按住卡扣平稳拔出，切勿强行拉拽线束）。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 5 步 放置 AMS 3H

将 AMS 3H 完全搬离打印机顶部，并平稳将其轻放至安全的平台上，注意保护好打印头组件，避免踩到。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ams3/zh/26_ams_3h__________8da6ed69c7.jpg)

## 安装 AMS 3H

### 第 1 步 将AMS 3H 放置到打印机顶部

将 AMS 3H （免装磁吸侧板）轻放于打印机顶部，AMS 背板略微超出打印机背板 20 mm, 便于连接线缆。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ams3/zh/26_ams_3h__________c807d089b5.png)

### 第 2 步 连接线缆

将手伸入 AMS 右侧框架内，分别将打印头控制板线缆与腔体散热风扇线缆准确插入打印机顶部的对应接口。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 固定 AMS 与打印机

将 AMS 3H 整体微幅抬起并向前平移，确保底部安装孔位对齐，将 AMS 3H 与打印机平稳对接。

|  |  |
| --- | --- |
| 图 | 图 |

使用 H1.5 内六角扳手，依次锁入 4 颗固定螺丝，将 AMS 3H 牢固安装在打印机顶部。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 4 步 放置打印头

依序将 9 个打印头安装至闪切挂架对应的泊位组件上。将打印头上的橙色定位框对齐泊位组件上的橙色挂钩，借助磁性吸力使打印头与泊位组件自动贴合吸附。

|  |  |
| --- | --- |
| 图 | 图 |

### 第5 步 安装左右磁吸侧板

对齐左/右框架下方的安装槽，将左/右侧板贴向 AMS 支架，按压左/右侧板将其安装到位，确认无浮起。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ams3/zh/04_____________filament_cutter_assembly_replacement_guide_f822c69a32.jpg)
