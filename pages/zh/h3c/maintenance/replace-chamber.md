## AMS 舱体 （非可更换配件）

AMS 舱体指的是 AMS 3H 的主体部分，非可更换配件。

## 何时使用

维护内容需要将 AMS 舱体移除的场景。

## 工具和材料

- H2.0 内六角扳手

## 安全提示

> **重要提醒 ！**
>
> 在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> ![001.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-chamber/zh/001.jpg)

> 拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次损伤。
>
> 拆除部件前，请妥善保管拆除的固定螺丝，以免丢失。

## 移除 AMS 舱体

> 注意：在移除或安装 AMS 舱体前，请先执行退料操作，并取出舱内的所有料盘。若未退料，残留的耗材可能在安装时被夹断或卡住，导致后续进退料困难；同时，料盘的自重也会增加操作难度。
>
> |  |  |
> | --- | --- |
> | 002.jpg | 003.jpg |

### 第 1 步 移除 AMS 左/右 侧板

> 左右侧板使用一样的磁吸方式进行固定，拆装方法一致。

用手把住侧板扣手位，向外用力，可将侧板从 AMS 上分离，取下侧板。

![004.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-chamber/zh/004.jpg)

### 第 2 步 移除 AMS 舱体

用 H2.0 内六角扳手移除左右两侧的固定螺丝，共 4 颗。

|  |  |
| --- | --- |
| 005.jpg | 006.jpg |

参照下图，扶着对角线的位置，向上搬起 AMS 舱体，将舱体与 AMS 框架分离。

> 注意：请从 AMS 舱体前后两端搬起，勿从左右两侧搬运，以免夹手。

![007.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-chamber/zh/007.jpg)

## 安装 AMS 舱体

### 第 1 步 安装 AMS 舱体

AMS 支架的四周及 AMS 舱体的四周均设置有一一对应的安装槽和舌片，如下图是靠前一侧的安装槽和舌片。

|  |  |
| --- | --- |
| 008.jpg | 009.jpg |

安装 AMS 舱体 时，用手前后抱起 AMS 舱体，先将舱体的前侧与支架安装到位，然后再放置后端。

![010.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-chamber/zh/010.jpg)

从左右两侧检查 AMS 舱体与 AMS 支架之间的间隙，确认无明显的偏差或浮起。如果一次性未能放置到位，请通过轻微偏移进行调节，直至安装到位，确保四周无缝隙、无翘起。

![011.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-chamber/zh/011.jpg)

锁入 4 颗螺丝固定。

|  |  |
| --- | --- |
| 012.jpg | 013.jpg |

### 第 2 步 安装 AMS 左/右侧板

先对齐侧板下方的安装槽，将侧板贴向 AMS 框架，按压侧板确认无浮起。

![014.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-chamber/zh/014.jpg)
