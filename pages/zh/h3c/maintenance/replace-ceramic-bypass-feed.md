## TPU 陶瓷版耗材直通口

陶瓷材质的 TPU 直通口。新的 AMS 3H 只标配 1 个陶瓷进料口，如有升级需求，可自行购买更换。

|  |  |
| --- | --- |
| img_728e454bfc73.jpg | img_bba863261eba.jpg |

> 重要提醒：  
> 升级更换 TPU 陶瓷进料口时，旧的进料口会被破坏性拆除，不可恢复。

## 何时更换

客户自行购买 TPU 陶瓷进料口进行升级

## 工具和材料

斜口钳

## 安全提示

> **重要提醒 ！**  
> 在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。  
> ![img_79620aa4b681.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ceramic-bypass-feed/zh/img_79620aa4b681.jpg)

> 拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次损伤。  
> 拆除部件前，请妥善保管拆除的固定螺丝，以免丢失。

## 拆装提示

> 本指南是在将 AMS 3H 舱体从支架上移除后的情况操作的，。

## 升级更换 TPU 陶瓷进料口

### 第 1 步 移除 AMS 舱体

请参考WIKI: [AMS 3H 舱体拆装指南](replace-chamber.md)，将 AMS 舱体从AMS 支架上移除。

> 注意：在移除或安装 AMS 舱体前，请先执行退料操作，并取出舱内的所有料盘。若未退料，残留的耗材可能在安装时被夹断或卡住，导致后续进退料困难；同时，料盘的自重也会增加操作难度。
>
> |  |  |
> | --- | --- |
> | img_b72adfdb39c1.jpg | img_79e538c4e76f.jpg |

### 第 2 步 移除装饰盖 （可跳过）

将 AMS 舱体底面朝上放置到平整的台面上，注意提前铺设柔软的缓冲物，避免 AMS 上盖在操作过程中出现划伤。  
一个有 6 个位置的 TPU 进料口可以更换成 陶瓷进料口，其中蓝色圈的 TPU 进料口可以直接移除，橙色圈的TPU 进料口需要先移除装饰盖（用 H1.5 内六角扳手拆除 4颗螺丝，即可移除）

|  |  |
| --- | --- |
| img_453891488320.jpg | img_2fd50e7a4f34.jpg |

### 第 3 步 移除普通版 TPU 进料口

使用斜口钳在较高的柱位上切断 TPU 进料口。

|  |  |
| --- | --- |
| img_f381a122830e.jpg | img_963038c5a52e.jpg |

被切断的TPU 进料口会跌落到 AMS 舱体内，请在下一步里找到它并取出来。

|  |  |
| --- | --- |
| img_50c13477433a.jpg | img_9dc26da5792b.jpg |

### 第 4步 安装 TPU 陶瓷进料口

翻转 AMS 舱体并打开 AMS 上盖，并使用撑杆固定。  
![img_33873ba285db.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ceramic-bypass-feed/zh/img_33873ba285db.jpg)

将 TPU 陶瓷进料口放置到已缺少进料口的位置，然后向下按压TPU 陶瓷进料口，会听到清脆的到位声，说明安装成功。
