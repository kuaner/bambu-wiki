## 喷嘴偏移校准传感器

喷嘴偏移校准传感器安装在热床的后方，用于对不同打印头的位置进行校准，保证良好的打印质量。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-nozzle-offset-calibration-sensor/zh/25_______________nozzle_offset_calibration_sensor_replacement_guide_c07de0d703.jpg)

## 何时更换

- 喷嘴的定位出现偏移，导致打印时模型出现错位、层移，并且通过喷嘴偏移校准也无法恢复。
- 结构件损坏，导致校准失败；
- 经 Bambu Lab 官方技术支持确认需更换喷嘴偏移校准传感器。

## 工具和材料

- H2.0 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-nozzle-offset-calibration-sensor/zh/01__________2012_toollock_motor_replacement_guide_01457bbe50.jpg)

> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除喷嘴偏移校准传感器

### 第 1 步 抬升热床 （非必须，只是方便操作）

执行一次回零操作，使热床抬升到较靠上部的位置，然后关闭打印机电源。  
用手移动工具头，将工具头移动到吐料组件位置，移除打印面板（如有）。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-nozzle-offset-calibration-sensor/zh/25_______________nozzle_offset_calibration_sensor_replacement_guide_234fd8b224.jpg)

### 第 2 步 移除螺丝

用 H2.0 内六角扳手移除 2 颗螺丝，并取下右侧位置的擦嘴钢片。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 移除喷嘴偏移校准传感器

小幅度拿起喷嘴偏移校准传感器，并进行翻转，露出连接器位置。用扳手按压插头卡扣进行解锁，移除喷嘴偏移校准传感器。

|  |  |
| --- | --- |
| 图 | 图 |

## 安装喷嘴偏移校准传感器

### 第 1 步 连接喷嘴偏移校准传感器

如图所示将连接器朝向热床，连接线缆，此时，插头卡扣朝下。然后翻转喷嘴偏移校准传感器，将其安装到支架上。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 2 步 锁螺丝

先锁左侧螺丝，然后在右侧安装擦嘴钢片，再锁右侧螺丝。

|  |  |
| --- | --- |
| 图 | 图 |

## 功能验证

启动打印机，放置打印板，执行一次喷嘴偏移校准操作，校准结果通过即可。
