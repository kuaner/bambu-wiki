## 介绍

XY 轴的传动总共包含 12 个惰轮，而惰轮内的轴承可能因为润滑不足，导致工具头移动过程中出现异响，本文将介绍如何进行维护。

## 所需工具

- H2.0 内六角扳手
- 清洁湿巾
- 润滑油
- [针头打印件](https://makerworld.com.cn/zh/models/1730129-xiao-shui-run-hua-you-di-cheng-ben-zhen-tou?from=search#profileId-1906070)

## 安全提示

## 维护步骤

首先降低热床到合适位置并上升挂架高度，以便于后续操作。

![bedmovezh.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/idle-gear/zh/bedmovezh.jpg)

### X 轴组件

先检查惰轮表面是否有脏污，若存在脏污，可使用清洁湿巾仔细擦除。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/idle-gear/zh/06_h3c_xy_________dfcf4a2f07.png)

再向惰轮上挤入适量润滑油。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/idle-gear/zh/06_h3c_xy_________71621f3214.png)

下侧和右侧惰轮也是相同的操作。

|  |  |
| --- | --- |
| 图 | 图 |

### 打印机前侧

取下 AMS 的磁吸侧盖。

|  |  |
| --- | --- |
| 图 | 图 |

打印机前侧总共 2 个惰轮，确保表面没有污渍后，可在惰轮上挤入适量润滑油。

|  |  |
| --- | --- |
| 图 | 图 |

### 打印机后侧

拧松惰轮支架的固定螺丝。

|  |  |
| --- | --- |
| 图 | 图 |

取出惰轮。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/idle-gear/zh/06_h3c_xy_________e3ec2489ed.png)

检查惰轮表面是否存在脏污，并使用清洁湿巾擦拭。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/idle-gear/zh/06_h3c_xy_________ab5d6be0e3.png)

在轴承上挤入适量润滑油后，装回设备。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/idle-gear/zh/06_h3c_xy_________22afab56d7.png)

张紧位置的两个惰轮需先[拆除背板](replace-back-panel.md)，再向惰轮上侧挤入适量润滑油。

|  |  |
| --- | --- |
| 图 | 图 |

完成以上工作后，推拉工具头左右滑动，更有利于润滑油进入轴承中。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/idle-gear/zh/06_h3c_xy_________6b270552b7.png)
