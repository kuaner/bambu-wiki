## 泊位组件

安装在闪切挂架上，用于放置闲置打印头的组件。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-dock-assembly/zh/07__________dock_assembly_replacement_guide_aecdc3ad1d.jpg)

## 何时更换

出现结构损坏或磁铁脱落，影响打印头的固定或检测。

## 工具和材料

- H1.5 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-dock-assembly/zh/01__________2012_toollock_motor_replacement_guide_01457bbe50.jpg)

> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除泊位组件

### 第 1 步 移除打印头

用手握住打印头组件的上部，斜向上提起，卸载对应位置的打印头组件。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-dock-assembly/zh/04_____________filament_cutter_assembly_replacement_guide_ed45d93eb1.jpg)

### 第 2 步 移除泊位组件

用 H1.5 内六角扳手，移除 3 颗螺丝，然后从腔体内侧，取下泊位组件。

|  |  |
| --- | --- |
| 图 | 图 |

## 安装泊位组件

### 第 1 步 安装泊位组件

从腔体内侧，将泊位组件安装到闪切挂架上，对齐螺丝孔后，从框架前面锁入 3 颗螺丝进行固定。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 2 步 放置打印头

将打印头收回到打印机腔体内，先对齐橙色安装导向槽，然后顺着磁铁吸附到位，放置到挂架上。

|  |  |
| --- | --- |
| 图 | 图 |

## 功能验证

启动打印机，执行一次挂架对位校准，能正常完成却可。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-dock-assembly/zh/07__________dock_assembly_replacement_guide_d660e36ef0.jpg)
