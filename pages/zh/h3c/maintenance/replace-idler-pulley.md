## 惰轮组件

本指南所述惰轮组件，是指 XY 同步皮带路径上使用的 12 个较容易更换的惰轮：

1. 安装在打印机后立柱两侧的惰轮组件，共 8 个；

|  |  |
| --- | --- |
| 图 | 图 |

2. 安装在打印机前立柱两侧的惰轮组件，共 2 个；  
   ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-idler-pulley/zh/17__________idler_pulley_replacement_guide_aa805d23c2.jpg)
3. 安装在左侧 Y 滑车上的惰轮组件，共 4 个（ 靠上的 2 个 适用本指南，靠下的 2 个只能在将 X 轴组件拆下后再处理。 ）

|  |  |
| --- | --- |
| 图 | 图 |

## 何时更换

- 惰轮异响
- 惰轮脏污或变形，且不可恢复。

> 温馨提示：由于更换左右两侧的惰轮在操作上完全类似，本指南以更换左侧惰轮为例进行说明。

## 工具和材料

- H2.0 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除惰轮组件 （后）

用 H2.0 内六角扳手，移除 2 颗螺丝；轻拉对应位置的同步皮带，可将整个惰轮组件扯出。

|  |  |
| --- | --- |
| 图 | 图 |

## 安惰轮组件 （后）

将惰轮轴穿过惰轮，并安装到惰轮支架上；将惰轮组件安装到空位上，用手压紧并锁入 2 颗螺丝固定。

|  |  |
| --- | --- |
| 图 | 图 |

## 移除惰轮组件 （前）

> 1. 位于前方的 2 个惰轮组件，被闪切挂架遮挡住，如果需要更换，请参考 WIKI ：[闪切挂架更换指南](replace-swaptek-rack.md)，闪切挂架的拆卸与安装（更换惰轮组件后）
> 2. 请根据要更换的惰轮位置，移除同侧的 XY 皮带固定支架。

用 H2.0 内六角扳手按图中螺丝标识的顺序，移除 3 颗螺丝，将 XY 皮带固定支架松出。

用扳手轻撬惰轮连着同步皮带一起松出惰轮槽，移除惰轮。

## 安装惰轮组件 （前）

将惰轮轴穿过惰轮，放置到 XY 同步皮带转向处，然后一起放入惰轮槽中。

|  |  |
| --- | --- |
| 图 | 图 |

检查惰轮支架的方向，有高遮挡的一侧朝前门的方向，安装到惰轮位置，锁入 2 颗螺丝进行固定。

|  |  |
| --- | --- |
| 图 | 图 |

将 XY 皮带固定支架安装到工具头上，用手压着固定支架，先锁中间位置的 1 颗螺丝，然后再锁上下 2 颗螺丝。

|  |  |
| --- | --- |
| 图 | 图 |

## 移除惰轮组件 （Y 滑车）

用 H2.0 内六角扳手按图中螺丝标识的顺序，移除 3 颗螺丝，将 XY 皮带固定支架松出。

|  |  |
| --- | --- |
| 图 | 图 |

用 H2.0 内六角扳手拧出惰轮螺丝轴，轻拉皮带，移除惰轮。

|  |  |
| --- | --- |
| 图 | 图 |

## 安装惰轮组件 （Y 滑车）

将惰轮放置到 Y 滑车上，注意 XY 同步皮带是被惰轮压在后面的，放入惰轮螺丝轴，用手微调惰轮的位置，使惰轮螺丝轴能完全通过惰轮并进入下面的螺纹孔，锁紧螺丝轴。

|  |  |
| --- | --- |
| 图 | 图 |

将 XY 皮带固定支架安装到工具头上，用手压着固定支架，先锁中间位置的 1 颗螺丝，然后再锁上下 2 颗螺丝。

|  |  |
| --- | --- |
