## 锁紧组件

由锁紧插销、锁紧弹片构成。在锁紧电机的驱动下，实现工具的定位与锁紧，保障工作过程中工具位置的稳定。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toollock-assembly/zh/74__________toollock_assembly_replacement_guide_06085e65df.jpg)

## 何时更换

结构件磨损且影响产品使用时。

## 工具和材料

- H1.5 内六角扳手
- H2.0 内六角扳手
- 专用套筒

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toollock-assembly/zh/01__________2012_toollock_motor_replacement_guide_01457bbe50.jpg)

> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除锁紧组件

### 第 1 步 移除工具头前盖

请参考 WIKI：[工具头外壳更换指南](replace-toolhead-front-cover.md)， 移除工具头前盖。

### 第 2 步 松开热端风扇和线圈连接线

用 H1.5 内六角扳手，移除 2 颗螺丝，将热端风扇向右松出。

|  |  |
| --- | --- |
| 图 | 图 |

将涡流线圈的线缆从从动轮下方的卡扣中松出并尽量远离银色螺丝，避免拆装过程损坏。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 移除锁紧组件

用 H1.5 内六角扳手移除 1 颗银色螺丝，用 H2.0 内六角扳手移除 1 颗黑色螺丝，将专用套筒安装到 H2.0 内六角扳手上。

|  |  |
| --- | --- |
| 图 | 图 |

通过专用套筒顺时针拧动锁紧电机的转轴，将锁紧插销将向左退出，然后用手将其拔下。

|  |  |
| --- | --- |
| 图 | 图 |

用 H1.5 内六角扳手移除黑色螺丝，用手取下锁紧弹片。

|  |  |
| --- | --- |
| 图 | 图 |

## 安装锁紧组件

### 第 1 步 安装锁紧组件

将锁紧弹片安装到工具定位槽上方，锁入 1 颗黑色螺丝（长螺丝）固定。

|  |  |
| --- | --- |
| 图 | 图 |

安装新的锁紧插销前，需要在插销上涂布专用的润滑脂，然后安装到插槽上，更具体的操作请参考 WIKI：[拓竹H3C 打印机定期维护](periodic-maintenance.md) 。

|  |  |
| --- | --- |
| 图 | 图 |
| 图 |

沿着插销槽安装锁紧插销，用手抵住插销，然后通过专用套筒逆时针拧动锁紧电机的转轴，锁紧插销将继续向右侧移动。

|  |  |
| --- | --- |
| 图 | 图 |

待插销左侧的螺丝孔完全露出后，锁入 1 颗银色螺丝 和 1 颗黑色螺丝将锁紧组件完全固定。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 2 步 整理线缆，锁紧热端风扇

将拆装过程中松出的线圈线缆整理进从动轮的卡扣中，装好热端风扇并锁上 2 颗螺丝固定。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 安装工具头前盖

请参考 WIKI：[工具头外壳更换指南](replace-toolhead-front-cover.md)， 安装工具头前盖。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-toollock-assembly/zh/40__________2012_flexfeed_motor_replacement_guide_5494848a85.jpg)

## 功能验证

连接电源，启动打印机，执行一次加载打印头的操作，能正常完成即可。
