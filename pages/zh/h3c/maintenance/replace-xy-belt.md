## XY 轴皮带

安装在 H3C 打印机上的开口同步皮带，一共有两条，它们将 X/Y 电机和工具头连接起来并驱动工具头在 X/Y 方向的移动。

## 何时更换

- XY 轴皮带使用磨损，影响打印质量
- XY 轴皮带断裂。

## 工具和材料

1. H2.0 内六角扳手
2. 瞬干胶 （如 502）

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 更换 XY 轴皮带

### 第 1 步 松出皮带固定支架

用 H2.0 内六角扳手按图中螺丝标识的顺序，移除 3 颗螺丝，将 XY 皮带固定支架松出。（另一侧同样的操作）

|  |  |
| --- | --- |
| img_5b717d9ca588.jpg | img_406982b9226f.jpg |

### 第 2 步 松出皮带

用力按箭头方向推动皮带，可将皮带压紧块松出。

|  |  |
| --- | --- |
| img_b2709758a390.jpg | img_33f4821151af.jpg |

移除压紧块，将皮带从固定支架中松出。同样的操作，将另一侧对应位置的皮带也从固定支架中松出。

|  |  |
| --- | --- |
| img_e3edae438bda.jpg | img_51a6e6ca8d60.jpg |

> 温馨提示：如果压紧块安装比较牢固，可使用 H1.5 内六角扳手将皮带压紧块撬出。  
> ![img_2314ee5ec558.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-belt/zh/img_2314ee5ec558.jpg)

### 第 3 步 粘接皮带

在旧皮带的齿面涂布少量瞬干胶，控制涂布面在 2~3 个齿范围内。

|  |  |
| --- | --- |
| img_e1f3b009b87e.jpg | img_a44862afb351.jpg |

将新皮带的背面贴到涂布瞬干胶的位置，保持 约 5 秒钟，然后尝试拉扯两条皮带，确认皮带能受住正常的拉扯不分开。（注：如果断开了，请重新点上瞬水，延长连接保持的时间。）

|  |  |
| --- | --- |
| img_cbbde5186cb9.jpg | img_15e27eff7909.jpg |

### 第 4 步 穿引皮带

从旧皮带的另一侧拉皮带，将新皮带按牵引过去，覆盖旧皮带，直到能看到两条皮带的连接点出现。

|  |  |
| --- | --- |
| img_2bbc384a2b02.jpg | img_d8cdb85a8e57.jpg |

用手在连接位置将两条皮带前后掰开，移除旧皮带，新皮带将旧皮带完全替换掉。

|  |  |
| --- | --- |
| img_843507bca076.jpg | img_9beed4639fec.jpg |

如果需要更换另一条旧皮带，可以重复第 2 步~第 4 步的操作。

### 第 5 步 固定皮带

将新皮带穿过皮带固定支架，在末端装上皮带压紧块。

|  |  |
| --- | --- |
| img_6632236e8601.jpg | img_a179d3777a0c.jpg |

将皮带拉紧，使压紧块固定。同样的操作将皮带另一端也固定到支架上。

|  |  |
| --- | --- |
| img_b1deeb9d38ed.jpg | img_5956f033693d.jpg |

### 第 6 步 安装皮带固定支架

将皮带固定支架安装到工具头两侧，按序号依次锁紧两侧的螺丝。

|  |  |
| --- | --- |
| img_9fdd4ae58481.jpg | img_a3b39c6e6776.jpg |

### 第 7 步 张紧皮带

拧松**左右两个** XY 张紧器的螺丝 ，让张紧器自然张紧，前后移除工具头 2~ 3 次，然后重新锁紧张紧器螺丝。  
![img_3a39b1827476.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-belt/zh/img_3a39b1827476.jpg)

## 功能验证

连接电源并打开打印机，执行一次振动补偿校准，能正常能通过即可。  
![img_53bf70c222ee.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-belt/zh/img_53bf70c222ee.jpg)
