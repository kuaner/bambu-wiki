## 介绍

定期润滑 XY 光轴、Z 光轴和丝杆可降低摩擦和磨损，提升运动平稳度和打印精度，同时延长机器使用寿命。

## 所需工具

- 润滑油
- 润滑脂
- 清洁湿巾

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 维护操作

### X 轴

取下 AMS 的磁吸侧盖。

|  |  |
| --- | --- |
| 图 | 图 |

使用清洁湿巾擦拭 X 轴光轴，清理旧润滑油以及灰尘、碎屑。

|  |  |
| --- | --- |
| 图 | 图 |

在 X 轴光轴上沿一定距离滴上一滴润滑油。

|  |  |
| --- | --- |
| 图 | 图 |

XY 光轴上请勿使用润滑脂。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/lubricate-x-y-z-axis/zh/05_h3c_xyz_______004def544c.png)

来回拉动工具头确保充分润滑。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/lubricate-x-y-z-axis/zh/05_h3c_xyz_______622ac7727c.webp)

若润滑油涂抹过多，可使用湿巾轻轻擦除部分。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/lubricate-x-y-z-axis/zh/05_h3c_xyz_______dbf3565626.png)

### Y 轴

使用清洁湿巾擦拭 Y 轴光轴，清理旧润滑油以及灰尘、碎屑。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/lubricate-x-y-z-axis/zh/05_h3c_xyz_______ceed2ce029.png)

在 Y 轴光轴上沿一定距离滴上一滴润滑油。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/lubricate-x-y-z-axis/zh/05_h3c_xyz_______c605826405.png)

前后拉动工具头确保充分润滑。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/lubricate-x-y-z-axis/zh/05_h3c_xyz_______8f6dcb43f0.webp)

若润滑油涂抹过多，可使用湿巾轻轻擦除部分。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/lubricate-x-y-z-axis/zh/05_h3c_xyz_______885fe16f32.png)

### Z 轴

使用清洁湿巾擦拭 Z 轴丝杆，清理旧润滑油以及灰尘、碎屑。

|  |  |
| --- | --- |
| 图 | 图 |

在 Z 轴丝杆上沿一定距离挤上一小团润滑脂。

> 注：三根丝杆均需润滑。

![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/lubricate-x-y-z-axis/zh/05_h3c_xyz_______ac5ea2568b.png)

再使用清洁湿巾擦拭 Z 轴光轴。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/lubricate-x-y-z-axis/zh/05_h3c_xyz_______d2ed115105.png)

在光轴上挤入少量润滑油。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/lubricate-x-y-z-axis/zh/05_h3c_xyz_______1e61826bbb.png)

完成后续校准，确保丝杆充分润滑。

### 校准

在屏幕上点击“校准-打印校准-振动补偿”，开始校准。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/lubricate-x-y-z-axis/zh/05_h3c_xyz_______de2c46dc5e.png)
