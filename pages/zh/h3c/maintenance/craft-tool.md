## 安全提醒

> 刀头十分锋利，进行维护、清理或更换时，请小心操作，避免手指直接触碰刀头导致划伤。  
> 维护前请确认设备已停止运行，平面加工头处于安全位置。

## 维护方法

为了延长平面加工头的使用寿命，保持其最佳工作状态，定期维护至关重要。  
应定期检查平面加工头及各组件的安装状态，及时清理刀头附近的耗材碎屑，并关注垫板粘性、刀头笔头磨损情况。

## 维护频次

| 维护项目 | 建议频次 | 说明 |
| --- | --- | --- |
| 平面加工头安装检查 | 每次安装后 | 确认在工具头上安装到位，无晃动 |
| 刀座 / 笔座安装检查 | 初次安装，每次安装或切换刀座 / 笔座后 | 确认螺纹拧紧，安装稳固 |
| 刀头附近碎屑清理 | 每次加工任务后 | 简单检查并清理可见碎屑 |
| 垫板粘性检查 | 每次加工任务前 | 确认耗材可牢固固定；粘性不足时及时更换粘板 |
| 刀头磨损检查与更换 | 视使用情况定期检查 | 刀切质量下降、边缘毛糙时更换 |
| 笔头磨损检查与更换 | 视使用情况定期检查 | 笔头明显磨损，绘画边缘不清晰时更换 |

## 所需工具

- 刷子
- 取刀器
- 钩针
- 替换笔头推杆

## 维护步骤

### 检查刀座和笔座安装状态

确认刀座和笔座在平面加工头基座上安装到位，螺纹已拧紧。

**刀座：**

1. 确认刀座已正确安装在平面加工头基座上。
2. 检查安装螺纹是否拧紧，刀座无松动。  
   ![](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/craft-tool/zh/08______________________0392154942.png)

**笔座：**

1. 确认笔座已正确安装在平面加工头基座上。
2. 检查安装螺纹是否拧紧，笔座上下无松动间隙。  
   ![](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/craft-tool/zh/08______________________9e7e18c12c.png)

### 清理刀头附近碎屑

定期检查刀头附近是否有耗材碎屑残留。如有，请及时清理，避免碎屑堆积阻碍刀头旋转。

1. 在设备停止运行后，观察刀头周围及刀座内部是否有碎屑堆积。  
   ![](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/craft-tool/zh/08______________________85fd4e05a4.png)
2. 使用刷子清理刀头、刀座周围的碎屑。  
   ![](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/craft-tool/zh/08______________________939155d606.gif)

### 检查垫板粘性

定期检查垫板的粘性，必要时进行更换，确保能够牢固固定耗材。

1. 检查垫板表面是否有明显灰尘、纸屑或油污。
2. 将测试耗材（或边角料）贴附在垫板表面，确认粘附牢固、不易脱落。  
   ![](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/craft-tool/zh/08______________________c8bcf604d8.png)
3. 不使用时，将透明保护膜贴回粘性面，防止垫板过早失去粘性。  
   ![](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/craft-tool/zh/08______________________17cc78afc2.png)

**粘性不足时的处理：**

- 使用钩针等工具清除垫板表面的材料残留和杂物。  
  ![](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/craft-tool/zh/08______________________bd4fcb0dc7.gif)
- 若清洁后粘性仍不足，请更换刀切粘板，可参考 wiki：[更换刀切粘板](../../h2d/maintenance/replace-the-cutting-mat.md)。

### 检查刀头

随着使用时间增加，刀头会出现磨损，导致刀切质量下降。为保证刀切质量，请定期更换刀头。  
**建议检查以下迹象：**

- 切割边缘毛糙、不易断开
- 刀头外观有明显磨损或卷刃  
  ![](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/craft-tool/zh/08______________________26ac5988e7.png)

**更换步骤：**

1. 在设备停止运行后，使用取刀器取下旧刀头。  
   ![](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/craft-tool/zh/08______________________62867bae4e.gif)
2. 安装时使用取刀器夹住新刀头，送入刀座中，确认刀头安装到位，可正常旋转。

> 不同耗材对刀头的磨损程度不同。加工较厚、较硬的材料时，建议提高刀头检查频率。

### 检查笔头

随着使用，墨水会逐渐减少，笔头也会磨损，可能导致可书写距离变短、线条变粗。为保证绘画质量，请注意：

- 每次使用结束后及时盖上笔盖，防止笔尖变干  
  ![](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/craft-tool/zh/08______________________72b1aded2a.png)
- 定期补墨，并按需更换笔头。补墨的详细操作请参阅[补墨套装使用流程](../manual/marker-refill-guide.md)。

### 检查平面加工头安装状态

确认平面加工头已正确安装在工具头上，连  
接稳固，无松动或异常晃动。

1. 从屏幕上取用平面加工头。

|  |  |
| --- | --- |
|  |  |

2. 轻轻晃动平面加工头，确认取用后无松动感。  
   ![](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/craft-tool/zh/08______________________1c713813e4.gif)
