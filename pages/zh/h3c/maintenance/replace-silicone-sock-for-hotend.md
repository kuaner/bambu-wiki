## 热端硅胶套

热端硅胶套（如图 序号1 所示）是安装在热端喷嘴尖端的硅胶制品，用于保证喷嘴温度的稳定。  
喉管位置也配备有喉管硅胶套（如图 序号 2 所示），正常使用情况下，一般不容易损坏，避免无故障拆装喉管硅胶套。  
![img_2968717ad868.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-silicone-sock-for-hotend/zh/img_2968717ad868.jpg)

## 何时更换

- 热端硅胶套破损/脏污。
- 热端硅胶套松动。

## 工具和材料

无

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

> 拆装提示：
>
> 1. 拆装热端硅胶套前，应主动通过打印机的显示屏确认热端的温度在 50℃ 以下，或已闲置超过 5 分钟；
> 2. 如果硅胶套被耗材粘附，不能在常温下移除，可通过打印机对热端进行加热，然后戴隔热手套操作，移除热端硅胶套。

## 移除热端硅胶套

### 第 1 步 取出打印头组件

用手抓住左/右侧板扣手位，向外侧用力，可将左/右侧板从 AMS 支架上分离，取下左/右侧板。  
![img_e11bdfa442e6.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-silicone-sock-for-hotend/zh/img_e11bdfa442e6.jpg)

用手握住打印头组件的上部，斜向上提起，卸载打印头组件，并从 AMS 支架侧面伸出。  
![img_ed45d93eb1c7.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-silicone-sock-for-hotend/zh/img_ed45d93eb1c7.jpg)

### 第 2 步 移除热端硅胶套

用手反复捏一圈热端硅胶套，使其松动；然后斜向用力掰开热端硅胶套，将热端硅胶套从热端上分离出来。

|  |  |
| --- | --- |
| img_c0ecd1d5caf0.jpg | img_aaa19550541d.jpg |

### 第 3 步 移除喉管硅胶套 （如无异常，不要主动拆除，容易损坏内部器件）

用手压着热端喉管硅胶套的左右两侧，用力将喉管硅胶套往喷嘴方向推出。

|  |  |
| --- | --- |
| img_81537b3b66f5.jpg | img_750b6b61eb53.jpg |

喉管硅胶套松出 3~5 mm 时，停顿检查另一面，确认上面的线缆没有被一起拉扯出来，然后继续向外（喷嘴）方向将喉管硅胶套完全松出。

|  |  |
| --- | --- |
| img_a4ad0a501534.jpg | img_d9a8e9817615.jpg |

## 安装热端硅胶套

### 第 1 步 安装喉管硅胶套

将喉管硅胶套 的缺口位对齐热端加热片的线缆（白色），然后用力向热端散热片方向推，装入喉管硅胶套。

|  |  |
| --- | --- |
| img_b116231fd1b1.jpg | img_dbf5e34a165b.jpg |

换到另一面，检查安装位置，对位置进行微调，确认喉管硅胶套安装到位。

|  |  |
| --- | --- |
| img_91f66da50738.jpg | img_d42f4ba3fd10.jpg |

### 第 2 步 安装热端硅胶套

将热端硅胶套的圆孔与喷嘴对齐，使喷嘴能穿过热端硅胶套，然后旋转热端硅胶套并向热端散热片方向用力，可以将热端硅胶套安装到位。

|  |  |
| --- | --- |
| img_d3f99655d217.jpg | img_999c376c79ec.jpg |

### 第 3 步 安装打印头组件

将打印头收回到打印机腔体内，先对齐橙色安装导向槽，然后顺着磁铁吸附到位，放置到挂架上。

|  |  |
| --- | --- |
| img_d2c06f628f88.jpg | img_2bc8c76d6194.jpg |

对齐左/右框架下方的安装槽，将左/右侧板贴向 AMS 支架，按压左/右侧板确认无浮起。  
![img_f822c69a32b3.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-silicone-sock-for-hotend/zh/img_f822c69a32b3.jpg)

## 功能验证

检查硅胶套外观，无倾斜或明显的浮起即可。  
![img_2968717ad868.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-silicone-sock-for-hotend/zh/img_2968717ad868.jpg)
