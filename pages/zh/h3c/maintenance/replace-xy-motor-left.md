## XY电机

XY 电机是安装在打印机背部，用于驱动工具头完成 X/Y 方向移动的步进电机。由于线缆的长度不同，我们用左右进行区分，面向打印机，左边的是XY电机-左，右边是XY电机-右。

|  |  |
| --- | --- |
| 图 | 图 |

## 何时更换

- 电机不转
- 电机异响
- 电机异味
- 经 Bambu Lab 技术支持确认需要更换电机

## 工具和材料

- H2.0 内六角扳手
- H2.0 内六角扳手 (XY 电机专用）

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-motor-left/zh/01__________2012_toollock_motor_replacement_guide_01457bbe50.jpg)

> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 拆装提示

> 1. XY 电机的锁定螺丝需要通过打印机框架上的通孔进行拆除，需要提前移除 AMS 3H，请参考 WIKI： [AMS 3H 拆除与安装指南](replace-ams3.md)，将 AMS 3H 从打印机上移除和重新安装，本指南的操作均在已移除 AMS 3H 的场景下进行。
> 2. XY 电机-左 和 XY 电机- 右 在拆装操作上基本一致，只是位置有差异，本指引以XY 电机-左为例进行编写， XY 电机- 右 也能参考。
> 3. 拆装 XY 电机的螺丝时，请提前给扳手上磁，避免螺丝跌落；拆除 XY 电机-右 时，需要使用配件赠送的专用 H2.0 内六角扳手。  
>    ![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-motor-left/zh/22_xy__________xy_motor_left_replacement_guide_077ce8c4d5.jpg)

## 移除 XY 电机-左

### 第 1 步 移除背板

请参考 WIKI：[背板更换指南](replace-back-panel.md)，移除背板。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-motor-left/zh/22_xy__________xy_motor_left_replacement_guide_b9e68804f7.jpg)

### 第 2 步 松皮带固定支架

注意：现在要拆装的是 XY 电机-左，需要拆装左侧的皮带固定支架。如果你需要更换的是 XY 电机-右，则请拆除右侧的固定支架。  
用 H2.0 内六角扳手按图中螺丝标识的顺序，移除 3 颗螺丝，将 XY 皮带固定支架松出。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 松张紧器

用 H2.0 内六角扳手移除 4 颗螺丝，移除黑色张紧器压片和银色弹簧压片。

|  |  |
| --- | --- |
| 图 | 图 |

松出张紧器，并取下张紧弹簧。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 4 步 断开电机线缆

将 蓝色 XY 电机插头从 MC 板上拨除，沿着布线路径将线缆从各卡扣上松出，打开线缆磁环的卡扣，移除磁环。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 5 步 移除 XY 电机-左

用内六角扳手沿着电机螺丝的位置向上穿过 XY 框架通孔，捅破顶上的泡棉，用磁铁给专用H2.0 内六角扳手加磁。

|  |  |
| --- | --- |
| 图 | 图 |

然后将扳手从上向下穿过框架通孔，移除后侧锁定电机的 2 颗螺丝。注意：这 2 颗螺丝拧出来后，需要及时用手取下，避免掉落。

|  |  |
| --- | --- |
| 图 | 图 |

用内六角扳手移除位于前侧的 2 颗螺丝，然后向腔内方向移除 XY 电机-左。

|  |  |
| --- | --- |
| 图 | 图 |

## 安装 XY 电机-左

### 第 1 步 安装 XY 电机-左

将电机线缆插头穿过过线孔，然后安装 XY 电机，注意 XY 皮带需要在电机的主动轮的内侧。

|  |  |
| --- | --- |
| 图 | 图 |

用手扶着电机，先预锁内侧的 1 颗螺丝，不要锁紧，然后按下图标识的序号，依次锁入另外 3 颗螺丝，待 4 颗螺丝都锁到位置上后，再依次锁紧。

|  |  |
| --- | --- |
| 图 | 图 |
| 图 | 图 |

### 第 2 步 连接电机线缆

在靠近插头的位置安装磁环，注意扣合时不要压到线缆。将电机线在靠近电机的线扣处绕线 1 周并扣紧，按布线路径整理入卡扣中，最后将插头连接到 MC 板的蓝色插头上。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 安装张紧器

将张紧弹簧安装到张紧器上，并装入张紧器槽中，弹簧先进槽。

|  |  |
| --- | --- |
| 图 | 图 |

安装张紧器压片，左侧张紧器的压片，缺口朝上进行安装，锁入 2 颗张紧器螺丝（细牙螺丝），不要锁紧；安装弹簧压片，方形定位缺口朝上，锁入 2 颗螺丝（粗牙）固定。

> 注意：另一侧的电机，压片的位置是刚好相反的。

|  |  |
| --- | --- |
| 图 | 图 |

用扳手推动张紧器压缩张紧弹簧，然后锁紧两颗张紧螺丝，使张紧器处于较极限的压缩状态。（这个操作是为了下一步更容易安装 XY 皮带固定支架）

|  |  |
| --- | --- |
| 图 | 图 |

### 第 4 步 装皮带固定支架

将 XY 皮带固定支架安装到工具头上，用手压着固定支架，先锁中间位置的 1 颗螺丝，然后再锁上下 2 颗螺丝。

|  |  |
| --- | --- |
| 图 | 图 |

拧松**左右两个** XY 张紧器的螺丝，让张紧器自然张紧，前后移动工具头 2~ 3 次，然后重新锁紧张紧器螺丝（相当于张紧 XY 皮带）。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-motor-left/zh/06_x____________tool_head_with_x_axis_assembly_replacement_guide_39a23b3cc4.jpg)

### 第 5 步 安装背板

请参考 WIKI：[背板更换指南](replace-back-panel.md)，将背板及其他配件安装好。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-xy-motor-left/zh/12_z________z_motor_replacement_guide_2980526540.jpg)

## 功能验证

启动打印机，执行一次回零操作，能正常完成即可。
