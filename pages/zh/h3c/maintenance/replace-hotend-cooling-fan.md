## 热端风扇

热端风扇安装在工具安装槽的右侧，用于给喷嘴的冷端散热，防止耗材在提前软化，从而导致堵头。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-hotend-cooling-fan/zh/103__________hotend_cooling_fan_replacement_guide_9d71a0ecfa.jpg)

## 何时更换

- 热端风扇异响
- 热端风扇转速异常或停转
- 热端风扇结构件损坏。

## 工具和材料

- H1.5 内六角扳手
- 镊子

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除热端风扇

### 第 1 步 移除工具头外壳

请参考 WIKI：[工具头外壳更换指南](replace-toolhead-front-cover.md)，移除 工具头前盖和顶盖，露出热端风扇及其线缆。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-hotend-cooling-fan/zh/103__________hotend_cooling_fan_replacement_guide_ac3c8d0f7e.jpg)

### 第 2 步 松出风扇线缆

将风扇线缆从接口板上断开，由于风扇线缆藏于插头2个插头线缆的下方，因此需要一并断开右边的2个插头以便于抽出线缆。

|  |  |
| --- | --- |
| 图 | 图 |

用镊子轻微掰开线缆卡扣，将风扇线缆从卡扣上松出。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 移除热端风扇

用H1.5 内六角扳手移除 2 颗螺丝，然后将热端风扇沿右侧松出，移除热端风扇。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-hotend-cooling-fan/zh/103__________hotend_cooling_fan_replacement_guide_629815d7f8.jpg)

## 安装热端风扇

### 第 1 步 安装热端风扇

将热端风扇的安装孔对准螺丝柱安装到工具头上。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-hotend-cooling-fan/zh/103__________hotend_cooling_fan_replacement_guide_9e8d42e43c.jpg)

锁入 2 颗螺丝固定。注意检查不要压住线缆。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-hotend-cooling-fan/zh/103__________hotend_cooling_fan_replacement_guide_629815d7f8.jpg)

### 第 2 步 整理风扇线缆

将热端风扇沿着布线路径进行整理，重新压回止扣。将风扇及其他线缆连接回工具头接口板。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 安装工具头外壳

请参考 WIKI：[工具头外壳更换指南](replace-toolhead-front-cover.md)，安装好工具头顶盖和前盖。  
![图](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-hotend-cooling-fan/zh/103__________hotend_cooling_fan_replacement_guide_7874090ab0.jpg)

## 功能验证

配置好打印机，连接电源并启动，执行加载打印头的操作，确认执端温度有正常升高，热端风扇正常运转无报错。
