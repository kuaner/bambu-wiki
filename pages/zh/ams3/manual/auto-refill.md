## **功能说明**

拓竹H3C 支持**多头续料**——当 AMS 中放入多卷**同品牌、同类型、同颜色**\*的耗材，且**对应打印头热端类**型一致时，系统会自动形成续料关系，一卷用完可无缝切换至下一卷，保障长时间打印不中断。该功能不限于 AMS，只要满足续料关系生效条件，外挂耗材也可以实现自动续料。

形成续料关系的耗材槽位会在 **“自动续料”** 页面以 **续料组** 的形式展示，该页面将显示续料组内的槽位、耗材品牌、类型、颜色及打印头类型等信息。

![001.png](https://public-cdn.bblmw.com/wiki/new/ams3/manual/auto-refill/zh/001.png)

为确保不同打印头续料后的打印质量，机器在打印准备阶段会对参与续料的打印头**自动执行喷嘴偏移校准。**

> \***注**：**最新版本将不限制自动续料的耗材颜色。建议升级至最新版本固件以体验跨 PLA 子类或颜色的自动续料。**

## 生效条件

续料关系可以由打印机自动识别，也可以手动设置。耗材需同时满足以下条件，打印机才能自动识别续料关系：

| **条件** | **说明** |
| --- | --- |
| 耗材属性一致 | **品牌、类型**完全相同 |
| 打印头类型一致 | 对应槽位下方的**打印头类型**相同（例如均为标准 0.4 mm 喷嘴） |
| 打印头已校准 | 打印头已完成**挂架对位校准** |

## **触发方式**

### 方式一：打印前插入（推荐）

打印发起前，将续料耗材放入 AMS 槽位，系统会在**自动续料页面**显示续料关系。发起打印后，机器自动执行喷嘴偏移校准，保障续打质量。

|  |  |
| --- | --- |
| 002.png | 003.png |

### 方式二：打印中插入

打印过程中，支持插入**官方耗材**并自动读取。识别完成后，机器会判断新插入的耗材是否与当前打印的耗材一致:

- **若结果一致：** 自动加入续料关系;
- 若新耗材对应打印头的**喷嘴偏移数据**无效：机器弹窗提醒，用户可选择:

  - 接受可能的续打瑕疵 → 加入续料关系；
  - 放弃加入 → 保持当前打印状态。

**建议优先使用方式一，** 打印前放入续料耗材，机器可自动完成喷嘴偏移校准，获得最佳续打质量。

## 编辑自动续料关系

用户可通过**打印机屏幕、Bambu Studio 和 Bambu Handy**界面，手动编辑自动续料关系。手动编辑时，**允许选择大类相同、小类**（比如 PLA Basic 和 PLA Lite）**或颜色不同的耗材组成续料关系。**

### 入口位置

**屏幕：**“耗材 > ... > 自动续料”

![004.png](https://public-cdn.bblmw.com/wiki/new/ams3/manual/auto-refill/zh/004.png)

**Bambu Studio：**“设备 > ... > 自动续料管理”

![005.png](https://public-cdn.bblmw.com/wiki/new/ams3/manual/auto-refill/zh/005.png)

**Bambu Handy：**“更多 > ... > 自动续料”

|  |  |
| --- | --- |
| 006.png | 007.png |

### 查看耗材续料关系

点击屏幕，进入 **“设备 > ... > 自动续料”** 页面，即可查看当前的耗材续料关系。

|  |  |
| --- | --- |
| 008.png | 009.png |

### 添加耗材续料组

若希望手动指定某些槽位组成续料组，可在自动续料页面按以下步骤操作：

1. 点击“**添加续料组”** 按钮；

![010.png](https://public-cdn.bblmw.com/wiki/new/ams3/manual/auto-refill/zh/010.png)

2. 勾选**符合要求且希望组成续料组**的槽位，并点击 **“确认”**；

![011.png](https://public-cdn.bblmw.com/wiki/new/ams3/manual/auto-refill/zh/011.png)

3. 确认后，系统将创建新的续料组，并在页面中显示。

![012.png](https://public-cdn.bblmw.com/wiki/new/ams3/manual/auto-refill/zh/012.png)

### 编辑耗材续料组

对于已存在的续料组，支持以下编辑操作：

#### **添加耗材**

在续料组详情中，点击 **“添加耗材”**，可选择符合条件的槽位加入当前组；

![013.png](https://public-cdn.bblmw.com/wiki/new/ams3/manual/auto-refill/zh/013.png)

#### **删除耗材**

- 在**自动创建的续料组**中，点击某耗材的 **“移除”** 按钮，可将其从该续料组中移除；

|  |  |
| --- | --- |
| 014.png | 015.png |

- 在**手动创建的续料组**中，点击某耗材的 **“移除”** 按钮；

  - 如果续料组中的耗材数量等于 2，则该续料组将被删除；

|  |  |
| --- | --- |
| 016.png | 017.png |

- 如果续料组中的耗材数量大于 2，则选中的耗材将被删除。

|  |  |
| --- | --- |
| 018.png | 019.png |

#### **重置续料组**

在续料组详情中，点击 **“重置”** 按钮，将移除手动添加的耗材。

|  |  |
| --- | --- |
| 020.png | 021.png |

> **注**：如果该续料组中没有手动添加的耗材，则“重置”按钮置灰。

## 远程续料

> 请将打印机升级到最新固件。

在打印过程中，如果某槽位耗材用尽，打印暂停，Bambu Handy 会弹出提示，并提供 **“使用其他槽位耗材”** 按钮，此时可手动选择符合要求（大类相同、小类或颜色可不同）的耗材进行续打。
