## AMS 前横梁及左/右支架

AMS 3H 框架的前侧、左侧及右侧构成部分。  
![img_bfde1269254c.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-front-beam/zh/img_bfde1269254c.jpg)

## 何时更换

支架或前横梁出现裂纹、断裂或明显变形。

## 工具和材料

- H1.5 内六角扳手
- H2.0 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 拆装提示

> 本指南是在已移除 AMS 3H 舱体的情况下操作的，请参考WIKI: [AMS 3H 舱体拆装指南](../../h3c/maintenance/replace-chamber.md)，完成将 AMS 舱体从AMS 支架上移除和安装的操作。

## 移除 AMS 前横梁及左/右支架

### 第1 步 移除磁吸侧板、前面板及背板

请参考 WIKI ：[AMS 3H 支架外壳更换指南](replace-right-panel.md)，移除左/右磁吸侧板、前面板及背板。

### 第 2 步 移除前横梁

> 重要提示：手严禁出现在前横梁移动的方向，可能会因为力度控制不好导致划伤或碰伤。  
> ![img_0efb96529617.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-front-beam/zh/img_0efb96529617.jpg)

前横梁通过卡扣固定，拆除时需要先松出一端，然后再松出另一端。  
具体的操作如下：用 H2.0 内六角扳手按压横梁右侧的卡口进行解锁。

|  |  |
| --- | --- |
| img_8ee3723b88f0.jpg | img_e8fa1938975f.jpg |

在按压的同时，另一只手握住支架，大拇指用力向上推，将前横梁的右侧松出；

|  |  |
| --- | --- |
| img_cdaca92c8b0f.jpg | img_18b71ba4e2cc.jpg |

同样的操作松出横梁左端，然后可移除前横梁。

### 第 3 步 移除 AMS 左/右侧料管支架

用手握住左料管支架的底座，将其从 AMS 左支架上拔出。

|  |  |
| --- | --- |
| img_71d131b57eff.jpg | img_787ea00102a5.jpg |

用手握住右料管支架的底座，将其从 AMS 右支架上拔出。

|  |  |
| --- | --- |
| img_1439a69fba7a.jpg | img_93243eff6e2c.jpg |

### 第 4 步 移除 AMS 左/右支架

用 H2.0 内六角扳手，拧出左右两侧的 4 颗螺丝，然后将主料管支架向上抬起，使其与左/右支架分离。

|  |  |
| --- | --- |
| img_8e9d5cfa8fad.jpg | img_cc422c491301.jpg |

用 H1.5 内六角扳手移除 2 颗 AMS 固定螺丝，移除 AMS 左支架。

|  |  |
| --- | --- |
| img_89ef23ded687.jpg | img_cb0d1803ebd6.jpg |

用 H1.5 内六角扳手移除 2 颗 AMS 固定螺丝，移除 AMS 右支架。

|  |  |
| --- | --- |
| img_d69fc9be4b39.jpg | img_a76eca20d8de.jpg |

## 安装 AMS 左/右支架及前横梁

### 第 1 步 安装 AMS 左/右支架

> 温馨提示：
>
> 1. 安装左/右支架前，请确认支架的安装柱上装有橡胶套，否则会有很明显的晃动。  
>    ![img_d734d2fe7c30.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-front-beam/zh/img_d734d2fe7c30.jpg)

> 1. 如果发现左/右支架安装到打印机上后，无法安装到底，请检查是否橡胶套没有安装到位，可以尝试重新安装橡胶套，安装时橡胶套上的缺口要与安装柱的缺口对齐；  
>    ![img_58c74be9c24d.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-front-beam/zh/img_58c74be9c24d.jpg)

> 1. 如果安装不上，请检查是否是旧的橡胶套留在打印机上，请进行移除。  
>    ![img_4893570ae420.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-front-beam/zh/img_4893570ae420.jpg)

将装有橡胶套的左&右支架分别安装到打印机顶部，如果只是拆除或更换其中一边的支架，操作其中一边即可。

|  |  |
| --- | --- |
| img_280a76286140.jpg | img_505c3c1267d8.jpg |

将料管主支架分别对齐 AMS 左支架和 AMS 右支架的固定块后，向下按压安装到位。注意：安装至右支架时，请确保线缆在料管支架的下方通过。

|  |  |
| --- | --- |
| img_17d44617672b.jpg | img_2d8a2efb5b8d.jpg |
| img_73f0f7916ae5.jpg |

然后分别锁入 4 颗螺丝固定主料管支架和 4 颗螺丝 固定AMS 左/右支架。  
![img_da922524720c.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-front-beam/zh/img_da922524720c.jpg)

### 第 2 步 安装 AMS 左/右侧料管支架

用手握住左料管支架的底座，将其安装到 AMS 左支架上。

|  |  |
| --- | --- |
| img_e086bf0da7df.jpg | img_71d131b57eff.jpg |

用手握住右料管支架的底座，将其安装到 AMS 右支架上。

|  |  |
| --- | --- |
| img_e4909f6596c4.jpg | img_1439a69fba7a.jpg |

### 第 3 步 安装前横梁

将前横梁左右两侧的卡片安装到 AMS 左右支架上，  
![img_cebc0b179490.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-front-beam/zh/img_cebc0b179490.jpg)

然后向下按压，将前横梁安装到位。

|  |  |
| --- | --- |
| img_77b2d75a67fc.jpg | img_4e3f8e12e658.jpg |

### 第 4 步 安装背板、前面板及磁吸侧板

请参考 WIKI ：[AMS 3H 支架外壳更换指南](replace-right-panel.md)，安装背板、前面板及左/右磁吸侧板。

## 功能验证

检查外观，确认安装到位。

- 磁吸侧板吸附牢固，轻推无松动
- 前面板无翘起
- 背板贴合平整
- 外壳各侧板缝隙均匀，无明显错位
