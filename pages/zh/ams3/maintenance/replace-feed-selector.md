## AMS 送料选择器

AMS 送料选择器是用于选择并引导来自不同通道的耗材进入指定供料路径的装置，需配合选料电机一起使用。

它由三个部分构成：

1. 选料杆
2. 选料霍尔板（含线）
3. 选料齿轮组件

![001.jpeg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feed-selector/zh/001.jpeg)

## 何时更换

1. 位置检测功能失效；
2. 齿轮或齿条上的齿磨损，影响使用。

## 工具和材料

- H2.0 内六角扳手
- H1.5 内六角扳手

## 安全提示

> 重要提醒！在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次损伤。拆除部件前，请妥善保管拆除的固定螺丝，以免丢失。

## 移除 AMS 送料选择器

### 第 1 步 移除 AMS 进料组件上盖

请参考 WIKI: **[AMS 进料组件上盖更换指南](replace-auto-filament-loader-cover.md)，** 移除 AMS 上下料组件上盖。

![002.jpeg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feed-selector/zh/002.jpeg)

### 第 2 步 移除 AMS 进料组件指示灯

用 H1.5 内六角扳手移除 4 颗螺丝，取下进料组件指示灯，按压插头锁扣并断开插头连接，移除 AMS 进料组件指示灯。

|  |  |
| --- | --- |
| 003.jpeg | 004.jpeg |

### 第 3 步 移除选料齿轮组件

用 H1.5 内六角扳手移除 3 颗送料选择器电机螺丝，松出选料电机，移除大齿轮。

|  |  |
| --- | --- |
| 005.jpeg | 006.jpeg |

用 H1.5 内六角扳手移除 4 颗选料齿轮组件螺丝，移除选料齿轮组件。

|  |  |
| --- | --- |
| 007.jpeg | 008.jpeg |

### 第 4 步 移除选料霍尔板

不换线时：按压插头锁扣，拔出线缆。用 H1.5 内六角扳手移除 1 颗螺丝，取下选料霍尔板；

要换线时：需翻转 AMS 舱体，从主板上断开连接线。

|  |  |
| --- | --- |
| 009.jpeg | 010.jpeg |

### 第 5 步 移除选料杆

握住选料杆用力向右侧拉，可将选料杆移除。

|  |  |
| --- | --- |
| 011.jpeg | 012.jpeg |

## 安装 AMS 送料选择器

### 第 1 步 安装选料杆

先找到导向槽并识别方向：选料杆底部有一条长凸台，在安装时，它与 AMS上下料组件底壳上的凹槽是配合活动的关系；选料杆的一端有磁铁，是与选料霍尔板配合使用的，安装时，它们在同一侧。

|  |  |
| --- | --- |
| 013.jpeg | 014.jpeg |

将选料杆的凸台与上下料组件底壳上的凹槽对齐，从右向左推选料杆，将选料杆安装到上下料组件底壳上。

|  |  |
| --- | --- |
| 015.jpeg | 016.jpeg |

在推到选料霍尔板支架位置时，选料杆会偏离凹槽并被霍尔板支架阻挡，这时只需要用手按下选料杆，使其与凹槽贴合，即可继续完成安装。

|  |  |
| --- | --- |
| 017.jpeg | 018.jpeg |

### 第 2 步 安装选料霍尔板

要换线时：需翻转 AMS 舱体，将一端线缆连接到主板上，并按布线路径将另一端经过过线孔送到 AMS 舱体另一侧；

不换线时：按压插头锁扣，拔出线缆。将选料霍尔板安装支架上，用 H1.5 内六角扳手锁入 1 颗螺丝固定，然后接上另一端插头。

|  |  |
| --- | --- |
| 019.jpeg | 020.jpeg |

### 第 3 步 安装选料齿轮组件

安装选料齿轮组件，对齐螺丝孔（如果无法对齐，可稍微调整选料杆的位置），锁入 4 颗螺丝固定，然后安装大齿轮。

|  |  |
| --- | --- |
| 021.jpeg | 022.jpeg |

### 第 4 步 安装选料电机

将选料电机装回原位，锁入 3 颗螺丝固定。

|  |  |
| --- | --- |
| 023.jpeg | 024.jpeg |

### 第 5 步 安装 AMS 进料组件指示灯

连接AMS 进料组件指示灯线缆，将指示灯组件安装到进料组件上，锁入 螺丝固定。

|  |  |
| --- | --- |
| 025.jpeg | 026.jpeg |

### 第 6 步 安装 AMS 进料组件上盖

请参考 WIKI: **[AMS 进料组件上盖更换指南](replace-auto-filament-loader-cover.md) ，** 安装 AMS 上下料组件上盖、上下料嘴。

![027.jpeg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feed-selector/zh/027.jpeg)

## 功能验证

1. 连接打印机，启动电源。检查确认指示灯工作无异常；
2. 执行一次上料操作，确认选料机构工作正常。
