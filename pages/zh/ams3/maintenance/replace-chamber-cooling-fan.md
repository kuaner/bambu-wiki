## 腔体散热风扇

安装在 AMS 背板处的 “吸入式” 风扇，用于加强打印机上部腔体的散热效率。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-chamber-cooling-fan/zh/78_ams_3h__________ams_3h_right_panel_ams_3h_left_panel_ams_3h_front_panel_ams_3h_rea_e6e5c6386a.jpg)

## 何时更换

- 风扇报错或出现异响。

## 工具和材料

- H2.0 内六角扳手
- H1.5 内六角扳手
- 剪刀或斜口钳

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除腔体散热风扇

### 第1 步 移除 AMS 舱体

请参考WIKI: [AMS 3H 舱体拆装指南](../../h3c/maintenance/replace-chamber.md)，将 AMS 舱体从 AMS 支架上移除。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-chamber-cooling-fan/zh/78_ams_3h__________ams_3h_right_panel_ams_3h_left_panel_ams_3h_front_panel_ams_3h_rea_a54d231c40.jpg)

### 第 2 步 移除 AMS 支架背板

请参考 WIKI ：[AMS 3H 支架外壳更换指南](replace-right-panel.md) 中移除背板的内容，将 AMS 框架的背板移除。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-chamber-cooling-fan/zh/28_______________printtool_cooling_fan_replacement_guide_95a63d8ef1.jpg)

### 第 3 步 移除腔体散热风扇

用 H1.5 内六角扳手移除 4 颗螺丝，松开风扇遮盖.  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-chamber-cooling-fan/zh/78_ams_3h__________ams_3h_right_panel_ams_3h_left_panel_ams_3h_front_panel_ams_3h_rea_0157215058.jpg)

将用剪刀将固定风扇的 4 个橡胶软钉剪断，移除腔体冷却风扇。（如果不是要更换风扇或更换背板，请不要将风扇拆除，没有新的橡胶软钉将很难装回风扇。）

|  |  |
| --- | --- |
| 图 | 图 |

如果退出风扇插头时有被卡住，按压一下插头锁扣即可。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-chamber-cooling-fan/zh/78_ams_3h__________ams_3h_right_panel_ams_3h_left_panel_ams_3h_front_panel_ams_3h_rea_d4d272375f.jpg)

翻转到另一面，拨除残留的另一截橡胶软钉。

## 安装 AMS 支架背板

### 第1 步 安装腔体散热风扇

在背板上安装新的橡胶较钉，尖端穿过后，直接拉长后安装，保留底座在另一面。

|  |  |
| --- | --- |
| 图 | 图 |

将风扇插头穿过线孔，橡胶软钉穿过风扇上的橡胶钉通孔，拉伸橡胶钉使小头穿过，将风扇固定，用剪刀剪掉多余的部份。

|  |  |
| --- | --- |
| 图 | 图 |

完成后，如下图。然后合上风扇遮盖，锁上 4 颗螺丝固定。

|  |  |
| --- | --- |
| 图 | 图 |

安装风扇遮盖，注意遮盖的方向，叶片能自然下垂闭合是正确的，叶片张开是错误的。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 2 步 安装 AMS 支架背板

请参考 WIKI ：[AMS 3H 支架外壳更换指南](replace-right-panel.md)，安装 AMS 3H 背板。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-chamber-cooling-fan/zh/28_______________printtool_cooling_fan_replacement_guide_c77b14c373.jpg)

## 功能验证

连接 AMS 并启动打印机，在空调系统内找到 腔体风扇，点击屏幕来控制腔体风扇，风扇受控正常。
