## AMS 3H 自动进料组件上盖

![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-auto-filament-loader-cover/zh/114_ams_3h______________ams_3h_auto_filament_loader_cover_replacement_guide_20f8ba6e06.jpg)

## 何时更换

- AMS 3H 自动进料组件上盖出现不可接受的开裂或物理损坏

## 工具和材料

- H2.0 内六角扳手

## 安全提示

> 重要提醒! 在对AMS及其内部电子设备进行任何维护工作之前,请关闭AMS及打印机电源,并断开电源连接,以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。拆装过程中请避免暴力操作,防止造成零部件或连接结构的二次损伤。拆除部件前,请妥善保管拆除的固定螺丝,以免丢失。

## 移除 AMS 3H 自动进料组件上盖

> 更换 AMS 3H 自动进料组件上盖时，不需要将 AMS 舱体从 AMS 支架上取下，本文档所展示的照片状态仅是为了方便拍摄。

### 第 1 步 移除耗材烘干仓盖

打开 AMS 上盖，并使用撑杆固定，移除耗材烘干仓盖。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-auto-filament-loader-cover/zh/114_ams_3h______________ams_3h_auto_filament_loader_cover_replacement_guide_2f889c67c0.jpg)

### 第 2 步 拨出上下料料嘴

用手握住上下料料嘴，用力斜向上拔出上下料料嘴，共 9 PCS。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 移除 AMS 上下料组件上盖

用H2.0 内六角扳手移除 4 颗螺丝，用手向上拿起并取下 AMS 上下料组件上盖。

|  |  |
| --- | --- |
| 图 | 图 |

## 安装 AMS 3H 自动进料组件上盖

### 第 1 步 安装 AMS 3H 自动进料组件上盖

将进料组件上盖安装回进料组件，注意对齐 烘干仓 RFID 组件的安装槽，

|  |  |
| --- | --- |
| 图 | 图 |

锁入 4 颗螺丝固定。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-auto-filament-loader-cover/zh/114_ams_3h______________ams_3h_auto_filament_loader_cover_replacement_guide_912d22f82d.jpg)

### 第 2 步 安装 9 个上下料料嘴

> 安装提示： 上下料料嘴与与入料口组件的连接如下图，设置有专门的导向键和定位槽，对齐后方可正常连接。  
> ![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-auto-filament-loader-cover/zh/97_ams___________ams_3h_feeding_funnel_replacement_guide_96b02cfc88.jpg)

保持导向键朝上，先将上下料料嘴装进橡胶孔，然后再对齐导向槽（不可见）将上下料料嘴安装到位。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-auto-filament-loader-cover/zh/97_ams___________ams_3h_feeding_funnel_replacement_guide_fbeb79dd8f.jpg)

一共需安装 9 个上下料料嘴。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-auto-filament-loader-cover/zh/114_ams_3h______________ams_3h_auto_filament_loader_cover_replacement_guide_84a2dfb534.jpg)

### 第 3 步 安装 烘干仓盖

将烘干仓盖装回原位，，合上 AMS 上盖。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-auto-filament-loader-cover/zh/114_ams_3h______________ams_3h_auto_filament_loader_cover_replacement_guide_e4111c4b68.jpg)

## 功能验证

检查确认上下料料嘴能正常固定，无松动。
