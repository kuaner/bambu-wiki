## AMS 3H 送料齿轮组

AMS 3H 送料齿轮组是一套齿轮组件，是送料机构的组成部件之一，确保耗材正常输送。

|  |  |
| --- | --- |
| 图 | 图 |

## 何时更换

- 齿轮磨损影响耗材输送
- 齿轮异响，润滑后无改善

## 工具和材料

- H2.0 内六角扳手
- H1.5 内六角扳手

## 安全提示

> 重要提醒！在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次损伤。拆除部件前，请妥善保管拆除的固定螺丝,以免丢失。

## 拆装提示

> 本指南是在已移除 AMS 3H 舱体的情况下操作的，请参考WIKI: [AMS 3H 舱体拆装指南](../../h3c/maintenance/replace-chamber.md)，完成将 AMS 舱体从 AMS 支架上移除和安装的操作。

## 移除 AMS 3H 送料齿轮组件 / 上下料组件底壳

### 第 1 步 移除 AMS 进料组件上盖

请参考 WIKI: [AMS 3H 自动进料组件上盖更换指南](replace-auto-filament-loader-cover.md)，移除 AMS 上下料组件上盖。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/10_ams_3h____________ams_3h_auto_filament_loader_replacement_guide_15119abbe1.jpg)

### 第 2 步 移除 AMS 进料组件指示灯

请参考 WIKI: [AMS 3H 进料组件指示灯更换指南](replace-auto-filament-loader-indicator.md)，移除 AMS 进料组件指示灯。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/10_ams_3h____________ams_3h_auto_filament_loader_replacement_guide_ce63c509cc.jpg)

### 第 3 步 移除选料齿轮组件和选料杆

请参考 WIKI: [AMS 3H 送料选择器更换指南](replace-feed-selector.md)，拆除选料杆组件（含霍尔板）、选料电机组件。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_16624aa0aa.jpg)

### 第 4 步 移除入料口组件

请参考 WIKI: [AMS 3H 入料口组件更换指南](replace-filament-inlet-assembly.md)，移除入料口组件。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_2a3b9b28b8.jpg)

### 第 5 步 移除送料电机

请参考 WIKI： [AMS 3H 送料电机更换指南](replace-feeder-motor.md)，将送料电机从进退料组件上移除。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_5ebd4eba3f.jpg)

### 第 6 步 移除 AMS 挤出齿轮组件 （黄色）

用 H2.0 内六角扳手移除 D 型轴（1 &2 ）和圆形轴（3&4）两端的螺丝，共 4 颗。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_14db650feb.jpg)

用 H1.5 内六角扳手塞进左侧螺丝孔，将 D 型轴从右侧顶出，移除 D 型轴，逐个取下摇臂齿轮。

|  |  |
| --- | --- |
| 图 | 图 |

用 H1.5 内六角扳手塞进左侧螺丝孔，将 圆形轴从右侧顶出，移除圆形轴，取下 AMS 挤出齿轮。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 7 步 移除 AMS 挤出齿轮组件 （金属齿轮）

> 金属齿轮由圆形轴串接，只更换金属齿轮时，可以只移除圆形轴，并参考 **AMS 进料组件更换指南**，将整个**进料组件**翻转过来，即可进行更换。  
> ![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_c0ca4b29fb.png)

用 H2.0 内六角扳手移除 4 颗螺丝，将上下料组件底壳翻转过来。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_cdac7071c8.jpg)

移除对应位置的进料导向块，倒出金属齿轮。将全部进料导向块及齿轮移除后，就余下上下料组件底壳。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_614c766403.jpg)

## 安装 AMS 挤出齿轮组件 / 上下料组件底壳

### 第 1 步 安装 AMS 挤出齿轮组件 （金属齿轮）

金属齿轮有安装方向，确认好方向后，将金属齿轮安装到进料组件底座上。

|  |  |
| --- | --- |
| 图 | 图 |

安装耗材进料导向块，耗材导向块的安装方向由金属齿轮的方向决定。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_e782d1e717.jpg)

### 第 2 步 安装 AMS 3H 自动进退料组件底壳

注意避让连接线缆，将**自动进退料组件底壳安装到 AMS 中框上。**  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_37e768c98d.jpg)

用 H2.0 内六角扳手锁入 4 颗螺丝固定。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_cdac7071c8.jpg)

### 第 3 步 安装 AMS 挤出齿轮组件

如图所示，确认摇摆齿轮的方向，将 5 PCS摇摆齿轮安装到自动进退料组件底壳。

|  |  |
| --- | --- |
| 图 | 图 |

放入 AMS 挤出齿轮  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_60f1c92e4e.jpg)

将 D 型轴从左往右依次穿过各摇摆齿轮和挤出轮，可以轻度调整 D 型轴和齿轮，使 D型轴顺利通过。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_5b60d8bc7c.jpg)

将 圆形轴从左往右依次穿过各金属齿轮。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_24cff16afa.jpg)

锁紧 D 型轴（1 &2 ）和圆形轴（3&4）两端的螺丝，共 4 颗。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-feeder-gear-set/zh/47_ams_3h___________ams_3h_feeder_gear_set_replacement_guide_14db650feb.jpg)

### 第 4 步 安装送料电机

## 功能验证

连接打印机并启动，对更换的配件所在槽位执行一次进退料操作，能正常完成且无异响。
