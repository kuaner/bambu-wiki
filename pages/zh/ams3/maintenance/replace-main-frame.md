## AMS 中框

AMS 中框即 AMS 3H 舱体的塑料主框，为 AMS 3H 内部各个功能组件提供安装位置。

![001.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-main-frame/zh/001.jpg)

> 温馨提示：
>
> 1. AMS 中框上预装了 TPU 入料口，除些之外，参考中框上各配件对应的拆装指南，移除所有的配件，最后得到的就是 AMS 中框。
> 2. 由于**操作步骤比较多**，如果在产品质保期内出现需要更换 AMS 中框的需求，请与我们的技术支持人员沟通是否有其他解决方案后再处理。
> 3. 本指南主要介绍拆解的主体步骤，一些细节内容，可能需要转到对应配件的更换指南。安装的操作逆着拆解的步骤看即可，我们会注明一些安装注意事项。

## 何时更换

AMS 中框发生物理损坏且影响使用时，需要更换。

## 工具和材料

- H2.0 内六角扳手
- H1.5 内六角扳手

## 安全提示

> 在对AMS及其内部电子设备进行任何维护工作之前,请关闭AMS及打印机电源,并断开电源连接,以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。拆装过程中请避免暴力操作,防止造成零部件或连接结构的二次损伤。拆除部件前,请妥善保管拆除的固定螺丝,以免丢失。

## 将 AMS 3H 的配件从 AMS 中框上移除

### 第 1 步 移除 AMS 舱体

请参考WIKI: [AMS 3H 舱体拆装指南](../../h3c/maintenance/replace-chamber.md)，将 AMS 舱体从AMS 支架上取下。

### 第 2 步 移除 AMS 上盖和左右撑杆组件

请参考 WIKI： [AMS 3H 上盖更换指南](replace-top-lid.md) 和 [AMS 3H 撑杆组件更换指南](replace-lid-strut-right.md)，移除 AMS 上盖和左右撑杆组件。

### 第 3 步 移除 AMS 主板/接口板

将 AMS 舱体底面朝上放置到平整的台面上，用 H1.5 内六角扳手，移除 7 颗螺丝，取下主板和接口板装饰盖。

|  |  |
| --- | --- |
| 004.jpg | 005.jpg |

断开主板和接口板上的连接器 （橙色框标记的连接器：主板-接口板连接线、主板上的前温湿度传感器连接线除外），断开前温湿度传感器插头，然后用 H1.5 内六角扳手，移除 5 颗螺丝，取下主板和接口板。

|  |  |
| --- | --- |
| 006.jpg | 007.jpg |

### 第 4 步 移除移除温湿度传感器和 RFID 理线硅胶条

用 H1.5 内六角扳手，移除 2 颗螺丝，取下温湿度传感器; 用扳手撬起RFID 理线硅胶条并移除。

### 第 5 步 移除 AMS 电源插座/ AC 板/ 烘干组件

用手在电源插座附近的边角处将尾板扳开并取下，用 H1.5 内六角扳手在图示编号位置移除 2 颗螺丝，移除 AC 板盖子。

|  |  |
| --- | --- |

用 H2.0 内六角扳手，移除固定烘干组件的 6 颗螺丝和固定电源插座的 2 颗螺丝，用 H1.5 内六角扳手移除固定 AC 板底座的 4 颗螺丝，将AMS 电源插座/ AC 板/ 烘干组件一起从 AMS 中框上移除。

### 第 6 步 松线缆，移除 4 颗 RFID 螺丝

将所有线缆从卡扣中完全松出，

用 H1.5 内六角扳手移除原烘干组件位置旁边的 4 颗 RFID 线圈固定螺丝，，然后将 AMS 中框正向放置。

### 第 7 步 移除 AMS 3H 自动进料组件（含指示灯）

用 H2.0 内六角扳手，移除自动进料组件（含指示灯）的 4 颗螺丝.

然后握着自动进料组件两端，同时缓慢向上拿起，将自动进料组件从 AMS 中框上取下。

### 第 8 步 移除 RFID 组件

我们在第 6 步时已移除烘干组件两侧的实心款 RFID 组件固定螺丝，这时只需要直接拿起来即可移除。注意取出时，不要操作太快，防止操作线缆，其中靠右侧边沿的 RFID 组件的线缆较长。

最后，从 AMS 前后舱体中，直接移除安装在上面的 AMS 从动支撑轴组件，共 18 PCS。

## 组装注意事项

### 安装 AMS 从动支撑轴组件

先将 AMS 从动支撑轴组件放到位置上，然后从中间按压，听到清脆的到位声即可。

![028.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-main-frame/zh/028.jpg)

### 安装RFID 组件

RFID 组件有安装方向，装错方向时无法按压到位；前排的 RFID 线圈组件，顶部的螺丝帽在左侧，后排的 RFID 线圈组件，顶部的螺丝帽在右侧，通过扳手的位置可以确认。

|  |  |
| --- | --- |
| 029.jpg | 030.jpg |

穿线时，可以在中框的另一侧拉一下线缆，确保线缆被完全穿过，避免压线。

|  |  |
| --- | --- |
| 031.jpg | 032.jpg |

### 安装自动进料组件

由于自动进料组件上有太多连接线缆， AMS 中框也有很多过线孔，为了避免穿孔，可以将线缆按前后分开，先钭自动进料组件安装到 AMS 中框上，再将线穿过过线孔，这样不会出错。

| 033.jpg | 034.jpg |

## 功能验证

更换 AMS 中框，相当于完整的组装了一次 AMS 3H，对功能的检查也很关键。

- 连接打印机并启动，确认 AMS 可被正常识别，指示灯能点亮且无红灯；
- 各个槽位都执行一次安装原装耗材并完成进退料的操作，确认原装耗材能正常读取，且进退料操作能正常完成。
