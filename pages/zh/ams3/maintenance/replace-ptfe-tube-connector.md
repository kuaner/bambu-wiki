## 气动接头

气动接头是 3D 打印机在进料路径中用于连接料管的接头。 适配 AMS 3H 的气动接头包含以下两个位置的气动接头：  
一是安装在 AMS 料管导向组件上的气动接头；  
二是安装在打印头组件上，连接透明料管的气动接头。

|  |  |
| --- | --- |
| img_debb8da3833a.jpg | img_55cdaee8c964.jpg |

## 何时更换

气动接头不能固定料管，或料管不能正常装入

## 工具和材料

- H1.5 内六角扳手
- H2.0 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除打印头组件气动接头

### 第 1 步 取出打印头组件

用手抓住左/右侧板扣手位，向外侧用力，可将左/右侧板从 AMS 支架上分离，取下左/右侧板。  
![img_e11bdfa442e6.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ptfe-tube-connector/zh/img_e11bdfa442e6.jpg)

用手握住打印头组件的上部，斜向上提起，卸载打印头组件，并从 AMS 支架侧面伸出。  
![img_ed45d93eb1c7.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ptfe-tube-connector/zh/img_ed45d93eb1c7.jpg)

### 第 2 步 移除料管

按压两侧料管卡扣，**先向下按压料管**，再将料管向外拔出。

### 第 3 步 松连接线缆

用 H1.5 内六角扳手，移除 2 颗螺丝，取下遮盖。

|  |  |
| --- | --- |
| img_7e618003ac42.jpg | img_59eb22096066.jpg |

用 H1.5 内六角扳手，移除 1 颗螺丝，使连接板能有松动空间。

### 第 4 步 移除打印头组件气动接头

用 H1.5 内六角扳手，移除 4 颗螺丝。

## 安装打印头组件气动接头

### 第 1 步 安装打印头组件气动接头

将气动接头安装到打印头组件上，装回线材底座。

|  |  |
| --- | --- |
| img_b639c2701f8c.jpg | img_79beb9260276.jpg |

用 H1.5 内六角扳手，锁入 4 颗螺丝。

|  |  |
| --- | --- |
| img_397994c1c530.jpg | img_f58fd8516912.jpg |

### 第 2 步 装回线材遮盖

检查线缆位置，确认定位柱和螺丝孔均对齐，然后锁入 1 颗螺丝固定。

|  |  |
| --- | --- |

装回线材遮盖，注意安装正确后再锁螺丝。

用 H1.5 内六角扳手，锁入 2 颗螺丝固定遮盖。

## 移除 AMS 料管导向组件气动接头

> 拆装提示：本指南是在已移除 AMS 3H 舱体的情况下操作的，请参考WIKI: [AMS 3H 舱体拆装指南](../../h3c/maintenance/replace-chamber.md)，完成将 AMS 舱体从AMS 支架上移除和安装的操作。

### 第 1 步 移除 AMS 料管导向组件

请参考WIKI: [AMS 料管导向组件更换指南](replace-ptfe-tube-guide-assembly.md)， 移除 AMS 料管导向组件。  
![img_4bc887369172.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ptfe-tube-connector/zh/img_4bc887369172.jpg)

### 第 2 步 移除需要更换气动接头的连接件

导向组件上安装了 4 个直列料管连接件（其中一个少装气动接头）和 1 个分叉料管连接件，根据实际情况拆出来。  
![img_9e25c4bb733b.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ptfe-tube-connector/zh/img_9e25c4bb733b.jpg)

连接件均通过 2 颗螺丝固定到导向组件上，使用 H2.0 内六角扳手移除螺丝后，即可取下连接件。  
![img_e2fddb893c3e.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ptfe-tube-connector/zh/img_e2fddb893c3e.jpg)

### 第 3 步 移除气动接头 （以直列料管连接件为例）

用 H1.5 内六角扳手移除 1 颗螺丝，然后翻到另一面，将直列料管连接件的 6 个卡扣按序号顺序进行解锁，注意解锁过程中避免两侧同时受力，防止卡扣重新锁紧。

## 安装 AMS 料管导向组件气动接头

### 第 1 步 安装气动接头 （以直列料管连接件为例）

将气动接头放置到拆开的直列料管连接件上，盖上另一侧。

|  |  |
| --- | --- |
| img_501de753f6f4.jpg | img_ac0058f32ff8.jpg |

按压使所有卡扣锁紧，锁入 1 颗螺丝固定。

|  |  |
| --- | --- |
| img_9519aace8f60.jpg | img_f4ce818e5e1c.jpg |

### 第 2 步 安装料管连接件

连接件均通过 2 颗螺丝固定到导向组件上，装到位置后使用 H2.0 内六角扳手锁紧螺丝。  
![img_e2fddb893c3e.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ptfe-tube-connector/zh/img_e2fddb893c3e.jpg)

注意直列料管连接件朝向是一致的，不要装错方向。  
![img_b77916c4d65a.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ptfe-tube-connector/zh/img_b77916c4d65a.jpg)

### 第 3 步 安装 AMS 料管导向组件

请参考WIKI: [AMS 料管导向组件更换指南](replace-ptfe-tube-guide-assembly.md)， 安装 AMS 料管导向组件。  
![img_f1de4133a94e.jpg](https://public-cdn.bblmw.com/wiki/new/h3c/maintenance/replace-ptfe-tube-connector/zh/img_f1de4133a94e.jpg)

## 功能验证

料管能正常连接且在不按压接头的情况下不会松出。
