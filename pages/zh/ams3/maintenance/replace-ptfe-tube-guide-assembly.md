## AMS 料管导向组件

![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-ptfe-tube-guide-assembly/zh/32_ams__________________ptfe_tube_guide_assembly_and_tube_connector_replacement_guide_afb238a7dc.jpg)

> 料管导向组件已预装有料管连接件，如果需要单独更换料管连接件时，才需要使用第 3 步 的操作。

## 何时更换

料管导向组件结构损坏，影响使用。

## 工具和材料

- H2.0 内六角扳手
- H1.5 内六角扳手

## 安全提示

> 重要提醒! 在对AMS及其内部电子设备进行任何维护工作之前,请关闭AMS及打印机电源,并断开电源连接,以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。拆装过程中请避免暴力操作,防止造成零部件或连接结构的二次损伤。拆除部件前,请妥善保管拆除的固定螺丝,以免丢失。

## 拆装提示

> 本指南是在已移除 AMS 3H 舱体的情况下操作的，请参考WIKI: [AMS 3H 舱体拆装指南](../../h3c/maintenance/replace-chamber.md)，完成将 AMS 舱体从AMS 支架上移除和安装的操作。

## 移除 AMS 料管导向组件

### 第 1 步 移除打印头控制板

参考WIKI：[打印头控制板更换指南](replace-tool-control-board.md)，将打印头控制板从料管导向组件上移除。  
（注意：移除螺丝并将控制板整体从导向组件上分离即可，不需要断开打印头控制板上的插头）  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-ptfe-tube-guide-assembly/zh/32_ams__________________ptfe_tube_guide_assembly_and_tube_connector_replacement_guide_9a2397b6cb.png)

将线缆从导向组件的卡扣上松出。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-ptfe-tube-guide-assembly/zh/32_ams__________________ptfe_tube_guide_assembly_and_tube_connector_replacement_guide_bd61769f46.jpg)

### 第 2 步 移除AMS 料管导向组件

按压气动接头，将料管从气动接头上断开。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-ptfe-tube-guide-assembly/zh/32_ams__________________ptfe_tube_guide_assembly_and_tube_connector_replacement_guide_cec57377e3.jpg)

移除左右各 1 颗螺丝，将料管导向组件从 AMS 支架上取出。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 移除料管连接件（单独更换时使用）

导向组件上安装了 4 个直列料管连接件（其中一个少装气动接头）和 1 个分叉料管连接件，需要单独更换时，可参考本步骤。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-ptfe-tube-guide-assembly/zh/31__________ptfe_tube_connector_replacement_guide_9e25c4bb73.jpg)

连接件均通过 2 颗螺丝固定到导向组件上，使用 H2.0 内六角扳手移除螺丝后，即可取下连接件。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-ptfe-tube-guide-assembly/zh/31__________ptfe_tube_connector_replacement_guide_e2fddb893c.jpg)

## 安装 AMS 料管导向组件

### 第 1 步 安装料管连接件（单独更换时使用）

将料管连接件都安装到导向组件上，锁紧螺丝，注意直列料管连接件朝向一致。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-ptfe-tube-guide-assembly/zh/31__________ptfe_tube_connector_replacement_guide_b77916c4d6.jpg)

> 请注意，如果是将 AMS 支架原来的料管连接件装回去，请确认缺少一个气动接头的那一个直列料管连接件安装在 9号 位置。  
> ![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-ptfe-tube-guide-assembly/zh/32_ams__________________ptfe_tube_guide_assembly_and_tube_connector_replacement_guide_6cfc4c11a2.jpg)

### 第 2 步 安装 AMS 料管导向组件

对准导向孔，安装料管导向组件，左右各锁入 1 颗螺丝。

|  |  |
| --- | --- |
| 图 | 图 |

根据料管所在支架的编号，将料管连接到对应编号的气动接头上。

|  |  |
| --- | --- |
| 图 | 图 |

### 第 3 步 安装打印头控制板

将线缆卡到导向组件背面的卡扣上。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-ptfe-tube-guide-assembly/zh/32_ams__________________ptfe_tube_guide_assembly_and_tube_connector_replacement_guide_bd61769f46.jpg)

参考WIKI：[打印头控制板更换指南](replace-tool-control-board.md)，将打印头控制板安装到导向组件背面。  
![图](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-ptfe-tube-guide-assembly/zh/31__________ptfe_tube_connector_replacement_guide_f1de4133a9.jpg)

## 功能验证

- 检查料管的连接顺序，主料管支架上的编号与左右料管支架上的编号要一一对应。
- 所有 PTFE 料管插入气动接头到位，接头锁紧无松动
- 进料支架卡扣卡入正确，料管走向无弯折
