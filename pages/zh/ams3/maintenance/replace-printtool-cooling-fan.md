## 打印头挂架散热风扇

安装在 AMS 框架上的冷却风扇，为放置在挂架上的热端提供定向冷却。  
![img_9117dcde3e70.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-printtool-cooling-fan/zh/img_9117dcde3e70.jpg)

## 何时更换

- 散热风扇异响
- 散热风扇报错

## 工具和材料

- H2.0 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 拆装提示

> 1. 本指南是在已移除 AMS 3H 舱体的情况操作的，请参考WIKI: [AMS 3H 舱体拆装指南](../../h3c/maintenance/replace-chamber.md)，完成将 AMS 舱体从AMS 支架上移除和安装的操作。
> 2. 受光线、空间等影响，导致操作困难的，请参考 WIKI： [AMS 3H 拆除与安装指南](../../h3c/maintenance/replace-ams3.md)，将 AMS 3H 从打印机上移除，然后再拆装打印头挂架散热风扇。
> 3. 如果有加装俯视摄像头，需要先将摄像头从支架上移除。

## 移除打印头挂架散热风扇

### 第 1 步 移除支架背板

请参考 WIKI ：[AMS 3H 支架外壳更换指南](replace-right-panel.md) 中移除背板的内容，将 AMS 框架的背板移除。  
![img_95a63d8ef1df.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-printtool-cooling-fan/zh/img_95a63d8ef1df.jpg)

### 第 2 步 移除打印头挂架散热风扇固定螺丝

用 H2.0 内六角扳手从打印机背面移除 1 颗螺丝；用 H2.0 内六角扳手从打印机左侧移除 1 颗螺丝。然后可以松出打印头挂架散热风扇。

|  |  |
| --- | --- |
| img_a867bd616ea9.jpg | img_d4decff171ea.jpg |

### 第 3 步 移除打印头挂架散热风扇

从打印机前面按压插头锁扣，将风扇线缆从打印头控制板上断开，然后将线缆从旁边的卡扣松出；从打印背面移除压紧线缆的两块胶塞，将线缆从线槽中松出，移除打印头挂架散热风扇。

|  |  |
| --- | --- |
| img_2a506efbd1fe.jpg | img_142beb6dd94e.jpg |

## 安装打印头挂架散热风扇

### 第 1 步 安装打印头挂架散热风扇

将风扇左侧的螺丝孔对齐主料管支架底下的螺丝柱，锁入 1 颗螺丝固定。

|  |  |
| --- | --- |
| img_5ba8d7c4a5fa.jpg | img_a047425ee4a2.jpg |

从打印机后侧锁入另 1 颗螺丝，固定散热风扇。  
![img_f3f7992a3a38.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-printtool-cooling-fan/zh/img_f3f7992a3a38.jpg)

### 第 2 步 连接线缆

将风扇线缆规范整理并嵌入走线槽中，随后安装好两个固定胶塞。

|  |  |
| --- | --- |
| img_c9ff5c4f10de.jpg | img_1dd4181faaae.jpg |

最后将插头连接到打印头控制板的连接器上。  
![img_6e27c327247b.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-printtool-cooling-fan/zh/img_6e27c327247b.jpg)

### 第 3 步 安装 AMS 背板

请参考 WIKI ：[AMS 3H 支架外壳更换指南](replace-right-panel.md) 中安装背板的内容，装好 AMS 框架的背板。  
![img_c77b14c373d9.jpg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-printtool-cooling-fan/zh/img_c77b14c373d9.jpg)

## 功能验证

打印机夹取打印头并进行打印，风扇无异响，也没有报错。
