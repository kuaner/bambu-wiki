## AMS 3H 撑杆组件

![001.jpeg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-lid-strut-right/zh/001.jpeg)

AMS 撑杆组件是安装在 AMS 左右两侧、用于撑起 AMS 上盖的可以活动的支撑杆，左右两侧各有一根。

## 何时更换

- 撑杆功能失效
- 撑杆出现结构损坏

## 工具和材料

H2.0 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除 AMS 左（右）撑杆组件

> 1. AMS 3H 的左右撑杆组件，在拆装操作上是完全一样的；
> 2. 请参考 AMS 3H 舱体拆装指南，先将 AMS 舱体从AMS 支架上分离出来。

### 第1步 移除 AMS 3H 上盖的撑杆螺丝

移除撑杆组件需要将上盖完全打开或移除，所以两侧撑杆与 AMS 上盖固定的螺丝均需要移除。

用 H2.0 内六角扳手移除左右两侧撑杆的螺丝，共 8 颗。

|  |  |
| --- | --- |
| 002.jpeg | 003.jpeg |

### 第2步 移除撑杆组件

向后完全张开 AMS 上盖。（或参考 更换 AMS 3H上盖指南，直接将 AMS 3H上盖移除）

![004.jpeg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-lid-strut-right/zh/004.jpeg)

用 H2.0 内六角扳手移除右撑杆组件与中框相连 2 颗螺丝，然后向上拉出右撑杆组件。

|  |  |
| --- | --- |
| 005.jpeg | 006.jpeg |

同样的操作，可移除左撑杆组件。

## 安装 AMS 撑杆组件

### 第1步 安装撑杆组件

将右撑杆组件对齐两个定位柱安装到 AMS 中框上，锁入 2 颗螺丝。

|  |  |
| --- | --- |
| 007.jpeg | 008.jpeg |

同样的操作，可安装左撑杆组件。

### 第2步 锁撑杆到 AMS 上盖

将右撑杆拉起来安装到 AMS 上盖，使撑杆固定且对齐螺丝孔，锁入 2 颗螺丝固定。

![009.jpeg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-lid-strut-right/zh/009.jpeg)

同样的操作，将左侧撑杆与 AMS 上盖锁紧。

![010.jpeg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-lid-strut-right/zh/010.jpeg)

### 第 3 步 锁撑杆底座加固螺丝

在 AMS 中框的左右两侧，分别锁入 2 颗螺丝，加固 AMS 撑杆底座。

|  |  |
| --- | --- |
| 011.jpeg | 012.jpeg |

## 如何验证成功

重复开合 AMS 上盖 3 次，确认撑杆能稳定支撑 AMS 上盖，且开合顺畅无异响。

![013.jpeg](https://public-cdn.bblmw.com/wiki/new/ams3/maintenance/replace-lid-strut-right/zh/013.jpeg)
