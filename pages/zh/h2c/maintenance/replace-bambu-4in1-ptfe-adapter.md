## 四进一料管拓展口二代

料管拓展口能同时将 4 个进料模块连接到打印机，例如可拓展实现 7 种耗材打印: 1 个 AMS (4 色)和其他 3 种耗材。还能使打印机同时连接 AMS 及与 AMS 不兼容的耗材,如:TPU95A、拓竹 PET-CF 和其他品牌的含碳纤维/玻璃纤维耗材。

内部包含清洁刮片可以有效的清洁耗材上的灰尘，关于清洁刮片的更多介绍可参考：[更换四进一扩展口清洁刮片](replace-4in1-ptfe-adapter-filament-cleaning-pad.md)

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-bambu-4in1-ptfe-adapter/007.png)

### 使用AMS时

1. "进"端(4个孔):1个孔连接 AMS,另外 3 个孔分别连接其他 3 种耗材或 AMS;

1. "出"端:通过铁氟龙料管连接到打印机。

### 不使用AMS时

1. "进"端(4个孔):最多可连接4种耗材;
2. "出"端:通过铁氟龙料管连接到打印机。

需注意,接反可能会导致耗材发生堵塞。因此,务必确保安装方向正确。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-bambu-4in1-ptfe-adapter/001.jpg)

## 何时更换

料管磨损

料管扩展口损害

料管不能正常锁紧

## 移除旧的 H2C四进一料管拓展口

按压四进一料管拓展口上的黑色弹片同时拔出料管，移除旧的 H2C四进一料管拓展口。

|  |  |
| --- | --- |
|  |  |

## 安装新的H2C四进一料管拓展口

将新的四进一料管拓展口与料管连接，安装新的四进一料管拓展口。

|  |  |
| --- | --- |
|  |  |

安装完成后轻轻后拉确保正常锁紧。

> 需要注意的是：
>
> 进端为4孔，可连接 AMS 或外挂料盘。
>
> 出端为1孔，需要与打印机工具头连接。
>
> ![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-bambu-4in1-ptfe-adapter/001.jpg)

## 如何验证成功

连接方向正确，耗材进料无卡顿、堵塞情况。
