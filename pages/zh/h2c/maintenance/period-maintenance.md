## 前言

为保障 3D 打印机长期稳定运行，减少故障风险并延长设备使用寿命，定期维护至关重要。维护核心涵盖运行系统的清洁与润滑，包括 XYZ 轴、热端挂架等关键运动结构，需通过专业护理确保传动顺畅；同时需全面清理机箱内外壁，重点擦拭各类传感器、摄像头等精密部件，避免污垢堆积影响设备监测精度与视线清晰度，建议使用酒精搭配无纺布完成清洁。

若使用激光模组，尽管排烟管会排出大部分烟雾，但仍有部分残留会加剧机箱内部污染，相比仅使用 3D 打印功能，此类场景下的设备维护频率需相应提高，以规避污染引发的设备故障与安全隐患。

## 维护频次

H2C 可以基于任务类型和任务时长评估打印机的污染程度，并给出对应的清洁维护提醒（此功能需升级固件至01.01.00.00或更新的版本），收到打印机后，请升级固件以启用清洁提醒功能。

**请务必按照要求对激光模组和打印机各部件进行维护清理，如果不按时清理，可能导致机器损坏并产生安全风险。**

如果仅使用3D 打印功能，各部件的维护频率如下：

| 部件 | 清洁维护频率 | 部件 | 清洁维护频率 |
| --- | --- | --- | --- |
| 打印机外表面和屏幕 | 3个月 | [X 轴线轨](https://wiki.bambulab.com/zh/h2c/maintenance/period-maintenance#xy-%E8%BD%B4%E6%B8%85%E6%B4%81%E6%B6%A6%E6%BB%91) | 1个月 |
| 热床 | 3个月 | [Y 轴光轴](https://wiki.bambulab.com/zh/h2c/maintenance/period-maintenance#xy-%E8%BD%B4%E6%B8%85%E6%B4%81%E6%B6%A6%E6%BB%91) | 3个月 |
| [工具头](https://wiki.bambulab.com/zh/h2c/maintenance/period-maintenance#%E5%B7%A5%E5%85%B7%E5%A4%B4%E6%B8%85%E6%B4%81%E6%B6%A6%E6%BB%91) | 3个月 | [Z 轴丝杆和光杆](https://wiki.bambulab.com/zh/h2c/maintenance/period-maintenance#z-%E8%BD%B4%E6%B8%85%E6%B4%81%E6%B6%A6%E6%BB%91) | 3个月 |
| 喷嘴相机 | 3个月 | 工具头相机 | 3个月 |
| 俯视相机 | 3个月 | 实况相机 | 3个月 |
| 火焰传感器 | 3个月 | 上盖组件 | 3个月 |
| 辅助部件冷却风扇 | 3个月 | 左右侧板 | 3个月 |
| 左右内衬 | 3个月 | 活性碳滤芯盖 | 3个月 |
| 腔体外排风扇 | 3个月 | 排气格栅 | 3个月 |
| 左喷嘴升降线轨 | 1个月 | 热端挂架 | 1个月 |

注意：如果长期持续打印高温/工程耗材，建议将维护频率提升至每月一次。

## 所需材料

- 无纺布
- 75%酒精 或 70%异丙醇
- 刷子
- 润滑油
- 润滑脂
- 无尘棉棒

## 维护步骤

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 机舱外部清洁

使用无纺布蘸取酒精清洁打印机外壁，重点清洁机身侧面、前门及边角缝隙，去除灰尘、耗材残留及指纹印记。

|  |  |
| --- | --- |
|  |  |

轻柔擦拭打印机屏幕。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/027.png)

针对打印机顶盖玻璃、风门、把手握持区域进行重点擦拭。

|  |  |
| --- | --- |
|  |  |

排气格栅位于腔体外排风扇的外侧，共有7条排气格栅。拆除排气格栅时，从上往下拆。先略微用力将排气格栅往外凹，然后将右侧的定位块从小孔中取出。顺时针旋转排气格栅90°，向上提一下排气格栅即可顺利取出插销，拆除排气格栅。按照相同的步骤拆除剩余6条排气格栅。

![](https://wiki.bambulab.com/h2/maintenance/replace-active-chamber-exhaust/%E6%8B%86.webp)

|  |  |
| --- | --- |
|  |  |

先用刷子扫除排气格栅上的灰尘，然后使用沾了酒精的无纺布擦拭排气格栅。

|  |  |
| --- | --- |
|  |  |

若排气格栅的脏污程度非常严重，普通方式已经无法清理排气格栅。可以尝试将排气格栅直接放在水龙头下进行冲洗，同时使用刷子清理。**请注意，水洗之后一定要将排气格栅完全擦干，排气格栅周围有一些电子器件，残留的水分可能会影响这些电子器件的功能。**

![](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/image-134.png)

拆除排气格栅后，使用刷子清理风扇外侧的灰尘。

![](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/image-135.png)

清理完毕后，安装排气格栅时从下往上装，先从左侧开始，将左侧插销先放入箭头所指的孔中，同时将左侧的定位块对准圆圈所示的小孔并扣合上，然后将右侧的定位块也扣入右侧的小孔中。按照相同的步骤安装剩余6条排气格栅。

|  |  |
| --- | --- |
|  |  |

> 详细步骤可参考：[H2 系列排气格栅更换指南](../../h2/maintenance/replace-active-chamber-exhaust.md)

### 机舱内部清洁

打开打印机前门，用无尘无纺布蘸取少量酒精，清洁外框和前门内壁。

|  |  |
| --- | --- |
|  |  |

通过操作屏幕控制热床上升，清扫底部耗材废料、支撑残留。

|  |  |
| --- | --- |
|  |  |

清扫完成废料后，为底部均匀喷涂酒精，使用无纺布擦拭干净。

|  |  |
| --- | --- |
|  |  |

操作屏幕下降热床，移除打印板（轻拿轻放，避免刮擦热床表面）。

|  |  |
| --- | --- |
|  |  |

在无纺布上喷涂适量酒精，擦拭热床表面。

|  |  |
| --- | --- |
|  |  |

重点清洁热床尾部、偏移校准传感器、喷嘴硅钢片及校准贴纸区域，确保传感器表面无污渍遮挡。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/019.webp)

待酒精完全挥发后，重新放置打印板。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/037.png)

接下来使用喷涂酒精的无纺布清理清洁机舱内部实况相机和左侧辅助散热风扇。

> **清洁摄像头时，请沾少量的酒精，并在擦拭前将无纺布捏干一些，以防酒精渗入塑料外壳内部**

|  |  |
| --- | --- |
|  |  |

擦拭左右内衬的表面以及的内衬上侧，同时擦拭一下吐料组件，清理残余的耗材。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/020.png)

清洁完成后移除打印机顶盖。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/049.webp)

如下图所示，用手向下按住活性碳滤芯盖顶部，向外拉活性碳滤芯盖以解锁顶部的卡扣，拆除活性碳滤芯盖。移除活性碳滤芯时，如果表面灰尘过多请用纸垫在活性碳滤芯下方，防止灰尘掉落到打印机内部。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/044.webp)

先使用刷子清理滤芯盖正反面的灰尘，然后使用沾了酒精的无纺布将滤芯盖擦拭干净。

|  |  |
| --- | --- |
|  |  |

若滤芯盖脏污程度非常严重，普通方式已经无法清理滤芯盖。可以尝试将滤芯盖直接放在水龙头下进行冲洗，同时使用刷子清理。**请注意，水洗之后一定要将滤芯盖完全擦干，滤芯盖周围有一些电子器件，残留的水分可能会腐蚀这些电子器件。**

![](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/image-109.png)

若滤芯表面出现明显污渍、堵塞或吸附饱和，建议更换活性炭滤芯，更换时握住滤芯拉手向前拉即可取出活性炭滤芯。

|  |  |
| --- | --- |
|  |  |

H2C 有配备 4 个火焰传感器位于打印机内部四角，使用无纺布蘸取酒精擦拭，左右两侧灯条可一并清洁。

|  |  |
| --- | --- |
|  |  |

若使用为激光版本则需要清洁前方俯视相机。

|  |  |
| --- | --- |
|  |  |

### 四进一料管拓展口清洁

随着耗材长期频繁进退料，四进一料管拓展口内部易残留耗材粉末、碎屑等杂质，若不及时清理可能影响送料顺畅性，需定期开展清洁维护。

![1.jpg](https://wiki.bambulab.com/h2c/troubleshoting/period-maintenance/1.jpg)

移步至打印机背部，按住气动接头两侧，拔下拓展口两端的气动接头，取出四进一料管拓展口。

|  |  |
| --- | --- |
|  |  |

参照下图所示，使用适配H1.5螺丝刀拧下拓展口外壳上的四颗固定螺丝。

|  |  |
| --- | --- |
|  |  |

打开拓展口外壳后，先用软毛刷轻轻刷除内部腔体、通道及组件表面附着的耗材粉末与浮尘，重点清理料管通道内壁。

|  |  |
| --- | --- |
|  |  |

可以使用无纺布蘸取适量酒精，擦拭内部组件；若脏污情况较严重，可将可拆卸组件进行水洗，洗净后务必完全风干，再进行后续安装步骤。

|  |  |
| --- | --- |
|  |  |

清洁完成后，确保内部无残留污渍、粉末及水分，状态如下：

![1.jpg](https://wiki.bambulab.com/h2c/troubleshoting/period-maintenance/4.jpg)

接下来开始进行组装，将 5 颗气动接头和内部黑色导向组件，安装至拓展口主体，确保连接牢固、无松动。

|  |  |
| --- | --- |
|  |  |

最后将料线清洁刮片按照此方向下压，安装进四进一料管拓展口中，完成四进一料管拓展口的清洁与组装。

|  |  |
| --- | --- |
|  |  |

### 工具头清洁润滑

使用高温清洁海绵，清洁热端表面黑色碳化脏污。手动将热端温度调整至当前打印耗材对应的工作温度；待热端温度稳定后，手持安装好海绵的刷柄，轻轻擦拭喷嘴外壁及周边区域，直至碳化残留完全清除。

|  |  |
| --- | --- |
|  |  |

> 使用高温海绵清洁前务必蘸水清洁；详细使用安装使用指南可参考：[热端清洁海绵安装使用指南](../../general/nozzle-cleaning-sponge.md)

接下来使用无纺布蘸取酒精清洁工具头相机以及喷嘴相机。

|  |  |
| --- | --- |
|  |  |

> **工具头底部会有磁铁位置会贴有保护高温胶带（黄色/红色），注意清洁时不要移除**

由于左侧喷嘴需要长期进行上下往复运动，需要对导轨进行清洁润滑；在清洁前需要移除左侧喷嘴以及前导向盖组件。使用棉棒蘸取酒精，擦拭线轨。

|  |  |
| --- | --- |
|  |  |

> 挤出机前导向盖详细拆装步骤可参考：[H2C 挤出机前导向盖拆装指南](replace-dual-extruder-filament-guide.md)

完成清洁后为线轨加上少许润滑油。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/029.png)

升降组件维护完成后需要在屏幕操作左右喷嘴切换 3-5 次，使得油液充分浸润扩散。

![](https://wiki.bambulab.com/h2/maintenance/upgrade-component-maintenance/20250418-110134.png)

接下来对感应热端拉柄进行清洁与润滑：先拉出感应热端拉柄，用无纺布擦拭并清除其表面脏污。

![1.png](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/3.webp)

清洁完毕后涂抹润滑油，最后将拉柄装入插槽即可。

|  |  |
| --- | --- |
|  |  |

> 挤出机前导向盖详细安装步骤可参考：[H2C 挤出机前导向盖拆装指南](replace-dual-extruder-filament-guide.md)

### 热端挂架清洁润滑

使用无纺布蘸取酒精，清洁热端挂架的泊位组件、光轴。

|  |  |
| --- | --- |
|  |  |

仔细擦拭6个镭雕标记，避免脏污影响。

![img2.jpg](https://wiki.bambulab.com/h2c/maintenance/period-maintenance/img2.jpg)

完成清洁后，为热端挂架前后四根光轴涂抹润滑油。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/047.png)

上下滑动挂架，使润滑油充分扩散至直线轴承内部。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/046.webp)

完成后注意清洁溢出的多余油脂。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/036.webp)

### XY 轴清洁润滑

使用无纺布蘸取酒精，清洁X轴直线导轨，清洁完成一侧后需要将工具头移动至另一端，再次清洁，确保整个导轨得到有效清洁。

|  |  |
| --- | --- |
|  |  |

清洁完成后，为导轨均匀涂抹润滑油。

|  |  |
| --- | --- |
|  |  |

导轨底部也需要适当涂抹润滑油，注意不要挤出过多防止滴落。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/013.png)

接下来，清洁Y轴左右两侧光轴，需要确保光轴前后两端都得到有效的清洁。

|  |  |
| --- | --- |
|  |  |

接下来为左右两侧导轨涂抹润滑油。

|  |  |
| --- | --- |
|  |  |

完成润滑后，握住工具头沿最大移动范围运动 4-6 次，确保润滑油充分扩散。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/022.webp)

### Z 轴清洁润滑

清洁 Z 轴丝杆和光轴，包括左右两侧以及后方三个位置。丝杆缝隙可能有存在残留污渍需要重点清洁。注意清洁完成后需要适当升高热床，确保丝杆光轴底部也得到有效清洁。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2c/maintenance/period-maintenance/010_2.png)

分别为前后以及后方丝杆光轴进行润滑，如下图所示带有螺纹的丝杆使用润滑脂，光轴使用润滑油。

|  |  |
| --- | --- |
|  |  |

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/period-maintenance/025.png)

完成润滑后通过屏幕控制热床上下往复运动（行程覆盖全范围）3 ~ 4 次，确保润滑脂与润滑油充分扩散至传动接触面.

## 打印机校准

完成上述维护保养后，为确保打印精度与设备运行稳定性，建议通过打印机屏幕执行全面的打印校准流程，涵盖电机降噪、振动补偿、自动热床调平、喷嘴偏移校准等关键项目，校准完成后即可投入正常使用。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend/007.png)

| 感应热端硅胶套 | [更换 H2C 感应热端硅胶套](replace-induction-hotend-silicone-sleeve.md) | 如果硅胶套上有磨损迹象，或者硅胶套不能牢固地固定在热端上，则应更换硅胶套。 |
| 热端 | [更换 H2 系列普通热端](../../h2/maintenance/replace-hotend.md) | 正常情况下，打印 PLA、PETG 这类非碳纤耗材时，建议每打印5卷耗材后清洁一次热端；打印碳纤耗材时，每打印2卷耗材清洁一次热端。如果发现热端有明显的磨损导致漏料，常规清理已经无法解决问题，请更换一个新热端。 |

### 清理左喷嘴和加热组件表面

屏幕上控制喷嘴加热到 250℃ 左右，小心取下喷嘴并用干净的纸巾擦拭。

![喷嘴擦拭清理.webp](https://wiki.bambulab.com/h2/maintenance/period-maintenance/%E5%96%B7%E5%98%B4%E6%93%A6%E6%8B%AD%E6%B8%85%E7%90%86.webp)

> 建议带上隔热手套完成这项清洁工作，注意高温烫伤。

清理完喷嘴后请检查屏幕上加热组件的温度是否仍维持在 250℃，再清理加热组件表面

> H2C 左加热组件和 H2D 加热组件结构相同，操作一致。

![h2d加热组件.webp](https://wiki.bambulab.com/h2/maintenance/period-maintenance/h2d%E5%8A%A0%E7%83%AD%E7%BB%84%E4%BB%B6.webp)

### 清理感应喷嘴

受热的感应喷嘴需要通过从挂架上取下，请通过屏幕先加热喷嘴温度到 250℃，待温度达到后，卸载该喷嘴再清理。

> 建议带上隔热手套完成这项清洁工作，注意高温烫伤。
