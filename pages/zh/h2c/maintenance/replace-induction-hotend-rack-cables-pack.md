## H2C 感应热端架至MC板线缆

Vortek系统的关键连接线缆，包含两根专用线缆：

1. 热端挂架与 MC 控制板之间的通讯及供电一体化线缆，保障控制信号传输与热端挂架电力供给。
2. 拉柄解锁组件线缆，传输拉柄解锁组件内部顶杆状态信号。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-cables-pack/001.png)

## 何时更换

- 线缆断裂
- 线缆接头损坏导致通讯异常
- 拓竹技术支持建议更换

## 工具和材料

- H2.0螺丝刀
- 镊子
- 螺丝盒（非必要）

本更换流程涉及的螺丝数量较多，为避免螺丝丢失或混淆，建议提前准备螺丝收纳盒进行分类，便于后续取用。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-cables-pack/002.jpg)

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，**请关闭打印机电源并断开电源连接**，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击提交服务工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 安装新的 感应热端架至MC板线缆

### 1. 安装H2C感应热端架至MC板线缆

将感应热端架线缆插到MC板接口上，并将线缆整理至理线扣内，避免线缆杂乱松散。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-cables-pack/036.webp)

参照图示，将线缆穿过排气格栅顶部的理线扣，规范线缆走向。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-cables-pack/040.webp)

将线缆穿过打印机后方立柱，从横梁侧边的预留小孔穿出；穿出后，将线缆有序归纳至设备的理线槽内，完成整体安装与理线操作。

## 感应热端架组件校准

重新感应热端架组件后，需及时对该组件执行校准操作，确保打印机运行精度，具体步骤如下：

1. 操作打印机屏幕，点击左侧栏设置按钮 → 进入“校准”界面，选择 “感应热端架组件初始化”。

|  |  |
| --- | --- |
|  |  |

2. 点击“开始”按钮，感应热端架将自动执行预设初始化流程。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/021.png)

> **异常处理说明：** 若初始化过程中出现报错或执行失败，大概率是感应热端架组件安装偏差超出允许范围。请参照[《H2C 感应热端架手动位置标定指引》](hotend-rack-manual-position-calibration.md)，重新进行手动位置标定，完成后可再次尝试初始化操作。

## 如何验证成功

连接电源并打开打印机，检查是否可以正常取用和放置感应热端组件。
