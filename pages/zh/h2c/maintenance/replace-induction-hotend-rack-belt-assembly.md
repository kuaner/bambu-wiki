皮带组件是 vortek 系统的动力传动核心。负责将挂架电机（3513 电机）输出的旋转运动，转化为感应热端挂架的线性升降运动。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/002.jpg)

## 何时更换

皮带断裂

拓竹技术支持建议更换

## 工具和材料

H1.5螺丝刀

H2.0螺丝刀

本更换流程涉及的螺丝数量较多，为避免螺丝丢失或混淆，建议提前准备螺丝收纳盒进行分类，便于后续取用。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/001.jpg)

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，**请关闭打印机电源并断开电源连接**，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击提交服务工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 移除旧的 感应热端架皮带组件

### 1. 移除感应热端拉柄解锁组件

拔掉感应热端拉柄解锁组件连接线，使用H2.0内六角扳手移除三颗固定螺丝，取下移除感应热端拉柄解锁组件。

|  |  |
| --- | --- |
|  |  |

详细更换步骤可参考wiki：[感应热端拉柄解锁组件更换指南](replace-induction-hotend-latch-actuator.md)

### 2. 取下感应热端架组件

|  |  |
| --- | --- |
|  |  |

详细更换步骤可参考wiki：[感应热端架组件更换指南](replace-induction-hotend-rack-assembly.md)

### 3. 移除感应热端架电机保护盖

使用H2.0内六角螺丝刀移除两颗螺丝，取下感应热端架电机保护盖。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/030.png)

### 4. 移除感应热端架皮带组件

使用H2.0内六角螺丝刀，松开皮带组件顶部的两颗螺丝

|  |  |
| --- | --- |
|  |  |

使用H1.5内六角螺丝刀，分别移除两个感应热端架升降固定块上的螺丝。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/014.png)

> 注意：拆卸螺丝时，请勿误拆皮带固定螺丝，否则会导致后续安装难度大幅增加。  
> ![09732_compressed.jpg](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/09732_compressed.jpg)

接下来移除 2、4、6号刀架升降固定块，使用H1.5内六角螺丝刀移除螺丝。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/018.png)

拔出线缆接头，把线缆从走线槽中取出，移除升降固定块。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/028.webp)

从电机同步带轮处取下感应热端架皮带组件。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/024.png)

## 安装新的感应热端架皮带组件

### 1. 安装感应热端架皮带组件

安装2、4、6号刀架升降上的固定块霍尔板，将线材塞入走线槽。

|  |  |
| --- | --- |
|  |  |

使用H1.5内六角螺丝刀锁紧螺丝。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/017.png)

将皮带安装至电机同步轮，使用H1.5内六角螺丝刀，分别锁紧两个固定块上的螺丝。

|  |  |
| --- | --- |
|  |  |

使用H2.0内六角螺丝刀，锁紧皮带组件顶部的两颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 2. 皮带张紧

首先松开电机三颗固定螺丝（不用完全移除螺丝），确保电机可以轻微晃动。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/026.png)

接下来调节张紧螺丝，松紧该螺丝同时皮带会同步张紧，可以用手指感受皮带绷紧的力度。

|  |  |
| --- | --- |
|  |  |

张紧完成后重新锁紧电机三颗螺丝即完成皮带张紧。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/025.png)

### 3. 安装感应热端架电机保护盖

使用H2.0内六角螺丝刀锁紧两颗螺丝，安装感应热端架电机保护盖。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/029.png)

## 感应热端架组件校准

重新安装感应热端架组件后，需及时对该组件执行校准操作，确保打印机运行精度，具体步骤如下：

1. 操作打印机屏幕，点击左侧栏设置按钮 → 进入“校准”界面，选择 “感应热端架组件初始化”。

|  |  |
| --- | --- |
|  |  |

2. 点击“开始”按钮，感应热端架将自动执行预设初始化流程。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/021.png)

> **异常处理说明：** 若初始化过程中出现报错或执行失败，大概率是感应热端架组件安装偏差超出允许范围。请参照[《H2C 感应热端架手动位置标定指引》](hotend-rack-manual-position-calibration.md)，重新进行手动位置标定，完成后可再次尝试初始化操作。

## 如何验证成功

连接电源并打开打印机，验证是否能正常取用和放置感应热端组件，并正常读取感应热端信息。
