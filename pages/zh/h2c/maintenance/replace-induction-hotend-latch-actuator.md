## 感应热端拉柄解锁组件

感应热端拉柄解锁组件（以下简称 “拉柄解锁组件”）是感应热端解锁与锁紧功能的核心执行部件，通过机械结构控制感应热端的固定与释放。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch-actuator/007.png)

## 何时更换

出现机械损坏，无法正常实现解锁 / 锁紧功能

拓竹技术支持建议更换

## 工具和材料

H2.0螺丝刀

新的拉柄解锁组件

## 视频指南

## 移除旧的拉柄解锁组件

正式开始前请将将工具头组件移动至最后方避免拆装过程出现干涉，使用H2.0内六角螺丝刀移除三颗固定螺丝。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch-actuator/001.png)

用手指轻轻向上顶起组件上箭头标识的按键，同时沿水平方向平稳取下拉柄解锁组件，取下过程中注意连接线缆，避免拉扯。

|  |  |
| --- | --- |
|  |  |

翻转至背面移除连接线接头。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch-actuator/004.png)

## 安装新的移除拉柄解锁组件

先将线缆接头插入新拉柄解锁组件的接口，确认接头无松动；

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch-actuator/005.png)

> 如果出现线缆长度不够的情况，可以轻微用力将线缆从横梁中拉出，出厂前为了美观会将多余的线缆藏于横梁中。

如下图所示，将感应热端组件从左向右插入热端架。

|  |  |
| --- | --- |
|  |  |

> 锁紧螺丝的时候请注意避开连接线缆，避免过度挤压影响通讯。

使用H2.0螺丝刀锁紧三颗固定螺丝，安装完成后可以轻微晃动确保锁紧。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch-actuator/002.png)

## 如何验证成功

用手按压组件底部按钮，观察查看组件内部圆柱销是否能同步正常上升，且上升过程无卡顿。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch-actuator/010.webp)

接下来连接电源并打开打印机，检查是否可以正常取用和放置感应热端组件。
