## 挤出机前盖导向

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-dual-extruder-filament-guide/004.png)

**挤出机前盖导向的备件包含以下：**

1. 挤出机前盖导向 \* 1
2. M2.5x7 螺丝 \* 3

## 何时更换

- 当**挤出机前盖导向出现损坏**（如结构开裂、定位偏移、导向功能失效等）时，需及时更换。

## 工具和材料

1. 新的挤出机前盖导向
2. H2.0 内六角扳手
3. 您也选择可以在 MakerWorld 下载并打印拆装辅助工具模型，以方便您更便捷拆装。[模型链接：H2D 挤出机前盖导向拆装辅助工具](https://makerworld.com.cn/zh/models/1217253-h2d-ji-chu-ji-qian-gai-dao-xiang-chai-zhuang-fu-zh#profileId-1295106)

## 视频指南

## 移除挤出机前盖导向

### 步骤 1：移除喷嘴

- 左喷嘴：取下左喷嘴的硅胶套，打开喷嘴组件的固定卡扣，即可取出左喷嘴组件。
- 右喷嘴：向右拉动喷嘴的拉柄完成解锁，取下右喷嘴组件。

|  |  |
| --- | --- |
|  |  |

### 步骤2：移除挤出机前盖导向组件与左切刀

用 H2.0 内六角扳手拧出前盖导向上的3颗螺丝。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-dual-extruder-filament-guide/006.png)

用手指从下方向上抵住黑色喷嘴连接件，同时轻轻按压左切刀的刀柄，使左切刀从切刀螺丝附近的开口槽中脱出。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-dual-extruder-filament-guide/012.webp)

左切刀位于前盖导向中，拆除前盖导向时会被一同带出，请注意保存，防止丢失。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-dual-extruder-filament-guide/007.png)

## 安装挤出机前盖导向

### 步骤1：安装挤出机前盖导向与左切刀

左切刀需要跟随前盖导向一起安装。确保左切刀的缺口面朝上，然后将其放入前盖导向的切刀槽中。

|  |  |
| --- | --- |
|  |  |

安装前盖导向时，需要一直往上顶住黑色热端连接件；并轻微按压左切刀，将其调整到一个合适的角度便于左切刀进入，然后将前盖导向装入。最后按压两侧切刀，同时用力将前壳完全压平。

|  |  |
| --- | --- |
|  |  |

然后重新锁紧前盖导向上的3颗螺丝（M2.5x7 \* 3）。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-dual-extruder-filament-guide/005.png)

### 步骤2：安装喷嘴

**左喷嘴安装**：将左喷嘴组件放入对应装配位，扣紧固定卡扣，确保喷嘴无松动；同时装回左喷嘴的硅胶套。

|  |  |
| --- | --- |
|  |  |

**右喷嘴安装**：将右喷嘴组件对准装配位推入，按下拉柄完成锁定；之后轻轻晃动喷嘴，确认锁定到位、无松动迹象。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-dual-extruder-filament-guide/010.webp)

## 功能验证

先检查前盖导向是否有松动，然后连接电源并打开打印机，检查左右热端是否可以完成正常的打印。
