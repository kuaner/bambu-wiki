## H2C感应热端锁紧拉柄

该组件用于热端组件快速锁定与解锁。内部集成微型磁铁，配合加热组件上的霍尔传感器，可以使打印机自动识别热端当前处于锁紧或松开状态。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch/003.jpg)

## 何时更换

- 感应热端锁紧拉柄损坏
- 感应热端锁紧拉柄磨损

## 工具和材料

- 新的感应热端锁紧拉柄
- 润滑油
- H2 内六角扳手

## 视频指南

## 移除旧的感应热端锁紧拉柄

### 1. 移除热端

- 左喷嘴：取下左喷嘴的硅胶套，打开喷嘴组件的固定卡扣，即可取出左喷嘴组件。
- 右喷嘴：向右拉动喷嘴的拉柄完成解锁，取下右喷嘴组件。

|  |  |
| --- | --- |
|  |  |

### 2. 移除挤出机前盖导向组件

用手指从下方向上抵住黑色喷嘴连接件，同时轻轻按压左切刀的刀柄，使左切刀从切刀螺丝附近的开口槽中脱出。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch/010.webp)

详细更换步骤可参考wiki：[H2C挤出机前导向更换指南](replace-dual-extruder-filament-guide.md)

### 3. 移除感应热端锁紧拉柄

向右拉动感应热端锁紧拉柄，直至完全拔出。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch/009.webp)

## 安装新的感应热端锁紧拉柄

### 1. 为新的感应热端锁紧拉柄涂润滑油

如图片所示，在新的感应热端锁紧拉柄滑槽处，正反两面涂抹**润滑油**。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch/002.jpg)

### 2. 安装新的感应热端锁紧拉柄

如图片所示，有两个小方块的一面为顶面，将感应热端锁紧拉柄顶面朝上插入工具头对应滑槽。

|  |  |
| --- | --- |
|  |  |

### 3. 安装挤出机前盖导向组件

并轻微按压左切刀，将其调整到一个合适的角度便于左切刀进入，然后将前盖导向装入。最后按压两侧切刀，同时用力将前壳完全压平。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch/005.webp)

详细更换步骤可参考wiki：[H2C挤出机前导向更换指南](replace-dual-extruder-filament-guide.md)

### 4. 安装热端

**左喷嘴安装**：将左喷嘴组件放入对应装配位，扣紧固定卡扣，确保喷嘴无松动；同时装回左喷嘴的硅胶套。

|  |  |
| --- | --- |
|  |  |

**右喷嘴安装**：确认拉柄的拉出的状态，将右喷嘴组件对准装配位推入，按下拉柄完成锁定；之后轻轻晃动喷嘴，确认锁定到位、无松动迹象。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch/007.webp)

详细安装步骤可参考wiki：[H2C 感应热端安装指南](replace-induction-hotend.md)

## 如何验证成功

轻轻晃动热端，确认感应热端锁紧拉柄是否能够锁紧右热端。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-latch/013.webp)
