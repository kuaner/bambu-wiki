本文将详细介绍 H2D 升级至 H2C 的操作流程。本次升级核心是为 H2D 搭载 Vortek 系统，实现从双喷嘴到七喷嘴的进阶升级，主要涉及热床、工具头线轨、AP 板、前面盖的更换，以及热端挂架组件、拉柄解锁组件的新增安装。需说明的是，本指南基于 H2D 激光版本编写，该版本因涉及气泵的拆装流程，操作难度较 H2D 标准版略高。

本文为 **H2D 升级 H2C 指引全流程指引 - 上篇**，将聚焦核心安装步骤，具体介绍**热床、工具头线轨及 AP 板**的安装方法。

## H2D-H2C升级包

H2D 升级至 H2C 需要 5 个核心组件，分别为**工具头线轨组件、热床、AP 板、热端挂架及 Vortek 升级包**。其中，Vortek 升级包内含喷嘴偏移校准传感器、多规格备用螺丝、感应热端、专用打印板、热端挂架横梁等关键配件。

建议收到包裹后，第一时间核对包装内物料是否齐全、无缺失，具体配件明细可参考专项文档[《H2D 升级包配件清单》](../../h2d/manual/h2d-to-h2c-acc-in-the-box.md)。

> 注：部分升级包中可能额外包含一根 MC-AP 线缆，在您[更换 AP 板](https://wiki.bambulab.com/zh/h2c/maintenance/upgrade-from-h2d-to-h2c#%E7%A7%BB%E9%99%A4-h2d-ap%E6%9D%BF)时可能用到。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/039.png)

**预计更换时长：4 - 5小时**

## 准备工作

### 1. 设备注册

收到升级包后，需联系 [**Bambu Lab 技术支持**](https://bambulab.com/en/support/activate-sn)，上传**新设备序列号**与**当前设备序列号**，并填写**升级包的订单号**，用于完成新设备注册。

**新设备序列号**位于 AP 板背面，需提交该序列号对应的二维码照片，确保二维码清晰可识别。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/011.jpg)

**当前设备序列号**可在打印机屏幕的“设备和序列号”中查询，同时打印机右侧内立柱上的二维码也对应设备序列号。

|  |  |
| --- | --- |
|  |  |

详细查看指南可以参考：[如何查找序列号及注册新序列号](../../general/find-sn.md)

> 注意：设备未成功注册前，无法绑定 WiFi 和 Bambu 账号。

### 2. 升级版本固件

正式升级前，请确保打印机已更新至最新版本固件。

### 3. 工具和材料

- 升级包
- H2.0 / H1.5 内六角螺丝刀（优先使用带有磁吸的螺丝刀）
- 撬棒 或 一字螺丝刀（用于撬开 LED 灯盖和侧板）
- 头灯（可选）
- 美工刀
- 斜口钳
- 润滑油&润滑脂
- [螺丝盒](https://makerworld.com.cn/zh/models/1346631-ke-dui-die-de-xiao-ling-jian-he#profileId-1453263)（拆装过程涉及螺丝种类较多，需分类存放，避免混淆丢失）

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/003.jpg)

> [了解常见打印机螺丝](../../knowledge-sharing/common-screws.md)

## 升级步骤

### 步骤 1：更换打印机热床 （耗时约1.5个小时）

#### 移除打印机背板

首先移除料盘支架底座与安全钥匙。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/002.png)

打印机背板固定螺丝分为两种类型：可以先拆除橙色标记位置的螺丝（ST3x6），再拆除绿色标记位置的螺丝(BT3x8)。

|  |  |
| --- | --- |
|  |  |

拆除背板所有螺丝后，向上抽出背板即可。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/042.png)

#### 断开热床背部连接线

由于气泵与热床线螺丝位存在干涉，需先移除气泵：断开气泵顶部气管与线缆，拆除气泵的 5 颗固定螺丝（非激光版本可跳过此气泵操作步骤）。

|  |  |
| --- | --- |
|  |  |

向外拉出气泵，拔下连接气管时，注意避让热床线缆。

|  |  |
| --- | --- |
|  |  |

拆除废料滑梯的 1 颗固定螺丝(BT3x8)，向下取下废料滑梯。

|  |  |
| --- | --- |
|  |  |

如下图所示，断开 MC 板（运动控制板）上的 4 根线缆接头。

|  |  |
| --- | --- |
|  |  |

拆除 AC 板（交流控制板）盖的固定螺丝(BT3x8 )，取下 AC 板盖。

|  |  |
| --- | --- |
|  |  |

拧松热床线缆固定螺丝(BT3x12)，按下图所示断开 AC 板上的 3 根线缆接头（分别为棕色、蓝色、红色）。

|  |  |
| --- | --- |
|  |  |

重要提示：拆除卡扣时，需用螺丝刀抵住解锁扣后再拔出线缆，避免蛮力损坏接头。

|  |  |
| --- | --- |
|  |  |

撕开打印机底部泡棉，使用 H2.0 螺丝刀拆除热床地线固定螺丝（M3x6带垫片）。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/029.png)

#### 移除热床状态指示灯

（后续步骤需将原 H2D 状态指示灯安装至 H2C 热床，故先进行拆除）

来到打印机正面，移除打印板。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/072.webp)

从打印机内侧抓住状态指示灯，向下扣动即可取下，取下后断开指示灯线缆接头。

|  |  |
| --- | --- |
|  |  |

#### 移除右侧板

（为后续操作预留空间，建议先拆除右侧板）

来到打印机内侧，拆除顶部的 2 颗固定螺丝(BT3x8)。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/013.jpg)

转到打印机正面，扣开胶条后，拆除前门位置的 2 颗螺丝(M3x3)。

|  |  |
| --- | --- |
|  |  |

螺丝拆除后，在顶部凹槽处撕开前门胶条。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/068.webp)

分别从前方与后方扣开右侧板缝隙。

|  |  |
| --- | --- |
|  |  |

待所有卡扣松开后拔除侧板霍尔传感线线缆接头，向上提起即可取下右侧板。

|  |  |
| --- | --- |
|  |  |

#### 移除 H2D 热床

扣开热床左右两侧的硅胶块，露出热床固定螺丝。

|  |  |
| --- | --- |
|  |  |

移除热床 6 颗固定螺丝(蓝胶M3x8)，即可取下 H2D 热床。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/059.png)

提示：此处操作空间有限，建议逐根缓慢拉出热床线缆，避免线缆接头损坏。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/047.png)

#### 安装 H2C 热床

将 H2C 热床线缆逐根穿过后方 Z 轴滑块，从滑块尾部将线缆拉出。

|  |  |
| --- | --- |
|  |  |

清洁打印机底部的废料与灰尘，防止后续 Z 轴滑块压到异物，导致热床安装倾斜。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/014.png)

将 H2C 热床靠左侧板放置，随后放倒打印机。

|  |  |
| --- | --- |
|  |  |

拉动底部皮带，将 Z 轴滑块降至最底部（拉不动为止）。

|  |  |
| --- | --- |
|  |  |

将热床靠打印机底部放置，然后摆正打印机。

|  |  |
| --- | --- |
|  |  |

将热床放置在 3 个 Z 轴滑块上方。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/045.png)

> 如果您有保留开箱时的热床固定螺丝或类似螺丝(M3x35 螺纹长度8)可以将锁紧此处四颗螺丝，确保底部三个滑块完全处于同一高度，等待热床与滑块固定后再移除此处四颗螺丝。如果您没有保留着四颗螺丝可跳过此步骤，确保三颗 Z 滑块完全贴近打印机底部即可。
>
> |  |  |
> | --- | --- |
> |  |  |

最后锁紧热床与滑块连接的 6 颗固定螺丝，可以使用原有热床固定螺丝或新热床包装内附赠螺丝（蓝胶M3x8) 。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/058.png)

#### 安装喷嘴偏移传感器&状态指示灯

在 Vortek 升级包中的 4 号标签盒中找到喷嘴偏移校准传感器，将其安装至热床尾部；连接线缆接头，放入指定槽位后，使用 H1.5 螺丝刀锁紧 2 颗固定螺丝(M2x5)。

|  |  |
| --- | --- |
|  |  |

> 安装喷嘴偏移传感器时，务必注意方向，以防装反。请确认银色的擦嘴钢片位于左侧。  
> ![20251124-174738_new_compressed.jpg](https://wiki.bambulab.com/h2c/h2d-to-h2c/20251124-174738_new_compressed.jpg)

拉动底部皮带，手动升高热床，连接状态指示灯线缆，对照热床底部扣位，将状态指示灯安装到位。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/063.webp)

安装热床左右两侧的硅胶块。

|  |  |
| --- | --- |
|  |  |

#### 插接 H2C 热床连接线

来到打印机背面，先将热床线缆卡入 Z 轴滑块的理线扣内，再将线缆穿过侧边孔隙。

|  |  |
| --- | --- |
|  |  |

将热床线缆插入 AC 板对应接头（按下图所示，分别对应棕色、蓝色、红色线缆）。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/026.png)

锁紧热床地线固定螺丝(M3x3)，完成后再锁紧热床线缆固定螺丝(BT3x12)。

|  |  |
| --- | --- |
|  |  |

安装 AC 板盖，锁紧其固定螺丝(M3x8)。

|  |  |
| --- | --- |
|  |  |

插接 MC 板上的 4 根线缆接头，并将线缆卡入 AC 板盖的理线槽内，避免线缆松动。

|  |  |
| --- | --- |
|  |  |

#### 安装内置气泵（非激光版可跳过此步骤）

连接气泵气管，安装内置气泵时，注意避开热床线缆。

|  |  |
| --- | --- |
|  |  |

锁紧气泵的 5 颗固定螺丝，完成安装后需要确保热床线需要位于气泵后方，如下图所示。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/007.jpg)

> 底部三颗和侧板附近固定螺丝为M3x4，左侧靠近线扣一端的螺丝为BT3x5。

连接气泵供电线缆，并插接气管，最后将气管整理至 AC 板盖理线槽内。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：更换工具头线轨组件 （耗时约 50 分钟）

工具头线轨组件内会附赠工具以及备用螺丝，找到以下长柄和短柄螺丝刀，用于工具头线轨特殊部位的拆装。

![1280x1280.jpeg](https://wiki.bambulab.com/h2c/h2d-to-h2c/1280x1280.jpeg)

#### 移除 AP 板盖

在打印机机舱内，拆除 AP 板盖的 1 颗固定螺丝，然后缓慢向外拉出 AP 板盖。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/volume-two/027.png)

#### 移除 H2D 工具头线轨组件

断开 AP 板（应用处理板）上的工具头 USB-C 线缆，并从 3 个线扣中取出该线缆。（部分版本为 4 个线扣）

|  |  |
| --- | --- |
|  |  |

找到 MC 板（运动控制板）与 TH 板（工具头主板）之间的两根连接线（分别为 TH 供电线缆和通讯线缆），按压接头卡扣解锁后，断开两个接头。

|  |  |
| --- | --- |
|  |  |

转到打印机背面，拆除背后 4 颗缓冲器固定螺丝，松开缓冲器（无需拔出缓冲器线缆）。

|  |  |
| --- | --- |
|  |  |

按下图所示，向下按压拖链右上角，使其从卡槽中脱出，再用力拔出整段拖链。

|  |  |
| --- | --- |
|  |  |

使用一字螺丝刀或撬棒，撬开左右两侧的 LED 灯盖。

|  |  |
| --- | --- |
|  |  |

拆除工具头皮带固定座的 6 颗螺丝（左右两侧各 3 颗）。

|  |  |
| --- | --- |
|  |  |

在工具头左右两侧粘贴胶带，防止移除线轨组件时工具头脱出线轨。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/volume-two/035.png)

> 以下操作极易造成螺丝滑牙，务必严格遵循教程：需将螺丝刀穿过泡棉及预留孔后再拧动拆卸，**严禁从螺丝侧面斜向施力拧动**。

打印机顶部设有专用螺丝刀插孔，使用长柄内六角扳手，穿过顶部泡棉，移除下方对应螺丝。

|  |  |
| --- | --- |
|  |  |

转到工具头后方，用 H2.0 内六角螺丝刀拧松两侧后方螺丝（左右各 2 颗）。

|  |  |
| --- | --- |
|  |  |

拧松底部螺丝（左右两侧各 1 颗）。

|  |  |
| --- | --- |
|  |  |

拆除全部 8 颗螺丝后，前后轻微倾斜线轨组件，即可完整取下。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/volume-two/046.png)

#### 安装 H2C 工具头线轨组件

将左右两侧的滑块移动到一前一后的位置，倾斜放入工具头线轨组件。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/volume-two/059.webp)

> 注意：工具头线轨组件未完全安装到位前，禁止剪断左右两侧的扎带。

安装完成后，向前推动线轨直至无法移动，通过前门立柱限位，确保线轨保持平行。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/volume-two/060.webp)

锁紧线轨组件的 8 颗螺丝：先锁紧左右两侧顶部螺丝（红胶M3x6），垂直向下操作时螺丝易滑脱，建议使用带磁吸功能的螺丝刀。

|  |  |
| --- | --- |
|  |  |

接着锁紧线轨组件后方螺丝（BT3x8），左右各 2 颗。

|  |  |
| --- | --- |
|  |  |

最后锁紧底部螺丝（红胶M3x6），左右各 1 颗。

|  |  |
| --- | --- |
|  |  |

使用斜口钳剪断左右两侧扎带。

|  |  |
| --- | --- |
|  |  |

将皮带固定座装入工具头对应槽位，锁紧两侧固定螺丝（蓝胶M3x8），左右各 3 颗：先预锁紧中间螺丝，再依次锁紧上下两颗，最后再次加固中间螺丝，确保固定牢固。

|  |  |
| --- | --- |
|  |  |

先将拖链末端压入槽内，再用力向左推，使其卡入卡槽固定。

|  |  |
| --- | --- |
|  |  |

重新连接 MC-TH 线的两个插头，并将线缆穿过理线扣，整理妥当。

|  |  |
| --- | --- |
|  |  |

安装缓存缓冲器组件，并锁紧背后四颗固定螺丝（无需安装背板）。

|  |  |
| --- | --- |
|  |  |

对准打印机上框卡槽，安装左右两侧 LED 灯盖并按压固定。

|  |  |
| --- | --- |
|  |  |

### 步骤 3：更换AP板 （20 分钟）

#### 移除 H2D AP板

断开 AP 板上的连接线，AP 板有 3 根排线，需打开接头卡扣后再移除，此步骤无需断开 WiFi 天线。

|  |  |
| --- | --- |
|  |  |

使用 H2.0 内六角扳手，拧松 4 颗 AP 板固定螺丝（BT3x5），取下 AP 板后，再断开 WiFi 天线。

|  |  |
| --- | --- |
|  |  |

> 取下 AP 板后请检查设备原装的 MC-AP 线缆，与新 AP 版自带的 MC-AP 线缆是否完全一致。如线芯数量不同，请参考[更换 H2 系列 MC-AP 线](../../h2/maintenance/replace-mc-ap-cable.md)更换。

> |  |  |
> | --- | --- |
> | 线芯少 | 线芯多 |

#### 安装 H2C AP板

先连接 WiFi 天线，避免 AP 板固定后安装困难；将 AP 板对准上框螺丝孔位，用 H2.0 螺丝刀锁紧 4 颗固定螺丝（BT3x5），同时将地线安装至左下角对应螺丝位。

|  |  |
| --- | --- |
|  |  |

连接 AP 板相关线缆，共需安装 10 个线缆接头，具体对应如下：

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/volume-two/005.jpg)

1. 俯视相机排线（激光版本配备）
2. 屏幕排线
3. 右 LED 灯
4. 左 LED 灯
5. WiFi 天线
6. USB 接口板
7. MC-AP 线缆（通信）
8. MC-AP 线缆（供电）
9. 实况摄像头排线
10. 工具头 USB-C 线缆

**注意：安装工具头 USB-C 线缆时，需确保带有字母 “A” 的一面朝外。**

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/volume-two/015.png)

#### 安装 AP 板盖

从靠近打印机背部的一侧开始安装 AP 板盖，确保盖体右侧与缓冲器齐平，再将整个 AP 板盖压入槽位卡紧。

|  |  |
| --- | --- |
|  |  |

最后使用 H2.0 内六角螺丝刀锁紧一颗固定螺丝（BT2.6x8）。

![](https://wiki.bambulab.com/h2c/h2d-to-h2c/volume-two/024.png)
