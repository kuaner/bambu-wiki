## 感应热端硅胶套

感应热端硅胶套覆盖于感应热端头部，核心作用是为喷嘴区域保温，同时隔绝杂质，避免耗材脏污喷嘴影响打印效果。

![1.jpg](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-silicone-sleeve/1.jpg)

## 感应加热组件底座硅胶套

该硅胶套安装于感应热端加热组件的底座上，作用是防止耗材粘附，避免产生裹头。

![silicone_sleeve_for_h2c_induction_heating_assembly_base.png](https://wiki.bambulab.com/h2c/maintenance/replace-induction-hotend-silicone-sleeve/silicone_sleeve_for_h2c_induction_heating_assembly_base.png)

## 何时更换

硅胶套出现破损、开裂或老化变形

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除旧的感应热端硅胶套

在热端找到以下豁口位置。

![1.jpg](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-silicone-sleeve/4.png)

沿豁口位置向上发力，即可轻松扣下旧硅胶套。

![c0318.webp](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-silicone-sleeve/c0318.webp)

## 安装新的感应热端硅胶套

分别找到感应热端上的定位凹槽与硅胶套的凸起结构，将两者对齐。

![1.jpg](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-silicone-sleeve/3.png)

将硅胶套的凸起部分对准热端凹槽按压嵌入，随后压紧硅胶套两侧以初步固定。

|  |  |
| --- | --- |
|  |  |

缓慢旋转硅胶套，同时向内均匀施压，确保贴合紧密。

![1.jpg](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-silicone-sleeve/2.webp)

检查硅胶套是否存在翘起部位，如果存在将翘起处按压嵌入对应热端凹槽，完成安装。

![1.jpg](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-silicone-sleeve/8.jpg)

安装完成后效果如下。

![1.jpg](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-silicone-sleeve/7.jpg)
