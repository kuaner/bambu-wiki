## 故障现象

在 H2C 感应热端加热组件上安装有一个传感器，主要用于检测感应热端是否正确安装。当该传感器的信号链路发生短路时，则会出现该报错信息。

![induction_heating_assembly_sensor.png](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_3000_0001_0041/induction_heating_assembly_sensor.png)

## 排查步骤

### 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 1. 关闭打印机电源

![](https://wiki.bambulab.com/h2c/manual/packing/3.png)

### 2. 裸露感应热端加热组件连接线接头

请参考这篇 wiki：[更换 H2D 部件冷却风扇指南](../../../h2/maintenance/replace-part-cooling-fan.md) 或下方视频（前1分40秒的内容）来移除部件冷却风扇风道和部件冷却风扇，裸露出 TH 板。

### 3. 拔插连接线

如图所示，打开感应加热组件信号线卡扣，断开并重新连接该线缆，注意避免暴力拉扯。

> **注意**：线缆插头被卡扣压住，需要先解锁卡扣，再拔出线缆。

|  |  |
| --- | --- |
|  |  |
| 拔出线缆 | 连接线缆 |

### 4. 重启打印机，检查告警是否消失

若告警消失，则问题解决。

若告警依旧存在，则需要更换感应热端加热组件，具体步骤请参考这篇 wiki：[更换 H2C 感应热端加热组件](../../maintenance/replace-induction-heating-assembly.md) 或下方视频。
