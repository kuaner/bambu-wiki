## 故障描述

热端挂架在执行粗回中过程中，受阻挡导致粗回中失败

**故障发生时有何现象：**

- 单独发送粗回中指令时：

  - **空闲状态下报错：** `07008036`
  - **打印过程中报错：** `07008035`
- 在其他换刀状态下触发的粗回中失败：会出现与该状态对应的其他错误码（以实际界面提示为准）

**可能原因：**

- 粗回中运动路径被异物阻挡
- 感应热端架运动卡涩
- 感应热端架粗回中霍尔或磁铁异常

## 故障定位与解决流程

1. 检查感应热端架上是否有异物阻塞

   - 检查是否有明显异物
   - 检查打印板是否放歪了导致阻塞感应热端架运动
   - 检查是否有热端掉落吸在感应热端架框架上面阻塞感应热端架运动
2. 手动拖动感应热端架，测试能否无阻塞完成全行程并排查阻塞异物

   - 若无异物但阻力较大：考虑光轴/直线轴承需要清洁与润滑
   - 若无明显阻力且粗回中能走完整个行程仍失败：需更换粗回中霍尔和磁铁。

## 排故措施

***用户可视情调整各排故措施的顺序。***

### 步骤 1. 检查感应热端架上是否有异物阻塞

将发现的阻塞物移除。清理完毕后，再次检查行程是否顺畅无干涉。

### 步骤 2. 无异物阻塞运动，运动阻力较大

对感应热端架光轴进行清洁与润滑，具体步骤如下：

1. 准备无纺布与酒精，用无纺布蘸取适量酒精，仔细擦拭热端挂架（含泊位组件）及光轴表面，去除油污、粉尘等杂质。

|  |  |
| --- | --- |
|  |  |

2. 清洁工作完成后，在热端挂架的前后四根光轴上均匀涂抹润滑油。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1100_0002_0002/3.png)

3. 缓慢上下滑动热端挂架，让润滑油充分渗透并扩散至直线轴承内部，确保润滑覆盖全面。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1100_0002_0002/4.webp)

4. 操作结束后，及时用无纺布清理光轴及挂架表面溢出的多余油脂，避免残留杂质粘连。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1100_0002_0002/5.webp)

### 步骤 3. 更换感应热端架皮带组件

若为粗回中霍尔异常，可参考 [更换 H2C 感应热端架皮带组件](../../maintenance/replace-induction-hotend-rack-belt-assembly.md) 完成感应热端架皮带组件的更换。更换后需重新执行粗回中操作，若报错仍未消除，继续进行下一步。

### 步骤 4. 更换感应热端架框架

若为粗回中磁铁异常，可参考 [更换 H2C 感应热端架框架](../../maintenance/replace-induction-hotend-rack-frame.md) 进行感应热端架框架的更换操作。
