## 故障描述

热端挂架位置检测传感器用于感知热端挂架升降的位置。当热端挂架控制板发现该传感器信号异常时，会弹出此告警。

![h2c_hall_sensor_for_homing_on_induction_hotend_rack.png](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_3300_0001_0040/h2c_hall_sensor_for_homing_on_induction_hotend_rack.png)

**可能的原因：**

- 热端挂架位置检测传感器上连接器松动；
- 热端挂架控制板上对应的连接器松动；
- 热端挂架位置检测传感器故障；
- 热端挂架控制板故障。

## 所需工具和材料

- H1.5 内六角扳手

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 排查步骤

### 步骤 1. 按压热端挂架位置检测传感器上的连接器

1. 在打印机屏幕上，将热床降至较低位置，留出操作空间。然后，关闭打印机电源。

|  |  |
| --- | --- |
|  |  |

2. 找到传感器的位置。

![h2c_hall_sensor_for_homing_on_induction_hotend_rack.png](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_3300_0001_0040/h2c_hall_sensor_for_homing_on_induction_hotend_rack.png)

3. 如下图所示，用手指或螺丝刀向上按压连接器，确保连接器不松动。

![press_connector_upward_to_ensure_secure_connection.webp](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_3300_0001_0040/press_connector_upward_to_ensure_secure_connection.webp)

4. 重启打印机，检查报错提示是否消除。若未消除，请继续下一步。

### 步骤 2. 重新连接热端挂架控制板上的传感器接线

1. 参考这篇wiki：[更换 H2C 感应热端架控制板](../../maintenance/replace-induction-hotend-rack-control-board.md)，取下感应热端架组件，裸露出感应热端架控制板。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-control-board/006.png)

2. 检查挂架控制板上4号连接线是否松动，并重新拔插。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-control-board/008.png)

3. 参考这篇wiki：[更换 H2C 感应热端架控制板](../../maintenance/replace-induction-hotend-rack-control-board.md)，将热端挂架装回。
4. 重启打印机，检查报错提示是否消除。若未消除，请继续下一步。

### 步骤 3. 更换感应热端架皮带组件

若前序报错未消除，则可能是热端挂架位置传感器发生故障，该组件与皮带相连，因此，请参考 [更换 H2C 感应热端架皮带组件](../../maintenance/replace-induction-hotend-rack-belt-assembly.md) 更换感应热端架皮带组件。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/024.png)

### 步骤 4. 更换热端挂架框架

1. 若参考步骤 3 更换了皮带组件后问题仍然存在，请参考这篇wiki：[更换 H2C 感应热端架框架](../../maintenance/replace-induction-hotend-rack-frame.md)，更换热端挂架框架。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-frame/009.png)

2. 重启打印机，检查报错提示是否消除。若未消除，请继续下一步。

### 步骤 5. 更换热端挂架控制板

请参考这篇wiki：[更换 H2C 感应热端架控制板](../../maintenance/replace-induction-hotend-rack-control-board.md)，更换热端挂架控制板。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-control-board/006.png)
