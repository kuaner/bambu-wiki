## 故障描述

感应热端挂架回中过程中，挂架电机通过实时检测运动阻力，以确定挂架的上下限位位置。  
若挂架在正常行程范围内被异物阻挡，会导致运动阻力异常增大，进而造成系统获取的上下限位坐标偏差。设备检测到该异常后会自动重试回中操作，多次重试仍存在坐标偏差时，系统将弹出此告警。

**可能原因：**

- 挂架正常行程范围内受到异物阻挡。

## 故障排除

### 步骤 1. 排查运动范围内异物干扰

观察感应热端挂架的整个运动行程，检查是否存在异物阻挡（常见异物包括耗材丝残渣、感应热端脱落部件等），若有异物需及时清理。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_e000_0001_0005/1.jpeg)

### 步骤 2. 检查打印板放置是否正确

确认打印板摆放位置正确，确保感应热端挂架运动时，不会与打印板发生碰撞或干涉。

|  |  |
| --- | --- |
| 放置错误，打印板和端架存在干涉 | 放置正确，无干涉 |

### 步骤 3. 手动检测挂架移动顺畅度

> **提示：** 先将工具头移至机箱后部，避免感应热端拉柄解锁组件顶出后与同步带发生干涉。

|  |  |
| --- | --- |
|  |  |

随后用手拉动感应热端挂架，在上下限位之间往返移动，检查其运动是否顺滑无卡顿、无明显阻力。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_e000_0001_0005/6.webp)

完成上述检查与处理后，在设备屏幕上点击 “回中”，尝试感应热端挂架回中操作。若未弹出告警，则故障已解决。若按以上流程操作后仍出现告警，需录制感应热端挂架回中全过程的视频，提交售后工单时同步上传设备日志，以便售后技术支持进一步定位问题、提供精准协助。
