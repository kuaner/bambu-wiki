## 故障描述

右热端散热片用于为喉管（Heatbreak）散热，系统通过温度传感器实时监测温度，以避免因热爬升造成堵头。

当右热端散热片温度传感器异常时，系统无法准确监测喉管温度。为保障散热效果，散热风扇会自动维持高转速；建议在设备空闲时对温度传感器进行排查。

**可能的原因：**

- 右热端 NTC 温度传感器线缆破损/接触不良
- NTC传感器损坏

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，**请关闭打印机电源并断开电源连接**，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 故障定位与解决流程

1. 检查NTC温度传感器线缆是否破损
2. 若未发现线缆破损，则是NTC温度传感器损坏。

## 排故措施

### 步骤 1. 检查NTC温度传感器线缆是否破损

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0300_ab00_0002_0003/image.png)

若未发现线缆破损，多为 NTC 温度传感器损坏。请继续参考 [步骤 2 更换损坏的感应热端组件](#second)

### 步骤 2. 更换损坏的感应热端组件

1. 在屏幕上依次点击：“**控制**” - “**喷嘴与挤出机**” - “**热端 & 挂架**”，进入热端 & 挂架设置页面。

|  |  |
| --- | --- |
|  |  |

2. 在感应热端架页面，点击一个空闲的热端架编号，随后点击放置按钮；工具头上挂载的热端将自动放回该热端架。

|  |  |
| --- | --- |
|  |  |

3. 此时，工具头会移动到对应泊位上方放置感应热端。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend/022.webp)

4. 工具头完成放置后，用手从热端架取下需更换的热端，并装上新的感应热端。

|  |  |
| --- | --- |
|  |  |

更多方法请参考 [更换 H2C 感应热端组件](../../maintenance/replace-induction-hotend.md)。
