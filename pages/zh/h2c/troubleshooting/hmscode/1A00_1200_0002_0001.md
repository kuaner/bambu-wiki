## 故障描述

在执行热端挂架位置标定过程中，左侧感应热端会通过升温并触碰热床上的喷嘴偏移校准传感器（热敏纸），在热敏纸纸上留下清晰的白色印记，随后工具头相机拍摄此标记以完成相对位置标定。如果该热敏纸标记区域存在脏污、残留异物或物理磨损等情况，将干扰工具头相机对白色印记的准确识别和定位，从而导致感应热端初始化标定和摄像头位置标定失败。

**可能原因：**

- 环境温度较低，热敏纸印记过快消失，导致工具头相机未拍到标记点。
- 热床上热敏纸区域存在料屑等杂物；
- 喷嘴上存在擦嘴未清除的残料；
- 热床热敏纸破损。

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，**请关闭打印机电源并断开电源连接**，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 工具、设备及材料

- H1.5 内六角扳手

## 故障定位与解决流程

1. 环境温度较低，热敏纸印记过快消失，导致工具头相机未拍到标记点。
2. 检查热床喷嘴偏移校准传感器热敏纸位置是否有料屑等杂物
3. 检查喷嘴上是否存在擦嘴未擦掉的残料
4. 检查热床喷嘴偏移校准传感器热敏纸是否破损

## 排故措施

### 步骤 1. 确认是否环境温度较低

当打印机处于低于 20°C 的低温环境，或有冷气流直接吹时，热端在热敏纸上留下的白色标记（印记）会因冷却过快而迅速消失，导致工具头相机无法捕获有效数据，从而影响初始化操作。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1200_0002_0001/00.png)

1. 请确保打印机顶盖处于关闭状态，以隔绝外部冷空气。
2. 将腔温设定为 40℃，减缓标记的消退速度，待腔温高过 35℃ 以后再进行热端挂架初始化校准。

> 重要提醒：若挤出机中有料线，在设定腔温时，为了避免耗材软化堵头，请先按照提示执行工具头退料动作，再设置腔温。

### 步骤 2. 热床喷嘴偏移校准传感器热敏纸位置有料屑等杂物

若发现该位置存在料屑等杂物，需先清理干净，再重新发起标定。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1200_0002_0001/00.png)

### 步骤 3. 喷嘴上存在擦嘴未擦掉的残料

若发现喷嘴上有擦嘴未清除的残料，需先清理干净，再重新发起标定。

### 步骤 4. 热床喷嘴偏移校准传感器热敏纸是否破损

热床喷嘴偏移校准传感器热敏纸样式如下所示，若发现热敏纸存在破损，需更换完好的热敏纸后，再重新发起标定。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1200_0002_0001/01.png)

1. **移除喷嘴偏移校准传感器**

使用 H1.5 内六角扳手移除两颗喷嘴偏移校准线圈的固定螺丝（M2x5），随后向上提起校准线圈并断开连接线。

|  |  |
| --- | --- |
|  |  |

2. **安装喷嘴偏移校准传感器**

将喷嘴偏移校准线圈与热床连接线连接，并使用 H1.5 内六角扳手拧紧两颗喷嘴偏移校准线圈的螺丝（M2x5）。
