## 故障描述

从 1 槽位取用热端时，设备检测到异常

**可能原因：**

- 热端锁紧拉柄未完全拉开
- 感应热端顶部残留有过长的耗材
- 感应热端与工具头连接处有异物卡住，或有料线伸出干扰。
- 感应热端与感应热端组件之间存在异物
- 感应热端架的运动轨迹被异物卡住

## 工具、设备及材料

- H1.5 六角扳手

## 故障定位与解决流程

***用户可视情调整各排故措施的顺序。***

### 步骤 1. 检查热端锁紧拉柄状态

观察工具头上的热端锁紧拉柄，确认是否处于完全拉开状态。若未拉开，将拉柄彻底拉开即可。

|  |  |
| --- | --- |
|  |  |

### 步骤 2. 检查感应热端顶部残余耗材

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0033/image-2.png)

查看 1 槽位内感应热端的顶部，确认是否有过长的残余耗材。若存在过长料线，用工具剪掉多余部分。

### 步骤 3. 检查工具头料线伸出情况

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0033/image-1.png)

观察工具头与热端连接的对应位置，确认是否有料线伸出。若有料线伸出，直接切断料线。

### 步骤 4. 若热端和工具头固定槽上下连接处有异物卡住

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0033/image.png)

仔细查看热端与工具头固定槽的上下连接处，确认是否有异物卡住。若发现异物，清除异物后重试。

### 步骤 5. 若有异物卡住感应热端挂架运动

观察感应热端架的运动轨迹，检查是否有异物卡住导致其无法正常活动。若存在阻碍异物，请清理异物。
