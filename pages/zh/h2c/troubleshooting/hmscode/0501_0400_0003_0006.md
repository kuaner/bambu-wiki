## 故障描述

长时间打印后，因感应热端挂架的光轴与锁紧拉柄频繁运动可能出现磨损，表现为：

- 自动热端切换成功率下降
- 自动取放时定位误差增大
- 打印表面质量变差，甚至热端切换失败

设备会根据你的打印行为自动评估润滑消耗，并在合适时机提示你进行维护。

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，**请关闭打印机电源并断开电源连接**，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击提交服务工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 工具、设备及材料

- H1.5 六角扳手

## 故障定位与解决流程

1. 断电后，手动拖动感应热端架，确认可覆盖完整行程且无明显阻力
2. 检查锁紧拉柄功能，确认是否能正常将热端锁紧

## 排故措施

### 情况 1. 感应热端架运动阻力过大

对挂架光轴进行清洁与润滑，具体步骤如下：

1. 准备无纺布与酒精，用无纺布蘸取适量酒精，仔细擦拭热端挂架（含泊位组件）及光轴表面，去除油污、粉尘等杂质。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0501_0400_0003_0006/050.webp)

2. 清洁工作完成后，在热端挂架的前后四根光轴上均匀涂抹润滑油。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0501_0400_0003_0006/047.png)

3. 缓慢上下滑动热端挂架，让润滑油充分渗透并扩散至直线轴承内部，确保润滑覆盖全面。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0501_0400_0003_0006/046.webp)

4. 操作结束后，及时用无纺布清理光轴及挂架表面溢出的多余油脂，避免残留杂质粘连。
5. 完成后手动拖动感应热端架，运动应顺畅、异响消除。

### 情况 2. 感应热端锁紧拉柄磨损

1. **移除热端**

- **左喷嘴：** 取下左喷嘴的硅胶套，打开喷嘴组件固定卡扣，取出左喷嘴组件。
- **右喷嘴：** 向右拉动喷嘴的拉柄完成解锁，取下右喷嘴组件。

|  |  |
| --- | --- |
|  |  |

2. 参考 [H2C挤出机前导向更换指南](../../maintenance/replace-dual-extruder-filament-guide.md) 中的步骤拆下挤出机前盖导向组件。
3. 向右拉动感应热端锁紧拉柄，直至完全拔出。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0501_0400_0003_0006/009.webp)

4. 在新的感应热端锁紧拉柄滑槽处，正反两面涂抹**润滑油**。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0501_0400_0003_0006/002.jpg)

5. 将感应热端锁紧拉柄顶面朝上插入工具头对应滑槽内。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0501_0400_0003_0006/006.webp)

> 如何识别顶面：如下图所示，带两个小方块的一面为顶面。
>
> ![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0501_0400_0003_0006/004.png)

6. 参考 [H2C挤出机前导向更换指南](../../maintenance/replace-dual-extruder-filament-guide.md) 中的步骤重新安装挤出机前导向盖
7. **安装热端**

- **左喷嘴安装：** 将左喷嘴组件放入装配位，扣紧固定卡扣，确认喷嘴无松动；装回左喷嘴硅胶套。

|  |  |
| --- | --- |
|  |  |

- **右喷嘴安装：** 确认拉柄处于拉出状态，将右喷嘴组件对准装配位推入，按下拉柄完成锁定；轻轻晃动喷嘴，确认锁定到位、无松动。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0501_0400_0003_0006/007.webp)

更加详细的感应热端安装步骤可参考 [H2C 感应热端安装指南](../../maintenance/replace-induction-hotend.md)。
