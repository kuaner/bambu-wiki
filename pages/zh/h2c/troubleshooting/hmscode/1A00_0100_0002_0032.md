## 故障描述

从 1 槽位取用热端时，设备检测到异常.

**可能原因：**

- 感应热端与感应加热组件之间存在异物
- 感应热端背面的磁铁出现破损，或从安装位置脱落。
- 感应热端架的标定数据异常，距离上次标定后结构发生变动，导致定位不准。
- 感应加热组件上的霍尔传感器工作异常。

## 工具、设备及材料

- H1.5 六角扳手

## 故障定位与解决流程

***用户可视情调整各排故措施的顺序。***

### 步骤 1.检查异物阻挡情况

|  |  |
| --- | --- |
|  |  |

若发现异物，请清除异物，然后重新尝试热端取用与安装操作，验证故障是否排除。

### 步骤 2. 检查感应热端背面磁铁是否破损或脱落

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0032/image.png)

取出感应热端，观察其背面的磁铁，确认是否存在破损、脱落等情况。若磁铁破损或脱落，说明该感应热端损坏，请参考 [更换 H2C 感应热端组件](../../maintenance/replace-induction-hotend.md) 更换感应热端组件

### 步骤 3. 若感应热端泊位组件未卡入热端散热片

1. 点击左侧栏 “设置” 按钮，进入 “校准” 界面，选择 “感应热端架组件初始化”

|  |  |
| --- | --- |
|  |  |

2. 点击 “开始” 按钮，感应热端架将自动执行预设初始化流程

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0023/3.png)

> **异常处理说明：** 若初始化过程中报错或执行失败，大概率是感应热端架组件安装偏差超出允许范围。需参照 [H2C 感应热端架手动位置标定指引](../../maintenance/hotend-rack-manual-position-calibration.md)，重新进行手动位置标定，完成后可再次尝试初始化操作。

### 步骤 4. 更换感应加热组件

经上述三步检查均无异常，或标定后故障仍未排除，说明感应加热组件上的霍尔传感器损坏。请参考 [更换 H2C 感应热端加热组件](../../maintenance/replace-induction-heating-assembly.md) 更换感应加热组件
