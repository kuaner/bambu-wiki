## 故障描述

从 1 槽位取用热端时，设备检测到异常.

**可能原因：**

- 工具头的右喷嘴位置已预先安装有感应热端，导致无法从 1 槽位取用新热端。
- 工具头右部霍尔传感器的对应位置，粘连有磁铁
- 工具头右感应加热组件上的霍尔传感器发生损坏

## 工具、设备及材料

- H1.5 六角扳手

## 故障定位与解决流程

***用户可视情调整各排故措施的顺序。***

### 步骤 1. 检查工具头右喷嘴是否已安装感应热端

观察工具头右喷嘴位置，确认是否已安装有感应热端。若已安装，取下该热端

|  |  |
| --- | --- |
|  |  |

### 步骤 2. 检查霍尔传感器对应位置是否粘连磁铁

若右喷嘴未安装热端，进一步查看工具头右部霍尔传感器的对应位置。发现有磁铁粘连，请清理掉磁铁。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0031/image.png)

#### 步骤 3. 更换感应加热组件

经上述两步检查均无异常，说明故障原因是工具头右感应加热组件上的霍尔传感器损坏。请参考 [更换 H2C 感应热端加热组件](../../maintenance/replace-induction-heating-assembly.md) 更换感应加热组件。
