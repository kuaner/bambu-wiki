## 故障描述

向 1 槽位放置热端时，设备检测到异常，随即暂停热端切换流程。

**可能原因：**

- 上一次热端放置操作已显示完成，但在流程最后的锁定阶段，热端发生掉落，用户未观察到该异常情况，直接点击 “继续” 导致后续放置 1 槽位时触发故障。

## 故障定位与解决流程

1. 解锁并取下异常热端：向右拉动感应热端的锁紧拉柄，完成感应热端解锁；用手捏住热端的喷嘴末端，斜向用力拉动，将热端从当前位置取下。

|  |  |
| --- | --- |
|  |  |

2. 将取下的感应热端，放置到指定槽位。
