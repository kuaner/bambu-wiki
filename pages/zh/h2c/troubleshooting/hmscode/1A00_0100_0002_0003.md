## 故障描述

更换热端前的自检过程中，系统检测到：**需要取用的槽位未安装感应热端**。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0003/1.jpg)

感应热端挂架如上图所示，共 **6 个感应热端组件**，分别放置在对应的感应热端泊位组件上，**序号从左到右 1 至 6**。

**故障现象：** 报错 `07008030`。

**可能的原因：**

- 感应热端架对应位置未安装感应热端组件
- 安装在对应位置的感应热端组件和感应热端泊位组件之间有异物阻挡
- 安装在对应位置的感应热端组件正面磁铁损坏
- 感应热端泊位组件对应位置霍尔传感器损坏

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，**请关闭打印机电源并断开电源连接**，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 故障定位与解决流程

1. 检查对应位置是否未安装感应热端组件
2. 如果发现已安装有感应热端组件，取下检查是否有异物卡在感应热端组件和感应热端泊位组件中间
3. 检查感应热端组件正面磁铁是否脱落、破损
4. 上述检查都没有问题说明是感应热端泊位组件霍尔传感器损坏，需要更换对应的感应热端泊位组件

## 排故措施

***用户可视情调整各排故措施的顺序。***

### 步骤 1. 检查感应热端架对应位置是否安装感应热端

若未安装，则按需安装后重试。您可参考如下步骤进行安装：

1. 在挂架上放置所需热端，如下图所示：

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0003/2.webp)

2. 点击热端架上所需的热端编号，点击 “**取用**” 按钮，设备将自动安装选中的热端至工具头。

|  |  |
| --- | --- |
|  |  |

详细操作可参考：[感应热端组件](../../maintenance/replace-induction-hotend.md)

### 步骤 2. 取下感应热端，检查是否有异物

若发现有异物卡在感应热端组件与感应热端泊位组件之间，请清理后重试。

### 步骤 3. 检查感应热端正面磁铁

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0003/5.png)

若磁铁破损或掉落，则该感应热端组件损坏，请更换新的感应热端组件。

### 步骤 4. 更换感应热端泊位组件

若上述检查均无异常，说明 **对应位置的霍尔传感器可能损坏**，需更换该 **感应热端泊位组件**。

1. **移除旧的感应热端泊位组件**

- 升起需要更换的感应热端架，取下该泊位上的感应热端；使用 **H2.0** 内六角螺丝刀移除两颗固定螺丝。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0003/6.png)

- 拿起感应热端泊位组件，断开连接线，取下感应热端泊位件组件。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0003/7.webp)

2. **安装新的感应热端泊位件组件**

- 感应热端泊位组件出厂时未粘贴数字贴纸，包装内附赠数字 **1–6** 的贴纸一套。请按需粘贴在更换的泊位组件上，以便正确区分序号。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0003/8.jpg)

- 将连接线插入新的感应热端泊位件组件，并将线缆整理入线槽。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0003/9.png)

- 使用 **H2.0** 内六角螺丝刀锁紧两颗螺丝，固定新的感应热端泊位件组件。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0003/10.png)
