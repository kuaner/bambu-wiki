## 故障描述

在低温料打印时，若腔体温度超过阈值，工具头热端存在堵头风险，需及时为腔体降温。出现本 HMS 提示，表示散热片温度已偏高；若不及时降低腔温，散热片温度可能继续上升。为避免热端堵头，当散热片温度过高时系统会自动暂停打印，请尽快降低腔体温度以使散热片降温。

**可能原因：**

1. 排气格栅、顶部自动风门未开启或被异物遮挡。
2. 打印机外部环境温度过高、通风不良。

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，**请关闭打印机电源并断开电源连接**，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>

## 排故措施

### 步骤 1. 检查排气格栅和顶部自动风门是否正常打开

排气格栅：

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0300_ab00_0002_0002/2.png)

顶部自动风门：

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0300_ab00_0002_0002/1.webp)

若存在异物遮挡，请清理后重新发起打印。

### 步骤 2. 检查腔体外排风扇是否正常开启

在屏幕上点击：“**控制**” - “**空调系统**” - “**腔体外排风扇**”，检查风扇是否开启；

|  |  |
| --- | --- |
|  |  |

腔体外排风扇

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/0300_ab00_0002_0002/3.png)

若未开启，请开启后观察；如已开启但风量明显不足，请联系在线技术服务团队进一步排查。

### 步骤 3. 检查打印机外部环境温度

如环境温度偏高，建议将打印机置于**常温、通风良好**的环境，或开启空调等降温措施，以降低腔体积热。
