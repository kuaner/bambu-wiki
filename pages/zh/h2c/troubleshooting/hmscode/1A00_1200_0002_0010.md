## 故障描述

感应热端架尚未完成初始化，因而无法发起热端切换任务。

**故障发生时有何现象：** 无法发起热端切换任务

**可能原因：** 设备尚未执行**感应热端架初始化**。

## 排故措施

### 发起感应热端挂架初始化

感应热端架初始化具体步骤如下：

1. 操作打印机屏幕，点击左侧栏 “**设置**” 按钮，进入 “**校准**” 界面后，选择 “**感应热端架组件初始化**”。

|  |  |
| --- | --- |
|  |  |

2. 点击 “**开始**” 按钮，感应热端架会自动执行预设的初始化流程。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1200_0002_0010/pixpin_2025-10-19_17-03-42.png)

> **异常处理说明：** 初始化过程中若出现报错或执行失败，通常为安装或位置偏差超出允许范围。请参照 [H2C 感应热端架手动位置标定指引](../../maintenance/hotend-rack-manual-position-calibration.md)，先完成手动位置标定，再回到本步骤重新尝试初始化。
