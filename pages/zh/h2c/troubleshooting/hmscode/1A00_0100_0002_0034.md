## 故障描述

取用 2 槽位热端时检测到异常。

可能的原因：

- 热端和感应热端泊位组件之间有异物连接
- 热端和感应加热组件之间有异物
- 感应热端架标定数据异常，距离上次标定结构出现了变动

## 故障排除

### 工具、设备及材料

- 无

### 故障定位与解决流程

1. 检查热端和感应热端泊位组件之间、热端和感应加热组件之间是否有异物
2. 检查感应热端中的料线是否过长，并检查切刀
3. 若都没有，则需要重新标定感应热端架

### 排故措施

***用户可视情调整各排故措施的顺序。***

#### 步骤1. 检查热端和感应热端泊位组件/热端和感应加热组件间是否有异物

如果感应热端与热端泊位组件之间、感应热端与感应加热组件之间有异物，请进行清理。

#### 步骤2. 检查感应热端中的料线是否过长

- 如果热端中的料线过长，请取下并剪断。

![screenshot-20251120-110709.png](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0034/screenshot-20251120-110709.png)

- 同时，检查切刀是否磨损，导致无法切断料线。

请参考此 wiki：[更换 H2D 切刀刀柄与刀片](../../../h2/maintenance/replace-filament-cutter-lever.md)。

#### 步骤3. 若无异物干扰

需要对感应热端架组件进行校准。

1. 操作打印机屏幕，点击左侧栏设置按钮 → 进入“校准”界面，选择 “感应热端架组件初始化”。

|  |  |
| --- | --- |
|  |  |

2. 点击“开始”按钮，感应热端架将自动执行预设初始化流程。

![pixpin_2025-10-19_17-03-42.png](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0034/pixpin_2025-10-19_17-03-42.png)

> **异常处理说明：**若初始化过程中出现报错或执行失败，大概率是感应热端架组件安装偏差超出允许范围。请参照 [H2C 感应热端架手动位置标定指引](../../maintenance/hotend-rack-manual-position-calibration.md)，重新进行手动位置标定，完成后可再次尝试初始化操作。
