## 故障描述

向 1 槽位放置热端时，设备检测到异常

**可能原因：**

- 感应热端架执行粗回中运动时，受到异物阻挡，导致粗回中动作失败
- 感应热端架运动部件存在卡涩
- 感应热端架的粗回中霍尔元件损坏，或磁铁出现异常

## 排故措施

### 步骤 1. 检查感应热端架是否有异物阻塞

- 观察感应热端架的运动轨迹及周边区域，检查是否存在明显异物。
- 查看打印板是否放置歪斜，确认其是否阻碍感应热端架运动。
- 检查是否有热端掉落并吸附在感应热端架框架上，导致运动受阻。

若发现上述任一阻塞情况，及时清理阻塞物（或调整打印板位置、取下掉落热端）

### 步骤 2. 无异物阻塞运动，运动阻力较大

对感应热端架光轴进行清洁与润滑，具体步骤如下：

1. 准备无纺布与酒精，用无纺布蘸取适量酒精，仔细擦拭热端挂架（含泊位组件）及光轴表面，去除油污、粉尘等杂质。

|  |  |
| --- | --- |
|  |  |

2. 清洁工作完成后，在热端挂架的前后四根光轴上均匀涂抹润滑油。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1100_0002_0002/3.png)

3. 缓慢上下滑动热端挂架，让润滑油充分渗透并扩散至直线轴承内部，确保润滑覆盖全面。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1100_0002_0002/4.webp)

4. 操作结束后，及时用无纺布清理光轴及挂架表面溢出的多余油脂，避免残留杂质粘连。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1100_0002_0002/5.webp)

### 步骤 3. 排查粗回中霍尔与磁铁异常

- 若为粗回中霍尔异常，请参考[更换 H2C 感应热端架皮带组件](../../maintenance/replace-induction-hotend-rack-belt-assembly.md) 需更换感应热端架皮带组件。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/002.jpg)

- 若为粗回中磁铁异常，请参考 [更换 H2C 感应热端架框架](../../maintenance/replace-induction-hotend-rack-frame.md) 更换感应热端架框架。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-frame/009.png)
