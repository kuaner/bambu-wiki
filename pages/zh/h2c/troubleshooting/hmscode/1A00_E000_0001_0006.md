## 故障描述

感应热端挂架回中时，挂架电机上的编码器会实时记录挂架位置与行程。若挂架的同步带过松，会造成其与电机轴齿轮啮合不良，可能出现未啮合或跳齿情况，导致编码器记录的回中行程超出正常范围。系统检测到异常后会自动重试，多次重试仍异常则弹出告警。

## 工具、设备及材料

- H1.5 六角扳手
- 张紧同步带所需工具

## 故障定位与解决流程

### 张紧同步带

1. 先将工具头移至机箱后部，避免感应热端拉柄解锁组件顶出后与同步皮带发生干涉。

|  |  |
| --- | --- |
|  |  |

2. 用 H2.0 螺丝刀拧下两颗固定螺丝，移除保护壳，再缓慢上下拉动感应热端挂架，观察电机轴齿轮与皮带的啮合状态。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_e000_0001_0006/2.png)

3. 若发现啮合不良（如挂架移动时齿轮不转或转动不同步），参考[H2C 皮带张紧](../../maintenance/belt-tension.md)调整同步带张紧度。
4. 调整后在屏幕点击 “回中” 重试，无报错则问题已解决。

> 若重试后仍报错，需录制两段视频：感应热端挂架回中过程视频、电机处齿轮与皮带啮合情况特写视频。提交售后工单时，提交这两段视频，并上传日志，方便售后技术支持进一步排查。
