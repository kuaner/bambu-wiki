## 故障描述

MC与热端挂架电机驱动板通信异常。

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手

### 故障定位与解决流程

#### 步骤一：重启打印机

重启打印机，检查是否仍出现报错；若问题依旧，请继续执行步骤 2。

#### 步骤二：检查电机排线的两端是否松动

请参考此 wiki：[更换感应热端架电机](../../maintenance/replace-induction-hotend-rack-motor.md)，检查电机排线的两端是否松动。

- 检查感应热端架控制板上的电机排线插头是否松动

![](https://public-cdn.bblmw.com/wiki/new/h2c/troubleshooting/hmccode/0700_f000_0002_0001/image.png)

- 检查热端挂架电机上的排线插头是否松动

|  |  |
| --- | --- |
|  |  |

若已确认热端挂架电机排线连接牢固，但问题依旧存在，需要更换热端挂架电机。

请参考此 wiki：[更换感应热端架电机](../../maintenance/replace-induction-hotend-rack-motor.md) 进行更换。
