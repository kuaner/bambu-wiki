## 故障描述

热端挂架位置检测传感器用于感知热端挂架升降的位置。当热端挂架控制板发现该传感器信号异常时，会弹出此告警。

![h2c_hall_sensor_for_homing_on_induction_hotend_rack.png](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_3300_0001_0040/h2c_hall_sensor_for_homing_on_induction_hotend_rack.png)

**可能的原因：**

- 热端挂架位置检测传感器故障；
- 热端挂架位置检测传感器连接线短路；
- 热端挂架控制板故障。

## 所需工具和材料

- H1.5 内六角扳手

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 排查步骤

### 步骤 1. 断开热端挂架位置检测传感器上的连接线，观察告警提示的变化

1. 参考这篇 wiki：[更换 H2C 感应热端架组件](../../maintenance/replace-induction-hotend-rack-assembly.md)，取下感应热端架组件。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-assembly/008.png)

2. 找到热端挂架位置检测传感器，使用 H1.5 内六角扳手移除传感器两侧的 2 颗固定螺丝。

![where_is_the_sensor_screws.png](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_3300_0001_0040/where_is_the_sensor_screws.png)

3. 反转传感器固定块，移除传感器电路板上的 1 颗银色固定螺丝。

|  |  |
| --- | --- |
|  |  |

4. 取下传感器电路板，按压连接线底座，断开连接线。

![connecter.jpg](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_3300_0001_0040/connecter.jpg)

5. 此时，连接图示热端架底部的连接线，然后将热端架放置在**热床**上（暂无须装回，且⚠️开机后**请勿用手触碰热端架**），重启打印机，**观察告警提示是否由“短路”变为“断路”。**

   - 若告警由“短路”变为“断路”，跳转步骤2。
   - 若告警依旧为“短路”，跳转步骤3。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-assembly/008.png)

### 步骤 2. 更换感应热端架皮带组件

请参考 [更换 H2C 感应热端架皮带组件](../../maintenance/replace-induction-hotend-rack-belt-assembly.md) 更换感应热端架皮带组件。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-belt-assembly/024.png)

### 步骤 3. 拆下感应热端挂架，拔插控制板上的连接器插头

1. 请参考这篇 wiki：[更换 H2C 感应热端架控制板](../../maintenance/replace-induction-hotend-rack-control-board.md)，取下感应热端架组件，裸露出感应热端架控制板。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-control-board/006.png)

2. 拔插控制板上 4 号连接线，再连接热端架组件底部的连接线，重启打印机，**观察告警提示是否由“短路”变为“断路”。**

|  |  |
| --- | --- |
|  |  |

- 若机器报错由短路变断路，请参考这篇 wiki：[更换 H2C 感应热端架框架](../../maintenance/replace-induction-hotend-rack-frame.md)，更换热端挂架框架。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-frame/009.png)

- 若机器报错依旧为短路，请参考这篇 wiki：[更换 H2C 感应热端架控制板](../../maintenance/replace-induction-hotend-rack-control-board.md)，更换热端挂架控制板。

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-rack-control-board/006.png)
