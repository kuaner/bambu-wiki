## 故障描述

在感应热端挂架的初始化标定过程中，高度标定数据异常，导致标定失败。

**故障发生时有何现象：** 标定任务被中断并退出，显示错误码 `1a004007`

**可能原因：**

- 高度标定过程中被异物阻挡，采集数据异常
- 润滑不足/缺油导致运动卡涩

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，**请关闭打印机电源并断开电源连接**，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 工具、设备及材料

- 无

## 故障定位与解决流程

1. 检查感应热端挂架是否有异物阻塞

- 观察挂架周边是否有明显异物
- 检查打印板是否不正，阻碍挂架运动。
- 检查是否有热端脱落并被吸附在挂架框架上，阻塞挂架运动

2. 手动拖动挂架，确认是否可在全行程内顺畅运动且无阻滞/异响；如存在卡点，定位并清除阻挡物。
3. 若手动拖动挂架发现无异物运动阻力较大，则需要上油

## 排故措施

***用户可视情调整各排故措施的顺序。***

### 步骤 1. 排除异物阻塞

移除发现的一切可能干涉挂架运动的异物；重新放置打印板；确认无热端或附件吸附在挂架框架上。

### 步骤 2. 无异物阻塞运动，单纯是运动卡涩

对感应热端架光轴进行清洁润滑，具体步骤如下：

1. 准备无纺布与酒精，用无纺布蘸取适量酒精，仔细擦拭热端挂架（含泊位组件）及光轴表面，去除油污、粉尘等杂质。

|  |  |
| --- | --- |
|  |  |

2. 清洁工作完成后，在热端挂架的前后四根光轴上均匀涂抹润滑油。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1200_0002_0004/047.png)

3. 缓慢上下滑动热端挂架，让润滑油充分渗透并扩散至直线轴承内部，确保润滑覆盖全面。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1200_0002_0004/046.webp)

4. 操作结束后，及时用无纺布清理光轴及挂架表面溢出的多余油脂，避免残留杂质粘连。

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_1200_0002_0004/036.webp)
