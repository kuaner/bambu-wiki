## 故障描述

H2C通过线圈产生的交变磁场对右挤出机热端进行涡流加热。当线圈发生异常短路时，系统的电感值异常，无法产生足够加热功率。可能的原因是线圈绝缘层破损导致短路异常。

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手

### 排故措施

***用户可视情调整各排故措施的顺序。***

#### 步骤 1. 取下感应热端

请参考此 wiki：[更换感应热端组件](../../maintenance/replace-induction-hotend.md)，取下感应热端。

#### 步骤 2. 初步检查感应热端加热组件

移除部件冷却风扇风道和风扇。

|  |  |
| --- | --- |
|  |  |

检查此处两根线缆是否出现破皮的情况，如果有万用表可以测量是否短路。

|  |  |
| --- | --- |
|  |  |

详细步骤可参考这篇 Wiki 移除部件冷却风扇风道和风扇：[更换 H2D 部件冷却风扇](../../../h2/maintenance/replace-part-cooling-fan.md)

请参考此 wiki：[更换感应热端加热组件](../../maintenance/replace-induction-heating-assembly.md)，拆下感应热端加热组件。

#### 步骤 3. 检查感应加热组件电源线或导磁线圈绝缘层是否破损

1. 若线圈绝缘层出现破损，需更换感应热端加热组件。
