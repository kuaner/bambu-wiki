## 故障描述

向 1 槽位放置热端时，设备触发异常检测，立即暂停热端切换流程.

**可能原因：**

- 有异物卡在感应热端散热片表面
- 感应热端正面磁铁破损或脱落
- 感应热端架的标定数据异常，上次标定后结构发生变动，导致定位精度不足。

- 感应热端泊位组件的霍尔传感器工作异常，无法正常识别热端在位状态。

## 工具、设备及材料

- H1.5 六角扳手

## 故障定位与解决流程

***用户可视情调整各排故措施的顺序。***

### 步骤 1. 检查感应热端散热片表面异物

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0023/image.png)

观察感应热端的散热片表面，确认是否有异物卡住。若发现异物，请清除异物后重试。

### 步骤 2. 检查感应热端正面磁铁状态

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0023/image-1.png)

观察感应热端正面，检查磁铁是否破损或已脱落。若出现破损或已脱落，请参考 [更换 H2C 感应热端组件](../../maintenance/replace-induction-hotend.md) 更换新的感应热端组件

### 步骤 3. 若感应热端泊位组件未卡入热端散热片

1. 点击左侧栏 “设置” 按钮，进入 “校准” 界面，选择 “感应热端架组件初始化”

|  |  |
| --- | --- |
|  |  |

2. 点击 “开始” 按钮，感应热端架将自动执行预设初始化流程

![](https://wiki.bambulab.com/h2c/troubleshoting/hmscode/1a00_0100_0002_0023/3.png)

> **异常处理说明：** 若初始化过程中报错或执行失败，大概率是感应热端架组件安装偏差超出允许范围。需参照 [H2C 感应热端架手动位置标定指引](../../maintenance/hotend-rack-manual-position-calibration.md)，重新进行手动位置标定，完成后可再次尝试初始化操作。

### 步骤 4. 若感应热端泊位组件正常卡入散热片但未能识别

若感应热端泊位组件已正常卡入散热片，但设备仍无法识别热端，说明感应热端泊位组件的霍尔传感器异常。请参考[更换 H2C 感应热端泊位件组件](../../maintenance/replace-induction-hotend-dock-assembly.md)更换感应热端泊位组件

![](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/replace-induction-hotend-dock-assembly/002.jpg)
