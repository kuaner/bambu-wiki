## 操作步骤

### 步骤 1. 移除底部 4 个卡扣

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/3.png)

### 步骤 2. 上提移除外箱

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/4.png)

### 步骤 3. 仔细阅读快速入门指南，了解详细操作步骤

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/5.png)

### 步骤 4. 取出耗材盒（激光套装）或配件盒（AMS 套装）

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/6.png)

### 步骤 5. 取出泡棉

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/7.png)

### 步骤 6. 撕掉底部 4 张贴纸

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/8.png)

### 步骤 7. 移除包装材料和气垫

|  |  |
| --- | --- |
|  |  |

### 步骤 8. 撕开防潮袋两侧提手和顶部开口

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/11.png)

### 步骤 9. 将防潮袋往下拉，套入底部纸箱的四角

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/12.png)

### 步骤 10. 两人合力抬出打印机，放至稳定平面

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/13.png)

### 步骤 11. 移除打印机周围的保护膜和贴纸

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/14.png)

### 步骤 12. 取下上盖玻璃

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/15.png)

### 步骤 13. 移除泡棉

|  |  |
| --- | --- |
|  |  |

### 步骤 14. 取出配件盒

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/18.png)

> 注意：仅适用于激光套装。

### 步骤 15. 用 H2.0 扳手拧下图示螺丝即可解锁 AMS 2 Pro

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/19.png)

### 步骤 16. 取出 AMS 2 Pro

取出后，内部一些固定 AMS 2 Pro 的泡棉会掉落，将其移除。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/22.png)

### 步骤 17. 用 H2.0 扳手拧下 4 颗螺丝后，移除底部固定件

|  |  |
| --- | --- |
|  |  |

### 步骤 18. 用 H2.0 扳手拧下 4 颗螺丝，解锁热床

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/25.png)

> 取下的固定件可以用来收纳热床固定螺丝。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/26.png)

### 步骤 19. 移除工具头附近的扎带

> 注意不要剪断皮带！

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/30.png)

### 步骤 20. 将工具头拉向前门，工具头的卡纸

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/31.png)

### 步骤 21. 继续将工具头拉向前门，缓慢取出拖链上的泡棉。

> 请勿掰动拖链，避免造成损坏。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/33.png)

### 步骤 22. 移除感应热端挂架上的扎带和泡棉

> 使用剪刀时，请注意剪刀的位置，避免刮伤挂架。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 23. 取出空气滤芯上的泡棉。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/34.png)

### 步骤 24. 移除左右以及中间丝杆上方的泡棉

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/62.png)

### 步骤 25. 将上盖放至打印机顶部

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/35.png)

### 步骤 26. 用 H2.0 扳手拧下气泵固定螺丝（仅激光套装需要拧除这颗螺丝，AMS 套装可以忽略这一步）

> 拧松后缓慢取出螺丝，以防掉入打印机内部。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/36.png)

### 步骤 27. 移除排气格栅上的贴纸

![remove_the_sticker.png](https://wiki.bambulab.com/h2c/manual/unboxing-h2c/remove_the_sticker.png)

### 步骤 28. 移除 AMS 2 Pro 内外的保护膜

![remove_the_ams_2_pro_protective_film.png](https://wiki.bambulab.com/h2c/manual/unboxing-h2c/remove_the_ams_2_pro_protective_film.png)

### 步骤 29. 取出 AMS 2 Pro 内部所有配件及泡棉

如果您拥有多台 AMS 产品，可以根据 [多机型 AMS 连接指南](../../ams/manual/multi-model-AMS-compatibility-guide.md) 安装更多 AMS。

### 步骤 38. 根据屏幕指引，进行首次校准

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/60.png)

### 步骤 39. 校准完成后，取出热床底部的泡棉

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/unboxing/61.png)

### 步骤 40. 放置废料盒

开始打印前，推荐准备一个盒子放置于**打印机背面的废料滑梯下方**，用于收集打印过程滑出的废料，保持环境整洁。

您可以打印一个 [H2C 专用废料盒](https://makerworld.com.cn/zh/search/models?keyword=H2C%E5%BA%9F%E6%96%99%E7%9B%92)，也可以使用耗材包装盒或其他容器来接废料。

下图为 P1S 打印机放置示例。

![purge_container_placement_p1s_example.png](https://wiki.bambulab.com/p1/manual/p1s-unboxing/purge_container_placement_p1s_example.png)
