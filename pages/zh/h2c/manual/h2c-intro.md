本页面将介绍 Bambu Lab H2C 3D 打印机的主要部件，通过介绍可让您快速了解该打印机的基本构造。

## H2C 是如何工作的？

H2C 系列 3D 打印机是一种使用塑料耗材来创建 3D 物体的机器。

大多数情况下，H2C 可以打印 stl 格式的 3D 模型，打印前需要使用切片软件对文件模型进行预处理。

以 Bambu Studio 为例，切片软件会将 stl 文件切分成很多层，每个层的信息将被自动转换成打印机可以理解的语言，用于指示打印过程中各轴移动路径及速率。

除此之外，切片软件还能够在生成的代码中集成多种参数设置，例如耗材的打印温度、打印机的挤出速度，并为打印模型的某些部分生成支撑。

## CoreXY 运动系统

Bambu Lab H2C 基于 Core-XY 架构，该架构含两个步进电机与多组惰轮，每个步进电机都通过一条独立的同步带与工具头连接，通过电机-同步带协同传动来控制工具头的运动及位置。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-10.png)

### 工作原理

A 电机与 B 电机在 Core-XY 系统中分别独立控制两组皮带的运动。如下动图所示，当左侧的 B 电机单独工作时，仅驱动左侧 Y 轴的皮带运动，此时工具头将沿 45° 斜对角方向移动。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/left-motor.webp)

同理，当右侧的 A 电机单独工作时，仅驱动右侧 Y 轴的皮带运动，工具头将沿着相反的 45°斜对角移动。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/right-motor.webp)

与传统的笛卡尔打印机相比，使用 Core-XY 运动系统的打印机打印速度更快，因为这种运动系统的重量更轻，使得打印速度更快、运动更平稳，从而提升打印质量与效率。想了解更多关于 CoreXY 运动系统的信息请访问该[链接](https://corexy.com/theory.html)。

### X 轴

X 轴采用线轨和皮带传动，控制工具头的左右移动，确保工具头在 X 轴上运动时始终固定在水平面上。X 方向的运动由 A 、B 步进电机同时驱动。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-7.png)

### Y 轴

Y 轴控制工具头的前后移动。工具头与 X 轴作为一个整体，沿位于机身两侧的 Y 轴光杆前后滑动。该运动同样由 A 、B 步进电机同时驱动。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-9.png)

### Z 轴

H2C 的 Z 轴由丝杆与光杆组成，分布在热床的左前方、右前方和中后方。

丝杆通过皮带与同一个 Z 步进电机相连，由电机统一驱动旋转，从而带动热床上的螺母同步升降，实现热床在竖直方向的移动。光杆则提供精准定位，有效抑制丝杆旋转引起的晃动，保证热床平稳运行。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-8.png)

> 注意： H2C 出厂前已完成热床调平。使用前请根据指引拆除用于固定 Z 轴滑块的 4 颗螺丝，并妥善保存。若后续进行 Z 轴丝杆的拆装维护或设备运输，请务必重新锁回这 4 颗螺丝，以防止设备损坏。
>
> ![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-2.png)

## 打印机外壳

H2C 打印机的上盖玻璃、前门玻璃和侧板视窗有钢化玻璃和激光防护两种版本。

激光版打印机默认配备激光防护版玻璃视窗，如果将非激光版打印机升级至激光版，则需单独购买升级套装（上市时间晚于整机）。升级套装包含绿色 PC 材质的激光防护前门、左右视窗，以及黑色顶部防护盖。如果需要使用激光模组，必须安装激光防护版本，否则激光功能将被强制停止。

|  |  |
| --- | --- |
| 钢化玻璃版 | 钢化玻璃版 |
| 激光防护版 | 激光防护版 |

H2C 打印机为上盖玻璃、前门玻璃、侧板及侧板视窗配备了开门检测功能。如果安装了激光模块，当打印机检测到“门”被打开时，设备则会弹出红色错误提示并立即暂停工作任务；如果使用的是非激光功能，设备则会在 HMS 页面提示“开门”，并弹出橙色警告提示，但不会暂停工作任务。

## 工具头

工具头是 3D 打印机中最核心的执行部件之一，负责将耗材加热熔融、精确挤出，并在打印平面上完成逐层沉积成型。以下介绍工具头的主要组成部件及其功能。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/img_v3_02r8_581ff80b-ea09-417e-94f1-d17bafbfd3bg.jpg)

### 挤出机

挤出机负责从线轴中拉出耗材，并将其送入热端。耗材在热端加热熔化后，通过喷嘴挤出，生成打印模型。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-1.png)

挤出机需要精确控制挤出和回抽耗材的长度，保证打印的模型尺寸精度和外观质量，是 3D 打印机核心部件之一。H2C 的挤出机主要由切换系统、挤出系统和切刀组成。

切换系统使用切换电机和传动系统驱动凸轮实现左右从动杆的摇摆运动，搭配连接从动杆的拉簧，使一侧从动杆上的从动轮与挤出系统上的主动轮压紧耗材，主动轮旋转实现耗材的挤出；与此同时，另一侧从动轮不压紧耗材，主动轮转动不会造成耗材运动。

挤出电机带动挤出主动轮顺时针或逆时针旋转，可以分别带动两侧从动轮挤出耗材，从而达到用一个挤出主动轮实现左右双挤出的效果。

![仅用于演示左右切换原理，不建议进行此操作](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/extruder-.webp)

### 切刀

切刀负责切断挤出机与热端之间的耗材，切断后即可退出耗材。切刀组件能和切刀顶杆与AMS（自动材料切换系统）配合，自动完成耗材的切断与更换，从而实现多色或多耗材打印。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image.png)

### 热端组件

热端组件是工具头模块的核心部件，主要由加热组件、热端和热端硅胶套组成，支持的最高加热温度为 350℃。热端组件将耗材加热到指定温度，熔化后的耗材以薄层的形式沉积来生成模型。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-20.png)

#### **左热端**

H2C 左热端的类型与 H2D 的左右热端及 H2S 的热端一致，均兼容标准流量、大流量和碳化钨三种版本。标准流量热端为打印机标配，后两种可在官方商城额外购买。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-15.png)

- 冷端：包含散热片和热阻断器。保持热端上部低温，防止热量向上传导（热爬现象），减少堵塞风险。
- 热端：耗材在此处熔融后通过喷嘴以薄层的形式沉积，从而生成模型。

**热端加热组件**

H2C 的左热端采用快速锁紧卡扣固定，拆装维护热端无需借助螺丝刀等工具。左热端加热组件采用氧化锆陶瓷隔热底座与铜导热底座设计，进一步提升隔热性能，左热端加热组件的热端加热器和 NTC 测温传感器固定在加热底座上。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-21.png)

**左热端上下升降的原理与作用**

升降电机转动时，通过传动机构带动左热端上升和下降，同时带动堵嘴片左右摆动。左热端和堵嘴片之间存在联动关系，当左热端下降时，堵嘴片会移至右热端堵住右喷嘴；当左热端上升时，堵嘴片会移至左热端堵住左喷嘴，从而避免非打印状态的热端漏料。

|  |  |
| --- | --- |
|  |  |

**注意事项：**

1. 堵嘴片的作用是堵住非工作状态的喷嘴防止漏料，如果出现轻微左右偏斜，只要不影响堵嘴功能就可以正常使用。如果发现堵嘴片没有压住喷嘴，可将堵嘴连杆拨到两个喷嘴中间的位置，尝试手动将堵嘴片向上掰一掰，然后在屏幕上手动切换左右喷嘴的升降，确认堵嘴片可以正常堵住喷嘴且能正常运动到位。
2. 堵嘴片位于喷嘴下方且比较脆弱，打印异常情况下，堵嘴片可能会被异常的凸出物撞至变形，此时建议更换堵嘴片。挡风片是薄钢片，拆装热端硅胶套或热端时可能会导致挡风片变形，若变形不严重可手动掰直，若严重变形，建议更换该挡风片。

与此同时，左热端旁边安装了一个挡风片，随同左热端同升同降，使风道吹出的风尽可能集中于热端的散热片部位，提高散热效率，降低堵头风险。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-18.png)

#### 右热端

H2C 的右热端采用智能感应热端设计，兼容标准流量和大流量两种版本，其中标准流量为打印机默认配置，大流量版本可在官方商城另行购买。该智能感应热端集成了喷嘴、热断层、热敏电阻 NTC 及一块小型 PCB 板，通过非接触式感应实现加热，可在约 8 秒内将喷嘴升至目标温度。与传统接触式加热方式相比，这种设计显著缩短了每次换料时的预热等待时间。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-17.png)

**冷端**

- **散热片：**用于保持热端上部低温，防止热量向上传导（热爬现象），减少堵塞风险。
- **PCB 板：**顶部 PCB 的主要功能是读取热端的规格信息，记录热端的温度数据以及上一次打印所使用的耗材颜色。随后，这些信息会通过非接触式的方式传递至热端加热组件上的中转 PCB，再由热端加热组件上的中转 PCB 将数据传输至打印机系统，并同步显示在屏幕上。
- **NTC温度传感器：**NTC 测温传感器作为独立的温度采集部件，直接实时采集喷嘴温度，将温度信号传递给打印机控制系统，由控制系统根据实时温度精准调节感应加热功率，确保热端温度稳定。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/img_v3_02ra_bb839231-0374-4129-a9b6-1b63dbe020fg.jpg)

- **孔位和小磁铁：**正面的两个孔位用于将热端固定在感应热端泊位组件上，磁铁用于确认热端是否正确安装至感应热端泊位组件上。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-16.png)

- **大磁铁：**背面大铁用于确认热端是否正确安装至加热组件上。

![image_-_2025-10-28t114623.641.png](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image_-_2025-10-28t114623.641.png)

**热端**  
智能感应热端在喷嘴与散热片之间的加热区内置了一层保温材料，底部喷嘴处配有带固定槽的硅胶套，用于包覆喷嘴。该设计能够有效减少热量流失，维持热端温度稳定，同时防止耗材在喷嘴表面积聚。若缺少硅胶套，热端可能会被冷却风扇过度冷却，导致温度波动，从而影响打印稳定性。

如发现硅胶套损坏，可使用配件盒内的备用硅胶套进行更换，或前往官方商城及电商平台购买同款配件。

![snipaste_2025-10-22_15-2113.png](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/snipaste_2025-10-22_15-2113.png)

**感应加热组件**

感应加热组件用于实现精准加热和温度监测，支持的最高加热温度为 350℃。感应加热组件包含两个独立插头：中转霍尔板插头和电源线插头。

- **中转霍尔板排线：**中转霍尔板排线负责传输通信和智能感应热端的相关数据。如前所述，智能感应热端配备了一个 PCB 和 NTC传感器，NTC 传感器采集并存储温度数据，然后通过非接触方式将温度信息传递到感应加热组件上的温度采集中转 PCB **（#2）** 上，该信息通过霍尔板插头与打印机主控系统中的 TH 板进行通信，使打印机实时监控热端的相关的信息。此外，热端加热组件还包括检测热端是否正确安装的霍尔传感器 **（#1）**，以及判断拉柄是否锁紧或松开的霍尔传感器 **（#3）**。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-19.png)

- **加热电源线：**为加热组件供电加热。电力驱动加热组件的感应线圈产生交变磁场，热端内的感应结构因电磁感应产生热量，从而实现智能感应热端的非接触式加热。

|  |  |
| --- | --- |
|  |  |

**右涡流线圈**

右涡流线圈参与 Z 轴归零、热床调平及动态流量校准等关键工作流程，其完好性与安装精度直接决定设备的打印精度和整体运行稳定性。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-14.png)

### **感应热端锁紧拉柄**

智能感应热端通过锁紧拉柄固定在感应加热组件上，从而确保热端安装稳固。锁紧拉柄前后各嵌有一块小磁铁，与加热组件内的霍尔位置检测板配合工作，系统可自动识别热端当前处于锁紧或松开状态。

为确保拉柄能够顺畅锁紧热端，应定期检查锁紧拉柄前端的润滑情况。尤其在更换新的锁紧拉柄时，请务必涂抹包装盒内附带的润滑油，否则可能因摩擦过大而导致拉柄卡滞、难以插入。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-26.png)

同时，打印机右侧的热端挂架内配备有感应热端拉柄解锁组件。该组件通过机械结构的推动或拉动，实现拉柄的自动插入与退出，从而完成热端的锁紧或解锁操作。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/switch-hotend.webp)

值得注意的是，H2C 在挤出机前盖的导向组件上相较于 H2D 额外增加了一个限位卡扣。该卡扣用于限制感应热端锁紧拉柄的行程，防止其过度拉出，确保工具头的工作机制稳定运行。

## 感应热端挂架

感应热端挂架安装在机箱右侧，通过 4 颗螺丝固定，主要包括感应热端拉柄解锁组件、感应热端挂架皮带组件、感应热端泊位组件和感应热端控制板等。

|  |  |
| --- | --- |
|  |  |

1. **感应热端泊位组件：**用于吸附热端，包含一个用于检测喷嘴是否在位的传感器，并且配备了指示灯，当热端正确放置到泊位组件上时，指示灯会随之亮起，直观反馈安装状态。
2. **感应热端拉柄解锁组件：**用于解锁拉柄，先将拉柄穿入对应孔位内，然后通过工具头往左移动拉出拉柄实现解锁，往右移动则锁紧拉柄，且组件内部由顶杆和弹簧配合构成，保障解锁与锁紧的动作稳定。
3. **感应热端挂架电机：**该伺服电机用于驱动感应热端完成上升、下降动作，该电机具备智能调节功能，当热端运动过程中遇到阻碍或出现异常情况时，能自动调整输出力矩，若问题无法自行解决，会及时发出提示HMS报错，避免设备损坏以及便于用户进行故障排查。
4. **感应热端挂架控制板：**作为核心控制单元，感应热端挂架控制板承担着连接 6 个热端泊位组件、热端拉柄解锁组件以及热端挂架电机的关键作用，通过精准的信号传输与指令调度，实现对这些组件和电机的协同控制，保障热端挂架系统的稳定运行与高效作业。
5. **感应热端挂架皮带组件：**传动部件，负责传递伺服电机输出的动力，把电机的旋转运动转化为感应热端挂架的直线运动（上升或下降），进而实现热端挂架的精准升降控制。
6. **回中霍尔板：** 在感应热端挂架组件的 2、4、6 号热端泊位组件上，包含了一个磁铁和一块霍尔板，用于检测热端挂架是否粗回中。

感应热端挂架底部配有两颗用于调节安装高度的螺丝（红色标记）。一般情况下，底部这两颗螺丝保持出厂默认设置即可，无需额外调整。此外，感应热端挂架底部还有一颗皮带张力调节（黄色标记），日常使用中不建议自行调整，该螺丝出厂前已按标准扭矩校准，随意调节可能破坏顶丝的受力平衡，导致皮带张力过紧或者过松，影响打印精度。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-31.png)

## 切刀顶杆

为了保证左右切刀正常工作，H2C 的左右两侧各有一个可折叠的切刀顶杆，切刀通过刀柄顶在顶杆上实现切料动作。

- **工具头回零避让位置：**为了不影响 Y 轴电机回零的准确性，切刀顶杆在工具头回零时会处于避让位置。

需要说明的是，与 X 和 P 系列打印机不同，H2C 的切刀顶杆不会限制工具头的移动范围，可以在不进行任何特殊操作的情况下实现 X 轴和 Y 轴的极限打印范围。

## 吐料组件

H2C 的吐料组件包括吐料部件和擦嘴部件（粗擦），其中吐料部件由推料板与接料板构成，擦嘴部件由推杆与擦嘴连杆组成。

- 吐料部件：用于高效处理喷嘴吐出的废弃耗材。它的功能包括收集和运送废弃耗材，确保废弃废料得到正确的处置，以确保打印过程的连续顺畅进行。该装置在多个打印过程中发挥着重要的作用，包括打印机准备、暂停和继续打印、耗材的装载和卸载，以及多色打印时的耗材更换和冲刷过程。

打印前清洁喷嘴包括粗擦和精擦，粗擦主要用于去除喷嘴上的残余废料，而精擦则确保喷嘴表面的光洁。此处提到的擦嘴部件是用于粗擦动作，精擦则是指喷嘴在热床的擦嘴钢片向下蹭动 1~2毫米，以达到更好的清洁效果。

## 热床

热床用于加热打印表面，以帮助打印层更好地附着在打印板上，如果不对打印表面加热，沉积的耗材会快速冷却，层之间的张力会使其翘曲。在打印过程中，H2C 打印机会根据所使用的材料类型来调节热床的加热温度，最高可达120°C。例如，使用 PLA 材料时，在低温打印板上打印时热床温度设定为 35-45°C，可以有效避免翘曲现象。而对于 ABS 和 PC 等材料，为了防止翘曲，需要将热床温度设置在 100-110°C 之间进行打印。

由于感应热端挂架占用部分空间，H2C 的热床面积略小于 H2D 与 H2S 打印机，打印机的最大打印面积为 330\*320 mm，实际打印面积与使用的左/右喷嘴有关，更多详情请参考：[H2 系列打印机最大打印/加工范围](../../h2/manual/max-printable-area.md)。

### 腔体冷却系统

当打印机启动外排风扇时，顶部自动风门和位于打印机背面的自动排气格栅会自动打开，以便精准控制腔温或控制机箱内的气体流动。顶部自动风门作为进气口，与出气口的自动排气格栅相配合，从而为系统提供充足的进气量，同时确保机箱内的气体流动符合预期并可控。

打印机在空闲或打印过程中，若未开启腔温加热，则打印机处于冷却模式。

冷却模式下：

1. 过滤切换风门保持打开；
2. 排气格栅和顶部自动风门会跟随腔体外排风扇打开，以保证打印机腔体与外界的空气流通性，降低腔体内温度。

为了兼顾噪音和冷却效果，打印时腔体外排风扇转速会随腔体温度升高而升高。当打印机腔体温度较低，对冷却需求不强时，腔体外排风扇会降至 30% 转速。

|  |  |
| --- | --- |
| 顶部自动风门 | 排气格栅和腔体外排风扇 |
| 过滤切换风门 | 腔体外排风扇（背面视角，拆开排气格栅后） |

综上，顶部自动风门和自动排气格栅主要有以下两个作用：

1. 3D 打印时，系统会根据所打印的耗材种类，以及对腔体温度的检测，自动控制开合及换气，实现腔温的精准控制；
2. 激光模组在工作时，应提供充足的进气量，以帮助激光作业产生的废气和微粒经过滤芯充分过滤后再排放到机外，减少污染。同时，风门的开启角度经过精心设计，既能确保进气量充足，又能避免激光直射设备外部，从而降低对人体的潜在伤害。

### 腔体加热系统

在腔体加热时，打印机的循环系统会切换到腔温保持模式，此时自动排气格栅和顶部自动风门会关闭。为了在腔温升温阶段增加气体流动性以加快升温，过滤切换风门会打开；而在腔温保持阶段，过滤切换风门则会关闭，以确保过滤效果。

|  |  |
| --- | --- |
| 过滤切换风门（需取下空气滤芯后才可观察到） | 腔温加热器：PTC加热片和腔体加热循环风扇（风扇位于加热片后面） |

当在屏幕上设定腔温，或者选择加热模式，或者切片文件中设置了腔温加热，则打印机进入加热模式（但腔温加热器不一定位于加热状态）

当在机器屏幕端、Bambu Studio 或 Bambu Handy端设置腔体温度后，循环模式将自动切换至腔温保持模式，腔温加热器开始工作。

腔温加热器由 PTC 加热片和腔体加热循环风扇组成，设定腔温温度后，PTC 将全功率加热，腔温加热风扇则以最大转速运行。当腔体温度达到设定值后，腔温加热风扇的转速保持不变，而 PTC 的功率会降低，以维持腔体温度在恒定值。

它有两路耗材通道，分别对应两个热端，缓冲器的上路连到右侧热端，下路连到左侧热端，配合出厂标配的标准长度料管，可以尽可能减小进料过程中的阻力。

使用缓冲器时，需要先从机器后面的料管支架处插入料管，注意要一直插到底部，无法插入更深，且从缓冲器正面开孔处可以看到料管即到位。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-55.png)

AP 板盖上设计了引导轨道，保证料管可以顺畅地插到位。此处需要注意，AP 板盖上的轨道仅能通过 PTFE 管，从而引导耗材进入缓冲器，如果没有插入 PTFE 管，而是直接插入耗材，几乎是无法把耗材成功送入缓冲区。

![screenshot-20251028-115015-.png](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/screenshot-20251028-115015-.png)

每一路分为缓冲部分及有料检测部分。缓冲部分主要包含一个滑块、一块磁铁、两个弹簧和一个霍尔传感器；有料检测部分主要包含一块磁铁、一个弹簧和一个霍尔传感器。

### 缓冲部分

缓冲部分的基本工作原理是，AMS 将耗材推入工具头挤出机时，送入耗材的压力会推动滑块向右移动，并存储一小段耗材在缓冲器内。当挤出机消耗缓冲器内的耗材后滑块会退回到左侧。通过传感器检测滑块所在的位置，并反馈回 AMS 和打印机，进而调整送料的速度。

另外，在用外挂料盘打印时，缓冲部分还具备缠料检测功能，可以检测到外挂料盘是否缠料。X1/P1 系列的缓冲器不同，H2C 的缓冲弹簧的另一侧还有一个缠料弹簧，当耗材进入机器阻力增大（例如缠料时），且工具头还在挤出，滑块向左侧运动，运动一段距离后，霍尔传感器的返回值超出阈值，就会判定缠料，打印机则会弹窗 HMS 提示告知用户处理，实现缠料检测功能。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-52.png)

### 有料检测部分

H2C 在缓冲器处增加了有料检测功能，配合官方的料管扩展口，可实现单侧热端配合至多四个 AMS 的配合关系，省去了 X1/P1 的 AMS Hub。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-50.png)

有料检测部分有一个磁铁，无耗材时，磁铁被弹簧压在远离霍尔的位置，有耗材时磁铁被耗材顶起靠近霍尔，实现有料检测的功能。

## 电气元件

H2C 内部有许多电子元件，这里给出一些最重要元件的介绍：

### 主控板

H2C 拥有两类核心主控板，一类负责交互逻辑处理，另一类负责整机运动单元控制处理。

**AP 逻辑主控板**

逻辑主控板含有一个四核 CPU 以及连接到打印机的不同媒体电子设备所需的连接。

CPU 处理 H2C 的智能功能（包括 AI 检测、流量校准和振动补偿）以及切片软件/移动应用与打印机之间的连接。

**MC 运动控制板**

运动控制板含有一颗双 M4 内核的 MCU、一颗单 M7 内核的MCU，同时包含步进驱动器以及连接到打印机的不同运动电子设备所需的连接，提供：xyz 运动控制、腔体温度控制、热床温度控制、腔体状态检测(舱门，顶盖，侧板开关及玻璃类型检测)、循环系统控制(空气循环及流通通道控制)。MCU 在从 CPU 获取G代码流后控制打印机的实际运动及整机状态。

### USB 储存接口

H2C 拥有一个支持 USB2.0 协议的普通 USBA 接口，可用于U盘离线发起打印和存储延时摄影录像文件。

### 屏幕

H2C 配备了一块 5 英寸 1280\*720 的触控屏幕，结合更为流畅的用户界面，实现丝滑的操作体验。

### 摄像头

#### 喷嘴摄像头

H2C 拥有支持 1080p 10fps（最高能到30fps）的喷嘴摄像头，可实现热端裹头、空打、炒面检测、垃圾桶位置标定。

#### 工具头摄像头

H2C 拥有支持 1080p 30fps 的工具头摄像头，可用于运动精度校准，高精度喷嘴偏移校准。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-51.png)

#### 实况摄像头

H2C 拥有支持 1080p 30fps 的实况摄像头，可查看打印机腔体内部实况，实现延时摄影和必要的 AI 检测功能。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-47.png)

#### 俯视摄像头（打印模块选配，激光必须安装）

H2C 可选配4K，最大 15fps 的俯视摄像头，以满足在激光 & 刀切扩展场景下的智能检测和识别功能。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-57.png)

### LED 照明

H2C 的左右横梁各配备有一个 LED 灯条，以确保腔体内有足够的照明。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-54.png)

### 启动/暂停按钮

激光任务需要有人值守，因此，在前处理软件中发送激光工作任务或者刀切任务后，需要操作员按下位于打印机右上方的启动按钮以开始任务作业。此外，该启动按钮还支持对 3D 打印、激光任务和刀切任务的暂停操作。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-44.png)

### 安全钥匙

为确保符合相关安全规范，H2C 打印机配备了一个安全钥匙插孔，必须插入安全钥匙（打印和刀切功能）或带有安全钥匙的急停按键（激光功能）才能启用电源。如果在连接打印机电源并打开电源开关后，打印机未正常供电，请务必检查这一点。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/h2c-intro/image-45.png)

### 急停按键（打印和刀切功能选配，激光功能必须安装）

如果需要使用激光功能，则必须安装带有安全钥匙的急停按键，并将急停按键的插头插入打印机背面的安全钥匙插槽。

激光任务全程需要有人在旁监管，并在紧急情况下及时按下急停按键以切断电源，以随时应对潜在的突发状况。

温馨提示：机器背面和急停按键上各有一个预装的安全钥匙，拔下机器背面的安全钥匙后请妥善保管。
