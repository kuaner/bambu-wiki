## 开始打印

### 步骤 1：建议插入 U 盘用于保存打印录像和缓存

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/first-use/21.png)

### 步骤 2：点击“打印文件”，选择想要打印的模型

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/first-use/33.png)

### 步骤 3：根据需求调整高级选项和设置耗材的匹配关系后，点击“打印”

|  |  |
| --- | --- |
|  |  |

### 步骤 4：等待热床和模型冷却至室温，取下打印板

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/first-use/22.png)

### 步骤 5：轻轻弯折打印板，取下模型和擦料塔

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/first-use/23.png)

### 步骤 6：用铲刀清除流量校准线

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/first-use/24.png)

## 放回打印板

确保打印板与热床的限位块对齐。

![](https://public-cdn.bblmw.com/wiki/new/h2c/manual/first-use/36.png)
