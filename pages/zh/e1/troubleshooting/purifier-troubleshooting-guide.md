## 安全提示

> 在进行任何清洁或维护操作前，请仔细阅读以下安全注意事项。
>
> 1. 清洁滤网、擦拭内部组件或进行任何维护操作前，必须先关闭电源开关并**拔下电源插头**，待风道内风扇完全停转后方可操作。
> 2. 滤网及内部组件上积累的灰尘含有大量微粒，取下滤网时请佩戴防尘口罩，并尽量在室外或通风良好的环境进行；建议用软毛刷轻扫或用湿布擦拭滤网；维护结束后请清洁双手。
> 3. 风扇扇叶边缘锐利，操作不当可能造成割伤。清洁扇叶前请先确认风扇已完全停转，再使用软刷轻扫，不得使用尖锐物品刮擦。

## 典型故障一：滤芯寿命临期/到期/过期

**故障现象**

1. 屏幕上会有“红色更换图标”，提示需更换滤芯。
2. 滤芯寿命小于 72 小时，提示滤芯寿命临期；滤芯寿命为 0 时，提示滤芯寿命到期/过期。

| 20261030-001.png | 20261030-002.png |

**解决方案**

请及时更换滤芯，可参考[E1 滤芯更换指南](../maintenance/replace-purifier-air-filter.md)。

## 典型故障二：风扇转速异常

**故障现象**

净化器启动后，按下风速按钮调节风速，但风扇没有转动，且听不到风扇运行声音。

**可能的原因**

1. 风管被堵塞
2. 进气口被堵塞
3. 出气口被堵塞
4. 滤芯被堵塞
5. 风扇扇叶灰尘积累严重
6. 风扇故障

**解决方案**

取下风管。

|  |  |
| --- | --- |
| 20261030-003.jpg | 20261030-004.jpg |

检查风管内部是否存在杂物，需保持干净。

![20261030-005.jpg](https://public-cdn.bblmw.com/wiki/new/e1/troubleshooting/purifier-troubleshooting-guide/zh/20261030-005.jpg)

检查打印机出气口是否被灰尘堵塞，需使用毛刷清洁。

![20261030-006.jpg](https://public-cdn.bblmw.com/wiki/new/e1/troubleshooting/purifier-troubleshooting-guide/zh/20261030-006.jpg)

检查净化器的进气口和出气口是否被异物堵塞，出气口四周请勿堆放杂物。

|  |  |
| --- | --- |
| 20261030-007.png | 20261030-008.png |

若以上情况都正常，则向上推开滤芯盖。

![20261030-009.png](https://public-cdn.bblmw.com/wiki/new/e1/troubleshooting/purifier-troubleshooting-guide/zh/20261030-009.png)

拎住净化器两侧拉环，取出滤芯后装回滤芯盖，重新启动净化器。

![20261030-010.png](https://public-cdn.bblmw.com/wiki/new/e1/troubleshooting/purifier-troubleshooting-guide/zh/20261030-010.png)

若该情况下依然提示风扇转速异常，请通过滤芯处观察风扇外观。

![20261030-011.png](https://public-cdn.bblmw.com/wiki/new/e1/troubleshooting/purifier-troubleshooting-guide/zh/20261030-011.png)

若灰尘积累明显，请参考 [E1 风扇更换指南](../maintenance/replace-purifier-fan.md)分离前后盖，使用毛刷及时清理。若扇叶较为干净，请联系客户支持团队。

## 典型故障四：出风口 PM 持续偏高

![20261030-015.png](https://public-cdn.bblmw.com/wiki/new/e1/troubleshooting/purifier-troubleshooting-guide/zh/20261030-015.png)

**故障现象：**

净化器屏幕上显示的 PM 值持续偏高（高于 100），且空气中存在异味，净化器过滤效果变差。

**解决方案**

1. 检查滤芯是否安装

打开滤芯盖，检查滤芯是否安装。

![20261030-016.png](https://public-cdn.bblmw.com/wiki/new/e1/troubleshooting/purifier-troubleshooting-guide/zh/20261030-016.png)

- 检查滤芯是否到期

通过屏幕检查滤芯是否到期。每次更换滤芯时都需要及时刷新滤芯寿命，否则计算可能存在偏差。

- 更换滤芯

若滤芯已经安装在设备上，则可能是滤芯实际寿命到期，请及时更换滤芯，可参考[E1 滤芯更换指南](../maintenance/replace-purifier-air-filter.md)。
