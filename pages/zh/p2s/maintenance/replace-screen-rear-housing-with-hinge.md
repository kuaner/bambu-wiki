## 屏幕后盖

屏幕后盖是安装在屏幕背面，带有卡扣，能将屏幕固定到打印机上的配件。  
![fac154.jpg](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/p2s-sku-pics/fac154.jpg)  
屏幕后盖的备件包含：

1. 屏幕后盖 \* 1；
2. BT2x5 螺丝 \* 5

## 何时更换

1. 屏幕后盖损坏；
2. 屏幕后盖卡扣断裂

## 所需的工具和材料

1. 新的屏幕后盖 \* 1；
2. H1.5 内六角扳手

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除屏幕后盖

### 步骤 1：移除屏幕

参考 [更换屏幕](replace-screen.md) 的指引，移除屏幕。

![remove_the_cable003.jpg](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/replace-front-cover/remove_the_cable003.jpg)

### 步骤 2：移除屏幕后盖

使用 H1.5 内六角扳手移除三颗屏幕后盖固定螺丝（BT2x5），然后使用 H1.5 内六角扳手移除两颗屏幕排线接口板固定螺丝（BT2x5）；

|  |  |
| --- | --- |
|  |  |

抓住转轴轻轻往上拉，打开螺丝孔下方的开孔，沿着开口小心地撬开两侧的卡扣。当两边的卡扣都松开后，将后盖向下拉动即可松开上方的卡扣,取下后盖。

**请勿用力直接撬开后盖，以免造成损坏。**

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 安装屏幕后盖

### 步骤 1：安装屏幕后盖

将屏幕排线接口板穿过后盖转轴（请注意区分方向），并将接口板与螺丝孔位对齐；

|  |  |
| --- | --- |
|  |  |

将屏幕后盖底部先卡入屏幕，确保底部齐平。然后沿着边缘按压屏幕后盖，使屏幕后盖卡扣安装到位；

|  |  |
| --- | --- |
|  |  |

使用 H1.5 内六角扳手拧紧两颗屏幕排线接口固定螺丝（BT2x5），再使用 H1.5 内六角扳手拧紧三颗屏幕后盖固定螺丝（BT2x5）。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：安装屏幕

参考[更换 P2S 屏幕](replace-screen.md)的指引，安装好屏幕。  
![install_the_screen020.jpg](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/replace-front-cover/install_the_screen020.jpg)

## 如何验证成功

- 检查屏幕能正常固定在打印机上；
- 启动打印机，确认打印机屏幕能正常显示且触摸屏功能正常；
