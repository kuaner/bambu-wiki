XY 轴惰轮作为打印机传动系统的关键部件，其顺畅运行直接影响打印精度与设备寿命。定期对惰轮进行润滑保养，可有效减少机械磨损、降低运行噪音，保障设备长期稳定工作。

**建议维护周期**：每 3-6 个月进行一次全面保养；若出现 XY 轴打印异响、传动卡顿等异常情况，应立即停机检查并执行维护操作。

## 所需材料

- 润滑油

建议您将润滑油斜向剪开，便于精准滴注。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/010.png)

> 温馨提示：随机附赠的润滑油外包装有所变更。为确保精准加注，推荐使用尖嘴头或滴管进行操作。

## 安全提示

> 在对打印机及其电子设备进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 惰轮润滑

### 张紧惰轮

首先来到打印机后方，润滑左张紧惰轮，润滑前需要将工具头移动到左侧方便后续移动使润滑油进入惰轮。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/018.png)

按下图所示位置，在皮带顶部位置滴注 1-2 滴润滑油。

|  |  |
| --- | --- |
|  |  |

> 经过大量实验测试该润滑方式不会对皮带强度及使用寿命产生影响寿命，请放心润滑。

> 若润滑油无法直接加注到背部惰轮位置，也可将其涂抹在机舱内皮带的上下边缘；随后移动工具头，润滑油会随皮带运转被带入惰轮，该方法同样能达到消音润滑的效果。
>
> |  |  |
> | --- | --- |
> |  |  |

润滑完成后缓慢将工具头向右侧拉动，使润滑油随皮带运转均匀渗入惰轮内部。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/015.png)

接下来我们润滑右侧惰轮，首先将工具头移动至右侧。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/017.png)

采用相同方法在右侧皮带顶部接触点滴注 1-2 滴润滑油。

|  |  |
| --- | --- |
|  |  |

缓慢将打印喷头向左侧拉动，使润滑油充分浸润惰轮。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/016.png)

### XY 框架惰轮

首先对打印机前部惰轮进行润滑操作，该部件位于前门玻璃左右上方。将润滑油涂抹于外侧皮带顶部与惰轮的接触区域，确保油脂可随皮带运转自然渗入惰轮。

|  |  |
| --- | --- |
|  |  |

接下来润滑X轴组件左右两侧惰轮，如下图所示将润滑油涂抹于以下两个位置皮带上方边缘即可。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/020.png)

右侧惰轮采用相同操作标准，在下图所示的两个皮带上方接触位置涂抹润滑油。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/021.png)

接下来润滑尾部惰轮，在上下两根传动皮带的顶部接触区域进行润滑。（在对应位置各点涂 1-2 滴即可）

|  |  |
| --- | --- |
|  |  |

完成上述润滑后，手动拖动工具头沿前后、左右方向做全行程移动，通过皮带与惰轮的摩擦传动，使油脂均匀渗入惰轮。

|  |  |
| --- | --- |
|  |  |

## 惰轮轴润滑

**惰轮轴润滑涵盖前惰轮轴（左右两侧）和后惰轮轴（左右两侧）。因中间 X 轴组件惰轮为一体化密封结构，无法拆卸，故不进行轴体润滑。**

在润滑前，首先需要拧松打印板背后的四颗张紧螺丝（无需完全拧下），使皮带松弛，以便后续安装固定块。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/belt-tension/image.png)

### 前惰轮轴润滑

使用 H2.0 螺丝刀移除实况摄像头上方的两颗固定螺丝，取出固定块，暴露惰轮轴体

|  |  |
| --- | --- |
|  |  |

向轴体与轴承的结合部位滴注 1-2 滴润滑油。（建议使用带毛细管的润滑油，方便点涂）

> 如果此处较难润滑，您也可以参考 P2S [惰轮更换指南](replace-idler-pulley.md)将其取下进行润滑。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/029.png)

接下来润滑右侧前惰轮，移除对应位置的两颗固定螺丝，取出固定块。

|  |  |
| --- | --- |
|  |  |

在轴体与轴承的接触点位滴注润滑油。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/032.png)

润滑完成后将固定块重新装回，并锁紧两颗螺丝。

### 后惰轮轴润滑

接下来开始润滑后惰轮，首先移除图示位置的三颗固定螺丝，向后拉出惰轮组件。

|  |  |
| --- | --- |
|  |  |

对两根轴体的左右两侧共四个点位进行润滑，确保轴体与轴承接触部位充分润滑。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/026.png)

润滑完成后，手动转动惰轮，确认运转顺滑无卡滞、无异常声响后，将组件装回原位并锁紧螺丝。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/004.webp)

接下来润滑左侧后惰轮，如下图所示移除三颗螺丝并取出惰轮组件。同样润滑惰轮轴两侧。

|  |  |
| --- | --- |
|  |  |

润滑完成后如下图所示将惰轮组件装回，并锁紧三颗固定螺丝。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/025.png)

所有惰轮轴安装完成后，手动拖动工具头沿 XY 轴往复移动（不少于 3 次），确保润滑油在轴体与轴承之间充分扩散，实现均匀润滑。

|  |  |
| --- | --- |
|  |  |

最后，拧紧机身后的四颗张紧螺丝，完成皮带固定。

> 注意：锁紧张紧器螺丝时请勿过度锁紧，避免滑丝。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/belt-tension/image.png)

## 全面校准

完成惰轮润滑后，建议进入设备校准界面执行**全面校准程序**，以确保机械部件在最佳状态下协同工作。具体包括：**电机降噪、振动补偿、自动热床调平**

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/008.png)

待全面校准流程自动完成后，您可以发起打印任务进行测试。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/idle-pulley-lubrication/009.png)
