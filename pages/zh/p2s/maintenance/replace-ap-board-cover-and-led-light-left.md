## AP 板盖/LED 补光灯 - 左

**AP 板盖：**  
安装在打印机左侧横梁处的塑料盖子，用于遮挡和保护AP 主板盖及其连接线缆。  
配件包装内包含：

1. AP 板盖 \* 1；
2. LED 灯罩 \* 1；
3. BT2x8 螺丝 \* 2  
   ![dlb049.jpg](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/p2s-sku-pics/dlb049.jpg)  
   **LED 补光灯 - 左：**  
   安装在 AP 板盖上，可用于给打印机腔室补光的LED灯条。  
   配件包装内包含：
4. LED 补光灯 \* 1  
   ![fah049.jpg](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/p2s-sku-pics/faz049.jpg)

## 何时更换

1. AP 板盖损坏；
2. LED 灯不亮或损坏

## 所需的工具和材料

1. 新的 AP 板盖/LED 补光灯 - 左；
2. H1.5 内六角扳手；
3. 镊子

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

> **易损提示：请勿从前端直接掰开 AP 板盖，会导致 AP 板盖折断！**

## 移除 AP 板盖/LED 补光灯

### 步骤 1：移除料管支架

参考 [更换料管支架](replace-ptfe-tube-bracket.md) 的指引，移除料管支架。  
![ptfe_tube_bracket_002.png](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/rear_panel/ptfe_tube_bracket_002.png)

### 步骤 2：解锁 AP 板盖

揭开 AP 板盖检修端，从 AP 板上断开 LED 补光灯 - 左连接线。

|  |  |
| --- | --- |
|  |  |

使用 H1.5 内六角扳手移除 2 颗 AP 板盖固定螺丝（BT2x8）。

![ap_002.png](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/replace-ap-board-cover-and-led-light-left/ap_002.png)

### 步骤 3 ：移除 AP 板盖

握住 AP 板盖连接拖链的一端，向右侧方向拉出 AP 板盖。在拉出时请用左手托住 AP 板左侧，当右侧拖链端拉出时，左手扶住 AP板盖，避免 AP 板盖跌落。

|  |  |
| --- | --- |
|  |  |

从 AP 板盖一侧起算，于第 2 节拖链处断开拖链，松开工具头线缆后，取下 AP 板盖。

![1_009.png](https://public-cdn.bblmw.com/wiki/new/1_009.png)

### 步骤 4：移除 LED 补光灯 - 左

用手顶开 LED 补光灯盖的两个卡扣，将灯罩从 AP 板盖上取下。

|  |  |
| --- | --- |
|  |  |

松出连接线，将 LED 补光灯从 AP 板盖上撕下。

|  |  |
| --- | --- |
|  |  |

## 安装 AP 板盖/LED 补光灯

### 步骤 1：安装 LED 补光灯 - 左

将新的 LED 补光灯 - 左的背胶撕下，将 LED 灯贴的一半装到灯槽上，将线缆穿过 AP 板盖，再按压 LED 补光灯，将其完全贴装好。

|  |  |
| --- | --- |
|  |  |

![led_017.png](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/replace-ap-board-cover-and-led-light-left/led_017.png)

将 LED 补光灯罩安装到 AP 板盖上，确认卡扣完全扣紧。

![led_018.png](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/replace-ap-board-cover-and-led-light-left/led_018.png)

### 步骤 2：安装 AP 板盖

将工具头线缆装入 AP 板盖，并连接上拖链。

![j_010.png](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/replace-ap-board-cover-and-led-light-left/j_010.png)

沿着安装槽将 AP 板盖拖链后侧推到位（可使用内六角扳手确认螺丝孔是否对齐），在推动 AP 板盖的时候，请用手扶着 AP 板盖检修端，并将卡扣装入框架中。

|  |  |
| --- | --- |
|  |  |

将 LED 补光灯 - 左的连接线连接到 AP 板，合上检修端。

![led_001.png](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/replace-ap-board-cover-and-led-light-left/led_001.png)

![ap3_007.png](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/replace-ap-board-cover-and-led-light-left/ap3_007.png)

使用 H1.5 内六角扳锁紧 2 颗螺丝（BT2x8），固定 AP 板盖。

![ap_002.png](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/replace-ap-board-cover-and-led-light-left/ap_002.png)

### 步骤 3：安装料管支架

请参考 [更换料管支架](replace-ptfe-tube-bracket.md) 的指引，将料管支架重新装回。

![ptfe_tube_bracket_002.png](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/rear_panel/ptfe_tube_bracket_002.png)

## 如何验证成功

连接电源，打开打印机，在屏幕上开启和关闭 LED 灯，确认功能正常。

如果您遇到任何问题，请先回溯您的步骤并检查 LED 补光灯 - 左的连接线是否连接正常，然后再次检查是否可以正常使用。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
