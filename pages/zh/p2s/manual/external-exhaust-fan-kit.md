P2S 打印机默认采用内部循环式废气处理设计，依托内部活性炭滤芯实现废气过滤。加装外排风扇套件后，设备将新增主动外排功能，为有严格外排要求的用户提供解决方案。对于具备外排条件的用户，该套件可将打印废气直接引至室外或指定区域。

加装完成后，打印机将自动识别外排风扇套件，并将其整合至空调系统进行统一管控，同时解锁打印结束后自动空气净化功能。针对 ABS、PA 等需密封打印的工程材料，只需在打印机屏幕设置中启用 “打印结束时净化空气” 功能，P2S 打印完成后便会自动开启外排模式，彻底排出机箱内残留气体。

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/019.jpg)

> 软件要求：正式加装前，需完成以下软件版本升级，确保设备兼容性：
>
> 1. 打印机固件版本需升级至 01.01.01.00 及以上；
> 2. 电脑端 Bambu Studio 需更新至 V2.4.1.80 及更高版本；
> 3. 移动端 Bambu Handy 需更新至 V3.11.0 及更高版本。

## 加装方案说明

P2S 打印机外排风扇加装提供两种可选方案，适配不同用户的使用需求：

### 方案一：更换外排风扇专用背板

该背板的排气孔位于缓冲器下方，气流通道设计更合理，排气效率更高。

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/017.jpg)

### 方案二：沿用原装打印机背板

排气孔设置在废料滑梯右侧，经官方测试，该方案可满足日常打印的正常排风需求。

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/022.jpg)

## 安装步骤

### 1. 更换打印机背板（可选，适配方案一）

若采用方案一加装，需先更换外排风扇专用背板。

移除原有背板：先拆卸缓冲器，再拧下背板固定螺丝（共三种型号，拆装时需注意区分）：

- 黄色标记螺丝：BT3x6
- 红色标记螺丝：ST3x4.5
- 绿色标记螺丝：M3x4.5

![013.png](https://wiki.bambulab.com/p2s/manual/013.png)

> 详细更换背板流程可参考Wiki指引：[P2S 背板更换指南](../maintenance/replace-rear-panel.md)

按照指引安装专用打印机背板。

|  |  |
| --- | --- |
|  |  |

### 2. 组装外排风扇

组装外排风扇顶盖，用 BT2\*5 螺丝将六个卡爪固定在外排风扇顶盖，开始前可以先可以将对应卡爪放置在对应槽位旁边，避免安装错误。

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/028.png)

先逐个安装右侧三个卡爪，需要确保卡爪和槽位适配。

|  |  |
| --- | --- |
|  |  |

安装左侧三个卡爪时，可先将三个卡爪同时卡入顶盖左侧的槽位中，再统一用 BT2x5 螺丝锁紧。

|  |  |
| --- | --- |
|  |  |

接下来进行外排风扇盖子的泡棉粘贴操作，首先取细泡棉，沿着风扇盖子的外围依次粘贴三面，确保泡棉与盖子边缘紧密贴合。

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/060.webp)

找到较短的一段泡棉，将其粘贴在盖子剩余的一面，完成风扇盖子泡棉的初步粘贴。

|  |  |
| --- | --- |
|  |  |

接下来，在出风口位置粘贴四块小泡棉防止风扇噪音，同时，在 6pin 线缆接头上方（示意图红色标注位置）粘贴长条泡棉，提升外排风扇的密封性能。

|  |  |
| --- | --- |
|  |  |

> 注：出风口四块小泡棉需要用此泡棉，同时该泡棉还用于滤芯四角。  
> ![1280x1280.jpg](https://wiki.bambulab.com/p2s/1280x1280.jpg)

准备风扇外壳，控制板，风扇以及三颗固定螺丝。

![77.png](https://wiki.bambulab.com/p2s/77.png)

在将风扇与控制板装入外壳前，先把风扇线缆连接至控制板，确保线缆连接牢固无松动。

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/036.png)

线缆连接完成后，将风扇与控制板一同装入风扇外壳内，再用三颗 BT25 螺丝将接口板固定在外壳上。装配完毕后，需将多余的线缆卡入外壳的走线槽内并固定。

> 注意：风扇安装时有明确的朝向要求，需将无标签的一侧朝内，带标签的一侧朝向打印机外侧，切勿装反。

> ![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/015.jpg)

|  |  |

上盖安装后，观察风扇左右两侧的四颗卡扣，若卡扣均已牢牢卡住，说明上盖安装到位。

### 3. 安装至打印机

#### 方案一：使用专用打印机背板

将专用打印机背板上排放口的贴纸撕开，露出安装位。

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/059.webp)

手持外排风扇，将其对准背板上的卡扣并向左推动，使风扇直接卡入背板的预设安装位；安装完成后，将风扇的线缆 6PIN 连接至缓冲器的对应接头。

|  |  |
| --- | --- |
|  |  |

#### 方案二：使用原有打印机背板

取出提前打印好的转接件，将其放置在原有打印机背板的对应位置，并用三颗螺丝进行固定，确保转接件安装牢固不晃动。

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/051.png)

> 注：上图右侧固定侧板的一颗螺丝需要更换，此处三颗螺丝为 M3x6（套件内有附赠）。
>
> ![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/004.jpg)

再将外排风扇组件对准转接件上的槽位，缓慢向上推动，使风扇组件与转接件完成卡合固定。

|  |  |
| --- | --- |
|  |  |

把风扇的 6PIN 线缆连接至缓冲器的接口处，连接完成后的状态可参考下图。

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/021.jpg)

### 4. 连接外排气管（可选）

若需要为打印机安装外排气管，首先需提前打印好气管接头和卡扣这两个配件。

开始组装排风管接头的卡扣，该卡扣分为长、短两个部分，先将较短的部件安装在排风管接头上，随后锁紧部件左右两侧的螺丝进行固定。

> 注意：此处的螺丝起到轴的作用，安装时不可过度锁紧，否则会导致卡扣无法顺滑活动，影响后续使用。

|  |  |
| --- | --- |
|  |  |

将较长的卡扣部件插入较短部件的一端，对准两者的螺丝孔后，锁紧左右两侧的螺丝，完成两个卡扣部件的拼接。

|  |  |
| --- | --- |
|  |  |

用手上下活动卡扣，检查其是否运动顺滑、无卡涩；按照此方法完成三个卡扣的组装，组装后的整体状态可参考下图。

| --- | --- |
|  |  |

将排气管的一端套在气管接头上，通过卡扣进行三点固定以完成安装，建议先固定上下两侧的卡扣，再固定右侧的卡扣。

## 风扇开启与控制方法

### 自动开启

外排风扇配备专有控制逻辑，适配不同耗材打印场景：

1. 打印 PLA、TPU、PVA、PETG等低温耗材时，外排风扇自动启动，初始以 30% 最低转速运行，转速随仓温升高同步上调，增强腔体散热。
2. 打印 ABS、PA 等高温耗材时，外排风扇默认关闭，避免降低腔内温度，仅支持手动开启。

此外，可在打印机屏幕的打印选项界面勾选 “打印结束后净化空气 - 外排”，打印完成后设备将自动开启外排，排出残留废气；

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/001.png)

### 手动开启

#### 打印机端

安装完成后，在设备调节界面打开空调系统，找到外排风扇控制选项，可直接手动开启并调节。

|  |  |
| --- | --- |
|  |  |

#### Bambu Studio

在软件设备界面的风扇控制模块中，选择外排风扇并手动开启。

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/025.png)
