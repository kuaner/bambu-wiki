## 操作步骤

### P2S Combo

#### 步骤1：移除包装

- 打开外箱，取出工具盒和快速入门指南。

|  |  |
| --- | --- |
|  |  |

- 移除纸卡，取下顶部泡棉。

|  |  |
| --- | --- |
|  |  |

- 提出打印机，放置于稳定平面，撕开并移除防潮袋。

|  |  |
| --- | --- |
|  |  |

- 移除侧板底部胶带。

|  |  |
| --- | --- |
|  |  |

> 注意：请确保完全移除侧板底部的胶带，否则可能影响机箱的散热效果。

- 撕开顶部胶带，取下上盖玻璃，移除保护袋。

|  |  |
| --- | --- |
|  |  |

- 撕开前门胶带，移除保护袋。

|  |  |
| --- | --- |
|  |  |

#### 步骤2：取出配件与AMS

- 取出配件盒，移除AMS顶部所有泡棉。

|  |  |  |
| --- | --- | --- |
|  |  |  |

> 包装方案更新，请按下图所示移除所有泡棉。  
> ![p2s-top-foams-new.png](https://wiki.bambulab.com/p2s/manual/unboxing-guide/p2s-top-foams-new.png)

- 用内六角扳手 H2.0 拧下 2 颗红色标记的螺丝。  
  ![19-remove-ams-screw.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/19-remove-ams-screw.png)

> 热床周围的泡棉请暂时保留，待校准完成后再移除。

- 向上取出 AMS，移除机箱内壁上的泡棉。

|  |  |
| --- | --- |
|  |  |

> 由于包装方案更新，机箱左侧的泡棉已取消，您只需移除机箱右侧和后方的泡棉。  
> ![remove-combo-chamber-foam-new.jpg](https://wiki.bambulab.com/p2s/manual/unboxing-guide/remove-combo-chamber-foam-new.jpg)

#### 步骤3：移除运输材料

- 用 H2.0 扳手拧下 3 颗螺丝，移除 AMS 运输固定件。

|  |  |
| --- | --- |
|  |  |

- 用 H2.0 扳手拧下 1 颗热床固定螺丝。  
  ![24-unlock-heatbed.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/24-unlock-heatbed.png)

> **注意：** 拆卸该螺丝过程中，螺丝易掉落至机箱后侧，建议使用吸磁螺丝刀、镊子等工具承接，避免螺丝掉入设备缝隙。

> 由于包装方案更新，热床左右前侧的两块固定泡棉已取消。若您收到的打印机仍包含此泡棉，请在此步骤将其移除。  
> ![25-remove-front-foam.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/25-remove-front-foam.png)

- 移除机箱内壁固定的干燥剂。  
  ![26-remove-chamber-dessicant.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/26-remove-chamber-dessicant.png)
- 下拉左右侧丝杆顶部的红色塑胶保护件，打开并移除。

|  |  |
| --- | --- |
|  |  |

- 剪断并移除光杆及工具头上的扎带，盖上玻璃上盖。

|  |  |
| --- | --- |
|  |  |

#### 步骤4：安装屏幕

- 移除排线固定胶布，按住排线两侧端子，将排线插入屏幕。

|  |  |
| --- | --- |
|  |  |

- 将排线收回打印机槽内，插入屏幕，左推锁紧。  
  ![33-install-screen-3.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/33-install-screen-3.png)

#### 步骤5：安装AMS

- 移除 AMS 表面保护膜和内部泡棉。

|  |  |
| --- | --- |
|  |  |

- 取出干燥剂并移除外包装后，放回原位。

|  |  |
| --- | --- |
|  |  |

- 将 AMS 放至打印机顶部。  
  ![38-install-ams-1.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/38-install-ams-1.png)
- 撕下打印机背部固定铁氟龙料管的胶带，将料管插入机箱进料口。

|  |  |
| --- | --- |
|  |  |

- 从配件盒取出 3 根铁氟龙料管中最长的一根。一端插入 AMS 出料口，推入到底，另一端插入缓冲器左侧任一进料口。

|  |  |
| --- | --- |
|  |  |

- 从配件盒取出 6-pin 连接线，两端分别插入打印机缓冲器和 AMS 任一 6-pin 接口。

|  |  |
| --- | --- |
|  |  |

#### 步骤6：安装料盘支架组件

- 从配件盒中取出料盘支架组件，将料盘支架滑入底座。  
  ![45-install-spool-holder-1.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/45-install-spool-holder-1.png)
- 将铁氟龙料管支架向下插入料盘支架上的凹槽。  
  ![46-install-spool-holder-2.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/46-install-spool-holder-2.png)
- 将较短的铁氟龙料管一端插入气动接头，另一端插入缓冲器的另一个进料口。

|  |  |
| --- | --- |
|  |  |

> 温馨提示：  
> 如需移除连接缓冲器的铁氟龙料管，请先按压黑色的气动接头，再向外轻拉料管。  
> ![release-tube-from-buffer.webp](https://wiki.bambulab.com/p2s/manual/first-print/release-tube-from-buffer.webp)  
> 分离料盘支架时，首次操作较为费力，建议先上下晃动支架，再顺势向外拔出。  
> ![10月21日.webp](https://wiki.bambulab.com/p2s/manual/10%E6%9C%8821%E6%97%A5.webp)

#### 步骤7：开机与校准

- 插入电源线并开机。

|  |  |
| --- | --- |
|  |  |

- 根据屏幕指引，进行首次校准。  
  ![51-calibration-1.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/51-calibration-1.png)

> 开始校准前，请确保打印板已放置在热床上。

- 完成校准后，取出热床底部的泡棉。

|  |  |
| --- | --- |
|  |  |

一切准备就绪，现在即可开启您的创作之旅。请参见 [P2S 首次打印](first-print.md)，开始您的首次打印。

### P2S

#### 步骤1：移除包装

- 打开外箱，取出并仔细阅读快速入门指南。  
  ![54-read-p2s-qs.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/54-read-p2s-qs.png)
- 移除纸卡，取出铁氟龙料管，继续移除顶部泡棉。

|  |  |  |
| --- | --- | --- |
|  |  |  |

- 提出打印机，放置于稳定平面，撕开并移除防潮袋。

|  |  |
| --- | --- |
|  |  |

- 移除打印机侧板底部的胶带。

|  |  |
| --- | --- |
|  |  |

> 请确保完全移除侧板底部的胶带，否则可能影响机箱的散热效果。

- 撕开顶部胶带，取下上盖玻璃。

|  |  |
| --- | --- |
|  |  |

- 撕开前侧胶带，取下前门保护袋。

|  |  |
| --- | --- |
|  |  |

#### 步骤2：取出配件

- 取出顶部所有配件，移除纸卡。  
  ![60-take-all-acc.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/60-take-all-acc.png)

#### 步骤3：拆除运输材料

- 用内六角扳手 H2.0 拧下 3 颗螺丝，解锁热床。  
  ![61-unlock-p2s-heatbed.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/61-unlock-p2s-heatbed.png)

> **注意：** 拆拆卸打印机后侧的热床固定螺丝时，该螺丝易掉落至机箱内部。建议提前准备吸磁螺丝刀、镊子等工具承接或辅助取出，避免螺丝掉入设备缝隙。

> 热床周围的泡棉请暂时保留，待校准完成后再移除。

- 移除机箱内的干燥剂和胶带。

|  |  |
| --- | --- |
|  |  |

- 下拉左右侧丝杆顶部的红色塑胶保护件，打开并移除。

|  |  |
| --- | --- |
|  |  |

- 剪断并移除光杆及工具头上的扎带，将工具头拉向前门，移除光杆后方泡棉。

|  |  |
| --- | --- |
|  |  |

#### 步骤4：安装屏幕

- 移除固定胶布，按住排线两侧端子，将排线插入屏幕。

|  |  |
| --- | --- |
|  |  |

- 将排线收回打印机槽内，插入屏幕，左推锁紧。  
  ![33-install-screen-3.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/33-install-screen-3.png)

#### 步骤5：安装料盘支架组件

- 取出料盘支架组件，将料盘支架滑入底座。  
  ![68-install-p2s-spool-holder-1.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/68-install-p2s-spool-holder-1.png)
- 将铁氟龙料管支架向下插入料盘支架上的凹槽。  
  ![69-intall-p2s-spool-holder-2.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/69-intall-p2s-spool-holder-2.png)
- 将较短的铁氟龙料管一端插入料盘支架的气动接头，另一端插入机箱进料口。

|  |  |
| --- | --- |
|  |  |

> 温馨提示：  
> 分离料盘支架时，首次操作较为费力，建议先上下晃动支架，再顺势向外拔出。  
> ![10月21日.webp](https://wiki.bambulab.com/p2s/manual/10%E6%9C%8821%E6%97%A5.webp)

#### 步骤6：开机与校准

- 插入电源线并开机。

|  |  |
| --- | --- |
|  |  |

- 根据屏幕指引，进行首次校准。  
  ![72-p2s-calibration-1.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/p2s-unboxing/72-p2s-calibration-1.png)

> 开始校准前，请确保打印板已放置在热床上。

- 完成校准后，取出热床底部的泡棉。

|  |  |
| --- | --- |
|  |  |

#### 步骤7：放置废料盒

开始打印前，推荐准备一个盒子放置于**打印机背面的废料滑梯下方**，用于收集打印过程滑出的废料，保持环境整洁。

您可以打印一个 [P2S 专用废料盒](https://makerworld.com.cn/zh/search/models?keyword=P2S%E5%BA%9F%E6%96%99%E7%9B%92)，也可以使用耗材包装盒或其他容器来接废料。

下图为 P1S 打印机放置示例。

![purge_container_placement_p1s_example.png](https://wiki.bambulab.com/p1/manual/p1s-unboxing/purge_container_placement_p1s_example.png)

接下来，请参考 [P2S 首次打印](first-print.md) 进行首次打印。
