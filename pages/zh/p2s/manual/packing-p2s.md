## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### P2S Combo

#### 步骤1：退料、下降热床、关闭电源

- 将 AMS 内的耗材卷回料盘并取出。  
  ![1-remove-ams-spool.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/packing-p2s/1-remove-ams-spool.png)
- 在屏幕点击退料后，将外挂料架上的耗材卷回料盘并拿下。

|  |  |
| --- | --- |
|  |  |

- 放回热床底部泡棉。  
  ![4-place-foam-under-heatbed.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/packing-p2s/4-place-foam-under-heatbed.png)
- 使用屏幕控制热床下降至底部，压紧泡棉。

|  |  |
| --- | --- |
|  |  |

> 热床接近底部时，请每次降低 1mm 进行操作，防止热床冲撞打印机底部。

- 关闭电源，拔下电源线。

|  |  |
| --- | --- |
|  |  |

#### 步骤2：移除外挂料盘

- 移除连接至料盘支架的铁氟龙管。

|  |  |
| --- | --- |
|  |  |

- 向外拉动移除料盘支架组件后，拆解料盘支架组件。

|  |  |
| --- | --- |
|  |  |

> 温馨提示：分离料盘支架时，首次操作可能会稍显费力，建议先上下晃动支架，再顺势向外拔出即可。  
> ![10月21日.webp](https://wiki.bambulab.com/p2s/manual/10%E6%9C%8821%E6%97%A5.webp)

#### 步骤3：移除 AMS

- 移除 6 pin 连接线。

|  |  |
| --- | --- |
|  |  |

- 移除连接至 AMS 的铁氟龙管。

|  |  |
| --- | --- |
|  |  |

- 取下气动接头固定片，拔出机箱进料口的铁氟龙管，用胶带固定在背板上，装回固定片。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

- 取下 AMS，放回 AMS 内部泡棉。  
  ![21-place-ams-foam.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/packing-p2s/21-place-ams-foam.png)

#### 步骤4：拆除屏幕

- 按压屏幕转轴底部的解锁位。

|  |  |
| --- | --- |
|  |  |

- 右推屏幕后向外轻拉。  
  ![24-remove-screen-3.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/packing-p2s/24-remove-screen-3.png)
- 按住排线两侧的端子取下屏幕。  
  ![25-remove-screen-4.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/packing-p2s/25-remove-screen-4.png)
- 将拉出的排线微微收回打印机槽内，用胶布固定。

|  |  |
| --- | --- |
|  |  |

#### 步骤5：固定工具头、丝杆、热床

- 使用扎带绑紧工具头和光杆。

|  |  |
| --- | --- |
|  |  |

- 安装两个丝杆保护件。

|  |  |
| --- | --- |
|  |  |

- 放回干燥剂。  
  ![32-place-dessicant.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/packing-p2s/32-place-dessicant.png)
- 拧紧 1 颗螺丝，固定热床。  
  ![33-secure-heatbed.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/packing-p2s/33-secure-heatbed.png)

#### 步骤6：固定AMS

- 放回 AMS 固定件，拧紧 3 颗螺丝。

|  |  |
| --- | --- |
|  |  |

- 放回机箱内壁上的泡棉。

|  |  |  |
| --- | --- | --- |
|  |  |  |

> 如打印机包装不含左侧泡棉，只需放回右侧和后方泡棉（面向打印机前门）。

- 对准底部固定件卡槽，放回 AMS，确保AMS上盖与泡棉贴合。  
  ![39-put-asm-back.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/packing-p2s/39-put-asm-back.png)
- 拧紧底部 2 颗螺丝。  
  ![40-secure-ams.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/packing-p2s/40-secure-ams.png)
- 放回顶部所有泡棉和配件盒。

|  |  |  |
| --- | --- | --- |
|  |  |  |

#### 步骤7：固定打印机并装箱

- 套上前门保护袋，并用胶带固定。

|  |  |
| --- | --- |
|  |  |

- 套上玻璃上盖保护袋，放至打印机顶部并用胶带固定。

|  |  |
| --- | --- |
|  |  |

- 把打印机放进防潮袋内，提起顶部两角放回外箱。

|  |  |
| --- | --- |
|  |  |

- 将缓冲气垫放至打印机四周。  
  ![50-place-air-cushion.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/packing-p2s/50-place-air-cushion.png)
- 放回顶部泡棉、纸卡、工具盒。

|  |  |  |
| --- | --- | --- |
|  |  |  |

- 用胶带封住外箱。  
  ![54-seal-box-4.png](https://public-cdn.bblmw.com/wiki/new/p2s/manual/packing-p2s/54-seal-box-4.png)
