## 01.02.00.00（20260409）

### 新增功能

1. 支持边烘干耗材边打印功能  
   需要注意功率限制和烘干温度不能高于材料的软化温度
2. 支持远程开启烘干功能

|  |  |
| --- | --- |
|  |  |

3. 支持延时摄影录制到内置存储，无需U盘即可录制  
   同时支持内置延时摄影文件导出功能，内外置延时摄影文件删除功能。  
   ![3-cn.png](https://wiki.bambulab.com/p2s/release-note/u2/3-cn.png)
4. 支持曲线规划增强功能  
   优化了曲线规划，改善某些场景下的打印质量。
5. 新增AI检测报错弹窗显示实况图像  
   目前实况摄像头遮挡检测、异物检测、炒面检测、裹头检测支持弹窗显示实况图像。  
   ![5-cn.png](https://wiki.bambulab.com/p2s/release-note/u2/5-cn.png)
6. 新手指引流程体验优化  
   新增新手引导流程，帮助新用户快速上手完成首次打印。后续可于“工具箱-新手引导”再次查看教学。  
   ![6-cn.png](https://wiki.bambulab.com/p2s/release-note/u2/6-cn.png)
7. 错误码弹窗详细原因展示  
   联动HMS显示可能的更详细的错误原因。  
   ![7-cn.png](https://wiki.bambulab.com/p2s/release-note/u2/7-cn.png)
8. 新增打印发起停止后进入停止中状态  
   此时打印机会屏蔽操作输入直到停止动作结束，避免在停止动作进程中由于插入操作指令导致控制指令时序错乱的问题。
9. 新增外挂料手动换料多色打印入口  
   使用外挂料时，新增加多色打印的按钮，以便在使用外部线轴时简化多色打印流程。开启后可以手动更换耗材，确保在没有AMS的情况下实现更顺畅的颜色过渡。  
   ![9-cn.png](https://wiki.bambulab.com/p2s/release-note/u2/9-cn.png)
10. 新增热床低功率模式  
    以便于在用户打印机供电功率受限的情况下，通过延长热床升温时间，降低最大功率。  
    ![10-cn.png](https://wiki.bambulab.com/p2s/release-note/u2/10-cn.png)
11. 支持XYZ电机空闲自由移动模式，方便维护维修  
    ![11-cn.png](https://wiki.bambulab.com/p2s/release-note/u2/11-cn.png)
12. 新增热床底部异物检测  
    在打印开始前检查热床底部空间，保证打印完整进行。
13. 打印板在位检测默认开启  
    打印板在位检测默认开启，不受打印板类型检测开关控制（防止使用第三方打印板的用户关闭打印板检测后漏放打印板）。
14. 支持首层质量校准功能  
    支持微调首层打印时喷嘴与热床间的距离，从而提升首层附着力与表面平整度。  
    注意：该功能是为了满足专业用户不同场景差异化的调参需求，一般情况无需用到，建议按需使用。  
    ![14-cn.png](https://wiki.bambulab.com/p2s/release-note/u2/14-cn.png)
15. 新增认证信息电子标签页  
    ![15-cn.png](https://wiki.bambulab.com/p2s/release-note/u2/15-cn.png)
16. 支持第三方VentoBox空气过滤装置的风扇速度调节与随打印任务启动  
    关于 VentoBox 创作者项目的特别说明： VentoBox 系拓竹科技与外部创作者联合发起的实验性项目。需特别留意，该项目本质上属于非官方改装方案，因此，涉及该改装件的安装指导及后续产品运维，均不属于拓竹官方客服的受理范畴。目前，此类合作尚处于试点评估阶段，尚未建立标准化的准入机制，故我司暂不接受其他创作者项目的嵌入申请。感谢您的理解与对创客生态的支持。  
    ![16-cn.png](https://wiki.bambulab.com/p2s/release-note/u2/16-cn.png)

### 功能优化

1. 挤出策略优化，优化部分场景出现挤出机过载的问题。
2. 堵头检测优化。降低部分场景的误报率。
3. 异物检测新增开关按钮，可以按需开启或关闭。  
   如果您使用第三方打印板频繁出现异物检测误检，可以通过开关关闭异物检测功能。
4. 优化部分场景的稳定性，修复一些低概率的问题。

## 01.01.03.00（20260209）

### 问题修复

1. 解决低概率打印期间发生系统崩溃导致打印失败的问题，进一步提升了系统的稳定性。

## 01.01.01.00（20251208）

### 新增功能

1. 新增对外排风扇套件的支持  
   该功能通过选配（需额外购买）加装外排风扇套件，使机器具备定向主动外排腔内气体的能力，使用此套件的用户在部分场景可以控制腔内气体通过外接排风管外排到指定的地方（比如打印工程耗材等等场景）。加装成功后，机器会自动识别风扇套件并且融合到空调系统中进行控制，同时用户也可以手动调整外排风扇的速度。详见WiKi：[P2S 外排风扇加装指南](external-exhaust-fan-kit.md) 。  
   该功能需Bambu Studio更新到V2.4.1.80或更高的版本；Bambu Handy更新到V3.11.0或更高的版本。

|  |  |
| --- | --- |
|  |  |

2.新增打印结束时净化空气功能  
该功能通过打印结束后，自动控制过滤系统运行一段时间，来进一步净化空气，更加符合对空气质量有高要求的用户的需求。该功能默认关闭，需要时要在机器设置页面->打印选项中开启，并且可以选择具体工作模式。默认情况下，该功能只支持内循环模式。如果有选配加装外排风扇套件，则可设置为外排模式，更有利于使用工程耗材的场景。该功能需Bambu Studio更新到V2.4.1.80或更高的版本/Bambu Handy更新到V3.11.0或更高的版本。

## 01.01.00.00（20251014）

### 新功能

1. 新增对辅助部件冷却风扇（左）的支持  
   该功能通过加装额外的辅助部件冷却风扇（左）（需另购），来获得更好的散热效果。部分场景可以有更好的打印效果，比如大面积悬垂场景等等。该功能需 Bambu Studio 更新到 V2.3.0.70 或更高的版本/Bambu Handy更新到V3.8.0或更高的版本。
2. 新增对高流量热端的支持  
   该功能通过选配额外的高流量热端（需另购），来获得更快的打印速度。该功能需 Bambu Studio 更新到 V2.3.0.70 或更高的版本/Bambu Handy 更新到 V3.8.0 或更高的版本。
3. 新增触碰裹头检测功能  
   该功能与实况相机裹头检测功能配合，覆盖更全面的打印场景。该功能在打印的第 4、11、20 层，通过挤出力传感器对喷嘴是否被耗材包裹进行检测。执行检测时，工具头会运动到热床外进行试探触碰，此过程会占用部分打印空间并需由擦料塔吸收喷嘴漏料以防打印瑕疵，在已有擦料塔的模型中会复用擦料塔，在无擦料塔的模型中（如单色模型）中自动新增一个小擦料塔。该功能需 Bambu Studio 更新到V2.3.0.70 或更高的版本，并在工艺预设下“其他-高级"中打开。  
   更多信息请参考：[Bambu Studio 触碰裹头检测功能介绍](../../software/bambu-studio/nozzle-clumping-detection-by-probing.md)。

![nozzle-detection-cn.png](https://public-cdn.bblmw.com/wiki/new/p2s/release-note/nozzle-detection-cn.png)

4. 新增触碰裹头检测校准功能  
   触碰裹头检测需要一个准确的触碰位置。由于P2S自身结构特性，不同机器触碰的物理位置会有一些差异，因此需要通过该功能进行校准标定。
5. 新增打印完结快照功能  
   该功能会在打印结束时，拍一张图片通过云端发送给handy，并且通过handy的系统通知展示该图片，让用户不用打开handy就能快速了解完结情况。当前只支持配合bambu handy使用。该功能需Bambu Handy更新到V3.8.0或更高的版本。

![](https://public-cdn.bblmw.com/wiki/new/p2s/release-note/renwuchenggong-1.jpeg)  
![](https://public-cdn.bblmw.com/wiki/new/p2s/release-note/renwuwancheng-2.png)

6. 新增打印机UI对俄语的支持

![eyu-cn.png](https://public-cdn.bblmw.com/wiki/new/p2s/release-note/eyu-cn.png)

7. 新增PIN码绑定功能  
   该功能让发起绑定不再限制打印机和电脑必须连接同一局域网。只要不同网络之间的必要接口和协议能够互相通信，即可在 Bambu Studio 中通过使用 Pin 码绑定打印机。该功能需Bambu Studio更新到V2.3.0.70或更高的版本。

![pin-code-cn.png](https://public-cdn.bblmw.com/wiki/new/p2s/release-note/pin-code-cn.png)

8. 新增AI视觉热端硅胶套在位检测功能  
   该功能基于实况摄像头对当前工具头上的热端硅胶套进行在位检测，防止高温料打印过程中热端硅胶套不在位出现打印质量等问题。
9. 新增发送当前盘到内置存储后打印功能  
   该功能让用户可以在没有外置存储（U盘）的情况下，也能发送当前盘到打印机，然后打印。该功能需Bambu Studio更新到V2.3.0.70或更高的版本。

![internal-store-cn.png](https://public-cdn.bblmw.com/wiki/new/p2s/release-note/internal-store-cn.png)

10. 新增仅局域网模式下发送到内置存储打印功能  
    该功能可以让用户在没有外置存储（U盘）的情况下，能直接利用打印机的内置存储，在仅局域网模式下发起远程打印。该功能需Bambu Studio更新到V2.3.0.70或更高的版本。
11. 新增加热底座维护模式功能  
    该功能开启后，即使未安装热端，也能升温加热底座。便于部分维护检修场景，用户进行工具头方面的维修。
12. 新增工具头前盖脱落检测和保护功能

### 功能优化

1. 优化了灵玑挤出机缠料检测/堵头检测功能，支持PLA，PETG，TPU耗材的检测
2. 优化了AI视觉炒面检测误检擦料塔的问题
3. 优化了AI视觉裹头检测功能，提高检出率，降低漏检率
4. 优化了空闲状态保护功能，支持空闲状态热床自动降温
5. 优化节能模式，增加对主机状态灯与AMS指示灯的控制
6. 优化一代AMS的湿度显示
7. 优化HMS消息的提示，增加条数显示
8. 优化了机器异常检测逻辑，开启了挤出电机过载检测功能

### 已知问题

1. 触碰裹头检测暂不支持高温耗材，会在后续版本支持。
