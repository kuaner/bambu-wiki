## 故障描述

对应的功能是”断料检测“，其功能是在外挂料盘耗材未装或用完后自动暂停打印并提示用户装入新的耗材。

- 打印机暂停，工具头挪到垃圾桶，屏幕弹框提示外挂料盘耗材用完；
- 屏幕耗材页面对应挤出机的耗材指示图标变为灰色，正常有耗材时图标是绿色。

## 工具、设备及材料

- 平头镊子
- 尖嘴镊子
- 内六角螺丝刀

## 排故措施

### 耗材已用完

如果发现耗材确实用完，则按屏幕提示装入新耗材到挤出机后，点继续恢复打印。

![20250905-111515.jpg](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/07ff_7000_0002_0003/20250905-111515.jpg)

### 耗材未用完

1. 如果发现耗材未用完且工具头内仍有耗材，检查耗材页面的耗材指示图标是否变为灰色；

|  |  |
| --- | --- |
| 灰色图标，霍尔开关状态：关 | 耗材颜色图标，霍尔开关状态：开 |

2. 若工具头里已有耗材，但 UI 的耗材指示图标仍然是灰色的，则可能是霍尔传感器异常导致误报没料，请参考[更换 P2S 挤出机配件](../../maintenance/replace-extruder-components.md)，重新拔插排线；

> **注意**：连接器盖子上可能有用于固定线缆连接的胶水，请用尖嘴镊子划开并小心移除胶水。断开该 FPC 排线时，请小心操作，避免因用力过猛导致排线损坏。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/extruder_unit/dipsconnect_fpc_007.png)

3. 如果依然报错，请用 H1.5 内六角扳手移除 2 颗螺丝（#5、#6），断开插头，取出进料霍尔组件。需要注意的是，取出时不要大力拉扯，摆放时也应小心操作，避免损坏黑色 FPC 排线。

|  |  |
| --- | --- |
|  |  |

将一截耗材插入进料霍尔组件，观察检测磁铁是否能够正常回弹。

![](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0700_2000_0002_0004/video.webp)

若磁铁无法回弹，请检查进料组件内部是否有断料，如有断料，需及时清理。

4. 如果仍有报错，请更换霍尔开关板组件。

[更换 P2S 挤出机配件](../../maintenance/replace-extruder-components.md)
