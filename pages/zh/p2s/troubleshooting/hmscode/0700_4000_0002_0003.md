## 故障描述

使用 AMS 时，缓冲器（或 AMS 集线器）连接在 AMS 和打印机之间。

它有一个滑块、一个弹簧和一个霍尔传感器。当 AMS 将耗材推入工具头挤出机时，由于耗材的压力，滑块将向前移动。然后，入口处第一个霍尔传感器检测耗材是否进入缓冲器，第二个滑块上方的霍尔传感器可以检测载滑块的位移和位置，并将该信号反馈回 AMS 和打印机。如果缓冲信号丢失，AMS 将无法顺利送入耗材。

![filament_buffer.jpg](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0700_4000_0002_0001/filament_buffer.jpg)

## 故障排除

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 步骤 1：重新插拔打印机背后缓冲器接线

![image-70.png](https://public-cdn.bblmw.com/wiki/new/p2s/hms/image-70.png)

### 步骤 2：检查 6-pin 线缆

检查线缆是否和 AMS 尾部接触良好，用手是否很容易就拔出来，建议使用二代 AMS 配套线缆，线缆区别如下:

![](https://wiki.bambulab.com//h2/troubleshooting/hmscode/0700_4000_0002_0001/image-8.png)

### 步骤 3：检查并重新连接 6-pin 线缆

请检查 6-pin 线缆的引脚是否打开（如下图 4-pin 所示）：

![](https://wiki.bambulab.com//h2/troubleshooting/hmscode/0700_4000_0002_0001/image.png)

并尝试重新连接 6-pin 线缆。

![screenshot-20250903-193140.png](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0700_4000_0002_0001/screenshot-20250903-193140.png)

### 步骤 4：检查 AMS 内部连接

如果问题仍然存在，请参考以下步骤检查 AMS 信号连接线是否松动：

1. 从 AMS 背面按压铁氟龙料管释放按钮，解锁接头，拉出料管；

![](https://wiki.bambulab.com//ams-2-pro/maintenance/disassembly-and-assembly/image-13.png)

2. 从下盖内部捏住卡扣自动弹开铁氟龙料管释放按钮后，从后面抽出铁氟龙料管释放按钮；

|  |  |
| --- | --- |
|  |  |

> 捏卡扣时，另一只手需要用从 AMS 的背面扶住铁氟龙料管释放按钮，以避免弹簧被弹出丢失。

3. 拆下中间 2 个料槽的从动支撑套筒组件;

![](https://wiki.bambulab.com//ams-2-pro/maintenance/disassembly-and-assembly/image-3.png)

4. 移除 2 颗螺丝 A (BT3x8);

![](https://wiki.bambulab.com//ams-2-pro/maintenance/disassembly-and-assembly/image-5.png)

5. 将主框架后部完全提起来，竖立放置在 AMS 下盖上。抬起时，建议先抬主框架前部分，再往前推，为框架后部分腾出空间。竖放AMS主框架时需避开风门的电子部件，以防压坏。

### 步骤 5：测量电压和电阻

1. 如果您有万用表，请将耗材卸载回 AMS，并检查缓冲器的滑块是否位于中间，如下所示：

![filament_buffer.jpg](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0700_4000_0002_0001/filament_buffer.jpg)

然后测量 6 针电缆（从 AMS 上拔下）引脚之间的电压。

![](https://wiki.bambulab.com//h2/troubleshooting/hmscode/0700_4000_0002_0001/image-2.png)

![](https://wiki.bambulab.com//h2/troubleshooting/hmscode/0700_4000_0002_0001/image-3.png)

正常电压应如下。**确保缓冲滑块回到左侧，否则电压值会有所不同。**

|  |  |
| --- | --- |
| pin-pin | 电压 |
| GND-Buffe\_A | 0.5~1.0V |
| GND-Buffe\_B | 2.8~2.3V |

**两个电压之和为3.0~3.3V（可以滑动滑块，测量不同位置电压，相加在这个范围内）。**

2. 如果测量的电压在正常范围内，则问题可能出在 AMS 侧。请测量 6 针电缆（插入 AMS）的电阻。正常电阻值如下：

|  |  |
| --- | --- |
| pin-pin | 电阻 |
| GND-Buffe\_A | 4~6 KΩ |
| GND-Buffe\_B | 4~6 KΩ |

如果测得的电阻值异常，请拆卸 AMS 并测量 AMS 主板上缓冲器 A 和 B 对 GND 的电阻。**正常范围为4~6KΩ。**如果电阻值异常，则 AMS 主板有故障。
