## 故障描述

自动热床调平通过检测热床的平面度，并且在打印过程中进行补偿，可获得更好的首层打印效果。当自动热床调平检测到的热床平面度数据出现异常值时会自动重试，如果依旧有异常值就会报此错误。

**导致该故障的原因包括：**

- 喷嘴或热床上可能有异物未清理干净
- Z滑块附近有异物卡住
- Z轴同步带轮有异物卡住

## 故障排除

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 排故措施

***用户可视情调整各排故措施的顺序。***

#### 步骤1. 检查热端喷嘴或热床上是否粘有耗材

|  |  |
| --- | --- |
|  |  |

若有耗材残留，请清理后重新调平。注意，清理热端时防止热端高温烫伤。

#### 步骤2. 检查3个Z轴滑块附近是否有异物卡住

![Z轴滑块异物检查](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0300_1800_0001_0005/plate.png)

若有耗材残留，请清理后重新调平。

#### 步骤3. 检查Z同步带轮是否被异物卡住

![Z轴同步带卡滞、打印机底部异物检查](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300_2500_0001_0005/image-1_cn.png)

请小心倾斜打印机，检查底部Z同步带轮是否被异物卡住。您可以手动拖拽同步带，观察是否阻塞Z轴运动。

若有异物或阻塞，请小心清理异物。

#### 步骤4. 重试调平

- 选项一

点击“校准”、“自动热床调平”。

![](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0300_1800_0001_0006/zidong-1.png)

- 选项二

重新发起打印，在“高级选项”中开启“自动热床调平”。
