## 故障描述

在使用外挂料盘进行打印时，系统会实时监测挤出电机的挤出力变化。若检测到挤出力异常，打印任务将自动暂停，需排除故障后方可继续打印。  
该告警用于识别“空打”现象。

|  |  |
| --- | --- |
| 挤出机  **挤出机** | 喷嘴  **喷嘴** |

**导致故障产生的原因包括：**

- 耗材直径过细、磨损，导致挤出机齿轮驱动耗材时打滑；
- 热端堵头，耗材无法从喷嘴挤出；
- 切片中设置的材料与实际使用的材料不符;
- 耗材触发了工具头进料传感器但是没有被挤出机咬上
- 在使用外挂料盘进行打印时，外挂料盘的耗材发生缠绕

> **备注：** 通过挤出电机检测空打的条件有3个：
>
> 1. 当前只支持当外挂料盘的耗材是PLA、PETG、PLA-CF、PETG-CF
> 2. 挤出流量需大于9.6mm^3/s
> 3. 暂时只支持0.4mm热端
>
> 检测时效性与打印耗材类型、打印速度等有关，检测可能有滞后，在故障排除后，请根据实际打印件情况，考虑是否继续打印。

## 故障排除

### 工具、设备及材料

- H2.0 内六角扳手
- H1.5 内六角扳手
- 斜口剪钳/剪刀
- 尖嘴钳

### 故障定位与解决流程

详细解决步骤见下文。

![](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0300_0900_0002_0004/13.png)

### 排故措施

***用户可依据实际情况调整各排故措施的顺序。***

#### 步骤 1. 确保实际使用耗材与切片中的一致

1. 若切片设置的耗材类型与实际使用的耗材不一致，可能导致空打现象。请调整切片参数或更换耗材，确保二者匹配。
2. 重新尝试挤出操作，若空打告警仍未消除，请跳转至 **步骤 2** 进行故障排查。

#### 步骤 2. 确保外挂料盘的耗材没有缠绕

外挂料盘的耗材可能发生缠绕，具体排查方法可参考 [排查外挂料盘的耗材缠绕故障](../../../h2/troubleshooting/hmscode/07FE_6000_0002_0001.md)。完成排查后，请再次尝试挤出耗材，如果仍然失败，请参照 **步骤 3** 继续排查。

#### 步骤 3. 降低喷嘴温度并手动切断耗材

1. 设置喷嘴温度为0°C，等待喷嘴降至室温

|  |  |
| --- | --- |
|  |  |

2. 按压切刀，切断耗材

![](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0300_0900_0002_0004/3-1.png)

#### 步骤 4. 升高喷嘴温度，尝试反向拉出耗材

1. 根据当前使用的耗材类型，将喷嘴温度设置为该耗材对应的打印温度，等待喷嘴升温至设定温度
2. 拔出挤出机上端PTFE管
3. 操作挤出机反向旋转，同时手动拉耗材

|  |  |
| --- | --- |
|  |  |

#### 步骤 5. 若 步骤 4 耗材未成功拉出，进行挤出机清理

挤出机内部可能存在堵塞，具体清理方法可参考 [P2S 挤出机堵塞清理指南](../../maintenance/extruder-cleaning-guide.md)。完成清理后，请尝试重新挤出。若依旧堵塞，进行 **步骤 6** 喷嘴堵塞排故。

#### 步骤 6. 若步骤5耗材成功拉出，说明挤出机段正常，进行喷嘴堵塞排故

喷嘴可能存在堵塞，请参考 [P2S 喷嘴堵塞清理指南](../../maintenance/cold-pull-maintenance-hotend.md) 清理喷嘴。完成清理后，尝试重新挤出。若恢复正常成功挤出，则问题已解决；若仍然无法挤出，可能喷嘴已经磨损或损坏，需要更换一个新的喷嘴。
