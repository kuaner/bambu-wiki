## 故障描述

在低温料打印时，当打印机腔体内温度高于一定温度时，工具头热端有堵头风险，同时过高的腔温会影响打印质量，需及时为腔体降温。

## 故障排除

### 工具、设备及材料

- H2.0 内六角扳手

### 排故措施

- 打开上盖玻璃和前门玻璃；

|  |  |
| --- | --- |
|  |  |

- 检查腔温传感器是否损坏  
  P2S 请参考：[更换 P2S 腔温检测传感器](../../maintenance/replace-chamber-temperature-sensor.md)  
  X2D 请参考：[更换 X2D 腔温检测传感器](../../../x2d/maintenance/replace-chamber-temperature-sensor.md)
