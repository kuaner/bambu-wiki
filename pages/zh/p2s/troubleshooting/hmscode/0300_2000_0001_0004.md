## 故障描述

当打印机出现 Y 轴异常 时，可能会导致打印头运动不畅、打印失败或报错。常见原因是皮带松弛。

## 故障排查指南

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。  
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

### 步骤一：张紧皮带

如果同步带松弛，可能会导致定位不准或运动异常。请参考下述步骤重新张紧皮带：

1. 在进行皮带张紧之前请关闭打印机，以防电机锁住无法移动工具头。
2. 使用 H2.0 内六角扳手拧松（**拧松 1-2 圈即可，请勿卸下螺丝**）四颗张紧螺丝，放松 XY 皮带。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/belt-tension/image.png)

3. 手动拖动工具头前后移动3-5次。

|  |  |
| --- | --- |
|  |  |

4. 再次拧紧打印机背后 4 颗螺丝；

> 注意：安装张紧器螺丝时请勿将螺丝拧太紧，避免滑丝。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/belt-tension/image-3.png)

5. 执行打印机校准。在屏幕上点击“校准-打印校准”，只需单独勾选“振动补偿”并完成该校准项即可。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/belt-tension/image-4.png)

### 步骤二：对 Y 轴润滑保养

1. 使用淋喷酒精的无纺布对 Y 轴光轴进行全面擦拭。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/lubricate-x-y-z-axis/011.webp)

2. 将 Y 轴移动至打印机前端，清洁被遮挡的光轴部分，确保无清洁死角。

|  |  |
| --- | --- |
|  |  |

3. 完成清洁后，为光轴均匀滴加润滑油（用量参照 X 轴：**每 5 cm 滴加 1–2 滴**）。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/lubricate-x-y-z-axis/020.png)

4. 按照同样的方法清理左侧光轴表面

|  |  |
| --- | --- |
|  |  |

5. 清洁完成后，为光轴均匀涂抹润滑油。

|  |  |
| --- | --- |
|  |  |

6. 手动推动工具头沿 Y 轴前后往复运动 3–5 次，使润滑油充分渗透至轴承内部并在光轴表面形成均匀油膜。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/lubricate-x-y-z-axis/002.webp)

7. 如果油脂光轴过多请用无尘布擦拭光轴表面多余油脂。
