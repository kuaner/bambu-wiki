## 故障描述

使用 AMS 时，缓冲器（或 AMS 集线器）连接在 AMS 和打印机之间。

它有一个滑块、一个弹簧和一个霍尔传感器。当 AMS 将耗材推入工具头挤出机时，由于耗材的压力，滑块将向前移动。然后，入口处第一个霍尔传感器检测耗材是否进入缓冲器，第二个滑块上方的霍尔传感器可以检测载滑块的位移和位置，并将该信号反馈回 AMS 和打印机。如果缓冲信号丢失，AMS 将无法顺利送入耗材。

![filament_buffer.jpg](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0700_4000_0002_0001/filament_buffer.jpg)

## 故障排除

### 步骤 1：重新插拔打印机背后缓冲器接线

![image-70.png](https://public-cdn.bblmw.com/wiki/new/p2s/hms/image-70.png)

### 步骤 2：检查 6-pin 线缆

检查线缆是否和 AMS 尾部接触良好，用手是否很容易就拔出来，建议使用二代 AMS 配套线缆，线缆区别如下:

![](https://wiki.bambulab.com//h2/troubleshooting/hmscode/0700_4000_0002_0001/image-8.png)

### 步骤 3：检查并重新连接 6-pin 线缆

请检查 6-pin 线缆的引脚是否打开（如下图 4-pin 所示）：

![](https://wiki.bambulab.com//h2/troubleshooting/hmscode/0700_4000_0002_0001/image.png)

并尝试重新连接 6-pin 线缆。

![screenshot-20250903-193140.png](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0700_4000_0002_0001/screenshot-20250903-193140.png)

### 步骤 4：检查 AMS 内部连接

如果问题仍然存在，请参考以下链接进行拆装，检查 AMS 内**电源线**和**信号线**是否脱落或损坏。

[更换 AMS 主板](../../../x1/maintenance/replace-ams-main-board.md)  
[更换 AMS 2 Pro 主板](../../../ams-2-pro/maintenance/replace-mainboard.md)  
[更换 AMS HT 主板](../../../ams-ht/maintenance/disassembly-and-assembly-of-the-motherboard.md)

### 步骤 5：测量电压和电阻

1. 如果您有万用表，请将耗材卸载回 AMS，并检查缓冲器的滑块是否位于中间，如下所示：

![filament_buffer.jpg](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0700_4000_0002_0001/filament_buffer.jpg)

然后测量 6 针电缆（从 AMS 上拔下）引脚之间的电压。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/004.png)

正常电压应如下。**确保缓冲滑块回到左侧，否则电压值会有所不同。**

|  |  |
| --- | --- |
| pin-pin | 电压 |
| GND-Buffe\_A | 0.5~1.0V |
| GND-Buffe\_B | 2.8~2.3V |

**两个电压之和为3.0~3.3V（可以滑动滑块，测量不同位置电压，相加在这个范围内）。**

2. 如果测量的电压在正常范围内，则问题可能出在 AMS，请根据机型选择测量方法。

- AMS
- AMS 2 Pro
- AMS HT
