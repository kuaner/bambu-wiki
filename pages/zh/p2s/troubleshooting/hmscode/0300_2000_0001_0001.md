## 故障描述

当打印机出现 X 轴异常时，可能会导致打印头运动不畅、打印失败或报错。常见原因为皮带松弛或者导轨上存在异物。

## 故障排查指南

### 步骤 1.检查工具头是否被卡住

观察工具头在X轴方向上是否能够顺畅移动，确认没有异物或阻碍物卡住工具头。若存在异物或阻碍物，请清理X轴导轨上的异物，确保导轨干净无阻碍。

### 步骤 2. 调整皮带张紧力

1. 在进行皮带张紧前，请先关闭打印机电源，以防电机锁定导致工具头无法移动。
2. 使用 **H2.0 内六角扳手**，拧松背部的 4 颗张紧螺丝（**拧松 1–2 圈即可，请勿完全卸下螺丝**），使 XY 皮带处于放松状态。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/belt-tension/image.png)

3. 用手轻轻推动工具头前后移动 3–5 次，使皮带在导轨上重新分布并均匀受力。

|  |  |
| --- | --- |
|  |  |

4. 将打印机背部的 4 颗张紧螺丝重新拧紧，固定张紧轮位置。

> ⚠️ **注意：** 请勿过度拧紧螺丝，以免导致滑丝或损坏螺纹。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/belt-tension/image-3.png)

5. 执行打印机校准。在屏幕上点击“校准-打印校准”，只需单独勾选“振动补偿”并完成该校准项即可。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/belt-tension/image-4.png)

### 步骤 3. 建议清洁 X 轴光轴

1. 切断电源，将工具头移动至**最左侧极限位置**。
2. 用准备好的无纺布蘸取适量酒精，沿 X 轴光轴进行往复擦拭，直至表面无可见油污及耗材碎屑。

> 建议同时检查皮带表面，若发现污渍，可使用无纺布清洁。

|  |  |
| --- | --- |
|  |  |

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/lubricate-x-y-z-axis/015.webp)

3. 将工具头移动至 最右侧极限位置，补充清洁左端原本被遮挡的光轴区域。

|  |  |
| --- | --- |
|  |  |

4. 使用点滴方式沿光轴轴向均匀涂抹润滑油（推荐 每 5 cm 滴加 1–2 滴）。

> **注意：** X 轴的上下两根光轴均需处理。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/lubricate-x-y-z-axis/009.webp)

5. 将工具头移动回左侧，为右端光轴涂抹润滑油。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/lubricate-x-y-z-axis/018.png)

6. 手动推动工具头沿 X 轴全程往复运动 3–5 次，使润滑油在光轴表面形成均匀油膜。

![](https://public-cdn.bblmw.com/wiki/new/p2s/maintenance/lubricate-x-y-z-axis/010.webp)

7. 使用无尘布轻轻擦拭光轴两端，去除多余油脂，避免灰尘吸附。
