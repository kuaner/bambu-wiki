## 故障描述

在使用 AMS 时，缓冲器（或 AMS 集线器）安装于 AMS 与打印机之间。

缓冲器由**滑块、弹簧和两个霍尔传感器**组成：

- 当 AMS 将耗材推入挤出机时，耗材的压力会推动滑块前移；
- 入口处的第一个霍尔传感器用于检测耗材是否进入缓冲器；
- 第二个霍尔传感器位于滑块上方，用于检测滑块位置并将信号反馈给 AMS 与打印机；
- 一旦缓冲信号丢失，AMS 将无法顺利送丝。

![](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0700_4000_0002_0001/filament_buffer.jpg)

## 故障排除

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 步骤 1. 重新插拔打印机背后缓冲器接线

请检查打印机背后的缓冲器连接线，拔下并重新插紧后再次上电，确认问题是否解决。

![](https://public-cdn.bblmw.com/wiki/new/p2s/hms/image-70.png)

### 步骤 2.检查缓冲器弹簧是否出现扭曲

![](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/image-69.png)

### 步骤 3. 检查 6-Pin 线缆

确认 6-Pin 线缆与 AMS 尾部接口连接牢固：

- 如果用手轻轻一拔即可松脱，说明连接不牢固；
- 建议使用**第二代 AMS 配套线缆**，二者线缆区别如下:

![](https://wiki.bambulab.com//h2/troubleshooting/hmscode/0700_4000_0002_0001/image-8.png)

### 步骤 4.检查并重新插紧 6-Pin 线缆

6-Pin 线缆常见问题包括 引脚松动或张开（下图以 4-Pin 线缆为例）。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700_4000_0002_0001/image.png)

请先检查外观，然后重新插拔并插紧：

![](https://public-cdn.bblmw.com/wiki/new/p2s/troubleshooting/hms/0700_4000_0002_0001/screenshot-20250903-193140.png)

### 步骤 5. 检查 AMS 内部信号线

若问题仍未解决，请检查 AMS 内部信号线是否松动。

1. 从 AMS 背面按下 PTFE 料管释放按钮，拉出料管；

![](https://wiki.bambulab.com/ams-2-pro/maintenance/disassembly-and-assembly/image-13.png)

2. 从下盖内侧捏住卡扣，同时从背面扶住释放按钮，避免弹簧弹出丢失；

|  |  |
| --- | --- |
|  |  |

3. 拆下中间 2 个料槽的从动支撑套筒组件;

![](https://wiki.bambulab.com/ams-2-pro/maintenance/disassembly-and-assembly/image-3.png)

4. 拆下 2 颗螺丝 A (BT3x8)；

![](https://wiki.bambulab.com/ams-2-pro/maintenance/disassembly-and-assembly/image-5.png)

5. 将主框架后部完全提起来，竖立放置在 AMS 下盖上。抬起时，建议先抬主框架前部分，再往前推，为框架后部分腾出空间。竖放AMS主框架时需避开风门的电子部件，以防压坏。

|  |  |
| --- | --- |
|  |  |

6. 检查信号线是否牢固插入。如未插紧，请重新插好；然后断开信号线和电源线，抬出中框；

|  |  |
| --- | --- |
|  |  |

7. 再次确认信号连接线是否插紧。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700_4000_0002_0001/20250610-142709.jpg)

### 步骤 6. 测量电压和电阻

若您有万用表，可进一步检查信号线状态：

1. 将耗材卸载回 AMS，缓冲器滑块应处于左侧；
2. 测量 6-Pin 电缆（从 AMS 拔下）的电压：

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700_4000_0002_0001/image-2.png)

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700_4000_0002_0001/image-3.png)

**正常电压范围如下（两者相加应为 3.0~3.3V）：**

| pin-pin | 电压 |
| --- | --- |
| GND - Buffer\_A | 0.5 ~ 1.0 V |
| GND - Buffer\_B | 2.3 ~ 2.8 V |

*提示：可以滑动缓冲滑块，在不同位置测量电压，其和应始终在 3.0~3.3 V 范围内。*

3. 如果电阻异常，请拆卸 AMS 并在主板上直接测量。正常范围为 4~6 kΩ，否则 AMS 主板可能损坏。

**正常电阻范围如下**

| pin-pin | 电阻 |
| --- | --- |
| GND - Buffer\_A | 4 ~ 6 kΩ |
| GND - Buffer\_B | 4 ~ 6 kΩ |
