## AMS 3P

简述：AMS 3P 位于 P3C 正上方，是其配套的核心供料管理装置。

![ams_3p_____________-ams_3p_replacement_guide-image-13.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-ams3/zh/ams_3p_____________-ams_3p_replacement_guide-image-13.png)

## 何时更换

需要换机 AMS 3P

## 所需工具和材料

- H1.5 内六角扳手
- AMS 3P

## 安全提示

> - 在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> ![ams_3p_____________-ams_3p_replacement_guide-image-11.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-ams3/zh/ams_3p_____________-ams_3p_replacement_guide-image-11.png)

> - 拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次损伤。
> - 拆除部件前，请妥善保管拆除的固定螺丝，以免丢失。
> - 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除 AMS 3P

> 注意：在移除或安装 AMS 舱体前，请先执行退料操作，并取出舱内的所有料盘。若未退料，残留的耗材可能在
>
> 安装时被夹断或卡住，导致后续进退料困难；同时，料盘的自重也会增加操作难度。
>
> |  |  |
> | --- | --- |
> | ams_3p_____________-ams_3p_replacement_guide-image-10.png | ams_3p_____________-ams_3p_replacement_guide-screenshot_20260918_172241.png |

### 步骤 1. 移除 AMS 左/右侧板

用手抓住左/右侧板扣手位，向外侧用力使其与 AMS 分离，取下左/右侧板。

|  |  |
| --- | --- |
| ams_3p_____________-ams_3p_replacement_guide-image-8.png | ams_3p_____________-ams_3p_replacement_guide-image-5.png |

### 步骤 2. 移除 AMS 3P 固定螺丝

使用 H1.5 内六角扳手移除 AMS 支架 4 颗固定螺丝。

|  |  |
| --- | --- |
| ams_3p_____________-ams_3p_replacement_guide-image-9.png | ams_3p_____________-ams_3p_replacement_guide-image-7.png |

### 步骤 3. 移除打印头组件

手持打印头组件并轻轻向上提，使其脱离磁性吸附及橙色挂钩的位置，依次将闪切挂架泊位组件上的5个打印头组

件卸下。

![ams_3p_____________-ams_3p_replacement_guide-image-3.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-ams3/zh/ams_3p_____________-ams_3p_replacement_guide-image-3.png)

### 步骤 4. 断开线缆

将 AMS 整体微幅抬起，并向后平移约20mm，使其脱离定位孔对接状态。

![ams_3p_____________-ams_3p_replacement_guide-image-4.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-ams3/zh/ams_3p_____________-ams_3p_replacement_guide-image-4.png)

将手伸入 AMS 右侧框架内，小心拔除连接在打印机顶部接口上的打印头控制板线缆。

**(注意按住卡扣平稳拔出，切勿强行拉拽线束)。**

![ams_3p_____________-ams_3p_replacement_guide-image-12.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-ams3/zh/ams_3p_____________-ams_3p_replacement_guide-image-12.png)

### 步骤 5. 放置 AMS

将 AMS 向上抬起，完全搬离打印机顶部，并平稳将其轻放至安全的平台上，注意保护好打印头组件，避免踩到。

![ams_3p_____________-ams_3p_replacement_guide-image-6.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-ams3/zh/ams_3p_____________-ams_3p_replacement_guide-image-6.png)

## 安装 AMS 3P

### 步骤 1. 将 AMS 3P 放置到打印机顶部

将AMS 3P（免装磁吸侧板）轻放于打印机顶部，AMS 背板略微超出打印机背板 20 mm，便于连接线缆。

![ams_3p_____________-ams_3p_replacement_guide-image-2.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-ams3/zh/ams_3p_____________-ams_3p_replacement_guide-image-2.png)

### 步骤 2. 连接线缆

将手伸入 AMS 右侧框架内，将打印头控制板线缆插入打印机顶部的连接器座。

![ams_3p_____________-ams_3p_replacement_guide-image.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-ams3/zh/ams_3p_____________-ams_3p_replacement_guide-image.png)

将 AMS 3P 整体微幅抬起并向前平移，确保底部安装孔位对齐，将 AMS 3P 支架的 4 处定位销嵌入到位。

![ams_3p_____________-ams_3p_replacement_guide-image-1.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-ams3/zh/ams_3p_____________-ams_3p_replacement_guide-image-1.png)

### 步骤 3. 安装 AMS 3P 固定螺丝

使用 H1.5 内六角扳手装回 AMS 支架 4 颗固定螺丝。

|  |  |
| --- | --- |
| ams_3p_____________-ams_3p_replacement_guide-image-18.png | ams_3p_____________-ams_3p_replacement_guide-image-17.png |

### 步骤 4. 安装打印头

依序将 5 个打印头安装至闪切挂架对应的泊位组件上。将打印头上的橙色定位框对齐泊位组件上的橙色挂钩，借助

磁性吸力使打印头与泊位组件自动贴合吸附。

|  |  |
| --- | --- |
| ams_3p_____________-ams_3p_replacement_guide-image-14.png | ams_3p_____________-ams_3p_replacement_guide-image-16.png |

### 步骤 5. 安装 AMS 左、右侧板

对准左/右侧板下方的卡扣与插入槽，将其插入后推回侧板，直至磁吸完全贴合。

![ams_3p_____________-ams_3p_replacement_guide-image-15.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-ams3/zh/ams_3p_____________-ams_3p_replacement_guide-image-15.png)

## 功能验证

- AMS 3P 安装平整，螺丝固定到位。
- 打开打印机，AMS 3P 运行正常。
