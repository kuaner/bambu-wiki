## AMS 上盖

简述：AMS 3P 舱体的塑料上盖。

![001.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-top-lid/zh/001.png)

## 何时更换

- 外观破损
- 上盖转轴损坏或转动不畅
- 上盖提手损坏

## 所需工具和材料

- H2.0 内六角扳手
- AMS 上盖组件

## 安全提示

> 重要提醒 ！
>
> 在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次损伤。
>
> 断开插头前，建议拍照记录各插头的连接位置，便于后续按正确顺序恢复连接。

## 移除 AMS 上盖

### 步骤 1. 移除 AMS 上盖螺丝

使用 H2.0 内六角扳手移除 AMS 上盖与左、右撑杆组件连接的 4 颗螺丝，左右各 2 颗。

|  |  |
| --- | --- |
| 002.png | 003.png |

使用 H2.0 内六角扳手移除左、右转轴装饰盖 4 颗螺丝，左右各 2 颗。

|  |  |
| --- | --- |
| 004.png | 005.png |

### 步骤 2. 移除转轴装饰盖

用手沿图示位置缝隙揭起装饰盖，移除左、右转轴装饰盖。左、右转轴装饰盖拆装方法相同。

![006.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-top-lid/zh/006.png)

### 步骤 3. 移除 AMS 上盖

用手抓住 AMS 上盖提手提起 AMS 上盖，随后移除 AMS 上盖。

|  |  |
| --- | --- |
| 007.png | 008.png |

## 安装 AMS 上盖

### 步骤 1. 安装 AMS 上盖

用手将 AMS 上盖装回 AMS 舱体上。

![009.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-top-lid/zh/009.png)

### 步骤 2. 安装转轴装饰盖

用手将左右 2 块转轴装饰盖装回。

![010.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-top-lid/zh/010.png)

### 步骤 3. 安装 AMS 上盖螺丝

用 H2.0 内六角扳手锁紧 AMS 转轴装饰盖 4 颗螺丝，左右各 2 颗。

|  |  |
| --- | --- |
| 011.png | 012.png |

用一只手抬起 AMS 上盖，另一只手将左撑杆嵌入撑杆定位槽，随后锁紧左撑杆组件与 AMS 上盖的 2 颗连接螺丝。

|  |  |
| --- | --- |
| 013.png | 014.png |

用同样的操作，嵌入右撑杆，并锁紧右撑杆组件与 AMS 上盖的 2 颗连接螺丝。

![015.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-top-lid/zh/015.png)

## 功能验证

AMS 上盖开合顺畅，关闭严密、贴合无缝隙。
