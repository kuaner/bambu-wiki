## AMS 前横梁（图标1）/ AMS 左框架（图标2）/ AMS 右框架（图标3）

简述：用于支撑并固定 AMS 3P 的塑料框架结构，左右框架通过前横梁连接成整体。

![001.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/001.png)

## 何时更换

AMS 前横梁及左/右框架外观或结构受损。

## 所需工具和材料

- H2.0 内六角扳手
- H1.5 内六角扳手
- AMS 前横梁/ AMS 左框架/ AMS 右框架

## 安全提示

> 在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> ![002.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/002.png)

> 拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次次损伤。
>
> 拆除部件前，请妥善保管拆除的固定螺丝，以免丢失。

## 移除 AMS 舱体

> 注意：在移除或安装 AMS 舱体前，请先执行退料操作，并取出舱内的所有料盘。若未退料，残留的耗材可能在
>
> 安装时被夹断或卡住，导致后续进退料困难；同时，料盘的自重也会增加操作难度。
>

## 移除 AMS 前横梁及左/右框架

### 步骤 1. 移除 AMS 3P 支架外壳

左/右侧板拆装方法相同，用手抓住左/右侧板扣手位，向外侧用力使其与 AMS 分离，取下左/右侧板。

|  |  |
| --- | --- |
| 005.png | 006.png |

抬起 AMS 上盖，用一只手扶住前面板，另一只手从舱内往外推，移除前面板。

|  |  |
| --- | --- |
| 007.png | 008.png |

### 步骤 2. 移除 AMS 舱体

您可以参考WIKI：[AMS 3P 舱体拆装指南](../../p3c/maintenance/replace-chamber.md)，移除 AMS 舱体。

### 步骤 3. 移除 AMS 前横梁

请注意前横梁移除方向，请勿用下图拆卸方式，避免因力度失控导致手部划伤。

![009.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/009.png)

前横梁通过卡扣固定，卡扣位置如图所示，请使用H1.5 内六角扳手顶起并解锁下方卡扣：

|  |  |
| --- | --- |
| 010.png | 011.jpg |

解锁的同时按图示方向使用大拇指将前横梁一侧向上顶起，同样的操作再移除另一侧。

|  |  |
| --- | --- |
| 012.jpg | 013.png |

### 步骤 4. 移除 AMS 左/右框架

**左框架：**

使用 H2.0 内六角扳手移除主料管支架左侧的 2 颗固定螺丝；

![014.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/014.png)

松出主料管支架左侧以及左料管支架的卡扣，使其与左框架完全分离；

![015.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/015.png)

使用 H1.5 内六角扳手移除左框架与打印机的 2 颗连接螺丝，随后向上提起并取下左框架。

![016.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/016.png)

**右框架：**

使用 H2.0 内六角扳手移除主料管支架右侧的 2 颗固定螺丝；

![017.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/017.png)

松出主料管支架右侧以及右料管支架卡扣，使其与左框架分离；

![018.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/018.png)

使用 H1.5 内六角扳手移除右框架与打印机的 2 颗连接螺丝，随后向上提起并取下右框架。

![019.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/019.png)

## 安装 AMS 前横梁及左/右框架

### 步骤 1. 安装 AMS 左/右框架

**左框架：**

将左框架定位销插入打印机顶部定位孔，并使用 H1.5 内六角扳手锁入 2 颗固定螺丝；

![020.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/020.png)

将主料管、左料管支架与左框架的连接卡扣安装到位；

![021.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/021.png)

使用 H2.0 内六角扳手锁入主料管支架左侧的 2 颗固定螺丝。

![022.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/022.png)

**右框架：**

将右框架定位销插入打印机顶部定位孔，并使用 H1.5 内六角扳手锁入 2 颗固定螺丝；

![023.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/023.png)

将主料管、右料管支架与右框架的连接卡扣安装到位；

![024.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/024.png)

使用 H2.0 内六角扳手锁入主料管支架右侧的 2 颗固定螺丝。

![025.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/025.png)

### 步骤 2. 安装 AMS 前横梁

将前横梁卡扣先卡入一端锁紧，同样的操作再卡入另一端。

![026.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/026.png)

### 步骤 3. 安装 AMS 舱体

您可以参考WIKI：[AMS 舱体拆装指南](../../p3c/maintenance/replace-chamber.md)，对 AMS 舱体进行安装。

### 步骤 4. 安装 AMS 3P 支架外壳

用一只手抬起 AMS 上盖，另一手将前面板卡扣对准框架上的插入槽装回，直到听见卡扣到位声。

![027.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/027.png)

对准左/右侧板下方的卡扣与插入槽，将其插入后推回侧板，直至磁吸完全贴合。

![028.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-front-beam/zh/028.png)

## 功能验证

卡扣、螺丝固定到位，AMS 能嵌合安装到位，无异常翘起。
