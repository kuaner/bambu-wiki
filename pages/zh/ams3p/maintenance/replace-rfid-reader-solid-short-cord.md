## AMS RFID 线圈-实心/AMS RFID 线圈-空心（短线）/AMS RFID 线圈-空心（长线）

简述：AMS 3P 共有 5 个 RFID 线圈，用于读取耗材信息，其中 R1 为 AMS RFID 线圈-空心（长款）；R2 为 AMS RFID 线圈-实心；R3、R4、R5 为 AMS RFID 线圈-空心（短款）。

![001.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-rfid-reader-solid-short-cord/zh/001.png)

## 何时更换

- RFID 线圈或连接线缆受损
- RFID 线圈无法读取耗材信息

## 所需工具和材料

- AMS RFID 线圈
- H2.0 内六角扳手
- H1.5 内六角扳手

## 安全提示

> 重要提醒 ！
>
> 在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次损伤。
>
> 断开插头前，建议拍照记录各插头的连接位置，便于后续按正确顺序恢复连接。

### 拆装提示

> RFID 线圈具有方向性，前后排安装方向相反，请务必注意区分！  
> **前排线圈：**顶部的螺丝帽朝向左侧**（如左图扳手指示位置）；**  
> \*\*后排线圈：\*\*顶部的螺丝帽朝向右侧（**如右图扳手指示位置**）。

## 移除AMS RFID线圈-实心

### 步骤 1. 移除 AMS 舱体

您可以参考WIKI [AMS 3P 舱体拆装指南](../../p3c/maintenance/replace-chamber.md)，对 AMS 舱体进行移除。

> 注意：在移除或安装 AMS 舱体前，请先执行退料操作，并取出舱内的所有料盘。若未退料，残留的耗材可能在
>
> 安装时被夹断或卡住，导致后续进退料困难；同时，料盘的自重也会增加操作难度。
>
> |  |  |
> | --- | --- |
> | 004.png | 005.png |

### 步骤 2. 移除 AMS 进料组件上盖

打开 AMS 上盖，使用 H2.0 内六角扳手移除 AMS 进料组件上盖图示位置的 4 颗螺丝，随即取下进料组件上盖。

|  |  |
| --- | --- |
| 006.png | 007.png |

### 步骤 3. 移除 AMS 主板装饰盖

使用 H1.5 内六角扳手，移除 AMS 主板装饰盖的 4 颗螺丝，随后取下装饰盖。

![008.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-rfid-reader-solid-short-cord/zh/008.png)

### 步骤 4. 移除 RFID 线圈-实心

断开图示位置的线缆连接器接口，并将线缆从理线扣中松出。

![009.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-rfid-reader-solid-short-cord/zh/009.png)

将AMS 舱体翻过来，使用 H1.5 内六角扳手移除 RFID 线圈的 2 颗固定螺丝后，取出RFID线圈-实心。

|  |  |
| --- | --- |
| 010.png | 011.png |

## 安装 AMS RFID线圈-实心

### 步骤 1. 安装 RFID 线圈

将线圈线缆穿过线孔，并将 RFID 线圈对齐安装导向块进行安装，确认线圈嵌入到底。

![012.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-rfid-reader-solid-short-cord/zh/012.png)

将 RFID 线圈连接器插入 AMS 主板连接器座，并将线缆埋入理线扣中。

![013.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-rfid-reader-solid-short-cord/zh/013.png)

### 步骤 2. 安装 AMS 主板装饰盖

将 AMS 主板装饰盖对齐图示的耗材直通口装入，并使用 H1.5 内六角扳手锁紧装饰盖 4 颗螺丝。

|  |  |
| --- | --- |
| 014.png | 015.png |

### 步骤 3. 安装 AMS 进料组件上盖

如图所示，用手将进料组件上盖的定位凸起对准 RFID 线圈结构空隙，平稳向下嵌入到位。并使用 H2.0 内六角扳手锁紧 AMS 进料组件上盖的 4 颗螺丝。

|  |  |
| --- | --- |
| 016.png | 017.png |

### 步骤 4. 安装 AMS 舱体

您可以参考WIKI：[AMS 3P 舱体拆装指南](../../p3c/maintenance/replace-chamber.md)，安装 AMS 舱体。

## 移除AMS RFID线圈-空心（短线）

### 步骤 1. 移除AMS舱体；

您可以参考WIKI：[AMS 3P 舱体拆装指南](../../p3c/maintenance/replace-chamber.md)，移除 AMS 舱体。

### 步骤 2. 移除 AMS 主板装饰盖

使用 H1.5 内六角扳手，移除 AMS 主板装饰盖的 4 颗螺丝，随后取下装饰盖。

![018.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-rfid-reader-solid-short-cord/zh/018.png)

### 步骤 3. 移除 RFID 线圈-空心（短线）

断开要更换的 RFID 线圈线缆连接器接口（图示标注的是所有短线款空心线圈的连接器接口，仅需移除要更换的线圈所对应的连接器接口即可）。

![019.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-rfid-reader-solid-short-cord/zh/019.png)

并使用 H1.5 内六角扳手移除 RFID 线圈的 2 颗固定螺丝，取出 RFID 线圈-空心（短线）。

![020.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-rfid-reader-solid-short-cord/zh/020.png)

## 安装AMS RFID线圈-空心（短线）

### 步骤 1. 安装 RFID 线圈

将线圈线缆穿过线孔，并将 RFID 线圈对齐安装导向块进行安装，确认线圈嵌入到底。

![021.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-rfid-reader-solid-short-cord/zh/021.png)

随后将线圈连接器插入 AMS 主板连接器座。

![022.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-rfid-reader-solid-short-cord/zh/022.png)

### 步骤 2. 安装 AMS 主板装饰盖

将 AMS 主板装饰盖对齐图示的耗材直通口装入，并使用 H1.5 内六角扳手锁紧装饰盖 4 颗螺丝。

|  |  |
| --- | --- |
| 023.png | 024.png |

### 步骤 3. 安装 AMS 舱体

您可以参考WIKI：[AMS 3P 舱体拆装指南](../../p3c/maintenance/replace-chamber.md)，安装 AMS 舱体。

## 功能验证

- RFID 线圈螺丝紧固到位，线圈无异常翘起
- 打开打印机，RFID 线圈可正常识别耗材信息
