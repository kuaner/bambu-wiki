## AMS 右侧板

简述：AMS 外壳包含 AMS 右侧板、AMS 左侧板、AMS 前面板和 AMS 背板，它们共同构成 AMS 3P 支架的外部封闭结构。其中，左右侧板采用磁吸方式固定；前面板通过卡扣结构与前横梁和框架连接；背板通过 4 颗螺丝进行固定。

## 何时更换

- 侧板、前面板或背板出现裂纹、断裂或明显变形
- 侧板磁吸附力减弱，无法正常贴合固定
- 前面板卡扣结构损坏，扣合失效
- 表面严重磨损或划伤，影响 AMS 密封性或外观

## 所需工具和材料

- H2.0 内六角扳手
- H1.5 内六角扳手

## 安全提示

> 重要提醒 ！
>
> 在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次损伤。
>
> 断开插头前，建议拍照记录各插头的连接位置，便于后续按正确顺序恢复连接。

## 移除AMS 左/右侧板

### 步骤 1. 移除 AMS 左/右侧板

左/右侧板拆装方法相同，用手抓住左/右侧板扣手位，向外侧用力使其与 AMS 分离，取下左/右侧板。

| 001.png | 002.png |

## 安装AMS 左/右侧板

### 步骤 1. 安装 AMS 左/右侧板

对准左/右侧板下方的卡扣与插入槽，将其插入后推回侧板，直至磁吸完全贴合。

![003.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-right-panel/zh/003.png)

---

## 移除AMS前面板

### 步骤 1. 移除 AMS 左/右侧板

左/右侧板拆装方法相同，用手抓住左/右侧板扣手位，向外侧用力使其与 AMS 分离，取下左/右侧板。

|  |  |
| --- | --- |
| 004.png | 005.png |

### 步骤 2. 移除 AMS 前面板

抬起 AMS 上盖，用一只手扶住前面板，另一只手从舱内往外推，移除前面板。

|  |  |
| --- | --- |
| 006.png | 007.png |

## 安装 AMS 前面板

### 步骤 1. 装回 AMS 前面板

用一只手抬起 AMS 上盖，另一手将前面板卡扣对准框架上的插入槽装回，直到听见卡扣到位声。

![008.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-right-panel/zh/008.png)

### 步骤 2. 安装 AMS 左/右侧板

对准左/右侧板下方的卡扣与插入槽，将其插入后推回侧板，直至磁吸完全贴合。

![009.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-right-panel/zh/009.png)

---

## 移除 AMS 背板

### 步骤 1. 移除 AMS 舱体螺丝

使用 H2.0 内六角扳手移除 AMS 舱体左右两侧的 4 颗螺丝。

![010.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-right-panel/zh/010.png)

### 步骤 2. 移除 AMS 背板

使用 H2.0 内六角扳手移除 AMS 背板 4 颗螺丝。

![011.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-right-panel/zh/011.png)

用手轻轻抬起 AMS 舱体使其与背板分离，同时向后拉动背板，即可将其顺利卸下。

|  |  |
| --- | --- |
| 012.png | 013.png |

## 安装 AMS 背板

### 步骤 1. 安装 AMS 背板

将 AMS 背板安装到位，并使用 H2.0 内六角扳手锁紧 AMS 背板 4 颗螺丝。

|  |  |
| --- | --- |
| 014.png | 015.png |

### 步骤 2. 锁紧 AMS 舱体螺丝

使用 H2.0 内六角扳手锁紧 AMS 舱体左右两侧的 4 颗螺丝。

![016.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-right-panel/zh/016.png)

## 功能验证

AMS 支架外壳安装平整，无翘起、松脱的现象。
