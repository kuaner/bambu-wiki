## AMS 电路板装饰盖

简述：AMS 电路板装饰盖为塑料材质，分别为 AMS 主板装饰盖与 AMS 6-pin 接口板装饰盖。

|  |  |
| --- | --- |
| 001.png | 002.png |

## 何时更换

电路板装饰盖破损

## 所需工具和材料

- H2.0 内六角扳手（AMS 6-pin 接口板装饰盖）
- H1.5 内六角扳手（AMS 主板装饰盖）
- AMS 电路板装饰盖

## 安全提示

> 重要提醒 ！
>
> 在对 AMS 及其内部电子设备进行任何维护工作之前，请关闭 AMS 及打印机电源，并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 拆装过程中请避免暴力操作，防止造成零部件或连接结构的二次损伤。
>
> 断开插头前，建议拍照记录各插头的连接位置，便于后续按正确顺序恢复连接。

## 移除 AMS 主板装饰盖

### 步骤 1. 移除 AMS 舱体

您可以参考WIKI：[AMS 3P 舱体拆装指南](../../p3c/maintenance/replace-chamber.md)，对 AMS 舱体进行移除。

> 注意：在移除或安装 AMS 舱体前，请先执行退料操作，并取出舱内的所有料盘。若未退料，残留的耗材可能在
>
> 安装时被夹断或卡住，导致后续进退料困难；同时，料盘的自重也会增加操作难度。
>
> |  |  |
> | --- | --- |
> | 003.png | 004.png |

### 步骤 2. 移除 AMS 主板装饰盖

使用 H1.5 内六角扳手，移除 AMS 主板装饰盖的 4 颗螺丝，随后取下装饰盖。

![005.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-circuit-board-trim/zh/005.png)

## 安装 AMS 主板装饰盖

### 步骤 1. 安装 AMS 主板装饰盖

将 AMS 主板装饰盖对齐图示的耗材直通口装入，并使用 H1.5 内六角扳手锁紧装饰盖 4 颗螺丝。

|  |  |
| --- | --- |
| 006.png | 007.png |

### 步骤 2. 安装 AMS 舱体

您可以参考WIKI：[AMS 3P 舱体拆装指南](../../p3c/maintenance/replace-chamber.md) ，安装 AMS 舱体。

---

## 移除 AMS 6-pin 接口板装饰盖

### 步骤 1. 移除 AMS 舱体

您可以参考WIKI：[AMS 3P 舱体拆装指南](../../p3c/maintenance/replace-chamber.md) ，移除AMS舱体。

### 步骤 2. 移除 AMS 6-pin 接口板装饰盖

使用 H2.0 内六角扳手，移除 AMS 接口板装饰盖 4 颗固定螺丝，底部 2 颗，装饰盖左右内侧各 1 颗。随后取下AMS 接口板装饰盖。

|  |  |
| --- | --- |
| 008.png | 009.png |

## 安装 AMS 6-pin 接口板装饰盖

### 步骤 1. 安装 AMS 6-pin 接口板装饰盖

将 AMS 接口板装饰盖左右内侧卡扣对准AMS舱体卡槽装入到位，随后使用 H2.0 内六角扳手锁紧装饰盖左右内侧共 2 颗螺丝。

![010.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-circuit-board-trim/zh/010.png)

使用 H2.0 内六角扳手锁紧装饰盖底部 2 颗固定螺丝。

![011.png](https://public-cdn.bblmw.com/wiki/new/ams3p/maintenance/replace-circuit-board-trim/zh/011.png)

### 步骤 2. 安装 AMS 舱体

您可以参考WIKI：[AMS 3P 舱体拆装指南](../../p3c/maintenance/replace-chamber.md) ，安装 AMS 舱体。

## 功能验证

装饰盖安装平整，所有螺丝紧固到位。
