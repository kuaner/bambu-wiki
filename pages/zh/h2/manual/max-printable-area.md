## H2D

### 3D 打印

- 整机：水平方向最大可打印面积 X350\*Y320mm，Z 方向最大高度325mm；最大可打印体积 X350\*Y320\*Z320mm。
- 左喷嘴：水平方向最大可打印面积 X325\*Y320mm，Z 方向最大高度320mm；最大可打印体积 X325\*Y320\*Z320mm。
- 右喷嘴：水平方向最大可打印面积 X325\*Y320mm，Z 方向最大高度325mm；最大可打印体积 X325\*Y320\*Z325mm。
- 左右喷嘴公共打印区域面积：X300\*Y320mm，Z 方向最大高度320mm；最大可打印体积 X300\*Y320\*Z320mm。

|  |  |
| --- | --- |
| 整机完整打印区域 | 左喷嘴可打印区域 |
| 右喷嘴可打印区域 | 左右喷嘴公共打印区域 |

### 激光模块

- 挂载 10W 激光模组：最大加工面积 X310\*Y270mm，最大加工高度 Z280mm；最大可加工体积 X310\*Y270\*Z280mm。
- 挂载 40W 激光模组：最大加工面积 X310\*Y250mm，最大加工高度 Z265mm；最大可加工体积 X310\*Y250\*Z265mm。

|  |  |
| --- | --- |
| 10W 激光模组可加工范围 | 40W 激光模组可加工范围 |

### 刀切/画笔模块

- 挂载刀切模块：最大加工面积 X300\*Y285mm。
- 挂载画笔模块：最大加工面积 X300\*Y255mm。

|  |  |
| --- | --- |
| 刀切模块可加工范围 | 画笔模块可加工范围 |

## H2S

### 3D 打印

水平方向最大可打印面积 X340\*Y320mm，Z 方向最大高度 340mm；最大可打印体积 X340\*Y320\*Z340mm。

![image_-_2025-12-15t175005.654.png](https://wiki.bambulab.com/h2/manual/max-printable-area/h2s-cn.jpg)

### 激光模组

> 注意：**H2S 仅支持 10W 激光模组**。由于 40W 激光模组安装在 H2S 工具头上时，会与风道和拖链发生干涉，且 40w 激光模组比 H2S 工具头宽，XY 回零的时候会撞到激光模组，因此 H2S 无法安装 40W 激光模组。

挂载 10W 激光模组：最大加工面积 X310\*Y260mm。

![image_-_2025-12-15t175009.419.png](https://wiki.bambulab.com/h2/manual/max-printable-area/image_-_2025-12-15t175009.419.png)

### 刀切/画笔模组

- 挂载刀切模组：最大加工面积 X297.5\*Y300mm；

> 为了避让切刀触发杆，H2S 在 X 方向上的刀切加工范围略有缩减。

- 挂载画笔模组: 最大加工面积 X300\*Y255mm。

|  |  |
| --- | --- |
| 刀切模组 | 画笔模组 |

## H2C

### 3D 打印

对于 H2C 打印机，水平方向上完整的打印面积是 330\*320mm，左喷嘴可打印区域为 325\*320mm，右喷嘴可打印区域为 305\*320mm。

- 整机：水平方向最大可打印面积 X330\*Y320mm，Z 方向最大高度 320mm。
- 左喷嘴：水平方向最大可打印面积 X325\*Y320mm，Z 方向最大高度 320 mm。
- 右喷嘴：水平方向最大可打印面积 X305\*Y320mm，Z 方向最大高度 325 mm。
- 左右喷嘴公共打印区域面积：X300\*Y320mm，Z 方向最大高度 320 mm。

> 注意：在 Bambu Studio 的打印板预览图上，左右两侧各有一块浅灰色区域，其中，**左侧标注 “仅左喷嘴可打印区域”，右侧的“仅右喷嘴可打印区域”因范围较小未进行文字标注**，这两个区域的含义是：若模型摆放在此区域内，仅可使用对应侧的左喷嘴或右喷嘴进行打印；而中间区域为左右喷嘴的公共打印区域，具体如示例图所示。

|  |  |
| --- | --- |
| 整机完整打印区域 | 左喷嘴可打印区域 |
| 右喷嘴可打印区域 | 左右喷嘴公共打印区域 |

### 激光模块

- 挂载 10W 激光模组：最大加工面积 X310\*Y270mm，最大加工高度 Z280mm；最大可加工体积 X310\*Y270\*Z280mm。
- 挂载 40W 激光模组：最大加工面积 X310\*Y250mm，最大加工高度 Z265mm；最大可加工体积 X310\*Y250\*Z265mm。

|  |  |
| --- | --- |
| 10W 激光模组可加工范围 | 40W 激光模组可加工范围 |

### 刀切/画笔模组

- 挂载刀切模块：最大加工面积 X300\*Y285mm。
- 挂载画笔模块：最大加工面积 X300\*Y255mm。

|  |  |
| --- | --- |
| 刀切模块可加工范围 | 画笔模块可加工范围 |
