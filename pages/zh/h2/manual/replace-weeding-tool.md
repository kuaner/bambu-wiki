## 钩针

钩针可用于提起或移动材料，例如在切割热转印膜等材料后，帮助清除废料。然而，钩针的用途不仅限于清除废料，它还可以协助移除完整的膜。

本页指导您如何更换钩针。

### 步骤 1. 卸下螺丝

卸下钩针主体上的三个螺丝。

![](https://wiki.bambulab.com/h2/maintenance/weeding-tool/remove_screws.png)

### 步骤 2. 打开外壳

如下图所示，轻轻地将钩针推向其主体，慢慢地将外壳的两半分开。

> 注意：请小心操作，避免受伤！

![](https://wiki.bambulab.com/h2/maintenance/weeding-tool/open.png)

### 步骤 3. 移除钩针

打开外壳后，小心拉出钩针，以免造成伤害。

|  |  |
| --- | --- |
|  |  |

### 步骤 4. 安装新的钩针

安装新的钩针，确保工具上的凹槽与外壳上的凸片对齐。然后，按照步骤2和步骤1的相反顺序重新组装外壳，最后安装螺丝。

![](https://wiki.bambulab.com/h2/maintenance/weeding-tool/final_assembly.png)
