> **注意**：本页面以 H2D 机器为例，**H2S 和 H2C 的更换步骤完全相同**。

## 为什么要标定激光的焦点？

由于激光模组是手动安装到工具头上的，激光器本身与喷嘴之间的高度差会受到加工公差和装配公差的影响，从而使激光焦点与喷嘴之间的相对高度与设计值产生轻微差异。若加工时仍按设计值执行，可能导致切割或雕刻时激光焦点未处于期望高度，进而影响加工效果。

## 什么时候要标定激光的焦点？

1. 激光模组到手后第一次安装时；
2. 激光模组受到磕碰时（包括其侧面的激光测高器）；
3. 雕刻时发现线宽变粗时。

## 如何触发激光焦点标定？

目前，当雕刻激光安装到工具头并插入电源线后，可在激光模组初始化中进行激光焦点标定。

打印机屏幕操作路径为：**设置 → 工具箱 → 激光模组初始化**。

![](https://wiki.bambulab.com/h2/manual/laser-focus-calibration-intro/image-10.png)

## 激光焦点标定操作过程

### 1. 准备标定耗材

如下图所示，准备一张矩形白色卡纸：

![](https://wiki.bambulab.com/h2/manual/laser-focus-calibration-intro/image-12.png)

**如果找不到卡纸，或卡纸出现折弯，怎么办？**

- **选项 1**：卡纸厚度为 0.35mm，如能找到此类卡纸，请剪取一块约 120mm × 120mm 的正方形（尺寸要求不严格，建议边长大于 100mm）。注意：卡纸需为浅色，深色卡纸不可使用。
- **选项 2**：使用普通 A4 纸，建议将 A4 纸的短边紧贴激光垫板底部，长边对半裁开，刀条按隔一放一的方式排列。

| --- | --- |
|  |  |

- **选项 3**：打印机包装内附有一张白色珠光卡纸，可将其对折撕开，取其中一半替代白色卡纸使用，刀条按隔一放一的方式排列。

|  |  |
| --- | --- |
|  |  |

- **选项 4**：如果你有透明亚克力板、便签纸和胶水，可同时使用这三样，如下图。

> 注意：一定要将胶水涂满亚克力板，防止纸张出现翘曲或鼓起。

![](https://wiki.bambulab.com/h2/manual/laser-focus-calibration-intro/image-11.png)

经测试，以下耗材不太适用于标定：

1. **木板**——表面纹理及热溢出会使标定线模糊不清，勉强可用；
2. **激光调光纸**——焦点处功率太高会直接烧穿；
3. **阳极氧化铝板**——表面纹理会影响识别效果。

### 2. 标定耗材的放置

首先，将至少 2 条刀条放置在靠近激光垫板标定台附近的位置，如下图：

![](https://wiki.bambulab.com/h2/manual/laser-focus-calibration-intro/image.png)

然后将标定耗材放置在紧贴标定台的中央位置，**下图为正确范例：**

|  |  |  |
| --- | --- | --- |
|  |  |  |
| 标定耗材紧贴标定台中央 | 虽然使用过，但烧灼过的区域不在本次标定范围内 | 便签纸或 A4 纸用胶水完全贴合在透明亚克力板上 |

**以下为错误放置的范例：**

|  |  |  |
| --- | --- | --- |
|  |  |  |
| 卡纸掉落在齿条中，未贴近标定平台 | 卡纸翘曲 | 直接将 A4/A5 纸放在垫板上而不调节齿条间距，纸张太薄容易被吹动 |

|  |  |
| --- | --- |
|  |  |
| 卡纸烧灼过的区域正好是本次标定会用到的范围 | 使用亚克力板 + 便签纸组合时，未用胶水将便签纸完全贴合，导致边缘翘起 |

### 3. 开始标定

放置好标定耗材后，按照屏幕上的步骤提示，执行激光模组初始化流程即可。
