## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### 步骤一：下降热床、退料、关闭电源

1. 放回热床底部的 3 块泡棉。

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-43.png)

- 在屏幕中控制热床下降至底部，压紧泡棉

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-48.png)

- 在屏幕点击退料后，将耗材卷回料盘并将其拿下。

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-72.png)

- 关闭电源，拔下电源线和安全钥匙。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤二：移除料管和外挂料盘

1. 移除两根连接至料盘支架的特氟龙料管。

|  |  |
| --- | --- |
|  |  |

- 向上推动移除两个料盘支架。

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-66.png)

### 步骤三：固定热床和工具头

1. 放回空气滤芯上方的泡棉和拖链处的泡棉，拉动工具头和拖链压紧泡棉。

|  |  |  |
| --- | --- | --- |
|  |  |  |

- 在图示位置绑紧扎带，固定 X 轴和机器后方桁架，以及拖链，注意不要绑住皮带。

|  |  |
| --- | --- |
|  |  |

- 放回两个丝杆固定泡棉。

|  |  |
| --- | --- |
|  |  |

- 在所示位置贴上贴纸，防止后续拧螺丝时刮蹭。

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-63.png)

- 拧紧靠近前门的 2 颗热床固定螺丝。

|  |  |
| --- | --- |
|  |  |

- 放回后方的热床固定件，拧紧 2 颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤四：放回配件盒，打包机器

1. 放回固定泡棉、电源线盒并用扎带固定。

|  |  |
| --- | --- |
|  |  |

- 将上盖玻璃装回纸板外壳后，放至打印机顶部，用胶带固定好两侧。

|  |  |
| --- | --- |
|  |  |

- 用胶带将前门固定。

|  |  |
| --- | --- |
|  |  |

- 将防潮袋套在底部纸箱的 4 个角，然后两个人抬入打印机。

|  |  |
| --- | --- |
|  |  |

- 拉起防潮袋，完全套住打印机，并在上方用胶带封好。

|  |  |
| --- | --- |
|  |  |

- 将缓冲气垫放至打印机四周。

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-81.png)

- 插回纸板和泡沫包装，确保放置到位。

|  |  |
| --- | --- |
|  |  |

- 放回顶部的泡棉和配件盒和快速入门指南手册

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-90.png)

- 套入外箱，确保底部 4 个孔对齐。

|  |  |
| --- | --- |
|  |  |

- 装入底部 4 个卡扣，并锁紧。
