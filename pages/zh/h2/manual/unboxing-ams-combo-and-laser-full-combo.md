### 步骤 25. 移除气泵固定螺丝（仅激光版本需要拧除这颗螺丝，非激光版本可以忽视这一步）

> 拧松后缓慢取出螺丝，以防掉入打印机内部。

请先拧松气泵固定螺丝，再取下硅胶套，螺丝将在此过程中一并被取出。

为防止螺丝在拆卸过程中掉入背板内部，硅胶套已更换为外凸设计。**在未拧松气泵螺丝前，请勿直接拔除硅胶套。**

### 步骤 29. 将另一端插入打印机背后任意进料口，向前推送直至无法前进，在缓冲器上观察窗口看到到料管即插入到位

|  |  |
| --- | --- |
|  |  |

> **注意：**  
> 鉴于不同批次及版本的整机配置存在料管长度差异，在确保进料阻力符合要求的前提下，适当缩短料管长度可有效减少打印耗时。经测试验证，H2D打印机从AMS模块至机身的料管长度建议不低于600mm，以保证设备的最佳工作状态。
