## 操作步骤

### 步骤一：拆开外包装

1. 移除底部两侧 4 个卡扣；

|  |  |
| --- | --- |
|  |  |

2. 上提移除外箱；

|  |  |
| --- | --- |
|  |  |

3. 撕掉底部 4 张贴纸；

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-6.png)

4. 取出并仔细阅读快速入门指南，了解详细操作步骤；

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-12.png)

5. 取出配件盒；

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-2.png)

6. 移除泡棉、纸壳和充气防护；

|  |  |  |
| --- | --- | --- |
|  |  |  |

7. 从防潮袋两侧示意处撕开防潮袋，并下拉将其套入下方纸箱四角；

|  |  |
| --- | --- |
|  |  |

- 两人合力抬出打印机，放至稳定平面；

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image.png)

- 移除打印机周围包装和胶带。

|  |  |
| --- | --- |
|  |  |

### 步骤二：解锁打印机热床和工具头

1. 取下上盖玻璃

|  |  |
| --- | --- |
|  |  |

- 移除四颗热床固定螺丝，解锁热床

|  |  |  |
| --- | --- | --- |
|  |  |  |

> 注意：拧下的四颗热床螺丝可以放在取下的热床固定件中以备后用。
>
> ![](https://wiki.bambulab.com/h2/manual/unboxing-h2d/img_v3_02ns_8f2b000d-f5a7-43ba-a7f0-74af6d413efg.jpg)

- 移除丝杆上的泡棉

左右丝杆

|  |  |
| --- | --- |
|  |  |

中间丝杆

|  |  |
| --- | --- |
|  |  |

- 移除机器内部胶带

|  |  |
| --- | --- |
|  |  |

- 剪开扎带，取出电源线盒

|  |  |  |
| --- | --- | --- |
|  |  |  |

- 剪开固定工具头和拖链的扎带；

> 注意不要剪断皮带！

|  |  |  |

- 向打印机前门移动工具头，取出固定拖链和 X 轴下方的泡棉

|  |  |
| --- | --- |

- 盖上上盖玻璃。

|  |  |
| --- | --- |
|  |  |

### 步骤三：安装外挂料盘支架和料管

1. 取出两个料盘支架，分别对齐打印机背部的上下两个支架底座，向下滑入安装。

|  |  |
| --- | --- |
|  |  |

- 从配件盒拿出两根料管

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-37.png)

- 将短料管一端插入上方的料盘支架，另一端插入打印机背面靠上的进料口；长料管连接下方的料盘支架和靠下的进料口。连接后可向外尝试拔出，检查料管是否安装到位或松脱。

|  |  |
| --- | --- |
|  |  |

- 将耗材放至料盘支架，将其插入料管，向前推送直至无法前进。

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-38.png)

### 步骤四：开机与校准

1. 取下打印机背后的安全钥匙，对齐孔位并插入安全钥匙。

|  |  |
| --- | --- |
|  |  |

- 移除背面的固定胶带。

![](https://wiki.bambulab.com/h2/manual/unboxing-h2d//image-47.png)

- 插入电源线并开机。

|  |  |
| --- | --- |
|  |  |

- 根据屏幕指引，进行语言使用地区等初始设置和首次校准。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

- 校准完成后热床会自动抬升，此时取出热床底部的泡沫即可。

|  |  |
| --- | --- |
|  |  |

现在您已经完成了 H2D 单机开箱的所有步骤，可以开始您的打印之旅！

### 步骤五：放置废料盒

开始打印前，推荐准备一个盒子放置于**打印机背面的废料滑梯下方**，用于收集打印过程滑出的废料，保持环境整洁。

您可以打印一个 [H2D 专用废料盒](https://makerworld.com.cn/zh/search/models?keyword=H2D%E5%BA%9F%E6%96%99%E7%9B%92)，也可以使用耗材包装盒或其他容器来接废料。

下图为 P1S 打印机放置示例。

![purge_container_placement_p1s_example.png](https://wiki.bambulab.com/p1/manual/p1s-unboxing/purge_container_placement_p1s_example.png)

接下来，请参考[首次使用](h2d-first-print.md)进行首次打印。
