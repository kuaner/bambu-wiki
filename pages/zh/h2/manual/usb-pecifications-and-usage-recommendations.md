部分机型提供了一个外部 USB 接口用于连接 U 盘，可将切片文件导入 U 盘，从屏幕端直接发起打印。除此之外，还可以保存工作录像、延时摄影和打印缓存。

|  |  |
| --- | --- |
|  |  |

## 适配机型

- H 系列打印机
- P2S 打印机

## U盘的规格要求

1. USB2.0 协议以上（实际最低写入速度需要大于 10M/s），支持的文件格式为 FAT32 和 exFAT。并且打印机只支持挂载一个 U盘，无法通过 USB 扩展坞连接多个U盘。
2. 打印机本身没有U盘容量的限制，**U盘的最大容量受限于文件系统格式**：

- 如果U盘的文件格式为 FAT32，在 linux 和 MAC 系统上格式化 U 盘，所支持的最大U盘容量为 2TB；在 Windows 系统上格式化U盘，所支持的最大 U 盘容量为 32G。对于 Windows 操作系统来说，如果 U 盘容量超过 32GB，则默认格式化为 exFAT，而对于 Linux 和 Mac OS 这两种操作系统而言，则没有此格式限制。
- 如果U盘的文件格式为 exFAT，所支持的最大 U 盘容量为 128PB。

总结如下表：

| U 盘文件格式 | 执行格式化的操作系统 | 最大U盘容量 | 最大单个文件 |
| --- | --- | --- | --- |
| FAT32 | linux 或 MAC系统 | 2TB | 4GB |
|  | Windows 系统 | 32G | 4GB |
| exFAT | 任何系统 | 128PB | 16EB |

- 打印机也具有格式化功能，格式化只支持 FAT32。对于 2TB 以下的 U 盘，您可以选择直接在打印机上进行格式化。若您的 U 盘大于 2TB，只能先在电脑上将其格式化成 exFAT 格式。**请注意，U 盘容量特别大的情况下（比如大于 1 T），打印机识别文件和格式化需要的时间也会更长。**

## U盘的使用建议

- 如果需要取下 U 盘，推荐使用 U 盘安全弹出功能，避免热拔插。直接拔出 U 盘可能会导致录像和延时摄影文件受损，无法打开。

![](https://wiki.bambulab.com/h2/manual/usb-pecifications-and-usage-recommendations/image-7.png)

- 推荐在打印机的 USB 接口上直接插入 U 盘，而不是读卡器+ SD 卡的模式。如果需要使用读卡器+ SD 卡，插拔时请直接插拔读卡器。
- 暂不支持加密的U盘。

## **录像与延时摄影的存储空间说明**

### 录像

录像功能可以在屏幕端的设置页面和 Bambu Studio 的设备页面里开启。

|  |  |
| --- | --- |
|  |  |

#### 存储空间要求和开启条件

- 录像视频最多占用 U 盘总容量的 65%，且录像文件最多不超过500个。
- U 盘总容量的 15% 将保留为未使用空间（即录像视频文件与U盘中的初始数据文件总占用不超过 85%）。
- 如果 U 盘中的初始数据已占用超过 85% 的容量，录像功能将无法启用。
- 当 U 盘空闲空间超过 15% 时，可在打印过程中启用录像功能。录像将持续进行，直到 U 盘容量占用达到 85%。
- 若后续打印需要录制新的视频，系统将自动清除 U 盘中原有的录像文件以释放空间。

### 延时摄影

延时摄影功能可以在发送打印任务的窗口开启，**只有打印机插入 U 盘后才会有该选项，** 如下图所示。

![](https://wiki.bambulab.com/h2/manual/usb-pecifications-and-usage-recommendations/image-5.png)

#### 存储空间要求

- **128GB 或更大容量 U 盘**：剩余空间小于 10GB 时，无法开启新的延时摄影录制。
- **64GB U 盘**：剩余空间小于 8GB 时，无法开启新的延时摄影录制。
- **32GB U 盘**：剩余空间小于 6GB 时，无法开启新的延时摄影录制。
- **16GB 或 8GB U 盘**：剩余空间小于 3GB 时，无法开启新的延时摄影录制。

#### 录制过程空间管理

延时摄影录制过程中，如果 U 盘剩余空间小于预留值，不会影响本次打印任务的延时摄影录制。
