## 为什么需要喷嘴偏移校准？

在使用双喷嘴打印机进行打印的时候，如果打印任务中用到了两个喷嘴，需要确保两个喷嘴的定位完全一致，才保证良好的打印质量。当两个喷嘴的定位出现偏移，则可能导致打印时模型出现错位、层移。当你在打印过程中发现切换喷嘴打印后模型出现明显的层移，那么我们建议您进行一次喷嘴偏移校准。

双喷嘴打印机提供了两种校准方式：**喷嘴偏移校准**和**高精度喷嘴偏移校准**。

## 喷嘴偏移校准

在打印机屏幕上点击 **设置——打印校准——喷嘴偏移校准**，即可开始喷嘴偏移校准。

- H2D/X2D：主要基于喷嘴偏移校准传感器对两个喷嘴的偏移量进行校准；

![](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/20251120-171523.jpg)

- H2C：校准工具头上的热端以及热端挂架上的每个热端。

![](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/20251120-171644.jpg)

> 注意：H2C 喷嘴偏移校准的耗时取决于热端挂架上的感应热端数量。

### Z 方向偏移校准

#### **校准原理**

左右两个喷嘴在理想的情况下高度差是 5mm，所以切换喷嘴的时候热床会上升/下降 5mm，如下图所示。由于实际装配的误差或者喷嘴尺寸的公差，可能会导致两个喷嘴的高度差无法精准保持在 5mm。Z 方向的偏移校准，就是两个喷嘴依次在热床上触碰，来计算各自 Z=0 时候的热床高度，从而计算出两个喷嘴的高度差，实际打印中会根据校准测得的值进行热床高度补偿。

![](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/%E5%8F%8C%E5%96%B7%E5%A4%B4%E5%88%87%E6%8D%A2.gif)

#### **校准动作**

两个喷嘴分别在热床表面触碰一下，像回零一样触热床，打印机获得触碰时热床的 Z 坐标，坐标之差就是 Z 偏移值。

![z偏移校准.gif](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/z%E5%81%8F%E7%A7%BB%E6%A0%A1%E5%87%86.gif)

### XY 方向偏移校准

#### **校准原理**

通过喷嘴偏移校准传感器感应两个喷嘴的位置，帮助喷嘴找到校准传感器的中心坐标**（喷嘴越靠近中心位置信号越强）**，两喷嘴在中心位置的坐标偏移量就是喷嘴在 XY 方向的偏移值。

1. **打印前“快速校准”**：打印前“喷嘴偏移校准”一项选择“自动”。如果该过程失败，或者测得两个喷嘴间偏移值过大，则会自动触发“打印前完整校准”流程（见下文）。

![打开-cn.png](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/%E8%87%AA%E5%8A%A8-cn.png)

2. **打印前“完整校准”**：打印前“喷嘴偏移校准”一项选择“开启”。如果找不到传感器或传感器信号弱，则会自动触发打印机屏幕校准页面中的 **“喷嘴偏移校准”** 流程。如果仍然检测到传感器信号弱，打印机就会报错。

![打开-cn.png](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/%E6%89%93%E5%BC%80-cn.png)

#### 校准动作

- **H2D：** 喷嘴的 XY 方向偏移校准是利用喷嘴和热床后面的**喷嘴偏移校准传感器**进行的。在热床内侧凸起的部分，右边的黑色小块就是 XY 偏移校准传感器（如下图红框中所示）**。**

![](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/image-7.png)

- **H2C：** H2C 的喷嘴偏移校准部件与 H2D 相同，仅在喷嘴偏移校准传感器上额外增加了一张热敏纸。该热敏纸用于热端挂架初始化校准，与喷嘴偏移校准本身无关，只是集成在同一组件上。

![](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/20251121-112930.jpg)

- **X2D：** X2D 的喷嘴偏移校准传感器位于下图蓝框内，用于校准热端偏移量，确保切换的热端定位完全一致。

![x2d-喷嘴偏移校准.jpg](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/x2d-%E5%96%B7%E5%98%B4%E5%81%8F%E7%A7%BB%E6%A0%A1%E5%87%86.jpg)

### **校准失败的可能原因**

#### 1. 校准传感器内部硬件损坏、校准传感器没装或者线没接，没信号。

检查喷嘴偏移校准传感器的接口是否正确连接。详情请参考：[HMS\_0300-2700-0001-0004](../troubleshooting/hmscode/0300_2700_0001_0004.md)。

#### 2. 使用的是第三方热端，例如不导磁的碳化硅热端，也不建议使用 A1 系列热端。

请使用官方热端。

#### 3. 热端未安装正确，导致热端没有完全被固定紧。

- **H2D：** 重新扣紧热端卡扣，请参考：[热端安装教程](../maintenance/replace-hotend.md)。
- **H2C：** 参考上方 wiki 检查左侧热端是否扣紧，参考此 wiki：[HMS\_1A00\_0100\_0002\_0034](../../h2c/troubleshooting/hmscode/1A00_0100_0002_0034.md)，检查右侧热端是否有异物。
- **X2D：** 重新扣紧热端卡扣，请参考：[热端安装教程](../../x2d/maintenance/replace-hotend-and-silicone-sock.md)。

#### 4. 固件 bug

请将固件更新至 01.01.02.08 及更新的版本。

## 高精度喷嘴偏移校准

在打印机屏幕上点击 **“设置——校准——高精度喷嘴偏移校准”**，可采用视觉校准的方式对喷嘴偏移进行校准。

![20251121-153809.jpg](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/20251121-153809.jpg)

**在当前版本固件中，如果想要使用高精度喷嘴偏移校准的数据，需要在发送打印任务前关闭“喷嘴偏移校准”选项。**

![关闭-cn.png](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/%E5%85%B3%E9%97%AD-cn.png)

### 校准原理及步骤

高精度喷嘴偏移校准主要通过打印测试模型，用 AI 视觉检测的方式校准两个喷嘴在 XY 方向上的偏移量。

首先需要准备一深一浅两卷耗材，然后将两卷耗材放入两个挤出机各自连接的 AMS 中（任意槽位即可）。如果没有 AMS，可使用外挂料盘提前将两卷耗材分别进料至两个喷嘴，然后在校准中选择“高精度喷嘴偏移校准”，根据屏幕上提示的步骤进行校准即可。

|  |  |
| --- | --- |
|  |  |

打印机会在打印板上打印测试模型，然后用工具头摄像头进行图像采集，分别识别两个喷嘴挤出的横向和纵向线条的中心位置。理论上 XY 方向的偏移应为 7mm，实际上测出来的值与理论值的偏差，就是两个喷嘴之间 XY 的偏移量。

![2025-07-22_11_35_16.png](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/2025-07-22_11_35_16.png)

理论上，高精度喷嘴偏移校准的定位精度优于普通喷嘴偏移校准，因其通过喷嘴打印出的线条直接计算偏移量；相较于喷嘴偏移校准传感器的校准方式，这种直接测量方法可排除其他因素造成的误差干扰。

> 注意：H2C 打印机的高精度喷嘴偏移校准**不会对热端挂架上的热端进行校准**，仅对工具头上的热端进行校准。

### 校准失败的可能原因

#### 1. 校准使用的两种耗材颜色过于相近

使用的耗材颜色对比度不够，导致 AI 识别的难度较大从而导致校准失败，建议尽量使用颜色深浅对比较为明显的耗材进行校准。

#### 2. 校准模型存在打印质量问题

如果校准模型最上层的标定线没有打上，或者打印的不够平直，都可能导致识别失败，需要结合实际打印模型状态，检查打印板是否粘接不良，或者喷嘴有堵塞等。

![校准模型存在明显打印质量问题，导致校准失败](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/image-5.png)

#### 3. 机箱两侧补光灯关闭

部分图像拍摄时会依赖机箱补光灯，手动关闭补光灯也可能导致识别失败。

#### 4. 工具头摄像头相对于喷嘴的偏移过大

请确认喷嘴是否有歪斜，工具头摄像头是否安装到位。

#### 5. 工具头摄像头无法工作，或镜头脏污

请确保工具头摄像头的镜头没有被遮挡，且没有镜头脏污等 HMS 报警。

![](https://wiki.bambulab.com/h2/manual/nozzle-offset-calibration/image-6.png)
