## 1. **空调系统UI介绍**

> H2 系列打印机能够为不同耗材自动选择合适的空调系统，您无需手动设置空调模式——Bambu Studio会在切片时根据耗材类型自动完成配置。

- **冷却模式**：适合打印 PLA/TPU 等**耐热性较低的耗材；**在此模式下，腔体加热循环风扇保持关闭状态，过滤切换风门位于低处。

![冷却模式.png](https://wiki.bambulab.com/h2/h2s/manual/screen-operation/%E5%86%B7%E5%8D%B4%E6%A8%A1%E5%BC%8F.png)

- **腔温保持模式**：适合打印 ABS/ASA/PC/PA 等**具备高耐热性的耗材。**腔体加热时，系统会自动切换至腔温保持模式；在此模式下，腔体加热循环风扇将自动开启，辅助部件冷却风扇将保持关闭状态，过滤切换风门位于高处。

![fan.png](https://wiki.bambulab.com/h2/h2s/manual/screen-operation/fan.png)

> 冷却模式与腔温保持模式的过滤切换风门状态，详见第 2 部分“三种空气循环模式”。

- **部件冷却风扇：**安装在工具头上，用于确保在打印过程中充分冷却打印层，有助于在挤出时快速冷却耗材，使每一层都能在下一层沉积之前凝固并保持原始形状。

![abcd.png](https://wiki.bambulab.com/h2/h2s/manual/screen-operation/abcd.png)

- **辅助部件冷却风扇：**安装在机腔内左侧，高速打印时，能为打印模型提供更好的冷却条件。

![](https://wiki.bambulab.com/h2/manual/screen-operation/fuzhubujian.png)

- **腔体外排风扇：** 安装在打印机右内衬上，当腔体冷却时，打印机循环系统会切换至冷却模式，腔体外排风扇转速会随腔温升高而加快。当打印机腔温较低，且机箱内打印耗材的散热需求不高时，腔体外排风扇的转速会降至 30%（以 PLA 为例，PETG 则为 0%）。

![](https://wiki.bambulab.com/h2/manual/screen-operation/5.png)

当打印机启动外排风扇时，顶部自动风门和位于打印机背面的自动排气格栅会自动打开，以便精准控制腔温或控制机箱内的气体流动。顶部自动风门作为进气口，与出气口的自动排气格栅相配合，从而为系统提供充足的进气量，同时过滤切换风门位于下方，确保机箱内的气体流动符合预期并可控。

|  |  |
| --- | --- |

- **腔体加热循环风扇：**安装在打印机右内衬上，当腔体加热时，打印机会自动切换至腔温保持模式。设置腔温后，腔温加热器（由 PTC 和腔体加热循环风扇组成）开始工作，PTC 全功率加热，风扇全速运转。当腔体温度达到目标值后，风扇转速不变，PTC 功率下降，以维持恒定温度。

![](https://wiki.bambulab.com/h2/manual/screen-operation/7.png)

- **腔温：**根据打印耗材的不同，可设置合适的腔温。低腔温适合打印 PLA、PETG 等耗材；高腔温适合打印 ABS 等的易翘曲耗材。

![qiangwen.png](https://wiki.bambulab.com/h2/h2s/manual/screen-operation/qiangwen.png)

当开启腔温加热后，打印机会切换至腔温保持模式，此时自动排气格栅和顶部自动风门会关闭。为了在升温阶段提升气体流动性、加快腔体升温，过滤切换风门会暂时开启；而在腔温保持阶段，过滤切换风门则会关闭，以确保过滤效果。

## 2. 三种空气循环模式介绍

H2系列打印机的空气循环系统共有三种模式，每种模式下自动排气格栅和过滤切换风门的状态如下：

> 顶部自动风门（进气口）与背部排气格栅（出气口）始终保持同步，本文不再单独说明。具体的开关状态请参考排气格栅。

- **冷却模式：**

  - 当腔体外排风扇打开时，自动排气格栅开启，过滤切换风门位于下方。

  |  |  |
  | --- | --- |

- 当腔体外排风扇关闭时，自动排气格栅关闭，过滤切换风门位于下方。

|  |  |
| --- | --- |

- **腔温保持模式：** 自动排气格栅关闭，过滤切换风门位于上方。

  |  |  |
  | --- | --- |

- **激光模式：** 自动排气格栅开启，过滤切换风门位于下方
