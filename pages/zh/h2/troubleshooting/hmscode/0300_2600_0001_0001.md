## 故障描述

左热端通过锁扣固定在热端加热器上，并随热端升降模块上下移动。  
当左挤出机工作时，热端升降模块下降，靠近后部的左**挤出机涡流传感器**，并与其保持一定间隙。随着挤出力的变化，间隙也会相应变化，从而实现挤出力测量。  
若传感器检测到的挤出力信号频率过低，系统将触发告警，热床会轻微下降，任务终止并显示错误信息。

**可能的原因包括：**

1. 左**挤出机涡流传感器**涡流线圈与热端升降模块间隙过大
2. 左**挤出机涡流传感器**与 TH 板的连接脱落或松动

|  |  |
| 1. 左挤出机涡流传感器涡流线圈 | 2. 热端升降模块  3. 涡流线圈与升降滑块间隙 |

## 故障排除

> ❗ 工具头拆装前，请务必保持打印机处于断电状态。

### 工具、设备及材料

- H2.0 内六角扳手
- 普通 A4（打印）纸

### 排故措施

***您可视情调整各排故措施的顺序。***

#### 步骤1. **检查挤出机涡流传感器涡流线圈与升降滑块间隙**

1. 参考 Wiki **[更换 H2D & H2C 部件冷却风扇风道](../../maintenance/replace-part-cooling-fan-air-duct.md)**，拆除部件冷却风扇风道。
2. 检查左**挤出机涡流传感器**的涡流线圈与左热端升降滑块之间的间隙。正常间隙范围：
   - 在左挤出机处于工作位置状态下。
   - 向间隙中插入\*\*两层普通打印纸条（总厚 0.2 mm）\*\*时能轻松滑动；
   - 且 \*\*三层打印纸条（总厚 0.3 mm）\*\*无法插入或插入后能感受到明显的摩擦。
3. 用 H2 螺丝刀轻轻尝试拧动螺钉（下图 2），检查螺钉是否有松动。

|  |
| --- |
|  |
| 1‑两层普通 A4 纸  2‑线圈支架后锁螺丝 |

4. 若间隙异常或螺钉松动，请按以下步骤调整：
   1. 松开螺钉，将\*\*三层普通打印纸（总厚：0.25~0.3 mm）\*\*垫在涡流线圈与升降滑块之间。
   2. 向升降滑块方向推住线圈支架状态下，锁紧螺丝。
   3. 锁紧后拔出打印纸，用两层和三层打印纸再次确认间隙是否合适（参考前述检查）。
   4. 最后，使用电子硅胶或 UV 胶固定螺丝，防止螺钉松脱。
5. 若间隙正常且螺钉无松动，则继续完成以下步骤 2。

#### 步骤2. 左**挤出机涡流传感器**与 TH 板连接松动检查

1. 参考 Wiki **[H2D 工具头拆装指南](../../maintenance/disassemble-and-install-h2d-toolhead.md)** 中步骤 4‑5，拆除部件冷却风扇及其 TH 接口板，裸露 TH 板。
2. 检查 TH 板底部的左**挤出机涡流传感器**接头（下图连接器 8）。  
   ![左**挤出机涡流传感器**接头（图示 8）](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-2600-0001-0001/image.png)
3. 若传感器接头与 TH 板连接松动，请重新安装确保接头扣合牢固，然后跳转步骤 4 进行测试。
4. 若无松动，则左**挤出机涡流传感器**可能损坏，请更换新的传感器模块，跳转至步骤 3 更换传感器模块。

#### 步骤3. 左**挤出机涡流传感器**更换

（此处按照正式更换流程操作，具体步骤可参考官方文档）

#### 步骤4. 工具头安装与测试

1. 安装热端（部件冷却风扇及其风道可在测试完成后安装）。
2. 点击屏幕，切换至左挤出机。
3. 手动触发回中。
4. 若无报警产生，测试成功。
5. 安装部件冷却风扇及其风道。

***若以上排故措施无法解决您的问题，请[提交工单](https://bambulab.com/zh/my/support/tickets/create?from=5)并上传打印机工作日志。***
