## 故障描述

排气风门由电磁铁控制，改变电流方向即可开关风门。内置霍尔传感器会实时检测风门位置。当 AMS HT 或 AMS 2 Pro 发出开关指令后，若传感器未检测到风门到位，设备将显示故障提示。

- 影响：

1. 排气风门不能正确开启和关闭
2. AMS 的气流循环可能受到影响
3. AMS 烘干过程的升温、排除潮湿空气的过程受到影响
4. 非烘干状态下，密封效果受到影响

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 故障排除

## AMS 2 Pro

## 拔插风门排线

### 步骤 1 - 拆下 AMS 2 Pro 背面的铁氟龙管

从 AMS 2 Pro 背面按压铁氟龙管释放开关，解锁接头，然后从 AMS 2 Pro 背面拉出铁氟龙管。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-11.png)

### 步骤 2 - 抽出铁氟龙管释放开关

从下盖内部捏住卡扣自动弹开铁氟龙管释放开关后，从 AMS 2 Pro 的背面抽出铁氟龙管释放开关。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image.png)

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-1.png)

捏卡扣时，另一只手需要用从 AMS 2 Pro 的背面扶住铁氟龙管释放开关，以避免弹簧被弹出丢失。

### 步骤 3 - 取出 AMS 2 Pro 主框架组件

拆下中间2个料槽的从动支撑套筒组件以露出2个螺丝孔，取出轴承套时，小心两端的轴承，避免丢失。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-2.png)

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-3.png)

移除固定 AMS 2 Pro 主框架上2颗螺丝A。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-4.png)

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-5.png)

将主框架后部完全提起来， 竖立放置在 AMS 2 Pro 下盖上，**注意有电缆连接，请勿暴力操作**；抬起时，建议先抬主框架前部分，再往前推一推，为框架后部分让出空间。

竖放 AMS 2 Pro 主框架时需避开风门的电子部件，以防压坏。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-6.png)

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-7.png)

解锁插头的卡扣，拔出 AMS 2 Pro 电源板上的信号连接线和电源连接线，整体抬出 AMS 2 Pro 主框架组件。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-10.png)

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-12.png)

### 步骤 4 - 重新拔插风门线缆

底面上的**风门1是进气口**，侧壁上的**风门2是出气口**。根据实际情况，重新拔插风门上的插头。

|  |  |
| --- | --- |
| 风门1（进气口） | 风门2（出气口） |

如果拔插风门线缆后，问题依然存在，请更换风门组件。  
考虑到线缆一般不会发生故障，更换风门组件时，可以先更换风门，不用更换线缆，如更换风门后，故障仍然存在，再更换线缆。

## 更换风门组件

### 步骤 1 - 安装风门1（进气口）或风门2（出气口）风门

对准螺丝孔位后，往螺丝孔的方向推推，将风门压到对应的孔位，锁紧风门2颗螺丝B或螺丝C，插回风门的插头。

安装时，需注意风门的方向性，若安装方向错误，风门是无法被卡到位的，切勿暴力下压。进风风门的插座开口方向朝右，出风风门的插座开口方向朝上。

|  |  |
| --- | --- |
| 风门1（进气口） | 风门2（出气口） |

### 步骤 2 - 安装主框架组件和从动支撑套筒组件

将 AMS 2 Pro 主框架组件装入 AMS 2 Pro 下盖，连接信号电缆和电源电缆连接到 AMS 2 Pro 电源板。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-27.png)

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-25.png)

将下盖组件舌位对准中框卡槽，然后插入安装。  
![screenshot-20250519-161423.png](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-heating-unit/screenshot-20250519-161423.png)

AMS 2 Pro 主框架安装到位后，锁入2颗螺丝A固定。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-26.png)

安装中间2个从动支撑套筒组件，确保所有从动轴两端的轴承都被按压到位。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-22.png)

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-21.png)

### 步骤 3 - 安装铁氟龙管释放开关

按照如下方向，将铁氟龙管释放开关压回外壳中，卡扣顺利卡入对应的卡槽中，保持黑色硅胶外壳平整嵌入。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-18.png)

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-20.png)

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-air-inlet-unit/image-19.png)

### 步骤 4 - 连接铁氟龙管

检查确认铁氟龙管硅胶支架与五通组件的料孔对齐，并从 AMS 2 Pro 后部推入铁氟龙管。装完后，拉动铁氟龙管，确认铁氟龙管已固定。  
![connect_ptfe2.gif](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700_9000_0002_0001/connect_ptfe2.gif)  
![connect_ptfe1.gif](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700_9000_0002_0001/connect_ptfe1.gif)

从 AMS HT 背面按压特氟龙料管释放按钮，解锁接头，然后从 AMS HT 背面拉出特氟龙管。

首先需要拆下料槽的**从动支撑轴**和**主动支撑轴**，取出轴承套时，小心两端的轴承，避免丢失。

### 步骤 3 - 重新拔插风门线缆

重新插拔**进/出气口组件**的两根连接线缆（如下图）。

- 后侧**出气口**组件的线缆连 #2 接口

## 更换风门组件

### 步骤 1 - 安装风门1（进气口）或风门2（出气口）风门

进/出气口组件安装注意区分线缆长度与安装位置！  
进气口的长线缆组件安装于底部（左图），出气口的短线缆组件安装于后侧（右图）。  
分别锁紧每个进/出气口组件两颗固定螺丝（BT2\*4）。

|  |  |
| --- | --- |
|  |  |

### 步骤 2 - 安装 AMS HT 中框

如下图所致连接 1、2 号位的线缆。其中1号位为主板通讯线（14pin），2号位为主板电源线（2pin）。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/58%E8%BF%9E%E6%8E%A5%E4%B8%A4%E4%B8%AA%E7%BA%BF%E7%BC%86.jpg)

将电源插座线缆插接在主板上并安装好绝缘橡胶套。  
![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/59ac%E7%BA%BF%E7%BC%86.jpg)

> 注意：此处连接不区分正负极。

连接 AMS HT 前端屏幕线缆，连接完成后需要注意将线缆卡入理线槽内。

|  |  |
| --- | --- |
|  |  |

用手指勾住凸出的线缆，将中框组件安装至下盖组件内。

|  |  |
| --- | --- |
|  |  |

需要确保中框组件完全压入下壳组件且前后没有翘起的情况，安装底部两颗固定螺丝（BT3\*8）。

|  |  |
| --- | --- |
|  |  |

### 步骤 3 - 安装主动支撑轴和从动支撑轴

主动支撑轴压入 AMS HT 前端槽内，直到听到“咔嗒”声，注意主动支撑轴黑色齿轮一端需要和中框组件内的黄色齿轮一端对齐。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/2%E5%AE%89%E8%A3%85%E4%B8%BB%E5%8A%A8%E8%BD%B4.jpg)

将从动支撑轴压入中框组件内，直到听到“咔嗒”声。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/%E4%BB%8E%E5%8A%A8%E8%BD%B4%E3%80%81.jpg)

> 注意：安装完成后可以手动转动**主动支撑轴和从动支撑轴**，需要确保旋转顺滑。

### 步骤 4 - 插入 AMS HT 背面特氟龙料管

最后将特氟龙管从 AMS HT 尾部推入。装完后，拉动特氟龙管，确认特氟龙管已固定。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/65%E6%8F%92%E6%96%99%E7%AE%A1.jpg)
