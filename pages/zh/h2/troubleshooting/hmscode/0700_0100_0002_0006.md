## 故障描述

- 功能：助力电机位于五通组件中，用于运输耗材，将耗材送往工具头打印，在打印过程中向缓冲器送入耗材，配合打印机打印。这里是检测到助力电机的三相电阻超出了合理的范围，电机排线可能脱落。
- 检测原理：开机的时候检测阻力电机的三相电阻值，如果三相阻值都超出了合理的范围，则提示该错误。
- 影响：助力电机不能正常工作，处于自由转动状态；AMS不能正常读取RFID，不能正常送料，不能正常助力打印。

## 工具、设备及材料

- 内六角螺丝刀

## 故障隔离流程

### 针对 AMS 2 Pro

- 参考 [AMS 2 Pro 拆装指南](../../../ams-2-pro/maintenance/disassembly-and-assembly.md)，拆开 AMS 主框架并抬起。重新五通检查助力电机的排线，是否接触不良。重新插拔电机的排线两端，然后再重启AMS看故障是否消失。

|  |  |
| --- | --- |
|  |  |

- 如果重新连接线缆后保存依然存在，则有可能是排线本身损坏了，需要更换**连接电机和 AMS 主板的排线**。
- 若更换排线后问题仍未解决，则需要更换**电机**，有可能是电机本身的线圈损坏了。
- 若更换电机后还是没解决，则可能是 AMS 主板故障导致的，需要**更换 AMS 主板**。

### 针对 AMS HT

- 参考 [AMS HT 拆装指南](../../../ams-ht/maintenance/disassembly-and-assembly.md)，拆开 AMS HT 主框架并抬起。重新检查内部助力电机的排线，是否接触不良。重新插拔助力电机两端的排线，然后再重启 AMS 查看故障是否消失。

- 如果重新连接线缆后保存依然存在，则有可能是排线本身损坏了，需要更换**连接电机和主板的排线**。
- 若更换排线后问题仍未解决，则需要更换**电机**，有可能是电机本身的线圈损坏了。
- 若更换电机后还是没解决，则可能是 AMS HT 主板故障导致的，需要[更换 AMS HT 主板](../../../x1/maintenance/replace-ams-main-board.md)。
