## 故障描述

该错误通常意味着系统无法检测到测高激光返回的光点。这可能是由于光路受阻（脏污/遮挡）或电路连接异常导致的。

### 可能的原因：

1.测高激光器被遮挡  
2.工具头摄像头被遮挡  
3.测高激光器断连

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 所需要工具

- 酒精
- 无纺布
- H2.0/H2.5内六角扳手
- 镊子

## 排故措施

### 步骤1. 清洁测高激光器

使用无纺布蘸取少量酒精，轻轻擦拭测高激光器的出光口镜片。

|  |  |
| --- | --- |
|  |  |

### 步骤2. 清洁工具头摄像头

使用喷了酒精的无纺布清洁工具头摄像头。

![image_17_76ee0d91a9.png](https://wiki.bambulab.com/h2c/image_17_76ee0d91a9.png)

清洁完成后请连接使用，若仍然出现该报错，则请重新插拔测高激光器线缆。

### 步骤3. 重新插拔测高激光器线缆

请检查测高激光器的线缆并重新插拔。拆除前请用镊子将插头上的胶移除，方便后续操作。拔出图示线缆时，请捏紧插头根部，垂直向上拔出，请勿用力向右拔，以免损坏插头。

详细拆解流程可参考：[10w 激光模组定期维护建议](../../maintenance/laser-module.md) (步骤6)
