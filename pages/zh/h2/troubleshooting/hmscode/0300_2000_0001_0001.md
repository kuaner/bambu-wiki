## 故障描述

当打印机出现 X 轴异常时，可能会导致打印头运动不畅、打印失败或报错。常见原因为皮带松弛或者导轨上存在异物。

## 所需要工具

- H2.0 内六角扳手
- H1.5 内六角扳手
- 润滑油
- 无纺布
- 酒精

> 重要提醒：操作之前请先关闭打印机电源。

## 故障排查指南

### 步骤 1.检查工具头是否被卡住

观察工具头在X轴方向上是否能够顺畅移动，确认没有异物或阻碍物卡住工具头。若存在异物或阻碍物，请清理X轴导轨上的异物，确保导轨干净无阻碍。

### 步骤 2. 调整皮带张紧力

1. 在进行皮带张紧前，请先关闭打印机电源，以防电机锁定导致工具头无法移动。
2. 使用 **H2.0 内六角扳手**，拧松背部的 4 颗张紧螺丝（**拧松 1–2 圈即可，请勿完全卸下螺丝**），使 XY 皮带处于放松状态。

|  |  |
| --- | --- |
|  |  |

3. 用手轻轻推动工具头前后移动 3–5 次，使皮带在导轨上重新分布并均匀受力。

![来回推动.webp](https://wiki.bambulab.com/h2/maintenance/belt-tension/%E6%9D%A5%E5%9B%9E%E6%8E%A8%E5%8A%A8.webp)

- 画面仅做示意如何推动工具头前后移动，您无需拆下热端。

移动后，确保工具头和线轨位置如下图所示，再进行下一步。

![位置.png](https://wiki.bambulab.com/h2/maintenance/belt-tension/%E4%BD%8D%E7%BD%AE.png)

4. 将打印机背部的 4 颗张紧螺丝重新拧紧，固定张紧轮位置。

> ⚠️ **注意：** 请勿过度拧紧螺丝，以免导致滑丝或损坏螺纹。

|  |  |
| --- | --- |
|  |  |

5. 执行打印机校准。在屏幕上点击“校准-打印校准”，只需单独勾选“振动补偿”并完成该校准项即可。

|  |  |
| --- | --- |
|  |  |

### 步骤 3. 建议清洁 X 轴线轨

1. 切断电源，将工具头移动至**最左侧极限位置**。
2. 用准备好的无纺布蘸取适量酒精，沿 X 轴线轨进行往复擦拭，直至表面无可见油污及耗材碎屑。

> 建议同时检查皮带表面，若发现污渍，可使用无纺布清洁。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/image-52.png)

3. 然后将工具头移动至另一侧，露出被遮挡的部分线轨，进行相同的清理操作。

|  |  |
| --- | --- |
|  |  |

4. 当X轴线轨表面的灰尘和异物都清理干净后，在线轨上补充润滑油。请注意，线轨的上侧和下侧都需要涂润滑油。

|  |  |
| --- | --- |
|  |  |

5. 添加完成润滑油后,手动推动工具头沿 X 轴全程往复运动 3–5 次，使润滑油在线轨上形成均匀油膜。

![](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/image-46.png)

6. 使用无尘布轻轻擦拭光轴两端，去除多余油脂，避免灰尘吸附。

***若以上排故措施无法解决您的问题，请[提交工单](https://bambulab.com/zh/my/support/tickets/create?from=5)并上传打印机工作日志。***
