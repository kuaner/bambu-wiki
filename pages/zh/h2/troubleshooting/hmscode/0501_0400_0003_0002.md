## 故障描述

3D打印机Z轴丝杆需要定期润滑，以减少摩擦和磨损，使平台升降更平稳，避免卡顿和层纹，提高打印精度，同时还能降低噪音、防锈防尘，从而延长丝杆和螺母的使用寿命。

## 故障排除

## 工具、设备及材料

- 润滑脂
- 润滑油
- 无纺布
- 手套

## 维护步骤

> 若您使用的是其他机型，同样可以参考本指南来开展维护工作，丝杆与光杆的维护保养方法并无差异，本教程仅作示意参考。

<https://public-cdn.bblmw.com/wiki/H2D/maintenance/h2d-Z-maintenance-zh.mp4>

将沾了酒精的无纺布包裹住光轴，上下移动进行擦拭，确保光轴清理干净。然后用同样的动作擦拭丝杆。

|  |  |
| --- | --- |
|  |  |

然后在光轴上涂**润滑油**，丝杆上涂**润滑脂**，请注意润滑油和润滑脂不要用混。

|  |  |
| --- | --- |
|  |  |

除了左侧的光轴和丝杆，H2D 内部还有右侧以及内侧的光轴和丝杆，总共3组。对于另外2组光轴、丝杆，也需要进行相同的清理和润滑操作。

下图为右侧光轴和丝杆的清理、润滑过程。

下图为内侧光轴和丝杆的清理、润滑过程。

润滑完毕后，重新将打印机上电，在打印机屏幕上控制热床上下移动，目的是让润滑油和润滑脂完全浸润 Z 轴丝杆和光杆，确保充分润滑。
