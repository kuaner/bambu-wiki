## 故障描述

激光雷达校准失败可能由以下原因导致：校准贴纸被遮挡、脏污或损坏，使得工具头相机无法准确识别贴纸上的特征点，进而导致校准过程失败。建议检查并确保校准贴纸的清洁和完整性。

|  |  |
| --- | --- |
|  |  |

1-测高激光器（激光雷达）2-工具头摄像头 3-校准贴纸

## 故障排除

### 工具、设备及材料

- 纸巾
- 备用的校准贴纸

### 排故措施

**检查校准贴纸的情况**

#### 步骤1. **检查校准贴纸是否有遮挡或脏污**

1. 如果是遮挡，清理贴纸上的遮挡物
2. 如果是脏污，用纸巾将贴纸擦干净

#### 步骤2. **检查校准贴纸是否有损坏或严重刮花，或是脏污无法整理干净**

撕下旧的校准贴纸，将新的校准贴纸准确粘贴在指定位置。

#### 步骤3. 重新安装工具头摄像头

**拆卸步骤**

使用 H2.0 内六角扳手移除四颗固定螺丝（BT3x8）

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-1.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-2.png)

握住部件冷却风扇风道尾部，小心向下将风道取出。

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-3.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-4.png)

然后使用 H1.5 内六角扳手移除两颗固定螺丝（M2x5），将右热端风扇风道斜着从工具头中抽出。

![](https://wiki.bambulab.com/h2/maintenance/replace-toolhead-camera/image-10.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-toolhead-camera/img_v3_02ip_7ef4c3e1-82e9-4e18-aeb0-33681f99826g-1.jpg)

使用 H1.5 内六角扳手拧松两颗工具头摄像头支架固定螺丝（M2x5），重新安装一次工具头摄像头。

![](https://wiki.bambulab.com/h2/maintenance/replace-toolhead-camera/image-3.png)

**安装风扇风道**

完成后装回右热端风扇风道和部件冷却风扇风道。

![](https://wiki.bambulab.com/h2/maintenance/replace-toolhead-camera/image-10.png)

在安装部件冷却风扇风道前，先将加热组件线缆压入理线槽，避免风道压住线缆。

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-24.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-25.png)

先安装前1/4风道，这样可以使后半部分风道更容易倾斜，从而避开喷嘴摄像头的干涉。然后抓住后半部分风道向上推入。

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-26.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-27.png)

推入后，再分别往外掰风道的两侧，将风道的两侧卡在工具头上，然后将风道用力往上卡紧。

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-28.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-29.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-30.png)

接下来往前推入前部分风道的顶部，使其完全贴合，不留缝隙。

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-31.png)

使用 H2.0 内六角扳手拧紧四颗固定螺丝（BT3x8）

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-32.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-33.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-34.png)

#### 步骤4. 重新校准

完成上述操作后，再重新发起挂载校准，观察是否可以正常完成。
