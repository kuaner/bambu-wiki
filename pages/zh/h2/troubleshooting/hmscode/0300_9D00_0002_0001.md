## 故障描述

由于用户每次往工具头上安装雕刻激光器的时候，激光器的夹紧状态会有变化，导致激光模块射出的激光焦点位置相对于之前可能会有所差异，所以需要进行雕刻激光器的焦点XY标定。为了拍照时获得更精准的雕刻切割位置。

故障发生的时候表现为报错 HMS，雕刻激光器的焦点XY标定失败。具体报错原因有以下几个：

- 雕刻激光器出现损坏，未能正常发起激光或者安装位置出现较大偏移。
- 热敏贴纸出现脏污、破损。
- 激光垫板回零台脏污。
- 激光垫板回零台安装未到位或者回零台反向安装。
- 腔温不在标定贴纸的工作温度范围，建议腔温在 20-30℃。

## 故障排除

### 工具及材料

- 湿巾

### 故障隔离流程

1. 确保热敏贴纸是干净，未破损的状态。

脏污、破损状态如下：

|  |  |
| --- | --- |
|  |  |

2. 用湿巾进行回零台擦拭，确保擦拭干净，等待干燥。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300_9d00_0002_0001/image-2.jpg)

3. 进行激光模组的首次安装操作（不要进行挂载校准操作），观察卡片上是否存在灼烧线条以及是否存在异常。

![image.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300_9d00_0002_0001/image.png)

4. 如果发现标定纸的灼烧线条清晰可见（未报错焦点 Z 标定失败），但是仍然存在焦点 XY 标定失败，请等待机器冷却到 20-30℃，再发起激光挂载校准。
5. 如果发现标定纸上灼烧线条断断续续，或者未出现灼烧线条，请更换激光模组重试，观察其是否正常，若其他激光模组正常则该激光模组可能出现损坏。
