## 故障描述

使用 AMS 时，缓冲器（或 AMS 集线器）连接在 AMS 和打印机之间。

它有两个滑块、两个弹簧和四个霍尔传感器。当AMS将长丝推入工具头挤出机时，由于长丝的压力，滑块将向前移动。然后，入口处第一个霍尔传感器检测料线是否进入缓冲器，第二个滑块上方的霍尔传感器可以检测载滑块的位移和位置，并将该信号反馈回 AMS 和打印机。如果缓冲信号丢失，AMS 将无法顺利送入料线。

## 故障排除

### 检查 6-pin 线缆

检查线缆是否和AMS尾部接触良好，用手是否很容易就拔出来，建议使用二代 AMS 配套线缆，线缆区别如下:

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700_4000_0002_0001/image-8.png)

### 检查并重新连接 6-pin 线缆

通常是 6-pin 线缆问题，请检查 6-pin 线缆的引脚是否打开（如下图4pin所示）：

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700_4000_0002_0001/image.png)

### 测量电压和电阻

1. 如果您有万用表，请将料线卸载回 AMS，换头置需要测量的通道（H2D 右头为上面通道，左头为下面通道），并检查AMS缓冲器的滑块是否在中间，如下所示：

![](https://wiki.bambulab.com/h2/manual/h2d-intro/image-28.png)  
然后**测量 6 针电缆（**从 AMS 上拔下）引脚之间的电压。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700_4000_0002_0001/image-2.png)

正常电压应如下。**确保缓冲滑块回到左侧，否则电压值会有所不同。**

|  |  |
| --- | --- |
| pin-pin | 电压 |
| GND-Buffe\_A | 0.5~1.0V |
| GND-Buffe\_B | 2.8~2.3V |

**两个电压之和为3.0~3.3V（可以滑动滑块，测量不同位置电压，相加在这个范围内）。**

2. 如果测量的电压在正常范围内，则问题可能出在 AMS，请根据机型选择测量方法。

- AMS
- AMS 2 Pro
- AMS HT
