## 故障描述

下图展示了工具头摄像头、喷嘴摄像头与相关电路板的连接关系。AP板经USB-C线从TH板获取摄像头图像数据。MC板通过TH电源线为TH板及摄像头提供电源。MC板经TH信号线控制TH板上的切换芯片，选择摄像头与AP连通。

当 AP 板无法检测到摄像头信号，打印机会告警提示摄像头不在位。

![diagram.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0500_0600_0002_0002/diagram.png)

**可能的原因如下（概率从高到低）：**

- MC对工具头的电源线、信号线断开
- MC板坏了
- 摄像头信号线与TH板的连接松动
- USB-C线断开或连接不稳定
- TH板坏了
- 喷嘴摄像头坏了
- AP对MC通信线缆断开
- AP板坏了

## 故障排除

注意！请在打印机断电情况下进行线缆的拔插动作。

### 工具、设备及材料

- H2.0 内六角扳手
- H1.5 内六角扳手

### 排故措施

***用户可视情调整各排故措施的顺序。***

#### 步骤1. 重启打印机，重新发起打印

- 重新启动打印机并开始打印几次，查看是否重复触发此告警。
- 如果告警消失，则可以忽略它。
- 若依旧有此告警，跳转步骤2。

#### 步骤2. 检查工具头是否有电

- 检查工具头工作指示灯是否点亮。

![工具头灯亮.jpg](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0500_0600_0002_0002/%E5%B7%A5%E5%85%B7%E5%A4%B4%E7%81%AF%E4%BA%AE.jpg)

- 若未点亮，说明 TH 供电异常，跳转步骤3。
- 若已点亮，检查工具头摄像头和喷嘴摄像头是否同时告警显示不在位。

  - 若同时不在位，跳转步骤4。
  - 若仅喷嘴摄像头不在位，跳转步骤5。

#### 步骤3. TH 供电异常检查

- 参考[更换 H2D MC-TH 电源通讯转接线](../../maintenance/replace-toolhead-to-mc-board-cable.md)，检查 MC-TH 电源转接线接头。若松动，重新连接。若线缆存在破皮损坏，请更换；
- 若接头连接正常，打开打印机后盖，观察 MC 板灯语。(参考：[拓竹打印机 LED 指示灯灯语解释](../../../general/indicator-led-explanation.md))，并根据下表灯语组合，执行对应的维修措施。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 状态 | 维修措施 | 左上灯 | 左下灯 | 右侧灯 |
| 正常 | - | 常亮 | 慢速闪烁 | 快速闪烁 |
| 开机初始化 | - | 常亮 | 常亮 | 快速闪烁 |
| 软件问题 | 重启设备若依旧故障，换MC板 | 常亮 | 常亮 | 常亮 |
| 软件问题 | 重启设备若依旧故障，换MC板 | 常亮 | 慢速闪烁 | 常亮 |
| 软件问题 | 重启设备若依旧故障，换MC板 | 常亮 | 常亮 | 快速闪烁 |
| 供电异常 | 将除MC供电线以外的其他连接线断开，上电检查灯语是否恢复正常。若依旧异常，换MC板。 | 常亮 | 慢速闪烁 | 不亮 |
| 供电异常 | 将除MC供电线以外的其他连接线断开，上电检查灯语是否恢复正常。若依旧异常，换MC板。 | 不亮 | - | - |

如果您对灯语的判断没有信心，请录制 MC 板指示灯视频，咨询客户服务团队。

#### 步骤4. 摄像头及 AP-TH 通信异常检查

- 检查打印机屏幕热端温度是否正常显示（异常时，左右热端温度均显示为 0℃）。

![nozzle.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0500_0600_0002_0002/nozzle.png)

##### 若热端温度显示正常

- 拆解工具头，裸露 TH 接口板（参考：[更换 H2D 挤出接口板/TH 板/FPC 排线](../../maintenance/replace-H2D-TH-board.md)）
- 拔插喷嘴摄像头连接线（#6）

![20260123-100951.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0500_0600_0002_0002/20260123-100951.png)

- 重启并尝试打印
- 若依旧报错，更换喷嘴摄像头；（参考：[更换 H2D 喷嘴摄像头](../../maintenance/replace-nozzle-camera.md)）
- 若更换喷嘴摄像头后继续报错，更换 TH 板。（参考：[更换 H2D 挤出接口板/TH 板/FPC 排线](../../maintenance/replace-H2D-TH-board.md)）

##### 若热端温度显示异常

参考：[更换 H2D MC-AP 线](../../maintenance/replace-mc-ap-cable.md)

- 检查 AP-MC 信号线 AP 侧接头是否松动，可重新拔插；

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-8.png)

- 检查 AP-MC 信号线 MC 侧接头是否松动，可重新拔插；

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-7.png)

- 检查 MC-TH 信号线接头是否松动，可重新拔插，包含：MC-TH 信号线转接头，MC 板侧接头。

![](https://wiki.bambulab.com/h2/maintenance/replace-toolhead-to-mc-board-cable/image-7.png)  
![](https://wiki.bambulab.com/h2/maintenance/replace-toolhead-to-mc-board-cable/image-14.png)

#### 步骤5. AP-TH 连接检查

- 检查 USB-C 线，AP 板侧是否连接松动、破损。若松动，请重新拔插接头。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0500-0600-0002-0032/image-1_en.png)

- 若 USB-C 线破损，请更换。（参考：[更换 H2D USB-C 数据线](../../maintenance/replace-usb-c-cable.md)）
- 若拔插后故障依然存在且 USB-C 完好无损，请更换 TH 板。（参考：[更换 H2D 挤出接口板/TH 板/FPC 排线](../../maintenance/replace-H2D-TH-board.md)）
- 重启并尝试打印，若故障依旧存在，更换 AP 板。（参考：[更换 H2D AP 板](../../maintenance/replace-ap-board.md)）
