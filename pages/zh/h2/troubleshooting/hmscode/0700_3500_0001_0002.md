## 故障描述

AMS 2 Pro中配有一个湿度传感器，用于检测舱内湿度。当AMS检测到湿度传感器离线时，就会上报此错误。需要拆开AMS检查湿度传感器的连接线是否松脱或者接触不良。AMS 2 Pro的湿度传感器位置如下图所示：

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700-3500-0001-0002/image-3_cn.png)

## 故障排除

### 工具、设备及材料

H2.0内六角扳手

### AMS 2 Pro 故障隔离流程

参考AMS 2 Pro拆装视频，先松开固定AMS主框架的两个螺丝，并抬起AMS 2 Pro的主框架。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700-3500-0001-0002/image-1_cn.png)

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700-3500-0001-0002/image_cn.png)

1. 检查湿度传感器与AMS主板之间的连接线是否松脱，以及接口的pin脚是否有损坏。若pin脚没有弯曲损坏，重新插紧连接线后重试；

   ![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700-3500-0001-0002/image-2_cn.png)
2. 如果重新插紧接线后报错仍然存在，有可能是传感器本身故障了，需要更换AMS主框架（湿度传感器是点胶固定在AMS主框架上的）；
3. 如果更换湿度传感器后问题依旧，则可能是AMS主板上对应的接口损坏了，需要更换AMS主板。

如果您的 AMS 2 Pro 仍在保修期内，请在尝试以上排查步骤后联系我们售后支持团队来获取更多的帮助。

### AMS HT 故障隔离流程

首先，断开 AMS HT 6 pin 连接线和电源线。接下来，按下位于 AMS HT 背部的 PTFE 管释放按钮以解锁连接器，拔出 PTFE 管。

![](https://wiki.bambulab.com/ams-ht/motherboard/disconnect-the-tube.png)

使用 H2.0 内六角螺丝刀，移除底部的两颗螺丝（BT3x8），它们用于固定 AMS 外壳的下部。小心地将螺丝放在安全的地方，以便稍后重新组装时使用。

![](https://wiki.bambulab.com/ams-ht/motherboard/bottom-screws.png)

如下图所示，缓慢向上提起中框组件，请务必缓慢操作，内部有线缆连接。

|  |  |
| --- | --- |
|  |  |

1. 检查湿度传感器线缆插头（烘干组件中）、 AMS 主板线缆插头（下图序号5）是否松脱，以及接口的 pin 脚是否有损坏。若 pin 脚没有弯曲损坏，重新插紧连接线后重试；  
   主板插头：  
   ![ht湿度传感器.jpg](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700-3500-0001-0002/ht%E6%B9%BF%E5%BA%A6%E4%BC%A0%E6%84%9F%E5%99%A8.jpg)  
   传感器插头：  
   ![heating_unit.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0700-3500-0001-0002/heating_unit.png)
2. 如果重新插紧接线后报错仍然存在，有可能是传感器本身故障了，需要更换烘干组件；  
   请参考该WIKI完成拆装： [AMS HT 烘干组件更换指南](../../../ams-ht/maintenance/heating-unit.md).
3. 如果更换烘干组件后问题依旧，则可能是 AMS 主板上对应的接口损坏了，需要更换 AMS 主板。  
   请参考该WIKI完成拆装： [AMS HT 主板更换指南](../../../ams-ht/maintenance/disassembly-and-assembly-of-the-motherboard.md).

如果您的 AMS HT 仍在保修期内，请在尝试以上排查步骤后联系我们售后支持团队来获取更多的帮助。
