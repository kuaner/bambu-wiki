## 故障描述

滤芯切换风门霍尔传感器是检测滤芯切换风门是否运动到位的传感器，当霍尔传感器自身损坏异常或排线松动脱落，会出现此hms。

## 故障排除

### 工具、设备及材料

- H2.0 内六角扳手
- H1.5 内六角扳手
- 万用电表（可选）

### 故障隔离流程

1. 检查过滤切换风门霍尔传感器排线是否松动或脱落
2. 若排线无松动脱落，则霍尔传感器自身损坏或传感器电源异常

### 排故措施

在不同的模式下，自动排气格栅的状态不同。因此，在开始排障前请先确认自动排气格栅现在是处于开启状态还是关闭状态。

H2D 的风道系统共有三种模式，每种模式下自动排气格栅和过滤切换风门的状态如下：

- **冷却模式：**

  - 当腔体外排风扇打开时，自动排气格栅开启，过滤切换风门位于下方。

  |  |  |
  | --- | --- |

- 当腔体外排风扇关闭时，自动排气格栅关闭，过滤切换风门位于下方。

|  |  |
| --- | --- |

- **腔温保持模式：** 自动排气格栅关闭，过滤切换风门位于上方。

  |  |  |
  | --- | --- |

- **激光模式：** 自动排气格栅开启，过滤切换风门位于下方

  |  |  |
  | --- | --- |

***用户可视情调整各排故措施的顺序。***

- **检查过滤切换风门霍尔传感器排线是否松动或脱落**

  1. 检查排线霍尔传感器端的接头是否松动脱落

     拆掉滤芯
  2. 检查排线MC模块端的接头是否松动脱落
- **检查霍尔传感器电源是否正常**

  测量霍尔传感器电压，检查供电电压是否正常 3.3v
- **检查霍尔传感器自身有无损坏**

  观察霍尔传感器有无结构损坏，是否霉变、锈蚀、元器件脱落

**步骤 1：检查过滤切换风门霍尔传感器连接线是否松动**

您可以先参考这篇 Wiki 来移除打印机背板和废料滑梯：

[更换 H2D 废料滑梯](../../maintenance/replace-purge-chute.md)

然后您可以参考下图检查霍尔连接线是否正常，如果连接线有松脱，建议插紧后重试，检查是否可以恢复正常：

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-c200-0001-0002/image-1_cn.png)  
![hall-plug.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/hall-plug.png)

**步骤 2：检查霍尔传感器是否损坏**

检查霍尔传感器有无结构损坏，是否霉变、锈蚀、元器件脱落。

当霍尔传感器异常时，您需要更换右内衬上盖，您可以参阅这篇 Wiki 来更换右内衬上盖。

[更换 H2D 右内衬上盖/腔温加热组件/腔温加热循环风扇](../../maintenance/repalce-right-inner-lining.md)

**步骤 3：检查霍尔传感器电压是否正常**

拔出霍尔传感器线缆，线缆有三种颜色：

- 黑色
- 彩色
- 白色

建议使用万用表检测霍尔板的电压， 根据测量结果并参考下述说明来进行判断：

将线缆从霍尔板一侧断开连接，测量红黑线之间的电压，正常情况下红黑线之间的电压为 3.3v。

1. 如果电压不为 3.3v，则可能是线缆异常或 MC 板异常。此时您可以从 MC 板断开霍尔连接线，在 MC 板上测量接口电压，检查电压是否正常，如果电压异常则为 MC 板异常；

   ![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-c200-0001-0002/image_cn.png)
2. 如果电压正常。将霍尔连接线与霍尔板连接，测量白色和黑色之间的电压。在测量的同时使用不同磁极的磁铁靠近霍尔板，检查电压是否发生变化。如果无变化，那么可能为霍尔传感器损坏。
3. 如果上述电压均正常，我们建议您断电重启试试。如果重启之后依然有报错，您可以提交工单并上传日志。
