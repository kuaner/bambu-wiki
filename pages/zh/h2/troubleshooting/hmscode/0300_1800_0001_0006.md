## 故障描述

自动热床调平通过检测热床的平面度，并且在打印过程中进行补偿，可获得更好的首层打印效果。当自动热床调平检测到的热床平面度数据出现异常值时会自动重试，如果依旧有异常值就会报此错误。

**导致该故障的原因包括：**

- 喷嘴或热床上可能有异物未清理干净
- Z滑块附近有异物卡住
- Z轴同步带轮有异物卡住

## 故障排除

### 工具、设备及材料

镊子

### 排故措施

***用户可视情调整各排故措施的顺序。***

#### 步骤1. 检查热端喷嘴或热床上是否粘有耗材

|  |  |
| --- | --- |
|  |  |

若有耗材残留，请清理后重新调平。注意，清理热端时防止热端高温烫伤。

#### 步骤2. 检查3个Z轴滑块附近是否有异物卡住

![image-2_cn.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300_1800_0001_0006/image-2_cn.png)

若有耗材残留，请清理后重新调平。

#### 步骤3. 检查Z同步带轮是否被异物卡住

![image-2_cn.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300_1800_0001_0006/image-3_cn.png)

请小心倾斜打印机，检查底部Z同步带轮是否被异物卡住。您可以手动拖拽同步带，观察是否阻塞Z轴运动。

若有异物或阻塞，请小心清理异物。

#### 步骤4. 重试调平

- 选项一

点击“校准”、“自动热床调平”。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300_1800_0001_0006/image_cn.png)

- 选项二

重新发起打印，在“高级选项”中开启“自动热床调平”。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300_1800_0001_0006/img_v3_02jj_f4d58183-a80c-4dd5-90ac-f79b24177c8g_cn.jpg)

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300_1800_0001_0006/img_v3_02jj_e4189ceb-8cfd-4a9b-8dd0-f387883f0c7g_cn.jpg)

***若以上排故措施无法解决您的问题，请[提交工单](https://bambulab.com/zh/my/support/tickets/create?from=5)并上传打印机工作日志。***
