## 故障描述

热端散热风扇用于保持喷嘴散热翅片处的耗材冷却且坚硬。如果热端风扇速度保持较低，则喷嘴温度升高，并导致耗材过软且易堵塞在热端中。

以下是发生此 HMS 错误的可能原因：

1. 风扇叶片被异物卡住，无法自由旋转；
2. 热端散热风扇连接器安装不正确；
3. 热端散热风扇坏了；
4. TH 板坏了。

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 故障排除

### 工具、设备及材料

1. H2.0 内六角扳手
2. H1.5 内六角扳手

### 排故措施

#### 步骤 1. 检查热端风扇连接器是否松动

1. 使用 H2.0 内六角扳手移除 4 颗固定螺丝（BT3x8）；  
   ![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image.png)  
   ![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-1.png)  
   ![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-2.png)
2. 握住部件冷却风扇风道尾部，小心向下将风道取出；

|  |  |
| --- | --- |
|  |  |

3. 使用 H2.0 内六角扳手移除 4 颗固定螺丝（BT3x20 方框标记，BT2.6x8 圆圈标记），然后小心将风扇放在 x 轴上；

> 注意：风扇线缆与 TH 板连接，请勿大力扯断风扇线缆。

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-5.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-6.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-part-cooling-fan/image-15.png)

4. 撕掉插头上的醋酸胶布，观察 TH 板上的热端风扇接口，检查热端风扇连接器和 TH 板是否安装正常。

| --- | --- |
|  |  |

- 若松动，请重新安装该接口；
- 若安装正常但 HMS 错误仍未消失，请进行步骤2。

#### 步骤 2. 检查并清理热端散热风扇异物

1. 参考 Wiki: [更换热端风扇及其支架](../../maintenance/replace-cooling-fan-for-hotend.md) ，拆下热端风扇；观察风扇扇叶是否被异物卡住，手动拨风扇叶片是否转动困难；若有异物，请清理；
2. 参考 Wiki: [更换热端风扇及其支架](../../maintenance/replace-cooling-fan-for-hotend.md)，装回工具头；操作屏幕，将热端温度设置为 0℃，等待喷嘴温度降至室温后，再将喷嘴温度设置为 60℃。

|  |  |
| --- | --- |
|  |  |

3. 若热端升温后，HMS 错误仍未消失，请进行步骤 3。

#### 步骤 3. 热端散热风扇更换

1. 参考 Wiki： [更换热端风扇及其支架](../../maintenance/replace-cooling-fan-for-hotend.md)，更换热端风扇；
2. 若更换热端风扇后，HMS 错误仍未消失，请进行步骤 4。

#### 步骤 4. TH 板更换

参考 Wiki [更换挤出接口板/TH 板/FPC 排线](../../maintenance/replace-H2D-TH-board.md) ，更换 TH 板。
