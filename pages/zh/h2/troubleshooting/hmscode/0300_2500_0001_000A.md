## 故障描述

打印机进行打印的时候，如果打印任务中用到了两个喷嘴，需要确保两个喷嘴的定位完全一致，才保证良好的打印质量。当两个喷嘴的定位出现偏移，则可能导致打印的时候模型出现错位、层移问题。喷嘴偏移校准包含Z轴方向、XY轴方向偏移校准。

若喷嘴与热床之间存在异物，可能导致Z轴方向的偏移距离计算不准确，进而在后续的偏移校准过程中损坏喷嘴偏移校准传感器。因此，当系统检测到异物时，将立即停止打印任务，以确保设备安全并防止进一步损坏。

**导致该故障的原因包括：**

- 喷嘴粘料
- 热床上可能有异物未清理干净

## 故障排除

### 工具、设备及材料

镊子

### 排故措施

***用户可视情调整各排故措施的顺序。***

#### 步骤1. 检查热端喷嘴或热床上是否粘有耗材

如果发现喷嘴或热端表面粘有耗材，请先将喷嘴加热至略高于当前耗材的正常打印温度，使粘连的耗材软化。

|  |  |
| --- | --- |
| 喷嘴粘有耗材 | 热床粘有耗材 |

1. 在打印机触控屏上依次点击「控制」→「喷嘴和挤出机」，选择粘有耗材的喷嘴（左边或右边），将喷嘴温度设置为略高于当前耗材的正常打印温度。例如，使用 PLA 时，可将温度设置为约 250 ℃。

> **警告：** 清理过程中喷嘴和热端温度较高，请勿用手直接触碰，并注意防止高温耗材造成烫伤。

|  |  |
| --- | --- |
|  |  |

2. 待耗材软化后，使用镊子小心地向下撬动并移除已经软化的耗材。
3. 若热床表面粘有耗材，请使用铲刀将其移除。

![](https://public-cdn.bblmw.com/wiki/new/a2l/manual/model/a2l-accessory-models-006-overview-scraper.png)

#### 步骤2. 重试喷嘴偏移校准

- **选项一**：

  点击：「**设置**」→「**校准**」→「**喷嘴偏移校准**」  
  ![h2_calibration_zh.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-2500-0001-000a/h2_calibration_zh.png)
- **选项二**：

  重新发起打印，并在「**高级选项**」中开启「**喷嘴偏移校准**」  
  ![h2_plate_to_print_zh.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-2500-0001-000a/h2_plate_to_print_zh.png)  
  ![h2_advanced_options_zh.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-2500-0001-000a/h2_advanced_options_zh.png)

***若以上排故措施无法解决您的问题，请[提交工单](https://bambulab.com/zh/my/support/tickets/create?from=5)并上传打印机工作日志。***
