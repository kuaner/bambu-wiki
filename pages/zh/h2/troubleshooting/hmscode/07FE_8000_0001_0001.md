### **问题描述**

左热端的垂直运动由升降电机驱动。在挤出机切换过程中，若系统检测到升降电机断开连接，将触发警报。

![左热端升降过程](https://wiki.bambulab.com/h2/troubleshooting/hmscode/07fe-8000-0001-0001/output_en.gif)

![升降电机通讯线路示意](https://wiki.bambulab.com/h2/troubleshooting/hmscode/07fe-8000-0001-0001/diagram_cn.png)

**可能导致该问题的原因包括：**

- MC-TH 板连接线接头松动
- 升降电机的 FPC 与 TH 连接板之间的连接松动
- 升降电机 FPC 断裂或升降电机故障
- TH 连接板上的 FPC 连接松动
- TH 连接板故障

  

## 安全警告

> **重要提示！**
>
> 在进行任何维护工作（包括打印机电子元件和工具头线路相关操作）前，**务必先关闭打印机电源**。打印机通电时操作可能导致短路，进而损坏电子元件并引发安全隐患。
>
> 在维护或故障排查过程中，你可能需要拆卸包括热端在内的部件，此时会暴露线路和电子元件。若打印机仍处于通电状态，这些线路和元件相互接触、或接触其他金属/电子元件时可能发生短路，**这会损坏打印机电子元件并引发更多问题**。
>
> 因此，开展任何维护前必须**关闭打印机并断开电源连接**，以此防止电子元件短路或损坏，确保维护操作安全有效。若你对遵循本指南有任何疑问，建议提交[技术工单](https://bambulab.com/zh/my/support/tickets?from=5)说明问题，我们将尽快回复并提供所需协助。

  

## 故障排查

### 所需工具和材料

- H2.0 内六角扳手
- 镊子

### **故障排查流程**

![troubleshooting_diagram_cn.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/07fe-8000-0001-0001/troubleshooting_diagram_cn.png)

### **解决方案**

**你可以根据需要调整以下解决方案的执行顺序。**

### 第1步：重启设备

重启设备，检查问题是否解决。通常简单重启即可解决问题。  
若问题仍然存在，请继续执行后续排查步骤。

  

### 第2步：检查故障影响范围

检查工具头是否同时出现其他故障：

- 健康管理系统（ HMS ）警报显示工具头模块故障
- 明明耗材已插入工具头，但两个进料检测指示灯**均未亮起**，或进料指示灯闪烁。

![filament_light.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300_0900_0001_0001/filament_light.png)

  

### 第3步：手动调节堵嘴片

- 手动调节堵嘴片，排除升降机构的机械卡顿。

![手动调节堵嘴片](https://wiki.bambulab.com/h2/troubleshooting/hmscode/07fe-8000-0001-0001/image-2_en.png)

- 进入屏幕上的“喷嘴和挤出机”模块，点击左或右挤出机，重试挤出机切换操作。

![左右喷嘴切换.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300_a100_0001_0001/%E5%B7%A6%E5%8F%B3%E5%96%B7%E5%98%B4%E5%88%87%E6%8D%A2.png)

  

### 第4步：检查工具板接头

参考[Wiki - 更换AP板](../../maintenance/replace-ap-board.md)，按照**第1步和第2步**卸下 AP 板盖，检查 MC-TH 板连接线接头的卡扣是否松动：

- 断开连接线，然后重新插回。
- 确保卡扣完全卡入，接头对齐平齐。

![mc-th_connector.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300_0900_0001_0001/mc-th_connector.png)

按照此步骤[重新安装AP板盖](https://wiki.bambulab.com/zh/h2/maintenance/replace-ap-board#step-3-reinstall-the-ap-board-cover)，接通设备电源，通过屏幕界面测试升降电机功能。  
  
  
✅ 若升降电机正常工作，即可恢复打印！  
❌ 若问题仍存在，请继续排查！

  

### 第5步：检查TH板接头

按照 Wiki [拆卸H2D工具头](../../maintenance/disassemble-and-install-h2d-toolhead.md)中的**第1至5步**，卸下热端、部件冷却风扇及其风道，露出 TH 连接板。

如下图所示，检查升降电机 FPC 与 TH 连接板的连接情况：

- 轻轻拉动线路，确认连接牢固。
- 若线路可移动或看起来松动，请断开后重新连接。确保线路方向正确，卡扣完全锁紧。

|  |  |
| --- | --- |
|  |  |

检查线路完毕后，[点击此处按照工具头组装步骤操作](https://wiki.bambulab.com/zh/h2/maintenance/disassemble-and-install-h2d-toolhead#step-13-install-the-part-cooling-fan)。  
接下来进行测试：接通设备电源，通过屏幕界面测试升降电机功能。  
  
  
✅ 若升降电机正常工作，即可恢复打印！  
❌ 若问题仍存在，请继续排查！

  

### 第6步：更换升降电机

操作前请先关闭打印机电源。

- 按照 Wiki [拆卸H2D工具头](https://wiki.bambulab.com/zh/h2/maintenance/disassemble-and-install-h2d-toolhead#step-1lower-the-heatbed)中的拆卸**第1至11步**，卸下升降电机。
- 按照 Wiki [重新组装H2D工具头](https://wiki.bambulab.com/zh/h2/maintenance/disassemble-and-install-h2d-toolhead#step-7-install-the-lifting-motor-unit)中的组装**第7至14步**，安装升降电机和电子元件。

接下来进行测试：接通设备电源，通过屏幕界面测试升降电机功能。  
  
  
✅ 若升降电机正常工作，即可恢复打印！  
❌ 若问题仍存在，请继续排查！

> **注意：** 若更换了升降电机的霍尔传感器，重新组装工具头后需执行工具头位置校准。

  

### 第7步：更换TH板

**1.** 卸下旧工具头板：按照此[Wiki页面 - 更换工具头板](https://wiki.bambulab.com/zh/h2/maintenance/replace-H2D-TH-board#step-1-remove-the-part-cooling-fan-air-duct-and-the-fan)中的拆卸步骤操作。

**2.** 安装新工具头板：按照[Wiki页面 - 更换工具头板](https://wiki.bambulab.com/zh/h2/maintenance/replace-H2D-TH-board#install-the-extruder-connection-boardth-boardfpc-cable)中的组装步骤操作。  
  
  
接下来进行测试：接通设备电源，通过屏幕界面测试升降电机功能。  
  
  
✅ 若升降电机正常工作，即可恢复打印！  
❌ 若问题仍存在，请继续排查！

**若以上方案均无法解决问题，请[提交工单](https://bambulab.com/zh/my/support/tickets?from=5)并上传打印机日志文件。**
