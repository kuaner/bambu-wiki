## 故障描述

左热端通过锁扣固定在热端加热器上，并随热端升降模块上下移动。当左挤出机工作时，热端升降模块下降，靠近后部的左**挤出机涡流传感器**，并与其保持一定间隙。随着挤出力的变化，间隙也会相应变化，从而实现挤出力测量。若传感器检测到的挤出力信号频率过高，系统将触发告警，热床会轻微下降，任务终止并显示错误信息。

**可能的原因包括：**

1. 左**挤出机涡流传感器**涡流线圈与热端升降模块间隙过小
2. 左**挤出机涡流传感器**涡流线圈固定螺钉已经松脱
3. 左**挤出机涡流传感器**与TH板的连接脱落或松动
4. 左**挤出机涡流传感器**损坏

| 1‑左**挤出机涡流传感器**涡流线圈 | 2‑热端升降模块，3‑涡流线圈与升降滑块间隙 |
| --- | --- |

## 故障排除

### 工具、设备及材料

- H2.0 内六角扳手
- 普通A4（打印）纸
- 结构胶（按需）

### 排故措施

***用户可视情调整各排故措施的顺序。***

#### 步骤1. 检查**挤出机涡流传感器**涡流线圈与升降滑块间隙

1. 参考Wiki（[H2D 工具头拆装指南](../../maintenance/disassemble-and-install-h2d-toolhead.md)）中步骤1‑4，拆除部件冷却风扇风道。
2. 检查左**挤出机涡流传感器**的涡流线圈与左热端升降滑块之间的间隙。正常间隙范围：

   1. 在左挤出机处于工作位置状态下。
   2. 向间隙中插入\*\*两层普通打印纸条（总厚0.2 mm）\*\*时能轻松滑动。
   3. \*\*三层打印纸条（总厚0.3 mm）\*\*无法插入或插入后能感受到明显的摩擦。
   > 左涡流线圈和升降滑块之间的距离约为0.2 mm，A4纸对折后的厚度约为0.2 mm。

   |  |  |  |
   | --- | --- | --- |
   |  |  |  |
3. 用H2螺丝刀轻轻尝试拧动螺钉（下图2），检查螺钉是否有松动。

   ![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-2600-0001-0007/image-1_cn.png)  
   1‑两层普通A4纸 2‑线圈支架后锁螺丝

   然后将A4纸插入左涡流线圈和升降滑块之间，用手将左涡流线圈按住，用手拉动A4纸，检查A4纸是否刚好可以滑动（存在一点阻力，但比较容易取出）。

   ![插入白纸.webp](https://wiki.bambulab.com/h2/maintenance/replace-nozzle-eddy-sensor/%E6%8F%92%E5%85%A5%E7%99%BD%E7%BA%B8.webp)

   如果可以刚好滑动，再使用H2.0内六角扳手将固定螺丝拧紧。在拧紧螺丝的过程中按住左涡流线圈的手请保持稳定，避免位置发生变化。当螺丝拧紧后，将A4纸拔出。
4. 若间隙异常或螺钉松动，请按以下步骤调整：

   1. 松开螺钉，将\*\*两层普通打印纸（总厚0.25~0.3 mm）\*\*垫在涡流线圈与升降滑块之间。
   2. 向升降滑块方向推住线圈支架后，锁紧螺丝。
   3. 锁紧后拔出打印纸，用两层和三层打印纸确认间隙是否合适（参考前述间隙检查）。
   4. 最后，使用结构胶固定螺丝，防止螺钉松脱。（如未松脱，或者未频繁报错，也可以不使用胶水）
5. 若间隙正常且螺钉无松动，则继续完成以下步骤2。

#### 步骤2. 左**挤出机涡流传感器**与TH板连接松动检查

1. 参考Wiki（[H2D 工具头拆装指南](../../maintenance/disassemble-and-install-h2d-toolhead.md)）中步骤4‑5，拆除部件冷却风扇及其TH接口板，裸露TH板。
2. 检查TH板底部的左**挤出机涡流传感器**接头（下图连接器8）。

   ![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-2600-0001-0007/image_cn.png)
3. 若传感器接头与TH板连接松动，请重新安装确保接头扣合牢固。跳转步骤4测试。
4. 若无松动，则左**挤出机涡流传感器**可能损坏，请更换新的传感器模块。跳转至步骤3更换传感器模块。

#### 步骤3. 更换左涡流线圈

请参考[更换 H2D 左右涡流线圈](../../maintenance/replace-nozzle-eddy-sensor.md)。

#### 步骤4. 工具头安装与测试

1. 安装热端（部件冷却风扇及其风道可在测试完成后安装）。
2. 点击屏幕，切换至左挤出机。
3. 手动触发回中。
4. 若无报警产生，测试成功。
5. 安装部件冷却风扇及其风道。

***若以上排故措施无法解决您的问题，请[提交工单](https://bambulab.com/zh/my/support/tickets/create?from=5)并上传打印机工作日志。***
