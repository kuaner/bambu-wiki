## 故障描述

左热端通过锁扣固定在热端加热器上，并随热端升降模块上下移动。当左挤出机工作时，热端升降模块下降，靠近后部的左挤出力涡流传感器，并与其保持一定间隙。随着挤出力的变化，间隙也会相应变化，从而实现挤出力测量。若传感器检测到的挤出力信号灵敏度不足，系统将触发告警，热床会轻微下降，任务终止并显示错误信息。

可能的原因是

- 左挤出力传感器涡流线圈与升降滑块间隙异常
- 左挤出力传感器涡流线圈松脱

|  |  |
| --- | --- |
| 1-左挤出力传感器涡流线圈 | 2-热端升降模块，3-涡流线圈与升降滑块间隙 |

## 故障排除

### 工具、设备及材料

- H2.0 螺丝刀
- 普通 A4（打印）纸

### 排故措施

*用户可视情调整各排故措施的顺序。*

#### 步骤1. 检查挤出力传感器涡流线圈是否脱落

1. 参考 [更换 H2D 部件冷却风扇](../../maintenance/replace-part-cooling-fan.md)，拆除部件冷却风扇风道。
2. 手动拨动堵嘴片，将左滑块抬升，裸露左挤出力传感器涡流线圈。
   - 若线圈松动，请参考 [更换 H2D 左右涡流线圈](../../maintenance/replace-nozzle-eddy-sensor.md)，更换左涡流线圈。
   - 若线圈没有松动，跳转步骤 2。

#### 步骤2. 检查挤出力传感器涡流线圈与升降滑块间隙

1. 检查左挤出力传感器的涡流线圈与左热端升降滑块之间的间隙。正常间隙范围：

   - 在左挤出机处于工作位置状态下；
   - 向间隙中插入总厚 0.2 mm 的两层普通打印纸条（下图中箭头 1）时能轻松滑动；
   - 且三层打印纸条（总厚 0.3 mm）无法插入或插入后能感受到明显的摩擦。
2. 用 H2.0 内六角扳手尝试轻轻拧动螺钉（下图中箭头 2），检查螺钉是否有松动。

   |  |
   | --- |
   | 1 - 两层普通 A4 纸 2 - 线圈支架后锁螺丝 |
3. 若间隙异常或螺钉松动，请按以下步骤调整：

   - 松开螺钉，将三层普通打印纸（总厚 0.25~0.3 mm）垫在涡流线圈与升降滑块之间。
   - 向升降滑块方向推住线圈支架后，锁紧螺丝。
   - 锁紧后拔出打印纸，用两层和三层打印纸确认间隙是否合适（参考前述间隙检查）。
   - 最后，使用结构胶固定螺丝，防止螺钉松脱。
4. 跳转步骤 3 测试。

#### 步骤3. 工具头安装与测试

1. 安装热端（部件冷却风扇及其风道可在测试完成后安装）。
2. 点击屏幕，切换至左挤出机。
3. 手动触发回中。
4. 若无报警产生，测试成功。
5. 参考 [更换 H2D 部件冷却风扇](../../maintenance/replace-part-cooling-fan.md) 中安装部件冷却风扇及其风道。
