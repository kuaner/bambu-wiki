## 故障描述

自动排气格栅位于打印机背部，是用于将打印机腔体内部与外界隔绝或连通的风门。自动排气格栅没有按照预期打开或关闭时，会弹出此hms。

## 故障排除

### 工具、设备及材料

H2.0 内六角扳手

### 故障隔离流程

1. 如果发现自动排气格栅不能正常打开和关闭，则为自动排气格栅动作异常；
2. 如果发现自动排气格栅能正常打开和关闭，则为自动排气格栅霍尔传感器或磁铁异常

### 排故措施

在不同的模式下，自动排气格栅的状态不同。因此，在开始排障前请先确认自动排气格栅现在是处于开启状态还是关闭状态。

H2D 的风道系统共有三种模式，每种模式下自动排气格栅和过滤切换风门的状态如下：

- **冷却模式：**

  - 当腔体外排风扇打开时，自动排气格栅开启，过滤切换风门位于下方。

  |  |  |
  | --- | --- |

- 当腔体外排风扇关闭时，自动排气格栅关闭，过滤切换风门位于下方。

|  |  |
| --- | --- |

- **腔温保持模式：** 自动排气格栅关闭，过滤切换风门位于上方。

  |  |  |
  | --- | --- |

- **激光模式：** 自动排气格栅开启，过滤切换风门位于下方

  |  |  |
  | --- | --- |

**步骤 1：确认自动排气格栅当前状态**

1. 先通过开关控制外排风扇的开关，观察打印机排气格栅是否正确开关，注意检查包装胶带是否已经移除。

|  |  |
| --- | --- |

> ![lengquemoshi.png](https://wiki.bambulab.com/h2c/lengquemoshi.png)

![1_compressed.png =800x](https://public-cdn.bblmw.com/wiki/new/aether/h2s/unboxing-ams-combo-and-laser-full-combo/37_compressed.png)

> 注意需要从上向下撕。

如果后方排气格栅正常但依然报错，请取下[滤芯](../../maintenance/replace-air-filter.md)，检查滤芯背面的过滤切换风门是否被卡住；

若风门处于图示的异常位置，请向上推将其手动复位后，再次重试开启外排风扇，观察是否报错。

![wrong-filter.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/wrong-filter.png)

如果在向上推的过程中感到异常阻力，或在切换至腔温保持模式时过滤切换风门无法自动抬升，则可能是舵机故障。请按照文末指引联系技术支持，或考虑[更换舵机](../../maintenance/servomotor-replacement.md)。

如果取下滤芯后发现，开启外排风扇时，过滤切换风门的位置与下图不符，例如风门位置偏高或偏低，则可能是过滤切换风门齿轮位置异常，需要按照本教程进行调整。[校准齿轮](../../maintenance/repalce-right-inner-lining.md))。

**步骤 2：检查自动排气格栅是否有异物卡住**

为便于检查原因，您可以先参考这篇 Wiki 将打印机背板移除： [更换 H2D 背板](../../maintenance/replace-rear-panel.md)

当您确定完自动排气格栅的状态后，您可以检查 7 个自动排气格栅及齿条附近是否有异物，导致自动排气格栅无法正常开启或关闭。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-c000-0001-0001/image-5_cn.png)

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-c000-0001-0001/img_v3_02kb_c9a33089-c6dd-4fbd-b478-7f0d6b90092g_cn.jpg)

- 如果有异物则请移除，然后重试查看是否恢复正常。
- 如果自动排气格栅损坏导致损坏，您可以参考这篇 Wiki 来更换自动排气格栅： [更换 H2D 自动排气格栅](../../maintenance/replace-active-chamber-exhaust.md)

**步骤 3：检查舵机和霍尔是否正常**

为便于后续的排障，您可以先参考这篇 Wiki 来移除废料滑梯：

[更换 H2D 废料滑梯](../../maintenance/replace-purge-chute.md)

舵机连接线和霍尔连接线共用一个插头与 MC 板连接，如果在“步骤 1”的排查中自动排气格栅都是正常的，而您依然遇到以下两种问题中的一种：

- **自动排气格栅无法开启/关闭：**

您可以参考下图先检查舵机连接线是否正常，如果连接线有松脱，建议插紧后重试，检查是否可以恢复正常：

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-c000-0001-0001/image-3_cn.png)

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-c000-0001-0001/image-4_cn.png)

如果连接线插紧，但**自动排气格栅无法开启/关闭**，可能是舵机异常。您可以参考这篇 Wiki 来更换右内衬上盖： [更换 H2D 右内衬上盖/腔温加热组件/腔温加热循环风扇](../../maintenance/repalce-right-inner-lining.md)

- **自动排气格栅可以开启/关闭，但依然报错：**

您可以参考下图先检查霍尔连接线是否正常，如果连接线有松脱，建议插紧后重试，检查是否可以恢复正常。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-c000-0001-0001/image-2_cn.png)

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-c000-0001-0001/image-1_cn.png)

**磁铁**:  
![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-c000-0001-0001/image_cn.png)

同时也请检查磁铁是否掉落。如果磁铁掉落，您可以参考这篇 Wiki 将右内衬组件从打印机上取出，然后将磁铁重新贴好。

[更换 H2D 右内衬上盖/腔温加热组件/腔温加热循环风扇](../../maintenance/repalce-right-inner-lining.md)

如果霍尔链接线缆和磁铁都正常，你也可以重新安装舵机，避免舵机失步导致霍尔值异常。

安装舵机时需将**排气格栅齿条向上顶起**，并确保**排气格栅处于关闭状态**。在顶住排气格栅齿条的同时，锁入固定螺丝。

![关闭.jpg](https://wiki.bambulab.com/h2/maintenance/servomotor-replacement/%E5%85%B3%E9%97%AD.jpg)

**依次安装上下两颗固定螺丝，其中第一颗螺丝初步锁入即可，无需完全拧紧。待两颗螺丝均安装到位后，再同时均匀拧紧，** 确保舵机稳固安装并避免偏移。

|  |  |
| --- | --- |
|  |  |

> 注意：安装时需确保舵机线缆朝上布置，并**确认排气格栅处于关闭状态**。若安装位置不当，可能导致舵机失步，进而造成排气格栅无法正常开启或关闭。
