## 故障描述

过滤切换风门是用于控制打印机气体循环是否经过滤芯的风门。过滤切换风门没有按照预期打开或关闭时，会弹出此hms。

## 故障排除

### 工具、设备及材料

H2.0 内六角扳手

## 故障隔离流程

1. 如果发现过滤切换风门不能正常打开和关闭，则为过滤切换风门动作异常
2. 如果发现过滤切换风门能正常打开和关闭，则为过滤切换风门霍尔传感器或磁铁异常

在不同的模式下，过滤切换风门的状态不同。因此，在开始排障前请先确认过滤切换风门现在是处于开启状态还是关闭状态。

H2系列打印机的空气循环系统共有三种模式，每种模式下自动排气格栅和过滤切换风门的状态如下：

- **冷却模式：**

  - 当腔体外排风扇打开时，自动排气格栅开启，过滤切换风门位于下方。

  |  |  |
  | --- | --- |

- 当腔体外排风扇关闭时，自动排气格栅关闭，过滤切换风门位于下方。

|  |  |
| --- | --- |

- **腔温保持模式：** 自动排气格栅关闭，过滤切换风门位于上方。

  |  |  |
  | --- | --- |

- **激光模式：** 自动排气格栅开启，过滤切换风门位于下方

  |  |  |
  | --- | --- |

## 排故措施

***用户可视情调整各排故措施的顺序。***

- **检查过滤切换风门是否有异物卡住/舵机自身运动异常**
- **检查霍尔传感器和磁铁安装是否正常，传感器排线是否脱落**

### 步骤 1：检查过滤切换风门是否有异物卡住\*\*

为便于后续排障步骤，您可以先参考这篇 Wiki 移除活性炭滤芯盖和活性碳滤芯： [更换 H2D 活性碳滤芯盖/活性碳滤芯](../../maintenance/replace-air-filter.md)

- 您可以检查过滤切换风门附近是否有异物，导致过滤切换风门无法正常开启或关闭，也可以尝试手动上下推动过滤切换风门，以检查在推动过程中是否存在异常阻力。 如果有异物则请移除，然后重试查看是否恢复正常。  
  ![](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/%E6%9C%80%E9%A1%B6%E7%AB%AF.png)
- 如果取下滤芯后发现，开启外排风扇和腔温保持模式时，切换风门可以自动下降和抬升，但过滤切换风门的位置与上图不符，例如风门位置偏高或偏低，则可能是过滤切换风门齿轮位置异常，需要按照本教程进行调整。[校准齿轮](https://wiki.bambulab.com/zh/h2/maintenance/repalce-right-inner-lining#%E9%BD%BF%E8%BD%AE%E4%BD%8D%E7%BD%AE%E6%A0%A1%E5%87%86)。
- 若风门处于图示的特殊异常位置（过低），请向上推将其手动复位后，再次重试开启外排风扇，观察是否报错。

![wrong-filter.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/wrong-filter.png)

- 如果在向上推的过程中感到异常阻力，或在切换至腔温保持模式时过滤切换风门无法自动抬升，则可能是舵机故障。请按照文末指引联系技术支持，或考虑[更换舵机](../../maintenance/servomotor-replacement.md)。
- 如果是过滤切换风门损坏导致损坏，您可以参考这篇 Wiki 来更换过滤切换风门： [更换 H2D 右内衬上盖/腔温加热组件/腔温加热循环风扇](../../maintenance/repalce-right-inner-lining.md)

> 在腔温加热组件的备件中含有过滤切换风门，如果是过滤切换风门损坏，建议更换腔温加热组件。

### 步骤 2：检查舵机和磁铁以及霍尔板是否正常\*\*

如果在“步骤 1”的排查中过滤切换风门都是正常的，以及手动推动滤芯上下移动，未感受到异常阻力，而您依然遇到以下两种问题中的一种：

- **过滤切换风门可以开启/关闭，但依然报错。**

如果过滤切换风门可以开启/关闭，但依然报错，可能是磁铁位置或者霍尔传感器异常。

请重点关注磁铁位置是否准确，当过滤切换风门位于右内衬顶部，磁铁标红线的一端应对准右侧霍尔板的位置。

![heat.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/heat.png)

|  |  |
| --- | --- |
|  |  |
| 错误：仓温保持模式下磁铁处于非水平状态 | 正确：仓温保持模式下磁铁保持水平状态且红线朝向霍尔板 |

若磁铁方向（齿轮位置）异常，您可以参考以下内容重新校准**齿条**位置。

如前所述，当进入腔温保持模式时，自动排气格栅会关闭，过滤切换风门抬升至上方。您可以利用切换风门位于上方的位置进行齿轮校准。

|  |  |
| --- | --- |

**手动将过滤切换风门推动至最顶端，将齿条轻微上抬，断开大齿轮和切换风门齿条的联动，点击屏幕切换至“腔温保持模式”，此时，舵机和大齿轮会旋转至特定的角度，即磁铁红线朝右。**

|  |  |
| --- | --- |
|  |  |

此时松开齿条，使其与齿轮完全啮合即可完成校准。

![20250416-104051.jpg](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/20250416-104051.jpg)

![20250416-110032.webp](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/20250416-110032.webp)

- **过滤切换风门无法开启/关闭；**  
  您可以先参考这篇 Wiki 来移除打印机背板和废料滑梯：  
   [更换 H2D 废料滑梯](../../maintenance/replace-purge-chute.md)

然后可以参考下图检查舵机连接线是否正常，舵机连接线和霍尔连接共用一个插头与 MC 板连接如果连接线有松脱，建议插紧后重试，检查是否可以恢复正常：

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-c000-0001-0002/image-2_cn.png)  
![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-c000-0001-0002/image-4_cn.png)

如果连接线插紧，但**过滤切换风门无法开启/关闭**，可能是舵机异常。您可以参考这篇 Wiki 来更换右内衬上盖： [更换 H2D 右内衬上盖/腔温加热组件/腔温加热循环风扇](../../maintenance/repalce-right-inner-lining.md)

> 右内衬上盖的备件中包含了过滤切换风门相关舵机和霍尔备件。
