## 故障描述

HMS\_0300\_2900\_0001\_0001 该故障对应的功能是“运动精度校准”，它是通过视觉编码板的绝对定位来标定工具头机械运动系统的运动误差，包括畸变与回差等，从而在实际打印过程对这类运动误差进行补偿修正。在校准过程中，工具头相机对视觉编码板上图案的识别至关重要。如果不能准确识别视觉编码板上的图案，则有可能出现此报错。  
请参考：[运动精度校准](../../manual/motion-accuracy.md)

出现该HMS的场景主要有：

- 视觉编码板摆放位置有问题；
- 视觉编码板严重变形或污损；
- 工具头相机镜头有污渍；
- 外界光源太强导致拍照过曝。

## 故障排除

### 工具、设备及材料

- 清洁纸/酒精

### 检查视觉编码板

先检查视觉编码板是否有正确放置在热床上（如下图所示），确认板子位置正确没有放歪。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-2900-0001-0001/image.png)

然后检查视觉编码板上每个小方格的图案是否清晰可见。若其中有部分图案脏污，可以用酒精清洁视觉编码板图案层表面。如果编码板有明显严重破损或扭曲变形，请及时更换新的视觉编码板。

> 校准过程打印机的机箱LED灯会自动关闭，如果在这个过程中手动开启机箱的LED灯，或者在打印机箱内额外加装了补光灯，也可能会因为亮度过高，工具头相机拍照过曝从而导致校准失败。

### 检查 H2 打印机工具头相机

检查工具头相机镜头是否有污渍或者被遮挡。如果发现有，可用清洁纸轻轻擦拭，并清理镜头前异物。

![](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-2900-0001-0001/image-1.png)

若还是多次出现报错，请检查工具头相机链路是否存在松动，参考[更换 H2D 工具头摄像头](../../maintenance/replace-toolhead-camera.md)重新连接 TH 上的工具头摄像头接口（9 号接口）。

![20250711-215017.jpg](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-2900-0001-0001/20250711-215017.jpg)。

使用 H2.0 内六角扳手拧下 1 颗固定螺丝（BT2.6x8），然后从靠近前门的一侧取下 AP 板盖，再重新连接 AP 板上的 USB-C 接口。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-ap-board/image-6.png)

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-ap-board/image-8.png)

![20250711-214717.jpg](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-2900-0001-0001/20250711-214717.jpg)

### 检查 X2 打印机工具头相机

检查工具头相机镜头是否有污渍或者被遮挡。如果发现有，可用清洁纸轻轻擦拭，并清理镜头前异物。

![x2dtooheadcamera.jpg](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-2900-0001-0001/x2dtooheadcamera.jpg)

若还是多次出现报错，请检查工具头相机链路是否存在松动。

#### 检查 AP 板上的 USB-C 接口

揭开 AP 板盖检修端。

|  |  |
| --- | --- |
|  |  |

移除固定 USB-C 数据线的线夹螺丝，重新连接一次 USB-C 数据线。

![007_usbc_cable_clip_screw.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/007_usbc_cable_clip_screw.png)

#### 检查 TH 上的工具头摄像头接口

使用 H1.5 内六角扳手移除 4 颗螺丝，移除工具头后盖。  
![remove_toolhead_cover_003.png](https://public-cdn.bblmw.com/wiki/new/x2d/replace_toolhead_camera/remove_toolhead_cover_003.png)

断开右热端风扇线缆，打开工具头摄像头排线锁扣。  
![disconnect_cables.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/replace_toolhead_camera/disconnect_cables.jpg)

用镊子将排线拉出重新安装。  
![remove_toolhead_camera_fpc_001.png](https://public-cdn.bblmw.com/wiki/new/x2d/replace_toolhead_camera/remove_toolhead_camera_fpc_001.png)
