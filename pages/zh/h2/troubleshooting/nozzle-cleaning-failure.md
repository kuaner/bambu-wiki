## 故障描述

喷嘴在热床后侧擦嘴钢片上摩擦，用于清除喷嘴上的残留耗材。

|  |  |
| --- | --- |
|  |  |

### 导致该故障的原因可能是：

- 热端未正确安装
- 擦嘴钢片松动
- 擦嘴钢片变形

## 所需工具

- H2.0 六角扳手

## 故障排除

### 步骤1. 检查喷嘴是否正确安装

1. 检查热端卡扣是否如图正确扣紧（先合上左侧金属板，再压紧右侧压环）。

![20251229-120749.jpg](https://wiki.bambulab.com/h2c/troubleshoting/nozzle-cleaning-failure/20251229-120749.jpg)

2. 用手摇晃热端是否松动，若不松动则正确安装。

### 步骤2. 检查擦嘴钢片的螺栓

检查小钢片两侧螺栓是否拧紧，小钢片是否松动。

![correct_clip_011.png](https://wiki.bambulab.com/h2c/troubleshoting/nozzle-cleaning-failure/1.jpg)

### 步骤3. 检查擦嘴钢片是否变形

检查小钢片是否变形，若变形，请拆下后尝试复原或更换新的擦嘴钢片。

![correct_clip_011.png](https://wiki.bambulab.com/h2c/troubleshoting/nozzle-cleaning-failure/2.jpg)

### 步骤4. 重新校准

完成以上排查步骤后，请在打印机屏幕上点击**重新校准**。
