## 软胶钉

![20250401-174207.jpg](https://wiki.bambulab.com/h2/troubleshooting/reinstall-rubber-screws/20250401-174207.jpg)

## 适用产品型号

H2D

## 何时使用

在运输或者维护过程中可能会出现意外碰撞导致软胶钉脱落的情况，可以参考本篇指南进行处理。

## 所需工具

- 软胶钉
- H2.0 内六角螺丝刀
- 镊子（非必须）
- 10分钟

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。  
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 操作步骤

### 移除辅助部件冷却风扇

使用 H2.0 内六角扳手移除辅助部件冷却风扇底部的两颗固定螺丝（BT3x16）。

|  |  |
| --- | --- |
|  |  |

如果软胶钉未完全脱落，您可以拿住辅助部件风扇，将风扇缓慢拔下。

![](https://wiki.bambulab.com/h2/maintenance/replace-auxiliary-part-cooling-fan/image-16.png)

### 安装软胶钉

为了确保侧板和横梁留有间隙，方便软胶钉安装，移除风扇后，需要移除中间横梁和侧板的固定螺丝，并将软胶钉安装到下图所示的两个孔中。

|  |  |
| --- | --- |
|  |  |

1. 首先将**软胶钉从中间对折**，轻轻向后推侧板，插入圆孔中，此时需要向内按压，缓慢旋转。  
   ![11.webp](https://wiki.bambulab.com/h2/troubleshooting/reinstall-rubber-screws/11.webp)
2. 当软胶钉进入一部分之后，可以使用**螺丝刀辅助将其压入**。  
   ![wechat_20250401181524.webp](https://wiki.bambulab.com/h2/troubleshooting/reinstall-rubber-screws/wechat_20250401181524.webp)
3. 锁紧横梁和侧边固定螺丝。  
   ![pixpin_2025-04-01_21-44-22.png](https://wiki.bambulab.com/h2/troubleshooting/reinstall-rubber-screws/pixpin_2025-04-01_21-44-22.png)

### 安装辅助部件冷却风扇

首先需要将风扇底部孔位对齐，锁紧底部的两颗螺丝。

|  |
| --- |
|  |

然后将软胶钉对准风扇顶部孔位插入，**向后拉软胶钉使其固定风扇**。

|  |  |  |
| --- | --- | --- |
|  |  |  |

![拉紧.webp](https://wiki.bambulab.com/h2/troubleshooting/reinstall-rubber-screws/%E6%8B%89%E7%B4%A7.webp)

> **注意：在安装风扇时可能是可能会出现以下两种情况。**  
> 情况1. 若拉出较为困难可能使用镊子辅助将软胶钉拉出。
>
> ![20250402-130827.jpg](https://wiki.bambulab.com/h2/troubleshooting/reinstall-rubber-screws/20250402-130827.jpg)  
> 情况2. 软胶钉过短，无法直接穿过来，或者没有镊子这类工具，则需要更换软胶钉。

下图所示为安装正确辅助部件冷却风扇的状态。

![](https://wiki.bambulab.com/h2/maintenance/replace-auxiliary-part-cooling-fan/image-14.png)
