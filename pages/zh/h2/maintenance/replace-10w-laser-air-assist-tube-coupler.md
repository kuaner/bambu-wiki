## 气管接头

![sla002.png](https://wiki.bambulab.com/h2/maintenance/replace-laser-air-assist-tube-coupler/sla002.png)

## 需要使用的工具

- H2.0/H2.5内六角扳手
- 新的气管接头

## 拆除气管接头

### 步骤 1 移除激光模组上盖

移除上盖正面和侧面的6颗螺丝（两颗长螺丝 M2.5x26，4 颗短螺丝 M2.5x5），然后取下上盖。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 2 移除气管接头

使用H2.0的内六角扳手移除气管接头（部分10W激光模组的气管接头需要使用H2.5内六角扳手移除，2种版本随机发货，具体以您收到的机器为准）。

|  |  |
| --- | --- |
|  |  |

## 安装气管接头

### 步骤 1 使用H2.5或H2.0内六角扳手重新装回气管接头。

![](https://wiki.bambulab.com/h2/manual/10w-laser-module-regular-maintenance/image-51.png)

### 步骤 2 安装激光模组上盖

重新将连接线上的卡扣扣回外壁，用手压住卡扣防止连接线晃动。然后将上盖沿着两侧的滑槽推入，最后压紧上盖。

|  |  |
| --- | --- |
|  |  |
|  |  |

先拧入上盖侧面的2颗短螺丝（M2.5x5），然后在顶部左边螺丝孔拧入同规格的2颗短螺丝，右边螺丝孔拧入2颗长螺丝（M2.5x26）（面向LOGO LED，从前往后看），安装完成。
