## X/Y 皮带张紧器惰轮

X/Y 皮带张紧器惰轮安装在打印机的背部，使用一颗螺丝固定在 X/Y 张紧器上。

**框架惰轮的备件包含以下：**

1. 惰轮 \* 1
2. 石墨垫片 - 仅用于在框架上安装惰轮 \* 2
3. 框架惰轮轴 - 仅用于在框架上安装惰轮 \* 1
4. 张紧器惰轮轴 - 仅用于在张紧器上安装惰轮 \* 1

## 何时更换

- 皮带摩擦惰轮边缘导致异响
- 惰轮损坏

**更换 H2D X/Y 皮带张紧器惰轮所涉及的螺丝规格及数量（建议妥善保管拆下的螺丝，避免丢失）：**

| **螺丝规格** | **螺丝图片** | **用途** | **位置示意图** |  | **螺丝数量** |
| --- | --- | --- | --- | --- | --- |
| BT3x8 |  | 用于固定背板（绿色方框标记） |  |  | 12 |
| ST3x8 |  | 用于固定背板（红色圆圈标记） |  |  | 11 |
| ST3x12 |  | 用于固定料盘支架底座（黄色方框标记） |  |  | 2 |
| M3x6 |  | 用于固定 X/Y 张紧器压板和张紧器支架 |  |  | 4 |

## 移除 X/Y 张紧器惰轮

### 步骤 1：移除背板

您可以参阅该 Wiki 来移除背板：

[更换 H2D 背板](replace-rear-panel.md)

### 步骤 2：移除张紧器压板

使用 H2.0 内六角扳手移除两颗张紧器压板固定螺丝（M3x6）和两颗张紧器支架固定螺丝（M3x6）。

> 在背面共有两个张紧器惰轮（左右各一个），您仅需更换所需更换的那一个惰轮。

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/image.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/img_v3_02js_04f868ed-732b-4ca2-8029-912f0a103dbg.jpg)

### 步骤 3：取出 X/Y 皮带张紧器

用手指顶住 X/Y 皮带张紧器的左侧，然后往外推，将张紧器斜着转出。如果张紧器卡住请勿用力，避免损坏张紧器。

> 这一步需要稍微用力。

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/image-1.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/image-2.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/img_v3_02js_f80fd3f1-a67b-4601-971c-85c593c1d09g.jpg)

### 步骤 4：移除 X/Y 皮带张紧器惰轮

使用 H2.0 内六角扳手拧松惰轮轴，然后移除惰轮轴。您可以在使用 H2.0 内六角扳手拧松惰轮轴的同时，借助摩擦力将惰轮轴提起，然后取出。如果依然无法移除，则可以从张紧器底部将惰轮向上顶出。

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/image-11.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/image-10.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/image-9.png)

## 安装 X/Y 张紧器惰轮

### 步骤 1：安装 X/Y 张紧器惰轮

将新的 X/Y 张紧器惰轮放入 X/Y 张紧器中，然后插入惰轮轴，使用 H2.0 内六角扳手拧紧。

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/image-5.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/img_v3_02js_10ede885-ea65-443d-96f9-9a43775b366g.jpg)

### 步骤 2：将 X/Y 皮带张紧器装入打印机

将弹簧插入张紧器支架的轴上，然后将弹簧垂直插进打印机框架，用力往左推动张紧器，将张紧器卡入打印机。

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/image-4.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/image-19.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/img_v3_02js_4a1aab6b-20b7-4529-a25a-fb14f6e8c09g.jpg)

### 步骤 3：安装张紧器反转支架和压板

将张紧器压板对准螺丝孔位后，使用 H2.0 内六角扳手拧紧两颗压板固定螺丝（M3x6）和两颗张紧器支架固定螺丝（M3x6）。

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt-tensioner/image-23.png)

### 步骤 4：安装背板

您可以参考这篇 Wiki 来安装打印机背板：

[更换 H2D 背板](replace-rear-panel.md)

## 如何验证成功

工具头可正常移动，张紧器惰轮转动无异响，未出现皮带共振频率异常/偏低的报错即可。
