## 挤出机组件

挤出机负责从线轴中拉出耗材，并将其送入热端。耗材在热端加热熔化后，通过喷嘴挤出，生成打印模型。

挤出机需要精确控制挤出和回抽耗材长度，保证打印的模型尺寸精度和外观质量，是 3D 打印机核心部件之一。

|  |  |
| --- | --- |
|  |  |

**挤出机组件的备件包含如下：**

1. 挤出机组件（含挤出电机） \* 1
2. BT2.6x8 螺丝 \* 2
3. M2.5x8 螺丝 \* 4

## 何时更换

1. 挤出机损坏
2. 挤出电机异常

## 所需的工具和材料

1. 新的挤出机组件
2. H2.0 内六角扳手
3. 镊子

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 视频指南

## 拆解步骤

### 步骤 1：降低热床

通过屏幕下降热床，确保热端位于室温状态，关机。

|  |
| --- |
|  |

### 步骤 2：移除工具头上方的PTFE管与前面盖

捏住工具头前盖顶部的两角处，向上提起以移除工具头前盖。

|  |  |
| --- | --- |
|  |  |

以对称的方式，按住黑色外圈，解锁挤出机上方的两个气动接头，释放PTFE管。

|  |  |
| --- | --- |
|  |  |

### 步骤 3：拆除左右热端

堵嘴片位于升降连杆上，通过拨动连杆，堵嘴片会左右移动。如果您需要拆卸某个热端，而堵嘴片挡住了热端，必须先拨动堵嘴连杆，将堵嘴片移开，然后再进行拆卸，以防在拆除热端时不小心压弯堵嘴片。拨动时，堵嘴片可能因连杆倾斜限位而未能一次拨到位，这时需要粗拨动后再进行精细调整，确保堵嘴片完全到位。

|  |  |
| --- | --- |
|  |  |

在开始拆热端之前，请先按压两侧切刀进行切料，方便拆除热端。先移除未被堵嘴片堵住的热端硅胶套，解锁卡扣以取下该热端，预扣回加热组件的卡扣。

|  |  |
| --- | --- |
|  |  |
|  |  |

拨动堵嘴连杆，将堵嘴片移至另一边，拆下剩余热端的硅胶套，解锁卡扣以取下热端，预扣回加热组件的卡扣。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 4：移除部件冷却风扇风道和风扇

您可以参考这篇 Wiki 来移除部件冷却风扇风道和风扇，以便于后续移除挤出机组件：

[更换 H2D 部件冷却风扇](replace-part-cooling-fan.md)

### 步骤 5：移除挤出机组件

先解开切换电机连接线的卡扣，断开切换电机连接线。用手指扶住切换电机连接线，再解开挤出电机连接线的卡扣，并断开挤出电机连接线。

|  |  |  |
| --- | --- | --- |
|  |  |  |

使用 H2.0 内六角扳手移除六颗固定螺丝（最上方的两颗螺丝:BT2.6x8 \* 2，剩余的四颗螺丝:M2.5x8 \* 2），拧出前盖导向底部的两颗螺丝时，先按住切刀，再拧出螺丝。

由于前盖导向底部的两颗螺丝位置比较深，将螺丝完全拧松后可能会掉落在切刀和前盖导向附近。若发生这种情况，可以拆除挤出机组件后，轻轻摇晃挤出机组件将这2颗被别住的螺丝取出即可。

|  |  |
| --- | --- |
|  |  |
|  |  |

取出挤出机组件时，可以用镊子从工具头上方的缝隙中将内部的连接线压平，防止连接线弯曲而无法取出挤出机组件。然后将后方的线缆压平，并用手指往外顶挤出电机盖，以倾斜的角度将挤出机取出，避免挤出电机盖与中框发生干涉。

|  |  |
| --- | --- |
|  |  |
|  |  |

最后解开挤出霍尔连接线的卡扣，断开挤出霍尔连接线，移除挤出机组件。

|  |  |
| --- | --- |
|  |  |

将拆下来的挤出机组件放到热床上方轻轻摇晃，将内部的螺丝抖出来。然后整理并保存好所有螺丝，防止丢失。  
![](https://wiki.bambulab.com/h2/maintenance/replace-dual-extruder-unit-2/image-38.png)

## 安装步骤

### 步骤 1：安装挤出机组件

挤出机备件自带一根挤出霍尔连接线，解开卡扣，断开这根新的挤出霍尔连接线。

![](https://wiki.bambulab.com/h2/maintenance/replace-dual-extruder-unit-2/image-39.png)

在安装新挤出机组件之前，为了使切换电机连接线和挤出电机连接线能够顺利通过工具头中框，需要先调整一下两根线缆的角度。

将两根连接线的头部略微向下弯曲，后半部分则略微向上弯曲，这样将有助于连接线通过中框。

|  |  |
| --- | --- |
|  |  |

接下来开始正式安装新挤出机组件，先将原本的挤出霍尔连接线插入插座，并确保连接线上的白线处于水平状态，再扣合插座。

![](https://wiki.bambulab.com/h2/maintenance/replace-dual-extruder-unit-2/image-42.png)

安装挤出机组件时，可以用手指从中框侧面将连接线往上顶，来辅助连接线穿过中框。

![](https://wiki.bambulab.com/h2/maintenance/replace-dual-extruder-unit-2/image-43.png)

先将挤出电机连接线插入插座，确保连接线上的白线处于水平状态，再扣合插座。如果挤出电机连接线的卡扣难以扣合，可以使用六角扳手来辅助扣合插座；然后将切换电机连接线也插入插座，确保连接线上的白线处于水平状态，扣合插座。

|  |  |  |
| --- | --- | --- |
|  |  |  |

将多余的挤出霍尔连接线塞入挤出接口板和挤出主板之间的缝隙中；将挤出机左上方的挤出霍尔连接线也塞入工具头的缝隙中。

|  |  |
| --- | --- |
|  |  |

使用 H2.0 内六角扳手拧紧六颗固定螺丝（最上方的两颗螺丝:BT2.6x8 \* 2，剩余的四颗螺丝:M2.5x8 \* 2）。安装前盖导向下方的两颗螺丝时，可以按住切刀，再拧入螺丝。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 2：安装部件冷却风扇和风道

您可以参考这篇 Wiki 来安装部件冷却风扇和风道：

[更换 H2D 部件冷却风扇](replace-part-cooling-fan.md)

### 步骤 3：安装左右热端

与拆卸的操作一样，如果您需要安装某个热端，而堵嘴片挡住了热端，您需要先拨动堵嘴连杆，将堵嘴片移开，然后再进行安装，以防在安装热端时不小心压弯堵嘴片。拨动时，堵嘴片可能因连杆倾斜限位而未能一次拨到位，您需要再次拨动连杆，确保连杆尾部的磁铁吸附在磁铁支架上，确保堵嘴片完全到位。

安装右喷嘴，锁紧喷嘴卡扣并戴上硅胶套。

|  |  |
| --- | --- |
|  |  |

拨动堵嘴连杆，将堵嘴片移至另一边，然后安装左喷嘴。同样锁紧喷嘴卡扣并戴上硅胶套。

请注意，安装左热端硅胶套时，需要保证硅胶套不能倾斜，以免造成旁边的挡风片变形。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 4：安装PTFE管和前面盖

连接2根PTFE管，拖链上方的PTFE管连接到右挤出机，拖链下方的PTFE管连接到左挤出机。

![](https://wiki.bambulab.com/h2/maintenance/replace-dual-extruder-unit-2/image-58.png)

装回工具头前面盖的时候，可以先扣入挤出机下方的位置，再往后推，将前面盖安装到位。

![](https://wiki.bambulab.com/h2/maintenance/replace-dual-extruder-unit-2/image-59.png)

## 如何验证成功

连接电源并打开打印机，发起打印，检查是否可以完成打印。
