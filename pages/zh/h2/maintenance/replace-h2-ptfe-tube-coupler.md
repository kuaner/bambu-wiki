> **注意**：本页面以 H2D 机器为例。**H2C 的维护步骤完全相同**。

## 料管支架和气动接头

料管支架是安装在打印机背面，用于固定 PTFE 管。

![](https://wiki.bambulab.com/h2/maintenance/replace-h2-ptfe-tube-coupler/image-13.png)

气动接头是安装在料管支架上的气动连接器。

![image-16.png](https://wiki.bambulab.com/h2/maintenance/replace-h2-ptfe-tube-coupler/image-16.png)

**料管支架的备件包含以下：**

1. 料管支架 \* 1
2. BT3x5 螺丝 - 用于固定料管支架 \* 1

## 何时更换

- 料管支架或气动接头损坏；
- 料管支架无法固定 PTFE 管

## 所需的工具和材料

- 新的料管支架
- H2.0 内六角扳手

**更换 H2D 料管支架或气动接头所涉及的螺丝规格及数量（建议妥善保管拆下的螺丝，避免丢失）：**

| **螺丝规格** | **螺丝图片** | **位置** | **位置示意图** |  | **螺丝数量** |
| --- | --- | --- | --- | --- | --- |
| BT3x8 |  | 用于固定背板（绿色方框标记） |  |  | 12 |
| ST3x8 |  | 用于固定背板（红色圆圈标记） |  |  | 11 |
| ST3x12 |  | 用于固定料盘支架底座（黄色方框标记） |  |  | 2 |
| BT3x5 |  | 用于固定料管支架 |  |  | 1 |

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除料管支架

### 步骤 1：移除背板

您可以参考这篇 Wiki 来移除打印机背板：

[更换 H2D 背板](replace-rear-panel.md)

### 步骤 2：移除料管支架

使用 H2.0 内六角扳手移除一颗螺丝（BT3x5），然后即可取下料管支架。

![](https://wiki.bambulab.com/h2/maintenance/replace-h2-ptfe-tube-coupler/image.png)

### 步骤 3： （若气动接头损坏）从料管支架上拆除气动接头

参考下面的动图，使用铲子（或切刀）撬出气动接头。

![拆气动接头gif.gif](https://wiki.bambulab.com/h2/maintenance/replace-h2-ptfe-tube-coupler/%E6%8B%86%E6%B0%94%E5%8A%A8%E6%8E%A5%E5%A4%B4gif.gif)

## 安装料管支架

### 步骤 1：安装气动接头到料管支架上（请按需操作）

气动接头为不规则的圆形，注意对准位置后再插入新的气动接头。

![安装_对齐_2.jpg](https://wiki.bambulab.com/h2/maintenance/replace-h2-ptfe-tube-coupler/%E5%AE%89%E8%A3%85_%E5%AF%B9%E9%BD%90_2.jpg)

参考下面动图进行安装。

![安装气动接头gif.gif](https://wiki.bambulab.com/h2/maintenance/replace-h2-ptfe-tube-coupler/%E5%AE%89%E8%A3%85%E6%B0%94%E5%8A%A8%E6%8E%A5%E5%A4%B4gif.gif)

### 步骤 2：安装料管支架

将新的料管支架安装在原位，然后使用 H2.0 内六角扳手拧紧一颗固定螺丝（BT3x5）。

![](https://wiki.bambulab.com/h2/maintenance/replace-h2-ptfe-tube-coupler/img_v3_02jk_36d0c1fe-8119-4161-a3a5-38ac0e6dd76g.jpg)

![](https://wiki.bambulab.com/h2/maintenance/replace-h2-ptfe-tube-coupler/image-3.png)

### 步骤 3：安装背板

您可以参考这篇 Wiki 来安装打印机背板：

[更换 H2D 背板](replace-rear-panel.md)

## 如何验证成功

检查料管支架无晃动，可以正常固定 PTFE 管即可。
