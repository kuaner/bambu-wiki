## 何时更换

侧板玻璃开裂或损坏时。

## 所需的工具和材料

- 左/右侧板玻璃
- H2.0 内六角扳手

## 开始操作前的安全警告和机器状态

玻璃易碎，移除和安装时注意持稳，防止跌落。如果玻璃有损坏的地方，要防止伤手。

## 更换左侧板玻璃

### 拆除左侧板玻璃

- 用 H2.0 内六角扳手移除左侧板玻璃的两颗螺丝；

|  |  |
| --- | --- |
|  |  |

- 从机箱内侧推出左侧板玻璃；

![](https://wiki.bambulab.com/h2/maintenance/replace-side-glass/image-4.png)

- 用力提起左侧板玻璃。

|  |  |
| --- | --- |
|  |  |

### 安装左侧板玻璃

- 将新的左侧板玻璃对准侧板底部三个卡扣；

|  |  |
| --- | --- |
|  |  |

- 安装左侧板玻璃；

![](https://wiki.bambulab.com/h2/maintenance/replace-side-glass/image-9.png)

- 安装两颗螺丝，固定左侧板玻璃。

|  |  |
| --- | --- |
|  |  |

## 更换右侧板玻璃

### 拆除右侧板玻璃

- 移除右侧板玻璃的两颗螺丝；

|  |  |
| --- | --- |
|  |  |

- 从机箱内推出右侧板玻璃，并用力将其提起；

|  |  |
| --- | --- |
|  |  |

### 安装右侧板玻璃

- 将新的右侧板玻璃对准底部卡扣，安装右侧板玻璃；

|  |  |
| --- | --- |
|  |  |

- 用一只手从外侧扶住右侧板玻璃，安装两颗螺丝，固定右侧板玻璃。

|  |  |
| --- | --- |
|  |  |

## 如何验证完成/成功

目视检查外观，确认螺丝无浮起，侧板玻璃闭合位置正常即可。
