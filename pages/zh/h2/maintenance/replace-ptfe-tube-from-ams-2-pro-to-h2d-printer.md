## 连接 AMS 2 Pro 和 H2D 的 PTFE 管

共两根料管，分别连接 AMS 2 Pro 和 H2D，以及缓冲器和工具头。

![ptfe-ams-2-pro.jpeg](https://wiki.bambulab.com/h2/maintenance/replace-ptfe-tube-from-ams-2-pro-to-h2d-printer/ptfe-ams-2-pro.jpeg)

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，[*请联系在线技术支持**（服务时间 9:00-21:00）*](https://support.bambulab.cn/cn/im)，我们将及时回复并为您提供所需的帮助。

## 移除料管

### 移除 AMS 2 Pro 到打印机进料口的料管

- 从 AMS 背面按压料管释放按钮，解锁接头，拉出料管；

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-feeder-unit/image-11.png)

- 按压接头，拔出进料口的料管。

![screenshot-20250620-154727.png](https://wiki.bambulab.com/h2/maintenance/replace-ptfe-tube-from-ams-2-pro-to-h2d-printer/screenshot-20250620-154727.png)

### 移除缓冲器和工具头的料管

- 按住挤出机上方的气动接头黑色外圈，拔出料管；

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-6.png)

- 按住缓冲器的气动接头黑色外圈，向右推气动接头，以解锁缓冲区上下两端的气动接头；

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-5.png)

- 从卡扣中取出料管。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-10.png)

## 连接料管

### 连接 AMS 2 Pro 到打印机进料口的料管

- 从 AMS 2 Pro 后部插入料管至无法前进，拉动料管，确认其已固定；

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-feeder-unit/image-43.png)

- 将另一端插入打印机背后任意进料口，向前推送直至无法前进，在缓冲器上观察窗口看到到料管即插入到位。

|  |  |
| --- | --- |
|  |  |

### 连接缓冲器和工具头的料管

- 将料管从拖链卡扣侧面的孔中穿过；

![path.png](https://wiki.bambulab.com/h2/maintenance/replace-ptfe-tube-on-h2d-printer/path.png)

- 插入缓冲器的气动接头中；

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-257.png)

- 将料管另一头插入挤出机上方的气动接头中。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-278.png)

> 请注意，拖链上方的铁氟龙料管需要连接到右挤出机，拖链下方的铁氟龙料管需要连接到左挤出机。
