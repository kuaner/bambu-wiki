> H2D挤出主板上的风扇和涡流线圈插头采用这种小型插头设计。**拔出插头时，请用手握住插头根部，垂直于PCB面方向用力抬起以解锁插头**。切勿在水平方向用力，以免损坏插头。

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请移除打印材料，关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 拆解指引

### 步骤 1：降低热床

通过屏幕将热床调至该高度，或者手动将热床下压至该高度，以便于工具头的拆装。然后关机。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 2：拆下机箱内和机箱背面的PTFE管

捏住工具头前盖的顶部，向上提出工具头前盖。

|  |  |
| --- | --- |
|  |  |

按住黑色外圈，以解锁挤出机上方和缓冲区上下两端的两个气动接头，然后拔出左右两根铁氟龙管。缓冲器的气动接头可以向右推，以便于解锁。

|  |  |
| --- | --- |
|  |  |
|  |  |
|  |  |

然后解锁机箱背面的气动接头，移除PTFE管。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-12.png)

### 步骤 3 - 拆除左右2个热端

> 💡 **拆前须知**：
>
> - 堵嘴片位于升降连杆上，通过拨动连杆，堵嘴片会左右移动。
> - 如果您需要拆卸某个热端，而堵嘴片挡住了热端，必须先拨动堵嘴连杆，将堵嘴片移开，然后再进行拆卸，以防在拆除热端时不小心压弯堵嘴片。
> - 拨动时，堵嘴片可能因连杆倾斜限位而未能一次拨到位，这时需要粗拨动后再进行精细调整，确保堵嘴片完全到位。
>
> |  |  |
> | --- | --- |
> |  |  |

拆除未被堵嘴片堵住的热端硅胶套，解锁卡扣以取下该热端，预扣回加热组件的卡扣。

|  |  |
| --- | --- |
|  |  |
|  |  |

拨动堵嘴连杆，将堵嘴片移至另一边，拆下剩余热端的硅胶套，解锁卡扣以取下热端，预扣回加热组件的卡扣。

|  |  |
| --- | --- |
|  |  |
|  |  |

> 💡 **小贴士：** 拆除热端后，可以将内六角扳手贴到热端的磁铁处进行充磁，便于后续拆卸螺丝。
>
> ![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-18.png)

### 步骤 4 - 拆除部件冷却风扇风道

拧下部件冷却风扇风道的4颗螺丝，向下取出部件冷却风扇风道。可按图示方向，小心向下扯出风道。

|  |  |
| --- | --- |
|  |  |
|  |  |
|  |  |

### 步骤 5 - 拆除部件冷却风扇

拆除部件冷却风扇的4颗螺丝，撕掉插头的辅助胶带，拔掉插头。可将撕下的胶带留在电路板上，便于后续安装。  
**请注意，这种类型的插头应该沿插头所在平面向上小心用力推出，而不是沿着电缆方向拉出。请按照视频中的操作进行，以避免损坏插头。**

|  |  |
| --- | --- |
|  |  |
|  |  |
|  |  |

### 步骤 6 - 拔掉插头，拆除TH接口板

依次拔掉接口板上的切换电机FPC插头、TH板接口板FPC插头、右热端加热组件插头、左热端加热组件插头及其泡棉（插头位于TH主板，泡棉位于TH接口板），和升降电机FPC插头。注意，FPC线缆是被卡扣压住的，需要先解锁卡扣，再拔出FPC线缆。

|  |  |  |
| --- | --- | --- |
|  |  |  |
|  |  |

撕开左热端加热组件插头泡棉时，建议先松开插头，再从下往上撕开，这样可以保证泡棉的完整性。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-33.png)

拧下两颗螺丝，然后在接口板靠近切换电机插头的地方小心晃动，以取出TH接口板。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 7 - **拔掉TH主板的插头和拆除喷嘴摄像头**

依次拔掉TH主板上的挤出电机插头、挤出霍尔转接板插头、工具头摄像头插头、喷嘴摄像头插头、左涡流线圈插头，右涡流线圈插头和升降霍尔插头。

|  |  |  |
| --- | --- | --- |
|  |  |  |

这一步，需要使用镊子剥离工具头摄像头和喷嘴摄像头FPC排线的背胶；

|  |  |
| --- | --- |
|  |  |
|  |  |

撕掉左涡流线圈和右涡流线圈上的胶带，并拔掉左右涡流线圈的插头，断开升降电机霍尔线缆。

|  |  |  |
| --- | --- | --- |
|  |  |  |

将左热端加热组件线缆、左涡流线圈插头、右涡流线圈插头、升降电机霍尔线缆从下方的两个理线槽中取出。

|  |  |
| --- | --- |
|  |  |
|  |  |

拧下2颗喷嘴摄像头的固定螺丝，拆下喷嘴摄像头。

|  |  |
| --- | --- |
|  |  |

拧下TH板剩余2颗固定螺丝，从下方轻微抬起TH板，创造出拔掉热端风扇的操作空间，抽出热端风扇线缆，拔掉热端风扇插头。

|  |  |  |
| --- | --- | --- |
|  |  |  |

拆下工具头上最靠近拖链支架的那节拖链，从拖链中拨出约4节长度的线缆。

|  |  |
| --- | --- |
|  |  |

从上往下推动TH板，以创造更长的线缆长度，便于抽出TH板的2根线缆。抽出线缆时，可从下往上抽出。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 8 - **拆除AP理线盖，缓冲器，USB-C线缆和MC-TH线缆包**

拧下AP理线盖的1颗螺丝，拆出AP理线盖。

|  |  |
| --- | --- |
|  |  |

拔掉AP板上的USB-C线缆，并从理线槽中抽出USB-C线缆，右图方框处的理线卡扣可以打开和关闭，方便整理线缆。

|  |  |
| --- | --- |
|  |  |

压住卡扣解锁后，断开缓冲器附近的MC-TH通信和电源转换插头，拧下缓冲器的4颗螺丝，松开缓冲器，露出背面的USB-C线缆和MC-TH通信线缆。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 9 - 分离TH主板，USB-C线缆和拖链

断开拖链与上盖框的连接，可按照箭头所示的位置，先抽出拖链的上半部分，再将拖链完整拉出。

|  |  |
| --- | --- |
|  |  |

松开并取下拖链上的2个卡扣；

|  |  |  |
| --- | --- | --- |
|  |  |  |

抽出拖链中的USB-C线缆和MC-TH线缆包；这一步完成后，你将分别得到USB-C线缆，TH主板和拖链。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 10 - 拆除热端冷却风扇

确认喷嘴相机FPC排线没有粘住升降电机后盖后，借助镊子撬开升降电机后盖。

|  |  |
| --- | --- |
|  |  |

拧下热端风扇的2颗固定螺丝，这2颗螺丝位于塑料中框槽的内部，需按照图示的方向插入螺丝刀拧出，这里强烈建议使用刀头具有磁性的螺丝刀，如没有磁性，可以利用热端上的磁铁为其充磁。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-79.png)

捏住热端风扇的下部分，往后推出热端风扇。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-75.png)

### 步骤 11 - 拆除升降电机组件

拧下3颗螺丝，向后推出并拆下升降电机组件。其中最下方的1颗螺丝不易观察，位于图示FPC线缆的下方。

|  |  |
| --- | --- |
|  |  |

### 步骤 12 - 拆除挤出机组件

使用 H2.0 内六角扳手移除六颗固定螺丝（最上方的两颗螺丝:BT2.6x8 \* 2，剩余的四颗螺丝:M2.5x8 \* 2），拧出前盖导向底部的两颗螺丝时，先按住切刀，再拧出螺丝。

由于前盖导向底部的两颗螺丝位置比较深，完全拧松后可能会掉落在切刀和前盖导向附近。如果发生这种情况，可以拆除挤出机组件后，轻轻摇晃该组件以取出这两颗被卡住的螺丝。

|  |  |
| --- | --- |
|  |  |
|  |  |

取出挤出机组件时，请小心操作，避免损坏3根FPC排线。需要先压低挤出电机和切换电机的FPC排线，使之从走线槽中抽出，然后再挤压电机侧边的螺丝柱盖子，使其穿过中框。最后将挤出霍尔连接线取出。

|  |  |
| --- | --- |
|  |  |
|  |  |

将拆下来的挤出机组件放到热床上方轻轻摇晃，将内部的螺丝抖出来。然后整理并保存好所有螺丝，防止丢失。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-97.png)

### 步骤 13 - 拆除右涡流线圈

拧下2颗螺丝，整理并扶住后方线缆，拆下右涡流线圈。

|  |  |
| --- | --- |
|  |  |

### 步骤 14 - 拆除左右2个热端风扇风道

左边的热端风扇风道是被1颗螺丝固定的，右边的热端风扇风道是被2颗螺丝固定的。拧下3颗螺丝，取下左右热端风扇风道。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 15 - 拆除工具头摄像头

拆除工具头摄像头的2颗螺丝，**抽出右热端加热组件的线缆后（重要）**，取下工具头摄像头。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 16 - 拆除左右2个热端加热组件

拆除右热端加热组件的3颗螺丝，拆除右热端加热组件。

|  |  |
| --- | --- |
|  |  |

拆除挡风片和理线片共锁的2颗螺丝，再拆除左热端加热组件的4颗螺丝，取下左热端加热组件。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 17 - 拆除线轨组件

拆除工具头侧面两边皮带锁紧块的共6颗螺丝。

|  |  |
| --- | --- |
|  |  |

接下来需要拆除线轨与滑车固定的共8颗螺丝，左右2边各4颗。

这个步骤对扳手工具头的要求很高，好的工具可以极大程度提高你的拆装体验。如果你没有非常好的工具，或者你没有足够的力气拧动螺丝刀需要的扭力，建议你配合使用开箱配件盒中的L型扳手和单品备件中附送的短把板螺丝刀，并使用磁铁为板上的刀头充磁，结合本指南的建议操作，以便成功拧下这8颗螺丝。

|  |  |
| --- | --- |
|  |  |

使用镊子或扁平的工具撬开左右LED补光灯盖，可使用拇指用力，下压上盖框，使灯盖轻微变形，便于工具嵌入撬开。

|  |  |
| --- | --- |
|  |  |
|  |  |

使用螺丝刀将上盖框正中间处的泡棉戳1个小洞，将线轨滑车移至正中间处，穿入L型扳手，借助L型扳手的短边，将螺丝拧下取出。

|  |  |
| --- | --- |
|  |  |

然后拆除线轨侧面的4颗螺丝以及滑车底部的2颗螺丝。如果您发现螺丝刀无法施力，仍可借助L型螺丝刀，先松动螺丝，再借助长条形螺丝刀拧下，以免螺丝滑丝，导致更大的问题。

|  |  |
| --- | --- |
|  |  |
|  |  |

拧下线轨左右共8颗螺丝后，推动滑车，使左右2个滑车一前一后，斜着拆出线轨组件。使用美纹胶封住线轨的两边，以防滑块滚珠从两端掉落。

|  |  |
| --- | --- |
|  |  |
|  |  |

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-123.png)

## 组装指引

### 步骤 1 - 安装线轨组件

移动线轨滑车，使得左右Y轴上的2个线轨滑车一前一后。然后用手扶正滑车，使得滑车呈水平状态，将线轨依次插入至滑车中。

|  |  |
| --- | --- |
|  |  |

往前门方向推动线轨，直至推不动，利用前门处的坚硬框架限位，保证线轨呈完全水平的状态。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-140.png)

锁入线轨上方的左右各1颗螺丝，预固定住线轨。建议使用单品备件中附送的短把板螺丝刀，并使用磁铁为螺丝刀刀头充磁。

|  |  |
| --- | --- |
|  |  |
|  |  |

再依次锁入侧面的各2颗螺丝，如忘记螺丝孔位，可参考拆除时的步骤。

|  |  |
| --- | --- |
|  |  |
|  |  |

锁入线轨下方左右的各1颗螺丝，以完全锁紧线轨。

|  |  |
| --- | --- |
|  |  |

撕开线轨左右两边的防脱出美纹胶带。

|  |  |
| --- | --- |
|  |  |

对准下方的卡扣，压入安装左右2边的LED灯盖。

|  |  |
| --- | --- |
|  |  |

锁入升降滑块支架侧面两边皮带锁紧块的共6颗螺丝。由于皮带具备一定的张紧力，所以装左边3颗螺丝时，可将工具头滑到最右边，利用框架做支撑点，用力压入皮带锁紧块，同样的，装右边3颗螺丝时，可将工具头滑到最左边。

|  |  |
| --- | --- |
|  |  |

### 步骤 2 - 安装左右2个热端加热组件

根据定位柱安装理线片（理线片与左热端加热底座连接在一起），同时安装左热端加热底座，对准螺丝孔，锁紧4颗螺丝。注意底座需要安装到位，平齐且不留缝隙。若拧螺丝时不顺畅，可轻微晃动底座，或交换螺丝。

|  |  |
| --- | --- |
|  |  |

再安装挡风片，然后锁紧2颗共锁螺丝。请注意安装顺序，先安装理线片，所以理线片应该在挡风片下面。

安装右热端加热底座隔热片和底座，确保底座与上方2个黑色的限位块贴住并呈水平状态。

|  |  |
| --- | --- |
|  |  |

目视检查左右热端加热底座之间处于平行状态，再锁紧3颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 3 - 安装工具头摄像头

将右热端加热组件的线缆卡入工具头摄像头支架的理线槽中，卡入后，前后移动线缆，使得较粗的带橡胶套的线缆靠近缺口，防止将来线缆脱出。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-151.png)

利用定位孔，安装摄像头支架，对准螺丝孔后，锁入2颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 4 - 安装左右2个热端风扇风道

根据定位孔安装左热端风扇风道，对准螺丝孔后，锁入1颗螺丝。

|  |  |
| --- | --- |
|  |  |

根据定位孔安装右热端风扇风道，对准螺丝孔后，锁入2颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 5 - 安装右涡流线圈

将涡流线圈的线缆从右加热底座上方的孔洞处，穿至工具头背面。根据螺丝孔定位，安装好右涡流线圈，锁入2颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 6 - 安装挤出机组件

将挤出机组件上的挤出霍尔排线从支架上的方孔中穿至工具头背面。  
安装挤出机组件时，请小心操作，避免损坏3根FPC排线。需要先下压切换电机FPC，使排线尽量不翘起来，干扰穿线。安装到位后，会有明显的到位感，且齿轮没有突出，左右两边的限位点与塑料中框接触，锁入6颗螺丝（2个种类）。

|  |  |
| --- | --- |
|  |  |

将挤出机左上方的挤出霍尔连接线塞入工具头的缝隙中。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-178.png)

使用 H2.0 内六角扳手拧紧六颗固定螺丝（最上方的两颗螺丝:BT2.6x8 \* 2，剩余的四颗螺丝:M2.5x8 \* 2）。安装前盖导向下方的两颗螺丝时，可以按住切刀，再拧入螺丝。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 7 - 安装升降电机组件

闭合左热端加热底座卡扣，向下拉动热端使升降滑块下滑。

|  |  |
| --- | --- |
|  |  |

手动旋转升降电机的转子，使得轴承的摇臂朝下。向下拉动工具头上的升降滑块支架，使滑块空缺开槽朝下，这一步的目的是安装电机时，摇臂的轴承可以顺利嵌入支架。

|  |  |
| --- | --- |
|  |  |

拨开线缆，防止被压住，对准轴承孔位，将升降电机组件安装到工具头上。

|  |  |
| --- | --- |
|  |  |

安装到位后，可以先不锁螺丝，先手动旋转升降电机的转子，观察左热端是否正常的升降，堵嘴片是否顺利地在左右2个热端之间切换。

|  |  |
| --- | --- |
|  |  |

在确认升降功能正常后，锁入3颗螺丝。其中最下方的1颗螺丝不易观察，位于图示升降霍尔FPC的后下方。

|  |  |
| --- | --- |
|  |  |

### 步骤 8 - 安装热端散热风扇

安装热端散热风扇，将升降电机排线从风扇支架的洞中穿出。整理线缆，其他线缆全部拨开，不要被压住。装好散热风扇之后先依次确认每根线缆未被压住后，再锁入螺丝。  
从上至下，从左至右，需要依次检查的线缆包括：切换电机、挤出电机、三合一排线、工具头摄像头、喷嘴摄像头、左右涡流线圈、升降霍尔以及升降电机排线（最后一个从电机转子后方的洞中穿出）。

|  |  |
| --- | --- |
|  |  |

锁入2颗螺丝，并扣上升降电机盖。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 9 - 安装TH主板，USB-C线缆和拖链

将USB-C线缆插入到TH主板的背面，请注意，插入时，印有字母“T”的那一面一定要朝上，且需要确保插到位（往前推不动为止）

|  |  |
| --- | --- |
|  |  |

依次将USB-C线缆和MC-TH线缆卡入到工具头拖链支架中，卡入线缆时，可先从下卡入一小段，再从下往上推入。

|  |  |
| --- | --- |
|  |  |

确保TH主板没有勾住任何线缆后，从工具头上方拉2根线缆，在长度合适的位置插入热端风扇插头。焊点金属面是朝上的，从上往下压入。压入后，再用手指抹平一次，确保没有接触不良。然后将风扇排线从插座附近的缺口处藏入TH板子背面。

|  |  |  |
| --- | --- | --- |
|  |  |  |

在确保其他剩余所有的插头没有被TH板压住后，利用螺丝孔定位，装好TH板，锁入上方2颗螺丝。从上至下，从左至右，需要依次检查的线缆包括：切换电机排线、挤出电机排线、TH接口板连接线、挤出霍尔排线、工具头摄像头排线、喷嘴摄像头排线、左右涡流线圈连接线、升降霍尔排线以及升降电机排线、左右热端加热组件排线。

|  |  |
| --- | --- |
|  |  |

将USB-C线缆和MC-TH线缆卡入到拖链支架后，将这2根线缆装入到拖链中，空心结构朝前，从上下有凸点这端开始卡入。

|  |  |
| --- | --- |
|  |  |

细线在内侧，粗线在外侧，即粗线（MC-TH）压着细线（USB-C）的方式压入2根线缆。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-197.png)

往后拉住2根线缆，使工具头拖链中2根线缆处于不松不紧的状态，将拖链卡入至拖链支架上。

|  |  |
| --- | --- |
|  |  |

将第一个卡扣卡入至第8节拖链的上方 ，安装卡扣时，注意有缺口的槽在上方。

|  |  |  |
| --- | --- | --- |
|  |  |  |

再从第一个卡扣往后数10节的地方卡入第2个卡扣（第1个卡扣所在的节不算数）。

|  |  |
| --- | --- |
|  |  |

安装拖链时向左下倾斜，避开右上角的平台，将拖链另一端装在上盖框上，再将圆圈处的位置倾斜压入。装到位后可左右拉扯拖链，看是否脱出，并检查拖链末尾上下两端是否水平，且上盖框和拖链末端是否咬合在一起。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 10 - 安装**AP理线盖，缓冲器，USB-C线缆和MC-TH线缆包**

将USB-C线和MC-TH通信线沿着线槽整理好，然后重新装回缓冲器，一只手压住缓冲器防止其掉落，另一只手锁紧缓冲器的4颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

依次连接好MC-TH线缆的2个分路小插头后，将MC-TH线缆和USB-C线缆卡入理线卡扣中，闭合卡扣。

|  |  |
| --- | --- |
|  |  |

将USB-C线卡入侧面的理线扣中，并将插头插入至AP板上，字母A必须朝前，并推动USB-C至推不动为止。

|  |  |
| --- | --- |
|  |  |

整理线缆，尤其是缓冲器附近料管进出口不要被MC-TH 的2个分路插头挡住，建议将小插头藏在大插头后面。  
安装AP理线盖，先卡入后半部分，再卡入前半部分，压入到位后，对准螺丝孔，锁入1颗螺丝。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 11 - 连接TH主板上的插头和安装喷嘴摄像头

先把升降电机霍尔排线卡入小理线槽，再依次把右涡流线圈、左涡流线圈排线卡入小理线槽。将升降电机霍尔连接线插入插头，确保FPC线缆的头部完全进入插头中（白线处于水平状态，代表FPC线缆插入到位），再扣合插座。  
然后装回右涡流线圈插头，金属面朝上，对齐接口后，向下压入插头；以同样的方法装回左涡流线圈插头，并折叠多余的线长，在左右涡流线圈插头上贴回醋酸胶布。

|  |  |
| --- | --- |
|  |  |
|  |  |

插入工具头摄像头插头，完全安装到位后，记得将利用排线背面的背胶，将排线贴到热端风扇支架上。

|  |  |
| --- | --- |
|  |  |

拧入喷嘴摄像头的两颗固定螺丝，插入喷嘴摄像头插头，完全安装到位后，利用排线背面的背胶，将排线贴到电机盖上。

|  |  |
| --- | --- |
|  |  |

喷嘴摄像头，工具头摄像头以及升降电机的插头与排线有一定的相似性，这里只需要插入2个摄像头的插头，升降电机是插入到后续的挤出接口板上的。插入插头时，请不要弄错部件，以免导致上电异常甚至永久损坏。  
最后，依次插入挤出霍尔排线插头、挤出电机排线插头，同样需要确保排线头部的白线处于平行状态。挤出电机排线位于切换电机排线下方，且线长更短。

|  |  |
| --- | --- |
|  |  |

### 步骤 12 - 安装TH接口板并连接上面的插头

挤出接口板的背面有两根金属柱，将其对准TH 板上的金属孔并插入，一边轻轻晃动一边向后推，确保挤出接口板安装到位。

|  |  |
| --- | --- |
|  |  |

然后拧入挤出接口板上的两颗固定螺丝。

|  |  |
| --- | --- |
|  |  |

将侧面的挤出霍尔转接线塞进TH主板和挤出接口板的缝隙中，然后依次重新连接升降电机连接线、左热端加热组件插头、右热端加热组件插头、TH 板连接线、切换电机连接线。  
在连接升降电机、TH 板和切换电机排线时，请确保FPC线缆的头部完全进入插头中（这3根FPC的插头均有一根横线，横线处于水平表示FPC线缆插入到位），再扣合插座。最后用手指轻轻折叠一下FPC线缆。

|  |  |
| --- | --- |
|  |  |
|  |  |

在连接左右热端加热组件插头时，需要合理规划走线。将左热端加热组件线缆依次穿过下方和背面的线槽，防止线缆松散。

|  |  |
| --- | --- |
|  |  |

然后将左热端加热组件插头插入TH 板对应的接口，再将泡棉重新压紧。

|  |  |
| --- | --- |
|  |  |

连接右热端加热组件时，同样先将右热端加热组件线缆穿过背面的线槽，再将插头插入TH 板。

|  |  |
| --- | --- |
|  |  |

### 步骤 13 - 安装部件冷却风扇

金属面朝上，对齐接口后，向下压入部件冷却风扇插头，并贴回醋酸胶布。

|  |  |  |
| --- | --- | --- |
|  |  |  |

对准螺丝孔，盖回部件冷却风扇，拧入 4 颗固定螺丝。（BT3x20 方框标记，BT2.6x8 圆圈标记）。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 14 - 安装部件冷却风扇风道

左热端加热组件线缆需要安装在理线槽中，在安装风道前，先将加热组件线缆压入理线槽，避免风道压住线缆。

|  |  |
| --- | --- |
|  |  |

先安装前1/4风道，这样可以使后半部分风道更容易倾斜，从而避开喷嘴摄像头的干涉。然后抓住后半部分风道向上推入。

|  |  |
| --- | --- |
|  |  |

推入后，再分别往外掰风道的两侧，将风道的两侧卡在工具头上，然后将风道用力往上卡紧。

|  |  |  |
| --- | --- | --- |
|  |  |  |

接下来往前推入前半部分风道的顶部，使其完全贴合，不留缝隙。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-262.png)

使用 H2.0 内六角扳手拧紧四颗固定螺丝（BT3x8）。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 15 - 安装机箱内和机箱背面的PTFE管

将两根PTFE管从拖链卡扣侧面的孔中穿过，并分别插入缓冲器一侧的两个气动接头中。然后将另一端的PTFE管插入挤出机上方的两个气动接头中。  
请注意，拖链上方的PTFE管需要连接到右挤出机，拖链下方的PTFE管需要连接到左挤出机。

|  |  |
| --- | --- |
|  |  |
|  |  |

最后将机箱背面的PTFE管插入进料口。当缓冲器前方的小孔中可以看到PTFE管时，说明PTFE管连接到位。

|  |  |
| --- | --- |
|  |  |

### 步骤 16 - 安装左右2个热端及其热端硅胶套

与拆卸的操作一样，如果您需要安装某个热端，而堵嘴片挡住了热端，您需要先拨动堵嘴连杆，将堵嘴片移开，然后再进行安装，以防在安装热端时不小心压弯堵嘴片。拨动时，堵嘴片可能因连杆倾斜限位而未能一次拨到位，您需要再次拨动连杆，确保连杆尾部的磁铁吸附在磁铁支架上，确保堵嘴片完全到位。  
安装右喷嘴，锁紧喷嘴卡扣并戴上硅胶套。

|  |  |
| --- | --- |
|  |  |

拨动堵嘴连杆，将堵嘴片移至另一边，然后安装左喷嘴。同样锁紧喷嘴卡扣并戴上硅胶套。  
请注意，安装左热端硅胶套时，需要保证硅胶套不能倾斜，以免造成旁边的挡风片变形。

|  |  |  |
| --- | --- | --- |
|  |  |  |

装回工具头前面盖的时候，可以先扣入挤出机下方的位置，再往后推，将前面盖安装到位。

![](https://wiki.bambulab.com/h2/maintenance/disassemble-and-install-h2d-toolhead/image-279.png)

## 设备校准

在屏幕上通过UI控制左右挤出机的切换，观察挤出机是否正常切换，热端是否正常升降，其堵嘴片是否正常左右移动，测试通过后，再通过屏幕为左右热端分别完成一次正常的进退料动作。
