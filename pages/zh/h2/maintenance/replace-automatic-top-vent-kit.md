## 顶部自动风门套件

顶部自动风门套件是安装在打印机上框架顶部，通过一个电机来控制风门的闭合。

顶部自动风门套件的备件包含以下：

1. 顶部自动风门 \* 1
2. 摆杆 \* 1

## 何时更换

- 顶部自动风门损坏
- 摆杆断裂

## 所需的工具和材料

- 新的顶部自动风门套件
- H1.5 内六角扳手

**更换 H2D 顶部自动风门套件所涉及的螺丝规格及数量（建议妥善保管拆下的螺丝，避免丢失）：**

| **螺丝规格** | **螺丝图片** | **位置** | **位置示意图** |  | **螺丝数量** |
| --- | --- | --- | --- | --- | --- |
| BT2×12 |  | 用于固定前面盖 |  |  | 1 |

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除顶部自动风门

### 步骤 1：移除前面盖

**仅需将屏幕和前面盖一起拆下，无需再将屏幕从前面盖上取下。**

#### 视频指引

1. 使用 H1.5 内六角扳手移除一颗固定螺丝（BT2×12），然后用手拿住前面盖左侧的卡扣，将前面盖左侧顶部扣出，再将右侧顶部也扣开：

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-12.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-10.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-11.png)

2. 然后双手拇指放在前面盖底部并往上推，将前面盖卡向上推开以解锁卡扣，然后拿住前面盖右侧使前面盖微微弯曲，从右侧将前面盖右侧从右侧板下面抽出。

> 请小心抽出，避免损坏屏幕排线！

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-13.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-7.png)

3. 将前面盖的右侧从打印机抽出后，小心的从右往左翻转前面盖，露出屏幕与屏幕排线的接口，向上扣开屏幕排线的卡扣，然后将屏幕排线从线扣中取出。

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-6.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-9.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-8.png)

### 步骤 2：移除顶部自动风门

顶部自动风门共由四个卡扣扣在上框架上，并通过摆杆和电机连接。

1. 您可以先将最右侧的卡扣使用内六角扳手撬开，然后使用内六角扳手撬开最左侧的卡扣，再依次朝内取出中间两个卡扣，最后取出最右侧朝外的一个卡扣。

> 如果摆杆在更换过程中损坏，可以使用备用的摆杆。

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-1.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-3.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-5.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-4.png)

2. 当取出卡扣后，可以向左移动顶部自动风门将摆杆从顶部自动风门中取出。

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-2.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/20250211160719_rec_.gif)

### 步骤 3：移除风门电机底座(可选)

风门电机底座是固定顶部自动风门电机的基础支架。如果底座出现破损、变形或安装不牢固，可能需要更换此部件。

首先移除顶部电机保护片。

![1_compressed.png](https://wiki.bambulab.com/h2/replace-automatic-top-vent-kit/1_compressed.png)

移除电机底座顶部及正面的 3 颗固定螺丝（顶部 1 颗、正面 2 颗）。

|  |  |
| --- | --- |
|  |  |

找到底座顶部用于固定电机的 2 颗螺丝，将其移除。小心地将电机从底座上分离，注意避免拉扯线缆。

|  |  |
| --- | --- |
|  |  |

## 安装顶部自动风门

### 步骤 1：安装风门电机底座(可选)

将电机与新风门电机底座的安装孔对齐，用 2 颗螺丝将其固定，并用 H1.5 扳手拧紧。

|  |  |
| --- | --- |
|  |  |

将组装好的电机与底座安装到打印机原位置，并依次拧紧正面 2 颗与顶部 1 颗固定螺丝。

![1_compressed.png](https://wiki.bambulab.com/h2/replace-automatic-top-vent-kit/3.webp)

|  |  |
| --- | --- |
|  |  |

将电机保护片贴到对应位置，确保正确对齐。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：将顶部自动风门安装到上框中

1. 将新的摆杆先插入顶部自动风门中，然后拿住顶部自动风门，将摆杆对准电机轴，使用内六角扳手辅助将摆杆推入电机轴；

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-23.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-22.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-20.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-27.png)

2. 先将顶部自动风门中间的两个卡扣往下按，扣入卡扣中，然后依次将左侧和右侧的两个卡扣往下按，扣入上框。

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-28.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-24.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-26.png)

### 步骤 3：安装前面盖

1. 先将前面盖左侧靠近打印机左侧，将屏幕排线插入插头中，然后扣紧黑色卡扣；

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-18.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-21.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-17.png)

2. 然后拿住前面盖的右侧使其微微弯曲，将前面盖右侧也插入打印机中，然后将前面盖往下压确保卡扣都扣到位。

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-19.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-25.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-16.png)

3. 最后使用 H1.5 内六角扳手拧紧一颗固定螺丝（BT2x12）。

![](https://wiki.bambulab.com/h2/maintenance/replace-automatic-top-vent-kit/image-15.png)

## 如何验证成功

检查顶部自动风门所有卡扣以及摆杆安装到位，并且可以正常控制风门的开合。
