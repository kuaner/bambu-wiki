## 喷嘴偏移校准传感器

喷嘴偏移校准传感器安装在热床的后方。

**喷嘴偏移校准传感器的备件包含如下：**

1. 喷嘴偏移校准传感器 \* 1
2. 喷嘴偏移校准传感器连接线 \* 1
3. M2x5 - 用于固定喷嘴偏移校准传感器 \* 2

## 所需的工具和材料

- 新的喷嘴偏移校准传感器

|  |  |
| --- | --- |
| H2D 偏移传感器 | H2C 偏移传感器 |

- H1.5 内六角扳手
- H2.0 内六角扳手（仅在更换喷嘴偏移校准传感器连接线时需要）

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 更换喷嘴偏移校准传感器

### 移除喷嘴偏移校准传感器

使用 H1.5 内六角扳手移除两颗喷嘴偏移校准线圈的固定螺丝（M2x5），然后向上提起校准线圈，断开连接线。

|  |  |
| --- | --- |
|  |  |

### 安装喷嘴偏移校准传感器

将喷嘴偏移校准线圈与热床连接线连接，并使用 H1.5 内六角扳手拧紧两颗喷嘴偏移校准线圈的螺丝（M2x5）。

|  |  |
| --- | --- |
|  |  |

> 安装喷嘴偏移传感器时，务必注意方向，以防装反。请确认银色的擦嘴钢片位于左侧。

## 更换喷嘴偏移校准传感器连接线

### 移除喷嘴偏移校准传感器连接线

#### 步骤 1：移除热床

您可以参考 [更换 H2D 热床组件](replace-heatbed-unit.md)中的步骤，移除热床，并移除喷嘴偏移校准传感器。

#### 步骤 2：移除喷嘴偏移校准传感器连接线

1. 将热床翻转，使用 H2.0 内六角扳手移除线盖固定螺丝（BT3x8），热床线盖上有一个小硅胶，您可以先取出硅胶后再移除热床线盖，然后使用 H2.0 内六角扳手，移除一颗热床线扣固定螺丝（ST3x12），将热床线缆从线扣中取出，最后将套管两端的胶布撕开；

|  |  |
| --- | --- |
|  |  |

2. 将喷嘴偏移校准传感器连接线从热床的线扣中取出，由于三个线扣被挡住，您可以将线缆从两个靠近边缘的线扣中移除，再使用内六角扳手辅助将线缆从中间的线扣中取出。您可以参考下图推动套管以便于更好的取出线缆，然后将喷嘴偏移校准传感器连接线从套管中取出。

|  |  |
| --- | --- |
|  |  |

### 安装喷嘴偏移校准传感器连接线

#### 步骤 1：连接喷嘴偏移校准传感器连接线

1. 您可以参考下图先推动套管，以便于将新的连接线穿过套管。然后将线缆卡入热床的线扣中，您可以使用内六角扳手来辅助压入线缆，然后将套管两端的胶布重新贴好。

请不要使用内六角扳手大力压线缆，避免损坏。

|  |  |
| --- | --- |
|  |  |

2. 将热床线盖穿过线缆（线缆需卡在线盖的卡扣中）后并对准螺丝孔位，使用 H2.0 内六角扳手拧紧两颗热床线盖固定螺丝（BT3x8），然后将线缆扣入理线扣，并使用 H2.0 内六角扳手拧紧线扣固定螺丝（ST3x12），最后将硅胶塞装入热床理线盖上。

![](https://wiki.bambulab.com/h2/maintenance/replace-nozzle-offset-calibration-sensor///img_v3_02jv_737d158b-c7e7-4096-8b0b-2ea3c1d68fcg-1.jpg)

#### 步骤 2：安装热床

您可以参考 [更换 H2D 热床组件](replace-heatbed-unit.md)中的步骤，将热床和喷嘴偏移校准传感器重新安装。

## 如何验证成功

连接电源并打开打印机，发起打印，没有报错即可。
