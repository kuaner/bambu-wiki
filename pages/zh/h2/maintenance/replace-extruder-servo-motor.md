## 挤出电机

挤出电机安装在挤出机背面，用于驱动挤出机，完成耗材的挤出。

**挤出电机的备件包含如下：**

1. 2004 挤出电机 \* 1
2. M2.5x8 螺丝 - 用于固定挤出电机 \* 2

## 何时更换

- 挤出电机损坏

## 所需的工具和材料

1. 新的挤出机前盖
2. H2.0 内六角扳手
3. H1.5 内六角扳手
4. 镊子

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，[*请联系在线技术支持**（服务时间 9:00-21:00）*](https://support.bambulab.cn/cn/im)，我们将及时回复并为您提供所需的帮助。

## 移除 3513 挤出电机

### 步骤 1：移除挤出机

您可以参考这篇 Wiki 将挤出机从工具头上移除，以便于后续移除挤出电机：

[更换 H2D 挤出机组件](replace-dual-extruder-unit.md)

### 步骤 2：移除右切刀

将挤出机放置在桌面上，使用 H2.0 内六角扳手移除一颗右切刀刀柄固定螺丝，将右切刀刀柄和扭簧一起从挤出机上拆下。

|  |  |
| --- | --- |
|  |  |

### 步骤 3：移除挤出机前盖导向

使用 H2.0 内六角扳手移除四颗固定螺丝（方框标记：M2.5x7 \* 3；圆圈标记：BT2x6 \* 1），然后按住左切刀和挤出机前盖导向底部的滑块（以便于切刀对准切刀刀柄上的缺口），然后将挤出机前盖导向往前抽出。

|  |  |
| --- | --- |
|  |  |

### 步骤 4：移除挤出机前盖

使用 H2.0 内六角扳手移除两颗固定螺丝（M2.5x7 \* 2），然后轻微晃动，将挤出机前盖取出，然后断开前盖霍尔连接线；

> 注意：请小心拔出挤出机前盖，避免扯断线缆！

|  |  |
| --- | --- |
|  |  |

### 步骤 5：移除挤出机从动轮组件

1. 使用 H1.5 内六角扳手移除挤出机齿轮从动轮组件右侧的霍尔排线固定螺丝（BT2x5 \* 1），然后将右侧的霍尔排线断开连接；

|  |  |
| --- | --- |
|  |  |

- 使用 H2.0 内六角扳手移除两颗固定螺丝（M2.5x19x5），将挤出机齿轮从动轮取出并翻转放置在左侧，以便于移除挤出电机固定螺丝。

> 注意：
>
> 1. 左侧霍尔排线无需移除；
> 2. 翻转时请小心，避免损坏左侧霍尔排线。

|  |  |
| --- | --- |
|  |  |

### 步骤 6：移除挤出电机

使用 H2.0 内六角扳手移除两颗 3513 挤出电机固定螺丝（M2.5x8），将挤出电机从挤出机上移除。

![](https://wiki.bambulab.com/h2/maintenance/replace-extruder-servo-motor/image-22.png)

## 安装 3513 挤出电机

### 步骤 1：安装 3513 挤出电机

将新的挤出电机对准挤出机后盖上的孔位，然后使用 H2.0 内六角扳手拧紧两颗固定螺丝。

> 在翻转挤出机后盖的时候请托住挤出机齿轮和凸轮或提前移除，避免翻转后掉落。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：安装挤出机从动轮组件

1. 将挤出机从动轮组件重新扣在挤出机上，可以通过手动推动从轮杆，将从动杆底部的螺丝孔位对准挤出机后盖，并使用 H2.0 内六角扳手拧紧两颗固定螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

- 将右侧的霍尔排线插入从动轮，扣紧卡扣后使用 H1.5 内六角扳手拧紧一颗霍尔排线固定螺丝（BT2x5）。

|  |  |
| --- | --- |
|  |  |

### 步骤 3：安装挤出机前盖

将霍尔排线与挤出机前盖连接，然后将挤出机前盖扣回挤出机，然后使用 H2.0 内六角扳手拧紧两颗固定螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 4：安装挤出机前盖导向

同时按住左切刀刀柄和挤出机前盖导向底部的滑块（将切刀对准切刀刀柄上的缺口），将挤出机前盖导向装入挤出机中，然后使用 H2.0 内六角扳手拧紧四颗固定螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 5：安装右切刀

将扭簧装入挤出机中，然后将切刀和切刀刀柄一起插入挤出机，使用 H2.0 内六角扳手拧紧一颗固定螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 6：安装挤出机

您可以参考这篇 Wiki 来将挤出机重新安装到工具头上：

[更换 H2D 挤出机组件](replace-dual-extruder-unit.md)

## 如何验证成功

连接电源并打开打印机，发起打印，检查是否可以完成打印。
