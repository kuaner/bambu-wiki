> **注意**：本页面以 H2D 机器为例。**H2C 的更换步骤完全相同**。

## 切刀顶块组件

切刀顶块组件是安装在打印机腔内左右两侧，用于顶住切刀，使其切断耗材，完成换料/退料等功能。在 H2D 上有两个切刀顶块组件，两个呈手性对称。

![](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-stopper/image-14.png)

切刀顶块组件的备件分左右两个版本：

**切刀顶块组件（左）：**

1. 切刀顶块组件 - 左 \* 1
2. BT2.6x8 \* 2
3. M2.5x5 \* 2

**切刀顶块组件（右）：**

1. 切刀顶块组件 - 右 \* 1
2. BT2.6x8 \* 2
3. M2.5x5 \* 2

![](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-stopper/image-13.png)

## 何时更换

- 切刀顶块损坏

## 所需的工具和材料

- 新的切刀顶块组件
- H2.0 内六角扳手

**更换 H2D 切刀顶块所涉及的螺丝规格及数量（建议妥善保管拆下的螺丝，避免丢失）：**

| **螺丝规格** | **螺丝图片** | **位置** | **位置示意图** |  | **螺丝数量** |
| --- | --- | --- | --- | --- | --- |
| M2x5 |  | 用于固定左/右切刀顶块（绿色方框标记） |  |  | 4（左/右切刀顶块各使用 2 颗） |
| BT2x6 |  | 用于固定左/右切刀顶块（红色圆圈标记） |  |  | 4（左/右切刀顶块各使用 2 颗） |

## 移除切刀顶块

您可以使用 H2.0 内六角扳手来移除切刀顶块的四颗固定螺丝（红色圆圈标记：BT2.6x8；绿色方块标记：M2.5x5）。

> 注：左右切刀顶块的螺丝孔位均类似，上排两颗以及下排两颗。

## 安装切刀顶块

> 安装切刀顶块前，需将 X 轴整体移动到最前（靠近前门）。

将切刀顶块对准打印机上的螺丝孔位，使用 H2.0 内六角扳手拧紧四颗固定螺丝。（红色圆圈标记：BT2.6x8；蓝色方块标记：M2.5x5）。

注：左右切刀顶块的螺丝孔位均类似，上排两颗以及下排两颗。

![](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-stopper/image.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-stopper/image-1.png)

## 如何验证成功

检查切刀顶块无晃动，可正常顶切刀即可。
