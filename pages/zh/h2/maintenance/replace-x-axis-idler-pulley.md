## 套件清单

X 轴惰轮位于轴两侧，由 1 个轴承、2 个石墨垫片、1 个螺丝组成。

![list.jpg](https://wiki.bambulab.com/h2/maintenance/replace-x-axis-idler-pulley/list.jpg)

## 何时更换

- 框架惰轮出现异常噪音
- 惰轮或其轴承损坏

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请点击此处联系在线技术支持 （服务时间 9:00-21:00），我们将及时回复并为您提供所需的帮助。

## 拆卸步骤

### 步骤一：拧松张紧螺丝

张紧器固定螺丝位于背板，拧松图中标记的4个螺丝即可，**无需取下**。

|  |  |
| --- | --- |
| image.png | image2.png |

### 步骤二：移除皮带固定块

使用 H2.0 内六角扳手移除 3 颗工具头上皮带压块的螺丝（M3x8），将**右侧的皮带固定块从工具头上取出**。

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt/image-11.png)

### 步骤三：撬开补光灯盖

使用刮刀分别**撬开左右补光灯的灯盖**,取下灯盖。

|  |  |
| --- | --- |
| image2.2.png | image3.jpg |

### 步骤四：移除上惰轮

使用**附赠的长柄扳手**，刺破两侧预留孔的泡棉。

> 请勿从侧面斜向拧动螺丝，避免螺丝滑丝。

|  |  |
| --- | --- |
| image4.jpg | image5.jpg |

使用螺丝刀穿过预留孔，拧松固定螺丝。

|  |  |
| --- | --- |
| image6.jpg | image7.jpg |

取下惰轮以及石墨垫片。

|  |  |
| --- | --- |
| image1.1.jpg | image2.1.jpg |

### 步骤五：移除下惰轮

拧松固定螺丝。

|  |  |
| --- | --- |
| image10.jpg | newscrew.png |

取出惰轮以及垫片。

|  |  |
| --- | --- |
| image3.1.jpg | image4.1.jpg |

如果未损坏惰轮存在脏污，请及时清理。

![dirty.png](https://wiki.bambulab.com/h2/maintenance/replace-x-axis-idler-pulley/dirty.png)

## 安装步骤

### 步骤一：安装下惰轮

将石墨垫片放在惰轮轴承上，点涂一些润滑油或润滑脂，避免石墨垫片滑动。

|  |  |
| --- | --- |
| image12.jpg | addoil.png |

小心地将左侧下惰轮从皮带齿面塞入，右侧下惰轮从皮带光面塞入。

|  |  |
| --- | --- |
| image5.1.jpg | new.png |

拧紧固定螺丝。

|  |  |
| --- | --- |
| image16.jpg | newscrew.png |

### 步骤二：安装上惰轮：

将左惰轮从皮带光面塞入，右惰轮从皮带齿面塞入。

|  |  |
| --- | --- |
| image7.1.jpg | image8.1.jpg |

拧紧固定螺丝：

|  |  |
| --- | --- |
| image20.jpg | image21.jpg |

### 步骤三：安装皮带固定块

需要用手将皮带固定块往里推，然后使用 H2.0 内六角扳手拧紧三颗螺丝（M3x8）。建议先拧紧中间的一颗螺丝。

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt/image-24.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-xy-belt/image-22.png)

### 步骤四：安装补光灯盖

将灯盖装回后轻轻按压，确保卡扣扣合。

![led.png](https://wiki.bambulab.com/h2/maintenance/replace-x-axis-idler-pulley/led.png)

### 步骤五：拧紧张紧螺丝

来回拉动工具头，确认工具头移动顺畅后，拧紧张紧器螺丝。

| --- | --- |
| image.png | image2.png |
