## 右内衬组件

![](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/img_v3_02l5_fdfe06ec-f84e-4efa-91de-2c9b37fe3a3g.jpg)

**右内衬上盖的备件包含以下：**

1. 右内衬上盖 - 预装两个舵机和挡风片 \* 1
2. BT3x8 螺丝 \* 9

   1. 用于固定右内衬上盖和腔温加热组件（右内衬底座） \* 7
   2. 用于固定右内衬组件和打印机 \* 2
3. ST3x8 螺丝 - 用于固定右内衬组件和打印机 \* 1
4. 纳米胶 - 用于粘贴右内衬上盖和腔温加热组件（右内衬底座） \* 2

**腔温加热组件的备件包含以下：**

1. 腔温加热组件 - 加热块预装在右内衬底座上 \* 1
2. BT3x8 螺丝 - 用于固定右内衬上盖和腔温加热组件（右内衬底座） \* 7
3. 纳米胶 - 用于粘贴右内衬上盖和腔温加热组件（右内衬底座） \* 2

**腔温加热循环风扇的备件包含以下：**

1. 腔温加热循环风扇 \* 1
2. BT4x32 螺丝 - 用于固定腔温加热循环风扇 \* 4
3. 纳米胶 - 用于粘贴右内衬上盖和腔温加热组件（右内衬底座） \* 2

## 何时更换

1. 右内衬上盖和底座损坏
2. 腔温加热循环风扇异响/损坏
3. 腔温加热功能异常

## 所需的工具和材料

1. 新的备件（根据需要选择对应的备件进行更换）
2. H2.0 内六角扳手
3. 十字螺丝刀

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请点击此处联系在线技术支持 （服务时间 9:00-21:00），我们将及时回复并为您提供所需的帮助。

## 移除右内衬上盖/腔温加热组件/腔温加热循环风扇

### 步骤 1：降低热床并移除活性炭滤芯

通过屏幕来控制热床，将热床降低至打印机底部。

|  |  |  |
| --- | --- | --- |
|  |  |  |

活性碳滤芯盖与打印机右内衬之间通过卡扣固定。您可以用手拿住活性碳滤芯盖顶部，向外拉活性炭滤芯盖以解锁顶部的卡扣，然后倾斜活性碳滤芯盖并往上提将活性碳滤芯盖取出，最后将活性碳滤芯往外拉出。

> 如果活性炭滤芯比较脏，您可以带手套进行操作。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 2：移除背板\废料滑梯\AC 板理线盖

您可以参阅这篇 Wiki 来依次移除

1. 背板
2. 废料滑梯
3. AC 板理线盖

由于更换电源开关插座不涉及 AC 板的拆装，因此您可忽略更换 AC 板的步骤：

[更换 H2D AC 板/AC 板理线盖](replace-ac-board-for.md)

### 步骤 3：移除电源

为便于后续移除电源开关和右内衬底部的固定螺丝，您可以先将电源移除。

向上扣开透明的保护壳后，使用十字螺丝刀拧松电源上的连接线固定螺丝（可以不用完全移除，拧松即可），然后将线缆向下取出。然后使用 H2.0 内六角扳手移除两颗固定螺丝（BTW3x6），然后从左侧（移除螺丝这一侧）向上掰开打印机电源，然后取出。

> 需要稍微用力取出电源，先将左侧取出后即可完全取出电源。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 4：移除电源开关插座

使用 H2.0 内六角扳手移除电源开关插座的两颗固定螺丝（红色方框：ST3x8；绿色圆圈：BT3x8），将电源开关斜着从内衬中抽出，然后按下卡扣与电源安全钥匙底座断开连接；

|  |  |
| --- | --- |
|  |  |

### 步骤 5：移除线缆

1. 从 MC 板上依次断开线缆，并将线缆从左内衬的线扣中取出；

|  |  |
| --- | --- |
|  |  |

2. 从 AC 板上断开加热块的供电线（将绝缘套往后推，按下卡扣后断开连接），然后使用 H2.0 内六角扳手解锁一颗线扣固定螺丝（BT3x12），将供电线从线扣中取出。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 7：移除右内衬

1. 使用 H2.0 内六角扳手移除3颗右内衬固定螺丝（ST3x8 \* 1，BT3x8 \* 2），另一版本使用5颗螺丝固定，并将顶部的电机线和霍尔线从线槽中取出；

|  |  |  |
| --- | --- | --- |
| 三个螺丝版本 | 五个螺丝版本 | 取出线缆 |

2. 先将右内衬底部往外掰，将两卡扣取出，然后将右内衬往打印机腔内推，将右内衬从打印机上取下。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 8：分离右内衬上盖/腔温加热组件

> 在分离右内衬上盖和腔温加热组件之前，请先查看挡风片是否位于顶部！如果不是位于顶部，请先用手推动挡风片至右内衬顶部。
>
> **分离后请勿转动装了大齿轮的舵机！**

|  |  |
| --- | --- |
|  |  |

将右内衬平放，然后使用 H2.0 内六角扳手移除 7 颗固定螺丝（BT3x8）；使用内六角扳手撬除粘贴在右内衬上盖和腔温加热组件中的纳米胶；将右内衬上盖向上提起，和腔温加热组件分开。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

### 步骤 9：选择所需更换的组件

将右内衬上盖和腔温加热组件分离后，您可以根据实际情况来选择更换。

**注：在更换的过程中，请勿转动舵机！！！**

![](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/image-19.png)

#### 移除腔温加热循环风扇（可选）

将右内衬上盖翻转，然后将右内衬上盖平放，使用 H2.0 内六角扳手移除四颗固定螺丝（BT4x32），将腔温加热循环风扇取下；

![](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/image-13.png)

#### 移除腔温加热组件（可选）

当右内衬上盖和腔温加热组件分离后，您无需再进一步移除其他部件。您可以直接更换新的腔温加热组件。

#### 移除右内衬上盖（可选）

右内衬上盖的备件不包含下列这些部件，您需要依次将这些移除：

1. **移除腔温加热循环风扇：**

将右内衬上盖翻转，然后将右内衬上盖平放，使用 H2.0 内六角扳手移除四颗固定螺丝（BT4x32），将腔温加热循环风扇取下；

![](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/image-27.png)

2. **移除电源安全钥匙底座：**

使用 H2.0 内六角扳手移除两颗固定螺丝，将电源安全钥匙底座取下。

![](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/image-29.png)

3. **移除自动排气格栅**

拿住自动排气格栅的中间将其稍微弯曲，将右侧从内衬中抽出，然后再将左侧的靠外的插销取出，最后将连接在铁片上的插销抽出，即可移除自动排气格栅。然后依次将剩余的自动排气格栅移除。

|  |  |
| --- | --- |
|  |  |

4. **移除腔体外排风扇**

翻转右内衬上盖，将腔体外排风扇往外推，以解锁软螺钉。

![](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/img_v3_02kb_8836b50a-7e7b-4454-a603-927e34220a2g.jpg)

## 安装右内衬上盖/腔温加热组件/腔温加热循环风扇

### 步骤 1：选择所需更换的组件

请根据实际情况进行更换，如未更换则请跳过。

#### 安装腔温加热循环风扇（可选）

将腔温加热循环风扇对准腔温加热组件上的螺丝孔位，确保线缆位置位于右下角；然后使用 H2.0 内六角扳手拧紧四颗固定螺丝（BT4x32）。

![](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/image-25.png)

#### 安装腔温加热组件（可选）

由于腔温加热组件无需额外移除/安装其他部件，您可以直接参考“步骤 2：组装右内衬上盖和腔温加热组件”。

#### 安装右内衬上盖（可选）

您可以依次将原有的部件安装至新的右内衬上盖中：

1. **安装腔温加热循环风扇**

将腔温加热循环风扇对准腔温加热组件上的螺丝孔位，确保线缆位置位于右下角；然后使用 H2.0 内六角扳手拧紧四颗固定螺丝（BT4x32）。

![](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/image-24.png)

2. **安装电源安全钥匙底座**

将电源安全钥匙底座对准右内衬上盖的螺丝孔位，在安装时请注意方向，您可以参考下图确认好方向后再使用 H2.0 内六角扳手拧紧两颗固定螺丝。

![](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/image-28.png)

3. **安装腔体外排风扇**

您可以先将软螺钉安装至腔体外排风扇上，然后确保风扇线缆的位置位于右上角。翻转右内衬上盖，使用镊子辅助操作，将四个软螺钉依次卡入右内衬上盖中。

> 在安装软螺钉的时候，请避免碰到舵机齿轮，避免转动导致位置异常。

|  |  |  |
| --- | --- | --- |
|  |  |  |

4. **安装自动排气格栅**

将新的排气格栅左侧的插销插入铁片中，然后再将左侧靠外的插销插入内衬，最后拿住排气格栅的中间使其弯曲，将右侧的插销插入即可。依次将剩余的自动排气格栅安装上。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：组装右内衬上盖和腔温加热组件

将新的纳米胶先贴在右内衬上盖外侧，然后先**检查腔温加热组件上的挡风片是否位于顶部**，确认位于顶部后再将右内衬上盖扣入腔温加热组件中；

|  |  |  |
| --- | --- | --- |
|  |  |  |

先将贴了纳米胶的位置按紧，再使用 H2.0 内六角扳手拧紧 7 颗固定螺丝（BT3x8）。

|  |  |
| --- | --- |
|  |  |

### 步骤 3：安装右内衬组件

1. 将右内衬组件从打印机腔内斜着放入，将底部的卡扣与左内衬连接;

> 右侧板玻璃霍尔的连接线需绕到顶部，请注意避让。
>
> ![](https://wiki.bambulab.com/h2/maintenance/replace-right-inner-lining/image-47.png)

|  |  |  |
| --- | --- | --- |
|  |  |  |

2. 使用 H2.0 内六角扳手依次拧紧 3 颗固定螺丝（ST3x8 \* 1，BT3x8 \* 2），将右侧板霍尔连接线和 X/Y 电机线缆卡入右内衬顶部的线槽中。

|  |  |
| --- | --- |
|  |  |

### 步骤 4：连接线缆

1. 将线缆先卡入打印机底部的线槽中，将右内衬组件上的线缆依次连接至 MC 板，并将线缆扣入线扣中；

|  |  |  |
| --- | --- | --- |
|  |  |  |

2. 将加热块的供电线与 AC 板连接，并将线缆扣入线扣中，然后使用 H2.0 内六角扳手拧紧一颗线扣固定螺丝（BT3x12）；

|  |  |
| --- | --- |
|  |  |

### 步骤 5：安装废料滑梯和 AC 板理线盖

参考此wiki： [更换 H2D AC 板/AC 板理线盖](replace-ac-board-for.md) 安装废料滑梯和AC 板理线盖。

### 步骤 6：安装电源开关插座

将电源开关插座与电源安全钥匙开关座的线缆连接，然后将电源开关左侧先卡入打印机中，再将开关推到位，使用 H2.0 内六角扳手拧紧两颗固定螺丝（BT3x8，ST3x8）。

|  |  |
| --- | --- |
|  |  |

### 步骤 7：安装电源

将电源**右侧**先装入内衬中，再将电源左侧用力推入内衬，并使用 H2.0 内六角扳手拧紧两颗固定螺丝（BT3x6）。打开透明保护壳，使用十字螺丝刀拧紧电源上的连接线固定螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 8：安装背板

您可以参考下面的这篇 Wiki 来安装打印机背板：

[更换 H2D 背板](replace-rear-panel.md)

## 齿轮位置校准

在安装完成后需要重新校准齿轮位置，否则可能会遇到**风门不能正常的上升和下降**，此时您可以参考以下内容重新校准**齿条**位置。当过滤切换风门位于右内衬顶部，磁铁标红线的一端应对准右侧霍尔板的位置。

![heat.png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/heat.png)

|  |  |
| --- | --- |
|  |  |
| 错误：仓温保持模式下磁铁处于非水平状态 | 正确：仓温保持模式下磁铁保持水平状态且红线朝向霍尔板 |

若磁铁方向（齿轮位置）异常，您可以参考以下内容重新校准**齿条**位置。

如前所述，当进入腔温保持模式时，自动排气格栅会关闭，过滤切换风门抬升至上方。您可以利用切换风门位于上方的位置进行齿轮校准。

|  |  |
| --- | --- |

**手动将过滤切换风门推动至最顶端，将齿条轻微上抬，断开大齿轮和切换风门齿条的联动，点击屏幕切换至“腔温保持模式”，此时，舵机和大齿轮会旋转至特定的角度，即磁铁红线朝右。**

|  |  |
| --- | --- |
|  |  |

此时松开齿条，使其与齿轮完全啮合即可完成校准。

2. 打开腔体外排风扇，检查是否可以正常开启。
