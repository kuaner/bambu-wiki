## 维护频率

何时应遵循本页面的步骤？

- 当机器提示时
- 使用激光模组后
- 如果机器轴看起来有脏污、有碎屑或发出异常声音时

## 所需工具和材料

- 润滑油
- 润滑脂
- 超细纤维布
- 酒精
- H2.0 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## X 轴线轨清洁和润滑

### 第 1 步：清洁 X 轴

使用超细纤维布清洁 X 轴线轨。您也可以同时擦拭皮带。

|  |  |
| --- | --- |
|  |  |

确保清洁 X 轴的所有表面。

![](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/image-52.png)

然后，将工具头移到另一侧，露出线轨的隐藏部分并执行相同的清洁操作。

|  |  |
| --- | --- |
|  |  |

### 第 2 步：润滑 X 轴

彻底清洁 X 轴线轨表面的灰尘和碎屑后，在线轨上涂抹润滑油。确保线轨的顶部和底部都涂有润滑油。

|  |  |
| --- | --- |
|  |  |

涂抹润滑油后，左右移动工具头，使润滑油在线轨上均匀分布。

> ⚠️ 注意不要让多余的油滴到打印板上。如果有油滴到打印板上，可以在最后的打印板清洗过程中清洁。

![](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/image-46.png)

## Y 轴光杆清洁和润滑

### 第 1 步：清洁 Y 轴

使用喷有酒精的超细纤维布擦拭 Y 轴光杆。

|  |  |
| --- | --- |
|  |  |

移动工具头以清洁 Y 轴被覆盖的部分。  
![image-80.png](https://wiki.bambulab.com/h2/maintenance/image-80.png)

- 对另一根 Y 轴光杆重复清洁过程。

|  |  |
| --- | --- |
|  |  |

### 第 2 步：润滑 Y 轴

在光杆上涂抹润滑油，前后移动工具头使油均匀分布，以确保充分润滑。

|  |  |
| --- | --- |
|  |  |

使用相同方法润滑另一根 Y 轴光杆。

## Z 轴光杆和丝杆的清洁和润滑

### 第 1 步：清洁光杆和丝杆

用无纺布包裹 Z 轴光杆，上下移动擦拭，确保光杆彻底清洁。然后，使用相同的动作擦拭丝杆。

- 重复该过程清洁另外两根 Z 轴光杆和丝杆。

|  |  |
| --- | --- |
|  |  |

### 第 2 步：润滑光杆和丝杆

接下来，**在光杆上涂抹润滑油**，**在丝杆上涂抹润滑脂**。请确保不要混淆润滑油和润滑脂。

- 重复该过程润滑另外两根 Z 轴光杆和丝杆。

|  |  |
| --- | --- |
|  |  |

### 第 3 步：上下移动热床

润滑完成后，再次为打印机通电，并在打印机屏幕上控制热床上下移动。这是为了确保润滑油和润滑脂充分渗透到 Z 轴丝杆和光杆中，保证充分润滑。

|  |  |
| --- | --- |
|  |  |

- 检查光杆或丝杆上是否有多余的油或脂。
- 根据需要擦拭掉多余的油或脂。

|  |  |
| --- | --- |
|  |  |

  

## H2D/H2C 挤出机升降导轨

> H2D 和 H2C 设备需要进行该项维护，H2S可跳过。

### 第 1 步：退出耗材

如果左喷嘴或右喷嘴中装有耗材，请在继续之前完全退出。

### 第 2 步：移除工具头前盖

捏住工具头前盖的两个上角，朝自己的方向拉动，向上提起以释放卡扣，然后移除前盖。

![remove_toolhead_front_cover_wiki_h2d_maintenance.jpg](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/remove_toolhead_front_cover_wiki_h2d_maintenance.jpg)

### 第 3 步：移动堵嘴片

将堵嘴片移至右热端，**抓住连杆**将堵嘴片移开，防止在移除左热端时意外弯曲。

> ⚠️ **警告**：不要直接推动堵嘴片。堵嘴片很脆弱，用力可能导致其断裂。始终抓住后部的连杆。

移动连杆时，由于连杆的倾斜限制，堵嘴片可能无法一次到达位置。  
继续推动连杆，直到它到达最右端且无法再移动。  
此时，左喷嘴应向下移动。

![move_nozzle_flow_blocker.webp](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/move_nozzle_flow_blocker.webp)

### 第 4 步：移除左热端

首先移除热端硅胶套。如果需要，可以使用螺丝刀轻轻撬开。

![remove_silicone_sock_wiki_h2d_maintenance.jpg](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/remove_silicone_sock_wiki_h2d_maintenance.jpg)

解锁卡扣以移除热端。

> ⚠️ **危险**：触摸热端前务必检查当前温度，避免**高温烫伤！**

![open_buckle_h2d.gif](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/open_buckle_h2d.gif)

向自己方向拉动喷嘴将其移除。

![remove_left_hotend.gif](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/remove_left_hotend.gif)

### 第 5 步：移除挤出机前盖导向

拧下挤出机前盖导向的四颗螺丝（*3 颗 M2.5x7（绿色标记）；BT2x6（红色标记）*）。

> ℹ️ 某些型号没有 BT2x6（红色标记）螺丝。如果您的机器没有，可以忽略。

![remove_front_plate_screws_wiki_h2d_maintenance.jpg](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/remove_front_plate_screws_wiki_h2d_maintenance.jpg)

> 💡 **提示**：用手指向上按压黑色热端连接器。同时，按下左切刀刀柄，使其从切刀顶块附近的槽中略微松开。  
> ![how_to_remove_front_face_place_wiki_h2d_maintenance.jpg](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/how_to_remove_front_face_place_wiki_h2d_maintenance.jpg)

在按压上述点的同时，从挤出机前盖导向的右下角施加轻微的向外力将其移除。

![拆下前盖导向.webp](https://wiki.bambulab.com/h2/maintenance/replace-dual-extruder-filament-guide/%E6%8B%86%E4%B8%8B%E5%89%8D%E7%9B%96%E5%AF%BC%E5%90%91.webp)

左切刀位于挤出机前盖导向内，移除挤出机前盖导向时会一起移除。**请小心妥善存放，以防丢失。**

> **如果您不小心移除了滑块**，请确保正确安装弹簧。
>
> |  |  |
> | --- | --- |
> | Incorrect installation 不正确 | Correct installation 正确 |

### 第 6 步：清洁和润滑挤出机升降导轨

按照以下图片清洁和润滑挤出机升降导轨。

|  |  |
| --- | --- |
| **清除任何碎屑** | **在导轨两侧涂抹润滑油** |
|  |  |

### 第 7 步：安装挤出机前盖导向

左切刀需与挤出机前盖导向一同安装。确保左切刀的缺口朝上，然后将其放入挤出机前盖导向的切刀槽中。

|  |  |
| --- | --- |
|  |  |

安装挤出机前盖导向时，请持续向上按压黑色热端连接器，同时按下左切刀刀柄，调整至合适角度以便插入。

![intall_filament_guide_plate_wiki_h2d_maintenance.jpg](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/intall_filament_guide_plate_wiki_h2d_maintenance.jpg)

**这可能需要一些调整和耐心。请勿用力过猛。**  
对齐后，按压切刀刀柄两侧，用力将前盖完全压平。

![安装前盖导向.webp](https://wiki.bambulab.com/h2/maintenance/replace-dual-extruder-filament-guide/%E5%AE%89%E8%A3%85%E5%89%8D%E7%9B%96%E5%AF%BC%E5%90%91.webp)

然后，拧紧挤出机前盖导向上的四颗螺丝（*3x M2.5x7（绿色标记）；BT2x6（红色标记）*）。

![screw_the_front_plate_install_wiki_h2d_maintenance.jpg](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/screw_the_front_plate_install_wiki_h2d_maintenance.jpg)

### 第 8 步：安装左热端及硅胶套

重新安装左热端，如下所示：

|  |  |
| --- | --- |
| **将左热端放入工具头并关闭卡扣** | **带上硅胶套** |
|  |  |

**注意**：左图中卡扣锁定错误，原因是同时按下了锁扣和卡扣，导致锁扣卡在卡扣内部。因此，请确保左锁扣与喷嘴完全对齐后，再扣合右卡扣。

|  |  |
| --- | --- |
| ams_int_board_1 | pry_up_the_interface_board |

### 第 9 步：安装工具头前盖

重新安装工具头前盖时，先将其钩入挤出机下方的位置，然后向前推直到听到咔嗒声，表明安装到位。

![remove_toolhead_front_cover_wiki_h2d_maintenance.jpg](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/remove_toolhead_front_cover_wiki_h2d_maintenance.jpg)

### 第 10 步：移动左喷嘴

为机器接通电源。  
点击屏幕在左右喷嘴之间切换 3-5 次，使油脂充分渗透和扩散。

![move_nozzle_up_and_down_wiki_h2d_maintenance_zh.png](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/move_nozzle_up_and_down_wiki_h2d_maintenance_zh.png)

## 重置维护计划

完成本页所有维护步骤后，您可以重置清洁计划。下次机器需要定期清洁时，会提示警告。

- 导航至工具箱菜单，点击“**XYZ 轴清洁**”。  
  ![clean_xy_clean_schedule_zh.png](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/clean_xy_clean_schedule_zh.png)
- 点击“**完成**”，XYZ 轴清洁计划将被重置。  
  ![clean_xy_clean_schedule_complete_zh.png](https://wiki.bambulab.com/h2/maintenance/regular-cleaning-and-maintanence/xyz-and-extruder-lifting-rail-maintenance/clean_xy_clean_schedule_complete_zh.png)

### 清洁打印板

强烈建议在此阶段[清洁打印板。](../../filament-acc/acc/pei-plate-clean-guide.md)  
维护过程中，少量油或油脂可能会滴落到打印板上。  
清洁打印板有助于保持稳定的附着力和打印质量。
