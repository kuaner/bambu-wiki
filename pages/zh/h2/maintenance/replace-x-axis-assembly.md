## 工具头线轨组件

本文提供 H2D 工具头线轨组件更换的相关指引和注意事项，但不包括工具头部分的拆装。

## 何时更换

工具头线轨组件损坏或者无法按照预期工作

## 所需的工具和材料

1. 新的工具头线轨组件
2. H1.5 和 H2.0 内六角扳手、短内角扳手
3. L 型内六角扳手
4. 镊子

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，[*请联系在线技术支持**（服务时间 9:00-21:00）*](https://support.bambulab.cn/cn/im)，我们将及时回复并为您提供所需的帮助。

## 注意事项

> 步骤 8 操作极易造成螺丝滑牙，务必严格遵循教程；需将 L 型内六角扳手穿过泡棉及预留孔后再拧动拆卸，严禁从螺丝侧面斜向施力拧动。

## 拆解步骤

### 步骤 1：降低热床

通过屏幕下降热床，确保热端处于室温状态，关机。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 2：移除铁氟龙料管与前面盖

捏住工具头前盖顶部的两角处，向上提起以移除工具头前盖。

以对称的方式，按住黑色外圈，解锁挤出机上方的两个气动接头，释放铁氟龙料管。

|  |  |
| --- | --- |
|  |  |

以同样的方式，按住黑色外圈，解锁缓冲器一侧的两个气动接头。将两根铁氟龙料管从拖链上抽出，妥善保存。

|  |  |  |
| --- | --- | --- |
|  |  |  |

然后解锁打印机背面进料口处的气动接头，移除铁氟龙料管。

![](https://wiki.bambulab.com/h2/maintenance/replace-x-axis-assembly-zh/image-12.png)

### 步骤 3：拆除左右热端

使用内六角扳手辅助拆除未被堵嘴片堵住的热端硅胶套，解锁卡扣以取下该热端，并预扣回加热组件的卡扣。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

拨动堵嘴连杆，将堵嘴片移至另一边，以同样的方式拆下剩余热端的硅胶套，解锁卡扣以取下热端，预扣回加热组件的卡扣。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

拆除热端后，可以将内六角扳手贴到热端的磁铁处进行充磁，便于后续拆卸螺丝。

![](https://wiki.bambulab.com/h2/maintenance/replace-x-axis-assembly-zh/image-15.png)

### 步骤 4：移除 AP 理线盖并断开 USB-C 线缆和 MC-TH 通信线缆

拧下 AP 理线盖的1颗螺丝，拆除 AP 理线盖。

|  |  |
| --- | --- |
|  |  |

拔掉 AP 板上的 USB 插头，并从理线槽中抽出 USB-C 线缆。

|  |  |
| --- | --- |
|  |  |

MC-TH 线缆有两个插头，分别是通信插头和电源转换插头。按压卡扣解锁，并断开 MC-TH 线缆的两个插头。

> 📌 温馨提示：MC-TH 电源通讯转接线有两种版本，请根据您的实际版本参考下图断开连接。

版本一：

版本二：

|  |  |
| --- | --- |
|  |  |

拧下缓冲器的4颗螺丝，松开缓冲器，露出里面的 USB-C 线缆和 MC-TH 通信线缆。

|  |  |
| --- | --- |
|  |  |

### 步骤 5：拆除拖链

将这段拖链从卡槽中拆除，请注意先将拖链略微往下拉，使拖链右上角从卡槽中脱出后，再用力拔出整段拖链。

|  |  |
| --- | --- |
|  |  |

### 步骤 6：移除皮带

拧出皮带固定座上的 3 颗螺丝，拆除皮带固定座。

|  |  |  |
| --- | --- | --- |
|  |  |  |

用同样的方法拆除另一侧的皮带固定座。

|  |  |
| --- | --- |
|  |  |

### 步骤 7：贴无痕胶布

在工具头两侧粘贴无痕胶布，如果没有无痕胶布，可以将纸片贴在线轨上然后用透明胶粘贴。这一步的目的是限制工具头移动，防止拆除线轨时工具头直接滑出线轨。

|  |  |
| --- | --- |
|  |  |

### 步骤 8：移除线轨组件

使用镊子辅助拆除左右两侧的 LED 灯盖。

|  |  |
| --- | --- |
|  |  |

在框架中部有一个预留的孔位，使用L型内六角扳手穿过这个孔，才能完好拆除滑车顶部的这颗线轨螺丝。

以同样的方式，拆除另一侧滑车上面的线轨螺丝。

> 操作极易造成螺丝滑牙，务必严格遵循教程；需将螺丝刀穿过泡棉及预留孔后再拧动拆卸，严禁从螺丝侧面斜向施力拧动。

|  |  |  |
| --- | --- | --- |
|  |  |  |

然后拆除线轨侧面的4颗螺丝以及滑车底部的2颗螺丝。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

拆除所有螺丝后，即可移除线轨。移除线轨时先将右侧线轨脱离滑车，再将左侧线轨也脱离滑车，然后倾斜着取出线轨。

## 安装步骤

### 步骤 1：安装线轨组件和 LED 灯盖

安装新线轨组件时，先将线轨右侧插入滑车，再将线轨左侧也插入滑车。然后将线轨往前推直到无法推动，这一步的目的是利用前门立柱进行限位，保证线轨平行。

|  |  |  |
| --- | --- | --- |
|  |  |  |

为了确保线轨平行，需要将线轨推到最前面才能拧入线轨螺丝，与拆解步骤不同，线轨无法推到中间位置并使用L型内六角扳手拧入线轨螺丝。因此我们建议使用短内六角扳手直接拧入滑车上面的2颗螺丝、线轨侧面的4颗螺丝以及滑车底部的2颗螺丝。

需要注意的是，滑车顶部和底部的螺丝是细螺纹螺丝，线轨侧面的螺丝是粗螺纹螺丝，请勿混淆。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

将 LED 盖对齐打印机上框的插槽，然后向上推动，直到听到“咔嗒”声。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：移除扎带

线轨组件安装完成后，用尖嘴钳剪掉工具头两侧的扎带。

|  |  |
| --- | --- |
|  |  |

### 步骤 3：安装皮带

将皮带固定座重新装入工具头的槽中，然后拧入3颗皮带固定座螺丝。

|  |  |
| --- | --- |
|  |  |

然后将工具头推到另一侧，安装另一个皮带固定座。由于第一个皮带固定座已经装好，所产生的的应力可能会导致第二个皮带固定座难以装入。先预锁中间的那颗螺丝，不要完全拧紧。将上下两颗螺丝完全拧紧后，再重新将中间的螺丝拧紧。

|  |  |
| --- | --- |
|  |  |

### 步骤 4：安装拖链

安装拖链时，请注意较细的 USB-C 线位于内侧，较粗的 MC-TH 通信线位于外侧，然后将装有 USB-C 线缆和 MC-TH 通信线缆的拖链装入卡槽，用力压紧后再往前推，确保安装到位。

|  |  |  |
| --- | --- | --- |
|  |  |  |

部分批次线轨备件的拖链卡扣方向安装错误，如果你发现了拖链卡扣朝向内侧，请根据后续步骤进行调节。

|  |  |
| --- | --- |
|  |  |

向下按压解锁卡扣，移除拖链卡扣。然后按照正确的方向重新安装拖链卡扣。

|  |  |
| --- | --- |
|  |  |

第一个卡扣安装在第 11 节拖链上（以工具头为起始点开始计算），然后锁紧卡扣。

|  |  |
| --- | --- |
|  |  |

以同样的方式拆除并重新安装第二个卡扣，第二个卡扣安装在第 18 节拖链上。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 5：连接 USB-C 线缆和 MC-TH 通信线缆并安装AP理线盖

将 USB-C 线和 MC-TH 通信线沿着线槽整理好，然后重新装回缓冲器，一只手压住缓冲器防止其掉落，另一只手锁紧缓冲器的 4 颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

重新连接 MC-TH 线的两个插头，并将 MC-TH 线穿过理线槽。

> 📌 温馨提示：MC-TH 电源通讯转接线有两种版本，请根据您的实际版本参考下图进行连接。若线缆头不匹配，则需要**更换 MC-TH 电源通讯转接线**，请参考[这篇指南](replace-toolhead-to-mc-board-cable.md)更换。

版本一：

|  |  |  |

版本二：

|  |  |

> 将 USB-C 线穿过侧面的两个理线槽，将 USB 插头插入 A P板，**连接时需要确保字母 “A” 必须朝上**，并向前推直到推不动为止，该插头比较紧，需要用一点力往前插入。

### 步骤 6：安装铁氟龙料管和工具头前盖

安装热端，确保卡扣正常闭合，然后再安装硅胶套。

|  |  |
| --- | --- |
|  |  |

## 如何验证完成/成功

重新启动打印机并进行校准，检查是否出现错误警告。如果打印机提示皮带需要张紧，则张紧皮带。

## 可能遇到的故障

工具头摄像头和喷嘴摄像头同时报错：

- HMS\_0500-0600-0002-0001: 工具头摄像头不在位，请检测硬件连接。
- HMS\_0500-0600-0002-0002：喷嘴摄像头不在位，请检测硬件连接。

**解决方案：** 请检查 AP 板的插头（字母 A）是否插反。
