> **隐私提示**：请确保摄像头已正确安装，使摄像头视野正确朝向打印机腔体，以避免对打印区域或喷嘴的检测出现问题。

## 俯视摄像头

俯视摄像头安装在上框的内侧。俯视摄像头仅在 H2DL 产品中预装， H2D 中未预装俯视摄像头。

俯视摄像头的备件包含以下：

1. 俯视摄像头 \* 1
2. 俯视摄像头连接线 \* 1

![](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-9.png)

## 何时更换

1. 俯视摄像头损坏

## 所需的工具和材料

1. 新的俯视摄像头
2. H1.5 内六角扳手或镊子
3. H2.0 内六角扳手 - 仅在更换俯视摄像头连接线时需要

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 更换俯视摄像头

### 移除俯视摄像头

#### 步骤 1：取出俯视摄像头

俯视摄像头由卡扣固定，您可以使用 H1.5 内六角扳手或镊子撬出俯视摄像头的一侧卡扣，将其取出。

![俯视摄像头.webp](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/%E4%BF%AF%E8%A7%86%E6%91%84%E5%83%8F%E5%A4%B4.webp)

#### 步骤 2：断开俯视摄像头连接线

由于俯视摄像头连接线上方的黑色卡扣上已打胶，需要先将胶剔除，然后打开卡扣，即可抽出俯视摄像头连接线。

|  |  |
| --- | --- |
|  |  |

### 安装俯视摄像头

#### 步骤 1：连接俯视摄像头连接线

将打印机上的俯视摄像头连接线插入激光相机上的接口，并扣上黑色卡扣。

![screenshot-20250411-144655.png](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/screenshot-20250411-144655.png)

#### 步骤 2：安装俯视摄像头

用内六角扳手将 LED 排线轻轻往里塞，避免安装俯视摄像头时压坏线缆；  
![压排线](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new.png)

将俯视摄像头外壳的卡扣对准插入打印机上的凹槽，微微用力按压俯视摄像头外壳，将其插入打印机中。

## 更换俯视摄像头连接线

### 移除俯视摄像头连接线

#### 步骤 1：打开 AP 板盖

使用 H2.0 内六角板扳手移除一颗 AP 板盖固定螺丝（BT2.6×8），然后从靠近前门的一侧打开 AP 板盖。

|  |  |
| --- | --- |
|  |  |

#### 步骤 2：移除俯视摄像头

俯视摄像头由卡扣固定，您可以使用 H1.5 内六角扳手或镊子撬出俯视摄像头的一侧卡扣，将其取出。

![俯视摄像头.webp](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/%E4%BF%AF%E8%A7%86%E6%91%84%E5%83%8F%E5%A4%B4.webp)

#### 步骤 3：移除俯视摄像头连接线

将俯视摄像头连接线从 AP 板上断开连接，然后从上框中将其撕下，并与俯视摄像头断开连接。

|  |  |
| --- | --- |
|  |  |

### 安装俯视摄像头连接线

#### 步骤 1：连接俯视摄像头与摄像头连接线

1. 将连接线没有印有 AP 字样的一端与俯视摄像头连接；

![screenshot-20250411-144655.png](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/screenshot-20250411-144655.png)

2. 用内六角扳手将 LED 排线轻轻往里塞，避免安装俯视摄像头时压坏线缆；

![压排线](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new.png)  
3. 安装俯视摄像头，将俯视摄像头外壳的左右两个卡扣对准打印机上的两个小凹槽；

|  |  |
| --- | --- |
|  |  |

4. 向上稍用力按压摄像头外壳，听到“咔”的一声，即为安装到位。

![](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new_(3).png)

5. 用无纺布擦拭镜头，清除灰尘。

![](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new_(14).png)

#### 步骤 2：粘贴俯视摄像头连接线

1. 移除一颗 AP 板盖固定螺丝；

![](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new_(11).png)  
2. 打开 AP 板盖；

![](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new_(9).png)  
3. 粘贴连接线时，需避开腔温传感器和火焰传感器（图中红色框）；

|  |  |
| --- | --- |
|  |  |

> 注意：粘贴时需持续施加适当压力（建议 30 秒），确保连接线粘牢。  
> ![](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new_(5).png)

4. 撕下卡扣贴纸；

![](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new_(6).png)

5. 将卡扣对准上盖的螺丝孔粘贴；

|  |  |
| --- | --- |
|  |  |

> 注意：粘贴时需持续施加适当压力（建议 15 秒），确保卡扣粘牢。

6. 将另一个卡扣安装在俯视摄像头和第一个卡扣中间，并按紧；

|  |  |
| --- | --- |
|  |  |

7. 锁紧卡扣固定螺丝。

|  |  |
| --- | --- |
|  |  |

#### 步骤 3：连接俯视摄像头线缆

1. 打开黑色卡扣；

![](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new_(15).png)

2. 将俯视摄像头连接线从其他线缆后面穿过，连接至 AP 板；

![](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new_(16).png)  
3. 按紧卡扣；

![](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new_(17).png)

4. 盖上 AP 板盖；

![](https://wiki.bambulab.com/h2/maintenance/replace-birds-eye-camera/image-new_(18).png)

5. 拧紧一颗固定螺丝；

|  |  |
| --- | --- |
|  |  |

## 如何验证成功/完成

在屏幕上进行俯视摄像头首次安装初始化，运行完成即可。
