> **注意**：本页面以 H2D 机器为例。**H2S 和 H2C 的更换步骤完全相同**。

## 前门安装配件

前门安装配件，是配合 H2D 打印机玻璃前门使用的配件。

**前门安装配件的备件包含如下：**

1. 合页 \* 2
2. M2.5x4 螺丝 - 用于固定下合页 \* 2
3. M2.5x5 螺丝 - 用于固定上合页 \* 2
4. M3x3 螺丝（螺帽直径 10mm） - 用于固定玻璃前门 \* 4
5. 密封胶条 - 左 \* 1
6. 密封胶条 - 右 \* 1

![fas044.png](https://wiki.bambulab.com/h2/maintenance/replace-front-door-mounting-kit/fas044.png)

## 何时更换

一般只有在合页变形的情况下才会需要更换前门配件，在 H2D 打印机上使用时，一般只需要更换上下合页，密封胶条一般不需要更换。

## 所需的工具和材料

- 前门安装配件
- H1.5 内六角扳手
- 2.0 内六角扳手

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除前门安装配件

### 步骤 1：移除玻璃前门

> 玻璃易碎，移除和安装时注意持稳，防止跌落。如果玻璃有损坏的地方，要防止伤手。

使用 H2.0 内六角扳手移除固定前门的 4 颗螺丝（M3x3，螺帽直径 10mm），上下各 2 颗，然后一只手扶住玻璃前门，将前门取下。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 2：拆除门合页

上下合页均使用两颗螺丝固定，您可以使用 H2.0 内六角扳手来移除上下合页的固定螺丝，请将上下合页的螺丝分开放置，两种螺丝的规格不同。（红色圆圈：M2.5x5；绿色方框：M2.5x4）

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 3：移除左右硅胶条（可选）

**如果您的硅胶套没有损坏，您无需更换。**

您可以直接将左右硅胶条撕下。

## 安装前门安装配件

### 步骤 1：安装左右硅胶条（可选）

**如果您的硅胶套没有损坏，您无需更换。**

左右硅胶条不一样，您可以先参考下图区分左右硅胶条，然后将硅胶条贴到对应的位置。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：安装前门合页

先将前门上合页对准螺丝孔位，使用 H2.0 内六角扳手拧紧两颗固定螺丝（红色圆圈：M2.5x5），下合页对准后也使用 H2.0 内六角扳手拧紧两颗固定螺丝（绿色方框：M2.5x4）。

|  |  |
| --- | --- |
|  |  |

### 步骤 3：安装玻璃前门

将玻璃前门上的 4 个螺丝孔位，对齐合页上的螺丝位安装好，用手扶稳玻璃前门，并使用 H2.0 内六角扳手拧紧 4 颗螺丝（M3x3，螺帽直径 10mm）。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 如何验证成功

检查前门无晃动，开合前门顺畅，闭合位置正常即可。
