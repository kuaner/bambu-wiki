## 气管接头

![40wair-assist.png](https://wiki.bambulab.com/h2c/maintenance/40wair-assist.png)

## 需要使用的工具

- H2.0/H2.5内六角扳手
- 新的气管接头

## 重要提醒

移除激光外壳时，需要拔掉LED指示灯的插头。**拆除时，请用手握住插头根部，垂直于PCB面方向用力抬起以解锁插头，或者使用H2.0螺丝刀或平头镊子等工具辅助解锁**。切勿在水平方向用力，以免损坏插头。

![插头.jpg](https://wiki.bambulab.com/h2/maintenance/laser-module-40w/%E6%8F%92%E5%A4%B4.jpg)

## 拆除气管接头

### 步骤1. 移除激光模组上盖

移除上盖正面和侧面的6颗螺丝（两颗长螺丝 M2.5x32，4 颗短螺丝 M2.5x5），然后取下上盖。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤2. 移除激光模组外壳

拧下激光模组侧面的4颗螺丝（M2.5x5），将连接线根部的卡扣从外壳上移除。

|  |  |  |
| --- | --- | --- |
|  |  |  |

将激光模组外壳向外轻轻推出一小段距离，防止拆坏插头。露出第一个线缆接头后，捏住根部，垂直于PCB面向上拔，断开这根线缆。

![20250528-121817.jpg](https://wiki.bambulab.com/h2/maintenance/laser-module-40w/20250528-121817.jpg)

|  |  |
| --- | --- |
|  |  |

> 对于部分版本的激光模组，此处线缆接头是通过打胶固定的，拆除时需要用手握住插头的根部往垂直于PCB面的方向上抬，以解锁插头，请勿在水平方向上用力，以免损坏插头。拆除后可以将插头上的胶移除，方便后续安装。

还有一部分版本的激光模组，此处线缆接头没有打胶，拆除的方法是相同的。

断开线缆接头后，即可成功移除激光模组外壳。

|  |  |
| --- | --- |
|  |  |

### 步骤3. 移除气管接头

使用H2.5内六角扳手从气管接头在外壳另一端对应处的孔洞中伸入，对准气管接头后，扶住气管接头，转动扳手将气管接头拧下。  
气管接头一般不易堵灰，如没有感觉到接头堵塞则可以跳过此清洁步骤。

## 安装气管接头

### 步骤1. 安装气管接头

然后使用H2.5内六角扳手重新装回气管接头。

![](https://wiki.bambulab.com/h2/maintenance/laser-module-40w/image-26.png)

### 步骤2. 安装激光模组外壳

在安装外壳前，请先将外壳内的线缆拨到外面，防止被激光模组压住。将连接线穿过外壳，压平激光模组上的连接线缆，防止线缆在安装过程中卡住。

|  |  |
| --- | --- |
|  |  |

然后将外壳沿着导轨推入一段距离，直到第一个插头之前。确保插头金属面朝上，重新将线缆压回插头中，并用手压平线缆，就可以将外壳完全装回。

|  |  |  |
| --- | --- | --- |
|  |  |  |

然后拧入外壳侧面的4颗固定螺丝（M2.5x5）。

![](https://wiki.bambulab.com/h2/maintenance/laser-module-40w//image-43.png)

### 步骤3. 安装激光模组上盖

重新将连接线上的卡扣扣回外壁，用手压住卡扣防止连接线晃动。然后将气管接头转动到外侧，这样不会影响到上盖的安装，然后将上盖沿着两侧的滑槽推入，最后压紧上盖。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

先拧入上盖侧面的2颗短螺丝（M2.5x5）。

![](https://wiki.bambulab.com/h2/maintenance/laser-module-40w//image-48.png)

然后在顶部靠近气嘴一侧（圈出的红色位置）螺丝孔拧入同规格的2颗短螺丝，远离气嘴一侧（圈出的绿色位置）螺丝孔拧入2颗长螺丝（M2.5x32）
