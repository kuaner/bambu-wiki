## 2004 升降电机组件

2004 升降电机组件是由升降电机和升降电机减速箱组成，可用于完成左热端的升降。

|  |  |
| --- | --- |
|  |  |

**2004 升降电机组件的备件包含如下：**

1. 2004 升降电机组件（升降电机和升降电机减速箱预装在一起）\* 1
2. 升降电机盖（如无损坏无需更换） \* 1
3. 摆杆 \* 1
4. 石墨垫片 \* 1
5. M2.5x5 - 用于固定升降电机减速箱 \* 3
6. BT2x5 - 用于固定升降电机 \* 2

## 何时更换

- 升降电机异常
- 升降电机减速箱异常

## 所需的工具和材料

1. 新的部件冷却风扇
2. H2.0 内六角扳手
3. H1.5 内六角扳手

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除 2004 升降电机组件

### 步骤 1：移除热端风扇及其支架

由于移除 2004 升降电机组件需要先将热端风扇移除，因此，您可以先参考这篇 Wiki 来移除热端风扇及其支架：

[更换 H2D 热端风扇及其支架](replace-cooling-fan-for-hotend.md)

### 步骤 2：移除喷嘴摄像头

由于 2004 升降电机组件有一颗螺丝被挡在喷嘴摄像头后面，您可以先使用 H1.5 内六角扳手移除两颗喷嘴摄像头固定螺丝，将喷嘴摄像头取下。

![](https://wiki.bambulab.com/h2/maintenance/replace-2004-lifting-motor-unit/image-15.png)

### 步骤 3：移除 2004 升降电机组件

您可以使用 H2.0 内六角扳手移除三颗升降电机减速箱固定螺丝，然后将升降电机组件从工具头上取下。当您移除最后一颗螺丝时，请用手扶着升降电机组件，避免升降电机组件掉落。

![](https://wiki.bambulab.com/h2/maintenance/replace-2004-lifting-motor-unit/image-16.png)

### 步骤 4：移除堵嘴磁铁支架和堵嘴组件

由于堵嘴磁铁支架和堵嘴组件是安装在升降电机组件上，升降电机组件不包含堵嘴磁铁支架和堵嘴组件，因此您需要将旧的移除，然后安装至新的升降电机组件上。您可以使用 H2.0 内六角扳手移除一颗堵嘴组件固定螺丝，将堵嘴组件取下，使用 H2.0 内六角扳手移除两颗堵嘴磁铁支架固定螺丝，将堵嘴磁铁支架取下。

## 安装 2004 升降电机组件

### 步骤 1：安装堵嘴磁铁支架和堵嘴组件

将原有的堵嘴组件与摆杆连接（请参考下图安装），使用 H.20 内六角扳手拧紧一颗固定螺丝，

|  |  |
| --- | --- |
|  |  |

将石墨垫片装入升降电机轴承上，再将摆杆的平面与轴承的平面对准，将摆杆装入升降电机组件上。最后将堵嘴磁铁支架的螺丝孔位对准升降电机组件，使用 H2.0 内六角扳手拧紧两颗固定螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 2：安装 2004 升降电机组件

将升降电机组件的两个轴承对准工具头上对应的孔位。请注意，左侧的轴承是卡在升降滑块中，当升降滑块处于底部时，左侧轴承也应位于下方，如下图所示。如果不处于对应的位置，则无法将升降电机组件安装进去，您可以通过波动摆杆来调整位置。

以下图为例，您可以先摆动摆杆，将堵嘴组件与堵嘴磁铁磁铁支架右侧的磁铁吸附在一起（方框位置处），此时对应升降滑块处于底部。然后将升降电机组件上的两个轴承对准工具头上的位置，装入后使用 H2.0 内六角扳手拧紧三颗固定螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 3：安装喷嘴摄像头

将喷嘴摄像头对准升降电机组件上的螺丝孔位，使用 H1.5 内六角扳手拧紧两颗固定螺丝。

![](https://wiki.bambulab.com/h2/maintenance/replace-2004-lifting-motor-unit/image-26.png)

### 步骤 4：安装热端风扇及其支架

您可以参考这篇 Wiki 来安装热端风扇及其支架：

[更换 H2D 热端风扇及其支架](replace-cooling-fan-for-hotend.md)

## 如何验证成功

连接电源并打开打印机，在屏幕操作切换热端，检查热端是否可以正常切换。
