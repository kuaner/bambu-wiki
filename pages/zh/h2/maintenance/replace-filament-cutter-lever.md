## 切刀刀柄与刀片

在 H2D/H2C 工具头左右两侧各装有一个切刀，左右切刀的刀柄和扭簧不同，在拆装时请注意区分。

**左切刀备件包含如下：**

1. 左切刀刀柄 \* 1
2. 扭簧 \* 1
3. 螺丝 \* 1

**右切刀备件包含如下：**

1. 右切刀刀柄 \* 1
2. 扭簧 \* 1
3. 螺丝 \* 1

**切刀刀片备件包含如下：**

1. 切刀刀片（左右通用） \* 3

## 何时更换

- 切刀刀片磨损
- 切刀刀柄损坏

## 所需的工具和材料

1. 新的切刀刀柄或刀片（请根据需要更换）
2. H2.0 内六角扳手

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 更换右切刀刀柄和刀片

使用 H2.0 内六角扳手移除一颗右切刀固定螺丝，将切刀和扭簧一起从挤出机中取出，然后将切刀刀片从切刀刀柄上抽出

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-lever/image-8.png)

取出刀柄后更换旧刀片。安装切刀时，**请确保切刀缺口面朝上**。

|  |  |
| --- | --- |
|  |  |

接下来将扭簧套在圆柱上，扭簧的一端插入小孔中，然后将右切刀刀柄和刀片一起插入挤出机，按住切刀刀柄避免松动，使用 H2.0 内六角扳手拧紧一颗螺丝。

![](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-lever/image-7.png)  
![右刀片.jpg](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-lever/%E5%8F%B3%E5%88%80%E7%89%87.jpg)  
![右切刀安装.webp](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-lever/%E5%8F%B3%E5%88%87%E5%88%80%E5%AE%89%E8%A3%85.webp)

**把切刀连同刀柄一起插入槽位中，从刀柄的底部缓慢地将其压入，随后安装上螺丝，以确保刀柄不会弹开。**

![](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-lever/image-9.png)

## 更换左切刀刀柄和刀片

**在更换左切刀前请先将热端切换至左热端。**

使用 H2.0 内六角扳手移除一颗固定螺丝，将左切刀刀柄从挤出机中抽出，最后将刀片从切刀刀柄中抽出即可。

![](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-lever/image-14.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-lever/image-13.png)

先将切刀刀片装入切刀刀柄中，将扭簧套在圆柱上，扭簧的一端插入小孔中。

![](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-lever/image.png)

然后将刀片插入刀槽中，按住切刀刀柄避免松动。

|  |  |
| --- | --- |
|  |  |

使用 H2.0 内六角扳手拧紧固定螺丝。

![](https://wiki.bambulab.com/h2/maintenance/replace-filament-cutter-lever/image-2.png)

## 如何验证成功

切刀无松动，回弹顺畅且能正常切断耗材即可。
