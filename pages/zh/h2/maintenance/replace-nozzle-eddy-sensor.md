## 重要提醒

H2D 挤出主板上的涡流线圈插头采用这种小型插头设计。**拔出插头时，请用手握住插头根部，垂直于PCB面方向用力抬起以解锁插头**。切勿在水平方向用力，以免损坏插头。

![插头.jpg](https://wiki.bambulab.com/h2/maintenance/laser-module-40w/%E6%8F%92%E5%A4%B4.jpg)

## 左右涡流线圈

左涡流线圈安装在升降滑块的后面，右涡流线圈安装在右热端的顶部。

**左涡流线圈的备件包含如下：**

1. 左涡流线圈 \* 1
2. BT2x6 螺丝 - 用于固定左涡流线圈 \* 1

**右涡流线圈的备件包含如下：**

1. 右涡流线圈 \* 1
2. BT2x5 螺丝 - 用于固定挤出霍尔转接板排线 \* 2
3. M2x5 螺丝 - 用于固定右涡流线圈 \* 2

## 何时更换

- 涡流线圈损坏；
- 经 Bambu Lab 官方技术支持确认需要更换涡流线圈。

## 更换左涡流线圈

### 移除左涡流线圈

#### 步骤 1：移除挤出接口板

首先，请参考这篇 Wiki 中移除章节的**步骤1-步骤2**，移除部件冷却风扇风道、风扇、以及挤出接口板：

[更换 H2D 挤出接口板/TH 板/FPC 排线](replace-H2D-TH-board.md)

#### 步骤 2：移除左热端和热端风扇左风道

移除热端前，先确认堵嘴组件的位置，如果堵嘴组件位于左热端底部，在移除热端的时候会有干涉，可能导致堵嘴弹片弯曲。您可以手动拨动摆杆，将堵嘴组件拨动至右侧。请确保堵嘴组件尾部和堵嘴磁铁支架右侧的磁铁吸附在一起，以确保拨动到位。

取下热端硅胶套，解开卡扣，将左热端取下。使用 H2.0 内六角扳手移除一颗热端风扇左风道固定螺丝（M2x5），将左风道取出。

|  |  |
| --- | --- |
|  |  |

#### 步骤 3：移除堵嘴磁铁支架

使用 H2.0 内六角扳手，移除两颗堵嘴磁铁支架固定螺丝（M2.5x2），然后将堵嘴磁铁支架取下。

|  |  |
| --- | --- |
|  |  |

#### 步骤 4：移除左涡流线圈

将左涡流线圈接口的胶布撕下， 沿着插头所在的平面将插头推出。

左涡流线圈线缆卡在热端风扇的线槽中，您需要先将线缆从右侧的线槽中取出，然后再将线缆从工具头上抽出。

右侧有一大一小两个线槽，其中下面的箭头处的大理线槽，用于收纳左热端加热组件线缆，上面箭头的小理线槽用于整理左涡流线圈插头、右涡流线圈插头和升降霍尔插头线缆。

您可以先将左热端加热组件连接线从大线槽中取出，然后再将左涡流线圈连接线从小线槽中取出。

|  |  |
| --- | --- |
|  |  |

使用 H2.0 内六角扳手移除一颗固定螺丝（BT2x6）。

请注意，为了确保运输的可靠性和安装的一致性，工厂在组装左涡流线圈时会涂抹一些胶水。因此，当您移除螺丝后，可能需要稍微用力才能从侧面取出左涡流线圈。在安装新的涡流线圈时，不需要涂抹胶水。

![](https://wiki.bambulab.com/h2/maintenance/replace-nozzle-eddy-sensor/image-17.png)

### 安装左涡流线圈

#### 步骤 1：安装左涡流线圈

由于在工具头上残留的胶水会影响左涡流线圈的安装精度，您可以先试用铲刀去除残留的胶水（胶水颜色为绿色）。

![](https://wiki.bambulab.com/h2/maintenance/replace-nozzle-eddy-sensor/image-16.png)

将新的左涡流线圈插入工具头，然后使用 H2.0 内六角扳手将螺丝拧入，不需要将螺丝完全拧紧。然后，准备一小片 A4 纸，将其对折；

> 左涡流线圈和升降滑块之间的距离约为 0.2mm，A4 纸对折后的厚度约为 0.2mm。

|  |  |  |
| --- | --- | --- |
|  |  |  |

然后将 A4 纸插入左涡流线圈和升降滑块之间，用手将左涡流线圈按住，用手拉动 A4 纸，检查 A4 纸是否刚好可以滑动（存在一点阻力，但比较容易取出）。

![插入白纸.webp](https://wiki.bambulab.com/h2/maintenance/replace-nozzle-eddy-sensor/%E6%8F%92%E5%85%A5%E7%99%BD%E7%BA%B8.webp)

如果可以刚好滑动，再使用 H2.0 内六角扳手将固定螺丝拧紧。在拧紧螺丝的过程中按住左涡流线圈的手需要保持稳定，避免位置发生变化。螺丝拧紧后，再将 A4 纸拔出。

|  |  |
| --- | --- |
|  |  |

将左涡流线圈的线缆先卡入小线槽中，将左涡流线圈连接线接头的金属面朝上，平着压入 TH 板上的接口，并贴好胶布。

<https://cms.bblmw.com/_e10d2a0e07.mp4>

> 左热端加热组件线缆将在“步骤 4 - 安装挤出接口板”中整理及安装。

![](https://wiki.bambulab.com/h2/maintenance/replace-nozzle-eddy-sensor/image-36.png)

#### 步骤 2：安装堵嘴磁铁支架

将堵嘴磁铁支架对准螺丝孔位，使用 H2.0 内六角扳手拧紧两颗固定螺丝：

|  |  |
| --- | --- |
|  |  |

#### 步骤 3：安装热端风扇左风道和左热端

将热端风扇左风道装回，使用 H1.5 内六角扳手拧紧一颗固定螺丝，然后将将左热端装回，扣紧卡扣后装回硅胶套。

|  |  |
| --- | --- |
|  |  |

#### 步骤 4：安装挤出接口板

请参考这篇 Wiki 中 **安装章节的步骤4-步骤5**，重新安装挤出接口板、部件冷却风扇风道、风扇：

[更换 H2D 挤出接口板/TH 板/FPC 排线](replace-H2D-TH-board.md)

## 更换右涡流线圈

### 移除右涡流线圈

#### 步骤 1：移除挤出机前盖导向

为便于后续移除右涡流线圈，您可以先参考这篇 Wiki 将挤出机前盖导向移除：

[更换 H2D 挤出机前盖导向](replace-dual-extruder-filament-guide.md)

#### 步骤 2：移除挤出接口板

您可以参考这篇 Wiki 来移除挤出接口板：

[更换 H2D 挤出接口板/TH 板/FPC 排线](replace-H2D-TH-board.md)

#### 步骤 3：移除右涡流线圈

使用 H2.0 内六角扳手移除两颗导向固定螺丝，将导向移除，然后使用 H1.5 内六角扳手移除两颗右涡流线圈固定螺丝；

|  |  |
| --- | --- |
|  |  |

撕掉贴在右涡流线圈接口上的胶布，然后将右涡流线圈连接线沿着插头所在的平面往外推出；

|  |  |
| --- | --- |
|  |  |

右涡流线圈的连接线卡在热端风扇的线扣中，您需要先将线缆从左右两个线扣中取出，然后再将线缆从工具头上抽出。

右侧有一个一小两个线扣，其中下面的箭头处的大理线槽，用于收纳左热端加热组件线缆，上面箭头的小理线槽用于整理左涡流线圈插头、右涡流线圈插头和升降霍尔插头线缆。

您可以先将左热端加热组件连接线从大线扣中取出，然后再将右涡流线圈连接线从线扣中取出。再将喷嘴摄像头的排线从升降电机盖上撕开一点，将右涡流线圈线缆从升降电机盖下方抽出。

|  |  |  |
| --- | --- | --- |
|  |  |  |

将右加热组件连接线从 TH 板上断开连接，将右热端加热组件连接线从线扣中取出，您可以将线缆往后推一点，将线缆一根一根从线扣中取出，然后将右涡流线圈连接线从线扣中取出，并将右涡流线圈抽出。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 安装右涡流线圈

#### 步骤 1：安装右涡流线圈

将新的右涡流线圈连接线穿过挤出机上的小孔，然后将右涡流线圈对准螺丝孔位，使用 H1.5 内六角扳手拧紧两颗固定螺丝。然后将导向对准挤出机上的螺丝孔位，使用 H2.0 内六角扳手拧紧两颗固定螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

先将右涡流线圈线缆卡入左侧线扣中，再将右热端加热组件连接线也卡入线扣中，然后将右涡流线圈线缆从喷嘴摄像头连接线下面穿过，卡入升降电机盖下方；

![卡入线缆.webp](https://wiki.bambulab.com/h2/maintenance/replace-nozzle-eddy-sensor/%E5%8D%A1%E5%85%A5%E7%BA%BF%E7%BC%86.webp)

|  |  |  |
| --- | --- | --- |
|  |  |  |

将右涡流线圈线缆卡入内侧的小线扣中，然后将左热端加热组件连接线卡入大线扣中，将右涡流线圈线缆接口的金属面朝上，平着压入 TH 板的接口中，并将胶布重新贴好。

|  |  |  |
| --- | --- | --- |
|  |  |  |

#### 步骤 2：安装挤出接口板

您可以参考这篇 Wiki 来安装挤出接口板：

[更换 H2D 挤出接口板/TH 板/FPC 排线](replace-H2D-TH-board.md)

#### 步骤 3：安装挤出前盖导向

您可以参考这篇 Wiki 来安装挤出机前盖导向：

[更换 H2D 挤出机前盖导向](replace-dual-extruder-filament-guide.md)
