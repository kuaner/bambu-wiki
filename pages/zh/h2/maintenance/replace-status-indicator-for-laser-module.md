## 激光模组状态指示灯

|  |  |
| --- | --- |
|  |  |

## 需要使用的工具

- H2.0 内六角扳手

- 新的激光模组状态指示灯

## 拆除激光模组状态指示灯步骤

> 对于 40W 激光模组，移除外壳的步骤可以参考此链接: [40w 激光模组定期维护建议](laser-module-40w.md)

### 步骤1. 移除激光模组上盖

移除上盖正面和侧面的6颗螺丝（两颗长螺丝 M2.5x26，4 颗短螺丝 M2.5x5），然后取下上盖。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2/manual/10w-laser-module-regular-maintenance/image-11.png)

### 步骤2. 移除激光模组外壳

使用H2.0的内六角扳手移除气管接头（部分10W激光模组的气管接头需要使用H2.5内六角扳手移除，2种版本随机发货，具体以您收到的机器为准）。

然后拧入风扇的一颗固定螺丝（MG2.5x26），防止后续移除激光模组外壳时，风扇松脱导致外壳难以拆除，因此无需拧入全部固定螺丝。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2/manual/10w-laser-module-regular-maintenance/image-16.png)

### 步骤3. 移除状态指示灯线缆

拧下激光模组侧面的6颗螺丝（M2.5x5），将激光模组外壳向外轻轻推出一小段距离，防止拆坏插头。露出LED指示灯的线缆后，断开这根线缆，就可以将外壳顺利向外取出。

|  |  |
| --- | --- |
|  |  |

> 注意：**拆除LED指示灯的插头时，请用手握住插头根部，垂直于PCB面方向用力抬起以解锁插头，或者使用H2.0螺丝刀或平头镊子等工具辅助解锁。** 切勿在水平方向用力，以免损坏插头。

![插头.jpg](https://wiki.bambulab.com/h2/maintenance/laser-module-40w/%E6%8F%92%E5%A4%B4.jpg)

对于部分版本的激光模组，此处线缆接头是通过打胶固定的，拆除时需要用手握住插头的根部往上抬，以解锁插头，请勿在水平方向上用力，以免损坏插头。拆除后可以将插头上的胶移除，方便后续安装。

还有一部分版本的激光模组，此处线缆接头没有打胶，拆除的方法是相同的。

|  |  |
| --- | --- |
|  |  |

### 步骤4. 移除状态指示灯灯罩及灯条

#### 拆除灯罩

使用螺丝刀或者镊子等硬物轻轻撬动灯罩，滑动取下。

![拆灯罩.gif](https://wiki.bambulab.com/h2/maintenance/replace-status-indicator-for-10w-laser-module/%E6%8B%86%E7%81%AF%E7%BD%A9.gif)

#### 拆除灯条

轻轻撕下废弃灯条。  
![拆除灯条.gif](https://wiki.bambulab.com/h2/maintenance/replace-status-indicator-for-10w-laser-module/%E6%8B%86%E9%99%A4%E7%81%AF%E6%9D%A1.gif)

## 安装激光模组状态指示灯步骤

### 步骤1.安装状态指示灯灯罩及灯条

#### 安装灯条

取出新的灯条，贴于凹槽处，并压紧。  
![安装灯条.gif](https://wiki.bambulab.com/h2/maintenance/replace-status-indicator-for-10w-laser-module/%E5%AE%89%E8%A3%85%E7%81%AF%E6%9D%A1.gif)

#### 安装灯罩

取出新的灯罩并滑入凹槽轨道。  
![安装灯罩.gif](https://wiki.bambulab.com/h2/maintenance/replace-status-indicator-for-10w-laser-module/%E5%AE%89%E8%A3%85%E7%81%AF%E7%BD%A9.gif)

### 步骤2.安装状态指示灯线缆

在安装外壳前，请先将外壳内的线缆拨到外面，防止被激光模组压住。将连接线穿过外壳，压平激光模组上的连接线缆，防止线缆在安装过程中卡住。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2/manual/10w-laser-module-regular-maintenance/image-33.png)

然后将外壳沿着导轨推入一段距离，直到状态指示灯线缆之前。确保插头金属面朝上，重新将线缆压回插头中，并用手压平线缆，就可以将外壳完全装回。

![](https://wiki.bambulab.com/h2/manual/10w-laser-module-regular-maintenance/image-50.png)

|  |  |
| --- | --- |
|  |  |

### 步骤3. 安装激光模组外壳

拧入剩余的1颗长螺丝（MG2.5x26）至靠近电路板这面剩余的一个孔中，然后拧入外壳侧面的6颗固定螺丝（M2.5x5）。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤4. 安装激光模组上盖

重新将连接线上的卡扣扣回外壁，用手压住卡扣防止连接线晃动。然后将上盖沿着两侧的滑槽推入，最后压紧上盖。

|  |  |
| --- | --- |
|  |  |
|  |  |

先拧入上盖侧面的2颗短螺丝（M2.5x5），然后在顶部左边螺丝孔拧入同规格的2颗短螺丝，右边螺丝孔拧入2颗长螺丝（M2.5x26）（面向LOGO LED，从前往后看）。
