> **注意**：本页面以 H2D 机器为例。**H2C 的更换步骤完全相同**。

## 废料滑梯

废料滑梯安装在吐料组件下方，用于将吐料组件产生的废料排出打印机外部。

废料滑梯**的备件包含以下：**

1. 废料滑梯；
2. BT3x8 螺丝 \* 1

## 何时更换

- 废料滑梯损坏

## 所需的工具和材料

- 新的废料滑梯
- H2.0 内六角扳手

**更换 H2D 废料滑梯所涉及的螺丝规格及数量（建议妥善保管拆下的螺丝，避免丢失）：**

| **螺丝规格** | **螺丝图片** | **用途** | **位置示意图** |  | **螺丝数量** |
| --- | --- | --- | --- | --- | --- |
| BT3x8 |  | 用于固定背板（绿色方框标记） |  |  | 12 |
| ST3x8 |  | 用于固定背板（红色圆圈标记） |  |  | 11 |
| ST3x12 |  | 用于固定料盘支架底座（黄色方框标记） |  |  | 2 |
| BT3x8 |  | 用于固定废料滑梯 |  |  | 1 |

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，[*请联系在线技术支持**（服务时间 9:00-21:00）*](https://support.bambulab.cn/cn/im)，我们将及时回复并为您提供所需的帮助。

## 移除废料滑梯

### 步骤 1：移除背板

参考打印机背板的相关内容，移除打印机的背板。

[更换 H2D 背板](replace-rear-panel.md)

### 步骤 2：拧下废料滑梯的固定螺丝

使用 H2.0 内六角扳手移除 1 颗固定螺丝（BT3x8）。

![](https://wiki.bambulab.com/h2/maintenance/replace-purge-chute/image-16.png)

### 步骤 3：取出废料滑梯

往下拉，取出废料滑梯。

![](https://wiki.bambulab.com/h2/maintenance/replace-purge-chute/image-17.png)

## 安装废料滑梯

### 步骤 1：装回废料滑梯

先对准滑梯下方 2 个卡扣位置，往前推，使这 2 个卡扣与内衬上的孔洞咬合。装回后，需检查螺丝孔位是否对齐；

> **注意：** 侧面有众多连接线，受压易留痕、甚至断裂；且线材断裂后更换复杂，原因难排查。 **压入时务必先整理好连接线，避开挤压连接线，如发现被挤压应立即停手，调整后再操作。**

![](https://wiki.bambulab.com/h2/maintenance/replace-purge-chute/image-18.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-purge-chute/image-19.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-purge-chute/image-20.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-purge-chute/image-21.png)

注：在安装废料滑梯的时候，需要注意将废料滑梯的两侧扣在内衬的外侧，如果扣在内侧可能无法正常安装。

![](https://wiki.bambulab.com/h2/maintenance/replace-purge-chute/image-22.png)

### 步骤 2：拧紧废料滑梯的固定螺丝

使用 H2.0 内六角扳手拧紧 1 颗固定螺丝（BT3x8）。

![](https://wiki.bambulab.com/h2/maintenance/replace-purge-chute/image-23.png)

### 步骤 3：安装后面板

参考打印机背板的相关内容，安装打印机的背板。

[更换 H2D 背板](replace-rear-panel.md)

## 如何验证成功

检查废料滑梯无晃动，可看见废料可正常从机箱背面滑出即可。
