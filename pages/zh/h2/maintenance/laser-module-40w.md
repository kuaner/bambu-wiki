## 重要提醒

移除激光外壳时，需要拔掉LED指示灯的插头。**拆除时，请用手握住插头根部，垂直于PCB面方向用力抬起以解锁插头，或者使用H2.0螺丝刀或平头镊子等工具辅助解锁**。切勿在水平方向用力，以免损坏插头。

![插头.jpg](https://wiki.bambulab.com/h2/maintenance/laser-module-40w/%E6%8F%92%E5%A4%B4.jpg)

## 40w激光头维护方法

应定期使用刷子清理散热片和风扇上积累的烟尘，同时使用酒精和无纺布清洁激光器前端的火焰传感器及窗口镜表面。 **在清洁传感器或者摄像头时，请沾少量的酒精，并在擦拭前将无纺布捏干一些，以防酒精渗入塑料外壳内部**。

  

## 维护频次

H2D 可以基于任务类型和任务时长评估打印机的污染程度，并给出对应的清洁维护提醒（固件版本01.01.00.00及更新的版本）。**请务必按照要求对激光模组进行维护清理，如果不按时清理，可能导致机器损坏并产生安全风险。**

建议在每次激光任务后，使用刷子简单清理碎屑和外表面的灰尘。当打印机弹窗清洁维护提示时，需要拆下激光模块的上盖和外壳，清理风扇表面以及风扇下方的散热片灰尘，使用快拆工具拆卸气嘴，并擦拭窗口镜。

## 需要使用的工具

- H2.0/H2.5内六角扳手
- 无纺布
- 刷子
- 吹气球
- 液体清洁剂
- 气嘴拆卸工具（打印机内置模型）

![](https://wiki.bambulab.com/h2/maintenance/laser-module-40w/image-13.png)

## 螺丝型号

- M2.5x5 \* 8
- M2.5x32 \* 4

## 维护步骤

### 步骤1. 清理激光模组的上盖外侧

使用刷子清理上盖灰尘。若激光模组的四周也有较多灰尘，可以先使用沾了酒精的无纺布擦拭。这一操作也会包含在后续的清理步骤中。

|  |  |
| --- | --- |
|  |  |

### 步骤2. 移除激光模组上盖

移除上盖正面和侧面的6颗螺丝（两颗长螺丝 M2.5x32，4 颗短螺丝 M2.5x5），然后取下上盖。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤3. 清理风扇

使用刷子清理风扇上的灰尘，清理风扇时请边旋转风扇边清理，确保每片扇叶上的灰尘都已清理干净。在清理大块灰尘后，可以用酒精清洁刷子，维持良好的清洁效果。

|  |  |
| --- | --- |
|  |  |

### 步骤4. 清理激光模组上盖

对取下的激光模组上盖再次进行清理，将上盖缝隙中残留的灰尘清理干净；然后翻转上盖，清理内侧灰尘。

|  |  |
| --- | --- |
|  |  |

### 步骤5. 移除激光模组外壳

拧下激光模组侧面的4颗螺丝（M2.5x5），将连接线根部的卡扣从外壳上移除。

|  |  |  |
| --- | --- | --- |
|  |  |  |

将激光模组外壳向外轻轻推出一小段距离，防止拆坏插头。露出第一个线缆接头后，捏住根部，垂直于PCB面向上拔，断开这根线缆。

![20250528-121817.jpg](https://wiki.bambulab.com/h2/maintenance/laser-module-40w/20250528-121817.jpg)

|  |  |
| --- | --- |
|  |  |

> 对于部分版本的激光模组，此处线缆接头是通过打胶固定的，拆除时需要用手握住插头的根部往垂直于PCB面的方向上抬，以解锁插头，请勿在水平方向上用力，以免损坏插头。拆除后可以将插头上的胶移除，方便后续安装。

还有一部分版本的激光模组，此处线缆接头没有打胶，拆除的方法是相同的。

断开线缆接头后，即可成功移除激光模组外壳。

|  |  |
| --- | --- |
|  |  |

### 步骤6. 移除气管接头（可选）

使用H2.5内六角扳手从气管接头在外壳另一端对应处的孔洞中伸入，对准气管接头后，扶住气管接头，转动扳手将气管接头拧下。  
气管接头一般不易堵灰，如没有感觉到接头堵塞则可以跳过此清洁步骤。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

### 步骤7. 清理激光模组外壳

使用刷子清理外壳的4面内壁，扫除表面的灰尘。

然后在刷子上喷涂酒精，并用无纺布将刷子擦拭干净。使用清洁后的刷子再次清理外壳的4面内壁。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

最后在无纺布上喷涂酒精，用手或镊子将无纺布塞入外壳中擦拭，将外壳的4面内壁完全清理干净。

### 步骤8. 清理气管接头（可选）

气管接头一般不易堵灰，如没有感觉到接头堵塞则可以跳过此清洁步骤。  
在刷子或无纺布上喷涂酒精，将气管接头表面和孔洞内清理干净。

|  |  |
| --- | --- |
|  |  |

然后使用H2.5内六角扳手重新装回气管接头。

![](https://wiki.bambulab.com/h2/maintenance/laser-module-40w/image-26.png)

### 步骤9. 清理风扇内侧

拧下风扇上的两颗固定螺丝（M2.5x32），将风扇翻转。

|  |  |
| --- | --- |
|  |  |

用刷子清理风扇背面的灰尘，然后将内部翅片表面上的灰尘也清理干净。

|  |  |
| --- | --- |
|  |  |

### 步骤10. 清理激光模组散热翅片

使用刷子清理散热翅片表面上的灰尘，然后使用吹气球将散热片内部的灰尘吹出。

|  |  |  |
| --- | --- | --- |
|  |  |  |

|  |  |
| --- | --- |
|  |  |

清理完毕后，重新将风扇2颗长螺丝（MG2.5x32）拧入靠近电路板一面的2个螺丝孔中固定风扇。

|  |  |
| --- | --- |
|  |  |

### 步骤11. 安装激光模组外壳

在安装外壳前，请先将外壳内的线缆拨到外面，防止被激光模组压住。将连接线穿过外壳，压平激光模组上的连接线缆，防止线缆在安装过程中卡住。

|  |  |
| --- | --- |
|  |  |

然后将外壳沿着导轨推入一段距离，直到第一个插头之前。确保插头金属面朝上，重新将线缆压回插头中，并用手压平线缆，就可以将外壳完全装回。

|  |  |  |
| --- | --- | --- |
|  |  |  |

然后拧入外壳侧面的4颗固定螺丝（M2.5x5）。

![](https://wiki.bambulab.com/h2/maintenance/laser-module-40w//image-43.png)

### 步骤12. 安装激光模组上盖

重新将连接线上的卡扣扣回外壁，用手压住卡扣防止连接线晃动。然后将气管接头转动到外侧，这样不会影响到上盖的安装，然后将上盖沿着两侧的滑槽推入，最后压紧上盖。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

先拧入上盖侧面的2颗短螺丝（M2.5x5）。

![](https://wiki.bambulab.com/h2/maintenance/laser-module-40w//image-48.png)

然后在顶部靠近气嘴一侧（圈出的红色位置）螺丝孔拧入同规格的2颗短螺丝，远离气嘴一侧（圈出的绿色位置）螺丝孔拧入2颗长螺丝（M2.5x32）

|  |  |
| --- | --- |
|  |  |

### 步骤13. 清理激光模组表面

经过一系列清理维护工作后，激光模组的表面可能会再次沾上灰尘。请使用喷涂了酒精的无纺布擦拭激光模组的表面。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤14. 清理火焰/温度传感器和气嘴

先使用吹气球初步吹出聚风罩内部的灰尘，然后使用刷子进行进一步清理，扫除灰尘。最后使用喷涂了酒精的无纺布仔细擦拭火焰/温度传感器和气嘴，将灰尘清理干净。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤15. 清理窗口镜

使用气嘴拆卸工具逆时针将气嘴拆下，露出内部的窗口镜。

此步骤使用的气嘴拆卸工具可以直接从打印机内置模型文件中打印。

> 注意：打印机内置文件自带的气嘴拆卸工具只提供了10W的六边形拆卸工具的模型，与40W的八边形不一致，因此无法用于拆卸40W激光模组。

>

> | --- | --- |
> |  |  |

|  |  |
| --- | --- |
|  |  |

使用无纺布擦拭窗口镜，确保镜头上没有任何灰尘。清理完毕后，使用气嘴拆卸工具将气嘴顺时针拧入。

|  |  |
| --- | --- |
|  |  |

### 步骤16. 清理测高激光器

最后，使用无纺布清洁测高激光器。

## 附录

在上述维护过程中，建议使用少量酒精（75%的乙醇或70%的异丙醇）和无纺布擦拭摄像头、金属和塑料等表面。对于特殊部位，如上盖、风扇叶片和散热片，建议使用毛刷进行清理。

**使用液体清洁剂后，请适当拧干无纺布再进行清理。同时，强烈建议您增加清洁频率，以防油污结块，难以去除。**

如果污染严重，可以使用威猛先生等油污清洁剂进行深层清洁。
