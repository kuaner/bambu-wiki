## MC-AP 线

MC-AP 线由两根线组成，用于连接 MC 板和 AP 板。

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-31.png)

**MC-AP 线的备件包含如下：**

1. MC-AP 线（供电 - 红黑）\* 1；
2. MC-AP 线（通讯 - 黑）\* 1

## 所需的工具和材料

- 新的 MC-AP 线
- H2.0 内六角扳手

> 请检查新的 MC-AP 线缆，与设备原装线缆的线芯数量是否一致。如线芯数量不同，请及时联系客户支持团队。

> |  |  |
> | --- | --- |
> | 线芯少 | 线芯多 |

**更换 H2D MC-AP 线所涉及的螺丝规格及数量（建议妥善保管拆下的螺丝，避免丢失）：**

| **螺丝规格** | **螺丝图片** | **用途** | **位置示意图** |  | **螺丝数量** |
| --- | --- | --- | --- | --- | --- |
| BT3x8  ST3x6 |  | 用于固定背板：  12 颗自攻螺丝（绿色方框标记）  11 颗机牙螺丝（红色圆圈标记） |  |  | 23 |
| ST3x12 |  | 用于固定料盘支架底座（黄色圆角标记） |  |  | 2 |
|  |  | 用于固定废料滑梯 |  |  | 1 |
| BT2.6x8 |  | 用于固定 AP 板盖 |  |  | 1 |

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，[*请联系在线技术支持**（服务时间 9:00-21:00）*](https://support.bambulab.cn/cn/im)，我们将及时回复并为您提供所需的帮助。

## 移除 MC-AP 线

### 步骤 1：移除背板

您可以参考这篇 Wiki 来移除打印机背板：

[更换 H2D 背板](replace-rear-panel.md)

### 步骤 2：移除 AP 板盖和护线盖

1. 使用 H2.0 内六角扳手拧下 1 颗固定螺丝（BT2.6x8），然后从靠近前门的一侧取下 AP 板盖。

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-1.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-2.png)

2. 护线盖由卡扣固定，您可以将护线盖向外拔出。

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-3.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/img_v3_02je_e67bcee0-e7bb-4c17-906d-e6e4c0819fcg.jpg)

### 步骤 3：移除废料滑梯

使用 H2.0 内六角扳手移除 1 颗固定螺丝（BT3x8），然后向下拉动废料滑梯，直到可以看见废料滑梯的两个卡扣，然后向外取出废料滑梯。

> 废料滑梯除了通过顶部的螺丝固定外，底部也有两个卡扣扣在内衬上来进行固定。

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-4.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-5.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-6.png)

### 步骤 4：移除 MC-AP 线

1. 分别从 MC 板和 AP 板上将 MC-AP 线断开连接；

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image99.jpg)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-8.png)

2. 打开线扣，将 MC-AP 线缆从内衬中抽出。

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-14.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-15.png)

## 安装 MC-AP 线

### 步骤 1：连接 MC-AP 线缆

1. 将 MC-AP 线从内衬的走线孔中穿过，再与 MC 板连接，并将黑色的线扣入内衬的卡扣中；

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image99.jpg)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-17.png)

2. 将 MC-AP 线的另外一端与 AP 板连接，并将线缆扣入上框的线扣中。

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-18.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-19.png)

### 步骤 2：安装废料滑梯

1. 先将废料滑梯底部的两个卡扣对准内衬上的两个孔位；

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-20.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-21.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-22.png)

2. 然后将废料滑梯往上扣，确保底部的卡扣扣入内衬中，用手托住废料滑梯的顶部，将废料滑梯的顶部的螺丝孔位对齐，最后使用 H2.0 内六角扳手拧紧一颗固定螺丝，并将黄绿和红白两根线缆扣在废料滑梯顶部的线扣后。

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-23.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-24.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-25.png)

注：在安装废料滑梯的时候，需要注意将废料滑梯的两侧扣在内衬的外侧，如果扣在内侧可能无法正常安装。

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-26.png)

### 步骤 3：安装 AP 板盖和护线盖

1. 将护线盖扣入打印机中；

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-27.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-28.png)

2. 先从靠近打印机背面的一侧扣回 AP 板盖，将箭头所示的两处均按压到位，右侧与缓冲器齐平，底部与护线盖齐平，然后使用 H 2.0 内六角扳手拧紧一颗固定螺丝（BT2.6x8）。

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-29.png)

![](https://wiki.bambulab.com/h2/maintenance/replace-mc-ap-cable/image-30.png)

### 步骤 4：安装背板

您可以参考这篇 Wiki 来安装打印机背板：

[更换 H2D 背板](replace-rear-panel.md)

## 如何验证成功

连接电源并打开打印机，发起打印，没有报错即可。
