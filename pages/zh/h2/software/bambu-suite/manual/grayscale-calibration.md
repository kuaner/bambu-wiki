在激光图像加工过程中，不同的激光功率和速度组合会影响雕刻在材料上的效果。一般来说，较高的功率或较慢的雕刻速度会产生更明显的雕刻效果。例如，在木材上，功率越高或速度越慢，雕刻的颜色通常会越深。通常，激光功率调节采用线性关系进行设置，但这种设置往往无法提供最佳的视觉效果。为了解决这个问题，我们开发了特殊的算法，可以根据不同功率，速度组合下的实际雕刻效果，拟合出更符合人眼的功率映射曲线。

## 如何启用灰度标定

注意：此功能只对图像雕刻模式，且选择了灰度雕刻时有效。

用户需要像选择其他耗材一样，在弹出的对话框中，选择一个雕刻效果，该效果对应的是图像中最深的颜色，也可以直接使用推荐的速度和功率选项。

![](https://wiki.bambulab.com/h2/manual/grayscale-calibration/zh1/image-2.png)

## 效果

通过灰度标定，用户可以获得更加精确的雕刻效果。启用灰度标定后，风景画保留更多的细节。

|  |  |
| --- | --- |
|  |  |
| 未启用灰度标定 | 启用灰度标定 |

注意，此功能正处于实验中，仅对部分耗材提供支持。未来将会持续对算法的稳定性和效果进行优化，敬请关注。
