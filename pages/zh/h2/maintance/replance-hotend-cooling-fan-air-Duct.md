## 热端冷却风扇风道

![pixpin_2025-07-17_15-33-24.png](https://wiki.bambulab.com/h2/maintenance/replance-hotend-cooling-fan-air-duct/pixpin_2025-07-17_15-33-24.png)

## 适用打印机型号

## 何时使用

拓竹技术支持建议更换

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 左侧风道更换

### 移除左侧风道

#### 1. 移除部件冷却风扇风道

您可以参考以下视频或[更换部件冷却风扇风道指南](../maintenance/replace-part-cooling-fan-air-duct.md)来移除该风道。

#### 2.移除左喷嘴组件

移除左喷嘴硅胶套，打开快拆卡扣并移除喷嘴。

|  |  |
| --- | --- |
|  |  |

#### 3.移除热端冷却风扇风道

完成以上步骤后，您将会看到左侧风道的固定螺丝，使用 H1.5 螺丝刀移除螺丝（M2\*5）后即可向外取出风道。

|  |  |
| --- | --- |
|  |  |

### 安装左侧风道

#### 1. 安装热端冷却风扇风道

插入左侧风道，使用 H1.5 螺丝刀锁紧螺丝即可。

|  |  |
| --- | --- |
|  |  |

#### 2. 安装左喷嘴组件

同样的操作安装喷嘴组件，安装时注意快拆卡扣是否锁紧。

|  |  |
| --- | --- |
| 热端卡扣错误锁紧 | 热端卡扣正确锁紧 |

#### 3. 安装部件冷却风扇风道

您可以参考以下视频或[更换部件冷却风扇风道指南](../maintenance/replace-part-cooling-fan-air-duct.md)来安装该风道。

## 右侧风道更换

### 移除右侧风道

#### 1. 移除部件冷却风扇风道

您可以参考以下视频或[更换部件冷却风扇风道指南](../maintenance/replace-part-cooling-fan-air-duct.md)来移除该风道。

#### 2.移除热端冷却风扇风道

使用 H1.5 螺丝刀，移除风道两颗固定螺丝（M2\*5），向外翻转即可取出右侧风道。

|  |  |
| --- | --- |
|  |  |

正确移除风道后如下图所示。

![右侧移除后.jpg](https://wiki.bambulab.com/h2/maintenance/replance-hotend-cooling-fan-air-duct/%E5%8F%B3%E4%BE%A7%E7%A7%BB%E9%99%A4%E5%90%8E.jpg)

### 安装右侧风道

#### 1. 安装热端冷却风扇风道

插入风道并向内旋转固定风道位置，接下来安装两颗固定螺丝即可完成风道安装。
