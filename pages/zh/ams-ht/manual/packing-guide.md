## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

**建议您使用原包装进行打包以确保运输安全。若您因退货需求需重新打包但原包装已丢失，请联系我们的售后团队为您补发专用的纸箱及缓冲泡沫等防护材料。**

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### 步骤一：移除铁氟龙料管

从 AMS HT 背面 **按压铁氟龙料管释放按钮**，解锁接头，然后**拉出铁氟龙料管**。

|  |  |
| --- | --- |
|  |  |

### 步骤二：断开 6-pin 连接线、电源线

**按紧线缆接口底端**，断开 6-pin 连接线。然后，**断开电源线**。

|  |  |
| --- | --- |
|  |  |

用黑色细线将 **6-pin 连接线**和**电源线**卷起。然后，将 **铁氟料龙料管（263mm × 2 + 900mm × 1）** 放入包装袋。

|  |  |
| --- | --- |
|  |  |

将铁氟料龙料管包装袋放入 AMS HT 内部。然后**盖紧上盖**，套上 AMS HT 保护袋。

|  |  |
| --- | --- |
|  |  |

### 步骤三：装箱操作

将 AMS HT 放入纸箱内，**放置时注意与泡沫底壳方向一致**。

|  |  |
| --- | --- |
|  |  |

将**6-pin 连接线，电源线，备用干燥剂（如有）放入底部泡沫的凹槽内**。然后，将说明书放在 AMS HT上方，盖上泡沫保护盒。

|  |  |
| --- | --- |
|  |  |

最后，用胶带将纸箱粘牢。
