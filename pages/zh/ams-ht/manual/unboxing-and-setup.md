## 视频指南

## 操作步骤

### 取出 AMS HT

1. 打开纸箱， 取出黑色泡棉。

|  |  |  |
| --- | --- | --- |
|  |  |  |

2. 取出 AMS HT、说明书及线缆。

|  |  |  |
| --- | --- | --- |
|  |  |  |

3. 撕开胶带，取出 AMS TH。

|  |  |
| --- | --- |
|  |  |

4. 撕下透明保护膜。

|  |  |
| --- | --- |
|  |  |

### 取出料管

打开上盖，取出料管。

![](https://wiki.bambulab.com/ams-ht/manual/image-25.png)

### 放置干燥剂

1. 撕下从动支撑轴上的贴纸；小心拆下从动支撑轴，避免两侧轴承掉落。

|  |  |
| --- | --- |
|  |  |

2. **移除干燥剂外包装**，将干燥剂放入从动支撑轴下方，并安装从动支撑轴。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 连接料管

将 AMS HT 放置打印机顶部，并将料管一端插入 AMS HT 的出料口；另一端插入打印机任一进料口，向前推送料管，直至无法前进。

|  |  |
| --- | --- |
|  |  |

### 连接 6pin 线和电源线

1. 关闭打印机电源开关。将 6pin 连接线插入 AMS HT 任一接口，另一端插入打印机。

|  |  |
| --- | --- |
|  |  |

2. 将电源线插入 AMS HT。

![](https://wiki.bambulab.com/ams-ht/manual/image-19.png)

### 开启打印机

开启打印机，可在“耗材”界面查看打印机与 AMS HT的连接。  
![中](https://wiki.bambulab.com/ams-ht/manual/image-27.png)
