## 指示灯

在日常使用 AMS HT 时，可以通过 LED 灯状态来判断 AMS HT 是否正常工作。

![](https://wiki.bambulab.com/ams-ht/manual/intro-and-connection-guide/image-7.png)

## 指示灯状态解析

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 工作状态 | 序号 | LED 灯 | 故障可能 | 备注 |
| 异常工作过程 | 1 | 红灯双闪 | 1. 打印机没检测到 AMS，通信异常，请检查屏幕上是否显示AMS HT  2. 错误状态，进料器和出料口的霍尔组件都检测到有料，可能是进料或者退料失败 |  |
| 2 | 红灯呼吸 | 1.错误状态，打印开始后进料器没有检测到料，**插入料后即可恢复正常**。 2. **烘干时**状态异常；  3. **空闲时**烘干模块 NTC 掉线，或者检测到风道温度过高等异常，需要**检测各部件是否插紧** | 可根据 [AMS HT 烘干组件更换指南](heating-unit.md) 重新安装烘干组件线缆 |
| 3 | 红灯常亮 | 错误状态，进料器没检测到料但出料霍尔组件检测到料，可能是**耗材丝断在出料霍尔组件内部** | 可根据 [更换 AMS HT 出料霍尔检测组件](replace-feeder-hall-sensor-assembly.md) 疏通处理。 |
| 4 | 红灯单闪 | 错误状态，**进料器检测到有料，出料霍尔组件没检测到料**，通常是进料失败，需要检查进料器是否被碎屑包裹，内部料管是否堵塞 | 可根据 [AMS HT 上下料组件更换指南](../../amsht/maintenance/replace-feeder-unit.md) 清理。 |
| 正常工作过程 | 1 | 间隔点亮 | AMS 上电初始化的时候，隔 3 秒左右闪一次白灯 |  |
| 2 | 白灯常亮 | AMS 上电初始化结束后，或者唤醒屏幕时槽里有料（唤醒屏幕会点亮有插入耗材的槽位） |  |
| 3 | 白灯常亮 | 该槽位正在进行预上料、读取 RFID 或者正常打印过程中（包含进退料） |  |
| 4 | 白灯熄灭 | 1. 息屏后 15 分钟内该槽无预上料、读取 RFID 或打印（进退料）动作，白灯熄灭；  2. 在预上料或者读取 RFID 时白灯会再次点亮，动作结束 10 秒后白灯熄灭；  3. AMS 上电初始化结束后，20 分钟内无预上料、读取 RFID 或打印（进退料）动作，白灯熄灭。 |  |
| 5 | 白灯呼吸 | 正常烘干状态 |  |
