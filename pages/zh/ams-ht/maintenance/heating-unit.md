## 烘干组件

AMS HT 的干燥组件由加热单元、涡轮风扇和 NTC 温度传感器组成。  
![image.png](https://wiki.bambulab.com/ams-ht/maintenance/drying-component/image.png)

## 何时使用

- 加热元件、温度传感器、涡轮风扇工作异常。
- 拓竹技术支持建议更换。

## 所需要工具和材料

- H1.5 螺丝刀
- H2.0 螺丝刀

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。  
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 移除旧的烘干组件

### 1. 移除 AMS HT 背面特氟龙料管

从 AMS HT 背面按压特氟龙料管释放按钮，解锁接头，然后从 AMS HT 背面拉出特氟龙管。

![取出料管.jpg](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/%E5%8F%96%E5%87%BA%E6%96%99%E7%AE%A1.jpg)

### 2. 取出 AMS HT 中框

移除底部两颗螺丝（BT3\*8）。

![3.底壳螺丝.jpg =800x](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/3.%E5%BA%95%E5%A3%B3%E8%9E%BA%E4%B8%9D.jpg)

移除螺丝后缓慢向上拉动中框组件。

|  |  |
| --- | --- |
|  |  |

打开缝隙后向上提起中框组件，**注意有电缆连接，请勿暴力操作**。

![6分离.jpg =800x](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/6%E5%88%86%E7%A6%BB.jpg)

解锁插头卡扣，拔出前端屏幕连接线缆。

![9移除前线缆.jpg](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/9%E7%A7%BB%E9%99%A4%E5%89%8D%E7%BA%BF%E7%BC%86.jpg)

接下来，拔出 AMS HT 电源板上的信号连接线和电源连接线。

|  |  |
| --- | --- |
|  |  |

移除电源插座到主板连接线，移除绝缘橡胶套**抵住解锁扣**，拉出线缆接头。

|  |  |
| --- | --- |
|  |  |

### 3. 移除烘干组件线缆

移除固定片螺丝（BT3x5），松开线缆和烘干组件的固定。

![移除螺丝.jpg](https://wiki.bambulab.com/ams-ht/maintenance/drying-component/%E7%A7%BB%E9%99%A4%E8%9E%BA%E4%B8%9D.jpg)

由于烘干组件固定螺丝和主板存在干涉，需要移动主板的位置来取出烘干组件的固定螺丝，拧松三颗主板固定螺丝（BT2x5），将主板从固定槽内推出。

|  |  |
| --- | --- |
|  |  |

接下来，从主板上移除烘干组件连接线缆和部分存在干涉的线缆。

1. 温湿度传感器
2. 烘干组件温度传感器
3. 出料口霍尔板
4. RFID 线圈
5. 烘干组件涡流风扇

![移除线缆标注.jpg](https://wiki.bambulab.com/ams-ht/maintenance/drying-component/%E7%A7%BB%E9%99%A4%E7%BA%BF%E7%BC%86%E6%A0%87%E6%B3%A8.jpg)

来到主板侧边断开加热单元线缆，首先需要先移除绝缘橡胶套按住解锁扣，再缓慢拔出线缆。

|  |  |
| --- | --- |
|  |  |

### 4. 移除烘干组件

如果下图所示移除烘干组件的 4 颗固定螺丝。

![安装螺丝.jpg](https://wiki.bambulab.com/ams-ht/maintenance/drying-component/%E5%AE%89%E8%A3%85%E8%9E%BA%E4%B8%9D.jpg)

使用 H1.5 螺丝刀解锁左右两侧固定卡扣，即可取出烘干组件。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/31%E5%88%86%E7%A6%BB%E5%8A%A0%E7%83%AD%E5%8D%95%E5%85%83.jpg)

## 安装新的烘干组件

### 1. 安装烘干组件

注意需要将风扇一端与中框通风孔一端对齐安装。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/38%E5%AF%B9%E9%BD%90%E4%B8%A4%E5%AD%94.jpg)

从 AMS HT 出料口的位置斜向下安装烘干组件。  
![安装新烘干组件.jpg](https://wiki.bambulab.com/ams-ht/maintenance/drying-component/%E5%AE%89%E8%A3%85%E6%96%B0%E7%83%98%E5%B9%B2%E7%BB%84%E4%BB%B6.jpg)

锁紧 4 颗烘干组件固定螺丝（BT2x6）。

![安装螺丝.jpg](https://wiki.bambulab.com/ams-ht/maintenance/drying-component/%E5%AE%89%E8%A3%85%E8%9E%BA%E4%B8%9D.jpg)

### 2. 连接烘干组件线缆

首先连接主板侧边加热单元线缆，注意完成线缆插接后将绝缘橡胶安装到位。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/50%E5%8A%A0%E7%83%AD%E7%BA%BF%E7%BC%86.jpg)

> 注意：此处连接不区分正负极。

接下来插接主板顶部的 5 根线缆。

1. 温湿度传感器
2. 烘干组件温度传感器
3. 出料口霍尔板
4. RFID 线圈
5. 烘干组件涡流风扇

![移除线缆标注.jpg](https://wiki.bambulab.com/ams-ht/maintenance/drying-component/%E7%A7%BB%E9%99%A4%E7%BA%BF%E7%BC%86%E6%A0%87%E6%B3%A8.jpg)

将主板插入槽内锁紧 3 颗固定螺丝（BT2x5）。  
![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/51%E5%AE%89%E8%A3%85%E4%B8%BB%E6%9D%BF.jpg)

完成线缆连接后，需要整理线缆。先将4根较细的线缆放置在底部，把较粗的主板通讯线压在这 4 根细线缆上方，之后安装固定片并锁紧螺丝（BT3x5）。

|  |  |
| --- | --- |
|  |  |

将 AMS HT 旋转 180° 整理前部的线缆，如果下图所示将线缆整理至理线槽内。

|  |  |
| --- | --- |
|  |  |

### 3. 安装 AMS HT 中框

在此步骤我们需要连接上下料器至出料组件的特氟龙管。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/57%E8%BF%9E%E6%8E%A5%E4%B8%A4%E7%AB%AFptfe%E7%AE%A1.jpg)

如下图所致连接 1、2 号位的线缆。其中1号位为主板通讯线（14pin），2号位为主板电源线（2pin）。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/58%E8%BF%9E%E6%8E%A5%E4%B8%A4%E4%B8%AA%E7%BA%BF%E7%BC%86.jpg)

将电源插座线缆插接在主板上并安装好绝缘橡胶套。  
![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/59ac%E7%BA%BF%E7%BC%86.jpg)

> 注意：此处连接不区分正负极。

连接 AMS HT 前端屏幕线缆，连接完成后需要注意将线缆卡入理线槽内。

|  |  |
| --- | --- |
|  |  |

用手指勾住凸出的线缆，将中框组件安装至下盖组件内。

|  |  |
| --- | --- |
|  |  |

需要确保中框组件完全压入下壳组件且前后没有翘起的情况，安装底部两颗固定螺丝（BT3\*8）。

|  |  |
| --- | --- |
|  |  |

### 4. 插入AMS HT背面特氟龙料管

最后将特氟龙管从 AMS TH 尾部推入。装完后，拉动特氟龙管，确认特氟龙管已固定。

![](https://wiki.bambulab.com/ams-ht/disassembly-and-assembly/65%E6%8F%92%E6%96%99%E7%AE%A1.jpg)

## 功能验证

将电源线连接妥当，把 AMS HT 设备与打印机进行对接。接通电源后，通过操作打印机显示屏上的相应界面，依次启用 AMS HT 的烘干功能和上料功能。

若烘干功能可正常开启，且设备能按预设升温至目标温度，则判定烘干组件工作正常。

接下来，对上料功能展开测试。确认整个上料流程正常且未出现任何错误提示。若上述测试均顺利通过，则表明 AMS HT 更换操作成功完成。

否则，请检查所有内部线缆连接，然后重试。如果问题仍然存在，请联系 Bambu Lab 技术支持团队寻求进一步帮助。
