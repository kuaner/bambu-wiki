## **问题现象**

- 废料堆积在吐料组件挡板上，且工具头离开吐料组件后，废料不能被弹走；

![堆料.jpg](https://wiki.bambulab.com/a1/%E5%A0%86%E6%96%99.jpg)

- 吐料组件挡板卡住

![卡住.webp](https://wiki.bambulab.com/a1-mini/%E5%8D%A1%E4%BD%8F.webp)

## 问题原因

1. 吐料组件挡板动作路径上有异物遮挡；
2. 吐料组件档板松动或变形歪斜；
3. X 轴左侧端盖位置未调整好；
4. 吐料组件的齿条卡住。

## 解决方案

### 1.更新打印机固件

我们在 2023 年 11 月 2 日发布了专门的修复固件（01.01.01.00），如果您的打印机固件版本比这个要低，请先进行固件升级，更新至最新版的固件。

### 2.清理吐料组件

用镊子、吹气球等清洁阻挡在吐料组件运动路径上的异物，如打印丝。

![](https://wiki.bambulab.com/n1/troubleshooting/purge-wiper-adjustment/%E6%BB%91%E6%A7%BD%E5%A0%86%E6%96%99.png)

### 3.调整档板位置

用 H1.5 内六角扳手拧紧挡板螺丝，并将挡板调整好。

|  |  |
| --- | --- |
|  |  |

### 4.调整左侧端盖安装位置

4.1 使用 H2.0 内六角扳手拧松固定 X 轴端盖和固定吐料组件的 2 颗螺丝。

|  |  |
| --- | --- |
|  |  |

4.2 把端盖按逆时针方向往内拔一下，使整个吐料组件更靠近热床方向，此时，左侧端盖与 X 轴导轨的端面会有一个小夹角。

|  |  |
| --- | --- |
|  |  |

4.3 用手将吐料组件保持在调整后的状态，重新将 2 颗螺丝锁紧即可。

### 5. 清理吐料组件的齿条

5.1 移除位于吐料组件下方的螺丝，拧下螺丝后，您可以将废料组件从支架中根据图片示意方向滑出。

|  |  |
| --- | --- |
|  |  |

5.2 使用 H1.5 内六角扳手拧松吐料组件底部的 4 颗螺丝，打开吐料组件的底盖，检查齿条和齿轮上是否有异物，如有异物则请清理。

|  |  |  |
| --- | --- | --- |
|  | 齿条上有异物 |  |

5.3 清理请检查挡板是否可以正常移动，如果可以正常移动，则使用 H1.5 内六角扳手拧回四颗吐料组件底板固定螺丝，然后将吐料组件装回 X 轴，并使用 H2.0 内六角扳手拧紧一颗固定螺丝。

### 6. 调整吐料组件

如果您的吐料组件由于变形导致无法正常回弹，一只手按住挡板，另外一只手掰回吐料组件使其恢复到正常位置。

![修复.webp](https://wiki.bambulab.com/a1-mini/%E4%BF%AE%E5%A4%8D.webp)

> **注意：掰回的时候请小心用力，避免将金属件与塑料件连接处掰断。**

|  |  |  |

### 7. 卡扣断裂

如果吐料组件的卡扣断裂，您可以使用 502 胶水粘接卡扣。
