## 何时需要使用该指南

连接电源线并打开电源后，打印机的显示屏没有被点亮。与此同时，一个或多个电路板指示灯发生故障。我们可能可以观察到：

- 屏幕不亮，但 HMS 指示灯常亮，且呈缓慢的呼吸状态;
- 屏幕不亮，HMS 指示灯也不亮。

## 排查须知

在开始正式的故障排查之前首先需要了解主板、工具头、HMS 灯语状态情况。

### TH 板指示灯正常状态

拉住后盖底部，小心撬开后盖，绿灯常亮说明工作正常。

<https://public-cdn.bblmw.com/wiki/video/A1M-TH.mp4>

### 主板指示灯正常状态

#### MC 板每 5 秒闪烁一次绿灯（该指示灯需要在特定的角度下观察）

<https://public-cdn.bblmw.com/wiki/video/A1M-MC.mp4>

#### AP 板每秒闪烁一次绿灯

<https://public-cdn.bblmw.com/wiki/video/A1M-AP.mp4>

### HMS 指示灯正常状态

当出现 HMS 错误时会快速闪烁，提示用户查看 HMS 错误信息。当没有 HMS 信息时，如果屏幕是点亮的，该指示灯是常亮的，如果屏幕没有点亮，该指示灯是缓慢的呼吸。

![hms_指示灯.png](https://wiki.bambulab.com/a1-mini/circuit-fault/hms_%E6%8C%87%E7%A4%BA%E7%81%AF.png)

### 安全提示

> **重要提醒 ！**  
> 本篇故障排查指南存在较多接头的插拔，**在对打印机及其电子设备（包括工具头线缆）进行任何维护或插拔接头工作之前，请关闭打印机电源并断开电源连接**，以避免带电操作发生电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 所需工具

- H2.0 内六角扳手
- H1.5 内六角扳手
- 万用表（非必须）

## 1. 屏幕不亮， HMS 指示灯亮

### 问题现象

启动打印机，显示屏黑屏无显示，HMS 指示灯常亮且呈缓慢的呼吸状态， 主板灯语正常。

### 排查建议

MicroSD 卡或屏幕可能故障，如果问题未解决，请进一步排查主板电路。

![情况1_cn.png](https://wiki.bambulab.com/a1-mini/circuit-fault/%E6%83%85%E5%86%B51_cn.png)

### 原因及解决方案

1. MicroSD 卡故障导致黑屏，更换 MicroSD 卡;
2. 屏幕排线松动，重新插拔排线；
3. 屏幕排线损坏，更换屏幕;
4. 屏幕损坏，更换屏幕。

### 排查指引

#### 一. 排查 MicroSD 卡

启动打印机后，若显示屏黑屏无显示，首先可排查 MicroSD 卡问题。

> **注意事项**：在进行以下操作前，请务必先关闭打印机电源。

1. 关闭打印机电源，并小心地从打印机中拔出 MicroSD 卡。
2. 重启打印机，观察显示屏是否能正常亮起。若显示屏在拔出 MicroSD 卡后能正常显示，那么请在关机状态下将 MicroSD 卡重新插入打印机，并再次开机以验证是否因 MicroSD 卡故障导致之前的黑屏问题。
3. 若确认是 MicroSD 卡故障导致黑屏，请更换 MicroSD 卡。

#### 二. 排查显示屏排线

拆开底板，若观察**电源指示灯，主板指示灯灯语正常**，可以判断为屏幕故障或者连接排线异常导致。

1. 断电并关闭打印机电源，移除 A1 mini 底板。

将打印机侧放，使Z轴支柱平行于桌面，并拧下下图所示的16颗螺丝。

请注意，第15号和第16号螺丝是不同的，请记住它们对应的位置，以便在重新安装底部外壳时使用。

|  |  |
| --- | --- |
|  |  |

卸下螺丝后，轻轻撬出外壳。可以从右上方开始，绕着外壳边缘轻轻转动，直到外壳松动。

2. 在拆开底板后，您可以将打印机再次接通电源，**但是在接通电源期间请不要触碰打印机任何部件，观察完打印机的指示灯状态后部请重新关闭打印机并拔出电源插头。**
3. 若全部指示灯均正常（见不同指示灯灯语于文章开头），请重新插拔屏幕排线，并检查接口和PIN针有无异常，FPC 排线（图中绿框）有无损伤。

4. 如若屏幕依旧异常则需要更换屏幕组件。

[A1 mini 更换触摸屏](../maintenance/touchscreen-replacement-guide.md)可参考 Wiki 文章。

## 2. 屏幕不亮， HMS 指示灯也不亮

### 问题现象

启动打印机，显示屏黑屏无显示，HMS 指示灯不亮。

### 排查建议

HMS 指示灯不亮，说明打印机主板或电源模块电路发生故障，建议排查主板及 TH 板电路。  
![流程排查图_a1_mini.png](https://wiki.bambulab.com/a1-mini/circuit-fault/%E6%B5%81%E7%A8%8B%E6%8E%92%E6%9F%A5%E5%9B%BE_a1_mini.png)

### 原因及解决方案

1. 电源供电异常，需更换电源或电源连接线；
2. 主板供电异常，需检查主板-电源连接线；
3. 主板损坏，需更换主板；
4. 主板上零件异常，导致主板短路；
5. TH 板或其板上零件异常，导致短路。

### 排查指引

拆开底板，若观察**电源指示灯，主板 MC 及 AP 指示灯灯语；排查 TH 板，请揭开工具头后盖，并观察其灯语是否正常。**

#### 一. 断电并拆开打印机底板观察灯语

**1. 断电并关闭打印机电源，移除 A1 mini 底板。**

将打印机侧放，使Z轴支柱平行于桌面，并拧下下图所示的16颗螺丝。

请注意，第15号和第16号螺丝是不同的，请记住它们，以便在重新安装底部外壳时使用。

|  |  |
| --- | --- |
|  |  |
|

卸下螺丝后，轻轻撬出外壳。可以从右上方开始，绕着外壳边缘轻轻转动，直到外壳松动。

**2. 观察指示灯**  
在拆开底板后，您可以将打印机再次接通电源以观察灯语，**但是在接通电源期间请不要触碰打印机任何部件，观察完打印机的指示灯状态后部请重新断电并拔出电源插头。**

#### 二. 若电源指示灯不亮

**1. 检查 24V 电源模块是否输出异常**

打印机主板的输入电压为24V，由 24V 电源模块提供。如果电源模块输出异常，将导致输入主板的的输入电压异常，从而引起所有的指示灯无法点亮；则需要更换电源模块。

a）检查 24V 电源模块指示灯以及接线端子插接是否正常，正常状态为绿灯常亮。

![电源指示灯.png](https://wiki.bambulab.com/a1-mini/circuit-fault/%E7%94%B5%E6%BA%90%E6%8C%87%E7%A4%BA%E7%81%AF.png)

b) 如果指示灯不亮或者是闪烁的，请拧下三颗螺丝并拆开电源模块以进一步排查。

![电源模块螺丝.png](https://wiki.bambulab.com/a1-mini/circuit-fault/%E7%94%B5%E6%BA%90%E6%A8%A1%E5%9D%97%E8%9E%BA%E4%B8%9D.png)

c) 用万用表测 +Vo 及 -Vo 两端的电压，若电压为0，说明电源可能异常或主板短路。若无万用表：可以尝试拧松下图 2 个螺丝取出主板供电线缆，此时电源模块没有外部干扰，插上电源打开打印机开关，若指示灯依旧异常可以判断电源模块故障，[更换电源模块](../maintenance/power-supply-replacement-guide.md)。

> **注意**：接通电源期间请不要触碰打印机任何部件，观察完打印机的指示灯状态后部请重新关闭打印机并拔出电源插头。

![万用表测电压.png](https://wiki.bambulab.com/a1-mini/circuit-fault/%E4%B8%87%E7%94%A8%E8%A1%A8%E6%B5%8B%E7%94%B5%E5%8E%8B.png)

**2. 检查主板是否输出异常**

若移除主板供电线缆之后，电源指示灯恢复正常并且有 24V 电源输出，可能是主板或者后级某个电路板短路导致需要跟着后文内容，以进一步排查故障。

> 打印机内部的电路板 24V 电源是串联连接的。如果主电路或分支电路（主板、工具头主板等某个电路板，或电路板上的风扇、加热器、电机等部件）中有任何一个发生短路，可能会导致整个 24V 系统发生短路。

![a1_mini_电路图4.jpg](https://wiki.bambulab.com/a1-mini/circuit-fault/a1_mini_%E7%94%B5%E8%B7%AF%E5%9B%BE4.jpg)

#### 三. 若电源指示灯亮，主板指示灯异常

如果 MC 板和/或 AP 板灯闪烁异常，说明主板异常，可能是：

- 主板的电源连接线损坏；
- 主板次级电路出现短路；
- 主板损坏。

![主板灯不亮.png](https://wiki.bambulab.com/a1-mini/circuit-fault/%E4%B8%BB%E6%9D%BF%E7%81%AF%E4%B8%8D%E4%BA%AE.png)

1. 主板供电异常，检查主板-电源连接线

如果家中有万用表，可以尝试测量一下主板上这两端的电压是否为 0（非必须），这是主板的直流电源输入端，如果为0说明主板电源连接线可能有损坏。

![万用表测电压2.png](https://wiki.bambulab.com/a1-mini/circuit-fault/%E4%B8%87%E7%94%A8%E8%A1%A8%E6%B5%8B%E7%94%B5%E5%8E%8B2.png)

2. 主板损坏或主板上零件异常，导致主板短路

|  |
| --- |
| 1. 工具头 USB-C 线缆；2. 屏幕；3. Y 电机；4. X 电机；5. Z 电机；6. Y 涡流传感器；7. 实况摄像头；8. 主板散热风扇； 9. 主板供电；10. 热传供电；11. 热床信号线；12. AMS lite；13. SD 卡槽 |
|

a) 断开电源，将主板上全部部件排线拔出，再次打开电源开关测试看主板灯语是否正常点亮。

若**主板正常**，此时开机后主板上的两颗指示灯会正常亮起若仍没有正常点亮，说明主板损坏，请[更换主板](../maintenance/mc-board-replacement-guide.md)。

b) 若主板指示灯重新亮起，说明主板上的其他部件存在短路或 TH 板发生故障。

请依次插上主板上的部件排线，并依次开机检测主板指示灯是否再次异常，以排查哪个部件发生短路，更换对应部件。

> **注意**：插拔部件时，请注意保持断电状态，以免损坏主板。

c）通过排查，若发现插上 TH 主板对应排线后，主板指示灯熄灭或闪烁。

这种情况说明问题是 TH 主板故障导致，需要进一步排查 TH 主板。

3. TH 板或其板上部件异常，导致短路。

揭开工具头后盖，观察 TH 板指示灯是否常亮绿灯，若指示灯常亮，TH 板可能损坏，请[更换 TH 板](../th-board-replacement-guide.md)。若指示灯不亮，断电后拔下 TH 板上所有部件排线，重新开机查看指示灯是否恢复。

|  |  |
| --- | --- |
|  |  |
|

a）若指示灯恢复，说明 TH 板上存在部件短路。

|  |
| --- |
| 1. 热端加热组件；2. 霍尔开关板；3. USB-C；4. 空缺；5. 挤出电机；6. TH 板指示灯；7. 涡流传感器；8. 热端风扇； 9. 部件风扇；10. 空缺 |
|

请依次插上 TH 板上的部件排线，并依次开机检测指示灯是否再次异常，以排查哪个部件发生短路，更换对应部件。

> 注意：插拔部件时，请注意保持断电状态，以免损坏主板。

b）若指示灯未恢复，说明 TH 板损坏，请[更换 TH 板](../th-board-replacement-guide.md)。
