## 视频教程

## 适用打印机型号

A1 mini

## 何时使用

前后移动热床，发出异响。

## 所需工具和材料

- 清洁布
- H2.0扳手
- 棉签
- 润滑脂
- 润滑油

![工具.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E5%B7%A5%E5%85%B7.png)

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，**请关闭打印机电源并断开电源连接**，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，**避免在高温状态下操作**，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 操作步骤

### 移除 Y 轴后盖

步骤 1. 关闭电源。

![关电源.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E5%85%B3%E7%94%B5%E6%BA%90.png)

步骤 2. 将热床前移。

![热床前移.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E7%83%AD%E5%BA%8A%E5%89%8D%E7%A7%BB.png)

步骤 3. 移除 Y 轴后盖螺丝。

![拆除螺丝.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E6%8B%86%E9%99%A4%E8%9E%BA%E4%B8%9D.png)

步骤 4. 取下 Y 轴后盖。

![移除后盖.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E7%A7%BB%E9%99%A4%E5%90%8E%E7%9B%96.png)

### 润滑涡流线圈及 Y 轴皮带

步骤 1. 移除涡流线圈螺丝。

![移除涡流线圈螺丝.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E7%A7%BB%E9%99%A4%E6%B6%A1%E6%B5%81%E7%BA%BF%E5%9C%88%E8%9E%BA%E4%B8%9D.png)

步骤 2. 将涡流线圈底座朝上，并用清洁布擦拭。

|  |  |
| --- | --- |
|  |  |

步骤 3. 用棉签蘸取润滑脂，将其均匀涂抹在涡流线圈上。

|  |  |
| --- | --- |
|  |  |

步骤 4. 将润滑油涂抹在 Y 轴皮带表面。

![涂抹润滑油.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E6%B6%82%E6%8A%B9%E6%B6%A6%E6%BB%91%E6%B2%B9.png)

步骤 5. 用清洁布按紧 Y 轴皮带，并前后推动热床，使润滑油均匀涂抹。

|  |  |
| --- | --- |
|  |  |

### 安装涡流线圈及 Y 轴后盖

步骤 1. 放回涡流线圈并上提，防止刮到皮带。

![装回涡流线圈.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E8%A3%85%E5%9B%9E%E6%B6%A1%E6%B5%81%E7%BA%BF%E5%9C%88.png)

步骤 2. 安装涡流线圈螺丝。

![安装涡流线圈螺丝.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E5%AE%89%E8%A3%85%E6%B6%A1%E6%B5%81%E7%BA%BF%E5%9C%88%E8%9E%BA%E4%B8%9D.png)

步骤 3. 安装 Y 轴后盖。

![安装_y_轴后盖.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E5%AE%89%E8%A3%85_y_%E8%BD%B4%E5%90%8E%E7%9B%96.png)

步骤 4. 安装 Y 轴后盖螺丝。

![安装后盖螺丝.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E5%AE%89%E8%A3%85%E5%90%8E%E7%9B%96%E8%9E%BA%E4%B8%9D.png)

### 检测效果

前后拉动热床，检验效果。

![测试效果.png](https://wiki.bambulab.com/a1m/troubleshooting/heatbed-repair/%E6%B5%8B%E8%AF%95%E6%95%88%E6%9E%9C.png)
