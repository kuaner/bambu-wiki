## 适用机型

A1 系列打印机

## 首层偏低

对于 3D 打印机来说，首层的打印效果至关重要的。如果首层没打好，那么整个模型打印失败的可能性将会增加。

所谓的**首层偏低**，即在打印首层时，**喷嘴与打印板之间的距离过近**，它会导致类似 **“起皮“，”凸起“，”波浪纹”等首层问题**。

## 何时使用？

- 打印首层的时候，出现 **“起皮“，”波浪纹”** 或 产生**凸起边缘**等现象；
- 或 **喷嘴太靠近打印板**，几乎贴着打印板表面，**剐蹭打印板**，导致几乎无法挤出耗材。

### 问题原因

1. 未进行热床调平操作，特别是打印板换面或更换了打印板后，新发布的打印任务未执行热床调平，与原先的调平数据有差异；
2. 打印时热端的位置相比于调平时出现变化，喷嘴更靠近热床导致首层过度挤压。

## **解决方案**

### 步骤一：热床调平（首选方案）

1. 发起打印时，勾选热床调平，进行一次热床调平操作，特别是 PEI 打印板换面，或更换了打印板；

![](https://wiki.bambulab.com/n1/troubleshooting/fist-layer-issues/bed_leveling_cn.jpg)

2. 执行过热床调平后，若情况并没有改善，可以参考下文，**重新锁紧合成石固定螺丝**。

### 步骤二：锁紧合成石螺丝

1. 通过显示屏确认热端处于低温（50摄氏度以下）状态，关闭打印机电源，移除工具头前盖，然后根据贴附在挤出机表面的指引贴纸的内容，将热端拆下。

|  |  |
| --- | --- |
|  |  |

2. 用 H2.0 内六角扳手移除3颗固定加热组件的螺丝，将加热组件从上往下翻转过来，露出背面的 4 颗小螺丝，用 H1.5 内六角扳手将螺丝重新拧紧。

注意：螺丝比较小，确认锁到底即可，避免因用力过猛引起螺丝滑牙。

|  |  |
| --- | --- |
|  |  |

> **注意** ：三颗固定加热组件螺丝规格为 M3\*10；背后小四颗螺丝规格为 M2\*6（带有平垫片和弹簧垫片）。

3. 重新扣好热端加热组件。

**请务必确保加热组件已经正确扣紧（请参考下图）并固定紧热端，可以手动检查看热端是否有明显晃动。**

**注意：** 如果加热组件未正确扣紧，或者夹子损坏导致无法固定住热端，在打印过程中，挤出压力会导致热端更靠近热床，从而造成打印首层堆料溢出，甚至喷嘴刮蹭打印板。

![扣紧卡扣.webp](https://wiki.bambulab.com/a1m/troubleshooting/nozzle-clog/%E6%89%A3%E7%B4%A7%E5%8D%A1%E6%89%A3.webp)

4. 重新将设备安装好，启动打印机后在校准界面找到自动热床调平，对打印机进行自动调平。
