- 如果报错弹窗提示如下，请参考解决方案1。

- 如果报错弹窗提示如下，请参考解决方案2。

## 缠料检测原理

工具头上方有个缠料检测装置。当AMS送料阻力过大时，缠料检测模块会被下压，触发工具头内部的霍尔传感器，打印机就会判断送料阻力过大。缠料检测模块正常送料和检测到缠料的状态对比如下：

![](https://wiki.bambulab.com/n1/hms/filament-position-check/未触发缠料检测.png)

**正常送料状态**

![](https://wiki.bambulab.com/n1/hms/filament-position-check/触发缠料检测.png)

**检测到缠料模块下压**

- 如果是在**打印过程中**，当缠料检测装置被触发时，打印机将自动切断耗材并退料，暂停然后报错。解决缠料问题后，请单击“重试”以继续打印。
- 如果是在**AMS给挤出机送入料线（含换料）过程中**，挤出机会先挤出一段料线确保咬合成功。如果是在这个过程缠料检测模块被触发，打印机也将暂停并报告错误。由于此时AMS无法自行退料解决缠结等问题，请优先参考下文**方案2**解决缠料问题后**，**点击“重试”继续打印。

缠料检测功能并不适用所有类型的耗材丝，详情可以参考这篇wiki了解更多：[缠料检测模块介绍 | Bambu Lab Wiki](../../../ams-lite/manual/filament-tangle-monitoring-intro.md)

## 方案1

1. 检查料盘上的耗材丝是否缠绕打结。如果缠绕，请手动将耗材丝重新整理好，再插入AMS插槽并单击“重试”按钮。

![](https://wiki.bambulab.com/n1/hms/filament_stuck/ams_stuck.png)

2. 有时候耗材可能被夹在料盘边缘导致无法送出，请将其拉出后再次重试。

![](https://wiki.bambulab.com/n1/hms/filament_stuck/sink2.png)

3. 如果耗材没有缠结或下陷的问题，请检查此槽连接的PTFE管是否弯曲过多或过长，这也会造成进料路径阻力过大。1、2号槽的标准长度为580mm，3、4号槽的标准长度为700mm。打印机和AMS的最佳位置如下图1所示。如果打印机和AMS相距较远，PTFE管将被拉弯，导致进料阻力变大，如下图2所示。

![](https://wiki.bambulab.com/n1/hms/filament_stuck/good_place.png)

**图1. 打印机和AMS的最佳放置位置**

![](https://wiki.bambulab.com/n1/hms/filament_stuck/bad_place.png)

**图2. 料管弯曲过多容易导致进料失败**

4. 检查AMS lite对应槽的上下料器齿轮上是否有残留的料屑。请清理干净，然后单击重试按钮。

5. 请确认是否料线插错槽位了，例如把1号槽的料线错插入到2号槽的上下料器中，如下图所示：

![](https://wiki.bambulab.com/f1/hms/filament-tangled/料线插错槽.jpg)

6. 如果您无法通过上述操作步骤解决，请创建工单联系我们售后支持团队。

## 方案2

1. 先检查料盘上的料是否缠结或者下陷了，以及料管是否装错或者AMS Lite与打印机摆放的距离过远，如解决方案1中所示。 处理好后，请手动按压工具头切刀刀柄切断耗材丝。

![](https://wiki.bambulab.com/n1/hms/filament-position-check/press1.png)

2. 用手动按压工具头的从动轮支架并从上下料器这一端拉出耗材，然后再把它重新插入插槽中并点击重试。

|  |  |
| --- | --- |
|  |  |

3.拔出耗材丝后，检查材料是否有磨损的迹象。如果有，将磨损的部分切掉，然后再将耗材插入AMS中重试一遍。

![](https://wiki.bambulab.com/n1/hms/filament-position-check/cut.png)

4. 若问题仍存在，请检查挤出机或者热端是否堵塞，如果喷嘴和挤出机都未堵塞，可以检查耗材丝是否线径过细，耗材丝是否与挤出机齿轮打滑等，也可以更换一卷耗材丝再次尝试。若多卷材料都会遇到这个问题，也有可能是挤出机齿轮异常导致无法顺利咬合耗材丝。

5.  如果你通过以上的步骤仍然无法解决问题，请[提交服务工单](https://bambulab.cn/zh-cn/my/support/tickets?from=5)联系售后支持团队。
