## 这是什么

在你发起进料、退料或启动打印任务时，如果打印机检测到工具头内有耗材丝，则会运行“检查料线位置”步骤。此步骤的目的是确认工具头内的耗材来自AMS的哪个槽或者来自料盘支架。如果在此步骤中出现错误，屏幕将显示如下图所示的提示信息。

![](https://wiki.bambulab.com/n1/hms/filament-position-check/filament_location_1.png)

## 检查料线位置

AMS中的每个上下料器都有里程轮，可以监测送出料线的长度。挤出机向下挤出一段耗材，根据各上下料器内里程轮的数据以确定工具头内的材料来自AMS的哪个槽或来自料盘支架。如果多根耗材丝堵塞在五通内，或材料过细打滑，都可能导致“检查料线位置”步骤失败。

## 解决方法

1. 按压切刀刀柄来手动切料。

![](https://wiki.bambulab.com/n1/hms/filament-position-check/press1.png)

2. 手动按压工具头的从动轮支架并从上下料器这一端拉出耗材。

|  |  |
| --- | --- |
|  |  |

3. 拔出耗材丝后，检查材料是否有磨损的迹象。如果有，将磨损的部分切掉，然后再将耗材插入AMS中重试一遍。

![](https://wiki.bambulab.com/n1/hms/filament-position-check/cut.png)

4. 在点击“重试”按钮之前，请确认工具头内没有耗材丝（可以根据显示屏上的图标判断，工具头图标显示绿点则说明有耗材在工具头内部），并且所有槽的耗材都在五通外。

|  |  |
| --- | --- |
|  |  |

5. 如果你通过以上的步骤仍然无法解决问题，请提交工单联系售后支持团队。
