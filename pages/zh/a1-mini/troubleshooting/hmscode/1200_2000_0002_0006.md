## 报错原因

A1系列打印机配合AMS lite使用时，换料过程和正常打印过程中都会检测耗材是否正常挤出。当检测到异常后，打印机将暂停并报告错误。详情可以参考wiki：[空打检测 | Bambu Lab Wiki](../../../ams-lite/manual/air-printing-detectiong.md)

**换料过程中：** 当AMS送料至挤出机，挤出机会挤出一段新耗材，同时打印机也会检查AMS槽中的里程轮传感器的信息。如果耗材丝的挤出长度不正常，打印机将暂停并报告错误。因为只有进料时挤出足够长度的耗材丝，打印机才能判断AMS lite顺利地将耗材送入挤出机并成功地被咬合上。

**打印过程中：** 当A1系列打印机的固件升级到01.02.00.00版本后，支持打印过程中的**空打检测**。当打印机配合AMS lite打印时，打印机会实时监测挤出机挤出距离和AMS lite对应槽中里程轮传感器信息。当检测到挤出机无法挤出料，正在"空打"，打印机将自动切断耗材，将耗材拉出到工具头,暂停并报告错误。

## 解决方法

1. 如果是在送料过程中报错挤出失败，请手动按压工具头切刀切断耗材丝。若是打印过程中报错挤出失败，请直接调到步骤3。

![](https://wiki.bambulab.com/n1/hms/filament-position-check/press1.png)

2. 并按压从动轮支架，从上下料器这一端拉出耗材。

|  |  |
| --- | --- |
|  |  |

3. 拔出耗材丝后，检查材料是否有磨损的迹象。如果有，将磨损的部分切掉，然后再将耗材插入AMS中重试一遍。

![](https://wiki.bambulab.com/n1/hms/filament-position-check/cut.png)

4. 若问题仍存在，请检查挤出机或者热端是否堵塞（参考[此 wiki](../how-to-check-which-part-is-clogged.md)）。如果喷嘴和挤出机都未堵塞，可以检查耗材丝是否线径过细，耗材丝是否与挤出机齿轮打滑等，也可以更换一卷耗材丝再次尝试。若多卷材料都会遇到这个问题，也有可能是挤出机齿轮异常导致无法顺利咬合耗材丝。

5.  如果你通过以上的步骤仍然无法解决问题，请[提交服务工单](https://bambulab.cn/zh-cn/my/support/tickets?from=5)联系售后支持团队。
