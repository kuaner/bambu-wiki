## 何时需要该指南

情况一：长时间使用打印机后，挤出机组件内部有可能残留有耗材碎屑和灰尘，容易导致挤出齿轮工作时卡顿甚至无法转动的情况。为保证打印机的正常打印，需要及时对挤出机进行异物清理。

情况二：挤出机堵料

## 需要的工具和材料

- 镊子
- 刷子
- 吹气球
- 内六角扳手

## 拆装指引

### 普通清洁

#### 步骤1: 移除喷嘴组件

（如果挤出机处于咬合料线的状态，请使用切刀手动切断料线）从侧面用力按压工具头前盖，解锁并移除工具头前盖，用手扣热端硅胶套侧面的凸起，移除热端硅胶套。

|  |  |
| --- | --- |
|  |  |

取下旋转轮。用 H1.5 内六角扳手移除 2 颗螺丝，取下料线压块。

|  |  |  |
| --- | --- | --- |
|  |  |  |

解除热端锁扣，然后用手握住散热片，将热端取出。

|  |  |  |
| --- | --- | --- |
|  |  |  |

#### 步骤2: 拧松切刀

用 H2.0 内六角扳手移除螺丝，松开切刀刀柄。

|  |  |
| --- | --- |
|  |  |

使用镊子和吹气球从图示位置清理内部的断料和残渣（断电状态下可手动拨动黄色齿轮顺时针旋转清理，开机状态下可点击屏幕退料按钮，让挤出轮旋转到指定角度清理）。

|  |  |
| --- | --- |
|  |  |

当按上面的步骤清理挤出机，无法取得较理想效果时，可以对挤出机进行拆解，取下挤出轮组件进行深度清洁。

### 深度清洁

#### 步骤3: 移除五通

用 H2.0 内六角扳手移除 2 颗螺丝，然后取出五通。需要注意的是，请小心不要损坏黑色的 FPC 线缆，取出五通后可以将其放在工具头上面，如图所示。

|  |  |  |
| --- | --- | --- |
|  |  |  |

#### 步骤4: 移除挤出机前盖

用 H2.0 内六角扳手移除前盖上的 4 颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

移除前盖时，先拧松侧边的螺丝，（只需要拧松一些即可）然后按住从动轮支架的顶部，另一边用力取出挤出机前盖。

|  |  |
| --- | --- |
|  |  |

> 注意：小心前盖轴承脱出，轴承参数：内径4mm，外径10mm，厚度4mm。

#### 步骤5: 移除从动轮支架

用 H2.0 内六角扳手移除侧面螺丝，取出支架的时候内部弹簧和端盖很容易掉落，请用镊子小心取出，防止丢失。

|  |  |
| --- | --- |
|  |  |

#### 步骤6: 移除挤出齿轮

直接取出挤出机齿轮组件，清理挤出机内部残留的耗材的残渣。

|  |  |
| --- | --- |
|  |  |

## 组装指引

### 步骤1: 安装挤出齿轮

安装挤出齿轮。

![](https://wiki.bambulab.com/n1/troubleshooting/extruder-clog/%E7%BB%84%E8%A3%85%E6%AD%A5%E9%AA%A41-%E5%AE%89%E8%A3%85%E6%8C%A4%E5%87%BA%E9%BD%BF%E8%BD%AE.jpg)

### 步骤2: 安装从动轮支架

将从动轮支架安装到对应的转轴上。将弹簧和端盖以**正确的方向和位置**（请参考下方的正确和错误示范）安装到一起，用镊子放到从动轮支架对应的位置上，拧入侧面螺丝将其顶住，但先不要将其拧紧。

|  |  |  |
| --- | --- | --- |
|  |  |  |

> **重要提醒！**
>
> 务必正确安装弹簧和端盖，否则将使得挤出机无法咬合耗材，导致打印失败。

|  |  |
| --- | --- |
| **正确的安装方式** | **错误的安装方式** |

### 步骤3: 安装挤出机前盖

拧入挤出机前盖的 4 颗螺丝。

![](https://wiki.bambulab.com/n1/troubleshooting/extruder-clog/%E7%BB%84%E8%A3%85%E6%AD%A5%E9%AA%A43-%E5%AE%89%E8%A3%85%E6%8C%A4%E5%87%BA%E6%9C%BA%E5%89%8D%E7%9B%96.jpg)

### 步骤4: 拧紧侧面螺丝

拧紧挤出机侧面螺丝。

![](https://wiki.bambulab.com/n1/troubleshooting/extruder-clog/tighten_screw_on_the_side_en.jpg)

### 步骤5: 安装五通

安装五通组件，请确保黑色 FPC 线缆不要被折叠，顺利放入空缺的位置。然后拧入 2 颗螺丝，固定五通。

|  |  |
| --- | --- |
|  |  |

### 步骤6: 安装切刀

抬起刀柄，沿着刀槽将切刀滑入到位，拧紧螺丝，固定刀柄。

|  |  |
| --- | --- |
|  |  |

### 步骤7: 安装喷嘴组件

握住喷嘴散热片，对齐安装位置，将喷嘴安装到位并锁定喷嘴，安装热端硅胶套。拧紧 2 颗螺丝，固定料线压块。

|  |  |  |
| --- | --- | --- |
|  |  |  |

安装旋转轮以及工具头前盖。

|  |  |
| --- | --- |
|  |  |
