Bambu Lab A1 mini 打印机的热床在出厂时是已调整好的，按照手册的指引操作完成后，即可直接打印。 但如果由于运输原因导致热床出现了异常，或因产品维修的需要，拆装或更换过热床，这时我们需要通过手动调平的方式来确保打印机的热床是平整的。

## 调平前的准备

在开始热床手动调平之前，准备工作很重要：

1. 移除热端硅胶套，并检查喷嘴，确保喷嘴清洁且喷嘴上没有材料附着；

![](https://wiki.bambulab.com/n1/bed-leveling/clean_nozzle.jpg)

2. 将热床底下的3颗锁定螺丝拧松；

|  |  |
| --- | --- |
|  |  |

3. 移除打印板，清理热床表面的异物，并将热床调平螺丝拧到与底部支架平齐的状态；

|  |  |
| --- | --- |
|  |  |

> 注意：确保 4 颗调平螺丝于底部支架平齐即可，避免螺丝凸出底部支架或者凹陷进去。

## 开始调平

首先，请将调平Gcode下载到SD卡中，将装有调平Gcode的SD卡插入打印机，然后开启打印机电源。

[a1mini\_manual\_bed\_screws\_adjust\_assist.gcode](https://wiki.bambulab.com/n1/bed-leveling/a1mini_manual_bed_screws_adjust_assist.gcode)

待机器完成启动并能成功识别文件后，选中上述Gcode文件，点击开始打印。

请注意，A1 mini不支持热插拔SD卡，请关闭电源后再插拔SD卡。

|  |  |
| --- | --- |
|  |  |

运行 Gcode 文件后，打印机将进行回中操作，然后移至热床左前方并等待 30 秒。这时，您可以用内六角扳手拧动热床调平螺丝，将喷嘴调成贴近热床的状态。

|  |  |
| --- | --- |
|  |  |

温馨提示：顺时针是拧紧调平螺丝，会使热床与喷嘴的距离增加；反之，逆时针是拧松调平螺丝，会使热床更加靠近喷嘴。

|  |  |  |
| --- | --- | --- |
|  |  |  |

当您发现中喷嘴开始主动抬升时，请务必停止调平的动作并移走内六角扳手，因为工具头要开始移动了。

（30 秒后）喷嘴将移动到热床右前方， 重复调整操作，使得热床刚好不接触喷嘴。，然后是热床右后方和热床左后方，分别完成调整。

当第一次调平完成后，该过程将再会重复两次，以便您微调并仔细检查喷嘴和热床之间的距离。整个Gcode的运行时间约8分钟。

确认完成调整后，最后请将锁定热床的3颗螺丝拧紧。

![](https://wiki.bambulab.com/n1/bed-leveling/3_screws.jpeg)

建议先插入扳手，然后用手固定扳手和打印板，防止螺丝脱落。

![](https://wiki.bambulab.com/a1m/manual/unbox/%E7%94%A8%E6%89%8B%E5%9B%BA%E5%AE%9A.jpg)

## **设备校准**

在打印机屏幕中点击 **设置 > 维护 > 校准**，开始进行校准。 如果一切正常，并且校准过程中没有出现错误或警告，则调平成功。如果仍有问题，请联系服务团队寻求进一步帮助。

![](https://wiki.bambulab.com/a1/maintenance/heatbed/20250115-171322.jpg)
