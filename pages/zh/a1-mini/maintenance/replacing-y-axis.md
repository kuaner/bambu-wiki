## Y轴轨道

![](https://wiki.bambulab.com/n1/a1-mini-printer/y%E8%BD%B4%E5%AF%BC%E8%BD%A8.png)

## 工具

- H2.0/H1.5 内六角扳手
- 剪钳
- 尖嘴钳

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 更换步骤

### 移除底板

向后放倒打印机，用 H2.0 内六角扳手移除 2 颗螺丝，再移除 14 颗螺丝，拉扯尼龙扎网使底板松动，移除底板。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 移除热床

正放打印机，在热床支架上移除 3 颗热床固定螺丝;

|  |  |  |
| --- | --- | --- |
|  |  |  |

用手压住热床，用 H2.0 内六角扳手移除 4 颗调平螺丝，取下热床和调整弹簧。

|  |  |
| --- | --- |
|  |  |

### 移除Y轴轨道

向后推动热床支架,露出连接板的 2 颗螺丝（图一）并将螺丝完全拧松，然后移除滑车上的 2 颗螺丝（图二），取下连接板;

|  |  |  |
| --- | --- | --- |
|  |  |  |

移除 2 颗螺丝,取下 Y 轴后盖;

|  |  |
| --- | --- |
|  |  |

移除 4 颗轨道螺丝，移除 Y 轴轨道，取下轨道时，请同时拿着支架和轨道，防止滑落。

|  |  |
| --- | --- |
|  |  |

### 安装Y轴轨道

将Y轴线轨放置到底座上，对齐螺丝孔，放入 4 颗螺丝，交替锁紧;  
![](https://wiki.bambulab.com/n1/a1-mini-printer/%E5%AE%89%E8%A3%85y%E8%BD%B4%E7%BA%BF%E8%BD%A8-4.png)

移动热床支架，露出 Y 轴同步带压块，然后安装连接板，确认卡到位，锁 2 颗螺丝固定连接板；

|  |  |  |
| --- | --- | --- |
|  |  |  |

然后透过底座，锁紧 2 颗螺丝，移动热床支架，确认热床支架能带动 Y 皮带运动且动作顺畅。

|  |  |
| --- | --- |
|  |  |

安装 Y 轴后盖，锁入 2 颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 安装热床

将 4 个弹簧用胶水预固定到对应位置上，对齐弹簧位置，放置热床，从热床底下确认热床上的 3 个固定片都在热床支架的外侧；

> 涂胶主要是为了便于安装弹簧,没有其他特殊的用途，如果弹簧已经固定好了，则可以不用胶水固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

放入 4 颗调平螺丝，用手将热床调平弹簧压缩，使调平螺丝能够进行锁定，全部锁紧后，再统一将这 4 颗调平螺丝拧松 1 圈；安装 3 颗热床固定螺丝，但不要锁紧，这 3 颗螺丝需要在完成热床的手动调平后再锁紧;

|  |  |
| --- | --- |
|  |  |

### 安装底板

安装底板，对齐位置后，锁入 14 颗螺丝固定; 然后安装走线夹，锁 2 颗螺丝固定；正放打印机。

|  |  |  |
| --- | --- | --- |
|  |  |  |
