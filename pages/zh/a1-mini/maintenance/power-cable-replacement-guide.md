## 电源线/电源开关

以下我们将展示更换 A1 mini 电源线和电源开关的过程。  
![a1_mini_power_cable.jpg](https://wiki.bambulab.com/a1-mini/a1mini-power-cable-switch/a1_mini_power_cable.jpg)

## 何时使用

A1 mini 电源线/开关导致的常见问题包括：

- 频繁断电
- 设备开机不上电
- 物理损坏
- 拓竹技术支持建议更换

## 所需工具和材料

- A1 mini 的 电源线以及开关。
- H2.0 内六角螺丝刀
- PH2 十字螺丝刀
- 20分钟

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。  
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 移除旧的电源线和开关

### 1. 取出打印机底部外壳

将打印机侧放，Z 轴立柱朝向桌子；  
移除固定底盖的 16 颗螺丝；移除螺丝后，可以从右上方开始环绕打印机轻轻撬开塑料底壳。

> 注意:螺钉 15# 和 16# 与其他螺丝是不同的，建议分开放置，以便在重新安装打印机底板时使用。

![](https://wiki.bambulab.com/a1-mini/a1min-wifi-replacement/remove_bottom_cover_screws_for_a1_mini.jpeg )

### 2. 移除电源模块护板

移除固定护板的三颗螺丝，即可看到 24V 电源接线端子 。

> 注意：3# 螺丝在侧面。

![remove_the_plastic_wire_cover.jpeg](https://wiki.bambulab.com/a1-mini/a1mini-power-cable-switch/remove_the_plastic_wire_cover.jpeg)

### 3. 移除旧的电源开关

压住开关边缘凸起的位置，会松开固定开关的卡扣；同时向外推出开关，只退出一半即可。

|  |  |
| --- | --- |
|  |  |

接下来需要移除开关的线缆；捏住开关从另外一端断开线缆，也可以使用钳子辅助。  
断开之后可以完全取下来电源开关。  
![a1_mini_power_switch_wires.jpg](https://wiki.bambulab.com/a1-mini/a1mini-power-cable-switch/a1_mini_power_switch_wires.jpg)

### 4. 断开电源线与电源模块的连接

使用 PH2 十字螺丝刀拧松三颗端子固定螺丝（不用完全移除），断开电源线和电源模块的连接。  
![attach_the_power_cable_wires_to_the_power_supply.jpeg](https://wiki.bambulab.com/a1-mini/a1mini-power-cable-switch/attach_the_power_cable_wires_to_the_power_supply.jpeg)

### 5. 移除打印机电源线

最后，卸掉电源线的固定螺丝，即可移除电源线。  
![remove_the_power_cable_from_the_a1_printer.jpeg](https://wiki.bambulab.com/a1-mini/a1mini-power-cable-switch/remove_the_power_cable_from_the_a1_printer.jpeg)

## 安装新的电源线

### 1. 将新电源线连接到打印机

将电源线安装到对应的支架，锁紧螺丝，注意不要过度锁紧。  
需要确定电源线扁平的一面朝向打印机底座。  
![attach_the_power_cable_to_the_printer.jpeg](https://wiki.bambulab.com/a1-mini/a1mini-power-cable-switch/attach_the_power_cable_to_the_printer.jpeg)

### 2. 安装电源开关

电源开关推到打印机外壳一半位置，同时需要确保“关闭”位置朝向打印机底部。  
不用完全推入需要为下一步连接线缆留出空间。  
![push_the_power_switch.jpeg](https://wiki.bambulab.com/a1-mini/a1mini-power-cable-switch/push_the_power_switch.jpeg)

### 3. 将棕色线缆连接到开关

此步骤中需要将棕色连接重新安装到电源开关上。  
首先，需要将电源线连接到开关后边的插针上，再将单独的棕色线缆连接到前边的插针上。

|  |  |
| --- | --- |
|  |  |

安装好两两根线缆之后，可以将电源开关压入机身外壳。

### 4. 将电源线连接到电源模块接线端子

接下来需要将线缆连接到电源模块的端子上并锁紧螺丝，接线如下图所示。

#### 中国、欧洲、英国、澳洲、阿根廷版本（棕蓝）

1. 火线（棕色）
2. 零线（蓝色）
3. 地线（黄色）

连接方法如图所示：

![attach_the_power_cable_wires_to_the_power_supply.jpeg](https://wiki.bambulab.com/a1-mini/a1mini-power-cable-switch/attach_the_power_cable_wires_to_the_power_supply.jpeg)

#### 美国、日本版本（绿白）

1. 火线（黑色）
2. 零线（白色）
3. 地线（绿色）

连接方法如图所示：

![美日.jpg](https://wiki.bambulab.com/a1-mini/a1mini-power-cable-switch/%E7%BE%8E%E6%97%A5.jpg)

### 5. 安装带能源模块护板

然后将护板安装到位锁紧三颗固定螺丝。

注意不要过度拧紧，否则可能会损坏塑料孔滑丝。  
![remove_the_plastic_wire_cover.jpeg](https://wiki.bambulab.com/a1-mini/a1mini-power-cable-switch/remove_the_plastic_wire_cover.jpeg)

### 6.整理内部排线。

安装底壳之前需要确保主板内部线缆布线正确，避免干扰散热风扇和挤压。

![](https://wiki.bambulab.com/a1-mini/a1min-wifi-replacement/a1_mini_board_and_wire_managemet.jpg)

### 7.安装打印机底壳。

首先拧紧 15# 和 16# 螺丝，确保侧面线缆布线正确；安装其余 14 颗螺丝，注意不要过度拧的锁紧。

  
![](https://wiki.bambulab.com/a1-mini/a1min-wifi-replacement/remove_bottom_cover_screws_for_a1_mini.jpeg )

### 功能验证

为了确保打印机可以正常工作，完成所以安装后可以通电并打开电源开关测试。

## 潜在问题及解决方案

安装完成电源线和电源开关之后可能会遇到其他功能故障，请参考如下方案进行排查。

### 打印机无法开机

检查安装[步骤 三、四](#A)  ，确保线缆正确连接。
