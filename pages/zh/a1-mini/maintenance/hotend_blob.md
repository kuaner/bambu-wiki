## 热端裹头

热端裹头，是指热端周围堆积大量耗材。当模型由于各种原因在前几层打印时出现脱落，脱落的模型有几率附着在喷嘴上，随着喷嘴的不断挤出最终导致较严重“裹头”情况。

![裹头.webp](https://wiki.bambulab.com/n1/maintenance/hotend_blob/%E8%A3%B9%E5%A4%B4.webp)

热端裹头是 3D 打印中较为灾难性的打印问题之一，但需要清理它也不是完全不可能，A1 系列工具头设计的比较紧凑，在一定程度上也增加了清理裹头材料的难度。为了帮助和引导用户完成清理的操作，我们准备了这篇文章，希望能帮助大家确认损坏情况并减少配件的二次损坏。

## 处理前的准备

### 一、 工具

- 吹风机（高温档）
- 平头镊子
- 纸巾
- 隔热手套
- H1.5/H2.0 内六角扳手

![](https://wiki.bambulab.com/n1/maintenance/hotend_blob/tools.jpg)

### 二、设置打印机的状态

#### 升起工具头，并将热床前移

点击屏幕上的按钮，抬高 X 轴以增加操作空间。

|  |  |
| --- | --- |
|  |  |
|  |  |

#### 打开维护模式

进入维护模式，可将热端在操作过程中保持加热状态。

|  |  |
| --- | --- |
|  |  |
|  |  |

#### 加热热端

将热端温度设置成比耗材打印温度稍高，以便软化耗材。以 PLA 材料为例，可将热端升温至 250℃。

|  |  |
| --- | --- |
|  |  |
|  |  |

> **注意**：考虑到安全问题，在非打印机正常工作状态的情况下，热端在高温状态下保持一段时间后会停止加热，如果您在这段时间内没有处理完，请重新加热热端。

## 安全提示

> **重要提醒 ！**  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 裹头清理

完成上面的准备工作后，可正式开始清理裹头。

> 注意：在清洁过程中需要尽量避免将工具头从 X 轴线性导轨移除，否则可能会导致滑块内的滚珠脱落。

### 拆除风扇

步骤 1. 取下工具头前盖。

![](https://wiki.bambulab.com/blob-cleaning/%E5%B7%A5%E5%85%B7%E5%A4%B4%E5%89%8D%E7%9B%96.png)

步骤 2. 取下固定热端风扇的两颗螺丝。

![](https://wiki.bambulab.com/blob-cleaning/%E6%8B%86%E9%99%A4%E4%B8%A4%E9%A2%97%E8%9E%BA%E4%B8%9D.png)

步骤 3. 取下固定部件冷却风扇的三颗螺丝。

![](https://wiki.bambulab.com/blob-cleaning/%E6%8B%86%E9%99%A4%E4%B8%89%E9%A2%97%E8%9E%BA%E4%B8%9D.png)

步骤 4. 向下轻拉部件冷却风扇。

![](https://wiki.bambulab.com/blob-cleaning/%E6%8B%86%E9%99%A4%E9%83%A8%E4%BB%B6%E5%86%B7%E5%8D%B4%E9%A3%8E%E6%89%87.png)

如果裹头较为严重，无法直接拆下。您可以强行扯下部件冷却风扇（可能会损坏螺丝孔位），然后从背面拧下 4 颗螺丝，移除热端加热组件。

![裹头强行拆部件冷却风扇.jpg](https://wiki.bambulab.com/n1/maintenance/hotend_blob/%E8%A3%B9%E5%A4%B4%E5%BC%BA%E8%A1%8C%E6%8B%86%E9%83%A8%E4%BB%B6%E5%86%B7%E5%8D%B4%E9%A3%8E%E6%89%87.jpg)

### 清洁热端硅胶套

步骤 1. 戴上耐热手套，取下硅胶套并立即清洗干净。

![](https://wiki.bambulab.com/blob-cleaning/%E6%88%B4%E4%B8%8A%E7%A1%85%E8%83%B6%E6%89%8B%E5%A5%97.png)

步骤 2. 需确保清洗后的硅胶套上没有耗材残留

![](https://wiki.bambulab.com/blob-cleaning/%E4%BF%9D%E8%AF%81%E6%B2%A1%E6%9C%89%E4%BB%BB%E4%BD%95%E6%AE%8B%E7%95%99.png)

### 清洁热端

步骤 1. 按下切刀，切断耗材。

![](https://wiki.bambulab.com/blob-cleaning/%E6%8C%89%E4%B8%8B%E5%88%87%E5%88%80.png)

步骤 2. 在热端加热时，打开卡扣，取下喷嘴。

![](https://wiki.bambulab.com/blob-cleaning/%E6%89%93%E5%BC%80%E5%8D%A1%E6%89%A3.png)

步骤 3. 取下后，应立即清理耗材，直至喷嘴上没有任何残留物。

|  |  |
| --- | --- |
|  |  |

### 清洁加热组件

步骤 1. 需小心清除热端加热组件周围的所有耗材，直至没有任何残留物。

|  |  |
| --- | --- |
|  |  |

步骤 2. 将热端温度设置为 0℃，并等待其冷却。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 清洁部件冷却风扇

步骤 1. 使用有加热档位的吹风机，持续吹 1-2 分钟，直至耗材开始变软。

![](https://wiki.bambulab.com/blob-cleaning/%E5%90%B9%E9%A3%8E%E6%9C%BA.png)

> **注意**：使用吹风机吹塑料部件时，**请注意不要吹得太久或离得太近**。根据政策，保修不支持更换此部件。

步骤 2. 将耗材轻轻拉离部件冷却风扇。

![](https://wiki.bambulab.com/blob-cleaning/%E5%B0%86%E5%85%B6%E6%8B%89%E7%A6%BB%E9%A3%8E%E6%89%87.png)

> **注意**：此时可先**停止加热热端**，避免操作中出现烫伤。

### 组装

步骤 1. 处理完成后，如果没有明显示的损坏，可重新安装拆除的部分。

![](https://wiki.bambulab.com/blob-cleaning/%E9%87%8D%E6%96%B0%E5%AE%89%E8%A3%85%E6%8B%86%E9%99%A4%E7%9A%84%E9%83%A8%E5%88%86.png)

步骤 2. 重新安装喷嘴，用卡扣固定，并套上硅胶套。

![](https://wiki.bambulab.com/blob-cleaning/%E5%AE%89%E8%A3%85%E5%A5%BD%E5%89%8D%E7%9B%96-%E7%A1%85%E8%83%B6%E5%A5%97.png)

步骤 3. 安装好工具头前盖。

![](https://wiki.bambulab.com/blob-cleaning/%E5%AE%89%E8%A3%85%E5%B7%A5%E5%85%B7%E5%A4%B4%E5%89%8D%E7%9B%96.png)

步骤 4. 安装完成后，按照准备阶段说明关闭维护模式，以完成操作。
