## 适用打印机型号

A1 mini

## Z 轴电机

Z 轴电机是安装在打印机底部，用于驱动工具头在 Z 轴方向上移动的步进电机。

## 何时使用

- Z 轴电机烧坏
- 经官方技术支持通过分析日志，确认是 Z 轴电机故障。

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击此处联系在线技术支持 （服务时间 9:00-21:00）](hhttps://support.bambulab.cn/cn/im)，我们将及时回复并为您提供所需的帮助。

## 所需工具和材料

- 新的 Z 轴电机（购买链接：请联系售后）
- 镊子
- H2.0 内六角扳手
- 20 分钟

## 移除 Z 轴电机

### 步骤 1：移除端盖

用平头镊子移除 Z 轴端盖。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：松动联轴器，移除 Z 轴电机螺丝

1. 拧松 4 颗联轴器螺丝，无需取下；

|  |  |
| --- | --- |
|  |  |

2. 移除 3 颗 Z 轴电机螺丝。

![](https://wiki.bambulab.com/a1m/replace-z-motor/取下3颗螺丝.jpg)

### 步骤 3：拆卸底壳

1. 向后放倒打印机，用 H2.0 内六角扳手移除 2 颗走线夹螺丝；
2. 移除 14 颗底壳螺丝（注意与走线夹螺丝区分开）；
3. 拉扯尼龙扎网使底板松动，移除底壳。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 4：拆卸 Z 轴电机

将 Z 轴电机取出，并断开主板上的电机线。

|  |  |
| --- | --- |
|  |  |

### 步骤 5：拆卸联轴器

拆下 Z 轴电机的联轴器。

|  |  |
| --- | --- |
|  |  |

## 安装 Z 轴电机

### **步骤 1：安装联轴器**

将拆下的联轴器安装到新的 Z 轴电机上，并拧紧 4 颗螺丝。

**注意：底部需留有间隙。**

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 2：安装 Z 轴电机

1.将 Z 轴电机按下图方向放置，并捋直线缆。

|  |  |
| --- | --- |
|  |  |

2. 安装新的 Z 轴电机，将电机线从 USB线、X 电机线等线缆下穿过，将 Z 轴电机线连接到主板上。

|  |  |  |
| --- | --- | --- |
|  |  |  |

3. 将打印机放回，安装 Z 轴电机的 3 颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 3：安装底壳

1. 安装底壳，对齐位置后，锁入14 颗底壳螺丝；
2. 安装走线夹，锁入 2 颗走线夹螺丝；
3. 正放打印机。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 4：安装端盖

将端盖扣回原位；如果操作困难，可借助扳手。

|  |  |
| --- | --- |
|  |  |

## 设备校准

在校准页面，仅选择振动补偿，点击开始。

请执行此步骤以确保打印机正常工作。
