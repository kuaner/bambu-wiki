## 何时更换?

本指南用于在热端加热组件出现问题时使用。

需要更换 A1 系列热端加热组件的常见问题包括：

- 热端加热组件因打印故障而被包裹在塑料中
- 加热器或热敏电阻损坏
- 热端金属卡扣损坏
- Bambu Lab 技术支持推荐

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除热端加热组件

### 1. 移除工具头前盖

按紧工具头前盖底部轻轻向前拉，取下工具头前盖。

|  |  |
| --- | --- |
|  |  |

### 2. 移除热端（喷嘴组件）

取下喷嘴硅胶套，打开卡扣，取下热端。

**所有步骤都已标注在挤出机贴纸上。**

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 3. 移除挤出机螺丝

卸下如图所示的螺丝，将挤出机轻轻向前拉出一些。

> **注意**：请勿用力将挤出模块拉出，容易扯断电机线。

|  |  |
| --- | --- |
|  |  |

### 4. 移除工具头后盖

拉住工具头后盖底部，小心撬开后盖。

|  |  |
| --- | --- |
|  |  |

### 5. 断开线缆

请小心断开连接工具头的热端加热组件线缆和部件冷却风扇线缆。

> **注意**：断开部件冷却风扇线缆是为了方便从线槽中取出加热组件线缆。

|  |  |
| --- | --- |
|  |  |

### 6. 拆卸右侧线盖

轻轻推出右侧线盖，将其取下。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 7. 取出线缆

小心从线槽中取出线缆。

|  |  |
| --- | --- |
|  |  |

### 8. 移除热端加热组件

卸下热端加热组件的 3 颗螺丝，移除热端加热组件。

|  |  |
| --- | --- |
|  |  |
|  |  |

如果设备原装的是陶瓷底座加热组件，拆卸后请检查黑色垫片是否一并取下。

|  |  |
| --- | --- |
|  |  |
|  |  |

对准中间的圆形卡扣并且确保加热组件顶部顶住工具头的白色对齐线后，拧紧三个固定螺丝。

| --- | --- | --- |
|  |  |  |

> **注意**：三颗固定加热组件螺丝规格为 M3\*10 。

### 2. 安装右侧线盖

## 功能确认

为确保一切正常运行，需将热端温度设置为 100℃。如设置成功，屏幕上将会显示相应温度。

## 设备校准

建议在此操作后对打印机进行全面校准。

> 强烈建议[在使用前清洗 PEI 纹理板](../../general/textured-PEI-plate-not-working-as-expected.md)，因为打印板可能在此过程中受到污染。

## 潜在问题和解决方案

如果在安装新的热端加热组件过程中遇到问题，请检查下列潜在问题和解决方案：

### 热端温度为 0℃

检查热端加热组件连接器，确保正确插入。  
请参考**步骤 5 连接线缆**。  
必须仔细将连接器 pin 对准 [TH 板](../th-board-replacement-guide.md)。

*如果问题仍然存在，热敏电阻线可能已损坏（白线）。*

### 热端无法加热

检查热端加热组件连接器，确保正确插入。  
请参考**步骤 5 连接线缆**。  
必须仔细将连接器 pin 对准 [TH 板](../th-board-replacement-guide.md) 。

*如果问题仍然存在，加热器电线可能已损坏（半透明电线）。*

### 首层问题

确保热端加热器组件的螺丝已拧紧，并在开始打印前已启用热床调平功能。

请参考[A1系列打印首层打印质量问题及对应方案](../troubleshooting/print-issues-troubleshooting.md) 获取更多相关问题及解决方案。
