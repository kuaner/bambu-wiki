## 适用打印机型号

A1 mini

## X 皮带

X 皮带是安装在 X 轴上，将工具头与 X 电机连接起来并驱动工具头在 X 方向上运动。

## 可解决的问题

- X 皮带磨损
- X 皮带断裂

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 安装 X 皮带

## **步骤 1：将 X 皮带穿到 X 轴上**

### 1. 从右侧压块中抽出皮带

拿到新皮带后，由于左右侧压块预装在 X 轴皮带上，而电机罩与 X 轴之间的孔较小，需提前将右侧压块与 X 皮带分离，将 X 皮带穿好之后再装回右侧压块。将皮带从右侧压块中取出的方法如下：

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 2. 穿皮带

检查皮带的方向，齿面朝上，将皮带从惰轮下方侧穿过 X 轴；

![](https://wiki.bambulab.com/a1/maintenance/replace-x-belt/装入皮带.jpg)

穿过后用镊子夹住皮带，将 X 轴皮带绕过电机主动轮，从 X 轴和电机罩之间的小孔中传出。

![](https://wiki.bambulab.com/a1/maintenance/replace-x-belt/用镊子穿皮带，绕过电机.jpg)

### 3. 固定左侧压块

将左侧压块插入工具头，并拧紧螺丝，然后将铁片装回工具头后方，拧紧螺丝。

将皮带穿过右侧压块，将皮带压紧块与皮带对齐，一起压入压块；

## **步骤 2：装回 X 电机盖**

确认安装方向，盖上 X 电机罩前盖

![](https://wiki.bambulab.com/n1/a1-mini-printer/x_front_cover.jpg)

## 步骤 3：装回吐料组件和 X 轴端盖

### 1. 装回 X 轴端盖

将 X 轴端盖插入 X 轴中，然后紧螺丝。

> 注意：端盖螺丝比吐料组件螺丝更短，如果用错则会顶到 X 轴惰轮，导致 X 轴阻力异常，回零时持续丢步等情况。

![](https://wiki.bambulab.com/a1/maintenance/replace-x-belt/x轴端盖-未取下.jpg)

### 2. 装回吐料组件

将吐料组件的插槽与支架对齐，将其滑入直至表面齐平，然后将螺钉重新插入原来的位置，重新拧紧即可。

## 步骤 5：装回工具头后盖

后盖使用卡扣固定。只需将后盖上的两个卡扣对准，然后推入后盖，直到听到几声“咔嗒”声。

![](https://wiki.bambulab.com/a1m/replace-th-board/back_cover_of_the_print_head_a1m.jpeg)

## 步骤 6：X 皮带张紧

1. 将 X 移动到移动到靠近 Z 轴中间位置，避免移动工具头时划伤热床，关闭打印机；

![安装完成.png](https://wiki.bambulab.com/n1/a1-mini-print-head/%E6%8B%86%E8%A3%85/%E5%AE%89%E8%A3%85%E5%AE%8C%E6%88%90.png)

2. 用 H2.0 内六角扳手拧松张紧螺丝一圈（请勿完全松开），用手移动工具头沿 X 轴方向来回运动 3 次，然后重新拧紧张紧螺丝。

3. 启动打印机，在校准菜单中选中振动补偿，完成一次校准流程。
