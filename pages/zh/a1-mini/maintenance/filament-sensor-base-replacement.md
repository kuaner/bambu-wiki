## 进料霍尔板底座

对于 A1 系列打印机，进料霍尔板底座是安装在工具头挤出机上方，用于安装进料霍尔板的固定底座，它同时也是A1系列五通组件的底座。

![filament_sensor_base-a1_series.png](https://wiki.bambulab.com/n1/maintenance/filament-sensor-base-replacement/filament_sensor_base-a1_series.png)

## 何时更换

正常使用情况下，进料霍尔板底座不易损坏；但是当遇到工具头撞击或者不当拆装 AMS 五通组件的情况下，可能导致进料霍尔板底座破损或者固定卡扣断裂，这时为保证打印机供料正常应及时更换底座。

## 所需的工具及材料

1. H1.5/H2.0内六角扳手

2.平头摄子

> ***提示：应妥善保存维护期间拆除的固定螺丝，以免丢失！***

## 安全提示

> ***重要提醒 ！***
>
> *在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。*
>
> *在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。*

## 操作步骤

### 第 1 步：退出耗材（单机适用）

**方法一：操作打印机退出线材 （开机状态）**

1.在打印机触摸屏上点击“耗材”，进入选中需要退出的耗材图标

|  |  |
| --- | --- |
|  |  |

2.点击“退料”进入退料流程界面，耐心等待3分钟左右，自动退料完成

|  |  |
| --- | --- |
|  |  |

**方法二：按下切刀切断线材，手动退出耗材（关机状态）**

|  |  |
| --- | --- |
|  |  |

### 第 2 步：关机打印机，移除 AMS 五通组件

按下打印机后侧开关按钮关机，关闭打印机

用扳手轻微撬起五通盖子，从上方移除五通组件和配套的五通弹簧

|  |  |
| --- | --- |
|  |  |
|  |  |

### 第 3 步：移除进料霍尔板，更换进料霍尔板底座

用H2.0 内六角扳手拧下 2 颗固定螺丝 A，向上拔起进料霍尔板底座，注意不要太用力，霍尔板还有软排线连接

|  |  |
| --- | --- |
|  |  |

用 H1.5 内六角扳手拧下 2 颗固定螺丝 B，将进料霍尔板取下，即可更换进料霍尔板底座。

|  |  |
| --- | --- |
|  |  |

参考拆解的过程，逆向操作，即可完成安装，注意要整理好进料霍尔板的排线，避免损伤。
