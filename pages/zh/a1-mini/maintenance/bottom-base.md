## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 拆解指引

### 步骤1: 移除触摸屏幕和WIFI天线

解锁并断开触摸屏幕排线连接，在显示屏背面向外推，松出并取下触摸屏幕；

|  |  |
| --- | --- |
|  |  |

从主板上断开天线连接，用平头镊子撬起WIFI天线板，移除天线。

|  |  |
| --- | --- |
|  |  |

### 步骤2: 移除电源模块

用十字螺丝刀拧松2颗端子螺丝，将主板电源线从电源模块上移除；用十字螺丝刀拧松3颗端子螺丝，将打印机电源线从电源模块上移除；

|  |  |
| --- | --- |
|  |  |

用H2.0内六角扳手拧下2颗螺丝A，1颗螺丝B, 取下电源模块。

|  |  |
| --- | --- |
|  |  |

### 步骤3: 移除主板

从主板上断开风扇排线，用H2.0内六角扳手移除2颗螺丝C，取下主板风扇；

|  |  |
| --- | --- |
|  |  |

从主板上断开Y电机线、Z电机线和Y线圈的连接，用H2.0内六角扳手移除3颗螺丝A，移除主板。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤4：移除底座

用H2.0内六角扳手移除1颗螺丝D，松出Y轴(涡流)线圈；

|  |  |
| --- | --- |
|  |  |

用H2.0内六角扳手移除移除2颗螺丝E，取下料盘架快装板；用平头镊子移除Z组装饰盖；

|  |  |  |
| --- | --- | --- |
|  |  |  |

用H2.0内六角扳手移除4颗螺丝A和1颗螺丝F，然后将底座沿Z立柱方向朝上取出。

|  |  |  |
| --- | --- | --- |
|  |  |  |

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤5：移除电源线

用钳子将电源线从开关上拔出，按压开关侧边卡扣，同时用力向外推，移除电源开关。

|  |  |  |
| --- | --- | --- |
|  |  |  |

|  |  |
| --- | --- |
|  |  |

## 组装指引

### 步骤1: 连接电源线

将电源开关安装到底座上，注意确认方向；

|  |  |
| --- | --- |
|  |  |

将电源线连接到开关上，线短的一端在底下。

|  |  |
| --- | --- |
|  |  |

### 步骤2: 安装底座

将底座沿Z轴方向往下安装到Z轴&Y轴组件上，注意避让Y轴线圈；

|  |  |  |
| --- | --- | --- |
|  |  |  |

锁入1颗螺丝F和4颗螺丝A， 将定底座固定到方钢上；

|  |  |
| --- | --- |
|  |  |

安装Y轴(涡流)线圈，锁入1颗螺丝D；

|  |  |
| --- | --- |
|  |  |

安装Z轴装饰盖，安装料盘架快装板，锁入2颗螺丝E。

|  |  |
| --- | --- |
|  |  |

### 步骤3: 安装主板

将主板安装到底座上，锁入3颗螺丝A固定；

|  |  |  |
| --- | --- | --- |
|  |  |  |

连接Y线圈、Z电机和Y电机电缆到对应连接器上；整理线缆

|  |  |  |
| --- | --- | --- |
|  |  |  |

安装主板风扇，锁入2颗螺丝C固定，连接风扇排线 。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤4：安装电源模块

安装电源模块；锁入2颗螺丝A，1颗螺丝B;

|  |  |
| --- | --- |
|  |  |

将主板电源线连接到电源模块的输出端子上，红线接正极，黑线接负极，锁紧2颗螺丝；

|  |  |
| --- | --- |
|  |  |

将电源线连接到输入端子上，棕色线接L, 蓝色线接N,黄色线接地，锁紧3颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤5：安装触摸屏幕和WIFI天线

将天线带背胶的一面粘附到底座WIFI限位上，将连接线接到主板上；

|  |  |  |
| --- | --- | --- |
|  |  |  |

（去除保护纸）将显示屏贴装好，将排线连接到主板上。

|  |  |  |  |
