## 拆解指引

### 步骤1：移除Z轴

- 用H2.0内六角扳手移除6颗螺丝A，取下Z轴；

|  |  |  |
| --- | --- | --- |
|  |  |  |

- 用H2.0内六角扳手移除1颗螺丝B, 取下Z轴上盖。

![](https://wiki.bambulab.com/n1/manual/取下z上盖.png)

### 步骤2：移除Z电机和联轴器

- 用H2.0内六角扳手移除3颗螺丝C，然后拧松2颗顶丝，取下Z电机；

|  |  |
| --- | --- |
|  |  |
|  |  |

- 继续拧松另外2颗顶丝，取下联轴器和垫圈。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤3：移除Y电机

- 按压Y张紧弹簧，解除张紧状态，用H2.0内六角扳手移除3颗螺丝D，取下Y电机；

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤4：移除Y轴同步带

- 用H2.0内六角扳手移除3颗螺丝E，打开Y同步带压块，将Y轴同步带从压块上剥离，移除Y轴同步带。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤5：移除Y张紧器

- 用H2.0内六角扳手移除1颗张紧螺丝F，并取下防转片；移除1颗螺丝G和螺母，取下Y张紧器。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 组装指引

### 步骤1：安装Y张紧器

- 将转轴螺丝穿过方钢，然后将Y张紧器安装到转轴螺丝上，放入螺母，用H2.0扳手将螺丝与螺母拧紧；

|  |  |
| --- | --- |
|  |  |
|  |  |

- 安装防转片，预锁1颗螺丝F，不要完全锁紧。

|  |  |
| --- | --- |
|  |  |

### 步骤2：安装Y轴同步带

- 确认Y皮带方向，按图所示将皮带穿过惰轮；

|  |  |
| --- | --- |
|  |  |

- 在皮带安装块的齿面涂布少量瞬间胶水，依次操作，将皮带齿面朝下粘贴到压块上，皮带的两端要接触到一起；

|  |  |
| --- | --- |
|  |  |
|  |  |

- 装上另一块皮带压块，对齐3个螺丝孔，拧入3颗螺丝E进行固定。

|  |  |
| --- | --- |
|  |  |

### 步骤3：安装Y电机

- 如图所求，将Y电机穿过电机安装座，确认电缆朝向，并将主动轮挂上Y轴同步带后安装到位；锁入3颗螺丝D固定Y电机。

|  |  |  |
| --- | --- | --- |
|  |  |  |

- 张紧弹簧，拉动Y皮带来回动作，确认动作顺畅，锁紧张紧螺丝F。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤4：安装Z电机

- 转动丝杆，如图所示，将丝杆的扁平面露出；

![](https://wiki.bambulab.com/n1/manual/露出丝杆的扁平面.png)

- 装入垫圈，将联轴器的顶丝位置对齐丝杆的扁平位，安装到Z轴丝杆上，拧紧两颗顶丝；

|  |  |  |
| --- | --- | --- |
|  |  |  |

- 根据电机排线确认朝向，转动电机转轴，将轴上扁平位与联轴器上的顶丝对齐；

|  |  |  |
| --- | --- | --- |
|  |  |  |

- 然后安装Z电机，拧紧2颗顶丝；拧入3颗螺丝C固定Z电机。

|  |  |  |
| --- | --- | --- |
|  |  |  |

注意：在这里要检查丝杆上端是否处于较中间的位置，如果不在，可以通过重新锁Z电机的螺丝进行丝杆位置的调整。

### 步骤5：安装Z轴

- 安装Z轴上盖，锁入1颗螺丝B;

![](https://wiki.bambulab.com/n1/manual/取下z上盖.png)

- 将Z轴与Y轴方钢连接到一起，确认螺丝孔对齐，锁入6颗螺丝A进行固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 功能确认

- 确认Y皮带动作顺畅；
- 确认Y电机、Z电机的电缆朝向正确。
