## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 拆解指引

### 步骤1：移除底板

向后放倒打印机，用 H2.0 内六角扳手移除 2 颗螺丝 A，再移除 14 颗螺丝 B，拉扯尼龙扎网使底板松动，移除底板。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 2：断开连接线

用剪钳剪断扎带,移除2颗螺丝C和压片,从主板上断开USB线、摄像头连接线和X电机连接线，请注意摄像头连接线是带锁扣的，要按压解锁后断开。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 3：移除热床

用H2.0内六角扳手移除3颗螺丝B,取下防火盖，用钳子移除两个端子绝缘胶套;

|  |  |
| --- | --- |
|  |  |

用扳手解除插头锁定的同时拔除2根热床电源线，从主板上断开热床信号线的连接,移除1颗螺丝A,将热床线从线扣中松出；

|  |  |
| --- | --- |
|  |  |

正放打印机，在热床支架上移除3颗热床固定螺丝D;

|  |  |  |
| --- | --- | --- |
|  |  |  |

用手压住热床，用H2.0内六角扳手移除4颗调平螺丝E，取下热床和调整弹簧。

|  |  |
| --- | --- |
|  |  |

### 步骤4：移除USB线、摄像头和X电机罩

将料管和USB线从集线器上移除，按压料管接头拔除料管，然后移除料管接头;

|  |  |  |
| --- | --- | --- |
|  |  |  |

从电机罩前盖下方用力,移除电机罩前盖,断开摄像头连接线,用内六角扳手穿过线夹并撬出,移除线夹;

|  |  |  |
| --- | --- | --- |
|  |  |  |

去除留在线材上的线夹，撕掉尼龙扎网一端的胶布，抽出摄像头连接线和X电机线；

|  |  |  |
| --- | --- | --- |
|  |  |  |

移除磁环，将USB线上的胶塞从电机罩上拔出，取下USB线;

USB-C电缆有两种磁环版本:一种是图片所示的分体结构,另一种是一体式的磁环。如果收到的是一体式磁环结构,那么就不需要再将分体磁环安装在电缆上,因为磁环已经集成在电缆中了。这两种版本会随机发货,最终以实际收到的产品为准。

|  |  |
| --- | --- |
|  |  |

移除1颗螺丝F，2颗螺丝G，取下X电机罩组件；

|  |  |
| --- | --- |
|  |  |

按箭头方向用力解锁摄像头，将摄像头从X电机罩上取下。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤5：移除X电机

移除2颗螺丝H移除电机罩后盖; 移除4颗螺丝I,取下X电机。

|  |  |
| --- | --- |
|  |  |

### 步骤6：移除X组件

移除 4 颗螺丝J ,取下 X 轴模块;再移除滑块和转接支架 4 颗螺丝,转到打印机背面移除2颗螺丝K,取下转接支架。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤7：移除Y轴线轨

向后推动热床支架,使连接板的 2 颗螺丝露出并将螺丝完全拧松，然后移除滑车上的2颗螺丝L，取下连接板;

|  |  |  |
| --- | --- | --- |
|  |  |  |

移除 2 颗螺丝 M,取下 Y 轴后盖;

|  |  |
| --- | --- |
|  |  |

移除 4 颗导轨螺丝 N，移除Y轴导轨，取下导轨时，请同时拿着支架和导轨，防止滑落。

|  |  |
| --- | --- |
|  |  |

## 组装指引

### 步骤1：安装Y轴线轨

用镊子移动Y皮带压块,使2螺丝露出。根据连接板的安装孔确认安装方向，将Y轴线轨放置到底座上，对齐螺丝孔,放入4颗螺丝N，交替锁紧;

|  |  |
| --- | --- |
|  |  |

移动热床支架，露出Y轴同步带压块，然后安装连接板，确认卡到位，锁2颗螺丝L固定连接板；

|  |  |  |
| --- | --- | --- |
|  |  |  |

然后透过底座，锁紧2颗螺丝，移动热床支架，确认热床支架能带动Y皮带运动且动作顺畅。

|  |  |
| --- | --- |
|  |  |

安装Y轴后盖，锁入2颗螺丝M。

|  |  |
| --- | --- |
|  |  |

### 步骤2：安装X组件

安装转接支架，在正面锁4颗银色螺丝，在背面锁2颗螺丝K;

|  |  |
| --- | --- |
|  |  |

安装X轴模块，注意防止X滑块脱落，然后锁4颗螺丝J，注意在拧下面的2颗螺丝时，不要压到X轴同步带。

|  |  |
| --- | --- |
|  |  |

### 步骤3：安装X电机

安装X电机，电机的排线朝下，锁入4螺丝G。

|  |  |
| --- | --- |
|  |  |

### 步骤4：安装X电机罩、摄像头、USB线

安装摄像头到电机罩上，然后穿USB线，并将其扣到电机罩上;

|  |  |  |
| --- | --- | --- |
|  |  |  |

将X轴同步带绕过电机主动轮，然后按箭头方向将电机罩安装到转接支架上，注意电机电缆要穿过电机罩，在X轴上锁入1颗螺丝F、在电机罩内锁2颗螺丝G将电机罩固定;

|  |  |  |
| --- | --- | --- |
|  |  |  |

将摄像头电缆小头的一端连接到摄像头上，然后依次将USB线、X电机线和摄像头线穿过编织网管；

|  |  |  |
| --- | --- | --- |
|  |  |  |

确认线夹的方向，将线夹安装到电机罩上，然后确认安装方向，盖上电机罩前盖；

|  |  |  |
| --- | --- | --- |
|  |  |  |

将X电机罩后盖安装到电机罩上，锁入2颗颗螺丝H，对齐安装位置，安装料管接头;

|  |  |  |
| --- | --- | --- |
|  |  |  |

用胶布将编织网管的另一端缠住，并在距离USB接头约2.5厘米处装上磁环。

|  |  |
| --- | --- |
|  |  |

### 步骤5：安装热床

将4个弹簧用胶水预固定到对应位置上，对齐弹簧位置，放置热床，从热床底下确认热床上的3个固定片都在热床支架的外侧； 涂胶主要是为了便于安装弹簧,没有其他特殊的用途，如果弹簧已经固定好了，则可以不用胶水固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

放入4颗调平螺丝E，用手将热床调平弹簧压缩，使调平螺丝能够进行锁定，全部锁紧后，再统一将这4颗调平螺丝拧松1圈；安装3颗热床固定螺丝D，但不要锁紧，这3颗螺丝需要在完成热床的手动调平后再锁紧;

|  |  |
| --- | --- |
|  |  |

向后放倒打印机，然后如图所示，连接热床电源线，注意区分红、黑线，要装好绝缘胶套，然后连接热床信号线;

|  |  |  |
| --- | --- | --- |
|  |  |  |

安装线扣,用2颗螺丝A，将热床线和电源线锁定;

|  |  |
| --- | --- |
|  |  |

整理好热床线缆和电源线，安装防火盖，确认没有压到线缆，然后锁入3颗螺丝B。

|  |  |
| --- | --- |
|  |  |

### 步骤6：连接电缆

将X电机线、摄像头线连接到主板上，连接USB线，确认磁环的位置，并用2颗螺丝C将压片锁定，整理好线缆,并用小扎带扎好。

USB-C电缆有两种磁环版本:一种是图片所示的分体结构,另一种是一体式的磁环。如果收到的是一体式磁环结构,那么就不需要再将分体磁环安装在电缆上,因为磁环已经集成在电缆中了。这两种版本会随机发货,最终以实际收到的产品为准。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

### 步骤7：安装底板

安装底板，对齐位置后，锁入14颗螺丝B固定; 然后安装走线夹，锁2颗螺丝A固定；正放打印机。

## 功能确认

安装好工具头后，连接上USB线后，启动打印机，确认打印机可以正常启动，屏幕能正常显示。
