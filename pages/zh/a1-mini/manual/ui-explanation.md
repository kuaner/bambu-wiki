## 校准

- 在开始正式打印之前，我们强烈建议您对打印机进行校准，以保证首次打印的质量，请勾选“振动补偿”和“电机降噪”并轻点“开始”来进行校准，整个过程大概会持续12分钟左右，校准过程中出现振动和噪音属于正常现象。

![](https://wiki.bambulab.com/n1/manual/ui-explanation/cn-version/%E5%BC%80%E6%9C%BA%E8%AE%BE%E7%BD%AE_3_%E6%A0%A1%E5%87%86_1_corrected.jpeg)

### 1. 电机降噪

噪音通常是由于打印机的机械振动、电机驱动、风扇运转或挤出机运行等因素引起的。这些噪音不仅可能对操作者造成干扰，还可能影响周围环境的舒适性。电机噪声抑制功能可以将打印过程中电机发出的噪声抑制下来，降低整体打印噪声。

电机降噪靠测量电机内的不理想特性，并在打印时结合电机实时运行状态，计算反向补偿量并输入电机，在电机内产生反向的振动，从而抵消掉由于电机不理想性所产生的振动。电机噪声校准在校准菜单中，用户可以自行对电机噪声进行重校准。

![](https://wiki.bambulab.com/n1/manual/ui-explanation/cn-version/%E5%BC%80%E6%9C%BA%E8%AE%BE%E7%BD%AE_3_%E6%A0%A1%E5%87%86_2.jpeg)

### **2. X轴共振检测和Y轴共振检测**

共振补偿旨在减轻或消除打印过程中由于机械振动或共振引起的不稳定性和质量问题。

在3D打印机的运行过程中，每一次加减速都会激励起打印机本身的共振模态并产生细微的往复振动。这种振动可能会对打印质量产生负面影响，例如零件表面的波纹、振动痕迹或失真。而共振检测这一过程是打印机在工作时为了确定共振频率并启用振动补偿所做的调整。这一过程的目的是减少打印过程中可能出现的打印质量问题，并显著提高打印速度。

# 主界面

- 当打印机完成自动校准后，初始设置就全部完成了。打印机主页面如下图所示，您可以在主界面进入打印操作、检视耗材余量及AMS的情况、控制打印机进行运动、进行打印机设置等。主界面上方状态栏从左到右分别显示了当前热端温度、热床温度、摄像头连接情况、无线网络的连接情况。

![](https://wiki.bambulab.com/n1/manual/ui-explanation/cn-version/%E4%B8%BB%E7%95%8C%E9%9D%A2_1.png)

## 设置

- 在“主界面-设置”选项卡中，您可以对打印机进行一系列通用性设置。

|  |
| --- |
| **设备设置第1页** |

**1. 账号**：登录您的Bambu Lab账号以同步打印设置和文件（需要连接网络）

**2. 固件**：点击可查看固件更新

**3. Wi-Fi**：将打印机连接至无线局域网络

**4. 校准**：与第一次设置打印机时进行的校准相同，您可以随时操作打印机进行校准。

| 设备设置第2页 | 打印选项 |
| --- | --- |

**5. 设备**：查看设备型号、序列号以及AMS序列号（如果已连接AMS）

**6. 打印选项**：开启或关闭声音（开机音效、打印开始及完成音效）、丢步恢复、AMS自动续料、缠料检测

**7. 语言**：选择打印机所显示的语言

**8. SD卡**：查看SD卡容量，格式化或弹出SD卡

|  |
| --- |
| **设备设置第3页** |

**9. 屏幕关闭时间**：设置不操作打印机时最长亮屏时间

**10. 局域网模式**：开启或关闭[局域网模式](../../knowledge-sharing/enable-lan-mode.md)

**11. 使用条款**：扫描二维码来查看使用条款

**12. 恢复出厂设置**：此选项会将打印机恢复出厂设置，请谨慎操作此步。
