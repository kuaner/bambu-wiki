## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### 关闭打印机电源，切断电源线

|  |  |
| --- | --- |
|  |  |

### 取下料盘，拆除料管

步骤 1. 取下 AMS Lite 上的耗材。

![手动退料.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E6%89%8B%E5%8A%A8%E9%80%80%E6%96%99.png)

步骤 2. 取下回转轴上的料盘。

![拔出料盘.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E6%8B%94%E5%87%BA%E6%96%99%E7%9B%98.png)

步骤 3. 断开 AMS lite 的 4pin 线。

![断开4pin线.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E6%96%AD%E5%BC%804pin%E7%BA%BF.png)

步骤 4. 取下集线器。

![取下集线器.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E5%8F%96%E4%B8%8B%E9%9B%86%E7%BA%BF%E5%99%A8.png)

步骤 5. 按压工具头入料口接口（推荐使用镊子），拔出 4 根料管。

|  |  |
| --- | --- |
|  |  |

步骤 6. 按压料盘支架上的料管接口，拆除料管。

![拔出ams_lite料管.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E6%8B%94%E5%87%BAams_lite%E6%96%99%E7%AE%A1.png)

### 拆除 AMS Lite

步骤 1. 拔出 AMS lite 回转轴。

![拔下回转轴.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E6%8B%94%E4%B8%8B%E5%9B%9E%E8%BD%AC%E8%BD%B4.png)

步骤 2. 拆除连接 AMS lite 主体和支架的四颗螺丝。

|  |  |
| --- | --- |
|  |  |

步骤 3. 拆下 AMS Lite 主体。

![取下ams主体.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E5%8F%96%E4%B8%8Bams%E4%B8%BB%E4%BD%93.png)

步骤 4. 用扎带进行固定。  
![线扎固定ams.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E7%BA%BF%E6%89%8E%E5%9B%BA%E5%AE%9Aams.png)

> 注意：在某些版本中，此处可能共有三根扎带。  
> ![a1mini_combo扎带.jpg](https://wiki.bambulab.com/a1-combo-packing/a1mini_combo%E6%89%8E%E5%B8%A6.jpg)

步骤 5. 将特氟龙管放回袋中。  
![放回料管.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E6%94%BE%E5%9B%9E%E6%96%99%E7%AE%A1.png)

### 拆除料盘支架和吐料组件

步骤 1. 将料盘支架向上滑出。

![向上滑出料盘支架.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E5%90%91%E4%B8%8A%E6%BB%91%E5%87%BA%E6%96%99%E7%9B%98%E6%94%AF%E6%9E%B6.png)

步骤 2. 拆除 2 颗固定螺丝，取下料盘支架底座。

|  |  |
| --- | --- |
|  |  |

步骤 3. 拆除吐料组件下方的 1 颗固定螺丝。

![吐料组件螺丝.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E5%90%90%E6%96%99%E7%BB%84%E4%BB%B6%E8%9E%BA%E4%B8%9D.png)

步骤 4. 将吐料组件滑出。

![左滑吐料组件.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E5%B7%A6%E6%BB%91%E5%90%90%E6%96%99%E7%BB%84%E4%BB%B6.png)

### 固定工具头、X 轴、热床和 Z 轴

步骤 1. 松开两圈热床螺丝。

|  |  |
| --- | --- |
|  |  |

步骤 2. 用泡棉抵住工具头，将工具头移到最末端。

|  |  |
| --- | --- |
|  |  |

步骤 3. 用扎带固定工具头。

![用线扎固定工具头.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E7%94%A8%E7%BA%BF%E6%89%8E%E5%9B%BA%E5%AE%9A%E5%B7%A5%E5%85%B7%E5%A4%B4.png)

步骤 4. 套上 X 轴保护套，并放置泡棉。

|  |  |
| --- | --- |
|  |  |

步骤 5. 在热床下方放置 2 块泡棉。

|  |  |
| --- | --- |
|  |  |
|  |  |

步骤 6. **卡准 Z 轴限制器位置**，安装 Z 轴限制器，并拧紧 4 颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 装回配件

步骤 1. 将配件装入泡棉盒内。

> 最新包装的 A1 系列打印机不提供色卡，具体以包装实物为准。

|  |  |
| --- | --- |
|  |  |

步骤 2. 装回回转轴。

![放回回转轴.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E6%94%BE%E5%9B%9E%E5%9B%9E%E8%BD%AC%E8%BD%B4.png)

步骤 3. 放置 AMS Lite 主体泡棉。

![装上ams主体泡棉.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E8%A3%85%E4%B8%8Aams%E4%B8%BB%E4%BD%93%E6%B3%A1%E6%A3%89.png)

> 注意：在某些版本中，此处可能共有三根扎带。  
> ![a1mini_combo扎带.jpg](https://wiki.bambulab.com/a1-combo-packing/a1mini_combo%E6%89%8E%E5%B8%A6.jpg)

### 装箱操作

步骤 1. 将特氟龙管、说明书等放置纸箱底部。

![料管、说明书等放入底部.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E6%96%99%E7%AE%A1%E3%80%81%E8%AF%B4%E6%98%8E%E4%B9%A6%E7%AD%89%E6%94%BE%E5%85%A5%E5%BA%95%E9%83%A8.png)

步骤 2. 将打印机放回纸箱。

![放入打印机.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E6%94%BE%E5%85%A5%E6%89%93%E5%8D%B0%E6%9C%BA.png)

步骤 3. 放入泡棉纸板。

|  |  |
| --- | --- |
|  |  |

步骤 4. 放置 AMS Lite 支架及泡棉纸板。

|  |  |
| --- | --- |
|  |  |

步骤 5. 放置 AMS Lite 主体及配件盒。

|  |  |
| --- | --- |
|  |  |

步骤 6. 盖上纸板后关上纸箱，并用胶带粘牢。
