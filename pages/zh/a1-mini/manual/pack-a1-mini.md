## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### 退料

步骤 1. 点击屏幕上的**耗材**。

![filament.png](https://wiki.bambulab.com/a1m/manual/a1-mini-packing/filament.png)

步骤 2. 点击**退料**。

![unload.png](https://wiki.bambulab.com/a1m/manual/a1-mini-packing/unload.png)

步骤 3. 退回耗材，并取下回转轴上的料盘。

|  |  |
| --- | --- |
|  |  |

### 拆除料管

步骤 1. 取下集线器。

![取下集线器-.png](https://wiki.bambulab.com/a1m/manual/a1-mini-packing/%E5%8F%96%E4%B8%8B%E9%9B%86%E7%BA%BF%E5%99%A8-.png)

步骤 2. 按压工具头入料口接口（推荐使用镊子），拔出料管。

![取下料管-.png](https://wiki.bambulab.com/a1m/manual/a1-mini-packing/%E5%8F%96%E4%B8%8B%E6%96%99%E7%AE%A1-.png)

步骤 3. 按压料管接口，拆除料管。

![按压料管接口.png](https://wiki.bambulab.com/a1m/manual/a1-mini-packing/%E6%8C%89%E5%8E%8B%E6%96%99%E7%AE%A1%E6%8E%A5%E5%8F%A3.png)

步骤 4. 将料管放入袋中。

![料管入袋.png](https://wiki.bambulab.com/a1m/manual/a1-mini-packing/%E6%96%99%E7%AE%A1%E5%85%A5%E8%A2%8B.png)

### 关闭打印机电源，切断电源线

|  |  |
| --- | --- |
|  |  |

### 拆除料盘支架和吐料组件

步骤 1. 将料盘支架向上滑出。

![向上滑出料盘支架.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E5%90%91%E4%B8%8A%E6%BB%91%E5%87%BA%E6%96%99%E7%9B%98%E6%94%AF%E6%9E%B6.png)

步骤 2. 拆除 2 颗固定螺丝，取下料盘支架底座。

|  |  |
| --- | --- |
|  |  |

步骤 3. 拆除吐料组件下方的 1 颗固定螺丝。

![吐料组件螺丝.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E5%90%90%E6%96%99%E7%BB%84%E4%BB%B6%E8%9E%BA%E4%B8%9D.png)

步骤 4. 将吐料组件滑出。

![左滑吐料组件.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E5%B7%A6%E6%BB%91%E5%90%90%E6%96%99%E7%BB%84%E4%BB%B6.png)

### 固定工具头、X 轴、热床和 Z 轴

步骤 1. 松开两圈热床螺丝。

|  |  |
| --- | --- |
|  |  |

步骤 2. 用泡棉抵住工具头，将工具头移到最末端。

|  |  |
| --- | --- |
|  |  |

步骤 3. 用扎带固定工具头。

![用线扎固定工具头.png](https://wiki.bambulab.com/a1m/manual/ai-mini-combo-pack/%E7%94%A8%E7%BA%BF%E6%89%8E%E5%9B%BA%E5%AE%9A%E5%B7%A5%E5%85%B7%E5%A4%B4.png)

步骤 4. 套上 X 轴保护套，并放置泡棉。

|  |  |
| --- | --- |
|  |  |

步骤 5. 在热床下方放置 2 块泡棉。

|  |  |
| --- | --- |
|  |  |

步骤 6. **卡准 Z 轴限制器位置**，安装 Z 轴限制器，并拧紧 4 颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 装箱操作

步骤 1. 卷起电源线缆。

![电源电缆.png](https://wiki.bambulab.com/a1m/manual/a1-mini-packing/%E7%94%B5%E6%BA%90%E7%94%B5%E7%BC%86.png)

步骤 2. 将特氟龙管、说明书等放置纸箱底部。

![纸箱底部.png](https://wiki.bambulab.com/a1m/manual/a1-mini-packing/%E7%BA%B8%E7%AE%B1%E5%BA%95%E9%83%A8.png)

步骤 3. 将打印机放回纸箱。

![打印机放回.png](https://wiki.bambulab.com/a1m/manual/a1-mini-packing/%E6%89%93%E5%8D%B0%E6%9C%BA%E6%94%BE%E5%9B%9E.png)

步骤 4. 放入两块泡棉纸板。

|  |  |
| --- | --- |
|  |  |

步骤 5. 放入打印机固定纸板，并扣紧卡扣。

|  |  |
| --- | --- |
|  |  |

步骤 6. 放置配件盒及 Z 轴上盖泡棉。

|  |  |
| --- | --- |
|  |  |

步骤 7. 放置顶部三块纸板。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 8. 关上纸箱，并用胶带粘牢。
