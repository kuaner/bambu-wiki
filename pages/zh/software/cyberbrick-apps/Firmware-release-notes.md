## 01.00.03.02 (20251126)

### **新功能**

- 新增遥控器自动休眠功能

### **改进**

- 优化设备蓝牙名称显示方式
- 修复已知问题

## 01.00.03.01 (202520910)

### 更新内容

- 修复部分 RC 配置文件可能引发的运行异常
- 增加 PIN 码开启和关闭功能
- 支持更新 MPY 项目
- 提升系统稳定性

### 注意事项

- 如何升级固件：使用最新的 Cyberbrick APP 或 Cyberbrick Desktop，选择任意项目刷新到 CyberBrick 核心板，将会使核心版更新到与固件匹配的版本，或者前往设备页面手动升级固件。
- 若固件升级失败，请重启 CyberBrick 核心板以及 Cyberbrick APP（ 或 Cyberbrick Desktop ）后重新升级。
