## 概述

Fleet Hub 是面向企业及工厂环境设计的离线打印机集群管理设备，可用于集中管理多台拓竹打印机。设备支持通过安全的 HTTP API 与 MES、ERP、等业务系统集成，无需依赖云端服务，适用于对数据安全、网络隔离及本地化部署有要求的场景。

![](https://wiki.bambulab.com/part_acc/fleet-hub/008.png)

## 基础功能

1. 支持拓竹打印机机型：P1P / P1S / P2S / A1 / A1 mini / X1 / X1E / H2D / H2S / X2D
2. 每台 Hub 最多支持同时连接 **50** 台打印机
3. 支持机身 LED 状态灯显示，用于指示：

- 系统运行状态
- 网络连接状态
- U 盘接口状态

## 网络连接

1. 支持有线网络接入与企业级网络（802.1X）认证接入。
2. 支持插入U盘后，自动将动态分配的IP地址写入U盘的 status 文件，便于快速获取设备 IP 地址。
3. 支持通过 U 盘导入网络配置文件，快速设置设备静态IP地址
4. Fleet Hub 会自动维护与打印机之间的 TLS 双向通信链路，并支持在网络中断或连接异常后自动重连。

## 访问安全

1. 绑定私有客户端证书，确保仅授权客户端可访问 Fleet Hub。
2. HTTP API 访问采用三层安全机制：

- 第 1 层 — 客户端证书校验
- 第 2 层 — mTLS 双向加密传输
- 第 3 层 — 用户名密码认证

## API集成

Fleet Hub 提供面向业务系统集成的 API 能力，便于 MES、ERP、WMS 或其他企业内部系统进行打印任务调度与设备状态监控。

1. 实时获取打印机运行状态信息，包括**温度、耗材、打印进度及打印速度**等。
2. 获取打印机错误码及 HMS 告警信息，并支持通过 API 接口查询对应的错误描述。
3. 支持获取打印机摄像头快照，便于远程查看当前打印状态。
4. 支持通过 API 编辑打印机耗材类型及颜色信息。
5. 支持将模型文件上传至 Fleet Hub 本地存储进行缓存，并按需触发单台或多台打印机从 Fleet Hub 下载文件，开始打印任务。
6. 支持配置外部文件服务器地址及 TLS 证书，打印机可通过 HTTPS 从指定服务器下载模型文件并执行打印任务。

## 内嵌Web

Fleet Hub 内嵌 Web 管理界面默认不启用，可通过 API 接口按需开启；支持打印机的发现、绑定与解绑、固件升级，以及Fleet Hub的升级与日志导出。

## U盘访问：

Fleet Hub 支持通过 U盘进行日志导出、固件升级，以及通过导入配置文件恢复出厂设置。
