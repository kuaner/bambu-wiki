在使用 Bambu Studio 发送打印文件时，可能由于多种原因导致文件发送失败。请按照下列步骤逐项排查。

## 存储介质写入异常

存储介质写入异常、写入速度低下或空间不足可能影响 FTP 传输，导致文件发送失败。

- **检测方法**：
  - 使用第三方工具检测存储介质写入速度。在 Windows 系统中可通过命令行运行以下命令（请将盘符替换为实际存储介质盘符）：`winsat disk -drive d`
  - 检查存储介质是否有足够空间，如果存储介质空间不够传输时传输失败。
- **问题处理**：
  - 如果检测结果显示存储介质无法写入或写入速度过低，请尝试更换、格式化或更新存储介质后重试。
  - 如果存储介质空间不足，请手动删除或格式化后再次重试。
  - 如存储介质状态正常，但问题依旧，请继续下一步排查。

## 局域网连接异常

Bambu Studio的文件发送功能依赖于局域网连接，请确认电脑与打印机处于同一局域网内。

- **步骤**：

  - 使用 cmd 命令工具执行 ping 命令，检查打印机的 IP 地址是否可达。

## FTP连接异常

文件发送失败也可能是由于设备FTP服务器端口被占用，导致无法建立FTP连接。

- **操作步骤**：
  - 使用第三方FTP客户端（例如FileZilla）进行检测。
  - 在FTP客户端中输入以下信息：
    - **主机名**： 打印机 IP 地址（参见“检查局域网连接”中的示意图）
    - **用户名**： `bblp`
    - **密码**： 打印机的 Access Code（打印机LAN模式下查看）
    - **端口**： `990`
  - 尝试连接，并上传一个大于1KB的文件测试上传功能。
- **问题处理**：
  - 如果无法连接或上传失败，请先重启打印机再试。
  - 如问题仍然存在，请提交工单，并提供打印机及Studio日志以便进一步排查。
  - 若FTP连接与上传均正常，而Studio依然无法发送文件，请提交工单，并附上设备及Studio日志，协助我们进一步诊断问题。

## SSL Certificate Problem/SSL Connection Timeout

当 Bambu Studio 发送打印任务失败，并且出现报错内容 SSL Certificate Problem 或 SSL Connection Timeout 时，需手动从微软官方更新并安装 Windows 根证书库。  
**操作步骤**：

- 在 Windows 搜索框中，搜索命令提示符，并点击“管理员运行”

![step1.png](https://wiki.bambulab.com/software/bambu-studio/failed-to-send-print-files/step1.png)

- 在命令提示符中按顺序输入“certutil -generateSSTFromWU roots.sst”、“certutil -addstore -f root roots.sst”并运行，系统将自动更新并安装。如反馈没有管理员权限，请重复第一步。

![cmd.png](https://wiki.bambulab.com/software/bambu-studio/failed-to-send-print-files/cmd.png)  
![cmdfeedback1.png](https://wiki.bambulab.com/software/bambu-studio/failed-to-send-print-files/cmdfeedback1.png)

- 新的根证书库存储在“C:\Users\用户名”中

![file.png](https://wiki.bambulab.com/software/bambu-studio/failed-to-send-print-files/file.png)

- 重启 Bambu Studio，再次尝试发送打印任务。

1. -3030、-3040 通常为 PC 端网络异常导致的，可以尝试重启电脑、打印机和路由器或者更换网络再次测试。
