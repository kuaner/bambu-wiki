该版本为基于V2.2.1.58的hotfix版本。

## BUG 修复

1. 修复了P/A机型使用AMS中耗材发起自动流量校准时映射至外挂的错误。([#8013](https://github.com/bambulab/BambuStudio/issues/8013), [#8011](https://github.com/bambulab/BambuStudio/issues/8011,), [#8005](https://github.com/bambulab/BambuStudio/issues/8005), [#7998](https://github.com/bambulab/BambuStudio/issues/7998))
2. 修复了部分情况下耗材预设中 Scarf Seam 参数导致的 Bambu Studio 无法正常启动的问题。
3. 修复了'设备-固件升级'页面 H2S 的配图错误。
