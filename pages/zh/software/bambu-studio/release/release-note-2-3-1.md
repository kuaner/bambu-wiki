该版本为基于V2.3.0的一个版本，主要修复了部分已知bug。

## Bug修复

1. 修复了X1E机型中AMS错误显示为AMS Lite的问题。
2. 修复了预设加载导致的发送打印crash问题。([#8444](https://github.com/bambulab/BambuStudio/issues/8444)，[#8451](https://github.com/bambulab/BambuStudio/issues/8451)，[#8413](https://github.com/bambulab/BambuStudio/issues/8413)，[#8420](https://github.com/bambulab/BambuStudio/issues/8420)，[#8483](https://github.com/bambulab/BambuStudio/issues/8483))
3. 修复了部分flathub的编译问题，感谢 [@hadess](https://github.com/hadess) 的贡献。
4. 更新了部分土耳其语翻译，感谢 [@fatih5228](https://github.com/fatih5228) 的贡献。
5. 修复了部分语言下发送任务界面的显示异常问题。([#8332](https://github.com/bambulab/BambuStudio/issues/8332)，[#8465](https://github.com/bambulab/BambuStudio/issues/8465)，[#8467](https://github.com/bambulab/BambuStudio/issues/8467)，[#8487](https://github.com/bambulab/BambuStudio/issues/8487))
6. 修复了A1 mini部分工艺预设中的若干兼容性问题。
7. 修复了A1 mini、P2S、X1E和H2D Pro机型的部分耗材预设的若干兼容性问题。
