Bambu Studio 官方版本 v1.9.3

# 新功能

MakerWorld中国区已上线, 中国区用户也可以在主页浏览下载MakerWorld上的模型了。

![](https://wiki.bambulab.com/software/bambu-studio/release-note/v1_9_3/mw_chinese_page.jpg)

# 改进

1. 添加PCTG耗材类型。在之前的版本中，PCTG被归类为PETG的一种，但从现在开始，它拥有自己的独特的类型。

2.   降低了悬垂部分的速度以改善悬垂的打印质量。

|  |  |
| --- | --- |
| Bambu Studio V01.09.02.57 默认配置, PLA Matte | Bambu Studio 01.09.03.50 (当前版本) 默认配置, PLA Matte |

3. 翻译改进，日语由 [**@Kazuyoshi Furuta**](https://github.com/do-gugan)翻译，土耳其语由[**@fatih5228**](https://github.com/fatih5228)翻译。感谢他们做出的贡献！

# Bug 修复

1. 修复了部分Bambu Studio客户端无法正常访问MakerWorld相关页面的问题。

2. 修复A1m耗材在垃圾桶外吐料的问题。

3. 修复了MAC上打开3D鼠标设置快捷键cmd+M和最小化冲突，将打开3D鼠标设置快捷键改为cmd+shift+M。 Windows操作系统下的快捷键保持不变。来自 [**@Alex Tang**](https://github.com/SuperTango), 感谢！
