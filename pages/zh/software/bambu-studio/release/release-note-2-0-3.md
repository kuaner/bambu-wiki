V2.0.3是基于V2.0.2的一个版本，主要修复了在V2.0.2中发现的一些问题。

## Bugs Fixed

1. 修复了部分场景下无法通过AMS发起打印的问题。([#6557](https://github.com/bambulab/BambuStudio/issues/6557))
2. 修复了Windows远程桌面（RDP）下的渲染问题。([#6536](https://github.com/bambulab/BambuStudio/issues/6536))
3. 修复了部分场景下普通支撑生成时crash的问题。([#6535](https://github.com/bambulab/BambuStudio/issues/6535), [#6616](https://github.com/bambulab/BambuStudio/issues/6616))
4. 修复了部分场景下CPU占用率过高的问题。([#6562](https://github.com/bambulab/BambuStudio/issues/6562))
5. 修复了部分场景下Studio退出时的crash问题。([#6544](https://github.com/bambulab/BambuStudio/issues/6544))
6. 修复了Window 7上无法启动的问题。
7. 修复了部分场景下Timelapse gcode中插入了升降温指令导致打印时间变长的问题。
8. 修复了部分场景下支撑料打印，H2D打印机报错的问题。
9. 修复了部分场景下AMS同步后，耗材丝预设未及时刷新的问题。([#6583](https://github.com/bambulab/BambuStudio/issues/6583), [#6197](https://github.com/bambulab/BambuStudio/issues/6197), [#6511](https://github.com/bambulab/BambuStudio/issues/6511), [#6478](https://github.com/bambulab/BambuStudio/issues/6478))
10. 更新了部分俄罗斯语翻译，感谢 [@AndylgTom](https://github.com/AndylgTom)的贡献。
