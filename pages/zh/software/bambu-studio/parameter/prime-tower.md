## 擦料塔

**在多色打印或者启用了平滑模式延时摄影的打印任务中，我们通常会需要用到擦料塔。** 工具头在空驶或者换料冲刷后，喷嘴可能还会残留一点材料。而启用擦料塔可以用来清理喷嘴上的残留料并且让喷嘴内部的腔压达到稳定状态，这样继续打印的时候就可以避免打印模型表面出现外观瑕疵。

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E6%89%93%E5%8D%B0%E7%9B%98%E6%93%A6%E6%96%99%E5%A1%94%E5%AE%9E%E7%89%A9%E5%9B%BE.png)

**从下图我们可以看到，擦料塔表面吸收了很多瑕疵，它可以帮助打印的模型表面更加干净整洁：**

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E6%93%A6%E6%96%99%E5%A1%94%E8%A1%A8%E9%9D%A2%E7%91%95%E7%96%B5%E5%9B%BE.png)

擦料塔是默认开启的，**不过只有在多色打印任务或者延时摄影选择平滑模式的时候才会在打印板上生成。** 您可以在其他——擦料塔中可以启用或者关闭它。

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/studio%E4%B8%AD%E6%93%A6%E6%8B%AD%E5%A1%94%E8%AE%BE%E7%BD%AE.png)

### 多色打印擦料塔

在多色打印中生成的擦料塔，形状和参数的解释如下。

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E6%96%99%E5%A1%94%E5%AE%BD%E5%BA%A6%E5%92%8C%E6%B7%B1%E5%BA%A6%E8%A7%A3%E9%87%8A.png)

**宽度：** 料塔的宽度，用户可以自定义，让料塔的所有层都采用设置的宽度。

**清理量：** 表示每一次换料，在料塔上打印的体积，**这指的是在擦料塔上的擦拭量，和设置换料时的冲刷体积是不同的概念。**

**注：冲刷体积=在吐料槽冲刷的体积+冲刷到支撑/填充/对象的体积。**

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E5%86%B2%E5%88%B7%E4%BD%93%E7%A7%AF%E8%AE%BE%E7%BD%AE%E9%A1%B5%E9%9D%A2.png)

根据清理量以及设置的层高和线宽可以计算出**每次换料后在料塔上需要打印的长度。**

**折返次数 = 每次换料打印的长度 / 料塔宽度，表示换料的走线需要来回折返几次，记为折返次数。**

**每次换料的料塔深度 = 折返次数 \* 走线线宽。**

**单层的料塔的总深度 = （折返次数 \* 线宽）\* 这一层换料次数。**

所以**单层换料次数越多，或者总清理量越大，这一层的料塔深度就越大。但是如果这一层的总清理量很少，料塔底部会有一个最小深度限制，防止料塔太窄在打印过程中脱落和倒塌**。当清理量较少时，擦料塔仍然需要保证一定的深度，所以喷嘴在擦料塔上折返的线就会比较稀疏，而不会密集排布。如下面动图所示：

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E6%B8%85%E7%90%86%E9%87%8F%E5%AF%B9%E6%B7%B1%E5%BA%A6%E7%9A%84%E5%BD%B1%E5%93%8Den.gif)

**如果不同层所需要的换料清理量不同，计算得出的较低层料塔深度小于较高层，会让较低层的料塔深度 = 较高层。**

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E6%93%A6%E6%8B%AD%E5%A1%94%E4%B8%8B%E9%9D%A2%E5%B0%91%E4%B8%8A%E9%9D%A2%E5%A4%9A1.gif)

**如果计算得出较高层料塔深度小于较低层，则较高层的料塔深度会减小，然后尽可能居中对齐。**

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E6%93%A6%E6%8B%AD%E5%A1%94%E4%B8%8B%E9%9D%A2%E5%A4%9A%E4%B8%8A%E9%9D%A2%E5%B0%91.gif)

**擦料塔的高度：** 擦料塔的高度是和模型高度同步增加的，多色打印的料塔高度会停留在最后换色的那一层。如下图所示，在最后一次换色后，由于后面的打印不需要再切换耗材了，所以也不用在擦料塔擦拭喷嘴了。有些模型可能在很高的地方才需要换色，擦料塔也会从第一层开始打印，一直打到需要最后一次换色的那层。

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E6%93%A6%E6%96%99%E5%A1%94%E9%AB%98%E5%BA%A6%E9%99%90%E5%88%B6en.gif)

**Brim宽度：** 用于设置擦料塔底部brim的宽度，添加brim可以使擦料塔更加稳固，防止打印过程中脱落倒塌。

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E6%93%A6%E6%96%99%E5%A1%94%E7%9A%84brim.png)

### 延时摄影擦料塔

除了多色打印，当你启用了平滑模式的延时摄影也会用到擦料塔。在启用了平滑模式的延时摄影后，打印完每层工具头将移动到吐料槽，然后拍摄快照。由于平滑模式在拍摄快照的过程中熔丝可能会从喷嘴中泄漏，因此也需要使用擦料塔进行喷嘴擦拭。延时摄影中选择“平滑模式”后，构建板上会生成一个擦料塔。\*\*所以用这个方法，也可以为单色的打印任务生成擦料塔。\*\*关于延时摄影功能的具体介绍可以参考：[延时摄影](../Timelapse.md)。

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E5%BB%B6%E6%97%B6%E6%91%84%E5%BD%B1%E9%80%89%E5%B9%B3%E6%BB%91%E7%94%9F%E6%88%90%E6%93%A6%E6%96%99%E5%A1%94.gif)

**不过，如果当前的打印任务已经是多色打印任务，那么平滑模式延时摄影将会复用多色的擦料塔来擦拭，不会再为延时摄影额外生成一个擦料塔。**

**宽度：** 和多色打印任务的擦料塔一样，用于设置料塔的宽度，用户可以自定义，让料塔的所有层都采用设置的宽度。

**清理量：** 延时摄影的擦料塔无法设置清理量，它仅由两圈外墙组成，中间是空心的，深度也是固定的。

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E5%BB%B6%E6%97%B6%E6%91%84%E5%BD%B1%E6%93%A6%E6%96%99%E5%A1%94%E7%A4%BA%E6%84%8F%E5%9B%BE.gif)

**擦料塔高度：** 由于延时摄影的原理是在每层打印结束后拍摄一次快照，所以每层拍完照喷嘴都需要去擦料塔上擦拭，**因此延时摄影擦料塔与打印板上最高的模型等高。**

### 注意事项

1. 切片之前的擦料塔只是一个示意图，不代表形状、高度和颜色分布是准确的。在切片后的才能预览到准确的形状、高度和颜色分布情况。

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/%E6%93%A6%E6%96%99%E5%A1%94%E5%88%87%E7%89%87%E5%89%8D%E5%90%8Een.gif)

2. 擦料塔只支持单向增加Z高度，所以即使有些层没有换料，也需要打印擦料塔来确保它和模型高度一致。**逐件打印模式下无法启用擦料塔。**

## Bambu Studio 2.0 擦料塔

从 Bambu Studio 2.0 版本开始，我们新增和优化了一些擦料塔设置，具体介绍如下：

## 1. 清理量参数与可摆放区域优化

### 1.1 清理量参数位置调整

在Bambu Studio 2.0版本中，我们将擦料塔清理量的参数设置移至"耗材丝设置"模块。这一改动使得在多材料混合打印时，用户能够为每种耗材单独设置清理量，不再受限于统一的清理参数。

![image_(12).png](https://wiki.bambulab.com/software/bambu-studio/prime-tower/image_(12).png)

此参数定义了换料后为清理喷嘴平衡腔内压力，在擦料塔挤出的材料体积。

- 材料清理量：适用于以下两种场景：

1. **单喷嘴机型（如 X1C、H2S）在单一固定热端上进行材料切换**，在吐料处完成冲刷后，在擦料塔上打印的清理量。
2. **多挤出机机型（如 H2D、H2C）在进行左右挤出机切换**后，在擦料塔上打印的清理量。

- **换热端清理量**： 适用于 H2C 机型，当右打印头在不同感应热端之间切换时在擦料塔打印的清理量。由于切换热端可能涉及更大的颜色过渡或材料兼容性问题，此值通常高于换料清理量。

注意：在 Bambu Studio 中，**“换挤出机”** 与 **“换热端”** 的具体含义如下：

- 在 H2D 和 H2D Pro 等双热端机型上，左右两个固定热端之间的机械升降切换，并伴随着挤出机的切换，我们称之为“换挤出机”。

![](https://wiki.bambulab.com/h2/manual/dual-nozzles-range/%E5%8F%8C%E5%96%B7%E5%98%B4%E5%88%87%E6%8D%A2.gif)

- 在 H2C 机型上，除了左右热端升降切换（称为“换挤出机”）外，其右打印头还可配合Vortek系统在多个感应热端之间切换，此动作被称为“换热端”。

![switch_hotend_(2).webp](https://wiki.bambulab.com/software/bambu-studio/prime-tower/switch_hotend_(2).webp)

### 1.2 擦料塔摆放区域优化

在切片前，擦料塔仅作为示意图显示，其实际形状、高度和颜色分布需在切片后才能准确预览。为确保擦料塔在大多数情况下不会超出边界，我们在切片前为其设置了移动边界限制。

自 Bambu Studio 2.0 版本起：

切片完成后，系统会基于实际尺寸更新准备界面中的擦料塔形状；

移除原有的边界限制，允许用户在准备页面自由调整擦料塔位置，优化打印布局的灵活性。

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/20250402144913_rec_.gif)

## 2. **多喷嘴打印漏料控制方案（仅针对多喷嘴打印机）**

在多喷嘴打印换料前后，针对易漏料材料增加额外的空驶运动，减少料塔表面材料堆积。当多头打印某些流动性好的材料时（如TPU），在打完tpu之后切换另一个喷嘴继续打印，这时TPU对应的喷嘴会挂起，为了减少喷嘴挂起期间漏料，会引入如下措施进行优化。**注：该部分的优化仅针对多喷嘴打印机。**

### 2.1 **动态降温控制**

针对漏料严重的材料，**切换喷嘴前在擦料塔上会先快速挤出一段材料**，我们称之为预冲刷。在预冲刷的同时进行降温，能够进一步缩短空驶吸附的时间（下文4.2中将会介绍）。从而在不显著增加换料时间的同时，减少切换喷嘴时的漏料和拉丝。

1. **参数控制**：

- **材料预冲刷长度**：该参数控制切换喷嘴前喷嘴在擦料塔上挤出的长度，0代表着禁用。禁用材料预冲刷长度后，切换喷嘴前仅会在擦料塔上打印简单的支撑结构为下一层提供支撑，并且将不再有空驶吸附动作，因为空驶吸附动作就是在材料预冲刷的间隙中进行的。由于预冲刷是以最大体积速度打印的，体积速度越大，溢料越少，同时为了防止打印速度过高，所以预冲刷的线宽是擦料塔普通走线线宽的两倍。

|  |  |  |
| --- | --- | --- |
| 启用预冲刷 | 禁用预冲刷 | 预冲刷的线宽更宽 |

- **切换喷嘴前期望的预降温温度**：预冲刷时喷嘴降温的目标温度。

![image_(14).png](https://wiki.bambulab.com/software/bambu-studio/prime-tower/image_(14).png)

- **材料打印喷嘴温度**

![image_-_2025-04-04t201233.992.png](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/image_-_2025-04-04t201233.992.png)

- **喷嘴降温速率：** 由打印机型号决定，用户无需自行调整。

2. **计算公式**： **预降温时间 = (材料打印喷嘴温度 - 预降温目标温度) / 喷嘴降温速率**
3. **执行逻辑**：

切换喷嘴前在擦料塔上快速挤出时同步降温。

挤出速度自动适配预降温时间要求。

**关闭方式**：如果不希望提前降温，**将预降温目标温度设置为0或者大于等于喷嘴打印温度即可。**

### 2.2 **切换喷嘴前空驶吸附**

1. **操作逻辑**：切换喷嘴前，TPU对应的喷嘴在擦料塔**预留吸附缝隙**处执行额外的**空驶路径**，确保熔融材料被缝隙吸收，不残留在打印路径上。然后在空驶至切换喷嘴处执行切换动作。如下图所示，在TPU走线空隙中的空驶即为换料前的空驶。

![image_-_2025-04-04t201240.834.png](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/image_-_2025-04-04t201240.834.png)

2. **参数控制**：可以在耗材丝设置中自定义预冲刷后的空驶时间（设为0秒可关闭该空驶）。另外，如果设置预冲刷后的空驶时间大于0，会自动将擦料塔的预冲刷的走线间距设置为2倍线宽，为空驶的溢料留出空间。

![image_(15).png](https://wiki.bambulab.com/software/bambu-studio/prime-tower/image_(15).png)

从 V2.4.0 版本开始，Bambu Studio 引入了 H2C 的预冲刷参数：

- 换挤出机预冲刷：适用于 H2D / H2C 等机型在左右热端之间切换前的预冲刷。
- 换热端预冲刷：适用于 H2C 机型在右打印头上不同感应热端之间切换前的预冲刷。
- 预降温目标温度（换热端）：仅会触发降温指令并开启风扇，系统不保证在预冲刷阶段能将喷嘴温度降至所设定的目标温度。

除上述三项参数外，其余预冲刷参数在“换热端”与“换挤出机”场景下的行为保持一致。

![image_-_2025-11-19t111846.770.png](https://wiki.bambulab.com/software/bambu-studio/prime-tower/image_-_2025-11-19t111846.770.png)

### 2.3 擦料塔冷却

Bambu Studio 2.5 版本新增“**擦料塔冷却**”参数。当该值大于 0 时，在切换挤出机后，热端将先升温至**目标温度减去该设定值**，随后在打印擦料塔的过程中逐渐升至目标温度。该功能主要用于减少换料过程中的漏料现象。  
例如，使用 PLA Basic 耗材时，若“擦料塔冷却”设置为 10℃，目标温度为 220℃，则换料后热端会先升至 210℃，并在打印擦料塔过程中再升温至 220℃。

![image_(16).png](https://wiki.bambulab.com/software/bambu-studio/prime-tower/image_(16).png)

## 3. 擦拭**塔起始点优化**

**问题背景**：在3D打印过程中，喷嘴换料后通常会残留少量材料或溢出的废料（下文统称为“料头”）。这些料头可能附着在擦料塔表面，尤其是在起始点附近。一旦凝固，它们会在后续打印中与喷嘴发生剐蹭，影响打印质量。为解决这一问题，我们推出了以下优化方案：

### 3.1 **料塔空驶避让**

**问题场景**：换料后空驶路径经过擦料塔主体区域，渗漏的材料粘附在料塔的填充区域。

**解决方案**：  
**空驶路径自动绕开擦料塔主体，使其不再与料塔在其打印起始点外的地方有交集，** 避免料头粘到料塔填充区域，如下图所示。

![](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/img_v3_02km_81ac21b9-23ab-4d8f-837b-c77ac1b1837g.jpg)

### 3.2 增加**外墙缺口**

**问题场景**：料头粘连在外墙表面，破坏外墙层高的一致性，且后续打印时喷嘴与擦料塔易刮蹭，影响料塔的稳定性。

**解决方案**：

在擦料塔外墙预留缺口，换料后首次打印路径从缺口处进入，使得料头附着在外墙缺口处而非外墙表面。

**操作选项**：

- 默认开启，可在Bambu Studio的 **工艺—其他—擦料塔—外墙缺口** 中选择启用或者关闭。

|  |  |
| --- | --- |
| 开启外墙缺口.png  启用外墙缺口 | 关闭后将打印封闭式外墙 |

### 3.3 打印起始点熨烫

为了彻底消除换料后料塔起始点附近料头的影响，系统会在擦料塔起始点执行“打印-熨烫-继续打印”操作。这一过程通过压实材料确保起始点层高一致，从而显著降低后续打印中喷嘴与擦料塔的剐蹭风险，下图中的螺旋空驶即为熨烫动作：

![image_-_2025-04-03t113344.238.png](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/image_-_2025-04-03t113344.238.png)

**操作选项：该操作与外墙缺口是联动的，关闭外墙缺口**即禁用此功能。

## 4. **开放额外参数控制**

### 4.1 擦料塔内支撑肋

在打印过程中，由于擦料塔各层所需的换料次数可能不同，各层料塔的深度会存在差异，进而在料塔内部可能形成“空区”。软件的最新切片算法里增加了内支撑肋结构。启用内支撑肋后，算法会在原本的空区内生成支撑结构，从而显著增强料塔的整体稳定。

|  |  |
| --- | --- |
| 上层料塔深度较窄，料塔内部出现空区 | 启用内支撑肋，增加空区处的稳定性 |

### 4.2 **料塔走线填充间隙**

擦料塔填充部分的走线间隙可手动设置，如下图所示。该参数表示两条走线中心线之间的间距，适当增加间隙有助于减少因材料膨胀或堆积导致的打印问题。

![image_-_2025-04-04t201302.362.png](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/image_-_2025-04-04t201302.362.png)

1. **设置方法：**

默认值为150%，即两条走线中心线间的距离为线宽的1.5倍，也就是两条走线的间隔为0.5倍线宽。

设置为100%时，走线间距将为0，适合高密度填充需求。

2. **注意事项**：

- 若材料启用了切换喷嘴前材料预冲刷功能（见4.1节），**预冲刷部分的走线间隙不会小于200%。**

### 4.3 **料塔填充打印速度**

料塔填充部分的走线最大速度支持自定义设置，默认值为90mm/s。如果觉得料塔打印表面质量比较好，可以适当提高，但这会增加打印头与料塔之间的剐蹭风险。

![image_-_2025-04-04t201307.970.png](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/image_-_2025-04-04t201307.970.png)

## 5. **擦料塔外轮廓优化**

传统擦料塔多采用柱状或立方体结构，随着高度增加，在喷嘴作用力下容易出现以下问题：

**Z向变形较大**：进一步增加喷嘴与料塔的剐蹭风险。

**底部粘接需求增加**：需要更大的热床粘接力，否则容易倾斜或倒塌。

**材料浪费**：单纯增大料塔尺寸虽能缓解问题，但会导致材料浪费。

新版本中，我们通过优化擦料塔外轮廓形状，显著提升了整体结构强度和稳定性，使其在高堆叠时具备更强的抗倾斜能力。

### 5.1 **外部加强肋设计**

1. **功能说明**：

在擦料塔外围添加斜向加强肋，提升抗振性和抗冲击性，减少因喷嘴剐蹭导致的偏移。我们将这种设计称为“肋角料塔”，其开启方式及形态见下图。

|  |  |
| --- | --- |
| 启用斜肋外墙 | 未启用斜肋外墙，传统柱状结构 |

2. **优势**：

相比传统等截面立柱，斜肋设计占用空间更少，节省材料。

减少 Z 向晃动，确保打印平面稳定性。

非斜肋部分与填充结构紧密贴合，增强整体支撑强度。

**注：当启用斜肋外墙后，为了确保擦料塔的形状是正方形，将无法调整其宽度。**

3. **参数调整**：

您可以通过调整一系列参数来改变肋角料塔的形状，具体解释如下。

![image_-_2025-04-03t115413.780.png](https://wiki.bambulab.com/bambu-studio/parameter/prime-tower/image_-_2025-04-03t115413.780.png)

- **斜肋额外长度：** 用于给斜肋增加额外的长度，额外长度越长，擦料塔在打印板占据的空间也就越大。

|  |  |
| --- | --- |
| 默认斜肋长度 | 斜肋额外长度10mm |

- **斜肋宽度：** 用于控制斜肋的宽度。**注意：斜肋宽度不能无限增大，需保证外墙与填充部分有足够的接触面积以维持整体强度。**

|  |  |
| --- | --- |
| 默认斜肋宽度 | 增加斜肋宽度，外墙与填充的接触面积变小 |

- **外墙倒圆角：** 启用外墙倒圆角后，外墙转角部分将以圆角的形式过渡，启用效果区别如下图。

|  |  |
| --- | --- |
| 启用外墙倒圆角 | 关闭外墙倒圆角 |

### 5.2 **动态轮廓调整**

为确保肋角料塔在X和Y方向上强度一致，我们将其设计为接近正方形的形状，并以对角线尺寸表示其大小。具体尺寸计算如下：

**橙色部分（a）**：**满足换料前后清理量要求的最小尺寸**，可通过调整**材料冲压长度、材料清理量**及**填充间隙**进行调整。

**蓝色部分（b）**：**满足料塔强度需求的推荐尺寸，随高度动态调整**，由程序自动计算。

**用户调整值（c）**：允许用户在推荐尺寸基础上额外调整，c为上文中提到的**斜肋额外的长度**，它的值可以是正值也可以是负值，正值增加肋壁，负值减小肋壁，**肋壁大小不能小于由清理量确定的最小值。如下示例，当擦料塔较高时，它的尺寸会自动调整为满足强度需求的尺寸**，通过减小斜肋额外长度，可以把它缩小至**满足清理量需求的最小尺寸。**

|  |  |
| --- | --- |
|  | 负值减小斜肋额外长度 |

**所以，料塔的最终尺寸 = max(b + c, a)**
