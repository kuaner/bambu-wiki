## 功能介绍

FDM 3D 打印的工作原理是熔化耗材丝并挤出，层层堆叠构建出 3D 模型。打印过程中，工具头不断移动，会产生大量空驶路径。我们不希望喷嘴在空驶时挤出耗材，但由于喷嘴的温度和内部压力，熔融的耗材丝仍可能渗漏出来，在打印件上留下拉丝。

回抽功能可以缓解打印中的拉丝现象，其原理如下：

- **空驶前**：提前将部分耗材丝从热端抽回，降低热端中熔融耗材的压力，从而减少空驶路径上的拉丝。
- **空驶后**：将耗材丝重新装填回热端，恢复正常出料，确保打印件不会挤出不足。

## 启用回抽

您可以在两个位置启用回抽功能并设置参数：

1. **打印机设置**：在「**打印机设置 → 挤出机**」中，设置打印机回抽的各项参数。

## 参数介绍

### 长度

回抽时拉回耗材丝的长度。设置为 `0` 表示关闭回抽。

### 回抽时抬升 Z

回抽完成后，喷嘴轻微抬升，与打印件之间留出间隙，以避免空驶时喷嘴剐蹭、碰撞打印件。

> **注意：** 该值最大不能超过 `5 mm`。

#### 自动

选择「**自动**」后，打印机会根据情况自适应选择 Z 抬升方式，判断逻辑如下：

- **单层内空驶**：先判断斜向抬升是否会经过悬空区域。
  - 斜向抬升在上升过程中会经过较大的 XY 区域，而悬空区域在打印中可能膨胀，二者有一定几率发生碰撞、刮蹭模型。
  - 若无碰撞风险，使用斜向抬升；否则使用螺旋抬升。因为螺旋抬升呈螺旋线，经过模型表面的 XY 区域较小，刮蹭概率更低。
- **换层时**：一律使用螺旋抬升方式。

### Z 抬升范围下限和上限

只有当 Z 抬升值落在该范围的下限与上限之间时，Z 抬升才会生效。该范围与打印机可打印的 Z 轴高度有关，不同型号打印机可能有所区别。

### 回抽速度

回抽时拉回耗材丝的速度。

### 装填速度

回抽后再次装填耗材丝的速度。设置为 `0` 表示与回抽速度保持一致。

### 空驶距离阈值

只有当工具头的空驶距离大于该阈值时，才会触发回抽。

打印带有小缝隙的模型时，空驶距离可能太小而无法触发回抽，导致喷嘴在缝隙间拉丝。此时可适当调整空驶距离阈值来触发回抽，改善该问题。示例如下：

> **注意：** 以下两种情况即使满足空驶距离阈值，也不会按常规触发回抽：
>
> - **启用「减小填充回抽」时**：在「**工艺 → 其他 → Gcode 输出**」中启用该选项后，只在打印完墙走线和换层时回抽，内部填充走线之间（如同心填充图案之间的空驶）不会触发回抽。因为回抽主要用于防止漏料拉丝影响外观，而模型内部的瑕疵通常可以忽略。
> - **支撑内部走线**：支撑内部走线即使满足空驶距离阈值，也始终不会触发回抽。因为支撑不属于模型的一部分，其内部瑕疵通常无需在意。

### 换层时回抽

启用后，每次换层时都会强制回抽。

### 回抽时擦拭

回抽时，让喷嘴沿前一段走线方向继续移动，清除喷嘴上的漏料，从而避免空驶结束、打印新区域时产生斑点。

|  |  |
| --- | --- |
|  |  |
| 回抽时擦拭 | 回抽前工具头的“抖动”动作即为擦拭 |

### 擦拭距离

启用「**回抽时擦拭**」后，可通过该值设置擦拭的移动距离。

![](https://wiki.bambulab.com/bambu-studio/parameter/%E5%9B%9E%E6%8A%BD%E5%89%8D%E6%93%A6%E6%8B%AD%E8%B7%9D%E7%A6%BB.png)

### 擦拭前的回抽量

擦拭前的回抽长度，以总回抽长度的百分比表示，默认值为 `0`。擦拭前不回抽时，外墙的 Z 缝效果会更好一些（适用于默认的内墙→外墙打印顺序）。

  

## 注意事项

回抽参数的设置需要平衡，过低或过高都会带来问题。请注意以下几点：

1. **回抽值不宜过高**：回抽对打印质量十分重要，缺少回抽很容易导致拉丝和漏料；但回抽值过高会使耗材丝被拉回过长或过于频繁，可能导致挤出不足、层间隙，甚至造成挤出机堵塞。
2. **柔性材料慎用回抽**：打印 TPU 等柔性材料时，回抽可能产生负面影响。这类材料具有弹性，回抽动作可能改变耗材丝直径并使其收缩，从而引起堵塞等挤出问题。而对于 PLA、ABS、PETG 等材料，启用回抽通常能较好地提升打印效果。
3. **先干燥再调参**：受潮耗材在打印中更容易拉丝、漏料，且通常仅靠调整回抽无法彻底解决。建议先干燥耗材，再调整回抽参数，以获得更好的打印质量。
