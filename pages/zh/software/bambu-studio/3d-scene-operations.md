## Bambu Studio快捷键

**Win**:在 Studio 左上角，点击下拉箭头，然后选择“帮助”，可以找到“快捷键”窗口。  
**Mac**:在窗口顶部直接点击帮助，即可找到“快捷键”窗口。

|  |  |
| --- | --- |
|  |  |

### Windows 快捷键

#### 全局

| 快捷键 | 功能说明 |
| --- | --- |
| Ctrl+N | 新建项目 |
| Ctrl+O | 打开项目 |
| Ctrl+S | 保存项目 |
| Ctrl+Shift+S | 项目另存为 |
| Ctrl+I | 从STL/STEP/3MF/OBJ/AMF文件中导入几何数据 |
| Ctrl+G | 导出单盘切片文件 |
| Ctrl+R | 切片单盘 |
| Ctrl+Shift+G | 打印单盘 |
| Ctrl+X | 剪切 |
| Ctrl+C | 复制到剪贴板 |
| Ctrl+V | 从剪切板粘贴 |
| Ctrl+P | 偏好设置 |
| Ctrl+Shift+M | 显示/隐藏3Dconnexion设备的设置对话框 |
| Ctrl+Tab | 切换标签页 |
| Delete | 删除所选项 |
| Shift+Alt+? | 显示键盘快捷键列表 |
| Ctrl+E | 在打印顺序为 “逐件” 的情况下，为每个对象显示打印序号标签。 |

## 控制视图

| 控制 | 鼠标 | 触控板 |
| --- | --- | --- |
| 平移 | 按住鼠标右键 + 移动鼠标 | Win：右键 + 滑动  Mac：按住 + 双指滑动 |
| 选择 | 左键 | Win：按住鼠标左键 + 滑动  Mac：⌘ Command + 三指滑动 |
| 缩放 | 滚动鼠标滚轮 | 两指滑动或捏合 |

## 选择对象/零件

| 目标 | 鼠标 | 触控板 |
| --- | --- | --- |
| 选择一个对象 | 左键 | 单击 |
| 选择多个对象 | Ctrl / ⌘ Command + 左键 | Ctrl / ⌘ Command + 单击 |
| 使用线框选择多个对象 | Shift + 左键拖动 | Shift + 单指拖动 |
| 选择零件 | Alt + 左键 | Alt + 单击 |

**注意：**

1. 修改器只需单击即可选择，无需Alt/Command。
2. Ctrl/Command + 左键，可取消选择当前选定的对象。
