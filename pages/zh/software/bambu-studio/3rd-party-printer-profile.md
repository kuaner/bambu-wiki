## 概述

如果您的打印机或喷嘴在 Bambu Studio 中不可用，您可使用此功能创建自定义打印机预设或为现有打印机添加新喷嘴。可在**创建打印机**中启用此功能：

![创建打印机.png](https://wiki.bambulab.com/create-printer/%E5%88%9B%E5%BB%BA%E6%89%93%E5%8D%B0%E6%9C%BA.png)

## 自定义打印机预置

自定义打印机预置和复制预置均属于用户预置，其中自定义打印机预置是创建用户打印机预置的高级方法。以下是使用步骤：

### 创建打印机

![创建打印机-喷嘴.png](https://wiki.bambulab.com/create-printer/%E5%88%9B%E5%BB%BA%E6%89%93%E5%8D%B0%E6%9C%BA-%E5%96%B7%E5%98%B4.png)

- **创建类型**：可创建打印机或为现有打印机创建喷嘴。如果从未创建过自定义打印机，请选择**创建打印机**选项。
- **打印机**：用于确定要定制的打印机的供应商和型号。如果没有要选择的供应商，可以点击**不能找到我的打印机模型**，输入供应商和型号。
- **喷嘴直径**：选择打印机的喷嘴直径。
- **热床形状**：热床形状默认为矩形，无法修改。
- **可打印形状**：热床的可打印尺寸，单位为毫米，请填写整数。
- **原点**：设置热床的原点位置。
- **热床 STL 模型**：上传热床 STL 模型。如果没有，可以跳过上传。
- **热床 SVG 图片**：上传热床 SVG 纹理。支持 .svg 和 .png 图像。如果不支持，可以跳过上传。
- **最大打印高度**：设置打印机的最大打印高度。

### 为现有打印机创建喷嘴

#### 创建打印机

![screenshot-20240918-193647.png](https://wiki.bambulab.com/create-printer/screenshot-20240918-193647.png)

选择要为哪台自定义打印机创建新喷嘴。

> 需提前创建打印机。

设置自定义打印机的基本信息后，单击**确定**按钮进入下一页。

#### 创建与打印机兼容的耗材和流程预设

1. 根据模板创建与打印机兼容的耗材和流程预设  
   ![screenshot-20240918-193834.png](https://wiki.bambulab.com/create-printer/screenshot-20240918-193834.png)

- **打印机预设**：包括系统预设和自定义打印机预设。有关自定义打印机的其他信息将从所选打印机预置中复制。
- **预设**：目前，Studio 提供了一些耗材和工艺预设模板供您选择。创建自定义打印机预设后，您可以在使用时选择这些耗材和工艺预设。

2. 根据当前打印机创建与打印机兼容的耗材和工艺预设：

![screenshot-20240918-193953.png](https://wiki.bambulab.com/create-printer/screenshot-20240918-193953.png)

- **预设**：如果您选择了**基于当前打印机创建**，以创建与您创建的自定义打印机兼容的耗材和工艺预设，那么您可以选择的耗材和工艺预设与您选择的**打印机预设**兼容。

点击创建按钮后，创建相应的预设，新预设将按照一定的命名规则创建。刷新界面后，当前打印机将则是您创建的新打印机，并会提醒您是否编辑当前打印机的预设。

![screenshot-20240918-194157.png](https://wiki.bambulab.com/create-printer/screenshot-20240918-194157.png)

## 自定义打印机设置

自定义打印机的**打印机设置**界面为修改创建时定义的变量提供了一个入口。打开**高级**选项，进入**基本信息**页面，点击**设置...** 按钮，可修改热床的形状、原点、纹理和模型。

![screenshot-20240918-194536.png](https://wiki.bambulab.com/create-printer/screenshot-20240918-194536.png)

![screenshot-20240918-194604.png](https://wiki.bambulab.com/create-printer/screenshot-20240918-194604.png)

## 删除自定义设置

本节介绍如何在 Bambu Studio 中删除自定义的**打印机预设**、**耗材预设**和**工艺预设**。

---

### 删除自定义打印机预设

点击打印机栏的 **「编辑」** 按钮，点击上侧 **「删除」** 图标，确认删除。

|  |  |
| --- | --- |
|  |  |

### 删除自定义耗材预设

点击耗材右侧的 **「▪▪▪」** 图标 → **「编辑」** → 上侧的 **「删除」** 图标 → **「是」**。

|  |  |
| --- | --- |
|  |  |

---

### 删除自定义工艺预设

在工艺栏，点击 **「删除」** 图标，然后点击 **「是」** 进行确认。

![zh_process.png](https://wiki.bambulab.com/software/bambu-studio/delete-custom-settings/zh_process.png)

## 云用户预设限制

启用用户预设同步后，新创建的打印机及相关耗材和流程预设将上传到云服务器。但**服务器仅支持有限的用户预设：最多支持 20 个打印机预设、100 个流程预设和 200 个耗材预设**。如果超出限制，新创建或导入的预设只能保存在本地，无法与当前账户的其他预设同步，并且 Studio 会弹出相应提示。

![20240919-093150.jpg](https://wiki.bambulab.com/create-printer/20240919-093150.jpg)

在此情况下，可通过导出和导入预置，手动同步多台计算机上的预置。
