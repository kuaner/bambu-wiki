# 功能介绍

“旋转花瓶”功能是一种特殊的打印模式，它仅通过一条走线来打印外墙，并通过螺旋上升的方式逐渐增加 Z 高度。这样，除了底部壳体的那几层，之后的每层外墙走线就不存在起始点和终点，就不会在模型表面留下“疤痕”一样的接缝（详情参考[接缝设置 | Bambu Lab Wiki](Seam.md)），这能够极大程度地改善模型表面的质量。

下面两个图片就是普通模式和旋转花瓶模式的对比，可以看到“旋转花瓶”模式打印的模型表面没有接缝。

# 使用方法和注意事项

1. “旋转花瓶”模式可以在特殊模式里启用：

![](https://wiki.bambulab.com/software/bambu-studio/spiral-vase/开启旋转花瓶.png)

2. 当你确认启用旋转花瓶模式后，它将会自动调整设置，把外墙层数设为1，顶壳层数设置为0，稀疏填充密度设为0%：

![](https://wiki.bambulab.com/software/bambu-studio/spiral-vase/旋转花瓶模式提示.png)

3. 不过要注意的是，用旋转花瓶模式打印出来的模型仅有单层墙，没有填充和顶壳。因此，它只适用于一些结构较为简单的模型。结构较为复杂的模型用该模式打印的话，由于无法通过一条走线完成，可能会出现悬空部分，如下图所示：

|  |  |
| --- | --- |
| **图2-1 普通模式** | **图 2-2 旋转花瓶模式** |

4. 如果在单个打印任务中，想要用“旋转花瓶”模式，同时实现多个对象的打印，请您选择“逐件”打印顺序。

![](https://wiki.bambulab.com/software/bambu-studio/spiral-vase/zhujian.png)

5. 在Bambu Studio1.9.0版本，引入了**“平滑旋转花瓶”**的选项。有些模型表面不够平滑圆润，导致启用“旋转花瓶”后前后层的起终点连接不够平滑，表面会出现类似“接缝”的纹路。启用“平滑旋转花瓶”选项后，将会做一个弧线拟合连接，来消除模型表面的接缝。

**最大XY平滑阈值：**由于该选项实际上是拟合前后层终止点和起始点的路径，把原本的折线拟合成弧线。该阈值表示最大的XY平面移动距离，也就是拟合的弧线与原本路径在XY平面的最大距离。当以%为单位时，基于喷嘴直径计算的阈值（例如：0.4mm喷嘴，200%代表阈值是0.8mm）。

![](https://wiki.bambulab.com/software/bambu-studio/spiral-vase/平滑旋转花瓶选项.png)

启用平滑旋转花瓶的效果如下图所示：

![](https://wiki.bambulab.com/software/bambu-studio/spiral-vase/开启旋转花瓶平滑模式对比.gif)
