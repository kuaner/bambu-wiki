## 新功能：

1. **新增H2C机型适配：**全面适配 H2C 机器，并新增曲面雕刻能力。
2. **H2Dpro机型支持曲面雕刻功能：**H2D Pro 机型现已支持曲面雕刻，拓展更多创作可能。（支持H2D Pro机型固件01.01.00.00或以上版本）
3. **新增多页签展示功能：**Bambu Suite 现支持以标签页形式同时打开与切换多个项目文件，大幅提升多项目设计与编辑效率**。**

![](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-1-3-50/1.gif)

4. **新增自由画笔功能：**新增铅笔工具，用户可进行自由手绘创作。

![](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-1-3-50/2.gif)

4. **新增 PDF 导出功能（打印后刀切工艺）：**打印后刀切工艺发送纸质打印时，支持导出pdf文件，按原始大小打印后可继续在机器加工。

![](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-1-3-50/11.png)

## 优化：

1. **优化图形矢量化算法：**优化图形矢量化算法，提升细节识别与性能表现；新增「原图」按钮，可直观对比 Trace 结果与原图还原程度。

![](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-1-3-50/3.gif)

2. **优化粘贴行为：**复制粘贴操作，将图案粘贴到当前视图窗口内，而非原始图案位置附近。

![](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-1-3-50/4.gif)

3. **优化加工模式选择：**将加工模式设置移动至材料分组区域，同一材料使用相同加工模式，无需重复设置。

4. **优化灭火器功能：**更新灭火器弹窗的视觉样式与关闭逻辑，提升使用体验。
5. **解除加工次数限制：**取消加工次数的最大限制，保留最小次数限制，使加工设置更灵活。

## 修复：

1. 修复部分场景适配深色模式的显示问题。
2. 修复机器端项目的缩略图显示问题。
3. 修复默认标定矩阵字体偏大的问题。
4. 修复参数中部分wiki无法点击的问题。
5. 修复mac端文字工具显示的问题。
6. 修复在线模型的语言显示错乱问题。
7. 修复局域网模式下，打开代理无法连接机器的问题。
