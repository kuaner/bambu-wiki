## Bug 修复

1. **修复启动问题** - 修复部分用户在特定电脑环境下无法启动 Bambu Suite 的问题。
2. **DXF 文件的填充行为** - 修复导入 DXF 文件后，选中部分对象并切换填充工艺时，填充区域显示异常的问题。
3. **文字工具显示** - 修复文字工具中元音字母无法正常显示的问题。
4. **贴纸工具的稳定性** - 修复在特定文件中使用贴纸工具时可能导致软件闪退的异常，提升了贴纸功能的稳定性和兼容性。
