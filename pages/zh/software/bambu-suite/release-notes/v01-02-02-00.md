## 新功能

1. **圆柱/旋转雕刻功能适配：** H2D Pro 机型现已支持在圆柱体表面进行激光雕刻，满足更多个性化定制与创意制作需求。

   适配信息：目前支持 H2D Pro 机型固件 01.02.00.00 或以上版本

> 如需了解详情或更多帮助，查看[圆柱/旋转雕刻功能说明](https://e.bambulab.com/t?c=vJZzvWSO86FBPNBw)

2. **增加激光图层颜色：** 激光颜色从原有数量增加至 16 种，支持参考为不同颜色分别设置参数，满足更丰富的制作效果。

![1.png](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/1.png)

3. **支持继续绘制：** 允许在已绘制的对象上继续进行绘制操作，提升创作灵活性。

![2.gif](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/2.gif)

4. **支持图形库拖拽添加：** 支持在图形库中通过拖拽方式直接将对象添加至画布，操作更直观便捷。

![3.gif](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/3.gif)

## 优化

1. **打印后刀切项目制作流程优化：** 调整了“打印后刀切”项目的制作流程，现支持单独发送任务或单独导出标定点纸张，流程更灵活。

![4.gif](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/4.gif)

2. **自动摆盘处理优化：** 进入准备页面时，提供“自动摆盘”与“保持设计布局”两种选项，支持保留对象在设计页面中的相对位置。（用户可随时在“偏好设置-项目”中修改）

![5.gif](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/5.gif)

3. **绑定、组合、合并功能UI优化：** 重新组织了绑定、组合、合并功能的入口，使界面更简洁、功能归类更合理。

![6.png](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/6.png)

4. **图片编辑工具优化：** 调整了图片编辑工具的 UI 布局，并补充了编辑工具的示例图，帮助用户更快上手。

![7.gif](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/7.gif)

5. **偏好设置中补充对象导入设置：** 用户可随时在偏好设置中修改导入尺寸过大对象时的处理策略，满足不同工作习惯。

![8.png](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/8.png)

6. **曲面雕刻可打印区域优化：** 将曲面雕刻的可打印区域优化为多边形显示，更充分利用材料。

![9.png](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/9.png)

7. **补充参数项说明：** 为加工参数项增加了文字说明与图示，降低理解成本。

![10.png](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/10.png)

8. **图片对象半透明处理：** 拖动、选中或框选对象时，图片对象将呈现半透明效果，减少对背景拍照图的视觉遮挡，操作更加直观清晰。

![11.gif](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/11.gif)

9. **长列表窗口中补充滚动条：** 为部分长列表窗口添加了滚动条，浏览与操作更为便利。

![12.gif](https://wiki.bambulab.com/software/bambu-suite/release-notes/1-2-2-0/12.gif)

10. **加载文件时单独过滤异常对象：** 加载文件时，支持单独识别并过滤出异常对象，其余正常对象仍可正常加载，避免因个别对象问题导致整体加载失败。
11. **优化部分法语翻译：** 针对法语设置下的部分文案进行了优化显示（感谢提出优化建议的用户）。

## 修复

1. 修复内置MW项目无法正常查看的问题。
2. 修复添加矩形对象触发文字对象尺寸变小、手动修改文字尺寸时数据异常的问题。
3. 修复Windows 系统设置为“自动隐藏任务栏”时，Bambu Suite出现黑屏闪烁的问题。
4. 修复打印后刀切项目在镜像操作后，切割路径异常的问题。
5. 修复Arial Nova/Arial Black等子家族字体缺失的问题。
6. 修复打开特殊项目软件会崩溃的问题。
