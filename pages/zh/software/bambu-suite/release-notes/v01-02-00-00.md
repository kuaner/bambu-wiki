## 新功能

1. **新增圆柱/旋转雕刻功能：**支持在圆柱体表面进行激光雕刻，满个性化定制与创意制作需求。

1）表面特性要求

- 平滑曲面,不能有剧烈起伏(最大支持15mm高度差)
- 物体轴线与物体中轴线夹角小于40度

2）几何限制

- 材料不能有高度突变(例如阶跃超过3mm的阶梯状物体)
- 尖角、内斜角区域较难加工

3）材料限制

- 不支持透明材质(如普通玻璃、透明亚克力等)
- 不支持镜面材质(如强反光金属、镜子等)

**适配信息：**目前支持H2D机型固件**01.02.30.00或以上版本**

**了解详情或更多帮助 : [圆柱/旋转雕刻功能说明](https://e.bambulab.com/t?c=vJZzvWSO86FBPNBw)**

2. **新增IP+访问码连接功能：**支持使用IP+访问码连接设备，满足远程管理、跨网段访问等高级工作场景。

![](https://wiki.bambulab.com/software/bambu-suite/release-notes/01-02-00-00/007.gif)

3. **新增MakerLab激光盒子生成器：**支持使用激光盒子生成器快速设计激光盒，并一键导入Bambu Suite进行加工。

![](https://wiki.bambulab.com//software/bambu-suite/release-notes/01-02-00-00/012.png)

4. **新增文字/对象搜索功能：**支持在对象列表中进行快速搜索，提升创作效率。

![](https://wiki.bambulab.com/software/bambu-suite/release-notes/01-02-00-00/008.gif)

## 优化

1. **材料分组优化：**根据多样化的加工模式对材料库进行分组管理，筛选更便捷。

![](https://wiki.bambulab.com/software/bambu-suite/release-notes/01-02-00-00/013.png)

2. **绘制工具撤销行为优化：**使用钢笔工具绘制时，支持单步撤销操作，调整更灵活。

![](https://wiki.bambulab.com/software/bambu-suite/release-notes/01-02-00-00/006.gif)

3. **文字属性修改优化：**支持选中多个文字对象，并统一修改其字体、大小等属性，批量编辑更高效。

![](https://wiki.bambulab.com/software/bambu-suite/release-notes/01-02-00-00/005.gif)

4. **软件运行逻辑优化：**调整为单实例运行模式，可通过选项卡编辑多项目。
5. **代码图形框架优化：** 升级底层框架。

## 修复

1. 修复发送任务提示证书过期的问题。
2. 修改MAC平台输入中文显示异常的问题。
3. 修复特定环境下界面底部显示不完全的问题。
4. 修复特定环境下设置本地字体不生效的问题。
5. 修复特定文件下编辑对象卡顿的问题。
6. 修复特定文件导入后选中框异常显示的问题。
7. 修复部分UI显示问题。
