## **功能介绍**

批量雕刻功能专为标准化小尺寸物品的高效加工而设计。依托先进的视觉算法，Bambu Suite能够智能识别与样本相似的材料，精准定位并自动生成相同设计，从而简化设计调整流程，显著提升生产效率，使您的制造过程更加便捷高效。

该功能通过俯视摄像头捕捉加工平面，精准识别多个材料的轮廓位置，并基于形状相似性实现图案的批量复制。这不仅优化了排版效率，也进一步提升了整体生产流程的智能化和自动化水平。

## 操作步骤

1. **摆放加工材料**

   - 放置相同大小、形状、颜色的材料到激光/模切垫板上（Suite软件未开启精细轮廓提取时，建议放置间隔超过5 mm）。
   - 物体需要摆放在俯视摄像头视野内，不应超出垫板加工区域边界或俯视摄像头视野。

   | 正确摆放 | 错误摆放：物体形状不同 | 错误摆放：物体摆放重叠 |
   | --- | --- | --- |
   |  |  |  |
2. **设计准备**

   - 在设计界面的画布上导入/创建图案，按需完成个性化调整**（无需手动复制多份）**。
3. **进入加工准备**

   - 点击「准备制作」→ 选择材料类型。
4. **开启精细轮廓提取（可选）**  
   如果需要更精细的材料轮廓，需要手动开启精细轮廓提取开关。默认状态时，精细轮廓处于关闭状态，也就是默认自动摆盘使用相对粗略的轮廓。**在大多数情况下，使用精细轮廓都会得到更准确的材料轮廓边界，但轮廓提取过程将更加耗时。**

   - 鼠标移动到**拍照**上方，在浮窗内开启精细轮廓提取。
   - 通常在物体摆放紧密或者物体比较细小时，建议开启此选项以提高成功率。
   - 开启精细轮廓提取会提高轮廓处理的精度，同时也会增加轮廓的计算时间，批量雕刻和自动摆盘会等待精细轮廓计算完成。
   - 首次开启精细轮廓提取时会联网下载“精细轮廓提取AI模型”，下载完成后拍照时可以处理得到目标物体的精细轮廓。  
     ![](https://wiki.bambulab.com/h2/manual/batch-engraving/fine_contour_extraction.png)
5. **拍摄材料图像**

   - 点击「拍照」以获取加工材料俯视图。Bambu Suite将会自动提取材料轮廓。这一步耗时约8~10秒，请耐心等待界面刷新出材料图。
6. **设定基准位置**

   - 将图案拖拽至**任意一个材料**表面，并调整位置和角度，使得图案完全落在材料轮廓的内部。
7. **批量复制和摆放图案**

   - 点击「批量雕刻」。Bambu Suite将自动识别其余材料轮廓，并按相同相对位置和角度复制图案到其余轮廓内部。
8. **执行加工**

   - 点击「制作」。Bambu Suite将一次性制作出所有图案。

![](https://wiki.bambulab.com/h2/manual/batch-engraving/1.gif)

## 注意事项

1. **依赖拍照功能**

   - 使用俯视摄像头拍摄垫板背景图，使用批量雕刻前需要确保俯视摄像头被正确安装，在Bambu Suite中能够正常完成拍照。

   ![俯视摄像头](https://wiki.bambulab.com/h2/manual/batch-engraving/image.png)
2. **材料要求**

   - 所有材料需为**相同形状与材质**，否则批量复制图案和自动摆放结果可能不正确。
   - 材料**颜色**需要和背景垫板应有一定差异，以保证Bambu Suite提取的物体轮廓边界清晰。
   - 材料**尺寸**需要在2cm到30cm之间（最短边长度）。材料太小不容易识别，材料太大则可能会超出俯视相机视野或加工范围。
   - 材料**厚度**应小于5mm。如果材料太厚，材料的阴影可能影响轮廓提取的精度。
3. **基准位置设定**

   - 须手动摆放**首个图案**，将其摆放至其中一个材料的表面，批量雕刻功能以此为标准批量复制。
4. **精细轮廓提取**

   - 精细轮廓提取可以提升批量雕刻的成功率，尤其是小物体和摆放紧密的物体。

|  | 默认轮廓提取 | 精细轮廓提取 |
| --- | --- | --- |
| 轮廓精准程度 | 粗糙 | 精准（更高的批量雕刻成功率） |
| 对物体大小要求 | 使用激光垫板：物体长宽>=20mm\*5mm使用模切垫板：物体长宽>=5mm\*5mm使用非官方垫板：不支持轮廓提取 | 使用激光垫板：物体长宽>=20mm\*5mm使用模切垫板：物体长宽>=5mm\*5mm使用非官方垫板：物体长宽>=30mm\*30mm（小于建议尺寸的物体也有机会批量雕刻成功，但是随着物体变小，识别准确率会降低） |
| 对物体摆放要求 | 物体摆放间隔 > 5mm  不允许物体摆放较近，导致轮廓粘连 | 避免重叠即可小于要求尺寸的物体，建议摆放间隔 > 5mm允许物体摆放较近 |
| 处理时间 | <1s ，通常在拍照后立刻完成(具体取决于计算机配置和任务状态) | 10s-20s（具体取决于计算机配置和任务状态） |

5. **垫板清理**

垫板的状态影响轮廓提取的精度，建议使用批量雕刻功能之前清理干净垫板。

| **雕刻碎屑** | **垫板刻痕** | **默认轮廓提取：仅支持官方垫板** |
| --- | --- | --- |
| - 较小碎屑 (长宽5mm以下)通常不会影响批量雕刻目标轮廓提取。 - 较大碎屑有可能会被识别成被雕刻物。 | - 较轻微的雕刻痕迹通常不会影响批量雕刻。 - 如果雕刻痕特别严重，则有可能影响轮廓提取精度。下图所示的垫板就不适合用于批量雕刻。 | - 材料需要摆放在官方垫板上。非官方垫板可能被整个识别为加工材料。 **开启精准轮廓提取：支持非官方垫板** |
|  |  |  |

6. **处理时间**

具体处理时间取决于您的计算机配置和操作系统运行状态。通常，批量雕刻的计算会在确定雕刻图案和位置后的1s内完成。
