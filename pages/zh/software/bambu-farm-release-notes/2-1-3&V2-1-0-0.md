## **新增**

1. 支持机型扩展：H2D、H2D Pro，X1E

- H2D 需升级至 01.02.00.00 或之后的版本。
- H2D Pro 需升级至 01.01.00.00 或之后的版本。

- X1E 需升级至 01.01.03.12 或之后的版本。

2. 挂载耗材总览页：

- 在同一页面内，完整展示每台打印机的外挂料盘与 AMS 各槽位的耗材状态：是否已装载、耗材类型及颜色。支持 AMS 列显示控制，一屏即可纵览多台设备的耗材情况。
- 批量更换耗材：可同时勾选多台打印机，统一设定耗材类型与颜色，告别逐台重复操作。

![](https://wiki.bambulab.com/software/bambu-farm-release-notes/2-1-3-2-1-0-0/image-4.png)

3. 打印设置支持AMS耗材自动映射、固定映射和单机编辑

- 自动映射：料槽内为 Bambu Lab RFID 耗材，或已手动设定耗材类型与颜色时，打印前可启用“自动配置”。系统一键将模型所需耗材与对应料槽匹配；若无法完成自动映射，将在界面给出提示。

![](https://wiki.bambulab.com/software/bambu-farm-release-notes/2-1-3-2-1-0-0/image-2.png)

- 固定映射：如需用固定槽位统一批量打印流程，可先开启“固定耗材映射”并设定槽位对应关系；软件将据此自动刷新打印机映射，若某台打印机无法满足该映射，将在界面给出提示。

![](https://wiki.bambulab.com/software/bambu-farm-release-notes/2-1-3-2-1-0-0/image-3.png)

- 单机修改：若对自动或固定映射结果不满意，可在核对后点击目标耗材，自行调整其在当前打印机上使用的槽位。

![](https://wiki.bambulab.com/software/bambu-farm-release-notes/2-1-3-2-1-0-0/image-1.png)

4. 客户端定期连接拓竹官网，检查软件新版本并提示。
5. 客户端定期连接拓竹官网，下载 HMS 数据更新包。
6. 新增客户端日志导出功能。
7. 新增葡萄牙语支持。

## **改进**

- 客户端裁剪组件，应用程序体积显著缩减。
- 服务器侧裁剪组件，应用程序体积显著缩减。
- 服务器端降低数据库备份频率，备份保留由最近 7 天减少至最近 3 天，减少磁盘空间占用。
- 服务器支持 3MF 断点续传功能。
- 删除 3MF 文件时，若文件正被运行中的任务引用，则提示无法删除。

## **Bug 修复**

- 修复批量绑定与批量清盘时客户端与服务器连接断开问题。
- 磁盘空间不足导致服务器数据库备份失败时，自动清理不完整备份文件。
