## 新增

### 1. **打印机网络状态监控与远程配置功能**

**【功能入口】**  
进入 **打印机列表页面** -> 点击右上角 **[...] 更多按钮** -> 选择 **网络状态与配置**

**【支持机型与固件版本】**

- **P1 系列**：固件版本不低于 `01.11.00.00`
- **A1 系列**：固件版本不低于 `01.09.00.00`

> *注：网络状态展示功能需要更新打印机固件。A1/P1 系列预计近期会有适配固件更新，其他机型将后续逐步适配支持。*

#### 1.1 **网络状态与拓扑展示**

当场地内部署了多个 Wi-Fi 热点、且有上百台打印机同时接入时，本功能可为网络质量监控提供有效手段，使您能够直观了解设备的网络接入情况，为后续的网络调优与排查提供数据支持。

- **网络拓扑与归类**：按热点名称（SSID）和 BSSID 归类显示打印机连接关系，使接入结构清晰可见。
- **质量综合评估**：信道、RSSI（信号强度）、延迟和掉线次数等指标，全方位呈现网络运行状态。

![](https://wiki.bambulab.com/software/bambu-farm-release-notes/3-1-0/0.png)

#### 1.2 **远程配置 Wi-Fi**

为减少网络改造时逐台手动切换 Wi-Fi 的繁琐流程，现支持在“网络状态与配置”页面进行远程切网。同时提供 3 种回退策略，最大程度保障设备切网后的在线稳定性：

- **未连接服务器则自动回退（推荐）**

  若 60 秒内未能通过新 Wi-Fi 成功连接农场管家服务器，打印机将自动恢复至原 Wi-Fi。适用于服务器 IP 不变的网络架构调整场景（如多 SSID 合并为一个、或一个拆分为多个）：在此情况下，打印机切网后可直接与原服务器恢复通信。
- **未接入新热点则自动回退**

  若 30 秒内未能连上新热点或路由器，将自动恢复至原 Wi-Fi。适用于服务器无法同时接入新旧网络的场景：需先将打印机切换至新热点，随后再把服务器迁移至新网络以恢复连接。
- **连接失败不自动回退**

  新 Wi-Fi 配置直接生效，连接失败不会退回原配置。适用于打印机搬迁至 Wi-Fi 配置相同的新环境；操作前请务必确认 SSID 和密码正确。

### 2. 支持上传多盘 `.gcode.3mf` 文件

文件上传支持直接导入多盘 `.gcode.3mf` 文件。上传后，系统会自动将其解析为多个子盘，方便您后续进行独立的发送与打印。

- **重命名规则**：上传前支持自定义修改子盘名称；若不修改，系统将默认命名为 `文件名_plateN`（N 为盘号）。
- **后续规划**：Bambu Studio 端发送至农场管家（发送至 BFMC）的接口功能已预留，Studio 将在后续版本中正式支持。

## **优化与改进**

1. **优化打印机利用率图表加载速度：**切换为按分组筛选数据范围。通过在后台对历史数据进行聚合预处理，大幅缩短了图表加载时间，解决历史数据较多时因加载超时而失败的问题。
2. **减少任务派发时的重复错误提示：**任务发送成功后，后台重试产生的临时错误提示会自动清理，避免因历史报错未清除而导致状态误判。
3. **文件全局搜索结果支持直接新建任务：**在模型文件全局搜索页面中，现在可以直接对搜索结果执行“新建任务”操作，无需再返回原目录。
4. **优化文件夹内搜索与返回体验：**在文件夹内搜索并点击“新建任务”后，若仅查看后并返回，系统将自动保留搜索条件与结果，免去重新输入。

## 修复：

1. **修复 H 系列打印机并行加热名额未能正确释放的问题：**当打印时开启主动仓温加热，同时软件侧配置了并行加热数量限制时，因软件侧未正确同步仓温上报状态，导致系统未能准确判定加热已结束，进而使对应的并行加热名额未能及时释放。现已修复该问题。
2. **修复服务器重启后打印机版本号显示为空的问题：**针对千台规模打印机连接场景，修复了服务器重启时因初始化消息积压导致版本号同步失败的问题。若进入升级页面发现打印机版本号为空，可稍后重新进入该页面，服务器会自动重新同步打印机版本。
3. **修复批量确认清盘时软件侧任务状态未同步的问题**：在数百台打印机同时清盘时，修复了设备端已完成、但软件侧仍显示关联任务的延迟问题，确保两端状态实时同步
