## 处理方法

### 检查是否达到最低配置要求

请运行“性能检测”，确保硬件满足 Bambu Scan 的最低配置。

- 最低配置:Intel i7 Gen7或AMD Ryzen7系;64位Windows10/11;内存≥16GB;显卡Nvidia 2060及以上,显存≥6GB
- 推荐配置:Intel i7 Gen13或AMDRyzen9系;64位Windows10/11;内存≥32GB;显卡Nvidia 3060及以上,显存>8GB

### 其他软件占用内存过大

打开 Windows 任务管理器，检查各软件的内存占用情况，若其他软件能够关闭，建议优先关闭。

### 降低 Bambu Scan 的内存占用

1. 提高点间距

   - 提高点间距可降低点云密度，减少软件的资源占用，但会损失扫描细节。

|  |
| --- |
| 005.png |

- 扫描后及时清理点云。

在点云处理页面可使用更多点云清理工具，但若内存不足，也可在扫描完毕后提前清理，减轻软件的资源占用。

- 分多次进行点云融合

扫描时新建其他扫描项，那么结束扫描时可以同时融合多个点云。

若设备内存不足，可结束一次扫描后，立刻点击“完成扫描”，融合完成后再新建扫描，一次仅处理一项。

### 检查虚拟内存及磁盘剩余空间

Windows 通常会默认启用虚拟内存功能。当物理内存不足时，系统可以借助磁盘上的页面文件提供额外的内存支持，但处理速度可能有所下降。

建议检查以下设置：

- **确认虚拟内存已启用。** 建议保持 Windows 默认的“自动管理所有驱动器的分页文件大小”设置。
- **确保磁盘有充足的剩余空间。** 除项目所在磁盘外，还应检查虚拟内存页面文件所在磁盘的剩余空间。

> 按下 `Win + R`，输入 `sysdm.cpl` 并回车，依次选择“高级”→“性能”中的“设置”→“高级”→“虚拟内存”中的“更改”，检查是否已启用自动管理。
