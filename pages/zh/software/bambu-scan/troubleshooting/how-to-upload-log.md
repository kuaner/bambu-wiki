## 介绍

当扫描仪或软件出现故障时，导出并上传日志会有利于技术团队分析故障原因。

## Bambu Scan 软件日志导出操作

点击左上角菜单栏-帮助-导出日志。

|  |
| --- |
| 001.png |

选择需要导出的日志时间，点击导出。

|  |
| --- |
| 003.png |

指定压缩包到指定位置后保存，生成压缩包文件。后续可随固件日志一同导出给支持团队。

## 扫描仪日志导出操作

在软件中点击设备页面。

|  |
| --- |
| 005.png |

选择导出日志。

|  |
| --- |
| 007.png |

等待扫描仪的日志导出完毕后，点击弹窗中的“打开文件夹”，即可获得扫描仪日志。

| --- |
