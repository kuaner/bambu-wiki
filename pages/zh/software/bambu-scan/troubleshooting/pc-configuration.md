## 电脑配置

在扫描过程中，扫描仪会实时捕获海量点云数据并通过 USB 3.1 或 Wi‑Fi 6 传输到电脑。随后，CPU 要负责对这些原始数据进行去噪、配准和拼接，GPU 则承担实时预览、渲染和后期网格生成的负载，而足够容量与速度的内存则用来缓存临时点云、保持工作流流畅。若任一环节的性能不足，整个扫描链路都会出现卡顿甚至中断。

**硬件性能不足时可能出现的故障**

|  |  |
| --- | --- |
| 硬件部件 | 可能导致的具体问题 |
| USB 3.1 | 数据丢帧、点云丢失、扫描中途断连 |
| Wi‑Fi 6 | 数据传输延迟、实时预览卡顿、扫描轨迹不连贯、偶发断连 |
| CPU | 扫描过程卡顿、后处理时间异常长，甚至软件崩溃 |
| GPU | 实时预览帧率下降、网格细分卡顿、无法进行高分辨率/精细扫描 |
| 内存 | 点云缓存溢出，出现“内存不足”提示，后处理时频繁卡死或自动退出，无法进行高分辨率/精细扫描 |

### 最低及推荐配置

- 最低配置:Intel i7 Gen7或AMD Ryzen7系;64位Windows10/11;内存≥16GB;显卡Nvidia 2060及以上,显存≥6GB
- 推荐配置:Intel i7 Gen13或AMDRyzen9系;64位Windows10/11;内存≥32GB;显卡Nvidia 3060及以上,显存>8GB

> 最低配置：满足 Bambu Scan 的基本性能要求，可完成大多数常见物体的扫描、点云融合及网格封装任务。对于更大规模或更复杂的扫描任务，处理速度和性能表现可能受到一定限制。最低配置会随着软件优化以及测试结果的更新。
>
> 推荐配置：适合希望获得更流畅、高效扫描体验的用户。在此配置下，扫描预览、点云融合及网格封装等操作通常具有更好的性能表现，并为大规模点云处理和复杂扫描任务提供更充足的性能余量。

若您不熟悉自身电脑配置，可下载 Bambu Scan 后，运行软件自带的性能检测。

### 最低显卡驱动版本

NVIDIA 显卡驱动版本过旧，可能导致扫描无法正常启动、扫描仪屏幕预览异常等问题。请确保显卡驱动版本为 **572.16 或更高版本**。驱动下载入口见：

- 中国大陆：<https://www.nvidia.cn/drivers/>
- 海外：<https://www.nvidia.com/en-us/drivers/>

> 注意：更新驱动后，请重启PC后再重新尝试性能检测与扫描，确保驱动升级生效。

#### GPU加速选项

GPU 计算加速可提升点云融合等处理任务的速度，但也会占用更多显存。对于显存容量较低的设备（如 4GB 显存），可以关闭该选项，以降低扫描过程中的显存占用，从而支持更大规模的点云数据，但部分处理任务可能需要更长时间。

> 该选项默认为**自动**，软件会根据当前 GPU 配置选择合适的加速模式。当设备显存容量低于最低配置要求时，将自动关闭额外加速；满足要求时则开启。用户也可以根据实际需求手动调整。

### Wifi 支持

对于无线扫描，需要确保您的电脑使用Wi‑Fi 6或以上协议，保障扫描过程中高速的数据交换和扫描视频推流。

> **如何检查电脑是否支持 Wi-Fi 6？**
>
> 按下 `Win + R`，输入 `cmd` 并回车。在命令提示符中执行 `netsh wlan show drivers`，查看“支持的无线电类型”。如果包含 `802.11ax` 或 `802.11be`，说明无线网卡支持 Wi-Fi 6 或更高标准。
>
> 实际无线连接质量还受到路由器规格、信号强度和网络环境等因素影响。

### Type-c 接口支持

有线扫描需要使用支持USB 3.1或更高数据传输规格的USB Type-C 接口。

**注意：** 建议使用设备附带的原装线缆。第三方线缆的数据传输规格和质量可能存在差异，使用不符合要求的线缆可能导致扫描帧率下降或连接不稳定。

> **如何检查 USB 端口？**
>
> 按 **Win + R**，输入 **msinfo32**，回车打开 **系统信息**。
>
> 在左侧导航中选择 **组件 → USB**，检查端口是否为 USB 3.1（10 Gbps）或 USB 3.2（20 Gbps。

## 常见配置或性能问题

1. 非NVIDIA显卡是否支持？

目前，Bambu Scan Windows版本仅支持 NVIDIA 显卡。使用其他品牌的显卡可能导致无法正常开始扫描，或在模型处理过程中出现异常。

2. 为什么我扫描时的帧率无法达到产品宣称的标准？

通常有以下情况影响帧率，请根据实际情况进行检查：

- **电脑配置：** 检查 CPU、GPU、内存容量及显卡驱动是否满足要求。
- **无线连接：** 建议使用 Wi-Fi 6 或更高标准的无线网络，并检查无线信号强度及网络干扰情况。
- **有线连接：** 确认使用支持 USB 3.1 或更高数据传输规格的 USB Type-C 接口及线缆，避免使用可能影响传输速度的扩展坞或转接设备。
- **扫描预设**：请检查扫描预设中是否将帧率设置到目标值。
- **外接电源**： 使用笔记本电脑进行扫描时，建议连接电源适配器，并将 Windows 电源模式设置为“最佳性能”，以减少功耗限制对CPU和GPU性能的影响，获得更稳定的扫描帧率。
