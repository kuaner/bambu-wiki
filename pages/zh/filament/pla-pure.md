## 耗材介绍

纯净 PLA 采用纯净、简单的配方，**仅由五种原料构成**：

- 源于天然玉米及甘蔗的 **聚乳酸（PLA）**
- 常用于儿童玩具的 **丙烯酸酯共聚物**
- 常用于婴儿餐盘的 **着色颜料**
- 常用于食品保鲜膜的 **亚乙基双硬脂酰胺**
- 常用于环保可降解吸管的 **滑石粉（不含石棉）**

所有原料均来自全球领先的原料供应商，并符合欧盟食品接触塑料材料及制品的相关法规要求，来源清晰可追溯，从源头提升材料安全性与品质稳定性。

作为拓竹耗材的安全性标杆，纯净 PLA 已通过了三项国际级别的安全性标准：

- **国际 UL GREENGUARD 绿色卫士认证**
- **EU No.10/2011 法规标准**
- **欧盟玩具安全指令 2009/48/EC 中的 EN 71-3 技术检测标准**

这三项认证标准分别对应 3D 打印过程中的**室内空气质量、食品接触安全**、以及**儿童玩具接触安全**。

本章将分别为您详细解读这三项认证对于日常场景中的 3D 打印安全方面的价值与意义。

> **阅读须知：**
>
> 尽管本产品在原材料及打印件层面已通过相关合规性测试，但 3D 打印工艺本身属于多变量制造过程，成品质量及安全性仍可能受到设备条件、打印环境、操作方式及后处理工艺等因素影响。因此，建议根据实际使用场景确认打印成品的适用性。

### 1. 打印**排放安全认证（国际 UL GREENGUARD 绿色卫士认证）**

|  |  |
| --- | --- |
|  |  |

证书下载：[点击此处](https://wiki.bambulab.com/filament-acc/filament/pla-pure/ul_greenguard_cert_a1+pla_pure.pdf)

**UL 2904** 是针对 **FDM 3D 打印排放安全** 的测试标准，主要检测打印过程中产生的**挥发性有机物（VOC）** 和 **颗粒物（PM2.5 / UFP等）**，并将结果与行业认可的健康阈值进行比较。

通过**国际 UL GREENGUARD 绿色卫士**认证表示：在标准化测试条件下，耗材打印排放量在安全限度内。用户在普通居家或办公环境中保持基本通风，并按照默认参数打印时，挥发性有机物与颗粒物排放可保持在安全范围内。

> **安全提示**：打印全程建议保持通风良好的环境。由于个体对空气中排放物的敏感程度不同，若打印过程中出现明显不适，如持续咳嗽、眼部或皮肤刺激，请立即离开打印区域，并及时联系客服。若状况仍得不到缓解，请及时就医。

#### 1.1 适用标准说明

**UL 2904** 由全球权威安全科学机构 **UL Solutions** 制定，并于 2019 年发布为 **ANSI/CAN/UL 2904**，同步获得美国国家标准协会（ANSI）和加拿大相关标准体系认可。

该标准参考了 **ASHRAE 189.1**（美国高性能绿色建筑室内空气质量指南）、**CDPH Standard Method v1.2**（加州公共卫生部室内空气排放标准），和 **EPA** 的排放毒理学研究，这些体系已广泛应用于室内空气质量管理场景，如家具、装修材料、厨房环境和汽车内饰等。

#### 1.2 测试方法

测试在 **1 m³ 的专业封闭环境舱** 中进行。测试过程中，使用拓竹 **A1** 与 **P2S** 打印机连续打印 **4–5 小时**，连续打印超过 3 小时后，自动封闭式采集大量舱内空气样品，对 **挥发性有机物** 与 **颗粒物** 进行监测和分析。

#### 1.3 测试结果

**挥发性有机物** 与 **颗粒物** 的检测指标均 **显著低于 UL 2904 规定的标准限值**，说明纯净 PLA 在标准化测试条件下具备**低排放**表现，可为日常居家或办公环境中的打印使用提供更安心的空气质量保障。

#### **1.4 安全使用指南**

- **打印环境**  
  **在通风良好的房间内进行打印**（打开窗户、使用排风扇），可以稀释挥发性有机物与颗粒物，防止排放物在局部空间累积。**请避免长时间在打印机旁近距离停留，也不建议在完全密闭的空间内连续长时间打印。**
- **参数建议**  
  使用纯净 PLA 时建议遵循官方提供的 **默认打印参数**，这样即可得到良好打印质量。
- **轻微气味说明**  
  在推荐温度范围内纯净 PLA 基本无味。若在密闭环境或温度偏高时闻到轻微气味，通常是食品级增韧剂的微量挥发。根据现有毒理学数据，这类挥发物 **对人体的影响可忽略不计**，但仍建议保持基本通风，以防感官不适。
- **敏感人群使用建议**

  纯净 PLA 的打印过程默认关闭过滤系统，且排放量在安全限度内，开启过滤会影响打印质量。如果您对气味异常敏感，可在打印软件或机器控制面板中手动启用**过滤系统**，并配合加强通风（打开窗户、使用排风机）。这样既能进一步降低空气中的微量气味。

### 2. 欧盟食品接触安全检测**（EU No.10/2011 ）**

|  |  |
| --- | --- |
|  |  |

检测报告下载：[点击此处](https://wiki.bambulab.com/filament-acc/filament/pla-pure/bambu_pla_pure_eu_food_contact_zh.pdf)

**EU No.10/2011 是欧盟针对食品接触塑料制定的法规，主要用于评估塑料制品与食品接触时，化学物质是否会迁移到食物中。**按照 EU No.10/2011 对实际 **3D 打印成品**进行迁移测试，若测试结果低于法规限值，即表明该成品在相应测试条件和食品接触场景下符合欧盟食品接触安全要求。

> **安全提示**：请确保**打印环境、打印机及后处理流程**（例如成品打磨、涂层）保持清洁、卫生、无污染。建议使用**全新的非铜制喷嘴**，并在后续打印中专用于纯净 PLA，以避免其他耗材的残留或金属污染；同时请确保**打印板、打印腔体**等与打印件可能接触的部位整洁无残留。**打印件的形态、表面状态及实际使用方式**也可能影响食品接触安全，使用前请结合具体应用场景确认其适用性。如在使用过程中出现不适，请立即停止使用，并及时联系客服；若症状仍未缓解，请及时就医。

#### 2.1 适用标准说明

EU No.10/2011 由 **欧盟委员会** 制定，建立在欧盟食品接触材料总纲法规 **(EC) No 1935/2004** 之上，并采用严格的**正清单制度**。只有经过 **EFSA（欧洲食品安全局）** 毒理学评估并列入清单的物质，才允许用于食品接触塑料。

同时，EU No.10/2011 会通过后续修订持续更新物质清单、迁移限值和测试要求，以反映最新的科学评估结果。因此，它是目前国际上较为严格且广泛认可的食品接触塑料安全法规之一。

#### 2.2 测试方法

EU No.10/2011 会根据实际食品接触场景，选择对应的 **食品模拟物** 和 **时间 / 温度条件**。测试时，将 3D 打印样本置于模拟溶液中进行萃取，再通过色谱分析检测迁移物质及含量；测试条件为 **70°C × 2 小时** 。

#### 2.3 测试结果

检测结果显示，在对应实验环境与测试条件下，参与测试的纯净 PLA **成品打印件**在与水、油、酸等食品接触模拟场景中均通过测试，检出迁移量低于 **EU No.10/2011** 法规限值，符合相应测试条件下的欧盟食品接触安全要求。

同时，纯净 PLA 配方成分公开透明，相关原料均可在合规清单中查询，且每一种物料均持有全球主要地区的食品接触合规声明。

#### **2.4 安全使用指南**

- 不建议将纯净 PLA 打印成品用于以下食品接触环境：

  - 温度 **超过 60℃** 或 **低于 0℃** 的食品接触场景；
  - 酸碱性、有机溶剂类或腐蚀性液体；
  - 长时间浸泡于液体食品中，或长期处于高湿食品接触环境；
  - 长期接触液体、油脂含量较高或清洁难度较高的食品。
- **食品接触适用性**

通过测试的是在指定条件下制备的纯净 PLA 成品打印件。实际适用性仍需结合打印流程、成品形态、表面状态、清洁方式及使用场景判断；为提升安全性，建议参考下文“进阶安全打印指南”部分内容。

- **成品推荐使用时限**

在标准室内环境下（温度 **18–26℃**，相对湿度 **40–60%**），且避免阳光直射及持续外力负载的条件下，纯净 PLA 打印成品的预期使用寿命可超过 **1 年**，期间外观及物理性能通常保持相对稳定。实际耐用性会受到模型结构、使用频率和具体应用环境影响，上述时间仅为理想条件下的预估参考。

### 3. 欧盟玩具接触安全**（**EN71-3**）**

|  |  |
| --- | --- |
|  |  |

检测报告下载：[点击此处](https://wiki.bambulab.com/filament-acc/filament/pla-pure/bambu_pla_pure_eu_toy_safety_zh.pdf)

**EN 71-3** 是欧盟玩具安全标准 **EN 71** 系列中，针对玩具重金属元素迁移的化学安全测试标准。该检测基于国际标准，模拟塑料误吞后，在胃酸环境中是否有有害物质溶出，及其含量是否低于标准限值。纯净 PLA 耗材已通过 EN71-3 测试，表明纯净 PLA 成分层面的化学安全性有保障。无论是启蒙教具，还是萌宠专属的趣味模型，均可选用拓竹纯净 PLA 进行打印。

> **安全提示：**3D打印成品的形态、尺寸、结构强度、边缘锐利度、小部件脱落风险及后处理方式，均可能影响到儿童使用安全。作为玩具投入使用前，须结合实际模型结构与使用场景进行综合安全评估，谨防 3D 打印玩具模型在物理层面有可能造成的呛噎窒息、尖锐物刮伤等危险。  
> **纯净PLA打印件严禁作为婴幼儿啃咬玩具直接入口，以免引发吞咽及窒息风险。**

#### 3.1 适用标准说明

EN 71-3 属于欧盟玩具安全法规体系中的重要化学安全标准，其上位法规为 **欧盟玩具安全指令 2009/48/EC。EN 71-3** 是由 **CEN（欧洲标准化委员会）**制定，用于验证玩具产品是否符合**欧盟** 2009/48/EC 玩具安全指令中关于"**特定元素迁移**" 的权威技术检测方法。其**限值**基于**欧盟 SCHER** (健康与环境风险科学委员会)的毒理学评估意见而设定，以**婴幼儿童为标准**考虑，安全门槛在全球玩具化学安全标准中**较为严苛**。因此，该标准在儿童玩具化学安全领域具有较高认可度。

> EN 71-3 核心管控的 **19 种特定元素**包括：铝(AI)、锑(Sb)、砷(As)、钡(Ba)、硼(B)、镉(Cd)、铬III(CrIIII)、铬VI(CrVI)、钻(Co)、铜(Cu)、铅(Pb)、锰(Mn)、汞(Hg)、镍(Ni)、硒(Se)、锶(Sr)、锡(Sn)、有机锡、锌(Zn)

#### 3.2 测试方法

**测试样品：**将受测纯净 PLA 进行粉碎处理，使其符合标准要求的测试状态。

**模拟环境：将样品浸入的 0.07 mol/L 盐酸溶液中。该溶液的酸性条件接近人体胃液环境，pH 值通常约为 1.0–1.2。**

**测试过程：**样品在 **37℃** 恒温环境（人体体温）中持续震荡1小时（模拟胃部蠕动消化过程），最后对于萃取液进行定量分析检测。

#### 3.3 测试结果

结果显示，溶液中无典型有害元素溶出，19 种 EN 71-3 标准所监管的元素限值全部合格，证明了在该检测环境中，纯净 PLA 耗材配方在化学层面的玩具接触安全性。

## 进阶安全打印建议

纯净 PLA 专为 FDM 3D 打印排放安全和接触安全设计，**使用纯净 PLA 默认参数打印，即可获得优秀打印质量和接触安全特性**。若对成品打印件的接触安全等级要求更高，可根据模型实际情况进行以下调整：

### 1. 模型设计建议

- **内角导角设计：**模型内角（如内腔转角）尽可能设计为**圆角导角**，避免出现卫生死角，滋生杂质。如下图所示，更加推荐右侧模型、即转角平滑过渡。

![2.1_rounded_inner_corners_1.png](https://wiki.bambulab.com/filament-acc/filament/pla-pure/2.1_rounded_inner_corners_1.png)

- **避免无法清洁的盲孔/空腔：**规避无法通过毛刷、水流触及的内部盲孔或空腔。若必须设计内腔，需提前预留部分通孔，以便清洁。如下图所示右侧模型所示。食品接触面应减少盲孔，并预留通孔以减少细菌滋生的可能性。

![](https://wiki.bambulab.com/filament-acc/filament/pla-pure/2.1_rounded_inner_corners_2.png)

- **接触面打印朝向设计：**用于直接或间接食品接触的表面，推荐作为**侧面**或**顶面**打印，避免将其置于底面或支撑面打印。

  - 操作步骤：在 **Bambu studio** 的上方工具栏中，点击**①“选择底面”**图标-**②**在模型上**点击想要作为底面的一面**。

### 2. **切片参数设置**

- **最大体积速度：**适当降低最大体积速度可进一步优化复杂模型的**表面质量**，并**减少**走线之间可能存在的缝隙、孔洞。

  - 操作步骤：在 **Bambu studio** 左侧栏的“**项目耗材列表**”，点击耗材右侧的 ① **"···"** 标志 →\*\*“编辑”**→**②“耗材丝”**→**③“最大体积速度 ”\*\* 改为**“6mm³/s”**。

![2.2_max_volumetric_speed_zh.png](https://wiki.bambulab.com/filament-acc/filament/pla-pure/2.2_max_volumetric_speed_zh.png)

- **稀疏填充密度：**提升至 20-40%，可**降低**打印成品**孔隙数量**、避免污渍细菌滋生。

  - 操作步骤：在 **Bambu studio** 左侧的**“工艺”**栏中，点击**①“强度”→②“稀疏填充密度”** 提升至**20-40%**。

  - 操作步骤：在 **Bambu studio** 左侧的**“工艺”**栏中，点击**①“强度”→②“墙层数”** 提升至**3-4层**。

### 3. 硬件全链路管控

3D 打印成品能否严格满足食品接触、玩具接触等安全等级要求，一方面取决于耗材本身的成分；另一方面还取决于**打印机硬件的全链路管控，**例如**铁氟龙料管、喷嘴及打印板等**关键部件。

- 若打印成品明确需要接触食品，打印时**禁止**将高温耗材或加纤耗材（如 ABS、ASA、PC 及各类玻纤/碳纤增强耗材）和纯净 PLA 在同一打印链路中交叉使用。
- 若对打印成品安全等级要求较高，强烈推荐为纯净 PLA 配置**独立的打印链路**与**打印设备**，包括 **AMS、铁氟龙料管、喷嘴（建议使用全新的非铜制喷嘴，并在后续打印中专用于纯净 PLA，禁止使用铜制喷嘴）、打印板**等，避免与其他种类耗材交叉使用。

#### **3.1 不建议使用胶水**

如果对成品有严苛的使用要求，建议不要在打印板上涂胶水。同时，建议在每次打印完成后使用洗洁精清洁打印板。

![3.1_no_glue.png](https://wiki.bambulab.com/filament-acc/filament/pla-pure/3.1_no_glue.png)

### 5. 食品级密封涂层处理

即使耗材和打印流程均符合食品接触相关标准，由于 FDM 打印采用“逐层挤出、层层堆叠”的成型方式，打印件表面及层间仍可能存在肉眼难以察觉的细小孔隙。在长期使用，尤其是接触液体的场景下，这些孔隙可能残留污渍，并滋生微生物。

因此，如果您对食品接触安全有非常高的要求，建议在打印完成后，对打印件进行严格的 **食品接触级密封涂层处理**。

**涂层要求：**通过欧盟 EU No 10/2011 或 美国 FDA 21 CFR 食品接触认证的树脂材料，如食品接触级透明环氧树脂。

**操作步骤：**

1. 密封处理前，请参考“**成品处理与清洁**”步骤对成品打印件进行完全清理。
2. 确保操作平台与工具洁净无尘。
3. 严格按照“食品接触树脂说明书”进行涂层前驱体溶液制备：以双组份环氧树脂为例，在洁净容器中精确称量 A、B 两组分溶液（配比参考对应说明书），并提前混合均匀、确保无明显气泡，如下图所示。

![2.5.1_coating_precursor_solution.png](https://wiki.bambulab.com/filament-acc/filament/pla-pure/2.5.1_coating_precursor_solution.png)

4. 基于“十字干涂法”，利用工具（如洁净毛刷）、依次在横向和竖向方向上匀速缓慢地将树脂涂覆于打印件表面、尤其是食品接触面，至少涂覆两层、必要时可对关键区域进行多次薄涂，确保树脂均匀覆盖到所有层纹孔隙。注意分别对内表面和外表面进行涂覆-固化操作，避免树脂在固化时流挂、堆积、粘连。

|  |  |
| --- | --- |
|  |  |

5. 涂覆完成后，将打印件放置在低于 40°C 的洁净环境中自然固化 12-24 小时（根据树脂材质适当调整），固化完成后对打印件表面进行检查，确保涂层连续完整、无漏涂、无开裂、无明显发白、无异味，且清洗后依旧稳定。最后，可观察到打印件表面具有明显树脂光泽，即成功完成**食品接触级密封涂层处理**操作。

![2.5.4_cure.png](https://wiki.bambulab.com/filament-acc/filament/pla-pure/2.5.4_cure.png)

### 6. 耗材存储条件

耗材使用完成后，请妥善存放于 **湿度 ≤ 20% RH** 的洁净密封容器中，并使用干燥剂或真空袋防潮，同时确保存储环境避光、阴凉、无二次污染风险（如如灰尘、湿气、液体及化学污染等）。

## 常见打印问题与解决方案

### 1. 模型炒面

**问题表现：**在打印中可能会遇到由于内外墙冷却散热可能不足，导致边缘略微翘起，进而产生炒面、喷嘴剐蹭、支撑倒塌等情况。

![3.1surface_scarring.png](https://wiki.bambulab.com/filament-acc/filament/pla-pure/3.1surface_scarring.png)

**解决方案操作步骤：**

**步骤1. 修改“回抽时抬升 Z”参数。**

在 **Bambu Studio** 左侧栏的**“项目耗材列表”**，点击耗材右侧的 **① "···" 符号**，点击**②“编辑”→③“参数覆盖”→④“回抽时抬升 Z”** 参数改为**“1mm”**。

|  |  |
| --- | --- |
|  |  |

**步骤2. 悬垂降速。**

在 **Bambu Studio** 左侧栏的**“工艺”**栏中，点击**①“速度”→②**勾选**悬垂降速**，并参照**下图参数**修改“**悬垂速度**”。

![3.1_overhang_zh.png](https://wiki.bambulab.com/filament-acc/filament/pla-pure/3.1_overhang_zh.png)

**步骤3. 支撑降速。**

1. 在 **Bambu Studio** 左侧栏的“**工艺**”栏中，点击**①“速度”**→②参照**下图参数**修改**“支撑”**与**“支撑面”**速度。
2. 必要时可点击**①“支撑”→②“类型”**，改为**“普通支撑**”，以获得更佳的支撑面。

|  |  |
| --- | --- |
|  |  |

### 2. 模型翘曲

**问题表现：**在打印多色大平面模型时，可能因为层时间过长、冷却过多、层高过低等原因出现翘曲现象。

![3.2_model_warping.png](https://wiki.bambulab.com/filament-acc/filament/pla-pure/3.2_model_warping.png)

**解决方案操作步骤：**

**步骤1. 清洁打印板**

请参考[纹理 PEI 板清洁指南](../filament-acc/acc/pei-plate-clean-guide.md)清理打印板，确保打印板无污渍。

![3.2clean_the_build_plate.png](https://wiki.bambulab.com/filament-acc/filament/pla-pure/3.2clean_the_build_plate.png)

**步骤2. 降低热床温度**

在无额外因素影响热床粘接性（如环境温度过低等）情况下，降低热床温度至 **50℃**。

|  |  |
| --- | --- |
|  |  |

### 3. 模型拉丝

**问题表现：**打印件表面出现绒毛状细丝。如下图中左侧的打印件。这通常是由于耗材拆封后，长时间暴露空气中受潮而造成。

![3.3_model_stringing.png](https://wiki.bambulab.com/filament-acc/filament/pla-pure/3.3_model_stringing.png)

**解决方案操作步骤**：请在打印前对耗材进行烘干。具体的烘干要求如下：

| 烘干方式 | 烘干要求 |
| --- | --- |
| **鼓风型烤箱** | 55℃，8 小时 |
| **AMS 2 Pro / AMS HT** | 耗材插入状态： 45℃，12 小时 耗材非插入状态： 55℃，8 小时 |
| **X / P / H2 系列打印机热床** | 60℃-70℃，12 小时 |

![3.3dry_the_filament_zh.png](https://wiki.bambulab.com/filament-acc/filament/pla-pure/3.3dry_the_filament_zh.png)

> 具体的耗材烘干步骤请参考：[耗材烘干操作指南](../filament-acc/filament/dry-filament.md)
