## 装箱步骤

1. 首先将扫描仪、电源适配器、数据线、背带放回对应位置。

![001.png](https://public-cdn.bblmw.com/wiki/new/s1/manual/packing/zh/001.png)

2. 再将标定板装回配套的黑袋。

![002.png](https://public-cdn.bblmw.com/wiki/new/s1/manual/packing/zh/002.png)

3. 将标记点、标定板、纸质材料、挂绳放回夹层中。

> 纸质材料需要放在指定位置，否则可能导致标定板受压碎裂。

|  |  |
| --- | --- |
| 003.png | 004.png |

4. 将布包装回纸箱。

![005.png](https://public-cdn.bblmw.com/wiki/new/s1/manual/packing/zh/005.png)

5. 装好缓冲泡棉。

![006.png](https://public-cdn.bblmw.com/wiki/new/s1/manual/packing/zh/006.png)

6. 放入外纸箱。

![007.png](https://public-cdn.bblmw.com/wiki/new/s1/manual/packing/zh/007.png)

7. 最后放入纸质材料即可。  
   ![008.png](https://public-cdn.bblmw.com/wiki/new/s1/manual/packing/zh/008.png)
