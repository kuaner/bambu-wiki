## 状态概览（颜色 + 常亮/闪烁）

在 Bambu S1 扫描仪上，状态指示灯用不同的颜色与闪烁方式来实时反馈设备当前的工作状态。了解并正确辨识这些信号，可帮助您快速判断设备是否准备就绪、是否出现异常或正在进行升级/充电等操作。

![002.jpg](https://public-cdn.bblmw.com/wiki/new/s1/manual/led-status/zh/002.jpg)

| LED 颜色 | 亮灯方式 | 含义 |
| --- | --- | --- |
| **绿色** | 常亮 | 已成功连接 **Bambu Scan**，可以开始扫描。 |
|  | 闪烁 | 正在**启动扫描**或**扫描已结束**（扫描完成后仍保持短暂闪烁）。 |
| **蓝色** | 常亮 | 设备未连接 **Bambu Scan** |
|  | 闪烁 | 正在**连接/搜索无线网络**（Wi‑Fi 6），网络尚未就绪。 |
| **黄色** | 常亮 | **固件升级**进行中，请耐心等待升级完成后再使用。 |
|  | 闪烁 | 出现 **电量、内存或温度报警**，建议检查设备状态并采取相应措施。 |
| **红色** | 常亮 | **电量不足**（已开机但电池低）或 **充电中**（在关机状态下插入电源）。 |
|  | 闪烁 | **距离异常**（扫描对象太近或太远）或 **设备故障**（硬件或软件异常），需要进一步排查。 |
