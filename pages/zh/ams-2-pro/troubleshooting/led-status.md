## 指示灯

在日常使用 AMS 2 Pro 时，可以通过 LED 灯状态来判断 AMS 2 Pro 是否正常工作。

## 指示灯状态解析

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | LED 灯 | AMS 2 Pro 状态 | 备注 |
| **错误状态（红灯）** |  |  |  |
| 1 | 4 个槽同时红灯双闪 | 打印机无法检测到 AMS，通信异常 | 可参考 [打印机无法检测到 AMS 2 Pro](ams-2-pro-communication-anomalies.md) 进行处理 |
| 2 | 红灯呼吸 | 错误状态，打印开始后上下料组件没有检测到料，**插入料后即可恢复正常** |  |
| 3 | 红灯常亮 | 错误状态，上下料组件没检测到料但五通检测到料，可能是耗材断在五通内部 | 可参考 [AMS 2 Pro 断裂耗材移除与五通组件传感器检查](../remove-broken-stuck-material.md) 清理 |
| 4 | 红灯单闪 | 错误状态，上下料组件检测到有料，五通没检测到料，通常是进料失败，需要检查上下料组件是否工作正常,以及料管内部是否堵塞 | 可参考 [AMS 2 Pro 断裂耗材移除与五通组件传感器检查](../remove-broken-stuck-material.md) 清理 |
| 5 | 红灯双闪 | 错误状态，上下料组件和五通都检测到有料，通常是进料或者退料失败，需要结合进退料过程进一步分析 |  |
| 6 | 4 个槽红灯同时呼吸 | 1. 烘干时状态异常；  2. 空闲时烘干模块 NTC 掉线，或者检测到风道温度过高等异常，需要检测各部件是否插紧。 | 可参考[更换 AMS 2 pro 烘干组件](../maintenance/replace-heating-unit.md)重新安装插头 |
| **正常状态（白灯）** |  |  |  |
| 1 | 跑马灯 | AMS 上电初始化的时候会跑马灯，初始化结束后 4 个槽转常亮 |  |
| 2 | 4 个槽白灯常亮 | AMS 上电初始化结束后，或者唤醒屏幕时 4 个槽都有料（唤醒屏幕会点亮有插入耗材的槽位） |  |
| 3 | 白灯常亮 | 该槽位正在进行预上料、读取 RFID 或者正常打印过程中（包含进退料） |  |
| 4 | 白灯熄灭 | 1. 息屏后 15 分钟内该槽无预上料、读取 RFID 或打印（进退料）动作，白灯熄灭；  2. 在预上料或者读取 RFID 时白灯会再次点亮，动作结束 10 秒后白灯熄灭；  3. AMS 上电初始化结束后，20 分钟内无预上料、读取 RFID 或打印（进退料）动作，白灯熄灭。 |  |
| 5 | 4 个槽白灯同时呼吸 | 正常烘干状态 |  |
