## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

**建议您使用原包装进行打包以确保运输安全。若您因退货需求需重新打包但原包装已丢失，请联系我们的售后团队为您补发专用的纸箱及缓冲泡沫等防护材料。**

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### 步骤一：断开铁氟龙料管、6-pin 连接线

1. 按住铁氟龙料管释放按钮，断开铁氟龙料管；
2. 按紧线缆接口底端，断开 6-pin 连接线；

|  |  |
| --- | --- |
|  |  |

3. 将 **6-pin 连接线、铁氟龙料管（185mm\*2+225mm\*2+900mm\*1）、备用干燥剂、说明书（如有）** 装入包装袋内；
4. 用胶带将包装袋固定在 AMS 2 Pro 腔内。

|  |  |
| --- | --- |
|  |  |

### 步骤二：安装上下料器保护泡沫

安装上下料器保护泡沫，并向下按压紧实。

|  |  |
| --- | --- |
|  |  |

### 步骤三：安装保护泡沫

将 AMS 2 Pro 放入保护袋内。然后，安装 AMS 2 Pro 两侧的主体保护泡沫。

|  |  |
| --- | --- |
|  |  |

### 步骤四：装箱操作

将包装好的 AMS 2 Pro 放入纸箱，然后用胶带将纸箱粘牢。

|  |  |
| --- | --- |
|  |  |
