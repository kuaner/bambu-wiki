## 视频指南

## 操作步骤

### 取出 AMS 2 Pro

1. 打开纸箱，取出 AMS 2 Pro。

|  |  |
| --- | --- |
|  |  |
|  |  |

2. 拆除左右两块黑色泡棉。

|  |  |
| --- | --- |
|  |  |

3. 撕下胶带，取出 AMS 2 Pro。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 取出配件

1. 取下说明书。

|  |  |
| --- | --- |
|  |  |

2. 撕下保护膜。

|  |  |
| --- | --- |
|  |  |
|  |  |

3. 打开上盖，取出黑色泡棉和线缆袋。

|  |  |  |
| --- | --- | --- |
|  |  |  |

4. 撕下贴纸，取出干燥剂。

|  |  |
| --- | --- |
|  |  |

### 放置干燥剂

**移除外包装后**，将干燥剂放入 AMS 2 Pro 的左右两个空槽中。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 检查主动支撑轴

运输过程的颠簸可能会导致槽位上的主动支撑轴脱出，请检查并确保每个轴都装配到位，以避免退料时料盘无法转动而引起料线散开。

![支撑轴.jpg](https://wiki.bambulab.com/ams-2-pro/manual/unboxing-and-setup/%E6%94%AF%E6%92%91%E8%BD%B4.jpg)

### 连接料管

撕开料管胶带，取下料管。

|  |  |
| --- | --- |
|  |  |

## 连接打印机和 AMS 2 Pro

- 连接AMS 2 Pro至H2系列打印机
- 连接 AMS 2 Pro 至 X2D 打印机
- 连接 AMS 2 Pro 至 X1 和 P1 系列打印机
- 连接 AMS 2 Pro 至 P2S 打印机
- 连接 AMS 2 Pro 至 A 系列打印机
