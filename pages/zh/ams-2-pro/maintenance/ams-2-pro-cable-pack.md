## AMS 2 Pro 线材包

我们提供的 AMS 2 Pro 线材包，里面包含 6 根连接线，分别是：

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/1._ams_2_pro线材包.jpg)

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/2.jpg)

1 - 上下料电机连接线\*1

2 - 电源板供电线\*1

3 - 电源板通讯线\*1

4 - 里程轮连接线\*1

5 - 五通电机连接线\*1

6 - 五通霍尔板连接线\*1

### 何时更换

线材在维修过程中损坏或使用过程中烧坏时，需要进行线材的更换。

### 所需工具和材料

- AMS 2 Pro 线材包
- H2.0 内六角扳手
- H1.5 内六角扳手

### 螺丝清单

|  | 型号 | 位置 |
| --- | --- | --- |
| 螺丝 A | BT3-8 | AMS 2 Pro 主框架 |
| 螺丝 B | BT2-5 | AMS 2 Pro 主板 |

## 安全提示

> ***❗❗ 重要提醒***   
> *在对 AMS 2 Pro 及其电子设备进行任何维护工作之前，请断开 AMS 2 Pro 与打印机的连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。*  
> *如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。*

## 拆卸 AMS 2 Pro 主框架组件

### 步骤 1 - 拆除料管

按压 AMS 2 Pro 背后的铁氟龙料管释放按钮，释放 PTFE 管并将其拉出。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/3.2.png)

### 步骤 2 - 抽出铁氟龙料管释放按钮

从下盖内部捏住卡扣自动弹开铁氟龙料管释放按钮后，从 AMS 2 Pro 的背面抽出铁氟龙料管释放按钮。

> 注意：捏卡扣时，另一只手需要用从 AMS 2 Pro 的背面扶住铁氟龙料管释放按钮，以避免弹簧被弹出丢失。

|  |  |
| --- | --- |
|  |  |

### 步骤 3 - 取出 AMS 2 Pro 主框架组件

1. 拆下中间 2 个料槽的从动支撑套筒组件以露出 2 个螺丝孔，取出轴承套时，小心两端的轴承，避免丢失。

|  |  |
| --- | --- |
|  |  |

2. 移除固定 AMS 2 Pro 主框架的 2 颗螺丝 A (BT3-8)。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/6.png)

3. 将主框架后部完全提起来， 竖立放置在 AMS 2 Pro 下盖上。抬起时，建议先抬主框架前部分，再往前推一推，为框架后部分腾出空间。

|  |  |
| --- | --- |
|  |  |

竖放 AMS 2 Pro 主框架时需避开风门的电子部件，以防压坏。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/8.png)

4. 解锁插头的卡扣，拔出 AMS 2 Pro 电源板上的电源板供电线和电源板通信线，移除 AMS 2 Pro 主框架组件。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/9.png)

## 更换电源板供电线和电源板通信线

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/10.jpg)

### 步骤 1 - 断开连接

在主板上找到电源板供电线和电源板通信线的接口（红框区域），依次断开连接。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/11.供电线+通信线（主板图）.jpg)

您需要按压蓝框区域，施加一点巧劲，才能更顺利地拔出接口，按压位置如下图所示：

|  |  |
| --- | --- |
|  |  |

### 步骤 2 - 连接电缆

将新的电源板供电线和电源板通信线依次连接到 AMS 2 Pro 主板对应接口上。

## 更换五通电机连接线

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/13.jpg)

### 步骤 1 - 断开连接

在主板和五通组件上找到五通电机连接线的两个接口（红框区域），依次断开连接。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/14.五通电机连接线.jpg)

### 步骤 2 - 连接电缆

将新的五通电机连接线连接到 AMS 2 Pro 主板和五通组件的对应接口上。

## 更换五通霍尔板连接线

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/15.jpg)

### 步骤 1 - 断开连接

先断开五通霍尔板连接线在主板上的接口，再从理线槽中抽出五通霍尔板连接线，最后断开五通霍尔板上的接口。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/16._五通霍尔板连接线.jpg)

### 步骤 2 - 连接电缆

将新的五通霍尔板连接线依次连接到 AMS 2 Pro 主板和五通霍尔板的对应接口上，整理五通霍尔板连接线在理线槽中的位置。

## 更换里程轮连接线

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/17.jpg)

### 步骤 1 - 断开连接

找到里程轮连接线的两个接口（红框区域），依次断开连接，并从理线槽中抽出线缆。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/18._里程轮连接线.jpg)

### 步骤 2 - 连接电缆

将新的里程轮连接线依次连接到对应接口上，整理里程轮连接线在理线槽中的位置。

## 更换上下料电机连接线

AMS 2 Pro 上有 4 根上下料电机连接线，您可以根据实际需要更换。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/19.png)

### 步骤 1 - 拆除主板

1. 断开 AMS 2 Pro 主板上 18 根电缆。断开前，您可以拍照记录下电缆的连接情况，以便稍后重新连接。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/20.png)

2. AMS 2 Pro 主板是被 2 颗螺丝 B (BT2-5)，加 5 个卡扣固定的。用 H1.5 内六角扳手移除 2 颗螺丝。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/21.png)

3. 移除 2 颗螺丝后，往外轻微拉住最左侧的卡扣，从下方抬起 AMS 2 Pro 主板，再将其取下。

|  |  |
| --- | --- |
|  |  |

### 步骤 2 - 断开连接

取下主板后，您就能看到 4 根上下料电机连接线的另一个接口。

拔下您需要更换的上下料电机连接线的接口。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/23.png)

### 步骤 3 - 连接电缆

插入新的上下料电机连接线的其中 1 个接口。

### 步骤 4 - 安装主板

1. 将主板安装到 AMS 2 Pro 中框上，先将主板从下至上嵌入上边沿的 3 个卡扣后，轻微下压，嵌入左右 2 个卡扣中。

|  |  |
| --- | --- |
|  |  |

> **注意：**安装 AMS 2 Pro 主板时，注意检查插头，不要将插头压在主板背面。

2. 连接 AMS 2 Pro 主板上 18 根电缆。

根据断开前的标记或照片，连接好 18 根电缆。在确认主板安装在被 5 个卡扣压住后，锁入 2 颗螺丝 B(BT2-5)。

|  |  |
| --- | --- |
|  |  |

## 安装 AMS 2 Pro 主框架组件

### 步骤 1 - 检查电缆连接

请检查并确认线材包中的线缆均已正确连接且牢固。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/26.jpg)

### 步骤 2 - 装入主框架组件

1. 将主框架组件装入 AMS 2 Pro 下盖。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/27.png)

2. 将电源板供电线和电源板通信线连接到 AMS 2 Pro 电源板。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/28.png)

3. AMS 2 Pro 主框架安装到位后，用 H2.0 内六角扳手锁入 2 颗螺丝 A 固定。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/29.png)

### 步骤 3 - 安装 2 个从动支撑套筒组件

安装中间 2 个从动支撑套筒组件，确保所有从动轴两端的轴承被按压到位。

|  |  |
| --- | --- |
|  |  |

### 步骤 4 - 安装铁氟龙料管释放按钮

按照如下方向，将铁氟龙料管释放按钮压回外壳中，将卡扣顺利卡入对应卡槽，并保持黑色硅胶外壳平整嵌入。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 5 - 连接铁氟龙管

检查确认铁氟龙管管硅胶支架与五通组件的料孔对齐，并从 AMS 2 Pro 后部推入铁氟龙管。装完后，拉动铁氟龙管，确认铁氟龙管已固定。

|  |  |
| --- | --- |
|  |  |

## 验证功能

1. 将 AMS 2 Pro 与打印机连接，启动打印机，给 AMS 2 Pro 供电，AMS 2 Pro 上下料处的指示灯亮起，说明供电正常。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/验证.png)

2. 装载带有拓竹 RFID 芯片的耗材，确认 AMS 2 Pro 能正常识别耗材，点击进料，加载耗材，确认 AMS 2 Pro 能正常将耗材送进到挤出机。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-cable-pack/34.png)

如果确认结果有异常，请返回检查步骤和连接后重试。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
