## AMS 2 Pro 上下料组件

上下料组件安装在 AMS 单元上，为 AMS 2 Pro 提供第一阶驱动力的供料装置。每台 AMS 2 Pro 配有 4 个上下料组件。在某些情况下，耗材可能会在上下料组件内部堆积或卡住，需要进行清理以恢复正常供料。本指南将演示如何拆卸与清洁上下料组件，使其恢复顺畅工作。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/feed-unit.jpg)

## 适用情形

- AMS 2 Pro 上下料组件内部出现耗材碎屑堆积或卡料

## 所需工具与材料

- H1.5 六角扳手
- H2.0 六角扳手
- 一根细长铁丝或一小段耗材
- 刷子
- 镊子

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 拆卸 AMS 2 Pro 上下料组件并进行清洁

### 步骤 1. 从 AMS 2 Pro 上取下上下料组件

请参考 [更换 AMS 2 Pro 上下料组件](replace-feeder-unit.md) 中 “拆除上下料组件” 章节的步骤 1～7，将需要清理的上下料组件从 AMS 2 Pro 中取出。

### 步骤 2. 初步清理内部碎屑

从上下料组件的漏斗状进料口处，缓慢插入细铁丝或一段耗材，按照下方动图所示的方式前后移动，利用工具将组件内部残留的耗材碎屑松动并带出，完成初步清理。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/removing_the_debris_inside_the_feeder.gif)

> 若插入过程中遇到明显阻力，说明内部可能有大量碎屑堆积，此时请继续进行下一步拆解操作。

### 步骤 3. 拆解组件外壳与底座

使用 H1.5 六角扳手，先移除组件底座与外壳连接的 4 颗固定螺丝，位置如下：

![feed-unit-screw1.png](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/feed-unit-screw1.png)  
![screw2.png](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/screw2.png)  
一手握住底座尾部，另一手握住上盖尾部，轻轻向两侧分离。**由于两部分内部有连接线束，分离时动作要轻，避免拉扯损坏线缆。**

![](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/detaching_feeder_unit.gif)

> **警告：** 分离后，弹簧和两个压料帽会从原位脱落。请务必注意不要丢失这些部件。
>
> ![](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/sprint_and_black_components.png)

### 步骤 4. 断开内部连接线

取下下图所示的黑色连接线。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/removing_the_black_wire.png)

### 步骤 5. 检查并清洁 AMS 上下料组件

先检查进料漏斗处的可见碎屑，再从组件底部插入细铁丝或小段耗材，缓慢推挤将内部卡滞的碎屑导出。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/removing_filament_debris.gif)

使用刷子清洁齿轮区域，确保将附着的碎屑彻底刷掉。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/using_brush_to_clean_gears.jpeg)

用手轻轻转动齿轮，确认其转动顺畅、无卡顿或异响，若存在阻力需再次检查是否有残留碎屑。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/moving_gears_and_ensuring_they_move_freely.gif)

检查上下料组件内部结构是否仍有碎屑残留，如有可使用镊子取出。

![](https://wiki.bambulab.com/ams-2-pro/manual/part-intro-and-connection-guide/internal_components_of_the_ams_feeder_unit.jpeg)

完成清理并确认所有耗材碎屑已清除后，即可进行下一步：重新组装 AMS 上下料组件。

## 组装 AMS 上下料组件

### 步骤 1. 将脱落的两个压料帽重新放回原位

先将其中一个压料帽放回一侧，然后旋转送料器顶盖，将另一个压料帽安装到另一侧。

|  |  |
| --- | --- |
|  |  |

### 步骤 2. 将弹簧安装到送料漏斗组件上

将弹簧安装到 AMS 入料口组件上，确保弹簧正确卡入到位。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/attaching-spring.png)

### 步骤 3. 组装上盖与底座

调整齿轮组的位置，然后安装上盖与底座。安装过程中，可使用镊子或手指辅助调整弹簧的位置，使其正确对准。

![](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/assembling_the_upper_and_bottom_base.png)

最后，将线缆重新连接回去。

### 步骤 4. 检查齿轮组位置

安装到位后，再次确认齿轮组的位置（应如下图所示）。如果位置不正确，请调整后重新安装上盖。

|  |  |
| --- | --- |
|  |  |

### 步骤 5. 固定螺丝

拧紧下图所示的四颗螺丝。

![feed-unit-screw1.png](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/feed-unit-screw1.png)  
![screw2.png](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/screw2.png)

### 步骤 6: 将送料器安装回 AMS 2 Pro

参照 [更换 AMS 2 Pro 上下料组件](replace-feeder-unit.md) 中安装上下料组件的步骤 1～7，连接 PTFE 管并将上下料组件安装到对应卡槽，然后组装回 AMS 2 Pro。

## 功能验证

将 AMS 2 Pro 与打印机连接并上电。将刚清洁过的 AMS 送料器插槽中插入耗材，然后在屏幕上点击“**进料**”开始进料。

![load.png](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/load.png)

随后点击“**退料**”开始退料。

![unload.png](https://wiki.bambulab.com/ams-2-pro/maintenance/clean-the-ams-2-pro-feeder-unit/unload.png)

将进料/退料操作重复进行三次。若每次均正常，则说明操作已成功完成。若仍有异常，请检查线缆和 PTFE 管连接是否正确；如确认连接无误但问题依旧，请联系我们技术支持寻求进一步协助。
