## 桌面

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/tabletop-overview.png)

## 何时更换

桌面变形。

## 所需工具和材料

- H3.0 内六角扳手

## 安全提示

> 在开始更换前，请务必提前清空所有抽屉并将上方的打印机等重物安全搬离，防止重心前移导致倾倒损坏；由于该柜体为全金属材质，拆装时 **请务必全程佩戴防护手套**，谨防钣金剪裁边缘、冲压折角及螺丝孔位可能残留的锋利毛刺割伤皮肤；拆卸抽屉滑轨时请参照教程准确寻找释放卡扣，切勿暴力硬拉，推拉抽屉及分离轨道时请时刻留意手指位置，以免夹伤；同时请规范使用工具，妥善收纳拆下的各类五金件，确保整个操作过程安全高效。

## 移除桌面

### 步骤1.移除工作站侧板、背板（可选）

> 如您选配了封箱套件，需要先拆除左右侧板及背板，未安装则跳过此步骤。

使用 H3.0 内六角扳手移除四颗侧板螺丝，移除工作站侧板。同样操作移除另一侧侧板。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/side-panel-screws.png)

使用 H3.0 内六角扳手移除图示四颗螺丝，取下背板。

|  |  |
| --- | --- |
|  |  |

取下背板。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/remove-back-panel.png)

### 步骤2.移除抽屉

> 抽屉滑轨为三段式滑轨，分为外轨、中轨、内轨，内轨直接固定在抽屉两侧，解锁限位后内轨将可以从滑轨中滑出。左侧滑轨限位为向上拨动解锁，右侧滑轨限位为向下拨动解锁，上下层抽屉滑轨解锁方法一致。  
> ![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/drawer-slide-stop-direction.png)

拉出上层抽屉到最外侧，此时可以观察到右侧内轨中央有一个塑料拨片，将拨片向下压，同时将外侧滑轨向后推动，解锁右侧滑轨限位。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/unlock-right-slide-stop.webp)

同样方法，将左侧内轨中的拨片向上抬，同时将外侧滑轨向后推动，解锁左侧滑轨限位。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/unlock-left-slide-stop.webp)

重复上述操作，拆除下层抽屉。

### 步骤3.移除抽屉滑轨

用手握住右侧滑轨前端，先往内侧（逆时针）微微旋转，接着向上抬起滑轨前端来解开前侧卡扣；随后将滑轨向前抽以解锁后侧卡扣，依次取下右侧两条滑轨。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/release-slide-front-tab.png)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/remove-right-drawer-slides.webp)

按照同样的方法取下左侧两条滑轨。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/remove-left-drawer-slides.webp)

### 步骤4.移除可调万向轮

将工作站倒置或侧置在平整且稳固平台上，漏出底板可调万向轮。

> 倒置前建议在工作站与放置平台之间铺设一层缓冲，避免操作过程中划伤工作站桌面。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/invert-station-on-platform.png)

使用 H3.0 内六角扳手移除图示四颗螺丝，取下可调万向轮。重复此步骤移除全部的可调万向轮。

|  |  |
| --- | --- |
|  |  |

### 步骤6.移除底座

使用 H3.0 内六角扳手从每个立柱的图示位置拆卸两颗螺丝，共计 8 颗。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/upright-base-two-screws.png)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/base-eight-screws-overview.png)

轮流敲击底座与立柱连接位置，直到底座完全松动，将底座取下。

> 注意：每次敲出的距离不宜过长，单个立柱位置一次敲出过长可能导致剩余立柱位置拆卸变得更加困难。建议每次敲出2cm左右，循环多次，直到底座完全松出。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/tap-off-base.webp)

### 步骤7.移除桌面

使用 H3.0 内六角扳手移除图示8颗螺丝。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/tabletop-eight-screws.png)

依次取下四根立柱。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/remove-uprights-1.webp)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/remove-uprights-2.webp)

## 安装桌面

### 步骤1.安装桌面

取出新的桌面，对照桌面和立柱上的数字标识，依次装回四根立柱。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/align-tabletop-upright-numbers.png)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/reattach-four-uprights.png)

使用 H3.0 内六角扳手锁入图示8颗螺丝，固定立柱。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/tabletop-eight-screws.png)

### 步骤2.安装底座

对准底座四角塑胶件与立柱插槽。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/align-base-corner-inserts.png)

轮流下压底座四角，将塑胶件竖直下压至半插入（勿完全压入），保持立柱垂直。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/half-insert-base-corners.webp)

对齐立柱定位楔与底座定位槽。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/align-upright-positioning-wedges.png)

继续轮流下压四角，直至定位楔完全卡入槽内。

> 注意：安装时请保持立柱垂直。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/press-base-fully-into-place.webp)

使用 H3.0 内六角扳手装回图示 8 颗螺丝

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/base-eight-screws-overview.png)

### 步骤3.安装可调万向轮

装回四个可调万向轮，使用 H3.0 内六角扳手为每个万向轮各锁入四颗螺丝固定。

|  |  |
| --- | --- |
|  |  |

### 步骤4.安装抽屉滑轨

将设备转正放置。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/stand-frame-upright.png)

取出有 R（右）标记的右侧滑轨安装到柜体右侧，先向后插入外轨后侧卡扣，然后从上向下插入前侧卡扣，从卡扣开孔观察，确保卡扣已插入到底。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/install-right-drawer-slides.webp)

取出有 L（左）标记的左侧滑轨安装到柜体左侧。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/install-left-drawer-slide-1.webp)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/install-left-drawer-slide-2.webp)

安装完成后，检查两侧滑轨前侧的卡扣是否卡入安装到位。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/check-slide-front-tab.png)

### 步骤5.安装抽屉

将下层抽屉两侧滑轨对准柜体轨道上的缺口平稳推入到底，此时限位会自动复位。然后将抽屉拉出至极限位置，检查限位装置是否正常生效。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/align-drawer-with-cabinet-rails.png)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/install-lower-drawer.webp)

同样方法装回上层抽屉。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/install-upper-drawer.webp)

### 步骤6.安装工作站侧板、背板（可选）

> 如果在前序步骤中未拆除工作站侧板、背板，则跳过此步骤。

装回工作站两侧侧板，使用 H3.0 内六角扳手每侧各锁入四颗螺丝固定。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/side-panel-screws.png)

装回工作站背板，对齐螺丝孔。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-tabletop/align-back-panel.png)

使用 H3.0 内六角扳手锁入图示四颗螺丝，完成安装。
