## 抽屉滑轨

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/drawer-slides-overview.png)

工作站不同层抽屉使用的滑轨一致，需要注意同一层抽屉的左右滑轨不同，请根据图示或滑轨上的 L（左）、R（右）标记区分。

## 何时更换

1. 滑轨卡涩。
2. 滑轨限位失效。

## 所需工具和材料

- H3.0 内六角扳手（可选）

## 安全提示

> 在开始更换前，请务必提前清空所有抽屉并将上方的打印机等重物安全搬离，防止重心前移导致倾倒损坏；由于该柜体为全金属材质，拆装时 **请务必全程佩戴防护手套**，谨防钣金剪裁边缘、冲压折角及螺丝孔位可能残留的锋利毛刺割伤皮肤；拆卸抽屉滑轨时请参照教程准确寻找释放卡扣，切勿暴力硬拉，推拉抽屉及分离轨道时请时刻留意手指位置，以免夹伤；同时请规范使用工具，妥善收纳拆下的各类五金件，确保整个操作过程安全高效。

## 移除抽屉滑轨

> **说明**：移除抽屉滑轨的步骤完全一致，本文将以中层抽屉演示拆装过程。

### 步骤1.移除工作站侧板、背板（可选）

> 如您选配了封箱套件，需要先拆除左右侧板及背板，未安装则跳过此步骤。

使用 H3.0 内六角扳手移除四颗侧板螺丝，移除工作站侧板。同样操作移除另一侧侧板。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/side-panel-screws-a.png)

使用 H3.0 内六角扳手移除图示四颗螺丝，取下背板。

|  |  |
| --- | --- |
|  |  |

取下背板。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/remove-back-panel.png)

### 步骤2.解锁抽屉滑轨限位

抽屉滑轨为三段式滑轨，分为外轨、中轨、内轨，内轨直接固定在抽屉两侧，解锁限位后内轨将可以从滑轨中滑出。左侧滑轨限位为向上拨动解锁，右侧滑轨限位为向下拨动解锁，上下层抽屉滑轨解锁方法一致。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/drawer-slide-stop-direction.png)

拉出抽屉到最外侧，此时可以观察到右侧内轨中央有一个塑料拨片，将拨片向下压，同时将外侧滑轨向后推动，解锁右侧滑轨限位。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/unlock-right-slide-stop-a.webp)

同样方法，将左侧内轨中的拨片向上抬，同时将外侧滑轨向后推动，解锁左侧滑轨限位。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/unlock-left-slide-stop-a.webp)

### 步骤3.移除抽屉

两侧抽屉滑轨都解除限位后，向外继续拉动抽屉，将抽屉从滑轨上滑出。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/slide-out-drawer-a.webp)

> 抽屉左右侧内轨拆卸方法相互通用，以下将以两侧内轨分别展示两种拆卸方法，可根据需要选择。

**方法一（使用内六角扳手拆卸）**：

使用螺丝刀等工具从抽屉内侧按下左侧内轨的卡扣，同时将内轨向下移动解锁卡扣。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/press-left-inner-rail-tab.png)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/unlock-left-inner-rail-tab-a.webp)

向抽屉前方拉出滑轨后方卡扣，移除抽屉左侧内轨。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/remove-left-inner-rail.webp)

**方法二（使用撬棒拆卸）**：

使用撬棒类工具从内轨与抽屉的缝隙处插入，撬动卡扣位置解锁卡扣，同时向下解锁右侧内轨。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/pry-right-inner-rail-tab.png)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/unlock-right-inner-rail-tab-a.webp)

向抽屉前方拉出滑轨后方卡扣，移除抽屉右侧内轨。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/remove-right-inner-rail.webp)

### 步骤4.移除抽屉滑轨

用手握住滑轨前端，先往内侧（逆时针）微微旋转，接着向上抬起前端来解开前侧卡扣；随后将滑轨向前抽拉以解锁后侧卡扣。另一侧滑轨按照相同的方法即可取下。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/release-slide-front-tab.png)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/remove-drawer-slide.webp)

## 安装抽屉滑轨

### 步骤1.安装内轨

取出新的抽屉滑轨，按下内轨解锁卡扣，将左右滑轨的内轨抽出。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/separate-inner-rails.webp)

> 抽屉滑轨和内轨上均有 L （左）、R（右）标记，表示其安装在抽屉的左侧或右侧，不可混用。  
> ![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/left-right-rail-markings.jpg)

安装抽屉左侧内轨，将抽屉正面面向自己左侧向上，取出左侧内轨，先从前向后插入后方卡扣，然后从下向上卡入前侧卡扣，安装到位后会有一声脆响。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/install-left-inner-rail.webp)

安装抽屉左侧内轨，同样将抽屉正面面向自己右侧向上，取出右侧内轨，先从前向后插入后方卡扣，然后从下向上卡入前侧卡扣，安装到位后会有一声脆响。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/install-right-inner-rail.webp)

安装完成后检查抽屉两侧锁止卡扣是否锁止到位。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/check-inner-rail-tabs.png)

### 步骤2.安装抽屉滑轨

先向后插入外轨后侧卡扣，然后从上向下插入前侧卡扣，从卡扣开孔观察，确保卡扣已插入到底。同样方法装入另一侧外轨。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/install-drawer-slide.webp)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/check-slide-front-tab.png)

### 步骤3.安装抽屉

将抽屉两侧滑轨对准柜体轨道上的缺口平稳推入到底，此时限位会自动复位。然后将抽屉拉出至极限位置，验证限位装置是否正常生效。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/push-in-drawer.webp)

### 步骤4.安装工作站侧板（可选）

> 如果在前序步骤中未拆除工作站侧板、背板，则跳过此步骤。

装回工作站两侧侧板，使用 H3.0 内六角扳手每侧各锁入四颗螺丝固定。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/side-panel-screws-a.png)

装回工作站背板，对齐螺丝孔。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-drawer-slides/align-back-panel.png)

使用 H3.0 内六角扳手锁入图示四颗螺丝，完成安装。

## 功能验证

拉出抽屉到前后极限位置，检查抽屉是否可以正常关闭和打开，滑轨限位正常则安装正确。
