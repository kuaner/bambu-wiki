## 可调万向轮

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-caster-wheel/caster-wheel-overview.png)

可调万向轮带有一个可调脚撑，通过调整脚撑可调整工作站水平以及锁定工作站位置。

## 何时更换

1. 可调万向轮转动卡顿、异响。
2. 万向轮主体结构破损。
3. 万向轮垫脚无法调节。

## 所需工具和材料

- H3.0 内六角扳手

## 安全提示

> 在开始更换前，请务必提前清空所有抽屉并将上方的打印机等重物安全搬离，防止重心前移导致倾倒损坏；由于该柜体为全金属材质，拆装时 **请务必全程佩戴防护手套**，谨防钣金剪裁边缘、冲压折角及螺丝孔位可能残留的锋利毛刺割伤皮肤；拆卸抽屉滑轨时请参照教程准确寻找释放卡扣，切勿暴力硬拉，推拉抽屉及分离轨道时请时刻留意手指位置，以免夹伤；同时请规范使用工具，妥善收纳拆下的各类五金件，确保整个操作过程安全高效。

## 移除可调万向轮

> 四个可调万向轮的拆卸方法一致，请根据需要选择更换。

### 步骤1.移除可调万向轮

清空抽屉内物品，将工作站倒置或侧置在平整且稳固平台上，漏出底板可调万向轮。

> 倒置前建议在工作站与平台之间铺设一层缓冲，避免操作过程中划伤工作站桌面。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-caster-wheel/flip-station-upside-down-a.jpg)

找到需要更换的可调万向轮，使用 H3.0 内六角扳手移除图示四颗螺丝，移除可调万向轮。

## 安装万向轮

### 步骤1.安装万向轮

装回可调万向轮，使用 H3.0 内六角扳手锁入四颗螺丝固定。

|  |  |
| --- | --- |
|  |  |

将设备重新转正，完成安装。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-caster-wheel/place-station-upright.png)

## 功能验证

请推动工作站确认万向轮转动是否顺畅、四个万向轮是否均正常接触地面、万向轮垫脚是否可以正常升降。
