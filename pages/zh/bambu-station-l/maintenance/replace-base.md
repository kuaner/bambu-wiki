## 底座

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/base-overview.png)

## 何时更换

1. 底座变形。
2. 底座螺柱断裂。
3. 底座螺丝孔滑牙。

## 所需工具和材料

H3.0 内六角扳手

## 安全提示

> 在开始更换前，请务必提前清空所有抽屉并将上方的打印机等重物安全搬离，防止重心前移导致倾倒损坏；由于该柜体为全金属材质，拆装时 **请务必全程佩戴防护手套**，谨防钣金剪裁边缘、冲压折角及螺丝孔位可能残留的锋利毛刺割伤皮肤；拆卸抽屉滑轨时请参照教程准确寻找释放卡扣，切勿暴力硬拉，推拉抽屉及分离轨道时请时刻留意手指位置，以免夹伤；同时请规范使用工具，妥善收纳拆下的各类五金件，确保整个操作过程安全高效。

## 移除底座

### 步骤1.移除工作站侧板（可选）

> 如您选配了封箱套件，需要先拆除左右侧板，未安装侧板则跳过此步骤。

使用 H3.0 内六角扳手移除四颗侧板螺丝，移除工作站侧板。同样操作移除另一侧侧板。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/side-panel-screws.png)

### 步骤2.移除抽屉

> 抽屉滑轨为三段式导轨，分为外轨、中轨、内轨，内轨直接固定在抽屉两侧，解锁限位后内轨将可以从导轨中滑出。

拉出抽屉到最外侧，此时可以观察到右侧内轨中央有一个塑料拨片，将拨片向下压，同时将外侧导轨向后推动，解锁右侧导轨限位。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/unlock-right-slide-stop.webp)

同样方法，将左侧内轨中的拨片向上抬，同时将外侧导轨向后推动，解锁左侧导轨限位。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/unlock-left-slide-stop.webp)

重复以上操作，将所有抽屉全部移除。

### 步骤3.移除可调万向轮

将工作站倒置或侧置在平整且稳固平台上，漏出底板可调万向轮。

> 倒置前建议在工作站与放置平台之间铺设一层缓冲，避免操作过程中划伤工作站桌面。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/invert-station-for-base.png)

使用 H3.0 内六角扳手移除图示四颗螺丝，取下可调万向轮。重复此步骤移除全部的可调万向轮。

|  |  |
| --- | --- |
|  |  |

### 步骤4.移除底座

使用 H3.0 内六角扳手从每个立柱的图示位置拆卸两颗螺丝，共计 8 颗。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/upright-base-two-screws.png)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/base-eight-screws-overview.png)

轮流敲击底座与立柱连接位置，直到底座完全松动，将底座取下。

> 注意：每次敲出的距离不宜过长，单个立柱位置一次敲出过长可能导致剩余立柱位置拆卸变得更加困难。建议每次敲出2cm左右，循环多次，直到底座完全松出。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/tap-off-base.webp)

## 安装底座

### 步骤1.安装底座

对准底座四角塑胶件与立柱插槽。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/align-base-corner-inserts.png)

轮流下压底座四角，将塑胶件竖直下压至半插入（勿完全压入），保持立柱垂直。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/half-insert-base-corners.webp)

对齐立柱定位楔与底座定位槽。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/align-upright-positioning-wedges.png)

继续轮流下压四角，直至定位楔完全卡入槽内。

> 注意：安装时请保持立柱垂直。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/press-base-fully-into-place.webp)

使用 H3.0 内六角扳手装回图示 8 颗螺丝

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/base-eight-screws-overview.png)

### 步骤2.安装可调万向轮

装回四个可调万向轮，使用 H3.0 内六角扳手为每个万向轮各锁入四颗螺丝固定。

|  |  |
| --- | --- |
|  |  |

### 步骤3.安装抽屉

将设备转正放置。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/stand-cabinet-upright.png)

将下层抽屉两侧滑轨对准柜体轨道上的缺口平稳推入到底，此时限位会自动复位。然后将抽屉拉出至极限位置，检查限位装置是否正常生效。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/align-drawer-with-cabinet-rails.png)

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/install-lower-drawer.webp)

同样方法装回上层抽屉。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/install-upper-drawer.webp)

### 步骤4.安装左右侧板（可选）

装回工作站两侧侧板，使用 H3.0 内六角扳手每侧各锁入四颗螺丝固定。

![](https://wiki.bambulab.com/bambu-station-l/maintenance/replace-base/side-panel-screws.png)
