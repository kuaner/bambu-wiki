## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### 关闭电源，并卷起线缆

步骤 1. 关闭打印机电源，切断电源线。

|  |  |
| --- | --- |
|  |  |

步骤 2. 按紧线缆接口底端，断开 AMS lite 的 4 pin 线。

|  |  |
| --- | --- |
|  |  |

步骤 3. 用黑色细线将 4 pin 线和电源线卷起。

|  |  |
| --- | --- |
|  |  |

### 拆除料管

步骤 1. 按压工具头入料口接口（推荐使用镊子），拔出四根料管。

|  |  |
| --- | --- |
|  |  |

步骤 2. 按压料盘支架上的料管接口，拆除料管。

|  |  |
| --- | --- |
|  |  |

### 拆除 AMS lite

步骤 1. 拔出 AMS lite 回转轴。

![40.png](https://wiki.bambulab.com/a1-combo-packing/40.png)

步骤 2. 拆除连接 AMS lite 主体和支架的四颗螺丝。

|  |  |
| --- | --- |
|  |  |

步骤 3. 拆下 AMS lite主体，并将 AMS 主体和支架放回泡沫纸板。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 4. 将 AMS lite 回转轴装回纸板，并盖回打印板，用胶带粘牢。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 5. 装回配件。

|  |  |
| --- | --- |
|  |  |

### 固定 Z 轴、工具头和 X 轴

步骤 1. 安装 Z 轴限制器，并拧紧四颗螺丝。**需卡准 Z 轴限制器位置。**

|  |  |
| --- | --- |
|  |  |

> **注意**：早期版本机器中，龙门架上并未打孔，因此装箱时可使用扎带固定 X 轴。

步骤 2. 用纸板抵住工具头，将工具头移到最左侧，并用扎带固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 3. 装回 X 轴纸板，并用扎带固定纸板和线缆。

|  |  |
| --- | --- |
|  |  |

### 取下打印板，固定热床

步骤 1. 取下打印板。

![57.png](https://wiki.bambulab.com/a1-combo-packing/57.png)

步骤 2. 放置热床防护泡沫，并用扎带固定。

|  |  |
| --- | --- |
|  |  |

### 装箱操作

步骤 1. 将打印机放回纸箱。

![60.png](https://wiki.bambulab.com/a1-combo-packing/60.png)

步骤 2. 放置 AMS lite。

![61.png](https://wiki.bambulab.com/a1-combo-packing/61.png)

步骤 3. 放置配件盒。

![62.png](https://wiki.bambulab.com/a1-combo-packing/62.png)

步骤 4. 放入泡沫纸板和配件，并用胶带粘牢。

|  |  |  |
| --- | --- | --- |
|  |  |  |
