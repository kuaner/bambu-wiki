## 故障描述

R1 机器通过霍尔传感器检测上盖和托盘的在位情况，若检测到传感器信号异常，则提示该报错信息。可根据报错情况检查对应的传感器。

## 可能的原因

- 传感器连接端子松脱
- 传感器连接线损坏破裂

## 故障排除

### 情况一：上盖及托盘传感器异常

若同时出现上盖及托盘传感器异常报错，大概率是主控板端的连接排线**（下图中③）**松脱、接触不良，需拆下左侧盖检查；参考 wiki：[更换主控板](https://wiki-test.bambulab.net/zh/r1/maintenance/replace-mainboard)；

![hms_0300-b900-0001-0002-img_v3_02157_2490bba7-091f-4b04-9654-3bada721e94g.jpg](https://wiki.bambulab.com/r1/troubleshooting/hmscode/0300_b900_0001_0002/hms_0300-b900-0001-0002-img_v3_02157_2490bba7-091f-4b04-9654-3bada721e94g.jpg)

### 情况二：上盖/托盘传感器异常

若只出现一个传感器的报错异常，则需找到对应传感器的安装位置，单独检查传感器端的连接情况：

- **上盖传感器异常：**

参考 wiki：[前后门更换指南](https://wiki-test.bambulab.net/zh/r1/maintenance/replace-riser-base-front-rear-panels)；

![hms_0300-b900-0001-0002-img_v3_0215h_a30adb26-c7f1-41ee-a7de-ede7bf41464g.jpg](https://wiki.bambulab.com/r1/troubleshooting/hmscode/0300_b900_0001_0002/hms_0300-b900-0001-0002-img_v3_0215h_a30adb26-c7f1-41ee-a7de-ede7bf41464g.jpg)

- **托盘传感器异常：**

托盘传感器位于底部较前侧的脚垫附近；

**左侧：**拧下保护盖固定螺丝，再重新连接插头；

|  |  |
| --- | --- |
|  |  |

**右侧：**拧下保护壳固定螺丝，再重新连接插头；

|  |  |
| --- | --- |
|  |  |

若完成以上工作后报错依旧，请联系客户支持团队。
