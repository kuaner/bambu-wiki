## 故障描述

设备无法识别到工具头摄像头接入，需检查线缆是否松脱或接触不良。

## 可能的原因：

- 摄像头线缆异常
- 摄像头故障
- 主板故障

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手
- H2.0 六角扳手

### 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

### 排故措施

#### 步骤1. 检查工具头内线缆

1. 断开设备电源。
2. 使用 H1.5 内六角螺丝刀拆卸图示两颗螺丝。

|  |  |
| --- | --- |
| 001.jpg | 002.jpg |

3. 取下工具头前盖。

![003.webp](https://public-cdn.bblmw.com/wiki/new/r1/troubleshooting/hmscode/0500_0600_0002_0031/zh/003.webp)

4. 重新连接 “3、4” 线缆插头。注意拆卸 “3” 时，需要打开黑色压块。

![004.png](https://public-cdn.bblmw.com/wiki/new/r1/troubleshooting/hmscode/0500_0600_0002_0031/zh/004.png)

4. 完成后装回前盖，开机观察报错。若报错依旧，则进行下一步。

#### 步骤2. 检查主板内线缆

1. 断开设备电源
2. 首先参考[更换左侧板](../../maintenance/replace-left-shell.md)移除左侧板，重新连接主板上的 “5” 号线缆插头。

![005.png](https://public-cdn.bblmw.com/wiki/new/r1/troubleshooting/hmscode/0500_0600_0002_0031/zh/005.png)

3. 重新开机测试：

   1. 若报错消失，按照指南装回壳体。
   2. 若报错依旧，请联系客户支持团队。
