## 故障描述

长时间使用设备后，皮带的张紧程度可能降低，此时需要重新张紧对应轴的皮带。

## 所需工具

- H2.0 内六角扳手

## 步骤 1. Y 轴同步带张紧

1. 拧下左右两侧盖板的固定螺丝， 拆下盖板。

|  |  |
| --- | --- |
| 001.png | 002.png |

2. 再拧松 1 圈两侧张紧块的固定螺丝，请勿完全拧下。

|  |  |
| --- | --- |
| 003.png | 004.png |

3. 完成后手动推拉工具头前后移动。

![005.webp](https://public-cdn.bblmw.com/wiki/new/r1/troubleshooting/hmscode/0300_1100_0002_0001/zh/005.webp)

4. 再拧紧张紧块的固定螺丝。

|  |  |
| --- | --- |
| 006.png | 007.png |

5. 安装盖板。

|  |  |
| --- | --- |
| 008.png | 009.png |

## 步骤 2. 校准

完成张紧后，进入校准页面开启“振动补偿校准”和“自动光路校准”。

![010.png](https://public-cdn.bblmw.com/wiki/new/r1/troubleshooting/hmscode/0300_1100_0002_0001/zh/010.png)
