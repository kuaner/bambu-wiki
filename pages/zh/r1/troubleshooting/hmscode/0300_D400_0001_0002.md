## 故障描述

灭火器会实时检测在位检测霍尔传感器的工作情况，如果工作异常，则会报此 hms。

## 可能的原因

- 在位检测霍尔传感器开路
- 在位检测霍尔传感器短路

## 故障排除

#### 步骤 1. 重启灭火器

- 确认灭火器 4-pin 线连接到位后，拔掉灭火器电源线；

|  |  |
| --- | --- |
| 001.png | 002.png |

- 稍等片刻后，重新插入灭火器电源线，观察 hms 是否仍存在；

![003.png](https://public-cdn.bblmw.com/wiki/new/r1/troubleshooting/hmscode/0300_d400_0001_0002/zh/003.png)

- 如果 hms 消失，则故障排除；否则执行下一步。

#### 步骤 2. 检查在位检测传感器连接线

- 拔掉灭火器电源线，移除应急手轮螺丝，检查霍尔板和连接线是否正常；

|  |  |
| --- | --- |
| 004.png | 005.png |

- 断开线缆，移除 6 颗螺丝，拆开灭火器的外壳；

|  |  |
| --- | --- |
| 006.png | 007.png |

- 检查在位霍尔连接线是否松动或损坏；

![008.png](https://public-cdn.bblmw.com/wiki/new/r1/troubleshooting/hmscode/0300_d400_0001_0002/zh/008.png)

- 装回外壳，重新插入灭火器电源线和 4-pin 线，观察 hms 是否还存在；

|  |  |
| --- | --- |
| 009.png | 010.png |

- 如果 hms 消失，则故障解决；如果未消失，请联系售后团队。
