## 聚焦镜

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-focusing-lens/zh/001.png)

聚焦镜有三个不同的焦距版本，更换方法一致，本文以**短焦聚焦镜**演示更换操作。  
以下为三款聚焦镜介绍：

**S 短焦聚焦镜** ：为机器标配，焦距 38.1mm，聚焦直径 0.11mm，参考雕刻精度约 140μm×160μm，光斑最小、细节表现最佳，熏黄改善效果最好，实测最大可切 15mm 黑胡桃木、20mm 亚克力，适合精细雕刻类场景。

**M 中焦聚焦镜** ：为选配配件，焦距 50.8mm，聚焦直径 0.17mm，参考雕刻精度约 150μm×180μm，综合性能均衡，实测最大可切 18mm 黑胡桃木、20mm 亚克力，适配绝大多数日常加工场景。

**L 长焦聚焦镜** ：为选配配件，焦距 63.5mm，聚焦直径 0.19mm，参考雕刻精度约 180μm×200μm，有效焦深最长，实测最大可切 18mm 黑胡桃木、20mm 亚克力，同等厚度下切割速度比中焦更快，更适配厚板切割类场景。

## 何时更换

聚焦镜出现脏污、破损。

## 所需工具和材料

- H2.0 内六角螺丝刀
- H1.5 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先**关闭设备电源并断开电源连接**，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除聚焦镜

### 步骤 1. 移除工具头外壳

使用 H1.5 内六角扳螺丝刀拆卸图示两颗螺丝。

|  |  |
| --- | --- |
| 002.jpg | 003.jpg |

取下工具头前盖。

![004.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-focusing-lens/zh/004.webp)

### 步骤 2. 移除聚焦镜

使用 H2.0 内六角螺丝刀移除四颗螺丝，向外拉出聚集镜。

|  |  |
| --- | --- |
| 005.jpg | 006.webp |

## 安装聚焦镜

### 步骤 1. 安装聚焦镜

将聚焦镜装入原位，使用 H2.0 内六角螺丝刀锁入四颗螺丝固定。

|  |  |
| --- | --- |
| 007.webp | 008.png |

### 步骤 2. 安装工具头前盖

将工具头前盖装回工具头。

![009.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-focusing-lens/zh/009.jpg)

使用 H1.5 内六角螺丝刀锁入两颗螺丝固定工具头前盖。

## 功能验证

1. 如果更换了不同规格的聚焦镜，请在设备屏幕上点击\*\*“设置 > 设备控制 > 聚焦镜”\*\*，更改设备聚焦镜类型。

|  |  |
| --- | --- |
| 012.png | 013.png |

2. 更换聚焦镜后，建议在设备屏幕上点击\*\*“设置 > 校准 > 视觉精度校准”\*\*，重新进行一次视觉精度校准。
