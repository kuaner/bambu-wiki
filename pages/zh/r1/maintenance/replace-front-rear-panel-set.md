## 前后盖板组

![SLA065.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/sla065.png)

## 所需工具和材料

- H2.0 内六角螺丝刀
- H1.5 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除前盖板

### 步骤 1.移除前盖板

从仓内观察，使用 H2.0 内六角螺丝刀移除图示 6 颗螺丝。

![PixPin_2026-07-29_12-07-06.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/pixpin_2026-07-29_12-07-06.jpg)

将设备拉动到桌子边缘位置，方便后续操作。注意：不要将脚垫拉出桌面范围，以免设备跌落。

![PixPin_2026-07-29_12-09-37.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/pixpin_2026-07-29_12-09-37.webp)

撕下底座中间位置硅胶垫，使用 H2.0内六角螺丝刀移除图示六颗螺丝。

> 底部中间螺丝位置贴有黑色硅胶垫，拆卸时需要提前取下，安装时需要复原。

![PixPin_2026-07-29_12-13-20.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/pixpin_2026-07-29_12-13-20.jpg)

将前盖向前拉出，然后断开两侧霍尔连接线。连接线插头有卡扣，需要按下后拔出，切勿暴力拉拽。

![PixPin_2026-07-29_12-18-36.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/pixpin_2026-07-29_12-18-36.webp)

## 移除后盖板

### 步骤 1.移除排烟风扇

断开排烟管，顺时针转动排烟风扇解锁卡扣，

![PixPin_2026-08-06_15-24-43.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/pixpin_2026-08-06_15-24-43.webp)

### 步骤 2.移除排烟风扇安装座

使用 H2.0 内六角螺丝刀，拆卸四颗固定螺丝，将排烟风扇安装座拉出一段距离。

![PixPin_2026-08-04_12-14-40.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/pixpin_2026-08-04_12-14-40_1.jpg)

使用 H1.5 内六角螺丝刀，拆卸两颗螺丝，断开插头连接，取下排烟风扇安装座。

![PixPin_2026-08-04_12-18-02.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/pixpin_2026-08-04_12-18-02.jpg)

移除注水口塞。

![C0104.MP4_20260827_153401.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/c0104.mp4_20260827_153401.webp)

### 步骤 3.移除后盖板

移除后盖，使用 H2.0 内六角螺丝刀拆除后盖板固定螺丝。（固定后盖板银色螺丝螺丝头更厚，建议分别保存）

|  |  |
| --- | --- |
| PixPin_2026-08-04_12-06-05.jpg | rear screws from the bottom.png |

取下后盖板。

![PixPin_2026-08-04_11-59-46.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/pixpin_2026-08-04_11-59-46.webp)

### 步骤 4.移除激光管盖板

使用 H2.0 内六角螺丝刀移除图示四颗螺丝。

![image.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/image_1.png)

关闭上盖，向上取下激光管盖板。

![C9459.MP4_20260909_144549.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/c9459.mp4_20260909_144549.webp)

## 安装前盖板

### 步骤 1.安装前盖板

连接前盖板霍尔板连接线，然后将前盖板安装到位。

|  |  |
| --- | --- |
| image.png | image.png |
| PixPin_2026-07-29_14-18-25.webp |

使用 H2.0 内六角螺丝刀从舱内锁入 6 颗螺丝，从设备下方锁入5颗螺丝固定。

|  |  |
| --- | --- |
| image.png | image.png |

## 安装后盖板

### 步骤 1.安装激光管盖板

装回激光管盖板。

![C9461.MP4_20260909_144916.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/c9461.mp4_20260909_144916.webp)

使用 H2.0 内六角螺丝刀锁入四颗螺丝固定。

![image.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/image_2.png)

装回后盖板。

![PixPin_2026-08-06_16-09-40.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/pixpin_2026-08-06_16-09-40.webp)

### 步骤 2.安装后盖板

使用 H2.0 内六角螺丝刀分别锁入图示13颗螺丝固定后盖板。

|  |  |
| --- | --- |
| PixPin_2026-08-04_12-06-05.jpg | rear screws from the bottom.png |

安装注水口塞。

![image.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/image_5.png)

### 步骤 3.安装排烟风扇安装座

将线缆插头对齐安装孔位，使用 H1.5 内六角螺丝刀，锁入两颗螺丝固定。

![PixPin_2026-08-04_12-18-02.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/pixpin_2026-08-04_12-18-02_1.jpg)

装好排烟风扇安装座，注意风扇座方向，使用 H2.0 内六角螺丝刀锁入四颗螺丝固定。

|  |  |
| --- | --- |
| PixPin_2026-08-04_12-21-59.webp | PixPin_2026-08-04_12-14-40.jpg |

### 步骤 4.安装排烟风扇

连接风扇插头，整理风扇线缆。将风扇对齐安装位置，逆时针转动风扇，直到听到咔哒一声。

![PixPin_2026-08-06_15-50-13.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-front-rear-panel-set/zh/pixpin_2026-08-06_15-50-13.webp)

## 功能验证

开机，运行激光切割任务，设备开盖检测正常且排烟风扇出风口正常出风则表示上述安装正确。
