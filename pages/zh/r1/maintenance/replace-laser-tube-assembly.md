## 激光管组件 Laser Tube Assembly

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/001.png)

## 所需工具和材料

- H1.5 内六角螺丝刀
- H1.5 内六角扳手
- H2.0 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

> 在正式操作拆装前，请将设备电源开关及电源线断开，静置三分钟，等待设备完全放电后操作。

## 移除激光管组件

### 步骤 1.移除前后盖板组

参照[前后盖板组更换指南](https://wiki.bambulab.com/zh/r1/maintenance/replace-front-rear-panel-set)移除前后盖板组。

### 步骤 2.移除右壳体

参照[右壳体更换指南](https://wiki.bambulab.com/zh/r1/maintenance/replace-right-shell)移除右壳体。

### 步骤 3.排出冷却液

装回注水孔塞，先开排水管堵头，再打开水箱注水孔塞子，等待水箱内液体排空，装回水管堵头。

|  |  |
| --- | --- |
| 002.png | 003.png |

解锁水管夹，拔出右侧水管。

|  |  |
| --- | --- |
| 004.webp | 005.webp |

使用气吹等工具吹出管道内剩余的冷却液。

![006.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/006.webp)

同样方法解锁左侧水管夹，拔出左侧水管。

![007.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/007.webp)

### 步骤 4.断开激光管电源线

使用 H2.0 内六角螺丝刀移除两颗螺丝。

|  |  |
| --- | --- |
| 008.png | 009.webp |

移除激光管阳极连接线压块，断开激光管阳极连接线。

![010.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/010.webp)

断开激光管阴极连接线。

![011.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/011.webp)

### 步骤 5.移除激光管

按照原来方法取下水管夹，断开激光管左侧的进水管。

![012.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/012.webp)

使用 H2.0 内六角螺丝刀移除图示八颗螺丝，取下激光管支架及硅胶垫。

|  |  |
| --- | --- |
| 013.png | 014.webp |

先抽出水管，用手堵住管口，以免后续取出激光管时内部剩余的液冷洒出，然后握住激光管两侧管身取出激光管组件，请勿直接拉拽水管或连接线取下激光管。

> 此步骤中激光管下部的硅胶垫可能粘附在激光管上，请注意将激光管上的硅胶垫取下。

![015.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/015.webp)

## 安装激光管组件

### 步骤 1.安装激光管

将四个硅胶垫重新安装到槽位中。

![016.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/016.webp)

将激光管放入安装槽，激光管脆弱请小心操作。

![017.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/017.webp)

调整激光管与反射模组的位置，间距保持在 5 mm左右，激光管的两个水管接口夹角对角线垂直与安装面。

|  |  |
| --- | --- |
| 018.png | 019.png |

将硅胶垫装回激光管支架，然后将激光管支架装回原位。重复此操作装好两个激光管支架。

![020.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/020.webp)

使用 H2.0 内六角螺丝刀锁入 8 颗螺丝固定两处支架。

![021.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/021.png)

装回激光管左侧水管。

![022.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/022.webp)

装回后方两根水管并安装水管夹固定。

![023.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/023.png)

### 步骤 2.连接激光管电源线

安装激光管阳极连接插头。

![024.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/024.webp)

将线缆沿槽位卡入压块，锁入两颗螺丝固定。

|  |  |
| --- | --- |
| 025.png | 026.png |

安装激光管阴极连接线。

![027.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-tube-assembly/zh/027.webp)

### 步骤 3.安装右壳体

参照[右壳体更换指南](https://wiki.bambulab.com/zh/r1/maintenance/replace-right-shell)装回右壳体。

### 步骤 4.安装前后盖板组

参照[前后盖板组更换指南](https://wiki.bambulab.com/zh/r1/maintenance/replace-front-rear-panel-set)装回前后盖板组。

### 步骤5.加注冷却液

参照[冷却液配备教程](coolant.md)，重新配比冷却液加注，也可以将旧的冷却液重新加入水箱。

## 功能验证

参照[光路校准](../manual/laser-alignment-guide.md)教程，运行一次光路校准操作，如果校准正常完成则上述安装正确。
