## 惰轮套件 Idler Pack

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/001.png)

惰轮套件包含两个Y轴惰轮和一个X轴惰轮，请根据需要选择更换。

## 所需工具和材料

- H2.0 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除 X 轴惰轮

### 步骤 1. 移除第二反射镜模组组件

使用 H2.0 内六角螺丝刀移除图示四颗螺丝。

![002.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/002.png)

取下图示盖板。

![003.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/003.webp)

将组件转至一侧，漏出 X 轴电机固定螺丝。

![004.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/004.webp)

### 步骤 2. 解锁 X 轴电机

释放 X 电机张紧弹簧，使用 H2.0 内六角螺丝刀拧松三颗电机固定螺丝（不需要拧下）。

|  |  |
| --- | --- |
| 005.webp | 006.png |

### 步骤 3. 移除 X 轴惰轮

使用 H2.0 内六角螺丝刀移除一颗螺丝，取下 X 轴惰轮。

![007.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/007.png)

## 安装 X 轴惰轮

### 步骤 1. 安装 X 轴惰轮

装配新的 X 轴惰轮。

> 注意：如果包装内有多个垫片，此处请使用较厚的垫片。

![008.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/008.webp)

使用 H2.0 内六角螺丝刀锁紧 X 轴惰轮，并将 X 皮带套回惰轮上。

![009.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/009.png)

### 步骤 2. 安装 X 轴电机

装回 X 电机张紧弹簧。

![010.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/010.webp)

左右滑动几次工具头释放皮带张力，然后使用 H2.0 内六角螺丝刀锁紧三颗电机固定螺丝。

![011.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/011.png)

### 步骤 3. 安装第二反射镜模组组件

将第二反射镜模组组件装回原位，使用 H2.0 内六角螺丝刀锁入四颗螺丝固定。

![012.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/012.png)

装回图示盖板。

![013.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/013.webp)

## 移除 Y 轴张紧惰轮

> 左右两侧的 Y 轴张紧惰轮组件一致，更换步骤也一致，下文将以左侧张紧惰轮为例演示更换步骤，请根据实际需要选择对应的惰轮更换。

### 步骤 1. 锁定 X 轴

将X轴推到最后方，使用开箱时的固定件，锁定X轴。

> 如果固定件已经丢失，则请在后续操作中始终保持X轴紧贴后方框架，避免安装后X轴出现倾斜。

![014.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/014.png)

### 步骤 2. 移除 Y 轴张紧惰轮

使用 H2.0 内六角螺丝刀移除左右各两颗螺丝，取下两侧 Y 轴张紧器盖板。

![015.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/015.png)

使用 H2.0 内六角螺丝刀拧松三颗螺丝（无需拧下），释放张紧器。另一侧同样操作。

![016.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/016.png)

释放张紧弹簧，同样方法释放另一侧弹簧。

![017.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/017.webp)

使用 H2.0 内六角螺丝刀拧松张紧弹簧固定螺丝，取下张紧弹簧。

![018.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/018.png)

将三颗螺丝彻底拧下，取下 Y 轴张紧器。同样方法操作另一侧。

| --- | --- |

## 安装 Y 轴张紧惰轮

### 步骤 1. 安装 Y 轴张紧惰轮

取出新的 Y 轴张紧惰轮，安装垫片、惰轮，使用 H2.0内六角螺丝刀锁入一颗螺丝固定。

> 惰轮套件中共有两种垫片，此处使用的垫片数量为 2 ，厚度比 X 轴惰轮使用的垫片薄，请勿用错。
>
> 如您收到的备件中 Y 轴张紧惰轮已经预装好，可跳过组装步骤。

![021.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/021.webp)

装回 Y 轴惰轮，注意将 Y 轴皮带绕过惰轮。另一侧安装同理。

![022.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/022.webp)

使用 H2.0 内六角螺丝刀锁入三颗螺丝，不需要拧紧，确保惰轮可以左右滑动。另一侧同样方法安装。

![023.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/023.png)

使用 H2.0 内六角螺丝刀锁入一颗螺丝固定张紧弹簧。另一侧同样方法安装。

![024.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/024.png)

装回张紧弹簧，移动几次 Y 轴后，锁紧图示三颗螺丝，锁定张紧器。

|  |  |
| --- | --- |
| 025.webp | 026.png |

装回张紧惰轮盖板，使用 H2.0 内六角螺丝刀锁入两颗螺丝固定。另一侧同样方法安装。

![027.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/027.png)

### 步骤 2. 解锁 X 轴

使用 H2.0 内六角螺丝刀移除 8 颗螺丝，取下固定件。

![028.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/028.png)

## 功能验证

开机，在设备屏幕选择设置——校准，分别运行电机校准和光路自动校准，如果校准顺利完成，则上述安装正确。

![029.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-idler-pack/zh/029.png)
