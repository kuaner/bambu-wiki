## 4-pin 与 8-pin 整合扩展板 4-pin & 8-pin Extension Board

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-4-pin-8-pin-extension-board/zh/001.png)

## 何时更换

1. 4 Pin 或 8 Pin 接口损坏。

## 所需工具和材料

- H2.0 内六角螺丝刀
- H1.5 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除 4-pin 与 8-pin 整合扩展板

### 步骤 1. 移除前后盖板组

参照[R1 前后盖板组更换指南](replace-front-rear-panel-set.md)移除前后盖板组。

### 步骤 2. 移除左壳体

参照[左壳体更换指南](replace-left-shell.md)移除左壳体，无需移除左侧上盖。

### 步骤 3. 移除气泵

参照[气泵更换指南](replace-air-pump.md)移除气泵组件。

### 步骤 4. 移除 4-pin 与 8-pin 整合扩展板

从主板断开 4-pin 与 8-pin 整合扩展板两根连接线，理出线缆。

|  |  |
| --- | --- |
| 002.png | 003.webp |

再从设备内侧使用 H2.0 内六角螺丝刀移除四颗螺丝，取下转接板。

![004.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-4-pin-8-pin-extension-board/zh/004.png)

## 安装 4-pin 与 8-pin 整合扩展板

### 步骤 1. 安装 4-pin 与 8-pin 整合扩展板

连接 4-pin 与 8-pin 整合扩展板连接线。

![005.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-4-pin-8-pin-extension-board/zh/005.png)

将 4-pin 与 8-pin 整合扩展板装回，使用 H2.0 内六角螺丝刀锁入四颗螺丝固定。

|  |  |
| --- | --- |
| 006.webp | 007.png |

整理线缆，连接主板端插头。

|  |  |
| --- | --- |
| 008.webp | 009.png |

### 步骤 2. 安装气泵

参照[气泵更换指南](replace-air-pump.md)移除气泵组件。

### 步骤 3. 安装左壳体

参照[左壳体更换指南](replace-left-shell.md)装回左壳体。

### 步骤 4. 安装前后盖板组

参照[R1 前后盖板组更换指南](replace-front-rear-panel-set.md)装回前后盖板组。
