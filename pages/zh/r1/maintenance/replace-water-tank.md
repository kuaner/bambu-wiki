## 水箱

![______-water_tank_replacement_guide-image.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-image.png)

## 何时更换

1. 水泵工作异常。
2. 水箱破损。
3. 水温显示异常。

## 所需工具和材料

- H2.0 内六角螺丝刀
- H1.5 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除水箱

### 步骤 1.移除整机后盖板

断开排烟管，顺时针转动排烟风扇解锁卡扣，断开内部连接线，取下排烟风扇。

![______-water_tank_replacement_guide-pixpin_2026-08-06_15-24-43.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-06_15-24-43.webp)

使用 H2.0 内六角螺丝刀，拆卸四颗固定螺丝，将排烟风扇安装座拉出一段距离。

![______-water_tank_replacement_guide-pixpin_2026-08-04_12-14-40.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-04_12-14-40.jpg)

使用 H1.5 内六角螺丝刀，拆卸两颗螺丝，断开插头连接，取下排烟风扇安装座。

![______-water_tank_replacement_guide-pixpin_2026-08-04_12-18-02.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-04_12-18-02.jpg)

移除注水口塞。

![______-water_tank_replacement_guide-c0104.mp4_20260827_153401.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-c0104.mp4_20260827_153401.webp)

移除后盖板，使用 H2.0 内六角螺丝刀拆除图示 13 颗后盖板固定螺丝。（固定后盖板银色螺丝螺丝头更厚，建议分别保存）

取下后盖板。

![______-water_tank_replacement_guide-pixpin_2026-08-04_11-59-46.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-04_11-59-46.webp)

### 步骤 2.排出冷却液

装回注水孔塞。

![______-water_tank_replacement_guide-image-1.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-image-1.png)

先开排水管堵头，再打开水箱注水孔塞子，等待水箱内液体排空，装回水管堵头。

![______-water_tank_replacement_guide-image-2.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-image-2.png)

将水管夹的锁扣分别上下掰动，解锁水管夹。同样方法拆除另一个水管夹。

|  |  |
| --- | --- |
| ______-water_tank_replacement_guide-image-3.png | ______-water_tank_replacement_guide-pixpin_2026-08-10_14-28-36.webp |

拔出水箱侧排水管、液冷风扇侧水管，拔除困难时可以使用镊子尾部撬动水管辅助拔出。

> 初次拔出时可能较为困难，可以使用镊子尾部辅助拔出。
>
> 拔出水管时管内可能仍然剩余少量液体，请注意不要溅到设备内，如不慎溅到设备内部请及时擦干。如液体不慎溅到PCB板上，及时擦除液体并使用吹风机吹干水分并联系技术支持获取帮助。

### 步骤 3.取出冷却模组

剪断水箱控制板线缆扎带，拔除四根线缆（1.AP控制线、2.电源线、3.火焰传感器、4.火焰传感器）  
注意：3、4号插头有卡扣，需要按下卡扣后拔出。

![______-water_tank_replacement_guide-pixpin_2026-08-10_14-26-14.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-10_14-26-14.jpg)

使用 H2.0 内六角螺丝刀移除 6 颗冷却模组固定螺丝。

![______-water_tank_replacement_guide-pixpin_2026-08-11_10-56-00.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-11_10-56-00.jpg)

将冷却模组拉出。

> 注意：拉出冷却模组时请尽量保持模组水平，取出该组件后请勿歪斜或者倒置，组件内可能仍然有液体未排出。

![______-water_tank_replacement_guide-c0018.mp4_20260922_141237.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-c0018.mp4_20260922_141237.webp)

> 如果您只是取出冷却模组，到此步骤已经完成。安装步骤请跳转到安装冷却模组。

### 步骤 4.移除水箱组件

断开标记的四个插头。1、3、4号插头有卡扣，需要按下卡扣后拔出。

![______-water_tank_replacement_guide-pixpin_2026-08-11_10-12-57.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-11_10-12-57.jpg)

使用 H2.0内六角螺丝刀移除图示 5 颗螺丝。

![______-water_tank_replacement_guide-pixpin_2026-08-11_10-05-47.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-11_10-05-47.jpg)

使用 H2.0内六角螺丝刀移除图示两颗螺丝。

![______-water_tank_replacement_guide-pixpin_2026-08-11_10-07-29.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-11_10-07-29.jpg)

解锁水管夹，从液冷风扇侧端断开水管。

![______-water_tank_replacement_guide-pixpin_2026-08-11_10-17-26.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-11_10-17-26.webp)

### 步骤 5.移除冷却组件转接板

断开液冷组件的三根连接线，使用 H2.0 内六角螺丝刀移除两颗螺丝，取下冷却组件转接板。

## 安装水箱

### 步骤 1.安装冷却组件转接板

将冷却组件转接板放入固定位置，使用 H2.0 内六角螺丝刀锁入两颗螺丝固定。

![______-water_tank_replacement_guide-image-4.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-image-4.png)

连接液冷组件的三根线缆，三根线缆完全相同，没有顺序要求。

![______-water_tank_replacement_guide-pixpin_2026-08-11_10-20-10-1.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-11_10-20-10-1.jpg)

### 步骤 2.安装水箱组件

连接水箱组件水管，并安装水管夹。

|  |  |
| --- | --- |
| ______-water_tank_replacement_guide-pixpin_2026-08-11_10-35-54.webp | ______-water_tank_replacement_guide-pixpin_2026-08-11_10-38-05.webp |

使用 H2.0 内六角螺丝刀锁入7颗螺丝固定水箱组件。

|  |  |
| --- | --- |
| ______-water_tank_replacement_guide-image-5.png | ______-water_tank_replacement_guide-image-6.png |

根据相应的颜色和插头型号，装回水箱连接插头。

![______-water_tank_replacement_guide-image-7.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-image-7.png)

### 步骤 3.安装冷却模组

将冷却模组装回，注意不要压到线缆和水管。

![______-water_tank_replacement_guide-image-8.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-image-8.png)

对齐安装孔位，锁入 6 颗螺丝固定

![______-water_tank_replacement_guide-pixpin_2026-08-11_10-56-00-1.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-11_10-56-00-1.jpg)

根据插头颜色和型号，连接冷却组件转接板插头。

![______-water_tank_replacement_guide-image-9.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-image-9.png)

连接水管，安装水管夹。  
注意：安装水管时，请将水管推动到接头最底部，并用力锁紧水管夹。

![______-water_tank_replacement_guide-pixpin_2026-08-11_11-17-52.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-11_11-17-52.jpg)

### 步骤 4.安装整机后盖板

装回后盖板。

![______-water_tank_replacement_guide-pixpin_2026-08-06_16-09-40.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-06_16-09-40.webp)

使用 H2.0 内六角螺丝刀分别锁入图示13颗螺丝固定后盖板。

|  |  |
| --- | --- |
| ______-water_tank_replacement_guide-pixpin_2026-08-04_12-06-05-1.jpg | ______-water_tank_replacement_guide-rear_screws_from_the_bottom-1.png |

安装注水口塞。

![______-water_tank_replacement_guide-image-10.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-image-10.png)

将线缆插头对齐安装孔位，使用 H1.5 内六角螺丝刀，锁入两颗螺丝固定。

![______-water_tank_replacement_guide-pixpin_2026-08-04_12-18-02-1.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-04_12-18-02-1.jpg)

装好排烟风扇安装座，注意风扇座方向，使用 H2.0内六角螺丝刀锁入四颗螺丝固定。

|  |  |
| --- | --- |
| ______-water_tank_replacement_guide-pixpin_2026-08-04_12-21-59.webp | ______-water_tank_replacement_guide-pixpin_2026-08-04_12-14-40-1.jpg |

连接风扇插头，整理风扇线缆。将风扇对齐安装位置，逆时针转动风扇，直到听到咔哒一声。

![______-water_tank_replacement_guide-pixpin_2026-08-06_15-50-13.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-water-tank/zh/______-water_tank_replacement_guide-pixpin_2026-08-06_15-50-13.webp)

### 步骤 5.重新加入冷却液

参照[R1 冷却液更换教程](coolant.md)重新加入冷却液，如果使用环境温度较低还需要配比防冻液，以免冷却液结冰损坏设备。
