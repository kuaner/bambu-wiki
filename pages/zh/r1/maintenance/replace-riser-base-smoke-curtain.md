## 增高架 挡烟帘 Riser Base Smoke Curtain

![001.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-smoke-curtain/zh/001.jpg)

增高架 挡烟帘单品不包含挡烟帘支架（图示金属部分）。增高架 挡烟帘及挡烟帘支架为滚轮送料机配套部件，增高底座不包含此部分。

## 何时更换

1. 挡烟帘破损、脱胶无法正常起到挡烟功能时。

## 所需工具和材料

- H2.0 内六角螺丝刀

## 安全提示

> 在对设备及其电子设备（包括相关线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除增高架 挡烟帘

### 步骤 1. 移除 R1 激光切割机

打开主机上盖，移除增高底座与主机的 8-pin 连接线。

![002.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-smoke-curtain/zh/002.png)

两人合力搬下主机。

![003.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-smoke-curtain/zh/003.png)

### 步骤 2. 移除挡烟帘支架

使用 H2.0 内六角螺丝刀移除 4 颗螺丝。

|  |  |
| --- | --- |
| 004.png | 005.png |

取下移除挡烟帘支架。

![006.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-smoke-curtain/zh/006.png)

### 步骤 3. 移除增高架 挡烟帘

从挡烟帘支架上撕下增高架 挡烟帘。

|  |  |
| --- | --- |
| 007.png | 008.png |

## 安装增高架 挡烟帘

### 步骤 1. 安装增高架 挡烟帘

撕下新挡烟帘的背胶，将挡烟帘粘回挡烟帘支架。

![009.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-smoke-curtain/zh/009.png)

> 注意：挡烟帘中间有一处预留缺口，粘贴时请注意缺口位置。缺口位置错误可能导致滚轮送料机的传感器出现误判。

![010.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-smoke-curtain/zh/010.png)

### 步骤 2. 安装挡烟帘支架

将挡烟帘支架装回增高底座。

![011.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-smoke-curtain/zh/011.png)

对齐左右定位凸起，使用 H2.0 内六角螺丝刀锁入4颗螺丝固定。

|  |  |
| --- | --- |
| 012.png | 013.png |

### 步骤 3. 安装 R1 激光切割机

两人合力将主机搬回增高底座。

![014.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-smoke-curtain/zh/014.png)

打开主机上盖，连接好增高底座与主机的 8-pin 连接线。

![015.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-smoke-curtain/zh/015.png)
