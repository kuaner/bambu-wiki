## 上盖组件 Top Lid Assembly

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-top-lid-assembly/zh/001.png)

## 所需工具和材料

- H2.0 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除上盖组件

### 步骤 1. 移除前盖盖板组

请参照[R1 前后盖板组更换指南](replace-front-rear-panel-set.md)移除前后盖板组。

### 步骤 2. 移除左壳体

请参照[左壳体](replace-left-shell.md)更换指南移除左壳体（无需移除左侧上盖）。

### 步骤 3. 移除上盖气撑

请参照[上盖气撑更换指南](replace-top-lid-strut.md)更换指南移除两侧气撑。

### 步骤 4. 移除上盖组件

使用 H2.0 内六角螺丝刀移除图示 8 颗螺丝。

|  |  |
| --- | --- |
| 002.png | 003.png |

使用 H1.5 内六角螺丝刀移除图示一颗螺丝，断开主板端插头（如箭头所示）。

![004.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-top-lid-assembly/zh/004.png)

抽出俯视摄像头和补光灯组件连接线。

![005.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-top-lid-assembly/zh/005.webp)

移除上盖组件。

![006.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-top-lid-assembly/zh/006.webp)

## 安装上盖组件

### 步骤 1. 安装上盖组件

将上盖组件装回，锁入图示 8 颗螺丝，但不拧紧。此时调整上盖组件左右以及前后缝隙，合适后锁紧 8 颗固定螺丝。

|  |  |
| --- | --- |
| 007.webp | 008.png |
| 009.png |

将俯视摄像头和补光灯连接线穿回原位置。

![010.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-top-lid-assembly/zh/010.png)

连接主板端插头，注意有字母 A 的一面向外插入，使用线夹固定好线缆，然后使用 H1.5 内六角螺丝刀锁入一颗螺丝固定。

![011.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-top-lid-assembly/zh/011.png)

### 步骤 2. 安装上盖气撑

请参照[上盖气撑更换指南](replace-top-lid-strut.md)更换指南装回两侧气撑。

### 步骤 3. 安装左壳体

请参照[左壳体](replace-left-shell.md)更换指南装回左壳体。

### 步骤 4. 安装前盖盖板组

请参照[R1 前后盖板组更换指南](replace-front-rear-panel-set.md)装回前后盖板组。
