## 俯视摄像头和补光灯组件 BirdsEye Camera with Lighting

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-birdseye-camera-with-lighting/zh/001.png)

俯视摄像头和补光灯组件包含摄像头和补光灯主体及连接线，请根据需要选择对应的步骤更换。

## 何时更换

俯视摄像头功能异常  
补光灯不亮

## 所需工具和材料

- H2.0 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除俯视摄像头和补光灯组件

### 步骤 1. 移除俯视摄像头和补光灯组件

打开设备上盖，使用 H2.0 内六角螺丝刀移除图示 2 颗螺丝。

![002.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-birdseye-camera-with-lighting/zh/002.png)

取下俯视摄像头和补光灯组件，断开连接线。

![003.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-birdseye-camera-with-lighting/zh/003.webp)

### 步骤 2. 移除俯视摄像头和补光灯组件连接线（可选）

> 更换连接线步骤较复杂，建议更换摄像头后观察功能是否恢复，如果线缆无异常则无需更换。

参照[左壳体更换指南](replace-left-shell.md)，移除左壳体。

撕下设备上盖左上角的贴纸，从缺口处将侧线缆抽出。

|  |  |
| --- | --- |
| 004.webp | 005.webp |

使用 H1.5 内六角螺丝刀移除图示一颗螺丝，断开主板端插头。

![006.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-birdseye-camera-with-lighting/zh/006.png)

抽出俯视摄像头和补光灯组件连接线。

|  |  |
| --- | --- |
| 007.webp | 008.webp |

## 安装俯视摄像头和补光灯组件

### 步骤 1. 安装俯视摄像头和补光灯组件连接线（可选）

将线缆穿回主板一侧。

|  |  |
| --- | --- |
| 009.webp | 010.webp |

连接主板端插头，注意有字母 A 的一面向外插入，使用线夹固定好线缆，使用 H1.5 内六角螺丝刀锁入一颗螺丝固定。

![011.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-birdseye-camera-with-lighting/zh/011.png)

参照[左壳体更换指南](replace-left-shell.md)，装回左壳体。

将线缆另一头穿回上盖，注意有字母 A 的一面向外插入。

![012.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-birdseye-camera-with-lighting/zh/012.webp)

重新贴好贴纸。

![013.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-birdseye-camera-with-lighting/zh/013.webp)

### 步骤 2. 安装俯视摄像头和补光灯组件

连接俯视摄像头和补光灯组件线缆，注意有字母 A 的一面向外插入。

![014.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-birdseye-camera-with-lighting/zh/014.png)

在图示位置涂抹附送的导热硅脂。

![015.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-birdseye-camera-with-lighting/zh/015.png)

装回俯视摄像头和补光灯组件，使用 H2.0 内六角螺丝刀锁入两颗螺丝固定。

![016.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-birdseye-camera-with-lighting/zh/016.png)

## 功能验证

启动设备，连接Bambu Suite，选择一键准备功能，观察拍照效果是否正常，拍照过程中补光灯是否正常亮起。

![017.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-birdseye-camera-with-lighting/zh/017.jpg)
