## X 轴电机 X-axis Motor

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/001.png)

## 所需工具和材料

- H2.0 内六角螺丝刀
- H1.5 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除 X 轴电机

### 步骤 1. 移除第二反射镜模组组件

使用 H2.0 内六角螺丝刀移除图示四颗螺丝。

![002.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/002.png)

取下图示盖板。

![003.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/003.webp)

将组件转至一侧，漏出 X 轴电机固定螺丝。

![004.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/004.webp)

### 步骤 2. 移除 X 轴电机

释放 X 电机张紧弹簧。

![005.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/005.webp)

断开编码器连接线、电机连接线。

![006.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/006.webp)

使用 H2.0内六角螺丝移除图示黑色螺丝，取下一条地线。使用 H1.5 内六角螺丝刀移除银色螺丝，取下另一条地线。

![007.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/007.png)

使用 H2.0 内六角螺丝刀移除三颗电机固定螺丝，取下 X 轴电机。

![008.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/008.png)

## 安装 X 轴电机

### 步骤 1. 安装 X 轴电机

装回 X 轴电机，将同步带绕过电机同步轮，使用 H2.0 内六角螺丝刀拧入三颗固定螺丝，但不锁紧。

> 安装 X 轴电机时，请小心整理电机附近线缆以及弹簧，避免电机挤压到相关组件。

![009.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/009.png)

安装张紧弹簧，左右拉动几次X轴，确保张力释放后，再使用 H2.0 内六角螺丝刀锁紧图示三颗螺丝。

|  |  |
| --- | --- |
| 010.webp | 011.png |

安装编码器连接线、电机连接线。

![012.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/012.png)

使用 H2.0 内六角螺丝刀锁入一颗黑色螺丝，固定一条地线。然后使用 H1.5 内六角螺丝刀锁入一颗银色螺丝，固定另一条地线。

![013.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/013.png)

### 步骤 2. 安装第二反射镜模组组件

将第二反射镜模组组件装回原位，使用 H2.0 内六角螺丝刀锁入四颗螺丝固定。

![014.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/014.png)

装回图示盖板。

![015.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-motor/zh/015.webp)
