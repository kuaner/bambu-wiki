## X 轴皮带组件 X-axis belt

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/001.png)

X 轴皮带组件包含皮带和固定块。

## 所需工具和材料

- H2.0 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除 X 轴皮带组件

### 步骤 1. 移除第二反射镜模组组件

使用 H2.0 内六角螺丝刀移除图示四颗螺丝。

![002.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/002.png)

取下图示盖板。

![003.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/003.webp)

将组件转至一侧，漏出 X 轴电机固定螺丝。

![004.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/004.webp)

### 步骤 2. 解锁 X 轴电机

解锁 X 轴涨紧弹簧，使用H2.0螺丝刀拧松三颗螺丝，确保X电机可以滑动即可。

|  |  |
| --- | --- |
| 005.webp | 006.png |

### 步骤 3. 移除 X 轴皮带组件

将工具头从左向右移动，直到通过 X 轴后方的观察孔看到图示的四颗螺丝。

![007.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/007.webp)

使用 H2.0 内六角螺丝刀移除图示四颗螺丝，取下 X 轴同步带固定块。

![008.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/008.png)

从 X 轴电机一侧、惰轮一侧取下 X 轴皮带，移除 X 轴皮带。

|  |  |
| --- | --- |
| 009.webp | 010.webp |

## 安装 X 轴皮带组件

### 步骤 1. 安装 X 轴皮带组件

将新的 X 轴皮带穿过工具头后侧，两端分别绕过 X 轴电机同步轮和惰轮。

> 注意：穿入皮带时保持有齿一面向内，并确保皮带没有扭转。

|  |  |
| --- | --- |
| 011.webp | 012.webp |

将工具头从左向右移动，直到通过 X 轴后方的观察孔看到图示的螺丝孔。先安装下方的固定块，使用 H2.0 内六角螺丝刀锁入两颗螺丝固定。

![013.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/013.webp)

安装上方固定块，使用 H2.0 内六角螺丝刀锁入两颗螺丝刀固定。

![014.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/014.webp)

### 步骤 2. 安装 X 轴电机

装回 X 电机张紧弹簧。

![015.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/015.webp)

左右滑动几次工具头释放皮带张力，然后使用 H2.0 内六角螺丝刀锁紧三颗电机固定螺丝。

![016.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/016.png)

### 步骤 3. 安装第二反射镜模组组件

将第二反射镜模组组件装回原位，使用 H2.0 内六角螺丝刀锁入四颗螺丝固定。

![017.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/017.png)

装回图示盖板。

![018.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/018.webp)

## 功能验证

开机，在设备屏幕选择设置——校准——电机定位校准，如果校准顺利完成，则上述安装正确。

![019.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-x-axis-belt/zh/019.png)
