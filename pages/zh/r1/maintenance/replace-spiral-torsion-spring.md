## 卷簧 Spiral Torsion Spring

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/001.png)

卷簧作用为Z轴提供保持力，避免断电后Z轴下降。

## 所需工具和材料

- H2.0 内六角螺丝刀
- H1.5 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除卷簧

### 步骤 1.移除工具头前盖

使用 H1.5 内六角螺丝刀拆卸图示两颗螺丝。

|  |  |
| --- | --- |
| 002.jpg | 003.jpg |

取下工具头前盖。

![004.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/004.webp)

### 步骤 2.移除接口板

1、2、3号插头需要先打开排线扣，然后向上抬出排线（排线有防松结构，不可直接向后暴力拔出），4号插头请小心向下拔出。接口板线缆较短，请小心操作。

![005.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/005.jpg)

打开 1 号卡扣，取出排线，断开 Type-线缆。

![006.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/006.webp)

拧下四颗螺丝，取下接口板，注意此时接口板仍然有线缆未断开。

![007.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/007.jpg)

断开接口板正面 2、3号插头，翻转TH板，断开背面两个插头。然后取下接口板。

|  |  |
| --- | --- |
| 008.webp | 009.webp |

### 步骤 3.移除TH板

使用 H1.5内六角螺丝刀拆下图示四颗螺丝。

![010.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/010.jpg)

断开 TH 板上的三个插头和一处排线。

![011.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/011.webp)

### 步骤 4.移除卷簧

将Z轴上升到极限位置，露出右侧标记螺丝，使用 H2.0 螺丝刀拧下图示螺丝。

![012.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/012.webp)

使用 H2.0 螺丝刀拧下卷簧固定螺丝，取下卷簧。

![013.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/013.jpg)

## 安装卷簧

### 步骤 1.安装卷簧

将固定螺丝穿过卷簧，使用 H2.0 内六角螺丝刀锁紧。

![014.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/014.webp)

将卷簧拉出一段距离，涂抹少量润滑油降低卷簧阻力。

> 注意：多余的润滑油请及时擦除，否则可能滴落到加工材料上影响加工效果。

![015.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/015.webp)

将镜座支架抬升到最高处，对齐卷簧末端和Z轴支架孔位，锁入一颗螺丝固定。安装完成后上下拉动Z轴检查运动是否顺畅。

![016.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/016.jpg)

### 步骤 2.安装 TH 板

将图示三个插头安装到 TH 板上。

![017.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/017.webp)

安装 TH 板，使用 H1.5 内六角螺丝刀锁入四颗螺固定。

![018.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/018.png)

### 步骤 3.安装接口板

使用 H1.5 内六角螺丝刀锁入三颗螺丝固定接口板。

![019.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/019.png)

连接接口板线缆。

| --- | --- |

### 步骤 4.安装工具头前壳

将工具头前盖装回工具头。

![022.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-spiral-torsion-spring/zh/022.jpg)

使用 H1.5 内六角螺丝刀锁入两颗螺丝固定。
