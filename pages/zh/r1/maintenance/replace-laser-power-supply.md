## 激光电源 Laser Power Supply

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/001.png)

## 所需工具和材料

- H2.0 内六角螺丝刀
- H1.5 内六角螺丝刀
- 一字螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。
>
> 在正式操作拆装前，请将设备电源开关及电源线断开，静置三分钟，等待设备完全放电后操作。

## 移除激光电源

### 步骤 1. 移除前后盖板组

参照[R1 前后盖板组更换指南](replace-front-rear-panel-set.md)移除前前后盖板组。

### 步骤 2. 移除右侧板

使用 H2.0 内六角螺丝刀拧下图示 4 颗螺丝，将右侧板向下滑出。

|  |  |
| --- | --- |
| 002.png | 003.webp |

### 步骤 2. 移除激光电源

> 操作此步骤前，请务必再次检查设备是否已经完全断电并移除电源线插头，仅关闭电源或急停开关并不能完全切断设备内电源。

移除麦拉片。

![004.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/004.webp)

拔出激光电源供电插头。

![005.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/005.webp)

使用 H2.0 内六角螺丝刀移除图示两颗螺丝，断开激光管阳极连接线。

|  |  |
| --- | --- |
| 006.png | 007.webp |

撕开图示麦拉片，断开激光管阴极连接线。

|  |  |
| --- | --- |
| 008.webp | 009.webp |

使用 H2.0 内六角螺丝刀从设备内侧移除四颗固定螺丝。

![010.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/010.png)

抽出激光电源阴极线，将激光电源向外拉出一段距离。

![011.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/011.webp)

断开电源右侧插头，抽出激光电源阳极线，撕下电源下方的胶带，移除激光电源。

![012.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/012.webp)

## 安装激光电源

### 步骤 1. 安装激光电源

使用胶带将激光电源信号线固定在图示位置。

![013.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/013.webp)

穿回激光电源阳极线和阴极线。

|  |  |
| --- | --- |
| 014.webp | 015.png |

装回激光电源，连接激光电源右侧插头。

|  |  |
| --- | --- |
| 016.webp | 017.webp |

使用 H2.0 内六角螺丝刀从设备内侧锁入四颗螺丝，固定激光电源。

![018.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/018.png)

重新粘贴激光电源麦拉片。

![019.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/019.webp)

插回激光电源供电线。

![020.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/020.png)

连接激光管阳极线。

![021.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/021.webp)

使用线卡固定阳极线。

![022.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/022.png)

使用 H2.0 内六角螺丝刀锁入两颗固定。

![023.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/023.png)

连接激光管阴极线缆，重新贴好麦拉片。

|  |  |
| --- | --- |
| 024.webp | 025.png |

> 注意：安装前请仔细检查阴极线缆护套是否安装到位，正常安装时护套边缘略微高于内部黄铜组件，如果黄铜组件外漏，则需要将护套向前拨动到位，以免后续护套出现脱落。

![026.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-power-supply/zh/026.png)

### 步骤 2. 安装右侧板

装回右侧板，使用 H2.0 内六角螺丝刀锁入 4 颗螺丝固定。

|  |  |
| --- | --- |
| 027.webp | 028.png |

### 步骤 3. 安装前后盖板组

参照[R1 前后盖板组更换指南](replace-front-rear-panel-set.md)装回前前后盖板组。

## 功能验证

启动设备，发起一次激光加工任务，激光管出光正常则上述操作正确。
