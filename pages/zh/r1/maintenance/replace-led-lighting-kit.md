## LED 灯套件 LED Lighting Kit

LED 灯包含左侧 LED 灯、右侧 LED 灯和后侧 LED 灯，请根据需要选择更换。

![sla072.png](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/sla072.png)

## 何时更换

1. LED 灯无法点亮。

## 所需工具和材料

- H2.0 内六角螺丝刀
- H1.5 内六角扳手

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

> 左侧 LED 灯、右侧 LED 灯和后侧 LED 灯均为独立组件，本文将分别展示三个 LED 灯的单独更换教程，请根据需要直接跳转到对应部分操作。

## 更换后侧 LED 灯

### 步骤 1.移除激光管盖板

请参照[前后盖板组更换指南](replace-front-rear-panel-set.md)移除前后盖板组。

### 步骤 2.移除左壳体

请参照[左壳体更换指南](replace-left-shell.md)移除左壳体（无需移除左侧上盖）。

### 步骤 3.移除后侧 LED 灯

断开主板上后侧 LED 灯插头，打开理线扣，取出线缆。

![1.webp](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/1.webp)

后侧 LED 灯位于图示框架下侧，撕下固定胶带，将线缆从激光管一侧拉出。

|  |  |
| --- | --- |
| 2.png | 3.webp |

沿着线缆将后侧 LED 灯完全撕下。

![4.webp](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/4.webp)

### 步骤 4.安装后侧 LED 灯

取出新的后侧 LED 灯，撕下背胶保护膜，粘贴到原位置。

|  |  |
| --- | --- |
| 5.png | 6.webp |

穿回 LED 灯连接线，并使用胶带固定好线缆。

|  |  |
| --- | --- |
| 7.webp | 8.webp |

![9.webp](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/9.webp)

> **⚠️ 注意**：请务必按照图示虚线轨迹固定好线缆，下图箭头指示为激光光路通过孔，**禁止遮挡**。  
> ![](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/10.png)

> **❗ 警示**：整个图示光路上禁止有任何异物遮挡，否则可能导致严重的安全风险。  
> ![](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/11.png)

连接主板侧插头，固定好后侧 LED 灯线缆。

![12.webp](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/12.webp)

### 步骤 5.安装左壳体

请参照[左壳体更换指南](replace-left-shell.md)装回左壳体。

### 步骤 6.安装前后盖板组

请参照[前后盖板组更换指南](replace-front-rear-panel-set.md)装回前后盖板组。

## 更换左侧 LED 灯

### 步骤 1.移除前后盖板组

请参照[前后盖板组更换指南](replace-front-rear-panel-set.md)移除前后盖板组。

### 步骤 2.移除左壳体

请参照[左壳体更换指南](replace-left-shell.md)移除左壳体，无需移除左侧上盖。

### 步骤 3.移除左侧 LED 灯

从设备内侧直接撕下左侧 LED 灯

![13.webp](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/13.webp)

断开主板端插头，撕下固定线缆的胶带，将灯带直接拉出。

![14.webp](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/14.webp)

### 步骤 4.安装左侧 LED 灯

将新的左侧 LED 灯穿入安装孔，连接主板侧插头，并使用胶带固定好线缆。

![15.webp](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/15.webp)

撕下 LED 灯背胶，将左侧 LED 灯粘贴到原位。

|  |  |
| --- | --- |
| 16.png | 17.png |

### 步骤 5.安装左壳体

请参照[左壳体更换指南](replace-left-shell.md)装回左壳体。

### 步骤 6.安装前后盖板组

请参照[前后盖板组更换指南](replace-front-rear-panel-set.md)装回前后盖板组。

## 更换右侧 LED 灯

### 步骤 1.移除前后盖板组

请参照[前后盖板组更换指南](replace-front-rear-panel-set.md)移除前后盖板组。

### 步骤 2.移除右侧板

参照[右壳体更换指南](replace-right-shell.md)移除右壳体，无需移除右壳体支架。

### 步骤 3.移除右侧 LED 灯

断开 LED 灯插头，撕下固定线缆的胶带，然后撕下旧 LED 灯。

![18.webp](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/18.webp)

取出新的右侧 LED 灯，撕下背胶保护膜，粘贴在原位置。

![19.png](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/19.png)

连接 LED 灯插头，并使用胶带固定好线缆。

![20.png](https://wiki.bambulab.com/r1/maintenance/replace-led-lighting-kit/20.png)

### 步骤 4.移除右侧板

请参照[右壳体更换指南](replace-right-shell.md)装回右壳体。

### 步骤 5.移除前后盖板组

请参照[前后盖板组更换指南](replace-front-rear-panel-set.md)装回前后盖板组。

### 功能验证

连接电源，开机后三个 LED 灯会均自动亮起，也可以通过 设置——设备控制——灯光 页面手动控制，若更换后的 LED 灯正常亮起则上述安装正确。
