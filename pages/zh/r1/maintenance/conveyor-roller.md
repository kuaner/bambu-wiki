## 介绍

长时间送料过程中，板材表面的碎屑以及加工过程中产生的碎屑会逐渐堆积在送料滚轮周围，从而影响送料的顺畅性和精度。此外，压紧滚轮的丝杆和送料滚轮的金属钢轴也需要定期保养，以确保设备稳定运行。设备内已设定维护提醒的时间阈值，当送料滚轮累计使用超过一定时间后，设备健康页面将显示相应的维护提醒。

## 需要使用的工具

- H2.0/1.5 内六角螺丝刀
- 润滑脂
- 清洁湿巾
- 毛刷

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 维护步骤

首先参考[压紧滚轮横梁组件更换指南](https://wiki.bambulab.com/zh/r1/maintenance/replace-conveyor-pinch-roller-mount)关机后将 R1 从增高架上抬下，再将送料滚轮组件从增高架上拆下。

### 张紧压紧滚轮同步带

拧松同步带的 3 颗张紧螺丝。

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/conveyor-roller/zh/001.png)

转动手轮，确保同步带未被卡住。

![002.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/conveyor-roller/zh/002.webp)

重新拧紧张紧螺丝。

![003.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/conveyor-roller/zh/003.png)

### 润滑压紧滚轮丝杆

转动手轮，观察压紧杆下移后，在丝杆上涂抹适量润滑脂。

|  |  |
| --- | --- |
| 004.jpg | 005.jpg |

在转动手轮，直到压紧杆回到最上侧。

![006.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/conveyor-roller/zh/006.webp)

### 清理摩擦送料滚轮

一只手推动/固定滚轮，另一只手使用毛刷清理滚轮上残留的碎屑。

|  |  |
| --- | --- |
| 007.webp | 008.webp |

### 擦拭钢棒

钢棒表面可使用清洁湿巾擦拭，避免脏污附着。

![009.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/conveyor-roller/zh/009.webp)

### 擦拭红外传感器

使用纸巾轻轻擦除红外传感器上的碎屑，存在异物或者遮挡会影响红外传感器工作。
