## 光路校准传感器排线 Laser Alignment Sensor FPC

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-alignment-sensor-fpc/zh/001.png)

用于连接光路校准传感器和 TH 板。

## 何时更换

1. 光路校准传感器排线破损。
2. 排线触点失效。

## 所需工具和材料

- H1.5 内六角螺丝刀
- H2.0 内六角螺丝刀

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除光路校准传感器排线/三反组件

### 步骤 1.移除工具头前盖

使用 H1.5 内六角螺丝刀拆卸两颗螺丝，取下工具头前盖。

|  |  |
| --- | --- |
| 002.jpg | 003.jpg |
| 004.webp |

### 步骤 2.移除光路校准传感器排线

断开TH板上光路校准器排线。

![005.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-alignment-sensor-fpc/zh/005.webp)

使用 H1.5 内六角螺丝刀拧下三颗螺丝，取下盖板。

![006.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-alignment-sensor-fpc/zh/006.png)

使用十字螺丝刀拧下两颗排线固定螺丝，将光路校准传感器排线撕下。

|  |  |
| --- | --- |
| 007.png | 008.png |

## 安装光路校准传感器排线/三反组件

### 步骤 1.安装光路校准传感器排线

将光路校准传感器排线装回，贴好排线，使用十字螺丝刀锁入两颗螺丝固定。

|  |  |
| --- | --- |
| 009.webp | 010.png |

装回盖板，使用 H1.5 内六角螺丝刀锁入三颗螺丝固定。

![011.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-alignment-sensor-fpc/zh/011.png)

### 步骤 2.安装工具头前盖

将工具头前盖装回工具头。

![012.jpg](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-laser-alignment-sensor-fpc/zh/012.jpg)

使用 H1.5 内六角螺丝刀锁入两颗螺丝固定。

## 功能验证

参照[光路校准](../manual/laser-alignment-guide.md)教程，运行一次光路校准操作，如果校准正常完成则上述安装正确。
