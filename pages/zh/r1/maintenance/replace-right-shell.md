## 右壳体

右壳体包括三部分：右侧板、右侧上盖（含屏幕组件）、右壳体支架，请根据需要选择对应的部分更换。  
![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/001.png)

## 何时更换

1. 屏幕显示异常。
2. 右壳体损坏。
3. 急停开关损坏。

## 所需工具和材料

- H2.0 内六角螺丝刀
- H1.5 内六角扳手

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。
>
> 触碰急停开关连接线前请务再次检查设备后方电源输入插头是否已经完全断开，仅关闭急停开关并不能完全切断设备电源。

## 移除右侧板

### 步骤 1. 移除前后盖板组

参照[R1 前后盖板组更换指南](replace-front-rear-panel-set.md)移除前后盖板组。

### 步骤 2. 移除右侧板

使用 H2.0 内六角螺丝刀拧下图示 4 颗螺丝，将右侧板向下滑出。

|  |  |
| --- | --- |
| 002.png | 003.webp |

> 如果仅需要更换右侧板，则可以跳转到右侧板安装步骤。

## 移除右侧上盖

### 步骤 1. 断开按键板排线

使用 H1.5 内六角螺丝刀移除三颗螺丝，取下按键板排线压块。

|  |  |
| --- | --- |
| 004.png | 005.webp |

### 步骤 2. 移除右侧上盖

使用 H2.0 内六角螺丝刀移除图示 3 颗螺丝。

![006.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/006.png)

使用 H2.0 内六角螺丝刀从设备内侧移除图示 3 颗螺丝。

![007.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/007.png)

使用 H2.0 内六角螺丝刀从激光管右侧移除 2 颗螺丝。

![008.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/008.png)

使用 H2.0 内六角螺丝刀从前侧移除 1 颗螺丝。

![009.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/009.png)

按下插头卡扣断开急停开关连接线。

> 触碰急停开关连接线前请务再次检查设备后方电源输入插头是否已经完全断开，仅关闭急停开关并不能完全切断设备电源。

![010.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/010.webp)

移除右侧上盖。

![011.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/011.webp)

## 移除右壳体支架

### 步骤 1. 移除右壳体支架

> 右壳体支架如无损坏可跳过此步骤。

使用 H2.0 内六角螺丝刀移除图示 4 颗螺丝，取下右壳体支架。

![012.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/012.png)

## 安装右壳体支架

### 步骤 1. 安装右壳体支架

装回右壳体支架，使用 H2.0 内六角螺丝刀锁入图示 4 颗螺丝。

![013.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/013.png)

## 安装右侧上盖

### 步骤 1. 移除左壳体

参照[左壳体更换指南](replace-left-shell.md)移除左壳体（无需移除左侧上盖）。

### 步骤 2. 安装按键板排线

断开主板侧按键板排线，并撕下固定胶带。

![014.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/014.webp)

将右侧的按键板排线撕下，并拉出一段距离，方便后续安装。

![015.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/015.webp)

> 注意：拉出排线时，请勿将左侧排线完全拉入框架内，以免影响后续安装。

![016.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/016.webp)

连接屏幕排线，安装压片并使用 H1.5 内六角螺丝刀锁入三颗螺丝固定。

|  |  |
| --- | --- |
| 017.webp | 018.png |

装回右侧上盖，连接急停开关插头。

> 急停开关的两个插头完全相同，安装时无顺序要求。

|  |  |
| --- | --- |
| 019.webp | 020.png |

将右侧按键板排线重新贴好。

![021.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/021.webp)

插回左侧按键板排线插头，并使用胶带重新固定。

![022.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/022.webp)

### 步骤 3. 装回左壳体

参照[左壳体更换指南](replace-left-shell.md)重新装回左壳体。

### 步骤 4. 装回右侧上盖

使用 H2.0 内六角螺丝刀锁入图示 3 颗螺丝。

![023.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/023.png)

使用 H2.0 内六角螺丝刀从设备内侧锁入图示 3 颗螺丝。

![024.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/024.png)

使用 H2.0 内六角螺丝刀锁入图示 2 颗螺丝。

![025.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/025.png)

使用 H2.0 内六角螺丝刀从设备前侧锁入 1 颗螺丝。

![026.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-right-shell/zh/026.png)

## 安装右侧板

### 步骤 1. 安装右侧板

装回右侧板，使用 H2.0 内六角螺丝刀锁入 4 颗螺丝固定。

|  |  |
| --- | --- |
| 027.webp | 028.png |

### 步骤 2. 安装前后盖板组

参照[R1 前后盖板组更换指南](replace-front-rear-panel-set.md)装回前前后盖板组。
