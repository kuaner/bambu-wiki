## 增高底座 前后门 Riser Base Front & Rear Panels

增高底座前后门包含增高底座前门和后门两部分，请根据需要，选择对应的步骤更换。

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/001.png)

## 何时更换

1. 前后门出现变形、破损。
2. 前后门无法正常开合。

## 所需工具和材料

- H2.0 内六角螺丝刀

## 安全提示

> 在对设备及其电子设备（包括相关线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 移除增高底座前门

### 步骤 1. 移除增高底座前门

扣住两侧解锁拉手，打开增高底座前门。

![002.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/002.webp)

使用 H2.0 内六角螺丝刀移除 6 颗螺丝，取下前门组件。

|  |  |
| --- | --- |
| 003.png | 004.webp |

## 安装增高底座前门

### 步骤 1. 安装增高底座前门

装回增高底座前门，使用 H2.0 内六角螺丝刀锁入 6 颗螺丝固定。

|  |  |
| --- | --- |
| 005.webp | 006.png |

合上增高底座前门。

![007.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/007.webp)

## 移除增高底座后门

### 步骤 1. 分离 R1 激光切割机

关闭主机电源，移除主机电源线。

|  |  |
| --- | --- |
| 008.png | 009.png |

扣住增高底座前门两边的门锁，向外打开前门，并取出托盘。

|  |  |
| --- | --- |
| 010.png | 011.png |

打开主机上盖，移除增高底座的 8-pin 连接线。

![012.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/012.png)

两人合力搬下主机。搬运时，**确保手掌中心对准主机两侧的对位标记**。避免将手掌完全伸入主机底部或抓握靠后的凹槽，以免夹伤。

|  |  |
| --- | --- |
| 027.png |  |

两人合力，翻转增高底座。请从增高底座的**两侧**抓握，避免拉扯前门，以免夹伤。

|  |  |
| --- | --- |
| 014.png | 015.png |

### 步骤 2. 移除增高底座前门组件

使用 H2.0 内六角螺丝刀，移除 6 颗螺丝。

![016.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/016.png)

向内扣住前门门锁，抬起前门和底板，并将其折叠放好。

![017.gif](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/017.gif)

### 步骤 3. 移除后侧组件

断开后侧组件的两端的排线。

|  |  |
| --- | --- |
| 左侧：两根排线 | 右侧：一根排线 |

使用 H2.0 内六角螺丝刀，从后侧组件两侧的螺丝拧下 8 颗螺丝。

|  |  |
| --- | --- |
| 020.png | 021.png |

轻轻抬起后侧组件，将左侧组件、右侧组件取下。

![022.gif](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/022.gif)

### 步骤 4. 移除增高底座后门

使用 H2.0 内六角螺丝刀从后侧组件下后方移除 5 颗螺丝。

![023.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/023.png)

打开增高底座后门。

![024.webp](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/024.webp)

使用 H2.0 内六角螺丝刀移除 3 颗螺丝，移除增高底座后门。

![025.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/025.png)

## 安装增高底座后门

### 步骤 1. 安装增高底座后门

装回增高底座后门，使用 H2.0 内六角螺丝刀锁入 8 颗螺丝固定。

|  |  |
| --- | --- |
| 026.png | 027.png |

### 步骤 2. 安装后侧组件

装回左侧组件、右侧组件，使用 H2.0 内六角螺丝刀锁入 8 颗螺丝固定。

|  |  |
| --- | --- |
| 028.png | 029.png |

分别连接后侧组件与左侧组件、右侧组件的排线。

|  |  |
| --- | --- |
| 左侧：两根排线 | 右侧：一根排线 |

### 步骤 3. 安装前门组件

展开前门组件，对齐底板定位孔。

|  |  |
| --- | --- |
| 030.png | 031.gif |

使用 H2.0 内六角螺丝刀锁入 6 颗螺丝。

![032.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/032.png)

### 步骤 4. 装回 R1 激光切割机

两人合力翻转并摆正增高底座，确保**前门朝向外侧（与日常使用方位相同）**。

> 注意：翻转时，请从增高底座**两侧**抓握，避免拉扯前门，以免夹伤。

|  |  |
| --- | --- |
| 027.png | 028.png |

两人合力将主机搬回增高底座。搬运时，**确保手掌中心对准主机两侧的对位标记**。避免将手掌完全伸入主机底部或抓握靠后的凹槽，以免夹伤。

|  |  |
| --- | --- |
| 027.png |  |

打开主机上盖，连接好增高底座与主机的 8-pin 连接线。

![034.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/034.png)

装回托盘，合上前门。

![035.png](https://public-cdn.bblmw.com/wiki/new/r1/maintenance/replace-riser-base-front-rear-panels/zh/035.png)
