> **危险**  
> 使用产品前，务必阅读激光使用安全相关文档，并按照《快速入门指南》或《[开箱指南](unboxing.md)》完成必要的初始安装和设置。

> **说明**  
> 为优化用户体验，部分图示可能更新，请以实际为准。

## 加工流程概览

1. 按照快速入门指南完成安装、注水和校准流程，首次使用时需在屏幕的校准页进行**光路校准和振动补偿**；
2. **放置待加工的材料**，在 Bambu Suite 中**新建项目**并设置工艺类型，完成**一键准备**后发起**制作**；
3. 按下机身的启停按钮，**开启加工任务**。等待加工完成后，取出作品并**清理托盘**内的碎屑。

## 工具准备

- **自备工具**：电脑（提前下载并安装 Bambu Suite）、清洁刷或清洁布；
- **随附配件**：光路校准传感器、椴木胶合板、材料固定夹、H2.0 内六角扳手。

## 步骤 1：进行光路校准

- 在产品屏幕上，点击 **设置** > **校准** > **自动光路校准**。

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/first-setup-guide/zh/001.png)

- 根据提示，打开工具头舱盖，将光路校准传感器吸附在顶部，然后关闭激光防护上盖。

|  |  |
| --- | --- |
| 002.png | 003.png |

- 回到产品屏幕，点击 **开始**，并按下启停按钮以发起校准任务。
- 等待校准完成，取下传感器并放回收纳盒。

## 步骤 2：放置材料

> **提示**  
> 推荐使用官方材料，支持自动识别材料类型，且对应加工参数已经过测试优化。

- 打开激光防护上盖，将随附的**椴木胶合板**放置在支撑刀条上，确保带有二维码的一面朝上。

![004.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/first-setup-guide/zh/004.png)

- 若加工材料发生翘曲，需使用材料固定夹固定。首先，**将材料固定夹卡入刀条的底部**。

![005.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/first-setup-guide/zh/005.gif)

- 适当移动木板，让翘曲位置覆盖在固定夹内，并**确保材料边缘与固定夹内侧贴合**。向下按压固定夹，直到完全压紧。

![006.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/first-setup-guide/zh/006.gif)

- 使用轻薄的材料时，可以**向上推动**两侧的手柄，同时按压顶部压块，以更好地压紧材料。

![007.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/first-setup-guide/zh/007.gif)

## 步骤 3：新建任务

> **说明**
>
> 1. 本篇文档中的软件截图以 **Windows 系统**为主。
> 2. 首次使用时，推荐根据**项目引导**成示例项目，以便快速熟悉软件和加工流程。

### 新建项目

- 在 Bambu Suite 主页，点击**新建项目**，并连接设备。

|  |  |
| --- | --- |
|  |  |

- 进入**新手项目引导**\*。点击**开始**，导入激光示例项目。

|  |  |
| --- | --- |
|  |  |

> **提示**  
> 日常使用时，您可随时通过项目引导图标，再次进入引导流程。

### 选择工艺类型

- 选择画布中的对象，并设置**工艺类型**。请根据引导，将指定的对象设置为**激光线条切割**。

|  |  |
| --- | --- |
|  |  |

### 绑定待加工对象

- 进入对象列表，选中并**绑定**所有待加工对象，点击**准备制作**。

|  |  |
| --- | --- |
|  |  |

## 步骤 4：发送任务

### 选择加工模式

- 根据材料外观，选择对应的加工模式。示例项目中，请为椴木板选择**平面加工模式**。

![](https://public-cdn.bblmw.com/wiki/new/r1/manual/first-setup-guide/zh/016.png)

### 一键准备

> **提示**  
> 完成**一键准备**后，请勿移动机箱内的材料。若位置有移动，请重新一键准备后再继续操作。

- 点击**一键准备**，产品会自动拍照并测量物体表面。完成后，界面会出现加工区域背景图像和距离测量值。

|  |  |
| --- | --- |
|  |  |

- 如果使用的是带有二维码的官方材料，则机器会自动识别材料类型。如使用非官方材料，选择或新建材料，并在正式加工前测试加工参数。

![](https://public-cdn.bblmw.com/wiki/new/r1/manual/first-setup-guide/zh/019.png)

> **说明**
>
> - 部分加工材料（如亚克力）带保护膜，在开始加工前需移除；
> - 使用非官方材料时，请确认本产品支持该类型的耗材后，再继续下一步操作。

### 调整对象并制作

- 选中对象，用鼠标拖动外框，可对图案进行**等比例缩放**。

> **提示**  
> 使用示例项目时，图案已为最佳尺寸，无需进行调整。

- 使用**自动摆盘**，将对象放置在合适的区域。**您也可以自由拖动对象，使其放置在想要加工的位置。**

|  |  |
| --- | --- |
|  |  |

- 完成后，请点击**制作**，将加工任务发送到产品。

![](https://public-cdn.bblmw.com/wiki/new/r1/manual/first-setup-guide/zh/022.png)

### 开始任务

> **注意**  
> 开始加工前，确保产品的排烟管末端已放置在室外，或已接入官方激光专用净化器（请在 [E1 Pro 净化器安装使用指南](air-purifier-unboxing.md) 查看连接方式）。

> **危险**  
> 产品运行期间，请始终确保本产品处于有人现场看管的状态。加工时，请勿透过机箱长时间直视激光。

- 关闭产品的防护上盖，按下**启停按钮**，产品将开始加工。您可在产品屏幕或 Suite 界面查看任务进度和剩余时间。

## 步骤 5：完成加工

### 取出作品

- 加工完成后，会预留一定的排烟时间，请等待排烟结束再打开防护上盖。

![025.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/first-setup-guide/zh/025.png)

- 若使用材料固定夹，向下推动固定夹两侧的手柄，即可释放材料。

![026.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/first-setup-guide/zh/026.png)

### 清理托盘

- 首次使用时，请使用 H2.0 内六角扳手，拧下托盘两侧的运输螺丝（共 4 颗），即可取出托盘。

|  |  |
| --- | --- |
| 027.png | 028.png |

- 每次加工任务完成后，请及时清理托盘内的残渣，以免堆积过多造成安全隐患。

| --- | --- |
| 029.png | 030.png |
