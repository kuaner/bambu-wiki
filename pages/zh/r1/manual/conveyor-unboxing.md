> **说明**
>
> - **滚轮送料机需安装在增高底座上。开始前，请确保[已完成增高底座的组装](riser-base-unboxing.md)**；
> - 为保障您顺畅的退换货权益，建议您保留所有包装材料至少 30 天；
> - 包材、配件可能会不定时更新，请以收到的版本为准，更新详情见操作步骤。

## 流程概览

1. 移除包装，取出配件。并打开增高底座的前门上半部分、中门和后门；
2. 依次安装支撑滚轮组件、挡烟帘支架和送料滚轮组件；
3. 将主机放置回增高底座，连接电源并发起校准；
4. 使用送料机加工材料前，需安装前、后两对导轨组件。

|  |  |

- 取出配件盒内的工具和组件。

### 安装前准备

> **提示**  
> 确保在使用位置（主机和增高底座）的前、后方各预留至少 550 mm 的安装空间，加工所需空间请查看 [R1 滚轮送料加工指南](https://bambulab.feishu.cn/docx/WjM2dk7DLo5og7xBVkjcLtVzn7g)中的说明。

> **说明**  
> 安装本产品前，需将增高底座提前组装好。**确保主机端的 8-pin 连接线和电源线已断开**，并将主机从增高底座上抬下。

- 打开增高底座的前门上部分、中门和后门，以便安装本产品。

![008.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/008.gif)

### 安装支撑滚轮组件

- 将组件紧贴**增高底座前门内侧**放入，前后推动，使组件卡入槽位。

|  |  |
| --- | --- |
| 009.png | 010.png |

> **注意**  
> 放置时，**小心不要碰到侧边的火焰传感器（红色圆圈处）**，以免划伤表面。

- 取出 2 颗螺丝 (M4×22mm)。将螺丝放入左侧的孔位，并使用 H2.0 内六角扳手拧紧。

|  |  |
| --- | --- |
| 011.png | 012.png |

- 重复操作，将螺丝放入右侧的两个孔位并拧紧。

![013.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/013.png)

- 轻轻摇晃组件，确认无松动。

![014.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/014.gif)

- 将组件**内嵌的 4-pin 连接线**插入增高底座的 4-pin 连接口，并将线缆收纳至侧边的线扣。

![015.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/015.png)

| 016.png | 017.png |

- 取出 2 颗螺丝 (M3×8 mm)。将螺丝放入右侧的孔位，并使用 H2.0 内六角扳手拧紧。

![018.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/018.png)

- 重复操作，将螺丝放入左侧的两个孔位并拧紧。

![019.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/019.png)

## 连接主机并校准

### 放置主机

> **注意**  
> 确保手部对准主机的对位标记后再搬运，避免使用靠后的凹槽，以防夹伤。

- 提前确认主机两侧的对位标记。**搬运时，对位标记应位于手掌中间，并避免手掌完全伸入主机底部。**

![030.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/030.png)

- 两人合力抬起主机，确保主机脚垫对准增高底座顶部的孔位，将主机放置在底座上。

|  |  |
| --- | --- |
| 031.png | 032.png |

- 取出遮光胶垫，移除背胶。

![033.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/033.png)

- 对齐主机底部的凹槽，将胶垫粘贴在图示位置。

![034.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/034.gif)

- 找到挡烟帘支架顶部中间的磁铁。轻轻向上推动支架，使磁铁吸附在主机底部。

|  |  |
| --- | --- |
| 035.png | 036.png |

- 打开主机上盖，将增高底座的 8-pin 连接线收纳回线扣，并将其插入主机的 8-pin 连接口。

|  |  |
| --- | --- |
| 037.png | 038.png |

### 发起校准

- 连接主机电源线，并打开电源开关。
- 确认主机屏幕是否正常显示**滚轮送料机**和**增高底座**的图标。

![039.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/039.png)

- 在主机屏幕点击 **设置 > 校准 > 滚轮送料系统**，根据屏幕提示操作，等待校准完成。

![040.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/040.png)

- 如果提示“加工物上边缘探测器脏污或存在异物，请及时清理。确保遮光胶布正确贴合后，重新执行滚轮送料校准。”错误，请检查是否已正确在粘贴遮光胶垫。

## 组装导轨

### 组装前导轨组件

- 取出任意一对导轨和导轨支架，找到导轨的 **FRONT** 标识。

![043.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/043.png)

- 将导轨支架的凸起部位卡入 **FRONT** 处的方形孔，然后放平。

|  |  |
| --- | --- |
| 044.png | 045.png |

- 取出 1 颗螺丝 (M3×18mm)。将螺丝放入导轨支架的孔位，并使用 H2.0 内六角扳手拧紧。

![046.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/046.png)

- 重复操作，完成另一对前导轨组件的装配。
- 查看导轨前部，拧松螺栓，**直到与顶部平齐**。

|  |  |
| --- | --- |
| 047.png | 048.png |

- 确保增高底座的前门上半部分已打开，将导轨组件卡入支撑滚轮右侧的凹槽，并沿槽位滑入。

![049.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/049.gif)

- 拧紧导轨前部的螺栓即可固定。

![050.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/050.png)

- 重复操作，将另一对前导轨组件从左侧滑入，并拧紧螺栓固定。

|  |  |
| --- | --- |
| 051.png | 052.png |

### 组装后导轨组件

- 将导轨支架卡入 **BACK** 处的方形孔，并用螺丝（M3×18mm）锁紧。

|  |  |
| --- | --- |
| 053.png | 054.png |

- 重复操作，组装另一对**后导轨组件**，并将两对导轨前部的螺栓拧至平齐位置。

![055.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/055.png)

- 绕至主机后部，确保后门已打开。

![056.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-unboxing/zh/056.png)

- 将两对后导轨组件**全部从送料滚轮的右侧凹槽**滑入，拧紧前部的螺栓即可固定。

|  |  |
| --- | --- |
| 057.png | 058.png |

- 完成安装后，可根据加工板材的实际宽度调整导轨。**确保前后导轨在同一条直线上，且相对主机左右对称**，以免宽度不均导致支撑不足。
