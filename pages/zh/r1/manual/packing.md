## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲材料是否放置到位**，充分保护设备。

## 所需工具

原包装（及内附的缓冲材料、固定件和运输螺丝等）、运输扎带、运输胶带、剪刀、H2.0 内六角扳手（随附）、盛水容器。

## 操作步骤

### 1. 关闭电源

- 关闭电源开关，移除电源线。

|  |  |
| --- | --- |
| 001.png | 002.png |

### 2. 移除排烟风扇和排烟管

- 从风扇出风口取下排烟管。

![003.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/003.png)

- 顺时针旋转，解锁风扇。

![004.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/004.gif)

- 捏住 4-pin 连接线底部凸出的弹片，即可拔出线缆。

|  |  |
| --- | --- |
| 005.png | 006.png |

### 3. 排空水箱

> **提示**  
> 如果您从未进行过任何注水操作，可跳过本步骤。

> **注意**  
> 移除水管前，请勿提前拔出注水口塞子，以免排水时撒漏。

- 使用H2.0内六角扳手，拧下风扇安装口的 **4** 颗螺丝。请妥善保存螺丝，排水完成后仍需装回。

![007.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/007.png)

- 小心取下安装口面板，放置在桌面上。

|  |  |
| --- | --- |
| 008.png | 009.png |

- 轻轻捏住水管顶部，将其从卡扣中取下。

![010.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/010.gif)

- 提前准备盛水的容器。**依序**拔下水管塞子以及注水口塞子，等待水箱内的液体流尽。

|  |  |
| --- | --- |
| 011.png | 012.png |

- 等待水箱里的冷却液流尽后，**将水管塞子和注水口塞子放回**，并将水管卡回原位。

|  |  |
| --- | --- |
| 013.png | 014.png |

- 放回安装口面板，并拧回 **4** 颗固定螺丝。

|  |  |
| --- | --- |
| 015.png | 016.png |

### 4. 复位固定件

- 将 Y 轴推回机箱最内侧。

![017.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/017.gif)

- 取出 Y 轴运输固定件，放入运输螺丝，将固定件卡入 Y 轴左侧并拧紧螺丝。

|  |  |
| --- | --- |
| 018.png | 019.png |

- 重复操作，放回 Y 轴右侧的固定件并拧紧螺丝。

![020.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/020.png)

- 卡入工具头固定件，然后将工具头移动至固定孔位前方。

![021.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/021.gif)

- 拧入 6 颗运输螺丝并锁紧。

![022.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/022.png)

### 5. 固定托盘

- 若之前已移除托盘四周的 L 型运输固定件，请在装箱时将运输螺丝和固定件放回并拧紧。

|  |  |
| --- | --- |
| 023.png | 024.png |

### 6. 打包配件盒

- 将配件放回配件盒中，使用纸卡固定好，然后合上配件盒。

|  |  |
| --- | --- |
| 025.png | 026.png |

- 将缓冲材料放回机箱内部，整理好贴合机箱两侧。

![027.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/027.png)

- 放回配件盒和缓冲材料。

|  |  |
| --- | --- |
| 028.png | 029.png |

- 关闭防护上盖。

![030.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/030.png)

- 将主机套入防潮袋，并使用胶带贴住封口。

![031.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/031.png)

### 7. 放回主机并封箱

- 提前准备好运输外箱，垫入纸卡，然后**将缓冲材料按图示位置放好**。

|  |  |
| --- | --- |
| 032.png | 033.png |

- 两人合力将产品抬回外箱，确保与四周的缓冲材料贴合。

![034.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/034.png)

- 放入前部的缓冲泡棉。

![035.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/035.png)

- 放入顶部的缓冲材料（和随附材料）。

![036.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/036.png)

- 放入纸卡，并将两侧的缓冲泡棉放好并整理贴合。

|  |  |
| --- | --- |
| 037.png | 038.png |

- 套回外箱，缓缓**向下按压至贴合**。

|  |  |
| --- | --- |
| 039.gif | 040.png |

- 将前、后部的卡扣放回并压实。

|  |  |
| --- | --- |
| 041.png | 042.png |

- 用运输胶带或扎带封住外箱，确保牢固无松动。

![043.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/packing/zh/043.png)
