> **提示**
>

- 右侧组件

## 组装底座

### 准备步骤

- 打开主机上盖，移除托盘**两侧的运输螺丝和 L 型固定件。**

|  |  |
| --- | --- |
| 002.png | 003.png |

- 将托盘从主机底部取出。

![004.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/004.png)

### 移除外包装

- 打开外箱，取出快速入门指南，并移除顶部的缓冲材料。

![005.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/005.png)

- 取下前门组件（D），并将剩余的组件和配件盒全部取出。

|  |  |
| --- | --- |
| 006.png | 007.png |

- 移除组件外部的纸卡和防潮袋，并将配件盒内的物品取出备用。

|  |  |
| --- | --- |
| 008.png | 009.png |

### 组装右侧组件（B）

- 取出右侧组件（B）和后侧组件（C），移除后侧组件内的泡沫。

|  |  |
| --- | --- |
| 010.png | 011.png |

- 对准右侧组件的安装面，向下放入后侧组件。

![012.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/012.png)

- 将 **4** 颗螺丝拧入图示孔位（约一半处），**确保所有螺丝可顺利旋入后**，**再全部锁紧**。

![013.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/013.png)

- 将安装好的组件平躺放置，**确保脚垫朝上**。

![014.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/014.png)

### 组装左侧组件（A）

- 取出左侧组件（A）。

![015.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/015.png)

- 对准左侧组件的安装面，将安装好的后侧组件**轻轻抬起并卡入**。

|  |  |
| --- | --- |
| 016.png | 017.png |

- 拧入 **4** 颗螺丝（约一半处），**确保所有螺丝可顺利旋入后**，**再全部锁紧**。

![018.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/018.png)

### 组装前门组件（D）

- 取出前门组件（D）。

![019.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/019.png)

- 展开前门组件，将**底板部分**平铺在安装好的组件上。

![020.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/020.png)

- 轻轻移动前门组件，让两侧的定位孔顺利卡入。**向下按压底板，确保定位孔卡入到位。**

![021.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/021.gif)

- 对照图示孔位，将 6 颗螺丝**依次拧入并锁紧**。

![022.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/022.png)

> **提示**  
> 如部分螺丝无法拧入，可以略微拧松后侧组件与左、右侧组件的螺丝（约一两圈），然后进行组装。完成后，需将拧松的螺丝重新锁紧。

### 连接通讯线

> **注意**
>
> - 接线前，务必对准连接线和接口的位置和方向，避免扯坏。
> - 因出货版本差异，固定胶布的颜色和材质可能变更，请以实物为准。

- 找到后侧组件**右边**的通讯连接线，撕开固定胶布，将其插入右侧组件的对应接口。

|  |  |
| --- | --- |
| 023.png | 024.png |

- 重复操作，将**左边**的两条连接线插入左侧组件的对应接口。

|  |  |
| --- | --- |
| 025.png | 026.png |

### 翻转增高底座

- 翻转组装好的组件，确保**前门朝向外侧（与日常使用方位相同）**。

|  |  |
| --- | --- |
| 027.png | 028.png |

> **注意**  
> 搬动时，请从**两侧**抓握，并避免拉扯前门，以防夹伤。

### 插入 8-pin 连接线

- 取出 8-pin 连接线，将任意一端插入增高底座的 **8-pin 连接口**。

|  |  |
| --- | --- |
| 029.png | 030.png |

- 将线缆收纳至侧边的线扣。

![031.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/031.gif)

> **提示**  
> 如购买滚轮送料机，可在本步骤之后开始安装。

## 连接主机

### 放置主机

- 提前确认主机两侧的对位标记。**搬运时，对位标记应位于手掌中间，并避免手掌完全伸入主机底部。**

![032.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/032.png)

> **注意**  
> 确保手部对准主机的对位标记后再搬运，避免使用靠后的凹槽，以防夹伤。

- 两人合力抬起主机，确保主机脚垫对准增高底座顶部的孔位，将主机放置在底座上。

|  |  |
| --- | --- |
| 033.png | 034.png |

- 打开主机上盖。
- 掀开 8-pin 连接口的防尘塞，将 **8-pin 连接线的另一端**插入连接口。

|  |  |
| --- | --- |
| 035.png | 036.png |

### 放入托盘

- 用手指扣住增高底座前门两边的门锁，并向内推动，以解锁前门。

|  |  |
| --- | --- |
| 037.png | 038.png |

- 将托盘放置至增高底座的任意一个托盘架，然后合上前门。

![039.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/039.png)

### 连接电源

- 连接主机电源线，并打开电源开关。

|  |  |
| --- | --- |
| 040.png | 041.png |

- 确认主页出现**增高底座图标**后，即为连接成功。

![039.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-unboxing/zh/042.png)
