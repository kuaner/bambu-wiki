## 加工模式概述

R1 打印机共支持五种加工模式，可在 Bambu Suite “准备”页面右侧栏的“模式”中选择不同的加工模式。

![mode-cn.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/laser-processing-mode-guide/zh/mode-cn.png)

## 各模式详解

> 注：此处“激光雕刻”包括激光线条雕刻、激光填充雕刻和激光图像雕刻。

### 平面加工

- **适用场景：** 木板、亚克力、皮革等平面材料；需要多工艺组合（如先雕后切）；批量化生产。
- **支持工艺：** 激光雕刻、激光切割
- **准备步骤：** 拍照 → 测厚 → 自动校准（可一键完成聚焦与测厚）。
- **独有优势：** 工作区域大、支持自动聚焦、支持批量雕刻。

![002.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/laser-processing-mode-guide/zh/002.png)

### 曲面加工

- **适用场景：** 造型异形件、高低差较大的工件、弧面器物。
- **支持工艺：** 激光雕刻、激光切割
- **准备步骤：** 拍照 → 曲面测量（生成 3D 点云）→ 自动定焦。
- **注意事项：**

  - 材料需刚性固定，加工中不可位移。
  - 与旋转轴、送料轴**互斥**，不可同时使用。
  - 不支持模拟切割等深度分级加工。

![003.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/laser-processing-mode-guide/zh/003.png)

### 圆柱加工

- **适用场景：** 杯子、马克杯、笔杆等标准圆柱工件
- **支持工艺：** 激光雕刻
- **准备步骤：** 安装旋转轴 → 扫描/测量直径与长度 → 拍照。
- **注意事项：** 安装旋转轴后，平面加工、曲面测量等功能自动禁用。

![004.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/laser-processing-mode-guide/zh/004.png)

### 滚轮送料加工

通过送料系统实现超长板材的连续激光加工。

- **适用场景：** 长度超出平台的板材，需分段连续加工。
- **支持工艺：** 激光雕刻、激光切割。
- **准备步骤：** 安装送料轮 → 完成送料校准 → 拍照测厚。
- **注意事项：** 与曲面加工互斥；未安装送料附件时无法启用。

![006.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/laser-processing-mode-guide/zh/006.png)

## 工艺自动适配规则

切换到非平面模式时，软件会自动调整不兼容的工艺：

- **切换到曲面/圆柱：** 非激光工艺（刀切、描线、打印）自动禁用。
- **切换到旋转轴模式：** 激光切割自动改为线条雕刻。
- **附件不匹配：** 系统提示并回退到可用模式。

## 常见问题

| **现象** | **说明** |
| --- | --- |
| 切换模式后工艺变了 | 非平面模式仅支持激光，属正常行为 |
| 自动聚焦用不了 | 仅平面模式支持 |
| 提示"材料不支持当前模式" | 更换支持该模式的材料，或调整材料库配置 |
| 曲面加工提示先扫描 | 必须先完成曲面测量 |
| 送料失效 | 检查送料轴安装与校准状态 |
