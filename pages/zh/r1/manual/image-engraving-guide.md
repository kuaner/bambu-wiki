## 什么是图雕？

图雕（Laser Image）可利用激光根据图片的明暗变化，在材料表面雕刻出连续的影调层次，能保留照片中的阴影、纹理和细节。适合：

- 人像与宠物照片
- 风景摄影
- 插画与艺术作品
- 需展现层次感的 Logo 图
- 其他具有灰度渐变的图像

## 什么样的图片适合图雕？

图片质量对最终效果的影响，往往大于图像模式的选择。请优先使用符合以下条件的图片：

| / | **图片说明** | **示例** | **图雕效果** |
| --- | --- | --- | --- |
| **推荐** | - 光线均匀，无明显过曝或死黑 - 主体清晰，对焦准确 - 分辨率充足 - 背景简洁或已去背景 | Image Image | Image Image |
| **不推荐** | - 夜景、强逆光、模糊的照片 - 背景杂乱且无法清除 - 经过多次压缩的低质量图片 - 纯色块极简图形（更适合矢量雕刻） | Image Image | Image Image |

## 图雕操作步骤

- 点击左侧栏中的“图片”，导入位图（JPG/PNG/BMP 等）；

![009.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/image-engraving-guide/zh/009.png)

- 导入后，画布右侧会弹出图片工具浮窗，包含四部分：

![010.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/image-engraving-guide/zh/010.png)

| **序号** | **项目** | **用途** |
| --- | --- | --- |
| 1 | 图像调整 | 调节锐度、亮度、对比度及反色 |
| 2 | 滤镜 | 快速应用风格化效果 |
| 3 | 工具 | 清除背景、裁剪、矢量化、蒙版 |
| 4 | 图像模式 | 决定激光如何表达明暗关系 |

> 注：图雕的最终效果，由**图像模式**和**加工参数**（激光功率、速度等） 共同决定。

- 首先进行**图像调整**，确保主体层次分明；

![011.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/image-engraving-guide/zh/011.png)

 点击此处了解"图像调整"的具体作用

| **图像调整** | **作用** | **备注** | **对比图** |
| --- | --- | --- | --- |
| **锐度** | 增强边缘与细节轮廓 | 适合人像、动物毛发、建筑等需要清晰边缘的图片；已足够清晰的图片不宜过度锐化，避免产生白边或噪点。 | Image Image |
| **亮度** | 整体提亮或压暗 | 图片偏暗时，可适当提高亮度；过曝图片适当降低亮度。 | Image Image |
| **对比度** | 增强明暗反差，让主体更立体 | **大多数图片建议适度提高**；画面过低时显灰，画面过高时会丢失亮部和暗部细节。 | Image Image |
| **反色** | 将明暗颠倒 | 常用场景：深色材料（如黑色阳极氧化铝）、透明亚克力背面雕刻时，正面观看。 | Image Image |

- 按需应用**滤镜**（大多数情况无需滤镜）；

![020.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/image-engraving-guide/zh/020.png)

 点击此处了解各种“滤镜”的具体效果

| **滤镜** | **用途** | **搭配建议** | **效果图** |
| --- | --- | --- | --- |
| **原图** | 保留真实细节，适用于绝大多数情况 | 所有图像模式 | Image |
| **二值化** | 将图片转为纯黑白，适合 Logo、文字 | 阈值模式 | Image |
| **草图** | 提取轮廓，呈现素描感 | Atkinson、Bayer 等风格化模式 | Image |
| **浮雕** | 表现立体凹凸感 | Javis、Stuki | Image |
| **网格** | 叠加方形网格，工业风装饰 | Bayer、半色调 | Image |
| **屏幕网格** | 细密点阵纹理，老屏幕风格 | 半色调、Atkinson | Image |

- 使用**工具**清除背景，减少干扰，或裁剪构图，让主体占据画面主要区域；

|  |  |
| --- | --- |
| 027.png | 028.png |

 点击此处了解各种“工具”的具体用途

| **工具** | **用途** |
| --- | --- |
| **清除背景** | 移除纯色背景，雕刻时背景区域不受激光作用。**人像、宠物、产品照**强烈推荐。 |
| **裁剪** | 重新构图，让主体更突出。 |
| **矢量化** | 将位图转为矢量轮廓，用于切割或描边，不适合照片（会丢失渐变）。 |
| **蒙版** | 手动指定雕刻区域，实现局部雕刻或渐隐效果。 |

- 选择**图像模式**；如果不确定选什么，可以选择 **Jarvis**，通用性最强；

![029.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/image-engraving-guide/zh/029.png)

 点击此处了解各种“图像模式”的具体介绍

| **图像模式** | **说明** | **效果图** |
| --- | --- | --- |
| **阈值模式** | - 推荐图像：Logo、文字、剪影、二维码等无渐变的图形 - 推荐材料：几乎所有材料 - 特点：纯黑纯白，对比最强烈，无中间调 - 慎用：有层次的照片，会丢失所有渐变过渡 | Image |
| **Stucki** | - 推荐图像：人像、建筑、卡通角色等轮廓明显的照片 - 推荐材料：木材 - 特点：边缘比 Jarvis 更清晰锐利，主体突出 - 慎用：噪点多的图片，锐利化会放大瑕疵 | Image |
| **Jarvis** | - 推荐图像：绝大多数照片，尤其是细节丰富、渐变柔和的图像 - 推荐材料：椴木胶合板、胡桃木、深色亚克力、皮革 - 特点：点阵分布均匀，细节保留最好，通用性最强 - 慎用：纯 Logo、极简图标等不需要丰富层次的设计 | Image |
| **Bayer** | - 推荐图像：像素艺术、低多边形插画、几何风格图案、工业风装饰 - 推荐材料：木板、MDF 等纹理较粗的板材 - 特点：规则排列的方块点阵，数码网格风格强烈，装饰感突出 - 慎用：写实照片（网格会破坏自然渐变）；深色亚克力、阳极氧化铝等高对比度均质材料（网格被放大，易产生莫尔纹） | Image |
| **半色调** | - 推荐图像：波普肖像、复古海报、漫画 - 推荐材料：帆布、卡纸、纸板、浅色木板 - 特点：大小变化的规则网点，报纸印刷质感 - 慎用：需要照片级真实感时不宜使用 | Image |
| **Atkinson** | - 推荐图像：矢量风格插画、扁平图标、极简艺术作品 - 推荐材料：帆布、纹理纸、毛毡、浅色原木 - 特点：大量留白，透出材料底色，复古像素感 - 慎用：细节丰富的照片，高光和暗部会丢失 | Image |
| **Floyd** | - 推荐图像：日常照片，快速出图需求 - 推荐材料：椴木、竹板、皮革 - 特点：对比鲜明，处理速度快 - 慎用：追求极细颗粒感时不如 Jarvis 和 Sierra | Image |
| **Sierra** | - 推荐图像：柔光写真、大面积渐变、皮肤特写、中间调丰富的照片 - 推荐材料：深色/浇铸亚克力、枫木、塑料板等对点阵敏感的材料 - 特点：中间调过渡极其柔和，颗粒感最弱，点阵均匀细腻 - 慎用：需要强烈轮廓或高反差的图片，效果偏软；极亮/极暗区域细节可能丢失 | Image |

- 完成图像处理后，点击右下角“准备”；

![038.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/image-engraving-guide/zh/038.png)

- 在“材料组”中选择打印模式和材料，并完成材料测距；

![039.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/image-engraving-guide/zh/039.png)

- 设置雕刻参数并预览；

![040.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/image-engraving-guide/zh/040.png)

- 试刻小样，确认效果后正式雕刻。

## 不同材料推荐模式

所有推荐均为**优先尝试**，实际效果可能因材料批次、品牌、激光参数而异，推荐先用小样进行雕刻测试。

| **材料** | **优先尝试** | **说明** |
| --- | --- | --- |
| 椴木胶合板 | Jarvis / Stucki | 纹理均匀，细节表现好 |
| 胡桃木 | Jarvis | 深色基底需匹配功率，以保留暗部层次 |
| 竹板 | Floyd | 纹理较明显，高对比模式可减少纹理干扰 |
| 不锈钢（带涂层） | Floyd / Jarvis | 涂层均匀时优先Floyd，否则用 Javis |
| 深色亚克力 | Sierra / Jarvis | 对点阵敏感，Sierra 可避免麻点 |
| 皮革 | Floyd | 对比明显，适应皮革本身纹理 |
| 帆布/织物 | 半色调 / Atkinson | 规则网点或稀疏点阵与织物纹理协调 |
| 卡纸/纸张 | 半色调 | 高速低功率，营造印刷感 |
| 石板/瓷砖 | 阈值 / Bayer | 需喷涂辅助，规则点阵容易出效果 |
