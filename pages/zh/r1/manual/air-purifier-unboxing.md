## 安全提示

**使用前，请确保：**

- 净化器外观完好、无损坏。
- 已关闭电源开关。
- 滤芯已平稳安装至净化器内部。

**放置要求：**

- 在净化器前方预留 5 厘米、后方预留 20 厘米的工作空间，并避免风管过度弯折。
- 请勿在净化器上放置任何物品。

**电源要求：**

- 请务必使用净化器自带的电源线。
- 请勿过度拧捏、弯折或扭转电源线，避免线芯折断或外漏，造成安全风险。
- 在维护或者移动净化器前，请务必先断开电源。

**使用过程中，请注意：**

- 移动净化器前，务必先断开电源；严禁通过拉扯电源线来移动净化器。
- 如果出现异响、异味、高温、风扇不规则旋转等异常情况，请立即断开电源并停止使用。
- 请勿倾斜净化器，或者倚靠、坐在净化器上。
- 由于净化器无法过滤一氧化碳 (CO) 或氡 (Rn)，因此在发生燃烧和危险化学品事故时，不能将净化器用作安全设备。
- 同时使用净化器和燃气灶、燃气热水器等家用燃气用具时，请注意通风换气，避免一氧化碳 (CO) 中毒。
- 请勿从进风口内放入液体、粉末、可燃物或任何异物。
- 滤芯严重堵塞时，请立即断开电源并停止使用，否则会缩短净化器的寿命，甚至造成损坏。
- 更换滤芯时，请使用官方滤芯，以确保最佳的过滤效果。

## 安装教程

### 步骤 1：移除外包装

- 打开外箱，移除缓冲材料，并取出快速入门指南及配件。

![002.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/air-purifier-unboxing/zh/002.png)

- 取出净化器，移除外部的防潮袋和侧边的固定胶布。胶布的数量和位置可能更新，请以收到的版本为准。

|  |  |
| --- | --- |
| 003.png | 004.png |

- 从扣手位打开盖板，将内侧的缓冲泡棉取出，然后盖回盖板。

|  |  |
| --- | --- |
| 005.png | 006.png |

### 步骤 2：连接排烟管

- 连接前，请确保主机的排烟风扇和排烟管已安装好。
- 拿起**主机排烟管**，将末端的螺纹拉开。

![007.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/air-purifier-unboxing/zh/007.png)

- 将转接口旋入排烟管中。

![008.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/air-purifier-unboxing/zh/008.gif)

- 将排烟管插入净化器的出风口，确认牢固无松动，**并避免排烟管过度弯折**。

|  |  |
| --- | --- |
| 009.png | 010.png |

### 步骤 3：插入 4-pin 连接线

- 取出随附的 4-pin 连接线。其中一端插入主机侧边的 4-pin 接口（EXPANSION），另一端插入净化器后部的 4-pin 接口。

|  |  |
| --- | --- |
| 011.png | 012.png |

### 步骤 4：连接电源

- 取出电源线，将净化器连接至市电插座，并打开电源开关。

![013.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/air-purifier-unboxing/zh/013.png)

- 等待净化器启动，确认屏幕出现连接成功的图标后即可使用。

![014.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/air-purifier-unboxing/zh/014.png)

### 步骤 5：连接出风口风管

- 取出随附的风管。将带有转接口的一端插入净化器出风口，并将另一端放至室外。**安装时，需留意不要过度弯折风管。**

|  |  |
| --- | --- |
| 015.png | 016.png |

- 日常使用时，请确保在净化器前方预留 5 厘米、后方预留 20 厘米的工作空间。

![017.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/air-purifier-unboxing/zh/017.png)

## 按键和显示屏

- 日常使用时，净化器会随主机任务自启停，并能够根据任务类型动态调节风速档位。

|  |  |
| --- | --- |
| 018.png | 019.png |
| 1. 开/关按钮，2. 风速按钮 | 显示屏 |

### 开/关按钮

- 按一下可唤醒或熄灭屏幕。
- 开机状态下长按，净化器会停止运行并待机，再次长按即可唤醒（默认重置为自动模式）。

### 风速按钮

- 按一下可循环切换风速档位，包含一档、二档、三档、自动模式和停止。
- 长按后可切换屏幕页面，查看滤芯状态、错误信息（如有）或返回**空气质量主页**。

### 显示屏图标

![](https://public-cdn.bblmw.com/wiki/new/r1/manual/air-purifier-unboxing/zh/020.png)

1. **连接状态**。使用 4-pin 连接净化器和主机后，净化器主页会自动显示该图标。若未显示该图标，可能为设备固件不支持，请在主机屏幕更新固件后再查看。
2. **滤芯类型**。
3. **实时 PM 2.5**。展示经过滤芯后的外排空气质量。
4. **风扇状态**。默认为自动模式 (auto）。短按风速按键，可以在自动、一档、二档、三档和停止之间循环切换。
