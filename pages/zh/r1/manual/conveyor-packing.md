## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲材料是否放置到位**，充分保护设备。

## 所需工具

- 原包装（及内附的缓冲材料、固定件和运输螺丝等）、运输胶带、扎带、H2.0 内六角扳手（随附）。

## 操作步骤

### 1. 移除前、后导轨组件

- 将**后导轨组件**顶部的螺栓拧松，然后将组件滑至**右侧的凹槽**取出。

|  |  |
| --- | --- |
| 001.png | 002.png |

- 将**前导轨组件**顶部的螺栓拧松，然后将组件滑至**两侧的凹槽**取出。

|  |  |
| --- | --- |
| 003.png | 004.png |

- 拧下导轨组件的螺丝，取下导轨和导轨支架。重复操作，拆下剩余 3 组组件。

|  |  |
| --- | --- |
| 005.png | 006.png |

### 2. 搬下主机

- 关闭主机电源，移除主机电源线。

|  |  |
| --- | --- |
| 007.png | 008.png |

- 打开主机上盖，移除增高底座的 8-pin 连接线。

![009.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/009.png)

- 两人合力取下主机。

![010.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/010.png)

### 3. 移除送料滚轮组件

- 移除组件的 6-pin 连接线并取出。拔线时，**捏住连接线顶部的弹片**，然后再拔出。

![011.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/011.gif)

- 同步拔下支撑滚轮组件的连接线。

![012.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/012.png)

- 拧松 8 颗螺丝，将送料滚轮组件取出。

|  |  |
| --- | --- |
| 013.png | 014.png |

- 翻转组件，将内部的 8 颗螺丝倒出并收纳好。

![015.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/015.gif)

- **逆时针**拧松张紧螺丝 1-2 圈。

![016.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/016.png)

- 将运输固定片装回组件提手的空隙（靠近 6-pin 接口的一侧），并下压按紧。

|  |  |
| --- | --- |
| 017.png | 018.png |

- 用扎带将固定片绑好即可。

|  |  |
| --- | --- |
| 019.png | 020.png |

### 4. 移除挡烟帘支架

- 拧下支架两端的 4 颗螺丝并收好。

|  |  |
| --- | --- |
| 021.png | 022.png |

- 取下挡烟帘支架。

![023.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/023.png)

### 5. 移除支撑滚轮组件

- 确认连接线已拔出，并将线缆从线扣处移除。
- 拧松两端的 4 颗螺丝。

|  |  |
| --- | --- |
| 024.png | 025.png |

- 取出支撑滚轮组件。

![026.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/026.png)

- 翻转组件，**将 4 颗螺丝倒出并收好**。

### 6. 打包导轨组件

- 将零散配件放入工具盒内，并合上封盖。

|  |  |
| --- | --- |
| 027.png | 028.png |

- 将 4 个导轨支架**相对放置**在防潮袋中，并平放在支架包装盒内。

|  |  |
| --- | --- |
| 029.png | 030.png |

- 在导轨包装盒内放入泡棉和配件盒。

![031.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/031.png)

- 将 1 对导轨组件**相对放置在防潮袋中**，然后卡入泡棉内。

![032.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/032.gif)

- 重复操作，将另一组导轨封好放入，并在顶部卡入缓冲泡棉。

|  |  |
| --- | --- |
| 033.png | 034.png |

- 将打包好的支架和放入导轨包装盒顶部，并合上封盖。

|  |  |
| --- | --- |
| 035.png | 036.png |

### 7. 放回包装并封箱

- 将支撑滚轮组件和送料滚轮组件放入防潮袋，并用胶带将封口贴好。

|  |  |
| --- | --- |
| 037.png | 038.png |

- 将缓冲泡棉按照图示朝向，放入外包装箱内。

![039.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/039.png)

- 放入送料滚轮组件。

|  |  |
| --- | --- |
| 040.png | 041.png |

- 在送料滚轮组件顶部，放入缓冲泡棉垫。

|  |  |
| --- | --- |
| 042.png | 043.png |

- 继续放入支撑滚轮组件，并使用缓冲泡棉固定两端。

|  |  |
| --- | --- |
| 044.png | 045.png |

- 将导轨包装盒放入外包装盒的泡棉空位。

|  |  |
| --- | --- |
| 046.png | 047.png |

- 在顶部放入挡烟帘支架，确保支架卡入缝隙内。

![048.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/conveyor-packing/zh/048.gif)

- 将顶部泡棉放回。合上纸箱封盖，并用运输胶带将四边及中部封好，确认牢固无松动即可。

|  |  |
| --- | --- |
| 049.png | 050.png |
