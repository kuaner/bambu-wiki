## 为什么需要设置连接点？

在使用「**激光线条切割**」工艺时，尤其是进行滚轮送料切割或连续加工时，零件可能会在尚未完成全部加工前就从板材上掉落、翘起或发生移位。一旦工件中途脱落或位置改变，后续切割路径就可能出现偏差，轻则影响边缘质量，重则导致加工失败，甚至卡住滚轮送料机构。

为了解决这个问题，Bambu Suite 针对切割场景提供了「**连接点**」功能。开启连接点后，软件会在切割路径上保留若干未完全切透的位置。激光经过这些位置时，会跳过或降低加工强度，使待切割零件暂时仍与主体板材相连，从而避免零件在加工过程中掉落或移位。

简单来说，连接点的作用就是在加工完成前，把工件“拴”在板材上。连接点设置得太小，工件可能在送料或切割过程中提前脱落；连接点设置得太大，后续拆卸时又可能撕坏木皮、留下明显毛边或造成结构损伤。

|  |  |
| --- | --- |
| 零件脱落 | 手动掰开取件 |
| ❌ 无/过小连接点：零件中途脱落 | ✅ 合适连接点：完成后可手动取下 |

因此，合理设置连接点的目标是：

- **加工过程中**：工件不掉落、不移位；
- **加工完成后**：工件容易取下；
- **拆卸时**：尽量不撕坏木皮，不破坏零件结构。

> **ℹ️ 提示**：开始之前，请确认切割参数已能稳定切透加工板材。

## 软件操作

「**连接点**」在 Bambu Suite 中的设置方法如下：

1. 选择工艺类型为 **“激光线条切割”**1 的路径对象；
2. 点击 **“连接点”**2，打开设置浮窗；
3. 选择生成规则，并设置连接点尺寸、加工系数等参数，或直接采用默认的参数；
4. 点击 **“确认”**3，即可在切割路径上生成连接点；
5. 检查连接点的位置和分布，必要时手动添加、移动或删除。

![](https://wiki.bambulab.com/r1/manual/laser-cut-tab-parameter-guide/1-tab.png)

  

## 生成规则

软件提供 **自动、间距、数量** 三种生成规则。每条参与生成的路径至少生成 1 个连接点。

![](https://wiki.bambulab.com/r1/manual/laser-cut-tab-parameter-guide/2-generation-rule.png)

  

### 自动

软件综合考虑路径长度和图案重心，计算连接点的位置和数量，尽量以较少的连接点满足固定需要。

**最大跨度**用于约束相邻连接点之间沿路径测量的距离。软件会在不超过最大跨度的前提下，按照自动规则安排连接点，**不会严格按最大跨度等距放置**。

- 最大跨度较小：通常需要更多连接点，固定更牢，但拆卸可能更费力。
- 最大跨度较大：通常允许更少的连接点，拆卸更容易，但可能降低固定效果。

![](https://wiki.bambulab.com/r1/manual/laser-cut-tab-parameter-guide/3-rule-auto1.webp)

  

### 间距

按照设定的间距，沿路径生成连接点。

与自动模式不同，**间距模式按照设定间距生成**，而不是仅将该数值作为最大跨度约束。

![](https://wiki.bambulab.com/r1/manual/laser-cut-tab-parameter-guide/4-rule-spacing.webp)

  

### 数量

按照设定的连接点总数生成。

**同时选择多个对象时，设置的数量是所选对象合计的连接点数量。**

![](https://wiki.bambulab.com/r1/manual/laser-cut-tab-parameter-guide/5-rule-count.webp)

> **✅ 说明**：以上三种生成规则在自动放置连接点时，都会**避开路径端点和尖角**位置。生成后仍可手动调整。

## 参数说明

![](https://wiki.bambulab.com/r1/manual/laser-cut-tab-parameter-guide/6-parameter-zh.png)

  

### 尺寸

尺寸表示连接点**沿切割路径方向的长度**。

- 尺寸较大：连接区域通常更宽，固定更牢，但拆卸可能更困难。
- 尺寸较小：连接区域通常更窄，更容易拆卸，但可能提前断裂。

|  |  |
| --- | --- |
|  |  |
| **连接点尺寸** （正方形尺寸 50×50 mm） | **切割效果** （正方形尺寸 50×50 mm） |

> 尺寸描述的是沿路径保留连接的长度，**不是剩余材料的厚度**。

### 允许开放路径连接点

控制是否在开放路径上自动生成连接点。

- **开启**：开放路径也参与自动生成。
- **关闭**：不在开放路径上自动生成连接点，但仍可手动添加。

![](https://wiki.bambulab.com/r1/manual/laser-cut-tab-parameter-guide/8-open.webp)

  

### 仅外轮廓连接点

开启后，软件根据对象之间的关系识别最外层轮廓，仅在最外层轮廓上自动添加连接点。

|  |  |
| --- | --- |
|  |  |
| ✅ **开启** 仅外轮廓添加连接点 | ❌ **关闭** 内外轮廓均添加连接点 |

> **带内部孔洞或嵌套轮廓的图案**，开启前后的生成结果。

### 加工系数

加工系数决定连接点处使用的激光功率，是**当前切割功率的百分比**。速度等其他加工参数保持不变。

例如，当前切割功率为 80%，加工系数为 50%，则连接点处的功率设置为：**80% × 50% = 40%**

- 加工系数为 0：连接点处不出光，不主动切削该连接区域。
- 加工系数大于 0：连接点处按计算后的功率加工，削弱连接区域，帮助后续拆卸。
- 在其他条件相同时，加工系数越大，通常切入越深、剩余连接越弱；设置过高可能切透连接点，使其失去固定作用。

![10-coefficient.png](https://wiki.bambulab.com/r1/manual/laser-cut-tab-parameter-guide/10-coefficient.png)

> **加工系数不代表切割深度或剩余厚度的比例。** 实际效果仍与材料、厚度和基础切割参数有关。
>
> 设置多次切割时，**每次切割都会应用连接点设置**。重复加工可能进一步削弱连接区域，测试时应使用与正式加工相同的切割次数。

## 手动调整连接点

无论使用哪一种生成规则，都可以手动添加、移动或删除连接点：

- **添加**：在路径上点击，添加连接点。
- **移动**：选中连接点后拖动，调整位置。
- **删除**：选中连接点后删除。

手动添加不限制端点或尖角位置，但这些位置的固定及拆卸效果需要结合实际加工测试。

**手动添加的连接点不会因后续调整生成规则或相关设置而被重新生成的连接点替换。** 如需从头设置，可以先「清除所有」连接点，再「重新生成」。

![](https://wiki.bambulab.com/r1/manual/laser-cut-tab-parameter-guide/11-add-clear.webp)

上面的附件是用于给不同材料测试连接点的文件，推荐从默认参数开始测试。

1. 连接点的本质，是在“**加工稳定**”和“**拆卸干净**”之间找到平衡：

- **尺寸**控制连接点粗细：越大越牢，越小越好拆。**如果拆卸困难或撕坏木皮，优先减小尺寸**
- **最大跨度**控制连接点密度：跨度越小，连接点越多，工件越不容易掉。如果工件**加工中容易掉落，优先减小最大跨度**
- **加工系数**控制连接点加工强度：数值越大，连接点越浅，越容易拆。对于胶合椴木板等带木皮材料，加工系数一般可先尝试 **20%**。

2. **注意木纹方向：**

- 设置连接点时，尽量让连接点位置与木纹方向垂直，而不是顺着木纹，避免拆卸时损伤工件表面。

![12-direction.png](https://wiki.bambulab.com/r1/manual/laser-cut-tab-parameter-guide/12-direction.png)
