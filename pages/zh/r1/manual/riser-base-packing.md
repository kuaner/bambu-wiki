## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲材料是否放置到位**，充分保护设备。

## 所需工具

- 原包装（及内附的缓冲材料、固定件和运输螺丝等）、运输胶带、H2.0 内六角扳手（随附）。

## 操作步骤

### 1. 搬下主机

- 关闭主机电源，移除主机电源线。

|  |  |
| --- | --- |
| 001.png | 002.png |

- 扣住增高底座前门两边的门锁，向外打开前门，并取出托盘。

|  |  |
| --- | --- |
| 003.png | 004.png |

- 打开主机上盖，移除增高底座的 8-pin 连接线。

![005.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/005.png)

- 两人合力搬下主机。

![006.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/006.png)

- 两人合力，翻转增高底座。请从增高底座的两侧抓握，避免拉扯前门，以免夹伤。

|  |  |
| --- | --- |
| 007.png | 008.png |

### 2. 移除前门

- 使用 H2.0 内六角扳手，将底板的 6 颗螺丝拧下并收纳好。

![009.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/009.png)

- 向内扣住前门门锁，抬起前门和底板，并将其折叠放好。

![010.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/010.gif)

### 3. 移除排线并固定

- 排线位于后侧组件的两端\*\*。捏住排线前端，将其小心拔下\*\*。

|  |  |
| --- | --- |
| 011.png | 012.png |

- 使用胶带，将左右两侧的排线固定在组件内壁。

![013.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/013.gif)

### 4. 移除后侧组件

- 使用 H2.0 内六角扳手，将后侧组件两侧的螺丝拧下，并将螺丝收纳好。

|  |  |
| --- | --- |
| 014.png | 015.png |

### 5. 取下左、右侧组件

- 轻轻抬起后侧组件，将左侧组件取下。

![016.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/016.gif)

- 重复操作，取下右侧组件。

![017.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/017.gif)

- 将后侧组件两端的泡棉塞回。

![018.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/018.gif)

### 6. 打包组件

- 将右侧组件和左侧组件套入防潮袋中。

|  |  |
| --- | --- |
| 019.png | 020.png |

- 将纸卡平铺在桌面。

![021.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/021.png)

- 将左侧组件的脚垫对准纸卡孔位放入，并用纸卡卷起包好。

![022.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/022.gif)

- 重复操作，放入右侧组件，然后卷起纸卡并包好。

|  |  |
| --- | --- |
| 023.png | 024.png |

- 合上纸卡两侧的封盖（共 4 处）。

|  |  |
| --- | --- |
| 025.png | 026.png |

- 提起纸卡中部的扣手，将打包好的组件立起放置。

![027.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/027.gif)

- 将配件放回配件盒内（包含内六角扳手、8-pin 连接线和螺丝），并将后侧组件、前门组件套入防潮袋。

![028.jpg](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/028.jpg)

### 7. 放回包装并封箱

- 将缓冲材料放回包装箱底部。

![029.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/029.png)

- 将包装好的左、右组件放入左侧的空位。您可调整中间的缓冲材料，使其与组件贴合。

![030.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/030.png)

- 将配件盒放入右侧的空位。

![031.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/031.png)

- 将后侧组件放回前部的空位，轻轻下压使其贴合泡棉。

|  |  |
| --- | --- |
| 032.png | 033.png |

- 将方块泡棉放入后侧组件与左、右侧组件的中部。

![034.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/034.gif)

- 将缓冲泡棉垫在前侧组件底部，将组件和泡棉放进包装箱。

![035.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/riser-base-packing/zh/035.png)

- 放回一侧的缓冲泡棉轻轻下压使其贴合。重复操作，卡入右侧的泡棉。

|  |  |
| --- | --- |
| 036.gif | 037.png |

- 在前门组件（底板的一侧）放入缓冲气袋和快速入门指南。

|  |  |
| --- | --- |
| 038.png | 039.png |

- 合上纸箱封盖，并用运输胶带将四边及中部封好，确认牢固无松动即可。

|  |  |
| --- | --- |
| 040.png | 041.png |
