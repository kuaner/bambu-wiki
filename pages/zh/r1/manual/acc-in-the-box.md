## 配件介绍

| 实物照片 | 名称 |
| --- | --- |
| Image | **电源线** 连接市电，为产品供电。 |
| Image | **排烟管** 带有转接口的一端连接至排烟风扇，另一端放置于通风良好的室外，或连接至官方的激光专用净化器。 |
| Image | **排烟风扇** 安装在机身后部的排烟口，用于抽排烟雾。 |
| Image | **防冻液** 用于配制冷却液，首次使用时，请按《快速入门指南》教程进行配制添加。后续日常维护时，请参考[《冷却液更换教程》](../maintenance/coolant.md)进行操作。 |
| Image | **漏斗** 注入冷却液时，需将漏斗插入机身后部的注水口，以便撒漏。 |
| Image | **H2.0 & H1.5 内六角扳手** 拆装工具。 |
| Image | **安全钥匙（预装）** 插入以启用激光功能，拔出则禁用。请妥善保管。请参考[《安全钥匙介绍》](safety-key.md)获取更多信息。 |
| Image | **光路校准传感器** 用于光路相关校准（调光）操作，请参考[《光路校准介绍》](laser-alignment-guide.md)了解详细步骤。 |
| Image | **材料固定夹** 用于将发生翘曲的材料固定在刀条上，请参考[《配件安装指南》](accessory-installation-guide.md)获取更多信息。 |
| Image | **标定板** 请参考[《视觉精度校准》](visual-accuracy-calibration.md)了解配件功能和使用方式。 |
| Image | **润滑油&润滑脂** 日常维护时，可用于润滑产品内部的金属运动部件（如光轴和线轨）。润滑油和润滑脂使用场景不同，务必按照[《定期维护建议》](../maintenance/periodic-maintenance.md)内的说明进行操作。 |
| Image | **椴木胶合板&纯透明亚克力板** 随附加工材料，可用于首次切割/雕刻体验，请跟随[《首次使用》](first-setup-guide.md)使用椴木胶合板完成第一件作品。 |
