## 概述

“精细拍照”是利用**工具头摄像头**进行的高精度成像；该摄像头随工具头移动，能够在最接近目标的位置和最佳视角捕获图像，因而比仅固定在机身顶部的俯视摄像头得到更清晰、分辨率更高的画面。

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/fine-capture-guide/zh/001.png)

## 使用场景

当需要将图像非常精确地摆放并加工在材料的特定位置时，可以采用精细拍照。精细拍照的加工对位精度可达 **0.2 mm**，能够在较小范围内提供细腻的细节信息。

## 材料要求

为确保精细拍照的准确性，拍照前需满足以下条件：

1. **物体表面需平整**：精细拍照仅在**平面加工模式**下支持。若物体表面不平整，会导致测距结果偏差，进而影响拍摄比例和图像精度；
2. **物体中心区域应完整**：旧版本会在框选区域的中心点（下图中绿点）进行距离测量。若物体中心存在空洞，将导致测距误差。

> 注意：
>
> - 中心空洞导致的测量误差问题将在新版本中解决，当前版本请尽量选择**中心区域完整的物体**进行拍照。
> - 若材料表面起伏不平，精细拍照的拼接也会产生较小误差。建议使用平整的材料进行精细拍照。
> - 如果材料是透明的，我们会转而使用触碰测量的方式进行测量，可能会导致图片位置以及拼接存在小幅误差，将在后续版本中优化。

![002.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/fine-capture-guide/zh/002.png)

## 操作流程

1. 建议先点击 **“一键准备”** 按钮，对材料进行全局拍照，并进行高度测量；

|  |  |
| --- | --- |
| 003.png | 004.png |

2. 点击“精细拍照”按钮，绘制矩形以选定需要精细拍照的区域；

|  |  |
| --- | --- |
| 005.png | 006.png |

框选之后，首先设备会对所选区域进行一次高度测量。测量的点会选择在框选区域的中心点

|  |  |
| --- | --- |
| 007.png | 008.png |

> 注意事项：
>
> - 当前版本默认在框选区域的中心取点测量。若材料中心存在空洞，可能导致测量结果不准，进而使图像拼接出现错位。该问题将在后续版本中优化；
> - 若材料表面起伏不平，精细拍照的拼接也会产生较小误差。建议使用平整的材料进行精细拍照。
> - 如果材料是透明的，我们会转而使用触碰测量的方式进行测量，此种测量方式的图像精度稍差，将在后续版本中优化。

获得高度之后，工具头摄像头将对用户框定的区域进行测距和拍照；

![009.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/fine-capture-guide/zh/009.png)

3. 拍照结束后，如果拍照的区域较小，则会清晰展示所框选区域的细小纹理，可放大查看细节；

![010.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/fine-capture-guide/zh/010.png)

> 注意：
>
> - 如果框选区域较大，则较为耗时，请耐心等待，期间请勿进行其他操作；
> - 当前精细拍照的结果图可能存在一定色差，在反光材料上会更明显，但不影响图像位置的准确性。此问题将在后续版本中优化，当前可适当缩小精细拍照的框选范围。

4. 可根据拍照后的细节图，调整加工图案的位置；

![012.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/fine-capture-guide/zh/012.png)

待加工完成后，检查加工细节。

![013.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/fine-capture-guide/zh/013.png)

## 注意事项

若需要重新拍照，可右击加工区域并选择 **“清除照片”**，该操作会清除整个加工平面的背景照片（包括俯视摄像头拍摄的加工平面图）。清除后，重新点击“精细拍照”即可。
