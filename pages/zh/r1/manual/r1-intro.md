## 光学系统

### 激光管

玻璃材质激光管，发射二氧化碳（CO₂）激光，是整机的激光光源。

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/001.png)

### 反射镜和聚焦镜

激光管发射的激光，需要经过**反射镜**多次转向、再由**聚焦镜**聚焦，才能最终作用于工件，两者共同构成了从激光管到工件的光路传导与聚焦系统。其中，反射镜负责改变激光传播方向、将光束准确引导到位，聚焦镜负责将光束聚焦成高能量密度的小光斑。

#### **反射镜**

用于改变激光的传播方向，**反射镜 1/2 **沿 XY 平面将光路从激光管反射入加工幅面内，并且内部通过运动机构进行光路校准，最终由**反射镜 3** 将 XY 平面内的水平光路转折为 Z 向（竖直向下），把激光准确传导至聚焦镜。

|  |  |
| --- | --- |
| 002.png | 003.png |

用于聚焦光斑，然后作用于工件。聚焦镜可更换不同规格的透镜，实现不同的焦距，整机标配 38.1 mm 短焦（S），另有 50.8 mm 中焦（M）和 63.5 mm 长焦（L）两种选配。不同焦距的聚焦光斑尺寸和焦深各有侧重，用于不同场景下的加工。

> 有关聚焦镜的更多信息请参考：[聚焦镜介绍](focusing-lens-guide.md)。

## 运动系统

### X 轴

X 轴采用双轴心导轨与皮带传动，由 X 步进电机单独驱动，控制工具头左右移动。X 轴皮带规格为 1.5GT。

|  |  |
| --- | --- |
| 006.png | 007.png |

### Y 轴

由 Y 步进电机驱动，控制工具头前后移动，与 X 轴配合实现加工幅面内的平面定位。Y 轴皮带规格为 2GT。

|  |  |
| --- | --- |
| 008.png | 009.png |

### Z 轴

Z 轴由齿轮齿条与直线导轨组成，Z 步进电机驱动齿轮齿条升降，线轨提供稳定导向，保证 Z 滑车上的透镜不抖动、不偏移。Z 轴行程最大为 65 mm。

|  |  |
| --- | --- |
| 010.png | 011.png |

## 工具头

负责将激光最后反射、聚焦并投射到加工平面，是激光加工的执行端，集成了多种激光、传感与摄像组件。

|  |  |
| --- | --- |
| 012.png | 013.png |

1. **气嘴：** 位于工具头激光出光口下方，加工时喷出辅助气体，用于吹除加工烟尘、保护镜片，并辅助切割；
2. **选点激光（红十字激光）：** 方便用户手动移动工具头时定位出光位置，也用于走边框预览。红色十字与实际出光孔不同轴，机器会自动进行偏置补偿；
3. **测距激光（蓝十字激光）：** 配合高分辨率相机实现测距，用于自动获取工件表面高度、辅助对焦；
4. **补光灯：** 在精细拍照和视觉精度校准时，补光灯会开启，确保工具头摄像头能够清楚拍摄到目标物体和校准 marker；
5. **火焰传感器：** 实时监测工具头附近的红外信号与温度，判断加工过程中是否发生起火，提升使用安全性；

> 注：R1 机身共有 5 个火焰传感器，另外 4 个位于机身腔体内；关于火焰传感器的更多介绍，请参考此 wiki：[火焰传感器介绍](flame-detection-safety.md)。

6. **工具头摄像头：** 用于近距离精细拍照，辅助定位、对焦及标记点识别。

## 激光防护上盖

激光防护上盖为 PC 材质，用于隔离激光、保护操作人员安全；上盖配有霍尔传感器，用于检测上盖开合状态，未闭合到位时限制激光启动。

> 请勿在上盖放置重物或尖锐物品，以免造成变形、开裂，降低激光防护效果。

![014.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/014.png)

1. **LED 补光灯：** 位于 R1 上盖，为腔体内提供充足照明，确保俯视摄像头成像清晰；
2. **俯视摄像头：** 上盖打开到位后，机器通过俯视摄像头拍摄整个工作区域的全景图像，结合 AI 算法进行图像拼接与矫正，为后续的定位、识别和其他功能提供精确的视觉基础。

## 加工平台

### 托盘

承载工件的平台，便于放置材料及清理加工残渣。

![015.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/015.png)

### 支撑刀条

用于支撑工件，减少工件与平台的接触面积，避免反射并利于排烟。

![016.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/016.png)

## 散热与排烟系统

### 散热格栅

用于机器内部散热通风，保证电控及关键部件工作在正常温度范围。

|  |  |
| --- | --- |
| 017.png | 018.png |

### 注水口

用于向激光管冷却水路加注/循环冷却液，维持激光管工作温度。

![019.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/019.png)

### 液冷风扇

为冷却液散热，配合水冷循环带走激光管产生的热量，保证激光管稳定工作。

![020.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/020.png)

### 排烟风扇

机身后部有一个排烟口，可在此安装外部排烟风扇，用于排出加工产生的烟雾，需定期清理风扇以保证排烟效果。旁边配有一个 4-pin 接口，仅用于连接排烟风扇。排烟风扇的排烟管外径为 86.5 mm。

|  |  |
| --- | --- |
| 021.png | 022.png |

### 排烟滤网

过滤加工产生的大直径烟尘颗粒，保持气流洁净并保护排烟系统。

![023.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/023.png)

## 对外接口

机器左侧板上集成一系列接口，具体作用如下：

![024.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/024.png)

1. **灭火器气管接口/4-pin 连接口：** 用于连接外置灭火装置气管，起火时向腔内输送灭火介质；
2. **4-pin 连接口：** 用于连接空气净化器等外部联动设备；
3. **安全钥匙：** 已预装安全钥匙，确保机器安全；只有插入钥匙，相关功能才能执行；

> 有关安全钥匙的更多信息请参考：[安全钥匙介绍](safety-key.md)。

4. **USB-C 接口：** 用于数据传输或外部设备连接。

> R1 支持通过 USB-C 线缆进行离线加工或离线升级，具体介绍请参考：[离线加工](offline-processing-guide.md)、[离线升级](offline-update.md)。

## 电气元件

### 主控板

整机的控制核心，负责运动控制、激光控制、传感器信号处理及各模块协调运行。

![025.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/025.png)

### 电源模块

#### 铁壳电源

铁壳电源是为整机各电控部件提供稳定的工作电源，下方有一块滤波板（右图），用于滤除电源中的高频干扰和纹波，为设备提供稳定、干净的电源。

|  |  |
| --- | --- |
| 026.png | 027.png |

#### 激光电源

为激光管提供高压驱动电源，控制激光的输出功率。

![028.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/028.png)

### 机身火焰传感器

R1 机身共有 5 个火焰传感器，其中 4 个位于机身腔体内（另一个位于工具头上），可从整机层面监测是否发生起火，与工具头火焰传感器形成双重防护。

> 关于火焰传感器的更多介绍，请参考此 wiki：[火焰传感器介绍](flame-detection-safety.md)。

|  |  |  |
| --- | --- | --- |
| 029.png | 030.png | 031.png |

### 急停开关

紧急情况下按下可立即切断相关动作，使机器停止运行，保障人身与设备安全。

![032.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/032.png)

### 启停按钮

激光加工任务须由操作员全程值守。在前处理软件中发送激光任务后，操作员需按下打印机右上方的启停按钮，以启动该任务。

![033.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/033.png)

### 触控屏

提供本机操作与状态显示界面，用户可通过触控屏进行参数设置、任务控制与信息查看。

![034.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/034.png)

### 腔内 LED 照明灯

位于机身腔体左右两侧，能为机器提供照明。

![035.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/r1-intro/zh/035.png)
