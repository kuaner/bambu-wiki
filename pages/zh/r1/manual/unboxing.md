> **说明**
>
> - **为保障您顺畅的退换货权益，建议您保留所有包装材料至少 30 天。**；
> - 包材、配件可能会不定时更新，请以收到的版本为准，更新详情见操作步骤。

> **提示**
>
> - **请预留足够的位置用于安装产品，并提前规划排烟管的放置路径**；
> - 首次安装前，需提前准备约 **1500 mL 蒸馏水**（请勿使用自来水或矿泉水）。

## 操作步骤

### 步骤 1：移除外包装

- 打开外箱，取出椴木胶合板和亚克力板。

![002.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/002.png)

- 移除顶部和前后的缓冲材料，并打开产品外部的防潮袋。

|  |  |
| --- | --- |
| 003.png | 004.png |

- 查看主机两侧的对位标记，双手托住标记底部。

![005.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/005.png)

- 两人合力将产品抬出，放置在稳定平面上。

![006.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/006.png)

- 打开产品的激光防护上盖，取出快速入门指南。

![007.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/007.png)

- 取出配件盒，并移除内部剩余的缓冲材料。

|  |  |
| --- | --- |
| 008.png | 009.png |

- 移除上盖、激光管及屏幕外部的保护膜。

### 步骤 2：解锁固定件

- 取出 H2.0 内六角扳手，将工具头固定件的 6 颗螺丝拧出，并将固定件取下。

|  |  |
| --- | --- |
| 010.png | 011.png |

- 拧出 Y 轴左侧的固定件螺丝，然后取下固定件。

|  |  |
| --- | --- |
| 012.png | 013.png |

- 继续拧出右侧的螺丝并取下固定件。

![014.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/014.png)

### 步骤 3：释放急停开关

检查产品右侧的急停开关是否为释放状态。若已被按下，手动旋转开关即可释放。

![015.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/015.gif)

### 步骤 4：安装排烟风扇和排烟管

> **危险**  
> 使用时，如未正确安装排烟风扇和排烟管，可能导致加工异常，甚至引发安全风险。

- 转至产品后部。

![016.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/016.png)

- 取出排烟风扇。将**风扇内嵌的连接线**插入机身 4-pin 接口，并将线缆整理至线槽内。

|  |  |
| --- | --- |
| 017.png | 018.png |

- 对准风扇与排烟口的**定位点**，将风扇卡入排烟口。

![019.jpg](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/019.jpg)

- 逆时针转动风扇，听到「咔嗒」声即为固定到位。

|  |  |
| --- | --- |
| 020.png | 021.png |

- 取出排烟管。将有**转接口**的一端套入排烟风扇的出风口，**确保排烟管完全覆盖胶圈**。

|  |  |
| --- | --- |
| 022.png | 023.png |

- 将排烟管的另一端放至通风良好的室外空间。

![024.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/024.png)

> **提示**  
> 您可另购官方激光专用净化器，以获得更好的过滤效果。（请在 [E1 Pro 净化器安装使用指南](air-purifier-unboxing.md) 查看连接方式）。

### 步骤 5：注入防冻液

> **注意**  
> 请勿将手指伸进注水口，以免受伤。

- 拔出注水口塞子，并插入漏斗。

|  |  |
| --- | --- |
| 025.png | 026.png |

- **取出防冻液。**请提前查询激光切割机所在区域的**全年最低温度**，以判断对应的水位刻度。

  - 若最低温度 ≥ 5℃，无需添加防冻液，请继续下一步。
  - 若 5℃ ≥ 最低温度 ≥－10℃，需倒入防冻液至 -10℃ 刻度处；
  - 若 -10℃ ≥ 最低温度 ≥－20℃，需倒入防冻液至 -20℃ 刻度处；
  - 若 -20℃ ≥ 最低温度 ≥－30℃，需倒入防冻液至 -30℃ 刻度处；

> **提示**  
> 目前暂不适用全年最低温度＜－30℃ 的情况。

![027.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/027.png)

### 步骤 5：首次注入蒸馏水

> **注意**  
> 请勿使用自来水、矿泉水等可能含有杂质的水，否则会严重影响激光管运行性能，甚至导致产品损坏。

- 取出准备好的蒸馏水。

![028.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/028.png)

- 平视水箱，倒入蒸馏水至**加水线 (Fill Line)**，水位可以略微超过刻度线。

![029.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/029.png)

### 步骤 6：连接电源

- 取出电源线，将产品连接至市电插座，并打开电源开关。

![030.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/030.png)

- 产品启动后，请等待水箱水位下降（约 30 秒），再继续下一步。

![031.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/031.gif)

### 步骤 7：再次补满蒸馏水

- 平视水箱，再次补充蒸馏水至**加水线 (Fill Line)** 处。

![032.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/unboxing/zh/032.png)

- 完成注水后，请取出漏斗，并将塞子塞回。

|  |  |
| --- | --- |
| 033.png | 034.png |

### 步骤 8：发起校准

- 根据屏幕指引，将产品绑定至 Bambu Handy，并进行首次校准。

|  |  |
| --- | --- |
| 035.png | 036.png |

> **说明**  
> 校准过程中出现振动和噪音属正常现象。

> **提示**  
> 您可继续阅读 [R1 首次使用](first-setup-guide.md)，完成第一件激光加工作品。
