烟尘净化器可以适配H2系列打印机的激光版本、R1激光雕刻机，该净化器无联动功能，通过机身的电源开关和调速旋转手动控制。

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/smoke-purifier-connection/zh/001.png)

## 安全提示

> 在对激光切割机及其电子设备（包括工具头线缆）进行任何维护前，请先关闭设备电源并断开电源连接，以防屏幕误触或电路短路造成额外的设备损坏与安全隐患。维护或排查故障前，请确认相关部件已冷却。

## 连接步骤

### 步骤 1.连接排烟管

用力拉开排烟管和转接口，拔出困难时可以尝试轻微晃动接头。

![002.webp](https://public-cdn.bblmw.com/wiki/new/r1/manual/smoke-purifier-connection/zh/002.webp)

取出烟尘净化器附送的排烟管，将排烟管套在转接口上，使用卡箍锁紧排烟管。

![003.webp](https://public-cdn.bblmw.com/wiki/new/r1/manual/smoke-purifier-connection/zh/003.webp)

连接排烟管和排烟风扇。

![004.webp](https://public-cdn.bblmw.com/wiki/new/r1/manual/smoke-purifier-connection/zh/004.webp)

### 步骤 2.连接烟尘净化器

将排烟管另一端连接到烟尘净化器进风口，并使用卡箍锁紧。

|  |  |
| --- | --- |
| 005.png | 006.png |

### 步骤 3.连接外排排烟管（可选）

如果需要将过滤后的空气外排，可以单独连接一条排烟管排向室外。

|  |  |
| --- | --- |
| 007.png | 008.png |

将排烟管另一端通往室外。（做此操作前，建议确认符合当地法律法规要求并且不会对周边环境造成不当影响）

![009.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/smoke-purifier-connection/zh/009.png)

### 步骤 4.开启烟尘净化器

连接电源线，打开烟尘净化器后方开关，通过旋钮调整合适风量即可开始使用。  
搭配 R1 使用时，烟尘净化器风量应不低于50%，否则可能导致烟尘外泄。
