## 支撑刀条

支撑刀条作为激光雕刻/切割时的工件载体，用于承载激光雕刻/切割的耗材，限制雕刻/切割过程中产生的火焰及烟尘。支撑刀条随机附送 11 条，作为独立模块，刀条在整机不同安装槽位之间切换时可快速拆换，便于适配不同尺寸的耗材。

### 何时安装？

- 进行常规的激光雕刻/切割时（非小物件）
- 加工较大的板材或工件时，建议优先选用刀条；如果过大，请使用滚轮送料系统进行加工。

### 操作步骤

- 将刀条尖端朝上；

![001.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/accessory-installation-guide/zh/001.png)

- 一端先插入卡槽中，另外一端再向下插入，听见“咔哒”声则代表刀条安装到位；

|  |  |
| --- | --- |
| 002.png | 003.png |

> 注意：常规使用时，每隔 2 个卡槽放一根支撑条；加工小的耗材（如吊牌等），建议将刀条紧密安装。

- 刀条安装完毕后，可再次检查刀条是否已按压到位，均处于水平状态。

![004.png](https://public-cdn.bblmw.com/wiki/new/r1/manual/accessory-installation-guide/zh/004.png)

## 托盘

托盘是机器的密封结构件，用于防止工作时漏光、漏烟，限制雕刻/切割过程中产生的火焰及烟尘，同时承接加工过程中产生的碎屑。

### 何时安装？

进行任何激光任务前都必须安装托盘。

### 操作步骤

将托盘沿轨道推到底，听见“咔哒”声则代表托盘安装到位；

从前部扣手位拉出托盘，即可将其取出。

## 材料固定夹

材料固定夹用于夹住起翘变形的材料，使其边缘平整，避免加工时翘起影响成品效果。

### 何时安装？

加工材料发生翘曲，需使用材料固定夹固定。

### 安装步骤

- **将材料固定夹卡入刀条的底部**。

![008.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/accessory-installation-guide/zh/008.gif)

- 适当移动木板，让翘曲位置覆盖在固定夹内，并**确保材料边缘与固定夹内侧贴合**。

|  |  |
| --- | --- |
| 009.png | 010.png |

**提示**

若材料宽度不够，无法卡入固定夹，可以将材料斜放后再夹紧固定。

- 向下按压固定夹，直到完全压紧。

![011.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/accessory-installation-guide/zh/011.gif)

- 使用轻薄的材料时，单次压紧可能无法完全固定。请**向上推动**两侧的手柄，同时按压顶部压块，以更好地压紧材料。

![012.gif](https://public-cdn.bblmw.com/wiki/new/r1/manual/accessory-installation-guide/zh/012.gif)

## 注意事项

- 请确保刀条卡入到位、无翘起，未安装到位可能导致加工异常；
- 避免在未放置工件的情况下空加工，激光长期直接打在刀条/托盘上会导致金属镀层脱落，极端情况下配件会产生热变形而无法正常使用；
- 长期使用后请及时清理配件表面的积灰与加工碎屑。
