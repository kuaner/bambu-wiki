## 连接 LED 灯板

1. 将 LED 背光板翻至背面，按顺序整齐摆放，确保 PH2.0 接口处凸起的一面朝上，然后连接灯板。
2. **注意：**

- Make My Lithophane 支持生成三种尺寸的相框，分别由 2、3 和 4 块灯板拼接而成。每块灯板有两个并联的电源插口,可作为电流入口或出口。请确保所有灯板连接起来，并将其中一块灯板与 USB 电源线连接。根据需要调整连接方式（参考下图中的推荐连接方式）。
- PH2.0 电源连接线的两端没有区别，可连接至任意接口。
- 此步骤先不要将 USB 电源线连接至 LED 灯板。

## 连接电源线

1. 根据打印的浮雕⽅向（竖向或横向），将 USB 电源线从预留孔位穿⼊相框。
2. 将 USB 电源线的 PH2.0 的⼀端连接⾄ LED 灯板（相框有两个孔位，可根据浮雕⽅向选择适当插⼝插⼊ USB 电源线）

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 固定 LED 灯板

1. 调整 LED 灯板底部连接线的位置，确保平整⽆凸起。
2. 将 LED 灯板卡⼊相框内部边缘的弹性卡扣下，并平铺在相框内。
3. 将电源线卡⼊固定⼝内。

**注意：** 如灯板⽆法平铺，请检查相框内的打印⽀撑是否清理⼲净，或连接线是否放置整⻬。

## 安装浮雕

轻轻掰开相框的插⼊⼝，将打印的浮雕嵌⼊相框。

|  |  |
| --- | --- |
|  |  |

## 接通电源

连接电源，轻触开关即可点亮浮雕。⻓按开关可调节亮度。

|  |  |
| --- | --- |
|  |  |

如需取下灯板，可按下⼀侧卡扣，并使⽤螺丝⼑从缝隙将灯板撬出。
