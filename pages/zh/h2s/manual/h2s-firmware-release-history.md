## 01.02.00.00 (20260331)

### 新功能

1. 支持远程开启烘干功能

|  |  |
| --- | --- |
|  |  |

2. 支持边烘边打功能，需要注意功率限制和烘干温度不能高于材料的软化温度
3. 支持局域网下不插入U盘发起打印
4. 新增热床底部异物检测
5. 新增AI检测报错弹窗显示实况图像  
   ![ai弹窗.png](https://wiki.bambulab.com/h2/releasenote/ai%E5%BC%B9%E7%AA%97.png)
6. 新增热床低功率模式  
   以便于在用户打印机供电功率受限的情况下，通过延长热床升温时间，降低最大功率  
   开启方式：在打印机屏幕上，进入“设置”页面，开启“低功率模式”即可。  
   ![zh-low-power-mode.jpg](https://wiki.bambulab.com/h2/releasenote/zh-low-power-mode.jpg)
7. 新增认证电子标签信息页  
   ![电子标签.png](https://wiki.bambulab.com/h2/releasenote/%E8%AE%A4%E8%AF%81%E4%BF%A1%E6%81%AF.png)
8. 新增打印结束后净化空气选项  
   打印完成后，会自动进行 3 分钟的空气净化。需要 Bambu Studio 2.5.0.64 及以上版本  
   ![打印结束后净化空气.png](https://wiki.bambulab.com/h2/releasenote/%E6%89%93%E5%8D%B0%E7%BB%93%E6%9D%9F%E5%90%8E%E5%87%80%E5%8C%96%E7%A9%BA%E6%B0%94.png)
9. 新增俄语操作语言
10. 新增支持打印机右上角物理按键暂停打印功能
11. 新增打印发起停止后进入停止中状态，此时打印机会屏蔽操作输入直到停止动作结束，避免在停止动作进程中由于插入操作指令导致控制指令时序错乱的问题
12. 新增冷却模式下开启自适应空气循环系统的过滤功能，该功能主要用于低温耗材打印过程中将空气通过过滤器过滤再排出,支持在切片软件中设置该选项或通过UI开关进行操作。切片设置该选项需要使用Studio 2.5.0.64及以上版本  
    ![冷却模式下过滤.jpg](https://wiki.bambulab.com/h2/releasenote/%E5%86%B7%E5%8D%B4%E6%A8%A1%E5%BC%8F%E4%B8%8B%E8%BF%87%E6%BB%A4.jpg)
13. 新增刀切模式下的俯视摄像头初始化
14. 优化耗材编辑页面耗材颜色显示框，新增可显示渐变或双色耗材的能力
15. 新增支持旋转轴加工，需要 Bambu Suite 01.02.01.00 及以上版本  
    新增结合旋转轴附件实现圆柱及旋转体工件的激光加工；结合无接触3D测高算法与运动规划算法，分别完成圆柱体与旋转体的加工路径生成与加工执行。整体流程简洁，将多项功能一键整合，并通过相机拍照实现所见即所得的加工效果。  
    ![旋转轴1.png](https://wiki.bambulab.com/h2/releasenote/%E6%97%8B%E8%BD%AC%E8%BD%B41.png)  
    新增页面可以实时查看旋转轴角度，雕刻前可以通过此页面调整旋转轴到水平，拍摄出更符合实物位置的展开图，并提升雕刻精度  
    ![旋转轴2.jpg](https://wiki.bambulab.com/h2/releasenote/%E6%97%8B%E8%BD%AC%E8%BD%B4%E5%8A%A0%E5%B7%A5.jpg)  
    ![旋转轴3.jpg](https://wiki.bambulab.com/h2/releasenote/%E6%97%8B%E8%BD%AC%E8%BD%B43.jpg)
16. 新增触碰裹头检测功能，需要 Bambu Studio 2.5.2.65 及以上版本  
    在打印的第4、11、20层，该功能会额外让工具头运动到热床外进行试探触碰，以增加裹头发生时的识别概率。该功能在工艺预设下“其他-高级"中打开。配合“打印校准-触碰裹头检测校准”以提高检出率。更多信息请参考wiki：<https://wiki.bambulab.com/zh/software/bambu-studio/nozzle-clumping-detection-by-probing>
17. 新增外挂料手动换料多色打印入口  
    添加了一个专用小工具，以便在使用外部线轴时简化多色打印流程。该工具可协助手动更换耗材，确保在没有 AMS 的情况下实现更顺畅的颜色过渡。  
    ![外挂料多色打印.jpg](https://wiki.bambulab.com/h2/releasenote/%E5%A4%96%E6%8C%82%E6%96%99%E5%A4%9A%E8%89%B2%E6%89%93%E5%8D%B0.jpg)
18. 支持曲面雕刻功能  
    <https://wiki.bambulab.com/zh/software/bambu-suite/manual/surface-engraving>
19. 支持曲线规划增强

## 01.01.00.00 (20250826)

### 新功能

1. 新增打印板偏移检测功能

该功能在打印准备阶段通过实况摄像头和工具头摄像头捕捉热床限位块等特征检测打印板是否放到正确对齐的位置，防止打印板干涉、调平异常、打印板边沿打印时越界等问题，该功能需Bambu Studio更新到V2.2.1.58或更高的版本。

![打印板偏移cn.png](https://wiki.bambulab.com/h2/releasenote/%E6%89%93%E5%8D%B0%E6%9D%BF%E5%81%8F%E7%A7%BBcn.png)

2. 新增AI裹头检测功能

该功能通过实况摄像头采集图像，配合AI算法，在检测到可能发生裹头时暂停打印，以减小裹头损坏打印机的风险。该功能启用时，建议打开机箱灯，不处于狂暴模式下，以获得更高的检测正确率。该功能可能对黑色深色料的裹头检测较为滞后。

3. 新增XY轴清洁与丝杆润滑的维护提醒

在XY轴与丝杆达到维护周期时通过HMS提醒，打印机组件的使用时长从第一次使用开始计算，更新该版本后部分组件可能会弹出提醒，请按指引参考即可，更多清洁维护建议请参考该wiki：<https://wiki.bambulab.com/zh/h2s/maintenance/period-maintenance>

![润滑提醒cn.png](https://wiki.bambulab.com/h2/releasenote/%E6%B6%A6%E6%BB%91%E6%8F%90%E9%86%92cn.png)

4. 新增对自动灭火装置（需另购）的支持（需要支持该功能的Bambu Suite版本配合使用）
5. 新增俯视摄像头偏移检测功能

系统检测到俯视摄像头由于长时间使用或震动而出现位置偏移时，会提示用户执行俯视摄像头初始化，以提升整机加工的位置精度。
