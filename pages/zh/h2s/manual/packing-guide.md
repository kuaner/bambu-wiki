## 操作步骤

### 1. 移除 AMS 2 Pro

按下图所示，移除AMS和打印板背后的料管与6PIN线缆。  
![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/1.png)

按住入料口的黑色圆环，将料管取下。  
![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/2.png)

移除打印机背后的6PIN线缆，按住解锁扣即可拔出线缆。  
![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/3.png)

按住料管上方的黑色硅胶，将料管拔出，最后取下AMS上的6PIN线缆。  
![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/4.png)  
![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/5.png)

将AMS从打印机顶部取下。

![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/7.png)

### 2. 移除外挂料盘

若您安装了外挂料盘，只需握住整个外挂支架向上推即可将其取下。  
![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/8.png)

### 3. 固定打印机热床

将热床适当升高，放入热床底部的泡棉。  
![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/9.png)

完成后，在打印机屏幕上点击热床下降。  
![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/10.png)

如下图所示，需将热床压入底部泡棉，注意接近底部时，需每次降低1mm进行操作，防止打印机冲撞底部。  
![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/11.png)  
完成后关闭打印机电源，取下安全钥匙和电源线。  
![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/12.png)

接下来，安装热床尾部的固定块和泡棉，并锁紧4颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 4. 安装舱内泡棉并固定工具头组件

安装左右两侧丝杆顶部的泡沫以及空气滤芯上方的泡沫。

|  |  |
| --- | --- |
|  |  |

安装尾部丝杆的保护泡沫。

![01.webp](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/01.webp)

安装泡沫以固定拖链。

![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/18.png)

在工具头两侧安装扎带，固定工具头以防其左右移动。

|  |  |
| --- | --- |
|  |  |

### 5. 固定 AMS 2 Pro

放入AMS固定支架并锁入四颗螺丝。

![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/21.png)

插入AMS，注意若您使用的是激光版本，需将排烟管、转接件、气管等物品放入AMS内，详情可参考[H2S配件清单](acc-in-the-box.md)。

|  |  |
| --- | --- |
|  |  |

安装AMS后方的泡棉，防止运输过程中出现晃动。

|  |  |
| --- | --- |
|  |  |

安装顶部左右两个AMS固定支架。

|  |  |
| --- | --- |
|  |  |

### 9. 装箱

💡 **在装箱前，若底壳需要折叠，请点此展开参考动图操作。**

- **步骤一：**  
  ![bottom_shell_folding_4.webp](https://wiki.bambulab.com/h2s/manual/packing-guide/bottom_shell_folding_4.webp)
- **步骤二：**  
  ![bottom_shell_folding_5.webp](https://wiki.bambulab.com/h2s/manual/packing-guide/bottom_shell_folding_5.webp)
- **步骤三：**  
  ![bottom_shell_folding_a.webp](https://wiki.bambulab.com/h2s/manual/packing-guide/bottom_shell_folding_a.webp)

  ![bottom_shell_folding_b.webp](https://wiki.bambulab.com/h2s/manual/packing-guide/bottom_shell_folding_b.webp)

套上防潮袋并将设备装入底壳内（装入底壳步骤需两人同时操作）。

![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/33.png)

![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/34.png)

![1.png](https://public-cdn.bblmw.com/wiki/new/aether/h2s/packing-guide/39.png)
