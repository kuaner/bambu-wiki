## 注意事项：

> 请务必严格按照本文所述的拆装顺序进行操作。特别是在拆卸挤出机前盖之前，务必先移除进料霍尔组件（操作时请小心，避免用力拉扯），否则可能会导致进料霍尔组件的排线断裂。

![damage2.png](https://wiki.bambulab.com/h2s/maintenance/damage2.png)

## 适用场景

打印机报错挤出电机过载、空打或者打印机未报错，但是可以观察热端无法出料。

## 问题可能发生的位置

1. 挤出机组件
2. 热端

## 所需工具

- H1.5和H2.0内六角扳手
- 镊子、吹气球
- 双面胶

![tool_001.jpeg](https://public-cdn.bblmw.com/wiki/new/h2/h2s/troubleshooting/clogging/tool_001.jpeg)

## 排障步骤

### 步骤1. 移除热端

从侧面用力按压工具头前盖，解锁并移除工具头前盖。  
![step1_001.png](https://public-cdn.bblmw.com/wiki/new/h2/h2s/troubleshooting/clogging/step1_001.png)

确认热端温度处于室温，按压切刀切断耗材。

|  |  |
| --- | --- |
|  |  |

取下旋转轮。用 H1.5 内六角扳手移除 2 颗螺丝，取下料线压块。正常情况下，不需要拆除料线压块就能直接移除热端，本文这样做的目的是方便后续清洁，因此先拆除料线压块。

|  |  |  |
| --- | --- | --- |
|  |  |  |

移除硅胶套，解除热端锁扣，然后用手握住散热片，将热端取出。

|  |  |
| --- | --- |
|  |  |

### 步骤2. 手动挤出

取下热端后，将耗材送入挤出机并尝试手动挤出，点击屏幕上的挤出键。如果打印机提示“请将喷嘴加热至170℃以上”，可选择“本次不再提醒”。  
若耗材顺利挤出，说明很可能是热端堵塞了，建议您参考[H2S热端堵塞清理](nozzle-clog.md)疏通热端。

|  |  |
| --- | --- |
|  |  |

若耗材无法正常挤出或回抽，说明挤出机堵塞或者卡料了，需要拆开挤出机清理。请跳转至步骤3.

> **提示：** 为了更好地帮助诊断问题，请在提交工单时 **上传手动挤出** 的视频。确保视频内容包括：**清晰展示进料路径、手动进料步骤及最后结果**。

### 步骤3. 普通清洁

用 H2.0 内六角扳手移除切刀螺丝，松开切刀刀柄。即可从挤出机侧面进行清洁。  
![step3_001.png](https://public-cdn.bblmw.com/wiki/new/h2/h2s/troubleshooting/clogging/step3_001.png)  
使用镊子或吹气球从图示位置清理内部的断料和残渣，断电状态下可手动拨动黑色齿轮顺时针旋转清理，让挤出轮旋转到指定角度清理。

|  |  |
| --- | --- |
|  |  |

当按上面的步骤清理挤出机后，仍然无法正常挤出时，你可以对挤出机进行拆解，取下挤出机组件进行深度清洁。

### 步骤4. 深度清洁

按压黑色外圈，断开PTFE管。  
![step4_001.png](https://public-cdn.bblmw.com/wiki/new/h2/h2s/troubleshooting/clogging/step4_001.png)  
用 H2.0 内六角扳手移除 2 颗螺丝，在取出进料霍尔组件之前，可以在工具头上方贴上双面胶，用于放置进料霍尔组件，防止中途掉落，如图所示。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

需要注意的是，进料霍尔组件的后面有一根FPC排线，拆除时请小心操作，避免扯断排线。

![step4_019.png](https://public-cdn.bblmw.com/wiki/new/h2/h2s/troubleshooting/clogging/step4_019.png)

移除前盖前，先拧松侧边的螺丝，（只需要拧松一些即可），然后移除挤出机前盖上的 4 颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

用力取出挤出机前盖。移除前盖时，请小心前盖轴承和弹簧脱出。

|  |  |
| --- | --- |
|  |  |

最后完全移除侧面螺丝，用镊子小心地取出内部弹簧和端盖，取出后保存起来，防止丢失。

|  |  |  |
| --- | --- | --- |
|  |  |  |

移除从动杆支架，并取出挤出机齿轮。

|  |  |
| --- | --- |
|  |  |

清理挤出机内部残留的耗材残渣。

![step4_016.png](https://public-cdn.bblmw.com/wiki/new/h2/h2s/troubleshooting/clogging/step4_016.png)

同样使用吹气球或者镊子清理挤出齿轮和从动轮上的耗材残渣。

|  |  |
| --- | --- |
|  |  |

### 步骤5. 安装挤出机和喷嘴

安装挤出齿轮。  
![step5_001.png](https://public-cdn.bblmw.com/wiki/new/h2/h2s/troubleshooting/clogging/step5_001.png)  
将从动轮支架安装到对应的转轴上。  
![step5_002.png](https://public-cdn.bblmw.com/wiki/new/h2/h2s/troubleshooting/clogging/step5_002.png)  
然后将弹簧和端盖以正确的方向和位置安装到一起，安装时端盖需要朝向螺丝这一侧。用镊子将弹簧和端口放到从动轮支架对应的位置上，拧入侧面螺丝将其顶住，但先不要将其拧得太紧。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

安装挤出机前盖并拧入挤出机前盖的 4 颗螺丝，最后拧紧挤出机侧面螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

从胶带上取下进料霍尔组件，在安装前请使用镊子等工具将排线推到理线槽内，防止排线脱出，导致拧入螺丝时排线损坏。

|  |  |
| --- | --- |
|  |  |

安装过程中请确保黑色 FPC 线缆不要被折叠。然后拧入 2 颗螺丝，固定进料霍尔组件。

|  |  |
| --- | --- |
|  |  |

然后移除工具头上的胶带。

![step5_012.png](https://public-cdn.bblmw.com/wiki/new/h2/h2s/troubleshooting/clogging/step5_012.png)  
用镊子抬起刀柄，沿着刀槽将切刀滑入到位，拧紧螺丝，固定刀柄。

|  |  |  |
| --- | --- | --- |
|  |  |  |

安装喷嘴并锁紧热端卡扣，安装热端硅胶套。

|  |  |
| --- | --- |
|  |  |

装入料线压块，拧紧 2 颗螺丝，固定料线压块。

|  |  |
| --- | --- |
|  |  |

安装旋转轮。

![step5_020.png](https://public-cdn.bblmw.com/wiki/new/h2/h2s/troubleshooting/clogging/step5_020.png)  
安装PTFE管和工具头前盖。
