## 故障描述

喷嘴温度控制系统主要由加热器和NTC传感器组成。TH板负责监测加热器的输出功率和NTC传感器的温度。当加热器以满功率运行但温度在预定时间内未能达到设定目标时，将触发加热器过温警报。

以下是出现此 HMS 错误代码的可能原因：

1. 加热器的连接器出现开路
2. 加热器坏了
3. TH板坏了

## 故障排除

### 工具、设备及材料

- H1.5 内六角螺丝刀
- 万用表

### 排故措施

***用户可视情调整各排故措施的顺序。***

#### 步骤1：检查热端硅胶套是否完好且安装正确

[更换H2S热端与热端硅胶套](../../maintenance/replace-silicone-sock-and-hotend.md)

#### 步骤2：检查热端加热组件插头是否松动或线缆有破损

参考[更换H2S热端加热组件](../../maintenance/replace-hotend-heating-assembly.md)教程检查热端加热组件线缆插头是否松动，线缆是否有破损。

1. **若线缆及连接器完好，有条件的话可以利用万用表进一步检查热端加热组件NTC和加热片的电阻值**

如果您有万用表可以尝试根据下面的步骤测量一下热端组件的电阻以判断是否为热端故障。常温下陶瓷加热片的电阻一般是**7Ω**（测量下图中红色箭头指向的两个pin脚），热敏电阻 NTC 的阻值为**100 KΩ**（测量下图中橙色箭头指向的两个 pin 脚，NTC 的电阻受温度波动范围大）

|  |  |
| --- | --- |
|  |  |

- 若万用表测量阻值异常，则可能是热端加热组件故障。
- 若万用表测量电阻正常，可能是TH板故障。
