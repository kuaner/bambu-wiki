## 故障描述

工具头摄像头镜头表面可能因灰尘、油脂或有机蒸汽而变脏，尤其是在长时间打印挥发性材料（如ABS）或使用激光模块进行加工后，挥发物或粉尘容易附着在镜头表面。脏镜头会降低图像的分辨率和对比度，进而影响摄像头的相关功能。定期清洁镜头有助于保持图像清晰度和设备性能。

## 故障排除

### 工具、设备及材料

- 酒精/高浓度异丙醇
- 棉签/微纤维布

### 故障定位与解决流程

#### 步骤1. 确保校准贴纸清洁且状况良好

|  |  |
| --- | --- |
|  |  |

#### 步骤2. 清洁摄像头镜头

- 将热床降至较低位置，方便操作；
- 关闭打印机电源；
- 使用棉签或微纤维布蘸酒精，擦拭摄像头镜头。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/troubleshooting/hmscode/0500_0400_0002_0043/image-1.png)

#### 步骤3. 重启打印机，检查告警是否消失

打开打印机，发起打印任务，观察告警消息是否消失。

#### 步骤4. 若多次清洁无效，更换工具头摄像头

参考Wiki[《更换H2S 工具头摄像头》](../../maintenance/replace-toolhead-camera.md)，更换工具头摄像头。  
如果问题仍未解决，请提交[服务工单](https://bambulab.cn/zh-cn/my/support/tickets/create?from=5)并附上您近期的打印机日志。
