## 注意事项：

> 请务必严格按照本文所述的拆装顺序进行操作。特别是在拆卸挤出机前盖之前，务必先移除进料霍尔组件（操作时请小心，避免用力拉扯），否则可能会导致进料霍尔组件的排线断裂。

![damage2.png](https://wiki.bambulab.com/h2s/maintenance/damage2.png)

## 切刀刀柄

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/143.png)

## 何时使用

当切刀刀柄出现不可逆的机械损坏，或在回弹过程中出现异常时，需要进行本部件的更换。

## 所需要工具和材料

- H1.5内六角螺丝刀
- H2.0内六角螺丝刀
- 新切刀刀柄、垫片、卡簧

## 移除旧的切刀刀柄

### 步骤一：移除前盖组件

捏住前盖底部，向前轻拉即可取下前盖，并移除位于内部的旋转指示轮。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/2.webp)

### 步骤二：移除喷嘴组件

取下喷嘴的硅胶套。然后，打开加热组件的卡扣，即可取出整个喷嘴组件。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/3.webp)

### 步骤三：移除霍尔底座

为方便操作，首先移除顶部的特氟龙管。按住黑色接头，即可将特氟龙管拔出。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/4.webp)

使用 H2.0 螺丝刀，移除霍尔底座顶部的两颗螺丝（BT2x6）。

> 注意：此时霍尔底座下方仍连接有排线。在操作时请务必小心，避免拉扯，以防排线断裂。

|  |  |
| --- | --- |

### 步骤四：移除挤出机前盖

接下来使用 H2.0 螺丝刀，移除切刀固定螺丝（BT2.6x14.5）。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/7.png)

将侧边的从动轮张紧螺丝（M3x12 ）拧松，这能为后续移除前盖提供足够的空间。（拧松即可不用全部移除）

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/8.png)

如果下图所示，使用 H2.0 内六角螺丝刀，移除固定前盖的四颗螺丝（BT3x8）。

|  |  |
| --- | --- |

移除这四颗固定螺丝后，即可取下挤出机前盖。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/yf.webp)

### 步骤五：移除切刀刀柄

> 为防止被刀片划伤，建议先将刀片取出。

使用螺丝刀或镊子按压卡簧，使其松开，即可取下刀片。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/yichu.webp)

随后，小心地取出垫片和切刀刀柄。

> 注意：垫片和卡簧体积较小，请妥善保管，以免遗失。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/yichudaob.webp)

## 安装新的切刀刀柄

### 步骤一：安装切刀刀柄

按照**刀柄 → 垫片 → 卡簧**的顺序进行安装。使用螺丝刀或类似工具，将卡簧轻轻压入，使其卡紧到位。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/yaru.webp)

### 步骤二：安装挤出机前盖

使用 H2.0 内六角螺丝刀，拧入四颗螺丝（BT3x8），将前盖固定。

|  |  |
| --- | --- |

重新拧紧侧边的从动轮张紧螺丝。**如果此螺丝未正确拧紧，可能会导致挤出机无法正常挤出耗材。**

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/14.png)

将刀片插入刀柄对应的槽位。按住切刀刀柄，使用 H2.0 螺丝刀锁紧切刀固定螺丝。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/15.png)

### 步骤三：安装霍尔底座

将霍尔底座放回原位，使用 H2.0 螺丝刀拧紧固定两颗螺丝。并连接PTFE管。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/image.png)

### 步骤四：安装喷嘴组件

如果下图所示安装喷嘴组件和硅胶套。

|  |  |
| --- | --- |

### 步骤五：安装前盖组件

将旋转指示轮放回原位。并扣回前盖组件，确保其卡紧到位。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/17.jpg)

## 功能验证

安装完成后，请多次按压切刀，确保其回弹顺滑、无卡滞现象。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-cutter-lever/sunh.webp)
