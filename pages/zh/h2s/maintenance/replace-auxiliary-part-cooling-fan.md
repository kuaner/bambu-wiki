## 辅助部件冷却风扇

辅助部件冷却风扇安装于打印机腔室左侧，可在高速打印时提供更强的风冷支持，优化冷却条件并提升成型稳定性。

![](https://wiki.bambulab.com/h2s/maintenance/replace-auxiliary-part-cooling-fan/1.png)

## 套件清单

**辅助部件冷却风扇的备件包含以下：**

1. 辅助部件冷却风扇\*1
2. 软螺钉 - 用于固定辅助部件冷却风扇上排两个螺丝孔位 \* 2；
3. BT3x16螺丝 - 用于锁辅助部件冷却风扇下排两个螺丝孔位 \* 2。

![](https://wiki.bambulab.com/h2s/maintenance/replace-auxiliary-part-cooling-fan/9.png)

## 何时更换

- 叶片损坏或风扇电机故障
- 风扇异响

## 所需工具

- 新的辅助部件冷却风扇
- H2.0 内六角扳手

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 移除辅助部件冷却风扇

### 步骤 1. 下降热床

在打印机屏幕上将热床下降至**最低位置**，为后续操作留出空间，避免刮碰或夹手。

|  |  |
| --- | --- |
|  |  |

### 步骤 2. 关闭电源并断开电源线

> **安全提示：** 对机器进行任何拆装前，务必先**断电**，防止触电或误动作。

关闭打印机电源开关，并**拔下电源线**。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-x-axis-assembly/image-11.png)

### 步骤 3. 移除背板

依次拆下 **11 颗钣金自攻螺钉（ST3×6）** 与 **12 颗塑料自攻螺钉（BT3×8）**。

> 建议提前准备两个小盒子，分别存放两种规格的螺钉，避免混淆。

1. 使用 H2.0 直柄内六角扳手移除 11 颗 ST3×6（前面图片中的红色圆圈标记， ST3×6）
2. 使用 H2.0 直柄内六角扳手移除 12 颗 BT3×8（前面图片中的绿色方框标记，BT3×8）
3. 黄色标记为外挂料盘固定螺钉（M3×12）

![](https://wiki.bambulab.com/h2/maintenance/replace-rear-panel/image-29.png)

4. 按压气管接头以避开干涉，然后将背板向后轻轻倾斜并取出。

![](https://wiki.bambulab.com/h2/maintenance/replace-rear-panel/image-31.png)

### 步骤 4. 移除玻璃前门

使用 H2.0 内六角扳手（2.0 mm）拧下固定前门的 4 颗螺丝（M3x3，螺帽直径 10 mm），上下各 2 颗。拆卸时一手扶住玻璃前门，再将前门取下。

> **注意：** 拆卸过程中请始终用手扶住玻璃前门，防止跌落。

|  |  |
| --- | --- |
|  |  |

### 步骤 5. 取下辅助部件冷却风扇

1. 使用 H2.0 内六角扳手，移除辅助部件冷却风扇**底部**的两颗固定螺丝（BT3x16）。

> **注：** H2S 的辅助部件冷却风扇固定螺丝均位于**底部小孔**内.

![](https://wiki.bambulab.com/h2s/maintenance/replace-auxiliary-part-cooling-fan/9.png)

2. 风扇**上方**的两颗螺丝为**软螺钉**（起定位作用）。当下方两颗固定螺丝拆下后，用一只手**托住风扇本体**，拔出风扇组件。取下后，可将风扇**放置在热床上**。

|  |  |
| --- | --- |
|  |  |

### 步骤 6. 移除左侧板固定螺丝

1. 使用 **H2.0 内六角扳手**，先拆下固定于上框的 **2 颗固定螺丝（BT3×8）** 和固定于横梁的 **1 颗固定螺丝（BT3×8）**。

> **注：** AP 板盖上已预留对应孔位，**无需**移除 AP 板盖也可拆下上框的 2 颗螺丝。下图为便于拍摄示意，故将 AP 板盖取下。

|  |  |
| --- | --- |
|  |  |

2. 拆下固定在立柱的 **2 颗 M3×3**。这两颗螺丝位于**胶条后方**，请从胶条的**开孔处**轻撬胶条，即可看到螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 7. 移除左侧板

1. 左侧板除螺丝固定外，还通过卡扣定位在机身上。开始前，请先将左侧板边缘的硅胶从断口处**撕断**，再进行后续操作。

![](https://wiki.bambulab.com/h2/maintenance/replace-side-panel-with-glass-window/image-74.png)

2. 随后从设备后方**先释放卡扣**：

|  |  |
| --- | --- |
|  |  |

3. 接着使用 **内六角扳手**从**顶部**位置**轻撬卡扣**，再从**正面**缓慢掰开左侧板；将贴附在左侧板上的胶布**撕下**后，取下左侧板：

|  |  |
| --- | --- |
|  |  |

4. 请同时留意**辅助部件冷却风扇后方**螺丝孔位附近的**圆形硅胶塞**，拆卸过程中注意收好，避免丢失：

|  |  |
| --- | --- |
|  |  |

### 步骤 8. 移除辅助部件冷却风扇

1. 将用于**固定辅助部件冷却风扇连接线**的胶布先**撕开并松开线缆**，再把这段胶布**临时贴在横梁上**，以便后续回装时继续用于固定。

|  |  |
| --- | --- |
|  |  |

2. 随后按住连接器上的**卡扣**（下图红色箭头所示），将线缆从 **MC 板**上**断开**，并沿**左内衬与立柱的缝隙**将线缆**顺势抽出**。

|  |  |
| --- | --- |
|  |  |

### 步骤 9. 移除辅助部件冷却风扇软螺钉（可选）

**若软螺钉未损坏且长度足以穿过辅助部件冷却风扇，可直接跳过本步骤，无需更换。**

从机身外侧拉动软螺钉，即可将软螺钉从打印机横梁上取下。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 安装辅助部件冷却风扇

### 步骤 1. 安装辅助部件冷却风扇软螺钉（可选）

**若软螺钉未损坏且长度足以穿过辅助部件冷却风扇，可直接跳过本步骤，无需更换。**

将软螺钉穿过横梁上的小孔，然后拉动软螺钉直至卡入横梁中。

> **注意：** 请**缓慢拉动**，避免损坏软螺钉。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 2. 连接风扇电缆

1. 将新的辅助部件冷却风扇的连接线从侧板与内衬的缝隙中穿过，与 MC 板连接，最后将左侧板霍尔连接线（红白黑）和辅助部件冷却风扇连接线卡入 AC 板盖的线扣中；

![](https://wiki.bambulab.com/h2/maintenance/replace-auxiliary-part-cooling-fan/image-30.png)

|  |  |
| --- | --- |
|  |  |

2. 使用胶布将线缆贴在横梁上。

> 注：您可以使用旧的胶布来粘贴。

![](https://wiki.bambulab.com/h2/maintenance/replace-auxiliary-part-cooling-fan/image-57.png)

### 步骤 3. 扣紧左侧板的卡扣

1. 在安装前请先检查横梁螺丝孔位置处的硅胶塞是否安装到位，如果没有找到请检查是否留在打印机左侧横梁上；

|  |  |
| --- | --- |
|  |  |

2. 将左侧板底部的两个大插销先与打印机底部对应的小孔对齐并插入；

> 建议先将打印机背面的卡扣推进，因为背面的卡扣没有用于固定的舌头，更容易推进。

![](https://wiki.bambulab.com/h2/maintenance/replace-auxiliary-part-cooling-fan/image-54.png)

3. 将左侧板缓缓往上推，先用手托住扶手处，将扶手处的卡扣卡入打印机底部，然后将靠近前门和背面的两个小卡扣插入打印机底部对应的小孔中；

|  |  |
| --- | --- |
|  |  |

4. **将左侧板底部装好后请先检查底部所有的卡扣是否已经扣到位，并且没有浮起。**然后再将左侧板往内推，将所有卡扣扣到位。

![](https://wiki.bambulab.com/h2/maintenance/replace-auxiliary-part-cooling-fan/image-55.png)

### 步骤 4. 拧紧左侧板固定螺丝

1. 使用 H2.0 内六角扳手拧紧两颗左侧板内侧的螺丝（BT3x8），然后使用 H2.0 内六角扳手拧紧一颗固定在横梁上的螺丝（BT3×8）；

|  |  |
| --- | --- |
|  |  |

2. 撬开硅胶条上的开口，使用 H2.0 内六角扳手拧紧两颗固定螺丝（ST3x3）；

> 如果开口不好撕开，拧可以使用内六角扳手来辅助撬开。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 5. 安装辅助部件冷却风扇

**方法一：**

1. 将软螺钉穿过辅助部件冷却风扇上的靠近内侧的小孔，然后用手拉动软螺钉，将辅助部件冷却风扇的顶部通过软螺钉固定；将内侧的安装完成后再安装外侧的软螺钉；

> 注：软螺钉拉到位时可听见“咔哒”一声。

|  |  |
| --- | --- |
|  |  |

2. 使用 H2.0 内六角扳手拧紧两颗底部固定螺丝。

> 注：H2S 的辅助部件冷却风扇的固定螺丝均位于下方的小孔中。

|  |  |
| --- | --- |
|  |  |

**方法二：**

1. 您可以先将辅助部件冷却风扇对准左侧板上的螺丝孔位，然后使用 H2.0 内六角扳手拧紧底部两颗固定螺丝（BT3x16）；

|  |  |
| --- | --- |
|  |  |

2. 双手轻微掰开辅助部件冷却风扇，将风扇顶部两个螺丝孔位对准软螺钉，将软螺钉插入孔位中；

![](https://wiki.bambulab.com/h2/maintenance/replace-auxiliary-part-cooling-fan/image-73.png)

3. 使用尖嘴钳等工具将软螺钉拉出一些，然后拉动软螺钉使其固定住风扇。

|  |  |
| --- | --- |
|  |  |

> **注意：** **避免使用具备剪切/裁断功能的钳子**（例如斜口钳），以免将软螺钉越夹越短。

### 步骤 6. 装回玻璃前门/激光防护视窗（前）

用 H2.0 内六角扳手移除固定前门的 4 颗螺丝（M3x3，螺帽直径 10mm），上下各 2 颗，然后一只手扶住前门玻璃，将前门取下。

> 注意用手扶住前门玻璃，防止跌落。

|  |  |
| --- | --- |
|  |  |

### 步骤 7. 安装背板

1. 先将背板斜着插入打印机底部

![](https://wiki.bambulab.com/h2/maintenance/replace-rear-panel/image-38.png)

2. 使用 H2.0 内六角扳手拧紧 11 颗螺丝（红色圆圈标记， ST3×6）
3. 使用 H2.0 内六角扳手拧紧 12 颗螺丝（绿色方框标记，BT3×8）

![](https://wiki.bambulab.com/h2/maintenance/replace-rear-panel/image-39.png)

4. 将料盘支架底座对准打印机背面的孔位，然后使用 H2.0 内六角扳手拧紧两颗固定螺丝。

![](https://wiki.bambulab.com/h2/maintenance/replace-rear-panel/image-40.png)

## 如何验证完成/成功

连接电源线并开启电源，在屏幕上点击辅助部件冷却风扇图标，开启辅助冷却风扇。

1. 连接电源线并开启打印机。
2. 打开 **控制** 界面，点击 **空调系统**。

![](https://wiki.bambulab.com/h2s/maintenance/replace-auxiliary-part-cooling-fan/cn-1.png)

3. 选择 **辅助**。

![](https://wiki.bambulab.com/h2s/maintenance/replace-auxiliary-part-cooling-fan/cn-2.png)

4. 打开右上角开关，并按需设置转速。

![](https://wiki.bambulab.com/h2s/maintenance/replace-auxiliary-part-cooling-fan/cn-3.png)

如果辅助部件冷却风扇按预期工作，那么更换完成。否则，请返回检查步骤和连接后重试。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
