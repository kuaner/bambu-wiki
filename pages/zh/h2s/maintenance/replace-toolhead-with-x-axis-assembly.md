## 工具头线轨组件

本文提供 H2S 工具头线轨组件更换的相关指引和注意事项，但不包括工具头部分的拆装。

## 何时更换

- 工具头线轨组件损坏或者无法按照预期工作

## 所需的工具和材料

1. 新的工具头线轨组件
2. H1.5 和 H2.0 内六角扳手、短内角扳手
3. L 型内六角扳手
4. 镊子

## 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。  
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 拆解步骤

### 步骤 1：降低热床

通过屏幕下降热床，确保热端处于室温状态，关机。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-2.png)

### 步骤 2：移除PTFE管

按压工具头上方的气动接头，断开工具头上方的PTFE管。推出缓冲器的气动接头，按压解锁气动接头。

|  |  |
| --- | --- |
|  |  |

从拖链中抽出PTFE管。

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-3.png)

然后解锁打印机背面进料口处的气动接头，移除 PTFE 管。

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-4.png)

### 步骤 3：移除热端

参考此教程移除热端（[点击此处跳转](replace-silicone-sock-and-hotend.md)）

### 步骤 4：移除 AP 理线盖

使用 H2.0 内六角扳手拧下 1 颗固定螺丝（BT2.6x8），然后从靠近前门的一侧取下 AP 板盖。

|  |  |
| --- | --- |
|  |  |

### 步骤 5：移除缓冲器并断开 USB-C 线缆

拧下USB-C理线扣中的螺丝。

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-8.png)

从卡扣中抽出线缆，断开 USB-C 数据线；

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-9.png)

使用 H2.0 内六角扳手移除四颗固定螺丝，松开缓冲器。

|  |  |
| --- | --- |
|  |  |

从卡扣中抽出USB-C线缆

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-7.png)

### 步骤 6：移除拖链

将这段拖链从卡槽中拆除，请注意先将拖链略微往下拉，使拖链右上角从卡槽中脱出后，再用力拔出整段拖链。

（以H2D机型操作为例，H2S操作方法完全一致）

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-11.png)

### 步骤 7：移除皮带

拧出皮带固定座上的 2 颗螺丝，拆除皮带固定座。

|  |  |
| --- | --- |
|  |  |

用同样的方法拆除另一侧的皮带固定座。

|  |  |
| --- | --- |
|  |  |

### 步骤 8：在线轨两边贴无痕胶布，防止滑块滚珠脱落

在工具头两侧粘贴无痕胶布，如果没有无痕胶布，可以将纸片贴在线轨上然后用透明胶粘贴。这一步的目的是限制工具头移动，防止拆除线轨时工具头直接滑出线轨。

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-16.png)

### 步骤 9：移除线轨组件

使用镊子辅助拆除左右两侧的 LED 灯盖。

|  |  |
| --- | --- |
|  |  |

在框架中部有一个预留的孔位，使用L型内六角扳手穿过这个孔，可以很方便地拆除滑车顶部的这颗线轨螺丝。

> 务必遵循教程，使用螺丝刀穿过泡棉以及预留孔，禁止从螺丝侧面斜向拧动螺丝。

以同样的方式，拆除另一侧滑车上面的线轨螺丝。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-21.png)

然后拆除线轨侧面的4颗螺丝以及滑车底部的2颗螺丝。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

拆除所有螺丝后，即可移除线轨。移除线轨时先将右侧线轨脱离滑车，再将左侧线轨也脱离滑车，然后倾斜着取出线轨。

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-26.png)

## 安装步骤

### 步骤 1：安装线轨组件

安装新线轨组件时，先将线轨右侧插入滑车，再将线轨左侧也插入滑车。然后将线轨往前推直到无法推动，这一步的目的是利用前门立柱进行限位，保证线轨平行。

|  |  |
| --- | --- |
|  |  |

![install-toolhead-assembly.webp](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/install-toolhead-assembly.webp)

为了确保线轨平行，需要将线轨推到最前面才能拧入线轨螺丝，与拆解步骤不同，线轨无法推到中间位置并使用L型内六角扳手拧入线轨螺丝。因此我们建议使用短内六角扳手直接拧入滑车上面的2颗螺丝、线轨侧面的4颗螺丝以及滑车底部的2颗螺丝。

需要注意的是，滑车顶部和底部的螺丝是细螺纹螺丝，线轨侧面的螺丝是粗螺纹螺丝，请勿混淆。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

卡扣对卡扣，装回左右2边的LED灯盖

![]()

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-36.png)

### 步骤 2：移除扎带

线轨组件安装完成后，用尖嘴钳剪掉工具头两侧的扎带。

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-37.png)

### 步骤 3：安装皮带

将皮带固定座重新装入工具头的槽中，然后拧入3颗皮带固定座螺丝。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-40.png)

然后将工具头推到另一侧，安装另一个皮带固定座。由于第一个皮带固定座已经装好，所产生的应力可能会导致第二个皮带固定座难以装入。先预锁中间的那颗螺丝，不要完全拧紧。将上下两颗螺丝完全拧紧后，再重新将中间的螺丝拧紧。

|  |  |
| --- | --- |
|  |  |

### 步骤 4：安装拖链

连接拖链与打印机框架（以H2D机型操作为例，H2S操作方法完全一致）

嵌入拖链卡扣凸点后，后再往前推，确保安装到位

|  |  |
| --- | --- |
|  |  |

![install-cable-chain.webp](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/install-cable-chain.webp)

### 步骤 5：安装缓冲器并连接 USB-C 线缆

将USB-C线缆卡入框架中的凹槽内，对准孔位，装回缓冲器。

|  |  |
| --- | --- |
|  |  |

缓冲器对准螺丝孔位后，使用 H2.0 内六角扳手拧紧四颗固定螺丝（BT3×8），最后重新将两根 PTFE 管与缓冲器连接。

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-47.png)

连接新的 USB-C 数据线时，请注意，插头表面有防晃动胶带，因此需要用点力气才能将其插入，直到感觉到无法再推动为止，这样才算插入到位。

> 注意：A 字这一头与 AP 板连接，并且 A 字朝外！

|  |  |
| --- | --- |
|  |  |

然后将线缆依次卡入线扣中，锁回这颗卡扣固定螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 6：安装AP理线盖

先从靠近打印机背面的一侧扣回 AP 板盖，将箭头所示的两处均按压到位，右侧与缓冲器齐平，底部与护线盖齐平，然后使用 H2.0 内六角扳手拧紧一颗固定螺丝（BT2.6x8）。

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-51.png)

注意：安装 AP 板盖前，需检查线缆是否阻碍 PTFE 管路，避免影响后续 PTFE 管的安装。

|  |  |
| --- | --- |
|  |  |

### 步骤 7：安装PTFE管

穿入PTFE管，连接气动接头

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/h2s/maintenance/replace-toolhead-with-x-axis-assembly/image-55.png)

### 步骤 8：安装热端

参考此教程安装热端（[点击此处跳转](replace-silicone-sock-and-hotend.md)）

## 如何验证完成/成功

重新启动打印机并进行校准，检查是否出现错误警告。如果打印机提示皮带需要张紧，则张紧皮带。
