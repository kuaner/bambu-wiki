## MC 板

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-mc-board/dlb048.png)

MC 板的备件包含如下：

1. MC 板 \* 1
2. 螺丝BT2x5 \*6 - 用于固定 MC 板

## 何时更换

- 正常供电情况下， 主控板工作指示灯不闪烁；
- 连接器损坏，有明显的元器件损坏；
- 拓竹服务团队通过日志文件确认是主控板关联问题。

## 所需的工具和材料

1. 新的 MC 板
2. H2.0 内六角扳手
3. H1.5 内六角扳手

# 安全提示

> 重要提醒 ！  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除 MC 板

### 步骤 1：移除背板

参考打印机背板的相关内容，移除打印机的背板。 [更换 H2 系列打印机背板](../../h2/maintenance/replace-rear-panel.md)

### 步骤 2：移除废料滑梯

参考 废料滑梯 的相关内容，移除废料滑梯。[更换废料滑梯](../../h2/maintenance/replace-purge-chute.md)

### 步骤 3：移除 MC 板

1. 从理线卡扣中取出这一捆线缆，以便为后续拔插头提供操作空间。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-mc-board/mc1.png)

2. 断开MC板上正面的所有连接线。请注意，有些插头采用卡扣结构，需先按压插座上方的卡扣解锁插头才能拔出。具体需要解锁卡扣的插头，参考下图。

|  |  |
| --- | --- |
|  |  |

另外，为了防止运输过程中插头松动，散热片下方的三个步进电机插头使用电子硅胶进行了加固。你需要先使用尖锐的工具，如镊子，在插头周围的胶水上划一道口子，然后再拔出插头。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-mc-board/image-2.png)

3. 使用 H1.5 内六角扳手移除 6 颗固定螺丝，将 MC 板从内衬中取出。请注意，MC板的背面还有一个为拔掉的MC板电源输入插头，请勿用力拉扯.
4. 拔掉MC背面的电源插头.

非激光版本（无内置气泵）H2D 有9个插座空闲，激光版本（有内置气泵）有8个插座空闲。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-mc-board/mc4.png)

Z电机安装在底座上，而AB电机则位于XY平面。如果你不确定AB和Z三个电机的插头，可以稍微拉动一下电缆，观察哪个电机的电缆会有晃动。例如，拉动某个插头时，如果连接A电机的电缆有晃动，就说明该电机是A电机，B电机和Z电机的判断方法也是类似的。

![](https://public-cdn.bblmw.com/wiki/new/aether/h2s/replace-mc-board/image-13.png)

## 如何验证成功

接上打印机电源，开启打印机，在屏幕上操作，运行设备自检流程，如自检通过，说明操作成功。  
否则，请再次检查所有连接并重试。如果仍然不行，请联系 Bambu Lab 服务团队寻求进一步帮助。
