## 第 1 步：开箱和拆除保护套

小心地打开纸盒，移除泡沫插件。

![顶部包材.jpg](https://wiki.bambulab.com/p1/unboxing-p1s_combo/%E9%A1%B6%E9%83%A8%E5%8C%85%E6%9D%90.jpg)

用两个塑料把手把整个东西从盒子里拖出来，放在桌面上。

![包装袋.jpg](https://wiki.bambulab.com/p1/unboxing-p1s_combo/%E5%8C%85%E8%A3%85%E8%A2%8B.jpg)

取出塑料袋，从上盖中取出快速入门指南。（请在进行下一步之前阅读快速入门指南）  
小心地取下上盖上的所有塑料包装纸。

![顶盖包装.jpg](https://wiki.bambulab.com/p1/unboxing-p1s_combo/%E9%A1%B6%E7%9B%96%E5%8C%85%E8%A3%85.jpg)

## 第 2 步：取出配件与 AMS 2 Pro

取出配件盒。

![配件盒3.jpg](https://wiki.bambulab.com/p1/unboxing-p1s_combo/%E9%85%8D%E4%BB%B6%E7%9B%923.jpg)

打开配件盒检查内部物品。

> 配件清单中包含屏幕、料盘支架、喷嘴组件、喷嘴擦拭组件、电源线、通针、特氟龙管、热床刮刀刀片、六角扳手（H1.5 和 H2.0）、4 pin 总线、6 pin 总线、AMS 缓冲器（已预安装）、热端固定卡扣、切刀、纹理 PEI 打印板（已预安装在热床上）、32 GB MicroSD 卡（打印机内）、导热硅脂、润滑脂、快速指南、免责声明和安全指引。

![配件盒.jpg](https://wiki.bambulab.com/p1/unboxing-p1s_combo/%E9%85%8D%E4%BB%B6%E7%9B%92.jpg)

取出机器内 AMS 2 Pro 周围的减震泡棉。

![顶部泡棉.jpg](https://wiki.bambulab.com/p1/unboxing-p1s_combo/%E9%A1%B6%E9%83%A8%E6%B3%A1%E6%A3%89.jpg)

移除前门包装。

![前门包装.jpg](https://wiki.bambulab.com/p1/unboxing-p1s_combo/%E5%89%8D%E9%97%A8%E5%8C%85%E8%A3%85.jpg)

移除 AMS 底座上的两颗固定螺丝，并取出 AMS。

|  |  |
| --- | --- |
|  | 取出ams.jpg |

撕下保护膜并取出电源适配器、料管。

|  |  |
| --- | --- |
| ams膜.jpg | ams电源适配器和料管.jpg |

AMS 包含两个存放干燥剂袋的隔间，以保持内部空气干燥，从而保护您的耗材免受湿气影响。请揭下胶带取出干燥剂，撕开透明包装后将放回。

> 请勿撕开第二层包装。

|  |  |
| --- | --- |
| 干燥剂.jpg | 干燥剂包装.jpg |

## 第 3 步：拆除运输材料

移除 4 颗由红色箭头标签贴指示的安全螺丝，取出 AMS 底座。

|  |  |
| --- | --- |
|  |  |

取出干燥剂和减震泡棉。

|  |  |
| --- | --- |
|  |  |

剪断工具头上的扎带以释放工具头，并拆开工具头四周的纸板。

|  |  |
| --- | --- |
| 剪断扎带.jpg | 工具头纸壳.jpg |

取下其余的减震泡棉。

![吐料组件泡棉.jpg](https://wiki.bambulab.com/p1/unboxing-p1s_combo/%E5%90%90%E6%96%99%E7%BB%84%E4%BB%B6%E6%B3%A1%E6%A3%89.jpg)

拧掉 Z 轴上 3 颗由红色箭头标签贴指示的安全螺丝。

![](https://wiki.bambulab.com/p1/manual/p1s-combo-unboxing/z%E8%BD%B43%E9%A2%97%E8%9E%BA%E4%B8%9D.png)

## 第 4 步：安装配件

将屏幕排线插入屏幕背后的插座中（注：请确保屏幕及排线方向与视频中一致），然后向左轻推，确保屏幕卡入插槽。

|  |  |
| --- | --- |
| 屏幕线缆.jpg | 推屏幕.jpg |

拧下一颗背板螺丝后，使用支架自带的两个长螺丝固定耗材支架。

|  |  |
| --- | --- |
| 支架螺丝.jpg | 安装外挂支架.jpg |

## 第 5 步：安装 AMS

放置上盖。

![盖上上盖.jpg](https://wiki.bambulab.com/p1/unboxing-p1s_combo/%E7%9B%96%E4%B8%8A%E4%B8%8A%E7%9B%96.jpg)

将 AMS 放置于打印机之上。

![放置ams.jpg](https://wiki.bambulab.com/p1/unboxing-p1s_combo/%E6%94%BE%E7%BD%AEams1.jpg)

安装 4-pin 线缆。

|  |  |
| --- | --- |
| 4pin1.jpg | 4pin2.jpg |

安装 6-pin 线缆和料管。

|  |  |
| --- | --- |
| 6pin.jpg | 6pin.jpg |

## 第 6 步：通电测试

插好电源线并打开电源开关。

|  |  |
| --- | --- |
|  |  |

打印机开机后，请按照屏幕上的提示完成打印机的自检。

|  |  |
| --- | --- |
|  |  |

如果你在开箱过程中跳过了联网和 Bambu Handy 绑定步骤，请在自检完成后让打印机联网，在 Handy 中绑定打印机。  
如果你在绑定Bambu Handy时遇到任何问题，请到此[教程](../../p1/manual/bind-handy-studio.md)中进行故障排除。

## **第 7 步**：**完成自检并**拆下热床下的减震泡棉

自检完成后记取下加热床下的固定泡沫。

![](https://wiki.bambulab.com/p1/manual/p1s-combo-unboxing/%E7%83%AD%E5%BA%8A%E6%B3%A1%E6%A3%89.png)
