## **问题现象:**

LED 补光灯亮度不足或启动失败。

## 原因及解决方案

1. LED 灯烧坏或电缆损坏，需要更换 LED 补光灯；
2. AP 主板烧坏，需要更换 AP 主板；
3. MC-AP 连接异常，根据异常的位置，可能需要更换 MC-AP 连接线或相关板件。

## 安全和操作提示

拆装打印机上的连接线时，打印机必须处于断开电源线的状态。

## 所需的工具

- H2.0 内六角扳手
- 万用表
- 镊子

## 排查指引

### 一、检查 AP 主板

 如果故障出现在用户改装或更换了补光灯之后，那么有可能损坏了主板上的补光灯控制电路 。下图是 LED 灯在 AP 主板上的连接器细节图。

|  |  |
| --- | --- |
|  |  |

（1）如果加装了电压是 5V，但工作电流大于 0.3A 的灯具，那么 0R 电阻和磁珠都可能损坏，一般故障现象是开路或电阻增大，导致电流通路中断，无法开关灯。

 （2）如果从座子位置灌入 5V 以上的电压，则 ESD 管可能过热损坏，现象大概率是短路，ESD 表面有烧焦痕迹。

维修措施是更换回原规格器件，并更换 AP 主板。

### 二、检查 MC-AP 连接线

(1) 在拆机检查前，可以先做个简单的预检：开机状态下，将 LED 灯设置为启动状态，然后去除 AP-MC 连接线的固定胶布，摇晃整条连接电缆，观察 LED 灯是否会恢复正常， 如果能恢复正常，说明是存在接触不良的情况，需要继续检查。

|  |  |
| --- | --- |
|  |  |

(2) 参考 [MC-AP 连接电缆](../maintenance/mc-ap-cable.md)的相关步骤，找到连接线在 AP 板和 MC 板上的连接器，主要是确认 MC 和 AP 之间的连接器和连接线，是否出现断线，脱落等接触不良的问题，同时也需要确认连接器座子是否存在松动的情况。

|  |  |
| --- | --- |
|  |  |

(3) 有条件检测的用户，可以在松出 AP 主板后，保持 MC-AP 的连接状态，并启动打印机，用万用表的红表笔电机红色箭头处的pin脚，黑表笔点击图中任意一个锁螺丝处的金属焊盘（GND），对 AP 板的 5V 接口进行输出电压测试，以确认电压是否正常。

### 三、检查补光灯

打印机其他功能正常，只是补光灯不亮的情况下，如家中有两台以上的 P1P 打印机，可以尝试交换补光灯进行确认。

没有多台打印机的情况下，直接（购买或申请）更换补光灯确认。

### 四、确认其他故障

如果打印机除了补光灯工作异常，还同时伴有其他故障，请同时结合其他故障的排查指引去解决问题。
