# 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

# 移除塑料右面板

## **第 1 步 -**移除前面盖

参考 [P1S前面盖](p1s-front-cover.md) 的相关指引，移除上盖玻璃、显示屏幕和前面盖。

![](https://wiki.bambulab.com/p1/maintenance/p1s-rear-panel/front_cover_removed.jpg)

## **第2步 - 移除金属后面板**

参考[更换P1S金属背板](p1s-rear-panel.md)的相关指引。

![](https://wiki.bambulab.com/p1/maintenance/p1s-rear-panel/without_rear_panel.jpg)

## **第 3 步 -** 移除螺丝，取下右侧面板

|  |  |
| --- | --- |
| 移除固定右侧面板顶部的4颗螺丝C | 移除上横梁处的3颗螺丝D |

|  |  |
| --- | --- |
| 移除前立柱处的4颗螺丝D | 移除中间横梁处的1颗螺丝D |

|  |  |
| --- | --- |
| 移除背部的4颗固定螺丝A | 移除后立柱处内部的2颗固定螺丝D, 您可能需要拆除风扇以更方便移除螺丝。 |

|  |  |
| --- | --- |
| 侧放打印机，使右侧面板朝上，移除2颗固定螺丝D | 取下右侧面板 |

# 安装新的塑料右侧面板

## **第 1 步 -** 安装右侧面板，锁螺丝

> ***注意**：侧板上从内向外拧紧的螺丝需边拧边观察侧板位置，避免因拧过头而顶坏侧板。*

|  |  |
| --- | --- |
| 侧放打印机，将右侧面板安装到打印机上 | 锁入2颗固定螺丝D |

|  |  |
| --- | --- |
| 正放打印机，在上横梁处锁入3颗固定螺丝D | 在右侧面板顶部锁入4颗固定螺丝C |

|  |  |
| --- | --- |
| 锁前立柱处的4颗固定螺丝D | 锁中间横梁处的1颗固定螺丝D |

|  |  |
| --- | --- |
| 锁后立柱处的2颗固定螺丝D | 锁背部的4颗固定螺丝A |

## **第2步 - 安装金属后面板**

参考[更换P1S金属背板](p1s-rear-panel.md)的相关指引。

![](https://wiki.bambulab.com/p1/maintenance/p1s-right-panel/rear_panel_installed.jpg)

## **第 3 步 - 安装**前面盖

参考 [P1S前面盖](p1s-front-cover.md) 的相关指引，安装好前面盖、显示屏幕和玻璃上盖。

![](https://wiki.bambulab.com/p1/maintenance/p1s-right-panel/installed.jpg)

# 功能确认

启动打印机，确认屏幕能正常显示，且其上的按键能正常响应。

![](https://wiki.bambulab.com/p1/maintenance/screen/screen_ok.jpg)

更换塑料右侧板不需要进行额外的校准操作。
