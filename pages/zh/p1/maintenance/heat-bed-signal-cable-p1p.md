## 热床信号线

[点击此处](../../x1/maintenance/Replacing-the-heat-bed-cable.md)查看 X1 系列的更换指南。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/heat_bed_signal_cable.jpg)

## 工具

H2.0/H1.5 内六角扳手

镊子

## 准备工作

断开电源连接。

## 拆除

### **第 1 步 -**  拆除背板、废料滑梯

参考 [后面板](rear-panel.md) 和 [废料滑梯](excess-chute.md)  的相关内容，移除后面板和废料滑梯。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/excess_chute_removed.jpg)

### **第 2 步 -** 移除走线槽

用 H2.0 内六角扳手移除 2 颗螺丝，取下走线槽。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/remove_the_cable_railing.jpg)

### **第 3 步 -** 断开热床信号线

先断开 MC-AC 连接线，然后先去除热床信号线上的硅胶，再断开热床信号线的连接。

> 💡 **注意：** 硅胶主要用于运输过程中固定连接器。去除硅胶时，**可以使用镊子/小刀去除。** 操作时请小心，避免划伤或损坏连接器或线缆。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/disconnect_2_cables.jpg)

### **第 4 步 -** 将热床信号线从扎网中松出

将电源线和信号线从立柱上的线扣中释放出来，去除扎网两端的胶布，抽出信号线。

|  |  |
| --- | --- |
|  |  |

### **第 5 步 -** 上升热床

侧放打印机，通过拉扯Z轴皮带将热床上升至约全程 2/3 以上的位置。

|  |  |
| --- | --- |
|  |  |

### **第 6 步 -** 移除走线压片

拧下 2 颗螺丝，移除走线压片。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed/remove_the_hold_plate.jpg)

### **第 7 步 -** 解锁热床

重新正放打印机，移除 6 颗固定热床的螺丝。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed/6_screws.jpg)

### **第 8 步 -** 取下热床：

翻转热床，将连接热床的电缆往热床端方向拉出一段，然后热床正面朝下放置在打印机底部表面上。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/upside_down_the_heat_bed.jpg)

### **第 9 步 -** 拆除调平螺母

拆除 3 颗调平螺母和垫圈，移除地线固定螺丝。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/3_nuts.jpg)

### **第 10 步 -** 打开热床支架

从左向右翻转打开热床支架，注意有一条 2PIN 电线连接，不要损坏。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/open_the_heat_bed.jpg)

### **第 11 步 -** 移除热床信号线

清理热床信号线连接器处的硅胶，断开连接，然后再将热床信号线移除。

> 💡 **注意：** 硅胶主要用于运输过程中固定连接器。去除硅胶时，**可以使用电吹风加热或使用镊子/小刀去除。** 操作时请小心，避免划伤或损坏连接器或线缆。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/disconnect_cable_1.jpg)

## 安装

### **第 1 步 -** 连接热床信号线

将热床信号线穿过热床支架上的过线孔，连接到板件的接口上，点上硅胶对连接器进行加固。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/connect_the_signal_cable_2.jpg)

### **第 2 步 -** 安装热床支架

合上热床支架，调整好位置。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/place_back_the_bracket.jpg)

### **第 3 步 -** 安装调平螺母

按压热床支架，依次拧上 3 颗调平螺母，通过肉眼观察，尽量将 3 颗螺母的拧入量接近一致，锁好地线。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 -** 安装热床

将热床安装到 3 个滑块上，预锁入 6 颗螺丝，然后将热床向前拉，使整个热床尽可以向前挪，再将预装的 6 颗螺丝锁紧。

|  |  |
| --- | --- |
|  |  |

### **第 5 步 -** 穿热床线，安装走线压片

侧放打印机，将热床信号线穿过后滑块过线孔，整理好滑块线槽内的电缆，装上走线压片并锁入 2 颗螺丝进行固定。

|  |  |
| --- | --- |
|  |  |

### **第 6 步 -** 固定扎网

正放打印机，将热床信号线穿过扎网，然后在扎网两端缠上胶布固定扎网。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/pass_through_the_net.jpg)

### **第 7 步 -** 连接热床信号线

将热床信号线连接到 MC 板对应接口上，在连接器处点上硅胶进行加固，连接 MC-AC 连接线。

|  |  |
| --- | --- |
|  |  |

### **第 8 步 -** 安装走线槽

安装走线槽，锁入 2 颗螺丝进行固定。

![](https://wiki.bambulab.com/p1/maintenance/heat-bed-signal-cable/remove_the_cable_railing.jpg)

### **第 9 步 -** 安装废料滑梯、背板

参考 [废料滑梯](excess-chute.md)  和 [后面板](rear-panel.md) 的相关内容，安装好废料滑梯和后面板。

![](https://wiki.bambulab.com/p1/maintenance/excess-chute/rear_panel_installed.jpg)

## 如何验证完成

接上打印机电源，开启打印机，在屏幕上操作，运行设备校准流程，如自检通过，说明操作成功。
