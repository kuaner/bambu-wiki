## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 移除塑料左侧面板

### \*\*第 1 步 -\*\*移除玻璃前门

参考 [更换玻璃前门](../../x1/maintenance/replace-the-front-door.md) 的相关指引，移除玻璃前门。

> **注意：新版本的前玻璃门额外使用了胶水，拆卸难度较大，需要用吹风机将胶吹软。如果无法拆下，则在更换左侧板的过程中，请务必小心注意前玻璃门。**

![](https://wiki.bambulab.com/p1/maintenance/p1s-left-panel/front_door.jpg)

### \*\*第 2 步 -\*\*移除前面盖

参考 [P1S前面盖](p1s-front-cover.md) 的相关指引，移除上盖玻璃、显示屏幕和前面盖。

![](https://wiki.bambulab.com/p1/maintenance/p1s-rear-panel/front_cover_removed.jpg)

### **第3步 - 移除金属后面板**

参考 [金属后面板](p1s-rear-panel.md) 的相关指引，移除金属后面板。

![](https://wiki.bambulab.com/p1/maintenance/p1s-rear-panel/without_rear_panel.jpg)

### **第 4 步 -** 移除辅助部件冷却风扇

参考 [辅助部件冷却风扇](p1s-aux-cooling-fan.md) 的相关指引，将辅助部件冷却风扇从左侧面板上分离。

![](https://wiki.bambulab.com/p1/maintenance/p1s-left-panel/aux_disattached.jpg)

### **第 5 步 -** 移除螺丝，取下左侧面板

|  |  |
| --- | --- |
| 移除固定左侧面板顶部的4颗螺丝C | 移除上横梁处的3颗螺丝D |

|  |  |
| --- | --- |
| 移除前立柱处的4颗螺丝D | 移除中间横梁处的1颗螺丝D |

|  |  |
| --- | --- |
| 移除后立柱处的2颗固定螺丝D | 移除背部的4颗固定螺丝A |

侧放打印机，使左侧面板朝上，移除2颗固定螺丝D，取下左侧面板。

![](https://wiki.bambulab.com/p1/maintenance/p1s-left-panel/bottom_2_screws.jpg)

## 安装新的塑料左侧面板

### **第 1 步 -** 安装左侧面板，锁螺丝

|  |  |
| --- | --- |
| 侧放打印机，将右侧面板安装到打印机上 | 锁入2颗固定螺丝D |

|  |  |
| --- | --- |
| 正放打印机，在上横梁处锁入3颗固定螺丝D | 在左侧面板顶部锁入4颗固定螺丝C |

|  |  |
| --- | --- |
| 锁前立柱处的4颗固定螺丝D | 锁中间横梁处的1颗固定螺丝D |

|  |  |
| --- | --- |
| 锁后立柱处的2颗固定螺丝D | 锁背部的4颗固定螺丝A |

### **第 2 步 - 安装**辅助部件冷却风扇

参考 [辅助部件冷却风扇](p1s-aux-cooling-fan.md) 的相关指引，将辅助部件冷却风扇安装到左侧面板上。

![](https://wiki.bambulab.com/p1/maintenance/p1s-left-panel/aux_fan_installed.jpg)

### **第3步 - 安装金属后面板**

参考 金属后面板 的相关指引，安装金属后面板。

![](https://wiki.bambulab.com/p1/maintenance/p1s-right-panel/rear_panel_installed.jpg)

### **第 4 步 - 安装**前面盖

参考 P1S前面盖 的相关指引，安装好前面盖、显示屏幕和玻璃上盖。

![](https://wiki.bambulab.com/p1/maintenance/p1s-right-panel/installed.jpg)

### **第 5 步 - 安装**玻璃前门

参考 [更换玻璃前门](../../x1/maintenance/replace-the-front-door.md) 的相关指引，安装玻璃前门。

![](https://wiki.bambulab.com/p1/maintenance/p1s-left-panel/front_door_installed.jpg)

## 功能确认

1. 启动打印机，确认屏幕能正常显示，且其上的按键能正常响应。

![](https://wiki.bambulab.com/p1/maintenance/screen/screen_ok.jpg)

2. 在屏幕上点击辅助部件冷却风扇图标，开启辅助冷却风扇 。

![](https://wiki.bambulab.com/p1/maintenance/p1s-aux-part-cooling-fan/on.jpg)

如果辅助部件冷却风扇按预期工作，那么更换完成。否则，请返回检查步骤和连接后重试。如果问题仍然存在，请联系Bambu Lab服务团队寻求进一步帮助。
