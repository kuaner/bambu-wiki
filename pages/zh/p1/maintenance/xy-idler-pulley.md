## XY 张紧器惰轮

![](https://wiki.bambulab.com/p1/maintenance/xy-idler-pulley/idler_pulley_2.jpg)

## 工具

H2.0 内六角扳手

## 准备工作

断开电源连接。

## 拆除

特别说明：2 个 XY 张紧器的惰轮拆装方式类似，可通用。

### **第 1 步 -**  移除张紧器固定支架

用 H2.0 内六角扳手拧下 2 颗螺丝，移除张紧器固定支架和弹簧。

|  |  |
| --- | --- |
|  |  |

### **第 2 步 -** 松出张紧器

用 H2.0 内六角扳手拧下并移除 2 颗螺丝和限位支架，松出张紧器。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 -** 移除惰轮

用内六角扳手推出转轴，移除惰轮和石墨垫圈。

|  |  |
| --- | --- |
|  |  |

## 安装

### **第 1 步 -** 贴附石墨垫圈

在 2 枚垫圈的单侧涂上油脂，将涂布油脂的一侧贴附到惰轮上。

![](https://wiki.bambulab.com/p1/maintenance/xy-idler-pulley/attach_washers.jpg)

### **第 2 步 -** 安装惰轮

将惰轮安装到惰轮支架上，可以暂时用内六角扳手穿起来，以保证惰轮和两个垫圈均在位置上，然后从上往下压入转轴，将转轴完全压入即可。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 -** 安装 XY 张紧器

将 XY 张紧器安装到位，装上 2 个限位支架并分别拧入螺丝进行预固定，不需要拧紧。

![](https://wiki.bambulab.com/p1/maintenance/xy-idler-pulley/install_the_tensioner.jpg)

### **第 4 步 -** 安装张紧器固定支架

将弹簧和固定支架安装到位，锁入 2 颗螺丝进行固定。

|  |  |
| --- | --- |
|  |  |

### **第 5 步 -** 张紧 XY 张紧器

拧松另外一个 XY 张紧器的 2 颗螺丝，双手握住工具头两端的滑车，前后移动数次，然后同时紧靠后部停住。拧紧两边 XY 张紧器上的 4 颗螺丝。关于皮带张紧的调整，请参考Wiki[皮带张紧](../../x1/maintenance/belt-tension.md)。

![](https://wiki.bambulab.com/p1/maintenance/xy-idler-pulley/move_the_toolhead.jpg)

![](https://wiki.bambulab.com/p1/maintenance/xy-idler-pulley/lock_the_tensioners.jpg)

## 如何验证完成

接上打印机电源，开启打印机，在屏幕上操作，运行设备**校准**流程，如自检通过，说明操作成功。
