## MC-AP 连接电缆

![](https://wiki.bambulab.com/p1/maintenance/mc-ap-cable/mc-ap_cable.jpg)

## 工具

- H2.0 内六角扳手
- 镊子

## 准备工作

关闭电源，移除 SD 卡。

## 拆除

### **第 1 步 -** 拆除后面板

参考 [后面板](rear-panel.md)  的相关内容，移除后面板。

![](https://wiki.bambulab.com/p1/maintenance/mc-ap-cable/rear_panel_removed.jpg)

### **第 2 步 - 松脱 AP 主板**

参考 [AP主板](ap-board.md) 的相关内容，移除屏幕和前面盖，将 AP 板从横梁上拆下，露出 MC-AP 连接器。

![](https://wiki.bambulab.com/p1/maintenance/mc-ap-cable/loosen_the_ap_board.jpg)

### **第 3 步 -** 断开连接器

分别断开 AP 板和 MC 板端的连接。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 -** 移除 MC-AP 连接电缆

撕掉固定胶布，将电缆从线槽中松出，移除 MC-AP 电缆。

|  |  |
| --- | --- |
|  |  |

## 安装

### **第 1 步 -** 穿线

将 MC-AP 电缆穿过过线孔，并压入线槽中。

![](https://wiki.bambulab.com/p1/maintenance/mc-ap-cable/pass_the_cable.jpg)

### **第 2 步 -** 连接电缆

将电缆两端分别连接到 AP 板和 MC 板对应接口上。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 -** 安装 AP 主板

参考 [AP主板](ap-board.md)  的相关内容，将 AP 主板和屏幕安装好。

![](https://wiki.bambulab.com/p1/maintenance/front-cover/display_installed.jpg)

### **第 4 步 - 理线**

用胶布将 MC-AP 连接电缆沿着横梁贴附好。

![](https://wiki.bambulab.com/p1/maintenance/mc-ap-cable/fixing_tapes.jpg)

### **第 5 步 -** 安装后面板

参考  [后面板](rear-panel.md) 的相关内容，安装好后面板。

![](https://wiki.bambulab.com/p1/maintenance/mc-ap-cable/rear_panel_installed.jpg)

## 如何验证完成

启动打印机，运行设备校准流程，如校准通过，说明操作成功。

![32.校准.jpg](https://wiki.bambulab.com/p1/screen-operation/%E5%B1%8F%E5%B9%95%E6%93%8D%E4%BD%9C/32.%E6%A0%A1%E5%87%86.jpg)
