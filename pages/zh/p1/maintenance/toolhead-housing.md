## 工具头后盖和中框

|  |  |
| --- | --- |
| 工具头后盖 | 工具头中框 |

## 工具

- H1.5 内六角扳手

## 准备工作

在更换之前，请确保您已经完成了退料操作并且关闭了电源。

## 拆除

### **第 1 步 -** 移除工具头前盖组件

揭开前盖组件，断开连接器，移除前盖。

|  |  |
| --- | --- |
| X1 系列 | P1 系列 |

### **第 2 步 -** 拔出料管

按下气动接头，拔出料管。

![](https://wiki.bambulab.com/p1/maintenance/toolhead-enclosure/disconnect_the_tube.jpg)

### **第 3 步 -** 释放切刀刀柄

拧松切刀刀柄螺丝，使整个切刀刀柄能自然下垂。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 -** 移除螺丝

用 H1.5 内六角扳手移除工具头后盖和中框上的 8 颗螺丝。

|  |  |
| --- | --- |
|  |  |

### **第 5 步 -** 移除工具头后盖

将工具头与工具头中框分离，移除工具头后盖。

![](https://wiki.bambulab.com/p1/maintenance/toolhead-enclosure/remove_the_rear_cover.jpg)

### **第 6 步 -** 移除工具头中框

移除工具头中框，**注意不要被切刀划伤**。

![](https://wiki.bambulab.com/p1/maintenance/toolhead-enclosure/rmeove_the_middle_cover.jpg)

## 安装

### **第 1 步 -** 安装工具头中框

根据圆形线孔的位置，确认安装方向，将工具头中框安装到位。

![](https://wiki.bambulab.com/p1/maintenance/toolhead-enclosure/install_the_middle_cover.jpg)

### **第 2 步 -** 安装工具头后盖

将工具头后盖安装到工具头上，注意上方有卡扣。

![](https://wiki.bambulab.com/p1/maintenance/toolhead-enclosure/mount_the_rear_cover.jpg)

### **第 3 步 -** 锁螺丝

确认工具头后盖与中框扣合到位后，依次锁入 8 颗螺丝固定。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 - 安**装切刀刀柄

用手抬起切刀杠杆，将切刀沿刀槽滑入挤出机内，锁紧固定螺丝。

![](https://wiki.bambulab.com/p1/maintenance/toolhead-housing/cutter.png)

### **第 5 步 -** 接料管

将料管直接插入气动接头。

![](https://wiki.bambulab.com/p1/maintenance/toolhead-housing/connect_ptfe_tube.png)

### **第 6 步 -** 装前盖组件

将前盖风扇电缆与接口板链接，合上前盖组件。

|  |  |
| --- | --- |
| X1 系列 | P1 系列 |

## 如何验证完成

1. 目视检查外观，接合位置无错位、浮起；

2. 启动打印机，在显示器上手动开启和关闭部件冷却风扇，确认冷却风扇能正常工作。

![](https://wiki.bambulab.com/p1/fan_on_off.jpg)
