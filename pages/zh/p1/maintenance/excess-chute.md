## 废料滑梯

安装在打印机背部，用于清洁喷嘴，并将冲刷的废料排出打印机外的组件。

![](https://wiki.bambulab.com/p1/maintenance/excess-chute/excess_chute.jpg)

## 工具

H2.0/H1.5 内六角扳手

## 准备工作

断开电源连接。

## 拆除

### **第 1 步 -**  移除后面板

参考 [后面板](rear-panel.md) 的相关内容，移除后面板。

![](https://wiki.bambulab.com/p1/maintenance/excess-chute/rear_panel_removed.jpg)

### **第 2 步 -** 移除废料滑梯

用 H1.5 内六角扳手拧下 2 颗螺丝（新版本机器的滑梯左侧增加了 1 颗螺丝，可用 H2.0 内六角扳手拧下)，取下废料滑梯。

|  |  |
| --- | --- |
|  |  |

## 安装

### **第 1 步 -** 安装废料滑梯

将废料滑梯安装到打印机上，注意将滑梯两侧的限位扣安装到位，且没有压到耗材。

![](https://wiki.bambulab.com/p1/maintenance/excess-chute/install_the_excess_chute.jpg)

### **第 2 步 -** 锁螺丝

锁入 2 颗螺丝固定滑梯。（新版本机器的滑梯左侧增加了 1 颗螺丝，可用 H2.0 内六角扳手装上）

|  |  |
| --- | --- |
|  |  |

### **第 3 步 -** 安装后面板

参考 [后面板](rear-panel.md) 的相关内容，安装好后面板。

![](https://wiki.bambulab.com/p1/maintenance/excess-chute/rear_panel_installed.jpg)

## 如何验证完成

检查外观，无异常即可。
