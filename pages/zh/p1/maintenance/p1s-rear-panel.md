## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 移除旧P1系列金属背板

### **第1步 -** 移除4颗螺丝

断开电源线连接，用内六角扳手移除4颗螺丝A。

![](https://wiki.bambulab.com/p1/maintenance/p1s-rear-panel/4_screws.jpg)

### **第 2 步 -**移除10颗螺丝

|  |  |
| --- | --- |
| 用内六角扳手移除1颗螺丝B（如果已安装了料盘支架，则是移除料盘支架） | 用内六角扳手移除9颗螺丝C |

### **第 3 步 -** 移除后面板

|  |  |
| --- | --- |
| 先将后盖从左侧（面向后盖）皮带张紧器的位置松开 | 然后松开右侧（面向后盖）皮带张紧器的位置，取下后面板。 |

## 安装新的P1系列金属背板

### **第1步 -** 安装背板

|  |  |
| --- | --- |
| 先将后面板穿过料管支架，并将右侧张紧器的位置安装好。 | 然后将左侧张紧器的位置也安装到位，再按压后面板，将料管支架的位置也装好。 |

### **第 2 步 -** 锁入10颗螺丝

|  |  |
| --- | --- |
| 用内六角扳手锁入9颗螺丝C | 用内六角扳手锁入1颗螺丝B（也可以是安装料盘支架） |

### **第 3 步 -** 锁入4颗螺丝

用内六角扳手锁入4颗螺丝A。

![](https://wiki.bambulab.com/p1/maintenance/p1s-rear-panel/4_screws.jpg)

## 功能确认

更换P1系列金属背板不需要进行功能确认，外观安装正常即可。

## 设备校准

更换P1系列金属背板不需要进行额外的校准操作。
