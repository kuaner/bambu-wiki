## 挤出机

![](https://wiki.bambulab.com/p1/maintenance/extruder-unit/extruder_unit.jpg)

## 工具

- H2.0/H1.5 内六角扳手
- 镊子

## 准备工作

已完成退料，喷嘴温度已冷却至 50℃ 以下，关闭电源。

## 拆除

### **第 1 步 -** 移除热端组件

参考维修页面中[热端组件](complete-hot-end-assembly.md)的相关内容，移除热端组件。

![](https://wiki.bambulab.com/p1/maintenance/extruder-unit/hotend_removed.jpg)

### **第 2 步 -** 断开连接

移除料管，断开霍尔开关排线。

![](https://wiki.bambulab.com/p1/maintenance/extruder-unit/disconect_cable_2.jpg)

### **第 3 步 -** 松出切刀

用 H1.5 内六角扳手拧松切刀刀柄螺丝，使切刀从挤出机中松出，切刀能完全下垂。

|  |  |
| --- | --- |
|  |  |

> **安全提醒**：切刀锋利，在更换挤出机时，请取下切刀防止误伤。  
> ![removecut.jpg](https://wiki.bambulab.com/x1/maintenance/replace-cutter/removecut.jpg)

### **第 4 步 -** 移除挤出机

用 H2.0 扳手拧下 3 颗螺丝，移除挤出机。

|  |  |
| --- | --- |
|  |  |

## （可选）更换挤出机轴承

如果挤出机轴承损坏，可自行购买以下尺寸的轴承更换即可。拆解挤出机及轴承位置可参考这篇 Wiki： [挤出机维护指南：P1系列挤出机维护](https://wiki.bambulab.com/zh/P1/maintenance/extruder-cleaning-guide)

内径 d: 3 mm

外径 D: 8 mm

宽度 H: 4 mm

## 安装

### **第 1 步 -** 安装挤出机

将挤出机安装到工具头上，锁入 3 颗螺丝固定。

|  |  |
| --- | --- |
|  |  |

### **第 2 步 -** 接上料管，连接电缆

将料管接入到挤出机，连接霍尔开关板排线。

![](https://wiki.bambulab.com/p1/maintenance/extruder-unit/connect_cable.jpg)

### **第 3 步 -** 安装切刀

-将刀片卡扣与拨杆对齐，然后将其插入挤出机。

![installcut.jpg](https://wiki.bambulab.com/x1/maintenance/replace-cutter/installcut.jpg)

抬起切刀刀柄，将切刀滑入挤出机刀槽，锁螺丝固定切刀刀柄。

![](https://wiki.bambulab.com/p1/maintenance/extruder-unit/install_the_cutter.jpg)

### **第 4 步 -** 安装热端，合上前盖

参考维修页面中 [热端组件](complete-hot-end-assembly.md)的相关内容，安装好热端组件，并合上前盖。

|  |  |
| --- | --- |
|  |  |

## 如何验证完成

启动打印机，完成一次手动上料和退料的操作，如果没有异常，说明操作成功。
