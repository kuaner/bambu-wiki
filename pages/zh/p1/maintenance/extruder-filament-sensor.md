# 霍尔开关板组件

霍尔开关板组件是安装在挤出机上，用于检测当前打印材料是否送达挤出机，以及切刀杆是否正常释放的一个组件。

![](https://wiki.bambulab.com/p1/maintenance/p-hall-switch-board/p-extru-sw.jpg)

## 何时更换

- 连接电缆损坏；
- 误报退料异常；
- 误报切刀卡住，经拓竹服务团队确认是霍尔检查开关的问题。

## 工具和材料

H1.5 内六角扳手 x 1

螺丝清单

|  |  |  |  |
| --- | --- | --- | --- |
|  | 型号 | 位置 | 规格 |
| 螺丝A | BT2\*05 | 霍尔开关组件底座 |  |
| 螺丝B | MG2.5\*13 | 切刀杆 |  |

# 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>

# 移除旧组件

## **步骤 1 - 移除工具头**前盖组件

 关闭打印机电源，打开工具头前壳组件，断开连接电缆，移除工具头前盖组件。

![](https://wiki.bambulab.com/p1/maintenance/p-hall-switch-board/remove_the_front_housing.jpg)

## **第 2 步 - 移除料管，松切刀杆**

按压料管支架，移除料管，用H1.5内六角扳手拧松切刀杆螺丝（螺丝B），使刀杆下垂。

|  |  |
| --- | --- |
|  |  |

## **第 3 步 - 断开排线连接**

 断开霍尔开关板电缆连接，撕开排线固定胶布，用H1.5内六角扳手移除2颗螺丝（螺丝A）。

|  |  |
| --- | --- |
|  |  |

## **第 4 步 - 移除霍尔开关板组件**

将内六角扳手伸入气动接口将组件撬松，然后取下霍尔开关板组件。

|  |  |
| --- | --- |
|  |  |

# 安装新组件

## **第 1 步 - 安装霍尔开关板组件**

按压霍尔开关板组件上的气动接头，将开关板组件安装到位，然后锁入2颗螺丝(螺丝A)进行固定。

|  |  |
| --- | --- |
|  |  |

## **第 2 步 - 连接排线**

对准连接器，连接霍尔开关板排线，用胶布将连接排线固定在挤出机上。

|  |  |
| --- | --- |
|  |  |

## **第 3 步 - 锁切杆**

用手扶起切刀杆，将切刀滑入刀槽内，拧紧切刀杆螺丝(螺丝B)。

![](https://wiki.bambulab.com/p1/maintenance/p-hall-switch-board/lock_the_lever.jpg)

### **第 4 步 - 接料管，安装前盖**

将料管插入气动接头，连接部件冷却风扇电缆， 然后盖上工具头前盖。

|  |  |
| --- | --- |
|  |  |

# 功能确认

打开打印机电源，手动上料(或通过AMS加载耗材)，然后操作一次退料操作，能正常完成说明更换完成。

否则，请再次检查所有连接并重试。如果仍然不行，请联系 Bambu Lab 服务团队寻求进一步帮助。

# 设备校准

更换霍尔开关板组件不需要进行额外的校准操作。
