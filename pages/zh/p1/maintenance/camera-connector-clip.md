## 接口盖

收到用户的反馈，在安装摄像时，AP 板上的接口盖容易松脱出来或者损坏。为此我们提供此篇指引，用于帮忙用户重新安装接口盖，对于盖子已经确认损坏的，我们将提供新的盖子或 AP 板方便用户进行更换。

![](https://wiki.bambulab.com/p1/maintenance/clip/clip.png)

## 工具

镊子

## 准备工作

关闭电源。

## 操作步骤

### **第 1 步 - 检查连接器和接口盖**

先确认连接器上的针脚没有变形。

![](https://wiki.bambulab.com/p1/maintenance/clip/connector.png)

然后区分好盖子的正反面，确认盖子两端的凸起没有缺失。

|  |  |
| --- | --- |
|  |  |

### **第 2 步 - 安装接口盖**

参照如下视频，用镊子将接口盖对齐连接器，接口盖的正向朝向你自己，然后向连接器的方向将盖推到位，并检查确认盖子开合状态正常。
