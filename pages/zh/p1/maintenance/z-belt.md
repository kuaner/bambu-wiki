## Z 同步皮带

![](https://wiki.bambulab.com/x1/maintenance/replace-z-belt/z_belt.jpg)

## 工具

- H2.0/1.5 内六角扳手
- 镊子

## 准备工作

断开电源连接。

## 拆除

### **第 1 步 -** 下降热床并锁定 Z 轴滑块

倾斜打印机，拉动 Z 轴皮带将热床下降到底部，锁入 3 颗辅助螺丝固定 3 个 Z 轴滑块。

![](https://wiki.bambulab.com/p1/maintenance/z-motor/lower_the_head_bed_and_lock_the_sliders.jpg)

### **第 2 步 -** 移除螺丝

侧放打印机，解除张紧弹簧的张紧状态，用 H1.5 内六角扳手移除 3 颗张紧器盖子螺丝。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 -** 移除张紧轮

用 H2.0 内六角扳手拧下张紧轮螺丝，取下张紧轮盖子，移除 Z 轴张紧弹簧和 Z 轴张紧轮组件。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 -** 移除 Z 轴皮带

这时，已经可以直接取下 Z 轴同步皮带。

![](https://wiki.bambulab.com/p1/maintenance/z-belt/remove_the_z_belt.jpg)

## 安装

### **第 1 步 -** 安装 Z 轴皮带

将 Z 轴皮带安装到打印机底部，如图所示放置，注意皮带齿面的朝向。

![](https://wiki.bambulab.com/p1/maintenance/z-belt/install_the_z_belt.jpg)

### **第 2 步 -** 安装张紧轮和弹簧

确认张紧轮上的螺母没有缺失，然后安装张紧轮和弹簧，注意弹簧长短脚的方向不要弄反。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 -** 安装张紧轮盖

安装张紧轮盖，锁入 1 颗张紧轮螺丝（不拧紧）和3颗盖子固定螺丝，将弹簧的长臂卡到位。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 -** 解除 Z 滑块锁定

正放打印机，然后移除锁定 Z 轴滑块的 3 颗螺丝。

![](https://wiki.bambulab.com/p1/maintenance/z-motor/unlock_the_sliders.jpg)

### **第 5 步 -** 锁张紧器螺丝

再次侧放打印机，拉动 Z 轴皮带使热床上下运动，确认动作无异常，然后锁紧张紧器螺丝。

|  |  |
| --- | --- |
|  |  |

## 如何验证完成

接上打印机电源，开启打印机，在屏幕上操作，运行设备校准流程，如自检通过，说明操作成功。

![32.校准.jpg](https://wiki.bambulab.com/p1/screen-operation/%E5%B1%8F%E5%B9%95%E6%93%8D%E4%BD%9C/32.%E6%A0%A1%E5%87%86.jpg)
