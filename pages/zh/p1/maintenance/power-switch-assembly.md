# 电源开关座

## 什么是电源开关座

电源开关组件是安装在打印机背面左下角的一个模块。它包含一个电源线插座、一个控制打印机电源的开关以及用于连接打印机电源、交流电板和地线的电缆。

![](https://wiki.bambulab.com/x1/maintenance/replace-power-switch-assembly/power-switch-photo.jpeg)

## 何时更换

- 开关损坏
- 连接线缆损坏
- 开关座接触不良

## 所需工具和材料

- 新的电源开关座
- H1.5 H2.0 内六角扳手
- 十字螺丝刀
- 镊子、撬棒或其他扁平工具
- 钳子

# 安全提示

> ***重要提醒 ！***
>
> *在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。*
>
> *在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。*

# 操作步骤 - 拆解

## 步骤1 - (拆卸)断开电源线

关闭电源，从电源插座上拔下电源线。

![](https://wiki.bambulab.com/x1/maintenance/replace-power-module/377px-disconnect_the_power.png)

## 步骤2 **- 拆除背板螺丝**

如图所示，取下后盖上4颗粗牙螺丝，P1P取下7颗细牙螺丝，P1S取下10颗细牙螺丝。这两种类型的螺丝不可混用，所以要把它们分开，以免弄混。

|  |  |  |
| --- | --- | --- |
|  | P1P | P1S |

## 步骤3 -拆除后盖

拆下后盖，先将后盖从左侧（面向后盖）皮带张紧口的位置松开，再松开右侧（面向后盖）皮带张紧口的位置，以免卡住。

|  |  |
| --- | --- |
|  |  |

## 步骤4 -移除废料滑梯

拧下2颗螺丝，并拆下废料滑梯

|  |  |
| --- | --- |
|  |  |

注意：新版本的机器在滑梯左侧有追加1颗螺丝，可以用H2.0扳手拧下。

![](https://wiki.bambulab.com/p1/maintenance/excess-chute/new_screw.png)

## 步骤5 - 拆除右侧板（P1S）

参考[该篇Wiki](p1s-right-panel.md)拆除机器右侧板

## 步骤6 - 移除保护盖

用H2.0内六角扳手移除2颗螺丝，取下走线槽。

用H1.5内六角扳手拆下6颗螺丝，将电源模块保护盖移到一边。

|  |  |
| --- | --- |
|  |  |

## 步骤7 - 断开电源线与电源模块和AC板的连接

用十字螺丝刀拧松下图红框中的6根线缆，向左拔出断开连接  
![中文.jpg](https://wiki.bambulab.com/p1/manual/%E4%B8%AD%E6%96%87.jpg)

## 步骤8 - 取下地线

从靠近电源开关座竖梁内侧用钳子固定住螺母，从竖梁外侧使用H2.0扳手松开地线固定螺丝，取下地线。

**注意**：竖梁处固定有两根地线，一根为整机接地（连接到电源开关座上）另一根为热床地线。只需松下整机接地地线即可。

**P1S 地线在打印机右侧，需要参考**[**这篇 wiki**](p1s-right-panel.md) **将右侧板移除。**

> ***竖梁内侧除了螺母还有一个垫圈，小心操作不要弄丢。***

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 步骤9 - 取出电源开关座

使用扁平工具从电源开关座两侧框架上的四个开口处翘松4个卡扣，随后即可将将电源开关座松出。

|  |  |
| --- | --- |
|  |  |

揭下电缆束线胶带，从右向左将步骤7中断开的线缆穿过线材扣取出，随后即可将电源开关座连同电缆一起取下完成拆卸。

|  |  |
| --- | --- |
|  |  |

# 操作步骤 - 安装

## 步骤1 - 安装电源开关座

将新的电源开关座所有缆线穿过电源开关座框架后向内推，将电源开关座通过卡扣固定到位

![](https://wiki.bambulab.com/p1/maintenance/power-switch-assembly/install-assembly-p.png)

## 步骤2 - 连接地线

将地线穿过竖梁后使用H2.0扳手固定在竖梁上。

**P1S 地线在打印机右侧，需要参考**[**这篇 wiki**](p1s-right-panel.md) **将右侧板移除。**

> ***注意：接地为保证用电安全的重要措施，请务必牢固固定地线。***

|  |  |
| --- | --- |
| P1P | P1S&X1 |

## 步骤3 - 连接电缆

将电缆从线材扣中从左向右穿出，贴上束线胶带。用十字螺丝刀将电缆接头通过十字螺丝固定在供电模块和AC板上。

> *注意：在连接顶部AC板时，线序从上向下应为零-火-地，即颜色为蓝-棕-黄绿。在23年8月前出场的设备中零火有反接的现象（如图）。由于电路保护该现象对打印机功能没有影响，但在连接极性插座时会出现跳闸的情况。*

|  |  |
| --- | --- |
|  |  |

## 步骤4 - 安装保护盖

锁入6颗螺丝，安装电源保护盖。安装走线槽，锁入2颗螺丝固定。

|  |  |
| --- | --- |
|  |  |

## 步骤5 - 安装侧板（P1S）

参考[该篇Wiki](p1s-right-panel.md)安装右侧面板

## 步骤6 -安装废料滑梯

安装废料滑梯，注意两边的卡扣，锁紧2颗螺丝。

|  |  |
| --- | --- |
|  |  |

注意：如果在拆解时发现滑梯侧面有螺丝，可以锁回去。

![](https://wiki.bambulab.com/p1/maintenance/excess-chute/new_screw.png)

## 步骤7 -安装后盖（P1S）

安装后盖时，应首先穿过PTFE管支架和装好右侧的皮带张紧口位置。

|  |  |
| --- | --- |
|  |  |

## 步骤8 - 锁紧螺丝

将后盖重新固定。注意使用的不同类型的螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

# 功能确认

连接电源线并启动电源。运行设备自检/校准流程，如果没有报错，更换电源开关座完成。
