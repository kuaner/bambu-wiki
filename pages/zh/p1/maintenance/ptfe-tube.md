## 料管

![](https://wiki.bambulab.com/p1/maintenance/tube/tube.jpg)

长度：530mm。

## 工具

无

## 准备工作

已完成退料，关闭电源。

## 拆除

### **第 1 步 - 拔料管**

揭开工具头前盖，按压接头拔出料管。

![](https://wiki.bambulab.com/p1/maintenance/tube/disconnect_the_tube_from_the_extruder.jpg)

### **第 2 步 -** 松脱工具头连接线

将工具头连接线从料管 & 线束固定卡中松出来，共 3 处。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 -** 移除固定卡

沿已松开一端的料管方向，移除 3PCS 固定卡

![](https://wiki.bambulab.com/p1/maintenance/tube/remove_the_clips.jpg)

### **第 4 步 -** 移除料管

按压接头，拔出料管。

![](https://wiki.bambulab.com/p1/maintenance/tube/disconnect_the_tube_from_holder.jpg)

## 安装

### **第 1 步 -** 安装固定卡

将 3PCS 固定卡装到料管上。

![](https://wiki.bambulab.com/p1/maintenance/tube/install_3.jpg)

### **第 2 步 -** 将料管安装到料管支架上

直接将已装有固定卡的一端插到支架接口上，并将 3PCS 固定卡移动到合适的位置。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 -** 将料管接入挤出机

将料管另一端插到挤出机上，合上工具头前盖。

|  |  |
| --- | --- |
|  |  |

### **第 4 步 -** 固定连接线

将工具头连接电线扣入到 3PCS 固定卡上。

![](https://wiki.bambulab.com/p1/maintenance/tube/fix_the_cable.jpg)

## 如何验证完成

1. 目视检查外观，料管无变形；

2. 尝试用手拔动料管，确认两端都已锁紧。
