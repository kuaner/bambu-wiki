# 热床软磁贴

热床软磁贴是附在热床铝基板表面的带有磁性的软质橡胶板，它是热床的一部件，它的主要作用是吸附构建板，使构建板稳定地吸附在热床上。我们在 P1 系列的打印机上，由于部分结构的差异，热床软磁贴存在两种版本，一种是有开孔的，需要避让调平螺丝；另一种是没有开孔的。X1 系列的打印机上使用的都是没有开孔的热床软磁贴。

|  |  |
| --- | --- |
|  |  |

如果您的打印机需要更换热床软磁贴，请根据实际版本购买，避免出错。

温馨提醒：如果您确认买错了版本，也是可以进行更换的，只需要在贴好热床软磁贴后，在相应的位置开孔，让下面的螺丝完整露出即可。

## 何时更换

1.  热床软磁贴起泡，导致构建板放置不良；

2. 热床软磁贴破损并浮起，导致构建板放置不良

3. 热床软磁贴磁性失效，吸附不了构建板。

温馨提醒：热床软磁贴表面的一些划痕、凹点，甚至小范围的破损，只要不存在顶起构建板的情况，是不影响打印功能的，不需要更换。

## 工具和材料清单

- 新的热床软磁贴
- 隔热手套
- 无尘布
- 无水酒精
- 铲刀

# 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

# 移除旧的热床软磁贴

无论是带孔的还是不带孔的热床软磁贴，移除的方式是一样的，这里以带孔的热床软磁贴为例进行说明。

## **第1步 - 加热热床**

一般来说，适当的加热热床，可以有效地帮助您更容易地将热床软磁贴从热床上移除。

启动打印机，将热床温度设置到 50 摄氏度左右，然后关闭打印机电源。对于使用了带孔热床软磁贴的热床，为了在贴附新的热床软磁贴时更好操作，建议先将螺丝帽调整至与热床软磁贴孔位完全平行的状态。

|  |  |  |
| --- | --- | --- |
| 50 摄氏度 | 螺丝帽歪斜，需要调正 | 调正后 |

## **第 2 步 -移除**热床软磁贴

用铲刀将热床软磁贴从边角位撬起，请注意，热床软磁贴上的双面胶要跟随热床软磁贴一起带离铝基板，这样可以尽量避免残胶留在铝基板表面。

|  |  |
| --- | --- |
|  |  |

在手撕热床软磁贴的过程中，如果出现破损，建议暂停下来，重新用铲刀协助撬起残留的部分，然后再继续撕下热床软磁贴。

|  |  |
| --- | --- |
|  |  |

撕下热床软磁贴是一个需要缓慢操作的过程，需要在整个过程中不断更换撕热床软磁贴的位置，同时，因为在开始时有加热热床，需要佩戴隔热手套，以防止高温烫伤和因长时间接触有较高温度的表面而引起手起水泡。

示例视频片段：

[remove\_the\_maget.mp4](https://wiki.bambulab.com/p1/maintenance/flexible-magnet/remove_the_maget.mp4)

## **第 3 步 - 清洁铝基板**

拆完热床软磁贴后，在贴附新的软磁铁前，我们需要对铝基板表面进行清洁，如清理表面的残胶、指印和油污等。将无水酒精喷洒在铝基板表面，然后用无尘布完整清洁表面即可。

![](https://wiki.bambulab.com/p1/maintenance/flexible-magnet/surface.jpg)

# 安装新的软磁贴

## **第1步 - 确认安装位置**

在开始贴装热床软磁贴前，建议先将带有保护纸的软磁铁放置到热床表面，确认安装方向和位置，特别是开孔软磁铁，需要将开孔对齐调平螺丝。

![](https://wiki.bambulab.com/p1/maintenance/flexible-magnet/check_before_attached.jpg)

## **第 2 步 - 安装**热床软磁贴

有开孔的热床软磁贴，先撕开部分贴纸，将热床软磁贴开孔对齐前面的两颗调平螺丝，然后从前向后拉出保护纸，将热床软磁贴贴附到热床上；

|  |  |
| --- | --- |
|  |  |

没有开孔的热床软磁贴，建议先对齐右侧边缘，热床软磁贴与右侧档边留下约 0.5mm 的间隙，上下两边保持平行。然后向左侧拉出保护纸，使热床软磁贴从右向左贴附到热床铝基板上。

|  |  |  |
| --- | --- | --- |
|  |  |  |

请注意，在贴附热床软磁贴的这个过程中，不要用力按压热床软磁贴，且要关注是否有偏移，可以适当进行微调。

如果贴完热床软磁贴后，发现有少量偏差，但并没有超过热床的挡边条，不需要重新贴，重新取下的过程可能会使热床软磁贴产生皱褶。

### **第 3 步 - 清洁和加压**

确认热床软磁贴贴附到位后，可以对表面进行清洁。在无尘布上醮取一些无水酒精，通过来回循环清洁的形式完成表面清洁，并在清洁的同时施加适度的压力挤压热床软磁贴，使粘贴得更牢固。

# 功能确认

# 设备校准

操作完成后，建议执行一次设备校准的操作，以保证热床及一些相关部件能正常工作。
