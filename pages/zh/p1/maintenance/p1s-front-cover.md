## P1S前面盖

P1S打印机的前面盖是安装在打印机正面上方，并印刷有打印机型号P1S的灰黑色盖子。

![](https://wiki.bambulab.com/p1/maintenance/p1s-front-cover/p1s_front_cover.jpg)

## 何时更换

一般情况下都是因为物流运输导致了前面盖损坏才会进行更换。

## 所需工具和材料

- 新的前面盖
- H2.0 内六角扳手
- 平头镊子

螺丝清单

|  |  |  |  |
| --- | --- | --- | --- |
|  | 型号 | 位置 | 规格 |
| 螺丝A | BT3\*5 | 前面盖正面 |  |
| 螺丝B | BT3\*5 | 前面盖背面 |  |

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 移除旧的前面盖

### **第 1 步 -**关闭电源

关闭打印机电源，打开前玻璃门，取下玻璃上盖。

### **第 2 步 - 移除屏幕和SD卡**

|  |  |
| --- | --- |
| 参考 [屏幕组件](screen.md)  的相关内容，拆除屏幕 | 按压SD卡使其弹出，取下SD卡 |

### **第 3 步 - 移除WIFI天线**

|  |  |
| --- | --- |
| 在前面盖背面找到贴附在上面的WIFI天线 | 用平头镊子将WIFI天线从前面盖上移除 |

### **第 4 步 -** 移除3颗螺丝

|  |  |
| --- | --- |
| 用H2.0内六角扳手拧下2颗螺丝A | 用H2.0内六角扳手拧下1颗螺丝B |

### **第 5 步 - 移**除前面盖

|  |  |
| --- | --- |
| 一只手抵住前面盖右侧的卡扣，另一个手向上推，解除前面盖右侧的固定 | 用手向上推前面盖左侧，解除前面盖左侧的固定 |

将显示屏连接电缆从方形过线孔中退出，向上移动前面盖，将前面盖从打印机上移除。

![](https://wiki.bambulab.com/p1/maintenance/p1s-front-cover/unlock_the_front_cover_0.jpg)

## 安装新的前面盖

### **第 1 步 -** 安装前面盖

从上而下沿着安装槽将前面盖装到打印机上。

![](https://wiki.bambulab.com/p1/maintenance/p1s-front-cover/install_the_front_cover.jpg)

将显示屏连接电缆穿过方形过线孔，然后两左右两端同时按压前面盖，将前面盖安装到位。

![](https://wiki.bambulab.com/p1/maintenance/p1s-front-cover/install_the_front_cover_v.jpg)

### **第 2 步 -** 锁螺丝固定

|  |  |
| --- | --- |
| 用H2.0内六角扳手于前面盖前方锁入2颗螺丝A | 用H2.0内六角扳手于前面盖后侧锁入1颗螺丝B |

### **第3步 - 贴附**WIFI天线

|  |  |
| --- | --- |
| 检查确认WIFI天线无异常 | 将WIFI天线贴到前面盖指定位置上，可追加胶水进行加固粘接效果 |

### **第 4 步 -** 安装屏幕

参考 [屏幕组件](screen.md)  的相关内容，安装好屏幕，并装上SD卡。

![](https://wiki.bambulab.com/p1/maintenance/front-cover/display_installed.jpg)

## 功能确认

启动打印机，确认屏幕能正常显示，且其上的按键能正常响应。

![](https://wiki.bambulab.com/p1/maintenance/screen/screen_ok.jpg)

## 设备校准

更换前面盖不需要进行设备校准。
