拿到 P1 打印机后，您一定急切的想开始打印，我们在打印机内置了一些预切片模型，便于您快速上手。

## 视频教程

## 装填耗材

打印开始前需要向打印机装入耗材。如果您没有 AMS，您可以查看 [这个页面](loading-filament.md) ，了解外挂料盘进料的标准操作。

![](https://wiki.bambulab.com/p1/manual/first-print-sd/filament-ready.png)

## 发起打印

在你选择了文件夹图标后，使用右箭头导航到预装 SD 卡文件目录。

![](https://wiki.bambulab.com/p1/manual/first-print-sd/select-model.png)

进入预装 SD 卡文件目录后，用上下箭头浏览文件夹的内容，然后按 OK 键选择你要打印的模型。

![](https://wiki.bambulab.com/p1/manual/first-print-sd/choose-scrapper.png)

再确认一次所选的模型，然后按 OK 键，就可以开始打印了。
