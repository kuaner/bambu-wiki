P1 系列自 01.08.00.00 版本开始支持 AMS 2 Pro 和 AMS HT。

由于固件限制，如果您需要通过 microSD 卡更新固件，并且已连接至 AMS 2 Pro 和 AMS HT，请按照本文档进行更新。

如果您的打印机固件版本已不低于 01.08.00.00，可忽略此页面，按照[通过 microSD 卡升级固件——P1P/P1S](P1-firmware-update-from-SD-card.md)更新固件即可。

## 更新步骤

1. 断开AMS 2 Pro和AMS-HT与打印机的连接；

|  |  |
| --- | --- |
| AMS 2 Pro | AMS-HT |

2. 参考[通过 microSD 卡升级固件——P1P/P1S](P1-firmware-update-from-SD-card.md)，将打印机固件升级至最新版本；
3. 连接AMS 2 Pro和AMS-HT；

|  |  |
| --- | --- |
| AMS 2 Pro | AMS-HT |

4. 重复步骤2，再次升级一次打印机固件。
