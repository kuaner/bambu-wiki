打印开始前，我们需要装入耗材。以下是在 3D 打印机上装入线材需要遵循的步骤:

## 视频教程：

## 1. 插入耗材

将耗材插入机器背面的特氟龙管中，直到耗材碰到挤出机

![插入耗材.jpg](https://wiki.bambulab.com/p1/%E6%8F%92%E5%85%A5%E8%80%97%E6%9D%90.jpg)

## 2. 点击“进料”

在屏幕上选择"进料"。

> *请注意，此功能仅可以装载料盘支架上的耗材。如果想要使用 AMS 中的耗材，您可以在 Bambu Studio 或 Bambu Handy 中发起打印，即可选择使用 AMS 中的具体耗材。但是，您首先需要在 AMS 装载所需耗材：*
>
> *1. 放置耗材至 AMS 中。*
>
> *2. 将耗材插入入料口组件。*
>
> *3. 在 Bambu Studio/Bambu Handy 中发起打印并选择已装载的耗材。*
>
> |  |  |
> | --- | --- |
> | *Bambu Studio* | *Bambu Handy* |

![点击进料.jpg](https://wiki.bambulab.com/p1/%E7%82%B9%E5%87%BB%E8%BF%9B%E6%96%99.jpg)

## 3. 手动推入耗材

喷嘴开始加热到 250 ℃ 后，手动推入耗材。

|  |  |
| --- | --- |
|  |  |

## 4. 正常吐料，完成进料

可以观察喷嘴，以确保挤出机正常吐料。在屏幕上选择“完成”，完成进料。

![正常吐料.jpg](https://wiki.bambulab.com/p1/%E6%AD%A3%E5%B8%B8%E5%90%90%E6%96%99.jpg)

如果是用 Bambu Studio/Bambu Handy，在观察料被挤出后，需要点击“耗材已挤出，继续”。

|  |  |
| --- | --- |
| Bambu Studio | Bambu Handy |

## 5. 未正常吐料，重试

如果耗材没有被吐出，选择“重试”，然后重复推入耗材的动作。

![未正常吐料.jpg](https://wiki.bambulab.com/p1/%E6%9C%AA%E6%AD%A3%E5%B8%B8%E5%90%90%E6%96%99.jpg)

如果是用 Bambu Studio/Bambu Handy，则需要点击“耗材未挤出，重试”。

|  |  |
| --- | --- |
| Bambu Studio | Bambu Handy |
