**开箱视频:**

建议您在打印机开箱前浏览完整视频，确保顺畅的开箱体验。

## 第 1 步：开箱和拆除保护套

- 小心地打开纸盒，移除泡沫插件。
- 用两个塑料把手把整个东西从盒子里拖出来，放在一个平面上（注意：打印机的重量约为 12.59 kg。）
- 取出塑料袋，从上侧盖中取出快速入门指南（请在进行下一步之前阅读快速入门指南）

|  |  |
| --- | --- |
|  |  |

- 小心地取下面板上的所有塑料包装纸
- 取出泡沫插件并取出配件盒
- 剪断 2 条拉链，释放工具头
- 剥去所有剩余的保护带

|  |  |
| --- | --- |
|  |  |

## 第 2 步：打开配件盒，检查盒子里的配件

P1S 包装内有屏幕、料盘支架、耗材、电源线、疏通针工具、PTFE管、纹理 PEI 板、导热硅脂、润滑脂、备用热端、喷嘴擦拭垫、Bambu 刮刀、内六角扳手、热端夹、手机支架双面胶、32 GB MicroSD 卡（打印机内），快速指南和免责声明。

|  |  |
| --- | --- |
|  |  |

## 第 3 步：连接液晶屏

将电缆插入屏幕，并确保你按照视频中显示的方向。将屏幕弹入槽内。

|  |  |
| --- | --- |
|  |  |

## 第 4 步：解锁热床

解开 Z 轴上的 3 个安全螺丝，红色箭头所示。

|  |  |
| --- | --- |
|  |  |

## 第 5 步：安装料盘固定器

拧入料盘支架

|  |  |
| --- | --- |
| 拧出右边螺丝孔原来的固定螺丝 | 安装料盘固定器 |

## 第 6 步：连接电源线并启动打印机

插上电源线，打开电源开关

打印机开启后，按照屏幕上的提示完成打印机的自检。

|  |  |
| --- | --- |
|  |  |

## 第 7 步：取下热床下面的泡沫衬垫

打印机开机后，请按照屏幕上的提示完成打印机的自检。**自检结束后，不要忘记将热床下的固定泡沫去除。**

|  |  |
| --- | --- |
|  |  |

如果你在绑定 Bambu Handy 时遇到任何问题，请到此[教程](bind-handy-studio.md)中进行故障排除。如果你在开箱过程中跳过了联网和Bambu Handy绑定步骤，请在自检完成后让打印机联网，在 Handy 中绑定打印机。

关好玻璃前门并盖好玻璃上盖。

## 第8步：完成初始化，并装入耗材

将耗材插入后面的 PTFE 管，直到到达挤出机。我们建议使用提供的拓竹 PLA 进行首次测试打印。

|  |  |
| --- | --- |
|  |  |

## 第9步：放置废料盒

开始打印前，推荐准备一个盒子放置于**打印机背面的废料滑梯下方**，用于收集打印过程滑出的废料，保持环境整洁。

您可以打印一个 [废料盒](https://makerworld.com.cn/zh/search/models?keyword=P1%E5%BA%9F%E6%96%99%E7%9B%92)，也可以使用耗材包装盒或其他容器来接废料。
