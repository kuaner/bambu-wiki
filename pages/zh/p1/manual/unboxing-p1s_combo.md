**开箱视频:**

建议您在打印机开箱前浏览完整视频，确保顺畅的开箱体验。

## 第 1 步：开箱和拆除保护套

- 小心地打开纸盒，移除泡沫插件。
- 用两个塑料把手把整个东西从盒子里拖出来，放在一个平面上

|  |  |
| --- | --- |
|  |  |

- 取出塑料袋，从上侧盖中取出快速入门指南（请在进行下一步之前阅读快速入门指南）
- 小心地取下玻璃面板上的所有塑料包装纸。

|  |  |
| --- | --- |
|  |  |

## 第 2 步：取出配件与 AMS

P1S 套装配件清单中包含屏幕、料盘架、耗材、备用喷嘴组件、喷嘴擦拭组件、电源线、通针、特氟龙管、热床刮刀刀片、六角扳手（H1.5 和 H2.0）、4 pin 总线、6 pin 总线、AMS 缓冲器、固体胶棒、热端固定卡扣、切刀、手机支架双面胶、纹理 PEI 打印板（已预安装在热床上）、32 GB MicroSD 卡（打印机内）、导热硅脂、润滑脂、快速指南、免责声明和安全指引。

- 取出箱底附赠的耗材
- 取出配件盒

|  |  |
| --- | --- |
|  |  |
| 包装清单更新：配件盒中不再包含胶棒。 | 配件包内 |

- 取出机器内 AMS 周围的减震泡棉。

|  |  |
| --- | --- |
|  |  |

- 移除 AMS 底座上的两颗固定螺丝，并取出 AMS。

|  |  |  |
| --- | --- | --- |
|  |  |  |

- 撕下保护膜并取出附赠料管。

|  |  |
| --- | --- |
|  |  |

- AMS 包含两个存放干燥剂袋的隔间，以保持内部空气干燥，从而保护您的耗材免受湿气影响。首次拆箱 AMS 时，您会注意到两个用胶带固定的网状隔间。从红色标签侧揭下胶带，然后将指尖抵住网罩上方的小端口，将网罩取下。

|  |  |
| --- | --- |
|  |  |

- 取下网罩后，取出干燥剂袋，然后将其从密封的透明塑料袋中取出。打开干燥剂袋后，像之前一样将其放回 AMS 内的隔间中。

|  |  |
| --- | --- |
|  |  |

- 最后，用网罩盖上干燥剂隔间。先插入网罩底侧，然后将顶部推入，直至其卡入到位。然后关闭 AMS 上盖。

|  |  |
| --- | --- |
|  |  |

## 第 3 步：拆除运输材料

- 移除 4 颗由红色箭头标签贴指示的安全螺丝，取出 AMS 底座。

|  |  |
| --- | --- |
|  |  |

- 取出干燥剂和减震泡棉。

|  |  |
| --- | --- |
|  |  |

- 剪断工具头上的两条扎带以释放工具头，并拆开工具头四周的纸板。

|  |  |
| --- | --- |
|  |  |

- 取下其余的减震泡棉及保护胶带。

|  |  |
| --- | --- |
|  |  |

- 拧掉 Z 轴上 3 颗由红色箭头标签贴指示的安全螺丝。

![](https://wiki.bambulab.com/p1/manual/p1s-combo-unboxing/z%E8%BD%B43%E9%A2%97%E8%9E%BA%E4%B8%9D.png)

## 第 4 步：安装配件

- 将屏幕排线插入屏幕背后的插槽中（注：请确保屏幕及排线方向与视频中一致）。
- 将屏幕卡入插槽中。

|  |  |
| --- | --- |
|  |  |

- 安装耗材支架。

|  |  |
| --- | --- |
|  |  |

## 第 5 步：安装 AMS

- 将 AMS 放置于打印机之上。
- 连接特氟龙管。

|  |  |
| --- | --- |
|  |  |

- 使用 4pin 线连接供料缓冲器与打印机。

|  |  |
| --- | --- |
|  |  |

- 使用 6pin 线连接供料缓冲器与 AMS。

|  |  |
| --- | --- |
|  |  |

## 第 6 步：通电测试

- 插好电源线并打开电源开关。

|  |  |
| --- | --- |
|  |  |

- 打印机开机后，请按照屏幕上的提示完成打印机的自检。

|  |  |
| --- | --- |
|  |  |

- 如果你在开箱过程中跳过了联网和 Bambu Handy 绑定步骤，请在自检完成后让打印机联网，在 Handy 中绑定打印机。
- 如果你在绑定Bambu Handy时遇到任何问题，请到此[教程](bind-handy-studio.md)中进行故障排除。

## **第 7 步**：**完成自检并**拆下热床下的减震泡棉

- 注意：自检完成后记请得取下加热床下的固定泡沫。

![](https://wiki.bambulab.com/p1/manual/p1s-combo-unboxing/%E7%83%AD%E5%BA%8A%E6%B3%A1%E6%A3%89.png)

## 第8步：AMS 打印测试

- 打开 AMS 并放入耗材。

> **注意**：请将干燥剂从密封的透明塑料袋中取出后，再放入 AMS 中。

|  |  |
| --- | --- |
|  |  |

- 耗材识别后即可开始打印。

> 您可以参考 [从料盘支架上装载打印耗材](loading-filament.md) 了解如何使用进退料功能。如需使用 AMS，请参考 [在 Bambu Studio 中使用 AMS](../../software/bambu-studio/use-ams-on-bambu-studio.md) ,了解如何使用 Bambu Studio 对 AMS 中的耗材进行耗材设置及进退料操作并发起打印。

![](https://wiki.bambulab.com/p1/manual/p1s-combo-unboxing/ams-load-filament3.png)

## 第9步：放置废料盒

开始打印前，推荐准备一个盒子放置于**打印机背面的废料滑梯下方**，用于收集打印过程滑出的废料，保持环境整洁。

您可以打印一个 [废料盒](https://makerworld.com.cn/zh/search/models?keyword=P1%E5%BA%9F%E6%96%99%E7%9B%92)，也可以使用耗材包装盒或其他容器来接废料。

![purge_container_placement_p1s_example.png](https://wiki.bambulab.com/p1/manual/p1s-unboxing/purge_container_placement_p1s_example.png)
