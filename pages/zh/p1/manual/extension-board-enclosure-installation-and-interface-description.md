# Bambu Lab扩展板安装方法和接口详细描述

Bambu Lab扩展板是一款为Bambu Lab添加高级和定制功能的开发板。在安装扩展板之前，请确保您已经阅读了扩展板的规格和兼容性，并准备好了必要的工具和材料。

![](https://wiki.bambulab.com/general/extension-board-examples/扩展板界面介绍2.png)

请点击[此处下载](https://public-cdn.bambulab.com/wiki/model/Extension_Board_Enclosure.3mf)Bambu Lab 扩展板

## Bambu Lab 扩展板的使用界面和接口

Bambu Lab扩展板接口包含以下功能：被动继电器连接器、步进电机连接器、RGB LED连接器、风扇连接器（4针）、总线接口、风扇连接器（2针）、舵机连接器、远程快门连接器和扩展 I/O 等。您可以根据需求制作不同的连接器，以实现不同功能的应用。

![](https://wiki.bambulab.com/general/extension-board-interface-desp/扩展板接口ch.jpg)

下面的表格详细描述了不同连接器的功能。

## **被动继电器连接器**

|  |  |
| --- | --- |
| **终端规格** | 3.5 毫米间距的 2P 端子块 |
| **接口描述** | 使用被动机械触点连接和断开外部电路，并隔离板上的其他电路。 |
| **线序** | 公共端(COM)  常开触点(NO) |
| **负载能力** | 电压：30V直流/交流  电流：10A |
| **接触电阻** | 20m Ω |
| **接线线径** | 24~18AWG/1.5mm2 |
| **剥离长度** | 5~6mm |
| **锁紧扭矩** | 0.2Nm (1.7 lb. in) |

## **步进电机连接器**

|  |  |
| --- | --- |
| **终端规格** | 2.54 毫米间距的 4P 端子块 |
| **接口描述** | 板上有两个单路 H 桥驱动 IC，可直接驱动步进电机 |
| **线序** | A+, A -, B+, B- |
| **负载能力** | 电压：24V直流  电流：1.5A峰值（由主机供电，整个板的最大电流为 2A 峰值），3A 峰值（由外部 24V 供电，请参附录 1 的详细信息） |

## 扩展I/O

|  |  |
| --- | --- |
| **终端规格** | 2.54 毫米间距的 2\*13P 双排针 |
| **接口描述** | 扩展输入/输出和 A/D 端口，请查看以下详细信息。 |
| **线序** | 注意：IO4~IO11 为 5V 电平，IO12~IO17为 3.3V 电平 |
| **负载能力** | - 5V，1.6A 峰值（整个板的 5V 负载为 2A 峰值） 3.3V，0.8A 峰值（整个板的 3.3V 负载为 1A 峰值） |

| **PWM端口规格** | - 频率：100Hz-100kHz - 占空比：0%-100% |
| **I/O端口规格** | - 高电平输入：2~3.6V - 低电平输入：- 0.3~0.8V - 高电平输出电压 ：2.9V~3.3V - 输出电流 0~20mA（板上的22R保护串联电阻将导致额外的电压降！） - 低电平输出电压：0~0.4V - 最大输入电流 20mA （板上的22R保护串联电阻将导致额外的电压降！） |

## 附录1

**如何切换到外部 24V 电源以驱动更高功率的 RGB LED 和/或步进电机？**

a. 保持电源按钮关闭（未接通），并连接总线接口。这表示板子不使用总线接口的电源。但是，连接是必要的，以保持板子和打印机之间的通信。

b. 如有需要，将外部 24V 直流电源的正极（红箭头）和负极（绿箭头）连接上。有 6 个 24V 接口和 8 个 GND 接口可供选择，以增加可用负载电流和可用负载功率。

![](https://wiki.bambulab.com/general/extension-board-interface-desp/appendix1.png)

**警告：**总线接口的 24V 电源和外部电源的 24V 电源不能同时生效，否则电路可能会受到损坏。
