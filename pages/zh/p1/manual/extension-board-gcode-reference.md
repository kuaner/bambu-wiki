# Bambu Lab扩展板 G-Code 使用说明

## 参数保存（S=0）

### 命令格式

```
M1004 S0 P[ppp]
```

如果用户未保存 DIY 配置的话 , 重启后将恢复默认。

当前保存的参数包括：

- LED 灯光配置；
- 风扇开关/转速设定；
- 滑动变阻器，预留 AD 接口的功能配置；
- 开关，预留通用 IO 的功能配置。

## 说明

`P`: 命令选择(0-1), 1 存储配置, 0 擦除配置。

## LED灯光配置(S=1, 2)

### 单独的灯光配置（S=1）

当前的设定支持对灯带中的每一个颜色单独控制, 实现更复杂的模式设定。

### 命令格式

```
M1004 S1 L[lll] M[mmm] B[bbb] T[sss] O[ooo] F[fff]
```

### 说明

- `L`: LED灯珠编号(0-5), 两个灯带, 每个包含RGB三色, 共计六个LED索引。
  - 两个灯带接口分别为LED0和LED1：
    - LED0灯带对应的灯珠编号为0、1、2
    - LED1灯带对应的灯珠编号为3、4、5
- `M`: LED灯珠模式(0-2)：
  - 0: 常亮模式
  - 1: 呼吸模式
  - 2: 闪烁模式
- `B`: 亮度设定(0-255): 通过对不同灯光的亮度设定, 可以搭配出多种颜色。
- `T`: 相对起始时间(0-65535毫秒), 这个参数用于灯带的延时控制, 介绍完全部参数会再对这个参数进行说明。
- `O`: 指定模式下(M=1,2)周期内开启时长(0-65535毫秒)。
- `F`: 指定模式下(M=1,2)周期内关闭时长(0-65535毫秒)。

例如, 实现RGB灯光的交替闪烁, 以灯带0为例(LED索引分别为0, 1, 2), 命令如下：

```
M1004 S1 L0 M2 B255 T0 O500 F1000
M1004 S1 L1 M2 B255 T500 O500 F1000
M1004 S1 L2 M2 B255 T1000 O500 F1000
```

以上的配置表示 RGB 三色灯光的周期都为 1500 毫秒(O500+F1000)，在周期内先开启 500 ms，随后关闭 1000 ms，同时 LED0 从 0 时刻开始执行(T=0)，LED1从500 ms 时开始执行(T=500)，LED2 从 1000ms 时开始执行(T=1000)。

这样，当 L0 在 500ms 时关闭后，L1 被点亮；当 L1 在 1000ms 被关闭后，L2 被点亮，依次循环，这样就实现了RGB三色交替闪烁。

## 整体的亮度配置（S=2）

### 命令格式

```
M1004 S2 I[iii] B[bbb]
```

### 说明

`I`: LED灯带索引(0-1)

`B`: 亮度(0-255)

这条命令同时控制 LED 灯带中的 RGB 三色亮度，不会改变颜色。需要注意的是，如果滑动变阻器或者预留的 AD 接口被配置为控制 LED 亮度，那么当 AD 采样值改变时，就会覆盖掉此命令的设定。

## 舵机控制(S=3)

### 命令格式

```
M1004 S3 I[iii] F[fff] D[ddd] T[ttt] B[bbb]
```

### 说明

`I`: 舵机索引(0-1)。

`F`: PWM 频率(hz)，一般舵机控制的频率为50Hz(周期20ms)。

`D`: PWM 占空比， 一般舵机控制的 PWM 占空比范围为0.025-0.125（脉宽0.5ms-2xn8b.nb.5ms）。

`T`: 【可选参数】当配置滑动变阻器的功能为舵机控制时，此参数限定占空比调节范围的最大值，默认为 0.125。

`B`: 【可选参数】当配置滑动变阻器的功能为舵机控制时，此参数限定占空比调节范围的最小值，默认为 0.025。

## 风扇控制（S=4）

### 命令格式

```
M1004 S4 F[iii] P[ppp]
```

### 说明

`F`: 风扇索引(0-3)

`P`: 速度/开关(0-100)：

- 对于 4pin 的风扇控制速度。
- 对于 2pin 的风扇只控制开关。
- 当此参数不为 0 时，风扇开启。

## 相机控制(S=5)

### 命令格式

```
M1004 S5 F[fff] P[ppp]
```

### 说明

`F`: 对焦(0-1)，0关闭对焦，1开启对焦。

`P`: 拍照(0-1)，0不响应，1拍照。

以上参数设定一个即可。

## 滑动电位器功能配置（S=6）

### 命令格式

```
M1004 S6 I[iii] F[fff] D[ddd]
```

### 说明

`I`: 滑动电位器索引(0-1)。

`F`: 功能选择, 支持以下功能：

- F=0: 控制 LED 亮度
- F=1: 控制风扇转速（仅对 FAN2/FAN3 有效）
- F=2: 控制舵机角度
- F=3: 控制电机转速

`D`: 控制的设备索引。

- 例如该功能用于控制风扇，此参数指定风扇编号（2/3）, 当索引大于等于设备总数时，将同时控制所有设备。

## 开关功能配置（S=7）

### 命令格式

```
M1004 S7 I[iii] F[fff] D[ddd]
```

### 说明

`I`: 开关索引(0-1)

`F`: 功能选择, 支持以下功能：

- F=0: 控制风扇开关
- F=1: 控制LED灯带开关
- F=2: 控制电机开关
- F=3: 控制继电器通断
- F=4: 控制蜂鸣器开关
- F=5: 控制预留GPIO的高低电平

`D`: 控制的设备索引。

- 例如，该功能用于控制风扇，此参数指定风扇编号。如果索引大于或等于所有设备的总数，则所有设备将同时被控制。

## 继电器开关控制（S=8）

### 命令格式

```
M1004 S8 P[ppp]
```

### 说明

- `P`: 开关参数(0-1), 0 断开, 1 连通。

## 蜂鸣器开关配置（S=9）

### 命令格式

```
M1004 S9 P[ppp] F[fff]
```

### 说明

- `P`: 开关参数(0-1), 0 关闭, 1 开启。
- `F`: 频率设定，蜂鸣器支持的频率范围为 2000~5000hz (V1硬件不支持此参数)。

## 步进电机控制（S=10）

### 命令格式

```
M1004 S10 D[ddd] P[ppp]
```

### 说明

`D`: 旋转方向(0-1)

`P`: 转速(r/min)

## 预留引脚控制命令（S=11）

### 命令格式

```
M1004 S11 T0 I[iii] O[lll] P[ppp] D[ddd]
M1004 S11 T1 I[iii] F[fff] D[ddd]
M1004 S11 T2 I[iii] F[fff] D[ddd]
```

### 说明

`T`: 预留 IO 的类型：

- T=0: GPIO引脚
- T=1: PWM引脚
- T=2: ADC引脚

### GPIO预留引脚参数（T=0）

`I`: GPIO 索引(4-17)。

`O`: GPIO 方向(0-1), 0 输入, 1 输出。

`P`: 当O为0时，控制输入功能，各项功能同开关一致，请参考开关功能配置(S=7)。当O为1时，控制输出电平高低（0-1），0为低电平，1为高电平。

`D`: 当O为0时，控制设备索引。例如，该功能用于控制风扇。此参数指定风扇编号。如果索引大于或等于所有设备的总数，则所有设备将同时被控制。当O为1时，此参数无效。

### PWM预留引脚参数(T=1)

`I`: PWM引脚索引(当前只能为0)。

`F`: PWM频率(Hz)，100-100k。

`D`: PWM输出占空比(0-1之间的浮点数, 例如0.02)。

### ADC预留引脚参数(T=2)

`I`: ADC引脚索引(0-2)

`F`: 功能选择, 各项功能同滑动电位器，请参考滑动电位器功能配置(S=6)。

`D`: 控制的设备索引，例如功能为控制风扇，此参数指定风扇编号，当索引大于等于设备k总数时将同时控制所有设备。
