日常打印过程中，喷嘴易沾染耗材残留物，长期使用后残留物会碳化发黑，影响打印质量。本款清洁海绵采用耐高温材质，专为清洁打印机热端喷嘴的顽固脏污设计，可有效去除碳化残留，保障打印效果，适用于所有机型的喷嘴。

## 所需材料

- 耐温海绵
- 刷柄模型文件：[brush.3mf](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/nozzle-cleaning-sponge/h1c-brush.3mf)
- 清水

![1.png](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/nozzle-cleaning-sponge/5.png)

## 安装步骤

手持清洁海绵，对准刷柄的安装槽位，平稳插入至底部贴合。

|  |  |
| --- | --- |
|  |  |

安装完成后状态如下，适当蘸取清水。

|  |  |
| --- | --- |
|  |  |

沾水后海绵会自然膨胀，与刷柄内壁紧密贴合，实现牢固卡紧，避免清洁时脱落。

![1.png](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/nozzle-cleaning-sponge/6.png)

## 使用指南

确保海绵充分吸湿（以湿润不滴水为宜），提升清洁去污能力同时防止高温损坏海绵。

![1.png](https://public-cdn.bblmw.com/wiki/new/h2c/maintenance/nozzle-cleaning-sponge/7.png)

通过打印机屏幕，手动将热端温度调整至当前打印耗材对应的工作温度；待热端温度稳定后，手持安装好海绵的刷柄，轻轻擦拭喷嘴外壁及周边区域，直至碳化残留完全清除。(以清理 H2C 感应热端为例)
