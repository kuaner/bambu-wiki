## 什么是 Bambu **可重复使用料盘？**

我们围绕可重复使用料盘设计建立了整个送料系统，实现了在耗材消耗中至少减少 20% 的废料。我们精选了包装材料，以尽量减少对不可回收材料的使用。

可重复使用料盘有两种：**高温料盘**与**低温料盘**。

|  |  |  |
| --- | --- | --- |
| 类型 | 低温料盘 (≤70℃) | 高温料盘 (≤90℃) |
| 材质 | ABS | ABS+PC |
| 耗材兼容性 | PLA、PETG | PLA、PETG、ABS、ASA、PA6-GF、ABS-GF、PAHT-CF、PET-CF、PA6-CF、PC、TPU |

以下是如何使用 Bambu 可重复使用料盘更换新耗材的步骤：

## 操作视频

- 安装 1kg 耗材
- 安装 250g 耗材

## 操作步骤

### 步骤 1：移除新耗材包装

准备好新耗材与可重复使用料盘，并移除新耗材包装。

|  |  |
| --- | --- |
|  |  |

📌 注意：

• 若您的耗材有透明的保护绑带，**请暂勿撕开保护绑带。**

![绑带示意](https://wiki.bambulab.com/general/bbl-reusable-spool/绑带示意.png)

• 若您的耗材是250g耗材，**请勿移除耗材的纸壳芯。**

![250g撕开包装袋](https://wiki.bambulab.com/general/bbl-reusable-spool/250g撕开包装袋.png)

### 步骤 2：拧开可重复使用料盘

逆时针旋开可重复使用料盘。

|  |  |
| --- | --- |
|  | 左侧为料盘宽片，右侧为料盘窄片。 |

### 步骤3：对齐卡槽，安装新耗材

📌 注意：
**切勿撕开保护绑带或移除耗材的纸壳芯。**

1. 找到料盘宽片上的卡扣。

![](https://wiki.bambulab.com/general/bbl-reusable-spool/250g对齐定位_结果.png)

2. 对齐耗材纸壳芯的缺口，牢固地扣上耗材，然后再按上窄片。

- **1kg 耗材:**

|  |  |
| --- | --- |
|  |  |

- **250g 耗材：**

|  |  |
| --- | --- |
|  |  |

3. 顺时针旋紧窄片，直到听到轻微的咔哒声。

|  |  |
| --- | --- |
|  |  |

### 步骤4：整理线头

- **若您的耗材有保护带**，请先撕开最接近耗材头部的保护带；然后将料线头插入到料盘圆孔内，防止料线松垮。最后抽除剩余的保护带。

|  |  |
| --- | --- |
|  |  |

- **若您的耗材没有保护带**，请移除线头胶带，然后将料线头插入到料盘圆孔内。

|  |  |
| --- | --- |
|  |  |

### 步骤5：用力按压耗材

安装完成后，若线材两侧与料盘之间存在缝隙，请手动按压料卷边缘至缝隙填满,以免出现卡线情况。

![](https://wiki.bambulab.com/general/bbl-reusable-spool/整理耗材.jpg)

### 步骤6：粘贴标签

最后，移除料盘上的旧标签，并将耗材附带的标签粘贴到料盘上。
