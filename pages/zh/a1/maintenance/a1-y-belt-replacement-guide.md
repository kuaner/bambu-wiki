## 适用打印机型号

A1

## A1 Y 皮带

Y 皮带是安装在 Y 轴上，将工具头与 Y 电机连接起来并驱动工具头在 Y 方向上运动。

## 何时使用

- Y 皮带磨损
- Y 皮带断裂

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击此处联系在线技术支持 （服务时间 9:00-21:00）](hhttps://support.bambulab.cn/cn/im)，我们将及时回复并为您提供所需的帮助。

## 移除 Y 皮带

### **步骤 1：移除热床和 Y 轴上盖**

将 A1 打印机放置在平整的桌面上，X 轴向上升至顶部；

![](https://wiki.bambulab.com/a1/maintenance/new-heatbed/x_axis_move_up.png)

热床前移到底，移除 Y 轴上盖。

|  |  |
| --- | --- |
|  |  |

然后把热床向后移动到底

![](https://wiki.bambulab.com/a1/maintenance/new-heatbed/heatbed_backward.png)

用 H2.0 内六角扳手移除 4 个软胶塞，完全拧松 4 颗螺丝，从底座上取下热床，放置在桌面上。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### **步骤 2：移除打印机底盖**

#### 1. 将打印机正面朝下放置

将打印机正面朝下放置，方便操作打印机底部。

首先将屏幕翻转到一侧，然后轻轻将打印机正面朝下放置，如下图所示。建议使用一盒耗材将打印机顶部抬起，避免压破挤出机和屏幕。

![](https://wiki.bambulab.com/a1/maintenance/power-supply/place_the_a1_printer_on_its_front.jpeg)

#### 2. 断开端子线缆并拆下线缆支架

断开相机、X 轴电机和 Z 轴电机的线缆,然后拧松下图所示的螺丝（拧松即可，请勿完全拧出！）。

![](https://wiki.bambulab.com/a1/maintenance/replace-z-motor/a1zmotor_(11).jpg)

然后，向上推动线缆支架来断开 USB 数据线。

![](https://wiki.bambulab.com/a1/maintenance/power-supply/disconnect_the_a1_wires_and_remove_the_wire_bracket.jpeg)

#### 3. 取出 SD 卡

从打印机上取出 SD 卡。

#### 4. 卸下打印机底盖

卸下红色标记的 10 颗螺丝。

![](https://wiki.bambulab.com/a1/maintenance/power-supply/remove_the_bottom_housing_cover_screws.jpeg)

### **步骤 3：释放 Y 皮带张紧扭簧和移除皮带压片**

#### 1. 释放 Y 皮带张紧扭簧

将打印机翻转过来，放置在平稳的桌面上。

参考下图释放 Y 皮带张紧扭簧：

|  |  |
| --- | --- |
| 释放张紧器1.jpg | 释放张紧器2.jpg |

#### 2. 拧松 Y 张紧螺丝

Y 同步带的张紧位置在底座的前方，有个遮盖遮住，需要先拿开盖遮盖。然后使用 H2.0 内六角扳手将两颗张紧螺丝松开一圈（请勿完全松开）

> 注意：请勿完全松开或卸下Y张紧螺丝，否则您可能需要重新组装Y张紧器。

|  |  |
| --- | --- |
|  |  |

#### 3. 移除皮带压片

用 H2.0 内六角扳手移除 4 颗螺丝，移除皮带压片

![压片固定螺丝.jpg](https://wiki.bambulab.com/a1/maintenance/a1-y-belt-replacement-guide/%E5%8E%8B%E7%89%87%E5%9B%BA%E5%AE%9A%E8%9E%BA%E4%B8%9D.jpg)

### **步骤 4：粘贴皮带**

请将新皮带与旧皮带通过胶水粘接起来，需要确保以下几点：

1. 新旧皮带的朝向一致，可参考旧皮带的朝向；
2. 以下图所示的粘贴方式为例，可将新皮带齿面较长的一端与旧皮带齿面较少的一端粘贴；

|  |  |
| --- | --- |
| 粘贴皮带.jpg | 新旧皮带.jpg |

## 安装 Y 皮带

### **步骤 1：穿 Y 皮带**

#### 1. 将 Y 皮带穿过 Y 轴

等待胶水凝固后，可拿住位于电机端的旧皮带，在旧皮带的引导下轻轻拉动旧皮带将新皮带穿过 Y 轴。

> 请小心拉皮带，避免新旧皮带在粘贴处断开。

![拉皮带.jpg](https://wiki.bambulab.com/a1/maintenance/a1-y-belt-replacement-guide/%E6%8B%89%E7%9A%AE%E5%B8%A6.jpg)

#### 2. 将新旧皮带分离

当新皮带穿过 Y 轴后，请将新旧皮带从粘贴处撕开分离。

![撕开皮带.jpg](https://wiki.bambulab.com/a1/maintenance/a1-y-belt-replacement-guide/%E6%92%95%E5%BC%80%E7%9A%AE%E5%B8%A6.jpg)

### **步骤 2：固定 Y 皮带**

将同步带两端都接到热床支架上，装上同步带压片，并锁上螺丝固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

移动热床支架确认同步带已安装到位，然后将张紧扭簧安装到固定座挂勾上

![固定张紧器挂钩.jpg](https://wiki.bambulab.com/a1/maintenance/a1-y-belt-replacement-guide/%E5%9B%BA%E5%AE%9A%E5%BC%A0%E7%B4%A7%E5%99%A8%E6%8C%82%E9%92%A9.jpg)

### **步骤 3：安装打印机底盖**

#### 1. 装回打印机底盖

将打印机正面朝下放置，方便操作打印机底部。

![](https://wiki.bambulab.com/a1/maintenance/power-supply/place_the_a1_printer_on_its_front.jpeg)

请注意红色箭头标示的电机线缆。请务必整理好这束线缆后，才能完全按下底盖。

将底盖卡扣到位后，拧入 10 颗螺丝，请注意不要过度拧紧。

![](https://wiki.bambulab.com/a1/maintenance/power-supply/install_the_back_cover_on_a1.jpeg)

#### 2. 装回 SD 卡

将 SD 卡装回打印机

#### 3. 安装线缆支架并连接线缆

对齐线缆支架后，然后向下推动，确保将 USB 数据线完全插入。

然后，拧紧图中所示的螺丝以将其锁定到位。由于这颗螺丝是拧入塑料框架的，请避免过度拧紧。

![](https://wiki.bambulab.com/a1/maintenance/power-supply/install_the_cable_bracket.jpeg)

重新连接摄像头、X 轴电机和 Z 轴电机线缆以完成安装。

![](https://wiki.bambulab.com/a1/maintenance/power-supply/a1_wires.jpeg)

### **步骤 4：装回热床**

将打印机翻转放在平稳的桌面上。

从打印机左（或右）侧观察安装位置，将热床放置到热床支架上；

![](https://wiki.bambulab.com/a1/maintenance/new-heatbed/align_holes.png)

对齐 4 个螺丝孔，用 H2.0 内六角扳手，按对角线锁螺丝的方式锁入 4 颗螺丝，请注意，螺丝需要锁在远离硅胶擦嘴的螺丝孔上，装上 4 个软胶塞。

|  |  |  |
| --- | --- | --- |
|  |  |  |

#### **步骤 5：装回 Y 上盖**

将热床前移到底，将 Y 轴上盖从热床底下穿过，并向前推到底，对齐卡扣，将 Y 轴上盖安装到位。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 设备校准

1. 手动沿 Y 轴方向来回移动热床 3 次，之后再重新拧紧张紧螺丝（拆 Y 皮带的时候已将张紧螺丝拧松一圈），并盖上遮盖。

|  |  |
| --- | --- |
|  |  |

1. 在校准菜单中选中振动补偿，完成一次校准流程。
