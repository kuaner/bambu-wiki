## USB-C 数据线

USB-C 数据线是连接主板与 TH 板之间的一根线缆。

![usb-c-cable.png](https://wiki.bambulab.com/a1/maintenance/usb-c-cable-replacement-guide/usb-c-cable.png)

## 适用打印机型号

A1 系列

## 何时使用

- USB-C 数据线断裂/损坏
- 打印机未检测到工具头
- Bambu Lab 的技术支持人员建议您更换

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击此处联系在线技术支持 （服务时间 9:00-21:00）](hhttps://support.bambulab.cn/cn/im)，我们将及时回复并为您提供所需的帮助。

## 移除旧 USB-C 线

### 步骤 1. 断开 USB-C 线

将工具头上固定 USB-C 线的 4 颗螺丝（BT2\*6）拧下，然后向上拉动 USB-C 线即可将其取下。

![](https://wiki.bambulab.com/a1m/replace-usb-c-cable/remove_usb_c_cable_from_a1_print_head.jpeg)

### 步骤 2. 取下 X 电机罩前盖与线夹

1. 从电机罩右侧卡扣处用力，移除电机罩前盖。

![电机罩前盖卡扣.jpg](https://wiki.bambulab.com/a1/maintenance/usb-c-cable-replacement-guide/%E7%94%B5%E6%9C%BA%E7%BD%A9%E5%89%8D%E7%9B%96%E5%8D%A1%E6%89%A3.jpg)

2. 用手按压线夹两侧，取出线夹。

![双手捏紧线夹.jpg](https://wiki.bambulab.com/a1/maintenance/usb-c-cable-replacement-guide/%E5%8F%8C%E6%89%8B%E6%8D%8F%E7%B4%A7%E7%BA%BF%E5%A4%B9.jpg)

### 步骤 3. 取下 USB-C 线固定器

使用类似平头螺丝刀等工具，从一侧轻轻撬开，即可松开电机罩顶部的 USB-C 线固定器。

![电机罩顶部固定器.jpg](https://wiki.bambulab.com/a1/maintenance/usb-c-cable-replacement-guide/%E7%94%B5%E6%9C%BA%E7%BD%A9%E9%A1%B6%E9%83%A8%E5%9B%BA%E5%AE%9A%E5%99%A8.jpg)

### 步骤 4. 取出线缆盒

1. 将屏幕翻转到一侧，然后轻轻将打印机正面朝下放置，如下图所示。建议使用一盒耗材将打印机顶部抬起，避免挤压挤出机和屏幕。

![](https://wiki.bambulab.com/a1/maintenance/power-supply/place_the_a1_printer_on_its_front.jpeg)

2. 卸下下图所示的 1 颗螺丝，然后断开相机、X 轴电机和 Z 轴电机的线缆；向上推动线缆盒，断开 USB-C 数据线。

|  |  |
| --- | --- |
| usb-c线固定螺丝.jpg |  |

### 步骤 5. 从线缆盒中取出 USB-C 数据线

1. 拧松下图所示的 1 颗螺丝，打开线缆盒；

|  |  |
| --- | --- |
| 线夹螺丝.jpg | 线夹打开关闭.jpg |

2. 从图示卡扣处打开线缆盒，取出 USB-C 数据线。

|  |  |
| --- | --- |
| usb-c线夹螺丝.jpg | usb-c线卡扣.jpg |

### 步骤 6. 从金属套管中取出 USB-C 数据线

1. 撕下粘贴在金属套管上的胶布。

> 可将撕下的胶布的末端贴在打印机或桌面上，安装时可重复使用。

![醋酸胶布.jpg](https://wiki.bambulab.com/a1/maintenance/usb-c-cable-replacement-guide/%E9%86%8B%E9%85%B8%E8%83%B6%E5%B8%83.jpg)

2. 先将带有铁氧体磁环的一端从金属套管中取出，打开图示的两个小卡扣即可取下。

> 请注意铁氧体磁环的位置，可参考旧 USB-C 数据线的位置，在新 UBS-C 线上保持同样的位置安装。

![磁环.jpg](https://wiki.bambulab.com/a1/maintenance/usb-c-cable-replacement-guide/%E7%A3%81%E7%8E%AF.jpg)

3. 从金属套管中把 USB-C 数据线取出。

### 步骤 7. 取下 USB-C 数据线

将 USB-C 数据线从 X 电机罩中取出。

![取出usb-c线.jpg](https://wiki.bambulab.com/a1/maintenance/usb-c-cable-replacement-guide/%E5%8F%96%E5%87%BAusb-c%E7%BA%BF.jpg)

## 安装 USB-C 数据线

### 步骤 1. 将 USB-C 数据线装入 X 电机罩

先将铁氧磁环从新 USB-C 数据线上取下，然后将 USB-C 数据线从电机罩上方的小孔中穿进。

> 建议在新 USB-C 数据线上标记铁氧磁环的位置，便于后续重新安装。

![装回usb-c线.jpg](https://wiki.bambulab.com/a1/maintenance/usb-c-cable-replacement-guide/%E8%A3%85%E5%9B%9Eusb-c%E7%BA%BF.jpg)

### 步骤 2. 将 USB-C 数据线穿入金属套管

1. 将 USB-C 数据线推入编织网管，直至到达编织网管的另一端。将套管压扁后更容易让 USB-C 数据线穿过：

![](https://wiki.bambulab.com/a1m/replace-usb-c-cable/compress_the_wire_loom.jpg)

2. 参考原位置将铁氧磁环安装在 USB-C 数据线上。

![磁环.jpg](https://wiki.bambulab.com/a1/maintenance/usb-c-cable-replacement-guide/%E7%A3%81%E7%8E%AF.jpg)

### 步骤 3. 将 USB-C 数据线装回线缆盒

1. 将 USB-C 数据线的接口对准位置放入线缆盒中，然后扣上卡扣。

|  |  |
| --- | --- |
| 把usb-c线装回线缆支架.jpg | usb-c线卡扣.jpg |

2. 参考下图依次将 X 电机、Z 电机和相机的连接线放入对应的线槽中，并扣上卡扣，拧紧螺丝。

|  |  |  |
| --- | --- | --- |
| 线插入线缆支架.jpg | 理线盒螺丝.jpg |  |

> **注意**：USB-C 的连接需区分方向，USB-C 数据线接口上有一个凸点，请将其朝上，按图示方向安装。  
> ![usbc方向.jpg](https://wiki.bambulab.com/a1/maintenance/usb-c-cable-replacement-guide/usbc%E6%96%B9%E5%90%91.jpg)

3. 对齐线缆支架后，向下推动，确保将 USB 数据线完全插入，并拧紧图中所示的螺丝以将其锁定到位。

> **注意**：由于这颗螺丝是拧入塑料框架的，请避免过度拧紧。

![](https://wiki.bambulab.com/a1/maintenance/wifi-antenna/%E5%AE%89%E8%A3%85%E6%94%AF%E6%9E%B6.jpg)

4. 重新连接摄像头、X 轴电机和 Z 轴电机线缆以完成安装。

> **注意：右侧较短线缆为 X 轴电机线缆，插入右上方接口；较长线缆为 Z 轴电机线缆，插入右下方接口。**

![](https://wiki.bambulab.com/a1/maintenance/wifi-antenna/%E6%8E%A5%E7%BA%BF%E7%BC%86.jpg)

### 步骤 4. 安装 USB-C 数据线固定器和线夹

1. 将 USB-C 线固定器卡在电机罩中。

![usb-c_线固定器.jpg](https://wiki.bambulab.com/a1/maintenance/usb-c-cable-replacement-guide/usb-c_%E7%BA%BF%E5%9B%BA%E5%AE%9A%E5%99%A8.jpg)

2. 参考下图将线夹重新插入到位。

|  |  |  |
| --- | --- | --- |
|  |  |  |

3. 然后将电机罩前盖重新扣上，直到听到卡扣“咔哒”声。

|  |  |
| --- | --- |
|  |  |

### 步骤 5. 将 USB-C 数据线固定至工具头

将 USB-C 线重新插入工具头中，然后用第一步中取下的 4 颗螺丝重新固定 USB-C 线。

![](https://wiki.bambulab.com/a1m/replace-usb-c-cable/usb_cable_orientation.jpeg)

> **注意！**
>
> 1. 请不要过度拧紧螺丝，可能会导致螺纹损坏。
> 2. 请注意 USB-C 数据线的方向和背面的小凹槽对齐。
> 3. USB-C 数据线只能用一种方式安装，正确的方向是数据线接头的凸起对准后方的凹槽。
