## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 拆下 X 轴组件

### 步骤 1：断开连接线

向左放倒机器，注意保护好工具头，露出底部理线盒；依次断开摄像头线、X 电机线、Z 电机线；

拧松 1 颗银色螺丝，滑动线盒断开 USB 线连接。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 2：移除 X 轴组件

从 X 轴背面，移除 6 颗螺丝，将 X 轴组件从龙门架上取下。

|  |  |
| --- | --- |
|  |  |

## 拆卸 X 轴组件

### 步骤1：移除吐料组件

用 H2.0 内六角扳手拧下 1 颗螺丝， 将吐料组件滑出并移除。

![](https://wiki.bambulab.com/a1/maintenance/x-axis/wiper.jpg)

### 步骤2：移除 X 皮带

用胶带固定 X 轴滑块，避免拆装过程中滑块脱落；

用 H2.0 内六角扳手移除 1 颗螺丝，取下 X 轴端盖；**请注意：端盖螺丝较吐料组件螺丝更短，请将两颗螺丝区分开，避免后续安装时出错。**

移除皮带右侧压块，松出皮带，握住皮带张紧块并将皮带抽出。

|  |  |  |
| --- | --- | --- |
|  |  |  |
|  |  |  |

### 步骤 3：移除惰轮和配重块

用 H2.0 内六角扳手拧下惰轮轴，取出惰轮和 2PSC 垫圈；

用 H2.0 内六角扳手移除 2 颗螺丝，取下配重块。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤4：移除理线盒

移除理线盒上的 1 颗银色螺丝和 1 颗黑色螺丝，打开盖子；

用镊子撬开 USB 数据线的盖子，移除理线盒。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤5：拆除 USB 摄像头组件

从电机罩前盖右侧凹槽处用力，取下电机盒前盖；

用力解锁摄像头，断开摄像头连接线，将摄像头取下；

将扳手穿过线夹上方的通孔，辅助拉出线材夹，移除尼龙网管，取下摄像头连接线。

|  |  |  |
| --- | --- | --- |
|  |  |  |
|  |  |  |

### 步骤6：移除 X 轴轨道组件

用 H2.0 内六角扳手拆下电机罩前方的 1 颗螺丝，再拆下背面位置的 3 颗螺丝，将 X 轴轨道组件与 X 电机盒组件分离。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 7：移除 USB-C 数据线

移除 USB-C 数据线的磁环，用力拔出 USB 线缆胶赛，将工具头线缆抽离 X 电机盒。

> **注意**：如果原本打印机的 USB-C 线无法拆除磁环，则无需拆除磁环。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤8：移除 X 轴电机

按照图示方向用力取下 X 电机盒后盖，

用 H2.0 螺丝刀拧下图示位置的 3 颗螺丝，取出 X 电机及其固定座，用 H2.0 内六角螺丝刀拆除电机固定座的 4 颗螺丝，取下 X 电机。

## 组装 X 轴组件

### 步骤1：安装 X 电机

确认 X 电机电缆的朝向，安装到电机固定座上，锁入 4 颗螺丝；

穿电机电缆，将 X 电机装到电机盒上，锁入 3 颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |
|  |  |  |

### 步骤2：安装 USB-C 数据线

穿 USB 数据线，将胶塞安装到位。

|  |  |
| --- | --- |
|  |  |

### 步骤3：安装 USB 摄像头

穿 USB 摄像头电缆，连接 USB 摄像头，将摄像头装到电机盒子上。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤4：安装理线盒

将线缆穿过尼龙编织网管，在电机盒一端装上线夹。

在距离 USB 端口约 12 厘米处安装磁环，然后缠上胶布固定尼龙编织网管，请注意，磁环应该被尼龙编织网管包住；

将线材装到理线盒上，整理好线材，锁 1 颗银色螺丝和 1 颗黑色螺丝，注意 USB 端口处的凸起，方向如图所示，不能装错；

装上电机盒后盖。

|  |  |  |
| --- | --- | --- |
|  |  |  |
|  |  |  |

### 步骤5：安装 X 皮带

将 X 同步带从左侧穿入，注意同步带齿面的朝向，从右侧穿出；

将同步带绕过 X 电机主动轮，安装同步带右侧压块；

|  |  |  |
| --- | --- | --- |
|  |  |  |

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤6：连接 X 线性导轨和 X 电机盒

连接 X 线性导轨和 X 电机盒，在正面锁入 1 颗螺丝，在背面锁入 3 颗螺丝，合上电机前盖。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤7：安装配重块和惰轮

安装配重块，锁入 2 颗螺丝固定；

安装惰轮，在上下侧分别放入垫圈，锁入惰轮轴螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

|  |  |
| --- | --- |
|  |  |

### 步骤8：安装吐料组件

安装 X 轴端盖，锁 1 颗黑色螺丝； 安装吐料组件，锁 1 颗螺丝。

> 注意：端盖螺丝比吐料组件螺丝更短，如果用错则会顶到 X 轴惰轮，导致 X 轴阻力异常，回零时持续丢步等情况。

|  |  |  |
| --- | --- | --- |

## 安装 X 轴组件

### 步骤1：安装 X 轴

将 X 轴对齐两个 Z 滑块上的定位梢，安装到 Z 轴滑块上，左右两侧各锁入 3 颗螺丝固定。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：连接线缆

向后放倒打印机，将 Z 电机线安装到理线盒上;

将理线盒安装在底座上，沿槽位方向滑动理线盒，连接 USB 线，锁紧1颗银色螺丝;

根据文字提示和颜色标贴，连接 X 电机线、Z 电机线和摄像头线，整理线缆，避免线材被压到。

|  |  |  |

2. 检查同步带方向及端盖方向正确。
