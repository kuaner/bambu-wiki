## A1 同步带张紧

我们在 A1 打印机上使用了 3 根同步皮带，它们是实现工具头（X）、热床（Y）和X轴（Z）沿设定方向移动的传动部件，适时的对同步带进行紧张是保持打印质量的重要保证。

> A1 打印机会在准备过程中进行频率扫描，并根据扫描收集到的结果判断同步带是否需要重新张紧。如果确认需要重新张紧，**打印会弹出相关的提示信息，请根据提示信息张紧对应皮带并完成校准。**

![](https://wiki.bambulab.com/a1/maintenance/belt_tension/belt.jpg)

## 所需工具和材料

- H2.0 内六角扳手

![](https://wiki.bambulab.com/n1/p-maintenance/hex_keys.png)

## X  同步带张紧

### 张紧位置

X同步带的张紧位置在工具头的背面，如下图所示。

![](https://wiki.bambulab.com/a1/maintenance/belt_tension/x_screw.jpg)

### 操作说明

1. 操作打印机，将 X 移动到靠近Z轴中间位置，避免移动工具头时划伤热床，关闭打印机；

![](https://wiki.bambulab.com/a1/maintenance/belt_tension/raise_x.jpg)

2. 用H2.0内六角扳手拧松张紧螺丝一圈（请勿完全松开），用手移动工具头沿X轴方向来回运动3次，然后重新拧紧张紧螺丝。

## Y  同步带张紧

### 张紧位置

Y同步带的张紧位置在底座的前方，有个小盖子遮住，需要先拿开盖子。

|  |  |
| --- | --- |
|  |  |

### 操作说明

1. 将热床后移，露出 Y 同步带张紧位置，移除遮盖；

|  |  |
| --- | --- |
|  |  |

2. 使用 H2.0 内六角扳手将 2 颗张紧螺丝松开一圈（请勿完全松开），然后手动沿 Y 轴方向来回移动热床 3 次，之后再重新拧紧张紧螺丝。

注意：请勿完全松开或卸下 Y 张紧螺丝，否则您可能需要重新组装 Y 张紧器。

|  |  |
| --- | --- |
|  |  |

## Z  同步带张紧

### 张紧位置

Z 同步带的张紧位置在底座靠右侧立柱的位置，将热床前移后可以看到。

![](https://wiki.bambulab.com/a1/maintenance/belt_tension/z_position_0.jpg)

### 操作说明

1. 将热床前移，露出 Z 轴同步带张紧位置, 用 H2.0 内六角扳手拧松 2 颗张紧螺丝一圈（请勿完全松开）;

|  |  |
| --- | --- |
|  |  |

2. 进入打印机运动控制界面，执行一次回中操作；然后按住 Z 轴向上（向下）方向键，使 X 轴沿 Z 轴方向上下移动 1 次（注意不要让喷嘴撞击到热床），重新锁紧 2 颗张紧螺丝；

|  |  |
| --- | --- |
|  |  |

## 校准工作

启动打印机，在校准菜单中选中振动补偿，完成一次校准流程。
