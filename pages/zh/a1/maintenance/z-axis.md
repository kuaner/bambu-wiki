## 拆解指引

### 步骤1：固定 Z 轴滑块

将 Z 轴滑块上升至最顶端，用扎带固定，确认滑块没有松动。

![](https://wiki.bambulab.com/a1/maintenance/z-axis/2_ties.jpg)

### 步骤2：移除 Z 轴上盖\*2

用镊子将Z轴上盖水平向外松出，然后向上松出两个边角，取下Z轴上盖。

|  |  |
| --- | --- |
|  |  |

### 步骤3：移除补强钣金

用 H2.0 螺丝刀拧下补强钣金周边的 8 颗黑色螺丝，和底下的 3 颗银色螺丝，移除补强钣金。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤4：移除 Z 轴底板

用 H2.0 螺丝刀移除 8 颗锁立柱螺丝（左右各 4 颗），移除 4 颗锁底板螺丝（中部），移除金属底板。

![](https://wiki.bambulab.com/a1/maintenance/z-axis/8_and_4_screws.jpg)

> 底板内部突出的螺丝头较为尖锐，部分金属框架上可能存在毛刺。在拆装过程请小心操作，注意规避，或佩戴防割手套进行操作。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤5：移除 Z 电机和 Z 同步带

移除线材固定胶布，用 H2.0 螺丝刀移除4颗螺丝，取下 Z 轴电机，移除 Z 同步带。

|  |  |  |
| --- | --- | --- |
|  |  |  |

![](https://wiki.bambulab.com/a1/maintenance/z-axis/remove_z_belt.jpg)

### 步骤6：移除 Z 张紧器

用 H2.0 螺丝刀移除 2 颗螺丝，取下防转片，然后将 2 颗螺丝重新锁回原位，不用锁紧；

用 H2.0 螺丝刀移除 3 颗螺丝，取下 Z 张紧器。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 组装指引

### 步骤1：安装 Z 张紧器

对准安装卡位，将Z张紧器放置到Z轴底座上，锁入3颗螺丝固定；

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤2：安装Z同步带、Z电机

将同步带按运动路径布置好；

根据Z电机电缆位置确认电机安装方向，将主动轮绕过Z同步带，并安装到位；

锁入4颗螺丝，整理好电缆，用胶带贴附固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

|  |  |
| --- | --- |
|  |  |

### 步骤3：张紧同步带

移除2颗张紧螺丝，放入防转片，重新锁入2颗螺丝，暂时不要锁紧；

剪断扎带，解除Z滑块锁定，拉动皮带，确认动作的顺畅无阻滞感；

锁紧两颗张紧螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

|  |  |
| --- | --- |
|  |  |

### 步骤4：安装Z底板

安装底板，根据螺丝位置确认安装方向 ；

两端各锁入4颗锁立柱螺丝，中间段锁入4颗底板固定螺丝。

![](https://wiki.bambulab.com/a1/maintenance/z-axis/8_and_4_screws.jpg)

### 步骤5：安装加强板

安装加强板，在底部锁入3颗螺丝；在正上方锁入4颗螺丝； 在两边锁入4颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤6：安装Z轴上盖

顺着安装槽边缘将Z轴上盖卡到Z轴上，然后向内侧推动上盖，将上盖装到位。

|  |  |  |
| --- | --- | --- |
