## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。

## 拆解指引

### 步骤1：移除料盘支架

> **注意**：需要先移除料盘。

移动工具头和并下降 X 轴，预留操作空间，在支架背面打开卡扣，从横梁上取下料盘支架。

|  |  |
| --- | --- |
|  |  |

### 步骤2：移除料盘轴

如图所示，按逆时针的方向旋转，可将料盘轴松出。

![](https://wiki.bambulab.com/a1/maintenance/spoolholder/remove.jpg)

### 步骤3：移除料管接头

用 H2.0 内六角扳手拧松圆头螺丝，将整个料管接头脱出。

|  |  |
| --- | --- |
|  |  |

## 组装指引

### 步骤1：安装料管接头

对齐支架上的安装槽，将料管接头安装到支架上，拧紧圆头螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤2：安装料盘转轴

如图所示，按顺时针的方向旋转，可将料盘轴拧紧。

![](https://wiki.bambulab.com/a1/maintenance/spoolholder/lock.jpg)

### 步骤3：安装料盘支架

将料盘支架开口向后，扣到横梁上，然后向上扣到位即可。

|  |  |
| --- | --- |
|  |  |

## 功能确认

检查卡扣，确认没有松动。
