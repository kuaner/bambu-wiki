## A1 Y 轴组件拆解指引

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 拆解指引

### 步骤1：移除 Y 轴皮带

释放 Y 轴皮带张紧扭簧，用 H2.0 内六角扳手拧松 2 颗张紧器调节螺丝（各拧松1圈）；

用 H2.0 内六角扳手移除 4 颗螺丝，移除同步带压片，将 Y 轴皮带从Y 轴导轨中抽出取下。

|  |  |
| --- | --- |
|  |  |

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤2：移除 Y 张紧器

用 H2.0 内六角扳手移除 4 颗螺丝，取下 Y 张紧器；

用 H2.0 内六角扳手移除 2 颗螺丝，取下扭簧固定座。

|  |  |
| --- | --- |
|  |  |

### 步骤3：移除 Y 电机

用 H2.0 内六角扳手移除 4 颗螺丝，取下 Y 电机；

用 H2.0 内六角扳手移除 4 颗螺丝，取下 Y 电机固定座。

|  |  |
| --- | --- |
|  |  |

### 步骤4：移除 Y 滑车轴承

将热床支架从 Y 双轴心线轨的一端取下；

用 H2.0 内六角扳手移除 1 颗螺丝，取下 Y 滑车轴承 （共 4 颗）;

请注意，固定 Y 滑车轴承的螺丝扭矩较大，且自带螺丝胶，谨防螺帽打滑。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 组装指引

### 步骤1：安装 Y 滑车轴承

将 Y 滑车轴承安装到热床支架下方，锁紧固定螺丝。（4 颗 Y 滑车轴承安装方法一样）

然后将热床支架安装到 Y 双轴心线轨上，注意安装方向。

|  |  |  |
| --- | --- | --- |
|  |  |  |

注意：更换新的 Y 双轴心线轨时，需要在安装前对滑轨涂抹润滑油润滑。

![](https://wiki.bambulab.com/img_v3_0294_67eba0ab-ab20-44df-9473-c3bc270c607g.jpg)

### 步骤2：安装 Y 电机

对齐安装槽，安装 Y 电机固定座，锁入 4 颗螺丝；

将 Y 电机安装到电机固定座上，电机的线朝下，锁入 4 颗螺丝。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

### 步骤3：安装 Y 张紧器

安装扭簧固定座，注意挂钩的朝向；

对齐安装槽，安装 Y 张紧器，锁入 4 颗螺丝

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤4：安装 Y 同步带

检查同步带的方向，将齿面较长的一端齿面朝下从 Y 张紧器处开始穿同步带，为了让同步带更容易穿过惰轮，需要同时将张紧器活动的部分向导轨方向推并保持住；

将同步带两端都接到热床支架上，装上同步带压片，并锁上螺丝固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

|  |  |  |
| --- | --- | --- |
|  |  |  |

移动热床支架确认同步带已安装到位，然后将张紧扭簧安装到固定座挂勾上，锁紧 2 颗张紧螺丝，完成皮带张紧。

## 功能确认

1. 移动热床支架，确认 Y 动作顺畅，阻力均匀；

2. 检查 Y 电机电缆的方向，出线朝下。

|  |  |
| --- | --- |
|  |  |

注意：如果安装 Y 滑车轴承后，支架在导轨上有阻力异常，可以通过拧松调整螺丝和同侧的Y滑车轴承螺丝，转动调整片实现调整，仅必要时用。
