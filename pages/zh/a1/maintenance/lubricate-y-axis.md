## 引言

A1 的 Y 轴采用了全金属导轮，这套导轨系统确保用户不需要频繁调整A1的运动组件，但需要定期进行润滑和清洁，以减少磨损和异音，保证打印机的精度和寿命，并有效防止导轨生锈。每一台打印机在出厂前，都会得到一定程度的润滑，但机器只会被涂抹少量的润滑剂，因为如果涂抹过量的润滑剂，可能会导致机器在运输中滴落到外壳上，影响外观。

因此，我们强烈建议您在打印机拆箱后，检查Y轴的润滑情况，确保润滑剂均匀覆盖整个导轨。如果发现润滑量不足，请参考以下的Y轴润滑指南。

在日常使用中，我们建议您每个月对Y轴导轨进行一次润滑。同时，当您收到润滑提示时，请按照提示对Y轴导轨进行润滑。

## 所需的材料

#### 润滑油补充说明

考虑到一些用户反馈润滑脂的黏稠性可能会引起灰尘和碎屑问题，**经过反复验证测试后，我们决定更换A1机型Y轴导轨的润滑剂。因此，对于A1型号的Y轴导轨，我们建议使用润滑油进行润滑。如果您之前已经使用了润滑脂，在以后的保养中，我们建议您改用润滑油进行润滑**。在进行润滑的过程中，您也可以先擦除导轨上的润滑脂，然后按照视频指南重新涂抹润滑油。

> 温馨提示：配件盒中提供了两种润滑剂，一种是消音润滑油，另一种是润滑脂。出货的包装可能会因批次而异，请以您收到的实际包装为准。以下是它们的应用场景介绍：
>
> 润滑油的用途：用于 X 轴线轨、Y 导轨和惰轮消异音之类的 。
>
> 润滑脂的用途：用于润滑丝杆和挤出轮。**请注意，严禁将润滑脂用于 X 轴线轨上。**

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 涂润滑油操作指南

在操作过程中，请小心操作，避免将润滑油沾到纹理板表面。如有需要，建议您在操作时将纹理板从热床表面取下。

### 第 1 步：使用无纺布清洁润滑油的尾部；旋转拧开润滑油盖，并将润滑油瓶口剪一个小孔

|  |  |
| --- | --- |
|  |  |

### **第 2 步：将热床推至屏幕方向的尽头，掀开 Y 轴盖板，轻轻抽出 Y 轴盖板**

|  |  |
| --- | --- |
|  |  |

### 第 3 步：使用一块清洁的无纺布擦除导轨上残留的润滑脂及其周围的灰尘和碎屑

|  |  |
| --- | --- |
|  |  |

### 第 4 步：小心地沿着 Y 轴钢轴的上边缘，轻压润滑油瓶，以使润滑油均匀涂抹在钢轴上

> 请注意：只需将润滑油涂抹在钢轴上即可。

|  |  |
| --- | --- |
|  |  |

### 第 5 步： 使用润滑油瓶的尾部，将润滑油均匀涂抹在钢轴的整个圆弧面上

|  |  |
| --- | --- |
|  |  |

### 第 6 步：前后移动热床，使润滑油均匀分布

|  |  |
| --- | --- |
|  |  |

按照相同的方法，对剩余的钢棒区域进行润滑处理。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 第 7 步：将热床推回至屏幕端，盖回 Y 轴上盖
