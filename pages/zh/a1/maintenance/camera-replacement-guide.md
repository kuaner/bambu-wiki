> **隐私提示**：请确保摄像头已正确安装，使摄像头视野正确朝向打印机腔体，以避免对打印区域或喷嘴的检测出现问题。

## 适用打印机型号

A1

## 摄像头组件

A1 摄像头有三种功能：录像、远程直播和延时摄影。

![a1-camera.png](https://wiki.bambulab.com/a1/maintenance/camera-replacement/a1-camera.png)

## 何时使用

当您遇到下列情况时，可能需要更换 A1 摄像头的情况：

- 摄像头或连接线的损坏  
  ![摄像头-.jpg](https://wiki.bambulab.com/a1/maintenance/camera-replacement/%E6%91%84%E5%83%8F%E5%A4%B4-.jpg)
- 摄像头的 LED 灯工作异常
- Bambu Lab 官方技术支持的建议

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 所需工具和材料

- 新摄像头（购买链接：[京东](https://item.jd.com/10093578871265.html)）
- 5 分钟

## 移除 A1 摄像头

### 步骤 1：移除 X 电机罩前盖

从电机罩右侧用力，移除电机罩前盖。

![](https://wiki.bambulab.com/a1/maintenance/a1-replace-x-belt/%E7%A7%BB%E9%99%A4x%E7%94%B5%E6%9C%BA%E7%BD%A9%E5%89%8D%E7%9B%96.jpg)

### 步骤 2：移除摄像头

参考下图从摄像头下方用力推动使其旋转一定的角度，然后断开摄像头连接线，将摄像头取下；

|  |  |
| --- | --- |
|  |  |

如果取下较困难，可以参照下方动图使用螺丝刀辅助。

![remove-with-allen-key.webp](https://wiki.bambulab.com/a1/maintenance/camera-replacement/remove-with-allen-key.webp)

## 安装 A1 摄像头

### 步骤 1：安装摄像头

将摄像头与连接线连接，并将摄像头安装到电机罩上。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：安装 X 电机罩前盖

确认方向后将电机罩前盖扣回，直到听到“咔哒”一声。

## 如何更换摄像头和连接线（可选）

如果仅更换摄像头仍无法解决问题，则可能还需要更换摄像头连接线。

为此，请参考 [A1 线缆更换指南](usb-c-cable-replacement-guide.md)，按照相同步骤从线束中取出相机电缆。

## 设备校准

请打开 Bambu Handy 或 Bambu Studio，检查摄像头组件工作是否正常。
