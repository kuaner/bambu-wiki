## 切刀刀柄

切刀刀柄用于固定切刀片，并驱动其切割耗材。  
![filament_cutter_lever_-_a1_series.png](https://wiki.bambulab.com/a1/maintenance/filament-cutter-lever-replacement/filament_cutter_lever_-_a1_series.png)

## 适用打印机型号

A1 系列打印机

## 何时更换

- 切刀刀柄有物理损坏，且影响使用。

## 所需工具和材料

- 新的切刀刀柄
- H2.0 内六角扳手
- 镊子

## 安全提示

> **重要提醒 ！  
> 切刀刀片比较锋利，拆装过程中注意避开刀刃位置。**

## 拆解步骤

### 步骤 1：拆下工具头前盖

按紧工具头前盖底部轻轻向前拉，取下工具头前盖。

|  |  |
| --- | --- |
|  |  |

取下旋转轮。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：移除热端（喷嘴组件）

移除硅胶套。

![](https://wiki.bambulab.com/a1/maintenance/filament-cutter-lever-replacement/img_e1293.jpg)

用 H1.5 内六角扳手移除下图所示的 2 颗螺丝，取下料线压块。

|  |  |
| --- | --- |
|  |  |

解除热端锁扣，然后捏住散热鳍片的位置，缓慢取出喷嘴组件。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

### 步骤 3：移除五通组件

用 H2.0 内六角扳手移除五通组件底座顶部的两颗螺丝，缓慢向上取出五通组件与底座。需要注意的是，请小心不要损坏黑色的 FPC 线缆。取出五通后可以将其放在工具头上面，如图所示。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

### 步骤 4：移除切刀

向内按压切刀刀柄，同时用 H2.0 内六角扳手拧下下图所示的螺丝。

|  |  |
| --- | --- |
|  |  |

取下螺丝后，缓慢松出切刀刀柄，用镊子夹住刀片底部，向下图箭头所示方向轻轻用力拉出刀片。注意避开刀刃位置，避免割伤。

|  |  |
| --- | --- |
|  |  |

> **重要提醒！** 刀片有尖锐的边角，操作时存在割伤风险，请务必小心谨慎。

### 步骤 5：移除挤出机前盖

用 H2.0 内六角扳手拧下下图所示的 4 颗前盖固定螺丝。

|  |  |
| --- | --- |
|  |  |

拧松工具头侧边的1颗压紧螺丝（不用完全移除，防止内部弹簧垫片掉落）。

|  |  |
| --- | --- |
|  |  |

取下挤出机前盖。

|  |  |
| --- | --- |
|  |  |

### 步骤 6：移除切刀刀柄

用镊子尾部用力推出E型卡簧，**注意的同时轻轻按住卡簧，避免卡簧弹飞。**  
![](https://wiki.bambulab.com/a1/maintenance/filament-cutter-lever-replacement/a%E5%8D%A1%E7%B0%A7%E7%A4%BA%E6%84%8F.jpg)

|  |  |
| --- | --- |
|  |  |

> **注意：** 卡簧与垫圈在拆装过程中非常容易弹飞，请注意提前固定和遮挡。

取下垫圈，刀柄和弹簧。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

## 安装步骤

### 步骤 1：安装切刀刀柄

将弹簧和刀柄安装到刀柄转轴上，放上垫圈，装上E型卡簧，用镊子按压卡簧将其安装到位。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

### 步骤 2：安装挤出机前盖

用 H2.0 内六角扳手锁紧 4 颗螺丝。

|  |  |
| --- | --- |
|  |  |

拧紧挤出机侧面螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 3：安装切刀

将切刀安装到刀柄上，抬起刀柄，沿着刀槽将切刀滑入到位，向内按压住切刀刀柄，锁紧 1 颗固定螺丝，固定刀柄。

|  |  |
| --- | --- |
|  |  |

|  |  |
| --- | --- |
|  |  |

> **重要提醒！** 刀片有尖锐的边角，操作时存在割伤风险，请务必小心谨慎。

### 步骤 4：安装五通组件

将五通组件与底座装回，请确保黑色 FPC 线缆不要被折叠，顺利放入空缺的位置。然后拧入 2 颗底座螺丝，固定五通。  
![](https://wiki.bambulab.com/a1/maintenance/filament-sensor-replacement/20250313-175901.webp)

|  |  |
| --- | --- |
|  |  |

### 步骤 5：安装热端（喷嘴组件）

将喷嘴组件的散热鳍片向后方倾斜一定角度放入，内部的磁铁会吸附在螺丝上辅助归位。

|  |  |
| --- | --- |
|  |  |

重新推回卡扣，锁紧喷嘴组件。按上料线压块。

|  |  |
| --- | --- |
|  |  |

用 H1.5 内六角扳手锁紧 2 颗螺丝，固定料线压块。

|  |  |
| --- | --- |
|  |  |

安装喷嘴硅胶套，要确保喷嘴组件尖端有正确露出。按上旋转轮。

|  |  |
| --- | --- |
|  |  |

### 步骤 6：安装工具头前盖

最后，将前盖上方凸出的位置对齐工具头凹槽，然后按压底部的位置，直到会听到“咔嚓”声，安装就完成了。  
![](https://wiki.bambulab.com/a1/maintenance/filament-cutter-lever-replacement/img_e1288.jpg)

## 如何验证成功

- 刀柄能顺畅动作
