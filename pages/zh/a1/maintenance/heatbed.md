## **A1 热床拆装指引**

本文将提供完整的更换 A1热床的操作指引。（白色硅胶挡块已取消，后续批次的热床单品将变为星型后档）

![星挡板.jpg](https://wiki.bambulab.com/a1/maintenance/heatbed/%E6%98%9F%E6%8C%A1%E6%9D%BF.jpg)

安装配件及其存在位置示图：

| --- | --- | --- |
| 安装配件 | 后挡配件及螺丝存放位置（首批） | 后挡配件及螺丝存放位置（新包装） |

**注意：**

**目前最新版本的热床已取消软胶塞，同时修改为 1 个螺丝孔。新旧版本热床随机发货。**

新旧版本热床仅软胶塞和螺丝孔存在差异，不影响正常工作。热床更新旨在防止更换时误装。

### 前期操作

断开电源线连接，移除打印板。

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请[点击这里提交工单](https://bambulab.cn/zh/sign-in?to=%2Fmy%2Fsupport%2Ftickets)，我们将及时回复并为您提供所需的帮助。

## 拆除旧热床

### 步骤1：将热床从底座上移除

将A1打印机放置在平整的桌面上，热床向后移动到底，X轴向上升至顶部；

|  |  |
| --- | --- |
|  |  |

用H2.0内六角扳手移除4个软胶塞，完全拧松4颗螺丝，从底座上取下热床，放置在桌面上。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤2：向左侧放打印机

在打印机吐料组件的一侧放置一个耗材盒；然后侧放打印机，使Z轴的上部落在耗材盒上，Z轴底部和底座左后角落在桌面上，注意避免压到X轴和吐料组件。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤3：移除理线盒

依次断开Z电机线（黄色标识）、X轴电机线（绿色标识）和摄像头连接线（白色标记）；

用H2.0内六角扳手完全拧松银色螺丝，滑动理线盒，断开USB线，并将Z电机线从线槽中松出。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤4：移除底板

用H2.0内六角扳手拧下6颗螺丝，从Z电机附近打开后底板并取下；

|  |  |
| --- | --- |
|  |  |

用H2.0内六角扳手拧下10颗螺丝，先从触摸屏的一侧打开前底板，然后将其取下。

注意：部分产品的前底板在电源模块的一侧边缘有打硅胶，需要稍微用力才能正常打开

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤5:  断开热床线缆

用手按压绝缘胶套，解锁加热线插头，断开2根热床加热线 ，然后断开4PIN的热床信号线，并将其从黑色胶布和白色硅胶中松出；

|  |  |  |
| --- | --- | --- |
|  |  |  |

用H2.0内六角扳手拧下1颗地线螺丝，松出黄绿色的地线，从左侧抬起线材胶塞后将其拔出，移除热床线缆。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤6:  正放打印机

现在旧热床已经被拆除，我们需要正放打印机，为安装新的热床做好准备。

注意避让理线盒，然后立起打印机。

|  |  |
| --- | --- |
|  |  |

## 安装新热床

### 步骤1:  将新热床安装到底座上

准备新的热床组件，从打印机左（或右）侧观察安装位置，将热床放置到热床支架上；

![](https://wiki.bambulab.com/a1/maintenance/new-heatbed/align_holes.png)

对齐4个螺丝孔，用H2.0内六角扳手，按对角线锁螺丝的方式锁入4颗螺丝，请注意，螺丝需要锁在远离硅胶擦嘴的螺丝孔上，装上4个软胶塞。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤2: 连接热床线缆

与拆装旧热床时类似，将打印机向吐料组件一侧放倒，注意避开X轴和吐料组件；拉直热床线缆，按图示中正确的方向弯折热床线缆；

|  |  |  |
| --- | --- | --- |
|  |  |  |

将热床线缆依次穿过底座后侧的过线孔，然后依次将4PIN的热床信号线、2根黑色加热线穿过龙门架底部处的过线孔，用内六角扳手可以协助您将线缆从另一端扯出；

|  |  |  |
| --- | --- | --- |
|  |  |  |

将白色的胶塞塞进底座过线孔，以保证连接线缆时，有足够的长度；握住加热线绝缘胶套，将2根加热线分别连接到2个连接柱上，然后连接热床信号线；为了避免信号线在安装过程中损伤，请将信号线绕过白色的螺丝柱，并使用胶布将信号线进行固定；

|  |  |  |
| --- | --- | --- |
|  |  |  |

用1颗螺丝（含垫圈）将热床地线（黄绿线）锁到Y轴导轨上。

![](https://wiki.bambulab.com/a1/maintenance/new-heatbed/lock_ground_cable.png)

### 步骤3: 安装底板

合上前底板，注意避让Z电机线，用H2.0内六角扳手锁入10颗螺丝；

|  |  |
| --- | --- |
|  |  |

如下图所示，调整白色线材胶塞的方向，避免热床线缆产生交叉的情况；

|  |  |  |
| --- | --- | --- |
|  |  |  |

将白色胶塞扣到底座的卡扣上，然后用后底板上的半圆形缺口压紧白色胶塞，用H2.0内六角扳手锁入6颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤4：安装理线盒

对齐卡扣位置和USB线连接口，向USB接口的方向滑动理线盒，将理线盒安装到位，并确认理线盒没有浮起；

|  |  |  |
| --- | --- | --- |
|  |  |  |

锁紧银色螺丝，并将Z电机线整理入线槽内，依次连接X轴电机线（绿色标识）、Z电机线（黄色标识）和摄像头连接线（白色标识）。

|  |  |
| --- | --- |
|  |  |

### 步骤5：安装后挡硅胶

正放打印机，在底座后侧接近热床线胶塞的地方贴上硅胶挡块，并保持按压3秒钟。如果底座有明显的脏污，请使用酒精擦拭清洁后，再粘贴上后挡硅胶。至此，新热床的安装操作完成。

|  |  |
| --- | --- |
|  |  |

## 功能检查

新热床安装完成后，我们需要给打印机通电，并设置一个比室温约高20度的温度值，确认热床温度能正常升高并保持在设定温度并值。

| --- | --- |
|  |  |
