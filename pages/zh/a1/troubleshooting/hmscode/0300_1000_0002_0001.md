## **为何会出现此错误**

随着时间的推移，同步带的预紧力会逐渐下降，刚度也越来越低。 如果刚度太低，打印质量会在高打印加速度下受到影响。 所以当打印机开始共振校准时，会计算皮带的预紧状态，如果松了，就会出现这个错误。

## A 系列打印机故障排除指南

### 张紧X皮带

使用 H2.0 内六角扳手松开工具头背后的螺丝（如下图所示），重新拧紧它，然后再重新执行一次打印机校准。

|  |  |
| --- | --- |
| 拧松X张紧螺丝 | 扶住右侧三角螺丝（不用发力），重新锁张紧螺丝 |

注意不要拧动工具头侧边凸出的这个螺丝，这会破坏内部弹簧的张力。

![](https://wiki.bambulab.com/n1/p-maintenance/x_belt_t_2.png)

### 张紧 Y 皮带

#### A1

1. 将热床后移，露出 Y 同步带张紧位置，移除遮盖；

|  |  |
| --- | --- |
|  |  |

2. 使用 H2.0 内六角扳手将 2 颗张紧螺丝松开一圈，然后手动沿 Y 轴方向来回移动热床 3 次，之后再重新拧紧张紧螺丝。  
**注意：请勿完全松开或卸下 Y 张紧螺丝，否则您可能需要重新组装 Y 张紧器。**

|  |  |
| --- | --- |
|  |  |

#### A1mini

移除Y轴维修盖

![picture1.jpeg](https://wiki.bambulab.com/n1/maintenance/belt_tension/picture1.jpeg)

拧松张紧螺丝（下方绿圈内的螺丝）

![](https://wiki.bambulab.com/n1/p-maintenance/y_belt_t_2.png)

轻轻推动 Y 张紧块，确保张紧块能够移动，再重新锁紧张紧螺丝

![](https://wiki.bambulab.com/n1/p-maintenance/press_the_tensioner_block.jpg)

若张紧皮带后设备依然提示 Y 轴频率偏低，请先移除热床上方的打印板。

![](https://wiki.bambulab.com/a1m/replace-heatbed/remove_the_textured_pei_plate.jpg)

再移除热床下侧的三颗松紧螺丝。请注意，热床右上角的位置没有螺丝的。

![](https://wiki.bambulab.com/a1m/replace-heatbed/heatbed_locking_screws.jpeg)

然后移除四颗图示的热床螺钉。

![](https://wiki.bambulab.com/a1m/replace-heatbed/remove_the_four_heatbed_screws.jpeg)

将热床翻开后，拧紧 Y 滑块上的这两个螺丝。

![热床.jpg](https://wiki.bambulab.com/x1/troubleshooting/hmscode/0300-1000-0002-0001/%E7%83%AD%E5%BA%8A.jpg)

完成后将热床安装回原位。

![](https://wiki.bambulab.com/a1m/replace-heatbed/remove_the_four_heatbed_screws.jpeg)

将螺丝拧紧至与热床底座齐平，再进行一次[手动调平](../../../a1-mini/maintenance/manual-bed-tramming.md)。

![](https://wiki.bambulab.com/a1m/replace-heatbed/heatbed_screw.png)

## 校准

以 A1 为例，在校准菜单中选中振动补偿，完成振动补偿校准。
