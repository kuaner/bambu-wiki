## 故障现象

A 系列打印机使用加速度传感器探测热床沿 Y 方向上运动。如果传感器脱落或受损，打印机接受到的传感器信号弱，会触发告警。

## 故障排除

### A1 打印机

1.取下打印板，并移除螺丝孔的硅胶保护盖，暴露出螺丝孔并卸下螺丝；

|  |  |
| --- | --- |
|  |  |

2.翻转热床面，暴露出热床底部结构即可看到热床加速度传感器，检查传感器接头连接是否松动。若松动，请重新拔插传感器接头。

|  |  |
| --- | --- |
|  |  |

3.若传感器连接正常，很有可能传感器已损坏，需要更换热床压力传感器，具体更换步骤请参考 wiki：[A1 热床传感器拆装指引](../../maintenance/heatbed-sensor.md)

### A1 mini 打印机

1.用H2.0内六角扳手移除螺丝，松出Y轴加速度传感器(涡流)线圈，检查线圈是否有损坏；

|  |  |
| --- | --- |
|  |  |

2. 参考[A1 mini 热床拆装指引](../../../a1-mini/maintenance/heatbed-replacement-guide.md)检查加速度传感器（如下图**标记3**所示）与主板连接是否松动，若松动请重新拔插;

![](https://wiki.bambulab.com/n1/a1-mini-base-housing/%E6%96%AD%E5%BC%80y%E7%94%B5%E6%9C%BA%E7%BA%BF%E3%80%81z%E7%94%B5%E6%9C%BA%E7%BA%BF%E5%92%8Cy%E7%BA%BF%E5%9C%88.png)

3. 若重新拔插无效或加速度传感器链路存在损坏，参考[A1 mini 热床拆装指引](../../../a1-mini/maintenance/heatbed-replacement-guide.md)更换加速度传感器。

## 错误信息

HMS\_0300-1B00-0001-0001: 热床加速度传感器信号弱，可能是传感器脱落或已受损。
