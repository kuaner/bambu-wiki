## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

### 步骤4：拆卸理线盒，并拔出相关的连接器

#### 1. 将热床推至屏幕另一端的尽头

![](https://wiki.bambulab.com/a1/manual/pack-a1-combo/4%E7%90%86%E7%BA%BF%E7%9B%921.png)

#### 2. 将A1向后旋转90度,将其仰放在桌子边缘(建议用硬纸反盖住桌子以保护打印机)，使打印机底座面向自己，以便下一步拆卸理线盒。

请注意，在进行后述步骤前,请确保打印机在桌面上是稳定的，并手扶打印机的底座。

|  |  |
| --- | --- |
|  |  |

#### 3. 拧松位置所示的理线盒预装固定螺丝，并拔掉3个连接器。

|  |  |
| --- | --- |
|  |  |

#### 4. 往下推动理线后，将Type-C连接口拔出。抠开黄色线缆卡线槽，并卸载理线盒。

在操作过程中，如果遇到困难，请参考开箱视频中的操作方法。你可以使用H1.5的内六角螺丝刀撬开线槽，以免损伤指甲。

|  |  |
| --- | --- |
|  |  |
|  |  |

#### 5. 用自封袋包装理线槽

### 步骤8：将热床上的四颗螺丝拧紧，以防止在运输过程中损坏热床组件

#### 1. 推动热床，使擦嘴组件的边缘大致与打印机底座凹槽对齐。这样，热床上的四个螺丝孔位就会大致和打印机底座对齐，以便于下一步拧入螺丝。

#### 2. 将底座翻转 90 度，使得屏幕位于正上方。

|  |  |
| --- | --- |
|  |  |

#### 3. 拧紧四颗螺丝，以锁紧热床。如果螺丝无法拧入，请进行微调，使热床孔位和底座孔位对齐。

|  |  |
| --- | --- |
|  |  |

#### 4. 检查热床状态，在螺丝锁紧后，确保热床处于固定不可移动的状态。
