## 操作步骤

**保护泡沫可能与开箱视频所示的机器有所不同，请以您收到的机器为准。**

### 第 1 步：拆箱取出 A1 打印机及其配件

1. 划开封箱胶带，从顶部将打印机及其配件整体提出，打开塑料包装袋并将保护泡沫取出

|  |  |
| --- | --- |
|  |  |
|  |  |

2. 取出构建板、快速指南和免责声明，仔细阅读快速指南，提前熟悉开箱的注意事项

|  |  |
| --- | --- |
|  |  |

 3. 取出保护纸壳，将打印机配件逐一取出

|  |  |
| --- | --- |
|  |  |

4. 拆除打印机保护泡沫和保护纸板，将打印机龙门架与底座取出，注意打印机底座下放有耗材样品与 PTFE 料管

|  |  |
| --- | --- |
|  |  |
|  |  |
|  |  |

### 第 2 步：检查包装盒中的配件

包装盒内包含 A1 打印机底座、A1 打印机龙门架、打印机底座螺丝（ST3-23 螺丝，用于底座）、3D 打印耗材色卡、吐料组件及其螺丝（M3-12 螺丝，用于吐料组件）、料盘支架、PTFE管（用于外挂料盘，1根）、耗材样品、通针、内六角扳手（H2和H1.5）、热床擦嘴胶条、料管集线器、热床刮刀刀片及其螺丝（BT2.6-8 螺丝，用于刮刀）、工具头切刀刀片、润滑油、润滑脂、快速指南、保修条款、免责声明和安全指引。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 第 3 步：解锁热床

1. 将打印机底座翻转 90 度，使得屏幕位于正上方。

|  |  |
| --- | --- |
|  |  |

2. 使用 H2 内六角扳手，拧下打印机底座上高亮标注的 4 个螺丝以解锁热床。

|  |  |
| --- | --- |
|  |  |
|  |  |

> ***注意：解锁热床后请小心移动热床；可使用包装中的缓冲泡棉保护热床，以防碰撞。***

### 第 4 步：组装打印机底座与龙门架

1. 如图所示放置打印机龙门架，并解开底座上面的线缆盒。

|  |  |
| --- | --- |
|  |  |

2. 将底座左右倾斜约 45 度，以穿过打印机框架；将侧面卡槽与打印机龙门架对齐，缓慢放下打印机底座，直至其与桌面上的打印机龙门架完全齐平。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 第 5 步：解锁工具头

剪下工具头和 X 轴周围的轧带，并取下纸板；去除龙门架上的轧带及减震泡棉。

|  |  |
| --- | --- |
|  |  |

### 第 6 步:  拆下 Y 轴滑轨盖板

1. 将热床平推至屏幕方向的尽头，从后侧撬开 Y 轴滑轨盖板

|  |  |  |
| --- | --- | --- |
|  |  |  |

2. 轻轻将 Y 轴滑轨盖板抽出

|  |  |
| --- | --- |
|  |  |

### 第 7 步：锁紧底座

1. 在图中高亮的螺丝孔位处安装 10 颗 ST3-23 螺丝（用于打印机底座）

|  |  |
| --- | --- |
|  |  |

2. 将热床推至屏幕另端的尽头，在图中高亮的螺丝孔位处再安装 2 颗 ST3-23 螺丝（用于打印机底座）

|  |  |
| --- | --- |
|  |  |

### 第 8 步：将 Y 轴滑轨盖板装回

再次将热床平推至屏幕方向的尽头，轻轻将 Y 轴导轨盖板滑回原位，确保对齐卡扣按下

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 第 9 步：将打印机放置在桌面上，使打印机底座面向自己，以便下一步插入理线盒

将热床推至屏幕另一端的尽头，将A1向后旋转90度，将其仰放在桌子边缘；建议用硬纸反盖住桌子以保护打印机。

|  |  |
| --- | --- |
|  |  |

> ***注意：此步骤建议用硬纸反盖住桌子以保护打印机，在进行后述步骤前,请确保打印机在桌面上是稳定的，并手扶打印机的底座。***

### 第 10 步：插入理线盒

1. 如图所示，将理线盒上的 2 个卡扣与底座上的卡槽对齐

|  |  |
| --- | --- |
|  |  |

2. 如图所示向上滑动理线盒，直到 Type-C 线缆卡入位，请勿强行插入线缆

|  |  |
| --- | --- |
|  |  |

3. 确保理线盒完好无损且与插槽齐平，然后拧入高亮位置所示的预装螺丝

|  |  |
| --- | --- |
|  |  |

### 第 11 步：插入连接器

连接器电机线缆连接方式如图所示。

|  |  |
| --- | --- |
|  |  |

1. 根据线缆标签颜色和连接器口的颜色，分别插入 3 根电机线缆

|  |  |
| --- | --- |
|  |  |
|  |  |

2. 将带黄色标签线缆塞入线缆槽中，关闭整线盖板。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 第 12 步：撕掉热床表面的保护膜并放置构建板

将打印机恢复正放，撕掉热床表面保护膜，将配件中的构建板放置在热床上

|  |  |
| --- | --- |
|  |  |
|  |  |

> ***注意：此步骤中撕掉热床表面保护膜的方式可能不同于视频，请以热床表面的提示为准。***

### 第 13 步：翻转触摸屏并撕掉屏幕保护膜

将触摸屏翻转，使触摸屏就位，如图所示。

|  |  |
| --- | --- |
|  |  |

### 第 14 步：安装吐料组件

将吐料组件从后往前滑入 X 轴导轨末端端盖的插槽中，使用配件盒中的 1 颗 M3-12 螺丝（用于吐料组件）来固定吐料组件；若操作中工具头被滑到最左侧，在安装吐料组件前，稍微朝电机罩方向推动工具头，为安装留出空间。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 第 15 步：安装料盘支架

1. 将料架支撑轴旋入料架主体，完成料盘支架组装

|  |  |
| --- | --- |
|  |  |

2. 将料盘支架卡在龙门架的横梁上，带有Bambu Lab LOGO的一面朝前；推荐将支架装在横梁中间偏右，可以贴着右侧横梁。

![](https://wiki.bambulab.com/a1/manual/unboxing-combo/ap4-v.png)

3. 将 PTFE 料管一端连接至任意一个工具头上的进料口，另一端与料盘支架上的料管接头连接。

|  |  |
| --- | --- |
|  |  |

4. 将工具头 Type-C 线缆卡进集线器的小孔中，将 PTFE 料管卡入其他任意一个大孔中。在热端与热床接触后，将集线器的边缘横梁的下沿对齐是集线器的最优位置，在此位置 Type-C 线缆与 Z 轴立柱卡住的可能性最低，避免干扰 Type-C 连接。

|  |  |
| --- | --- |
|  |  |

5. 将耗材料盘挂在料盘支架上，手动将耗材送入 PTFE 料管上料。

![](https://wiki.bambulab.com/a1/manual/unboxing-combo/ap10-v.png)

### 第 16 步：启动打印机，完成初始化和校准

1. 连接电源线，按下左后侧开关按钮启动打印机

|  |  |  |
| --- | --- | --- |
|  |  |  |

2. 确保热床上面安装了构建板（参考第 13 步），打印机开机后根据屏幕上的提示完成打印机的初始化和校准。
