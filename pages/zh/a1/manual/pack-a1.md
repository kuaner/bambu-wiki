## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 视频指南

## 拆卸操作步骤

### 第 1 步：从料盘支架上取下料盘

将耗材手动从料管中抽出，将料头线卡入料盘孔，从料盘支架上取下料盘

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 第 2 步：拆除打印机上的料管并切断电源

1. 固定料管和工具头连接线的集线器取下

|  |  |
| --- | --- |
|  |  |

2. 按压工具头入料口接头（推荐使用镊子），将料管拔出；按压料盘支架上的料管接头，拔出料管的另一端，拆除料管

|  |  |
| --- | --- |
|  |  |

3. 按下左后侧开关按钮关机，断开电源线

|  |  |
| --- | --- |
|  |  |

### 第 3 步：卸下吐料组件、取下打印面板、折叠屏幕并卸载耗材支架

1. 拆除吐料组件下方的一颗 M3-12 固定螺丝，将吐料组件向后滑出X轴末端端盖插槽

|  |  |
| --- | --- |
|  |  |

2. 从热床上取下打印面板，将打印机右侧的显示屏向后翻转收起

|  |  |
| --- | --- |
|  |  |

3. 打开料盘支架固定卡扣，将其从龙门架的横梁上取下

|  |  |
| --- | --- |
|  |  |

### 第 4 步：拆卸理线盒，并拔出电机连接器

1. 将热床推至屏幕另一端的尽头

![](https://wiki.bambulab.com/a1/manual/pack-a1-combo/4%E7%90%86%E7%BA%BF%E7%9B%921.png)

2. 将打印机向后旋转90度，将其仰放在桌子边缘，使打印机底座面向自己，以便下一步拆卸理线盒

|  |  |
| --- | --- |
|  |  |

> ***注意：此步骤建议用硬纸反盖住桌子以保护打印机，在进行后述步骤前,请确保打印机在桌面上是稳定的，并手扶打印机的底座。***

3. 拧松位置所示的理线盒预装固定螺丝，并拔掉 3 个连接器

|  |  |
| --- | --- |
|  |  |

4. 往下推动理线器，将 Type-C 线缆从接口拔出；撬开黄色线缆卡线槽，并卸载理线盒。

|  |  |
| --- | --- |
|  |  |
|  |  |

> ***注意：操作过程中，如果遇到困难，请参考开箱视频中的操作方法。建议使用H1.5的内六角螺丝刀撬开线槽，以免损伤指甲。***

5. 使用自封袋包装理线槽

|  |  |
| --- | --- |
|  |  |

### 第 5 步：移除12颗打印机底座和龙门架间的固定螺丝

打印机底座和龙门架间的固定螺丝（12颗）位置如图所示。

|  |  |
| --- | --- |
|  |  |

1. 将热床平推至屏幕方向的尽头，并抽出 Y 轴滑轨盖板。

|  |  |
| --- | --- |
|  |  |

2. 松开打印机底座和龙门架间的 12 颗固定螺丝，期间需要推动一次热床，以找到最后 2 颗螺丝的孔位。

|  |  |
| --- | --- |
|  |  |

3. 再次将热床平推至屏幕方向的尽头，推回 Y 轴滑轨盖板。

|  |  |
| --- | --- |
|  |  |

### 第 6 步：用扎带锁住工具头并安装保护泡棉和纸板

1. 将工具头向 X 轴导轨末端移动，安装工具头保护纸壳，并使用扎带将工具头与龙门架捆绑固定。

|  |  |
| --- | --- |
|  |  |

2. 安装 X 轴导轨保护纸壳，并使用扎带固定

|  |  |
| --- | --- |
|  |  |

3. 将减震泡棉分别放置在龙门架两端内侧，并分别使用扎带固定

|  |  |
| --- | --- |
|  |  |
|  |  |

如果您的打印机有 Z 轴限位器，可对齐螺丝孔安装限位器。

|  |  |
| --- | --- |
|  |  |
|  |  |

4. 使用扎带将线缆与龙门架固定

|  |  |
| --- | --- |
|  |  |

### 第 7 步：分离打印机龙门架和打印机底座

将打印机底座抬起，稍微倾斜从龙门架中分离

|  |  |
| --- | --- |
|  |  |

### 第 8 步：将热床上的四颗螺丝拧紧，以防止在运输过程中损坏热床组件

1. 推动热床，使擦嘴组件的边缘大致与打印机底座凹槽对齐，使热床上的四个螺丝孔位就会大致和打印机底座对齐，以便于下一步拧入固定螺丝；将底座翻转 90 度，使得屏幕位于正上方

|  |  |
| --- | --- |
|  |  |

2. 拧紧 4颗固定螺丝以锁紧热床。若螺丝无法拧入，可以稍微移动热床进行微调，使热床孔位和底座孔位对齐。

|  |  |
| --- | --- |
|  |  |

3. 检查热床运动状态，将螺丝锁紧后确保热床处于固定不可移动的状态。

![](https://wiki.bambulab.com/a1/manual/pack-a1-combo/8%E9%94%81%E7%B4%A7%E7%83%AD%E5%BA%8A%E8%9E%BA%E4%B8%9D5.png)

## 装箱操作步骤

### 步骤1：将零件装回配件盒，将其他配件逐一放入保护泡棉

1. 将零件装回配件盒；将料盘支架卡扣锁回，将料架支撑轴旋出料架主体

|  |  |
| --- | --- |
|  |  |

2. 将料盘支架、吐料组件、配件盒、电源线和3D打印耗材色卡逐一放入保护泡棉中

![](https://wiki.bambulab.com/a1/manual/pack-a1/accessories_general.jpg)

### 步骤2：放置保护泡棉并装箱

1. 在打印机底座两侧安装保护泡棉，注意在安装时将热床线缆穿过保护泡棉孔洞，避免发生挤压。

|  |  |
| --- | --- |
|  |  |

2. 将打印机各部件及其配件依次装入包装箱

|  |  |
| --- | --- |
|  |  |
|  |  |
|  |  |
|  |  |

3. 将塑料包装袋封起，使用胶带封箱

|  |  |
| --- | --- |
|  |  |
|  |  |
