建议您在打印机开箱前浏览完整视频，确保顺畅的开箱体验。新版和旧版两种的包装方式随机发货，请以实际收到的产品为准。新包装开箱指南请参考[此页面](unboxing-a1-new.md)。

- [A1 单机/combo 开箱指南（新）](unboxing-a1-new.md)

保护膜、保护泡沫和保护纸板可能与开箱视频所展示的机器有所不同。例如，新出货的 A1 已移除了工具头周围的纸板，请以您实际收到的机器为准。

A1 上市以来，不少用户反馈热床保护贴膜过粘不易撕取，另外还有部分用户忘记撕膜导致打印问题，经过反复验证，在 2023 年底迭代取消热床保护贴膜。

> **最新包装的 A1 系列打印机已不再赠送色卡。**

1. 从纸盒里使用塑料袋左右两侧的拉手从纸箱中取出打印机，将打印机放置在平坦的桌面上，并移除表面的保护泡沫。

## 第 2 步：检查包装盒中的配件

包装盒内包含 A1 打印机底座、A1 打印机龙门架、打印机底座螺丝（ST3-23 螺丝，用于底座）、AMS lite 主体（包含 4-pin 线）、AMS lite 底座支架和安装螺丝（BT3-8 螺丝，用于 AMS 支架）、AMS lite 料盘卷轴、吐料组件及其螺丝（M3-12 螺丝，用于吐料组件）、料盘支架、PTFE 管（用于 AMS lite，2 长 2 短共 4 根）、PTFE 管(用于外挂料盘，1 根）、PEI纹理板、耗材样品、通针、内六角扳手（H2.0 和 H1.5）、料管集线器、热床刮刀刀片及其螺丝（BT2.6-8 螺丝，用于刮刀）、工具头切刀刀片、润滑油、润滑脂、快速指南、保修条款、免责声明和安全指引、32 GB MicroSD 卡（打印机内）。

## 第 16 步：组装 AMS lite

### 2. 使用配件盒中的 4 颗 BT3-8 螺丝（用于 AMS 底座支架）连接 AMS lite 的主体和支架

### 3. 滑入料盘转轴，并推到底部。安装时，请确保料盘转轴及料盘轴颜色一一对应(如图所示，黄色对黄色，绿色对绿色)，以防损坏部件

黄色转轴是六边形的形状，相对容易对准卡扣位置。绿色转轴是长方形的形状，所以建议在插入之前先大致对准孔位，然后平行移动，稍作微调以确保对准卡扣位置。

### 4. 在成功安装转轴后，将 AMS lite 放置在 A1 mini 打印机的右侧位置，A1 和 AMS lite 之间的推荐距离为 50mm

![](https://wiki.bambulab.com/a1/manual/unboxing-combo/step15-12.png)

### 5. 将 4 个铁氟龙管插入工具头五通

如图所示，将两根较短特氟龙管插入 AMS lite 接口 1 和 2 中；将两根较长特氟龙管插入 AMS lite 接口 3 和 4 中;

|  |  |
| --- | --- |
|  |  |

> **注意**：AMS lite 的  PTFE 管上带有硅胶集线器，硅胶集线器的推荐位置如下。如位置不正确，可能会导致供料系统阻力过大而报错。
>
> ![](https://wiki.bambulab.com/a1/manual/unboxing-combo/step15-15.png)

### 6. 将黑色数据线卡入集线器中。

集线器的位置应该靠近工具头这一侧，但不要太低。在热端与热床接触后，将集线器的边缘横梁的下沿对齐是集线器的最优位置。在这个位置，Type-C 与 Z 轴立柱卡住的可能性最低，避免立柱干扰 Type-C 连接。

> 未安装集线器可能导致线缆与热床剐蹭。

|  |  |
| --- | --- |
|  |  |

放置打印机时，请在 Y 方向上留出足够热床移动的安全空间（图示）。有关打印机预留空间的更多信息，详情请参阅：[A1 常见问答 热床预留空间](faq.md)。

|  |  |
| --- | --- |
|  |  |

> **注意**  
> PTFE 管使用时间过长，会因老化而自然弯曲。此时，AMS lite 连接的料管弯折角度过大，很可能导致进料失败。
>
> ![](https://wiki.bambulab.com/a1/自然弯曲.jpg)
>
> 您可以采取以下步骤使 AMS lite 连接的料管立起来：  
> **步骤 1 ：调整硅胶集线器到 AMS lite 之间的料管的长度**
>
> 1. 从 AMS lite 的 4 个接口中释放 PTFE 管。
>
> ![](https://wiki.bambulab.com/a1/释放_ptfe_管.gif)
>
> 2. 调整料管长度，使 4 根料管末端到硅胶集线器距离大致相同。
>
> ![](https://wiki.bambulab.com/a1/调整料管长度.gif)
> 如图，料管末端到硅胶集线器之间的长度约为 15cm。
> ![](https://wiki.bambulab.com/a1/料管长度相同.jpg)
>
> 3. 将 2 根较短特氟龙管插入 AMS lite 接口 1 和 2 中；将 2 根较长特氟龙管插入 AMS lite 接口 3 和 4 中。
>
> ![](https://wiki.bambulab.com/a1/插回料管.gif)
>
> 此时，AMS lite 连接的料管建构成类似三棱锥的立体空间，料管也立起来了。
>
> **步骤 2 ：调整料管角度**
>
> 有些料管老化严重，即使按照第一步操作后，料管也无法很好地立住，这时可以调整料管角度。
>
> 1. 从 AMS lite 的接口中释放严重弯曲的 PTFE 管。
> 2. 逆着 PTFE 管的弯曲方向将其重新插回接口。
>
> ![](https://wiki.bambulab.com/a1/调整料管角度.gif)

## 附录：安装外挂料盘和初次打印

![](https://wiki.bambulab.com/a1/manual/unboxing-combo/ap1.png)

如果您想使用外挂的料盘，可以参考下图的方式，安装料盘支架、料盘 PTFE 管和料盘。

如果您只使用 AMS lite 进行打印，您可以选择是否安装料盘支架。

### 1. 组装料盘支架

将料架支撑轴旋入料架主体

|  |  |
| --- | --- |
|  |  |

### 2. 将料盘支架卡在龙门架的横梁上，带有 Bambu Lab LOGO 的一面朝前

推荐将支架装在横梁中间偏右，可以贴着右侧横梁。

![](https://wiki.bambulab.com/a1/manual/unboxing-combo/ap4-v.png)

### 3. 使用最短的铁氟龙管连接任意一个工具头上的进料口，耗材将通过该铁氟龙管进料

|  |  |
| --- | --- |
|  |  |

### 4. 安装集线器

将黑色线缆卡进集线器的小孔中，将特氟龙管卡入其他任意一个个大孔中。在热端与热床接触后，将集线器的边缘横梁的下沿对齐是集线器的最优位置。这是因为在这个位置，Type-C 与 Z 轴立柱卡住的可能性最低，从而避免干扰 Type-C 连接。

|  |  |
| --- | --- |
|  |  |

将耗材料卷挂在料盘支架上，然后将耗材送入铁氟龙管。

![](https://wiki.bambulab.com/a1/manual/unboxing-combo/ap10-v.png)

### 5. 放置废料盒

开始打印前，推荐准备一个盒子放置于**打印机侧面的吐料组件下方**，用于收集打印过程产生的废料，保持环境整洁。

您可以打印一个 [废料盒](https://makerworld.com.cn/zh/search/models?keyword=A1+%E5%BA%9F%E6%96%99%E7%9B%92)，也可以使用耗材包装盒或其他容器来接废料。

![a1_purge_container_example.png](https://wiki.bambulab.com/a1/manual/unboxing-combo/a1_purge_container_example.png)

由于篇幅有限，首次打印的教程请移步 [A1 初次打印指南（使用AMS lite）](first-print-with-ams-lite.md)。
