## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

**建议您使用原包装进行打包以确保运输安全。若您因退货需求需重新打包但原包装已丢失，请联系我们的售后团队为您补发专用的纸箱及缓冲泡沫等防护材料。**

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### 步骤一：断开 AMS lite

1. **断开 4-pin 连接线：** 在打印机背面，按紧线缆接口底端，断开 AMS lite 的 4-pin 连接线，然后用黑色细线将 4 pin 线卷起。

|  |  |
| --- | --- |
|  |  |

2. **断开铁氟龙料管：**

- 按压工具头入料口接口（推荐使用镊子），拔出四根料管。

|  |  |
| --- | --- |
|  |  |

- 按压料盘支架上的料管接口，拆除料管。

|  |  |
| --- | --- |
|  |  |

### 步骤二：移除回转轴

握住卡爪，拔出图示的两个 AMS lite 回转轴。

|  |  |
| --- | --- |
|  |  |

### 步骤三：拆卸 AMS lite 支架

1. 移除连接 AMS lite 主体和支架的四颗螺丝；

|  |  |
| --- | --- |
|  |  |

2. 将 AMS lite 主体从支架上拆下；
3. 用三条扎带将 AMS lite 主体在图示绿色高亮位置固定。

|  |  |
| --- | --- |
|  |  |

### 步骤四：固定铁氟龙料管与回转轴

将铁氟龙料管、回转轴、螺丝包、说明书等物品放入顶部纸壳。

|  |  |
| --- | --- |
|  |  |

### 步骤五：固定 AMS lite

1. 先将 **AMS lite 装入包装袋**，然后**放入纸箱**内，注意对齐卡槽。
2. 将**支架放入包装袋**，再按照图示位置放入 AMS lite 的包装袋中。
3. 将**内六角扳手**放在任一卡槽内。
