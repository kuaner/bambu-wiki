## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### 关闭电源，并卷起线缆

步骤 1. 关闭打印机电源，切断电源线。

|  |  |
| --- | --- |
| 1.jpg | 3.jpg |

步骤 2. 按紧线缆接口底端，断开 AMS lite 的 4 pin 线。

|  |  |
| --- | --- |
| 4_pin.jpg | 3.jpg |

步骤 3. 安装好电源插头保护套，卷起电源线并用皮筋固定。

|  |  |
| --- | --- |
| 4.png |  |

### 拆除料管

步骤 1. 按压工具头入料口接口（推荐使用镊子），拔出四根料管。

|  |  |
| --- | --- |
|  | 6.1.jpg |

步骤 2. 按压料盘支架上的料管接口，拆除料管。

|  |  |
| --- | --- |
|  | 7.1.jpg |

### 拆除 AMS lite

步骤 1. 握住卡爪，拔出 AMS lite 回转轴，并将回转轴放回泡沫盒中。

|  |  |
| --- | --- |
| 8.jpg |  |

步骤 2. 拆除连接 AMS lite 主体和支架的四颗螺丝，用绑带收好线束。

|  |  |
| --- | --- |
| 9.jpg |  |

步骤 3. 拆下 AMS lite主体，并将 AMS lite 主体放回泡沫盒。

|  |  |  |
| --- | --- | --- |
| 11.jpg |  |  |

步骤 4. 将装有回转轴的泡沫盒装在有 AMS lite 主体的泡沫盒，并将 AMS lite 主体用扎带固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 固定 Z 轴、工具头和 X 轴

步骤 1. 将工具头移到最左侧，拧开螺丝并取下吐料组件，用纸板抵住工具头，用扎带固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 2. 装回 X 轴纸板，并用扎带固定纸板和线缆。

|  |  |
| --- | --- |
|  |  |

步骤 3. 安装 Z 轴限制器，**对准 Z 轴限制器螺丝位置**，并拧紧四颗螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 取下理线盒，拆下龙门架

步骤 1. 将打印机平放。

> **注意**：打印机龙门架需要垫高以免损伤工具头。

![](https://wiki.bambulab.com/a1-combo-packing/new/30.jpg)

步骤 2. 拧松理线盒预装固定螺丝，并拔掉 3 个连接器。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 3. 往下推动理线器，将 Type-C 线缆从接口拔出，并卸载理线盒。

|  |  |
| --- | --- |
|  |  |

步骤 4. 平放打印机，移除打印板，将热床推至打印机前端，取下热床下方 Y 轴滑轨盖板。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 5. 拧下绿色标记位置的全部螺丝后，将热床推至打印机后方，继续拧下剩余 4 颗绿色标记螺丝。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 6. 重新安装 Y 轴滑轨盖板，抬起打印机底座并微微倾斜，将底座与龙门架分开取出。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 7. 掰开黄色线缆卡线槽，取出黄色线缆，并将理线盒用胶带固定至龙门架上。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 固定热床

步骤 1. 放置热床防护泡沫，并用扎带固定，剪掉多余扎带。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 2. 将底座放回泡沫盒中。

|  |  |
| --- | --- |
|  |  |

步骤 3. 放回打印板及吐料组件，并用胶带固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 装箱操作

步骤 1. 将防水袋在地上摊开铺好后，将配件及上述卸下的螺丝收到塑料袋中，放至底部。

![](https://wiki.bambulab.com/a1-combo-packing/new/52.jpg)

步骤 2. 放置打印机底座，将电源线放入侧面泡沫槽中。

|  |  |
| --- | --- |
|  |  |

步骤 3. 放置打印机龙门架。

![](https://wiki.bambulab.com/a1-combo-packing/new/55.jpg)

步骤 4. 放置左右两块纸板，其中一块固定有料盘支架。

|  |  |
| --- | --- |
|  |  |

步骤 5. 放置 AMS lite，并调整好部件位置，最后倒置放入 AMS lite 底座，并盖上贴有打印板的纸板。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 6. 收起防水袋，并提起放入包装纸箱中，贴上胶带即可。
