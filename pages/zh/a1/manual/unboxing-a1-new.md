建议您在打印机开箱前浏览完整视频，确保顺畅的开箱体验。新版和旧版两种的包装方式随机发货，请以实际收到的产品为准。旧包装开箱指南请参考[此页面](unboxing-a1-combo.md)。

保护膜、保护泡沫和保护纸板可能与开箱视频所展示的机器有所不同。例如，新出货的A1已移除了工具头周围的纸板，请以您实际收到的机器为准。

A1上市以来，不少用户反馈热床保护贴膜过粘不易撕取，另外还有部分用户忘记撕膜导致打印问题，经过反复验证，在2023年底迭代取消热床保护贴膜。

> **A1 系列打印机已不再赠送色卡。**  
> ![色卡.png](https://wiki.bambulab.com/a1/manual/unbox-new-package/%E8%89%B2%E5%8D%A1.png)

## 检查包装中的物品

**单机版本**：A1 打印机、料盘支架、PTFE 管（用于外挂料盘，1 根）、PEI 纹理板、耗材样品、通针、内六角扳手（H2 和 H1.5）、料管集线器、热床刮刀刀片及其螺丝（BT2.6-8 螺丝，用于刮刀）、工具头切刀刀片、润滑油、润滑脂、快速指南、保修条款、免责声明和安全指引、32 GB MicroSD 卡（打印机内）。

**Combo 版本**：A1 打印机、AMS lite 主体（包括 4-pin 线）、AMS lite 底座支架和安装螺丝（BT3-8 螺丝，用于 AMS 支架）、AMS lite 料盘卷轴、料盘支架、PTFE 管（用于 AMS lite，2 长 2 短共 4 根）、PTFE 管(用于外挂料盘，1 根）、PEI 纹理板、耗材样品、通针、内六角扳手（H2 和 H1.5）、32 GB MicroSD 卡（打印机内）、料管集线器、热床刮刀刀片及其螺丝（BT2.6-8 螺丝，用于刮刀）、工具头切刀刀片、润滑油、润滑脂、快速指南、保修条款、免责声明和安全指引。

## 安装 AMS lite

此步骤适用于 combo 版本。

### 步骤 1. 剪下扎带。

![](https://wiki.bambulab.com/a1/manual/unbox-new-package/a1_unbox_(32).png)

### 步骤 2. 将主体放在其支架上，主体有线缆的一端朝向支架的斜上方。

![](https://wiki.bambulab.com/a1/manual/unbox-new-package/a1_unbox_(33).png)

### 步骤 3. 使用配件盒中的 4 颗 BT3-8 螺丝（用于 AMS 底座支架）连接主体和支架。

|  |  |
| --- | --- |
|  |  |

### 步骤 4. 滑入料盘转轴，并推到底部。

安装时，请确保料盘转轴及料盘轴颜色一一对应(如图所示，黄色对黄色，绿色对绿色)，以防损坏部件。

![](https://wiki.bambulab.com/a1/manual/unbox-new-package/a1_unbox_(36).png)

黄色转轴是六边形的形状，相对容易对准卡扣位置。绿色转轴是长方形的形状，所以建议在插入之前先大致对准孔位，然后平行移动，稍作微调以确保对准卡扣位置。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 5. 将 AMS lite 放在打印机右侧，推荐距离为 50mm。

![](https://wiki.bambulab.com/a1/manual/unbox-new-package/a1_unbox_(40).png)

### 步骤 6. 将 2 根较短 PTFE 管插入 AMS lite 接口 1 和 2 中; 将 2 根较长 PTFE 管插入 AMS lite 接口 3 和 4 中。

|  |  |
| --- | --- |
|  |  |

### 步骤 7. 将 4 根 PTFE 管的另一端都插入至工具头的进料口。

![](https://wiki.bambulab.com/a1/manual/unbox-new-package/a1_unbox_(43).png)

### 步骤 8. 将黑色数据线卡入集线器的小孔中。

![organizer-small-hole-cn.png](https://wiki.bambulab.com/a1/manual/unbox-new-package/organizer-small-hole-cn.png)

![](https://wiki.bambulab.com/a1/manual/unbox-new-package/a1_unbox_(44).png)

![](https://wiki.bambulab.com/a1/manual/unbox-new-package/a1_unbox_(45).png)

## 放置打印板

利用卡位，确保打印板对准热床边缘。

|  |  |
| --- | --- |
|  |  |
|  |

## 打开摄像头遮盖并撕掉屏幕保护膜

将摄像头的遮盖旋至 LED 灯的位置。  
有些打印机出厂时会有 2 层保护膜（第 1 层带有手撕位），而有些只有 1 层膜（如果没有看到手撕位，就说明只有 1 层膜）。这两种情况都会同时发货，以用户实际收到的为准。

|  |  |
| --- | --- |
|  |  |

## 连接电源并开机

将 AMS lite 的 4pin 线插入打印机后方的任意一个接口。请确保正确插入 4 针电缆，将其对准保护卡的方向。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 根据屏幕提示，完成初始化和校准

确保热床上面安装了打印板，在打印机开机后，请按照屏幕上的提示完成打印机的初始化和校准。如果跳过了联网和 Bambu Handy 绑定步骤，也可以在打印机完成校准后，在设置页面联网绑定打印机。

![](https://wiki.bambulab.com/a1/manual/unbox-new-package/a1_unbox_(55).png)

## 放置废料盒

开始打印前，推荐准备一个盒子放置于**打印机侧面的吐料组件下方**，用于收集打印过程产生的废料，保持环境整洁。

您可以打印一个 [废料盒](https://makerworld.com.cn/zh/search/models?keyword=A1+%E5%BA%9F%E6%96%99%E7%9B%92)，也可以使用耗材包装盒或其他容器来接废料。

![a1_purge_container_example.png](https://wiki.bambulab.com/a1/manual/unboxing-combo/a1_purge_container_example.png)
