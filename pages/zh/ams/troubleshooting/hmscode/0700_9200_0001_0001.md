## 故障描述

AMS 2 Pro/AMS HT 的干燥组件由加热单元、散热风扇和 NTC 温度传感器组成。当散热风扇转动受阻，将影响烘干效果。

### 风扇受阻可能的原因：

- 加热器散热风扇中有异物
- 加热器散热风扇连接器松动
- 加热器散热风扇坏了

## 所需工具、设备及材料

- H1.5 六角扳手
- H2.0 六角扳手
- 小毛刷

## 故障排除

*注：用户可视情况调整各排故措施的顺序。*

### 步骤1-AMS 2 Pro/AMS-HT 拆卸，暴露散热风扇。

请参考以下链接进行烘干组件的拆卸：

- AMS 2 Pro：[更换 AMS 2 pro 烘干组件](../../../ams-2-pro/maintenance/replace-heating-unit.md)
- AMS-HT：[AMS HT 烘干组件更换指南](../../../ams-ht/maintenance/heating-unit.md)

### 步骤2-检查风扇中异物，并使用毛刷清洁。

|  |  |
| --- | --- |
| 66.png | 55.png |
| 干净的 AMS 2 Pro 散热风扇 | 干净的 AMS-HT 散热风扇 |

### 步骤3-检查风扇连接线是否松动，可重新拔插

|  |  |
| --- | --- |
| 3.png | 4.png |
| AMS 2 Pro 三个接线端 | AMS-HT 第5号接线端 |

### 步骤4-组装设备，重试烘干

### 步骤5-若问题依旧，请更换烘干组件
