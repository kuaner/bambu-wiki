# AMS 线材包

当您收到线包的时候，您不需要更换全部的线缆，只需更换损坏的线缆，其他的线缆留作备用即可。

## AMS 线材包（五合一）

**五合一线材包中包含5根连接线，分别是：**

1. RFID板连接线 \*1

2. 测速板连接线\*1

3. 选料板连接线\*1

4. 电源连接线\*1

5. 485总线\*1

|  |  |
| --- | --- |
|  |  |

## AMS 线材包（六合一）

**六合一线材包里面包含6种连接线，分别是：**

1. RFID板连接线 \*1

2. 测速板连接线\*1

3. 选料板连接线\*1

4. 电源连接线\*1

5. 485总线\*1

6. 上下料组件连接线\*2

|  |  |
| --- | --- |
|  |  |

## 何时更换

线材在维修过程中损坏或使用过程中烧坏时，需要进行线材的更换。

## 所需工具和材料

- AMS 线材包
- H2.0 内六角扳手
- 镊子

螺丝清单

|  |  |  |  |
| --- | --- | --- | --- |
|  | 型号 | 位置 | 规格 |
| 螺丝A | BT3\*8 | AMS 主框架 |  |
| 螺丝B | BTG2\*8 | AMS 五通组件 |  |

# 安全提示

> **重要提醒 ！**
>
> 在对AMS及其电子设备进行任何维护工作之前，请断开AMS与打印机的连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。

# 拆装AMS 主框架组件

## 步骤 1 - 拆除料管

|  |  |
| --- | --- |
| 打开AMS上盖 | 按压AMS 五通按钮，解锁接头，然后从AMS背面拉出PTFE管 |

## 步骤2 - 松出AMS主框架组件

移除固定AMS主框架上2颗螺丝A。

![](https://wiki.bambulab.com/ams/ams-cables/2_screws.jpg)

|  |  |
| --- | --- |
| 按压五通组件上的按钮来将主框架后部完全提起来 | 将主框架组件竖立放置在AMS底盖上，注意有电缆连接 |

## 步骤3 - 移除AMS主框架组件

|  |  |
| --- | --- |
| 将485连接线和电源连接线从AMS电源板上断开 | 取出AMS主框架组件 |

## 步骤4 - 连接电源线和485总线

|  |  |
| --- | --- |
| 将AMS主框架组件放入到AMS底盖上 | 将485总线和电源线连接到AMS电源板对应接口上 |

## 步骤5 - 安装AMS主框架组件

|  |  |
| --- | --- |
| 按压五通接头按钮，将AMS主框架安装到位 | 锁入2颗螺丝A固定AMS主框架组件 |

## 步骤6 - 连接PTFE管

|  |  |
| --- | --- |
| 检查确认PTFE管硅胶支架与五通组件的料孔对齐 | 从AMS后部推入PTFE管，装完后，拉动PTFE管，确认PTFE管已固定 |

RFID 连接线

|  |  |
| --- | --- |

## **第 2 步 - 连接RFID连接线**

|  |  |
| --- | --- |

# 更换电源线和485总线

![](https://wiki.bambulab.com/ams/ams-cables/485_and_power_cable.jpg)

2PIN的是电源线，5PIN的是485总线

## **第 1 步 - 断开连接**

|  |  |
| --- | --- |
| 在主板上找到两条连接线的接口，依次断开连接 | 将扳手穿过磁环的固定支架，用力撬起磁环 |

## **第 2 步 - 移除连接线**

|  |  |
| --- | --- |
| 解锁磁环的两个扣子 | 松开磁环，取出连接线 |

## **第 3 步 - 连接电缆**

将电源连接线和486总线依次连接到AMS主板对应接口上。

![](https://wiki.bambulab.com/ams/ams-cables/connect_2_cables.jpg)

## **第 4 步 - 安装磁环**

|  |  |
| --- | --- |
| 将电源线和485总线装入磁环，然后将安装到支架位置 | 如有点胶条件，可以对磁环进行点胶加固，没有也可忽略 |

# 更换选料板连接线和测速板连接线

![](https://wiki.bambulab.com/ams/ams-cables/hall_and_speed_cable.jpg)

外面的是测速板连接线，带HALL字样的是选料板连接线

## **第 1 步 - 断开主板连接**

|  |  |
| --- | --- |
| 依次按压料管接头，将五通上的4根料管断开 | 断开测速板连接线和选料板连接线与主板的连接，并从2个卡扣中松出 |

## **第 2 步 - 取下五通组件**

|  |  |
| --- | --- |
| 用H2.0内六角扳手移除4颗螺丝B | 将五通组件从主框架上松出来 |

## **第 3 步 - 移除电缆**

用镊子去除连接器上的部分白胶，然后依次断开2根电缆，移除选料板连接线和测速板连接线。

![](https://wiki.bambulab.com/ams/ams-cables/hall_and_speed_connectors.jpg)

## **第 4 步 - 连接五通组件**

|  |  |
| --- | --- |
| 依次将选料板连接线和测速板连接线接到五通组件上 | 在两个连接器处点上白胶进行加固 |

## **第 5 步 - 安装五通组件**

|  |  |
| --- | --- |
| 将五通组件安装到主框架上，确认每个胶套都安装到位 | 用H2.0内六角扳手锁入4颗螺丝B，固定五通组件 |

## **第 6 步 - 连接主板，安装料管**

|  |  |
| --- | --- |
| 将选料板连接线和测速板连接线接到主板，整理好连接线 | 依次连接4根料管 |

# 更换上下料组件连接线

本章节适用于**六合一线材包**。

## 第 1 步 - 拆卸上下料组件

请参考 [更换AMS上下料组件](../x1/maintenance/replace-first-stage-feeder.md)  的步骤1~7的内容将需要处理的AMS上下料组件拆下并移除料管。

![](https://wiki.bambulab.com/x1/maintenance/replace-feed-funnel-assay/the_first_stage_feeder.jpg)

## **第 2 步 -** 移除螺丝

用H1.5内六角扳手移除4颗螺丝。

|  |  |
| --- | --- |
|  |  |

## **第 3 步 - 更换连接线**

将上盖从底座上分离开来，断开上下料电路板处的旧连接线，并将新线插入。

|  |  |
| --- | --- |
|  |  |

再从电机处的接口断开连接线，并将新线插入。  
![image26.png](https://wiki.bambulab.com/x1/troubleshooting/ams-feeder-fault/image26.png)

## **第 4 步 - 组合上盖和底座**

调整好齿轮组件的位置，将上盖和底座接合起来，在接合的过程中，用镊子调整弹簧位置并将另一端安装到底座凸柱上。

|  |  |
| --- | --- |
|  |  |

![](https://wiki.bambulab.com/ams/maintenance/20250307-092455.webp))

### **第 5 步 - 检查齿轮组位置**

接合到位后，检查齿轮组的位置，如果位置不对，请调整齿轮位置后重新安装。

|  |  |
| --- | --- |
|  |  |

### **第 6 步 - 锁附螺丝**

依次锁入4颗螺丝固定，锁到位即可，不可大力拧紧，防止滑牙。

|  |  |
| --- | --- |
|  |  |

### **第 7 步 - 安装上下料组件到AMS**

请参考 [更换AMS上下料组件](../x1/maintenance/replace-first-stage-feeder.md)  的步骤8~14的内容将料管接好，将上下料器安装到AMS上，并组装好AMS。

# 功能确认

1. 将AMS与打印连接，启动打印机，给AMS供电，AMS上下料处的指示灯亮起，说明供电正常；

![](https://wiki.bambulab.com/ams/ams-cables/ams_on.jpg)

2. 装载带有拓竹RFID芯片的耗材，确认AMS能正常识别耗材，点击进料，加载耗材，确认AMS能正常将耗材送进到挤出机。

![](https://wiki.bambulab.com/ams/ams-cables/loading.jpg)

如果确认结果有异常，请返回检查步骤和连接后重试。如果问题仍然存在，请联系Bambu Lab服务团队寻求进一步帮助。
