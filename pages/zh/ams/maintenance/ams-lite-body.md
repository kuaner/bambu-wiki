# 拆装视频

# AMS lite 主体拆解

## 步骤1：移除右侧盖

从AMS Lite主板上断开2根线圈的连接，用H2.0 内六角扳手移除6颗螺丝A；

|  |  |  |
| --- | --- | --- |
|  |  |  |

解除卡扣锁定，将左右侧盖分开，移除右侧盖。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 步骤2：移除AMS lite主板

从AMS Lite 主板上断开另外2根线圈的连接，用H2.0 内六角扳手移除3颗螺丝B，取下AMS Lite主板；

|  |  |
| --- | --- |
|  |  |

将AMS Lite 4pin数据线从AMS Lite 主板上断开。

|  |  |
| --- | --- |
|  |  |

## 步骤3：移除料盘轴

在其中一根料盘轴和壳体上进行标记（便于后面安装时确认），用H2.0 内六角扳手移除2颗螺丝C，然后取下2根料盘轴。

|  |  |  |
| --- | --- | --- |
|  |  |  |

# AMS lite 主体组装

## 步骤1：安装料盘轴

参考在拆除料盘轴时的标记，将料盘轴和壳体按原对应的位置进行安装，依次锁入2颗螺丝C将2根料盘轴固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 步骤2：安装AMS lite主板

将AMS Lite 4pin数据线连接到主板接口上，请注意安装方向要正确；将AMS Lite主板安装到壳体上，锁入3颗螺丝B，然后连接2根线圈连接线。

|  |  |  |
| --- | --- | --- |
|  |  |  |

|  |  |
| --- | --- |
|  |  |

## 步骤3：安装右侧盖

将右侧盖与左侧盖组合到一起，注意检查AMS Lite 4pin数据线的位置，确认正常后，将左右侧盖扣合好。

|  |  |
| --- | --- |
|  |  |

锁入6颗螺丝A，然后连接另外2根线圈连接线。

|  |  |  |
| --- | --- | --- |
|  |  |  |

# 功能确认

检查确认4根据RFID线都已连接上，左右侧盖接合无异常。
