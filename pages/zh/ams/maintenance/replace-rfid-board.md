## RFID 板

RFID 板是 RFID 识别功能的核心电路板，内部包含一组 RFID 识别线圈，用于识别拓竹料盘上的 RFID 标签，获取线材类型、颜色、生产序列号等信息。每一个 RFID 板用以识别 2 个槽位的耗材。  
![rfid_board.png](https://wiki.bambulab.com/ams/maintenance/replace-rfid-board/rfid_board.png)

## 适用机型

AMS

## 何时更换

RFID 板损坏或线缆断连。

## 所需要的工具和材料

- 镊子
- UV 胶/热熔胶
- H 2.0 内六角扳手

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除旧的 RFID 板

### 步骤 1. 拆下 PTFE 管

打开 AMS 上盖， 按压 AMS 五通按钮，解锁接头，然后从 AMS 背面拉出 PTFE 管。

|  |  |
| --- | --- |
|  |  |

### 步骤 2. 取出 AMS 主框架

移除固定 AMS 主框架上2颗螺丝。按压五通组件上的按钮缓慢地将主框架后部完全提起来，将主框架组件竖立放置在 AMS 下盖上，注意有电缆连接。

|  |  |
| --- | --- |
|  |  |

将485连接线和电源连接线从 AMS 电源板上断开，取出 AMS 主框架组件。

|  |  |
| --- | --- |
|  |  |

### 步骤 3. 取出 RFID 板

拔下两块 RFID 板上的线缆。

|  |  |
| --- | --- |
|  |  |

用镊子分别去除两块 RFID 板边上的UV胶。

|  |  |
| --- | --- |
|  |  |

取出两块 RFID 板。

|  |  |
| --- | --- |
|  |  |

## 安装新的 RFID 板

### 步骤 1. 安装 RFID 板

将两块 RFID 板安装到安装槽内，确认安装到位。然后在原先用胶水的位置，再次用热熔胶或 UV 胶将 RFID 板固定。

|  |  |
| --- | --- |
|  |  |

### 步骤 2. 安装 AMS 主框架

等待胶水凝固后，将 AMS 主框架组件竖直放入 AMS 外壳，然后将总线电缆和电源电缆连接到 AMS 电源板上。

|  |  |
| --- | --- |
|  |  |

连接好后，再将主框架组件平放在 AMS 下盖中。随后，安装 AMS 主框架上的2颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 3. 插入 PTFE 管

检查确认 PTFE 管硅胶支架与五通组件的料孔对齐，并从 AMS 后部推入 PTFE 管。装完后，拉动 PTFE 管，确认 PTFE 管已固定。

|  |  |
| --- | --- |
|  |  |

## 功能验证

连接电源线，将 AMS 连接到打印机，打开电源，放入耗材，通过打印机显示屏观察 AMS 能否正常读取 RFID 耗材信息，若可以正常读取并且没有出现错误提示，则更换成功。

否则，请检查所有连接，然后重试。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
