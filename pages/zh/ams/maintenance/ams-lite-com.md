## 拆解指引

### **步骤 1 - 移除4个回转轴**

断开AMS lite与打印机的连接，用手扶住AMS lite, 依次用力将4个回转轴拔下来。

|  |  |
| --- | --- |
|  |  |

### **第 2 步 - 移除上下料模块**

移除下图中的4颗螺丝A并将整个上下料模块从AMS lite上取下，然后断开黑红连接线、蓝白连接线，移除上下料模块。

|  |  |
| --- | --- |
|  |  |

### **第 3 步 - 移除上下料组件**

移除左图中的2颗螺丝B，取下上下料组件(1/2)；

|  |  |
| --- | --- |
|  |  |

移除图中的2颗螺丝B，取下上下料组件(3/4)。

|  |  |
| --- | --- |
|  |  |

### **第4 步 - 移除底座支架**

移除4颗螺丝A（左右侧各2颗)， 移除底座支架。

## 组装指引

### **第 1 步 - 安装底座支架**

将AMS外壳组件放置到底座支架上（电源线朝上），轻压AMS lite主体使螺丝孔完全露出。确认安装方向无误后，依次锁入左右两侧的2颗螺丝A固定底座支架。

|  |  |
| --- | --- |
|  |  |

### **第 2 步 - 安装上下料组件**

将蓝白连接线穿过连杆,锁入2颗螺丝B固定上下料组件(3/4)；

|  |  |
| --- | --- |
|  |  |

将黑红连接线穿过连杆,锁入2颗螺丝B固定上下料组件(1/2) 。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### **第 3 步 - 安装上下料模块**

将上下料模块安装到主体上并锁入4颗螺丝A。 通过连接线颜色的区分连接位置，连接好2根连接线;

|  |  |  |
| --- | --- | --- |
|  |  |  |

### **第 4 步 - 安装回转轴**

根据颜色进行配对安装，安装前需大致对齐安装方向，依次将4个回转轴安装到料盘轴上。

|  |  |  |
| --- | --- | --- |
|  |  |  |

## 功能确认

1. 将AMS Lite连接到打印机，开启打印机电源，确认AMS lite上下料上的指示灯能正常点亮；

2. 装载打印材料，操作进退料，确认进退料功能正常。

如测试失败，请再次检查所有连接并重试。如果仍然不行，请联系 Bambu Lab 服务团队。
