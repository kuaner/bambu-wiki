## 作用

密封套件用于保证 AMS 内部干燥，降低耗材、干燥剂受潮的速度。**密封套件包括密封胶条、上盖卡扣和五通硅胶**，根据实际情况选择更换的部分。

![sealing-kit.jpg](https://wiki.bambulab.com/ams/maintenance/replace-sealing-kit/sealing-kit.jpg)

## 何时更换

- 即使放了有效的干燥剂，AMS 内部湿度依然过高。
- 使用时间过长，密封套件老化失效。
- 密封套件存在明显的损坏，导致失效。
- 技术支持建议更换。

## 所需工具和材料

- AMS 密封套件
- 铲刀

## 开始操作前的安全警告

在开始操作之前，请确认打印机已关闭、AMS 已经从打印机上卸下。

## 操作指南

### 更换密封胶条

#### 步骤 1：移除旧的密封胶条。

从一侧角落拉起密封胶条，沿着边缘将旧密封胶条移除。

|  |  |
| --- | --- |
|  |  |

#### 步骤 2：安装新的密封胶条。

撕下新密封胶条的靠近四个角落位置的背胶，优先安装四个角落位置。对齐四个角落后，撕下剩余的背胶，将胶条全部压入槽位中。

装好后按压几次有背胶的区域，确保安装到位。

> 安装过程中，请勿过度拉拽密封胶条。否则会使得胶条被拉长，导致密封不佳。

|  |  |
| --- | --- |
|  |  |

#### 步骤 3：检查密封胶条是否安装到位。

安装完成后，开合几次上盖，检查密封胶条是否安装到位。

### 更换上盖卡扣

#### 步骤 1：移除旧卡扣。

将上盖卡扣旋转到锁止位置，使用铲刀向上将其撬出。重复此步骤移除另一侧的卡扣。

> 使用铲刀操作时请注意安全，避免过度用力导致受伤。

![](https://wiki.bambulab.com/ams/maintenance/replace-sealing-kit/replace-sealing-kit_5.png)

#### 步骤 2：安装新的卡扣。

向内 45 度角将卡扣放入安装孔，然后向下按压，直到卡入到位。

> 请确保卡扣处在正确的角度，再将其按压。

![](https://wiki.bambulab.com/ams/maintenance/replace-sealing-kit/replace-sealing-kit_6.png)

### 更换五通硅胶

#### 步骤 1：移除 PTFE 料管。

打开 AMS 上盖，按压五通组件的按钮（解锁快速接头），同时从 AMS 背面拉出 PTFE 料管。

|  |  |
| --- | --- |
|  |  |

#### 步骤 2：移除旧五通硅胶。

撕开旧五通硅胶并将其移除。

![](https://wiki.bambulab.com/ams/maintenance/replace-sealing-kit/replace-sealing-kit_9.png)

#### 步骤 3：安装新的五通硅胶。

撕下新的五通硅胶的背胶，旋转至料管的出口方向朝上，装入原位置。多次按压背胶区域，确保粘黏牢固。

![](https://wiki.bambulab.com/ams/maintenance/replace-sealing-kit/replace-sealing-kit_10.png)
