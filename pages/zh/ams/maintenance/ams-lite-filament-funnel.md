## AMS lite 入料口组件

本指引提供更换 AMS lite 入料口组件的相关指导和注意事项，旨在拆卸入料口组件以检查齿轮的转动是否顺畅。

因两边的入料口组件在结构上是类似的，本文只对 AMS lite 入料口组件（3）进行更换，并说明一些注意事项。

## 何时使用？

1. 上下料器的霍尔传感器无法正确检测到耗材，例如插入耗材后指示灯没有反应，需要更换入料口组件；
2. 上下料器进料困难，怀疑是齿轮转动不畅，需要拆下入料口组件检查。

## 所需工具

- H1.5 /H2.0 内六角扳手
- 料盘

## 前期操作

如有需要，请参考 [AMS lite 整机拆装指引](ams-lite-com.md) 的内容了解如何将上下料组件从 AMS lite 上拆除和安装。

## 安全提示

> **重要提醒 ！**
>
> 在对 AMS lite 及其电子设备进行任何维护工作之前，请断开 AMS lite 与打印机的连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。

## 拆卸指引

### 步骤 1：移除上盖

使用扳手从上盖的缺口位置小心撬开上盖，并取下。

|  |  |
| --- | --- |
|  |  |

### 步骤 2：拆下入料口组件

用 H1.5 内六角扳手拧下 3 颗螺丝，断开 1 根排线连接，并断开电缆，取下入料口组件。

|  |  |
| --- | --- |
|  |  |
|  |  |

**以下步骤用于检查齿轮轴承：**

### 步骤 3：移除插销

1. 用扳手顶住漏斗一侧，用力将另一侧插销顶出。

> 注意：可在料盘上进行此操作。

|  |  |
| --- | --- |
|  |  |

2. 用扳手顶住齿轮一侧，用力将插销顶出。

|  |  |
| --- | --- |
|  |  |

### 步骤 4：移除漏斗和齿轮

![](https://wiki.bambulab.com/ams/ams-lite/ams-feeder-unit/%E6%8B%86%E5%8D%B8%E5%AE%8C%E6%88%90.jpg)

### 步骤 5：检查漏斗上的齿轮

拆卸耗材检测传感器的 2 颗螺丝，检查齿轮是否转动顺畅。如果不顺畅，请联系售后服务团队。

|  |  |
| --- | --- |
|  |  |

> 注意：请勿弄丢电路板下方的耗材传感器磁铁和弹簧。

## 安装指引

### 步骤 1：安装检测传感器

使用 H1.5 内六角扳手安装耗材检测传感器的 2 颗螺丝。

![](https://wiki.bambulab.com/ams/ams-lite/ams-feeder-unit/install-.jpg)

### 步骤 2：安装漏斗

将漏斗对准卡扣放置，从另一侧的卡扣中安装插销；用手握住滚花一侧，将**没有滚花的一侧先插入**，然后按紧插销。

|  |  |  |
| --- | --- | --- |
|  |  |  |

### 步骤 3：安装齿轮

将齿轮对准卡扣放置，可从两侧卡扣缝隙中检查是否放置到位。用手握住插销的滚花一侧，从卡扣中安装插销，确保**没有滚花的一侧先插入**。

|  |  |
| --- | --- |
|  |  |
|  |  |

### 步骤 4：安装入料口组件

1. 连接电缆；如图所示调节摇摆齿轮组的位置，外侧的齿轮向左侧打到底，内侧的齿轮立起来。

|  |  |
| --- | --- |
|  |  |

2. 安装入料口组件，用内六角扳手将弹簧另一端插入图示孔中，确保弹簧安装到位。

|  |  |  |
| --- | --- | --- |
|  |  |  |

注意外侧摇摆齿轮靠限位块下方。

![](https://wiki.bambulab.com/ams/ams-lite-feeder/feeder_funel_34-_gears3.jpg)

用手推动摇杆，确认动作和顺畅度无异常。
