## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

**建议您使用原包装进行打包以确保运输安全。若您因退货需求需重新打包但原包装已丢失，请联系我们的售后团队为您补发专用的纸箱及缓冲泡沫等防护材料。**

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### 步骤一：断开铁氟龙料管、6-pin 连接线

按住 AMS 内部的料管释放按钮，断开铁氟龙料管。然后，断开 AMS 端的 6-pin 连接线。

|  |  |
| --- | --- |
|  |  |

找到进料管接头，按压蓝色弹簧环，拔出铁氟龙料管。

|  |  |
| --- | --- |
|  |  |

### 步骤二：拆卸供料缓冲器

1. **移除螺丝：**使用 H2.0内六角扳手，移除供料缓冲器上的两颗螺丝，然后将供料缓冲器拆下。

|  |  |
| --- | --- |
|  |  |

2. **拔除线缆：**按紧线缆接口的底端，分别断开 4-pin 连接线和 6-pin 连接线。

|  |  |
| --- | --- |
|  |  |

3. **拔除铁氟龙料管：** 按压黑色垫圈，拔出供料缓冲器上连接着的两根铁氟龙料管。（推荐使用镊子）

|  |  |
| --- | --- |
|  |  |

4. **整理打包：**将铁氟龙料管、气动接头、说明书、备用刀片（如有）、4-pin 连接线、6-pin 连接线、供料缓冲器装入包装袋内。

![2.packing_items.jpg](https://wiki.bambulab.com/ams/packing--guide/2.packing_items.jpg)

### 步骤三：包装料盘

> 💡 如您购买的是打印机+ AMS 套装，请忽略此步。若您购买的是 AMS 单机，请按照此步骤将附赠的四个料盘打包整理，避免运输过程中料盘摩擦出现磨损。

使用海绵纸包装可重复使用料盘（低温可回收料盘\*3+高温可回收料盘\*1）。

|  |  |
| --- | --- |
|  |  |

然后将料盘放入 AMS 内部，盖上 AMS 上盖，锁上卡扣。

|  |  |
| --- | --- |
|  |  |

### 步骤四：安装主体保护泡沫

将 AMS 放入保护袋内，然后安装主体两侧的保护泡沫。

|  |  |
| --- | --- |
|  |  |

### 步骤五：装箱操作

将包装好的 AMS 放入纸箱。然后将 4-pin 线与 6-pin 线放入下图槽1，供料缓冲器放入槽3，说明书及铁氟龙料管等放入槽2。

|  |  |
| --- | --- |
|  |  |

最后，用胶带将纸箱粘牢。  
![5.packing3.jpg](https://wiki.bambulab.com/ams/packing--guide/5.packing3.jpg)
