## 供料缓冲板

供料缓冲板位于 AMS 供料缓冲器内部，其上包含霍尔传感器，可以通过检测缓冲区滑块的位置变化来监控 AMS 的进料状态。

## 何时更换

AMS 供料缓冲器使用过程中，当出现以下情况时，需要对供料缓冲板进行更换：

- AMS 工作不正常，经检查供料缓冲板出现明显元器件损坏
- 打印机使用过程中提示错误信息“料线缓冲信号丢失，电缆或位置传感器可能出现故障”，经过测量电压电阻，确定供料缓冲板故障；相关指南可以参考 [料线缓冲信号丢失，电缆或信号传感器可能出现故障](../x1/troubleshooting/hmscode/0700_4000_0002_0001.md)。
- 经过技术支持的分析确认，需要更换供料缓冲板

## 所需的工具及材料

- H1.5 内六角扳手
- 平头镊子（可选）

> ***重要提醒 ！***
>
> *在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。*

> *在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。*

## 拆解操作步骤

### 第 1 步：拆除缓冲区滑块与弹簧组件

1. 使用 H1.5 内六角扳手 移除缓冲区滑块左端两颗固定螺丝 A，将缓冲区滑块上盖板取下

|  |  |
| --- | --- |
|  |  |

2. 使用 H1.5 内六角扳手从左端将缓冲区滑块与弹簧组件一起翘起取下

|  |  |
| --- | --- |
|  |  |

> ***注意：此步骤可能会导致缓冲区滑块零件脱落，请在组装时按照“安装操作步骤”中的“第 2 步”装回即可，不会造成损坏。***

### 第 2 步：拆除供料缓冲板

使用 H1.5 内六角扳手移除供料缓冲板上 3 颗固定螺丝 A；用手将供料缓冲板从右端轻轻拉起，完成拆卸

|  |  |
| --- | --- |
|  |  |

> ***注意：供料缓冲板左端接口与外壳卡紧，可以先将供料缓冲板向右稍微移动再尝试拉起。***

## 安装操作步骤

### 第 1 步：安装供料缓冲板

将供料缓冲板从右端装入，将螺丝孔位对齐；使用 H1.5 内六角扳手锁紧供料缓冲板上 3 颗固定螺丝 A

|  |  |
| --- | --- |
|  |  |

### 第 2 步：安装缓冲区滑块与弹簧组件

1. 重新组装缓冲区滑块零件（如拆卸时发生脱落）与弹簧组件；用平头镊子将弹簧组件一端装入固定槽位，将缓冲区滑块左端卡入固定柱

|  |  |
| --- | --- |
|  |  |

2. 将缓冲区滑块上盖板安装上，使用 H1.5 内六角扳手锁紧缓冲区滑块左端两颗固定螺丝 A，完成安装
