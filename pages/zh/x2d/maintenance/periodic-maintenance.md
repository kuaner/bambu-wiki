为了确保打印机能够长期保持高精度、高稳定性的运行状态，规避机械磨损及潜在故障，建议您参考本指南定期对设备进行深度维护。

## 所需材料

- 润滑油/润滑脂
- 无纺布
- 酒精
- 刷子
- 镊子

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 一、舱内清洁

长期使用后，机舱底部及内衬极易积聚耗材碎屑。若碎屑进入运行机构，易造成 XYZ 轴运动卡涩，进而引发设备打印时产生异响。

使用毛刷对机舱底部进行初步清扫并移除大块耗材残余及异物。

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/026.webp)

使用无纺布淋喷酒精擦拭机舱底部，并重点清洁**丝杆**与**光轴**底部区域以防堆积物影响 Z 轴行程。

|  |  |
| --- | --- |
|  |  |

清洁打印机内衬顶部，擦除附着的残留耗材及污渍。

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/036.webp)

手动拉动打印机底部皮带，将热床缓慢降低，对机舱两侧散热风扇、机舱内壁进行全面擦拭清洁。

## 二、XYZ 轴清洁润滑

### 视频教程

### 保养周期

根据设备使用频率差异，建议执行以下保养周期：

- **高频使用场景**（日均打印时长≥5 小时）：XY 轴每月进行 1 次全面清洁润滑保养；Z 轴每 3 个月进行 1 次深度保养。
- **常规使用场景**（日均打印时长 1-5 小时）：XY 轴每 2 个月进行 1 次保养；Z 轴每 4 个月进行 1 次保养。
- **低频使用场景**（日均打印时长＜1 小时）：XY 轴每 3 个月进行 1 次保养；Z 轴每 5 个月进行 1 次保养。

### X 轴润滑保养

沿 X 轴光轴轴向进行往复擦拭，直至表面无可见油污及耗材碎屑。建议同步检查皮带表面，若存在污渍可使用无纺布进行清洁

|  |  |
| --- | --- |
|  |  |

采用点滴方式沿光轴轴向均匀涂抹润滑油（每 5cm 长度滴加 1-2 滴），上下两根光轴均需处理。

|  |  |
| --- | --- |
|  |  |

手动推动工具头沿 X 轴全程往复运动 3-5 次，确保润滑油在光轴表面形成均匀油膜。

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/024.webp)

> 注意：推动工具头时请保持缓慢速度，以确保石墨套能充分吸收润滑油；若移动速度过快，易导致润滑油被直接推至中框，影响润滑效果。

完成后可以用无尘布轻擦光轴两端，去除多余油脂防止吸附灰尘。

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/008.jpg)

### Y 轴润滑保养

使用淋喷酒精的无纺布对左右两侧 Y 轴光轴进行全面擦拭。

|  |  |
| --- | --- |
|  |  |

完成以上动作后为光轴涂抹润润滑油。（用量参照 X 轴标准）

|  |  |
| --- | --- |
|  |  |

手动驱动工具头沿 Y 轴前后往复运动 3-5 次，使润滑油充分渗透至轴承内部。

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/012.webp)

如果油脂光轴过多请用无尘布擦拭光轴表面多余油脂。

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/005.jpg)

### Z轴润滑保养

> ℹ️**注意：** 极少数情况下，Z 轴皮带运转时可能出现吱吱异响，可在皮带与 Z 轴皮带张紧器惰轮的接触处滴 1 小滴润滑油，有效降低运行噪音。

打开打印机电源，点击向下按钮将热床降至最低点。（不要多次连续点击，防止热床过冲撞击底部）

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/016.png)

使用蘸有酒精的无纺布对左右两侧丝杆、光轴及热床尾部丝杆进行擦拭，确保螺纹间隙内无残留物。同时重点清理丝杆螺母与丝杆接触部位，可配合镊子清理耗材残留。

|  |  |
| --- | --- |
|  |  |

完成后为三根丝杆均匀涂抹润滑脂，左右两侧光轴涂抹润滑油。

|  |  |
| --- | --- |
|  |  |

完成以上步骤后通过控制面板驱动热床从最低位升至最高位，再降至最低位，重复 3-5 个循环，使润滑脂和润滑油均匀分布于丝杆和光轴。

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/020.webp)

润滑完成后，若顶部或底部存在油脂堆积、耗材碎屑等异物，可用无纺布擦拭干净。

|  |  |
| --- | --- |
|  |  |

全面校准完成打印机 XYZ 三轴的清洁润滑后，需进入设备校准界面执行**全面校准程序**，以确保机械部件在最佳状态下协同工作。具体包括：**电机降噪、振动补偿、自动热床调平**

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/003.png)

## 三、主挤出机清洁

### 快速清洁

移除入料口 PTFE 管、热端压块及左侧热端后，可使用压缩空气从顶部入料口向下吹气，以快速清洁挤出机内部碎屑。

|  |  |
| --- | --- |
|  |  |

清洁完成后可以在工具头侧面齿轮位置添加润滑油。

![lubrication.jpg](https://wiki.bambulab.com/x2d/periodic-maintenance/lubrication.jpg)

### 深度清洁

挤出机长时间使用后，内部易堆积耗材碎屑，需定期清洁；同时对齿轮传动部位进行润滑养护，减少齿轮磨损。

> 关于挤出机齿轮的详细拆装步骤，可参考 [X2D 挤出机堵塞清洁维护](extruder-cleaning-guide.md)。

打开挤出机外壳，清除内部堆积的耗材碎屑及残留杂质。

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/035.webp)

在以下的两个齿轮传动部位涂抹润滑脂，减少齿轮磨损。

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/014.png)

## 四、辅助挤出机清洁

### 快速清洁

按压进料口气动接头，拔出进料铁氟龙管。使用 8 mm 开口扳手拧松辅助挤出机出料口的锁紧螺母，并拔出料管。

|  |  |
| --- | --- |
|  |  |

> 注：拔出料口料管时，如阻力较大，可从打印机内部辅助拉动料管。

用手托住辅助挤出机并向上轻推，使其与打印机背板解锁。  
![002.png](https://public-cdn.bblmw.com/wiki/new/x2d/replace_auxiliary_extruder/002.png)

移除辅助挤出机上的连接器护盖，按下连接器插头锁扣，断开连接线，并取下辅助挤出机组件。  
![014.webp](https://public-cdn.bblmw.com/wiki/new/x2d/replace_auxiliary_extruder/014.webp)

使用压缩空气对辅助挤出机内部进行清洁，重点吹除齿轮、进出料通道及缝隙中的耗材碎屑和粉尘。

|  |  |
| --- | --- |
|  |  |

清洁完成后，可在黑色齿轮表面适量涂抹润滑脂。

![lubriaction-auxiliary-extruder.jpg](https://wiki.bambulab.com/x2d/periodic-maintenance/lubriaction-auxiliary-extruder.jpg)

### 深度清洁

长时间使用后，辅助挤出机内部可能会积聚较多碎屑，也可能出现齿轮磨损。您可参考[辅助挤出机拆解指南](replace-auxiliary-extruder.md)，对挤出机进行拆解并开展深度清洁保养。

![014.webp](https://public-cdn.bblmw.com/wiki/new/x2d/replace_auxiliary_extruder/016.webp)

## 五、打印板清洁

X2D 打印机标配**纹理 PEI 打印板**，该打印板由 PEI 材料喷涂于不锈钢板制成，适配多种常用打印耗材，且打印 PLA 时无需使用任何胶水。为保持打印板最佳的耗材粘附力，需定期清洁，清洁完成后**严禁手指直接接触打印板表面**，防止皮肤油脂附着影响耗材贴合效果。

> PEI 打印板的清洁方式请查阅此链接：[Bambu Textrued PEI Plate 清理指南](../../filament-acc/acc/pei-plate-clean-guide.md)

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/015.png)

## 六、清洁实况摄像头

打印机长期使用后，挥发性有机物颗粒可能附着在摄像头镜头上，导致远程查看画面模糊等问题。建议每6个月清洁一次摄像头（强挥发材料如ABS等需要缩短清洁时间）。

![](https://public-cdn.bblmw.com/wiki/new/x2d/period-maintenance/002.webp)

## 七、更换活性炭滤芯

当滤芯出现严重脏污时，为保证过滤效果，建议及时更换。从侧边卡扣处打开并拆除活性炭滤芯盖，拉住滤芯上下拉手即可取出。

|  |  |
| --- | --- |
|  |  |

> 若滤芯盖脏污严重且常规清洁无效，可将其置于水龙头下冲洗，同时用刷子清理。**注意**：水洗后必须彻底擦干滤芯盖，因其周围存在电子器件，残留水分可能影响器件正常功能。

## 八、更换擦嘴硅胶

硅胶擦嘴用于清除喷嘴上的残余废料。若硅胶擦嘴出现损坏或变形，为确保喷嘴清洁效果，建议及时更换。

|  |  |
| --- | --- |
|  |  |

## 九、更换辅助挤出机/辅助热端料管

辅助挤出机出料口和辅助热端进料口均通过辅助料管夹紧螺母固定料管。长期使用后，料管可能逐渐松动并发生位移，在料管接头夹持位置产生磨损，进而导致拉丝、回抽不良及打印质量下降。  
在螺母固定的状态下，如果发现料管可上下移动，则说明料管端部出现磨损，无法被正常夹紧，建议及时更换料管，以确保打印质量。

## 十、工具头切刀维护

工具头切刀负责在换料流程中切割耗材。随使用时长增加，刀片会逐渐磨损变钝，进而导致切割阻力增大。**若在使用 AMS 过程中频繁出现退料失败，通常是由于切刀刀片未能彻底切断耗材所致，此时应优先检查刀片状态。**

- **常规耗材（如 PLA/PETG/ABS/PC 等）**：建议每累计打印 **8-12 卷**检查一次刀片锋利度，若有迟钝感请及时更换。
- **高磨损耗材（如 PA+CF/PA+GF/PPA+CF 等）**：由于增强纤维会加速刃口磨损，建议每打印 **6-10 卷**即进行专项检查，视磨损情况进行更换。

> 详细更检查换步骤请参考[切刀刀片更换指南](replace-filament-cutter.md)。
