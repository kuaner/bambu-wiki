## 一、概述

喷嘴堵塞是 3D 打印领域内的一个常见的现象，时常会遇到这个问题。堵塞的发生有各种不同的原因，例如，喷嘴的温度不够高，不能确保耗材在挤压时足够快地融化；或者可能您使用的耗材可能有微小颗粒(如碳纤维耗材或木质耗材)，这些颗粒会聚集在喷嘴的尖端，限制流动。这些现象很容易判断，会通过以下方式表现出来：

- 没有挤出 （取下喷嘴后耗材能从挤出机送出，但无法从喷头中出来）
- 挤出不足（挤压出的耗材不够，导致打印模型周围有间隙）

当喷嘴无法冲刷出任何耗材时，建议使用通针疏通并冷拔喷嘴。

> **安全须知**
>
> 1.本视频涉及高温组件操作，存在烫伤风险，请务必做好安全防护。操作时全程佩戴防烫手套，切勿直接触碰喷嘴、热端等加热部件。
>
> 2.加热清理耗材残留时可能产生烟雾，请保持工作环境通风良好。

## 二、所需工具

为了解决大部分的堵塞问题，你可能会用到以下工具：

- 通针
- 钳子
- 耐温手套
- 一段耗材
- H1.5和H2.0内六角螺丝刀

![](https://public-cdn.bblmw.com/wiki/new/x2d/cold-pull-maintenance-hotend/002.png)

## 三、使用通针进行疏通

> 通针疏通时会释放喷嘴内部压力，喷嘴可能突然喷出高温杂质，因此务必佩戴手套，且清理时禁止将头伸入机箱观察。

以PLA为例，等待喷嘴温度为250℃后，使用通针伸入喷嘴并上下来回疏通多次。

|  |  |
| --- | --- |
|  |  |

趁热取下喷嘴，使用通针由入口处推出热端内残留的耗材，配合尖嘴钳将其彻底拔出。随后取出通针，重新装回喷嘴。

![](https://public-cdn.bblmw.com/wiki/new/x2d/cold-pull-maintenance-hotend/031.jpg)

完成后将热端温度设置到耗材的推荐温度以上，尝试手动挤出，观察耗材是否正常挤出。如果依旧无法正常挤出请根据以下步骤对喷嘴组件进行冷拔。

| --- | --- |
|  |  |

## 四、冷拔

打印机内置了“喷嘴冷拔维护”功能，可引导您完成清理操作。

### 右热端冷拔步骤

进入**工具箱**页面，选择“**喷嘴冷拔维护**”；根据当前喷嘴尺寸及残留耗材类型选择参数。例如：喷嘴 0.4mm，残留耗材为 PLA。确认后点击“**开始**”。

|  |  |
| --- | --- |
|  |  |

根据屏幕指引，拔掉机器后方的辅助挤出机进料管。

|  |  |
| --- | --- |
|  |  |

当屏幕提示从辅助挤出机插入耗材时，将耗材手动送入挤出机。

|  |  |
| --- | --- |
|  |  |

等待程序自动执行“加热-冲刷-降温-冷拔”流程。

|  |  |
| --- | --- |
|  |  |

冷拔完成后，屏幕会提示拔出耗材。此时请缓慢地将耗材拉出。

|  |  |
| --- | --- |
|  |  |

检查耗材末端，观察其形状是否完整及是否有黑色杂质残留。

![](https://public-cdn.bblmw.com/wiki/new/x2d/cold-pull-maintenance-hotend/001.jpg)

若杂质较多，可用斜口钳剪断污浊末端，重复冷拔流程直到耗材尖端干净。

|  |  |
| --- | --- |
|  |  |

### 左侧热端冷拔步骤

选择左侧喷嘴，确认参数并点击“**开始**”。

|  |  |
| --- | --- |
|  |  |

等待打印头回原点后，移除打印机上盖，并将前盖组件临时悬挂在 X 轴上。

|  |  |
| --- | --- |
|  |  |

根据屏幕提示按下黑色气动接头处，拔下 PTFE 料管。

|  |  |
| --- | --- |
|  |  |

当系统提示插入耗材时，将耗材插入左侧进料口。打印机会自动咬合耗材，加热喷嘴并开始冲刷。

|  |  |
| --- | --- |
|  |  |

等待冷拔程序自动执行完毕。

|  |  |
| --- | --- |
|  |  |

根据打印机屏幕提示缓慢拉出耗材。

|  |  |
| --- | --- |
|  |  |

检查冷拔质量。若已达到要求（末端无残留物），点击“**完成**”并恢复料管及前盖组件。

## 五、热六角螺丝刀疏通（适用于冷端堵塞）

少部分堵塞现象是耗材由于热蠕变问题而卡在热端散热片位置。这篇文章 [热蠕变](../../filament-acc/filament/heat-creep.md)详细介绍了这种现象，我们建议您阅读这篇文章，了解如何避免此类堵塞。

接下来的步骤需要拆下喷嘴进行操作。 详细步骤可参考 [X2D 热端&硅胶套更换指南](replace-hotend-and-silicone-sock.md)。

> 注意事项：
>
> - **建议在操作过程中佩戴防护手套** ，防止熔化的耗材滴落灼伤皮肤。
> - 此方法需使用 H1.5 内六角螺丝刀。

### 步骤 1. 加热六角螺丝刀

首先**加热六角螺丝刀**约 10 s 。用钳子牢牢夹住六角螺丝刀，以免烫伤。

![](https://public-cdn.bblmw.com/wiki/new/x2d/cold-pull-maintenance-hotend/003.jpg)

### 步骤 2. 将六角螺丝刀插入喷嘴入口

趁螺丝刀尖端处于高温状态，快速将其从喷嘴顶端插入，穿过散热器区域并推入内部残留的耗材中（如下图所示）。静置约 30 秒，让螺丝刀与耗材充分结合并冷却固化。

![](https://public-cdn.bblmw.com/wiki/new/x2d/cold-pull-maintenance-hotend/030.jpg)

### 步骤 3. 加热喷嘴尖端并拉出耗材堵塞物

六角螺丝刀现在卡在喷嘴里了，耗材也卡在了它周围。要取出卡住喷嘴的六角螺丝刀，此时需要加热喷嘴的熔腔区域 10-20 秒。

![](https://public-cdn.bblmw.com/wiki/new/x2d/cold-pull-maintenance-hotend/005.jpg)

> **警告！** **避免长时间加热喷嘴或使用高功率丁烷喷灯；**喷嘴的热侧只需足够热，以便即可取出带有耗材的内六角螺丝刀。

加热约 20 秒后，向外缓慢用力拉拽螺丝刀。此时卡住的耗材块应随螺丝刀整体拔出，从而清除堵塞。

![](https://public-cdn.bblmw.com/wiki/new/x2d/cold-pull-maintenance-hotend/029.jpg)

## 六、验证喷嘴是否正常

重新安装喷嘴，连接 PTFE 管，并重新装入耗材测试挤出效果，如果仍然堵塞或挤出不足，还需要反复多次尝试清理喷嘴。上述方法往往能清除 99% 的堵塞物，但在某些情况下，喷嘴可能完全堵塞或损坏，建议更换喷嘴组件。

![](https://public-cdn.bblmw.com/wiki/new/x2d/cold-pull-maintenance-hotend/004.jpg)
