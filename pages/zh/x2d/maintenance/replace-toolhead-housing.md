## 工具头外壳

工具头外壳一共包含3个配件，分别是：

- 工具头前盖组件：由工具头前盖和部件冷却风扇组件，并通过磁铁吸附在工具头中框上；
- 工具头后盖：用于封闭工具头后部的塑料盖子；
- 工具头中框组件：工具头中部的塑料盖子，上部安装有磁铁，能将工具头前盖组件吸附固定。

## 适用打印机型号

X2D

## 何时更换

**工具头前盖组件**

- 出现物理损坏，包括磁铁脱落
- 部件冷却风扇故障

**工具头后盖**

- 出现物理损坏

**工具头中框组件**

- 出现物理损坏，包括磁铁脱落

## 所需要工具和材料

- H1.5 内六角扳手
- 工具头前盖组件/工具头后盖/工具头中框组件

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除旧的工具头外壳

### 1. 移除工具头前盖

打开工具头前盖，按压前盖侧的连接器锁扣拔出连接插头，取下工具头前盖。  
![002_remove_front_cover_cable.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/002_remove_front_cover_cable.png)

### 2. 移除工具头后盖

用 H1.5 内六角扳手移除工具头后盖侧边的 4 颗螺丝

|  |  |
| --- | --- |
|  |  |

轻轻晃动工具头后盖，使卡扣松动（避免力气过大，以防卡扣断裂），然后移除工具头后盖。  
![005_remove_rear_cover.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/005_remove_rear_cover.png)

### 3. 移除工具头中框

用 H1.5 内六角扳手移除侧边的 4 颗螺丝

|  |  |
| --- | --- |
|  |  |

> 以下移除料管的操作并非必要，只是为了更方便取下中框。如果维修的内容不包括挤出机和霍尔检测板，也可以不移除料管。

按压左霍尔检测板上的气动接头并拔出料管  
![008_release_left_tube.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/008_release_left_tube.png)  
向右拨动堵嘴组件的拨杆，使得右霍尔检测板的气动接头露出，用扳手逆时针拧松气动接头，取出料管  
![009_release_right_tube.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/009_release_right_tube.png)  
用手扳开中框底部，先松出左侧，将工具头中框从拖链支架处松出，取下工具头中框。  
![010_remove_mid_cover.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/010_remove_mid_cover.png)

## 安装新的工具头外壳

### 1. 安装工具头中框

将工具头中框缺口对准拖链支架并压入，右侧位置避让工具头相机，  
![011_install_mid_cover.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/011_install_mid_cover.png)  
将中框安装到工具头上，  
![012_install_mid_cover.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/012_install_mid_cover.png)  
将辅助挤出机的料管安装到气动接头处，然后用打印的扳手顺时针拧紧气动接头，固定右侧料管。  
![009_release_right_tube.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/009_release_right_tube.png)  
然后向左拨动堵嘴组件的拨杆，使得右霍尔检测板的气动接头降下。  
![013_switch_flow_blocker_assembly.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/013_switch_flow_blocker_assembly.png)  
将左侧料管安装到左气动接头上，并轻轻拉动看是否安装到位。  
![014_install_left_tube.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/014_install_left_tube.png)  
锁入工具头中框的 4 颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 2. 安装工具头后盖

将工具头后盖安装到工具头上，注意后盖上的卡扣都需要安装到位，  
![015_install_rear_cover.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/015_install_rear_cover.png)  
然后锁入侧边的 4 颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 3. 安装工具头前盖组件

将工具头前盖电缆连接到挤出接口板的连接器上，  
![016_install_front_cover.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/016_install_front_cover.png)  
整理好线缆，合上工具头前盖组件。  
![017_front_cover.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_toolhead_cover/017_front_cover.png)

## 功能验证

- 检查外壳之间的缝隙，无明显的错位和浮起。
- 部件冷却风扇能正常开启和关闭。
