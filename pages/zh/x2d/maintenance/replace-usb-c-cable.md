## USB-C 数据线

USB-C 数据线是用于连接打印机 AP 板和 TH 板，对工具头进行控制及数据交互的连接线。

## 适用打印机型号

X2D

## 何时更换

- USB-C 数据线损坏；
- 经 Bambu Lab 技术支持分析需更换 USB-C 数据线。

## 所需要工具和材料

- H1.5 内六角螺丝刀
- H2.0 内六角螺丝刀
- 新的 USB-C 数据线

## 安全提示

> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

## 移除旧的 USB-C 数据线

### 步骤 1. 移除 AP 板盖

将辅助挤出机向上提起，露出 AP 板盖固定螺丝。

|  |  |
| --- | --- |
|  |  |

使用 H1.5 内六角扳手移除 2 颗 AP 板盖固定螺丝（BT2x8）；  
![003_remove_ap_board_cover_screws.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/003_remove_ap_board_cover_screws.png)

揭开 AP 板盖检修端，

|  |  |
| --- | --- |
|  |  |

从 AP 板上断开左 LED 灯连接线；

|  |  |
| --- | --- |
|  |  |

握住 AP 板盖连接拖链的一端，向右侧方向拉出 AP 板盖。在拉出时请用左手托住 AP 板左侧，当右侧拖链端拉出时，左手扶住 AP板盖，避免 AP 板盖跌落。  
![006_remove_ap_board_cover.webp](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/006_remove_ap_board_cover.webp)

> **易损提示：请勿从前端直接掰开 AP 板盖，会导致 AP 板盖折断！**

### 步骤 2. 断开 USB-C 数据线在 AP 板上的连接

移除固定 USB-C 数据线的线夹螺丝，  
![007_usbc_cable_clip_screw.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/007_usbc_cable_clip_screw.png)  
将 USB-C 数据线从 AP 板上断开连接后，将 USB-C 数据线从线夹中取出（请保留好线夹不要丢失），再将 USB-C 数据线从打印机框架上的线夹中取出。

|  |  |
| --- | --- |
|  |  |

### 步骤 3. 移除特氟龙进料管

按压料管支架上的启动接头，释放特氟龙进料管。

|  |  |
| --- | --- |
|  |  |

### 步骤 4. 松开拖链卡扣

将拖链组件上的拖链卡扣松开，然后将两个卡扣从拖链上移除。  
![010_remove_chain_clip.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/010_remove_chain_clip.png)

### 步骤 5. 移除工具头后盖及 TH 板

移除工具头后盖的两侧螺丝。

|  |  |
| --- | --- |
|  |  |

取下工具头后盖，

|  |  |
| --- | --- |
|  |  |

移除 TH 板上的所有线缆，  
![013_disconnect_the_th_board_cable_connection.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/013_disconnect_the_th_board_cable_connection.png)

移除 TH 板的 4 颗螺丝。  
![014_remove_th_board_screws.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/014_remove_th_board_screws.png)

### 步骤 6. 移除 USB-C 数据线

将TH 板翻转过来，拔取 USB-C 数据线，取下 TH 板。

|  |  |
| --- | --- |
|  |  |

将拖链底座卡扣从工具头中框上取下（可以将拖链底座卡扣适当转 90°，使底座更轻松的从工具头中框中取出）。  
![016_remove_usbc_cable.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/016_remove_usbc_cable.png)

将拖链底座的安装件旋转 180°，使其有一个缺口可以让 USB-C 数据线取出。

|  |  |
| --- | --- |
|  |  |

将 USB-C 数据线沿着拖链的方向将线缆从拖链松出，  
![018_pull_out_usbc_cable.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/018_pull_out_usbc_cable.png)

将 USB-C 数据线从 AP 板盖中取下。  
![019_release_usbc_cable.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/019_release_usbc_cable.png)

## 安装新的 USB-C 数据线

### 步骤 1. 安装 USB-C 数据线到拖链组件

将 USB-C 数据线安装到拖链底座卡扣中（插头大约伸出 10cm），然后将拖链底座的安装件旋转 180°。

|  |  |
| --- | --- |
|  |  |

将 USB-C 数据线按进拖链组件的空隙中，直到全部 USB-C 数据线都在拖链组件内。  
![021_install_usbc_cable.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/021_install_usbc_cable.png)

将拖链底座卡扣安装到工具头中框里。  
![022_install_chain_base.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/022_install_chain_base.png)

### 步骤 2. 安装 TH 板和工具头后盖

将 USB-C 数据线安装到 TH 板上，  
![015_pull_out_usbc_cable.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/015_pull_out_usbc_cable.png)

将 TH 板放置好，并锁上安装螺丝。  
![014_remove_th_board_screws.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/014_remove_th_board_screws.png)

将 TH 板上的线缆安装好。  
![013_disconnect_the_th_board_cable_connection.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/013_disconnect_the_th_board_cable_connection.png)

可以参考[这篇 Wiki](replace-th-board.md) 获得更详细的指引。

安装工具头后盖并锁上 4 颗螺丝。

|  |  |
| --- | --- |
|  |  |

### 步骤 3. 安装拖链卡扣

将拖链组件上的拖链卡扣装好，将第一个拖链卡扣安装到第 7 节拖链上（从工具头的一侧开始数），第二个拖链卡扣安装到第 14 节拖链上。  
![010_remove_chain_clip.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/010_remove_chain_clip.png)

### 步骤 4. 安装特氟龙进料管

将特氟龙进料管安装到料管支架上，并用手轻轻晃动看是否安装到位。  
![009_release_ptfe_tube.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/009_release_ptfe_tube.png)

### 步骤 5. 断开 USB-C 数据线在 AP 板上的连接

将 USB-C 数据线连接到 TH 板上，然后将线缆卡进打印机框架上的线夹和USB-C 数据线的线夹上。  
![023_install_usbc_to_clip.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/023_install_usbc_to_clip.png)

锁上固定 USB-C 数据线的线夹螺丝。  
![007_usbc_cable_clip_screw.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/007_usbc_cable_clip_screw.png)

### 步骤 6. 安装 AP 板盖

安装 AP 板盖，  
![024_install_ap_board_cover.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/024_install_ap_board_cover.png)

安装左 LED 灯连接线，

|  |  |
| --- | --- |
|  |  |

盖上 AP 板盖检修端，

|  |  |
| --- | --- |
|  |  |

使用 H1.5 内六角扳手锁 2 颗 AP 板盖固定螺丝（BT2x8）；  
![003_remove_ap_board_cover_screws.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/003_remove_ap_board_cover_screws.png)

将辅助挤出机安装在背板上，固定好卡扣，可以轻轻摇晃一下看是否安装到位。  
![002_lift_auxiliary_extruder.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_usb-c_cable/002_lift_auxiliary_extruder.png)

## 功能验证

连接电源，打开打印机并执行设备校准操作，校准通过则更换成功。  
如果您遇到任何问题，请先回溯您的步骤并检查线缆是否连接正常，然后再次检查是否可以正常使用。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
