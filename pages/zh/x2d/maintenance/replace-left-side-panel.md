## 左侧板

面对 X2D 打印机玻璃前门，安装在打印机左侧的塑料面板。  
![fas079.png](https://public-cdn.bblmw.com/wiki/new/x2d/sku_pics/fas079.png)

## 适用打印机型号

X2D

## 何时更换

左侧板由于运输导致变形或损伤时，可以选择更换。

## 工具和材料

- 新的左侧板
- H1.5 内六角扳手
- H2.0 内六角扳手

## 安全提示

> **重要提醒 ！**
>
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生电路短路从而引起额外的电子设备损坏和安全隐患。
>
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。
>
> 如果您对本指南有任何疑问，请点击这里提交工单，我们将及时回复并为您提供所需的帮助。

## 移除旧的左侧板

### 步骤 1. 移除辅助挤出机、料管支架、缓冲器和背板

您可以参考如下 Wiki 的拆解部份内容，依次移除料管支架、缓冲器和背板。

- [更换辅助挤出机](replace-auxiliary-extruder.md)
- [更换缓冲器](replace-filament-buffer.md)
- [更换背板](replace-rear-panel.md)

![002_remove_rear_panel.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/002_remove_rear_panel.png)

### 步骤 2. 移除腔温加热组件

您可以参考[更换腔温加热组件](replace-chamber-heater-unit.md)，来移除腔温加热组件。

### 步骤 3. 移除屏幕和前面盖

您可以参考[更换前面盖](replace-front-cover.md)的拆解部份内容，移除屏幕和前面盖。

### 步骤 4. 移除 AP 板盖

揭开 AP 板盖检修端，从 AP 板上断开左 LED 灯连接线；

|  |  |
| --- | --- |
|  |  |

使用 H1.5 内六角扳手移除 2 颗 AP 板盖固定螺丝（BT2x8）；  
![005_remove_ap_board_cover_screws.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/005_remove_ap_board_cover_screws.png)

握住 AP 板盖连接拖链的一端，向右侧方向拉出 AP 板盖。在拉出时请用左手托住 AP 板左侧，当右侧拖链端拉出时，左手扶住 AP板盖，避免 AP 板盖跌落。

> **易损提示：请勿从前端直接掰开 AP 板盖，会导致 AP 板盖折断！**

![006_remove_ap_board_cover.webp](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/006_remove_ap_board_cover.webp)

### 步骤 5. 移除左侧板

用 H1.5 内六角扳手移除固定左侧板顶部的 2 颗黑色螺丝（ST2x3.5），1 颗银色螺丝（ST2x4.5）；  
![007_top_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/007_top_screws.jpg)

用 H2.0 内六角扳手移除上横梁处的 2 颗螺丝（BT3x6）；  
![008_top_beam_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/008_top_beam_screws.jpg)

用 H2.0 内六角扳手移除中间横梁处的 1 颗螺丝（BT3x6）；  
![009_mid_beam_screw.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/009_mid_beam_screw.jpg)

用 H2.0 内六角扳手移除前立柱的 3 颗螺丝（BT3x6）；  
![010_front_beam_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/010_front_beam_screws.jpg)

用 H2.0 内六角扳手移除内侧的 2 颗螺丝（BT3x6）；  
![011_mid_beam_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/011_mid_beam_screws.jpg)

用 H2.0 内六角扳手移除背部上方的 1 颗螺丝（M3x4.5），和下方的 3 颗螺丝（ST3x4.5）；  
![012_back_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/012_back_screws.jpg)

用 H2.0 内六角扳手移除后立柱的 1 颗螺丝（BT3x6）；  
![013_back_beam_screw.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/013_back_beam_screw.jpg)

向右侧放打印机；

|  |  |
| --- | --- |
|  |  |

用 H2.0 内六角扳手移除底部的 3 颗螺丝（BT3x8）；  
![015_bottom_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/015_bottom_screws.jpg)  
正放打印机，用内六角扳手在左上角撬动左侧板，解除该处的卡扣锁定。

![leftpanel.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/leftpanel.jpg)  
将左侧板向上提拉少许，解除其余卡扣锁定，然后移除左侧板。  
![016_remove_left_panel.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/016_remove_left_panel.jpg)

## 安装新的左侧板

### 步骤 1. 安装左侧板

将左侧板安装到打印机上，注意需要将卡扣对准卡槽安装。

|  |  |
| --- | --- |
|  |  |

安装前立柱的 3 颗螺丝（BT3x6）；  
![010_front_beam_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/010_front_beam_screws.jpg)

安装内侧的 2 颗螺丝（BT3x6）；  
![011_mid_beam_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/011_mid_beam_screws.jpg)

安装中间横梁处的 1 颗螺丝（BT3x6）；  
![009_mid_beam_screw.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/009_mid_beam_screw.jpg)

安装背部上方的 1 颗螺丝（M3x4.5），和下方的 3 颗螺丝（ST3x4.5）；  
![012_back_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/012_back_screws.jpg)

安装后立柱的 1 颗螺丝（BT3x6）；  
![013_back_beam_screw.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/013_back_beam_screw.jpg)

安装上横梁处的 2 颗螺丝（BT3x6）；  
![008_top_beam_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/008_top_beam_screws.jpg)

安装固定在左侧板顶部的 3 颗螺丝，靠近前门的 1 颗银色螺丝（ST2x4.5），和剩余的 2 颗黑色螺丝（ST2x3.5）；  
![007_top_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/007_top_screws.jpg)

向右侧放打印机

|  |  |
| --- | --- |
|  |  |

安装底部的 3 颗螺丝（BT3x8），然后正放打印机。  
![015_bottom_screws.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/015_bottom_screws.jpg)

### 步骤 2. 安装 AP 板盖

沿着安装槽将 AP 板盖拖链一侧推到位（可使用内六角扳手确认螺丝孔对齐），在推动 AP 板的时候，请用手扶着 AP 板盖左侧，并将左侧的卡扣卡入框架中。  
![018_install_ap_board_cover.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/018_install_ap_board_cover.png)

将 LED 补光灯 - 左的连接线插入 AP 板，并将检修端扣紧。

|  |  |
| --- | --- |
|  |  |

使用 H1.5 内六角扳锁紧 2 颗螺丝（BT2x8）。  
![005_remove_ap_board_cover_screws.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/005_remove_ap_board_cover_screws.png)

### 步骤 3. 安装前面盖和屏幕

您可以参考[更换前面盖](replace-front-cover.md)，装好前面盖和屏幕。

### 步骤 4. 安装腔温加热组件

您可以参考[更换腔温加热组件](replace-chamber-heater-unit.md)安装腔温加热组件。

### 步骤 5. 安装辅助挤出机、背板、缓冲器和料管支架

您可以参考如下 Wiki 的安装部份内容，依次安装背板、缓冲器和料管支架。

- [更换辅助挤出机](replace-auxiliary-extruder.md)
- [更换缓冲器](replace-filament-buffer.md)
- [更换背板](replace-rear-panel.md)

![002_remove_rear_panel.png](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_left_side_panel/002_remove_rear_panel.png)

## 如何验证成功

- 启动打印机，屏幕能正常开启
- 在屏幕上进行操作, 左LED 灯能正常开启与关闭。

如果您遇到任何问题，请先回溯您的步骤并检查线缆连接是否正常，然后再次检查是否可以正常使用。如果问题仍然存在，请联系 Bambu Lab 服务团队寻求进一步帮助。
