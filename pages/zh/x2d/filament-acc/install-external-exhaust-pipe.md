## 排气管

排气管可以将 X2D 腔内的空气导向室外，这有助于去除在打印 ABS/ASA 等工程耗材时产生的异味和颗粒物。在打印产生强烈异味的材料时，或在需要改进室内空气时，这非常有用。

## 安装指南

### 安装气管连接件

开始组装排气管接头的卡扣，该卡扣分为长、短两个部分，先将较短的部件安装在排气管接头上，随后锁紧部件左右两侧的螺丝(BT2\*5)进行固定。

> 注意事项：  
> 1.使用到的所有螺丝仅充当转轴作用，安装时不可过度锁紧，否则会导致卡扣无法顺滑活动，影响后续使用。  
> 2.若您没有该规格的螺丝，可插入一小截耗材充当转轴。  
> ![pixpin_2026-07-06_15-11-43.jpg](https://wiki.bambulab.com/x2d/filament-acc/install-external-exhaust-pipe/pixpin_2026-07-06_15-11-43.jpg)

| --- | --- |
|  |  |

将较长的卡扣部件插入较短部件的一端，对准两者的螺丝孔后，锁紧左右两侧的螺丝，完成两个卡扣部件的拼接。

|  |  |
| --- | --- |
|  |  |

用手上下活动卡扣，检查其是否运动顺滑、无卡涩；按照此方法完成三个卡扣的组装，组装后的整体状态可参考下图。

|  |  |
| --- | --- |
|  |  |

将排气管的一端套在气管接头上，通过卡扣进行三点固定以完成安装，建议先固定上下两侧的卡扣，再固定右侧的卡扣。

|  |  |
| --- | --- |
|  |  |

最后将排气管和卡箍装在打印件上，安装完成后如下图所示。
