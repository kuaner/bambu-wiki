## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### 1. 退料、下降热床、关闭电源

- 屏幕点击退料，将料盘支架上的耗材卷回料盘并拿下。

|  |  |
| --- | --- |
|  |  |

- 将 AMS 内的耗材卷回料盘并取出。

![x2d-combo-packing-image-10.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-10.png)

- 放回热床底部泡棉。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-11.png)

- 使用屏幕控制热床下降至底部，压紧泡棉。

|  |  |
| --- | --- |
|  |  |

> 注意：热床接近底部时，请每次降低 1 mm，防止热床冲撞打印机底部。

- 关闭电源，拔下电源线。

|  |  |
| --- | --- |
|  |  |

### 2. 移除外排套装

- 移除外排风扇 6-pin 连接线。

|  |  |
| --- | --- |
|  |  |

- 按压图示区域后右滑解锁，向外取出风扇。

|  |  |
| --- | --- |
|  |  |

### 3. 移除料盘支架

- 移除连接至料盘支架的铁氟龙料管。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-3.png)

- 向外拉动移除料盘支架。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-4.png)

- 上下晃动支架进行拆解。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/unintall-spool-holder.webp)

### 4. 移除 AMS 2 Pro

- 移除连接 AMS 2 Pro 的 6 pin 连接线。

|  |  |
| --- | --- |
|  |  |

- 按压释放按钮，拔出铁氟龙料管。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-15.png)

- 取下 AMS 2 Pro，放回外排套装。

|  |  |
| --- | --- |
|  |  |

- 放回泡棉，用纸卡固定外排套装。

|  |  |
| --- | --- |
|  |  |

### 5. 移除辅助挤出机

- 按压气动接头，拔出白色料管。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-20.png)

- 取下蓝色固定片。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-21.png)

- 按压气动接头，拔出灰色料管，装回蓝色固定片。

|  |  |
| --- | --- |
|  |  |

- 使用开口六角扳手拧松挤出机左侧螺母。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-23.png)

- 将辅助挤出机上抬后向外轻拉。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-24.png)

- 拔出左侧料管。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-25.png)

- 滑出挡片，拔出连接线缆。

|  |  |
| --- | --- |
|  |  |

- 装回挡片。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-36-v2.png)

- 用胶带固定背板上的线缆及料管。

|  |  |
| --- | --- |
|  |  |

### 6. 移除屏幕

- 按压屏幕转轴底部的解锁位，右推屏幕后向外轻拉。

|  |  |
| --- | --- |
|  |  |

- 按住排线两侧的端子取下屏幕。

|  |  |
| --- | --- |
|  |  |

- 用胶布固定排线。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-28.png)

### 7. 固定工具头、丝杆、热床

- 取下玻璃上盖。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-29.png)

- 用扎带固定工具头，并将其移至机箱右后方。

|  |  |
| --- | --- |
|  |  |

- 将扎带穿过图示孔位，固定光杆。

|  |  |
| --- | --- |
|  |  |

- 安装两个丝杆保护件。

|  |  |
| --- | --- |
|  |  |

- 放回干燥剂。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-40.png)

- 拧紧 1 颗螺丝，固定热床。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-heatbed-screw.png)

### 8. 固定AMS

- 放回 AMS 2 Pro 固定件，对齐孔位并拧紧 3 颗螺丝。

|  |  |
| --- | --- |
|  |  |

- 放回机箱内壁上的泡棉。

|  |  |
| --- | --- |
|  |  |

- 对准底部固定件卡槽，放回 AMS 2 Pro，确保其上盖与泡棉贴合。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-41.png)

- 拧紧底部 2 颗螺丝。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-ams-front-screws.png)

- 放回顶部所有泡棉和配件盒。

|  |  |
| --- | --- |
|  |  |

### 9. 固定打印机并装箱

- 放回把手泡棉，套上前门保护袋，并用胶带固定。

|  |  |
| --- | --- |
|  |  |

- 套上玻璃上盖保护袋，放至打印机顶部并用胶带固定。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-42.png)

- 用胶带固定铁氟龙料管，套好防潮袋并密封。

|  |  |
| --- | --- |
|  |  |

- 将打印机放回外箱，将缓冲气垫放至打印机四周。

|  |  |
| --- | --- |
|  |  |

- 放回顶部泡棉、纸卡、工具盒。

|  |  |
| --- | --- |
|  |  |

- 用胶带封住外箱。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/packing-x2d-combo/x2d-combo-packing-image-51.png)
