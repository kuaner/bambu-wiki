## 视频指南

## 包装内配件

- 配件盒
- 工具盒
- 外排套装
- 备用铁氟龙料管\*2  
  ![x2d_combo_unboxing_1.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_1.jpg)

## 操作步骤

### 1. 移除包装

- 打开外箱，取出工具盒和快速入门指南。

|  |  |
| --- | --- |
|  |  |

- 内部的物品可取出等待使用。（开口扳手有银色和黑色，请以实际收到为准）  
  ![img_v3_0211m_9ac7c6de-5a2c-42c7-bd51-45eceb044a5g.png](https://wiki.bambulab.com/x2d/manual/unboxing/img_v3_0211m_9ac7c6de-5a2c-42c7-bd51-45eceb044a5g.png)
- 移除纸卡和顶部泡棉。

|  |  |
| --- | --- |
|  |  |

- 提出打印机，放置于稳定平面。

|  |  |
| --- | --- |
|  |  |

- 撕开并移除防潮袋，取下备用铁氟龙料管。

|  |  |
| --- | --- |
|  |  |

- 撕开顶部胶带，取下上盖玻璃，移除保护袋。

|  |  |
| --- | --- |
|  |  |

- 撕开前门胶带，移除保护袋和把手处的泡棉。

|  |  |
| --- | --- |
|  |  |

- 移除侧面视窗上的保护膜。

|  |  |
| --- | --- |
|  |  |

### 2. 取出配件与AMS 2 Pro

- 取出配件盒。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_16.jpg)
- 移除顶部所有泡棉。

|  |  |
| --- | --- |
|  |  |

> 包装方案更新，请按下图所示移除所有泡棉。  
> ![x2d-top-foams-new.png](https://wiki.bambulab.com/x2d/manual/unboxing/x2d-top-foams-new.png)

> 靠近前门的泡棉块安装紧实，请按如下方式取出。  
> ![remove-front-top-foam-block-v2.webp](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/remove-front-top-foam-block-v2.webp)

- 用内六角扳手 H2.0 拧下 2 颗螺丝。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_19.jpg)
> 注意：热床底部泡棉在完成首次校准后才能移除。

- 向上取出 AMS 2 Pro。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_20.jpg)
- 移除机箱内壁上的泡棉和侧面视窗上的白色防护膜。

|  |  |
| --- | --- |
|  |  |

- 用 H2.0 扳手拧下 3 颗螺丝，移除 AMS 2 Pro 运输固定件。

|  |  |
| --- | --- |
|  |  |

### 3. 移除运输材料

- 用 H2.0 扳手拧下 1 颗热床固定螺丝。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_25.jpg)

> 注意： 拆卸该螺丝过程中，螺丝易掉落至机箱后侧，建议使用吸磁螺丝刀、镊子等工具承接，避免螺丝掉入设备缝隙。

- 移除机箱内壁固定的干燥剂。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_26.jpg)
- 下拉左右侧丝杆顶部的红色塑胶保护件，打开并移除。

|  |  |
| --- | --- |
|  |  |

- 剪断并移除光杆上的扎带。

![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_29.jpg)

- 将工具头拉向前门，剪断并移除工具头上的扎带。

|  |  |
| --- | --- |
|  |  |

- 撕下工具头上的保护膜。  
  ![x2d_combo_unboxing_74.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_74.png)

> 包装更新：工具头保护膜已取消。

- 盖上玻璃上盖。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_33.jpg)

### 4. 安装屏幕

- 移除排线固定胶布。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_34.jpg)
- 按住排线两侧端子，将排线插入屏幕。

|  |  |
| --- | --- |
|  |  |

- 将排线收回打印机槽内，插入屏幕，左推锁紧。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_37.jpg)

### 5. 安装辅助挤出机

- 移除胶带，从配件盒中取出辅助挤出机。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_38.jpg)
- 划出挡片，插入线缆。

|  |  |
| --- | --- |
|  |  |

> 向外滑出挡片有助于扩展操作空间，观察线缆安装是否到位，您也可在不拆卸挡片的情况下直接插入线缆。

- 装回挡片。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_41.jpg)
- 用手拧松辅助挤出机左侧接口的螺母。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_42.jpg)
- 将铁氟龙料管插入接口，伸入到底（约 22 mm）。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_43.jpg)

> 铁氟龙料管新增到位标识。安装时，请确保灰色贴纸进入螺母。  
> ![insert-tube-into-aux-extruder.png](https://wiki.bambulab.com/x2d/manual/unboxing/insert-tube-into-aux-extruder.png)

- 将辅助挤出机插入打印机背部孔位，下压锁紧。

|  |  |
| --- | --- |
|  |  |

- 再次确认左侧铁氟龙料管插入到底。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_46.jpg)
- 使用开口六角扳手拧紧螺母，直到听见"哒哒"声。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_47.jpg)
- 移除料管固定胶带。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_48.jpg)
- 将灰色料管插入主挤出机进料口。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_49.jpg)
- 将白色料管插入辅助挤出机进料口。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_50.jpg)

### 6. 安装AMS 2 Pro

- 移除 AMS 2 Pro 表面保护膜和内部固定纸卡。

|  |  |
| --- | --- |
|  |  |

- 移除泡棉，取出外排套装。

|  |  |
| --- | --- |
|  |  |

- 取出干燥剂并移除外包装后，放回原位。

|  |  |
| --- | --- |
|  |  |

- 将 AMS 2 Pro 放至打印机顶部。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_57.jpg)
- 将缓冲器左侧连接的灰色料管插入 AMS 2 Pro 的出料口。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_58.jpg)
- 从配件盒取出 6-pin 连接线，两端分别插入打印机缓冲器和 AMS 2 Pro 的 6-pin 接口。

|  |  |
| --- | --- |
|  |  |

### 7. 安装料盘支架组件

- 从配件盒中取出料盘支架组件，将料盘支架滑入底座。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_61.jpg)
- 将铁氟龙料管支架向下插入料盘支架上的凹槽。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_62.jpg)
- 将缓冲器左侧连接的白色铁氟龙料管连接至料盘支架。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_63.jpg)

### 8. 安装外排套装

- 将外排风扇插入打印机背部孔位，按压风扇左推锁紧。

|  |  |
| --- | --- |
|  |  |

- 将 6-pin 连接线的两端分别插入打印机缓冲器和外排风扇的 6-pin 接口。

|  |  |
| --- | --- |
|  |  |

### 9. 开机与校准

- 确保电源插座旁标签所示的电压与当地电压标准一致。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_68.jpg)
- 插入电源线并开机。

|  |  |
| --- | --- |
|  |  |

- 根据屏幕指引进行首次校准。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_71.jpg)
- 完成校准后，取出热床底部的泡棉。  
  ![](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_72.jpg)

一切准备就绪，现在即可开启您的创作之旅。请参见 [X2D 首次打印](first-print.md)，完成您的首次打印。
