## 打印流程概览

- 根据您所购买的版本（[AMS 套装](https://wiki.bambulab.com/zh/x2d/manual/first-print#x2d-ams-%E5%A5%97%E8%A3%85%E8%BF%9E%E6%8E%A5%E6%96%B9%E5%BC%8F)/[单机](https://wiki.bambulab.com/zh/x2d/manual/first-print#x2d-%E5%8D%95%E6%9C%BA%E8%BF%9E%E6%8E%A5%E6%96%B9%E5%BC%8F)），将 AMS 2 Pro 及外挂料盘连接至打印机，装载耗材并完成进料。
- 打印前，先[检查打印板和热床](https://wiki.bambulab.com/zh/x2d/manual/first-print#%E6%AD%A5%E9%AA%A4-4%E6%89%93%E5%8D%B0%E5%89%8D%E5%87%86%E5%A4%87)的状态，再[发起打印](https://wiki.bambulab.com/zh/x2d/manual/first-print#%E6%AD%A5%E9%AA%A4-5%E5%BC%80%E5%A7%8B%E6%89%93%E5%8D%B0)任务。
- 打印结束后，等待模型冷却至室温后再[取下模型](https://wiki.bambulab.com/zh/x2d/manual/first-print#%E6%AD%A5%E9%AA%A4-6%E5%8F%96%E4%B8%8B%E6%A8%A1%E5%9E%8B)，并将[耗材退出](https://wiki.bambulab.com/zh/x2d/manual/first-print#%E6%AD%A5%E9%AA%A4-7%E9%80%80%E5%87%BA%E8%80%97%E6%9D%90)打印机，以便下次使用。

## 视频指南

## 步骤 1：正确连接 AMS 2 Pro 和外挂料盘

### X2D AMS 套装连接方式

详细操作说明请参见 [X2D AMS 套装开箱指南](unboxing-x2d-combo.md)。

![x2d-first-print-am404013.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-am404013.jpg)

> X2D AMS 套装包含 AMS 2 Pro 和外挂料盘支架，推荐优先连接 AMS 2 Pro 至缓冲器上进料口，从而使用左侧主热端，以充分发挥主热端的耗材兼容性优势。

### X2D 单机连接方式

详细操作说明请参见 [X2D 单机开箱指南](unboxing-x2d.md)。

![x2d-first-print-am404150.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-am404150.jpg)

## 步骤 2：AMS 2 Pro 进料与初始化

1. 打开电源开关。

![x2d-first-print-image.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-image.png)

2. 将打印所需耗材放入 AMS 2 Pro 料槽，轻推进料口，然后将耗材插入约 2 cm，AMS 将检测到耗材并自动送料。

![x2d-first-print-load-from-ams.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-load-from-ams.png)

3. 在打印机屏幕主页，从助手跳转至初始化页面。

|  |  |
| --- | --- |
|  |  |

4. 选择**自动模式**-**检测**，打印机将自动检测 AMS 2 Pro 连接至哪个挤出机。

![x2d-first-print-ams-initiation-auto-mode.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-ams-initiation-auto-mode.png)

> - 如果 AMS 2 Pro 连接缓冲器上进料口，则配置到左热端；如果连接缓冲器下进料口，则配置到右热端（辅助）。
> - 如果暂无耗材用于 AMS 2 Pro 自动初始化，可以在屏幕上点击**手动模式**，把接入的 AMS 2 Pro 配置到左边或右边（辅助）。

## 步骤 3：外挂料盘进料

1. 取一卷耗材，记住耗材类型和颜色后，根据绕线方向放置在料盘支架上。

|  |  |
| --- | --- |
|  |  |

2. 在屏幕上点击**编辑**，选择耗材的类型和颜色后，点击**确认**。

![x2d-first-print-image-3.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-image-3.png)

3. 将耗材插入铁氟龙料管，向前推送，直至无法前进。此时，打印机屏幕上工具头与料盘间的连接线会显示耗材颜色，表示挤出机检测到耗材进入。

|  |  |
| --- | --- |
|  |  |

4. 在屏幕上点击**进料**。期间按屏幕提示再次推动耗材，确保耗材仍然留在挤出机内。

![x2d-first-print-image-4.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-image-4.png)

5. 观察喷嘴，看见喷嘴顺利挤出耗材后，在屏幕上点击**耗材已挤出，继续**；如果耗材没有被挤出，选择**耗材未挤出，重试**，然后重复推入耗材的动作，直至耗材被顺利挤出。

|  |  |
| --- | --- |
|  |  |

## 步骤 4：打印前准备

### 检查热床

在放置打印板前，请检查并清洁热床表面，确保无异物残留。若存在异物，在加热过程中可能对软磁贴表面造成不可逆损伤。

![x2d-first-print-image-6.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-image-6.png)

### 清洁打印板

请避免在开箱或操作过程中直接用手接触打印板表面，以免油污影响打印附着力。

如不慎触碰，请按以下步骤清洁：

1. 取出打印板，用温水和洗洁精清洗表面；
2. 使用干净的纸巾或无纺布将其擦干；
3. 确认表面清洁后，放回打印板。

## 步骤 5：开始打印

您可通过打印机屏幕、Bambu Studio 或 Bambu Handy 发起打印，以下使用屏幕作为展示。您也可以在[其他打印方式](https://wiki.bambulab.com/zh/x2d/manual/first-print#%E5%85%B6%E4%BB%96%E6%89%93%E5%8D%B0%E6%96%B9%E5%BC%8F)，了解如何通过 Bambu Studio 和 Bambu Handy 进行操作。

建议自行准备一个 U 盘并插入打印机，用于保存工作录像和历史打印缓存，U 盘规格要求见 [X2D FAQs](x2d-faq.md)。  
![x2d-first-print-image-7.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-image-7.png)

### 选择模型

在首页点击**打印文件**，选择想要打印的模型。

![x2d-first-print-start-print-select-model.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-start-print-select-model.png)

### 确认配置

确认使用的打印板和喷嘴配置正确，并根据需要设置延时摄影和高级选项（默认为自动模式），然后点击**下一步**。

![x2d-first-print-start-print-check-info.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-start-print-check-info.png)

### 匹配耗材

选择两个热端使用的耗材，点击**打印**。

打印机内置模型及 USB 存储中的模型是已经切片完成的文件，切片文件中的耗材与热端的配对关系也已确定，故无法强行更改到另一个热端进行打印。

如果在匹配耗材页面无法选择想要打印的耗材，请调整耗材放置位置，把其放入目标热端所连接的 AMS 或者外挂料盘中。

### 其他打印方式

#### 从 Bambu Studio 发起打印

1. 参考[打印机账号绑定指南](../../knowledge-sharing/printer-account-binding-guide.md)连接 Wi-Fi。
2. 参考 [Bambu Studio 快速上手教程](../../software/bambu-studio/studio-quick-start.md) 安装软件，连接打印机。
3. 进入 Bambu Studio 主页，挑选想要打印的模型，选择打印配置后点击**下载并打开**。

![print-with-studio-cn-1.jpeg](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/print-with-studio-cn-1.jpeg)

4. 点击**切片单盘**，查看耗材分组策略及其他切片信息。如需修改默认的耗材分组，可点击**重新分组**，选择合适的耗材分组模式并调整耗材位置。有关耗材分组模式的详细介绍，请参见[双喷嘴打印机耗材切片分组](../../software/bambu-studio/manual/dual-nozzles-slicing-filament-grouping.md)。
5. 点击**打印单盘**，确认双热端所用耗材，按需设置高级选项，点击**发送**。

![print-with-studio-cn-2.jpeg](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/print-with-studio-cn-2.jpeg)

#### 从 Bambu Handy 发起打印

1. 参考[打印机账号绑定指南](../../knowledge-sharing/printer-account-binding-guide.md)连接 Wi-Fi。
2. 参考 [Bambu Handy 快速入门指南](../../studio-handy/handy/bambu-handy-quick-start.md)安装软件，连接打印机。
3. 在 Bambu Handy 中选择想要打印的模型，点击**准备打印**，选择打印配置，确认打印信息，再点击**开始打印**即可将打印任务发送给打印机。

| --- | --- |
|  |  |

您可前往 [Bambu Lab 软件页](../../software.md) 获取更多软件使用教程。

## 步骤 6：取下模型

1. 打印结束后，等待热床和模型冷却至室温。随后取下打印板，轻轻弯折打印板以取下模型和擦拭塔。

|  |  |
| --- | --- |
|  |  |

2. 使用刮刀清除打印板上的预挤出线，再将打印板重新放回热床。

|  |  |
| --- | --- |
|  |  |

## 步骤 7：退出耗材

### AMS 2 Pro 退料

在打印任务正常完成后，耗材会自动退回到 AMS 2 pro。

**如果打印任务在中途被取消或中断**，可以在屏幕上选择对应耗材，点击"退料"，以便让被挤出机咬合的耗材退回到 AMS 2 pro。

![x2d-first-print-unload-ams.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-unload-ams.png)

### 外挂料盘退料

如需更换外挂料盘上的耗材，可以将耗材退出挤出机后存储收纳。

1. 在屏幕上点击**退料**。  
   ![x2d-first-print-unload-external-spool.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-unload-external-spool.png)
2. 根据打印机提示，在耗材退出工具头后边旋转料盘，边拉回耗材。当耗材接近气动接头时，用手接住耗材末端，并将其插入料盘上的孔洞固定。

|  |  |
| --- | --- |
|  |  |

3. 完成后，在屏幕点击**已完成，继续**。  
   ![x2d-first-print-image-16.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/first-print/x2d-first-print-image-16.png)
