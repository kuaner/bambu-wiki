> - 包材、配件可能会不定时更新，请以收到的版本为准，更新详情见操作步骤。

## 视频指南

## 包装内配件

- 工具盒
- 辅助挤出机
- 料盘支架\*2
- 备用铁氟龙料管\*2
- 屏幕
- 外排套装（外排风扇 + 6-pin 连接线）

![x2d-unboxing-acc-list.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-acc-list.jpg)

## 操作步骤

### 1. 移除包装

- 打开外箱，取出工具盒和快速入门指南。

|  |  |
| --- | --- |
|  |  |

- 内部的物品可取出等待使用。（开口扳手有银色和黑色，请以实际收到为准）

![x2d工具盒.jpg](https://wiki.bambulab.com/x2d/manual/unboxing/x2d%E5%B7%A5%E5%85%B7%E7%9B%92.jpg)

- 移除纸卡和顶部泡棉。

|  |  |
| --- | --- |
|  |  |

- 提出打印机，放置于稳定平面。

|  |  |
| --- | --- |
|  |  |

- 撕开并移除防潮袋，取下铁氟龙料管。

|  |  |
| --- | --- |
|  |  |

- 撕开顶部胶带，取下上盖玻璃，移除保护袋。

|  |  |
| --- | --- |
|  |  |

- 撕开前门胶带，移除保护袋和把手处的泡棉。

|  |  |
| --- | --- |
|  |  |

- 移除侧面视窗上的保护膜。

|  |  |
| --- | --- |
|  |  |

### 2. 取出配件

- 拿出纸卡，取出辅助挤出机、外排风扇及 6-pin 连接线、屏幕、外挂料盘、电源线。

|  |  |
| --- | --- |
|  |  |

### 3. 拆除运输材料

- 用内六角扳手 H2.0 拧下 3 颗热床固定螺丝。  
  ![x2d-unboxing-heatbed-screws-x2d.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-heatbed-screws-x2d.png)

> - 热床底部泡棉在完成首次校准后才能移除。
> - 拆拆卸打印机后侧的热床固定螺丝时，螺丝易掉落至机箱内部。建议提前准备吸磁螺丝刀、镊子等工具承接或辅助取出，避免螺丝掉入设备缝隙。

- 移除两个丝杆固定件。

|  |  |
| --- | --- |
|  |  |

- 移除机箱内的干燥剂和胶带、侧面视窗上的白色防护膜。

|  |  |
| --- | --- |
|  |  |

- 下拉左右侧丝杆顶部的红色塑胶保护件，打开并移除。

|  |  |
| --- | --- |
|  |  |

- 剪断并移除光杆上的扎带，将工具头拉向前门。

|  |  |
| --- | --- |
|  |  |

- 移除光杆后方泡棉和工具头上的扎带。

|  |  |
| --- | --- |
|  |  |

- 撕下工具头上的保护膜。  
  ![x2d_combo_unboxing_74.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-combo-unboxing/x2d_combo_unboxing_74.png)

> 包装更新：工具头保护膜已取消。

- 盖上玻璃上盖。  
  ![x2d-unboxing-image-24.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-24.png)

### 4. 安装屏幕

- 移除排线固定胶布。

![x2d-unboxing-image-25.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-25.png)

- 按住排线两侧端子，将排线插入屏幕。

|  |  |
| --- | --- |
|  |  |

- 将排线收回打印机槽内，插入屏幕，左推锁紧。

![x2d-unboxing-install-touchscreen.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-install-touchscreen.png)

### 5. 安装辅助挤出机

- 移除胶带。

![x2d-unboxing-image-28.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-28.png)

- 划出挡片，插入线缆。

|  |  |
| --- | --- |
|  |  |

> 向外滑出挡片有助于扩展操作空间，观察线缆安装是否到位，您也可在不拆卸挡片的情况下直接插入线缆。

- 装回挡片。

![x2d-unboxing-image-31.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-31.png)

- 用手拧松辅助挤出机左侧接口的螺母。

![x2d-unboxing-image-32.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-32.png)

- 将铁氟龙料管插入接口，伸入到底（约 22 mm)。

![x2d-unboxing-image-33.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-33.png)

> 铁氟龙料管新增到位标识。安装时，请确保灰色贴纸进入螺母。  
> ![insert-tube-into-aux-extruder.png](https://wiki.bambulab.com/x2d/manual/unboxing/insert-tube-into-aux-extruder.png)

- 将辅助挤出机插入打印机背部孔位，下压锁紧。

|  |  |
| --- | --- |
|  |  |

- 再次确认左侧铁氟龙料管插入到底。

![x2d-unboxing-image-36.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-36.png)

- 使用开口六角扳手拧紧螺母，直到听见"哒哒"声。

![x2d-unboxing-image-37.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-37.png)

- 移除料管固定胶带。

![x2d-unboxing-image-38.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-38.png)

- 将灰色料管插入主挤出机进料口。

![x2d-unboxing-image-39.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-39.png)

- 将白色料管插入辅助挤出机进料口。

![x2d-unboxing-image-40.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-40.png)

### 6. 安装料盘支架

- 取出料盘支架组件，将料盘支架滑入底座。

![x2d-unboxing-image-41.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-41.png)

- 将铁氟龙料管支架向下插入料盘支架上的凹槽。

![x2d-unboxing-image-42.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-42.png)

- 将缓冲器左侧连接的灰色料管连接至上料盘支架。

![x2d-unboxing-image-43.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-43.png)

- 安装好另一个料盘支架。

|  |  |
| --- | --- |
|  |  |

- 将白色料管连接至下料盘支架。

![x2d-unboxing-image-46.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-46.png)

### 7. 安装外排套装

- 将外排风扇插入打印机背部孔位，按压风扇左推锁紧。

|  |  |
| --- | --- |
|  |  |

- 将 6-pin 连接线的两端分别插入打印机缓冲器和外排风扇的 6-pin 接口。

|  |  |
| --- | --- |
|  |  |

### 8. 开机与校准

- 确保电源插座旁标签所示的电压与当地电压标准一致。

![x2d-unboxing-check-voltage.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-check-voltage.png)

- 插入电源线并开机。

|  |  |
| --- | --- |
|  |  |

- 根据屏幕指引进行首次校准。

![x2d-unboxing-image-52.png](https://public-cdn.bblmw.com/wiki/new/x2d/manual/x2d-unboxing/x2d-unboxing-image-52.png)

- 完成校准后，取出热床底部的泡棉。

|  |  |
| --- | --- |
|  |  |

一切准备就绪，现在即可开启您的创作之旅。请参见 [X2D 首次打印](first-print.md)，完成您的首次打印。
