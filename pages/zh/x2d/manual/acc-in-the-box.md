## 配件介绍

| 实物照片 | 名称 | 描述 |
| --- | --- | --- |
| build-plate.png | 纹理 PEI 打印板 | 预装在热床上，承载模型，两面均可使用。 |

| aux-extruder.png | 辅助挤出机 | 安装在打印机背板，将右（辅助）热端耗材从缓冲器推送到工具头。 |
| external-exhaust-fan.png | 外排套装 (外排风扇 + 6-pin 连接线） | 6-pin 连接线用于连接外排风扇和打印机。 外排风扇可排出机箱内热空气。 |
| spare-hotend.png | 0.4 mm 硬化钢热端 & 热端硅胶套 | 热端或硅胶套损坏时可进行更换。 |
| filament_cutter.png | 左/右切料组件 | 位于工具头内，用于切断耗材。 |
| uncloggin-pin.jpg | 通针 | 用于疏通热端堵塞。 |
| nozzle-wiping-pad.png | 擦嘴块 | 位于吐料组件上，在开始打印任务前清洁喷嘴。 |
| scraper-blade.png | 刮刀刀片 | 用于制作刮刀，可在打印机内置模型中找到刮刀模型，打印后进行组装。 |
| screw-for-scraper.jpg | 螺丝（用于刮刀） | 用于组装刮刀。 |
| ptfe-locking-nut.png | 辅助料管夹紧螺母 | 用于固定辅助挤出机连接的料管，确保耗材顺畅传输。 |
| allen-key.jpg | 内六角扳手（H1.5 和 H2.0） | 拆装工具。 |
| open-end-wrench.png | 开口六角扳手（银色或黑色） | 用于拆装辅助挤出机和辅助热端上的螺母。 |
| flow-blocker.png | 堵嘴片 | 位于喷嘴下方，堵住非工作状态的喷嘴，防止漏料。 |
