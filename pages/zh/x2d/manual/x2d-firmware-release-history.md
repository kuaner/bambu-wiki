## 01.01.01.00（20260520）

### 新增功能

1. 新增Z轴电机降噪功能。
2. 新增打印过程中的挤出机异常切换检测，可更及时地识别外力导致的异常情况。

### 功能优化

1. 修复喷嘴偏移校准、外挂料盘检测、辅助挤出机进退料等场景中的异常问题，提升使用稳定性。
2. 优化打印板偏移和打印件位移检测，提升异常光照等复杂场景下的识别可靠性。
3. 修复AMS 2 Pro烘干掉电、送料卡料等问题，提升耗材进退料和烘干稳定性。
4. 优化设备进入引导流程的等待体验。
5. 优化挤出机切换时候的限位检测功能。

## 01.01.00.00（20260414）

### 新增功能

1. **新增对耗材变轨器的支持**

- 耗材变轨器专为双喷嘴打印机设计，配备 2 个进料口与 2 个出料口，可支持 AMS 与双喷嘴的任意映射。详见[耗材变轨器使用指南](../../general/manual/filament-track-switch.md)；
- 该功能需 Bambu Studio 更新到 V2.5.3.60 或更高的版本，Bambu Handy 更新到 V3.18.0 或更高的版本。

2. **支持边烘干耗材边打印功能**

- 需要注意功率限制和烘干温度不能高于材料的软化温度；
- 运行该功能需要额外购买的 AMS 外接电源。

3. **支持远程开启烘干功能**

|  |  |  |
| --- | --- | --- |
|  |  |  |

4. **新增对高流量热端的支持**

- 该功能通过选配额外的高流量热端（需另购），来获得更快的打印速度。
- 该功能需 Bambu Studio 更新到 V2.5.3.60 或更高的版本，Bambu Handy 更新到 V3.18.0 或更高的版本。

5. **支持延时摄影录制到内置存储，无需 U 盘即可录制**

同时支持内置延时摄影文件导出功能，内外置延时摄影文件删除功能。

![5-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/5-cn.png)

6. **支持曲线规划增强功能**

优化了曲线规划，改善某些场景下的打印质量。

7. **新增 AI 检测报错弹窗显示实况图像**

目前实况摄像头遮挡检测、异物检测、炒面检测、裹头检测、打印件位移检测支持弹窗显示实况图像。

![7-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/7-cn.png)

8. **新手指引流程体验优化**

新增新手引导流程，帮助新用户快速上手完成首次打印。后续可于“工具箱-新手引导”再次查看教学。

![8-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/8-cn.png)

9. **错误码弹窗详细原因展示**

联动 HMS 显示可能的更详细的错误原因。

![9-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/9-cn.png)

10. **新增热床低功率模式**

以便于在用户打印机供电功率受限的情况下，通过延长热床升温时间，降低最大功率。

![10-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/10-cn.png)

11. **支持 XYZ 电机空闲自由移动模式，方便维护维修**

![11-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/11-cn.png)

12. **新增热床底部异物检测**

在打印开始前检查热床底部空间，保证打印顺利进行。

13. **支持首层质量校准功能**

支持微调首层打印时喷嘴与热床间的距离，从而提升首层附着力与表面平整度。

> 注意：该功能是为了满足专业用户不同场景差异化的调参需求，一般情况无需用到，建议按需使用。

![13-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/13-cn.png)

14. **新增认证信息电子标签页**

![14-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/14-cn.png)

15. **新增实况相机固件升级功能，并且优化部分场景相机画质**
16. **新增机器内置模型升级功能，优化部分内置模型的打印质量**
17. **新增屏幕亮度调节功能**

![17-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/17-cn.png)

18. **新增打印件位移检测功能**

该功能通过机箱内的实况摄像头，持续监测打印中发生的打印件位移和倒塌事件。该功能需要用户在UI界面 "设置->打印选项->AI检测"中打开打印件位移检测开关。

19. **调整打印机设置页面的AI检测开关选项**

- 打印板在位检测默认开启：打印板在位检测不受打印板类型检测开关控制 （防止使用第三方打印板的用户关闭打印板检测后漏放打印板）。
- 新增异物检测开关。
- 新增打印件位移检测开关。

20. **新增对俄语的支持**

![20-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/20-cn.png)

21. **新增 PIN 码绑定功能**

- 使用该功能后，发起绑定时不再要求打印机与电脑必须连接在同一局域网内。只要不同网络之间的必要接口和协议能够互相通信，即可在 Bambu Studio 中通过使用 Pin 码绑定打印机。
- 该功能需 Bambu Studio 更新到 V2.5.3.60 或更高的版本，Bambu Handy 更新到 V3.18.0 或更高的版本。

![21-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/21-cn.png)

22. **新增发送当前盘到内置存储后打印功能**

- 该功能让用户可以在没有外置存储（U盘）的情况下，也能发送当前盘到打印机，然后打印。
- 该功能需 Bambu Studio 更新到 V2.5.3.60 或更高的版本。

![22-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/22-cn.png)

23. **新增仅局域网模式下发送到内置存储打印功能**

- 该功能可以让用户在没有外置存储（U盘）的情况下，能直接利用打印机的内置存储，在仅局域网模式下发起远程打印。
- 该功能需 Bambu Studio 更新到 V2.5.3.60 或更高的版本，Bambu Handy 更新到 V3.18.0 或更高的版本。

24. **新增加热底座维护模式功能**

该功能开启后，即使未安装热端，也能升温加热底座。便于部分维护检修场景，用户进行工具头方面的维修。

25. **新增工具头前盖脱落检测和保护功能**

### 功能优化

1. 升级过程交互页面优化

![26-cn.png](https://public-cdn.bblmw.com/wiki/new/x2d/release_note/26-cn.png)

4. 优化了空闲状态保护功能，支持空闲状态热床自动降温
