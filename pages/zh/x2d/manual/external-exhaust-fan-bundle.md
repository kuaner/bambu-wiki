## 介绍

安装了外排风扇套件后，如果打印 ABS、PA 等需密封打印的工程材料，就能在打印机屏幕的设置中启用 “打印结束时净化空气”-"外排"，X2D 将会在打印完成后自动开启外排模式，彻底排出机箱内废气，未安装风扇时仅采取“内循环”模式。

![pixpin_2026-08-27_15-34-43.jpg](https://wiki.bambulab.com/x2d/manual/external-exhaust-fan-bundle/pixpin_2026-08-27_15-34-43.jpg)

## 所需工具

- H2.0/H1.5 内六角扳手
- 外排风扇套件
- 6-pin 线缆
- 排气管连接件
- 排气管卡箍
- 排气管

## 安装外排风扇

- 将外排风扇插入打印机背部孔位，按压风扇左推锁紧。

|  |  |
| --- | --- |
|  |  |

- 将 6-pin 连接线的两端分别插入打印机缓冲器和外排风扇的 6-pin 接口。

|  |  |
| --- | --- |
|  |  |

### 安装排气管

打印以下部分零件后，开始组装排气管连接件。

[模型来源](https://makerworld.com.cn/zh/models/1857875-p2szhuan-yong-wai-pai-tao-jian-da-yin-mo-xing#profileId-2056503)

![](https://wiki.bambulab.com/p2s/manual/external-exhaust-fan-kit/027.png)

该卡扣分为长、短两个部分，先将较短的部件安装在排气管接头上，随后锁紧部件左右两侧的螺丝(BT2\*5)进行固定。

|  |  |
| --- | --- |
|  |  |

> 注意事项：  
> 1.使用到的所有螺丝仅充当转轴作用，安装时不可过度锁紧，否则会导致卡扣无法顺滑活动，影响后续使用。  
> 2.若您没有该规格的螺丝，可插入一小截耗材充当转轴。  
> ![pixpin_2026-07-06_15-11-43.jpg](https://wiki.bambulab.com/x2d/filament-acc/install-external-exhaust-pipe/pixpin_2026-07-06_15-11-43.jpg)

将较长的卡扣部件插入较短部件的一端，对准两者的螺丝孔后，锁紧左右两侧的螺丝，完成两个卡扣部件的拼接。

|  |  |
| --- | --- |
|  |  |

用手上下活动卡扣，检查其是否运动顺滑、无卡涩；按照此方法完成三个卡扣的组装，组装后的整体状态可参考下图。

|  |  |
| --- | --- |
|  |  |

将排气管的一端套在气管接头上，通过卡扣进行三点固定以完成安装，建议先固定上下两侧的卡扣，再固定右侧的卡扣。

|  |  |
| --- | --- |
|  |  |

最后将排气管和卡箍装在连接件上，安装完成后如下图所示，排气管另一头可连接至室外。

![pixpin_2026-07-07_17-49-30.jpg](https://wiki.bambulab.com/x2d/filament-acc/install-external-exhaust-pipe/pixpin_2026-07-07_17-49-30.jpg)
