## 故障描述

由于工具头与缓冲器之间的料管连接错误，导致 AMS 送料到对应挤出机失败。

### 排故措施

- 检查工具头与缓冲器之间料管的连接关系是否为：

缓冲器上入料口——主挤出机入料口——左热端  
缓冲器下入料口——辅助挤出机入料口——右热端

|  |  |
| --- | --- |
|  |  |

- 如果不是上述顺序，请参考下图重新连接；

> 注意：灰色铁氟龙管连接缓冲器上入料口（left nozzle）和主挤出机入料口，白色料管连接缓冲器下入料口（right nozzle）和辅助挤出机入料口。
