## 故障描述

挤出机切换过程中，MC 端检测到和 TH 板的通信断联。

**可能的原因：**

MC 板和 TH 板之间的连接线松动。

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手

### 排故措施

#### 步骤 1. 重启机器

如果重启后依然报错，请参考以下步骤。

#### 步骤 2. 检查 MC - AP 信号线

1. 参考[更换 AP 板](../../maintenance/replace-ap-board.md)，裸露 AP 板；

检查信号线是否破损，并重新插拔 MC 板信号线；

![07fe800000010006-image.png](https://wiki.bambulab.com/x2d/troubleshooting/hms/07fe_8000_0001_0006/07fe800000010006-image.png)

- 参考[更换 MC 板](../../maintenance/replace-mc-board-and-the-cooling-fan.md)，移除背板，解锁 MC 板风扇，裸露 MC 板；

|  |  |
| --- | --- |
|  |  |

检查信号线是否破损，并重新插拔 AP 板信号线；

![07fe800000010006-image-1.png](https://wiki.bambulab.com/x2d/troubleshooting/hms/07fe_8000_0001_0006/07fe800000010006-image-3.png)

- 如果插拔后仍报错，或信号线破损，请参考 [MC-AP 线缆更换教程](https://wiki.bambulab.com/zh/p2s/maintenance/replace-mc-ap-cable-pack-(2-in-1))进行更换。
