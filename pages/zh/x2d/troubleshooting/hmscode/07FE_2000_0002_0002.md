## 故障描述

对应的功能是”断料检测“，其功能是在外挂料盘耗材未装或用完后自动暂停打印并提示用户装入新的耗材。

- 打印机暂停，工具头挪到垃圾桶，屏幕弹框提示外挂料盘耗材用完；
- 屏幕耗材页面对应挤出机的耗材指示图标变为灰色，正常有耗材时图标是绿色。

## 工具、设备及材料

- 镊子（扁平头）
- 内六角螺丝刀

## 故障排除

### 检查外挂料盘耗材是否用完

- 如果发现耗材确实用完，则按屏幕提示装入新耗材到挤出机后点继续恢复打印；
- 如果耗材未用完，请确认外挂料盘连接到的挤出机。

### 主挤出机排障

#### 步骤 1：查看屏幕

如果发现耗材未用完且工具头内仍有耗材，检查屏幕的耗材页面：

|  |  |
| --- | --- |
| 无料状态 | 有料状态 |

- 如果屏幕显示有料，则为正常；
- 如果屏幕显示无料，则可能是传感器异常导致误报，请参考下一步。

#### 步骤 2：检查霍尔传感器

参考[更换左霍尔检测板](../../maintenance/replace-extruder-filament-sensor-left.md)，小心取出左霍尔检测板，并移除两颗螺丝。

![left-hall-sensor-screws.png](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07fe_2000_0002_0002/left-hall-sensor-screws.png)

插入一小段耗材，观察摇臂是否正常，取出耗材后是否会自动归位。

![left-hall.webp](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07fe_2000_0002_0002/left-hall.webp)

- 如果摇臂异常，卡住耗材或回弹卡涩，需检查摇臂转轴是否存在异物，并将其清理干净。
- 如果摇臂正常，则霍尔传感器故障，请参考[更换左霍尔检测板](../../maintenance/replace-extruder-filament-sensor-left.md)进行更换。

### 辅助挤出机排障

#### 步骤 1：查看屏幕

如果发现耗材未用完且工具头内仍有耗材，检查屏幕的耗材页面：

|  |  |
| --- | --- |
| 无料状态 | 工具头内有料状态 |

- 如果屏幕显示有料，则为正常；
- 如果屏幕显示无料，则可能是传感器异常导致误报，请参考下一步。

#### 步骤 2：检查霍尔传感器

- 参考[更换 X2D 工具头外壳](../../maintenance/replace-toolhead-housing.md)，小心移除工具头前盖和中框；
- 手动拨动切料拨杆组件，下降辅助热端；

![right_hotend.webp](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07fe_2000_0002_0002/right_hotend.webp)

- 取下切料组件固定螺丝；

![screw.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07fe_2000_0002_0002/screw.jpg)

- 向上抬起切刀刀柄，插入一小段耗材；

![](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07fe_2000_0002_0002/1.jpg)

观察摇臂是否正常，取出耗材后是否会自动归位。

![20260312-113448.webp](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07fe_2000_0002_0002/20260312-113448.webp)

- 如果摇臂异常，卡住耗材或回弹卡涩，需检查摇臂转轴是否存在异物，并将其清理干净。
- 如果摇臂正常，则霍尔传感器故障，请参考[更换 X2D 挤出机配件](../../maintenance/replace-extruder-components.md)，更换右霍尔检测板。

## 等效代码

如下HMS代码均代表同一类型的故障。

| HMS代码 | 故障描述 |
| --- | --- |
| 07FE-2000-0002-0002 | 未发现左挤出机外部挂载的耗材；请装入新的耗材。 |
| 07FF-2000-0002-0002 | 未发现右（辅助）挤出机外部挂载的耗材；请装入新的耗材。 |
