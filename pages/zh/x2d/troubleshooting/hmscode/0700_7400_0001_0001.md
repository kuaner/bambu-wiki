## 故障描述

在打印发起时如果使用到耗材变轨器，打印中途检测到耗材变轨器离线则提示该问题。若耗材页面变轨器图标消失，或固件页面未显示耗材变轨器及版本信息，通常表示耗材变轨器的 6-pin 线连接不稳定或已断开。

|  |  |
| --- | --- |
|  |  |

## 故障排除

检查耗材变轨器 6-pin 连接线是否都正常插入；若未插紧，请重新插拔 6-pin 线。
