## 故障描述

当辅助挤出机与 AMS 配合使用时，如果退料过程中发生异常，无法把耗材退出辅助挤出机，则会弹出该报错。

可能的原因：

1. 耗材在辅助挤出机内磨损，耗材出现凹坑，导致打滑
2. 挤出机中存在断料
3. 料管弯曲导致耗材阻力过大
4. 工具头进料霍尔异常、辅助挤出机进料霍尔异常
5. AMS 里程轮速度信号异常
6. 缓冲器卡住

## 工具、设备及材料

- H1.5 内六角扳手

## 故障排除

***用户可视情调整各排故措施的顺序。***

### 步骤 1. 手动取出耗材

- 按压料管接头，拔掉缓冲器入料口的料管；

![](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07ff_2000_0002_0008/plug-tube.webp)

- 按压辅助挤出机张紧拨杆，使挤出轮松开对耗材的咬合；在**全程按住张紧拨杆不松开**的状态下，从入料口处缓慢拉出耗材。

|  |  |
| --- | --- |
|  |  |

### 步骤 2. 检查耗材是否存在磨损

检查拉出的耗材是否存在明显磨损痕迹。

![](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07ff_2000_0002_0008/image-1.png)

- 若有磨损，可剪掉磨损部分，或直接从 PTFE 管位置剪断耗材，然后重新插回料管，在屏幕点击“重试”；若故障消除，即可判定故障原因为耗材磨损。
- 若无磨损，请继续下一步。

> 若退料前发生缠料、堵头等异常情况，会导致耗材被辅助挤出机磨损，进而产生表面凹坑或局部直径变细的问题。

### 步骤 3. 检查挤出机是否存在断料

取出耗材后，观察料管内以及屏幕中右喷嘴内是否有料。

|  |  |
| --- | --- |
| 无料状态 | 工具头内有料状态 |

- 如果均无料，则说明正常，可跳过此步骤。
- 如果屏幕显示有料，请尝试拔掉工具头料管，拆掉热端（注意温度防止烫伤），从右挤出机进料口插入一段耗材，观察能否顺利穿出：

  - 如果不能顺利穿出，则需要取出工具头内阻塞耗材，请参考[X2D 堵塞排查指南](../clogging.md)；
  - 如果能顺利穿出，拔出耗材后，查看屏幕右喷嘴是否有料，如果依然为有料状态，则为霍尔开关损坏，请参考[霍尔开关故障排查指南](../../../x1/troubleshooting/filament-sensor-test.md)排除霍尔开关故障。

### 步骤 4. 检查料管是否弯曲、阻力过大

通常工具头料管过于弯曲会导致阻力过大，从而影响正常退料。

**(1) 料管弯折过大**  
向右拨动堵嘴组件拨杆，露出右霍尔检测板的气动接头，用扳手逆时针拧松气动接头，取出料管，再重新插入；  
![20260121-141810.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07ff_2000_0002_0008/20260121-141810.jpg)

**(2) 特殊耗材退料失败**  
若仅特定类型耗材出现退料失败问题（如 PLA-CF 等硬度较高的耗材），**建议使用外挂料盘打印该类耗材**。

### 步骤 5. 检查工具头和辅助挤出机进料霍尔

拆掉工具头前盖，用六角扳手取下右喷嘴的料管夹紧螺母和料管，插入一段耗材；

|  |  |
| --- | --- |
|  |  |

观察屏幕右喷嘴中是否有耗材；拔出耗材后，观察其是否变为无料。

|  |  |
| --- | --- |
| 无料状态 | 工具头内有料状态 |

- 如果插拔耗材时，屏幕的耗材状态未发生变化，请参考[挤出机分解与组装](../../maintenance/replace-extruder-components.md)重新插拔排线后重试。若霍尔开关工作正常但故障未消除，请继续后续排查。

从辅助挤出机进料口或对应的缓冲器进料口（下进料口）插入耗材，直到推不动为止；  
![aux_inlet_filament.png](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07ff_2000_0002_0008/aux_inlet_filament.png)

确认耗材进入辅助挤出机后，观察屏幕中辅助挤出机中是否有料；拔出耗材后，观察其是否变为无料。

|  |  |
| --- | --- |
| 无料状态 | 辅助挤出机内有料状态 |

- 若屏幕显示的耗材状态不变，或与实际情况不符，则为辅助挤出机进料霍尔故障，参考[霍尔开关故障排查指南](../../../x1/troubleshooting/filament-sensor-test.md)排除霍尔开关故障后重试。若霍尔开关工作正常但故障未消除，请继续参考下一步。

### 步骤 6. 检查 HMS 是否存在 AMS 里程轮速度信号异常

若屏幕提示 AMS 里程轮速度信号异常的 hms，请参考[更换 AMS 2 Pro 五通组件和内部五通组件马达](../../../ams-2-pro/maintenance/replace-internal-hub-unit.md)更换 AMS 五通里程轮组件。

### 步骤 7. 检查缓冲器是否卡住

取出耗材后，拨动缓冲器滑块，检查其运动是否顺畅；

![](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07ff_2000_0002_0008/buffer.webp)

若缓冲器滑块卡顿或无法回弹，检查缓冲器弹簧是否出现扭曲。

![20260121-174404.png](https://public-cdn.bblmw.com/wiki/new/x2d/troubleshooting/hmscode/07ff_2000_0002_0008/20260121-174404.png)

- 如果出现扭曲，可使用镊子矫正弹簧；
- 如果未出现扭曲，请参考[更换 X2D 缓冲器](../../maintenance/replace-filament-buffer.md)进行更换。
