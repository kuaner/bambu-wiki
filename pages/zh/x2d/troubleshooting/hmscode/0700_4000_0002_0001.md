## 故障描述

使用 AMS 时，缓冲器（或 AMS 集线器）连接在 AMS 和打印机之间。

缓冲器包含滑块、弹簧和霍尔传感器。当 AMS 将耗材推入工具头挤出机时，耗材产生的压力会推动滑块向前移动。入口处的第一个霍尔传感器用于检测耗材是否进入缓冲器；第二个霍尔传感器位于滑块上方，可检测滑块的位移与位置，并将信号反馈给 AMS 和打印机。若缓冲信号丢失，AMS 将无法正常送料。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/010.png)

## 故障排除

### 步骤 1：重新插拔缓冲器接线

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/011.jpg)

### 步骤 2：检查 6-pin 线缆

检查线缆是否和 AMS 尾部接触良好，用手是否很容易就拔出来，建议使用二代 AMS 配套线缆，线缆区别如下:

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/008.png)

### 步骤 3：检查并重新连接 6-pin 线缆

请检查 6-pin 线缆的引脚是否打开（如下图 4-pin 所示）：

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/007.png)

并尝试重新连接 6-pin 线缆。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/012.jpg)

### 步骤 4：检查 AMS 内部连接

如果问题仍然存在，请参考以下步骤检查 AMS 信号连接线是否松动：

1. 从 AMS 背面按压铁氟龙料管释放按钮，解锁接头，拉出料管；

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/005.png)

2. 从下盖内部捏住卡扣自动弹开铁氟龙料管释放按钮后，从后面抽出铁氟龙料管释放按钮；

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/018.png)

> 捏卡扣时，另一只手需要用从 AMS 的背面扶住铁氟龙料管释放按钮，以避免弹簧被弹出丢失。

3. 拆下中间 2 个料槽的从动支撑套筒组件;

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/006.png)

4. 移除 2 颗螺丝 A (BT3x8);

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/009.png)

5. 将主框架后部完全提起来，竖立放置在 AMS 下盖上。抬起时，建议先抬主框架前部分，再往前推，为框架后部分腾出空间。竖放AMS主框架时需避开风门的电子部件，以防压坏。

|  |  |
| --- | --- |
|  |  |

6. 检查信号连接线是否插到位，如果未插到位，请重新插紧；然后断开信号连接线和电源连接线，抬出中框；

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/017.jpg)

7. 检查信号连接线是否插紧，如果未插到位，请重新插紧。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/001.jpg)

### 步骤 5：测量电压和电阻

1. 如果您有万用表，请将耗材卸载回 AMS，并检查缓冲器的滑块是否位于中间，如下所示：

![](https://public-cdn.bblmw.com/wiki/new/x2d/0700_4000_0002_0001/012.jpg)

然后测量 6 针电缆（从 AMS 上拔下）引脚之间的电压。

|  |  |
| --- | --- |
|  |  |

正常电压应如下。**确保缓冲滑块回到左侧，否则电压值会有所不同。**

**两个电压之和为3.0~3.3V（可以滑动滑块，测量不同位置电压，相加在这个范围内）。**

2. 如果测量的电压在正常范围内，则问题可能出在 AMS 侧。请测量 6 针电缆（插入 AMS）的电阻。正常电阻值如下：

如果测得的电阻值异常，请拆卸 AMS 并测量 AMS 主板上缓冲器 A 和 B 对 GND 的电阻。**正常范围为4~6KΩ。**如果电阻值异常，则 AMS 主板有故障。
