## 故障描述

腔温加热组件由加热组件、腔温切换风门和气流管道组成。它会根据打印机的需求自动切换到特定的气流模式。如果风门组件无法移动到位或无法保持正确位置，系统将无法切换到相应的气流模式。如果风门卡住或校准失败，请按照以下故障排除步骤进行操作。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c000_0001_0001/008.jpg)

## 工具、设备及材料

- H2.0 六角扳手

## 故障定位

1. 当风门处于强力冷却模式时，打开左侧风扇。正常情况下，空气应从左上方（外部循环出口）吹出。金属片会移动到 COLD 位置。
2. 当风门处于腔温保持模式时，打开左侧风扇(开启腔温)。正常情况下，空气应从左侧中间位置（内部加热出口）吹出。金属片会移动到 HOT 位置。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c100_0001_0001/009.jpg)

- 如果实际出风方向与上述描述不符，则可能是风门卡住了，可能是传动部件异常或存在碎屑。
- 如果实际出风口方向与上述描述相符，则可能是霍尔传感器或磁铁出现故障，请检查齿轮磁铁是否错位。

## 故障排除

### **步骤 1：松开腔温加热组件**

参考[更换腔温加热组件指南](../../maintenance/replace-chamber-heater-unit.md)，使用 H2.0 六角扳手移除腔温加热组件的 **3 颗固定螺丝**。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c000_0001_0001/002.jpg)

先向**前门方向**平推，再**向上提起**，小心拉出腔温加热组件**（不用完全移出）**。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c000_0001_0001/001.webp)

### 步骤 2：打开腔温加热组件盖子

移除 **5 颗固定螺丝和黑色醋酸胶带**，打开组件盖板。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c100_0001_0001/006.jpg)

移除加热器上的 **2 颗固定螺丝**并抬起加热器，露出底部的切换电机和接口板。

|  |  |
| --- | --- |
|  |  |

### 步骤 3：检查电机、齿轮、电路板是否损坏

检查电机及线缆是否有 **开裂、变形、烧焦** 等明显异常。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c100_0001_0001/008.jpg)

- 如果是线缆松动，您可以将线缆重新接回即可；
- 如果电机出现开裂、变形、烧焦等，建议[更换腔温加热组件](../../maintenance/replace-chamber-heater-unit.md)。
