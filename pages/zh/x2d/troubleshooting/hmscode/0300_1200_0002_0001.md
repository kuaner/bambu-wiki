## 故障描述

前盖和工具头由磁铁吸附在一起，两侧共有 7 个磁铁和 1 个金属片 8（无磁性）。

![front_cover_8.jpg](https://wiki.bambulab.com/x2d/troubleshooting/hms/0300_1200_0002_0001/front_cover_7.jpg)

**工具头前盖脱落的检测原理**：前盖吸附安装到位时，前盖磁铁使金属片8被磁化，其磁场被工具头内「热端加热组件接口板」上的「霍尔传感器」感应到；前盖脱落后金属片磁性消失，「霍尔传感器」检测不到磁场，即触发本报错。

|  |  |
| --- | --- |
|  |  |
| 工具头前盖和中框 | 接口板与霍尔传感器 |

## 故障排除指南

请先确认工具头前盖当前是否已脱落，再按对应情形处理。

### 情形一：前盖已脱落

手动将前盖重新装回工具头对应位置，确认磁铁吸附到位。然后点击“继续”以恢复打印作业。

![install_toolhead_frontcover.webp](https://wiki.bambulab.com/x2d/troubleshooting/hms/0300_1200_0002_0001/install_toolhead_frontcover.webp)

> **ℹ️ 提示**：若前盖在打印过程中脱落，通常是工具头运动时碰到热床上的残留物（如翘边模型、废料等）所致。建议开启录像功能（「**设置**」→「**录像**」）记录打印过程，如果再次出现前盖脱落的情况，您可以将相应的视频和日志文件发送给我们的客户支持团队，以便进一步分析。  
> ![x2d_screenshot_20260202.png](https://wiki.bambulab.com/x2d/troubleshooting/hms/0300_1200_0002_0001/x2d_screenshot_20260202.png)

### 情形二：前盖未脱落（误报）

若前盖并未脱落但仍出现本报错，请按以下顺序排查：

#### 1. 检查前盖安装状态

检查工具头前盖的 4 颗磁铁是否吸附螺丝、铁屑等异物，以及磁铁是否消磁。并确认前盖线缆连接牢固、安装到位。

![install_front_cover.jpg](https://public-cdn.bblmw.com/wiki/new/x2d/maintenance/replace_hotend_and_sock/install_front_cover.jpg)

#### 2. 检查工具头中框金属片

检查工具头中框左上角的金属片是否有杂物，以免影响磁性。

![middle_cover.jpg](https://wiki.bambulab.com/x2d/troubleshooting/hms/0300_1200_0002_0001/middle_cover.jpg)

#### 3. 检查霍尔传感器

若以上检查均正常，则可能是「热端加热组件接口板」上的「霍尔传感器」故障。可先按以下步骤检查其安装与连接情况；若均正常，则可能需要更换「热端加热组件接口板」。

![hall.jpg](https://wiki.bambulab.com/x2d/troubleshooting/hms/0300_1200_0002_0001/hall.jpg)

请参考 [更换 X2D 工具头电路板](../../maintenance/replace-th-board.md)，检查固定「热端加热组件接口板」支架的两颗螺丝是否松动，确认支架与接口板安装牢固。

|  |  |
| --- | --- |
|  |  |

前盖脱落误报也可能由接触不良或连接器损坏引起。请参考 [更换 X2D 工具头电路板](../../maintenance/replace-th-board.md)，重新插拔「热端加热组件接口板」与「TH 板」之间的排线 1。若错误仍未解决，则可能需要更换「热端加热组件接口板」，请联系客户支持团队。
