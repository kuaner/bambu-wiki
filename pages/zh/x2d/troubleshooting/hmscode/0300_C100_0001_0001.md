## 故障描述

自适应气流系统由腔温加热器切换风门、过滤器切换风门和气流管道组成。它会根据打印机的需求自动切换到特定的气流模式。如果风门组件无法移动到位或无法保持正确位置，系统将无法切换到相应的气流模式。如果风门卡住或校准失败，请按照以下故障排除步骤进行操作。

## 工具、设备及材料

- H2.0 螺丝刀

## 故障定位

### 右侧-自适应风道组件

1. 当风门处于冷却模式（黄色风门露出）时，打开右侧风扇。正常情况下，空气应从右上方（外部循环空气出口）吹出。
2. 当风门处于腔体温保持模式（黄色风门隐藏）时，打开右侧风扇。正常情况下，空气应从右侧中间位置（内部循环空气出口）吹出。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c100_0001_0001/002.webp)

### 左侧-腔温加热组件

1. 当风门处于强力冷却模式时，打开左侧风扇。正常情况下，空气应从左上方（外部循环出口）吹出。金属片会移动到 COLD 位置。
2. 当风门处于腔温保持模式时，打开左侧风扇(开启腔温)。正常情况下，空气应从左侧中间位置（内部加热出口）吹出。金属片会移动到 HOT 位置。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c100_0001_0001/009.jpg)

- **如果实际出风方向与上述描述不符，则可能是风门卡住了，这可能是由于传动部件异常或有碎屑造成的。**
- **如果实际出风口方向与上述描述相符，则可能是霍尔传感器或磁铁出现故障。请检查齿轮磁铁是否错位。**

## 排查步骤

结合关联 HMS 报错，先确认是**左侧腔温加热组件风门**异常，还是**右侧自适应风道风门**异常：

- 右侧风门故障，参照 [自适应风道故障排查指南](../../../p2s/troubleshooting/hmscode/0300_C000_0001_0002.md) 处理。
- 左侧腔温加热组件故障按以下步骤排查。

### 步骤 1：检查自适应气流切换连接

参考 [X2D 背板更换指南](../../maintenance/replace-rear-panel.md) ，使用 H2.0 螺丝刀移除背板固定螺丝，取下打印机背板。

|  |  |
| --- | --- |
|  |  |

检查腔温加热组件线缆接头的卡扣是否连接正常，可尝试重新插拔该线缆。

其中，1 号接头为温度传感器接头，2 号接头为腔温加热组件通讯线缆，**请重点检查 2 号线缆的连接状态**。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c100_0001_0001/001.png)

### **步骤 2：检查腔温切换风门电机和传动组件是否异常**

参考[更换腔温加热组件指南](../../maintenance/replace-chamber-heater-unit.md)，使用 H2.0 六角扳手移除腔温加热组件的 **3 颗固定螺丝**。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c100_0001_0001/005.jpg)

先向**前门方向**平推，再**向上提起**，小心拉出腔温加热组件（不用完全移出）。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c100_0001_0001/003.webp)

移除 **5 颗固定螺丝和黑色醋酸胶带**，打开组件盖板。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c100_0001_0001/006.jpg)

移除加热器上的 **2 颗固定螺丝**并抬起加热器，露出底部的切换电机和接口板。

|  |  |
| --- | --- |
|  |  |

检查电机、齿轮、电路板及线缆是否有 **开裂、变形、烧焦** 等明显异常。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c100_0001_0001/008.jpg)

- 如果是线缆松动，您可以将线缆重新接回即可；
- 如果电机、齿轮、电路板出现开裂、变形、烧焦等，建议[更换腔温加热组件](../../maintenance/replace-chamber-heater-unit.md)。
