## 故障描述

X2D 腔温加热器用于主动加热并稳定腔体内部温度。该故障表示**腔温加热器加热失效、加热丝升温异常**，通常由腔温出风口被遮挡，或加热丝连接线路断路，导致加热丝触发**温控保护开关或保险丝**所引起。

## 工具、设备及材料

- H2.0 螺丝刀
- H1.5 螺丝刀

## 可能原因

- 腔温加热出风口被异物遮挡，或风门切换异常
- 腔温加热丝与 AC 板连接松动、脱落或开路
- 腔温加热组件内部损坏

## 排故措施

### 步骤1. 检查腔温出风口与风门状态;

在打印机屏幕中将**空调系统设为腔温保持模式**，温度设为 **40℃**。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_9100_0001_0008/005.jpg)

**检查腔温出风口是否存在异物遮挡**，并确认风门切换正常（开启腔温加热后，风门切换至正确位置，呈现下方出风、上方不出风状态）。

用手感受左侧出风状态：

- 正常情况：**左侧下方出风口出风**，**左侧上方不出风**。

|  |  |
| --- | --- |
| 出风口 | 不出风 |

### 步骤2. 检查腔温加热丝与AC板的连接。

参考 [X2D 背板更换指南](../../maintenance/replace-rear-panel.md) 移除打印机背板，检查腔温加热组件与 AC 板之间的连接线（红、蓝线缆），确保插头插紧、无松脱、无破损。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_9100_0001_0008/002.png)

参考[AC板更换指南检查](../../maintenance/replace-ac-board.md)， AC 板和 MC 板的接头是否松动。

|  |  |
| --- | --- |
|  |  |

### 步骤3. 更换腔温加热组件

若以上检查均正常，但故障依旧，可以参考 [腔温加热组件更换指南](../../maintenance/replace-chamber-heater-unit.md) 更换腔温加热组件。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_9100_0001_0008/007.png)
