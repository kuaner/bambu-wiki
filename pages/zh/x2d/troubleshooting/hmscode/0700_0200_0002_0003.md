## 故障描述

系统检测到AMS里程轮速度信号存在大幅度跳动，远超过真实料线的速度变化规律，则会判断为里程轮速度信异常。在远程挤出机与AMS配合使用时，退料需要让AMS五通电机与远程挤出机的速度一致，如果AMS里程轮速度信号异常，可能会导致退料失败。

## 可能的原因

- 五通里程轮线缆松脱
- 五通里程轮故障

## 所需工具

H2.0 螺丝刀  
H1.5 螺丝刀

## 排查步骤

1. 参考 AMS 2 Pro 拆装视频，先松开固定AMS主框架的两个螺丝，并抬起AMS 2 Pro的主框架。

|  |  |
| --- | --- |
|  |  |

2. 重新插拔五通里程轮到主板的连接线缆（如下图所示），重新插拔完成后，可以再次发起打印测试。

![2.png](https://wiki.bambulab.com//h2/troubleshooting/hmscode/0700_2000_0002_0014/2.png)

4. 如果仍未解决，则有可能是五通里程轮故障了，需要[更换五通组件](../../../ams-2-pro/maintenance/replace-internal-hub-unit.md)。

![2.png](https://wiki.bambulab.com/ams-2-pro/maintenance/replace-internal-hub-unit/image-14.png)
