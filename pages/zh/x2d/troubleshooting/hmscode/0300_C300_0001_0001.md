## 故障描述

腔温切换风门电流传感器负责实时监测执行电机的运行状态。当风门连接线松动或内部采样电路出现故障时，系统将无法获得准确的电流反馈，从而触发此报错并停止风道切换动作。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c300_0001_0001/003.png)

## 工具、设备及材料

- H2.0 六角扳手

## 可能原因

1. 左侧腔温加热组件排线是否松动或脱落。
2. 腔温切换风门电机或硬件采样电路故障。

## 排查步骤

### **步骤 1：检查腔温加热组件连接线**

参考 [X2D 背板更换指南](../../maintenance/replace-rear-panel.md) ，使用 H2.0 螺丝刀移除背板固定螺丝，取下打印机背板。

|  |  |
| --- | --- |
|  |  |

检查腔温加热组件线缆接头的卡扣是否连接正常，可尝试重新插拔该线缆。

其中，1 号接头为温度传感器接头，2 号接头为腔温加热组件通讯线缆，**请重点检查 2 号线缆的连接状态**。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c300_0001_0001/001.png)

### **步骤 2：检查腔温切换风门电机是否异常**

参考[更换腔温加热组件指南](../../maintenance/replace-chamber-heater-unit.md)，使用 H2.0 六角扳手移除腔温加热组件的 **3 颗固定螺丝**。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c300_0001_0001/005.jpg)

先向**前门方向**平推，再**向上提起**，小心拉出腔温加热组件**（不用完全移出）**。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c300_0001_0001/002.webp)

移除 **5 颗固定螺丝和黑色醋酸胶带**，打开组件盖板。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c300_0001_0001/006.jpg)

移除加热器上的 **2 颗固定螺丝**并抬起加热器，露出底部的切换电机和接口板。

|  |  |
| --- | --- |
|  |  |

检查电机及线缆是否有 **开裂、变形、烧焦** 等明显异常。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_c300_0001_0001/008.jpg)

- 如果是线缆松动，您可以将线缆重新接回即可；
- 如果电机出现开裂、变形、烧焦等，建议[更换腔温加热组件](../../maintenance/replace-chamber-heater-unit.md)。
