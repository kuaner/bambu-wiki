## 故障描述

当系统检测到有 AMS 在线但尚未与耗材变轨器建立绑定关系时，需要通过初始化流程来确定每台 AMS 连接到耗材变轨器的哪一侧进料口（IN-A 或 IN-B）。此告警提示用户需要执行 AMS 初始化操作。

## 故障排除

### 步骤 1. 执行 AMS 初始化

从耗材页面左下角进入 AMS 初始化，或点击“工具 > AMS 初始化”，重新进行一次 AMS 初始化；

|  |  |
| --- | --- |
|  |  |

### 步骤 2. 确认初始化完成

初始化完成后，屏幕上会显示 AMS 与耗材变轨器的连接关系。该 hms 会自动消失。
