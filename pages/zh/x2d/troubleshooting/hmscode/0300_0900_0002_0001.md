## 故障描述

在打印过程中，挤出电机将实时监测挤出力的变化。当检测到挤出力异常时（如耗材卡在挤出机内部、喷嘴堵塞等情况），系统会自动报错并暂停打印任务，需排除故障后方可继续打印。

## 工具、设备及材料

- H2.0 内六角扳手
- H1.5 内六角扳手
- 斜口剪钳/剪刀
- 尖嘴钳

## 故障原因

1. 热端卡扣未安装到位，打印首层时喷嘴剐蹭热床，造成挤出困难；
2. 模型翘曲，导致喷嘴剐蹭；
3. 耗材变形或直径不标准导致卡料，电机出现异响；
4. 打印未充分干燥的 PVA 耗材，造成热端堵头；
5. 热端温度设置异常偏低；
6. 挤出机或热端堵塞。

## 排故措施

#### 步骤1：检查首层打印质量

- 如果此时正在打印首层，喷嘴下移剐蹭热床，**请立即取消当前打印任务，等待热端降至室温，避免高温烫伤**。

降温后，请移除热端硅胶套，检查喷嘴卡扣是否正确锁紧；

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_0900_0002_0001/001.jpg)

如果卡扣安装不正确，请按照正确的方式重新扣紧。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_0900_0002_0001/003.webp)

若热端未明显下移，建议点击屏幕“设置 > 校准 > 打印校准”，执行一次热床自动调平，完成后重新尝试打印；

| --- | --- |
|  |  |

若调平后，热端仍在热床特定位置出现剐蹭，请参考 [P2S & X2D 热床手动调平](../../../p2s/maintenance/manual-bed-tramming.md)执行手动热床调平。

- 如果当前并非打印首层，请参考步骤 2。

#### 步骤2：检查模型是否翘边

- 如果模型翘边，请参考[模型翘边](../../../knowledge-sharing/printed-model-warping.md)解决问题，从而避免热端与模型表面剐蹭。

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_0900_0002_0001/002.png)

- 如果模型未翘边，请参考步骤 3。

#### 步骤3：检查报错是否仅在喷嘴冲刷时发生

- 如果是，请检查最大体积速度是否与所使用的热端类型相匹配。进入 Bambu Studio ，点击耗材编辑，查看耗材的最大体积速度；

|  |  |
| --- | --- |
|  |  |

![](https://public-cdn.bblmw.com/wiki/new/x2d/0300_0900_0002_0001/005.png)

例如，标准流量热端打印 PLA basic 预设的最大体积速度是 25mm³/s，而高流量热端 PLA basic 的预设是 40mm³/s。如果使用标准流量热端打印高流量热端的参数，则可能造成报错挤出电机过载。

- 如果不是，请继续参考步骤4。

#### 步骤4：检查是否使用 PVA 耗材打印

- 打印 PVA 耗材时，**必须确保 PVA 充分烘干**。打印建议如下：

  - 打印前需烘干，建议使用鼓风式烤箱，85 度烘烤 12 小时；
  - 不推荐使用 0.2mm 热端打印。

更多 PVA 耗材打印建议请参考：[PVA 打印指南](../../../filament-acc/filament/pva-printing-guide.md)。

- 如果未使用 PVA 打印，请参考步骤 5。

#### 步骤5：检查热端温度是否与耗材打印的所需温度匹配

若热端温度设置远低于耗材正常打印温度（例如将 PLA Basic 设为 60℃，而非常规 220℃），会导致耗材无法正常挤出。请确认报错时或重试打印时，热端温度是否符合耗材的预设温度。

- 如果热端温度不正常，请设置正确的耗材温度；
- 如果热端温度正常，请参考步骤 6。

#### 步骤6：判断热端或挤出机是否堵塞

请参考 [X2D 堵塞排查](../clogging.md)判断热端和挤出机是否堵塞，并对堵塞的部件彻底清理，再恢复打印。观察问题是否解决。
