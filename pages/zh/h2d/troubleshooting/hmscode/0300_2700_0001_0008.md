## 故障描述

喷嘴偏移校准传感器用于测量左右喷嘴之间的 XY 偏移，以保证双喷嘴协同打印时的对位精度。图中黑色小块即为该传感器。当热端在传感器上移动校准时，如果传感器反馈信号偏弱，系统会触发该告警。

|  |  |
| --- | --- |
| H2D 偏移传感器 | H2C 偏移传感器 |

**可能原因：**

- 喷嘴有残留粘料，导致喷嘴尖端在 Z 方向上距离传感器过远。
- 传感器左右装反，位置方向错误。
- 传感器本身异常（例如连接器接触不良、线缆损坏或内部电路阻值异常）。

## 工具、设备及材料

- H1.5 六角扳手

## 排故措施

***用户可视情调整各排故措施的顺序。***

### 步骤 1. 检查传感器安装方向与紧固状态

- 确认喷嘴偏移校准传感器安装方向，左右未装反。

- 检查固定螺栓是否松动，必要时用 H1.5 六角扳手拧紧。

![](https://wiki.bambulab.com/h2/maintenance/replace-nozzle-offset-calibration-sensor/image-9.png)

### 步骤 2. 清理喷嘴表面残料

- 在打印机控制面板将热端升温到 170°C。
- 使用耐高温毛刷或适当工具清除喷嘴表面残留料，使喷嘴尖端恢复干净形态。
- 清理完成后降温并重试校准。

### 步骤 3. 重新拔插传感器连接

使用 H1.5 内六角扳手移除两颗喷嘴偏移校准线圈的固定螺丝（M2x5），然后向上提起校准线圈，插拔连接线。

| --- | --- |
|  |  |

### 步骤 4. 更换传感器

若以上步骤均不能解决问题，可能为传感器硬件故障。请更换传感器。
