## 故障描述

腔温加热器能主动给腔体提供热量，维持腔内温度稳定。此故障为腔温加热器中的加热丝升温异常，无法将腔温加热至目标温度。  
可能的原因：

- 腔温出风口被遮挡
- 腔温加热器加热丝连接断路

## 故障排除

### 工具、设备及材料

- H1.5 六角扳手

### 故障定位与解决流程

1，检查腔温出风口是否有异物遮挡、或检查风门是否正确切换。  
2，检查腔温加热丝与 AC 板的连接。

## 排查步骤

### 安全提示

> **重要提醒 ！**  
> 在对打印机及其电子设备（包括工具头线缆）进行任何维护工作之前，请关闭打印机电源并断开电源连接，以避免发生屏幕误触或电路短路从而引起额外的电子设备损坏和安全隐患。  
> 在您对打印机进行维护或故障排查时，请先确认热端和热床的温度，避免在高温状态下操作，如果必须在高温状态下操作，请佩戴好隔热手套，以确保安全有效地执行维护工作。

### 步骤 1. 检查异物遮挡

移除出风口外的遮挡物，包括紧贴出风口的高耸打印件。清理出风口上积累的粉尘、异物等。

![image_(1).jpeg](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-9100-0001-0008/image_(1).jpeg)

### 步骤 2. 检查风门切换过程

在空调系统页面，点击 “机箱”，设置高于当前腔温的温度（如：50℃），触发腔温加热，观察各风门状态。

|  |  |
| --- | --- |
|  |  |

正常情况下，以下风门应该处于关闭状态：

|  |  |  |
| --- | --- | --- |
| 顶部自动风门 - 关闭 | 过滤切换风门 - 关闭 | 自动排气格栅 - 关闭 |

若过滤切换风门切换失败，参考该 [Wiki](../../../h2/troubleshooting/hmscode/0300_C000_0001_0002.md) 排查。

### 步骤 3. 检查线缆连接

根据该 [Wiki](../../../h2/maintenance/replace-ac-board-for.md) 拆开背板，先检查 MC 板上 12 号插头是否松脱，再检查 AC 板上加热器线缆是否松脱。若插头存在松动或接触不良，需重新连接。

![image_(5).png](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-9100-0001-0008/image_(5).png)  
![image_(2).jpg](https://wiki.bambulab.com/h2/troubleshooting/hmscode/0300-9100-0001-0008/image_(2).jpg)

### 步骤 4. 更换腔温加热器

若以上措施均无法解决问题，请参考该 [Wiki](../../../h2/maintenance/repalce-right-inner-lining.md) 更换新的腔温加热器。
