## 01.03.00.00 (20260303)

### 新功能

1. 支持远程开启烘干功能

|  |  |
| --- | --- |
|  |  |

2. 支持边烘边打功能，需要注意功率限制和烘干温度不能高于材料的软化温度
3. 支持通过摄像头识别碳化钨喷嘴在位情况
4. 支持左头打印TPU（支持TPU硬度等级>=90A）
5. 支持TPU高流量套件与TPU送料助力模块 (配件会在Q1末上市销售）
6. 支持局域网下不插入U盘发起打印
7. 新增热床底部异物检测
8. 裹头检测功能优化，提升可靠性  
   新增通过实况摄像头采集图像，叠加原本通过喷嘴摄像头采集的图像，配合AI算法，在检测到可能发生裹头时暂停打印，以减小裹头损坏打印机的风险。该功能启用时，建议打开机箱灯，不处于狂暴模式下，以获得更高的检测正确率。该功能可能对黑色深色料的裹头检测较为滞后。
9. 新增AI检测报错弹窗显示实况图像  
   ![ai弹窗.png](https://wiki.bambulab.com/h2/releasenote/ai%E5%BC%B9%E7%AA%97.png)
10. 新增热床低功率模式  
    以便于在用户打印机供电功率受限的情况下，通过延长热床升温时间，降低最大功率
11. 新增认证电子标签信息页  
    ![电子标签.png](https://wiki.bambulab.com/h2/releasenote/%E7%94%B5%E5%AD%90%E6%A0%87%E7%AD%BE.png)
12. 新增打印结束后净化空气选项  
    打印完成后，会自动进行 3 分钟的空气净化。需要 Bambu Studio 2.5.0.64 版本  
    ![打印结束后净化空气.png](https://wiki.bambulab.com/h2/releasenote/%E6%89%93%E5%8D%B0%E7%BB%93%E6%9D%9F%E5%90%8E%E5%87%80%E5%8C%96%E7%A9%BA%E6%B0%94.png)
13. 新增俄语操作语言
14. 新增支持打印机右上角物理按键暂停打印功能
15. 新增打印发起停止后进入停止中状态，此时打印机会屏蔽操作输入直到停止动作结束，避免在停止动作进程中由于插入操作指令导致控制指令时序错乱的问题
16. 新增冷却模式下开启自适应空气循环系统的过滤功能,该功能主要用于低温耗材打印过程中将空气通过过滤器过滤再排出,支持在切片软件中设置该选项或通过UI开关进行操作。切片设置该选项需要使用Studio 2.5.0.64版本  
    ![冷却模式下过滤.jpg](https://wiki.bambulab.com/h2/releasenote/%E5%86%B7%E5%8D%B4%E6%A8%A1%E5%BC%8F%E4%B8%8B%E8%BF%87%E6%BB%A4.jpg)
17. 新增刀切模式下的俯视摄像头初始化
18. 优化耗材编辑页面耗材颜色显示框，新增可显示渐变或双色耗材的能力
19. 新增支持工具头散热增强风扇
20. 新增支持工程材料打印板和增稳低温打印板
21. 新增支持旋转轴加工，需要 Bambu Suite 01.02.00.00 版本  
    新增结合旋转轴附件实现圆柱及旋转体工件的激光加工；结合无接触3D测高算法与运动规划算法，分别完成圆柱体与旋转体的加工路径生成与加工执行。整体流程简洁，将多项功能一键整合，并通过相机拍照实现所见即所得的加工效果。  
    ![旋转轴1.png](https://wiki.bambulab.com/h2/releasenote/%E6%97%8B%E8%BD%AC%E8%BD%B41.png)  
    新增页面可以实时查看旋转轴角度，雕刻前可以通过此页面调整旋转轴到水平，拍摄出更符合实物位置的展开图，并提升雕刻精度  
    ![旋转轴2.jpg](https://wiki.bambulab.com/h2/releasenote/%E6%97%8B%E8%BD%AC%E8%BD%B42.jpg)  
    ![旋转轴3.jpg](https://wiki.bambulab.com/h2/releasenote/%E6%97%8B%E8%BD%AC%E8%BD%B43.jpg)

## 01.02.00.00 (20250813)

### 新功能

1. 新增打印板偏移检测功能

该功能在打印准备阶段通过实况摄像头和工具头摄像头捕捉热床限位块等特征检测打印板是否放到正确对齐的位置，防止打印板干涉、调平异常、打印板边沿打印时越界等问题，**该功能需Bambu Studio更新到V2.2.0.85或更高的版本**。

![打印板偏移cn.png](https://wiki.bambulab.com/h2/releasenote/%E6%89%93%E5%8D%B0%E6%9D%BF%E5%81%8F%E7%A7%BBcn.png)  
2. 新增触碰裹头检测功能

该功能与喷嘴相机裹头检测功能配合，覆盖更全面的打印场景。该功能在打印的第4、11、20层，通过挤出力传感器对喷嘴是否被耗材包裹进行检测。执行检测时，工具头会运动到热床外进行试探触碰，此过程会占用部分打印空间并需由擦料塔吸收喷嘴漏料以防打印瑕疵，在已有擦料塔的模型中会复用擦料塔，在无擦料塔的模型中（如单色模型）中自动新增一个小擦料塔。

**该功能需Bambu Studio更新到V2.2.0.85或更高的版本，并在工艺预设下“其他-高级"中打开**。更多信息请参考[H2D触碰裹头检测功能](../../software/bambu-studio/nozzle-clumping-detection-by-probing.md)

![触碰裹头检测cn.png](https://wiki.bambulab.com/h2/releasenote/%E8%A7%A6%E7%A2%B0%E8%A3%B9%E5%A4%B4%E6%A3%80%E6%B5%8Bcn.png)

3. 新增XY轴清洁与丝杆润滑的维护提醒

在XY轴与丝杆达到维护周期时通过HMS提醒，打印机组件的使用时长从第一次使用开始计算，更新该版本后部分组件可能会弹出提醒，请按指引参考即可，更多清洁维护建议请参考[H2D 定期清洁维护建议](../../h2/maintenance/period-maintenance.md)

![润滑提醒cn.png](https://wiki.bambulab.com/h2/releasenote/%E6%B6%A6%E6%BB%91%E6%8F%90%E9%86%92cn.png)

4. 新增对自动灭火装置（需另购）的支持（需要支持该功能的Bambu Suite版本配合使用）
5. 新增俯视摄像头偏移检测功能:系统检测到俯视摄像头由于长时间使用或震动而出现位置偏移时,会提示用户执行俯视摄像头初始化，以提升整机加工的位置精度

## 01.01.00.00 (20250325)

> 需要更新 [Bambu Studio](https://bambulab.cn/zh-cn/download/studio) 版本至 **2.0.0.95** 及以上  
> 需要更新 [Bambu Suite](https://bambulab.cn/zh-cn/download/suite) 版本至 **1.0.0.0** 及以上  
> 需要更新 [Bambu Handy](https://bambulab.cn/zh-cn/download/app) 版本至 **3.0.0** 及以上

### 新功能

#### 1. 3D打印相关功能

- a. 新增喷嘴相机脏污检测。在打印及准备阶段进行脏污判断，以保证AI算法的可靠性。
- b. 新增喷嘴冷拔维护功能。

![](https://wiki.bambulab.com/h2/releasenote/cn01.png)

- c. 支持开发者模式（适用于3D打印的「仅局域网」模式）：
  - 在3D打印的情况可以启动开发者模式。启用此模式后，授权控制功能将被禁用，打印机将接受所有控制指令，不验证指令来源.
  - 高级用户可通过此模式完全控制打印机的安全性!
  - 有关如何启用开发者模式的详细指南，请参阅 Bambu Lab Wiki：「如何在 Bambu Lab 打印机上使用开发者模式」

![](https://wiki.bambulab.com/h2/releasenote/cn02.png)

- d. 新增高腔温材料发起打印前的关门提醒。

![](https://wiki.bambulab.com/h2/releasenote/cn03.png)

- e. 提高TPU的进料的稳定性，增加TPU进料方式与冷拔的提醒。

![](https://wiki.bambulab.com/h2/releasenote/cn04.png)

  

#### 2.激光、刀切、画笔及其相关功能：

- a. 新增画笔填充工艺。
- b. 新增更换外挂模组但没有再次校准的情况下，加工精度会下降的提醒。

![](https://wiki.bambulab.com/h2/releasenote/cn05.png)

- c. 新增火焰安全页面，展示火焰安全相关的传感器和执行器状态。

![](https://wiki.bambulab.com/h2/releasenote/cn09.png)

- d. 新增易起火加工场景下的人员在位提醒和定时检查功能，确保这些场景下用户始终在机器旁边。

- e. 新增清灰维护提醒，当污染程度达到阈值时提醒用户进行清灰维护。

![](https://wiki.bambulab.com/h2/releasenote/cn07.png)

- f. 新增实况相机脏污检测，避免相机脏污时垫板、材料等的检测结果受到影响。
- g. 新增实体按键暂停功能，任务中可以通过单击实体按键暂停任务。
- h. 支持高物体的激光加工。

  

#### 3.机箱灯模式：

- 支持手动模式和节能模式。在节能模式下，打印机会在空闲时自动关灯，并在必要时打开。  
  **注意：** 激光/模切挂载时，灯光暂时不会关闭。

![](https://wiki.bambulab.com/h2/releasenote/cn08.png)
