## 一、概述

TPU 高流量套件专为提升柔性耗材打印性能而设计，能显著提高打印时的体积流量及运行稳定性。套件内包含专用热端盖及 TPU 规格热端（0.4mm 与 0.6mm）。 TPU 专用热端在结构上与标准 H2 系列热端不同，必须配合 TPU 专用热端盖使用。后续使用中可根据打印需求，在 TPU 热端与标准热端之间灵活切换。

![](https://wiki.bambulab.com/h2/h2d-tpu-high-flow-kit/zh/004.jpg)

**1. 0.6mm TPU 热端**

**2. 0.4mm TPU 热端**

**3. 前导向盖**

**4. 标准热端盖**

**5. TPU 热端盖**

**6. M2x5 热端盖固定螺丝**

> ### 注意事项
>
> - **功能受限**：安装 TPU 热端后不支持安装切刀，切刀功能将无法使用；同时右喷头不支持自动换料及自动进/退料，仅支持外挂料盘打印。
> - **仅限柔性耗材**：TPU 热端喉管带有特殊镀层，**禁止打印硬质耗材**（如 PLA、PETG、**TPU for AMS**），否则会造成镀层磨损失效。
> - **位置限定**：TPU 热端仅建议安装于**右喷头**；若强行装入左喷头，将导致喷头升降功能异常。

## 二、适用机型

- 仅适用于 **H2D** 系列（包括H2D和H2D Pro）

## 三、所需工具和材料

- TPU 高流量套件（含专用热端及前导向盖）
- H1.5 / H2.0 六角螺丝刀

## 六、TPU 热端使用指南

### 5.1 进料操作

在挤出机界面将热端温度加热至 **250℃**，点击向下挤出箭头，手动将耗材送入挤出机。

|  |  |
| --- | --- |
|  |  |

直至观察到喷嘴处有耗材顺畅挤出，即完成进料。

![](https://wiki.bambulab.com/h2/h2d-tpu-high-flow-kit/zh/026.png)

> 如果长时间使用导致喷嘴轻微堵塞，可参考 [H2D 喷嘴冷拔维护清理](../../h2/maintenance/nozzl-cold-pull-maintenance-and-cleaning.md) 使用 PLA 耗材进行冷拔，冷拔过程对特殊镀层的磨损量非常小，可以忽略不计。

### 5.2 退料操作

由于 TPU 热端**不支持切刀**，需要将热端加热到100℃，软化 TPU 耗材后边手动拔出。

![](https://wiki.bambulab.com/h2/h2d-tpu-high-flow-kit/zh/029.png)

到达指定温度后，点击回退耗材按钮，同时手动向上平稳拔出耗材即可。

|  |  |
| --- | --- |
|  |  |

### 5.3 打印说明

#### 5.3.1 打印前准备

**耗材烘干：**

TPU 柔性耗材属于吸潮性材料，受潮后会导致打印时出现气泡、拉丝等问题，因此在打印前，**[必须确保 TPU 耗材完全烘干](../../filament-acc/filament/dry-filament.md)。**

**进料推荐：**

- 仅**右头打印 TPU** 时：90A 及以上硬度耗材建议从 **TPU 专用进料口** 进料。
- **左、右双头均打印 TPU** 时：90A 及以上硬度耗材优先使用**顶置料架**，以降低进料阻力。
- **85A TPU**：仅推荐使用**顶置料架**方案。

顶置料架安装与使用参考：[柔性耗材顶部进料架](https://makerworld.com/en/models/1421552-h2d-flexible-filament-top-feed-rack#profileId-1477010)

![](https://wiki.bambulab.com/h2/h2d-tpu-high-flow-kit/zh/001.webp)

相比于普通进料支架，更推荐使用 [TPU 助力器](https://e.bambulab.com/t?c=jivEkgSbdHdLabWZ)，可进一步优化进料稳定性，减少柔性耗材的拉扯、变形。

![](https://wiki.bambulab.com/h2/h2d-tpu-high-flow-kit/zh/027.png)

#### 5.3.2 推荐参数

为兼顾质量与稳定性，建议按以下思路选择喷嘴与层高：

**1）优先推荐 0.6mm TPU 喷嘴组件**

- 0.6mm 喷嘴通道更大、阻力更小，对柔性耗材更友好；在相同速度下更容易稳定出料，且更适合较高体积流量打印。

**2）层高建议（避免过低层高带来的阻力与波动）**

- **0.4mm 喷嘴**：不推荐使用 **0.2mm 以下层高**。
- **0.6mm 喷嘴**：不推荐使用 **0.3mm 以下层高**。

#### 5.3.3 体积流量

使用 TPU 套件可显著提升 TPU 耗材的打印流量，切片软件需根据喷嘴型号匹配对应参数。

TPU硬度与不同喷嘴流量对应表

| TPU 硬度 | 0.4mm TPU 喷嘴 | 0.4mm 标准喷嘴 | 0.6mm TPU 喷嘴 | 0.6mm 标准喷嘴 |
| --- | --- | --- | --- | --- |
| 85A | 2.2 mm³/s | 不推荐 | 2.2 mm³/s | 2.2 mm³/s |
| 90A | 5.6 mm³/s | 2.8 mm³/s | 5.6 mm³/s | 2.8 mm³/s |

#### Bambu Studio 喷嘴确认

发起打印前需要同步信息，并确认右热端为 **TPU 高流量**。

## 七、标准热端安装步骤（恢复硬质耗材打印）

如果需要打印硬质耗材如 PLA PETG 等，请按以下步骤安装标准热端：

完成退料后，使用 H1.5 内六角螺丝刀拆下 TPU 热端盖，取下 TPU 专用热端。

|  |  |
| --- | --- |
|  |  |

安装标准热端盖，并锁紧 2 颗固定螺丝。

|  |  |
| --- | --- |
|  |  |

> 注意：更换标准热端时，**必须先安装热端盖，再安装右切刀**，顺序错误会导致安装干涉。

安装切刀扭簧及右切刀，将扭簧放入对应槽位。

![](https://wiki.bambulab.com/h2/h2d-tpu-high-flow-kit/zh/024.png)

插入切刀刀柄和刀片，使用 H2.0 内六角螺丝刀锁紧切刀固定螺丝。

|  |  |
| --- | --- |
|  |  |

安装标准热端与硅胶套，并装回工具头前盖。

![](https://wiki.bambulab.com/h2/h2d-tpu-high-flow-kit/zh/036.webp)

标准热端安装完成后，可在**喷嘴和挤出机**界面点击**识别喷嘴信息**，设备将自动识别并设置喷嘴类型；也可手动在**右喷嘴类型**中进行选择。

|  |  |
| --- | --- |
|  |  |

> 拆除注意事项：使用标准热端盖时，若热端盖内残留料头，可松开热端锁扣、拧下热端盖螺丝，将**热端与热端盖一同取下**，再进行清理。
