## 装箱提示

规范打包是避免运输损伤最有效的方式，能最大程度地保障货物安全、减少不必要的经济损失。

> **为确保您的设备安全抵达目的地，我们特别提醒您:**
>
> - **请检查所有螺丝是否拧紧**，防止元件松动。
> - **请确认缓冲海绵是否放置到位**，充分保护设备。

## 操作步骤

### 退料并取下料盘

步骤 1. 点击退料。

![1.png](https://wiki.bambulab.com/a1-packing/1.png)

步骤 2. 取下支架上的料盘。

![2.png](https://wiki.bambulab.com/a1-packing/2.png)

步骤 3. 将耗材卡入料盘的固定孔中。

![3.png](https://wiki.bambulab.com/a1-packing/3.png)

### 拆除打印机上的料管和支架，切断电源

步骤 1. 取下集线器。  
![4.png](https://wiki.bambulab.com/a1-packing/4.png)

步骤 2. 按压工具头入料口接口（推荐使用镊子），拔出料管。

![5.png](https://wiki.bambulab.com/a1-packing/5.png)

步骤 3. 按压料盘支架上的料管接口，拆除料管。

![6.png](https://wiki.bambulab.com/a1-packing/6.png)

步骤 4. 打开卡位，拆下支架。

![7.png](https://wiki.bambulab.com/a1-packing/7.png)

步骤 5. 关闭电源，断开电源线。

|  |  |
| --- | --- |
|  |  |

### 取下打印板，并固定 Z 轴

步骤 1. 取下打印板。

![10.png](https://wiki.bambulab.com/a1-packing/10.png)

步骤 2. 安装 Z 轴限制器的四颗螺丝。**需卡准 Z 轴限制器位置。**

|  |  |
| --- | --- |
|  |  |

> 注意：早期版本中，龙门架没有打孔，可以使用扎带固定 X 轴。

### 锁住工具头，并安装保护泡棉和纸板

步骤 1. 放置工具头泡沫，并将工具头移到泡沫一侧，用扎带固定。

|  |  |  |
| --- | --- | --- |
|  |  |  |

步骤 2. 放置热床防护泡沫，并用扎带固定。

|  |  |
| --- | --- |
|  |  |

### 装箱操作

步骤 1. 将零件装回配件盒，并装回纸板。

|  |  |
| --- | --- |
|  |  |

步骤 2. 在纸箱底部放置防护泡沫。

![20.png](https://wiki.bambulab.com/a1-packing/20.png)

步骤 3. 放置打印机、配件盒。

|  |  |
| --- | --- |
|  |  |

步骤 4. 放入泡沫纸板和配件，并用胶带粘牢。
