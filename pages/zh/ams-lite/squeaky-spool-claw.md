## 何时使用

回转轴卡爪发出异响。

## 所需工具和材料

- 回转轴
- 平头镊子
- 棉签
- 润滑脂

![爪子-工具.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E7%88%AA%E5%AD%90-%E5%B7%A5%E5%85%B7.png)

## 视频指南

## 操作步骤

### 拆卸回转轴

1. 用镊子从卡爪的缝隙处撬起卡爪，取下卡爪。

|  |  |  |
| --- | --- | --- |
|  |  |  |

> 注意：取下卡爪时，避免此部位滑出。  
> ![防止滑落.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E9%98%B2%E6%AD%A2%E6%BB%91%E8%90%BD.png)

2. 以相同方式拆下另外两个卡爪。

![相同方式拆下另外两个.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E7%9B%B8%E5%90%8C%E6%96%B9%E5%BC%8F%E6%8B%86%E4%B8%8B%E5%8F%A6%E5%A4%96%E4%B8%A4%E4%B8%AA.png)

3. 注意底盖卡扣位置，将底盖向左旋转，拆下底盖。

|  |  |  |
| --- | --- | --- |
|  |  |  |

4. 拆下回转轴外壳。

|  |  |
| --- | --- |
|  |  |

5. 拆下回转轴顶盖。

![移除顶盖.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E7%A7%BB%E9%99%A4%E9%A1%B6%E7%9B%96.png)

6. 拆下回转轴弹簧组件。

|  |  |
| --- | --- |
|  |  |

### 涂抹润滑脂

1. 用棉签蘸取润滑脂。

![棉签蘸润滑脂.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E6%A3%89%E7%AD%BE%E8%98%B8%E6%B6%A6%E6%BB%91%E8%84%82.png)

2. 在顶部内圈涂抹润滑脂。

![涂抹内圈.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E6%B6%82%E6%8A%B9%E5%86%85%E5%9C%88.png)

3. 在顶部外圈涂抹润滑脂。

![涂抹外圈.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E6%B6%82%E6%8A%B9%E5%A4%96%E5%9C%88.png)

4. 分别在两端涂抹润滑脂。

|  |  |
| --- | --- |
|  |  |

### 装回回转轴卡爪

1. 装上回转轴弹簧组件。

![放回弹簧组件.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E6%94%BE%E5%9B%9E%E5%BC%B9%E7%B0%A7%E7%BB%84%E4%BB%B6.png)

2. 放置弹簧，将短边装在组件底座上，按紧短边，将长边扣入顶部卡扣中。

|  |  |
| --- | --- |
|  |  |

> **注意弹簧的安装方向**。如果弹簧未正确安装，则回转轴无法自动卷绕线轴，并且可能产生过载错误。  
> ![注意弹簧位置.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E6%B3%A8%E6%84%8F%E5%BC%B9%E7%B0%A7%E4%BD%8D%E7%BD%AE.png)

3. 装上回转轴顶盖。

![装顶盖-.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E8%A3%85%E9%A1%B6%E7%9B%96-.png)

3. 装上回转轴外壳。

![套入外壳.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E5%A5%97%E5%85%A5%E5%A4%96%E5%A3%B3.png)

4. 装上回转轴底盖，向右扭动，扣紧卡扣。

|  |  |
| --- | --- |
|  |  |

5. 装上回转轴的 3 个卡爪。

![装回爪子.png](https://wiki.bambulab.com/ams/squeaky-spool-claw/%E8%A3%85%E5%9B%9E%E7%88%AA%E5%AD%90.png)
