在日常使用 AMS lite 过程中，可以通过上下料组件的 LED 灯状态来判断 AMS lite 是否正常工作。

## 指示灯状态

|  |  |  |
| --- | --- | --- |
| **LED 状态** | **AMS lite 状态** |  |
| 走马灯（4个白灯依次闪烁） | 正常状态，四个槽都没有料 |  |
| 白灯常亮 | 正常状态，有料插入该槽且处于空闲状态 |  |
| 白灯呼吸 | 正常状态，有料插入该槽且处于忙碌状态（送料，读取RFID等） |  |
| 红灯双闪 | 错误状态，可能是进料或退料失败,原因可能包括送料超时、退料超时、耗材打滑、电机过载，需结合工作过程判断。 |  |
| 红灯呼吸 | 错误状态，打印开始后对应槽没放入耗材，**插入耗材后恢复正常**。 |  |
| 4个槽都闪红灯 | 错误状态，AMS通信异常，此时[AMS lite 无法被打印机识别](ams-lite-cannot-be-detected.md) |  |
| LED灯不亮 | 1.当某个槽插入料线后，其余没有料线的空槽的LED灯都不亮，这是正常的  2.当 4 个槽都是空的时候，如果某个槽的 LED 始终不亮，说明是上下料组件供电异常。 | 可参考[AMS lite 上下料组件拆装指引](../../ams/maintenance/ams-lite-feeder.md)重新安装上下料组件线缆，或对调测试 |
