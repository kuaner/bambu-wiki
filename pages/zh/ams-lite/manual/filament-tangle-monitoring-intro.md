## 概述

缠料，通常指的是料盘上的料线缠绕打结，导致在打印过程中，挤出机无法拉动缠绕的料线从而无法继续挤出。而且通常在这种情况下，由于工具头的料线检测传感器内仍检测到有料，所以无法触发断料检测，会造成打印过程中“空打”的现象。

Bambu A1 系列配备了一个缠料检测模块来应对这种情况，当检测到料线打结后，由于送料阻力过大，会触发相应的传感器，打印机便会自动暂停打印并弹出缠料的提醒，用户可以重新整理好料盘上的料线再继续打印，避免打印机出现“空打”的情况。

## 原理介绍

缠料检测模块位于工具头上方，由五通和进料支架组成。五通负责连接四根进料管。进料支架侧边连接着霍尔传感器，内部有个弹簧，五通下方还有个磁铁，把五通和进料支架组装在一起后，五通磁铁就类似一个滑块可以上下移动，这样组成了一个缠料检测模块，它主要是由弹簧+滑块(带磁铁)+传感器组成的。

|  |  |  |
| --- | --- | --- |
|  |  |  |

当进料阻力过大的时候，五通连接的料管这一侧难以送入耗材，而挤出机这一侧仍然在消耗耗材，所以挤出机就会消耗缠料检测模块内部的料线，因此内部的弹簧就被压缩，滑块磁铁也会更靠近霍尔传感器。通过传感器检测滑块位置得到弹簧的压缩量进而得到工具头外的进料阻力。另外弹簧同时提供缓冲的作用，从而在检测到料线阻力过大时仍有足够的缓冲的料线供挤出机消耗，避免出现空打造成打印瑕疵。

![](https://wiki.bambulab.com/ams/ams-lite/filament-tangle-monitoring-intro/缠料.webp)

另外，缠料检测系统的工作还依赖料管和两侧固定件来传递力，因此未安装料管或料管两侧未固定紧时缠料模块不生效。

你可以在显示屏上的**设置** > **打印选项**里开启**缠料检测**功能：

该功能默认开启，若你想手动测试该功能，请注意：

正常的缠料其实是一个料线由松弛变紧绷缓慢的过程，若直接用手用力往回拉料线或直接将料盘往回转动，可能会让料线直接绷紧导致挤出机齿轮与料线打滑，缠料检测模块的缓冲作用消失，容易导致空打造成打印瑕疵。

以 A1 为例（A1 mini 同理），打印过程中，如果触发了缠料检测，分为以下两种情况：

- 不使用 AMS Lite 时：机器会退料并暂停打印，如下动图所示：

![](https://wiki.bambulab.com/n1/manual/filament-tangle-detection/外挂缠料后退料暂停.gif)

- 使用 AMS Lite 时：机器会在吐料组件处，先吐出一小段料，检测缠料模块是否回弹。如果回弹，说明供料阻力恢复正常，则继续打印；否则，它会判断为到工具头外的送料阻力过大（比如：耗材打结），机器会退料并暂停打印。

![](https://wiki.bambulab.com/n1/manual/filament-tangle-detection/ams缠料恢复打印_.gif)

**缠料模块恢复并继续打印**

![](https://wiki.bambulab.com/n1/manual/filament-tangle-detection/ams缠料后退料.gif)

**缠料模块无法恢复，退料暂停打印**

## 缠料检测功能使用限制

缠料检测功能不支持柔性材料，包括 TPU、TPE 或潮湿的水溶性耗材、PVA 耗材。

### 使用外挂料盘打印

打印前，请将料盘正确放置在打印机外挂支架上，料线通过料管送到挤出机中，并确认料管两侧已固定。

![](https://wiki.bambulab.com/a1/manual/first-print-external/开始打印1.png)

触发缠料检测的根本原因是料管一侧的送料阻力过大，挤出机消耗了检测模块内部的料线导致弹簧下压。缠料检测触发后，请检查是否有以下情况：

（1）耗材丝缠绕、打结；

（2）料盘直接放在桌子上或放在干燥箱中；

（3）使用的料管长度过长或者料管弯折严重。

### 使用 AMS lite 打印

> **注意：**如果缠料霍尔传感器出现故障，有时会导致误报错。当打印机进料失败并显示缠料错误，而实际上并没有缠料时，您可以先关闭缠料检测功能，再尝试进料。

请避免使用太硬（即模量过高）或太脆（即韧性不足）的材料，包括第三方纤维增强材料，如 PA-CF/GF、PET-CF/GF 和 PLA-CF/GF 等。

打印前，请将 AMS lite 按照推荐位置放置到打印机旁，如下图所示：

|  |  |
| --- | --- |
| A1 mini | A1 |

使用 AMS lite 打印且触发缠料检测后，请检查是否有以下情况导致料管一侧的送料阻力过大：

（1）耗材丝缠绕、打结；

（2）耗材丝卡在料盘边缘；

（3）AMS lite 摆放位置太远，料管安装方式不正确，导致弯曲太多送料阻力过大；

（4）料盘安装不到位，将料盘放到干燥箱中，再把料线拉到AMS lite里；

（5）AMS lite 的上下料器的挤出轮有料屑（需清理干净）。
